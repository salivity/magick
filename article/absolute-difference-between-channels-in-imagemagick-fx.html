Absolute Difference Between Channels in ImageMagick fx

This article explains how to compute the absolute difference between two color channels within an image using ImageMagick’s -fx operator. You will learn the exact syntax for channel referencing, the mathematical expression required, and practical command-line examples to generate accurate difference maps.

The -fx operator in ImageMagick allows you to evaluate mathematical expressions on an image at a per-pixel level. When using -fx, color channel values are normalized to a floating-point range between 0.0 (minimum intensity) and 1.0 (maximum intensity).

To compute the absolute difference between two channels, such as the Red and Green channels of an image, use the abs() function along with channel selectors. In ImageMagick, the primary input image is referenced as u, and its channels can be accessed using suffixes like .r, .g, and .b.

The core expression is:

abs(u.r - u.g)

Basic Command Example

To compute the absolute difference between the red and green channels of a single image and output the result as a grayscale image, run:

magick input.png -fx "abs(u.r - u.g)" difference.png

For ImageMagick version 6, replace magick with convert:

convert input.png -fx "abs(u.r - u.g)" difference.png

Because -fx defaults to evaluating the expression for every output channel if none is specified, the resulting image will contain identical red, green, and blue channels, effectively yielding a grayscale representation of the channel disparity.

Storing the Result in a Specific Channel

If you want to calculate the difference and write it only to a specific channel (for example, replacing the blue channel with the difference of red and green), restrict the operation using the -channel flag:

magick input.png -channel B -fx "abs(u.r - u.g)" +channel output.png

The +channel flag resets channel selection to prevent subsequent operations from being constrained.

Comparing Channels Across Two Separate Images

To find the absolute difference between a channel in the first image and a channel in a second image, reference the first image as u and the second image as v:

magick image1.png image2.png -fx "abs(u.r - v.r)" channel_diff.png

This subtracts the red channel of image2.png from the red channel of image1.png, applies the absolute value to ensure non-negative results, and saves the comparison.
