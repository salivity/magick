Adaptive Local Thresholding in ImageMagick

This guide explains how to perform adaptive local thresholding across a moving window using ImageMagick's built-in Local Adaptive Threshold (-lat) operator. You will learn the command syntax, how moving window dimensions and offset values interact, and how to effectively binarize images with uneven lighting, gradients, or shadows.

The -lat Operator Syntax

ImageMagick provides the -lat (Local Adaptive Threshold) operator specifically designed to calculate dynamic thresholds across a moving window.

The basic syntax in ImageMagick 7 is:

magick input.png -lat <width>x<height>{+-}<offset>{%} output.png

If you are using ImageMagick 6, replace magick with convert:

convert input.png -lat <width>x<height>{+-}<offset>{%} output.png

Understanding the Parameters

The argument for -lat consists of two primary components:

  1. Window Size (<width>x<height>): Defines the pixel dimensions of the moving window centered on each target pixel. A larger window accounts for broader variations across the image, while a smaller window adapts strictly to fine, local details. For most text-based documents or standard photography, window sizes between 15x15 and 50x50 are standard starting points.
  2. Offset ({+-}<offset>{%}): Adjusts the computed local average. It can be specified as a raw pixel value or as a percentage (%).
    • A positive offset means a pixel must be brighter than the local average plus the offset to become white.
    • A negative offset means a pixel must be brighter than the local average minus the offset to become white.

Practical Examples

1. Standard Document Binarization

To separate dark text from a page with uneven lighting or shadow gradients:

magick input.jpg -colorspace Gray -lat 25x25-10% output.png

This command converts the image to grayscale, applies a \(25 \times 25\) moving window, and sets pixels to white if they are within 10% of the surrounding average, isolating dark text against the background.

2. Inverting Polarity with -negate

Depending on whether your target features are dark or light, the output polarity can be adjusted using -negate:

magick input.jpg -colorspace Gray -negate -lat 30x30+5% -negate output.png

Negating before and after the -lat command allows precise control over high-contrast feature extraction, ensuring that foreground objects remain black while the background is pushed to pure white.

Parameter Tuning Tips

  • Background Noise: If the background contains speckled noise, increase the window size (e.g., from 20x20 to 40x40) or increase the negative offset percentage.
  • Thin or Broken Strokes: If thin lines or small text characters disappear, reduce the window size or decrease the offset to make the threshold less aggressive.
