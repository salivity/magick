Add Canvas Padding in ImageMagick Without Scaling

Adding custom canvas padding in ImageMagick without scaling the original image is achieved primarily using the -extent or -border operators alongside positioning flags. This guide covers the precise command-line syntax required to expand an image canvas, set background colors, and control the exact placement of the original graphic.

Method 1: Using -extent for Fixed Dimensions

The -extent operator adjusts the overall canvas dimensions to a specified width and height without resizing the original image content.

magick input.png -background "#FFFFFF" -gravity center -extent 1200x800 output.png
  • -background "#FFFFFF": Sets the fill color for the padded area (supports color names, hex codes, or none for transparency).
  • -gravity center: Anchors the source image to the center of the new canvas. Other options include North, South, East, West, NorthWest, etc.
  • -extent 1200x800: Defines the final canvas resolution (WidthxHeight).

Method 2: Using -border for Uniform Pixel Padding

To add an exact number of pixels around all sides of an image without calculating the total final resolution, use -border.

magick input.png -bordercolor transparent -border 50x50 output.png
  • -bordercolor transparent: Defines the color of the added border.
  • -border 50x50: Adds 50 pixels of padding to the left/right and 50 pixels to the top/bottom.

Method 3: Asymmetrical Padding with Relative -extent

To add custom, relative padding to specific sides (for example, expanding the canvas by 100 pixels in width and 50 pixels in height relative to the input image):

magick input.png -background black -gravity center -extent "%[fx:w+100]x%[fx:h+50]" output.png
  • %[fx:w+100]: Dynamically calculates the new width by adding 100 pixels to the original width.
  • %[fx:h+50]: Dynamically calculates the new height by adding 50 pixels to the original height.

Method 4: Single-Side Padding Using -splice

To add padding to only one side of an image without affecting other dimensions:

magick input.png -background white -gravity North -splice 0x100 output.png
  • -gravity North: Directs the expansion to the top of the image.
  • -splice 0x100: Inserts 100 pixels of vertical padding at the specified gravity location.
