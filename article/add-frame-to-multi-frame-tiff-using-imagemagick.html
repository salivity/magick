Add Frame to Multi-Frame TIFF Using ImageMagick

This guide explains how to insert an additional frame into an existing multi-frame TIFF image using ImageMagick. Whether you need to append an image to the end, prepend it to the beginning, or place it at a specific index within the sequence, ImageMagick provides dedicated operators and index slicing to modify multi-page files directly from the command line.

Appending a Frame to the End

To add a new frame as the last page of an existing TIFF, pass the original TIFF file first, followed by the new image file, and specify the output filename:

magick existing.tif new_frame.png output.tif

ImageMagick loads all frames from existing.tif, appends new_frame.png to the list, and writes the combined sequence into output.tif.

Prepending a Frame to the Beginning

To add a new frame as the first page (index 0), list the new image before the multi-frame TIFF:

magick new_frame.png existing.tif output.tif

Inserting a Frame at a Specific Position

To insert a frame at an arbitrary position (e.g., making it page 3, which corresponds to index 2 in zero-based indexing), use the -insert operator.

magick existing.tif new_frame.png -insert 2 output.tif

How -insert Works

  1. existing.tif loads all existing frames into the image sequence.
  2. new_frame.png is read and temporarily placed at the end of the sequence.
  3. -insert 2 moves the last image in the sequence to zero-based index 2 (the 3rd page).
  4. output.tif writes the newly ordered sequence to disk.

Inserting Using Frame Ranges

Alternatively, you can extract specific frame ranges and combine them with the new frame. For example, to insert new_frame.png between frame 1 and frame 2 of a 5-frame TIFF:

magick existing.tif[0-1] new_frame.png existing.tif[2-4] output.tif

Preserving TIFF Compression

When writing multi-frame TIFFs, ImageMagick may default to uncompressed output unless specified. To maintain smaller file sizes, specify a compression algorithm such as LZW, ZIP (Deflate), or Group4 (for 1-bit monochrome documents):

magick existing.tif new_frame.png -insert 2 -compress lzw output.tif
