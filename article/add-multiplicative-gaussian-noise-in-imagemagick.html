Add Multiplicative Gaussian Noise in ImageMagick

This guide explains how to apply multiplicative Gaussian noise to an image or canvas using ImageMagick's native operators. Unlike additive noise, multiplicative noise scales proportionally with image pixel values, making it essential for simulating granular film textures, radar speckle, and physical camera sensor degradation.

Applying Noise to an Existing Image

In ImageMagick, multiplicative Gaussian noise is applied using the +noise MultiplicativeGaussian operator. To control the strength of the noise, define the -attenuate setting immediately before the noise operation.

Command Syntax (ImageMagick v7)

magick input.jpg -attenuate 0.5 +noise MultiplicativeGaussian output.jpg

For ImageMagick v6, replace magick with convert:

convert input.jpg -attenuate 0.5 +noise MultiplicativeGaussian output.jpg

Parameter Breakdown

  • -attenuate <factor>: Controls the magnitude and variance of the distribution. A value of 1.0 is default; lower values (such as 0.2 to 0.5) produce subtle noise, while higher values create heavy grain.
  • +noise MultiplicativeGaussian: Multiplies the value of each pixel by a randomized Gaussian distribution centered around 1.0.

Generating a Pure Multiplicative Noise Canvas

To create a standalone noise texture canvas rather than applying noise to a photograph, initialize a canvas with xc: (constant color) and apply the noise operator.

magick -size 800x600 xc:gray50 -attenuate 0.75 +noise MultiplicativeGaussian noise_texture.png

Using a mid-tone baseline such as xc:gray50 allows the multiplicative variance to scale evenly across the dynamic range without immediately clipping highlights or shadows.

Preserving Dynamic Range with HDRI

Because multiplicative noise scales intensities, high values can easily push brighter pixels beyond the maximum 8-bit or 16-bit color boundaries, causing harsh highlight clipping. If you are running an HDRI (High Dynamic Range Imaging) build of ImageMagick, values exceeding 1.0 are preserved in intermediate steps.

To manually restrict values and avoid clipping artifacts on standard builds:

magick input.jpg -attenuate 0.4 +noise MultiplicativeGaussian -clamp output.png

The -clamp operator forces all resulting color channels to remain strictly within the standard dynamic range (0% to 100%) before saving the output.
