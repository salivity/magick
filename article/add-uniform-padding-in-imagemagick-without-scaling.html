Add Uniform Padding in ImageMagick Without Scaling

This guide provides the exact command-line syntax required to add uniform canvas padding around an image using ImageMagick without scaling or distorting the original image pixels. By using the built-in border and extent operators, you can expand the canvas dimensions symmetrically while preserving the source image's original resolution and aspect ratio.

The Recommended Syntax: -border

The simplest and most effective way to add uniform padding without resizing the original image is by using the -border and -bordercolor options.

ImageMagick v7 (Current)

magick input.jpg -bordercolor white -border 20 output.jpg

ImageMagick v6 (Legacy)

convert input.jpg -bordercolor white -border 20 output.jpg

Parameter Breakdown

  • -bordercolor <color>: Sets the color of the padding. You can specify named colors (e.g., white, black, none for transparent), hex codes (e.g., "#ffffff"), or RGB/RGBA values.
  • -border <size>: Specifies the thickness of the padding in pixels.
    • 20: Adds 20 pixels uniformly to all four sides (top, bottom, left, right).
    • 20x10: Adds 20 pixels horizontally (left/right) and 10 pixels vertically (top/bottom).

Example: Adding Transparent Padding

To add uniform padding with a transparent background (typically for PNG images):

magick input.png -background none -bordercolor none -border 50 output.png

Alternative Method: -gravity and -extent

If you need to pad an image to a fixed total canvas size rather than adding a relative pixel border, use -gravity center and -extent:

magick input.jpg -gravity center -background white -extent 1200x1200 output.jpg
  • -gravity center: Keeps the original image positioned centrally without scaling.
  • -background <color>: Defines the fill color for the added canvas area.
  • -extent <width>x<height>: Expands the canvas to the specified dimensions without modifying the inner image dimensions.
