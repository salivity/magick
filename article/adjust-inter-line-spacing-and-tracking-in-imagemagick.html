Adjust Inter-Line Spacing and Tracking in ImageMagick

Controlling typography layout in ImageMagick requires adjusting letter tracking and line height to ensure text renders cleanly across generated graphics. This guide explains how to configure line tracking using the -kerning setting and adjust inter-line spacing using the -interline-spacing setting across ImageMagick command-line operations.

Adjusting Line Tracking with -kerning

In ImageMagick, tracking (or letter-spacing) is managed with the -kerning option. This setting defines the amount of horizontal space added or subtracted between individual characters.

  • Positive values increase the spacing between letters.
  • Negative values decrease the spacing, bringing characters closer together.

Example Syntax

magick -size 600x150 xc:white \
  -font Arial -pointsize 32 -fill black \
  -kerning 5 \
  -gravity center -annotate +0+0 "EXPANDED LETTER SPACING" \
  output_tracking.png

To tighten character spacing instead, use a negative value:

magick -size 600x150 xc:white \
  -font Arial -pointsize 32 -fill black \
  -kerning -2 \
  -gravity center -annotate +0+0 "TIGHT LETTER SPACING" \
  output_tight_tracking.png

Adjusting Inter-Line Spacing with -interline-spacing

Inter-line spacing (often referred to as leading or line-height) is controlled via the -interline-spacing option. It defines the vertical space added or removed between lines of multiline text.

  • Positive values expand the gap between lines.
  • Negative values compress the gap between lines.

Example Syntax

magick -size 500x300 xc:white \
  -font Arial -pointsize 24 -fill black \
  -interline-spacing 15 \
  -gravity center -annotate +0+0 "First Line of Text\nSecond Line of Text\nThird Line of Text" \
  output_linespacing.png

Combining Tracking and Inter-Line Spacing

When creating layouts using text rendering operators like caption: or label:, you can combine -kerning and -interline-spacing before declaring the text source.

magick -background lightblue -fill black \
  -font Helvetica-Bold -pointsize 28 \
  -kerning 3 \
  -interline-spacing 12 \
  -size 400x \
  caption:"ImageMagick allows full control over typography, including custom line spacing and kerning." \
  output_combined.png

Key Considerations

  • Placement Order: In ImageMagick 7 (magick), always specify -kerning and -interline-spacing before defining the -annotate, label:, or caption: operation so that the settings apply to the rendered text.
  • Font Metrics: Different fonts have varying native baselines and kerning tables. Adjust your pixel values proportionally to the -pointsize being used.
