Adjust Lanczos Filter Blur in ImageMagick

Adjusting the blur factor of a Lanczos filter in ImageMagick allows you to fine-tune image sharpness or softness when resizing. By default, the Lanczos filter provides a balanced, sharp result, but you can alter its support radius using the filter:blur definition. This guide explains how to apply and modify this parameter directly in your ImageMagick commands.

The filter:blur Setting

ImageMagick controls the blur factor of resampling filters through the -define filter:blur=value option. This option scales the filter's support size along the x-axis before sampling:

  • Value = 1.0: The default setting with standard Lanczos behavior.
  • Value < 1.0 (e.g., 0.8 to 0.95): Narrows the filter radius, producing a sharper output (note that values that are too low can introduce aliasing or ringing artifacts).
  • Value > 1.0 (e.g., 1.05 to 1.3): Widens the filter radius, introducing additional blurring to smooth out noise or reduce moiré patterns.

Basic Command Syntax

To adjust the blur factor during a resize operation in ImageMagick 7, place the filter selection and define options before the -resize argument:

magick input.jpg -filter Lanczos -define filter:blur=0.85 -resize 800x600 output.jpg

For ImageMagick 6 (legacy), use the convert command:

convert input.jpg -filter Lanczos -define filter:blur=0.85 -resize 800x600 output.jpg

Practical Examples

Sharper Downscaling

To downscale an image while retaining crisp details:

magick input.png -filter Lanczos -define filter:blur=0.8 -resize 50% sharp_output.png

Softened Downscaling (Artifact Reduction)

To reduce ringing artifacts or soften sharp transitions:

magick input.png -filter Lanczos -define filter:blur=1.15 -resize 50% soft_output.png

Applying Blur to 2-Lobe or 3-Lobe Variants

You can pair the blur definition with specific Lanczos variants, such as Lanczos2 (a 2-lobe windowed sinc filter):

magick input.jpg -filter Lanczos2 -define filter:blur=0.9 -resize 1024x768 output.jpg
