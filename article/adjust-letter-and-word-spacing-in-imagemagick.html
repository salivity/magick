Adjust Letter and Word Spacing in ImageMagick

Controlling text layout in ImageMagick requires fine-tuning the space between individual characters and words. This guide provides a direct walkthrough on how to adjust letter spacing (tracking/kerning) and word spacing during text annotation using the -kerning and -interword-spacing command-line settings in ImageMagick.

Adjusting Letter Spacing with -kerning

To control the distance between individual letters, use the -kerning option before defining your text or calling the -annotate operation.

  • Positive values increase the spacing between characters.
  • Negative values decrease the spacing, bringing characters closer together.

Example:

magick input.jpg -font Arial -pointsize 36 -fill white -kerning 5 -annotate +50+100 "Expanded Letter Spacing" output.jpg

To reduce letter spacing:

magick input.jpg -font Arial -pointsize 36 -fill white -kerning -2 -annotate +50+100 "Condensed Letter Spacing" output.jpg

Adjusting Word Spacing with -interword-spacing

To adjust the distance between entire words without altering the spacing between individual letters within a word, use the -interword-spacing option.

  • Positive values add extra space between words.
  • Negative values reduce the default space between words.

Example:

magick input.jpg -font Arial -pointsize 36 -fill white -interword-spacing 15 -annotate +50+100 "Wider Space Between Words" output.jpg

Combining Letter and Word Spacing

You can use both settings simultaneously to achieve precise typographic balance when annotating an image.

Example:

magick input.jpg -font Helvetica-Bold -pointsize 42 -fill "#ffffff" \
  -kerning 3 \
  -interword-spacing 10 \
  -gravity center \
  -annotate +0+0 "Balanced Custom Typography" \
  output.jpg

Applying Spacing to Text Canvases (label: and caption:)

The -kerning and -interword-spacing options also apply when generating text images directly using label: or multi-line caption: operators.

Example:

magick -size 600x200 xc:black -font Arial -pointsize 28 -fill white \
  -kerning 2 -interword-spacing 8 \
  caption:"This is a multi-line text block with custom letter and word spacing." \
  output.jpg
