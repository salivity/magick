Adjust Saturation Without Affecting Luminance in ImageMagick

This guide explains how to increase or decrease color saturation in ImageMagick while preserving the original perceived luminance. By converting images into a perceptually uniform color space like LCH (Lightness, Chroma, Hue) rather than relying on standard HSL modulation, you can modify color intensity cleanly without unintentionally lightening, darkening, or washing out tonal details.

The Problem with Standard -modulate

The standard ImageMagick command for adjusting saturation is -modulate, which operates in the HSL or HSB color spaces by default:

magick input.jpg -modulate 100,150,100 output.jpg

While this method is simple, HSL does not account for human perception of brightness. Increasing saturation in HSL often shifts perceived luminance, making certain colors (like yellow or cyan) appear significantly brighter or causing clipping in high-intensity areas.

The Solution: Using the LCH Color Space

To modify saturation independently of luminance, convert the image to the LCHab (Lightness, Chroma, Hue) color space. In this space:

  • Channel 0 (Red / Lightness): Perceived luminance.
  • Channel 1 (Green / Chroma): Color saturation/intensity.
  • Channel 2 (Blue / Hue): Color tint.

By targeting only the Chroma channel (Channel 1 / Green), you modify the saturation while leaving the Lightness channel completely unaltered.

ImageMagick Command Syntax

1. Increase Saturation (Chroma)

To increase saturation by 40%, multiply the Chroma channel by 1.4:

magick input.jpg -colorspace LCHab -channel G -evaluate multiply 1.4 +channel -colorspace sRGB output.jpg

2. Decrease Saturation (Desaturate)

To reduce saturation by 30%, multiply the Chroma channel by 0.7:

magick input.jpg -colorspace LCHab -channel G -evaluate multiply 0.7 +channel -colorspace sRGB output.jpg

Breakdown of the Command

  • magick input.jpg: Reads the source image.
  • -colorspace LCHab: Converts the pixel data to the perceptually uniform LCH color space.
  • -channel G: Restricts subsequent operations to the second channel (Chroma).
  • -evaluate multiply <factor>: Multiplies the chroma values by the given factor (values greater than 1.0 boost saturation; values between 0.0 and 1.0 reduce it).
  • +channel: Resets the active channel selection so all channels are processed in subsequent steps.
  • -colorspace sRGB: Converts the image back to standard sRGB for output.
  • output.jpg: Saves the processed image.

Legacy Syntax (ImageMagick v6)

If you are using ImageMagick version 6, replace magick with convert:

convert input.jpg -colorspace LCHab -channel G -evaluate multiply 1.4 +channel -colorspace sRGB output.jpg
