Affine Transformations in ImageMagick

Affine transformations allow you to rotate, scale, shear, and translate images while preserving straight lines and parallelism. In ImageMagick, these geometric operations are executed primarily using the -distort Affine and -distort AffineProjection operators. This guide explains how to map coordinate control points, apply transformation matrices, and execute affine transformations directly from the command line.

Method 1: Using Coordinate Pairs (-distort Affine)

The most intuitive way to apply an affine transformation in ImageMagick is by mapping three source coordinate points \((x, y)\) to three destination coordinate points \((u, v)\).

Basic Syntax

magick input.png -distort Affine "x1,y1,u1,v1  x2,y2,u2,v2  x3,y3,u3,v3" output.png

How Control Points Work

  • 1 point pair: Translates (shifts) the image.
  • 2 point pairs: Scales, rotates, and translates the image uniformly.
  • 3 point pairs: Fully defines an affine transformation, allowing independent non-uniform scaling, rotation, shearing, and translation.

Example: Shearing and Scaling

To transform an image with dimensions 500x500 pixels by anchoring the top-left, moving the top-right, and shifting the bottom-left:

magick input.png -distort Affine "0,0,0,0  500,0,450,50  0,500,50,450" output.png

Method 2: Using a Transformation Matrix (-distort AffineProjection)

If you already have calculated transformation matrix coefficients, use -distort AffineProjection.

The matrix takes six coefficients: \[\begin{bmatrix} s_x & r_x \\ r_y & s_y \end{bmatrix} + \begin{bmatrix} t_x \\ t_y \end{bmatrix}\]

  • sx: Scale X
  • rx: Shear/Rotate X
  • ry: Shear/Rotate Y
  • sy: Scale Y
  • tx: Translate X
  • ty: Translate Y

Basic Syntax

magick input.png -distort AffineProjection "sx,rx,ry,sy,tx,ty" output.png

Example: 30-Degree Rotation Matrix

To rotate an image around the origin \((0,0)\) by 30 degrees (\(\cos(30^\circ) \approx 0.866\), \(\sin(30^\circ) = 0.5\)):

magick input.png -distort AffineProjection "0.866,0.5,-0.5,0.866,0,0" output.png

Managing Output Canvas Size

By default, -distort keeps the original image canvas dimensions, which may crop parts of the transformed image.

  • To expand the canvas automatically: Use +distort instead of -distort.
magick input.png +distort Affine "0,0,0,0  500,0,450,50  0,500,50,450" output.png
  • To remove virtual canvas offsets: Append +repage after the distortion if saving to formats like PNG or GIF to prevent positioning issues.
magick input.png +distort Affine "0,0,0,0  500,0,450,50  0,500,50,450" +repage output.png

Setting Background Color and Interpolation

Affine distortions often introduce empty space around the transformed image or require pixel resampling.

  • Set background color for empty areas: Use -background.
  • Set interpolation filter for smoother edges: Use -interpolate.
magick input.png -background transparent -interpolate Bicubic +distort Affine "0,0,20,30  100,0,120,40  0,100,10,130" output.png
