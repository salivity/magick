Align Images for Focus Stacking in ImageMagick

Handheld focus-bracketed photography often introduces subtle framing shifts between consecutive exposures that can ruin an otherwise sharp focus stack. This guide explains how to align slightly shifted handheld exposures using ImageMagick's translation and registration techniques prior to focus stacking, ensuring sharp, artifact-free composites without manual pixel matching.

Prerequisites and Preparation

To align images effectively, ensure all source photos are the same dimensions, format, and color space. Place your source files in a dedicated directory and order them sequentially according to their focus point.

For the best results, pick the sharpest or middle exposure as your anchor (reference) image. All other frames in the sequence will be aligned to this single reference frame.

Method 1: Alignment Using Phase Correlation (Fourier Transform)

ImageMagick 7 supports Fast Fourier Transform (FFT) operations to perform Phase Correlation, which calculates the exact horizontal (X) and vertical (Y) shift between two images.

1. Calculate the Shift Vector

To find the offset between a reference image (ref.jpg) and a shifted image (input.jpg), compute their cross-power spectrum:

magick ref.jpg input.jpg \
  \( -clone 0 -fft \) \
  \( -clone 1 -fft \) \
  \( -clone 0 -clone 2 -compose Multiply -composite \) \
  \( -clone 1 -clone 3 -compose Multiply -composite \) \
  -delete 0-3 \
  -ift -evaluate-sequence Max shift_map.png

2. Extract Coordinates and Reposition

Find the brightest peak in the generated shift map to determine the X/Y translation offset, then apply that offset to the target image:

# Identify the peak pixel location
OFFSET=$(magick shift_map.png -format "%[fx:w/2-maxima.x],%[fx:h/2-maxima.y]" info:)

# Shift the input image to match the reference
magick input.jpg -roll +${OFFSET%,*}+${OFFSET#*,} aligned_input.jpg

Method 2: Automated Translation via Subimage Search

For minor handheld jitter, ImageMagick’s compare tool can locate the best match by searching for a cropped region of the reference image inside the shifted image.

1. Crop a Feature-Rich Region from the Reference

Crop a central bounding box containing high-contrast detail from your anchor image:

magick ref.jpg -gravity Center -crop 80%x80%+0+0 +repage template.png

2. Search and Offset

Locate the offset coordinates where template.png fits best within the shifted image:

magick compare -metric RMSE -subimage-search input.jpg template.png match_%d.png 2>&1

The terminal output will display the offset in @ X,Y format. Use those coordinates to crop or roll input.jpg into precise alignment with ref.jpg.

Merging the Aligned Sequence

Once all frames are shifted to match the reference frame, proceed to focus stacking. ImageMagick can blend the aligned images using a maximum intensity or edge-detection composite:

magick aligned_*.jpg -evaluate-sequence Max focus_stacked_result.jpg

For more complex depth-of-field blending, generate high-pass focus masks for each aligned frame before merging to retain only the in-focus pixels from each exposure.
