Alpha Copy vs Alpha Extract in ImageMagick

In ImageMagick, -alpha copy and -alpha extract are two complementary channel operations used to manipulate transparency masks, but they move image data in opposite directions. While -alpha copy takes the color or grayscale data from an image and applies it directly to the alpha channel to create transparency, -alpha extract takes the existing transparency data from the alpha channel and turns it into a visible grayscale image across the RGB channels. Understanding this directional difference is essential for creating, editing, and debugging alpha masks and cutouts in automated image processing pipelines.

Understanding -alpha extract

The -alpha extract operator pulls transparency data out of the alpha channel and renders it visibly in the color channels.

When you run this operation:

  • ImageMagick copies the alpha values directly into the Red, Green, and Blue channels.
  • Fully transparent areas become pure black, fully opaque areas become pure white, and semi-transparent pixels become corresponding shades of gray.
  • The original alpha channel is then disabled or set to fully opaque.

This command is primarily used to isolate, view, or export an image's matte mask for editing or inspection:

magick input.png -alpha extract mask.png

Understanding -alpha copy

The -alpha copy operator works in reverse: it takes color information and pushes it into the alpha channel to dictate transparency.

When you run this operation on a single image:

  • ImageMagick reads the grayscale intensity (or the red channel, depending on the colorspace) and copies those values directly into the alpha channel.
  • Areas that are black become fully transparent (alpha value of 0), areas that are white become fully opaque (alpha value of 1 or 255/65535), and mid-tone grays receive partial transparency.
  • The original color channels remain unchanged beneath the newly applied transparency.

This command is typically used when you have created or imported a black-and-white silhouette or matte and want to convert that visible mask into functional transparency:

magick mask.png -alpha copy transparent_result.png

Key Differences at a Glance

  • Data Direction: -alpha extract moves data from Alpha to RGB. -alpha copy moves data from RGB to Alpha.
  • Resulting Appearance: -alpha extract outputs a visible black-and-white image representing the mask, with no active transparency. -alpha copy outputs an image with active transparency based on visible pixel brightness.
  • Common Workflow: A common pattern involves using -alpha extract to pull a mask, processing that mask with threshold or blur filters, and then using -alpha copy or composite operators to reapply the modified mask as transparency.
