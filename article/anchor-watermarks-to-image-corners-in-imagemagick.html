Anchor Watermarks to Image Corners in ImageMagick

This guide explains the command-line syntax for positioning and anchoring a watermark logo relative to the corners of an image using ImageMagick. You will learn the core operators for corner placement, how to add margins using offset coordinates, and how to apply transparency for a polished watermark effect across both ImageMagick v7 and v6.

Core Syntax Overview

In ImageMagick, corner anchoring is controlled by two primary options:

  • -gravity: Specifies the anchor point or corner of the canvas.
  • -geometry: Sets the offset (margin/padding) relative to the specified gravity point.

ImageMagick 7 Command

To position a watermark in ImageMagick 7, use the magick tool with the -composite operator:

magick input.jpg watermark.png -gravity SouthEast -geometry +20+20 -composite output.jpg

In this command:

  • input.jpg is the base image.
  • watermark.png is the logo overlay.
  • -gravity SouthEast anchors the watermark to the bottom-right corner.
  • -geometry +20+20 adds a 20-pixel horizontal and vertical margin away from the edges.
  • -composite merges the two layers.

Corner Gravity Values

Replace SouthEast with any of the following compass directions to target different corners:

  • Top-Left Corner: -gravity NorthWest
  • Top-Right Corner: -gravity NorthEast
  • Bottom-Left Corner: -gravity SouthWest
  • Bottom-Right Corner: -gravity SouthEast

The +X+Y coordinates in the -geometry flag always measure inwards toward the center of the image from the specified corner. For example, -gravity NorthEast -geometry +15+15 places the logo 15 pixels from the top edge and 15 pixels from the right edge.

Adding Opacity to the Watermark

To make the anchored watermark semi-transparent, use the dissolve composite operation:

magick input.jpg watermark.png -gravity SouthEast -geometry +20+20 -define compose:args=40,100 -compose dissolve -composite output.jpg

In this command, compose:args=40,100 sets the watermark layer to 40% opacity while keeping the background image at 100% opacity.

Legacy ImageMagick 6 Syntax

If you are using ImageMagick 6, replace magick with convert or use the dedicated composite command:

Using convert:

convert input.jpg watermark.png -gravity SouthEast -geometry +20+20 -composite output.jpg

Using composite:

composite -gravity SouthEast -geometry +20+20 watermark.png input.jpg output.jpg

Note that the composite utility takes the overlay image first, followed by the background image.
