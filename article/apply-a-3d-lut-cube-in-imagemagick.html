Apply a 3D LUT (.cube) in ImageMagick

Applying a 3D LUT (.cube file) to an image in ImageMagick is accomplished using the Hald CLUT (Color Look-Up Table) system. Because ImageMagick utilizes 2D matrix representations of 3D color spaces called Hald CLUTs, applying a .cube file involves generating a neutral Hald identity image, applying your .cube profile to it, and then using ImageMagick's -hald-clut operator to grade the target image.

Step 1: Generate a Neutral Hald Identity Image

ImageMagick can generate a neutral Hald image that acts as a baseline color canvas. Open your terminal and create a Hald identity image:

magick hald:8 hald_identity.png

Note: hald:8 creates a standard 8-bit lookup table (512x512 pixels). For 16-bit or high-dynamic-range workflows, use hald:16.

Step 2: Apply the .cube File to the Hald Image

To bridge the 3D .cube format into ImageMagick's Hald format, render the .cube file onto the generated hald_identity.png. You can do this quickly using FFmpeg's lut3d filter:

ffmpeg -i hald_identity.png -vf "lut3d=file=your_lut.cube" hald_with_lut.png

This transforms your neutral Hald image into a pre-baked lookup table containing all the color adjustments defined in the .cube file.

Step 3: Apply the LUT to Your Image in ImageMagick

Once you have the hald_with_lut.png file, apply it to any image using the -hald-clut command in ImageMagick:

magick input.jpg hald_with_lut.png -hald-clut output.jpg

Combined Single-Command Workflow

If you want to apply a .cube file directly in one automated pipeline without saving intermediate files, pipe the processed Hald CLUT directly into ImageMagick:

ffmpeg -f lavfi -i haldclutsrc=level=8 -vf "lut3d=file=your_lut.cube" -frames:v 1 -f image2pipe -vcodec png - | magick input.jpg - -hald-clut output.jpg

This applies the 3D LUT to input.jpg and produces output.jpg with the color grading applied.
