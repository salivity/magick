Apply a Color Grading LUT to Animation in ImageMagick

This guide demonstrates how to apply a 3D color grading Look-Up Table (LUT) across every frame of an animated GIF or image sequence using ImageMagick. By utilizing ImageMagick’s Hald CLUT pipeline and layer composition, you can adjust the color profile of an entire animation in a single command while preserving frame timing and visual quality.

1. Understanding Hald CLUT in ImageMagick

ImageMagick utilizes Hald CLUT images (a 2D matrix representing a 3D color space) to perform 3D LUT color grading. Before grading an animation, you need a graded Hald image:

  1. Generate a neutral Hald identity image: 
    magick hald:8 hald_identity.png
  2. Apply your color adjustments or import your .cube LUT onto hald_identity.png using an image editor or LUT utility, and save it as lut.png.

2. Apply the LUT to an Animated GIF

To process all frames of an animated GIF in a single operation, use the -compose HaldClut operator combined with -layers composite:

magick input.gif -coalesce null: lut.png -compose HaldClut -layers composite -layers optimize output.gif

Command Breakdown:

  • input.gif -coalesce: Fully reconstructs each frame to prevent artifacting from inter-frame optimization.
  • null:: Inserts a special ImageMagick separator marking the boundary between the animation frames and the LUT.
  • lut.png: The color-graded Hald image.
  • -compose HaldClut -layers composite: Applies the LUT layer-by-layer across every frame in the sequence.
  • -layers optimize: Re-compresses the GIF file size after the color transformation.
  • output.gif: The final graded animation.

3. Processing Image Sequences via Mogrify

If you are working with long animations, video frames, or high-resolution PNG sequences, running the grading step in a batch using mogrify is often faster and uses less memory:

  1. Extract or place your frames in a directory (e.g., frame_0001.png, frame_0002.png, etc.).
  2. Apply the LUT across all frames simultaneously: 
    magick mogrify -hald-clut lut.png frame_*.png
  3. Reassemble the frames into your desired animated format (such as APNG, GIF, or video): 
    magick -delay 4 frame_*.png -loop 0 output.gif
