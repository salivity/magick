Apply a Custom CLUT in ImageMagick

Applying a Color Look-Up Table (CLUT) in ImageMagick allows you to remap the colors of an image using a predefined reference palette or color transformation profile. ImageMagick supports both 1D gradient-based look-up tables via the -clut operator and full 3D color transformations using the -hald-clut operator. This guide covers the commands required to apply both 1D and 3D custom CLUTs to your images efficiently.

1. Applying a 1D CLUT

A standard 1D CLUT uses a single-strip gradient image to remap the luminance or individual channels of a source image to the colors present in the lookup image.

The syntax requires providing the source image first, followed by the CLUT image, and then calling the -clut operator:

magick input.jpg clut_palette.png -clut output.jpg

For ImageMagick v6, replace magick with convert.

2. Applying a 3D Hald CLUT

A Hald CLUT is a 2D representation of a 3D color matrix, making it ideal for complex color grading, film simulations, and tone curves.

To apply a Hald CLUT to an image:

magick input.jpg custom_hald8.png -hald-clut output.jpg

3. Generating and Creating a Custom Hald CLUT

To create your own custom Hald CLUT using standard photo editing software:

  1. Generate an identity Hald image: Generate a default, unaltered Hald image in ImageMagick (level 8 is standard and creates a 512x512 image):

    magick hald:8 identity_hald.png

  2. Apply your color adjustments: Open identity_hald.png in any image editor (such as Photoshop, GIMP, or Lightroom) and apply your desired color grading, contrast, or saturation adjustments. Do not resize or crop the image. Save the modified file as custom_hald.png.

  3. Apply the modified Hald CLUT to your target photo:

    magick photo.jpg custom_hald.png -hald-clut photo_graded.jpg

4. Controlling Color Space and Interpolation

To ensure accurate color reproduction across different color profiles, explicitly set the color space and interpolation method when executing the command:

magick input.jpg custom_hald.png -interpolate Spline -hald-clut output.jpg

The -interpolate Spline or -interpolate Bilinear option smooths the color transitions between LUT sample points, reducing banding in subtle gradients.
