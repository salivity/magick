Apply Bilateral Filter in ImageMagick

The bilateral filter is an advanced image-smoothing tool that reduces unwanted noise and textures while preserving sharp, distinct edges. In this guide, you will learn the exact ImageMagick command syntax, the parameters used to control the filter, and a practical example to process your images effectively.

The Command Syntax

In modern ImageMagick (version 7 and later), the bilateral filter is applied using the -bilateral-blur operator with the magick command:

magick input.jpg -bilateral-blur {radius}x{sigma}+{intensity_sigma}+{spatial_sigma} output.jpg

(For ImageMagick v6, replace magick with convert.)

Parameter Breakdown

The geometry string for -bilateral-blur controls how aggressively the filter smooths colors versus how strictly it respects borders:

  • Radius ({radius}): The maximum distance around each pixel to evaluate. Setting this to 0 allows ImageMagick to compute the optimal radius automatically based on the spatial sigma.
  • Sigma ({sigma}): The standard deviation of the spatial Gaussian filter. It determines the spatial blur range.
  • Intensity Sigma ({intensity_sigma}): Controls edge preservation based on color/intensity difference. Pixels with a color difference greater than this threshold will not be blended together, keeping edges sharp. This can be defined as an absolute value or a percentage (e.g., 10%).
  • Spatial Sigma ({spatial_sigma}): An optional secondary spatial control used to fine-tune coordinate weighting.

Practical Example

To smooth skin tones or flat surfaces in a photograph without blurring structural outlines, run:

magick portrait.jpg -bilateral-blur 0x5+15% smoothed_portrait.jpg

In this command:

  • 0x5 calculates an automatic radius with a spatial blur spread of 5 pixels.
  • +15% ensures that color transitions greater than 15% difference are preserved as hard edges rather than blended.
