Apply Bilinear Distortion in ImageMagick

Bilinear distortion allows you to map any four-point quadrilateral to another quadrilateral, making it ideal for perspective corrections, texture mapping, and warping effects. In ImageMagick, this transformation is achieved using the -distort operator with either BilinearForward or BilinearReverse methods. This guide details the command-line syntax and coordinate mapping structure needed to perform a bilinear distortion on an image.

Understanding the Coordinate Syntax

A bilinear transformation requires four sets of coordinate pairs. Each pair maps a source pixel coordinate (u, v) from the original image to a destination coordinate (x, y) on the output canvas:

u1,v1 x1,y1   u2,v2 x2,y2   u3,v3 x3,y3   u4,v4 x4,y4

The four points typically represent the four corners of the image:

  1. Top-Left
  2. Top-Right
  3. Bottom-Right
  4. Bottom-Left

Applying BilinearForward Distortion

BilinearForward maps the input image coordinates directly to destination coordinates.

Assuming an input image named input.jpg with dimensions 500x500 pixels, use the following command to distort the image corners into an irregular quadrilateral:

magick input.jpg -distort BilinearForward "0,0 50,50  500,0 450,30  500,500 480,460  0,500 20,480" output.jpg

In this command:

  • 0,0 50,50 maps the top-left corner (0,0) to (50,50).
  • 500,0 450,30 maps the top-right corner (500,0) to (450,30).
  • 500,500 480,460 maps the bottom-right corner (500,500) to (480,460).
  • 0,500 20,480 maps the bottom-left corner (0,500) to (20,480).

Preserving Canvas Boundaries with +distort

By default, -distort keeps the original canvas size, which can cause portions of the distorted image to be clipped if they extend outside the original boundary. To automatically expand or adjust the output canvas so the entire warped image remains visible, use +distort instead of -distort:

magick input.jpg +distort BilinearForward "0,0 20,10  500,0 550,40  500,500 520,530  0,500 -20,490" output.jpg

BilinearForward vs. BilinearReverse

  • BilinearForward: Maps forward from source coordinates to destination coordinates. This is the most intuitive method when you know where the four corners of the original image should move.
  • BilinearReverse: Inverts the mapping equation, which can be useful when mapping an existing warped area in a photo back into a flat, rectangular image.
