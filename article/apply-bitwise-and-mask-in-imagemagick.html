Apply Bitwise AND Mask in ImageMagick

Applying a bitwise AND mask to an image allows you to zero out specific bit planes, which is commonly used to eliminate lower-order bits for image compression, posterization effects, or digital forensics and steganography analysis. In ImageMagick, this operation is performed using the -evaluate And operator, which applies a specified bitmask across the color channels of an image.

The Command

To apply a bitwise AND mask and eliminate lower-order bits, use the following command structure:

magick input.png -evaluate And <mask_value> output.png

(Note: If you are using ImageMagick version 6, replace magick with convert.)

How It Works

The -evaluate And operator takes a numerical value (in decimal, hexadecimal, or percentage) and performs a logical bitwise AND comparison on each pixel channel against that value. Any bit set to 0 in the mask is forced to 0 in the output image, effectively stripping away data in those bit positions.

Selecting the Mask Value

ImageMagick builds typically run with a 16-bit quantum depth (Q16), though some operate at 8-bit (Q8). To ensure consistent behavior, you can specify your mask in hexadecimal or set the bit depth explicitly.

8-Bit Quantum (Q8)

To eliminate the lower 4 bits of an 8-bit image (retaining only the 4 most significant bits):

magick input.png -evaluate And 0xF0 output.png
  • 0xF0 (binary 11110000, decimal 240) preserves the upper 4 bits and clears the lower 4 bits.
  • 0xFE (binary 11111110, decimal 254) clears only the least significant bit (LSB).

16-Bit Quantum (Q16)

If your ImageMagick build uses Q16, an 8-bit hex value like 0xF0 will only target the bottom of the 16-bit range. To mask the top-level bits in Q16:

magick input.png -evaluate And 0xF000 output.png

Alternatively, force the image to an 8-bit depth during processing:

magick input.png -depth 8 -evaluate And 240 output.png

Channel-Specific Masking

If you only want to clear the lower bits of specific channels (for example, just the Red channel), use the -channel flag:

magick input.png -channel R -evaluate And 0xF0 +channel output.png

The +channel switch resets the channel selection back to the default so subsequent operations affect all channels normally.
