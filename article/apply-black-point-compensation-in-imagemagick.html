Apply Black Point Compensation in ImageMagick

This article explains how to enable and apply Black Point Compensation (BPC) during ICC profile conversions in ImageMagick. Black Point Compensation adjusts for dynamic range differences between color spaces, preventing dark shadow details from clipping to solid black. You will learn the exact command-line syntax, flags, and configuration settings required to ensure accurate color mapping with LittleCMS integration.

What is Black Point Compensation?

Black Point Compensation (BPC) is a color management feature defined by the International Color Consortium (ICC). When transforming an image between different color profiles (such as sRGB to a CMYK print profile), the darkest achievable black of the source profile may not match the destination profile. BPC scales the source color space's dynamic range to fit the destination space, ensuring that shadow details are preserved rather than clipped.

Enabling BPC in ImageMagick

ImageMagick relies on the LittleCMS (LCMS2) library to handle ICC color profile conversions. To apply Black Point Compensation, you must specify the BPC configuration before applying the target profile.

1. Using the -define lcms:bpc=true Flag (Recommended)

The most reliable cross-version method to enable BPC is using the LCMS definition:

magick input.jpg -define lcms:bpc=true -profile sRGB.icc -profile USWebCoatedSWOP.icc output.jpg

For ImageMagick v6:

convert input.jpg -define lcms:bpc=true -profile sRGB.icc -profile USWebCoatedSWOP.icc output.jpg

2. Using the Direct Option Flag

In recent versions of ImageMagick 7, you can use the direct command-line option:

magick input.jpg -black-point-compensation -profile target_profile.icc output.jpg

Standard Workflow and Command Ordering

Command-line order matters in ImageMagick. Settings like rendering intent and BPC must be declared before the output -profile switch is executed.

Step-by-Step Conversion Example:

magick input.tif \
  -profile /path/to/source_profile.icc \
  -intent Relative \
  -define lcms:bpc=true \
  -profile /path/to/destination_profile.icc \
  output.tif
  • -profile source_profile.icc: Assigns the source profile if the image does not already contain an embedded one.
  • -intent Relative: Sets the rendering intent to Relative Colorimetric. BPC is most commonly paired with Relative Colorimetric intent.
  • -define lcms:bpc=true: Tells LCMS to calculate and match black points across profiles.
  • -profile destination_profile.icc: Performs the transformation into the destination color space.

Verification and Requirements

  1. LCMS Delegate Support: BPC requires ImageMagick to be compiled with LittleCMS support. Verify your installation by running:

    magick -version

    Check the Delegates output to ensure lcms is listed.

  2. Embedded Profiles: If the input image already contains an embedded ICC profile, you do not need to specify the first -profile argument; ImageMagick will use the embedded profile as the source.
