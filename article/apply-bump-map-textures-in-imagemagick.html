Apply Bump Map Textures in ImageMagick

Applying a bump map texture to an image adds realistic surface depth, embossed effects, and simulated lighting to 2D graphics. This guide explains how to use ImageMagick’s built-in composition operators—specifically the Bumpmap compose method and lighting-based blend modes like HardLight—to map grayscale heightmaps onto target surfaces effectively.

Understanding the Bumpmap Composite Operator

In ImageMagick, the -compose Bumpmap operator modifies the brightness of a destination image based on the luminance values of a source image (the bump map). Dark areas in the bump map darken the underlying surface, while light areas brighten it, creating an illusion of 3D depth and surface variation.

Basic Bump Mapping Syntax

To apply a bump map directly to a base image using modern ImageMagick (v7+), use the following command structure:

magick base_image.png bumpmap_texture.png -compose Bumpmap -composite output.png

For ImageMagick v6 legacy commands:

composite -compose Bumpmap bumpmap_texture.png base_image.png output.png

In this setup:

  • base_image.png is the target surface receiving the texture.
  • bumpmap_texture.png is the grayscale heightmap representing surface elevation.

Preparing the Bump Map

For the best visual results, your bump map texture should be a high-contrast grayscale image. You can generate or refine a bump map directly within ImageMagick before applying it:

magick texture.png -colorspace Gray -auto-level prepared_bumpmap.png

Advanced Method: Directional Shading with -shade

While the direct Bumpmap operator alters luminance directly, a more realistic 3D surface effect uses directional light shading combined with blend operators like HardLight or Overlay.

  1. Generate a Shaded Surface: Use the -shade operator with specific azimuth (horizontal angle) and elevation (vertical angle) parameters.
magick heightmap.png -shade 120x45 shaded_map.png
  1. Blend with the Base Image: Composite the shaded map over your base surface using the HardLight composition operator to preserve midtones while transferring highlights and shadows:
magick base_image.png ( heightmap.png -shade 120x45 ) -compose HardLight -composite output.png

Adjusting Texture Intensity

If the bump effect is too intense, you can modulate the strength by adjusting the opacity or contrast of the bump layer before composition:

magick base_image.png ( heightmap.png -shade 120x45 -channel A -evaluate set 50% ) -compose HardLight -composite output.png

Alternatively, adjust the elevation angle in the -shade operator; higher elevation angles (closer to 90 degrees) produce softer shadows, whereas lower angles produce dramatic, high-contrast textures.
