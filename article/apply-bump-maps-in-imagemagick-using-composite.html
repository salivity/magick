Apply Bump Maps in ImageMagick Using Composite

This guide explains how to apply a bump map to a 2D surface using ImageMagick's built-in composite operations. By using a grayscale heightmap to represent surface depth, you can simulate realistic 3D lighting, highlights, and textures directly on flat images via command-line operations.

Understanding the Inputs

Bump mapping requires two primary image files:

  1. Base Image: The flat 2D color surface, texture, or pattern you want to emboss.
  2. Heightmap (Bump Map): A grayscale image where white represents the highest elevations, black represents the lowest depths, and mid-gray represents neutral, flat areas.

Method 1: The Direct Bumpmap Composite Operator

ImageMagick provides a native Bumpmap composition method. In ImageMagick 7, this operator uses the luminance values of the overlay image to modulate the shading of the destination image.

Run the following command in your terminal:

magick base.png heightmap.png -compose Bumpmap -composite output.png

If you are using legacy ImageMagick (version 6), use the composite tool syntax:

composite -compose Bumpmap heightmap.png base.png output.png

In this operation, heightmap.png dictates the surface variation applied across base.png.

Method 2: Shaded Relief Composite (Recommended for Controlled Lighting)

For more realistic and customizable depth, create a directional light source using the -shade operator before blending the result with a composite mode like Hardlight or Overlay.

The -shade operator takes the format <Azimuth>x<Elevation>:

  • Azimuth: The direction of the light source in degrees (e.g., 120 for top-left lighting).
  • Elevation: The angle of the light above the horizon in degrees (e.g., 45 for standard diffuse light).

You can chain this process into a single command:

magick base.png ( heightmap.png -shade 120x45 ) -compose Hardlight -composite output.png

Fine-Tuning the Results

  • Adjust Lighting Angles: Modify the azimuth and elevation parameters (such as 135x30 for longer, dramatic shadows) to change the direction and intensity of highlights.
  • Vary the Blend Mode: If Hardlight produces excessive contrast, switch -compose Hardlight to -compose Overlay for softer integration or -compose Multiply for a darker, etched finish.
  • Pre-blur the Heightmap: Sharp edges in the heightmap can cause harsh, pixelated ridges. Adding -blur 0x1 to the heightmap sub-command smoothens the transitions across the surface:
magick base.png ( heightmap.png -blur 0x1 -shade 120x45 ) -compose Hardlight -composite output.png
