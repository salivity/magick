Apply Color LUT to ImageMagick Animation Frames

Applying a color lookup table (LUT) uniformly to an animated image sequence or GIF in ImageMagick requires breaking the animation into full frames, applying the LUT across every frame in the stack, and then re-optimizing the sequence for output. This guide explains how to properly handle frame disposal, apply 3D Hald CLUTs or 1D standard CLUTs, and export a consistent, color-graded animation without artifacts.

Understanding the Process

Animated formats like GIF often use partial frame updates (frame disposal) to reduce file size. Directly applying a LUT without preparing the sequence can corrupt the animation. The process requires three sequential steps:

  1. Coalescing: Rebuilding each frame into a complete, standalone image.
  2. Applying the LUT: Mapping colors on every frame using either -hald-clut (for 3D color grading) or -clut (for 1D gradient mapping).
  3. Re-optimizing: Compacting identical pixels and frame differences to reduce the final file size.

Applying a 3D Hald CLUT

A Hald CLUT is a 2D representation of a 3D color lookup table. It is the standard format for cinematic color grading in ImageMagick.

ImageMagick 7 Syntax

magick input.gif -coalesce null: lut.png -compose HaldCLUT -layers composite -layers optimize output.gif

Alternatively, you can load the coalesced animation and the LUT image directly with the -hald-clut operator:

magick input.gif -coalesce lut.png -hald-clut -layers optimize output.gif
  • -coalesce: Expands every frame to its full canvas size, resolving any delta-encoded frames.
  • lut.png: The identity Hald image modified by your photo/video grading software.
  • -hald-clut: Applies the color transform uniformly across all preceding frames in the sequence.
  • -layers optimize: Re-applies GIF compression and frame difference optimization to keep file sizes minimal.

ImageMagick 6 Syntax

For older ImageMagick 6 installations, use the convert binary:

convert input.gif -coalesce lut.png -hald-clut -layers optimize output.gif

Applying a 1D Standard LUT

If you are using a standard 1D gradient strip (such as a 256x1 gradient map) to remap grayscale or tone values, use the -clut operator instead of -hald-clut.

magick input.gif -coalesce gradient_lut.png -clut -layers optimize output.gif

Converting Cube LUTs (.cube) to Hald CLUT

ImageMagick does not read .cube files directly. To apply a .cube file to an animation, first generate a Hald CLUT PNG:

  1. Generate an identity Hald CLUT image: 
    magick hald:8 identity.png
  2. Open identity.png in your LUT-editing software, apply your .cube file to it, and export the result as lut.png.
  3. Run the animation command with the exported lut.png.

Key Best Practices

  • Always use -coalesce first: Skipping -coalesce causes ghosting and visual artifacts because intermediate frames only contain pixel changes rather than full color data.
  • Preserve Frame Timing: Using -coalesce and -layers optimize automatically preserves frame delays and loop counts without manual reconfiguration.
  • Format Flexibility: This method works on all animated formats supported by ImageMagick, including animated GIFs, APNGs, and multi-frame TIFFs.
