Apply Custom 3x3 Convolution Matrix in ImageMagick

Applying a custom 3x3 convolution matrix in ImageMagick allows you to perform custom spatial filtering operations such as sharpening, blurring, edge detection, and embossing. This guide provides the exact command-line syntax required to construct and apply a 3x3 convolution kernel using both modern and legacy ImageMagick commands.

Standard Syntax (ImageMagick 6 and 7)

The recommended method to apply a custom convolution matrix is using the -morphology Convolve operator. The matrix is defined by specifying its dimensions followed by a colon and the comma-separated or space-separated weights in row-major order.

ImageMagick 7 Syntax

magick input.png -morphology Convolve "3x3: k1,k2,k3, k4,k5,k6, k7,k8,k9" output.png

ImageMagick 6 Syntax

convert input.png -morphology Convolve "3x3: k1,k2,k3, k4,k5,k6, k7,k8,k9" output.png

In this syntax, k1 through k9 represent the nine numerical values of your 3x3 matrix, ordered from top-left to bottom-right:

Column 1 Column 2 Column 3
k1 k2 k3
k4 k5 k6
k7 k8 k9

Practical Examples

1. Custom Sharpen Matrix

A standard sharpening filter with a central weight:

magick input.png -morphology Convolve "3x3: 0,-1,0, -1,5,-1, 0,-1,0" output_sharpen.png

2. Edge Detection (Sobel Horizontal)

A horizontal gradient operator that highlights horizontal edges:

magick input.png -morphology Convolve "3x3: -1,-2,-1, 0,0,0, 1,2,1" -bias 50% output_edge.png

Note: Adding -bias 50% ensures that negative values produced by edge detection map to neutral gray rather than clipping to black.

3. Box Blur (Normalized)

A uniform blur where each pixel is averaged with its neighbors:

magick input.png -morphology Convolve "3x3: 0.111,0.111,0.111, 0.111,0.111,0.111, 0.111,0.111,0.111" output_blur.png

Legacy Syntax (-convolve)

ImageMagick also supports a simpler legacy operator -convolve, which automatically infers the 3x3 dimensions from a list of nine values:

magick input.png -convolve "0,-1,0,-1,5,-1,0,-1,0" output.png

While -convolve remains functional for backwards compatibility, -morphology Convolve is preferred for modern workflows because it offers better handling of scaling, kernel normalization, and alpha channels.
