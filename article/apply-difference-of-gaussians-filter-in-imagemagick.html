Apply Difference of Gaussians Filter in ImageMagick

The Difference of Gaussians (DoG) bandpass filter is an edge-detection and feature-enhancement algorithm that works by subtracting one blurred version of an image from another with a different blur radius. In ImageMagick, this filter isolates spatial frequencies within a specific band, effectively suppressing high-frequency noise and low-frequency uniform areas. This guide explains how to apply a DoG bandpass filter directly using ImageMagick's built-in morphology kernels and manual Gaussian subtraction commands.

Method 1: Using the Built-in Morphology DoG Kernel

The fastest and most accurate way to apply a DoG bandpass filter is with the -morphology Convolve operator using the DoG kernel syntax.

Syntax:

magick input.png -morphology Convolve "DoG:radius,sigma1,sigma2" output.png
  • radius: The size of the convolution matrix. Setting this to 0 allows ImageMagick to calculate the optimal matrix size automatically.
  • sigma1: The standard deviation of the narrower Gaussian (smaller blur).
  • sigma2: The standard deviation of the wider Gaussian (larger blur).

Example Command:

magick input.png -morphology Convolve "DoG:0,1.0,3.0" output.png

Normalizing the Output

Because a DoG filter generates negative values (where the wider blur is brighter than the narrower blur) and positive values, standard 8-bit image formats can clip the results to black. To visualize the full bandpass frequency response, bias the output so that zero is represented as 50% gray:

magick input.png -define morphology:compose=Lighten -morphology Convolve "DoG:0,1.0,3.0" -bias 50% output.png

Alternatively, you can normalize the dynamic range to stretch the contrast across the full black-to-white spectrum:

magick input.png -morphology Convolve "DoG:0,1.0,3.0" -auto-level output.png

Method 2: Manual Subtraction (Multi-Step Pipeline)

If you need explicit control over how the two blurred images are blended, you can create two separate blurred versions and subtract them manually:

magick input.png \
  \( +clone -gaussian-blur 0x1.0 \) \
  \( +clone -gaussian-blur 0x3.0 \) \
  -delete 0 \
  +swap -compose Mathematics -set option:compose:args "0,1,-1,0.5" -composite \
  output.png
  • -gaussian-blur 0x1.0: Generates the fine-detail blur.
  • -gaussian-blur 0x3.0: Generates the coarse-detail blur.
  • -compose Mathematics -set option:compose:args "0,1,-1,0.5": Subtracts the second blur from the first (Image1 - Image2) and adds a 0.5 (50% gray) offset to preserve negative differences without clipping.

Choosing the Right Parameters

  • Fine Detail / High-Pass Focus: Use smaller, closely spaced sigma values (e.g., DoG:0,0.5,1.0) to isolate thin edges and fine textures.
  • Broad Bandpass / Shape Isolation: Use a wider gap between sigma values (e.g., DoG:0,1.5,5.0) to capture larger structural contours while ignoring fine noise.
