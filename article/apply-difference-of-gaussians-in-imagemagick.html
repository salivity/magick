Apply Difference of Gaussians in ImageMagick

This guide explains how to apply a Difference of Gaussians (DoG) bandpass filter using ImageMagick. You will learn the core concept of the DoG filter, how to execute it efficiently using ImageMagick's built-in convolution kernels, and how to perform manual multi-pass blurring and subtraction for custom frequency isolation.

What is a Difference of Gaussians Filter?

A Difference of Gaussians (DoG) filter is a bandpass filter that enhances edges and specific spatial frequencies in an image. It works by subtracting one Gaussian-blurred version of an image from a second, less-blurred version. This process eliminates high-frequency noise (from the first blur) as well as low-frequency homogeneous regions (via the subtraction), isolating the frequency band in between.

Method 1: Using the Built-In DoG Kernel (Recommended)

ImageMagick provides a direct way to compute a Difference of Gaussians using the -morphology operator with a DoG kernel.

Syntax

magick input.jpg -morphology Convolve "DoG:radius,sigma1,sigma2" output.jpg

(Note: If using ImageMagick 6, replace magick with convert.)

  • radius: The size of the convolution matrix (set to 0 to let ImageMagick calculate it automatically based on sigma).
  • sigma1: The standard deviation of the narrower Gaussian blur (preserves fine details).
  • sigma2: The standard deviation of the wider Gaussian blur (captures broader features).

Example

To isolate mid-frequency details:

magick input.jpg -morphology Convolve "DoG:0,1.0,2.0" -auto-level dog_output.png

Adding -auto-level stretches the dynamic range so that zero-crossings and subtle edges are clearly visible in the final output.

Method 2: Manual Blurring and Image Subtraction

You can also construct the DoG filter manually by cloning the original image, generating two distinct blurred layers, and calculating the difference. This approach gives you granular control over color channels and composition modes.

Example Command

magick input.jpg \
  \( +clone -gaussian-blur 0x1 \) \
  \( +clone -gaussian-blur 0x4 \) \
  -delete 0 \
  -compose minus -composite \
  -auto-level dog_manual.png

Step-by-Step Breakdown:

  1. +clone -gaussian-blur 0x1: Creates the first blurred layer with a small radius (\(\sigma = 1\)).
  2. +clone -gaussian-blur 0x4: Creates the second blurred layer with a larger radius (\(\sigma = 4\)).
  3. -delete 0: Removes the original unprocessed image from the working stack.
  4. -compose minus -composite: Subtracts the heavily blurred image from the lightly blurred image.
  5. -auto-level: Normalizes the contrast of the resulting edge image.

Preserving Negative Values with a 50% Gray Bias

Because the subtraction creates negative values where the second blur is brighter than the first, standard image formats will clip values below zero. To center the zero-frequency point at neutral gray (128 on an 8-bit scale):

magick input.jpg \
  \( +clone -gaussian-blur 0x1 \) \
  \( +clone -gaussian-blur 0x3 \) \
  -delete 0 \
  -compose Mathematics -set option:compose:args "0,1,-1,0.5" -composite \
  dog_biased.png

The mathematical formula applied here is \((1.0 \times \text{Image}_1) - (1.0 \times \text{Image}_2) + 0.5\), shifting the neutral baseline to middle gray without clipping negative edge variations.
