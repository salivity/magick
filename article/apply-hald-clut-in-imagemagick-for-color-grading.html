Apply Hald CLUT in ImageMagick for Color Grading

Hald Color Look-Up Tables (Hald CLUTs) offer a fast, reliable method for transferring complex color grading workflows into automated batch processing. This guide covers how to generate a neutral Hald CLUT identity image, modify it in your preferred image editor to create a custom color preset, and apply the final grade to target images using ImageMagick.

Step 1: Generate a Neutral Identity Hald CLUT

Before creating a color grade, you need a baseline Hald CLUT image containing all original color values. ImageMagick includes a built-in generator for this purpose.

Run the following command to generate a standard 8-bit identity image:

magick hald:8 identity.png

Note: For ImageMagick 6, replace magick with convert.

The parameter 8 generates an image with a color resolution of 8 bits per channel (512x512 pixels), which is sufficient for most standard photographic needs. For 16-bit workflows requiring higher precision, you can use hald:16 (4096x4096 pixels).

Step 2: Apply Your Color Grade to the Identity Image

  1. Open identity.png in any image editing application (such as Adobe Photoshop, GIMP, Darktable, or Lightroom).
  2. Apply your desired color adjustments, including curves, selective color grading, saturation changes, or contrast tweaks.
  3. Important: Do not use spatial effects (like blur, sharpening, or grain), and do not resize or crop the image. Only global color and tone adjustments are supported.
  4. Export the modified image as an uncompressed, lossless format (PNG or TIFF), for example, graded_hald.png.

Step 3: Apply the Hald CLUT to an Image

Once you have your custom graded_hald.png, you can map its color adjustments directly to any target image using ImageMagick's -hald-clut operator.

Run the following command:

magick input.jpg graded_hald.png -hald-clut output.jpg

In this command:

  • input.jpg is your original photo.
  • graded_hald.png is your modified Hald CLUT file.
  • -hald-clut processes the color transformation.
  • output.jpg is the resulting color-graded photo.

Step 4: Batch Processing Multiple Files

To apply the same color grade across multiple images in a directory, you can loop through your files using a shell command.

On Linux / macOS (Bash/Zsh):

for file in *.jpg; do
  magick "$file" graded_hald.png -hald-clut "graded_${file}"
done

On Windows (PowerShell):

Get-ChildItem -Filter *.jpg | ForEach-Object {
    magick $_.Name graded_hald.png -hald-clut "graded_$($_.Name)"
}

This workflow ensures consistent, repeatable color grading across large datasets, video frames, or image libraries directly from the command line.
