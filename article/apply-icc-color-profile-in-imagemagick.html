Apply ICC Color Profile in ImageMagick

Managing color accuracy in digital images often requires applying an external International Color Consortium (ICC) profile to standardize color spaces across different devices. ImageMagick handles color management through the -profile operator, which can either embed a color profile into an image or transform the image data from one color space to another.

Basic Syntax

In ImageMagick version 7, the command uses the magick tool (in version 6, replace magick with convert):

magick input.jpg -profile /path/to/profile.icc output.jpg

How the -profile Operator Works

The behavior of the -profile command depends on whether the source image already contains an embedded ICC profile:

1. Converting to a New Color Space (Image Has an Embedded Profile)

If the input image already has an embedded ICC profile, specifying a new profile converts the pixel values from the current profile to the target profile:

magick input.png -profile /path/to/sRGB.icc output.png

2. Assigning and Converting (Image Has No Embedded Profile)

If the input image lacks an embedded profile, applying -profile once simply assigns (tags) the profile without modifying the raw pixel data. Applying -profile a second time converts the image from the newly assigned source profile to the desired target profile:

magick input.jpg -profile /path/to/AdobeRGB.icc -profile /path/to/sRGB.icc output.jpg

In this command:

  • The first -profile AdobeRGB.icc defines the input color space.
  • The second -profile sRGB.icc transforms the image data into standard sRGB.

Extracting and Stripping Profiles

  • Remove all profiles: Use -strip to discard all metadata and color profiles for reduced file size: 
    magick input.jpg -strip output.jpg
  • Extract an embedded profile: Save the existing ICC profile from an image directly to a file: 
    magick input.jpg profile.icc
