Apply Ordered Dithering in ImageMagick

Ordered dithering is an algorithmic method used to approximate shades and gradients when reducing an image to a limited color palette by applying a repeating threshold matrix. This guide explains how to use ImageMagick's -ordered-dither operator to apply predefined patterns—such as standard Bayer matrices and halftone screens—as well as how to control color depth levels and configure custom threshold maps.

Basic Syntax

In ImageMagick (version 7 and newer), the primary command syntax for applying an ordered dither is:

magick input.jpg -ordered-dither <threshold_map>[,<level>...] output.png

For ImageMagick v6, replace magick with convert.

Predefined Dither Matrices

ImageMagick includes a variety of built-in matrix patterns:

  • Bayer Matrices: o2x2, o3x3, o4x4, o8x8 (standard ordered dither patterns that create classic crosshatch textures).
  • Halftone Dots: h6x6a, h8x8a, h16x16a (angled halftone screens).
  • Circles and Shapes: c5x5b, c5x5w, c6x6b, c6x6w (circular clustered dots).

To list all available threshold maps installed on your system, run:

magick -list threshold

Controlling Color Levels

The -ordered-dither option allows you to define how many distinct color levels each channel should be reduced to.

1-Bit Monochrome (Black and White)

To reduce an image to strictly black and white using an 8x8 Bayer matrix, specify 2 levels (black and white):

magick input.jpg -ordered-dither o8x8,2 output.png

Grayscale with Multiple Levels

To produce a grayscale image with a specific number of tones, such as 4 levels (2-bit gray):

magick input.jpg -colorspace Gray -ordered-dither o8x8,4 output.png

Color Palette Quantization

You can control the red, green, and blue channel depths separately by supplying individual values for each channel:

# 8 levels of Red, 8 levels of Green, 4 levels of Blue (similar to 8-bit color)
magick input.jpg -ordered-dither o8x8,8,8,4 output.png

If only one level argument is provided (e.g., o8x8,4), that level count is applied uniformly to all active image channels.

Applying Custom Dither Matrices

ImageMagick loads its threshold matrices from an XML configuration file named thresholds.xml. To create and use a custom dither matrix:

  1. Locate your configuration directory using magick -list path or create a thresholds.xml file in your working directory or home configuration folder (~/.config/ImageMagick/ on Linux/macOS).
  2. Define a <threshold> element containing the matrix dimensions, divisor, and threshold values:
<thresholdmap>
  <threshold map="custom2x2" alias="c2">
    <description>Custom 2x2 Matrix</description>
    <levels width="2" height="2" divisor="4">
      0  2
      3  1
    </levels>
  </threshold>
</thresholdmap>
  1. Call the custom map directly by the name assigned in the XML:
magick input.jpg -ordered-dither custom2x2,2 output.png
