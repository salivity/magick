Apply Percentage Thresholds in ImageMagick

This article provides a guide on how to apply threshold operations based on a percentage of the maximum quantum value in ImageMagick. By appending a percent symbol (%) to threshold operators, ImageMagick automatically calculates the absolute threshold value relative to your build's specific quantum depth (such as Q8, Q16, or Q32), eliminating the need for manual quantum value calculations across different environments.

Understanding the Quantum Range and Percentages

In ImageMagick, pixel values are stored within a quantum range determined by the build depth:

  • Q8: 0 to 255
  • Q16: 0 to 65,535
  • Q32: 0 to 4,294,967,295

Using an absolute number (e.g., -threshold 128) assumes fixed scale values that can produce different results across different builds. Passing a percentage (e.g., -threshold 50%) scales proportionally to QuantumRange, where 0% is pure black and 100% is maximum quantum intensity (pure white).

Basic Binary Thresholding

To convert an image into binary black and white where pixels above a certain percentage of the quantum limit turn white and all others turn black, use the -threshold option:

ImageMagick v7:

magick input.jpg -threshold 50% output.png

ImageMagick v6:

convert input.jpg -threshold 50% output.png

In this command, any pixel value higher than 50% of the quantum maximum becomes white, while pixels at or below 50% become black.

Grayscale Conversion Before Thresholding

By default, -threshold applies to each color channel independently (Red, Green, Blue). To threshold based on overall image brightness, convert the image to grayscale first:

magick input.jpg -colorspace Gray -threshold 65% output.png

Partial Thresholding: Black and White Thresholds

ImageMagick also provides operators to selectively clamp low or high values while leaving the rest of the image intact.

1. Black Threshold

Forces all pixels below the specified percentage to become black, leaving values above the percentage unchanged:

magick input.jpg -black-threshold 20% output.png

2. White Threshold

Forces all pixels above the specified percentage to become white, leaving values below the percentage unchanged:

magick input.jpg -white-threshold 80% output.png

3. Combining Both Thresholds

You can combine both operators to isolate specific tonal ranges:

magick input.jpg -black-threshold 25% -white-threshold 75% output.png

Channel-Specific Percentage Thresholding

To apply a percentage threshold to a single channel without affecting the others, use the -channel flag:

magick input.jpg -channel R -threshold 40% +channel output.png

This command applies the 40% threshold solely to the Red channel while leaving Green, Blue, and Alpha channels untouched. The +channel resets channel selection back to default.
