Apply Screen Compositing in ImageMagick

This article provides a quick guide on how to lighten overlapping images using the Screen compositing mode in ImageMagick. You will learn the basic command-line syntax for applying the Screen blend operation, how the blend mode works mathematically to brighten pixels, and how to control the intensity of the blend using opacity adjustments.

What is the Screen Composite Mode?

The Screen blend mode multiplies the inverse of the base and overlay image colors, then inverts the result. This always produces a color that is lighter than or equal to both input images.

  • Black pixels in the overlay produce no change (acting as transparent).
  • White pixels in the overlay result in pure white.
  • Mid-tones lighten the underlying image based on their luminosity.

Basic Screen Blending Command

In ImageMagick version 7, you combine images using the magick command with the -compose Screen and -composite operators.

magick base.png overlay.png -compose Screen -composite output.png
  • base.png: The background layer.
  • overlay.png: The layer placed on top to brighten the background.
  • -compose Screen: Sets the compositing operator to Screen.
  • -composite: Executes the blend between the two loaded images.
  • output.png: The resulting blended image.

Legacy Syntax (ImageMagick v6)

If you are using ImageMagick v6, you can use either the convert or composite command:

convert base.png overlay.png -compose Screen -composite output.png

Or using the dedicated composite tool (note the argument order where the overlay comes first):

composite -compose Screen overlay.png base.png output.png

Adjusting the Intensity of the Screen Effect

If the Screen effect is too strong, you can reduce the opacity of the overlay image before blending it onto the base.

magick base.png ( overlay.png -alpha set -channel A -evaluate multiply 0.5 +channel ) -compose Screen -composite output.png
  • ( ... ): Groups the overlay image operations isolated from the base image.
  • -alpha set: Ensures the overlay image has an alpha channel.
  • -channel A -evaluate multiply 0.5 +channel: Lowers the transparency to 50%, reducing the overall brightness contribution of the overlay.

Common Use Cases

  • Light Leaks and Lens Flares: Adding lighting effects saved against black backgrounds onto a photograph.
  • Double Exposures: Blending high-contrast images to create artistic overlays.
  • Texture Overlays: Adding dust, scratches, or paper textures without darkening the underlying image.
