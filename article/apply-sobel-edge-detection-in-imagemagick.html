Apply Sobel Edge Detection in ImageMagick

This guide demonstrates how to apply a Sobel edge detection filter using ImageMagick's convolution tools. You will learn the principles of the Sobel operator, how to run the built-in directional Sobel kernels using morphology convolution, and how to define custom 3x3 convolution matrices to extract horizontal, vertical, and combined gradient edges from an image.

Understanding the Sobel Kernels

The Sobel operator computes image intensity gradients using two 3x3 convolution matrices: one for horizontal changes (\(G_x\)) and one for vertical changes (\(G_y\)).

Horizontal Kernel (\(G_x\)):

-1  0  1
-2  0  2
-1  0  1

Vertical Kernel (\(G_y\)):

-1 -2 -1
 0  0  0
 1  2  1

Method 1: Using Built-in Sobel Morphology Kernels

ImageMagick provides built-in Sobel kernels via the -morphology Convolve operator. Before applying edge detection, convert the image to grayscale to focus on luminance changes.

1. Horizontal Edges (\(G_x\))

magick input.jpg -colorspace Gray -morphology Convolve Sobel output_horizontal.jpg

2. Vertical Edges (\(G_y\))

To rotate the kernel 90 degrees for vertical edge detection, append >:

magick input.jpg -colorspace Gray -morphology Convolve Sobel:> output_vertical.jpg

Method 2: Defining Custom 3x3 Convolution Matrices

If you need precise control over the weights, you can specify custom user-defined 3x3 convolution kernels directly.

Custom Horizontal Matrix:

magick input.jpg -colorspace Gray \
  -define convolve:scale='!' \
  -morphology Convolve "3x3: -1,0,1 -2,0,2 -1,0,1" \
  output_sobel_x.jpg

Custom Vertical Matrix:

magick input.jpg -colorspace Gray \
  -define convolve:scale='!' \
  -morphology Convolve "3x3: -1,-2,-1 0,0,0 1,2,1" \
  output_sobel_y.jpg

Note: The -define convolve:scale='!' flag prevents ImageMagick from automatically normalizing the matrix, preserving the standard Sobel gradient values.

Method 3: Combining Horizontal and Vertical Gradients

To generate a complete Sobel edge map, compute both directional gradients and combine them to determine the total edge magnitude (\(\sqrt{G_x^2 + G_y^2}\)).

magick input.jpg -colorspace Gray \
  \( -clone 0 -morphology Convolve Sobel \) \
  \( -clone 0 -morphology Convolve Sobel:> \) \
  -delete 0 \
  -solarize 50% -evaluate multiply 2 \
  -compose Mathematics -set option:compose:args "0,1,1,0" -composite \
  sobel_full_edges.jpg

Legacy ImageMagick 6 Syntax

If using ImageMagick 6, replace magick with convert:

convert input.jpg -colorspace Gray -morphology Convolve Sobel output_sobel.jpg
