Assign ICC Profile in ImageMagick Without Conversion

Assigning an ICC color profile to an image tags the file with color space metadata without altering the underlying RGB or CMYK pixel values, unlike color profile conversion which recalculates pixel data to match a new color space. This guide explains how to use ImageMagick to safely embed or replace an ICC profile strictly as metadata, ensuring your raw pixel values remain unchanged.

The Difference Between Assigning and Converting

When using standard ImageMagick commands, the -profile operator behaves differently depending on whether the image already contains an embedded profile:

  • If the image has no profile, -profile filename.icc embeds the profile without modifying pixel values (assignment).
  • If the image already has a profile, -profile filename.icc transforms the image's pixel data from the source profile to the target profile (conversion).

To ensure that pixel values are never recomputed, you must bypass the color transformation engine.

Method 1: Using the -set profile Operator (Recommended)

The most direct way to assign an ICC profile without altering pixel data is using the -set profile operator. This explicitly sets the profile metadata property without invoking the color management module.

ImageMagick v7:

magick input.jpg -set profile "path/to/profile.icc" output.jpg

ImageMagick v6:

convert input.jpg -set profile "path/to/profile.icc" output.jpg

Even if input.jpg already contains an embedded profile, -set profile overwrites the existing profile metadata directly, leaving the pixel values intact.

Method 2: Stripping and Re-applying the Profile

Another approach is to remove the existing profile before attaching the new one. Because ImageMagick only converts pixels when transitioning from an existing profile to a new one, stripping the profile first forces the subsequent -profile flag to act purely as an assignment.

Using +profile:

magick input.jpg +profile "icc" -profile "path/to/profile.icc" output.jpg
  • +profile "icc": Strips any existing ICC profile from the image.
  • -profile "path/to/profile.icc": Embeds the new profile into the profile-less image without recalculating pixels.

Verifying the Assigned Profile

To verify that the ICC profile was successfully embedded without inspecting pixel data manually, use the identify command:

magick identify -verbose output.jpg | grep -i "Profile-icc"

To confirm pixel values remained completely identical, you can compare the original and modified images using the RMSE (Root Mean Squared Error) metric:

magick compare -metric RMSE input.jpg output.jpg null:

A result of 0 (0) confirms that no pixel data was modified during the profile assignment process.
