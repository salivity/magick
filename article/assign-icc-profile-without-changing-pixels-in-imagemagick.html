Assign ICC Profile Without Changing Pixels in ImageMagick

Assigning an ICC profile to an untagged image allows color-managed applications to interpret its color space correctly without modifying the image's raw pixel values. This guide explains how to use ImageMagick's profile options to embed a color profile as metadata into an untagged image without performing color space conversions or pixel alterations.

Understanding Assignment vs. Conversion

In color management:

  • Assigning a profile simply attaches the ICC metadata to the file, defining how existing pixel values should be interpreted without changing the underlying numerical RGB or CMYK data.
  • Converting transforms the numerical pixel values from one color profile to another.

In ImageMagick, the behavior of the -profile switch depends on whether the source file already contains an embedded profile.

The Command to Assign an ICC Profile

When an image contains no embedded profile, applying a single -profile operation assigns the specified profile without converting or recalculating any pixel values.

For ImageMagick v7:

magick input_untagged.jpg -profile /path/to/profile.icc output_tagged.jpg

For ImageMagick v6:

convert input_untagged.jpg -profile /path/to/profile.icc output_tagged.jpg

Ensuring No Prior Profile Exists

If you are unsure whether the input image is truly untagged, stripping existing metadata before applying the new profile ensures that a conversion does not occur:

magick input.jpg -strip -profile /path/to/sRGB.icc output.jpg

The -strip option removes all embedded profiles and metadata first. The subsequent -profile argument then strictly assigns the new profile rather than executing a color conversion.

Verifying the Pixel Values

To verify that the underlying pixel data has remained unchanged after assigning the profile, compare the image checksums before and after with profiles stripped:

magick input.jpg -strip -format "%#" info:
magick output.jpg -strip -format "%#" info:

If both signatures match, the raw image data is identical and only the ICC color profile metadata was added.
