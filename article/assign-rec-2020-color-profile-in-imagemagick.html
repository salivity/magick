Assign Rec.2020 Color Profile in ImageMagick

This guide explains how to assign an untagged photograph the Rec.2020 (ITU-R BT.2020) wide-gamut color profile using ImageMagick. You will learn the difference between assigning and converting color profiles, the exact ImageMagick commands required for untagged images, and how to verify that the ICC profile has been successfully embedded into the output file.

Assigning vs. Converting Profiles

When an image is untagged, image viewers typically assume the image is in the standard sRGB color space.

  • Assigning a profile attaches color space metadata to an image without changing its underlying RGB pixel values. It tells software to interpret the existing pixel values using the Rec.2020 color coordinates.
  • Converting a profile recalculates pixel values to preserve visual appearance when moving from one color space to another.

Because your image is untagged, you need to assign the profile so color-managed applications render the wide-gamut colors correctly.

Prerequisites

To assign the profile, you must have an official Rec.2020 ICC file on your system (often named Rec2020.icc, BT2020.icc, or ITUR_2020.icc). These can be obtained from standard ICC profile repositories or your operating system's color management directory.

The ImageMagick Command

In ImageMagick, the -profile operator assigns a profile when used on an image that contains no existing embedded profile.

ImageMagick 7 (Recommended)

magick untagged_photo.jpg -profile /path/to/Rec2020.icc tagged_photo.jpg

ImageMagick 6

convert untagged_photo.jpg -profile /path/to/Rec2020.icc tagged_photo.jpg

How ImageMagick Processes -profile

  • When an image has no embedded profile, the first -profile option simply embeds the specified ICC profile (an assignment).
  • If you run a second -profile flag in the same command, ImageMagick will transform the pixel data to that second color space (a conversion).

If you are unsure whether the input file is completely free of color profile metadata, you can strip existing profiles prior to assigning Rec.2020:

magick untagged_photo.jpg +profile "icc,icm" -profile /path/to/Rec2020.icc tagged_photo.jpg

Verifying the Embedded Profile

To confirm that the Rec.2020 profile has been successfully embedded into the file, inspect the image metadata using the identify tool:

magick identify -verbose tagged_photo.jpg | grep -i "Profile-icc"

You can also display the full profile description to confirm the Rec.2020 designation:

magick identify -format "%[icc:description]\n" tagged_photo.jpg

If the profile was applied correctly, the output will display the name of your Rec.2020 profile.
