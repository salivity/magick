Assign Rec.2020 Color Profile with ImageMagick

Untagged images lack embedded metadata that instructs rendering software on how to correctly interpret their color values. This guide explains how to assign a generic Rec.2020 (ITU-R Recommendation BT.2020) color profile to an untagged image using ImageMagick, establishing a wide color gamut interpretation without modifying the underlying pixel data.

Understanding Profile Assignment in ImageMagick

In color management, assigning a profile defines how existing pixel values are interpreted, whereas converting recalculates pixel values to fit a different color space.

When you apply the -profile operator to an untagged image (an image with no existing embedded ICC profile), ImageMagick automatically assigns the specified profile without re-encoding the pixel values.

Step 1: Obtain a Rec.2020 ICC Profile

ImageMagick does not include built-in color profiles in standard installations. You must have a generic Rec.2020 .icc or .icm file on your system. You can obtain standard Rec.2020 profiles from color management packages such as ArgyllCMS, Elle Stone’s Well-Behaved ICC Profiles, or standard operating system display directories.

Save the profile locally (for example, as Rec2020.icc).

Step 2: Run the ImageMagick Command

To assign the profile, run the magick command (ImageMagick v7) or convert command (ImageMagick v6) and specify the path to your Rec.2020 ICC file.

For ImageMagick v7:

magick untagged_image.png -profile "/path/to/Rec2020.icc" tagged_image.png

For ImageMagick v6:

convert untagged_image.png -profile "/path/to/Rec2020.icc" tagged_image.png

Because the input image has no existing embedded profile, passing the -profile flag once embeds the Rec.2020 metadata into the output file.

Step 3: Verify the Profile

To confirm that the Rec.2020 profile was successfully embedded, use the identify tool:

magick identify -verbose tagged_image.png | grep "Profile-icc"

Alternatively, to inspect the profile description directly:

magick identify -format "%[icc:description]\n" tagged_image.png

The output should confirm the profile name as Rec.2020 or BT.2020.
