Auto-Crop Multiple Scans with ImageMagick

This guide explains how to automatically detect, crop, and separate multiple photos or documents scanned together on a flatbed scanner into individual image files using ImageMagick. By analyzing background contrast and bounding boxes, you can automate what would otherwise be a tedious manual cropping process.

The Standard ImageMagick Multi-Crop Approach

When you scan multiple items at once, they typically sit against a solid white or black flatbed scanner lid. ImageMagick uses Connected Components Analysis (-connected-components) to identify the individual items and extract their coordinates.

Run the following multi-step approach in ImageMagick 7:

magick input_scan.jpg \
  -fuzz 15% \
  -fill white -draw "color 0,0 floodfill" \
  -define connected-components:verbose=true \
  -define connected-components:area-threshold=50000 \
  -connected-components 8 \
  output_mask.png

Explanation of Parameters

  • -fuzz 15%: Accounts for slight variations and noise in the scanner background color rather than requiring an exact match.
  • -fill white -draw "color 0,0 floodfill": Floods the background starting from the top-left corner (pixel 0,0) to create a clean mask.
  • -define connected-components:area-threshold=50000: Ignores small specks, dust, or noise smaller than 50,000 pixels so that only actual photos or documents are detected.
  • -connected-components 8: Finds all connected pixel regions and outputs the bounding box geometry (WIDTHxHEIGHT+X+Y) for each detected object to the terminal.

Automating the Crop via Bash Script

You can parse the bounding boxes generated by the connected components output directly into a single automated pipeline:

magick input_scan.jpg \
  -fuzz 10% -transparent white \
  -define connected-components:verbose=true \
  -define connected-components:area-threshold=50000 \
  -connected-components 8 null: | \
  awk 'NR>1 {print $2}' | while read -r bbox; do
    [ -n "$bbox" ] && magick input_scan.jpg -crop "$bbox" +repage "cropped_${bbox}.jpg"
done

This command parses each identified bounding box and immediately crops the original high-resolution scan, outputting each item as a uniquely named, isolated image file without altering the original.
