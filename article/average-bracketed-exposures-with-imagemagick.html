Average Bracketed Exposures with ImageMagick

Combining bracketed exposures is an effective technique for reducing digital noise, increasing dynamic range, and creating a balanced overall exposure. ImageMagick offers a straightforward command-line workflow to blend multiple photos into an average exposure without requiring heavy graphical editing software. This guide covers how to prepare your files, execute the averaging command, and output high-quality blended results.

Ensure Images Are Aligned

Before averaging your photos, all exposures must be perfectly aligned. If you shot using a sturdy tripod with a remote shutter, your source images might already match pixel-for-pixel. If there is even slight camera movement between frames, averaging will cause ghosting or blur. If hand-held, align the images beforehand using an alignment tool such as align_image_stack before passing them to ImageMagick.

The Basic Averaging Command

In ImageMagick version 7, exposure averaging is achieved using the -evaluate-sequence operator set to mean. This calculates the arithmetic mean of each pixel across all input files.

Open your terminal or command prompt and run:

magick img1.jpg img2.jpg img3.jpg -evaluate-sequence mean output.jpg

If you are using ImageMagick version 6, the legacy syntax utilizes the convert command:

convert img1.jpg img2.jpg img3.jpg -evaluate-sequence mean output.jpg

(Note: Older versions also supported the -average flag, but -evaluate-sequence mean is the modern, preferred method).

Averaging a Batch of Images

If you have a large sequence of bracketed images in a single folder, you can use wildcards rather than listing each file name manually:

magick exposure_*.tif -evaluate-sequence mean blended_result.tif

Preserving Dynamic Range with High Bit-Depth

Bracketed sets are often shot to capture high dynamic range (HDR) details. When working with 16-bit TIFF files or linear formats, ensure ImageMagick retains the bit depth by explicitly declaring the output format settings:

magick cap1.tif cap2.tif cap3.tif -depth 16 -evaluate-sequence mean final_average.tif

Using 16-bit TIFFs prevents color banding and preserves fine shadow and highlight detail during the mathematical averaging process.

Mean vs. Median for Bracketed Sets

While -evaluate-sequence mean produces the best statistical noise reduction for static scenes, -evaluate-sequence median is an alternative worth considering if your bracketed shots contain moving elements, such as pedestrians, moving cars, or swaying branches.

To use the median instead:

magick img*.jpg -evaluate-sequence median output_median.jpg

The median method discards outliers, helping eliminate moving subjects from the blended exposure while still balancing exposure consistency across the set.
