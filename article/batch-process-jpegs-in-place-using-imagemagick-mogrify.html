Batch Process JPEGs In-Place Using ImageMagick Mogrify

This article explains how to batch process an entire directory of JPEG images in-place using ImageMagick’s mogrify command. Unlike the standard convert tool, which produces new files, mogrify modifies the original files directly in their existing directory. By using simple command-line arguments, you can rapidly resize, compress, strip metadata, or rotate thousands of JPEG images simultaneously without writing complex shell scripts.

Understanding the Mogrify Command

The mogrify tool is specifically designed for batch operations where modifying the target files directly is desired. Because mogrify permanently overwrites the original files, it is strongly recommended to create a backup copy of your folder before running any commands.

The basic syntax for processing all JPEG images in the current working directory is:

mogrify [options] *.jpg

To include both .jpg and .jpeg extensions, you can specify:

mogrify [options] *.[jJ][pP][gG]

Common Batch Processing Operations

1. Batch Resizing Images

To resize all JPEGs to a maximum width of 1920 pixels and height of 1080 pixels while preserving the aspect ratio:

mogrify -resize 1920x1080 *.jpg

To scale all images down by a fixed percentage (for example, 50%):

mogrify -resize 50% *.jpg

2. Adjusting JPEG Quality and Compression

To reduce file sizes across an entire folder by setting the JPEG compression quality to 80%:

mogrify -quality 80% *.jpg

3. Stripping Metadata

Digital cameras and phones embed EXIF profiles, GPS coordinates, and thumbnails inside JPEGs. Removing this metadata reduces file size and protects privacy:

mogrify -strip *.jpg

4. Combining Multiple Operations

You can chain multiple operations together in a single command. The following example resizes images to a maximum width of 1200px, strips all metadata, sets the quality to 85%, and auto-orients images based on EXIF rotation tags before discarding them:

mogrify -auto-orient -resize 1200x\> -strip -quality 85% *.jpg

(Note: The \> operator ensures that images are only shrunk if their dimensions exceed the specified limit, preventing smaller images from being enlarged.)

Recursive In-Place Processing

If your JPEG images are organized across nested subdirectories, standard shell wildcards may not reach every file. You can combine find with mogrify to process an entire directory tree in-place:

find /path/to/folder -type f \( -name "*.jpg" -o -name "*.jpeg" \) -exec mogrify -resize 1920x1080 -quality 85% {} +
