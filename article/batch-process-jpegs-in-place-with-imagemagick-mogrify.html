Batch Process JPEGs In-Place with ImageMagick Mogrify

ImageMagick’s mogrify tool is designed specifically for batch processing image files in-place, overwriting the original files with the modified versions. Unlike the standard convert or magick commands that generate new output files, mogrify allows you to resize, compress, rotate, or strip metadata from an entire folder of JPEG images using a single, concise terminal command without needing shell loops.

Basic Syntax and Usage

To process all JPEG files in the current working directory, navigate to that directory in your terminal and execute mogrify followed by your desired operations and the file pattern.

Resize all JPEGs: To resize all .jpg files to a maximum width of 1920 pixels and height of 1080 pixels while preserving the aspect ratio:

mogrify -resize 1920x1080 *.jpg

Compress and adjust quality: To recompress all JPEGs to an 80% quality level:

mogrify -quality 80% *.jpg

Strip metadata (EXIF data): To remove unnecessary color profiles, timestamps, GPS coordinates, and camera metadata to reduce file size:

mogrify -strip *.jpg

Combine multiple operations: You can chain multiple transformations together in a single command. The following example auto-orients images based on EXIF tags, strips metadata, resizes the images down to a maximum bounding box of 1200x1200, and sets the compression quality to 85%:

mogrify -auto-orient -strip -resize 1200x1200 -quality 85% *.jpg

Handling Different File Extensions

If your directory contains mixed extensions (such as uppercase .JPG or .jpeg), specify multiple wildcards:

mogrify -quality 85% *.jpg *.jpeg *.JPG *.JPEG

Recursive Processing (Subdirectories)

By default, mogrify *.jpg only affects files in the current folder. To process all JPEG images in the current directory and all subdirectories, combine find with mogrify:

find . -type f \( -name "*.jpg" -o -name "*.jpeg" \) -exec mogrify -quality 85% -strip {} +

Note: Because mogrify overwrites existing files permanently, always ensure you have a backup of your original images before running batch modifications.
