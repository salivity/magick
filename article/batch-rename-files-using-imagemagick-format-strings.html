Batch Rename Files Using ImageMagick Format Strings

This guide explains how to batch rename files during image processing using ImageMagick’s formatted string properties and percent-escape sequences. By leveraging internal metadata properties—such as image dimensions, original filenames, and EXIF tags—you can dynamically construct custom output filenames across entire directories from the command line.

Understanding Formatted String Properties

ImageMagick allows you to capture image properties and assign them to a custom variable using the -set filename:key "format_string" operator. You can then reference this custom property in the output path using %[filename:key].

Key Percent-Escape Sequences

  • %t – Base filename (without extension).
  • %e – Extension of the input file.
  • %w and %h – Image width and height in pixels.
  • %[EXIF:DateTimeOriginal] – EXIF original creation timestamp.
  • %[channels] – Image color channel details.
  • %q – Image color depth/quantum depth.

Practical Batch Renaming Examples

1. Renaming Files with Image Dimensions

To append the width and height of each image to its existing filename:

magick *.jpg -set filename:dim "%t_%wx%h" "%[filename:dim].jpg"
  • Input: photo.jpg (1920x1080)
  • Output: photo_1920x1080.jpg

2. Renaming Using EXIF Creation Date

To organize photos using their embedded capture date:

magick *.jpg -set filename:exifdate "%[EXIF:DateTimeOriginal]" "%[filename:exifdate]_%t.jpg"
  • Input: IMG_001.jpg (Taken on 2023:10:15)
  • Output: 2023:10:15 14:30:00_IMG_001.jpg

(Note: Depending on your operating system, colons or spaces in dates may need to be formatted or sanitized).

3. Converting Formats While Keeping the Original Base Name

To convert files from PNG to WebP while explicitly controlling the target name dynamically:

magick *.png -set filename:base "%t" "converted_%[filename:base].webp"
  • Input: graphic.png
  • Output: converted_graphic.webp

4. Renaming with Multiple Combined Properties

You can combine multiple metadata tags into a single filename string to create descriptive identifiers:

magick *.jpg -set filename:custom "%t_q%q_%wx%h" "output/%[filename:custom].%e"
  • Input: banner.jpg (8-bit, 1200x400)
  • Output: output/banner_q8_1200x400.jpg

Important Usage Notes

  • ImageMagick Version: The commands above use ImageMagick v7 (magick). For ImageMagick v6, replace magick with convert.
  • Output Directory: Ensure that any target output directory specified in the filename template (such as output/) exists before running the command, as ImageMagick will not create missing directories automatically.
