Benchmark ImageMagick Performance with -bench

ImageMagick provides a built-in benchmarking tool to measure execution speed, system resource usage, and throughput for image processing tasks. By appending the -bench switch to your commands, you can run an operation multiple times in a controlled loop to profile performance, evaluate server hardware capabilities, and optimize command pipelines without relying on external benchmarking scripts.

The Basic -bench Command Syntax

In ImageMagick version 7, the core syntax for benchmarking an operation over a specified number of iterations is:

magick input.jpg [operations] null: -bench <iterations>

(Note: For ImageMagick version 6, replace magick with convert.)

Using null: as the output target discards the output image instead of saving it to disk, ensuring that disk write latency does not distort the processing performance metrics.

Practical Examples

1. Benchmarking an Image Resize Operation

To benchmark resizing an image to 50% of its original size across 10 iterations:

magick input.jpg -resize 50% null: -bench 10

2. Benchmarking Multi-Step Processing

To test performance on complex operations such as blurring, color adjustments, and sharpening:

magick input.jpg -gaussian-blur 0x2 -modulate 110,105,100 -sharpen 0x1 null: -bench 20

3. Benchmarking Without an Input File (Synthetic Canvas)

To test CPU performance independently of an existing image file on disk, generate a canvas on the fly:

magick -size 1920x1080 canvas:white -noise Gaussian null: -bench 15

Understanding the Output Metrics

After the command completes the specified number of iterations, ImageMagick prints a summary line to the terminal containing several key performance indicators:

  • Iterations: The total number of test loops executed.
  • Elapsed Time (e.g., 0.456u / 0.021s / 0:01.234):
    • u (User Time): Time spent executing your command within CPU user mode.
    • s (System Time): Time spent within system kernel calls.
    • Total clock time taken to complete all iterations.
  • Throughput (e.g., 21.895i/s): The number of iterations completed per second. Higher values indicate faster processing.
  • Memory Usage: Peak memory and pixel cache memory allocated during the execution.
