Bend Image into Semi-Circle with ImageMagick

ImageMagick enables you to warp flat rectangular graphics into curved shapes using the Arc distortion operator. By configuring the operator's arguments—specifically setting the sweep angle to 180 degrees—you can bend any image into a precise semi-circle or arch. This guide breaks down the syntax, the core parameters required for a semi-circular transformation, and practical command-line examples.

The Arc Distortion Syntax

In ImageMagick, the Arc operator is invoked using the -distort setting. The argument string accepts up to four numerical parameters:

-distort Arc "{arc_angle} {rotation_angle} {outer_radius} {inner_radius}"

Only the first parameter is strictly required; ImageMagick will automatically calculate sensible defaults for any omitted values.

Configuring the Parameters for a Semi-Circle

To create a semi-circle, configure the parameters as follows:

  • Arc Angle (180): This is the crucial setting. A complete circle is 360 degrees, so setting this value to 180 restricts the bend to a half-circle.
  • Rotation Angle (Optional, default 0): Determines the orientation of the center of the arc. A rotation of 0 places the center of the arc at the top (creating an arch or rainbow shape). A value of 180 flips the arc upside down (creating a bowl or smile shape).
  • Outer Radius (Optional): Controls the distance from the center point of the arc to the outer edge of the curved image. If left undefined, ImageMagick sizes it automatically based on the source image dimensions.
  • Inner Radius (Optional): Controls the radius of the inner cutout, determining the thickness of the band. If omitted, it defaults to placing the bottom edge of the image at the center point.

Practical Examples

Basic Arch (Rainbow Orientation)

To bend an image into a standard upward semi-circle, supply an angle of 180:

magick input.png -virtual-pixel HorizontalTile -background none -distort Arc 180 output.png

Note: For ImageMagick version 6, replace magick with convert.

Inverted Semi-Circle (U-Shape)

To invert the curve so it resembles a bowl, set the rotation parameter to 180:

magick input.png -virtual-pixel HorizontalTile -background none -distort Arc "180 180" output.png

Specifying Radii for Precise Thickness

To control the exact curvature and inner hole size, specify the outer and inner radii:

magick input.png -virtual-pixel HorizontalTile -background none -distort Arc "180 0 200 100" output.png

In this command:

  • 180 defines the semi-circle.
  • 0 keeps the arch centered upward.
  • 200 sets the outer edge radius to 200 pixels.
  • 100 sets the inner edge radius to 100 pixels, producing a 100-pixel thick curved band.
