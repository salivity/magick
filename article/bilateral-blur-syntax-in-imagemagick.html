Bilateral Blur Syntax in ImageMagick

This guide explains the command-line syntax for applying an edge-preserving bilateral blur in ImageMagick. A bilateral blur smooths flat areas, reduces digital noise, and softens textures while retaining sharp, high-contrast edges. Below, you will find the exact command structure, a breakdown of its parameters, and practical usage examples.

Basic Command Syntax

In ImageMagick (version 7 and later), the bilateral blur is applied using the -bilateral-blur operator:

magick input.png -bilateral-blur {radius}x{sigma}+{intensity_sigma}+{spatial_sigma} output.png

For ImageMagick v6, replace magick with convert:

convert input.png -bilateral-blur {radius}x{sigma}+{intensity_sigma}+{spatial_sigma} output.png

Parameter Breakdown

The geometry string for -bilateral-blur uses the format radiusxsigma+intensity_sigma+spatial_sigma:

  • radius (radius): The size of the Gaussian blur kernel window. Setting this to 0 allows ImageMagick to automatically determine the optimal radius based on the sigma value.
  • sigma (sigma): The standard deviation of the spatial Gaussian filter. It determines the overall area of neighborhood pixels considered for blurring.
  • intensity_sigma (+intensity_sigma): Controls the threshold for photometric (color/brightness) similarity. Pixels with color differences exceeding this value are treated as edges and are not smoothed together. Higher values blur across more distinct color boundaries, while lower values preserve more edge details.
  • spatial_sigma (+spatial_sigma): (Optional) Overrides the spatial distance standard deviation if different from the initial sigma.

Practical Examples

Standard Edge-Preserving Denoise: To apply a standard edge-preserving blur with an automatic radius, a spatial sigma of 5, and an intensity sigma of 15:

magick photo.jpg -bilateral-blur 0x5+15 output.jpg

Strong Surface Smoothing: To smooth larger texture variations while keeping distinct borders:

magick photo.jpg -bilateral-blur 0x10+30 output.jpg

Delicate Detail Preservation: To reduce fine noise without softening delicate line work:

magick photo.jpg -bilateral-blur 0x2+5 output.jpg
