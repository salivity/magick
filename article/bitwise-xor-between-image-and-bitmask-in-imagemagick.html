Bitwise XOR Between Image and Bitmask in ImageMagick

This article explains how to compute a bitwise XOR operation between an image and a bitmask using the ImageMagick command-line tool. Performing this operation allows you to manipulate pixel values at the binary level for tasks such as steganography, data obfuscation, or custom graphics masking. Below, you will find the direct commands for ImageMagick version 7 and version 6, along with key considerations regarding channel management and bit depth.

Using ImageMagick 7 (Recommended)

In ImageMagick 7, you use the magick tool combined with the -compose BitwiseXor operator to blend an image and a bitmask file.

magick base_image.png mask.png -compose BitwiseXor -composite output.png

Using ImageMagick 6

In ImageMagick 6, the legacy composite command performs the same function:

composite -compose BitwiseXor mask.png base_image.png output.png

Alternatively, you can use the convert command:

convert base_image.png mask.png -compose BitwiseXor -composite output.png

Applying a Constant Bitmask with -evaluate

If your bitmask is a single numeric value rather than a separate image file, use the -evaluate operator instead of compositing:

magick base_image.png -evaluate xor 0xAA output.png

You can pass hexadecimal values (like 0xFF or 0x55) or decimal values directly to the command.

Important Considerations

  • Bit Depth: Bitwise operations depend heavily on the bit depth of the pixels. If your base image and mask have mismatched bit depths, normalizations can produce unintended results. Explicitly set matching bit depths using the -depth flag (e.g., -depth 8).
  • Color Channels: By default, ImageMagick applies the compose operation across all available channels, including the alpha channel. To restrict the bitwise XOR to only color channels, explicitly select them using -channel: 
    magick base_image.png mask.png -channel RGB -compose BitwiseXor -composite +channel output.png
  • Mask Dimensions: The bitmask image should match the dimensions of the base image. If the mask is smaller or larger, resize or tile it to fit before compositing to avoid clipped regions.
