Blend Animation Frames for Motion Blur in ImageMagick

This article provides a direct guide on how to blend adjacent animation frames to generate a motion-blur transition using ImageMagick. You will learn the exact command-line techniques to coalesce animated files, interpolate intermediate frames, adjust opacity blends between sequential images, and optimize the final output for smooth motion.

Preparing the Animation with Coalesce

Before manipulating individual frames, you must remove any frame optimizations present in GIFs or animated formats. The -coalesce command reconstructs each frame to its full visual state.

magick input.gif -coalesce raw_frames_%03d.png

Method 1: Generating Blended Frames Using -morph

The simplest way to create a motion-blur transition across an entire animation is the -morph operator. It generates a specified number of linearly interpolated, semi-transparent frames between each pair of adjacent frames.

magick input.gif -coalesce -morph 3 -set delay 4 -layers Optimize output_blur.gif
  • -coalesce: Fully expands all partial frames.
  • -morph 3: Generates three blended in-between frames between every adjacent frame pair.
  • -set delay 4: Adjusts frame delay (in hundredths of a second) so the added frames maintain proper playback speed.
  • -layers Optimize: Re-optimizes the file size for distribution.

Method 2: Creating a Sliding Temporal Blur Across Adjacent Frames

If you want to simulate real camera motion blur by directly superimposing adjacent frames rather than adding extra intermediate frames, use a rolling weighted blend across a frame sequence.

To blend adjacent pairs (e.g., current frame at 50% opacity over the previous frame at 50% opacity):

magick input.gif -coalesce \
  \( -clone 0--1 -roll +0+0 \) \
  \( -clone 1--1 -clone 0 \) \
  -compose Blend -define compose:args=50,50 -composite \
  -set delay 10 -layers Optimize motion_blurred.gif

For higher-order blur incorporating three consecutive frames (previous, current, next):

magick input.gif -coalesce \
  \( -clone 0 -clone 0--2 \) \
  \( -clone 0--1 \) \
  \( -clone 1--1 -clone -1 \) \
  -evaluate-sequence mean \
  -set delay 10 -layers Optimize temporal_blur.gif
  • \( -clone ... \): Creates shifted versions of the frame sequence representing \(t-1\), \(t\), and \(t+1\).
  • -evaluate-sequence mean: Computes the average pixel value across all aligned layers, producing a realistic shutter-angle motion blur.

Method 3: Blending Image Sequences Directly

If working from a folder of pre-extracted image sequences (e.g., frame_01.png, frame_02.png), you can batch-process the transition into a single blurred animation:

magick frame_*.png -morph 2 -set delay 5 -loop 0 motion_blur_sequence.gif

Adjust the -morph value higher for smoother, longer blur trails, or lower for a tighter, subtle motion effect.
