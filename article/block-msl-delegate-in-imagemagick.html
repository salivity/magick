Block MSL Delegate in ImageMagick

This article explains how to disable the Magick Scripting Language (MSL) delegate and coder using ImageMagick’s security policy configuration. Securing ImageMagick installations often requires restricting potentially dangerous formats and delegates to prevent arbitrary file reading, server-side request forgery (SSRF), and remote code execution vulnerabilities.

The Policy Directive

To completely disable the Magick Scripting Language delegate in ImageMagick, add the following policy directive to the policy.xml file:

<policy domain="coder" rights="none" pattern="MSL" />

If you specifically want to block it via the delegate domain as well, include:

<policy domain="delegate" rights="none" pattern="msl" />

Where to Apply the Directive

The directive must be placed inside the <policymap> element of the system's policy.xml configuration file. The typical path depends on your operating system and ImageMagick version:

  • Linux (ImageMagick 7): /etc/ImageMagick-7/policy.xml
  • Linux (ImageMagick 6): /etc/ImageMagick-6/policy.xml
  • macOS (Homebrew): /usr/local/etc/ImageMagick-7/policy.xml or /opt/homebrew/etc/ImageMagick-7/policy.xml
  • Windows: Located in the ImageMagick installation directory.

Structure of the Rule

  • domain="coder": Specifies that the policy applies to file format coders responsible for decoding or encoding images.
  • domain="delegate": Restricts external command-line delegates that ImageMagick invokes to handle specific formats.
  • rights="none": Revokes all read and write permissions for the specified pattern.
  • pattern="MSL": Targets the Magick Scripting Language format case-insensitively.

Verifying the Configuration

After saving the updated policy.xml file, verify that the MSL coder is successfully blocked by running the following command in your terminal:

identify -list policy

Or, for ImageMagick 7:

magick identify -list policy

Look for the entry containing domain: Coder, rights: None, and pattern: MSL to confirm that the directive is actively enforced.
