Build ImageMagick with WebP Support

Building ImageMagick from source with Google WebP support requires compiling the software alongside the libwebp development libraries. This guide outlines the end-to-end process for engineers, covering dependency installation, source code acquisition, configuration with the WebP delegate, compilation, installation, and final format verification.

1. Install Prerequisites and libwebp

Before configuring ImageMagick, your system must have a C compiler, build tools, and the development headers for WebP.

On Debian/Ubuntu-based systems:

sudo apt update
sudo apt install -y build-essential pkg-config libwebp-dev

On RHEL/CentOS/Fedora systems:

sudo dnf groupinstall -y "Development Tools"
sudo dnf install -y pkgconfig libwebp-devel

2. Download ImageMagick Source

Clone the latest ImageMagick source repository directly from GitHub or download the source tarball:

git clone https://github.com/ImageMagick/ImageMagick.git
cd ImageMagick

3. Configure the Build Environment

Run the configure script to detect the system environment and delegates. Ensure that pkg-config can locate libwebp.

./configure --with-webp=yes

After the script runs, check the delegate configuration summary printed at the end of the terminal output. Look for the Delegate Configuration section and confirm that WEBP is listed under DELEGATES:

DELEGATES = ... webp ...

If WEBP shows as no, verify that libwebp-dev is installed and that its .pc file is accessible via pkg-config --modversion libwebp.

4. Compile and Install

Compile the source using multiple processor cores to speed up the build, then install the binaries:

make -j$(nproc)
sudo make install

Update the runtime dynamic linker cache so the operating system locates the newly installed shared libraries:

sudo ldconfig /usr/local/lib

5. Verify WebP Support

Verify that the ImageMagick binary properly registers the WebP delegate:

magick identify -list format | grep -i webp

A successful build will output WebP with read/write (rw+) permissions:

      WEBP* rw+   Google WebP Image Format (libwebp 1.x.x)
