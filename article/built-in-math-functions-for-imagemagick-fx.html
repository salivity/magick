Built-In Math Functions for ImageMagick -fx

The ImageMagick -fx operator provides a versatile expression evaluator for pixel-level image manipulation using mathematical formulas. This article outlines the built-in mathematical functions supported by -fx, detailing rounding tools such as floor, ceil, and round, alongside algebraic, trigonometric, and utility functions used for custom channel and geometry calculations.

In ImageMagick's -fx environment, image channel values are typically normalized as floating-point numbers between 0.0 and 1.0. The operator recognizes a comprehensive set of C-style mathematical functions.

Rounding and Truncation Functions

  • floor(x): Returns the largest integer value less than or equal to x.
  • ceil(x): Returns the smallest integer value greater than or equal to x.
  • round(x): Rounds x to the nearest integer. Halfway values round away from zero.
  • trunc(x): Truncates x to an integer by removing the fractional component (rounds toward zero).

Algebraic and Exponential Functions

  • abs(x): Computes the absolute value of x.
  • sign(x): Returns -1 if x < 0, 0 if x == 0, and 1 if x > 0.
  • sqrt(x): Computes the square root of x.
  • cbrt(x): Computes the cube root of x.
  • exp(x): Calculates the exponential function \(e^x\).
  • ln(x): Calculates the natural logarithm (base \(e\)) of x.
  • log(x) or logten(x): Calculates the base-10 logarithm of x.
  • pow(x, y): Returns x raised to the power of y (\(x^y\)).
  • fmod(x, y): Computes the floating-point remainder of x / y.

Trigonometric and Hyperbolic Functions

All trigonometric functions expect angles expressed in radians:

  • sin(x), cos(x), tan(x): Standard sine, cosine, and tangent.
  • asin(x), acos(x), atan(x): Inverse trigonometric functions (arcsine, arccosine, arctangent).
  • atan2(y, x): Calculates the arctangent of the two variables y and x to determine the angle in the correct quadrant.
  • sinh(x), cosh(x), tanh(x): Hyperbolic sine, cosine, and tangent.
  • asinh(x), acosh(x), atanh(x): Inverse hyperbolic functions.
  • sinc(x): Calculates the normalized sinc function, defined as \(\sin(\pi x) / (\pi x)\).

Utility and Comparison Functions

  • min(x, y): Returns the lesser of x and y.
  • max(x, y): Returns the greater of x and y.
  • hypot(x, y): Computes \(\sqrt{x^2 + y^2}\) without intermediate underflow or overflow.
  • rand(): Returns a pseudo-random floating-point value uniformly distributed between 0.0 and 1.0.
