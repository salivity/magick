Butteraugli Distance for JPEG XL in ImageMagick

This article provides an overview of how to control the Butteraugli visual distance metric when encoding JPEG XL (JXL) images using ImageMagick. It details the specific -define option required, explains how the Butteraugli numerical values correspond to human visual perception, and demonstrates how to apply this setting in standard command-line operations.

In ImageMagick, the Butteraugli visual distance metric for JPEG XL encoding is configured using the -define jxl:distance=value setting. This setting interfaces directly with the underlying libjxl library to control the target psychovisual error, determining the trade-off between image fidelity and file size.

Understanding the Butteraugli Distance Scale

The Butteraugli metric measures the visual difference between the original and compressed image based on the human visual system. Unlike standard quality percentages, the distance scale is inverted:

  • 0.0: Mathematically lossless (or visually identical to the original).
  • 0.5 – 1.0: Visually lossless under typical viewing conditions. A distance of 1.0 is the standard baseline where differences are generally imperceptible to the human eye.
  • 1.5 – 3.0: High-to-medium quality with subtle, acceptable compression artifacts, resulting in significantly smaller file sizes.
  • Above 3.0: Noticeable compression artifacts begin to appear, suitable only when aggressive bandwidth savings are required. The maximum practical value is typically around 15.0.

Usage Example

To set the visual distance directly in an ImageMagick command, place the define before the output filename:

magick input.png -define jxl:distance=1.0 output.jxl

Direct Define vs. Standard Quality Setting

While ImageMagick allows setting image quality via the standard -quality flag—which internally maps percentage values to Butteraugli distances—using -define jxl:distance is preferred for precise encoding targets. Setting jxl:distance bypasses ImageMagick's internal approximation curve and instructs the JPEG XL encoder to optimize directly for the specified Butteraugli distance.
