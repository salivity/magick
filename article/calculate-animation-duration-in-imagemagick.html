Calculate Animation Duration in ImageMagick

This guide explains how to calculate the exact duration of an entire animated sequence in seconds using ImageMagick. You will learn the precise command-line method to extract per-frame delay metadata and compute the total playback runtime for formats such as GIF, animated WebP, or APNG.

The Command

ImageMagick stores frame delays individually rather than providing a single metadata field for the total duration. To obtain the exact length of the animation in seconds, use ImageMagick to output the delay of every frame and pipe the results to a processing tool like awk to sum them:

magick identify -format "%T\n" animation.gif | awk '{sum += $1} END {print sum / 100 " seconds"}'

If you are using ImageMagick 6, replace magick identify with identify:

identify -format "%T\n" animation.gif | awk '{sum += $1} END {print sum / 100 " seconds"}'

For Windows PowerShell users, execute:

(magick identify -format "%T " animation.gif).Trim().Split() | Measure-Object -Sum | ForEach-Object { $_.Sum / 100 }

How It Works

  1. magick identify: Reads the image sequence without decompressing or modifying pixel data, keeping the execution fast.
  2. -format "%T\n": The %T format specifier retrieves the display delay for each frame. ImageMagick outputs this value in hundredths of a second (centiseconds), printing each frame's delay on a separate line.
  3. awk '{sum += $1} END {print sum / 100}': Reads each centisecond value line-by-line, adds it to a running total, and divides the final sum by 100 to output the duration in full seconds.

This calculation accurately reflects animations with variable frame rates, where individual frames remain on screen for different durations.
