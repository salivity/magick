Calculate Image Brightness with Rec601 in ImageMagick

This guide explains how to calculate the perceived brightness of an image using the Rec601 luma formula in ImageMagick. You will find the exact command-line syntax to extract brightness as a normalized value or percentage, along with an explanation of how the command processes the color channels according to human visual perception.

The Command

To calculate the mean perceived brightness using Rec601 luma in ImageMagick 7, use the following command:

magick input.jpg -grayscale Rec601Luma -format "%[fx:mean]" info:

For ImageMagick 6, replace magick with convert:

convert input.jpg -grayscale Rec601Luma -format "%[fx:mean]" info:

How the Command Works

  • input.jpg: Specifies your source image file.
  • -grayscale Rec601Luma: Converts the color channels into a single grayscale intensity channel using the ITU-R BT.601 standard formula:
    \[\text{Luma} = 0.299R + 0.587G + 0.114B\]
    This weights green highest and blue lowest to align with human eye sensitivity.
  • -format "%[fx:mean]": Calculates the mathematical mean of all pixel values in the grayscale image. It returns a floating-point number between 0.0 (pure black) and 1.0 (pure white).
  • info:: Instructs ImageMagick to print the formatted result to the standard output instead of writing an image file to disk.

Alternative Outputs

Get Brightness as a Percentage (0% to 100%):

magick input.jpg -grayscale Rec601Luma -format "%[fx:mean*100]%%\n" info:

Get the Standard Deviation (Contrast/Spread):

magick input.jpg -grayscale Rec601Luma -format "%[fx:standard_deviation]" info:
