Calculate Perceptual Hash Using ImageMagick

Perceptual hashing (pHash) creates a distinct digital fingerprint based on an image's visual features rather than its raw byte data, allowing you to detect similar, resized, or compressed images. This article explains how to compute, extract, and compare perceptual hash values of images directly using ImageMagick command-line utilities.

Extracting Perceptual Hash Moments

ImageMagick calculates perceptual hashes using invariant color and shape moments across various color spaces. To view the full perceptual hash data for an image, use the identify command with the -moments flag:

magick identify -verbose -moments input.jpg

In older versions of ImageMagick (version 6 and earlier), replace magick identify with identify:

identify -verbose -moments input.jpg

Look for the PHash: section under Channel moments: in the output. This section lists invariant moment values computed for the red/luminance, green/chroma, and blue/chroma channels.

Extracting Specific PHash Values

To extract the pHash string directly for scripting or database storage, you can format the output using the info: delegate:

magick input.jpg -format "%[phash:1.1],%[phash:1.2],%[phash:1.3]" info:

This returns the first few invariant moment coefficients representing the visual fingerprint of the image.

Comparing Two Images Using the PHASH Metric

Instead of manually calculating and comparing hash strings, ImageMagick provides a built-in PHASH metric within its compare tool to measure the perceptual distance between two images:

magick compare -metric PHASH image1.jpg image2.jpg null:

Interpreting the Results

  • 0.0: The images have identical perceptual structures.
  • Low values (< 5.0): The images are visually very similar (e.g., resized, compressed, or slight color changes).
  • High values: The images have significantly different visual content.
