Calculate Perimeter Length in ImageMagick

Calculating the perimeter length of a shape in ImageMagick involves isolating the boundary pixels of a binary shape and counting them. While ImageMagick does not have a single dedicated "perimeter" command, you can accurately measure a shape's perimeter in pixels by applying morphological edge detection combined with an inline image calculation expression.

Basic Command Syntax

To determine the perimeter length in pixels of a high-contrast or binary shape, use the following syntax in ImageMagick version 7:

magick input.png -threshold 50% -morphology Edge Diamond -format "%[fx:mean*w*h]\n" info:

(If using ImageMagick v6, replace magick with convert.)

Syntax Breakdown

  • input.png: The target image containing the shape. For best results, the shape should be solid white on a black background, or vice versa.
  • -threshold 50%: Converts the image into pure binary (black and white) to remove anti-aliasing and soft edges that could distort pixel counts. Invert the image first using -negate if your shape is black on a white background.
  • -morphology Edge Diamond: Performs an edge-detection operation using a diamond-shaped structuring element. This operation isolates the single-pixel-wide boundary along the perimeter of the shape.
  • -format "%[fx:mean*w*h]\n" info:: Calculates the total number of white boundary pixels without creating an output image file.
    • mean: The normalized average pixel intensity across the image (ranging from 0.0 to 1.0).
    • w: Image width in pixels.
    • h: Image height in pixels.
    • mean*w*h: Multiplies the average intensity by the total image area, yielding the exact count of white perimeter pixels.

Alternative Kernels for Perimeter Estimation

Different boundary-tracing kernels can alter how diagonal pixels are measured:

  • Diamond Kernel (-morphology Edge Diamond): Detects 4-connected boundary pixels. This is the standard choice for simple pixel-length estimation.
  • Square Kernel (-morphology Edge Square): Detects 8-connected boundaries, capturing diagonal adjacencies.
  • Octagon Kernel (-morphology Edge Octagon): Provides a smoother boundary trace for rounded shapes.

Alternative Syntax Using the Edge Operator

You can also use the built-in -edge operator as a simpler alternative to -morphology:

magick input.png -threshold 50% -edge 1 -format "%[fx:mean*w*h]\n" info:

The -edge 1 flag applies a 1-pixel edge-detection filter to trace the perimeter before counting the edge pixels with the -format FX expression.
