Calculate PSNR Across Channels in ImageMagick

Peak Signal-to-Noise Ratio (PSNR) is an objective metric used to assess the quality of a reconstructed or compressed image compared to an original reference. This guide demonstrates how to calculate PSNR values across individual color channels (Red, Green, Blue, Alpha) as well as the composite image using ImageMagick's command-line tools.

The Basic Channel PSNR Command

In ImageMagick version 7, the magick compare command computes differences between two images. When run with -metric PSNR, it calculates the signal-to-noise ratio in decibels (dB) for both the overall image and each channel individually:

magick compare -metric PSNR original.png compressed.png null:

(For ImageMagick v6, replace magick compare with compare.)

Interpreting the Output

ImageMagick prints the PSNR metric to the standard error stream (stderr). The output format presents the overall composite PSNR followed by channel-specific values inside parentheses:

36.421 (35.120, 36.850, 37.410)
  • 36.421: The overall composite image PSNR.
  • 35.120: Red channel PSNR.
  • 36.850: Green channel PSNR.
  • 37.410: Blue channel PSNR.

If the images are identical, ImageMagick outputs inf (infinity), indicating no signal loss.

Measuring a Specific Channel

To isolate and calculate PSNR for a single channel, combine the -channel flag with -metric PSNR:

Red Channel Only

magick compare -channel R -metric PSNR original.png compressed.png null:

Green Channel Only

magick compare -channel G -metric PSNR original.png compressed.png null:

Blue Channel Only

magick compare -channel B -metric PSNR original.png compressed.png null:

Alpha Channel Only

magick compare -channel A -metric PSNR original.png compressed.png null:

Capturing Values in Scripts

Because ImageMagick writes metric results to stderr, redirect the stream to capture the output into a variable or file in shell environments:

# Capture output in Bash
psnr_output=$(magick compare -metric PSNR original.png compressed.png null: 2>&1)
echo "PSNR Result: $psnr_output"

Advanced Formatting with identify

If you need programmatic access to formatted metric values without manual text parsing, use the -format option via magick identify:

magick original.png compressed.png -metric PSNR -format "%[distortion]" info:

To limit this measurement to a single channel:

magick original.png compressed.png -channel R -metric PSNR -format "%[distortion]" info:
