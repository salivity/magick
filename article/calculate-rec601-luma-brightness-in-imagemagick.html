Calculate Rec601 Luma Brightness in ImageMagick

This guide explains how to measure the perceived brightness of an image using ImageMagick and the standard Rec. 601 luma formula. By converting the image using Rec601 weighting (\(0.299\text{R} + 0.587\text{G} + 0.114\text{B}\)) and querying the resulting mean pixel value, you can obtain the exact perceived brightness as a normalized decimal, percentage, or 8-bit/16-bit integer.

ImageMagick Command Syntax

In ImageMagick v7, use the magick command with the -grayscale Rec601Luma operator:

magick input.jpg -grayscale Rec601Luma -format "%[fx:mean]" info:

In ImageMagick v6, use convert with the -colorspace setting:

convert input.jpg -colorspace Rec601Luma -format "%[fx:mean]" info:

Output Format Variations

You can adjust the -format string depending on how you want the brightness value represented:

1. Normalized Value (0.0 to 1.0)

Returns a floating-point number where 0.0 is pure black and 1.0 is pure white.

magick input.jpg -grayscale Rec601Luma -format "%[fx:mean]\n" info:

2. Percentage (0% to 100%)

Returns the overall brightness as a human-readable percentage.

magick input.jpg -grayscale Rec601Luma -format "%[fx:mean*100]%%\n" info:

3. Standard 8-bit Scale (0 to 255)

Maps the mean brightness directly to standard 8-bit integer values.

magick input.jpg -grayscale Rec601Luma -format "%[fx:round(mean*255)]\n" info:

4. Raw Quantum Scale

Returns the raw average value relative to your ImageMagick build's quantum depth (e.g., 0–65535 for Q16).

magick input.jpg -grayscale Rec601Luma -format "%[mean]\n" info:

How It Works

  1. -grayscale Rec601Luma: Converts the color image to a single-channel grayscale representation using the ITU-R BT.601 standard coefficients (\(Y' = 0.299R + 0.587G + 0.114B\)).
  2. -format "%[fx:mean]": Evaluates the arithmetic mean across all pixels in the converted grayscale image using ImageMagick's FX expression parser.
  3. info:: Outputs the computed metadata directly to standard output without writing a new image file to disk.
