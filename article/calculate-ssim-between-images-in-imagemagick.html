Calculate SSIM Between Images in ImageMagick

Measuring perceptual quality loss between original and compressed images is essential for optimizing digital media workflows. ImageMagick includes a built-in implementation of the Structural Similarity Index Measure (SSIM), enabling you to evaluate structural degradation and visual fidelity directly from the command line without needing external scripts.

Basic SSIM Command

To calculate the SSIM between two images, use the magick compare tool (or simply compare in ImageMagick version 6) with the -metric SSIM argument.

magick compare -metric SSIM original.png compressed.jpg null:
  • original.png: The reference or uncompressed image.
  • compressed.jpg: The modified or compressed image you want to evaluate.
  • null:: Tells ImageMagick not to write an output image to disk, outputting only the numeric score.

Interpreting the Output

ImageMagick writes the SSIM score directly to standard error (stderr). The output is a decimal value representing structural similarity:

  • 1.0: The images are structurally identical.
  • 0.90 to 0.99: High similarity with minimal perceived visual distortion.
  • Below 0.80: Noticeable structural differences and significant quality degradation.

Generating a Visual Difference Map

If you want to see where compression artifacts occur alongside the numerical score, specify an output filename instead of null::

magick compare -metric SSIM original.png compressed.jpg diff.png

This command creates diff.png, highlighting structural discrepancies in red or visual heatmaps depending on your ImageMagick configuration.

Capturing the Score in Scripts

Because ImageMagick outputs metric values to standard error, you must redirect stderr to stdout to store the score in a variable or file within automated shell scripts:

ssim_score=$(magick compare -metric SSIM original.png compressed.jpg null: 2>&1)
echo "SSIM Score: $ssim_score"

Preconditions for Accurate Comparison

For ImageMagick to calculate SSIM correctly, both images must share the exact same pixel dimensions. If the compressed image was resized, scale it back to the original dimensions before running the comparison:

magick compare -metric SSIM original.png \( compressed.jpg -resize 1920x1080\! \) null:
