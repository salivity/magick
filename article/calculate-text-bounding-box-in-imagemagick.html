Calculate Text Bounding Box in ImageMagick

Calculating text bounding box dimensions before rendering in ImageMagick allows developers to dynamically size backgrounds, position elements, and control layouts without generating unnecessary image files. ImageMagick accomplishes this by simulating the text rendering process using the label: or caption: protocol combined with the info: output format.

The Standard Measurement Command

To calculate the exact width and height (bounding box) of a text string given a specific font and point size, run the following command:

magick -font Arial -pointsize 36 label:"Sample Text" -format "%w %h\n" info:

(For ImageMagick v6, replace magick with convert)

How It Works:

  • -font Arial: Specifies the typeface to use for measurement.
  • -pointsize 36: Sets the font size in points.
  • label:"Sample Text": Creates an in-memory representation of the single-line text string.
  • -format "%w %h\n": Extracts the resulting width (%w) and height (%h) in pixels.
  • info:: Prints the formatted output directly to standard output without saving an image to disk.

Measuring Multiline Text Dimensions

If your text spans multiple lines or requires automatic wrapping within a maximum width, use caption: instead of label:.

magick -size 300x -font Arial -pointsize 24 caption:"This is a longer string that will wrap automatically." -format "%w %h\n" info:
  • -size 300x: Sets a fixed boundary width of 300 pixels with an unrestricted height.
  • caption:: Wraps the text within the specified width and calculates the total required height.

Advanced Font Metrics and Bounding Box Offsets

If you need detailed typographic metrics—such as ascenders, descenders, text offsets, or the precise character origin bounding box—use the -debug annotate flag:

magick -debug annotate xc: -font Arial -pointsize 36 -annotate +0+0 "Sample Text" null: 2>&1 | grep -i "metrics"

This outputs detailed internal layout metrics, including:

  • Horizontal and Vertical Advance: Total distance moved after rendering.
  • Ascent and Descent: Pixels above and below the baseline.
  • Bounds: Exact minimum and maximum X/Y coordinates of the rendered glyph path.
