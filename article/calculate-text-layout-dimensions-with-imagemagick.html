Calculate Text Layout Dimensions with ImageMagick

Before rendering text onto an image, calculating the exact bounding box and layout dimensions is essential for dynamic canvas sizing, alignment, and margin calculation. ImageMagick allows you to simulate text rendering in memory and extract the resulting width, height, and font metrics using the identify command or the info: format protocol without writing an actual image file to disk.

Measuring Single-Line Text Dimensions

For single-line text where the text length dictates the final width, use the label: protocol combined with the info: output delegate.

ImageMagick v7

magick -font Arial -pointsize 48 label:"Sample Text" -format "%wx%h" info:

ImageMagick v6

convert -font Arial -pointsize 48 label:"Sample Text" -format "%wx%h" info:

To extract width and height separately for programmatic use in shell scripts:

WIDTH=$(magick -font Arial -pointsize 48 label:"Sample Text" -format "%w" info:)
HEIGHT=$(magick -font Arial -pointsize 48 label:"Sample Text" -format "%h" info:)

Measuring Wrapped Multiline Text

When dealing with paragraphs or multiline text constrained within a specific bounding width, use the caption: protocol with a defined width and an unbounded height (e.g., -size 400x). ImageMagick will automatically wrap the text and calculate the resulting height.

magick -size 400x -font Arial -pointsize 24 caption:"This is a longer text string that will automatically wrap into multiple lines based on the defined width constraint." -format "%w %h" info:
  • %w returns the width of the bounding box (in this case, 400).
  • %h returns the computed vertical height required to fit all wrapped text lines at the specified point size.

Extracting Advanced Font Metrics

If your layout requires exact typographic baseline positioning rather than a standard bounding box, use the %[type:*] or %[fx:*] format properties.

To inspect all font metric values:

magick -font Arial -pointsize 48 label:"Sample Text" -format "Width: %w\nHeight: %h\nAscent: %[type:ascent]\nDescent: %[type:descent]\nMax Advance: %[type:max-advance]\n" info:

Key Metrics Explained:

  • Ascent (%[type:ascent]): The distance from the baseline to the highest point of the font outline.
  • Descent (%[type:descent]): The distance from the baseline to the lowest point of the font outline (typically a negative number).
  • Text Width (%[type:text-width]): The exact horizontal advance of the glyphs excluding trailing canvas padding.

Measuring Text Dimensions with identify Directly

You can also pipe the generated layout into the standalone identify command:

magick -font Arial -pointsize 32 label:"Measure Me" miff:- | identify -format "%w x %h\n" -

Using the in-memory output delegate info: is generally faster than piping to identify, as it avoids subshell creation and process-piping overhead.
