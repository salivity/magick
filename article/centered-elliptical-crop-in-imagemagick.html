Centered Elliptical Crop in ImageMagick

Cropping an image into a centered ellipse or circle using ImageMagick requires generating an elliptical alpha mask and applying it over the source image. This article provides the exact command-line syntax for executing a centered elliptical crop automatically using dynamic image dimensions, as well as instructions for fixed-size dimensions in both ImageMagick 6 and ImageMagick 7.

Automatic Centered Elliptical Crop Syntax

To crop an image into an ellipse that scales automatically to the full width and height of the image, use the following command:

ImageMagick 7

magick input.jpg \( +clone -alpha extract -draw "fill black polygon 0,0 0,%h %w,%h %w,0 fill white ellipse %[fx:w/2],%[fx:h/2] %[fx:w/2],%[fx:h/2] 0,360" \) -alpha off -compose CopyOpacity -composite output.png

Alternatively, a more concise syntax utilizing DstIn composition:

magick input.jpg -alpha set \( +clone -channel A -evaluate set 0 +channel -fill white -draw "ellipse %[fx:w/2],%[fx:h/2] %[fx:w/2],%[fx:h/2] 0,360" \) -compose DstIn -composite output.png

ImageMagick 6

Replace magick with convert:

convert input.jpg -alpha set \( +clone -channel A -evaluate set 0 +channel -fill white -draw "ellipse %[fx:w/2],%[fx:h/2] %[fx:w/2],%[fx:h/2] 0,360" \) -compose DstIn -composite output.png

Syntax Breakdown

  • -alpha set: Ensures the base image has an active transparency channel.
  • \( +clone ... \): Creates an in-memory clone of the image to generate the mask.
  • -channel A -evaluate set 0 +channel: Clears the cloned image to a fully transparent layer.
  • -fill white: Defines the fill color of the ellipse mask to make the selected area visible.
  • -draw "ellipse center_x,center_y radius_x,radius_y start_angle,end_angle":
    • %[fx:w/2],%[fx:h/2]: Dynamically calculates the center coordinates (\(X, Y\)) of the image.
    • %[fx:w/2],%[fx:h/2]: Dynamically sets the horizontal and vertical radii to fit the image bounds.
    • 0,360: Draws a complete 360-degree ellipse.
  • -compose DstIn -composite: Applies the mask so only the overlapping parts of the source image inside the white ellipse remain visible.
  • output.png: The resulting image must be saved in a format supporting transparency (such as PNG or WebP).

Fixed Dimension Example

If the image dimensions are already known (for example, a 400x300 pixel image), explicit pixel values can replace the dynamic fx expressions:

magick input.jpg -alpha set \( +clone -channel A -evaluate set 0 +channel -fill white -draw "ellipse 200,150 200,150 0,360" \) -compose DstIn -composite output.png

In this example:

  • Center point: 200, 150
  • Horizontal radius: 200
  • Vertical radius: 150
