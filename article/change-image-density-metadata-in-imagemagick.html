Change Image Density Metadata in ImageMagick

Modifying the density metadata (DPI or PPI) of an image without altering its pixel dimensions is a common requirement when preparing files for print or standardized asset pipelines. This article explains the exact ImageMagick commands required to update the resolution metadata tags without resampling or modifying the underlying pixel array.

Core Syntax

To change only the image density metadata, use the -units and -density flags.

ImageMagick v7

magick input.jpg -units PixelsPerInch -density 300 output.jpg

ImageMagick v6

convert input.jpg -units PixelsPerInch -density 300 output.jpg

Batch In-Place Modification

To update images in place across a directory without creating new files, use the mogrify tool:

magick mogrify -units PixelsPerInch -density 300 *.jpg

(For v6, omit the initial magick keyword).

How It Works

  • -units PixelsPerInch: Defines the measurement unit for the density setting. You can also specify PixelsPerCentimeter or Undefined.
  • -density <value>: Sets the horizontal and vertical resolution metadata (e.g., 300 sets both X and Y density to 300 DPI). To set distinct horizontal and vertical values, use the format 300x150.

Avoiding Pixel Resampling

It is critical to distinguish between -density and -resample:

  • -density: Updates only the metadata headers (such as EXIF, JFIF, or PNG pHYs chunks). The image's width and height in pixels remain completely unchanged.
  • -resample: Recalculates and scales the actual pixel dimensions to match the target density. Do not use -resample if you want to keep the pixel array untouched.

Verifying the Metadata Change

To confirm that the density was updated while preserving the original pixel dimensions, run the identify command:

magick identify -format "%f: %[fx:w]x%[fx:h] pixels, %x x %y %U\n" output.jpg

This output will show the untouched pixel dimensions alongside the updated resolution values and measurement units.
