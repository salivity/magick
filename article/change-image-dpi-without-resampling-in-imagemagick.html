Change Image DPI Without Resampling in ImageMagick

Changing an image's DPI (dots per inch) alters its intended physical print size while leaving the actual pixel dimensions untouched. In ImageMagick, this is achieved by modifying the resolution metadata rather than executing a resampling operation. This guide provides the exact command-line syntax for ImageMagick versions 6 and 7 to adjust image DPI/PPI metadata safely without altering image quality or pixel counts.

ImageMagick Syntax

To change the DPI metadata without resizing or resampling the pixels, use the -density option along with -units PixelsPerInch.

ImageMagick Version 7

magick input.jpg -units PixelsPerInch -density 300 output.jpg

ImageMagick Version 6

convert input.jpg -units PixelsPerInch -density 300 output.jpg

Parameter Breakdown

  • input.jpg: The source image file. Placing the input file first ensures ImageMagick reads the existing pixel buffer before applying metadata changes.
  • -units PixelsPerInch: Defines the unit of measurement. By default, ImageMagick may use Undefined or PixelsPerCentimeter. Specifying PixelsPerInch guarantees the density corresponds to standard DPI/PPI values.
  • -density 300: Sets the resolution value to 300 DPI. You can also specify non-square resolutions using width x height format (for example, -density 300x300).
  • output.jpg: The destination file where the new metadata is saved.

Important: -density vs. -resample

  • -density: Updates the metadata header of the file. The total width and height in pixels remain identical to the original image.
  • -resample: Recalculates and scales the actual pixel dimensions of the image to match the specified density. Do not use -resample if you want to preserve the original pixel data.

Batch Updating Multiple Images

To update the DPI of multiple files in place without resampling, use the mogrify command:

magick mogrify -units PixelsPerInch -density 300 *.jpg

(For ImageMagick v6, omit the magick prefix and use mogrify directly).

Verifying the DPI Change

To verify that the DPI has changed while the pixel dimensions remain unchanged, run the identify command:

magick identify -format "%f: %w x %h pixels, %x x %y %U\n" output.jpg

This output displays the filename, pixel dimensions (%w x %h), and the resolution values with units (%x x %y %U).
