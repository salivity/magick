Chebyshev vs Manhattan Distance in ImageMagick

This article provides an overview of the differences between Chebyshev and Manhattan metric kernels when performing distance transforms in ImageMagick. A distance transform replaces each pixel value in a binary image with the distance to the nearest boundary pixel. While both metrics generate spatial distance maps using ImageMagick’s morphological operations, they rely on fundamentally different mathematical definitions of space and neighbor connectivity, resulting in distinct geometric outputs.

Distance Transforms in ImageMagick

In ImageMagick, distance transforms are executed using the morphology operator:

magick input.png -morphology Distance:<value> Manhattan output.png
magick input.png -morphology Distance:<value> Chebyshev output.png

The algorithm propagates distances from the object boundary across the image canvas. The chosen kernel determines how steps across neighboring pixels are accumulated.

The Manhattan Metric (L1 Norm)

The Manhattan metric, also known as the City Block or \(L_1\) distance, measures the path between two points strictly along grid axes.

  • Movement Rules: Only orthogonal movements (up, down, left, right) are allowed. Diagonal transitions are not permitted as single steps.
  • Connectivity: It operates using 4-connectivity.
  • Mathematical Formula: \[D_{\text{Manhattan}} = |x_1 - x_2| + |y_1 - y_2|\]
  • Diagonal Step Cost: Moving diagonally to an adjacent pixel requires two steps (one horizontal and one vertical), yielding a distance value of 2.
  • Visual Contour: Distance isolines propagate outward in diamond shapes (rhombuses) centered around isolated point sources.

In ImageMagick, the Manhattan kernel generates sharp, diamond-shaped gradients around discrete features. It is ideal for grid-constrained routing simulations, taxicab geometry models, or when diagonal proximity should be penalized.

The Chebyshev Metric (L-infinity Norm)

The Chebyshev metric, also referred to as the Chessboard or \(L_\infty\) distance, measures distance assuming movement in any adjacent direction carries equal cost.

  • Movement Rules: Both orthogonal and diagonal movements are treated identically, mirroring the movements of a King piece on a chessboard.
  • Connectivity: It operates using 8-connectivity.
  • Mathematical Formula: \[D_{\text{Chebyshev}} = \max(|x_1 - x_2|, |y_1 - y_2|)\]
  • Diagonal Step Cost: Moving diagonally to an adjacent pixel costs only 1 unit, identical to an orthogonal step.
  • Visual Contour: Distance isolines propagate outward as concentric squares aligned with the pixel grid.

In ImageMagick, the Chebyshev kernel produces square distance maps around single points. It is suited for applications where diagonal adjacency has the exact same weight as orthogonal adjacency, such as boundary containment checks, tile-based game mechanics, or maximum-range calculations.

Summary of Differences

  • Path Geometry: Manhattan creates diamond-shaped expansions; Chebyshev creates square-shaped expansions.
  • Neighborhood Reach: Manhattan evaluates a 4-neighborhood; Chebyshev evaluates an 8-neighborhood.
  • Diagonal Handling: Manhattan assigns diagonal steps a weight of 2; Chebyshev assigns diagonal steps a weight of 1.
  • Distance Values: For any diagonal vector, the Manhattan distance will always be greater than or equal to the Chebyshev distance.
