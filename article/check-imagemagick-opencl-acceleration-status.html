Check ImageMagick OpenCL Acceleration Status

This article explains how to determine whether ImageMagick is actively using OpenCL hardware acceleration for image processing tasks. You will learn about the primary environment variables used to trace acceleration events, how to interpret debugging output, and how to verify OpenCL device support directly from the command line.

The Environment Variable: MAGICK_DEBUG

The primary environment variable used to check if ImageMagick OpenCL acceleration is actively running is MAGICK_DEBUG set to the value accelerate (or MAGICK_DEBUG=Accelerate).

When this variable is set, ImageMagick outputs real-time diagnostic information to the standard error stream (stderr) whenever an OpenCL-accelerated kernel is initialized, compiled, or executed during an image operation.

How to Use MAGICK_DEBUG

You can set the environment variable per command or globally in your shell environment.

On Linux and macOS (Bash/Zsh):

export MAGICK_DEBUG=accelerate
magick input.jpg -resize 50% output.jpg

Or run it inline for a single execution:

MAGICK_DEBUG=accelerate magick input.jpg -blur 0x8 output.jpg

On Windows (Command Prompt):

set MAGICK_DEBUG=accelerate
magick input.jpg -resize 50% output.jpg

On Windows (PowerShell):

$env:MAGICK_DEBUG="accelerate"
magick input.jpg -resize 50% output.jpg

Interpreting the Output

If OpenCL acceleration is active, you will see log entries indicating that OpenCL kernels are running, such as:

  • Detection and selection of the OpenCL device (GPU or CPU).
  • Kernel compilation or loading from the OpenCL cache.
  • Execution timestamps for accelerated functions like resize, blur, or convolve.

If no acceleration output appears, ImageMagick is falling back to standard CPU-based algorithms.

Controlling the OpenCL Device with MAGICK_OCL_DEVICE

Another relevant environment variable is MAGICK_OCL_DEVICE. While MAGICK_DEBUG monitors execution, MAGICK_OCL_DEVICE allows you to select, test, or disable OpenCL devices directly.

  • Disable OpenCL: Set MAGICK_OCL_DEVICE=OFF to turn off OpenCL acceleration entirely to compare performance benchmarks.
  • Select a Device: Set MAGICK_OCL_DEVICE=<device_name> or an index number to force ImageMagick to use a specific OpenCL-capable GPU or accelerator.

Verifying Built-In OpenCL Support

Before checking runtime acceleration, ensure your ImageMagick build includes OpenCL support by running:

magick -version

Look at the Features line in the output. If OpenCL is supported by your installation, OpenCL will be listed among the enabled features (e.g., Features: Cipher DPC HDRI Modules OpenCL).
