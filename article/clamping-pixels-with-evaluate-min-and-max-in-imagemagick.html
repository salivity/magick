Clamping Pixels with Evaluate Min and Max in ImageMagick

Clamping pixel values in ImageMagick restricts image channels to a specified lower and upper bound, effectively truncating extreme highlights and shadows without scaling the data in between. By combining the -evaluate Max and -evaluate Min operators in sequence, you can set absolute floor and ceiling thresholds for your pixels. This guide details the command-line syntax, explains the operational logic of the Min and Max evaluate operators, and demonstrates how to apply bounds across specific channels or the entire image.

Syntax Overview

To clamp pixel values within a lower and upper boundary, use the following syntax structure:

magick input.png -evaluate Max <lower_bound> -evaluate Min <upper_bound> output.png

(Note: In ImageMagick version 6, replace magick with convert.)

How -evaluate Max and -evaluate Min Work

The logic behind the operator names can feel counter-intuitive when clamping:

  • -evaluate Max <value> sets the lower limit (floor): This operation calculates result = max(pixel, value). If a pixel's value is lower than the parameter, it is raised to match that parameter. Any pixel above this value remains untouched.
  • -evaluate Min <value> sets the upper limit (ceiling): This operation calculates result = min(pixel, value). If a pixel's value is higher than the parameter, it is lowered to match that parameter. Any pixel below this value remains untouched.

Executing both in sequence guarantees that all output pixels remain strictly inside the [lower_bound, upper_bound] range.

Example: Using Percentages

The most portable way to clamp pixel data is using percentages, which automatically adapt to your ImageMagick build's quantum depth (e.g., Q8, Q16, or Q32):

magick input.jpg -evaluate Max 10% -evaluate Min 90% output.jpg

In this command:

  • Any pixel with an intensity below 10% is forced up to 10%.
  • Any pixel with an intensity above 90% is forced down to 90%.
  • Pixel values between 10% and 90% are unchanged.

Example: Using Raw Quantum Values

You can also specify absolute integer values based on your build's bit-depth. For an 8-bit quantum depth image (values from 0 to 255):

magick input.png -evaluate Max 25 -evaluate Min 230 output.png

For a 16-bit quantum depth image (values from 0 to 65535):

magick input.png -evaluate Max 6554 -evaluate Min 58982 output.png

Applying Clamping to Specific Channels

By default, the -evaluate operation applies to all color channels. If you need to clamp a single channel (for example, the alpha channel or the red channel), combine the evaluate operators with the -channel flag:

magick input.png -channel A -evaluate Max 20% -evaluate Min 80% +channel output.png

The +channel switch at the end restores default channel behavior for any subsequent operations in the pipeline.
