Clip Pixel Values to a Dynamic Range in ImageMagick

This guide explains the syntax and methods for clipping pixel values to a specified dynamic range in ImageMagick. You will learn how to perform hard clipping to restrict values within custom boundaries, clamp high-dynamic-range imaging (HDRI) values to standard limits, and remap dynamic ranges using native ImageMagick operations.

Method 1: Hard Clipping to a Custom Range with -evaluate

To clamp values so that pixels below a minimum boundary and above a maximum boundary are clipped directly to those values without scaling the rest of the image, use the -evaluate Max and -evaluate Min operations sequentially.

Syntax

magick input.png -evaluate Max <MIN_VALUE> -evaluate Min <MAX_VALUE> output.png

Example

To clip all pixel values to stay within the range of 10% to 90%:

magick input.jpg -evaluate Max 10% -evaluate Min 90% output.jpg
  • -evaluate Max 10%: Any pixel with a brightness value lower than 10% is set to 10%.
  • -evaluate Min 90%: Any pixel with a brightness value higher than 90% is set to 90%.

Method 2: Dynamic Range Adjustment and Clipping with -level

If you want to compress/stretch the dynamic range between two points while clipping any values outside that window, use the -level operator.

Syntax

magick input.png -level <BLACK_POINT>,<WHITE_POINT> output.png

Example

magick input.jpg -level 10%,90% output.jpg
  • Pixels below 10% are clipped to black (0%).
  • Pixels above 90% are clipped to white (100%).
  • Pixels between 10% and 90% are linearly scaled across the full 0–100% dynamic range.

Method 3: Standard Dynamic Range Clamping with -clamp

When working in ImageMagick HDRI mode, image processing operations can produce pixel values below 0.0 or above the standard maximum (QuantumRange). The -clamp command restricts all values back to the standard range [0, QuantumRange].

Syntax

magick input.exr -clamp output.png
  • Pixels with values < 0 become 0.
  • Pixels with values > QuantumRange (or 100%) are clipped to the maximum allowed value for the output depth.

Method 4: Threshold Clipping with -black-threshold and -white-threshold

To force out-of-range pixels strictly to full black (0) or full white (QuantumRange) instead of pinning them to the threshold value:

Syntax

magick input.png -black-threshold <MIN_VALUE> -white-threshold <MAX_VALUE> output.png

Example

magick input.jpg -black-threshold 15% -white-threshold 85% output.jpg
  • Pixels below 15% become 0% (black).
  • Pixels above 85% become 100% (white).
  • Pixels between 15% and 85% remain completely unchanged.
