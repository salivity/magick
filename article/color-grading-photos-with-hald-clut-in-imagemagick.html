Color Grading Photos with Hald CLUT in ImageMagick

This guide explains how to color-grade images efficiently using ImageMagick and a modified Hald CLUT (Color Look-Up Table). You will learn how to generate an identity Hald image, apply your custom color adjustments using any photo editing software, and then apply that modified color profile to single or batch images via the command line.

What is a Hald CLUT?

A Hald CLUT is a 2D image representation of a 3D color lookup table. Unlike typical 1D LUTs, a 3D color matrix can accurately map complex adjustments, including hue shifts, saturation changes, contrast, and color curves. ImageMagick uses Hald CLUTs to replicate the exact color grading applied to the reference matrix onto any target photograph.

Step 1: Generate an Identity Hald CLUT

To begin, you must generate a neutral "identity" Hald image. This file contains an unedited baseline spectrum of colors.

Run the following command in your terminal:

magick hald:8 identity.png

Note: The number 8 represents the color level, producing a 512x512 pixel image (which corresponds to \(8^3 \times 8^3 = 64^3\) color points). Level 8 offers an ideal balance of color precision and small file size.

Step 2: Modify the Hald CLUT in Your Photo Editor

Open the generated identity.png in any image editing software of your choice (such as Adobe Photoshop, Lightroom, GIMP, or Darktable).

Apply your desired color transformations:

  • Adjust color temperature, tint, curves, and levels.
  • Apply split-toning, cross-processing, or saturation adjustments.
  • Use existing presets or LUTs within your software.

Critical Rules for Editing the Hald Image:

  • Do not resize, crop, rotate, or transform the image dimensions.
  • Do not apply spatial filters such as blur, sharpen, noise, or vignette.
  • Export or save the result as a lossless format (PNG or TIFF) named modified_hald.png in the same bit depth (usually 8-bit or 16-bit).

Step 3: Apply the Modified Hald CLUT to an Image

Once your custom modified_hald.png is saved, use ImageMagick's -hald-clut operator to apply the grade to a photo:

magick input.jpg modified_hald.png -hald-clut output.jpg

ImageMagick will map the pixel values of input.jpg against the color transformations stored in modified_hald.png and produce the graded output.jpg.

Step 4: Batch Processing Multiple Photos

The primary advantage of using command-line Hald CLUT grading is speed when handling large batches of images.

On Linux / macOS (Bash):

for img in *.jpg; do
  magick "$img" modified_hald.png -hald-clut "graded_${img}"
done

On Windows (Command Prompt):

for %i in (*.jpg) do magick "%i" modified_hald.png -hald-clut "graded_%i"

On Windows (PowerShell):

Get-ChildItem *.jpg | ForEach-Object {
    magick $_.Name modified_hald.png -hald-clut "graded_$($_.Name)"
}

This workflow enables you to design your color grading visually in your favorite software and deploy it instantly across hundreds of photos using ImageMagick.
