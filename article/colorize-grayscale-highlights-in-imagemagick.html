Colorize Grayscale Highlights in ImageMagick

This article provides a direct guide on how to selectively colorize the highlights of a grayscale image while leaving the dark shadow values intact using ImageMagick. By utilizing ImageMagick's tonal mapping operators, you can create split-toning effects, warm sepia finishes, or custom photographic tints quickly from the command line.

The Most Efficient Method: +level-colors

The simplest and most effective way to map specific colors to the shadows and highlights of a grayscale image is the +level-colors operator. This operator remaps the black point (shadows) to one color and the white point (highlights) to another color, smoothly interpolating the midtones between them.

To preserve shadows, set the dark point to black (or #000000) and set the light point to your target highlight color.

Command Syntax (ImageMagick v7):

magick input.jpg +level-colors "black,gold" output.jpg

(Note: If you are using ImageMagick v6, use convert instead of magick.)

How It Works

  • input.jpg: The source image (grayscale or desaturated).
  • +level-colors: Tells ImageMagick to remap the low and high luminance levels to specific colors.
  • "black,gold": Defines the mapping range. The first argument (black) ensures that pure black pixels remain #000000 and dark tones remain dark. The second argument (gold or any hex code like #ffcc66) replaces pure white with that color. Grayscale values between 0% and 100% receive a proportional blend of the two colors.
  • output.jpg: The resulting tinted image.

Examples with Hex Values

You can use standard CSS color names or exact Hex codes for precise color matching:

Warm Golden Highlights

magick input.png +level-colors "#000000,#ffb347" warm_highlights.png

Cool Cyan Highlights

magick input.png +level-colors "#000000,#00e5ff" cool_highlights.png

Advanced Control: Using a Color Lookup Table (CLUT)

If you need non-linear control over how midtones transition into highlights, generate a 1-pixel high gradient and apply it using -clut.

  1. Generate a gradient from black to your desired highlight color:
magick -size 1x256 gradient:"black-#ff9900" clut_map.png
  1. Apply the gradient mapping to your grayscale image:
magick input.png clut_map.png -clut output.png

This method allows you to introduce intermediate color stops (e.g., gradient:"black-darkred-yellow") if you decide to stylize the midtones separately while still keeping shadows completely black.
