Colorize Grayscale Shadows in ImageMagick

Colorizing shadows while keeping highlights pure and unaltered is a classic split-toning effect used in digital image processing. In ImageMagick, this effect is achieved by remapping tonal ranges using operations such as +level-colors or Color Look-Up Tables (-clut). These methods map dark values to a chosen color tone while anchoring bright values to pure white, ensuring smooth transitions without washing out lighter areas.

Method 1: Using +level-colors

The simplest and most direct way to tint shadows while protecting highlights is the +level-colors operator. This command maps the black point of the image to a designated color while maintaining the white point.

magick input.jpg +level-colors "midnightblue,white" output.jpg
  • First Value (midnightblue): Sets the color applied to the deepest shadows (black point). You can use named colors or hex codes (e.g., "#1b263b").
  • Second Value (white): Sets the color for the highlights. Setting this to white ensures the upper tonal values remain uncolored.

If your source image is already in color, convert it to grayscale first within the same command:

magick input.jpg -colorspace Gray +level-colors "#102a43,white" output.jpg

Method 2: Using a Color Look-Up Table (-clut)

For more precise control over midtones and falloff, generate an in-memory 1D gradient and apply it using -clut. This maps the brightness spectrum of the input image directly to the colors defined in the gradient.

magick input.jpg -colorspace Gray \
  \( -size 1x256 gradient:"#0f3057-#ffffff" \) \
  -clut output.jpg
  • -size 1x256 gradient:"[ShadowColor]-[HighlightColor]" generates a 256-level gradient transitioning smoothly from your shadow tint to pure white.
  • -clut replaces every grayscale pixel value with the corresponding color from that gradient.

Method 3: Multi-Stop Gradients for Advanced Toning

If you want the tint restricted strictly to deep shadows while keeping both midtones and highlights neutral, create a multi-stop gradient with -clut:

magick input.jpg -colorspace Gray \
  \( -size 1x256 gradient:"#1a365d-#808080" gradient:"#808080-#ffffff" -append \) \
  -clut output.jpg

This ensures that values from 50% gray to 100% white transition naturally to pure white, confining the color cast exclusively to the lower half of the histogram.
