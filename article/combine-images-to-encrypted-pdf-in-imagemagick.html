Combine Images to Encrypted PDF in ImageMagick

This guide explains how to merge multiple image files into a single, password-protected PDF file using ImageMagick from the command line. By leveraging ImageMagick's built-in PDF property defines and Ghostscript integration, you can batch-process images, set permissions, and apply strong encryption in a single command.

Prerequisites

Ensure you have both ImageMagick (version 7 or later) and Ghostscript installed on your system. ImageMagick relies on Ghostscript under the hood for rendering and generating secure PDF documents.

The Command Syntax

To combine multiple images and apply password protection, use the magick command along with the -define operator to set user and owner passwords.

magick image1.jpg image2.png image3.jpg \
  -define pdf:user-password="YourUserPassword" \
  -define pdf:owner-password="YourOwnerPassword" \
  -define pdf:encryption-method=AES_128 \
  output_encrypted.pdf

Batch Converting Multiple Images

If you have an entire directory of images you want to combine in alphabetical order, you can use wildcards:

magick *.jpg -define pdf:user-password="SecretPassword" output_encrypted.pdf

Parameter Breakdown

  • image1.jpg image2.png ...: The list of source images you want to include as pages in the PDF. ImageMagick preserves the order provided in the command.
  • -define pdf:user-password="password": Sets the password required to open and view the PDF.
  • -define pdf:owner-password="password": Sets the administrative password required to change permissions or modify the document.
  • -define pdf:encryption-method=AES_128: Specifies the encryption algorithm. Standard options include AES_128, AES_256, or RC4_128 depending on your Ghostscript version support.
  • output_encrypted.pdf: The final destination file.
