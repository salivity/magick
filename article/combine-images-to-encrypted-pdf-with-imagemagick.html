Combine Images to Encrypted PDF with ImageMagick

This article provides the exact command-line syntax and options required to merge multiple image files into a single, password-protected PDF using ImageMagick. You will learn the commands for both ImageMagick version 7 and version 6, how to set user and owner passwords, and how to apply compression settings to manage the final file size.

Basic Syntax for ImageMagick 7

In modern versions of ImageMagick (v7+), the magick command is used alongside PDF-specific defines to set encryption passwords:

magick input1.jpg input2.png input3.jpg -define pdf:user-password="YourUserPassword" -define pdf:owner-password="YourOwnerPassword" output.pdf

Merging Multiple Images with a Wildcard

To combine all images in a directory into a single encrypted document in alphabetical order, use a wildcard:

magick *.jpg -define pdf:user-password="SecretPassword123" output.pdf

Password Definitions and Permissions

ImageMagick utilizes specific -define flags to configure PDF security levels:

  • User Password (pdf:user-password): The password required for a user to open and view the PDF document.
  • Owner Password (pdf:owner-password): The administrative password required to edit permissions, modify content, or change security settings.
  • Encryption Key Length (pdf:encryption-key-length): Sets the encryption strength (typically 40, 128, or 256 bits depending on the underlying delegate library).

Example with 128-bit encryption:

magick *.png -define pdf:encryption-key-length=128 -define pdf:user-password="OpenPassword" -define pdf:owner-password="AdminPassword" secured_document.pdf

Legacy Syntax for ImageMagick 6

For systems running ImageMagick version 6, use the convert command:

convert image1.jpg image2.jpg -define pdf:user-password="YourPassword" output.pdf

Alternatively, some ImageMagick builds support the -authenticate flag for setting passwords during PDF generation:

convert *.jpg -authenticate "YourPassword" output.pdf

Optimizing Output Quality and Page Geometry

To control page sizing, resolution, and image compression while encrypting, include the -density, -quality, and -compress flags:

magick -density 150 *.jpg -compress jpeg -quality 80 -define pdf:user-password="SecurePassword" final_optimized.pdf
  • -density 150: Sets the resolution to 150 DPI for appropriate document scaling.
  • -compress jpeg: Applies JPEG compression to keep the PDF file size small.
  • -quality 80: Adjusts the image compression quality level (0–100).
