Compare Two Animations Frame by Frame with ImageMagick

Comparing animated sequences frame-by-frame is essential for regression testing, rendering validation, and quality assurance in digital media workflows. This guide covers how to use ImageMagick's command-line tools to identify visual differences, generate statistical difference metrics, and create visual difference maps between two animated files (such as GIFs, WebP, or APNG sequences).

1. Generating a Visual Difference Animation

ImageMagick can process two multi-frame files directly and output a new animation where differing pixels are highlighted (red by default), while identical pixels are rendered in low-contrast grayscale.

magick compare animation_a.gif animation_b.gif -fuzz 5% diff_animation.gif
  • animation_a.gif and animation_b.gif: The two source animations to compare. They must have the same frame count and dimensions.
  • -fuzz 5%: Sets a color tolerance threshold so that minor compression artifacts or imperceptible color shifts are ignored.
  • diff_animation.gif: The output file containing the frame-by-frame visual difference.

To customize the highlight color for clearer visibility:

magick compare -highlight-color "#FF0000" -lowlight-color "#FFFFFF" animation_a.gif animation_b.gif diff_animation.gif

2. Measuring Difference Metrics Numerically

To determine the degree of difference programmatically without writing a full visual file, use the -metric option and direct the output to the null: sink.

magick compare -metric AE animation_a.gif animation_b.gif null:

Commonly used metrics include:

  • AE (Absolute Error): Outputs the exact count of pixels that differ.
  • RMSE (Root Mean Squared Error): Measures the average color difference (outputs values between 0.0 and 1.0, along with the raw value in parentheses).
  • PSNR (Peak Signal-to-Noise Ratio): Standard measurement for image compression quality.

To get individual scores for every single frame, append the metric calculation across frame indices or process them individually in a loop.

3. Deconstructing Sequences for Granular Frame Analysis

If the animated sequences have mismatched frame rates, disposal methods, or need isolated inspection, extract individual frames into a folder first.

Step 1: Coalesce and Extract

Animated GIFs often use frame disposal (only saving changed regions). Use -coalesce to fully reconstruct each full frame before exporting:

magick animation_a.gif -coalesce frames_a_%03d.png
magick animation_b.gif -coalesce frames_b_%03d.png

Step 2: Compare Specific Frames

Compare matching frame numbers directly:

magick compare -metric RMSE frames_a_005.png frames_b_005.png diff_005.png

4. Creating a Side-by-Side Comparison

To visually inspect both sources alongside their generated difference map, combine them horizontally into a composite frame:

magick frames_a_001.png frames_b_001.png diff_001.png +append side_by_side_001.png

Using +append aligns the images side-by-side, allowing direct visual comparison between original Frame A, original Frame B, and the difference map.
