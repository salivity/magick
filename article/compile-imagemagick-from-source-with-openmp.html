Compile ImageMagick from Source with OpenMP

Compiling ImageMagick from source with OpenMP allows the software to distribute image processing tasks across multiple CPU cores, significantly speeding up operations on multi-core systems. This guide provides step-by-step instructions to install the required build dependencies, configure the source tree with explicit OpenMP support, build the binaries, and verify that multi-threading is active on your system.

1. Install Build Tools and Dependencies

Before compiling, install a C compiler with OpenMP support (such as GCC), essential build tools, and the libraries for the image formats you intend to process.

On Debian/Ubuntu-based distributions:

sudo apt update
sudo apt install -y build-essential gcc g++ make \
    libgomp1 libpng-dev libjpeg-dev libtiff-dev \
    libwebp-dev libfreetype-dev libxml2-dev

On RHEL/CentOS/Fedora systems:

sudo dnf groupinstall -y "Development Tools"
sudo dnf install -y libgomp-devel libpng-devel libjpeg-turbo-devel \
    libtiff-devel libwebp-devel freetype-devel libxml2-devel

2. Download the ImageMagick Source Code

Clone the official Git repository or download and extract the latest source tarball.

git clone https://github.com/ImageMagick/ImageMagick.git
cd ImageMagick

Alternatively, download a tarball release:

wget https://imagemagick.org/archive/ImageMagick.tar.gz
tar -xzvf ImageMagick.tar.gz
cd ImageMagick-*

3. Configure the Build with OpenMP

Run the configure script to prepare the build environment. Explicitly pass the --enable-openmp flag to ensure multi-threading support is linked against libgomp.

./configure --enable-openmp --with-modules

Inspect the output at the end of the configuration run. Under the features summary, confirm that OpenMP is recognized:

OpenMP          --enable-openmp: yes

If it reads no, verify that GCC and libgomp are installed properly.

4. Compile and Install

Compile the source tree using all available processor cores, then install the compiled files to the system:

make -j$(nproc)
sudo make install
sudo ldconfig /usr/local/lib

The ldconfig command ensures the dynamic linker detects the newly installed shared libraries.

5. Verify the Installation

Check the installed ImageMagick version to confirm that OpenMP is listed under the compiled features:

magick -version

Look for OpenMP in the Features line of the output:

Version: ImageMagick 7.x.x-xx ...
Features: Cipher DPC HDRI Modules OpenMP

6. Managing OpenMP Threads

ImageMagick automatically attempts to utilize all available CPU threads. You can control the thread count per command or system-wide using environment variables:

# Limit ImageMagick to 4 threads for a specific run
MAGICK_THREAD_LIMIT=4 magick input.jpg -resize 50% output.jpg

# Or set standard OpenMP thread concurrency
export OMP_NUM_THREADS=4
