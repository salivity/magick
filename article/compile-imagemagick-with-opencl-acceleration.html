Compile ImageMagick with OpenCL Acceleration

This article explains how to build ImageMagick from source with OpenCL support to leverage GPU hardware acceleration for image processing tasks. Enabling OpenCL offloads computationally heavy filters and transformations to your graphics processor, significantly improving performance. Below, you will find the exact configuration flag needed, the required dependencies, and the steps to verify that your build correctly detects and utilizes your GPU.

The Configure Flag

The configure flag used to enable OpenCL GPU acceleration in ImageMagick is:

--enable-opencl

By default, the ./configure script attempts to detect OpenCL automatically, but passing the --enable-opencl flag explicitly enforces the requirement and ensures the build fails early if necessary development headers are missing.

Prerequisites

Before running the configuration script, ensure your system has the appropriate GPU drivers and OpenCL development packages installed:

  • OpenCL Headers and Libraries: Install the OpenCL ICD (Installable Client Driver) loader and developer files.
    • On Debian/Ubuntu: sudo apt install ocl-icd-opencl-dev opencl-headers
    • On Fedora/RHEL: sudo dnf install ocl-icd-devel opencl-headers
  • GPU Vendor Drivers: Ensure proprietary or compatible open-source drivers (such as NVIDIA CUDA Toolkit, AMD ROCm, or Intel Compute Runtime) are properly installed so the system can communicate with the hardware.

Compiling ImageMagick

To compile ImageMagick with OpenCL acceleration enabled, navigate to the extracted source directory and execute the following commands:

./configure --enable-opencl
make -j$(nproc)
sudo make install
sudo ldconfig

During the configuration step, review the summary output at the end of the script to confirm that OpenCL is listed under the enabled delegate libraries and features.

Verifying OpenCL Support

After installation, verify that ImageMagick was successfully compiled with OpenCL support by checking its version information:

magick -version

Look at the Features line in the output. If the compilation was successful, OpenCL will appear in the list:

Features: Cipher DPC HDRI Modules OpenCL OpenMP

You can control or disable OpenCL at runtime using the MAGICK_OCL_DEVICE environment variable. Setting MAGICK_OCL_DEVICE=OFF temporarily disables hardware acceleration, while setting it to an integer or device name selects a specific GPU device.
