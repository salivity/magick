Compile ImageMagick with OpenJPEG for JPEG 2000

This article provides the compile-time configuration flags, environment variables, and verification steps necessary to link the OpenJPEG library to ImageMagick. By following this guide, you can compile ImageMagick from source to handle ISO-compliant JPEG 2000 (JP2 and J2K) images using modern OpenJPEG delegates instead of deprecated libraries.

Primary Configure Flag

ImageMagick utilizes GNU Autoconf for its build system. To explicitly link the OpenJPEG library (specifically version 2.x, which provides ISO/IEC 15444-1 compliance), use the following configure option:

./configure --with-openjp2=yes

If OpenJPEG is installed in standard system paths (such as /usr or /usr/local), ./configure --with-openjp2 is sufficient to enable auto-detection.

Avoiding Conflicts with JasPer

ImageMagick historically used JasPer as its default JPEG 2000 delegate. Because JasPer is largely obsolete and lacks full modern ISO compliance, ensure it does not conflict with OpenJPEG by explicitly disabling it during configuration:

./configure --with-openjp2=yes --without-jasper

Specifying Custom Library Paths

If OpenJPEG is installed in a non-standard directory, the configure script might fail to detect it. You can direct ImageMagick to the proper headers and binaries using pkg-config or direct environment variables.

Using PKG_CONFIG_PATH

Set the path to the directory containing libopenjp2.pc:

PKG_CONFIG_PATH="/path/to/openjpeg/lib/pkgconfig" ./configure --with-openjp2=yes --without-jasper

Using OPENJP2_CFLAGS and OPENJP2_LIBS

If pkg-config is unavailable, specify the compilation flags directly:

./configure \
  --with-openjp2=yes \
  --without-jasper \
  OPENJP2_CFLAGS="-I/path/to/openjpeg/include/openjpeg-2.x" \
  OPENJP2_LIBS="-L/path/to/openjpeg/lib -lopenjp2"

Complete Build Sequence

A standard build routine on a Unix-like system follows these commands:

./configure --with-openjp2=yes --without-jasper
make
sudo make install
sudo ldconfig /usr/local/lib

Verifying OpenJPEG Integration

  1. Review the Configuration Summary: At the end of the ./configure execution, review the Delegate Configuration summary output in your terminal. Ensure that OPENJP2 or JP2 displays yes:

    OpenJP2           --with-openjp2=yes       yes

  2. Check ImageMagick Formats: After running make install, query the installed delegates to verify JPEG 2000 support:

    magick identify -list format | grep -i jp2

    A successful build will display JP2 and J2K formats with read/write (rw-) capabilities mapped to the OpenJPEG engine.
