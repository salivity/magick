Compute Depth Maps with ImageMagick Compare

This guide explains how to generate disparity and depth maps from stereo photo pairs using ImageMagick's compare command-line utility. You will learn the principles of stereo image comparison, how to prepare and align your stereo images, the exact commands required to extract pixel differences, and how to post-process the resulting output into a clear, usable depth map.

1. Prerequisites and Image Rectification

To successfully compute a depth map, your stereo image pair must be properly rectified. This means:

  • Both images must share identical dimensions.
  • The vertical alignment (Y-axis) must match exactly; depth differences should only appear horizontally (X-axis disparity).
  • Lens distortion should be corrected prior to comparison.

Ensure your files are named clearly, such as left.png and right.png.

2. Generating a Basic Disparity Map with compare

ImageMagick’s compare command computes pixel-by-pixel differences across images. For stereo pairs, horizontal shift differences reveal depth: objects closer to the camera exhibit larger shifts (higher disparity) than distant backgrounds.

Run the following command in your terminal:

magick compare -metric AE -fuzz 5% left.png right.png depth_raw.png

Note: If using ImageMagick v6, use compare instead of magick compare.

Parameter Breakdown:

  • -metric AE: Absolute Error metric, comparing pixel values directly.
  • -fuzz 5%: Ignores minor noise and lighting variances between the left and right captures.
  • depth_raw.png: The output image highlighting the regions with spatial disparity.

3. Creating a Normalized Grayscale Depth Map

The raw output from compare highlights differences in red and preserves background visual information. To convert this output into a standard grayscale depth map where brighter pixels indicate closer objects, combine comparison with color channel extraction and contrast normalization:

magick compare -metric RMSE -compose Difference left.png right.png difference.png
magick difference.png -colorspace Gray -auto-level -negate depth_map.png

Steps Explained:

  1. RMSE Comparison: Measures Root Mean Square Error between the stereo pair to capture subtle gradients in disparity.
  2. -colorspace Gray: Converts the difference output into a single-channel grayscale image.
  3. -auto-level: Stretches pixel intensity across the full dynamic range (pure black to pure white) to maximize contrast.
  4. -negate: Inverts the values so closer objects (larger difference) appear brighter and distant objects appear darker.

4. Multi-Offset Scanning for Dense Depth Maps

A single direct comparison only measures absolute pixel difference, not exact pixel shift. To build a more accurate dense disparity map, compare the left image against multiple horizontally shifted versions of the right image:

# Shift right image across a disparity range (e.g., 0 to 20 pixels)
for offset in $(seq 0 20); do
  magick right.png -roll +${offset}+0 right_shifted.png
  magick compare -metric RMSE left.png right_shifted.png diff_${offset}.png 2>/dev/null
done

By finding the offset value that minimizes difference for each block of pixels, you obtain the precise horizontal disparity value for each coordinate in your scene.
