Compute dHash Difference Hash With ImageMagick

Difference hash (dHash) is an algorithm used to identify visually similar images by comparing the relative gradients of adjacent pixels. This article explains how to generate a standard 64-bit dHash using ImageMagick by resizing the image to a 9x8 grayscale grid, comparing neighboring pixel values, and outputting the final binary or hexadecimal hash.

The dHash Logic

A standard difference hash requires:

  1. Converting the image to grayscale.
  2. Resizing it to 9 columns by 8 rows (72 pixels total), ignoring the aspect ratio.
  3. Comparing each pixel to its horizontal neighbor to the right (pixel[x] > pixel[x+1]).
  4. Assigning a 1 if the left pixel is brighter, or 0 if it is darker or equal, resulting in an 8x8 grid of 64 bits.

ImageMagick Command Syntax

You can perform the pixel differences and thresholding directly within ImageMagick using sub-image cropping and subtraction.

ImageMagick v7 (Recommended)

magick input.jpg -colorspace Gray -resize 9x8! \
  \( -clone 0 -crop 8x8+0+0 +repage \) \
  \( -clone 0 -crop 8x8+1+0 +repage \) \
  -delete 0 +swap -compose MinusSrc -composite \
  -threshold 0 -negate -depth 1 txt:-

ImageMagick v6

convert input.jpg -colorspace Gray -resize 9x8\! \
  \( -clone 0 -crop 8x8+0+0 +repage \) \
  \( -clone 0 -crop 8x8+1+0 +repage \) \
  -delete 0 +swap -compose MinusSrc -composite \
  -threshold 0 -negate -depth 1 txt:-

Converting Directly to a 64-Bit Hex String

To get a single 16-character hexadecimal hash string in a shell environment, pipe the pixel data to awk:

magick input.jpg -colorspace Gray -resize 9x8! \
  \( -clone 0 -crop 8x8+0+0 +repage \) \
  \( -clone 0 -crop 8x8+1+0 +repage \) \
  -delete 0 +swap -compose MinusSrc -composite \
  -threshold 0 -depth 1 txt:- | \
  awk '/gray\(0\)/ {printf "0"} /gray\(1\)/ {printf "1"}' | \
  awk '{
    for (i=1; i<=length($0); i+=4) {
      printf "%x", ("0b" substr($0, i, 4)) + 0
    }
    print ""
  }'

Alternative: Exporting Grayscale Values for Scripting

If you prefer to perform the binary comparisons in an external script (such as Python, Bash, or Node.js), extract the raw 9x8 pixel values directly into text format:

magick input.jpg -colorspace Gray -resize 9x8! -depth 8 txt:-

This outputs 72 coordinates (0,0 to 8,7) alongside their grayscale intensity values (0–255), ready to be iterated and compared row by row.
