Compute Haralick Texture Features in ImageMagick

Computing Haralick texture features such as Angular Second Moment (ASM) in ImageMagick provides quantitative data about spatial gray-level patterns and image uniformity. This guide demonstrates how to utilize ImageMagick’s built-in -features operator to construct Gray-Level Co-occurrence Matrices (GLCM), compute Haralick metrics across multiple angles, and isolate specific metrics like ASM directly from the command-line interface.

The -features Command Syntax

ImageMagick provides native support for generating Haralick texture metrics via the -features setting in the identify or magick utilities. The -features option requires an integer argument representing the spatial distance (offset) between pixel pairs.

To compute the features:

magick identify -features 1 input.jpg

In older versions (ImageMagick 6), use:

identify -features 1 input.jpg

Preprocessing to Grayscale

Haralick features are traditionally calculated on single-channel grayscale intensity values. If executed on a color image, ImageMagick will compute separate matrices and metrics for each color channel (Red, Green, Blue). To calculate standard texture features across luminance, convert the image to grayscale first:

magick input.jpg -colorspace Gray -features 1 info:

Understanding the Output

Running the command produces statistical metrics evaluated across four spatial orientations: 0°, 45°, 90°, and 135°. ImageMagick outputs both directional values and a combined average for the following metrics:

  • Angular Second Moment (ASM): Also known as Uniformity or Energy. It measures the textural uniformity of the image. High ASM values occur when pixel pair transitions are orderly and repetitive, while low values indicate texture complexity or randomness.
  • Contrast
  • Correlation
  • Sum of Squares: Variance
  • Inverse Difference Moment (Homogeneity)
  • Sum Average, Variance, and Entropy
  • Entropy
  • Difference Variance and Entropy
  • Information Measures of Correlation

An excerpt of the generated text block appears as follows:

Features (distance 1):
  Channel 0 (gray):
    Angular Second Moment:
      0 deg: 0.04312
      45 deg: 0.03981
      90 deg: 0.04255
      135 deg: 0.03912
      Average: 0.04115

Isolating Angular Second Moment Values

To extract only the Angular Second Moment without scanning the full report, pipe the output through standard text-filtering utilities like grep and sed or awk:

magick input.jpg -colorspace Gray -features 1 info: | grep -A 5 "Angular Second Moment"

To capture solely the average ASM numerical value:

magick input.jpg -colorspace Gray -features 1 info: | grep -A 5 "Angular Second Moment" | awk '/Average:/ {print $2}'
