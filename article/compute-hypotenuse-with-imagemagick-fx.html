Compute Hypotenuse with ImageMagick -fx

This article explains how to compute the hypotenuse of two distinct color channels in an image using the ImageMagick -fx operator. It details the mathematical syntax required by the expression parser, the channel reference notation, and provides direct command-line examples for both grayscale output and channel-specific assignments.

The -fx Hypotenuse Syntax

The -fx operator includes a built-in hypot(x, y) function that computes \(\sqrt{x^2 + y^2}\). To compute the hypotenuse of two color channels—such as the red and green channels—use the channel accessor properties on the primary image symbol u:

magick input.png -fx "hypot(u.r, u.g)" output.png

If you prefer explicit exponentiation rather than the built-in function, the equivalent mathematical expression is:

magick input.png -fx "sqrt(u.r^2 + u.g^2)" output.png

Channel Notation

ImageMagick normalizes channel values between 0.0 and 1.0. In the -fx expression engine:

  • u refers to the first image in the current image sequence.
  • .r, .g, and .b select the red, green, and blue channels respectively.
  • Alternatively, channel indices can be used: u.p[0] for red, u.p[1] for green, and u.p[2] for blue.

For example, to compute the hypotenuse of the green and blue channels:

magick input.png -fx "hypot(u.g, u.b)" output.png

Writing the Result to a Specific Channel

By default, running -fx applies the computed expression across all channels, resulting in a grayscale image. To compute the hypotenuse of two channels and write the result into a third channel (for instance, storing \(\text{hypot}(\text{red}, \text{green})\) into the blue channel while preserving the others), restrict the operation using the -channel setting:

magick input.png -channel B -fx "hypot(u.r, u.g)" +channel output.png

In this command:

  • -channel B activates only the blue channel for modification.
  • -fx "hypot(u.r, u.g)" reads the original red and green values and writes the resulting scalar strictly to the active blue channel.
  • +channel resets channel targeting back to default behavior for subsequent operations or saving.
