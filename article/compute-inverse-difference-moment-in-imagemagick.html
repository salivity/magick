Compute Inverse Difference Moment in ImageMagick

This article explains how to compute the Inverse Difference Moment (IDM) texture metric using ImageMagick's command-line tools. You will learn the exact command syntax required to generate Gray-Level Co-occurrence Matrix (GLCM) features, how to target the IDM metric specifically, and how to configure pixel distance for accurate texture analysis.

The Command to Compute IDM

In ImageMagick version 7, texture metrics are generated using the -features operator. The command to compute all texture metrics—including the Inverse Difference Moment—is:

magick input.png -features 1 info:

(For ImageMagick v6, replace magick with convert)

The integer argument following -features (in this case, 1) defines the pixel distance metric used to construct the spatial co-occurrence matrix.

Filtering Output Specifically for Inverse Difference Moment

By default, the -features operator outputs four Haralick texture features across all channels and four directional angles (0°, 45°, 90°, and 135°): Angular Second Moment, Contrast, Correlation, and Inverse Difference Moment.

To extract only the Inverse Difference Moment values, pipe the output into grep:

magick input.png -features 1 info: | grep "Inverse Difference Moment"

Computing IDM on Grayscale Images

Texture metrics like IDM are conventionally calculated on single-channel grayscale data rather than separate color channels. To convert the image to grayscale and compute IDM across the whole image texture in a single command, use:

magick input.png -colorspace Gray -features 1 info: | grep "Inverse Difference Moment"

Understanding the Output

The output displays IDM values for the image across the four standard directions:

  • Horizontal (0°)
  • Positive Diagonal (45°)
  • Vertical (90°)
  • Negative Diagonal (135°)

IDM measures image homogeneity. Values range from 0.0 to 1.0, where higher values indicate lower contrast and a smoother, more uniform local texture.
