Compute Morphological Gradient with ImageMagick

This guide provides a straightforward walkthrough on computing the morphological gradient of an image using ImageMagick. The morphological gradient highlights sharp intensity variations and boundaries by calculating the difference between an image's dilation and erosion, making it a valuable tool for edge detection. Below, you will learn the core syntax, kernel options, and specific gradient methods available in ImageMagick to achieve precise edge extraction.

The Standard Morphological Gradient

In mathematical morphology, the basic morphological gradient is calculated by subtracting the eroded version of an image from its dilated version. ImageMagick includes a built-in method specifically for this operation via the -morphology operator.

To compute the basic gradient, use the Gradient method followed by your chosen structuring element (kernel):

magick input.png -morphology Gradient Disk:1 output.png

Note: If you are using ImageMagick 6, replace magick with convert.

In this command:

  • -morphology Gradient instructs ImageMagick to perform both dilation and erosion and compute their difference.
  • Disk:1 defines the kernel shape as a circular disk with a radius of 1 pixel (creating a 3x3 pixel neighborhood).

Choosing the Right Kernel

The kernel (or structuring element) controls the size and direction of the edge detection. You can adjust the shape and radius to fine-tune your results:

  • Disk: Provides isotropic (uniform in all directions) edge detection. 
    magick input.png -morphology Gradient Disk:1.5 output.png
  • Square: Emphasizes horizontal, vertical, and diagonal edges equally across a square grid. 
    magick input.png -morphology Gradient Square:1 output.png
  • Diamond: Focuses on horizontal and vertical directions based on Manhattan distance. 
    magick input.png -morphology Gradient Diamond:1 output.png

Increasing the radius parameter (the number after the colon) increases the thickness of the detected boundaries.

Computing Half-Gradients

ImageMagick also allows you to calculate directional half-gradients, which provide thinner, more localized edges depending on your requirements.

External Gradient (EdgeOut)

The external gradient subtracts the original image from the dilated image, producing an outline that sits just outside the boundary of the object:

magick input.png -morphology EdgeOut Disk:1 external_gradient.png

Internal Gradient (EdgeIn)

The internal gradient subtracts the eroded image from the original image, producing an outline that sits just inside the boundary of the object:

magick input.png -morphology EdgeIn Disk:1 internal_gradient.png

Preprocessing for Clean Edges

Morphological operations are often most effective when applied to single-channel images. Converting an image to grayscale before computing the gradient helps eliminate color artifacts and highlights structural contrast:

magick input.png -colorspace Gray -morphology Gradient Disk:1 gradient_edges.png

If you need a binary edge map, you can chain a thresholding operation directly after the gradient calculation:

magick input.png -colorspace Gray -morphology Gradient Disk:1 -threshold 20% binary_edges.png
