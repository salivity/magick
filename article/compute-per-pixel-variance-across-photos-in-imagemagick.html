Compute Per-Pixel Variance Across Photos in ImageMagick

This guide demonstrates how to calculate the per-pixel variance across a burst or sequence of photographs using ImageMagick. Because variance measures the spread of pixel intensity values over time, it is frequently used to detect motion, analyze sensor noise, and isolate transient objects. Below, you will find the single-line command required to perform this calculation, a breakdown of the mathematical process, and practical considerations for handling dynamic range.

The ImageMagick Command

To compute per-pixel variance across an image burst, use the following ImageMagick 7 command:

magick input_*.jpg \
  \( -clone 0--1 -evaluate Pow 2 -evaluate-sequence Mean \) \
  \( -clone 0--2 -evaluate-sequence Mean -evaluate Pow 2 \) \
  -delete 0--3 \
  -compose Subtract -composite \
  variance.tiff

If you are running ImageMagick 6, replace magick with convert.

How the Command Works

ImageMagick does not have a dedicated single-word sequence operator for variance, but it computes variance using the algebraic definition:

\[\text{Var}(X) = E[X^2] - (E[X])^2\]

In this formula, \(E[X^2]\) represents the mean of the squared pixel values, and \((E[X])^2\) represents the square of the mean pixel values.

  1. input_*.jpg: Loads the burst of images into the image stack (indices 0 through N-1).
  2. \( -clone 0--1 -evaluate Pow 2 -evaluate-sequence Mean \): Clones all input images, squares every pixel's value (\(X^2\)), and calculates the average across the sequence to produce \(E[X^2]\).
  3. \( -clone 0--2 -evaluate-sequence Mean -evaluate Pow 2 \): Clones the original input images again, computes their average (\(E[X]\)), and squares that average to produce \((E[X])^2\).
  4. -delete 0--3: Removes the original input images from memory, leaving only the two processed images: \(E[X^2]\) and \((E[X])^2\).
  5. -compose Subtract -composite: Subtracts the squared mean from the mean of the squares, resulting in the per-pixel variance.
  6. variance.tiff: Saves the resulting image. Using a format like 16-bit or 32-bit TIFF preserves low-magnitude variance values that standard 8-bit formats (like JPEG or standard PNG) might truncate or crush to black.

Considerations for Accuracy

  • HDRI Support: Modern ImageMagick installations have HDRI (High Dynamic Range Imaging) enabled by default. This ensures intermediate operations—such as squaring values—do not clip at maximum intensity.
  • Standard Deviation: If you need the standard deviation instead of variance, append -evaluate Pow 0.5 directly after -composite to compute the square root of the variance image.
  • Normalization: The output variance values are relative to ImageMagick's internal quantum range (\([0, 1]\) in HDRI). If the variance values are small and appear nearly black, you can stretch the contrast for visual inspection by adding -auto-level before saving the output.
