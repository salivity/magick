Compute Pixel-by-Pixel MAD in ImageMagick

This guide explains how to calculate the pixel-by-pixel Median Absolute Deviation (MAD) across an image stack using ImageMagick. Because ImageMagick does not provide a single native operator for MAD, the computation is executed in a single command pipeline by combining median sequence evaluation, difference compositing, and a final median reduction.

The Command

Run the following ImageMagick 7 command in your terminal:

magick input_*.png \
  \( -clone 0--1 -evaluate-sequence median \) \
  -reverse -compose Difference -layers Composite \
  -evaluate-sequence median mad_output.png

How the Command Works

The Median Absolute Deviation measures statistical dispersion and is defined mathematically as:

\[\text{MAD} = \text{median}(|X_i - \text{median}(X)|)\]

The command executes this formula across the image stack in three distinct phases:

  1. Calculate the Stack Median:
    \( -clone 0--1 -evaluate-sequence median \)
    Clones all loaded source images into an isolated sub-shell and flattens them into a single reference image representing the median color value at each \((x, y)\) coordinate.

  2. Compute Absolute Differences:
    -reverse -compose Difference -layers Composite
    Reverses the image sequence so the newly computed median image acts as the base canvas, then uses the Difference composition mode to subtract each individual input image from that median image. This produces a stack of absolute deviation maps (\(|X_i - \text{median}|\)).

  3. Compute the Median of the Deviations:
    -evaluate-sequence median mad_output.png
    Applies the median operator across the generated difference maps to determine the final median absolute deviation for every pixel, writing the result to mad_output.png.

Applying Normal Distribution Scaling

If you require the MAD to serve as a consistent estimator for standard deviation under a normal distribution, multiply the result by approximately \(1.4826\):

magick input_*.png \
  \( -clone 0--1 -evaluate-sequence median \) \
  -reverse -compose Difference -layers Composite \
  -evaluate-sequence median \
  -evaluate Multiply 1.4826 mad_scaled.png
