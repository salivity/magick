Compute Rec601 Image Luminance in ImageMagick

This article provides the exact ImageMagick syntax required to calculate perceived image luminance using standard ITU-R Rec. 601 coefficients. Converting an image to grayscale using perceived luminance weights red at 29.9%, green at 58.7%, and blue at 11.4% (\(Y = 0.299R + 0.587G + 0.114B\)). You will find direct command-line examples for both ImageMagick v7 and legacy v6 implementations below.

Method 1: Using the Native -grayscale Operator (Recommended)

ImageMagick provides built-in support for Rec. 601 calculations via the -grayscale option. This is the fastest and most efficient method.

For non-linear (gamma-corrected) Rec601 Luma (\(Y'\)):

magick input.jpg -grayscale Rec601Luma output.jpg

For linear Rec601 Luminance (\(Y\)):

magick input.jpg -grayscale Rec601Luminance output.jpg

(For ImageMagick v6, replace magick with convert).

Method 2: Using the -color-matrix Operator

If you need precise matrix transformations or need to map the Rec. 601 luminance into specific RGB channels, use -color-matrix.

magick input.jpg -color-matrix " \
  0.299 0.587 0.114 \
  0.299 0.587 0.114 \
  0.299 0.587 0.114 " output.jpg

Method 3: Using the -intensity Setting

You can define the global intensity method as Rec. 601 before applying grayscale or colorspace operations:

magick input.jpg -intensity Rec601Luma -colorspace Gray output.jpg

Method 4: Using the -fx Custom Expression

For fully manual control over the calculation per pixel, you can compute the values directly using the -fx operator. Note that -fx is computationally slower than -grayscale or -color-matrix.

magick input.jpg -fx "0.299*r + 0.587*g + 0.114*b" output.jpg
