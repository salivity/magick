Compute Skew Angle with ImageMagick Deskew

This guide demonstrates how to calculate the skew angle of scanned text documents using ImageMagick's built-in -deskew operator. By running the deskew analysis and querying the internal image metadata, you can extract the exact rotation angle in degrees without needing to modify or save a new image file.

How ImageMagick Calculates Skew Angle

ImageMagick's -deskew operator analyzes the distribution of dark and light pixels along various projection angles to find the dominant orientation of text lines. When this operation runs, ImageMagick sets an internal property named deskew:angle, which stores the calculated angle in degrees.

Command to Output the Skew Angle

To compute and print only the skew angle directly to the terminal, run the following command:

For ImageMagick v7:

magick input_scan.png -deskew 40% -format "%[deskew:angle]\n" info:

For ImageMagick v6:

convert input_scan.png -deskew 40% -format "%[deskew:angle]\n" info:

Explanation of Command Options

  • input_scan.png: The path to your input image (TIFF, PNG, JPEG, or PDF page).
  • -deskew 40%: Analyzes the image to calculate the tilt angle. The 40% value is the threshold percentage, which defines how strictly the algorithm differentiates foreground text from the background. A setting of 40% is optimal for most standard text documents.
  • -format "%[deskew:angle]\n": Extracts the calculated angle value stored in the image properties and appends a newline.
  • info:: Outputs the formatted text directly to standard output (stdout) rather than writing an output image to the disk.

Interpreting the Output

The output is a single floating-point number representing the rotation angle in degrees:

  • A positive value (e.g., 1.452) indicates the document is tilted clockwise.
  • A negative value (e.g., -2.105) indicates the document is tilted counter-clockwise.
  • A value of 0 indicates no significant skew was detected within the specified threshold.

Tuning the Detection Threshold

If the detected angle is inaccurate, adjust the threshold percentage:

  • Lower values (e.g., 20%–30%): Better for low-contrast scans or documents with faint text.
  • Higher values (e.g., 60%–80%): Better for high-contrast, clean documents with heavy background noise, bleed-through, or dark borders.

Correcting the Skew

If you want to compute the angle and automatically rotate the image in a single step, supply an output filename instead of the info: directive:

magick input_scan.png -deskew 40% output_deskewed.png
