Configure Custom Delegates in ImageMagick delegates.xml

ImageMagick relies on external helper programs, known as delegates, to decode, encode, or manipulate file formats that it cannot process natively. This guide explains how to configure custom external delegate commands by locating, modifying, and testing the delegates.xml configuration file to expand ImageMagick's file handling capabilities.

1. Locate the delegates.xml File

ImageMagick searches for configuration files in several system and user-level directories. To identify the active configuration paths and locate your delegates.xml file, run the following command:

magick -list delegate

(Use convert -list delegate if using ImageMagick v6).

Typical file paths include:

  • Linux (System-wide): /etc/ImageMagick-7/delegates.xml or /usr/local/etc/ImageMagick-7/delegates.xml
  • Linux (User-specific): ~/.config/ImageMagick/delegates.xml
  • macOS (Homebrew): /opt/homebrew/etc/ImageMagick-7/delegates.xml
  • Windows: C:\Program Files\ImageMagick-7.x.x-Q16\delegates.xml

You can edit the system-wide file using administrative privileges or create/modify the file in your user configuration directory (~/.config/ImageMagick/delegates.xml) to avoid overriding global settings.

2. Understand the Delegate XML Structure

Delegate rules are defined within <delegatemap> as individual <delegate> elements. Each element defines how an input format is read (decode) or written (encode).

A standard <delegate> element contains the following primary attributes:

  • decode: The source format or file extension being read (e.g., "pdf", "svg", "custom").
  • encode: The target format generated by the delegate command (e.g., "png", "tiff").
  • mode: Execution mode. Use "bi" for bidirectional (both encode and decode), "encode" for encoding only, or "decode" for decoding only.
  • command: The shell command executed by ImageMagick, using specific substitution variables.

Substitution Tokens

Inside the command attribute, ImageMagick provides placeholder tokens:

  • "%i": Input file path.
  • "%o": Output file path.
  • "%u": Unique temporary file.
  • "%s": Scene/page number (useful for multi-page documents).
  • "%w" and "%h": Target width and height.
  • "%q": Quantum depth/quality setting.

3. Add a Custom Delegate Command

Open delegates.xml in a text editor and add your custom entry inside the <delegatemap> tags.

Example: Custom SVG Renderer using resvg

If you want ImageMagick to use an external tool like resvg instead of the default renderer for SVG decoding, add:

<delegate decode="svg" command="&quot;resvg&quot; &quot;%i&quot; &quot;%o&quot;"/>

Example: Custom Format Conversion

To convert a proprietary raw format (.myraw) to a PNG intermediate file using a custom utility:

<delegate decode="myraw" encode="png" mode="decode" command="&quot;my-raw-converter&quot; --input &quot;%i&quot; --output &quot;%o&quot; --width &quot;%w&quot;"/>

Note: Special characters inside the command must be XML-escaped (e.g., use &quot; for quotation marks, &amp; for ampersands).

4. Verify and Test the New Delegate

After saving the delegates.xml file, check if ImageMagick recognizes the newly added rule:

magick -list delegate | grep myraw

Test the delegate with actual image processing while enabling the -verbose flag. This displays the underlying external command as it executes:

magick -verbose input.myraw output.jpg

If configured correctly, the output stream will show ImageMagick invoking your custom command with the substituted file paths before completing the final conversion.
