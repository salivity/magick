Configure Demosaicing for Raw Files in ImageMagick

This guide explains how to configure demosaicing algorithms—such as Variable Number of Gradients (VNG) and Patterned Pixel Grouping (PPG)—when decoding camera raw files in ImageMagick. It covers the command-line defines utilized by ImageMagick’s LibRaw delegate, maps the numeric quality values to their corresponding demosaicing algorithms, and demonstrates practical usage for processing raw image formats.

How ImageMagick Handles Raw Demosaicing

ImageMagick does not decode camera raw formats (such as .CR2, .NEF, .ARW, or .DNG) natively. Instead, it delegates raw processing to LibRaw (or historically, dcraw). LibRaw reads the Bayer pattern recorded by the camera sensor and converts it into a full RGB image through demosaicing.

To control which demosaicing algorithm is applied, ImageMagick provides the -define option prefixed with dng:.

Configuring the Demosaicing Algorithm with dng:user-qual

The primary setting for selecting the demosaicing algorithm is dng:user-qual. This option directly maps to LibRaw’s user_qual parameter (equivalent to the -q parameter in dcraw).

Available Algorithm Values

  • 0 – Linear / Bilinear: Fast, low-resource interpolation, but prone to color fringing and soft edges.
  • 1 – VNG (Variable Number of Gradients): Effective at reducing color moiré and artifacts in high-frequency textured areas.
  • 2 – PPG (Patterned Pixel Grouping): A fast, edge-directed interpolation algorithm that produces sharp transitions and fine edge clarity.
  • 3 – AHD (Adaptive Homogeneity-Directed): LibRaw's typical default algorithm, balancing edge preservation and color artifact suppression.
  • 4 – DCB: An advanced algorithm designed to preserve high detail while minimizing chromatic aberrations.
  • 11 – DHT: High-fidelity demosaicing designed for challenging color patterns.
  • 12 – Modified AHD: An updated implementation of the AHD algorithm.

Command-Line Examples

To apply an algorithm correctly, place the -define statement before the input raw file so ImageMagick applies the setting while decoding.

Using VNG Demosaicing

magick -define dng:user-qual=1 input.CR2 output.png

Using PPG Demosaicing

magick -define dng:user-qual=2 input.NEF output.tiff

Using DCB Demosaicing

magick -define dng:user-qual=4 input.ARW output.jpg

Related Demosaicing Options

ImageMagick provides additional -define settings to further refine raw decoding:

  • Bypass Demosaicing: If you require raw mosaic sensor data without any interpolation applied, disable demosaicing entirely: 
    magick -define dng:demosaic=false input.CR2 raw_sensor.tiff
  • Four-Color Interpolation (dng:four-color-rgb): Computes separate green values (treating green channels as distinct) to minimize maze artifacts with specific sensors: 
    magick -define dng:user-qual=1 -define dng:four-color-rgb=true input.CR2 output.png

Configuring via delegates.xml (For Standalone dcraw)

If your ImageMagick build uses an external dcraw binary instead of the built-in LibRaw delegate:

  1. Locate your ImageMagick configuration directory and open delegates.xml.
  2. Locate the decode line for raw camera formats: 
    <delegate decode="dng:decode" command="&quot;dcraw&quot; -6 -W -q 3 -O &quot;%u.ppm&quot; &quot;%i&quot;"/>
  3. Change the -q flag value to select your desired algorithm:
    • -q 1 for VNG
    • -q 2 for PPG
  4. Save the file to make the selected algorithm the global default for raw decoding.
