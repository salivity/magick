Configure ImageMagick CR2 and CR3 Demosaicing

ImageMagick processes camera RAW formats such as Canon CR2 and CR3 through external delegate libraries, primarily LibRaw or dcraw, rather than native decoding engines. This article explains how ImageMagick routes RAW decoding tasks, how to locate and configure the delegates.xml file, and the specific delegate flags used to adjust or override demosaicing algorithms for CR2 and CR3 workflows.

How ImageMagick Handles CR2 and CR3 Files

ImageMagick checks its delegate subsystem whenever it encounters Canon RAW formats. Standard behavior routes CR2 and CR3 to external command-line utilities or shared C libraries:

  • Canon CR2: Typically processed using dcraw or LibRaw's emulation wrapper (dcraw_emu).
  • Canon CR3: Encapsulated in an ISOBMFF (HEIF) container. Handling CR3 requires LibRaw (version 0.20 or later) built with CR3 support enabled, or a dedicated delegate configuration calling a modern LibRaw binary.

Locating and Modifying delegates.xml

Delegate definitions dictate the exact command executed when reading RAW formats. You can locate your system's active delegate configuration file using the following ImageMagick command:

magick -list delegate

To edit the settings directly, open delegates.xml, typically located in:

  • Linux: /etc/ImageMagick-7/delegates.xml or ~/.config/ImageMagick/delegates.xml
  • macOS (Homebrew): /usr/local/etc/ImageMagick-7/delegates.xml or /opt/homebrew/etc/ImageMagick-7/delegates.xml
  • Windows: Located in the primary installation directory alongside magick.exe.

Delegate Flags Controlling Demosaicing

Demosaicing quality, algorithm choice, and speed are controlled by the flags appended to the delegate command in delegates.xml. The primary delegate entry for RAW formats typically looks like this:

<delegate decode="dng:decode" command="&quot;dcraw&quot; -6 -W -q 3 -O &quot;%o&quot; &quot;%i&quot;"/>

Depending on your installation, CR2 and CR3 might fall under decode="cr2", decode="cr3", or generic RAW delegates (decode="dng").

The primary flags governing the demosaicing phase include:

  • -q 0 (Bilinear Interpolation): The fastest method, resulting in lower image quality and potential color artifacts around high-contrast edges.
  • -q 1 (VNG - Variable Number of Gradients): Reduces color moiré at the expense of processing speed.
  • -q 2 (PPG - Patterned Pixel Grouping): A balanced algorithm providing sharp detail with moderate processing requirements.
  • -q 3 (AHD - Adaptive Homogeneity-Directed): Often the default setting. It calculates horizontal and vertical interpolations to minimize chromatic aberrations and color artifacts.
  • -q 4 (DCB - LibRaw only): An advanced demosaicing algorithm available in modern LibRaw distributions that reduces moiré and edge artifacts on fine patterns.
  • -h (Half-size decoding): Skips full demosaicing entirely, outputting a half-resolution image at significantly faster speeds.
  • -d (Document Mode): Disables demosaicing, treating the raw sensor data as grayscale/Bayer arrays without color interpolation.

Overriding Settings via ImageMagick CLI

If ImageMagick is built with direct LibRaw integration rather than an external CLI delegate, demosaicing can sometimes be passed via the command line without editing delegates.xml:

magick -define dng:demosaic=ahd input.cr2 output.tiff

If ImageMagick delegates via an external command, direct changes to the flags in delegates.xml are required to ensure the specified demosaicing level is applied to all incoming CR2 and CR3 conversions.
