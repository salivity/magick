Configure ImageMagick Mean-Shift Parameters

ImageMagick’s mean-shift filter is an edge-preserving smoothing operator commonly used for image segmentation, noise removal, and artistic posterization effects. Configuring the mean-shift algorithm effectively requires tuning two core values: the spatial radius, which defines the physical pixel neighborhood to inspect, and the color radius (or color distance), which sets the threshold for grouping similar color values. This guide explains the exact syntax and best practices for setting both parameters.

Mean-Shift Command Syntax

In ImageMagick (version 7+), the mean-shift operation is invoked using the -mean-shift operator followed by a geometry string:

magick input.jpg -mean-shift {width}x{height}+{color_distance}[%] output.jpg

For ImageMagick 6, replace magick with convert.

Configuring the Spatial Radius

The spatial radius is defined by the {width}x{height} portion of the geometry argument. It determines the pixel window (neighborhood) examined around each pixel during each iteration of the algorithm.

  • Format: Typically specified as a square, such as 7x7, 10x10, or 21x21.
  • Behavior: Smaller spatial dimensions (e.g., 3x3 to 7x7) preserve finer structural details and small textures. Larger values (e.g., 15x15 to 31x31) group larger regions together, significantly smoothing out texture across broader surfaces.
  • Performance Impact: Computational cost scales dramatically with larger spatial dimensions. Keep the spatial window as small as possible to achieve your desired smoothing effect without excessive processing time.

Configuring the Color Radius (Distance)

The color radius is specified after the + sign and defines the maximum distance in color space for two pixels to be considered part of the same cluster.

  • Absolute Values vs. Percentages: Color distance can be set as an absolute value or as a percentage using the % symbol. Using percentages (e.g., +10%) is strongly recommended because absolute values depend on your build's quantum depth (Q8, Q16, or Q32). A value like +10% works consistently across all installations.
  • Behavior:
    • Low values (e.g., +2% to +5%) only merge pixels that are nearly identical in color, preserving subtle gradients.
    • Moderate values (e.g., +10% to +15%) merge similar tones, creating flat color fields while preserving sharp edges.
    • High values (e.g., +25% and above) aggressively merge distinct colors, leading to high-contrast posterization.

Practical Examples

Subtle Denoising and Texture Smoothing: To remove noise while keeping edges and fine details intact, use a small spatial radius and a low color threshold:

magick photo.jpg -mean-shift 5x5+5% denoised.jpg

Flat Color Segmentation (Cartoon Effect): To eliminate textures and create uniform color regions suitable for segmentation or graphic illustration, increase both parameters:

magick photo.jpg -mean-shift 15x15+12% segmented.jpg

Aggressive Stylization: For broad, abstract color pooling across wide areas of the image:

magick photo.jpg -mean-shift 25x25+20% posterized.jpg
