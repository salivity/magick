Configure ImageMagick with OpenCL GPU Acceleration

This article provides a straightforward guide to configuring ImageMagick to use OpenCL for GPU-accelerated image processing. By offloading intensive filtering operations—such as blurs, convolutions, and resizing—to a compatible graphics card, you can significantly reduce processing times. You will learn the required prerequisites, how to verify or compile OpenCL support, how to configure GPU device selection, and how to execute accelerated filtering operations.

1. Ensure GPU Driver and OpenCL Runtime Support

Before configuring ImageMagick, ensure that your system has the proper OpenCL runtimes and drivers installed for your graphics hardware:

  • NVIDIA: Install the proprietary NVIDIA GPU drivers (the OpenCL runtime is included).
  • AMD: Install the AMD ROCm platform or the proprietary AMDGPU-PRO driver.
  • Intel: Install the Intel OpenCL NEO driver package for integrated or discrete GPUs.

You can verify that your operating system detects OpenCL platforms by installing and running clinfo in your terminal.

2. Verify or Install ImageMagick with OpenCL

On Windows:

Pre-compiled binary releases for Windows typically include OpenCL support by default. Download and run the dynamic/DLL installer from the official ImageMagick release page, and ensure the "Install OpenCL support" option is checked during setup.

On Linux (Building from Source):

If your Linux package manager does not include OpenCL-enabled binaries, you must compile ImageMagick from source with the --enable-opencl flag:

# Install OpenCL development headers
sudo apt-get install ocl-icd-opencl-dev opencl-headers  # Debian/Ubuntu
# sudo dnf install ocl-icd-devel opencl-headers         # RHEL/Fedora

# Clone and configure ImageMagick
git clone https://github.com/ImageMagick/ImageMagick.git
cd ImageMagick
./configure --enable-opencl --with-modules
make -j$(nproc)
sudo make install
sudo ldconfig

3. Verify OpenCL Activation in ImageMagick

To verify that ImageMagick recognizes your OpenCL runtime, run:

magick -version

Look for OpenCL in the Features line of the output:

Features: Cipher DPC HDRI Modules OpenCL

To list all detected OpenCL devices available to ImageMagick, run:

magick -list opencl

4. Configure Device Selection and Performance Profiling

ImageMagick automatically benchmarks available OpenCL devices on their first run and creates a configuration profile (saved in ~/.config/ImageMagick/ on Linux or %APPDATA%\ImageMagick\ on Windows). This profile determines whether using the GPU is faster than the CPU for specific filter kernels.

You can manually control device behavior using environment variables:

  • Force a specific OpenCL device type: 
    export MAGICK_OCL_DEVICE=GPU    # Force GPU usage
# or
export MAGICK_OCL_DEVICE=CPU    # Force CPU usage
  • Disable OpenCL entirely: 
    export MAGICK_OCL_DEVICE=OFF

5. Running Accelerated Image Filters

OpenCL acceleration in ImageMagick activates automatically for supported computationally intensive operations. Common supported filters include -blur, -adaptive-blur, -convolve, -radial-blur, and -resize.

Example of executing an accelerated adaptive blur:

magick input.jpg -adaptive-blur 0x5 output.jpg

To monitor whether OpenCL is actively dispatching kernels to the GPU, prepend the debug flag to your command:

magick -debug Accelerate input.jpg -blur 0x8 output.jpg

The output will log OpenCL kernel compilations, memory transfers, and execution times directly to the console.
