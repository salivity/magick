Configure JPEG XL Speed and Quality in ImageMagick

This guide explains how to configure JPEG XL (JXL) compression speed and quality settings in ImageMagick. By utilizing standard quality flags alongside specialized -define parameters, you can fine-tune the balance between visual fidelity, file size, and processing time for both lossy and lossless encoding.

Adjusting JPEG XL Quality

In ImageMagick, JPEG XL image quality is primarily controlled using the standard -quality parameter.

Lossy Compression

For lossy compression, set the -quality parameter between 1 and 99. A higher number results in higher visual fidelity and larger file sizes:

magick input.png -quality 85 output.jxl

A value between 75 and 90 is generally recommended for high-quality web images.

Lossless Compression

To encode an image losslessly, set -quality 100 or explicitly enable the lossless define:

magick input.png -quality 100 output.jxl

Alternatively:

magick input.png -define jxl:lossless=true output.jxl

Configuring Compression Speed (Effort)

JPEG XL compression speed is governed by the "effort" level, which controls how much CPU time the encoder spends searching for compression optimizations. In ImageMagick, this is set using the -define jxl:effort option with a value ranging from 1 (fastest encoding, larger file size) to 9 (slowest encoding, best compression).

  • Effort 1–3 (Fast): Best for real-time applications or quick batch conversions.
  • Effort 7 (Default): Offers a balanced trade-off between encoding time and compression ratio.
  • Effort 8–9 (Slow / Best): Ideal for archival storage or final web assets where minimum file size is prioritized over CPU time.

Example: High Effort (Better Compression)

magick input.png -quality 85 -define jxl:effort=8 output.jxl

Example: Low Effort (Fast Processing)

magick input.png -quality 85 -define jxl:effort=3 output.jxl

Practical Command Examples

1. Maximum Lossless Compression for Archiving

To achieve the smallest possible file size while preserving pixel-perfect data:

magick input.png -quality 100 -define jxl:effort=9 output.jxl

2. High-Quality Web Production Asset

For high visual fidelity with balanced compression speed suitable for deployment:

magick input.png -quality 80 -define jxl:effort=7 output.jxl

3. Rapid Batch Processing

To convert a large directory of images quickly without overburdening the CPU:

magick mogrify -format jxl -quality 75 -define jxl:effort=2 *.jpg
