Configure SSIM Window and Constants in ImageMagick

ImageMagick enables precise structural similarity (SSIM) image comparisons by allowing users to adjust calculation parameters directly through command-line definitions. This guide explains how to customize the SSIM Gaussian window dimensions and stability constants (\(K_1\) and \(K_2\)) using ImageMagick's -define directives to tailor quality assessments to specific image analysis workflows.

Basic SSIM Syntax in ImageMagick

To compute SSIM between two images, the compare command (or magick compare in ImageMagick 7) is executed with the -metric SSIM argument:

magick compare -metric SSIM reference.png distorted.png null:

Window Dimension Configuration

The SSIM metric relies on a local Gaussian sliding window to evaluate luminance, contrast, and structural similarity across local neighborhoods. ImageMagick configures this window using two key parameters:

  • ssim:radius: Sets the radius of the Gaussian weighting window.
  • ssim:sigma: Sets the standard deviation (\(\sigma\)) of the Gaussian weighting function.

To modify the default window dimensions (default radius is derived from \(\sigma\), typically \(\sigma = 1.5\)), use the following syntax:

magick compare -metric SSIM \
  -define ssim:radius=5 \
  -define ssim:sigma=1.5 \
  reference.png distorted.png null:

A smaller window focuses more on micro-textures and high-frequency details, while a larger window evaluates broader structural changes across larger regions.

SSIM Constant Configuration

SSIM uses two stabilizing constants, \(C_1\) and \(C_2\), to prevent division-by-zero instability when local mean or variance is close to zero. These are calculated as:

  • \(C_1 = (K_1 \cdot L)^2\)
  • \(C_2 = (K_2 \cdot L)^2\)

(where \(L\) is the dynamic range of pixel values, automatically handled by ImageMagick according to quantum depth).

You can adjust \(K_1\) and \(K_2\) using:

  • ssim:k1: Modifies the luminance stability constant (standard default is 0.01).
  • ssim:k2: Modifies the contrast/structure stability constant (standard default is 0.03).
magick compare -metric SSIM \
  -define ssim:k1=0.01 \
  -define ssim:k2=0.03 \
  reference.png distorted.png null:

Complete Command Example

Combining window dimensions and constants in a single command:

magick compare -metric SSIM \
  -define ssim:radius=7 \
  -define ssim:sigma=2.0 \
  -define ssim:k1=0.01 \
  -define ssim:k2=0.03 \
  reference.png distorted.png difference_map.png

This command outputs both the numerical SSIM score to the terminal and a visual difference map saved to difference_map.png.
