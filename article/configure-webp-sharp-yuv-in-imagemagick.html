Configure WebP Sharp-YUV in ImageMagick

This article provides a straightforward guide on how to configure WebP preprocessing filters—specifically the sharp-yuv algorithm—in ImageMagick. You will learn the exact command-line syntax required to pass WebP encoder definitions, what prerequisites are needed, and how to combine sharp-yuv with other WebP filtering and preprocessing parameters to optimize output quality.

Understanding Sharp-YUV

The sharp-yuv feature (provided by Google's libwebp) is an advanced color conversion algorithm that minimizes chroma distortion during RGB-to-YUV420 conversion. By default, downsampling color channels can cause noticeable color bleeding or artifacts around high-contrast edges and text. Enabling sharp-yuv produces sharper, cleaner color transitions at the expense of a slight increase in encoding time.

Prerequisites

To use sharp-yuv within ImageMagick:

  • ImageMagick 7+ (recommended) or ImageMagick 6.
  • libwebp 1.3.0 or higher compiled with libsharpyuv support.

You can verify your current delegate version using:

magick -version

Look for webp under the delegates list to ensure support is present.

Enabling Sharp-YUV in ImageMagick

ImageMagick exposes internal libwebp encoder flags via the -define argument. To enable Sharp-YUV, use the webp:use-sharp-yuv flag set to true or 1.

Basic Syntax

magick input.png -define webp:use-sharp-yuv=true output.webp

If using ImageMagick 6, replace magick with convert:

convert input.png -define webp:use-sharp-yuv=true output.webp

Additional WebP Preprocessing and Filtering Flags

You can pair sharp-yuv with other libwebp preprocessing and filtering parameters to fine-tune compression and artifact handling.

1. In-Loop Deblocking Filter Strength (webp:filter-strength)

Controls the strength of the WebP deblocking filter. Values range from 0 (filtering off) to 100 (maximum filtering).

magick input.jpg -define webp:use-sharp-yuv=true -define webp:filter-strength=60 output.webp

2. Filter Sharpness (webp:filter-sharpness)

Sets the sharpness reduction of the filter. The value ranges from 0 (least sharp) to 7 (most sharp).

magick input.jpg -define webp:use-sharp-yuv=true -define webp:filter-sharpness=4 output.webp

3. Filter Type (webp:filter-type)

Specifies the filter algorithm: 0 for simple filtering or 1 for strong filtering (default).

magick input.jpg -define webp:use-sharp-yuv=true -define webp:filter-type=1 output.webp

4. General Preprocessing (webp:preprocessing)

Applies built-in image preprocessing before encoding. Values include:

  • 0: None (default)
  • 1: Segment-smooth
  • 2: Pseudo-random dithering
magick input.jpg -define webp:use-sharp-yuv=true -define webp:preprocessing=1 output.webp

Complete Production Example

For high-contrast images, UI elements, or illustrations where color clarity and edge definition are critical, use a combined set of defines:

magick input.png \
  -quality 85 \
  -define webp:lossless=false \
  -define webp:use-sharp-yuv=true \
  -define webp:filter-strength=25 \
  -define webp:filter-sharpness=5 \
  -define webp:method=6 \
  output.webp

In this command:

  • -quality 85 sets standard lossy compression.
  • -define webp:use-sharp-yuv=true preserves edge chroma.
  • -define webp:method=6 forces the encoder to use the highest compression effort for the smallest file size.
