Control Wave Amplitude and Frequency in ImageMagick

The ImageMagick -wave effect alters an image by applying a sinusoidal distortion along its vertical plane, creating a flowing, wave-like appearance. The effect is entirely controlled by a single geometry argument formatted as <amplitude>x<wavelength>, where the first value dictates the amplitude (wave height) and the second value controls the wavelength, which directly determines the wave frequency.

The -wave Syntax

The operator takes two numerical values separated by an x:

magick input.jpg -wave <amplitude>x<wavelength> output.jpg

(Note: In ImageMagick 6, the legacy command uses convert instead of magick.)

Parameter Breakdown

1. Amplitude (Wave Height)

  • What it controls: The vertical magnitude or displacement of the wave.
  • Unit: Pixels.
  • Behavior: A larger number creates taller, more dramatic peaks and valleys, while a smaller number creates subtle ripples. If set to 0, no vertical displacement occurs.

2. Wavelength (Wave Frequency)

  • What it controls: The horizontal length of a complete cycle (from crest to crest or trough to trough).
  • Unit: Pixels.
  • Behavior: Wavelength is inversely proportional to frequency:
    • Lower wavelength value: Compresses the wave cycles closer together, resulting in a higher frequency (more ripples across the image).
    • Higher wavelength value: Stretches the wave cycles across the canvas, resulting in a lower frequency (fewer, broader ripples across the image).

Practical Examples

Subtle, High-Frequency Ripple

To create a tight, ripple-like pattern with low amplitude and high frequency (short wavelength):

magick input.png -background transparent -wave 5x30 output.png
  • Amplitude: 5 (5-pixel displacement)
  • Wavelength: 30 (30 pixels per wave cycle)

Dramatic, Low-Frequency Wave

To create a large, sweeping roll with high amplitude and low frequency (long wavelength):

magick input.png -background transparent -wave 25x200 output.png
  • Amplitude: 25 (25-pixel displacement)
  • Wavelength: 200 (200 pixels per wave cycle)

Canvas and Virtual-Pixel Considerations

When the -wave distortion shifts pixels beyond the original image boundaries:

  • Set -background before the -wave operator to specify the fill color for any newly revealed canvas areas.
  • Set -virtual-pixel (e.g., -virtual-pixel mirror or -virtual-pixel tile) to define how edge boundaries are handled during the transformation.
