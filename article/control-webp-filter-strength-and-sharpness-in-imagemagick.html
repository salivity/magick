Control WebP Filter Strength and Sharpness in ImageMagick

This guide explains how to fine-tune WebP image compression in ImageMagick by controlling the deblocking filter strength and sharpness parameters. Adjusting these settings allows you to balance compression artifact reduction against edge clarity, ensuring your WebP exports maintain the exact balance of crispness and file size required for your project.

Understanding WebP Filtering

When compressing lossy WebP images, the encoder applies a deblocking filter to smooth harsh edges created by block-based encoding. ImageMagick exposes the underlying libwebp controls for this process through the -define flag.

Two primary parameters govern this behavior:

  • webp:filter-strength: Dictates the intensity of the deblocking filter. It accepts integer values from 0 to 100. A value of 0 turns off filtering entirely, leaving raw compression blocks visible at lower qualities. Higher values aggressively smooth out boundaries between blocks, reducing artifacts at the expense of fine textures. The default value is typically 60.
  • webp:filter-sharpness: Dictates the filter's sharpness curve. It accepts integer values from 0 to 7, where 0 provides the sharpest result (least filtering applied to high-contrast edges) and 7 provides the softest result (filtering is applied even across distinct edges). The default value is 0.

Basic Command Syntax

To apply these parameters in ImageMagick 7, use the magick command paired with the -define arguments before specifying the output file:

magick input.jpg -define webp:filter-strength=40 -define webp:filter-sharpness=2 output.webp

If you are using ImageMagick 6, replace magick with convert:

convert input.jpg -define webp:filter-strength=40 -define webp:filter-sharpness=2 output.webp

Practical Configuration Examples

1. Preserving Maximum Edge Detail

For line art, diagrams, or screenshots where sharp borders matter more than smooth gradients, disable or reduce the deblocking filter:

magick input.png -quality 80 -define webp:filter-strength=0 -define webp:filter-sharpness=0 output-sharp.webp

Setting filter-strength=0 disables the deblocking pass, preventing the encoder from introducing artificial blur around fine text and hard edges.

2. Aggressive Smoothing for Low-Bitrate Images

When encoding photographs at low quality targets (e.g., quality 30–50), macroblocking can cause distracting grid patterns. You can increase the filter strength and lower sharpness to blend those blocks:

magick input.jpg -quality 40 -define webp:filter-strength=80 -define webp:filter-sharpness=5 output-smooth.webp

3. Combining with Filter Type

WebP also supports a filter type setting (webp:filter-type), which can be set to 0 (simple) or 1 (strong). The strong filter is active by default in lossy mode. Pairing a strong filter type with specific strength values gives granular control over processing speed and visual softness:

magick input.jpg -quality 75 -define webp:filter-type=1 -define webp:filter-strength=50 -define webp:filter-sharpness=1 output.webp

Summary of Parameter Ranges

Parameter Accepted Range Default Purpose
webp:filter-strength 0 – 100 60 Overall strength of the deblocking filter. 0 disables smoothing.
webp:filter-sharpness 0 – 7 0 Sharpness curve. 0 is sharpest, 7 is least sharp (most filtered).
webp:filter-type 0 or 1 1 0 uses a faster, simple filter; 1 uses the standard strong filter.
