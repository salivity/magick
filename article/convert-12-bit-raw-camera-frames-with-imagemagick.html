Convert 12-Bit Raw Camera Frames with ImageMagick

Converting 12-bit raw industrial camera frames into standard formats like PNG or TIFF requires defining specific raw stream parameters such as pixel dimensions, bit depth, byte order, and dynamic range scaling. ImageMagick provides robust command-line tools to interpret these uncompressed data streams accurately and map the 12-bit sensor data to viewable 16-bit or 8-bit output files.

The Basic Conversion Command

Industrial cameras typically output 12-bit data in an unpacked format stored within 16-bit words (little-endian by default). To convert a single-channel (monochrome) raw image to a 16-bit PNG, use the following ImageMagick command:

magick -size 1920x1080 -depth 16 -endian lsb gray:frame.raw -auto-level output.png

Parameter Breakdown

  • -size WIDTHxHEIGHT: Specifies the exact pixel dimensions of the frame (e.g., 1920x1080 or 2048x2048). Raw files contain no metadata headers, so dimensions must be explicitly provided.
  • -depth 16: Instructs ImageMagick to read 2 bytes per pixel. Because standard 12-bit raw files are generally unpacked into 16-bit integer containers, reading at 16-bit depth captures the entire word.
  • -endian lsb: Defines the byte order. Most machine vision interfaces (GigE Vision, USB3 Vision, Camera Link) deliver little-endian (lsb) data. If the output appears noisy or scrambled, switch to big-endian (-endian msb).
  • gray:frame.raw: Tells the decoder to interpret the binary file frame.raw as raw grayscale pixel values.
  • -auto-level: Normalizes the dynamic range. A 12-bit sensor has a maximum value of 4095. When placed in a 16-bit container (max 65535), the image will look extremely dark without scaling the values to fill the dynamic range.
  • output.png: The target file name and format (PNG and TIFF natively support 16-bit grayscale).

Converting Bayer Raw (Color Sensors)

If the 12-bit raw frame is from a color camera utilizing a Bayer color filter array (e.g., RGGB):

magick -size 1920x1080 -depth 16 -endian lsb gray:frame.raw -auto-level -define colorspace:auto-grayscale=false -demosaic RGGB output.png

Replace RGGB with the specific Bayer pattern used by your sensor (such as BGGR, GRBG, or GBRG).

Converting Packed 12-Bit Formats

If the camera outputs packed 12-bit data (where two pixels share 3 consecutive bytes, commonly labeled as Mono12p or Mono12Packed), ImageMagick cannot natively unpack the non-byte-aligned bits directly. In this scenario, use a preprocessing utility or Python script to unpack the 12-bit values into 16-bit aligned integers prior to running the ImageMagick pipeline.
