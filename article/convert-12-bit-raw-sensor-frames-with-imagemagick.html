Convert 12-Bit Raw Sensor Frames with ImageMagick

Converting 12-bit raw industrial sensor frames into standard image formats requires ImageMagick to explicitly define missing metadata, such as image dimensions, bit depth, pixel format, and byte ordering. Because raw files contain uncompressed pixel values without header metadata, you must pass these hardware-specific parameters directly via the command line to decode the image correctly.

The Basic Conversion Command

To convert an unpacked 12-bit grayscale raw frame into a 16-bit PNG or TIFF, use the following magick command (or convert in ImageMagick v6):

magick -size 1920x1080 -depth 12 -endian lsb gray:input_frame.raw -auto-level output.png

Parameter Breakdown

  • -size <width>x<height>: Defines the exact sensor resolution (e.g., 1920x1080 or 4096x3072). This is required for ImageMagick to calculate line breaks properly.
  • -depth 12: Specifies the bit depth of the sensor data.
  • -endian lsb (or msb): Defines the byte order. Most modern industrial cameras (such as USB3 Vision or GigE Vision) output Little-Endian (lsb) data. If the image appears noisy or corrupted, switch to Big-Endian (msb).
  • gray:input_frame.raw: Tells ImageMagick to interpret the binary file as raw grayscale data. The gray: prefix is necessary because raw files lack file headers.
  • -auto-level: Scales the 12-bit dynamic range (values 0–4095) across the full 16-bit output space (0–65535) so the resulting image does not appear unnaturally dark in standard image viewers.
  • output.png: The target file name and format. PNG and TIFF formats natively support 16-bit depths, preserving the dynamic range of the 12-bit source.

Handling 12-Bit Data in 16-Bit Containers

Many industrial frame grabbers output 12-bit data aligned inside 16-bit words (often called Mono12 unpacked). In this scenario, read the file as 16-bit data and normalize the range:

magick -size 1920x1080 -depth 16 -endian lsb gray:input_frame.raw -auto-level output.tiff

Converting Bayer Pattern Raw Frames

If the sensor outputs 12-bit raw color data using a Bayer filter array (e.g., RGGB), read the file in grayscale first, then apply demosaicing:

magick -size 1920x1080 -depth 12 -endian lsb gray:input_bayer.raw -auto-level -demosaic RGGB output.png
