Convert 16-Bit TIFF to 8-Bit JPEG in ImageMagick

Converting a 16-bit TIFF to an 8-bit JPEG using ImageMagick is a straightforward process that involves downsampling color depth and applying standard JPEG compression. This guide outlines the exact command-line syntax required for single-file and batch conversions, as well as best practices for managing color spaces and image quality.

Basic Conversion Command

To convert a 16-bit TIFF image to an 8-bit JPEG, use the -depth 8 option with the magick command (or convert if using ImageMagick v6):

magick input.tif -depth 8 output.jpg
  • input.tif: Your source 16-bit TIFF file.
  • -depth 8: Reduces the color channel depth from 16 bits per channel to 8 bits per channel, which is required for standard JPEG output.
  • output.jpg: The generated 8-bit JPEG file.

Controlling Quality and Color Space

TIFF files frequently use wide color gamuts such as Adobe RGB or ProPhoto RGB. To ensure the output JPEG renders correctly in standard image viewers and web browsers, specify the sRGB color space and set your desired compression quality:

magick input.tif -colorspace sRGB -depth 8 -quality 90 output.jpg
  • -colorspace sRGB: Converts wide-gamut color data to standard sRGB.
  • -quality 90: Sets the JPEG compression level on a scale from 1 to 100 (90–95 provides a good balance between file size and visual fidelity).

Handling Layered or Multi-Page TIFFs

If your TIFF file contains multiple layers or pages, ImageMagick might generate separate JPEG files for each layer. To convert only the first layer or flatten the image into a single JPEG, use either the frame index or the -flatten option:

# Convert only the first layer/page
magick input.tif[0] -depth 8 -quality 90 output.jpg

# Flatten all layers into one image
magick input.tif -flatten -depth 8 -quality 90 output.jpg

Batch Conversion

To convert an entire folder of 16-bit TIFF images to 8-bit JPEGs simultaneously, use the mogrify tool:

magick mogrify -format jpg -colorspace sRGB -depth 8 -quality 90 *.tif

This command processes every .tif file in the current directory and creates corresponding .jpg files without overwriting the original TIFFs.
