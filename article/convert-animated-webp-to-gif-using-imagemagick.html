Convert Animated WebP to GIF Using ImageMagick

Converting an animated WebP image to an animated GIF using ImageMagick is a straightforward process that can be accomplished with a single terminal command. This guide covers the basic conversion syntax, explains how to maintain frame rates and animation loops, and provides optimization techniques to keep the resulting GIF file size manageable.

Basic Conversion Command

To convert an animated WebP file to an animated GIF, use the standard magick command in ImageMagick v7:

magick input.webp output.gif

If you are using an older version of ImageMagick (v6), use the convert command instead:

convert input.webp output.gif

Ensuring Smooth Playback with Coalesce

Animated WebP files often use frame disposal methods that only store changes between frames to reduce file size. To prevent visual artifacts or frame-stacking glitches during conversion, include the -coalesce flag to fully reconstruct each frame:

magick input.webp -coalesce output.gif

Optimizing Output File Size

GIF files are significantly less efficient than WebP files and can easily become large. You can optimize the output GIF by applying frame optimization and color reduction:

magick input.webp -coalesce -layers Optimize output.gif

To reduce the file size even further, you can use the -fuzz option to merge nearly identical colors across frames:

magick input.webp -coalesce -fuzz 2% -layers Optimize output.gif

Controlling Loops and Frame Delays

By default, ImageMagick attempts to preserve the looping behavior and frame delay of the original file. If you need to manually force the GIF to loop infinitely, add the -loop 0 flag:

magick -loop 0 input.webp -coalesce -layers Optimize output.gif

If the animation plays at the wrong speed, you can manually define the delay between frames (measured in hundredths of a second, or centiseconds):

magick -delay 10 input.webp -coalesce -layers Optimize output.gif

Batch Converting Multiple Files

To convert all animated WebP files in a single folder to GIF format, run a shell loop:

Linux / macOS (Bash/Zsh):

for file in *.webp; do
  magick "$file" -coalesce -layers Optimize "${file%.webp}.gif"
done

Windows (Command Prompt):

for %f in (*.webp) do magick "%f" -coalesce -layers Optimize "%~nf.gif"
