Convert Cineon to Linear sRGB Using ImageMagick

Converting Cineon film scans into linear sRGB is an essential step when preparing legacy film footage for modern visual effects, 3D rendering, and linear compositing workflows. This guide covers how to decode 10-bit logarithmic Cineon data (.cin or .dpx) and transform it into un-companded, linear sRGB color values using the ImageMagick command-line interface.

Understanding Colorspace Definitions in ImageMagick

ImageMagick handles colorspace transformations internally, but terminology varies depending on your destination format:

  • sRGB: Standard non-linear sRGB with the standard gamma transfer curve applied.
  • RGB: In modern ImageMagick (version 7+), RGB refers to linear sRGB (gamma 1.0).
  • Cineon / Log: The logarithmic curve traditionally used for Kodak film scans, mapping density ranges into a 10-bit container.

Because linear data stretches shadows and compresses highlights, you must save output files in a high-bit-depth format (such as 16-bit TIFF or OpenEXR) to prevent severe posterization and banding.

Basic Conversion Command

If your input file is a native Cineon file (.cin), ImageMagick automatically recognizes the Cineon logarithmic curve. Use the following command to convert the frame to linear sRGB and save it as a 16-bit TIFF:

magick input.cin -colorspace RGB -depth 16 output_linear.tiff

If you are outputting to OpenEXR for VFX pipelines, run:

magick input.cin -colorspace RGB output_linear.exr

Handling DPX Files with Explicit Colorspace Tagging

DPX files frequently encapsulate Cineon log curves without setting standard metadata headers. If ImageMagick does not automatically read the file as logarithmic, explicitly define the source colorspace before the conversion:

magick input.dpx -set colorspace Log -colorspace RGB -depth 16 output_linear.tiff

If the file uses Cineon metadata directly:

magick input.dpx -set colorspace Cineon -colorspace RGB -depth 16 output_linear.tiff

Batch Converting an Image Sequence

Film frames are typically stored in numbered sequences. To batch convert an entire sequence of Cineon frames into linear OpenEXR files, use ImageMagick's batch processing syntax:

magick mogrify -path ./linear_output -format exr -colorspace RGB *.cin

This processes every .cin file in the current directory, performs the logarithmic-to-linear sRGB conversion, and writes the resulting linear frames into the linear_output directory.
