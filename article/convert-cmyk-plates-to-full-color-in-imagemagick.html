Convert CMYK Plates to Full Color in ImageMagick

This guide explains how to combine four separate grayscale CMYK separation plates (Cyan, Magenta, Yellow, and Key/Black) into a single full-color composite image using ImageMagick. You will learn the exact command-line syntax required to merge these channels, assign the correct colorspace, and output the final image for digital display or print.

The Basic CMYK Combination Command

To combine four individual grayscale separation files into a single full-color image, supply the files in the specific order of Cyan, Magenta, Yellow, and Black, set the colorspace, and combine them.

In ImageMagick v7, execute the following command:

magick cyan.png magenta.png yellow.png black.png -set colorspace CMYK -combine output_cmyk.tif

For ImageMagick v6, use convert instead of magick:

convert cyan.png magenta.png yellow.png black.png -set colorspace CMYK -combine output_cmyk.tif

Converting to sRGB for Web and Display

If the final image is intended for digital viewing rather than commercial printing, convert the combined image into standard sRGB to ensure accurate color rendering across web browsers and image viewers:

magick cyan.png magenta.png yellow.png black.png -set colorspace CMYK -combine -colorspace sRGB output.jpg

Command Breakdown

  • Input Order (cyan, magenta, yellow, black): ImageMagick maps input files to channels sequentially. The sequence must strictly follow Cyan (Channel 0), Magenta (Channel 1), Yellow (Channel 2), and Black (Channel 3).
  • -set colorspace CMYK: Instructs ImageMagick to interpret the four grayscale inputs as CMYK channels instead of default RGB or RGBA channels.
  • -combine: Merges the individual grayscale layers into a single composite multi-channel image.
  • -colorspace sRGB: Converts the CMYK values into standard RGB color values for screen display.

Handling Inverted or Negative Plates

In traditional prepress workflows, separation plates may represent ink density where white indicates maximum ink coverage and black indicates zero ink. If the resulting image appears inverted, apply the -negate operator prior to combining:

magick cyan.png magenta.png yellow.png black.png -negate -set colorspace CMYK -combine -colorspace sRGB output.jpg
