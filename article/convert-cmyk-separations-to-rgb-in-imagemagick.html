Convert CMYK Separations to RGB in ImageMagick

This guide demonstrates how to merge individual CMYK color separation plates (Cyan, Magenta, Yellow, and Black grayscale images) into a single composite RGB image for digital proofing using ImageMagick. You will learn the core command-line syntax for combining channel files, adjusting channel polarity, and applying ICC color profiles for accurate proofing results.

The Standard Merge Command

In ImageMagick, individual grayscale separation plates must be provided in the exact order of the color space: Cyan, Magenta, Yellow, and Black. The -combine operator merges these inputs into a single CMYK image, which is then converted into sRGB for digital viewing.

For ImageMagick v7, run:

magick cyan.tif magenta.tif yellow.tif black.tif -set colorspace CMYK -combine -colorspace sRGB proof.png

(For ImageMagick v6, replace magick with convert.)

How It Works:

  1. Input files: Passes the four separation plates in C-M-Y-K sequence.
  2. -set colorspace CMYK: Tells ImageMagick to interpret the sequence as CMYK channels rather than standard RGB/Alpha.
  3. -combine: Combines the four separate grayscale images into a single 4-channel image.
  4. -colorspace sRGB: Converts the resulting CMYK composite into standard sRGB for web and screen display.

Handling Inverted Separation Plates

Print plates often represent ink coverage differently depending on the RIP (Raster Image Processor) output:

  • Positive plates: Black represents 100% ink coverage, and white represents 0% ink coverage.
  • Negative/Standard Digital plates: White represents 100% ink coverage, and black represents 0% ink.

If your output proof appears inverted or dark, apply the -negate flag before combining:

magick cyan.tif magenta.tif yellow.tif black.tif -negate -set colorspace CMYK -combine -colorspace sRGB proof.png

Accurate Proofing Using ICC Profiles

A standard -colorspace sRGB conversion uses generic mathematical transformations that may shift colors. For an accurate press simulation proof, apply specific ICC profiles for both the source print standard (e.g., GRACoL, SWOP, or FOGRA) and the target display profile (sRGB).

magick cyan.tif magenta.tif yellow.tif black.tif \
  -set colorspace CMYK -combine \
  -profile "USWebCoatedSWOP.icc" \
  -profile "sRGB.icc" \
  proof.jpg

Order of Operations with Profiles:

  1. Combine the plates into CMYK.
  2. Apply the print profile (USWebCoatedSWOP.icc or your specific press profile) to define the source CMYK color behavior.
  3. Apply the destination profile (sRGB.icc) to translate the CMYK colors into exact RGB screen coordinates.
