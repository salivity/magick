Convert DICOM and Reset Window Center in ImageMagick

This article provides a quick overview of converting medical DICOM (.dcm) files into standard image formats like PNG or JPEG while resetting or defining custom Window Center (Level) and Window Width settings using ImageMagick. It covers the precise command-line syntax required to override embedded DICOM metadata, adjust display ranges, and ensure correct visual contrast in your output files.

The Conversion Command

To convert a DICOM file while specifying or overriding the Window Center and Window Width, use the ImageMagick magick command (or convert in ImageMagick 6) with the -define operator:

magick input.dcm -define dcm:window-center=40 -define dcm:window-width=400 output.png

If your goal is to ignore the embedded DICOM windowing tags entirely and reset the image to its full dynamic range, use the dcm:display-range=reset define combined with -auto-level:

magick input.dcm -define dcm:display-range=reset -auto-level output.png

Understanding the Parameters

  • -define dcm:window-center=<value>: Sets the midpoint of the grayscale values (Hounsfield Units in CT scans) mapped to visible shades of gray. Also known as Window Level.
  • -define dcm:window-width=<value>: Defines the total range of pixel intensities displayed. Pixels below center - (width / 2) appear black, and pixels above center + (width / 2) appear white.
  • -define dcm:display-range=reset: Forces ImageMagick to ignore the stored WindowCenter (0028,1050) and WindowWidth (0028,1051) metadata in the DICOM header and recalculate the range based on raw pixel data.
  • -auto-level: Stretches the dynamic range of the image to span black to white across the target format's bit depth.

Common CT Windowing Presets

When converting CT scans, common window presets can be applied directly using these flags:

  • Soft Tissue: 
    magick input.dcm -define dcm:window-center=40 -define dcm:window-width=400 soft_tissue.png
  • Bone: 
    magick input.dcm -define dcm:window-center=300 -define dcm:window-width=1500 bone.png
  • Lung: 
    magick input.dcm -define dcm:window-center=-600 -define dcm:window-width=1500 lung.png

Batch Conversion

To reset the window center and convert multiple DICOM files within a directory in ImageMagick 7:

magick mogrify -format png -define dcm:window-center=40 -define dcm:window-width=400 *.dcm
