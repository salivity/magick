Convert DICOM with Window Level in ImageMagick

Converting DICOM (Digital Imaging and Communications in Medicine) files to standard formats like PNG or JPEG requires applying proper Window Width (WW) and Window Center/Level (WL) settings to preserve crucial medical contrast. This guide explains how DICOM windowing works, how ImageMagick handles high-bit-depth medical data, and the exact commands needed to convert your DICOM images with correct visual contrast.

Understanding DICOM Window Width and Window Center

DICOM images often store data in 12-bit or 16-bit grayscale, representing Hounsfield Units (HU) in CT scans or raw signal intensities in MRI scans. Standard displays can only show 8-bit grayscale (256 shades of gray).

To map this wide dynamic range to standard displays, DICOM uses two values:

  • Window Center (WC) / Window Level (WL): The midpoint brightness value of the region of interest.
  • Window Width (WW): The range of pixel values displayed around the center.

Any values below the range become completely black, and values above become completely white:

  • Lower Bound (Black): \(\text{Minimum} = \text{WC} - (\text{WW} / 2)\)
  • Upper Bound (White): \(\text{Maximum} = \text{WC} + (\text{WW} / 2)\)

Step 1: Extract DICOM Window Metadata

Before converting, you must check the DICOM header for the predefined Window Center and Window Width tags. Run the ImageMagick identify command:

magick identify -verbose input.dcm | grep -i window

Look for the following output:

  • dcm:WindowCenter: (e.g., 40)
  • dcm:WindowWidth: (e.g., 400)
  • dcm:RescaleIntercept: (e.g., -1024)
  • dcm:RescaleSlope: (e.g., 1)

Step 2: Calculate the Intensity Levels

To apply standard CT window presets (such as a soft tissue window with \(WC = 40\) and \(WW = 400\)):

  1. Calculate the HU limits:

    • \(\text{Min} = 40 - (400 / 2) = -160\text{ HU}\)
    • \(\text{Max} = 40 + (400 / 2) = 240\text{ HU}\)

  2. Account for Rescale Intercept: DICOM stores raw pixel values (\(PV\)) that relate to HU via the formula: \(\text{HU} = (PV \times \text{RescaleSlope}) + \text{RescaleIntercept}\).

    • If \(\text{RescaleIntercept} = -1024\), convert HU back to raw pixel values:
    • \(\text{Raw Min} = -160 - (-1024) = 864\)
    • \(\text{Raw Max} = 240 - (-1024) = 1264\)

Step 3: Convert Using the -level Option

ImageMagick's -level parameter maps the calculated minimum and maximum values to full black and white (0% and 100%).

For an image with a known raw data range (or 16-bit range):

magick input.dcm -level 864,1264 output.png

Alternatively, if ImageMagick automatically scales the input pixel range into a 16-bit container (\(0 \text{ to } 65535\)), specify the values as percentages:

magick input.dcm -level 20%,60% output.png

Step 4: Built-in Windowing via ImageMagick Defines

Recent versions of ImageMagick can automatically parse DICOM Window Center and Width tags using custom defines during conversion:

magick -define dcm:display-range=reset input.dcm -auto-level output.png

For custom Window Center and Window Width parameters directly in the command:

magick -define dcm:window-center=40 -define dcm:window-width=400 input.dcm output.png

Step 5: Common Presets for DICOM Conversion

When processing specific medical modalities (such as CT), use standard Window Level configurations:

  • Soft Tissue / Abdomen: \(\text{WC} = 40, \text{WW} = 400\)
  • Bone: \(\text{WC} = 400, \text{WW} = 1800\)
  • Lung: \(\text{WC} = -600, \text{WW} = 1500\)
  • Brain: \(\text{WC} = 40, \text{WW} = 80\)

By applying these values via -level or -define, ImageMagick renders DICOM images with correct, diagnostically relevant contrast.
