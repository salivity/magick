Convert EPS to SVG Using ImageMagick

Converting an Encapsulated PostScript (EPS) file to a Scalable Vector Graphics (SVG) format using ImageMagick can be accomplished directly from the command line. This article explains the exact commands needed to execute the conversion, outlines the necessary prerequisites such as Ghostscript, and addresses the technical behavior of how ImageMagick handles vector-to-vector transformations.

The Conversion Command

For ImageMagick version 7, use the following syntax to convert an EPS file to SVG:

magick input.eps output.svg

If you are using ImageMagick version 6, use the legacy convert tool:

convert input.eps output.svg

Improving Output Quality with Density

ImageMagick utilizes Ghostscript as a delegate to decode EPS files. Because ImageMagick rasterizes EPS data during processing, the resulting SVG often contains an embedded high-resolution bitmap rather than native vector paths.

To ensure the output does not appear blurry or pixelated, you must specify a higher rendering density (DPI) before reading the input file. The default resolution is typically 72 DPI. Increasing this to 300 or 600 DPI ensures crisp graphics:

magick -density 300 input.eps -background none output.svg
  • -density 300: Renders the EPS file at 300 dots per inch for sharper quality.
  • -background none: Ensures that transparent backgrounds present in the EPS are preserved in the SVG.

Prerequisites

For ImageMagick to process EPS files, Ghostscript must be installed on your system.

  • Ubuntu/Debian: sudo apt-get install ghostscript
  • macOS (via Homebrew): brew install ghostscript
  • Windows: Download and install the Ghostscript AGPL release from the official Ghostscript website.

True Vector Conversion Note

If your workflow strictly requires native vector paths (XML paths) rather than an embedded raster image inside an SVG wrapper, ImageMagick is not the optimal tool. For lossless, path-preserving vector conversion, use Inkscape or pstoedit:

inkscape input.eps --export-plain-svg=output.svg
