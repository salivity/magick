Convert FITS to 16-Bit PNG with ImageMagick

This guide explains how to convert astronomical observation data stored in Flexible Image Transport System (FITS) files into standard 16-bit PNG images using ImageMagick. Converting to 16-bit PNG preserves the high dynamic range and subtle tonal gradients captured by astronomical sensors while making the imagery compatible with standard image viewers, graphic editors, and web platforms.

Verify ImageMagick Build Architecture

To output true 16-bit PNG files, your ImageMagick installation must be compiled with a quantum depth of at least 16 (Q16 or Q16-HDRI). Run the following command in your terminal to verify:

magick -version

Look for Q16 or Q16-HDRI under Features. If your version is compiled with Q8, it will downsample your images to 8-bit precision, discarding critical astronomical data.

Basic 16-Bit Conversion

By default, ImageMagick can read standard FITS images. In ImageMagick version 7, use the magick command (or convert for ImageMagick version 6) to read the input and specify the output bit depth:

magick input.fits -depth 16 output.png

Applying Dynamic Range Scaling

Astronomical CCD/CMOS sensors produce raw linear data where faint nebulae and stars occupy a small segment of the histogram, often causing a direct conversion to appear completely black. To make the details visible while preserving 16-bit precision, apply an automatic contrast stretch:

magick input.fits -auto-level -depth 16 output.png
  • -auto-level: Linearly scales the minimum pixel value to pure black (0) and the maximum pixel value to full white (65535), utilizing the entire 16-bit dynamic range without clipping data.
  • -normalize: Alternatively, stretches the contrast while clipping a tiny fraction (typically 0.1%) of the extreme dark and light pixels to maximize contrast.

Handling Specific Header Data Units (HDUs)

Many astronomical FITS files are multi-extension files containing metadata, calibration data, or multiple exposures in separate Header Data Units (HDUs). To convert a specific extension or data cube slice, specify the zero-indexed frame in brackets:

magick "input.fits[0]" -auto-level -depth 16 output.png

If the primary image is stored in the first extension instead of the primary header, target it with [1]:

magick "input.fits[1]" -auto-level -depth 16 output.png

Applying Non-Linear Stretches (Logarithmic Stretch)

Linear astronomical data often hides faint deep-sky structures. To mimic standard astrophotography visual processing, you can apply a logarithmic transform directly in the pipeline:

magick input.fits -auto-level -evaluate log 1000 -depth 16 output.png

The -evaluate log operation compresses high-intensity star cores while boosting dim background structures, producing a visual representation suitable for display.

Verifying the Output

To confirm that the output PNG maintained the intended 16-bit depth, run ImageMagick's identify utility:

magick identify -verbose output.png | grep "Depth:"

The output should report Depth: 16-bit.
