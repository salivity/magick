Convert Image to 8-Bit Palette Mode in ImageMagick

This guide provides the exact ImageMagick commands required to convert any image into an 8-bit truecolor palette mode (indexed color with a maximum of 256 colors). By leveraging ImageMagick's color quantization and palette-defining operators, you can significantly reduce image file sizes while preserving visual quality across various formats like PNG and GIF.

The Command

For ImageMagick 7, use the following syntax:

magick input.png -depth 8 -colors 256 -type Palette output.png

For ImageMagick 6 (legacy), use convert:

convert input.png -depth 8 -colors 256 -type Palette output.png

Command Breakdown

  • magick / convert: Invokes the ImageMagick processing tool.
  • input.png: The source image path.
  • -depth 8: Sets the color depth to 8 bits per channel.
  • -colors 256: Reduces the total color palette to a maximum of 256 distinct colors (the limit for standard 8-bit indexed palettes).
  • -type Palette: Forces the image encoding type to indexed palette mode rather than TrueColor (RGB).
  • output.png: The generated output file.

Handling Transparency (Alpha Channel)

If your source image contains transparency and you want to retain an 8-bit indexed palette with binary or alpha transparency, use the PaletteAlpha (or PaletteMatte) type:

magick input.png -depth 8 -colors 256 -type PaletteAlpha output.png

Alternatively, for explicit PNG 8-bit formatting with indexed transparency, specify the PNG8 format prefix:

magick input.png PNG8:output.png

Dithering Options

By default, ImageMagick applies Floyd-Steinberg dithering to smooth out color gradients. You can control this behavior using the +dither or -dither flags:

  • Disable dithering (cleaner flat areas, smaller size):

    magick input.png +dither -colors 256 -type Palette output.png

  • Explicitly enable dithering:

    magick input.png -dither FloydSteinberg -colors 256 -type Palette output.png
