Convert Image to ASCII Art with ImageMagick

This guide explains how to convert standard image files into ASCII text art using ImageMagick. By adjusting the image dimensions, reducing color channels to grayscale, and utilizing character-based output formats or delegates like Libcaca, you can quickly generate terminal-ready text representations of your images straight from the command line.

Method 1: Using the Libcaca Delegate

The most direct way to generate formatted ASCII art in ImageMagick is by exporting the image using the caca: format delegate. This requires ImageMagick to be compiled with Libcaca support.

Run the following command in your terminal:

magick input.jpg -resize 80x40 caca:output.txt

To display the ASCII art directly in your terminal without saving to a file, direct the output to standard out:

magick input.jpg -resize 80x40 caca:-
  • input.jpg: The source image path.
  • -resize 80x40: Scales the image down to fit typical terminal dimensions while preserving readability.
  • caca:: Specifies the ASCII art output coder.

Method 2: Exporting Grayscale Pixel Maps (TXT:)

If your installation does not support the Libcaca delegate, you can convert the image into a grayscale text matrix using ImageMagick's built-in TXT: format. This extracts brightness values per pixel that map directly to characters.

  1. Resize and convert to grayscale values:
magick input.jpg -resize 80x -colorspace Gray -depth 8 txt:pixel_data.txt
  1. Process into ASCII characters:

The generated pixel_data.txt file contains coordinates and grayscale intensity values from 0 to 255. You can pipe this data through a simple shell script or tool (like awk or sed) to substitute brightness thresholds with characters ranging from dark to light (such as @, %, #, *, +, =, :, ., and space).

Method 3: Converting Monochromatic Bitmaps

For high-contrast line art or logos, convert the image to pure 1-bit monochrome (black and white) before exporting to plain text PBM format:

magick input.jpg -resize 80x -threshold 50% output.pbm

The resulting plain format PBM file contains a text matrix of 0s (white) and 1s (black), which functions as basic digital ASCII art readable in any text editor.
