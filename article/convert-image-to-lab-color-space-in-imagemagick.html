Convert Image to Lab Color Space in ImageMagick

ImageMagick provides a straightforward command-line interface to convert digital images from standard RGB or CMYK into the CIELAB (Lab) color space. This guide covers the essential commands required to perform basic color space transformations, apply ICC color profiles for higher precision, separate individual Lab channels, and save the resulting files in appropriate formats.

Basic Color Space Conversion

To convert an image to the Lab color space, use the -colorspace Lab option.

For ImageMagick version 7:

magick input.jpg -colorspace Lab output.tiff

For ImageMagick version 6:

convert input.jpg -colorspace Lab output.tiff

When saving in the Lab color space, use file formats that natively support multi-channel or Lab data, such as TIFF (.tiff), Photoshop documents (.psd), or MIFF (.miff). Standard JPEG formats typically force the image back into sRGB or YCbCr, which can cause unexpected color shifts.

Conversion Using ICC Color Profiles

Using the -colorspace operator performs a mathematical transformation. If you require color-accurate translation based on specific device profiles, use the -profile option with standard ICC/ICM color profiles.

magick input.jpg -profile sRGB.icc -profile Lab.icc output.tiff

This ensures the source color space is mapped accurately to the target Lab profile.

Separating Lab Channels

The Lab color space divides an image into three channels:

  • L*: Lightness (luminance)
  • a*: Green to Red chromatic component
  • b*: Blue to Yellow chromatic component

To split an image into three separate grayscale files representing each channel:

magick input.jpg -colorspace Lab -separate channel_%d.tiff

This produces:

  • channel_0.tiff (Lightness)
  • channel_1.tiff (a-channel)
  • channel_2.tiff (b-channel)

To extract only the Lightness channel (L*):

magick input.jpg -colorspace Lab -channel 0 -separate lightness.tiff

Converting from Lab Back to sRGB

To reverse the process and return a Lab image to standard sRGB for web or standard display use:

magick input_lab.tiff -colorspace sRGB output.jpg
