Convert Image to LMS Color Space in ImageMagick

Converting an image to the LMS (Long, Medium, Short) cone response color space in ImageMagick requires transforming color values to match the human eye's photoreceptor responses. Because ImageMagick does not feature a dedicated, built-in -colorspace LMS setting, the conversion is achieved by linearizing the image and applying a transformation matrix using the -color-matrix operator. This guide outlines the exact matrix operations and commands required to execute this conversion accurately.

Understanding the Conversion Process

The LMS color space represents the spectral sensitivities of the human eye's three cone types. Standard displays use non-linear sRGB, meaning the image must first be linearized or mapped to a standard CIE space (such as CIE XYZ), after which an LMS transformation matrix (such as CAT02 or Hunt-Pointer-Estevez) can be applied.

Because LMS values can exceed standard 8-bit integer boundaries, outputting to a format that supports high dynamic range and floating-point data (such as TIFF, MIFF, or OpenEXR) is recommended.

Method 1: Converting via CIE XYZ (CAT02 Matrix)

The most common approach maps sRGB to the CIE XYZ color space first, followed by the CAT02 transformation matrix to obtain LMS values.

The CAT02 Matrix Values

The standard CAT02 matrix to convert from XYZ to LMS is:

  • L: 0.7328, 0.4296, -0.1624
  • M: -0.7036, 1.6975, 0.0061
  • S: 0.0030, 0.0136, 0.9834

ImageMagick Command (v7)

magick input.jpg -colorspace XYZ \
  -color-matrix " 0.7328  0.4296 -0.1624 \
                 -0.7036  1.6975  0.0061 \
                  0.0030  0.0136  0.9834" \
  -define quantum:format=floating-point output_lms.tiff

For ImageMagick v6, replace magick with convert.

Method 2: Direct Linear sRGB to LMS Conversion

If you prefer to bypass XYZ and convert directly from linear sRGB to LMS, you can use the combined linear sRGB-to-LMS matrix (derived from the sRGB-to-XYZ and CAT02 matrices).

The Direct Matrix Values

  • L: 0.3904724, 0.5499923, 0.0089018
  • M: 0.0709259, 0.9631074, 0.0013580
  • S: 0.0231427, 0.1108620, 0.9496354

ImageMagick Command (v7)

magick input.jpg -colorspace RGB \
  -color-matrix "0.3904724 0.5499923 0.0089018 \
                 0.0709259 0.9631074 0.0013580 \
                 0.0231427 0.1108620 0.9496354" \
  -define quantum:format=floating-point output_lms.tiff

Note: In ImageMagick, -colorspace RGB transforms non-linear sRGB into linear RGB, which is necessary before applying the matrix.

Verifying the Channels

After processing:

  • Red Channel: Corresponds to the L (Long wavelength) cone response.
  • Green Channel: Corresponds to the M (Medium wavelength) cone response.
  • Blue Channel: Corresponds to the S (Short wavelength) cone response.

To inspect or extract individual cone responses, use the -channel operator or separate them into distinct grayscale images:

magick output_lms.tiff -separate cone_%d.tiff

This produces cone_0.tiff (L), cone_1.tiff (M), and cone_2.tiff (S).
