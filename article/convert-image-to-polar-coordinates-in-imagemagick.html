Convert Image to Polar Coordinates in ImageMagick

This guide provides the exact ImageMagick commands and parameters needed to transform a rectangular image into a circular polar coordinate projection. You will learn the primary distortion operator, the syntax for both ImageMagick version 6 and version 7, and how to fine-tune the center point, radius, and rotation of your output.

The Polar Transformation Command

To warp a rectangular image into a circular polar projection, use the -distort Polar operator.

ImageMagick v7 (Current)

magick input.jpg -distort Polar 0 output.jpg

ImageMagick v6 (Legacy)

convert input.jpg -distort Polar 0 output.jpg

Passing 0 as the parameter tells ImageMagick to automatically calculate the maximum radius so the entire image fits within the bounds of the output canvas.

Understanding Polar Parameters

The -distort Polar operator accepts up to four optional arguments formatted as a comma-separated list:

-distort Polar "Radius, Angle, CenterX, CenterY"
  • Radius: Defines the outer boundary radius of the polar circle in pixels. Setting this to 0 uses the default maximum dimension.
  • Angle: The starting angle (in degrees) for the projection. The default is 0, which places the seam at the bottom. Setting it to 90 or 180 rotates the orientation.
  • CenterX, CenterY: The X and Y pixel coordinates that serve as the center point of the distortion. By default, ImageMagick uses the center of the original image canvas.

Example with Custom Parameters

To create a projection with a fixed radius of 300 pixels rotated by 90 degrees around the center:

magick input.jpg -distort Polar "300,90" output.jpg

Setting a Custom Background and Canvas

Polar distortions often leave empty space in the corners of the canvas. You can define the background color and canvas behavior using the -background and -virtual-pixel options:

magick input.jpg -background transparent -virtual-pixel transparent -distort Polar 0 output.png

Reversing the Process (Polar to Rectangular)

To reverse the transformation and unroll a circular polar image back into a flat rectangular format, replace Polar with DePolar:

magick polar_input.jpg -distort DePolar 0 rectangular_output.jpg
