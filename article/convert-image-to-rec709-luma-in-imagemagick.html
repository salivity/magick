Convert Image to Rec709 Luma in ImageMagick

This guide outlines the exact syntax required to convert an image to the Rec709 luminance colorspace using ImageMagick. You will learn the standard command-line options for both modern and legacy ImageMagick versions, along with the difference between standard non-linear luma and linear luminance operations.

ImageMagick v7 Syntax

In ImageMagick 7, use the magick command followed by the -colorspace operator set to Rec709Luma:

magick input.jpg -colorspace Rec709Luma output.jpg

ImageMagick v6 Syntax

In ImageMagick 6, the legacy convert tool uses the same operator:

convert input.jpg -colorspace Rec709Luma output.jpg

Rec709Luma vs. Rec709Luminance

ImageMagick provides two distinct colorspace identifiers based on the ITU-R BT.709 standard:

  • Rec709Luma: Calculates the non-linear, gamma-corrected luma (\(Y'\)) using the formula: \[Y' = 0.2126R' + 0.7152G' + 0.0722B'\] This is the standard grayscale conversion method for typical photographic viewing.
  • Rec709Luminance: Calculates linear luminance (\(Y\)) directly from linear RGB values, which is typically used for scientific or linear-light workflows.

To perform a linear conversion, replace the colorspace argument with Rec709Luminance:

magick input.jpg -colorspace Rec709Luminance output.jpg
