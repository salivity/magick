Convert Image to X11 Bitmap in ImageMagick

This guide explains how to convert standard graphic formats like PNG, JPEG, or GIF into an X11 Bitmap (XBM) source header using the ImageMagick command-line suite. An XBM file is a plain-text C source file that stores monochrome bitmap data as a static byte array, making it ideal for direct inclusion in C/C++ applications, embedded displays, and legacy X Window System software.

Basic Conversion Command

To convert an image to an XBM header, provide your source image and an output filename with the .xbm extension. ImageMagick automatically selects the correct encoder based on the extension.

For ImageMagick v7:

magick input.png output.xbm

For ImageMagick v6:

convert input.png output.xbm

Controlling Monochrome Binarization

Because XBM only supports 1-bit monochrome data (pure black and white), ImageMagick must reduce multi-color or grayscale pixels. You can control how this conversion happens using the -monochrome or -threshold flags.

1. Dithering (Monochrome)

To preserve perceived gradients and details using Floyd-Steinberg dithering:

magick input.png -monochrome output.xbm

2. Hard Thresholding

To split pixels strictly based on brightness without dithering patterns:

magick input.png -threshold 50% output.xbm

Inverting Pixel Values

In the XBM specification, a bit set to 1 typically represents a set/foreground pixel (black), while 0 represents an unset/background pixel (white). If your output appears inverted on your target display, invert the colors prior to conversion using -negate:

magick input.png -negate output.xbm

Output File Structure

ImageMagick generates a standard C header named according to the output file prefix. For instance, running magick icon.png icon.xbm creates an icon.xbm file containing:

#define icon_width 16
#define icon_height 16
static unsigned char icon_bits[] = {
   0x00, 0x00, 0x7e, 0x7e, 0x81, 0x81, 0xbd, 0xbd, 
   0xbd, 0xbd, 0x81, 0x81, 0x7e, 0x7e, 0x00, 0x00
};

This file can be included directly in C or C++ projects using #include "icon.xbm" to access the image dimensions and pixel array.
