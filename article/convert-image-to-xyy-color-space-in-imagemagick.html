Convert Image to xyY Color Space in ImageMagick

Converting an image to the CIE xyY chromaticity color space in ImageMagick requires transforming the source image to CIE XYZ and then mathematically deriving the chromaticity coordinates. While ImageMagick natively supports many color spaces via the -colorspace operator, it does not include a direct one-step xyY argument. You can achieve an accurate conversion by first converting the image to XYZ, separating the color channels, and calculating the \(x\) and \(y\) coordinates while preserving the luminance channel (\(Y\)).

Mathematical Relationship Between XYZ and xyY

The CIE xyY color space separates chromaticity (the \(x\) and \(y\) values) from luminance (the \(Y\) value). Given an image in the CIE XYZ color space, the components are defined as:

  • \(x = \frac{X}{X + Y + Z}\)
  • \(y = \frac{Y}{X + Y + Z}\)
  • \(Y = Y\)

Because the chromaticity values represent ratios, the output channels should ideally be stored in a format that supports high dynamic range or 16-bit floating-point data, such as TIFF, MIFF, or EXR, to prevent quantization artifacts.

The Conversion Command

In ImageMagick 7, use the magick command to perform the transformation without relying on the slower -fx interpreter. The following command uses channel separation, sequence addition, and division:

magick input.jpg -colorspace XYZ -separate \
  \( -clone 0,1,2 -evaluate-sequence Add \) \
  \( -clone 0 -clone 3 -compose Divide -composite \) \
  \( -clone 1 -clone 3 -compose Divide -composite \) \
  -delete 0,2,3 \
  -reverse -combine -set colorspace xyY output.tiff

Command Breakdown

  1. -colorspace XYZ: Converts the incoming image (such as sRGB) into the linear CIE XYZ color space.
  2. -separate: Splits the image into three distinct grayscale images in memory representing \(X\) (index 0), \(Y\) (index 1), and \(Z\) (index 2).
  3. \( -clone 0,1,2 -evaluate-sequence Add \): Sums the three channels together to compute the total denominator \(X + Y + Z\), creating index 3.
  4. \( -clone 0 -clone 3 -compose Divide -composite \): Computes the chromaticity coordinate \(x\) by dividing channel \(X\) (index 0) by the sum (index 3), creating index 4.
  5. \( -clone 1 -clone 3 -compose Divide -composite \): Computes the chromaticity coordinate \(y\) by dividing channel \(Y\) (index 1) by the sum (index 3), creating index 5.
  6. -delete 0,2,3: Removes the original \(X\) and \(Z\) images along with the intermediate sum image, leaving \(Y\) (index 0 in remaining stack), \(x\) (index 1), and \(y\) (index 2).
  7. -reverse -combine: Reorders the images so they map to red (\(x\)), green (\(y\)), and blue (\(Y\)), then merges them back into a single three-channel image.
  8. -set colorspace xyY: Annotates the image metadata with the appropriate label for reference.
