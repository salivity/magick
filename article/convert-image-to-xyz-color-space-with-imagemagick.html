Convert Image to XYZ Color Space with ImageMagick

Converting images between different color representations is a common requirement in image processing, photography, and color science. This guide provides a straightforward method for converting standard images (such as sRGB JPEG or PNG files) into the CIE XYZ chromaticity space using ImageMagick's command-line utilities. You will learn the exact commands for modern and legacy versions of ImageMagick, along with best practices for preserving color precision.

Understanding the CIE XYZ Color Space

The CIE 1931 XYZ color space is an absolute, device-independent color standard developed to model human vision. Unlike standard RGB (sRGB), which depends on monitor characteristics and has a limited gamut, XYZ encompasses all colors visible to the human eye. Converting to XYZ is typically required for accurate colorimetric analysis, calculating chromaticity coordinates (\(x, y\)), or preparing images for advanced rendering pipelines.

The Basic Conversion Command

To convert an image to the XYZ color space, use the -colorspace parameter followed by XYZ.

For ImageMagick 7+:

magick input.png -colorspace XYZ output.tiff

For ImageMagick 6:

convert input.png -colorspace XYZ output.tiff

Note: TIFF is recommended over JPEG for XYZ output because standard JPEG compressors assume sRGB color encoding and may clip or distort out-of-gamut color channels.

Preserving Color Precision (16-bit Depth)

Because the XYZ space spans a broader dynamic range than standard 8-bit RGB, converting with low bit depth can introduce banding or quantization errors. To preserve detail and accuracy, explicitly define a higher bit depth:

magick input.png -colorspace XYZ -depth 16 output_16bit.tiff

Converting Back from XYZ to sRGB

If you perform modifications in the XYZ color space and need to convert the image back to a standard display-ready format, invert the colorspace parameter:

magick input_xyz.tiff -colorspace sRGB output_display.jpg

Batch Converting Multiple Images

To convert an entire directory of images to the XYZ color space simultaneously, use the mogrify tool:

magick mogrify -format tiff -colorspace XYZ -depth 16 *.png

This command converts all .png files in the current folder into 16-bit .tiff files in the XYZ color space without overwriting the original files.
