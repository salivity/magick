Convert Monochrome Fax to PDF Using ImageMagick

Converting monochrome fax documents into PDF format using ImageMagick is a fast command-line solution that preserves document clarity while keeping file sizes extremely small. This guide explains the primary command needed to perform the conversion, the optimal compression flags to use for 1-bit monochrome data, and examples for handling both single-page and multi-page fax files.

The Standard Conversion Command

In ImageMagick 7, the recommended command to convert a monochrome fax image (such as a TIFF or FAX file) into a PDF is:

magick input.fax -compress Group4 output.pdf

For systems running ImageMagick 6, use the convert tool:

convert input.fax -compress Group4 output.pdf

Optimizing with CCITT Group 4 Compression

The -compress Group4 flag applies CCITT Group 4 (T.6 Fax) compression. This is the industry-standard lossless compression algorithm designed specifically for 1-bit black-and-white images. Applying this flag ensures the resulting PDF remains minimal in file size while retaining full sharpness and text readability.

Converting Grayscale or Color Images to Monochrome Fax PDF

If your source file is not already a true 1-bit monochrome image, force the monochrome conversion using the -monochrome or -threshold flag before applying the compression:

magick input.jpg -monochrome -compress Group4 output.pdf

Alternatively, use a defined threshold percentage to control black-and-white separation:

magick input.png -threshold 50% -compress Group4 output.pdf

Combining Multi-Page Fax Files

To combine multiple single-page monochrome fax scans into a single multi-page PDF document, list the input files sequentially or use a wildcard:

magick page_*.tif -compress Group4 combined_document.pdf

Setting Fax Resolution (DPI)

Standard faxes typically use resolutions such as 204x98 DPI (standard) or 204x196 DPI (fine). To ensure the PDF renders with correct physical dimensions, specify the density:

magick -density 204x196 input.fax -compress Group4 output.pdf
