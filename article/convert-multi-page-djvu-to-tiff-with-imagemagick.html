Convert Multi-Page DjVu to TIFF with ImageMagick

This guide demonstrates how to convert multi-page DjVu documents into TIFF format using the ImageMagick command-line interface. You will learn the standard syntax for creating single multi-page TIFF files, generating separate TIFF images for each page, and applying compression settings to keep file sizes manageable.

Prerequisites

ImageMagick relies on the djvulibre library to decode DjVu files. Before running ImageMagick commands, ensure both ImageMagick and djvulibre are installed on your system. On Debian-based Linux systems, install them using:

sudo apt update
sudo apt install imagemagick djvulibre-bin

Basic Multi-Page Conversion

To convert an entire multi-page DjVu document into a single multi-page TIFF file, provide the input .djvu file and specify a .tiff extension for the output.

For ImageMagick version 7:

magick input.djvu output.tiff

For ImageMagick version 6:

convert input.djvu output.tiff

ImageMagick automatically preserves all pages and packages them sequentially into the output TIFF container.

Converting to Separate TIFF Files per Page

If you need each page saved as an independent TIFF file instead of a single multi-page document, use standard format specifiers (such as %d or %03d) in the output filename:

magick input.djvu page_%03d.tiff

This command outputs sequentially numbered files, such as page_000.tiff, page_001.tiff, and so on.

Applying Compression

Uncompressed TIFF files can be exceptionally large. You can use the -compress flag to significantly reduce file size without losing quality.

For general multi-page documents (color or grayscale), use LZW or ZIP compression:

magick input.djvu -compress lzw output.tiff

For black-and-white text documents, CCITT Group 4 compression provides the smallest file size:

magick input.djvu -monochrome -compress group4 output.tiff

Adjusting Rendering Resolution

DjVu files are vector- or layer-based and benefit from explicitly defining rendering density. To control output sharpness, specify the -density parameter before loading the input file:

magick -density 300 input.djvu -compress lzw output.tiff

This ensures the document renders at 300 DPI, making text clear and suitable for printing or OCR.
