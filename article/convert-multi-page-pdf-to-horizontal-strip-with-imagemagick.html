Convert Multi-Page PDF to Horizontal Strip with ImageMagick

This article explains how to convert a multi-page PDF document into a single horizontal filmstrip image using ImageMagick. By utilizing ImageMagick's appending tools, you can quickly rasterize all pages of a PDF and stitch them side-by-side into a single image file such as PNG or JPEG.

The Basic Command

To merge all pages of a multi-page PDF side-by-side horizontally, use the +append operator.

For ImageMagick version 7:

magick input.pdf +append output.png

For ImageMagick version 6:

convert input.pdf +append output.png

Recommended Command for High-Quality Output

PDF files are vector-based documents. By default, ImageMagick renders PDFs at a low resolution (72 DPI), which often results in blurry text. To produce a sharp, high-resolution filmstrip, set the -density parameter before reading the input PDF:

magick -density 300 input.pdf +append output.png

Command Breakdown

  • magick: Invokes ImageMagick 7.
  • -density 300: Sets the horizontal and vertical resolution to 300 DPI, ensuring the PDF pages are rasterized with high clarity. This must be placed before the input file.
  • input.pdf: The source multi-page PDF document.
  • +append: Joins all decoded pages horizontally from left to right. (Note: Using -append with a minus sign joins pages vertically from top to bottom).
  • output.png: The resulting panoramic image containing all pages in a single row.

Adding Spacing Between Pages

If you want visual separation between the pages in the filmstrip, you can define a border or background color and use the -splice option:

magick -density 300 input.pdf -splice 10x0 +append output.png

This adds a 10-pixel horizontal gap between each page in the final image.
