Convert Multi-Page TIFF to PNG with ImageMagick

Multi-page TIFF files often need to be split into standard formats for web display, document management, or easier sharing. ImageMagick provides a fast command-line solution to extract and convert every page of a multi-page TIFF file into individual PNG images. This guide details the essential commands, file naming conventions, resolution settings, and specific page extraction syntax for both modern and legacy ImageMagick versions.

Basic Conversion Syntax

For ImageMagick 7, use the magick command:

magick input.tiff output-%d.png

For ImageMagick 6 (legacy), use the convert command:

convert input.tiff output-%d.png

In this command:

  • input.tiff is the source multi-page file.
  • output-%d.png specifies the naming pattern. The %d placeholder dynamically inserts a zero-indexed page number (e.g., output-0.png, output-1.png, output-2.png).

Adding Leading Zeros to Output Filenames

To format output numbers with leading zeros (useful for sorting), specify the number of digits using %0Nd, where N is the desired total width:

magick input.tiff output-%03d.png

This outputs files formatted as output-000.png, output-001.png, and so on.

Converting Specific Pages

To convert only a single page or a subset of pages, use bracket notation [index] immediately after the input file name (indexing starts at 0):

  • Extract the first page:

    magick input.tiff[0] page-1.png

  • Extract a range of pages (e.g., pages 1 through 3):

    magick input.tiff[0-2] page-%d.png

  • Extract specific non-consecutive pages (e.g., pages 1 and 4):

    magick "input.tiff[0,3]" page-%d.png

Preserving Resolution and Quality

When dealing with scanned documents or print-ready TIFFs, set the DPI resolution using the -density flag before the input file to ensure sharp PNG outputs:

magick -density 300 input.tiff -quality 100 output-%02d.png
  • -density 300 renders the TIFF at 300 DPI.
  • -quality 100 applies minimal compression to the generated PNG files.
