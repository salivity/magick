Convert Multiple PNGs to a Single PDF in ImageMagick

Converting multiple PNG images into a single multi-page PDF is a fast and simple process using ImageMagick's command-line interface. This guide explains the core commands required to merge your images, control page order, adjust output resolution, and resolve common configuration issues.

Basic Conversion Command

To combine multiple PNG files into one PDF document, open your terminal or command prompt, navigate to the folder containing your images, and run the following command:

For ImageMagick v7+:

magick image1.png image2.png image3.png output.pdf

For ImageMagick v6:

convert image1.png image2.png image3.png output.pdf

To merge all PNG files in the current directory, use a wildcard:

magick *.png output.pdf

Controlling Page Order

ImageMagick processes files in the order they are provided in the command. If you use *.png, the operating system's sorting order determines the page sequence.

To ensure pages are ordered correctly:

  • Rename files with zero-padded numbers (for example: page-01.png, page-02.png, page-10.png).
  • Explicitly list files in your desired order if naming is irregular:
magick front.png body_01.png body_02.png back.png final_document.pdf

Adjusting Resolution and Quality

By default, ImageMagick may use a standard 72 DPI resolution, which can result in low-quality or oversized pages in the output PDF. You can define the density and compression to optimize the document:

magick -density 300 -quality 100 *.png output.pdf
  • -density 300: Sets the horizontal and vertical resolution to 300 DPI for high-print quality.
  • -quality 100: Preserves maximum image quality during conversion.

Standardizing Page Sizes

If your PNG images have varying dimensions, you can fit them to a standard page size (such as A4 or Letter) while maintaining their aspect ratio:

magick *.png -page A4 -gravity center output.pdf

Resolving PDF Policy Errors

On Linux systems, ImageMagick might return an error stating: attempt to perform an operation not allowed by the security policy 'PDF'.

To fix this security restriction:

  1. Open the policy file (commonly located at /etc/ImageMagick-6/policy.xml or /etc/ImageMagick-7/policy.xml) using a text editor with administrative privileges.
  2. Find the line: 
    <policy domain="coder" rights="none" pattern="PDF" />
  3. Change rights="none" to rights="read|write": 
    <policy domain="coder" rights="read|write" pattern="PDF" />
  4. Save the file and rerun your conversion command.
