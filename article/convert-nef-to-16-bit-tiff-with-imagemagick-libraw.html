Convert NEF to 16-Bit TIFF with ImageMagick & LibRaw

This guide explains how to convert Nikon NEF raw images into high-quality 16-bit TIFF files using the LibRaw library alongside ImageMagick. By combining LibRaw's precise raw demosaicing engine with ImageMagick's processing tools, you can preserve maximum color depth, dynamic range, and image fidelity for archival or post-processing purposes. The following sections outline the necessary software requirements, command syntax for single-file conversions, and scripts for batch processing.

Prerequisites

To achieve 16-bit output, ensure your tools meet these specifications:

  1. LibRaw: Provides the demosaicing utilities (specifically dcraw_emu).
  2. ImageMagick (v7 or later): Must be built with 16-bit quantum support (Q16 or Q16-HDRI), which is standard in most official binary distributions. Verify this by running magick -version and checking that Q16 appears in the Features line.

ImageMagick automatically delegates raw file handling to LibRaw when available on your system path.

Single File Conversion

To convert a single .NEF file into an uncompressed, 16-bit depth TIFF, run the following command in your terminal:

magick input.NEF -depth 16 -compress none output.tiff

Recommended Flags and Optimizations

Raw processing can be customized to adjust color profiles, compression, and white balance behavior:

  • Compression: Use LZW or ZIP compression to reduce storage requirements without loss of data: 
    magick input.NEF -depth 16 -compress lzw output.tiff
  • Color Space: Ensure consistent rendering by assigning an explicit color profile (such as Adobe RGB or sRGB): 
    magick input.NEF -depth 16 -colorspace sRGB output.tiff

Direct Decoding via LibRaw's dcraw_emu

If you prefer to bypass ImageMagick's default raw delegate settings and rely directly on LibRaw before finalizing with ImageMagick, use LibRaw's dcraw_emu utility:

# -4 generates 16-bit linear output
# -T writes a TIFF file directly
dcraw_emu -4 -T -w input.NEF
  • -4: Writes 16-bit linear samples.
  • -T: Outputs directly to TIFF format.
  • -w: Uses the camera's recorded white balance.

You can then use ImageMagick to apply additional adjustments or compression to the resulting TIFF:

magick input.tiff -compress zip final_16bit.tiff

Batch Conversion

To convert an entire folder of .NEF files to 16-bit TIFFs, use one of the following methods depending on your operating system.

Linux / macOS (Bash)

for file in *.NEF; do
  magick "$file" -depth 16 -compress lzw "${file%.NEF}.tiff"
done

Windows (Command Prompt)

for %f in (*.NEF) do magick "%f" -depth 16 -compress lzw "%~nf.tiff"

Using ImageMagick Mogrify

To quickly convert and write files to an existing output directory:

magick mogrify -path ./converted -format tiff -depth 16 -compress lzw *.NEF

Verifying the Output

Confirm that the output image is correctly encoded at 16 bits per channel using ImageMagick's identify tool:

magick identify -format "%f: %r, Depth: %z-bit\n" output.tiff

The output should confirm a depth of 16-bit per color channel.
