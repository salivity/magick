Convert OpenEXR to SDR JPEG Using ImageMagick

Converting high-dynamic-range (HDR) OpenEXR (.exr) files to standard-dynamic-range (SDR) JPEG images requires transforming 16-bit or 32-bit floating-point linear color data into an 8-bit non-linear format. This guide demonstrates how to use ImageMagick's command-line tools to properly handle color space conversion, tone mapping, and gamma correction so that your output JPEGs retain balanced highlights and shadows without appearing washed out or clipped.

Basic Conversion

By default, ImageMagick handles the basic format translation, automatically mapping the floating-point values to an 8-bit integer range:

magick input.exr output.jpg

Applying Correct Color Space and Tone Mapping

Because OpenEXR files store color in linear space and JPEGs display in standard non-linear sRGB space, a direct conversion often produces overly dark or contrast-heavy results. To correct this, explicitly enforce the sRGB colorspace:

magick input.exr -colorspace sRGB output.jpg

If the HDR file contains extreme dynamic range, high-intensity values will clip to pure white. You can use -auto-level or -sigmoidal-contrast to tone map the highlights and shadows into a viewable SDR range:

magick input.exr -colorspace sRGB -auto-level -quality 95 output.jpg

For more precise tone mapping with contrast adjustment:

magick input.exr -colorspace sRGB -sigmoidal-contrast 5,50% -quality 95 output.jpg

Adjusting Exposure Before Conversion

If the input render is too dark or overexposed, adjust the exposure before clamping to 8-bit SDR by multiplying the pixel values in linear space:

magick input.exr -evaluate multiply 1.5 -colorspace sRGB -quality 95 output.jpg
  • Use a multiplier greater than 1.0 (e.g., 1.5 or 2.0) to brighten dark linear renders.
  • Use a multiplier less than 1.0 (e.g., 0.5 or 0.75) to recover details from overexposed areas.

Batch Converting Multiple EXR Files

To convert an entire directory of OpenEXR files to SDR JPEGs with optimized quality and color space, run:

magick mogrify -format jpg -colorspace sRGB -auto-level -quality 92 *.exr
