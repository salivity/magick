Convert OpenRaster ORA with ImageMagick

This article provides a straightforward guide on how to convert multi-layer OpenRaster (.ora) images using ImageMagick. You will learn the command-line syntax required to flatten multi-layer files into standard single-layer formats like PNG or JPEG, as well as how to extract individual layers or target specific layers directly.

Flatten an OpenRaster File to a Single Image

By default, an OpenRaster file contains multiple layers. To merge these layers and export a standard single-image file, use the -flatten operator.

For ImageMagick v7:

magick input.ora -flatten output.png

For ImageMagick v6:

convert input.ora -flatten output.png

This composite command merges all visible layers from top to bottom into a single background layer before writing the final output.

Extract All Layers Separately

If you need to separate every layer contained in the .ora file into individual images, provide an output filename pattern that accepts an index format:

magick input.ora layer-%d.png

This generates numbered image files (layer-0.png, layer-1.png, etc.) corresponding to each layer stored inside the OpenRaster container.

Extract a Specific Layer

To extract only a single layer without processing the entire stack, specify the layer index inside brackets immediately following the input filename. Indexing begins at 0:

magick input.ora[0] first-layer.png

To extract the second layer:

magick input.ora[1] second-layer.png

Alternative: Direct Archive Extraction

An OpenRaster file is a ZIP archive containing a dedicated directory of individual layer images and a pre-rendered composite. If your ImageMagick build does not include native .ora delegate support, you can unzip the archive directly using standard archive utilities:

unzip input.ora -d extracted_ora/

Inside the extracted folder:

  • mergedimage.png represents the fully rendered composite image.
  • data/ contains all individual raster layers in standard PNG format.

Once extracted, you can run any standard ImageMagick operation directly on the resulting PNG files.
