Convert PDF to High-Res JPG with ImageMagick

This guide explains how to convert PDF documents into high-resolution JPEG images using ImageMagick from the command line. You will learn the exact command syntax required to output crisp images, adjust the rendering density (DPI), preserve image quality, and properly handle PDF background transparency.

The High-Resolution Conversion Command

To convert a PDF into high-resolution JPEGs, run the following command in your terminal:

magick -density 300 -background white -alpha remove input.pdf -quality 95 output-%03d.jpg

(Note: If you are using ImageMagick version 6, replace magick with convert at the beginning of the command.)

Command Breakdown

  • -density 300: Sets the horizontal and vertical resolution to 300 DPI (dots per inch). By default, ImageMagick reads PDFs at 72 DPI, which results in blurry images. This flag must be placed before the input file so the PDF is rasterized at high resolution from the start.
  • -background white -alpha remove: PDFs frequently have transparent backgrounds. Since JPEG does not support transparency, transparent areas can turn black. This setting ensures the background renders as clean white.
  • input.pdf: The path to the source PDF file you want to convert.
  • -quality 95: Sets the JPEG compression quality level (on a scale from 1 to 100). A value between 90 and 95 provides high visual quality without creating excessively large file sizes.
  • output-%03d.jpg: Defines the output filename pattern. If the PDF contains multiple pages, ImageMagick generates sequential files such as output-000.jpg, output-001.jpg, and so on.

Converting a Specific Page

To convert only a single page from a multi-page document, specify the page index in square brackets immediately following the filename (page numbering starts at index 0):

magick -density 300 -background white -alpha remove input.pdf[0] -quality 95 first-page.jpg

Requirements

ImageMagick relies on Ghostscript to interpret and render PDF files. Ensure both ImageMagick and Ghostscript are installed on your system. If you encounter a security policy error on Linux distributions, you may need to open /etc/ImageMagick-6/policy.xml (or ImageMagick-7) and enable read/write permissions for the PDF pattern domain.
