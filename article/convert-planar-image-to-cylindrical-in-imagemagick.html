Convert Planar Image to Cylindrical in ImageMagick

Converting a flat, planar photograph into a cylindrical projection is a common requirement when preparing images for panoramic stitching or 360-degree environment mapping. This guide explains how to use the plane2cylinder script alongside ImageMagick to warp perspective images into cylindrical coordinates, covering installation requirements, core command-line options, field of view adjustments, and practical conversion examples.

Prerequisites

The plane2cylinder tool is a specialized ImageMagick-based shell script developed by Fred Weinhaus. To use it, ensure you have:

  • ImageMagick installed on your system (Linux, macOS, or Windows via WSL/Cygwin).
  • Standard Unix utilities (bash, bc, sed).
  • The plane2cylinder script downloaded and made executable.

Make the script executable after downloading:

chmod +x plane2cylinder

Basic Command Syntax

The general syntax requires specifying the horizontal field of view (FOV) of the original camera lens and providing the input and output filenames:

./plane2cylinder -f <fov> input.jpg output.jpg

Key Parameters

To achieve accurate reprojection without unnatural stretching, you must configure the following flags according to your source image:

  • -f <angle> (Field of View): The horizontal field of view of the input image in degrees. The default is typically 60. Providing the exact FOV matching the focal length of the camera lens is essential for maintaining proper geometric proportions.
  • -c <x,y> (Center Point): Specifies the image center (optical axis). By default, this is calculated as the center of the image canvas (width/2, height/2). If the image has been cropped off-center, define the original optical center here.
  • -v <val> (Vertical FOV behavior): Controls whether the vertical dimensions scale proportionally to maintain aspect ratios.
  • -b <color> (Background Color): Sets the background fill color for areas outside the reprojected image boundary (default is black or transparent if supported by the format).

Step-by-Step Conversion Examples

1. Standard Conversion Using Known FOV

If an image was taken with a lens providing an 84-degree horizontal field of view (equivalent to roughly a 24mm full-frame lens):

./plane2cylinder -f 84 input.jpg cylindrical_output.jpg

The script curves the horizontal edges outward while compressing the vertical edges toward the left and right borders, mapping the flat planar coordinates to the interior surface of a cylinder.

2. Specifying a Transparent Background

If the output will be layered over other assets, set the background fill to none using a PNG container:

./plane2cylinder -f 75 -b none input.jpg cylindrical_output.png

3. Adjusting for Off-Center Cropping

If the original image has a resolution of 4000x3000, but 500 pixels were cropped from the left edge, the optical center shifts:

./plane2cylinder -f 70 -c 1500,1500 cropped_input.jpg output.jpg

Native ImageMagick Alternative

If you cannot run external Bash scripts, ImageMagick provides internal reprojection via the -distort operator using mathematical mappings. The internal equivalent to planar-to-cylindrical mapping uses forward polynomial or custom FX transforms:

magick input.jpg -virtual-pixel Black -distort Cylinder2Plane "60" output.jpg

Note: In ImageMagick's built-in terminology, -distort Cylinder2Plane acts inversely depending on mapping direction; when using direct transformation pipelines, Weinhaus's plane2cylinder script provides the most direct and mathematically consistent forward-warp implementation for panoramic generation.
