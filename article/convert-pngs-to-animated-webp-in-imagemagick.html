Convert PNGs to Animated WebP in ImageMagick

This guide provides the exact ImageMagick commands and parameters needed to compile a sequence of PNG images into a single animated WebP file. You will learn the primary command syntax, how to adjust frame delays and looping settings, and how to apply quality controls for optimal file size and performance.

The Basic Command

To merge a series of numbered PNG files into an animated WebP using ImageMagick (version 7+), use the magick command:

magick -delay 10 -loop 0 frame*.png output.webp

If you are using ImageMagick version 6, replace magick with convert:

convert -delay 10 -loop 0 frame*.png output.webp

Parameter Breakdown

  • -delay <value>: Sets the duration each frame is displayed. The value is measured in hundredths of a second (ticks). For example:
    • -delay 10 = 100 milliseconds per frame (10 frames per second).
    • -delay 5 = 50 milliseconds per frame (20 frames per second).
    • -delay 4 = 40 milliseconds per frame (25 frames per second).
  • -loop <count>: Configures how many times the animation repeats. Setting -loop 0 creates an infinite loop. A value of 1 or higher plays the animation that specific number of times.
  • frame*.png: The input files. Ensure your files are named sequentially (e.g., frame_01.png, frame_02.png) so ImageMagick reads them in the correct chronological order.
  • output.webp: The designated output file name with the .webp extension.

Advanced Examples

Creating a Lossless Animated WebP

To maintain the exact image quality of your source PNGs without compression artifacts, add the lossless WebP definition:

magick -delay 10 -loop 0 frame*.png -define webp:lossless=true output.webp

Controlling Compression and Quality

If you need a smaller file size for web deployment, specify a quality level between 0 and 100:

magick -delay 10 -loop 0 frame*.png -quality 80 output.webp

Setting Individual Frame Delays

To make the final frame pause longer than preceding frames:

magick -delay 10 frame1.png frame2.png frame3.png -delay 100 frame4.png -loop 0 output.webp
