Convert PostScript Fonts to Bitmaps in ImageMagick

This article provides the exact command-line syntax for converting PostScript outline fonts into raster bitmap images using ImageMagick. You will learn the primary commands, essential flags for controlling resolution and dimensions, and direct examples for rendering both standalone font files and PostScript vector documents into common bitmap formats such as PNG and TIFF.

Basic Syntax for Rendering Text Using PostScript Fonts

To rasterize text using a PostScript Type 1 font file (.pfb or .pfa), use the magick command (or convert in ImageMagick v6) combined with the -font and label: operators:

magick -font "/path/to/font.pfb" -pointsize 48 label:"Sample Text" output.png

Key Parameters:

  • -font: Specifies the path to the PostScript outline font file.
  • -pointsize: Sets the size of the font in points.
  • label:: Defines the text string to be rendered into the bitmap.
  • output.png: Specifies the target raster image format (e.g., PNG, BMP, TIFF, JPG).

Setting Resolution and Anti-Aliasing

PostScript outline fonts scale vectorially. To ensure high-quality rasterization at specific resolutions, use the -density flag before rendering the text.

High-Resolution Rasterization (300 DPI)

magick -density 300 -font "Helvetica-Bold.pfb" -pointsize 24 label:"High Resolution Text" -quality 100 output.png

Disabling Anti-Aliasing for Crisp Pixel Bitmaps

If you need pure monochrome 1-bit style bitmaps without smooth anti-aliased edges, disable anti-aliasing with +antialias:

magick +antialias -font "Courier.pfb" -pointsize 16 label:"Pixelated Text" -monochrome output.bmp

Converting PostScript (.ps / .eps) Vector Files to Bitmaps

If your PostScript outline fonts are encapsulated within a .ps or .eps document, ImageMagick uses Ghostscript as a delegate to rasterize the entire document into a bitmap.

Syntax for EPS/PS File Conversion

magick -density 300 input.eps -background white -flatten -alpha off output.png

Parameter Breakdown:

  • -density 300: Sets the rendering resolution to 300 DPI (must be placed before the input file).
  • -background white: Specifies the background color behind transparent areas.
  • -flatten: Merges layers into a single raster plane.
  • -alpha off: Removes the alpha channel if a solid bitmap is required.

Batch Converting Characters or Glyphs

To rasterize multi-line character sets or custom glyph lists into a single contact sheet bitmap:

magick -density 150 -font "MyFont.pfb" -pointsize 32 \
  -background white -fill black \
  label:"ABCDEFGHIJKLMNOPQRSTUVWXYZ\nabcdefghijklmnopqrstuvwxyz\n0123456789" \
  font_sheet.png
