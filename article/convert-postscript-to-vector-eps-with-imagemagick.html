Convert PostScript to Vector EPS with ImageMagick

This guide explains how to convert PostScript (PS) files into Encapsulated PostScript (EPS) documents using ImageMagick on the command line. You will learn the required commands, prerequisite software configurations, and specific parameters needed to manage output quality and format settings during the conversion process.

Prerequisites

ImageMagick relies on Ghostscript as its underlying delegate engine to interpret and render PostScript-based formats (PS, EPS, PDF). Before running conversions, ensure both packages are installed on your system:

  • Linux (Ubuntu/Debian): sudo apt install imagemagick ghostscript
  • macOS (Homebrew): brew install imagemagick ghostscript
  • Windows: Install both via the official binary installers or using a package manager like winget or choco.

Basic Conversion Command

For ImageMagick v7, use the magick command:

magick input.ps output.eps

For ImageMagick v6, use the legacy convert command:

convert input.ps output.eps

Managing Resolution and Rendering

ImageMagick processes vector formats by rasterizing the PostScript paths using Ghostscript at a specified density before packaging the data into the target container. To ensure the generated EPS document maintains crisp details and high visual quality for print or display, define the rendering density using the -density flag before specifying the input file:

magick -density 300 input.ps -compress lzw output.eps

Key Parameters:

  • -density 300: Sets the horizontal and vertical resolution to 300 DPI, preventing pixelation when the PS file is parsed.
  • -compress lzw: Applies LZW compression to reduce the final EPS file size without degrading image quality.
  • -colorspace CMYK (Optional): Converts color profiles to CMYK, which is ideal if the output EPS is intended for commercial printing.
magick -density 300 input.ps -colorspace CMYK output.eps

Batch Converting Multiple PS Files

To convert all .ps files within a directory to .eps in a single command, you can use standard shell loops:

Linux / macOS (Bash)

for file in *.ps; do
  magick -density 300 "$file" "${file%.ps}.eps"
done

Windows (Command Prompt)

for %f in (*.ps) do magick -density 300 "%f" "%~nf.eps"
