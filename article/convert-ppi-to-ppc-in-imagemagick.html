Convert PPI to PPC in ImageMagick

Spatial density defines the resolution of an image for printing and physical display, measured typically in Pixels Per Inch (PPI) or Pixels Per Centimeter (PPC). In ImageMagick, you can easily switch or define these units using the -units and -density operators. This guide demonstrates how to check current image density, convert between PPI and PPC, and apply new density settings directly from the command line.

Checking Current Density and Units

Before modifying an image, you can check its existing spatial resolution and measurement units using the identify command:

magick identify -format "%x x %y %U\n" input.jpg
  • %x outputs the horizontal resolution.
  • %y outputs the vertical resolution.
  • %U outputs the current units (PixelsPerInch, PixelsPerCentimeter, or Undefined).

Changing Units from PPI to PPC

To change the density units from Pixels Per Inch to Pixels Per Centimeter while recalculating or assigning the resolution value, use the -units flag set to PixelsPerCentimeter:

magick input.jpg -units PixelsPerCentimeter -density 118.11 output.jpg

(Note: 300 PPI is approximately equal to 118.11 PPC, calculated by dividing 300 by 2.54).

If you simply want ImageMagick to automatically convert the existing PPI numerical value to its equivalent PPC value, declare the target unit and re-apply the density attribute:

magick input.jpg -units PixelsPerCentimeter output.jpg

Changing Units from PPC to PPI

To convert an image configured in Pixels Per Centimeter back to Pixels Per Inch, set the -units option to PixelsPerInch:

magick input.jpg -units PixelsPerInch -density 300 output.jpg

Key Differences Between Legacy and Modern Syntax

  • ImageMagick v7+: Use the magick command: 
    magick input.png -units PixelsPerInch -density 72 output.png
  • ImageMagick v6: Use the convert command: 
    convert input.png -units PixelsPerInch -density 72 output.png

Setting the spatial density does not resample or alter the pixel dimensions of the image; it only updates the metadata used by rendering software and printers to determine the output size.
