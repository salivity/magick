Convert ProPhoto RGB to sRGB with ImageMagick

Converting images from the wide-gamut ProPhoto RGB color space to the standard sRGB color space ensures that images display consistently and vibrantly across web browsers, mobile devices, and standard computer monitors. This guide provides the exact ImageMagick command-line syntax required to safely and accurately transform your images using ICC color profiles.

Basic Syntax (Image with Embedded Profile)

If your input image already contains an embedded ProPhoto RGB color profile, you only need to apply the target sRGB profile. ImageMagick will detect the input profile and perform the conversion automatically.

For ImageMagick v7:

magick input_prophoto.tif -profile /path/to/sRGB.icc output_srgb.jpg

For ImageMagick v6:

convert input_prophoto.tif -profile /path/to/sRGB.icc output_srgb.jpg

Syntax for Images Without an Embedded Profile

If your image was saved in the ProPhoto RGB color space but lacks an embedded ICC profile, applying a target profile directly will misinterpret the color data. You must pass the -profile option twice: the first to assign the source profile, and the second to convert to the target profile.

magick input_raw_prophoto.tif -profile /path/to/ProPhoto.icc -profile /path/to/sRGB.icc output_srgb.jpg

Controlling Rendering Intent

When converting from a very wide gamut like ProPhoto RGB to a narrower gamut like sRGB, out-of-gamut colors must be mapped into the smaller space. You can control this behavior using the -intent flag before applying the profiles:

  • Perceptual: Preserves visual relationships between colors (ideal for photographic images).
  • Relative: Preserves in-gamut colors exactly and clips out-of-gamut colors to the nearest reproducible hue.
magick input_prophoto.tif -intent Perceptual -profile /path/to/sRGB.icc output_srgb.jpg

Batch Conversion Syntax

To convert an entire directory of ProPhoto RGB images into sRGB, use mogrify:

magick mogrify -format jpg -path /path/to/output_directory -profile /path/to/sRGB.icc *.tif
