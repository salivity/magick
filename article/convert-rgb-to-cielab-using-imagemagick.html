Convert RGB to CIELAB Using ImageMagick

Converting an image from the RGB color space to CIELAB (commonly referred to as LAB or L*a*b*) allows you to separate lightness from color information for advanced image processing and color correction. This article explains the exact command-line syntax required to perform this conversion using ImageMagick, how to save the output in a compatible file format, and how to separate or revert the individual LAB channels.

Basic RGB to CIELAB Conversion

In ImageMagick version 7, use the magick command along with the -colorspace flag set to Lab. If you are using ImageMagick version 6, replace magick with convert.

magick input.jpg -colorspace Lab output.tiff

Choosing the Right File Format

Standard image formats like JPEG and PNG are designed for RGB data and may misinterpret LAB channels when viewed in standard image viewers. TIFF is the recommended format because it natively supports the CIELAB color space and preserves color metadata accurately.

Viewing and Extracting Individual LAB Channels

CIELAB is divided into three channels:

  • L* (Lightness): Represents brightness from black (0) to white (100).
  • a* (Green–Red): Represents color values along the green-to-red axis.
  • b* (Blue–Yellow): Represents color values along the blue-to-yellow axis.

To separate an image into three distinct grayscale images representing each channel, run:

magick input.jpg -colorspace Lab -separate lab_channel_%d.png

This generates three files:

  • lab_channel_0.png (Lightness / L*)
  • lab_channel_1.png (Green–Red / a*)
  • lab_channel_2.png (Blue–Yellow / b*)

Converting CIELAB Back to sRGB

After processing the image in the LAB color space, you can convert it back to standard sRGB for web or display usage using the following command:

magick output.tiff -colorspace sRGB final_image.jpg
