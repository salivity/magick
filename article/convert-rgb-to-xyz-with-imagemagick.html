Convert RGB to XYZ with ImageMagick

This article provides a straightforward guide to converting standard RGB images into the CIE XYZ color space using ImageMagick. You will learn the standard command-line methods for direct mathematical transformation, how to apply ICC color profiles for colorimetric accuracy, and how to configure bit depth and file formats to prevent data loss.

Direct Colorspace Conversion

The fastest way to convert an RGB image to the XYZ color space is by using the -colorspace operator. ImageMagick handles the linear transformation and matrix calculations automatically.

For ImageMagick v7, run:

magick input.jpg -colorspace XYZ output.tiff

For ImageMagick v6, use the legacy syntax:

convert input.jpg -colorspace XYZ output.tiff

This operation maps the red, green, and blue channels to the corresponding CIE X, Y, and Z tristimulus values.

Profile-Based Conversion (ICC Profiles)

For precise color management—such as when translating from a specific device profile or calibrating for a D50/D65 illuminant—converting via ICC color profiles is recommended.

  1. Ensure you have the source profile (e.g., sRGB.icc) and the destination profile (e.g., XYZ.icc).
  2. Run the following command:
magick input.jpg -profile sRGB.icc -profile XYZ.icc output.tiff

The first -profile flag assigns the source color space if it is not already embedded in the image, and the second -profile flag executes the transformation to the target profile.

Best Practices for XYZ Conversion

  • Use Non-Lossy Formats: Always save XYZ data to formats like TIFF, PNG, or EXR. Standard JPEG compression is designed around human perception in RGB/YCbCr spaces and will degrade XYZ data.
  • Increase Bit Depth: XYZ coordinates often require higher precision to prevent quantization errors. Use the -depth 16 flag to maintain a 16-bit channel depth:
magick input.png -depth 16 -colorspace XYZ output.tiff
  • Verify the Output: Inspect the resulting image metadata to confirm the color space mapping using the identify command:
magick identify -verbose output.tiff
