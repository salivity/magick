Convert Scanned Faxes to CCITT PDF Using ImageMagick

This guide explains how to convert scanned black-and-white fax images into compact, standard-compliant PDF documents using ImageMagick and CCITT Group 4 compression. You will find the exact command-line syntax, parameter explanations, and instructions for handling multi-page fax documents.

The ImageMagick Command

To convert an image file (such as a TIFF, PNG, or JPEG scan) to a CCITT Group 4 compressed PDF, run the following command:

magick input_fax.tif -monochrome -compress Group4 output.pdf

(Note: For ImageMagick version 6, replace magick with convert.)

Parameter Breakdown

  • input_fax.tif: The source image or scanned fax file.
  • -monochrome: Forces the image into a strict 1-bit black-and-white format, which is required because CCITT compression does not support grayscale or color data.
  • -compress Group4: Applies CCITT Group 4 (T.6) facsimile compression, yielding the smallest possible file sizes for monochrome scanned text and drawings. Alternatively, -compress Fax applies CCITT Group 3 (T.4) compression.
  • output.pdf: The resulting PDF document containing the compressed raster data.

Advanced Usage

Handling Grayscale Scans with Thresholding

If the source scan contains gray tones or anti-aliasing, use -threshold to create cleaner black-and-white output before compression:

magick input_fax.tif -threshold 50% -compress Group4 output.pdf

Merging Multiple Fax Pages into a Single PDF

To combine multiple scanned pages into one multi-page PDF document:

magick page1.tif page2.tif page3.tif -monochrome -compress Group4 combined_fax.pdf

Setting the Output Resolution (DPI)

To ensure the PDF preserves standard fax dimensions (typically 200x200 or 300x300 DPI), define the density:

magick -density 300 input_fax.tif -monochrome -compress Group4 output.pdf
