Convert SDR to HDR with ImageMagick

Converting standard dynamic range (SDR) images into high dynamic range (HDR) formats involves expanding color depth, linearizing gamma curves, and applying inverse tone mapping to recover luminance headroom. This guide provides a direct, technical walkthrough on using ImageMagick's command-line tools to transform 8-bit SDR files (such as JPEG or PNG) into 32-bit floating-point HDR formats (such as EXR or Radiance HDR).

1. Verify ImageMagick HDRI Support

Before processing, ensure your ImageMagick installation supports High Dynamic Range Imaging (HDRI), which is standard in ImageMagick 7. Run the following command in your terminal:

magick -version

Look for HDRI in the Features: line. Without HDRI enabled, pixel values will be clamped to standard 8-bit or 16-bit integers, preventing true HDR output.

2. The SDR-to-HDR Conversion Pipeline

Standard images are encoded with an sRGB non-linear transfer function and capped at a maximum brightness value of 1.0 (or 255 in 8-bit). Converting them into HDR requires three core steps:

  1. Linearization: Removing the sRGB gamma curve to calculate light values accurately.
  2. Dynamic Range Expansion (Inverse Tone Mapping): Scaling luminance values beyond standard 1.0 limits to simulate HDR highlights.
  3. Format Conversion: Saving floating-point values into an HDR container such as .exr or .hdr.

3. Step-by-Step Conversion Commands

Basic Linearization and Export

To convert an SDR image into a linear HDR format without dynamic range scaling:

magick input.jpg -colorspace RGB output.exr

Note: Using -colorspace RGB transforms the gamma-corrected sRGB values into linear light values.

Expanding Dynamic Range (Inverse Tone Mapping)

Standard SDR highlights peak at 1.0. To create dynamic range headroom for HDR rendering or visual effects pipelines, apply inverse tone curves using exposure and contrast operators.

Method A: Exponential Highlight Boost

Use mathematical evaluation to stretch higher-end luminance values:

magick input.jpg -colorspace RGB -evaluate Pow 2.2 -evaluate Multiply 2.0 output.exr
Method B: Sigmoidal Dynamic Range Stretching

Using inverse sigmoidal contrast allows you to push highlight values above the standard ceiling while preserving midtone fidelity:

magick input.jpg -colorspace RGB +sigmoidal-contrast 6.5,50% -define quantum:format=floating-point output.hdr

4. Advanced Production Pipeline Command

For production environments requiring precise control over color preservation, exposure compensation, and float-precision outputs, use the combined pipeline command below:

magick input.png \
  -colorspace sRGB \
  -depth 32 \
  -define quantum:format=floating-point \
  -gamma 0.454545 \
  -evaluate Multiply 1.5 \
  +sigmoidal-contrast 4.0,40% \
  output.exr
  • -depth 32 & -define quantum:format=floating-point: Forces the output buffer to 32-bit floating-point precision per channel.
  • -gamma 0.454545: Converts the standard 2.2 display gamma into linear space.
  • -evaluate Multiply 1.5: Increases exposure to raise white-point ceilings.
  • +sigmoidal-contrast: De-compresses tonal values smoothly across highlights and shadows.

5. Supported HDR Target Formats

ImageMagick can output to multiple HDR-compatible formats:

  • OpenEXR (.exr): Standard for VFX and 3D rendering. Supports half (16-bit) and full (32-bit) floating-point channels.
  • Radiance HDR (.hdr): Common for environment maps and lighting setups.
  • Floating-Point TIFF (.tiff): Useful for archival and high-bit-depth raster processing.
