Convert sRGB to Adobe RGB in ImageMagick

This guide explains how to convert an image from the standard sRGB color space to the wider Adobe RGB (1998) color space using ImageMagick. You will learn the exact command-line syntax required, how color profile transformation works in ImageMagick, and how to verify that the target color profile was applied correctly.

Prerequisites

To perform an accurate color profile conversion, you need:

  1. ImageMagick installed (version 7 is recommended, which uses the magick command).
  2. ICC Profile files:
    • An sRGB profile (e.g., sRGB.icc or sRGB_v4_ICC_preference.icc)
    • An Adobe RGB (1998) profile (e.g., AdobeRGB1998.icc)

You can download standard ICC profiles directly from the official International Color Consortium (ICC) or Adobe website.

The Conversion Command

ImageMagick handles color space conversions using the -profile operator.

Scenario 1: The input image already has an embedded sRGB profile

If your source image already contains an embedded sRGB profile, apply the target profile once:

magick input.jpg -profile AdobeRGB1998.icc output.jpg

Scenario 2: The input image has no embedded profile (Untagged sRGB)

If the source image does not have an embedded profile, ImageMagick needs to know the source profile first. Specifying -profile twice tells ImageMagick to assign the first profile to the source data and transform the pixel values to the second profile:

magick input.jpg -profile sRGB.icc -profile AdobeRGB1998.icc output.jpg

Understanding the -profile Parameter

  • First -profile flag: Assigns the source color profile without changing pixel color values (only if the image lacks an embedded profile).
  • Second -profile flag: Transforms the pixel values from the source color space into the destination color space (Adobe RGB 1998) and embeds the new profile into the output file.

Caution: Do not use -colorspace AdobeRGB for this conversion. The -colorspace operator mathematically shifts color values without using ICC color management, which often leads to inaccurate or washed-out colors.

Verifying the Output

To confirm that the output image contains the Adobe RGB (1998) profile, run:

magick identify -verbose output.jpg | grep -i "Profile-icc"

Alternatively, to inspect the profile description directly:

magick identify -format "%[profile:icc:description]\n" output.jpg

The output should confirm Adobe RGB (1998).
