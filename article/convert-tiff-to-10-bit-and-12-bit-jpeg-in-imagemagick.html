Convert TIFF to 10-Bit and 12-Bit JPEG in ImageMagick

Converting high-bit-depth TIFF images—such as 16-bit captures—into 10-bit or 12-bit JPEGs preserves smooth gradients and dynamic range while reducing file size. This guide covers how to execute these conversions using ImageMagick command-line tools, the underlying software requirements for deep-color JPEG encoding, and how to verify your output files.

Understanding JPEG Bit Depths

Standard baseline JPEG (ISO/IEC 10918-1) is restricted to 8-bit precision. The standard also defines an extended sequential discrete cosine transform (DCT) mode that supports 12-bit precision.

Because traditional JPEG standards define 8-bit and 12-bit modes, there is no discrete 10-bit specification for standard .jpg files. When requesting 10-bit precision, you must either scale it into a 12-bit container or target modern formats like JPEG 2000 (.jp2) or JPEG XL (.jxl), which natively support 10-bit data.

Prerequisites

To handle deep-color conversions, your ImageMagick installation must meet two criteria:

  1. High Quantum Build: ImageMagick must be compiled with Q16 or Q32 (standard or HDRI). An 8-bit build (Q8) will downsample images immediately upon loading.
  2. 12-bit Delegate Support: The underlying JPEG library (such as libjpeg or libjpeg-turbo) must be compiled with 12-bit support enabled.

Verify your ImageMagick build by running:

magick -version

Ensure the output contains Q16 or Q32 in the features list.

Converting TIFF to 12-Bit JPEG

To convert a 16-bit TIFF directly into an extended 12-bit JPEG, use the -depth flag set to 12:

magick input.tiff -depth 12 output_12bit.jpg

To preserve maximum fidelity, define the compression quality and retain the original color profile:

magick input.tiff -quality 95 -depth 12 output_12bit.jpg

If the underlying JPEG delegate was not compiled with 12-bit support, ImageMagick will issue an error or default back to 8-bit encoding.

Converting TIFF to 10-Bit

Because traditional JPEG delegates do not write true 10-bit streams:

Option A: Package 10-bit Data in a 12-bit JPEG

Setting -depth 10 instructs ImageMagick to quantize the data to 10 bits, but the writer will store the values within a 12-bit JPEG structure:

magick input.tiff -depth 10 output_10bit_in_12bit.jpg

Option B: Target JPEG 2000 for True 10-Bit Storage

If your target workflow requires a strictly defined 10-bit file rather than a padded 12-bit container, output to JPEG 2000 using the OpenJPEG delegate:

magick input.tiff -depth 10 output_10bit.jp2

Verifying the Output File

To verify that the resulting file retained the expected bit depth, run ImageMagick's identify tool:

magick identify -verbose output_12bit.jpg

Locate the Depth: field in the output. A successfully converted file will report:

Depth: 12-bit
