Convert to ACEScg in Modern ImageMagick

This guide provides the exact ImageMagick command needed to transform images into the ACEScg color space, along with the correct workflow for managing wide-gamut linear conversions. Because ImageMagick utilizes Little CMS for advanced color transformations, converting to ACEScg requires applying International Color Consortium (ICC) profiles rather than simple internal colorspace flags.

The Conversion Command

Modern ImageMagick (version 7 and newer) uses the magick binary along with the -profile operator to translate color spaces. To convert an image to ACEScg, you must map the source profile to an ACEScg profile:

magick input.png -profile sRGB.icc -profile ACEScg.icc output.exr

How the Command Works

  1. magick: Invokes the ImageMagick 7 command-line interface.
  2. input.png: The source image.
  3. -profile sRGB.icc: Defines the source color profile. If your source file (like an untagged JPEG or PNG) does not already have an embedded color profile, this first -profile option assigns the standard sRGB profile without altering pixel values. If the input image already has an embedded profile, this first flag can be omitted.
  4. -profile ACEScg.icc: Transforms the pixel data from the source color space into the target ACEScg profile.
  5. output.exr: Saves the output. ACEScg is a wide-gamut, scene-linear color space intended for computer graphics and visual effects workflows. Storing the result in a 16-bit half-float or 32-bit float format—such as OpenEXR (.exr) or high-bit-depth TIFF (.tif)—is necessary to prevent clipping and banding.

Handling Pre-Tagged Source Images

If your input image already contains an embedded ICC profile (such as a properly exported camera RAW or Display P3 image), you only need to supply the target ACEScg profile once:

magick tagged_input.tif -profile ACEScg.icc output.exr

Acquiring the ACEScg ICC Profile

ImageMagick does not bundle proprietary or specialized third-party profiles out of the box. You must provide a valid ACEScg.icc (or .icm) file. These profiles can be obtained from the official Academy Color Encoding System (ACES) repositories or generated using tools like OpenColorIO (OCIO). Ensure the path to the .icc file matches its location on your system when running the command.
