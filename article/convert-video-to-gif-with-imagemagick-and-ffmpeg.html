Convert Video to GIF with ImageMagick and FFmpeg

Converting a video clip into an animated GIF can be accomplished using ImageMagick directly—which calls FFmpeg as a delegate behind the scenes—or by piping FFmpeg output into ImageMagick for greater control. This guide outlines the essential ImageMagick command syntax for direct video-to-GIF conversion, parameter tuning for size and frame rate, and advanced piping techniques for optimal GIF quality and file size.

Direct ImageMagick Conversion

When FFmpeg is installed on your system, ImageMagick automatically delegates video reading tasks to it. The simplest command to convert a video into an animated GIF is:

magick input.mp4 output.gif

(Note: If you are using ImageMagick v6, replace magick with convert.)

Specifying Frame Rate, Sizing, and Optimization

Running a direct conversion without parameters often produces massive GIF files. You can adjust the dimensions, reduce colors, and optimize frames directly in ImageMagick:

magick -delay 1x15 input.mp4 -resize 480x -fuzz 2% +dither -layers Optimize output.gif
  • -delay 1x15: Sets the display delay to match a 15 frames-per-second (FPS) playback speed.
  • -resize 480x: Scales the width to 480 pixels while preserving the aspect ratio.
  • -fuzz 2%: Treats colors with minor differences as identical to improve compression.
  • +dither: Disables dithering to reduce color noise and decrease file size.
  • -layers Optimize: Applies frame-differencing optimization so only moving pixels are saved between frames.

Piping FFmpeg Directly to ImageMagick

To trim specific timestamps and handle scaling efficiently before passing raw frames to ImageMagick for palette reduction and layer optimization, use a pipe syntax:

ffmpeg -ss 00:00:02 -t 4 -i input.mp4 -vf "fps=15,scale=480:-1:flags=lanczos" -f image2pipe -vcodec ppm - | magick - -loop 0 -layers Optimize output.gif
  • -ss 00:00:02: Starts the capture at the 2-second mark.
  • -t 4: Limits the capture duration to 4 seconds.
  • -vf "fps=15,scale=480:-1:flags=lanczos": Changes the frame rate to 15 FPS and resizes the video width to 480px using high-quality Lanczos resampling.
  • -f image2pipe -vcodec ppm -: Outputs uncompressed PPM image streams to standard output (stdout).
  • magick -: Tells ImageMagick to read frames directly from standard input (stdin).
  • -loop 0: Configures the GIF to loop infinitely.
