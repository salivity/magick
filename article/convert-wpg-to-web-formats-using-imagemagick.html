Convert WPG to Web Formats Using ImageMagick

This article explains how the ImageMagick software suite decodes legacy WordPerfect Graphics (WPG) files and transforms them into modern, web-ready formats such as PNG, JPEG, and WebP. It outlines the internal parsing mechanisms ImageMagick uses to process legacy vector and raster elements, the conversion of archaic color profiles into modern web standards, and the straightforward command-line operations required to execute these conversions.

WordPerfect Graphics (WPG) is a hybrid graphic format developed in the late 1980s and 1990s that can contain vector objects, embedded bitmaps, or a combination of both across multiple versions (principally WPG1 and WPG2). Because modern web browsers do not support WPG natively, files must be converted into standardized formats that browsers can render.

ImageMagick processes WPG files through a dedicated internal decoder module (coders/wpg.c). When a user supplies a WPG file, ImageMagick reads the binary header to identify whether the file is a Version 1 (typically 8-bit palette-based raster or simple vectors) or Version 2 (supporting complex vector paths, gradients, and 24-bit color) file. The decoder extracts the embedded coordinates, drawing primitives, and raster data blocks sequentially.

Because standard web formats like PNG, JPEG, and WebP are primarily raster-based, ImageMagick’s rendering engine rasterizes any vector instructions found in the WPG file onto an internal pixel canvas. During this rasterization phase:

  • Resolution and Scaling: ImageMagick assigns a dots-per-inch (DPI) density to interpret vector dimensions into precise pixel grids.
  • Palette and Color Space Translation: Older WPG files often use proprietary or index-based color palettes. ImageMagick maps these legacy color indexes into modern 24-bit or 32-bit sRGB color spaces.
  • Alpha Channel Handling: If a WPG file defines background fills or transparent zones, ImageMagick assigns an alpha channel, which can be preserved when converting to formats that support transparency, such as PNG or WebP.

Once the data is held in ImageMagick's unified in-memory pixel cache, it passes the rasterized image to the target format's encoder. The user initiates this process using standard ImageMagick command-line syntax:

magick input.wpg output.png

To convert directly to a compressed format like WebP while setting a specific background color and resolution, the command can be fine-tuned:

magick -density 300 input.wpg -background white -flatten -quality 85 output.webp

In this pipeline, -density ensures vector lines render sharply before rasterization, -background white -flatten eliminates undefined transparent pixels to prevent visual artifacts, and -quality configures the final compression level for web delivery. Through this automated decoding, rasterizing, and re-encoding process, ImageMagick provides an efficient bridge between obsolete office formats and modern web architectures.
