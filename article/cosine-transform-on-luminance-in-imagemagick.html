Cosine Transform on Luminance in ImageMagick

Applying a mathematical cosine transform to pixel luminances in ImageMagick alters the tonal curve or frequency response of an image based on cosine mathematics. This guide details the exact command-line syntax required to isolate image luminance and apply a cosine transformation using operators such as -function Sinusoid, -evaluate Cosine, and the flexible -fx mathematical evaluator.

1. The Standard Sinusoid Function (Recommended)

The most efficient and standard way to apply a cosine curve to pixel values in ImageMagick is using the -function Sinusoid operator.

A cosine curve is mathematically identical to a sine wave shifted by 90 degrees.

Syntax:

magick input.png -colorspace Lab -channel 0 -function Sinusoid <frequency,phase_shift,amplitude,bias> +channel -colorspace sRGB output.png

Parameters for a Standard Cosine Map:

  • Frequency: 1 (one full cycle across the 0–1 tonal range)
  • Phase shift: 90 (shifts sine into cosine)
  • Amplitude: 0.5 (scales output to stay within 0–1 range)
  • Bias: 0.5 (centers the output at midpoint)

Example Command:

magick input.png -colorspace Lab -channel 0 -function Sinusoid 1,90,0.5,0.5 +channel -colorspace sRGB output.png

2. Using the -evaluate Cosine Operator

The -evaluate Cosine operator evaluates the cosine function across the pixel values directly. It takes an integer or floating-point frequency parameter.

Syntax:

magick input.png -colorspace HSL -channel 2 -evaluate Cosine <frequency> +channel -colorspace sRGB output.png

Example Command:

magick input.png -colorspace HSL -channel 2 -evaluate Cosine 1 +channel -colorspace sRGB output.png

Note: In the HSL colorspace, channel 2 corresponds to Lightness (Luminance).

3. Using the -fx Expression Operator

For custom mathematical formulas involving cosine, the -fx operator allows explicit mathematical programming. In -fx, pixel values (\(u\)) range from 0.0 to 1.0, and standard trigonometric functions are computed in radians.

Syntax:

magick input.png -colorspace Lab -channel 0 -fx "0.5 + 0.5 * cos(u * pi)" +channel -colorspace sRGB output.png

Formula Breakdown:

  • u: The input luminance value (normalized between 0 and 1).
  • pi: Built-in constant \(\pi \approx 3.14159\).
  • cos(u * pi): Computes the cosine over a half-cycle.
  • 0.5 + 0.5 * ...: Rescales the cosine range \([-1, 1]\) into the standard image intensity range \([0, 1]\).

Summary of Best Practices

  • Isolate Luminance First: Convert to a luminance-preserving color space like Lab (L-channel is channel 0) or HSL (L-channel is channel 2) using -colorspace to avoid altering color hues.
  • Restore Channel Masking: Always use +channel after your transformation to ensure subsequent operations affect all color channels normally.
  • Return to sRGB: Convert back to sRGB at the end of the command chain for correct viewing and output formatting.
