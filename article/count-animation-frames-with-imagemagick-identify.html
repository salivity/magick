Count Animation Frames with ImageMagick Identify

This guide provides the exact ImageMagick commands needed to extract the total frame count from animated files such as GIFs, APNGs, or WebP images. By using the identify utility along with format specifiers, you can quickly retrieve frame statistics directly in your terminal or automation scripts without manually inspecting every individual layer.

The Most Efficient Command

To output only the total number of frames as a single integer, use the %n format specifier targeted at the first frame index:

identify -format "%n\n" "animation.gif[0]"

If you are using ImageMagick 7, invoke it via the magick command:

magick identify -format "%n\n" "animation.gif[0]"

How It Works

  • -format "%n": The %n format string represents the total number of images (frames) in the current image sequence.
  • "animation.gif[0]": Specifying [0] instructs ImageMagick to only process metadata for the first frame. Because %n calculates the total frame count regardless of the frame selected, targeting [0] prevents ImageMagick from printing the number repeatedly for every single frame in the file.
  • \n: Appends a newline character to ensure the terminal output is clean.

Alternative Methods

If you want to extract the frame count using standard Unix utilities, you can use one of the following approaches:

Piping to head:

identify -format "%n\n" animation.gif | head -n 1

Counting lines from verbose identify:

identify animation.gif | wc -l

(Note: While identify animation.gif | wc -l works by counting each output line representing a frame, it is slower on large files compared to reading the metadata directly with animation.gif[0].)

Storing the Frame Count in a Bash Variable

To capture the frame count inside a shell script, store the command output directly:

FRAME_COUNT=$(identify -format "%n" "animation.gif[0]")
echo "Total frames: $FRAME_COUNT"
