Count Blobs in Binary Image Using ImageMagick

Counting distinct blobs in a binary image using ImageMagick can be achieved reliably using the connected-components labeling (-connected-components) operator. This guide explains how to analyze a black-and-white image, isolate contiguous regions of pixels, filter out background components and noise, and obtain an exact numerical count of objects directly from the command line.

The Connected-Components Operator

ImageMagick provides the -connected-components operator to find and uniquely label connected groups of pixels. In a binary image, pixels are either black (background) or white (foreground/blobs).

To inspect the components, you can invoke ImageMagick with verbose logging enabled:

magick input.png -define connected-components:verbose=true -connected-components 8 null:

Note: If you are using ImageMagick v6, replace magick with convert.

In this command:

  • -define connected-components:verbose=true prints a text report detailing every detected component (its ID, bounding box, centroid, pixel area, and color).
  • -connected-components 8 defines the connectivity. Use 8 to treat diagonal neighbors as connected, or 4 to consider only horizontal and vertical neighbors.
  • null: tells ImageMagick to discard the visual output image and only print the textual analysis to standard output.

Counting the Blobs via Command Line

The verbose output includes a header line, an entry for the background color, and an entry for each distinct blob. To extract the exact count automatically in a Unix-like shell (Linux, macOS, WSL), pipe the output through grep and wc:

magick input.png \
  -define connected-components:verbose=true \
  -connected-components 8 null: \
  | grep "white" | wc -l

How this works:

  1. grep "white" filters the component list to only match the lines representing foreground blobs (assuming blobs are white and the background is black). If your blobs are black on white, change "white" to "black".
  2. wc -l counts the remaining matched lines, yielding the exact number of blobs.

Filtering Small Noise and Artifacts

Binary images often contain single-pixel noise or small artifacts that should not be counted as valid blobs. You can ignore components below a specific pixel area by using the area-threshold define:

magick input.png \
  -define connected-components:verbose=true \
  -define connected-components:area-threshold=15 \
  -connected-components 8 null: \
  | grep "white" | wc -l

In this command, -define connected-components:area-threshold=15 merges any component containing fewer than 15 pixels into its surrounding background before generating the list, ensuring that only significant blobs are included in the final count.
