Count Frames in Animated Image Using ImageMagick

This guide demonstrates how to extract the total frame count of an animated image, such as a GIF, WebP, or APNG, using the ImageMagick identify tool. You will learn the exact command syntax required to output just the numeric frame count, how to optimize the command for speed, and how to handle versions across ImageMagick 6 and 7.

The Basic Command

To extract the exact number of frames from an animated file, run the following command:

identify -format "%n\n" animation.gif | head -n 1

For ImageMagick version 7 and newer, use the magick prefix:

magick identify -format "%n\n" animation.gif | head -n 1

How It Works

  • -format "%n\n": The %n format specifier tells ImageMagick to print the total number of frames (scenes) contained within the image sequence.
  • head -n 1: By default, identify iterates through every frame in the file and prints the total count for each one (e.g., if there are 20 frames, it prints 20 twenty times). Piping the output to head -n 1 restricts the output to a single number representing the total frame count.

Faster Alternative Using Frame Indexing

Instead of piping to head, you can tell ImageMagick to read only the metadata of the first frame by appending [0] to the filename:

identify -format "%n" "animation.gif[0]"

Optimizing Performance with -ping

For large animated files, decoding the entire image into memory can be slow. Adding the -ping flag forces ImageMagick to quickly read file attributes without loading the image data:

identify -ping -format "%n" "animation.gif[0]"

Saving Frame Count to a Shell Variable

To capture the frame count directly into a Bash variable for scripting:

frames=$(identify -ping -format "%n" "animation.gif[0]")
echo "Total frames: $frames"
