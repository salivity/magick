Count Unique Colors in Image with ImageMagick

This article demonstrates how to quickly and accurately calculate the total number of unique colors in an image file using ImageMagick from the command line. You will learn the standard format specifiers used to output the exact color count for both modern and legacy versions of ImageMagick, as well as how to inspect the colors themselves.

Using the %k Format Specifier (ImageMagick v7)

The fastest and most direct way to count unique colors in ImageMagick version 7 is using the magick command paired with the -format "%k" flag.

magick input.png -format "%k\n" info:
  • input.png: The path to your source image.
  • -format "%k\n": Tells ImageMagick to calculate and return only the number of unique colors, followed by a newline.
  • info:: Instructs the tool to print image properties directly to the standard output rather than creating a new file.

Legacy Method (ImageMagick v6)

If you are using ImageMagick version 6, the standalone identify utility is used instead:

identify -format "%k\n" input.png

Handling Alpha (Transparency)

By default, ImageMagick factors alpha channel transparency into the unique color calculation. If you want to count unique RGB values while ignoring transparent layers, disable the alpha channel before calculating:

magick input.png -alpha off -format "%k\n" info:

Listing the Unique Colors

If you need to view the specific hex codes and RGB values alongside the total count, reduce the image to its unique colors and output them in text format:

magick input.png -unique-colors txt:-

This generates a text table listing every individual color present in the image along with its coordinates, sRGB values, and hex representations.
