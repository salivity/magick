Create a Font Specimen Sheet with ImageMagick

Generating a font specimen sheet allows you to quickly inspect all available characters, numbers, symbols, and glyphs contained within a font file. Using ImageMagick from the command line, you can programmatically render clean, high-resolution specimen sheets without relying on external design software. This guide covers how to generate standard character maps and complete Unicode glyph sheets using built-in ImageMagick tools.

1. Generating a Standard Specimen Sheet

To create a quick specimen sheet containing uppercase letters, lowercase letters, numbers, and common punctuation, use the magick command (or convert in ImageMagick v6) paired with the label: operator.

magick -background white -fill black \
  -font "/path/to/font.ttf" -pointsize 36 \
  label:"[Font Name] Specimen\n\nABCDEFGHIJKLMNOPQRSTUVWXYZ\nabcdefghijklmnopqrstuvwxyz\n0123456789\n!@#$%^&*()_+-=[]{}|;':\",./<>?" \
  -bordercolor white -border 40 \
  specimen.png

2. Generating a Grid-Based Specimen Sheet for All Printable Glyphs

For a comprehensive layout where each character is displayed inside its own cell along with its corresponding index or code, you can use ImageMagick's montage utility.

Step A: Generate Character Labels

Run a shell loop to generate individual character images across the standard printable ASCII range (hex 0x20 to 0x7E):

mkdir -p glyphs
for i in $(seq 32 126); do
  char=$(printf "\\$(printf '%03o' "$i")")
  magick -size 60x60 xc:white -font "/path/to/font.ttf" -pointsize 28 \
    -gravity center -fill black -annotate +0+0 "$char" \
    "glyphs/glyph_$(printf '%03d' "$i").png"
done

Step B: Combine Glyphs into a Sheet

Combine the generated glyph images into a structured grid using montage:

montage glyphs/*.png -tile 16x -geometry +2+2 -border 1 -bordercolor "#cccccc" \
  -background white specimen_grid.png

Clean up the temporary individual images when finished:

rm -rf glyphs

3. Rendering Multi-Page Unicode Glyph Sheets

For complete TrueType/OpenType fonts containing hundreds of Unicode glyphs, you can generate a text file containing the entire desired Unicode range and render it across structured pages using caption::

# Create a UTF-8 character list for Unicode range 32 to 1024
python3 -c "print(''.join(chr(i) + ('\n' if (i - 31) % 32 == 0 else ' ') for i in range(32, 1024)))" > unicode_glyphs.txt

# Render into a multi-page PDF specimen sheet
magick -size 1200x1600 -background white -fill black \
  -font "/path/to/font.ttf" -pointsize 20 -gravity northwest \
  caption:@unicode_glyphs.txt -bordercolor white -border 50 \
  specimen_unicode.pdf

Key Parameters Explained

  • -font: Specifies the absolute or relative path to your TTF or OTF font file.
  • -pointsize: Adjusts the font rendering size in points.
  • -gravity: Controls text alignment within the defined canvas (center, northwest, etc.).
  • label: vs caption:: Use label: for auto-sizing single-line or manually wrapped text, and caption: for multi-line text that automatically wraps to the specified image -size.
  • montage: Takes a collection of individual image files and arranges them into an evenly spaced, bordered grid.
