Create a Gray Step Wedge in ImageMagick

This guide explains how to generate an image featuring a stepped grayscale wedge using ImageMagick. By combining the built-in gradient: operator with the -posterize or quantization options, you can quickly produce standard calibration charts and discrete gray-level ramps directly from the command line.

Basic Syntax for a Step Wedge

The most efficient method to create a gray step wedge is to generate a smooth gradient and reduce its color levels using -posterize.

For ImageMagick v7, use the following syntax:

magick -size 600x100 gradient:black-white -posterize 6 step_wedge.png

For ImageMagick v6, replace magick with convert:

convert -size 600x100 gradient:black-white -posterize 6 step_wedge.png

Parameter Breakdown

  • -size WIDTHxHEIGHT: Sets the overall dimensions of the output image in pixels (e.g., 600x100).
  • gradient:black-white (or simply gradient:): Generates a smooth linear transition from black to white. You can reverse the direction using gradient:white-black.
  • -posterize N: Divides the continuous gradient into \(N\) evenly spaced discrete tonal levels. In the example above, -posterize 6 creates a 6-step gray wedge.
  • step_wedge.png: Specifies the output filename and format.

Creating a Vertical Step Wedge

To orient the wedge vertically from top to bottom, swap the dimension ratios and specify the gradient direction:

magick -size 100x600 gradient:white-black -posterize 8 vertical_wedge.png

Creating Custom Defined Gray Steps

If you require specific, non-linear gray values rather than evenly quantized steps, construct the wedge by appending individual color patches horizontally with +append:

magick \( -size 100x100 xc:"gray(10%)" \) \
       \( -size 100x100 xc:"gray(30%)" \) \
       \( -size 100x100 xc:"gray(50%)" \) \
       \( -size 100x100 xc:"gray(70%)" \) \
       \( -size 100x100 xc:"gray(90%)" \) \
       +append custom_wedge.png
  • xc:"gray(X%)": Generates an image canvas filled with a specific percentage of gray.
  • +append: Glues the individual images together horizontally from left to right. To stack them vertically, use -append.
