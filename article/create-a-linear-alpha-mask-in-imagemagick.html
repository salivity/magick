Create a Linear Alpha Mask in ImageMagick

This guide explains how to generate a linear transparent-to-opaque alpha mask and apply it to an image using ImageMagick. You will learn the core concepts behind grayscale alpha channels, how to construct standalone linear gradient masks, and how to combine an image with a gradient mask in a single command using ImageMagick version 7.

Understanding Alpha Masks in ImageMagick

In digital imaging, an alpha mask defines the opacity of different areas of an image using grayscale values. When mapped to an alpha channel:

  • Pure Black (#000000) represents 0% opacity (completely transparent).
  • Pure White (#FFFFFF) represents 100% opacity (completely opaque).
  • Gray values create proportional levels of semi-transparency.

A linear transition from black to white generates a smooth fade from transparent to opaque.

Method 1: Creating a Standalone Alpha Mask

To generate a standalone linear gradient image file to inspect or reuse later, use the gradient: operator.

Top-to-Bottom Gradient (Vertical)

magick -size 800x600 gradient:black-white vertical_mask.png

Left-to-Right Gradient (Horizontal)

In ImageMagick 7, use the gradient:direction setting to control the angle of the gradient:

magick -size 800x600 -define gradient:direction=east gradient:black-white horizontal_mask.png

Method 2: Applying a Linear Mask Directly to an Image

You can generate the linear mask dynamically and apply it directly to a target image without saving an intermediate mask file.

Vertical Fade (Transparent Top to Opaque Bottom)

magick input.jpg \( +clone -size %wx%h gradient:black-white \) -alpha off -compose CopyOpacity -composite output.png

Command Breakdown:

  • input.jpg: The original source image.
  • \( ... \): Opens a sub-operation that creates the mask.
  • +clone -size %wx%h gradient:black-white: Dynamically matches the exact width (%w) and height (%h) of the source image and fills it with a black-to-white gradient.
  • -alpha off: Disables any existing alpha channels on the generated gradient to ensure a pure grayscale map.
  • -compose CopyOpacity -composite: Copies the grayscale values of the gradient into the alpha channel of the input image.
  • output.png: Saves the result as a PNG to preserve transparency.

Horizontal Fade (Transparent Left to Opaque Right)

magick input.jpg \( +clone -size %wx%h -define gradient:direction=east gradient:black-white \) -alpha off -compose CopyOpacity -composite output.png

Inverted Fade (Opaque to Transparent)

To reverse the direction of the fade, invert the gradient colors from white-black:

magick input.jpg \( +clone -size %wx%h gradient:white-black \) -alpha off -compose CopyOpacity -composite output.png

Method 3: Masking an Image with an Existing Mask File

If you already have a grayscale mask file saved on disk, apply it to an image with the following syntax:

magick input.jpg mask.png -alpha off -compose CopyOpacity -composite output.png

Ensure that mask.png matches the dimensions of input.jpg for optimal results.
