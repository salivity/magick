Create a Radial Gradient Canvas in ImageMagick

This article provides a quick guide on generating radial gradient canvases using ImageMagick's built-in radial-gradient: primitive. You will learn the core syntax, how to specify inner and outer colors, and how to customize the center position and radius to generate smooth, circular, or elliptical gradient backgrounds directly from the command line.

Basic Radial Gradient Syntax

ImageMagick utilizes the radial-gradient: protocol to generate a gradient transitioning outward from a central point. The basic syntax requires specifying the canvas dimensions via the -size option and declaring the start (center) and end (outer) colors separated by a hyphen.

magick -size 600x400 radial-gradient:white-black radial_output.png

In this example, ImageMagick creates a 600x400 canvas where the gradient begins as white in the center and smoothly blends into black at the edges.

Specifying Colors

You can use standard color names, hex codes, RGB values, or RGBA values (for gradients with transparency).

  • Hex values: 
    magick -size 500x500 radial-gradient:"#ff7e5f-#feb47b" sunset_gradient.png
  • Transparency (RGBA): 
    magick -size 500x500 radial-gradient:"rgba(255,0,0,1)-rgba(255,0,0,0)" glow.png

Adjusting Gradient Center and Extent

ImageMagick provides specialized -define settings to control the geometry, position, and bounding extent of the radial gradient.

Changing the Center Point

By default, the gradient originates at the center of the canvas (50%,50%). You can reposition the origin using radial-gradient:center.

magick -size 600x400 -define radial-gradient:center=150,100 radial-gradient:yellow-blue offcenter_gradient.png

Controlling the Gradient Extent

The radial-gradient:extent definition dictates how far the gradient stretches before reaching the final color:

  • circle: Forces the gradient to remain a true circle regardless of canvas dimensions.
  • diagonal: Extends the gradient to the furthest corner of the canvas.
  • minimum: Extends the gradient only to the closest edge.
  • maximum: Extends the gradient to the furthest edge.
magick -size 800x400 -define radial-gradient:extent=circle radial-gradient:cyan-navy circular_extent.png

Creating Elliptical vs. Circular Gradients

When the canvas is non-square (such as 800x400), ImageMagick automatically stretches a standard radial gradient into an ellipse to fit the aspect ratio. If you want a perfectly circular gradient on a rectangular canvas, combine -define radial-gradient:extent=circle or use square dimensions and crop/resize the output as needed.
