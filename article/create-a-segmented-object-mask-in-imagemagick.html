Create a Segmented Object Mask in ImageMagick

Generating a segmented object mask in ImageMagick involves isolating a specific region or object within an image based on color, intensity, or spatial clusters, and converting that region into a binary black-and-white mask. This guide provides the core command-line syntax for creating masks using thresholding, color-range selection, the built-in segmentation operator, and connected-component analysis in ImageMagick 7 (and ImageMagick 6).

1. Basic Thresholding (Luminance Mask)

If your object has high contrast against the background, apply a grayscale conversion followed by a threshold to create a binary mask.

magick input.jpg -colorspace Gray -threshold 50% mask.png
  • -colorspace Gray: Converts the source image to grayscale.
  • -threshold 50%: Turns all pixels brighter than 50% white and all darker pixels black. Invert the logic by swapping the output using -negate if needed.

2. Color-Based Object Masking

To isolate an object of a specific color, use -fuzz to allow a tolerance range around the target color, make the target white, and turn everything else black.

magick input.jpg -fuzz 15% -fill white -opaque "#FF0000" -fill black +opaque white mask.png
  • -fuzz 15%: Defines the color distance tolerance.
  • -fill white -opaque "#FF0000": Replaces any pixel within 15% of pure red with white.
  • -fill black +opaque white: Replaces everything that is not white with black.

3. Using the Segment Operator

ImageMagick includes a -segment operator that segments an image by analyzing color clusters in the CIELAB color space.

magick input.jpg -segment 2.0x1.5 segmented.png
  • cluster_threshold (e.g., 2.0): Defines the minimum cluster size for segmentation.
  • smoothing_threshold (e.g., 1.5): Reduces noise in the segmented output.

To convert a segmented region into a distinct mask, chain it with a threshold or color-isolation command:

magick input.jpg -segment 2.0x1.5 -colorspace Gray -threshold 40% mask.png

4. Advanced: Connected-Components Labeling

To mask distinct objects based on area and remove small noise artifacts, use the -connected-components feature:

magick input.jpg -colorspace Gray -threshold 50% \
  -define connected-components:area-threshold=100 \
  -define connected-components:mean-color=true \
  -connected-components 8 mask.png
  • -define connected-components:area-threshold=100: Ignores and fills in any connected region smaller than 100 pixels.
  • -define connected-components:mean-color=true: Replaces labeled objects with their mean gray value.
  • -connected-components 8: Analyzes connectivity using 8-neighbor connectivity.

5. Applying the Mask to the Original Image

To apply the generated mask to extract the object with a transparent background:

magick input.jpg mask.png -alpha off -compose CopyOpacity -composite output.png
  • input.jpg: The original RGB image.
  • mask.png: The black-and-white segmented mask.
  • -compose CopyOpacity -composite: Uses the grayscale values of the mask as the alpha channel for the primary image.
