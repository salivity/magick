Create a Tilt-Shift Effect in ImageMagick

This guide explains how to create a miniature tilt-shift effect on any photograph using ImageMagick. By combining selective gradient blurring with slight contrast and saturation adjustments, you can turn real-world landscapes and cityscapes into toy-like miniature scenes directly from the command line.

The Tilt-Shift Command

To generate the tilt-shift miniature effect using ImageMagick version 7, run the following command:

magick input.jpg -modulate 105,140,100 \( +clone -blur 0x12 \) \( +clone -size %[fx:w]x%[fx:h] gradient: -solarize 50% -level 0,50% \) -composite output.jpg

For ImageMagick version 6, replace magick with convert:

convert input.jpg -modulate 105,140,100 \( +clone -blur 0x12 \) \( +clone -size %[fx:w]x%[fx:h] gradient: -solarize 50% -level 0,50% \) -composite output.jpg

How the Command Works

  • -modulate 105,140,100: Slightly increases the brightness (105%) and significantly boosts the color saturation (140%) to simulate the vivid, plastic-like appearance of miniature models.
  • \( +clone -blur 0x12 \): Creates a duplicate of the image and applies a heavy Gaussian blur with a radius/sigma of 0x12.
  • \( +clone -size %[fx:w]x%[fx:h] gradient: -solarize 50% -level 0,50% \): Generates a linear gradient mask where the center remains white (sharp) and the top and bottom edges fade to black (blurred).
  • -composite: Combines the original image, the blurred layer, and the gradient mask into the final output image.

Customizing the Effect

  • Blur Strength: Adjust the -blur 0x12 parameter. Higher values (such as 0x16 or 0x20) produce a shallower depth of field, while lower values (such as 0x8) provide a subtler blur.
  • Saturation Level: Change the second value in -modulate 105,140,100 to adjust how vivid the colors appear. Higher values enhance the toy-like look.
  • Focal Point Position: To shift the sharp focus area up or down instead of keeping it dead-center, adjust the -level 0,50% threshold or construct an asymmetric mask using -sparse-color.
