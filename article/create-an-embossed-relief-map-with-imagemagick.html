Create an Embossed Relief Map with ImageMagick

Creating an embossed relief map transforms a flat heightmap or aerial image into a simulated 3D topographic visualization by applying directional lighting and shadow effects. This guide explains how to use ImageMagick's command-line tools to generate clean, highly customizable relief maps using built-in shading, convolution, and image blending techniques.

Prerequisites

Ensure you have ImageMagick installed on your system. Modern installations use the magick command, while legacy versions use convert. Prepare a grayscale heightmap or digital elevation model (DEM) where lighter shades represent higher elevations and darker shades represent valleys.

Method 1: Using the Built-In Emboss Filter

The most direct way to create a basic relief texture is the -emboss operator. This applies a directional edge-detection convolution matrix to your image.

magick input_dem.png -emboss 2 relief_map.png

The numeric argument (e.g., 2) controls the radius of the embossing effect. Higher values increase the perceived depth of the terrain features.

Method 2: Realistic Relief Shading with -shade

For true cartographic hillshading, the -shade operator yields superior results compared to standard embossing. It allows you to define the exact position of the virtual light source.

The syntax requires setting the light source angle: Azimuth × Elevation (degrees):

  • Azimuth (0–360): The direction from which the light originates (315° is standard cartographic northwest lighting).
  • Elevation (0–90): The height of the sun above the horizon (45° is standard).
magick input_dem.png -shade 315x45 shaded_relief.png

To normalize the contrast and enhance the depth of the terrain:

magick input_dem.png -shade 315x45 -auto-level shaded_relief_enhanced.png

Method 3: Blending Shaded Relief with Color Textures

To create a full-color topographic map, combine the grayscale shaded relief layer with a color-coded elevation map or satellite photo.

  1. Generate the shaded relief:

    magick heightmap.png -shade 315x45 relief.png

  2. Blend the relief with the base texture using Overlay composition:

    magick color_map.png relief.png -compose Overlay -composite final_relief_map.png

If the shadows are too harsh, adjust the opacity of the relief layer before compositing using the -define compose:args parameter or by adjusting brightness and contrast:

magick color_map.png \( relief.png -brightness-contrast 0x-20 \) -compose SoftLight -composite final_relief_map.png

Complete One-Line Script

You can perform the entire process—from raw heightmap to color-shaded relief—in a single ImageMagick command without creating temporary intermediate files:

magick color_map.png \( heightmap.png -shade 315x45 -auto-level \) -compose Overlay -composite output_map.png
