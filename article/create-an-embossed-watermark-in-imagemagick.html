Create an Embossed Watermark in ImageMagick

This guide demonstrates how to generate a semi-transparent, embossed watermark logo on an image using ImageMagick. By combining alpha channel extraction, directional shading, and composite blending modes, you can produce a professional, non-intrusive 3D watermark effect that blends seamlessly across both light and dark backgrounds.

Prerequisites

Ensure you have ImageMagick 7 installed. Commands use the modern magick binary. Your watermark source should ideally be a transparent PNG file where the graphic elements have a clean alpha channel.

The Single-Command Method

You can generate the embossed watermark and apply it directly onto your target image in a single execution:

magick target.jpg \( logo.png -alpha extract -shade 135x45 -auto-level -alpha on -channel A -evaluate multiply 0.5 +channel \) -gravity southeast -geometry +20+20 -compose Hardlight -composite output.jpg

How the Parameters Work

The command uses parenthesis-based subprocessing to process the logo before overlaying it:

  1. target.jpg: Specifies the base image you want to protect.
  2. logo.png -alpha extract: Extracts the shape of your transparent logo as a grayscale silhouette, discarding original colors.
  3. -shade 135x45: Creates the 3D embossed lighting effect. The first number (135) is the azimuth (the angle of the light source in degrees), and the second number (45) is the elevation above the horizon.
  4. -auto-level: Normalizes the shaded mask to maximize contrast between the highlighted edges and shadowed edges.
  5. -alpha on -channel A -evaluate multiply 0.5 +channel: Re-enables the alpha channel and reduces the overall opacity to 50%. Adjust 0.5 higher or lower to change visibility.
  6. -gravity southeast -geometry +20+20: Positions the watermark in the bottom-right corner with a 20-pixel padding from the edges.
  7. -compose Hardlight -composite: Blends the shaded watermark into the base image. The Hardlight (or Overlay) compose method allows the lighter edges to brighten the underlying image and darker edges to darken it, achieving the transparent embossed appearance.
  8. output.jpg: The resulting watermarked image.

Alternative Two-Step Method

If you need to apply the same watermark across multiple images, generate the reusable embossed asset first:

Step 1: Create the reusable transparent embossed asset

magick logo.png -alpha extract -shade 135x45 -auto-level -channel A -evaluate set 40% +channel embossed_watermark.png

Step 2: Overlay it onto a base image

magick target.jpg embossed_watermark.png -gravity center -compose Overlay -composite output.jpg

Using -compose Overlay or -compose Hardlight ensures the neutral 50% gray base of the shaded graphic becomes invisible, leaving only the raised edges visible over the image beneath.
