Create an Image Reflection in ImageMagick

This guide explains how to generate a realistic, faded mirror reflection beneath an image using ImageMagick. By flipping the original graphic, applying an alpha gradient mask to simulate light fading across a shiny surface, and appending the result directly underneath, you can automate polished product-style mockups via the command line.

The Complete Command

In ImageMagick (version 7 and newer), you can generate the reflection in a single command using the magick tool:

magick input.png \
  \( +clone -flip -size 100%x50% gradient:rgba\(255,255,255,0.7\)-rgba\(255,255,255,0\) \
     -alpha off -compose CopyOpacity -composite \) \
  -append output.png

If you are using ImageMagick 6, replace magick with convert.

Step-by-Step Breakdown

  1. input.png
    Specifies the base source image to which the reflection will be added.

  2. \( +clone ... \)
    Creates an isolated copy (clone) of the input image in memory to process the reflection independently without affecting the original.

  3. -flip
    Flips the cloned image vertically to produce the inverted mirror orientation.

  4. -size 100%x50% gradient:...
    Creates a linear gradient matching the width of the image and half its height. Adjusting the gradient values controls the starting and ending opacity of the reflection.

  5. -alpha off -compose CopyOpacity -composite
    Applies the gradient as an alpha transparency mask to the flipped image, causing it to smoothly fade to completely transparent toward the bottom.

  6. -append
    Joins the original image and the faded reflection vertically into a single file.

Customizing the Effect

  • Adjust Reflection Height: To show more or less of the reflection, change the crop or gradient percentage (e.g., -size 100%x30% for a subtle, shorter reflection).
  • Adjust Fade Intensity: Modify the starting opacity in rgba(255,255,255,0.7). Lowering 0.7 to 0.4 makes the reflection fainter, while raising it toward 1.0 makes the surface appear more polished and reflective.
  • Add a Background Color: If saving to formats that do not support transparency (like JPEG), add -background white -flatten before the output filename to composite the final result onto a solid background.
