Create Anaglyph 3D Images with ImageMagick

Learn how to quickly assemble a red-cyan 3D anaglyph image from a pair of stereo photos using ImageMagick. This guide provides the exact command-line syntax, parameter options, and instructions required to combine left-eye and right-eye source images into a single stereoscopic 3D image viewable with standard red-cyan glasses.

The Basic Command

To merge a left-eye image (left.jpg) and a right-eye image (right.jpg) into a standard red-cyan 3D anaglyph, use the -stereo operator.

For ImageMagick v7:

magick composite -stereo 0 left.jpg right.jpg anaglyph.jpg

For ImageMagick v6 (Legacy):

composite -stereo 0 left.jpg right.jpg anaglyph.jpg

Understanding the Parameters

  • composite: The ImageMagick tool used for combining and layering multiple images.
  • -stereo <offset>: Combines the red channel of the first (left) image with the green and blue (cyan) channels of the second (right) image. The numerical value represents horizontal pixel offset (convergence adjustment). Setting this to 0 applies no horizontal shift.
  • left.jpg: The image representing the view from the left perspective.
  • right.jpg: The image representing the view from the right perspective.
  • anaglyph.jpg: The resulting 3D output image.

Adjusting Convergence (Stereo Offset)

If the 3D effect feels misaligned or causes eye strain, adjust the convergence point by changing the offset value:

  • Shift right image rightward: 
    magick composite -stereo +10 left.jpg right.jpg anaglyph.jpg
  • Shift right image leftward: 
    magick composite -stereo -10 left.jpg right.jpg anaglyph.jpg

Advanced Channel Method

If you need precise control over channel combining without using the composite shorthand, use the magick convert syntax with channel extraction:

magick left.jpg right.jpg ( -clone 0 -channel R -separate ) ( -clone 1 -channel GB -separate ) -delete 0,1 -combine anaglyph.jpg

Requirements for Best Results

  1. Resolution Match: Both the left and right source images must share identical pixel dimensions before running the command.
  2. Vertical Alignment: Ensure the vertical alignment between both perspectives is perfectly level to prevent visual distortion.
