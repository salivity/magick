Create Animated GIF with Fixed Loops in ImageMagick

Creating an animated GIF that stops after a specific number of iterations is simple with ImageMagick. By using the -loop setting alongside your frame sequencing commands, you can define exactly how many times the animation should play before stopping on the final frame.

The ImageMagick Command

To create an animated GIF from a sequence of images and set it to loop a fixed number of times, use the following syntax:

magick -delay 20 -loop 3 frame1.png frame2.png frame3.png output.gif

(Note: If you are using ImageMagick version 6, replace magick with convert.)

How the Parameters Work

  • -delay <value>: Sets the display duration for each frame. The value is measured in hundredths of a second (ticks). For example, -delay 20 creates a 0.2-second pause between frames (5 frames per second).
  • -loop <iterations>: Sets the number of repetitions.
    • Passing a positive integer such as -loop 3 makes the GIF play through a total of 3 times.
    • Setting -loop 1 will play the animation once and then stop.
    • Setting -loop 0 sets the animation to loop indefinitely.
  • Input Files: List the individual image files in order, or use a wildcard like frame*.png or *.jpg.
  • Output File: The final argument specifies the name of the generated GIF.

Modifying an Existing GIF

If you already have an animated GIF and want to change its loop count to a fixed number without reassembling individual frames, run:

magick input.gif -loop 2 output.gif
