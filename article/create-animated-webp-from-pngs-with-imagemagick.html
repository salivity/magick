Create Animated WebP from PNGs with ImageMagick

This guide explains how to convert a sequence of PNG images into an animated WebP file using ImageMagick. You will learn the exact command-line syntax, how to control the frame rate and loop count, and how to optimize the output file quality.

Basic Command

For ImageMagick version 7, use the magick command:

magick -delay 10 -loop 0 *.png output.webp

If you are using ImageMagick version 6, use the legacy convert command:

convert -delay 10 -loop 0 *.png output.webp

Command Parameters Explained

  • -delay <value>: Sets the duration each frame is displayed. The default unit is hundredths of a second (ticks). For example:
    • -delay 10 displays each frame for 100 milliseconds (10 frames per second).
    • -delay 5 displays each frame for 50 milliseconds (20 frames per second).
    • -delay 1x30 sets the delay precisely to 30 frames per second.
  • -loop <count>: Controls animation playback:
    • -loop 0 creates an infinite loop.
    • -loop 1 (or any positive integer) loops the animation that specific number of times.
  • *.png: The input files. You can use wildcards (like frame_*.png) or list individual files sequentially (frame1.png frame2.png frame3.png). Ensure files are named in chronological order if using wildcards.
  • output.webp: The name of the resulting animated WebP file.

Advanced Options and Optimization

Lossless Compression

To preserve the exact visual quality of your PNGs without compression artifacts, enable lossless WebP encoding:

magick -delay 10 -loop 0 *.png -define webp:lossless=true output.webp

Adjusting Quality and File Size

For lossy compression to reduce file size, specify a quality level between 0 and 100 (default is typically 75):

magick -delay 10 -loop 0 *.png -quality 80 output.webp

Setting Individual Frame Delays

To set different display durations for specific frames, assign the delay before each file:

magick -loop 0 -delay 10 frame1.png frame2.png -delay 50 frame3.png output.webp
