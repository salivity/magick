Create Anti-Aliased Circle Avatar in ImageMagick

This guide explains how to convert standard rectangular images into smooth, anti-aliased circular profile avatars using ImageMagick. You will learn the exact command-line syntax required to crop an image to a square, generate a vector-based circular alpha mask, and export the final result as a transparent image.

Recommended Command Syntax

For modern ImageMagick (version 7+), use the following syntax in your terminal:

magick input.jpg -resize 400x400^ -gravity center -extent 400x400 \
\( +clone -alpha extract -draw "fill black polygon 0,0 0,0 fill white circle 200,200 200,0" \) \
-alpha off -compose CopyOpacity -composite output.png

If you are using legacy ImageMagick (version 6), replace magick with convert:

convert input.jpg -resize 400x400^ -gravity center -extent 400x400 \
\( +clone -alpha extract -draw "fill black polygon 0,0 0,0 fill white circle 200,200 200,0" \) \
-alpha off -compose CopyOpacity -composite output.png

Syntax Breakdown

  1. -resize 400x400^ -gravity center -extent 400x400

    • -resize 400x400^: Scales the image proportionally so that the smallest dimension is at least 400 pixels.
    • -gravity center: Positions the cropping area in the center of the image.
    • -extent 400x400: Crops the image to an exact 400x400 pixel square.

  2. \( +clone -alpha extract ... \)

    • +clone: Duplicates the cropped image in memory.
    • -draw "fill black polygon 0,0 0,0 fill white circle 200,200 200,0": Generates an anti-aliased white circle on a black background. The coordinates 200,200 200,0 define the center of the circle (x=200, y=200) and the perimeter point (x=200, y=0), creating a radius equal to half the width.

  3. -alpha off -compose CopyOpacity -composite

    • Converts the drawn mask into the alpha channel of the original image, making the area outside the circle transparent with smooth, anti-aliased edges.

  4. output.png

    • Saves the result in a format that supports alpha transparency (such as PNG or WebP).

Dynamic Sizing with FX Expressions

To generate an anti-aliased circle on an image of any dimension without hardcoding pixel values, use ImageMagick's built-in FX expressions:

magick input.jpg -gravity center -crop "%[fx:min(w,h)]x%[fx:min(w,h)]+0+0" +repage \
\( +clone -alpha extract -draw "fill black polygon 0,0 0,0 fill white circle %[fx:w/2],%[fx:h/2] %[fx:w/2],0" \) \
-alpha off -compose CopyOpacity -composite output.png

This syntax automatically detects the smallest dimension of the input file, crops it into a square, and draws the circle mask using the calculated center and radius coordinates.
