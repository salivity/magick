Create Anti-Aliased Circular Avatars with ImageMagick

This article provides the exact command-line syntax required to crop any square or rectangular image into a smooth, anti-aliased circular avatar using ImageMagick. You will learn the optimal command for ImageMagick version 7, how to square the input image automatically, and how the underlying mask composition ensures clean, blur-free edges without jagged pixel artifacts.

The Standard ImageMagick v7 Command

To produce a high-quality circular avatar with smooth, anti-aliased edges, use the following magick command:

magick input.jpg \
  -gravity center \
  -extent "%[fx:min(w,h)]x%[fx:min(w,h)]" \
  \( +clone -alpha extract \
     -draw "fill black polygon 0,0 0,%[h] %[w],%[h] %[w],0" \
     -draw "fill white circle %[fx:w/2],%[fx:h/2] %[fx:w/2],0" \) \
  -alpha off -compose CopyOpacity -composite \
  avatar.png

Command Breakdown

  1. -gravity center: Sets the reference point to the center of the image so subsequent cropping operations are aligned symmetrically.
  2. -extent "%[fx:min(w,h)]x%[fx:min(w,h)]": Crops the input to a perfect 1:1 square based on whichever dimension (width or height) is smaller, preventing distortion.
  3. \( +clone ... \): Creates an isolated mask layer matching the dimensions of the cropped image.
  4. -draw "fill white circle ...": Draws a vector circle inside the mask. Because vector drawing in ImageMagick is anti-aliased by default, the boundary between white and black contains smooth semi-transparent transitions.
  5. -compose CopyOpacity -composite: Applies the generated grayscale circle as an alpha channel directly onto the source image, masking out everything outside the circle.
  6. avatar.png: Exports the final result in PNG format to preserve the transparent background around the avatar.

Legacy Syntax for ImageMagick v6

If you are using ImageMagick v6, replace magick with convert and use static pixel values or pre-cropped square inputs:

convert input.jpg -resize 200x200^ -gravity center -extent 200x200 \
  \( +clone -alpha extract \
     -draw "fill black polygon 0,0 0,200 200,200 200,0" \
     -draw "fill white circle 100,100 100,0" \) \
  -alpha off -compose CopyOpacity -composite \
  avatar.png
