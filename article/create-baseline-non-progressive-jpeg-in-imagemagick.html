Create Baseline Non-Progressive JPEG in ImageMagick

This guide explains how to generate baseline, non-progressive JPEG images using ImageMagick's interlace settings. By configuring the -interlace flag to none, you can ensure that output JPEG files render sequentially from top to bottom rather than gradually refining in multiple passes, making them compatible with legacy hardware, specific decoders, and embedded devices that do not support progressive encoding.

The Interlace Option for Baseline JPEG

ImageMagick controls progressive and baseline JPEG encoding via the -interlace command-line option. To create a baseline JPEG, the interlace type must be explicitly set to None (or none). Setting this value disables multi-scan progressive rendering and writes a standard sequential baseline DCT (Discrete Cosine Transform) stream.

Basic Command Syntax

For ImageMagick version 7, use the magick command:

magick input.png -interlace none output.jpg

If you are using ImageMagick version 6, use the convert command:

convert input.png -interlace None output.jpg

You can convert any supported input format—such as PNG, TIFF, or an existing progressive JPEG—into a baseline JPEG using this syntax.

Combining with Quality and Stripping Metadata

To optimize file size while maintaining a strict baseline format, specify the JPEG compression quality using -quality and strip unnecessary color profiles or EXIF metadata using -strip:

magick input.jpg -strip -quality 85 -interlace none baseline_output.jpg

Verifying Baseline Format

To confirm that the output JPEG is non-progressive, use ImageMagick's identify tool with verbose output:

magick identify -verbose baseline_output.jpg | grep Interlace

If the command was successful, the output will display:

Interlace: None

A value of None confirms that the image is encoded as a baseline, non-progressive JPEG. If the image were progressive, this field would display JPEG or Plane.
