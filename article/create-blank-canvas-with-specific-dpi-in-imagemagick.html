Create Blank Canvas with Specific DPI in ImageMagick

This guide explains how to generate a blank white canvas with exact physical dimensions (such as inches or centimeters) and a target dots-per-inch (DPI) resolution using the ImageMagick command line. It covers the required parameters, the calculation for converting physical units to pixels, and ready-to-use command examples for both ImageMagick v7 and v6.

The Dimension Formula

ImageMagick creates raster canvases using pixel values. To create an image that matches specific physical dimensions at a designated DPI, calculate the pixel dimensions using the following formulas:

  • For Inches: Pixels = Inches × DPI
  • For Centimeters: Pixels = (Centimeters / 2.54) × DPI

Command Syntax and Flags

To set both physical resolution metadata and canvas size, use these flags:

  • -units PixelsPerInch: Specifies that the density is measured in DPI (dots per inch).
  • -density <value>: Sets the target resolution metadata (e.g., 300).
  • -size <width>x<height>: Specifies the total canvas dimensions in calculated pixels.
  • xc:white (or canvas:white): Fills the created image with a solid white background.

Step-by-Step Examples

Example 1: 8 × 10 Inch Canvas at 300 DPI

  1. Calculate Dimensions:

    • Width: 8 in × 300 DPI = 2400 pixels
    • Height: 10 in × 300 DPI = 3000 pixels

  2. ImageMagick v7 Command:

    magick -units PixelsPerInch -density 300 -size 2400x3000 xc:white canvas_8x10.png

  3. ImageMagick v6 Command:

    convert -units PixelsPerInch -density 300 -size 2400x3000 xc:white canvas_8x10.png

Example 2: Standard A4 Canvas (210 × 297 mm) at 300 DPI

  1. Calculate Dimensions:

    • Width: (21.0 cm / 2.54) × 300 ≈ 2480 pixels
    • Height: (29.7 cm / 2.54) × 300 ≈ 3508 pixels

  2. Command:

    magick -units PixelsPerInch -density 300 -size 2480x3508 xc:white canvas_a4.png

Verifying the Output

To verify that the file was generated with the correct dimensions and DPI metadata, run the identify tool:

magick identify -format "%w x %h pixels, %x x %y %U\n" canvas_8x10.png

Output:

2400 x 3000 pixels, 300 x 300 PixelsPerInch
