Create Blank White Canvas with DPI in ImageMagick

Creating an empty white canvas with specific physical dimensions (like inches or centimeters) and a defined DPI (dots per inch) in ImageMagick requires setting the pixel density, specifying the units, and defining the total pixel dimensions calculated from your physical measurements. This guide details the formula to convert physical units to pixel sizes and provides the exact CLI commands needed to generate print-ready blank canvases.

The Conversion Formula

ImageMagick creates canvases based on pixel dimensions using the -size parameter, while the -density and -units flags embed the physical resolution metadata into the file. To get the required pixel dimensions, calculate them before running the command:

  • For Inches: Pixels = Inches × DPI
  • For Centimeters: Pixels = (Centimeters / 2.54) × DPI

Basic Command Syntax

In ImageMagick version 7, use the magick command (or convert for ImageMagick version 6):

magick -units PixelsPerInch -density <DPI> -size <Width_in_Pixels>x<Height_in_Pixels> xc:white <output_filename>

Parameter Breakdown:

  • -units PixelsPerInch: Specifies that the density metadata represents dots/pixels per inch.
  • -density <DPI>: Sets the target resolution metadata (e.g., 300).
  • -size <WIDTHxHEIGHT>: Defines the total canvas size in pixels.
  • xc:white (or canvas:white): Fills the new canvas with a solid white color.

Example 1: Standard Letter Size (8.5 × 11 Inches at 300 DPI)

  1. Calculate pixel dimensions:

    • Width: \(8.5 \times 300 = 2550\text{ px}\)
    • Height: \(11 \times 300 = 3300\text{ px}\)

  2. Run the command:

magick -units PixelsPerInch -density 300 -size 2550x3300 xc:white letter_300dpi.png

Example 2: A4 Size (21 × 29.7 Centimeters at 300 DPI)

  1. Calculate pixel dimensions:

    • Width: \((21 / 2.54) \times 300 \approx 2480\text{ px}\)
    • Height: \((29.7 / 2.54) \times 300 \approx 3508\text{ px}\)

  2. Run the command:

magick -units PixelsPerInch -density 300 -size 2480x3508 xc:white a4_300dpi.png

Example 3: Using Metric Density Units (Pixels Per Centimeter)

If your workflow strictly uses metric measurements, set -units PixelsPerCentimeter:

magick -units PixelsPerCentimeter -density 118.11 -size 2480x3508 xc:white a4_metric.png

(Note: 300 DPI is approximately equal to 118.11 pixels per centimeter).

Verifying the Output File

To verify that the physical dimensions and resolution were applied correctly, inspect the generated file with ImageMagick's identify command:

magick identify -verbose output_filename.png

Check the Geometry, Resolution, and Units fields in the output to confirm that the image matches your required dimensions and DPI settings.
