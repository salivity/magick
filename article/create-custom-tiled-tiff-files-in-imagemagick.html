Create Custom Tiled TIFF Files in ImageMagick

This guide explains how to generate tiled TIFF images with custom tile dimensions using ImageMagick. You will learn the exact -define flag required to configure custom tile widths and heights, examine practical command-line syntax, and review important formatting constraints defined by the TIFF specification.

The Tiled TIFF Define Flag

To generate a tiled TIFF with custom tile dimensions in ImageMagick, use the -define tiff:tile-geometry flag.

The syntax for this flag is:

-define tiff:tile-geometry=<width>x<height>

When this flag is passed to ImageMagick, the output TIFF is organized into regular rectangular tiles rather than standard horizontal strips. This is particularly useful for rapid panning, zooming, and partial rendering in large-format graphics, geospatial applications, and digital pathology.

Command-Line Examples

Basic Custom Tile Dimensions

To convert an image to a tiled TIFF with custom tiles measuring 256 pixels wide by 256 pixels high:

magick input.png -define tiff:tile-geometry=256x256 output.tif

(Note: In ImageMagick version 6, replace magick with convert.)

Adding Compression

Tiled TIFFs are often large, so applying lossless compression such as Deflate (ZIP) or LZW is recommended:

magick input.jpg -compress zip -define tiff:tile-geometry=512x512 output.tif

Pyramidal Tiled TIFF

To create a multi-resolution pyramidal tiled TIFF (often used in deep-zoom viewers), use the ptif: output format prefix alongside the tile geometry flag:

magick input.jpg -define tiff:tile-geometry=256x256 ptif:pyramid.tif

Dimensional Requirements

According to the Baseline TIFF 6.0 specification, both the tile width and tile length (height) must be multiples of 16 pixels. If you specify values that are not divisible by 16 (for example, 100x100), ImageMagick may automatically adjust or round the dimensions to the nearest valid multiple to maintain compatibility with standard TIFF readers. Common dimensions include 128x128, 256x256, and 512x512.
