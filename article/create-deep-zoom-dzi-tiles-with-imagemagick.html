Create Deep Zoom DZI Tiles with ImageMagick

This guide demonstrates how to generate Deep Zoom Image (DZI) pyramidal tiles using ImageMagick for multi-resolution viewers like OpenSeadragon. You will learn the structure of the DZI format, how to calculate pyramid zoom levels, how to slice images into standard tiles using ImageMagick commands, and how to create the accompanying XML descriptor file.

Understanding the DZI Structure

A Deep Zoom Image consists of two components:

  1. An XML descriptor file (image.dzi) that defines the image dimensions, tile size, overlap, and format.
  2. A folder (image_files/) containing subfolders for each zoom level (from 0 up to the maximum level \(N\)), where each subfolder contains the individual image tiles named in a {column}_{row}.jpg (or .png) format.

The maximum level \(N\) is calculated using the formula: \[\text{Max Level} = \lceil \log_2(\max(\text{Width}, \text{Height})) \rceil\]

Step 1: Create the DZI Metadata File

Create an XML file named image.dzi with your image's specifications.

<?xml version="1.0" encoding="UTF-8"?>
<Image xmlns="http://schemas.microsoft.com/deepzoom/2008"
  Format="jpg"
  Overlap="1"
  TileSize="254">
  <Size Width="8000" Height="6000"/>
</Image>
  • TileSize: The width and height of each tile (typically 254 or 256).
  • Overlap: The pixel overlap between adjacent tiles (standard is 1 for seamless rendering in viewers).
  • Format: The file extension (jpg or png).
  • Size: The exact width and height of the original full-resolution image.

Step 2: Generate Tiles Using ImageMagick

To generate the individual tile levels, ImageMagick resizes the source image down by powers of 2 for each level and crops it into tiles.

Command for a Single Level

For any given level, resize the source image to the target dimensions for that level, then crop into tiles with the specified size:

magick input.jpg -resize 8000x6000 -crop 256x256 \
  -set filename:tile "%[fx:page.x/256]_%[fx:page.y/256]" \
  +repage +adjoin "image_files/13/%[filename:tile].jpg"

Step 3: Complete Automation Script

Because DZI requires generating every level from 0 to the maximum level, use the following Bash script to automate the entire process with ImageMagick:

#!/bin/bash

INPUT="input.jpg"
OUTPUT_NAME="image"
TILE_SIZE=256
OVERLAP=0
FORMAT="jpg"

# 1. Get original dimensions
WIDTH=$(magick identify -format "%w" "$INPUT")
HEIGHT=$(magick identify -format "%h" "$INPUT")

# 2. Determine max dimension and calculate max zoom level
MAX_DIM=$(( WIDTH > HEIGHT ? WIDTH : HEIGHT ))
MAX_LEVEL=$(awk -v max="$MAX_DIM" 'BEGIN { print int(log(max)/log(2) + 0.999999) }')

# 3. Create directories
mkdir -p "${OUTPUT_NAME}_files"

# 4. Generate XML descriptor
cat <<EOF > "${OUTPUT_NAME}.dzi"
<?xml version="1.0" encoding="UTF-8"?>
<Image xmlns="http://schemas.microsoft.com/deepzoom/2008"
  Format="${FORMAT}"
  Overlap="${OVERLAP}"
  TileSize="${TILE_SIZE}">
  <Size Width="${WIDTH}" Height="${HEIGHT}"/>
</Image>
EOF

# 5. Generate pyramid levels and tiles
for (( LEVEL=MAX_LEVEL; LEVEL>=0; LEVEL-- ))
do
  mkdir -p "${OUTPUT_NAME}_files/${LEVEL}"
  
  # Calculate scale for the current level
  SCALE=$(awk -v l="$LEVEL" -v max="$MAX_LEVEL" 'BEGIN { print 0.5^(max - l) }')
  CUR_W=$(awk -v w="$WIDTH" -v s="$SCALE" 'BEGIN { print int(w * s + 0.5) }')
  CUR_H=$(awk -v h="$HEIGHT" -v s="$SCALE" 'BEGIN { print int(h * s + 0.5) }')
  
  # Ensure minimum dimensions are 1x1
  [ "$CUR_W" -lt 1 ] && CUR_W=1
  [ "$CUR_H" -lt 1 ] && CUR_H=1

  # Resize and slice into tiles
  magick "$INPUT" -resize "${CUR_W}x${CUR_H}!" \
    -crop "${TILE_SIZE}x${TILE_SIZE}" \
    -set filename:tile "%[fx:int(page.x/${TILE_SIZE})]_%[fx:int(page.y/${TILE_SIZE})]" \
    +repage +adjoin "${OUTPUT_NAME}_files/${LEVEL}/%[filename:tile].${FORMAT}"
done

Step 4: Verification

Once generated, your project structure should appear as follows:

├── image.dzi
└── image_files/
    ├── 0/
    │   └── 0_0.jpg
    ├── 1/
    │   └── 0_0.jpg
    ├── ...
    └── 13/
        ├── 0_0.jpg
        ├── 0_1.jpg
        └── ...

This output is fully compatible with deep-zoom image visualizers.
