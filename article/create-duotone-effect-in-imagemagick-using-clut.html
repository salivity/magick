Create Duotone Effect in ImageMagick Using CLUT

Duotone effects map the light and dark tonal values of a photograph onto two distinct colors, creating a stylized, modern aesthetic. By utilizing ImageMagick’s Color Look-Up Table (CLUT) feature, you can transform standard color photographs into clean, high-impact duotone images directly from the command line. This guide demonstrates how to prepare an image, generate a custom two-color gradient, and map it accurately onto your source visual.

How the CLUT Method Works

The -clut (Color Look-Up Table) operator replaces pixel values in an image by referencing a secondary gradient image. When a grayscale image is provided as the primary source, its lightness values—ranging from 0% (pure black) to 100% (pure white)—are mapped directly across the gradient from left to right. The darkest pixels take the first color of the gradient, while the brightest pixels take the second color, with midtones smoothly blended in between.

The Basic Duotone Command

To achieve a clean duotone effect, you must convert the source image to grayscale and apply a 1-dimensional gradient representing your two target colors.

Using ImageMagick 7, execute the following command:

magick input.jpg -colorspace Gray \( -size 1x256 gradient:"#1A1A40"-"#E056FD" \) -clut output.jpg

For ImageMagick 6, replace magick with convert.

Breaking Down the Command

  1. input.jpg: The original color image you want to transform.
  2. -colorspace Gray: Converts the source image to a clean grayscale baseline. This ensures lightness values are properly standardized across the image before mapping colors.
  3. \( -size 1x256 gradient:"#1A1A40"-"#E056FD" \): Creates an in-memory 1x256 pixel vertical gradient moving from the shadow color (#1A1A40) to the highlight color (#E056FD). You can replace these hex values with any CSS-compatible color names or hex codes.
  4. -clut: Applies the generated gradient across the tonal range of the grayscale image.
  5. output.jpg: The resulting duotone file.

Optimizing Contrast for Clean Results

Photographs with low dynamic range can produce muddy duotones. To ensure crisp highlights and deep shadows, normalize the tonal range with -auto-level or adjust contrast with -level prior to applying the CLUT:

magick input.jpg -colorspace Gray -auto-level \( -size 1x256 gradient:"#00204A"-"#F85A40" \) -clut output.jpg

If you want stronger contrast, you can fine-tune the black and white points using -level:

magick input.jpg -colorspace Gray -level 10%,90% \( -size 1x256 gradient:"#0B132B"-"#6FFFE9" \) -clut output.jpg

This method provides precise, repeatable, and scriptable duotone generation without the need for manual photo-editing software.
