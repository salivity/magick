Create Finite Loop Animated GIF in ImageMagick

This guide explains how to generate an animated GIF with a finite loop count using ImageMagick. By using the -loop setting alongside frame timing parameters, you can specify the exact number of times an animation plays before stopping on the final frame.

The ImageMagick Command

To create an animated GIF configured to repeat a finite number of times, use the -loop option followed by your desired iteration count (a positive integer).

For ImageMagick v7:

magick -delay 20 -loop 3 frame*.png output.gif

For ImageMagick v6 (Legacy):

convert -delay 20 -loop 3 frame*.png output.gif

Parameter Breakdown

  • magick / convert: Invokes the ImageMagick image manipulation tool.
  • -delay <ticks>: Sets the display duration for each frame in 1/100ths of a second. For example, -delay 20 creates a delay of 0.2 seconds (5 frames per second).
  • -loop <N>: Sets the number of playback cycles. Setting N to a positive integer (such as 1, 2, or 5) causes the GIF to play that exact number of times and then stop. Setting -loop 0 creates an infinite loop.
  • frame*.png: Specifies the input source images in sequential order. You can use wildcards or list individual files separated by spaces (frame1.png frame2.png frame3.png).
  • output.gif: Defines the name of the final generated GIF file.

Example: Playing an Animation Exactly Twice

If you have three images (img1.jpg, img2.jpg, img3.jpg) and want them to cycle twice with a half-second pause between frames:

magick -delay 50 -loop 2 img1.jpg img2.jpg img3.jpg animation.gif

Once generated, the GIF will cycle through the frames twice and stop permanently on the final image.
