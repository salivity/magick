Create HDR Radiance Images with ImageMagick

This article provides the exact commands and requirements for creating and converting images into the Radiance HDR format using ImageMagick. It covers the primary command-line syntax for both ImageMagick 7 and ImageMagick 6, explains how to explicitly specify the Radiance format, and highlights essential settings needed to preserve high dynamic range data.

Basic Command to Create a Radiance HDR Image

To convert an existing high-bit-depth image (such as EXR, TIFF, or PFM) into a Radiance HDR (.hdr) file, use the standard conversion syntax:

ImageMagick 7 (Current):

magick input.exr output.hdr

ImageMagick 6 (Legacy):

convert input.exr output.hdr

ImageMagick automatically identifies the Radiance format from the .hdr file extension.

Explicit Format Definition

If your output file does not use the .hdr extension, or to ensure ImageMagick explicitly uses the Radiance encoder, prepend the hdr: prefix to the output filename:

magick input.tiff hdr:output_file

Converting Standard LDR Images to Radiance HDR

You can also convert standard low dynamic range (LDR) images (like JPEG or PNG) into the Radiance HDR container, though dynamic range will be limited by the source file:

magick input.jpg -colorspace RGB output.hdr

Prerequisites and Best Practices

  1. HDRI Support: Ensure your ImageMagick installation was compiled with HDRI (High Dynamic Range Imaging) support enabled. In ImageMagick 7, HDRI is enabled by default. Check your installation by running:

    magick -version

    Look for HDRI in the Features line of the output.

  2. Color Space: Radiance HDR files store linear RGB values with a shared exponent (RGBE format). When converting from sRGB sources, converting the colorspace to linear RGB prevents tone clipping:

    magick input.png -colorspace RGB output.hdr
