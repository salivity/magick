Create Image Mosaic with Coordinates in ImageMagick

Creating an image mosaic using coordinate-positioned layers in ImageMagick allows you to arrange multiple images across a single canvas using precise pixel offsets. This guide explains how to define individual layer coordinates using the page geometry operator and merge them into a composite mosaic using both modern ImageMagick 7 and legacy ImageMagick 6 commands.

The Core Concept: Page Offsets

In ImageMagick, coordinates for mosaic layers are defined using the -page +X+Y geometry operator. The +X represents the horizontal pixel offset from the left edge of the canvas, while +Y represents the vertical pixel offset from the top edge.

When you assign a -page offset immediately before loading an image file, ImageMagick tags that image with those canvas coordinates.

Basic Syntax Using the Mosaic Operator

The -mosaic operator automatically determines the overall canvas size required to contain all positioned layers, initializes a canvas using the current -background color, and composites each image in sequential order.

In ImageMagick 7:

magick -background white \
  -page +0+0 image1.jpg \
  -page +150+50 image2.png \
  -page +300+200 image3.png \
  -mosaic output_mosaic.jpg

In ImageMagick 6:

convert -background white \
  -page +0+0 image1.jpg \
  -page +150+50 image2.png \
  -page +300+200 image3.png \
  -mosaic output_mosaic.jpg

Creating a Mosaic with a Fixed Canvas Size

If you need a canvas with predefined dimensions rather than an automatically calculated size, declare an explicit canvas size using -size and create a blank base layer (such as xc:none for transparency or xc:white for solid white):

magick -size 1920x1080 xc:white \
  -page +100+100 layer1.png \
  -page +600+100 layer2.png \
  -page +1100+400 layer3.png \
  -layers merge output_fixed.png

Using -layers merge vs. -mosaic

While -mosaic works consistently across versions, -layers merge is the modern and preferred approach in ImageMagick 7.

  • -mosaic: Always expands the canvas to fit the bounding box of all images, anchored at (0,0), filling empty space with the defined -background.
  • -layers merge: Respects negative offsets and canvas definitions set by base images, making it more flexible for complex layering pipelines.

Example with transparency using -layers merge:

magick -background none \
  -page +0+0 tile_top_left.png \
  -page +256+0 tile_top_right.png \
  -page +0+256 tile_bottom_left.png \
  -page +256+256 tile_bottom_right.png \
  -layers merge mosaic_transparent.png

Layer Order and Overlapping

Images are rendered in the order they are listed in the command. Subsequent layers will overlap earlier layers if their coordinate bounds intersect. To preserve image transparency when overlapping, ensure input formats support alpha channels (such as PNG or TIFF) and set -background none.
