Create ImageMagick Fade Transition Between Images

Creating an animated fading transition between two images in ImageMagick is achieved using the -morph command. This guide provides the exact command-line syntax required to interpolate frames between images, adjust animation speeds, set looping parameters, and create seamless crossfade animations in both ImageMagick v7 and v6.

Basic Fade Transition Syntax

In ImageMagick version 7, use the magick command along with -morph to generate in-between frames that blend the two images.

magick image1.jpg image2.jpg -delay 10 -morph 20 -loop 0 fade.gif

For ImageMagick version 6, use the convert command:

convert image1.jpg image2.jpg -delay 10 -morph 20 -loop 0 fade.gif

Parameter Breakdown

  • image1.jpg image2.jpg: The source images. Both images must have the exact same pixel dimensions.
  • -morph 20: The number of interpolated intermediate frames to create. A higher number produces a smoother fade, but increases file size.
  • -delay 10: The duration each frame is displayed, measured in hundredths of a second (ticks). 10 equals 100 milliseconds (0.10s) per frame.
  • -loop 0: Configures the GIF to loop infinitely. Set to 1 to play once without repeating.
  • fade.gif: The output animated image file name.

Creating a Seamless Looping Transition

To create a continuous fade where the second image smoothly fades back into the first image, list the initial image again at the end of the input sequence:

magick image1.jpg image2.jpg image1.jpg -delay 8 -morph 25 -loop 0 seamless_fade.gif

Adding a Pause on the Key Images

To prevent the animation from continuously fading without stopping, you can set a longer display time on the original images while keeping the transition frames fast:

magick image1.jpg -delay 150 \( image2.jpg -delay 150 \) -morph 20 -loop 0 paused_fade.gif
  • -delay 150: Holds the primary images for 1.5 seconds.
  • Intermediate morphed frames will automatically maintain a balanced transition speed between keyframes.
