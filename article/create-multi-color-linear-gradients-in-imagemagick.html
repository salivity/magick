Create Multi-Color Linear Gradients in ImageMagick

This guide explains the syntax and methods for creating multi-color linear gradient canvases using ImageMagick. You will learn the standard commands for modern ImageMagick versions, how to set custom color stops, adjust gradient angles, and utilize alternative methods for older versions.

Multi-Color Gradient Syntax (ImageMagick v7)

ImageMagick 7 natively supports multi-stop linear gradients using hyphen-separated color values with the gradient: protocol.

Basic Multi-Color Syntax

magick -size <width>x<height> gradient:"<color1>-<color2>-<color3>..." <output_filename>

Example: Horizontal Three-Color Gradient

magick -size 800x400 gradient:"#FF0000-#00FF00-#0000FF" output.png

You can use standard color names, hex codes, or RGB values:

magick -size 1200x600 gradient:"red-orange-yellow-green-blue-purple" rainbow.png

Controlling Gradient Direction and Angle

By default, linear gradients run from top to bottom (vertical). You can control the direction using the -define gradient:angle setting.

Syntax for Angled Gradients

magick -size <width>x<height> -define gradient:angle=<degrees> gradient:"<colors>" <output_filename>
  • 0 degrees: Bottom to top
  • 90 degrees: Left to right (Horizontal)
  • 180 degrees: Top to bottom
  • 270 degrees: Right to left
  • 45 degrees: Diagonal (bottom-left to top-right)

Example: Left-to-Right Multi-Color Gradient

magick -size 800x400 -define gradient:angle=90 gradient:"#ff7e5f-#feb47b-#86a8e7" gradient_horizontal.png

Controlling Color Stop Positions

ImageMagick allows you to specify custom offset percentages for individual colors to control where each transition takes place.

Syntax with Stop Positions

magick -size 800x400 gradient:"red-yellow:25%-green:75%-blue" stops_gradient.png
  • red begins at 0%
  • yellow peaks at 25%
  • green peaks at 75%
  • blue ends at 100%

Alternative Method: Using Sparse-Color (ImageMagick v6 and v7)

If you are using ImageMagick v6 or need precise pixel-coordinate control over linear interpolation, use the sparse-color operator with the Barycentric method.

Syntax

convert -size <width>x<height> xc: -sparse-color Barycentric "x1,y1 <color1>  x2,y2 <color2>  x3,y3 <color3>" <output_filename>

Example: 3-Point Horizontal Linear Gradient

convert -size 600x300 xc: -sparse-color Barycentric "0,0 red  300,0 yellow  599,0 blue" sparse_gradient.png
