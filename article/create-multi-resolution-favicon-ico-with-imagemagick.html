Create Multi-Resolution Favicon ICO with ImageMagick

Creating a multi-resolution .ico file ensures your website favicon renders crisply across various browsers, operating systems, bookmark bars, and desktop shortcuts. This guide provides the exact ImageMagick command needed to convert a single high-resolution source image into a multi-layered ICO file containing standard web dimensions, along with the recommended settings for optimal quality.

The ImageMagick Command

To generate a multi-resolution ICO file from a single high-resolution input image (such as a 512x512 PNG), run the following command:

For ImageMagick v7+:

magick input.png -define icon:auto-resize=64,48,32,16 favicon.ico

For ImageMagick v6 (Legacy):

convert input.png -define icon:auto-resize=64,48,32,16 favicon.ico

How the Command Works

  • input.png: Your source file. It should be a square image with a transparent background, preferably at least 512x512 pixels.
  • -define icon:auto-resize=64,48,32,16: Instructs ImageMagick to automatically downscale the input image and embed four distinct resolution layers into a single .ico container.
  • favicon.ico: The output file name.

Standard Resolutions Included

The embedded sizes serve specific display environments across the web:

  • 16x16: Standard browser tabs and address bars.
  • 32x32: High-DPI/Retina browser tabs, desktop shortcuts, and "New Tab" pages.
  • 48x48: Windows taskbar and desktop icons.
  • 64x64: High-resolution operating system shortcuts and modern high-DPI displays.

Verifying the Multi-Resolution File

To confirm that the output .ico file contains all specified resolutions, run:

magick identify favicon.ico

The output will list four separate entries for favicon.ico corresponding to the 16x16, 32x32, 48x48, and 64x64 layers.
