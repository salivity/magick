Create Multi-Resolution ICO Files with ImageMagick

This guide explains how to generate a multi-resolution Windows icon (.ico) file from an image using ImageMagick. You will learn the exact command-line syntax for both ImageMagick v7 and legacy versions, how to automatically scale a high-resolution master image to standard Windows sizes, and how to assemble separate resolution layers into a single .ico container.

The Recommended Syntax (ImageMagick v7)

The most efficient way to generate a multi-resolution .ico file is to use a high-resolution square image (such as a 256x256 or 512x512 PNG) and let ImageMagick automatically downscale the required dimensions using the icon:auto-resize define:

magick input.png -define icon:auto-resize=256,128,64,48,32,16 favicon.ico

Legacy Syntax (ImageMagick v6)

If you are using ImageMagick version 6, replace magick with the convert command:

convert input.png -define icon:auto-resize=256,128,64,48,32,16 favicon.ico

Syntax for Pre-Rendered Images

If you have manually crafted, pixel-optimized icons for each individual size rather than relying on automated downscaling, you can combine multiple distinct files into a single .ico file by listing them sequentially:

magick icon-256.png icon-128.png icon-64.png icon-48.png icon-32.png icon-16.png output.ico

Key Parameter Breakdown

  • magick: The primary executable command in ImageMagick v7+.
  • input.png: The master source image. For best results, use a transparent PNG of at least 256x256 pixels.
  • -define icon:auto-resize=...: Instructs the ICO coder to generate embedded sub-images at the specified comma-separated pixel dimensions.
  • Standard Sizes:
    • 256×256: Used for large and extra-large Windows Explorer folder/app views.
    • 48×48 / 64×64: Used for desktop icons and medium views.
    • 32×32: Standard size for taskbars, file explorer lists, and Control Panel items.
    • 16×16: System tray notifications, browser tabs (favicons), and small list details.
  • output.ico: The destination Windows Icon file containing all generated resolutions.
