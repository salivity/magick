Create Offset Radial Gradients in ImageMagick

Creating a radial gradient with an offset center in ImageMagick allows you to produce dynamic lighting effects, custom vignettes, and asymmetrical backgrounds. This guide demonstrates how to reposition the focal point of a radial gradient using ImageMagick's built-in gradient definitions and command-line options.

Using -define gradient:center

The most direct way to offset the center of a radial gradient in ImageMagick (version 6.9.2-5 and newer, including ImageMagick 7) is by using the -define gradient:center setting.

Basic Command Syntax

magick -size 600x400 -define gradient:center=150,100 radial-gradient:white-black offset_gradient.png

(Note: For ImageMagick 6, replace magick with convert.)

Parameter Breakdown

  • -size 600x400: Defines the canvas width and height in pixels.
  • -define gradient:center=150,100: Sets the origin (center point) of the gradient at coordinates X=150, Y=100 rather than the default canvas center (300, 200).
  • radial-gradient:white-black: Specifies the start and end colors. The gradient begins at the offset center point with the first color (white) and radiates outward to the second color (black).
  • offset_gradient.png: The name of the output image file.

Controlling Gradient Extent and Shape

By default, the gradient radius expands to the furthest corner of the canvas. You can constrain or reshape the gradient using -define gradient:radii.

magick -size 600x400 \
  -define gradient:center=200,150 \
  -define gradient:radii=150,150 \
  radial-gradient:#ffcc00-#003366 \
  custom_radius.png
  • gradient:radii=150,150: Forces the gradient to reach its ending color at an explicit horizontal and vertical radius of 150 pixels from the offset center, creating a circular fade.
  • Different X and Y values (e.g., gradient:radii=300,150) will produce an elliptical offset gradient.

Using Percentage Coordinates

You can also define coordinates as percentages instead of absolute pixels to make scripts responsive to different canvas sizes:

magick -size 800x600 \
  -define gradient:center=25%,25% \
  radial-gradient:rgba(255,255,255,1)-rgba(0,0,0,0) \
  offset_spotlight.png

This places the center 25% from the left and 25% from the top, fading from an opaque white center into full transparency at the edges.
