Create Outlined Font Glyphs with ImageMagick

This article provides a direct guide on using ImageMagick to create outlined font glyphs with the -stroke and -strokewidth settings. You will learn the exact command-line syntax required to define the outline color, control line thickness, and manipulate the interior fill to achieve either solid-filled text with an outline or completely hollow glyphs.

Basic Syntax for Outlined Text

In ImageMagick, outlining text requires defining the outline color with -stroke, the border thickness with -strokewidth, and the interior color with -fill.

The general syntax using modern ImageMagick (v7) is:

magick -size [width]x[height] xc:[background_color] \
  -font [font_name_or_path] \
  -pointsize [size] \
  -fill [fill_color] \
  -stroke [stroke_color] \
  -strokewidth [pixels] \
  -annotate +[x]+[y] "[Your Text]" \
  output.png

If you are using ImageMagick v6, replace the initial magick with convert.

Key Parameters Explained

  • -stroke [color]: Sets the color of the glyph's outline. You can use standard color names (e.g., black, red) or hex values (e.g., "#000000").
  • -strokewidth [integer/float]: Specifies the thickness of the outline in pixels. A value of 1 or 2 provides a subtle border, while larger values create bold, heavy outlines.
  • -fill [color]: Determines the color inside the glyph. Setting this to none leaves the inside of the font hollow, rendering only the outline.

Example 1: Text with a Fill and an Outline

To generate white text with a 2-pixel black outline on a gray background:

magick -size 600x200 xc:lightgray \
  -gravity center \
  -font Arial \
  -pointsize 48 \
  -fill white \
  -stroke black \
  -strokewidth 2 \
  -annotate +0+0 "Outlined Text" \
  filled_outline.png

Example 2: Hollow Outlined Font (No Fill)

To create text that only renders the outline without any interior color, set -fill to none:

magick -size 600x200 xc:white \
  -gravity center \
  -font Arial \
  -pointsize 48 \
  -fill none \
  -stroke navy \
  -strokewidth 3 \
  -annotate +0+0 "Hollow Glyphs" \
  hollow_outline.png

Example 3: Using the label: Operator

Alternatively, you can use the label: format to let ImageMagick automatically size the canvas around the text:

magick -background lightblue \
  -font Arial \
  -pointsize 64 \
  -fill yellow \
  -stroke red \
  -strokewidth 2 \
  label:"Quick Label" \
  label_outline.png

Important Usage Notes

  1. Stroke Alignment: ImageMagick draws strokes centered on the vector path of the font glyph. As -strokewidth increases, the stroke expands both outward and inward, which can cover up the interior -fill color if the stroke width is too large relative to the -pointsize.
  2. Order of Operations: Place -stroke, -strokewidth, and -fill before the -annotate or label: directive so the rendering engine applies these properties correctly.
