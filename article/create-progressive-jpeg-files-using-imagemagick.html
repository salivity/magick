Create Progressive JPEG Files Using ImageMagick

Progressive JPEG files improve perceived page load times by rendering a low-resolution preview of an image immediately, then progressively adding detail as the full data downloads. This guide covers how to use ImageMagick's command-line interface to encode single or batch images into progressive JPEGs using specific encoding flags.

The Interlace Flag

The primary flag used in ImageMagick to create a progressive JPEG is -interlace Plane. When applied to JPEG output, this flag structures the image data in progressive scans instead of a single top-to-bottom scan (baseline).

ImageMagick v7 Syntax

magick input.jpg -interlace Plane output_progressive.jpg

ImageMagick v6 (Legacy) Syntax

convert input.jpg -interlace Plane output_progressive.jpg

Optimizing Progressive JPEGs

To achieve optimal web performance, combine the interlacing flag with compression and metadata removal flags.

magick input.png -strip -quality 85 -interlace Plane output.jpg

Key flags used in this command:

  • -strip: Removes all metadata (EXIF, IPTC, color profiles) to reduce file size.
  • -quality 85: Sets the compression level to balance visual quality and file weight.
  • -interlace Plane: Encodes the file as a progressive JPEG.

Verifying Progressive JPEG Output

You can verify that the output file is progressive using ImageMagick's identify tool:

magick identify -verbose output_progressive.jpg | grep Interlace

If successful, the output will display:

Interlace: JPEG

(Note: Output may also show Interlace: Plane depending on the ImageMagick build).

Batch Processing Multiple Files

To convert an entire directory of JPEG or PNG images into progressive JPEGs:

Linux / macOS (Bash)

for file in *.jpg; do
  magick "$file" -strip -quality 85 -interlace Plane "progressive_${file}"
done

Windows (Command Prompt)

for %f in (*.jpg) do magick "%f" -strip -quality 85 -interlace Plane "progressive_%f"
