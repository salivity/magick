Create Progressive JPEGs Using ImageMagick

Progressive JPEGs improve perceived page load speeds on the web by rendering a low-resolution preview that sharpens as the image downloads, rather than loading scanlines from top to bottom. This guide covers how to use ImageMagick's encoding flags to convert standard images into web-optimized progressive JPEGs via the command line.

The Interlace Flag

The primary flag used to generate a progressive JPEG in ImageMagick is -interlace Plane. This instructs the encoder to store the image data in progressive scans.

Basic Conversion Syntax

For ImageMagick v7, use the magick command:

magick input.jpg -interlace Plane output_progressive.jpg

If you are using ImageMagick v6, use the legacy convert command:

convert input.jpg -interlace Plane output_progressive.jpg

Full Web Optimization Example

To optimize a JPEG for web delivery, combine the progressive flag with compression, metadata stripping, and chroma subsampling:

magick input.png -strip -interlace Plane -sampling-factor 4:2:0 -quality 85 output.jpg
  • -strip: Removes all profiles, EXIF metadata, and comments to reduce file size.
  • -interlace Plane: Enables progressive encoding.
  • -sampling-factor 4:2:0: Sets standard chroma subsampling for photographic web content.
  • -quality 85: Sets a balanced visual quality and file size ratio.

Batch Processing Multiple Files

To convert an entire directory of JPEG files in place, use the mogrify command:

mogrify -strip -interlace Plane -quality 85 *.jpg

Verifying Progressive Encoding

To verify that the output file is progressive, run the identify command:

magick identify -verbose output.jpg | grep Interlace

If successful, the output will display:

Interlace: JPEG

(or Interlace: Plane depending on the ImageMagick build)
