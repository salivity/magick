Create Pyramidal TIFF Files with ImageMagick

Pyramidal TIFF files store an image at multiple resolution levels, allowing high-resolution viewers to load large images quickly without loading the full file into memory. This guide explains the exact ImageMagick commands and parameters required to convert standard images into tiled pyramidal TIFF (PTIF) files efficiently.

The Basic Command

ImageMagick includes a built-in output delegate specifically for pyramidal TIFFs designated by the ptif: prefix.

ImageMagick v7

magick input.jpg -define tiff:tile-geometry=256x256 ptif:output.tif

ImageMagick v6

convert input.jpg -define tiff:tile-geometry=256x256 ptif:output.tif

Parameter Breakdown

  • ptif:: The output prefix that instructs ImageMagick to generate a Pyramidal TIFF. It automatically creates sub-sampled layers (each typically half the dimensions of the previous) down to a base thumbnail.
  • -define tiff:tile-geometry=256x256: Sets the dimensions of the internal tiles. While 256x256 is standard for web map viewers (like OpenLayers, Leaflet, or OpenSeadragon), you can adjust this to 512x512 if required.

Adding Compression

Uncompressed pyramidal TIFF files can be exceptionally large. To reduce file size, apply compression alongside your conversion command.

Deflate (Lossless)

Best for scientific imagery, graphics, or preservation:

magick input.jpg -define tiff:tile-geometry=256x256 -compress zip ptif:output.tif

JPEG Compression (Lossy)

Best for large photographic scans to optimize web delivery:

magick input.jpg -define tiff:tile-geometry=256x256 -compress jpeg -quality 85 ptif:output.tif

Verifying the Pyramidal TIFF Structure

To confirm the output contains the tiled pyramid structure, run the identify command:

magick identify output.tif

The output will list multiple resolution layers starting from the full resolution image down to the smallest pyramid level, confirming the file is properly tiled and multi-layered.
