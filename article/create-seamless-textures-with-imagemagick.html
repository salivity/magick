Create Seamless Textures with ImageMagick

Creating seamless, tileable textures from photos is essential for 3D modeling, game development, and web design. This guide explains how to convert standard photos into repeating patterns using ImageMagick by flattening uneven lighting, offsetting image boundaries, and blending the resulting seams smoothly.

1. Flatten Uneven Lighting

Natural photos often contain lighting gradients, shadows, or vignetting that create obvious grid artifacts when repeated. Remove low-frequency lighting variations using a high-pass filter technique before attempting to blend edges:

magick input.jpg \( +clone -blur 0x50 \) +swap -compose Divide -composite -auto-level flat_lighting.jpg

This divides the original photo by a heavily blurred version of itself, neutralizing broad shadows while preserving fine surface details.

2. Offset the Image Boundaries

To fix the visible seams between repeating tiles, shift the image by 50% horizontally and 50% vertically using the -roll command. This moves the outer edges into the center of the image canvas where they can be blended.

magick flat_lighting.jpg -roll +50%+50% centered_seams.jpg

3. Blend the Center Seams

Once the edges meet at the center, blend them using an alpha-gradient mask to hide the hard transition lines.

You can automate this blending process by overlapping the edges with a single ImageMagick composite sequence:

magick flat_lighting.jpg \
  \( +clone -roll +50%+0% \) \
  \( -size 100x100 gradient: -rotate 90 -resize %[w]x%[h]! -solarize 50% -level 0,50% \) \
  -composite \
  \( +clone -roll +0%+50% \) \
  \( -size 100x100 gradient: -resize %[w]x%[h]! -solarize 50% -level 0,50% \) \
  -composite seamless_texture.jpg

Command Breakdown:

  • -roll +50%+0%: Shifts the image horizontally.
  • gradient: ... -solarize 50%: Generates a linear blend mask centered on the seam line.
  • -composite: Blends the rolled version over the base using the mask.
  • -roll +0%+50%: Repeats the operation vertically.

4. Complete One-Line Automation

To process a raw photo directly into a seamless, lighting-corrected texture in a single command, combine the steps:

magick input.jpg \
  \( +clone -blur 0x64 \) +swap -compose Divide -composite -auto-level \
  \( +clone -roll +50%+0% \) \
  \( -size 100x100 gradient: -rotate 90 -resize %[w]x%[h]! -solarize 50% -level 0,50% \) \
  -composite \
  \( +clone -roll +0%+50% \) \
  \( -size 100x100 gradient: -resize %[w]x%[h]! -solarize 50% -level 0,50% \) \
  -composite output_seamless.jpg

5. Verify the Result

Test how well the texture repeats by creating a 2x2 tiled grid preview:

magick output_seamless.jpg -write mpr:tile +delete -size 200%x200% tile:mpr:tile test_grid.jpg

Inspect test_grid.jpg to verify that all seams and lighting variations have been eliminated.
