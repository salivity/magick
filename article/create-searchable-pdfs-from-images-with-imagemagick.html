Create Searchable PDFs from Images with ImageMagick

Creating a searchable PDF from a collection of images requires both an image-processing utility and an Optical Character Recognition (OCR) engine. While ImageMagick is ideal for combining and enhancing images into a standard PDF, it outputs pure raster graphics without an embedded text layer. To make the resulting document fully searchable, you must pair ImageMagick’s image-merging capabilities with an OCR tool like OCRmyPDF or Tesseract.

Why ImageMagick Alone Is Not Enough

ImageMagick treats every input as pixels. When you run a command like magick *.jpg output.pdf, it packages the raster images into a PDF wrapper, but it cannot analyze the shapes of letters or create selectable, searchable text.

Furthermore, you should avoid using ImageMagick to merge PDF pages that already contain OCR text, as ImageMagick rasterizes input PDFs via Ghostscript by default, destroying any existing text layer. The standard, effective pipeline is to use ImageMagick to optimize and merge the raw images, then apply OCR to inject the hidden text layer.

Step 1: Optimize and Merge Images Using ImageMagick

Before running OCR, clean up your scanned images to improve text recognition accuracy, then compile them into an initial PDF document.

Open your terminal and run:

magick convert *.jpg -deskew 40% -contrast-stretch 0.15x0.05% temp_merged.pdf
  • -deskew 40%: Automatically straightens crooked scans.
  • -contrast-stretch: Enhances text contrast by whitening the background and darkening the text.
  • temp_merged.pdf: The intermediate, non-searchable PDF file.

If your images are already clean and oriented properly, you can combine them directly:

magick convert page1.png page2.png page3.png temp_merged.pdf

Step 2: Add Searchable Text Layer with OCRmyPDF

The most reliable way to turn the intermediate PDF into a searchable document is using OCRmyPDF, a command-line tool built on top of the Tesseract OCR engine.

  1. Install OCRmyPDF (via Homebrew on macOS, or apt on Ubuntu/Debian):

    • macOS: brew install ocrmypdf
    • Linux: sudo apt install ocrmypdf

  2. Generate the searchable PDF:

    ocrmypdf temp_merged.pdf final_searchable.pdf

OCRmyPDF inspects the pages, extracts the text using Tesseract, and layers invisible, selectable text directly over your original images without re-compressing them unnecessarily.

Alternative Method: Direct Processing with Tesseract

If you prefer not to create an intermediate merged PDF, you can use Tesseract directly to convert each image into an individual searchable PDF, then merge them using a tool like pdfunite.

  1. Convert images to single-page searchable PDFs:

    for img in *.jpg; do
    tesseract "$img" "${img%.*}" pdf
done

    This generates a .pdf file for every .jpg image, complete with an embedded text layer.

  2. Combine the searchable PDFs without losing the text: Use pdfunite (part of the Poppler utility suite) instead of ImageMagick so the text layer is preserved:

    pdfunite page1.pdf page2.pdf page3.pdf final_searchable.pdf

Verification

Open final_searchable.pdf in any standard PDF reader (such as Adobe Acrobat, Preview, or a web browser). Test the document by pressing Ctrl+F (or Cmd+F on macOS) to search for a word, or click and drag your cursor to highlight and copy text directly from the scanned pages.
