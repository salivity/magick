Create Transparent Gradient Mask in ImageMagick

Creating a transparent-to-color gradient mask in ImageMagick allows you to smoothly blend images into transparency or create fading color overlays. This guide demonstrates how to generate a linear or radial gradient transitioning from a fully transparent state to a solid color using simple command-line syntax in both ImageMagick v7 and v6.

Generating a Basic Transparent-to-Color Gradient

The simplest way to create a transparent-to-color gradient is to define the canvas size and specify the gradient colors using none (or transparent) for the fully transparent end, followed by your target color.

magick -size 600x400 gradient:none-black transparent_to_black.png

For ImageMagick v6, replace magick with convert:

convert -size 600x400 gradient:none-black transparent_to_black.png

To use a specific hex code or RGBA color:

magick -size 600x400 gradient:"rgba(255,0,0,0)-#ff0000" transparent_to_red.png

Changing Gradient Direction

By default, ImageMagick generates vertical gradients (top to bottom). You can alter the direction by rotating the generated canvas or using built-in rotation options.

Horizontal Gradient (Left to Right)

Generate the gradient with swapped dimensions and rotate it 90 degrees:

magick -size 400x600 gradient:none-blue -rotate 90 horizontal_gradient.png

Bottom to Top Gradient

Invert the color order in the definition:

magick -size 600x400 gradient:blue-none bottom_to_top.png

Creating a Radial Transparent-to-Color Gradient

To create a circular vignette effect where the center is transparent and the outer edges fade into a solid color, use radial-gradient::

magick -size 500x500 radial-gradient:none-black radial_mask.png

If you want the center to be solid and the edges to fade out into transparency, reverse the color order:

magick -size 500x500 radial-gradient:black-none radial_fade_out.png

Applying a Transparent Gradient Mask to an Existing Image

To fade an existing image into transparency using a gradient mask, create a grayscale gradient representing the alpha values (white is opaque, black is transparent) and composite it with the CopyOpacity operator.

magick input.jpg \( -size 600x400 gradient:white-black \) -alpha off -compose CopyOpacity -composite output_faded.png

In this command:

  • gradient:white-black defines the opacity levels across the canvas.
  • -alpha off ensures the mask only reads grayscale luminosity.
  • -compose CopyOpacity -composite transfers the grayscale map directly into the image's alpha channel.
