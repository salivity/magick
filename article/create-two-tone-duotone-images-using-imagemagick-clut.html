Create Two-Tone Duotone Images Using ImageMagick CLUT

This guide provides a straightforward method to transform any photograph into a pure, high-contrast duotone image using ImageMagick’s Color Look-Up Table (-clut) operator. You will learn the mechanics behind the CLUT replacement process, the standard command-line syntax for ImageMagick v7 and v6, and how to define custom dual-color gradients to produce striking, consistent two-tone visual assets.

How ImageMagick CLUT Works

A Color Look-Up Table (CLUT) works by replacing the brightness levels of an image with specific colors mapped from a custom gradient or palette. When an image is reduced to grayscale, its pixel values range from pure black (luminance 0) to pure white (luminance 1). ImageMagick maps the darkest pixels to the starting color of your gradient and the lightest pixels to the ending color, automatically interpolating the midtones between them.

The Basic Duotone Command

To generate a pure duotone, you must convert the base image to grayscale and apply an inline 1D gradient.

ImageMagick Version 7 Syntax

magick input.jpg -colorspace Gray \
  \( -size 1x256 gradient:"#0D2040"-"#F25C54" \) \
  -clut output.jpg

ImageMagick Version 6 Syntax

convert input.jpg -colorspace Gray \
  \( -size 1x256 gradient:"#0D2040"-"#F25C54" \) \
  -clut output.jpg

Command Breakdown

  • input.jpg -colorspace Gray: Converts the source photo to a linear grayscale representation, ensuring that color brightness dictates the gradient distribution.
  • \( -size 1x256 gradient:"#0D2040"-"#F25C54" \): Constructs a temporary 256-pixel vertical color ramp. The first hexadecimal value (#0D2040) represents the shadows, and the second value (#F25C54) represents the highlights.
  • -clut: The Color Look-Up Table operator that evaluates the luminance of each pixel in the primary image and replaces it with the corresponding color from the generated gradient ramp.
  • output.jpg: The path to save the final duotone image.

Optimizing Duotone Contrast

To achieve a bolder, cleaner two-tone look, maximize the contrast of the grayscale base before applying the -clut operator. Adding -auto-level stretches the source image's tonal range so the darkest points hit 0% and the lightest hit 100%.

magick input.jpg -colorspace Gray -auto-level \
  \( -size 1x256 gradient:"#1A1A24"-"#00E5FF" \) \
  -clut output_high_contrast.jpg

Customizing Shadow and Highlight Colors

You can swap out hexadecimal codes for standard CSS color names or RGB values. Always place the darker (shadow) color first and the lighter (highlight) color second to maintain natural photographic shading:

  • Navy and Gold: gradient:"#001F3F"-"#FFDC00"
  • Forest Green and Peach: gradient:"#1B4332"-"#FFB5A7"
  • Deep Purple and Neon Green: gradient:"#2B0938"-"#39FF14"

To invert the effect (creating a negative duotone), reverse the order of the two colors in the gradient definition.
