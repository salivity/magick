Create Vignette with Radial Masks in ImageMagick

This guide explains how to create an automatic, dimension-independent vignette effect on any image using radial masks in ImageMagick. By dynamically generating a radial gradient sized to the input image and compositing it via blending modes, you can produce clean, customizable vignette edges without hardcoding width or height values.

The Standard Syntax (ImageMagick v7)

The most efficient command for creating an automatic radial mask vignette uses the Multiply composite operator combined with dynamic geometry expressions:

magick input.jpg ( +clone -sparse-color Radial "%[fx:w/2],%[fx:h/2] white %[fx:w/2],0 black" ) -compose Multiply -composite output.jpg

For a softer, elliptical falloff using the radial-gradient: generator dynamically:

magick input.jpg ( -clone 0 -fill black -colorize 100% -size "%[w]x%[h]" radial-gradient:none-black ) -compose Over -composite output.jpg

Alternative Syntax (ImageMagick v6)

In ImageMagick 6, dynamic calculation requires retrieving image dimensions directly or using standard layer-cloning techniques:

convert input.jpg ( +clone -background black -shadow 100x20+0+0 ) -compose Multiply -composite output.jpg

Or using an explicit radial-gradient canvas matching the source dimensions:

convert input.jpg ( -size "%[fx:w]x%[fx:h]" radial-gradient:none-black ) -composite output.jpg

Parameter Breakdown

  • +clone: Creates a working copy of the input image in memory to ensure identical dimensions and aspect ratio.
  • -sparse-color Radial: Dynamically generates a radial gradient originating from the center coordinates (%[fx:w/2],%[fx:h/2]) with a white inner radius transitioning to a black outer boundary (%[fx:w/2],0).
  • radial-gradient:none-black: Generates a gradient from transparent center (none) to solid black at the furthest edge, preserving the original image center while darkening the perimeter.
  • -compose Multiply: Multiplies the color values of the source image by the mask. White areas (value 1.0) leave pixels unchanged, while black areas (value 0.0) darken pixels to pure black.
  • -composite: Merges the generated mask back onto the base image.

Customizing the Effect

Adjusting Vignette Radius and Intensity

To shift the falloff further toward the borders, modify the color stopping points:

magick input.jpg ( +clone -sparse-color Radial "%[fx:w/2],%[fx:h/2] white %[fx:w*0.75],0 black" ) -compose Multiply -composite output.jpg

Creating a White or High-Key Vignette

To create a high-key (white) vignette rather than a dark frame, use radial-gradient:none-white:

magick input.jpg ( -clone 0 -size "%[w]x%[h]" radial-gradient:none-white ) -compose Over -composite output.jpg
