Crop and Center Images in ImageMagick

This guide explains how to resize, crop, and center an image using ImageMagick's geometry conventions. You will learn how the hash mark (#) geometry flag operates in ImageMagick ecosystems to produce centered thumbnail crops, how it translates into native Command Line Interface (CLI) commands, and how to execute the process efficiently.

Understanding the # Geometry Flag

In ImageMagick processing libraries and wrappers (such as Paperclip, CarrierWave, and MiniMagick), appending a hash mark (#) to a geometry string (for example, 300x300#) indicates a "resize to fill and center crop" operation.

This flag instructs the processor to:

  1. Scale the image proportionally so that the smaller dimension matches the target dimension, completely filling the designated box.
  2. Align the focal point to the center.
  3. Crop out any overflowing edges evenly from both sides or top and bottom.

Using the Syntax in Wrappers and Configuration

If you are using an ImageMagick integration library or API that recognizes the # modifier, specify the target width and height followed by #:

300x200#
  • Target dimensions: 300 pixels wide by 200 pixels high.
  • Behavior: The source image will be scaled so that it covers the entire 300x200 area without distorting aspect ratio, then trimmed around the center.

Executing the Command in the Standard ImageMagick CLI

Native ImageMagick CLI tools (magick in ImageMagick 7 or convert in ImageMagick 6) do not use # directly on the command line because the hash character is interpreted as a shell comment. Instead, the native CLI accomplishes the exact same # behavior by combining the fill flag (^), center gravity, and a centered crop.

ImageMagick 7 Syntax:

magick input.jpg -resize "300x300^" -gravity center -crop 300x300+0+0 +repage output.jpg

ImageMagick 6 Syntax:

convert input.jpg -resize "300x300^" -gravity center -crop 300x300+0+0 +repage output.jpg

Breakdown of the Native Commands

  • -resize "300x300^": The caret (^) flag acts as the minimum dimension specifier. It scales the image proportionally so that both width and height are at least equal to the specified target dimensions, preventing empty space. Quotes prevent shell interpretation of the ^ symbol.
  • -gravity center: Sets the reference point for subsequent operations to the absolute center of the canvas.
  • -crop 300x300+0+0: Trims the image to the exact dimensions specified. The +0+0 offset ensures the cut is made relative to the center anchor established by -gravity.
  • +repage: Strips the virtual canvas coordinates from the output image, ensuring compatibility across web browsers and viewer software.

Alternative Method Using -extent

Another way to reproduce the # geometry flag in the CLI is using -extent:

magick input.jpg -resize "300x300^" -gravity center -extent 300x300 output.jpg

-extent automatically adjusts the image canvas around the specified gravity point to fit the final dimensions without requiring canvas repaging.
