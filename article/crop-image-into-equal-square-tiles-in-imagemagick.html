Crop Image into Equal Square Tiles in ImageMagick

Splitting an image into equal square tiles is a common task for game development, mapping, web optimization, and print preparation. This guide provides the exact ImageMagick commands required to slice any image into uniform square dimensions, explaining how the parameters work to produce cleanly indexed output files.

The Basic Command for Fixed-Size Square Tiles

To crop an image into square tiles of a specific pixel dimension (for example, 256x256 pixels), use the -crop option followed by +repage:

magick input.jpg -crop 256x256 +repage tile_%d.jpg

(Note: If you are using ImageMagick version 6, replace magick with convert.)

How the Command Works

  • input.jpg: The source image you want to split.
  • -crop 256x256: Specifies the target width and height for each tile. ImageMagick automatically starts from the top-left corner and creates a grid across the entire canvas.
  • +repage: Resets the virtual canvas coordinate metadata. This ensures each generated tile acts as an independent image rather than retaining the canvas offsets of the original file.
  • tile_%d.jpg: Defines the output naming format. The %d placeholder automatically numbers the tiles sequentially (e.g., tile_0.jpg, tile_1.jpg).

Formatting the Output Filenames

You can control how the numbers are formatted in your output files using standard printf notation:

  • Zero-padded numbers: Use %02d or %03d to maintain consistent filename lengths (e.g., tile_001.jpg, tile_002.jpg): 
    magick input.jpg -crop 256x256 +repage tile_%03d.jpg

Cropping by Equal Grid Count Instead of Pixels

If you want to divide an image into an equal number of grid sections rather than specifying pixel sizes, use the @ symbol. For example, to split an image into a 3x3 grid (9 equal sections):

magick input.jpg -crop 3x3@ +repage tile_%d.jpg

If the original image is a perfect square, this command will produce perfectly equal square tiles.
