Crop Images into Equal Quadrants Using ImageMagick

This guide explains how to split an image into multiple equal quadrants or tiles using ImageMagick's built-in crop syntax. By utilizing the @ tile modifier within the -crop parameter, you can automatically divide any image into an even grid—such as a four-quadrant 2x2 layout—without needing to manually calculate pixel dimensions or coordinates.

The Basic Quadrant Crop Command

To split an image into four equal quadrants (a 2x2 grid), use the -crop operator with the 2x2@ geometry specification:

magick input.jpg -crop 2x2@ +repage quadrant_%d.jpg

(Note: If you are using ImageMagick version 6, replace magick with convert.)

Command Breakdown

  • input.jpg: The source image you want to divide.
  • -crop 2x2@: The @ symbol instructs ImageMagick to treat the preceding numbers as a grid layout (columns x rows) rather than pixel dimensions. 2x2@ cuts the image into two equal columns and two equal rows, producing four equal quadrants.
  • +repage: Resets the canvas offset metadata on the resulting cropped segments. This ensures each quadrant functions as a standalone image without lingering canvas coordinates.
  • quadrant_%d.jpg: The output naming format. The %d acts as an index placeholder, generating files named quadrant_0.jpg, quadrant_1.jpg, quadrant_2.jpg, and quadrant_3.jpg reading from left-to-right, top-to-bottom.

Customizing Grid Layouts

The same syntax applies to any arbitrary grid layout:

  • 3x3 Grid (9 equal tiles):

    magick input.jpg -crop 3x3@ +repage tile_%d.png

  • Horizontal Split (2 columns, 1 row):

    magick input.jpg -crop 2x1@ +repage split_%d.png

  • Vertical Split (1 column, 2 rows):

    magick input.jpg -crop 1x2@ +repage split_%d.png

Formatting Output Numbering

You can format the generated index numbers with leading zeros by adjusting the format specifier:

  • quadrant_%02d.png produces quadrant_00.png, quadrant_01.png, etc.
  • quadrant_%03d.png produces quadrant_000.png, quadrant_001.png, etc.
