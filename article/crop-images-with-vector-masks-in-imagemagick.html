Crop Images with Vector Masks in ImageMagick

ImageMagick allows you to isolate and crop image regions into custom, non-rectangular shapes—such as circles, polygons, or complex curves—using vector masks and alpha compositing. While standard cropping operations strictly produce rectangular boundaries, applying vector paths defined via SVG or Magick Vector Graphics (MVG) to an image's alpha channel effectively clips the image to any geometry. This guide outlines how to define vector shapes inline, load external vector files, and apply them as clipping masks.

Understanding Vector Masking in ImageMagick

ImageMagick achieves non-rectangular crops through alpha channel masking rather than traditional pixel-coordinate cropping. The process involves two primary steps:

  1. Creating or importing a vector shape where the target area is opaque (or white) and the discarded area is transparent (or black).
  2. Compositing the mask over the source image using the DstIn composition operator, which keeps only the source pixels that overlap with the opaque areas of the mask.

Method 1: Using Inline Vector Paths

You can define vector shapes directly inside the ImageMagick command using the -draw operator with standard SVG path syntax or geometric primitives.

magick input.jpg \
  \( +clone -alpha transparent -background none \
     -fill white -draw "path 'M 100,50 C 100,0 200,0 200,50 C 200,100 100,150 100,200 C 100,150 0,100 0,50 C 0,0 100,0 100,50 Z'" \) \
  -compose DstIn -composite \
  -trim +repage output.png

In this command:

  • +clone creates a temporary copy matching the dimensions of the input image.
  • -alpha transparent sets the temporary layer to be fully transparent.
  • -draw "path '...'" renders an SVG-standard vector path filled with solid color.
  • -compose DstIn -composite cuts the source image to the exact shape of the rendered vector path.
  • -trim +repage removes the excess transparent border surrounding the cropped vector shape.

Method 2: Defining Polygons and Curves

For simpler geometric boundaries, you can define arbitrary polygons or circles directly without full SVG path notation:

magick input.jpg \
  \( -size 800x600 xc:none \
     -fill white -draw "polygon 100,50 300,80 400,300 250,500 50,400" \) \
  -alpha set -compose DstIn -composite \
  -trim +repage output.png

Here, xc:none initializes a blank, transparent canvas, and polygon specifies vertex coordinates to create an irregular polygon mask.

Method 3: Using an External SVG File as a Mask

If you have a complex vector path designed in vector editing software, you can supply the .svg file directly to act as the mask layer:

magick input.jpg mask.svg \
  -alpha set -compose DstIn -composite \
  -trim +repage output.png

Ensure that mask.svg matches the target dimensions and resolution of input.jpg, or use -resize on the vector mask within an ImageMagick stack so the vectors align properly with the source image before compositing.
