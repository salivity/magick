Custom Delegate Mapping in ImageMagick delegates.xml

ImageMagick relies on external helper applications, known as delegates, to decode, process, and encode specialized file formats it cannot handle natively. This article provides a straightforward guide on how to specify custom delegate mappings inside ImageMagick's delegates.xml file, covering file location, XML syntax, command string parameters, and verification steps.

Locating the delegates.xml File

ImageMagick searches for configuration files in several system and user-level directories. To find the active delegates.xml file being used by your installation, run the following command in your terminal:

magick -list delegate

To view the exact paths where ImageMagick looks for configuration files, execute:

magick -list configure | grep CONFIGURE_PATH

Common locations include:

  • Global Configuration (Linux/macOS): /etc/ImageMagick-7/delegates.xml or /usr/local/etc/ImageMagick-7/delegates.xml
  • User-Specific Configuration: ~/.config/ImageMagick/delegates.xml
  • Windows: Located in the ImageMagick root installation directory alongside magick.exe.

User-level configuration files override global configurations without requiring administrative privileges.

Structure of delegates.xml

The delegates.xml file uses standard XML format wrapped inside a root <delegatemap> element. Each mapping is defined using an individual <delegate /> tag.

<delegatemap>
  <delegate decode="format_in" encode="format_out" mode="bi" command="&quot;tool_name&quot; &quot;%i&quot; &quot;%o&quot;" />
</delegatemap>

Key Delegate Attributes

  • decode: The format ImageMagick reads. If specified without an encode attribute, this delegate handles input files of this format.
  • encode: The format ImageMagick writes. If specified alongside decode, it defines a specific conversion path between two formats.
  • mode: The directionality of the command.
    • bi: Bidirectional (can handle both encoding and decoding flows).
    • encode: Only used for output generation.
    • decode: Only used for input extraction.
  • command: The exact shell command executed by ImageMagick to perform the conversion.
  • spawn: (Optional) Set to "True" to run the command asynchronously without waiting for it to terminate.
  • stealth: (Optional) Set to "True" to hide the delegate from standard listing outputs.

Command String Substitution Variables

ImageMagick passes dynamic arguments into the command string using percentage (%) placeholders:

  • %i: The input file path.
  • %o: The output file path.
  • %u: A unique temporary input file created by ImageMagick.
  • %v: A unique temporary output file created by ImageMagick.
  • %s: Scene, page, or frame number.
  • %w: Image width.
  • %h: Image height.
  • %q: Quantum depth or quality setting.

Note: Special XML characters within commands must be escaped (e.g., use &quot; instead of ", and &amp; instead of &).

Step-by-Step: Adding a Custom Delegate

1. Identify the External Tool

Ensure the third-party binary or CLI tool you want to map is installed and accessible in the system's PATH. For example, suppose you have a tool called customconv that converts .rawcustom files into standard .png images via:

customconv input.rawcustom output.png

2. Add the Entry to delegates.xml

Open your delegates.xml file in a text editor and add your custom mapping inside the <delegatemap> tags:

<delegate decode="rawcustom" encode="png" mode="decode" command="&quot;customconv&quot; &quot;%i&quot; &quot;%o&quot;" />

If the tool supports piped output directly to stdout or reads from stdin, use - in place of filenames if supported by the tool.

3. Verify the Configuration

Verify that ImageMagick recognizes the newly defined delegate mapping:

magick -list delegate | grep rawcustom

4. Test the Integration

Run a standard ImageMagick conversion to verify that the delegate processes the file correctly:

magick input.rawcustom output.jpg

ImageMagick will invoke customconv to convert input.rawcustom into a temporary PNG file, and then internally convert that PNG into the final output.jpg.
