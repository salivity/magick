Custom Halftone Patterns in ImageMagick Dithering

This article explains how to create and apply custom halftone screen patterns in ImageMagick using ordered dithering threshold maps. You will learn how threshold matrices work, how to write your own custom pattern definition in an XML configuration file, and how to execute the command-line operations required to render the custom halftone effect onto your images.

Understanding Ordered Dithering in ImageMagick

ImageMagick's -ordered-dither operator relies on predefined threshold maps (matrices) to determine whether a pixel should turn black, white, or a specific intermediate tone based on its brightness. While ImageMagick includes standard matrices such as Bayer patterns (o8x8, o4x4) and standard halftone circles (h8x8a, h6x6a), you can create custom screens by defining your own matrix.

Step 1: Define the Custom Matrix in XML

ImageMagick loads ordered dither matrices from an XML configuration file named thresholds.xml. You can define custom dot sizes, angled screens, lines, or crosshatch patterns by creating or modifying this file.

Create a file named thresholds.xml in your current working directory (or in your ImageMagick configuration directory, such as ~/.config/ImageMagick/ on Linux/macOS):

<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE thresholdmap [
  <!ELEMENT thresholdmap (threshold)+>
  <!ELEMENT threshold (description,levels,divisor,matrix)>
  <!ATTLIST threshold map CDATA #REQUIRED>
  <!ELEMENT description (#PCDATA)>
  <!ELEMENT levels (#PCDATA)>
  <!ELEMENT divisor (#PCDATA)>
  <!ELEMENT matrix (#PCDATA)>
]>
<thresholdmap>
  <threshold map="custom-diamond">
    <description>Custom 4x4 Diamond Halftone Pattern</description>
    <levels>1</levels>
    <divisor>16</divisor>
    <matrix>
      12,  4,  5, 13,
       3,  0,  1,  6,
       8,  2,  7, 14,
      15,  9, 10, 11
    </matrix>
  </threshold>
</thresholdmap>

Matrix Components Explained

  • map: The unique identifier used to call your pattern in the CLI (e.g., custom-diamond).
  • levels: The base number of intensity levels represented by the matrix (usually set to 1).
  • divisor: The total range of threshold values (typically equal to the total number of cells in the matrix, such as 16 for a 4x4 matrix).
  • matrix: A comma-separated list of threshold values arranged in a grid. The order of numbers dictates the sequence in which pixels activate as image brightness increases.

Step 2: Applying the Custom Pattern

Once the XML file is placed in your working directory or ImageMagick configuration path, invoke your custom map using the -ordered-dither operator:

magick input.jpg -ordered-dither custom-diamond output.png

For ImageMagick version 6, use:

convert input.jpg -ordered-dither custom-diamond output.png

Step 3: Multi-Level and Color Halftoning

You can expand your custom matrix beyond simple 1-bit monochrome output by specifying color levels directly in the command:

  • Multi-level Grayscale: To produce an output with 4 distinct tonal levels per channel: 
    magick input.jpg -ordered-dither custom-diamond,4 output.png
  • Separated Color Channels: To apply different color quantization levels across RGB channels (e.g., Red: 2 levels, Green: 4 levels, Blue: 2 levels): 
    magick input.jpg -ordered-dither custom-diamond,2,4,2 output.png

Designing Line and Dot Screens

To create specific geometric screens, control the layout of the matrix values:

  • Clustered Dot (Round Halftone): Place lower threshold values in the center and increase values outward to create dots that grow as brightness rises.
  • Line Screens: Assign identical threshold values across entire rows or columns to produce horizontal or vertical halftone scanning lines.
  • Diagonal Lines: Place incrementing values diagonally across the matrix to create 45-degree angled line screens.
