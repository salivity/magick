Custom Halftoning with ImageMagick Ordered Dither

ImageMagick provides a powerful framework for generating stylized halftone patterns and vintage print aesthetics through its ordered dithering engine. By leveraging threshold maps, users can control how pixel intensities are converted into geometric dot clusters, crosshatches, or custom shapes. This guide explains how to define custom ordered dither matrices in ImageMagick's configuration files and apply them to images using the command line.

Understanding Ordered Dithering in ImageMagick

Ordered dithering works by comparing the intensity of each image pixel against a repeating threshold matrix (a 2D grid of numerical threshold values). If the pixel intensity is higher than the corresponding matrix value, it is quantized to a lighter tone; otherwise, it becomes darker.

ImageMagick exposes this functionality through the -ordered-dither operator (or -auto-threshold depending on the use case). While ImageMagick includes pre-configured matrices (such as Bayer matrices o8x8 or clustered dots c5x5), custom halftoning effects require defining a user-specified threshold matrix.

Step 1: Define a Custom Threshold Matrix

Custom matrices are defined in an XML file named thresholds.xml. ImageMagick searches for this file in its configuration paths, including your local user directory:

  • Linux/macOS: ~/.config/ImageMagick/thresholds.xml or ~/.magick/thresholds.xml
  • Windows: %APPDATA%\ImageMagick\thresholds.xml

Create or edit thresholds.xml to include your custom halftone pattern:

<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE thresholdmap [
  <!ELEMENT thresholdmap (threshold)+>
  <!ELEMENT threshold (description,levels,divisor,matrix)>
  <!ATTLIST threshold map CDATA #REQUIRED>
  <!ELEMENT description (#PCDATA)>
  <!ELEMENT levels (#PCDATA)>
  <!ELEMENT divisor (#PCDATA)>
  <!ELEMENT matrix (#PCDATA)>
]>
<thresholdmap>
  <threshold map="custom_cluster_4x4">
    <description>Custom 4x4 Clustered Dot Halftone</description>
    <levels>1</levels>
    <divisor>16</divisor>
    <matrix>
      12  5  6 13
       4  0  1  7
       3  2  8 14
      11 10  9 15
    </matrix>
  </threshold>
  <threshold map="custom_line_4x4">
    <description>Custom 4x4 Diagonal Line Screen</description>
    <levels>1</levels>
    <divisor>16</divisor>
    <matrix>
       1  5  9 13
       6 10 14  2
      11 15  3  7
      16  4  8 12
    </matrix>
  </threshold>
</thresholdmap>

Matrix Components Explained:

  • map: The unique identifier used in the command-line interface.
  • divisor: The maximum value used to normalize the matrix values into floating-point numbers between 0 and 1.
  • levels: The default number of intensity levels to dither across (typically 1 or 2 for pure 1-bit halftones).
  • matrix: The spatial arrangement of threshold values. The order and clustering of values determine whether the output appears as circular dots, diagonal lines, or stochastic noise.

Step 2: Apply the Custom Dither to an Image

Once the matrix is registered, apply it using the magick command.

Basic Monochrome Halftone

To convert an image to grayscale and apply the custom cluster pattern:

magick input.jpg -colorspace Gray -ordered-dither custom_cluster_4x4 output.png

Multi-Level Dithering

You can specify the number of color quantization levels directly in the command by appending a level count to the map name:

magick input.jpg -colorspace Gray -ordered-dither custom_cluster_4x4,4 output.png

Step 3: CMYK Color Separation Halftoning

To achieve an offset-print visual effect, split the image into its CMYK channels, apply the ordered dither to each channel independently, and recombine them:

magick input.jpg -colorspace CMYK \
  -channel C -ordered-dither custom_cluster_4x4 \
  -channel M -ordered-dither custom_cluster_4x4 \
  -channel Y -ordered-dither custom_cluster_4x4 \
  -channel K -ordered-dither custom_cluster_4x4 \
  +channel -colorspace sRGB cmyk_halftone.png

Step 4: Scaling Matrix Size for Visible Dot Effects

Because dither matrices operate at the single-pixel level, modern high-resolution images will produce extremely fine dots that appear smooth rather than stylized.

To create prominent, poster-style halftone dots:

  1. Downscale the image.
  2. Apply the ordered dither.
  3. Upscale the image using nearest-neighbor interpolation to preserve sharp dot edges.
magick input.jpg \
  -resize 25% \
  -colorspace Gray \
  -ordered-dither custom_cluster_4x4 \
  -scale 400% \
  large_dot_halftone.png

Using -scale (or -filter point -resize) ensures the pixelated halftone pattern remains crisp without introducing unwanted anti-aliasing blur.
