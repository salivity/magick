Custom Non-Uniform Image Montages in ImageMagick

Creating image montages with non-uniform, custom geometries in ImageMagick allows you to build complex collages where images have varied dimensions, aspect ratios, and specific coordinate positions. This guide demonstrates how to bypass the standard grid constraints of the default montage tool by utilizing the magick command with canvas mapping, explicit sizing, and layer positioning to assemble fully customized layouts.

The Limitation of the Default montage Command

The built-in montage command is designed primarily for regular, uniform grids. When applying -geometry, montage applies the same tile size and spacing to every image in the sequence. To achieve a non-uniform montage where individual images have unique widths, heights, and coordinates, you must use layer composition via the magick (or convert in ImageMagick 6) tool.

Method 1: Using -page Offsets and -layers merge

The most efficient way to place images of varying sizes at specific positions is by combining sub-shell image processing, the -page offset operator, and -layers merge.

Syntax Breakdown

  • Parentheses ( ... ): Isolate each image to resize or crop it individually without affecting other images.
  • -page +X+Y: Defines the absolute pixel coordinates on the final canvas where the top-left corner of the image will be placed.
  • -background: Sets the canvas background color (e.g., none, white, black).
  • -layers merge: Merges all positioned layers into a single canvas that automatically sizes itself to fit the outermost coordinates.

Example Command

Suppose you want to create a canvas containing three differently sized images:

  1. img1.jpg resized to 400x400 at position (0, 0)
  2. img2.jpg resized to 200x200 at position (400, 0)
  3. img3.jpg resized to 200x200 at position (400, 200)
magick \
  -page +0+0 \( img1.jpg -resize 400x400^ -gravity center -extent 400x400 \) \
  -page +400+0 \( img2.jpg -resize 200x200^ -gravity center -extent 200x200 \) \
  -page +400+200 \( img3.jpg -resize 200x200^ -gravity center -extent 200x200 \) \
  -background white -layers merge custom_montage.jpg

Method 2: Drawing onto an Explicit Base Canvas

If you need a predefined canvas size with margins, borders, or specific empty areas, generate a blank base canvas first and composite the individual images onto it sequentially.

Example Command

To create an explicit 800x600 canvas and place two non-uniform images with exact coordinates:

magick -size 800x600 xc:white \
  \( img1.jpg -resize 500x600^ -gravity center -extent 500x600 \) -geometry +0+0 -composite \
  \( img2.jpg -resize 300x300^ -gravity center -extent 300x300 \) -geometry +500+150 -composite \
  output_canvas.png

Key Geometry Controls

  • Exact Fit with Cropping (-resize WxH^ -gravity center -extent WxH): Ensures that images with varying aspect ratios completely fill their target dimensions without distortion.
  • Coordinate Positioning (-geometry +X+Y or -page +X+Y): Determines the exact horizontal (+X) and vertical (+Y) offsets relative to the top-left corner (0,0).
  • Negative Offsets: You can overlap images by providing negative offsets or coordinates that place images over existing ones in the stacking order.
