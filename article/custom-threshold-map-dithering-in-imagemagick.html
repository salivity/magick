Custom Threshold Map Dithering in ImageMagick

Ordered dithering with custom threshold maps in ImageMagick allows you to create specific pixel patterns, crosshatches, or retro halftone effects by defining your own matrix values. This guide explains how to define a custom threshold map in ImageMagick's configuration and apply it to an image using the -ordered-dither operator.

1. Locate or Create the thresholds.xml File

ImageMagick loads custom ordered dither patterns from an XML configuration file named thresholds.xml. You can place this file in your user configuration directory so it does not overwrite system defaults:

  • Linux / macOS: ~/.config/ImageMagick/thresholds.xml (or ~/.imagemagick/thresholds.xml)
  • Windows: %APPDATA%\ImageMagick\thresholds.xml

2. Define the Custom Matrix

Open or create thresholds.xml and define your custom matrix within the <thresholds> root element.

Here is an example defining a custom 2×2 matrix and a custom 4×4 Bayer-style matrix:

<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE thresholds [
  <!ELEMENT thresholds (threshold)+>
  <!ELEMENT threshold (description?,levels)>
  <!ATTLIST threshold map CDATA #REQUIRED>
  <!ATTLIST threshold alias CDATA #IMPLIED>
  <!ELEMENT description (#PCDATA)>
  <!ELEMENT levels (#PCDATA)>
  <!ATTLIST levels width CDATA #REQUIRED>
  <!ATTLIST levels height CDATA #REQUIRED>
  <!ATTLIST levels divisor CDATA #REQUIRED>
]>
<thresholds>
  <threshold map="custom2x2" alias="c2">
    <description>Custom 2x2 ordered dither matrix</description>
    <levels width="2" height="2" divisor="4">
      1  3
      4  2
    </levels>
  </threshold>

  <threshold map="custom4x4" alias="c4">
    <description>Custom 4x4 ordered dither matrix</description>
    <levels width="4" height="4" divisor="16">
       1  9  3 11
      13  5 15  7
       4 12  2 10
      16  8 14  6
    </levels>
  </threshold>
</thresholds>
  • map: The unique identifier used to call the matrix in the command line.
  • width and height: The dimensions of your matrix grid.
  • divisor: The total normalization factor (typically width × height).
  • levels content: The threshold values arranged in rows and columns.

3. Verify the Custom Map

Ensure ImageMagick detects your custom map by listing the available threshold maps:

magick -list threshold

Your custom names (custom2x2, custom4x4) should appear in the output list.

4. Apply the Dither Matrix to an Image

Use the -ordered-dither operator followed by your map name and the number of desired color levels.

1-Bit Monochrome Dithering

To produce a 2-level (black and white) image:

magick input.jpg -colorspace Gray -ordered-dither custom2x2,2 output.png

Multi-Level Color Dithering

To dither individual RGB channels into specific quantization levels (e.g., 4 levels of Red, 4 levels of Green, 4 levels of Blue):

magick input.jpg -ordered-dither custom4x4,4,4,4 output.png

Web-Safe Color Dithering

To dither directly to standard color channels with uniform levels across Red, Green, and Blue:

magick input.jpg -ordered-dither custom2x2 output.png
