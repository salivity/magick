Customize Tile Layout in ImageMagick Montage

This guide explains how to customize the tile layout grid dimensions when using the ImageMagick montage command. By utilizing the -tile and -geometry options, you can precisely define the number of rows, columns, thumbnail sizes, and spacing between images to create tailored image grids and contact sheets.

The -tile Option Syntax

The primary option for controlling grid dimensions in montage is -tile. It uses the format [columns]x[rows].

montage input*.jpg -tile <columns>x<rows> output.jpg

1. Setting Fixed Columns and Rows

To create a specific fixed grid (such as 3 columns by 2 rows), specify both numbers:

montage *.jpg -tile 3x2 output.jpg

If you have more images than the grid can hold (e.g., 10 images with a 3x2 grid), ImageMagick will generate multiple output files. You can save them as indexed pages:

montage *.jpg -tile 3x2 output_%d.jpg

2. Setting a Fixed Number of Columns (Variable Rows)

To fix the number of columns and let ImageMagick automatically calculate the required rows based on the total number of images, omit the row value:

montage *.jpg -tile 4x output.jpg

This creates a grid that is always 4 columns wide, expanding downward as needed.

3. Setting a Fixed Number of Rows (Variable Columns)

To fix the number of rows and allow the columns to expand horizontally, omit the column value:

montage *.jpg -tile x2 output.jpg

This ensures the layout is strictly 2 rows high, adding columns horizontally to fit all input images.

Controlling Tile Sizing and Spacing with -geometry

The -tile option controls only the grid arrangement. To control thumbnail dimensions and the margins/spacing around each tile, combine it with the -geometry option:

montage *.jpg -tile 3x3 -geometry [width]x[height]+[x_offset]+[y_offset] output.jpg

Example Configurations:

  • Fixed tile size with spacing:

    montage *.jpg -tile 3x -geometry 200x200+10+10 output.jpg

    (Resizes images to fit within 200x200 pixels with a 10px gap between tiles)

  • Original image sizes without gaps (seamless grid):

    montage *.jpg -tile 2x2 -geometry +0+0 output.jpg

    (Preserves original sizes and removes all borders and spacing)

  • Crop to fill exact dimensions (with ^ and -gravity):

    montage *.jpg -tile 4x2 -geometry 150x150^+0+0 -gravity center output.jpg

    (Crops each image into a uniform 150x150 square centered tile with zero gaps)

Complete Example Command

To create a clean, 4-column photo sheet with 250px thumbnails, 5px spacing, and a custom background color:

montage *.jpg -background "#FFFFFF" -tile 4x -geometry 250x250+5+5 final_montage.jpg
