Decode Apple QuickTime PICT in ImageMagick

This article explains how ImageMagick handles Apple QuickTime PICT files, identifying the specific delegate libraries and internal coders required to decode both vector and raster data. You will learn which software components process the legacy Macintosh format and how ImageMagick manages complex PICT rendering across different environments.

The Delegate Library for Apple QuickTime PICT

ImageMagick processes standard Apple Macintosh PICT (both v1 and v2) files primarily through its built-in internal coder, coders/pict.c. However, for advanced Apple QuickTime PICT files containing proprietary compression schemes, embedded vector operations, or QuickTime-specific extensions, ImageMagick historically relies on the Apple QuickTime SDK / QuickTime Framework as its external delegate library.

Because PICT was designed around Apple's QuickDraw graphics engine, fully rendering both vector drawing opcodes and embedded raster bitmaps requires access to Apple's native graphics subsystem.

Raster vs. Vector PICT Decoding

  • Raster PICT Files: For basic uncompressed or Run-Length Encoded (RLE) bitmaps stored within a PICT container, ImageMagick does not require an external third-party library. The native pict.c coder directly parses the header, color tables, and scanlines to reconstruct the image.
  • Vector and QuickTime-Compressed PICT Files: When a PICT file contains QuickDraw vector opcodes, PostScript data, or JPEG/QuickTime compression, ImageMagick cannot parse the drawing routines entirely through native C routines on non-Mac platforms. In Apple environments (such as classic Mac OS and older Mac OS X systems), ImageMagick links directly against the native QuickTime framework (or QuickDraw API) to delegate rendering. On non-Apple platforms (such as Linux and Windows), vector opcodes cannot be natively evaluated without an emulated interpreter, meaning vector data may be ignored or fail to decode without pre-conversion.

Checking PICT Support in ImageMagick

To verify if your ImageMagick installation is configured to read or write PICT files, execute the following command in your terminal:

magick identify -list format | grep -i pict

A properly configured installation will return:

PICT*  rw-  Apple Macintosh QuickDraw/PICT
PCT*   rw-  Apple Macintosh QuickDraw/PICT

To see the compiled external delegates in your current build:

magick -version

Look at the Delegates (built-in) line to inspect linked libraries such as cairo, freetype, jpeg, png, and rsvg.
