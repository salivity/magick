Decode Fujifilm RAF Files Using ImageMagick

This guide explains how to decode and convert Fujifilm RAF (raw) image files using ImageMagick. It covers the essential command-line syntax for both basic conversions and advanced raw processing, including white balance adjustments, color management, and delegate configuration using LibRaw or dcraw.

How ImageMagick Handles RAF Files

ImageMagick does not decode RAF files natively; it delegates raw decoding to external tools—primarily LibRaw or dcraw. Ensure that your ImageMagick build includes raw delegate support before running these commands. You can verify support by checking the output of magick -version or magick -list configure for libraw or dng.

Basic Conversion Syntax

For ImageMagick 7, use the magick command:

magick input.RAF output.jpg

For ImageMagick 6, use the convert syntax:

convert input.RAF output.jpg

To preserve maximum bit depth, convert to a 16-bit format such as TIFF or PNG:

magick input.RAF -depth 16 output.tiff

Raw Processing Directives (-define dng:)

Because ImageMagick passes raw files through its DNG/LibRaw delegate, you can control raw-specific decoding settings using the -define dng: prefixes. These must be placed before the input filename in ImageMagick 7.

1. White Balance Settings

Use camera white balance:

magick -define dng:use-camera-wb=true input.RAF output.jpg

Use automatic white balance calculated across the entire image:

magick -define dng:use-auto-wb=true input.RAF output.jpg

2. Demosaicing and Quality

Set the demosaicing interpolation quality (crucial for Fujifilm X-Trans and Bayer sensor patterns):

magick -define dng:interpolation-quality=3 -define dng:use-camera-wb=true input.RAF output.jpg

Value range is typically 0 to 4 (0 = linear, 3 = AHD, 4 = custom LibRaw modes).

3. Color Space and Gamut

Ensure the decoded image is converted to a standard color profile, preventing washed-out tones:

magick -define dng:use-camera-wb=true input.RAF -colorspace sRGB -quality 95 output.jpg

4. Faster Previews (Half-Size Decoding)

For rapid batch processing or quick previews, decode at half resolution:

magick -define dng:read-half=true input.RAF preview.jpg

Complete Production Example

For an optimal balance of detail, color accuracy, and file quality, combine raw directives with standard output options:

magick -define dng:use-camera-wb=true \
       -define dng:interpolation-quality=3 \
       input.RAF \
       -auto-orient \
       -colorspace sRGB \
       -quality 92 \
       output.jpg
  • -auto-orient: Reads EXIF orientation flags to correct image rotation automatically.
  • -quality 92: Sets JPEG compression to high quality without excessive file size.

Batch Conversion Syntax

To decode an entire directory of RAF files to JPEG on Unix-like systems (Linux, macOS):

magick mogrify -format jpg -define dng:use-camera-wb=true -auto-orient *.RAF

On Windows (PowerShell):

Get-ChildItem *.RAF | ForEach-Object {
    magick -define dng:use-camera-wb=true $_.FullName -auto-orient "$($_.BaseName).jpg"
}
