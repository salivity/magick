Defining Gaussian Kernel Radius and Sigma in ImageMagick

In ImageMagick, defining a discrete Gaussian kernel requires specifying two parameters: the kernel radius and the standard deviation (\(\sigma\)). This guide explains the standard {radius}x{sigma} syntax, details how both values influence the mathematical generation of the discrete matrix, and demonstrates how to apply Gaussian kernels using ImageMagick’s command-line operators.

The {radius}x{sigma} Syntax

ImageMagick uses the {radius}x{sigma} geometry format to construct Gaussian kernels. The two values control distinct aspects of the operation:

  • Sigma (\(\sigma\)): Represents the standard deviation of the Gaussian distribution. It determines the actual spread or strength of the blur. Larger values create a broader, softer blur, while smaller values preserve sharper edges.
  • Radius (\(r\)): Sets the physical boundary or maximum distance from the center pixel that ImageMagick uses to construct the discrete matrix. The resulting 2D convolution matrix has dimensions of \((2r + 1) \times (2r + 1)\).

Choosing Between Explicit and Automatic Radius

Setting Radius to 0 (Recommended)

When you set the radius to 0 (e.g., 0x2.5), ImageMagick automatically calculates an optimal radius based on the formula:

\[\text{Radius} \approx 3 \times \sigma\]

Because a standard Gaussian distribution contains roughly 99.7% of its total area within three standard deviations of the mean, this default prevents edge-clipping artifacts while avoiding unnecessary computation.

Setting an Explicit Radius

Setting an explicit non-zero radius limits the size of the kernel matrix manually:

  • If the radius is smaller than \(3\sigma\), the Gaussian curve is cut off prematurely, potentially causing visual banding or hard edges.
  • If the radius is significantly larger than \(3\sigma\), processing time increases with negligible visual difference, as weights near the outer edges approach zero.

Applying Gaussian Kernels in Practice

You can implement discrete Gaussian kernels in ImageMagick using either built-in blur operators or explicit morphology convolutions.

1. Using the -gaussian-blur Operator

The -gaussian-blur operator applies a two-pass 1D discrete Gaussian filter across the horizontal and vertical axes:

magick input.png -gaussian-blur 0x2.0 output.png

To limit the discrete kernel boundary manually to a 7x7 matrix (radius of 3):

magick input.png -gaussian-blur 3x1.5 output.png

2. Using the -morphology Convolve Operator

For low-level control over the convolution kernel, use the Gaussian kernel type with the -morphology operator:

magick input.png -morphology Convolve Gaussian:0x2.0 output.png

This generates a full 2D discrete kernel matrix directly from the Gaussian function. To inspect the generated discrete weights, you can output the kernel definition to the console:

magick -define morphology:showKernel=1 -morphology Convolve Gaussian:3x1.0 null:
