Deploy ImageMagick on AWS Lambda with Custom Layers

This article provides a step-by-step guide to deploying ImageMagick within AWS Lambda functions using AWS Lambda Layers. You will learn how to compile ImageMagick binaries compatible with the Amazon Linux runtime using Docker, package the binaries into a reusable custom layer, publish the layer via the AWS CLI, and invoke ImageMagick commands directly from your serverless function code.

1. Compile ImageMagick Using Docker

AWS Lambda executes in an Amazon Linux environment (Amazon Linux 2 or Amazon Linux 2023). To ensure binary compatibility, compile ImageMagick inside an official Amazon Linux Docker container.

Create a Dockerfile with the following build instructions:

FROM amazonlinux:2

# Install build tools and libraries
RUN yum update -y && \
    yum groupinstall -y "Development Tools" && \
    yum install -y libpng-devel libjpeg-devel libtiff-devel

# Download and compile ImageMagick
WORKDIR /tmp
RUN curl -O https://download.imagemagick.org/ImageMagick/download/ImageMagick.tar.gz && \
    tar -xvzf ImageMagick.tar.gz && \
    cd ImageMagick-* && \
    ./configure --prefix=/opt --without-x --without-perl && \
    make && \
    make install

# Package the binaries and libraries
WORKDIR /opt
CMD tar -czvf /out/imagemagick-layer.tar.gz bin lib

Build the Docker image and extract the compiled archive to your host system:

mkdir -p build output
docker build -t imagemagick-lambda-builder .
docker run --rm -v $(pwd)/output:/out imagemagick-lambda-builder

2. Structure and Zip the Lambda Layer

Lambda automatically extracts layer contents into the /opt directory of the execution environment. To ensure the binaries and shared libraries are discovered properly:

  1. Extract the compiled archive into a folder structure matching /opt/bin and /opt/lib.
  2. Package the directory into a standard .zip file.
mkdir -p layer-package/bin layer-package/lib
tar -xzvf output/imagemagick-layer.tar.gz -C layer-package/

cd layer-package
zip -r ../imagemagick-layer.zip bin lib
cd ..

3. Publish the Custom Lambda Layer

Publish the zip file as a Lambda Layer using the AWS Command Line Interface (AWS CLI):

aws lambda publish-layer-version \
    --layer-name "imagemagick-layer" \
    --description "ImageMagick binaries for Amazon Linux 2" \
    --zip-file "fileb://imagemagick-layer.zip" \
    --compatible-runtimes "nodejs18.x" "nodejs20.x" "python3.10" "python3.11"

Save the LayerVersionArn returned in the output JSON.

4. Attach the Layer to Your Lambda Function

Add the published layer to your existing Lambda function using the AWS Management Console or the CLI:

aws lambda update-function-configuration \
    --function-name "your-function-name" \
    --layers "arn:aws:lambda:region:account-id:layer:imagemagick-layer:1"

Set the PATH and LD_LIBRARY_PATH environment variables on the function if they are not already pointing to /opt/bin and /opt/lib:

  • PATH: /usr/local/bin:/usr/bin:/bin:/opt/bin
  • LD_LIBRARY_PATH: /lib64:/usr/lib64:/var/runtime:/var/runtime/lib:/var/task:/var/task/lib:/opt/lib

5. Execute ImageMagick in Lambda Code

With the layer attached, ImageMagick utilities such as magick, convert, and identify can be invoked using subprocess execution in your runtime.

Node.js Example

const { execSync } = require('child_process');
const fs = require('fs');

exports.handler = async (event) => {
    // Check if ImageMagick is executable
    const version = execSync('/opt/bin/magick -version').toString();
    console.log(version);

    // Example image conversion: Convert input.jpg to output.png in the /tmp directory
    execSync('/opt/bin/magick /tmp/input.jpg -resize 50% /tmp/output.png');

    return {
        statusCode: 200,
        body: JSON.stringify({ message: "Image processed successfully" })
    };
};

Python Example

import subprocess
import json

def lambda_handler(event, context):
    # Check ImageMagick installation
    result = subprocess.run(['/opt/bin/magick', '-version'], capture_output=True, text=True)
    print(result.stdout)

    # Example image resize operation
    subprocess.run(['/opt/bin/magick', '/tmp/input.jpg', '-resize', '50%', '/tmp/output.png'], check=True)

    return {
        'statusCode': 200,
        'body': json.dumps({'message': 'Image processed successfully'})
    }
