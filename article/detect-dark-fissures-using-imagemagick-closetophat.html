Detect Dark Fissures Using ImageMagick CloseTopHat

Detecting narrow, dark features such as fissures, cracks, or scratches on uneven surfaces requires isolating local intensity minima from the surrounding background. In ImageMagick, the CloseTopHat morphology operator—commonly known in image processing as the "black top-hat" transform—performs this task by subtracting the original image from its morphological closing. This process neutralizes broad background lighting variations and leaves behind only the dark structures that fit within the specified structuring element.

How CloseTopHat Works

Morphological closing involves a dilation followed by an erosion using a specific kernel (structuring element). Closing bridges gaps and fills in dark structures that are smaller than the kernel size while preserving the general background intensity.

When you apply CloseTopHat, ImageMagick subtracts the original pixel values from this closed version:

\[\text{CloseTopHat} = \text{Closing}(I) - I\]

Because the closed image has the dark features filled in, subtracting the original dark pixels yields high values (bright pixels) exactly where the fissures were located. Everywhere else, the difference remains near zero (black).

Basic Command Syntax

In ImageMagick version 7, morphology operations are applied directly via the magick command:

magick input.jpg -morphology CloseTopHat Disk:3 fissures.png

For ImageMagick version 6, replace magick with convert:

convert input.jpg -morphology CloseTopHat Disk:3 fissures.png

Choosing the Structuring Element (Kernel)

The kernel type and radius determine which features are detected:

  • Radius: The radius must be slightly larger than the half-width of the widest fissure you wish to detect. If a crack is 4 pixels wide, a radius of 3 or 4 ensures the closing operation bridges the gap completely. If the radius is set too large, unwanted background textures may be captured.
  • Shape: The Disk shape provides an isotropic (uniform in all directions) response, which is ideal for organic or winding cracks. Square or Diamond shapes can be substituted if you are working with grid-aligned or directional surface defects.

Example using an elliptical or larger disk kernel:

magick input.jpg -morphology CloseTopHat Disk:5 fissures.png

Enhancing and Isolating Fissures

Raw CloseTopHat output often contains subtle differences that appear dim. To convert the detected fissures into a high-contrast representation or a binary mask, combine the operation with contrast stretching and thresholding.

1. Maximizing Contrast with Auto-Level

Stretch the dynamic range so the most prominent fissures become stark white against a solid black background:

magick input.jpg -colorspace Gray -morphology CloseTopHat Disk:3 -auto-level fissures_enhanced.png

2. Generating a Binary Mask

To isolate the cracks for automated inspection or measurement, apply a threshold to eliminate minor noise and keep only the strongest fissure boundaries:

magick input.jpg -colorspace Gray -morphology CloseTopHat Disk:3 -auto-level -threshold 20% fissure_mask.png

3. Inverting for Black-on-White Display

If your workflow requires the fissures to remain dark against a white background, add the -negate operator at the end of the chain:

magick input.jpg -colorspace Gray -morphology CloseTopHat Disk:3 -auto-level -threshold 20% -negate fissure_inverted.png
