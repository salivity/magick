Detect ICC Profile in Images with ImageMagick

This article explains how to determine whether an image contains an embedded International Color Consortium (ICC) color profile using ImageMagick. You will learn the precise command-line methods using both ImageMagick v7 and v6, how to extract profile names, and how to format the output for automated scripting environments.

The Fastest Method: Using the %[profiles] Format

The most direct way to check for an ICC profile is by querying the embedded profile names using the -format option with identify (or magick identify).

ImageMagick v7

magick identify -format "%[profiles]\n" image.jpg

ImageMagick v6

identify -format "%[profiles]\n" image.jpg

Output:

  • If an ICC profile is embedded, the output will contain icc.
  • If no profiles are embedded, the command returns an empty line.

Checking for the ICC Profile Specifically

If you want to check exclusively for an ICC profile and ignore other metadata profiles (such as EXIF, IPTC, or XMP), query the profile:icc property.

magick identify -format "%[profile:icc]\n" image.jpg

Output:

  • If present, it will print the raw byte size or generic identifier for the ICC profile.
  • If absent, it outputs nothing.

Reading the ICC Profile Name or Description

To verify not just the presence of the profile, but also its specific name (e.g., sRGB, Display P3, or Adobe RGB), query the profile description metadata:

magick identify -format "%[ICC:description]\n" image.jpg

Output:

sRGB IEC61966-2.1

If no ICC profile is attached, the output remains blank.

Using Verbose Output with grep

You can also run a full inspection of the image's properties using the -verbose flag and filter the results:

magick identify -verbose image.jpg | grep -i "Profile-icc"

If the profile exists, ImageMagick displays the profile block and its byte length:

  Profiles:
    Profile-icc: 2644 bytes

Automating the Check in a Bash Script

To use this check inside automated workflows or shell scripts, you can evaluate the output in a conditional statement:

#!/bin/bash

IMAGE="image.jpg"
ICC_CHECK=$(magick identify -format "%[profile:icc]" "$IMAGE" 2>/dev/null)

if [ -n "$ICC_CHECK" ]; then
    echo "ICC profile detected."
else
    echo "No ICC profile found."
fi
