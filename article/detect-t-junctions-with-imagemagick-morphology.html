Detect T-Junctions with ImageMagick Morphology

Detecting T-junctions in binary line art using ImageMagick requires the Hit-and-Miss morphology method paired with rotational 3x3 kernels representing the intersection geometry. This guide outlines the exact kernel syntax, explains the required values for line and background pixels, and demonstrates the command used to isolate orthogonal and diagonal T-junctions from skeletonized artwork.

The Hit-and-Miss Morphology Method

To locate specific pixel configurations such as junctions, endpoints, or corners, ImageMagick uses the Hit-and-Miss transform (HMT). This operation compares a user-defined matrix (the kernel) against the image pixels. A match occurs only when the foreground pixels ("hits") and background pixels ("misses") correspond exactly to the pattern specified by the kernel.

In ImageMagick syntax, the morphology call is:

magick input.png -morphology HitAndMiss "<kernel_definition>" output.png

Kernel Syntax Breakdown

A 3x3 morphology kernel in ImageMagick is written as a geometry prefix (3x3:) followed by nine comma-separated or space-separated values representing the rows, and optional rotation flags:

  • 1 (Hit): Requires a foreground (white) pixel.
  • 0 (Miss): Requires a background (black) pixel.
  • - (Don't Care): Matches any pixel value, allowing flexibility in line variations.
  • > (Rotational Modifier): Automatically rotates the kernel through four 90-degree steps (0°, 90°, 180°, 270°) to find junctions in all cardinal orientations.

Orthogonal T-Junction Kernel

In a 1-pixel-wide skeletonized image, an orthogonal T-junction consists of a central pixel with three orthogonal neighbors and no continuation on the fourth side. The corners must remain background pixels to avoid matching solid regions or diagonal paths.

The 3x3 matrix for an upward-pointing T-junction is:

0, 1, 0
1, 1, 1
0, 0, 0

Written in ImageMagick syntax with the 90-degree rotation flag:

"3x3: 0,1,0 1,1,1 0,0,0>"

Diagonal T-Junction Kernel

If the line art contains diagonal lines, a T-junction can occur where a straight stem meets a diagonal bar, or vice versa. A common diagonal T-junction pattern resembles:

1, 0, 1
0, 1, 0
0, 1, 0

In ImageMagick syntax:

"3x3: 1,0,1 0,1,0 0,1,0>"

Combining Kernels into a Single Command

To detect both orthogonal and diagonal T-junctions in one pass, multiple kernels can be concatenated using a semicolon (;). ImageMagick executes each kernel and combines the results using a boolean OR operation.

magick skeleton.png -morphology HitAndMiss \
  "3x3: 0,1,0 1,1,1 0,0,0> ; 3x3: 1,0,1 0,1,0 0,1,0>" \
  junctions.png

The resulting junctions.png file contains isolated single white pixels marking the precise coordinate of each detected T-junction across the entire image.
