Deuteranopia Color Matrix in ImageMagick

Deuteranopia, a common form of red-green color blindness caused by the absence of green retinal photoreceptors, can be effectively simulated using ImageMagick’s -color-matrix operator. This guide provides the exact color transformation matrix coefficients, explains how each channel is recalculated, and demonstrates the practical command-line syntax required to process images.

The Deuteranopia Transformation Matrix

To simulate complete deuteranopia on standard RGB images, the transformation maps red, green, and blue input values to a reduced color space that eliminates distinct green perception. A widely used 3×3 simulation matrix (based on the Viénot, Brettel, and Mollon model) is:

\[ \begin{bmatrix} 0.625 & 0.375 & 0.000 \\ 0.700 & 0.300 & 0.000 \\ 0.000 & 0.300 & 0.700 \end{bmatrix} \]

Channel Mapping Breakdown

  • Red Channel (\(R'\)): \(0.625 \times R + 0.375 \times G + 0.000 \times B\)
  • Green Channel (\(G'\)): \(0.700 \times R + 0.300 \times G + 0.000 \times B\)
  • Blue Channel (\(B'\)): \(0.000 \times R + 0.300 \times G + 0.700 \times B\)

In this transformation, the red and green output channels receive heavily blended values derived primarily from the red and green inputs, collapsing the chromatic distinction between them, while the blue channel is adjusted to maintain perceptual luminance.

ImageMagick Command-Line Usage

ImageMagick applies this transformation using the -color-matrix operator by passing the matrix values as a space-separated or comma-separated string formatted in a single row or grid.

ImageMagick v7

magick input.jpg -color-matrix \
  "0.625 0.375 0.000 \
   0.700 0.300 0.000 \
   0.000 0.300 0.700" \
  output_deuteranopia.jpg

ImageMagick v6 (Legacy)

convert input.jpg -color-matrix \
  "0.625 0.375 0.000 \
   0.700 0.300 0.000 \
   0.000 0.300 0.700" \
  output_deuteranopia.jpg

Alternative High-Precision Matrix (Machado Model)

For workflows requiring the Machado et al. (2009) physiologically accurate model at 100% severity, use the following 3×3 matrix coefficients:

magick input.jpg -color-matrix \
  " 0.367322  0.860646 -0.227968 \
    0.280085  0.672501  0.047413 \
   -0.011820  0.042940  0.968881" \
  output_machado.jpg
