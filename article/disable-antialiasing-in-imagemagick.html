Disable Antialiasing in ImageMagick

Rendering crisp, pixel-perfect vector shapes often requires disabling the default smoothing applied by rendering engines. This guide explains how to turn off antialiasing during vector shape rendering in ImageMagick, detailing the specific command-line option required, its placement in commands, and practical usage examples.

The Option: +antialias

To turn off antialiasing in ImageMagick, use the +antialias option.

In ImageMagick's command-line syntax, a minus sign (-) typically enables a feature, while a plus sign (+) disables or resets it. Therefore:

  • -antialias enables antialiasing (default behavior).
  • +antialias disables antialiasing.

How to Use +antialias for Vector Shapes

When rendering vector primitives (such as lines, circles, polygons, or text) using the -draw operator or importing vector formats like SVG, +antialias must appear before the drawing operations or input files in your command.

Example: Drawing Shapes Without Antialiasing

magick -size 200x200 xc:white +antialias -fill blue -draw "circle 100,100 100,20" output.png

In this command:

  1. -size 200x200 xc:white creates a blank 200x200 white canvas.
  2. +antialias disables edge smoothing for subsequent operations.
  3. -fill blue -draw "circle 100,100 100,20" draws a hard-edged circle without blended boundary pixels.
  4. output.png saves the final image.

Example: Disabling Antialiasing for SVG Rendering

When converting vector files (such as SVG) to raster formats, place +antialias before the input file:

magick +antialias input.svg output.png

Legacy ImageMagick 6 Syntax

If you are using ImageMagick 6, the convert tool uses the exact same flag:

convert -size 200x200 xc:white +antialias -fill red -draw "line 10,10 190,190" output.png

Key Considerations

  • Placement Matters: Ensure +antialias precedes the -draw command or the vector input file. Placing it afterward may cause ImageMagick to ignore the flag during rasterization.
  • Text Rendering: +antialias also disables subpixel rendering and font smoothing when rendering text with the -annotate or -draw "text ..." operators, resulting in bitmap-style fonts.
