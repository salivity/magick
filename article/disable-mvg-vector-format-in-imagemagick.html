Disable MVG Vector Format in ImageMagick

This article provides a direct guide on how to secure your ImageMagick installation by disabling the Magick Vector Graphics (MVG) coder in the policy.xml file. Disabling this vector format prevents the rendering of MVG files, mitigating common security risks such as remote code execution and server-side request forgery (SSRF) vulnerabilities associated with vector format processing.

1. Locate the policy.xml File

The location of policy.xml depends on your operating system and the version of ImageMagick installed. Run the following command in your terminal to find the active path:

identify -list policy

Alternatively, look in the standard configuration directories:

  • Ubuntu/Debian: /etc/ImageMagick-6/policy.xml or /etc/ImageMagick-7/policy.xml
  • RHEL/CentOS: /etc/ImageMagick/policy.xml
  • macOS (Homebrew): /usr/local/etc/ImageMagick-7/policy.xml or /opt/homebrew/etc/ImageMagick-7/policy.xml

2. Edit policy.xml

Open the configuration file in a text editor with administrative privileges:

sudo nano /etc/ImageMagick-6/policy.xml

Locate the <policymap> block. Add the following rule inside the <policymap> tags to revoke all read and write permissions for the MVG format:

<policymap>
  <!-- Disable MVG vector format -->
  <policy domain="coder" rights="none" pattern="MVG" />
</policymap>

If you also want to block file variants often associated with MVG (such as MSVG), you can broaden the pattern using a wildcard or explicit lines:

<policy domain="coder" rights="none" pattern="{MVG,MSVG}" />

Save the file and exit the editor.

3. Verify the Policy Configuration

To confirm that ImageMagick has loaded the new restriction, query the active security policies:

identify -list policy

Look for the coder entry in the output. It should display:

Path: /etc/ImageMagick-6/policy.xml
  Policy: Coder
    rights: None
    pattern: MVG

You can also test the policy directly by attempting to process an MVG file. Create a temporary file named test.mvg:

echo "push graphic-context viewbox 0 0 640 480 pop graphic-context" > test.mvg
convert test.mvg test.png

If the policy is working correctly, ImageMagick will block the operation and return an error:

convert: not authorized `test.mvg' @ error/constitute.c/ReadImage/...
