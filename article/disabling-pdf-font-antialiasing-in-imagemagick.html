Disabling PDF Font Antialiasing in ImageMagick

When rasterizing PDF documents with ImageMagick, users frequently seek a -define option to eliminate text smoothing and produce sharp, pixel-crisp typography. While ImageMagick uses -define keys for various format-specific configurations, font antialiasing during PDF interpretation is governed by the global +antialias operator rather than a -define key. This guide explains how PDF rasterization handles antialiasing, how to apply the correct flags in your commands, and how to configure underlying Ghostscript parameters.

Why ImageMagick Uses +antialias Instead of -define

ImageMagick delegates the rasterization of vector formats like PDF and PostScript to Ghostscript. During this process, font smoothing is controlled internally by passing rendering parameters directly to the Ghostscript engine.

Instead of configuring this behavior through a -define key (such as pdf:antialias=false), ImageMagick uses the unary plus operator on the antialias flag:

  • -antialias: Enables antialiasing (enabled by default).
  • +antialias: Disables antialiasing.

The Correct Command-Line Syntax

To disable font and graphic antialiasing during PDF conversion, place +antialias before the input file on the command line. Placing it after the input file will not affect rasterization because the delegate reads the flag prior to decoding the PDF stream.

magick +antialias input.pdf output.png

For ImageMagick version 6 legacy syntax:

convert +antialias input.pdf output.png

Under the Hood: Ghostscript Alpha Bits

When +antialias is passed before reading a PDF, ImageMagick alters the flags passed to the Ghostscript delegate:

  • Antialiasing enabled (-antialias): Ghostscript receives -dTextAlphaBits=4 -dGraphicsAlphaBits=4, which blends edges for smooth text and vector rendering.
  • Antialiasing disabled (+antialias): Ghostscript receives -dTextAlphaBits=1 -dGraphicsAlphaBits=1, which limits alpha blending to 1-bit, generating hard, aliased edges.

Disabling Font Antialiasing Exclusively

The +antialias switch disables antialiasing for both text and vector graphics. If your workflow requires disabling font antialiasing while retaining smooth rendering for vector paths, you must modify the Ghostscript entry directly in ImageMagick's delegates.xml configuration file.

  1. Locate your delegates.xml configuration file.
  2. Find the delegate entry for decode="pdf".
  3. Locate the parameter -dTextAlphaBits=%u.
  4. Replace %u with 1 explicitly for text: 
    -dTextAlphaBits=1 -dGraphicsAlphaBits=%u
  5. Save the file.

With this configuration, text will always render without smoothing, while graphics will continue to follow the standard -antialias behavior.
