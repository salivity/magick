Discard Color and Keep Alpha in ImageMagick

This guide explains how to remove all RGB color information from an image while preserving transparency information using ImageMagick's -alpha extract operator. By isolating the alpha channel, you can discard unwanted color channels and either export the transparency as an isolated grayscale mask or rebuild a flat-color image that retains the original transparency levels.

Understanding -alpha extract

In ImageMagick, the -alpha extract operator removes all RGB color channels from an image and transforms the alpha (transparency) channel into a visible, grayscale image. Fully opaque pixels become pure white, completely transparent pixels become pure black, and semi-transparent pixels become corresponding shades of gray. The alpha channel itself is then turned off.

To perform a direct extraction of the alpha channel to a grayscale file, run:

magick input.png -alpha extract mask.png

For ImageMagick version 6, replace magick with convert:

convert input.png -alpha extract mask.png

Retaining Transparency with Discarded Color

If your goal is to discard the original color data but keep the image transparent (creating a uniform silhouette such as solid black or white with the original alpha values), you can pair -alpha extract with the -alpha shape operator.

Creating a Uniform Black Silhouette with Original Transparency

magick input.png -alpha extract -background black -alpha shape output.png

Creating a Uniform White Silhouette with Original Transparency

magick input.png -alpha extract -background white -alpha shape output.png

In this process:

  1. -alpha extract strips out all original RGB color data and outputs a grayscale representation of the alpha channel.
  2. -background <color> specifies the uniform replacement color to use across all pixels.
  3. -alpha shape uses the grayscale values generated by -alpha extract to assign transparency back to the background color, ensuring all original color data is lost while the transparency curve is fully preserved.

Handling Images with Alpha Copy

An alternative workflow using -alpha extract involves copying the extracted mask back onto a solid color canvas using parentheses for operation containment:

magick input.png ( +clone -alpha extract ) -channel RGB -evaluate set 0 +channel -compose CopyOpacity -composite output.png

This method extracts the alpha channel into a cloned layer, wipes the color channels of the source to black (0% luminance), and uses the extracted mask to restore the original opacity, completely replacing the original color information.
