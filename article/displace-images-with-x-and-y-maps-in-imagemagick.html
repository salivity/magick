Displace Images with X and Y Maps in ImageMagick

This guide explains how to distort an image in ImageMagick using separate X (horizontal) and Y (vertical) displacement maps. You will learn how ImageMagick interprets color channels for 2D shifting, how to combine distinct grayscale maps into a single displacement map, and how to execute the command for precise pixel displacement.

Understanding Displacement Channels in ImageMagick

ImageMagick's -displace operator shifts pixels based on the intensity values in an overlay map. When applying two-dimensional distortion:

  • The Red channel controls X (horizontal) displacement.
  • The Green channel controls Y (vertical) displacement.
  • Neutral gray (#808080 or 50% intensity) represents zero displacement.
  • Values brighter than 50% shift pixels in the positive direction (right/down).
  • Values darker than 50% shift pixels in the negative direction (left/up).

Method: Combining Separate X and Y Maps

If you have two separate grayscale images—x_map.png for horizontal distortion and y_map.png for vertical distortion—you must merge them into the Red and Green channels of a single displacement map, then apply the displacement operator.

ImageMagick v7 Command

magick input.png \
  ( x_map.png y_map.png -background gray50 -combine ) \
  -virtual-pixel mirror \
  -displace 30x20 \
  output.png

ImageMagick v6 Command

convert input.png \
  \( x_map.png y_map.png -background gray50 -combine \) \
  -virtual-pixel mirror \
  -displace 30x20 \
  output.png

Command Breakdown

  1. input.png: The source image you want to distort.
  2. ( x_map.png y_map.png -background gray50 -combine ): Loads the two separate grayscale maps and packs them into a single image. x_map.png becomes the Red channel, y_map.png becomes the Green channel, and the background fills the Blue channel with 50% neutral gray.
  3. -virtual-pixel mirror: Defines how areas outside the image boundaries are sampled when pixels are pushed inward (options include transparent, edge, black, or mirror).
  4. -displace <X_scale>x<Y_scale>: Specifies the maximum displacement distance in pixels (or percentage if using %). For example, 30x20 means full white/black in the X map moves pixels up to 30 pixels horizontally, and full white/black in the Y map moves pixels up to 20 pixels vertically.
  5. output.png: The final distorted image.

Percentage-Based Scaling

If you prefer relative distortion scaling based on the original image dimensions, append a percentage sign (%) to the -displace arguments:

magick input.png ( x_map.png y_map.png -background gray50 -combine ) -displace 5%x10% output.png
