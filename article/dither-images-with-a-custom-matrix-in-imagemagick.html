Dither Images with a Custom Matrix in ImageMagick

Dithering simulates colors and gradients by strategically arranging limited palettes of pixels, and ImageMagick provides robust tools to achieve this through ordered dithering. By creating and loading a custom threshold matrix XML file, you can define unique dithering patterns tailored to specific aesthetic or functional needs. This guide covers how to structure a custom threshold matrix file, load it into ImageMagick, and apply it to your images via the command line.

1. Structure the Custom Threshold XML File

ImageMagick defines ordered dithering matrices within an XML structure using the <threshold> tag. Create a new file named thresholds.xml in your working directory.

Below is an example defining a custom 4x4 Bayer-style threshold matrix:

<?xml version="1.0" encoding="UTF-8"?>
<thresholds>
  <threshold map="custom_4x4" alias="c4">
    <description>Custom 4x4 Ordered Dither</description>
    <levels width="4" height="4" divisor="16">
       0  8  2 10
      12  4 14  6
       3 11  1  9
      15  7 13  5
    </levels>
  </threshold>
</thresholds>
  • map: The unique name you will reference in the command line.
  • width and height: The dimensions of the matrix grid.
  • divisor: The normalization divisor. The threshold values in the grid are divided by this number (values range from 0 to divisor - 1).

2. Configure ImageMagick to Read the Custom File

ImageMagick looks for configuration files in specific system directories. To instruct ImageMagick to read your local thresholds.xml, set the MAGICK_CONFIGURE_PATH environment variable to the directory containing your file.

On Linux / macOS:

export MAGICK_CONFIGURE_PATH="."

On Windows (Command Prompt):

set MAGICK_CONFIGURE_PATH=.

On Windows (PowerShell):

$env:MAGICK_CONFIGURE_PATH="."

3. Verify the Custom Matrix

Check if ImageMagick recognizes your custom matrix by listing all available threshold maps:

magick -list threshold

Look for custom_4x4 (or the alias c4) in the output list.

4. Apply the Ordered Dither to an Image

Apply the custom threshold matrix using the -ordered-dither operator followed by your map name and the number of target color levels per channel.

Monochrome (1-bit Black and White):

magick input.jpg -colorspace Gray -ordered-dither custom_4x4,2 output.png
  • The ,2 specifies 2 levels (black and white).

Custom Color Levels:

magick input.jpg -ordered-dither custom_4x4,4,4,4 output.png
  • The 4,4,4 applies the custom dither using 4 levels for each RGB color channel (totaling 64 distinct colors).
