DPX Header Metadata Parameters in ImageMagick

This article provides a concise overview of the parameters and properties used to read, preserve, and encode Digital Picture Exchange (DPX) motion picture header metadata in ImageMagick. ImageMagick adheres to the SMPTE 268M standard for DPX files, utilizing specific command-line defines and artifact properties prefixed with dpx: to read and encode detailed camera, production, and film stock metadata.

Understanding DPX Headers in ImageMagick

The DPX specification contains multiple header sections: Generic Header, Industry Specific Header (Motion Picture Film Information), Television Specific Information, and User Defined Data. In ImageMagick, these metadata fields are treated as image properties. You can modify, inject, or preserve these headers during image processing using the -set or -define options.

Motion Picture Film Information (dpx:mp.*)

The Motion Picture Information header stores physical film and production-specific details. ImageMagick maps these to key-value attributes starting with dpx:mp.:

  • dpx:mp.film.manufacturer.id: A two-digit code representing the film manufacturer.
  • dpx:mp.film.type: A two-digit code identifying the film stock type.
  • dpx:mp.perfs.per.frame: Specifies the film perforation count per frame (e.g., 2, 3, 4).
  • dpx:mp.format: Defines the film gauge or recording format (e.g., 35mm, 16mm).
  • dpx:mp.frame.rate: Defines the camera capture frame rate in frames per second (e.g., 24, 23.976, 48).
  • dpx:mp.shutter.angle: The camera shutter angle during capture, defined in degrees.
  • dpx:mp.frame.position: Specifies the current frame's position within the overall sequence.
  • dpx:mp.sequence.length: The total length of the sequence in frames.
  • dpx:mp.held.count: Denotes how many consecutive frames display this identical image.
  • dpx:mp.frame.id: A unique alphanumeric identifier or label assigned to the frame.
  • dpx:mp.slate.info: Production slate information, typically capturing scene, shot, take, and roll numbers.

Television Information Header (dpx:tv.*)

When video cameras or telecine systems generate DPX files, broadcast and timecode information is routed through the Television Information Header:

  • dpx:tv.time.code: The SMPTE timecode encoded as an 8-character hex string representing hours, minutes, seconds, and frames (e.g., 01:23:45:12).
  • dpx:tv.user.bits: User-defined timecode bits for custom indexing.
  • dpx:tv.frame.rate: The playback or temporal video sampling rate in frames per second.
  • dpx:tv.video.signal: Encodes the video signal standard (e.g., NTSC, PAL, SMPTE 274M).

DPX Encoding Defines (-define dpx:*)

In addition to property-level tags, ImageMagick provides operational defines that control how the underlying DPX file structure and bit-packing are written to disk:

  • -define dpx:bits-per-sample=<value>: Controls the bit depth per channel (commonly 8, 10, 12, or 16). 10-bit is standard for motion picture workflows.
  • -define dpx:storage-format=<value>: Configures the pixel data storage orientation, accepting either packed or padded.
  • -define dpx:packing-method=<value>: Defines whether 10-bit data packing aligns according to SMPTE Method A (a) or Method B (b).
  • -define dpx:swap-samples=<true|false>: Toggles sample byte ordering to accommodate specific hardware or vendor requirements.

Applying Metadata via the Command Line

To set or modify these parameters during conversion, use -set followed by the target property name:

magick input.tif \
  -depth 10 \
  -define dpx:packing-method=a \
  -set dpx:mp.frame.rate 24 \
  -set dpx:mp.slate.info "Scene 12 Take 4" \
  -set dpx:tv.time.code "01:00:15:08" \
  output.dpx

To view all existing DPX metadata from an image, run:

magick identify -verbose input.dpx | grep "dpx:"
