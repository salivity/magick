Draw an Elliptical Arc in ImageMagick

This guide explains how to draw an elliptical arc segment using ImageMagick's command-line interface. You will learn the exact command syntax, the parameters required to define the ellipse's center, radii, and angle span, along with clear examples for both unfilled arc strokes and filled elliptical segments.

The Command Syntax

To draw an elliptical arc in ImageMagick, use the -draw operator with the ellipse primitive. The basic syntax is:

magick input.png -stroke color -fill none -draw "ellipse ox,oy rx,ry a0,a1" output.png

For ImageMagick version 6, replace magick with convert.

Parameter Breakdown

  • ox,oy: The center coordinates (X and Y) of the ellipse.
  • rx,ry: The horizontal (X-axis) and vertical (Y-axis) radii of the ellipse.
  • a0: The starting angle in degrees (measured clockwise, where 0 degrees is at the 3 o'clock position).
  • a1: The ending angle in degrees.

Practical Examples

1. Stroke-Only Arc Segment

To draw a curved line (open arc) without filling the shape, set -fill none and specify a -stroke color and -strokewidth:

magick -size 400x400 xc:white \
  -stroke black -strokewidth 3 -fill none \
  -draw "ellipse 200,200 150,100 45,225" \
  elliptical_arc.png

This creates a 400x400 white canvas with an elliptical arc centered at (200, 200), an X-radius of 150, a Y-radius of 100, sweeping from 45 degrees to 225 degrees.

2. Filled Elliptical Segment (Pie Slice)

To fill the interior of the arc segment, set -fill to a color:

magick -size 400x400 xc:white \
  -stroke black -strokewidth 2 -fill red \
  -draw "ellipse 200,200 150,100 0,90" \
  filled_arc_segment.png

This draws a filled pie-slice segment from 0 degrees (east) to 90 degrees (south).

Alternative: Using the SVG Path Primitive

For advanced SVG-compliant elliptical arcs connecting specific points, use the path primitive with the A command:

magick -size 400x400 xc:white \
  -stroke blue -strokewidth 3 -fill none \
  -draw "path 'M 100,200 A 150,100 0 0,1 300,200'" \
  svg_arc.png
  • M 100,200: Moves to starting point (100, 200).
  • A rx ry x-axis-rotation large-arc-flag sweep-flag x y: Draws an arc with radii 150 and 100 to the endpoint (300, 200).
