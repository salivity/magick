Draw Antialiased Bezier Curves in ImageMagick

This guide explains how to render smooth, antialiased Bezier curves on images using ImageMagick's command-line tools. You will learn the syntax for the bezier drawing primitive, how to configure coordinates for quadratic and cubic curves, and how to ensure proper antialiasing and stroke quality.

Basic Syntax for Drawing Bezier Curves

ImageMagick provides the -draw operator with the bezier primitive to construct curves. By default, ImageMagick applies antialiasing to all vector drawing primitives to prevent jagged edges.

The basic command structure using ImageMagick v7 (magick) is:

magick -size 500x500 xc:white \
  -stroke "#007acc" -strokewidth 4 -fill none \
  -draw "bezier 50,450 100,50 400,50 450,450" \
  output.png

If you are using ImageMagick v6, replace magick with convert.

Understanding Control Points

The shape of the Bezier curve depends on the number and placement of the coordinate pairs provided:

  • 3 Points (Quadratic Bezier): Start (x1,y1), Control Point (x2,y2), End (x3,y3)
  • 4 Points (Cubic Bezier): Start (x1,y1), First Control (x2,y2), Second Control (x3,y3), End (x4,y4)
  • Polybezier (Joined Curves): You can provide \(3n + 1\) points to create multiple connected cubic Bezier segments in a single command.

Quadratic Curve Example

magick -size 400x300 xc:white \
  -stroke red -strokewidth 3 -fill none \
  -draw "bezier 50,250 200,20 350,250" \
  quadratic.png

Cubic Curve Example

magick -size 400x300 xc:white \
  -stroke darkgreen -strokewidth 3 -fill none \
  -draw "bezier 50,200 150,50 250,250 350,100" \
  cubic.png

Managing Antialiasing and Stroke Quality

ImageMagick enables antialiasing by default. However, you can fine-tune rendering quality using the following options:

  • Enable/Disable Antialiasing: Vector antialiasing is active by default. If it was explicitly turned off, use +antialias to re-enable it (-antialias disables antialiasing in ImageMagick syntax).
  • Line Caps and Joins: For smooth endpoints, specify the cap style using -stroke-linecap (options: butt, round, square):
magick -size 500x500 xc:white \
  +antialias \
  -stroke black -strokewidth 6 -stroke-linecap round -fill none \
  -draw "bezier 50,400 150,100 350,100 450,400" \
  smooth_curve.png

Drawing on an Existing Image

To draw a curve over an existing image file instead of a blank canvas, replace the -size and xc: parameters with the source image path:

magick input.jpg \
  -stroke yellow -strokewidth 3 -fill none \
  -draw "bezier 100,500 300,100 600,100 800,500" \
  output.jpg

Using SVG Path Syntax as an Alternative

ImageMagick also supports SVG path definitions inside the -draw operator, which provides precise control over cubic (C) and quadratic (Q) Bezier commands:

magick -size 500x500 xc:white \
  -stroke purple -strokewidth 4 -fill none \
  -draw "path 'M 50,450 C 100,50 400,50 450,450'" \
  svg_bezier.png
