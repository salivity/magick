Draw Open and Closed Polygons in ImageMagick

This guide explains the exact command-line syntax for drawing both open and closed polygons using the -draw operator in ImageMagick. You will learn how to implement the polyline primitive for open paths and the polygon primitive for closed shapes, along with configuring essential styling parameters such as fill, stroke color, and stroke width.

Drawing Closed Polygons

To draw a closed polygon, ImageMagick provides the polygon primitive. This primitive automatically connects the last coordinate pair back to the first coordinate pair, forming a sealed boundary that can be filled with color.

Syntax

magick input.png -fill <fill_color> -stroke <stroke_color> -strokewidth <width> -draw "polygon x1,y1 x2,y2 x3,y3 ... xN,yN" output.png

Example: Closed Triangle

magick -size 300x300 xc:white -fill skyblue -stroke blue -strokewidth 3 -draw "polygon 50,250 150,50 250,250" closed_polygon.png

In this command:

  • polygon 50,250 150,50 250,250 defines three vertices. ImageMagick automatically draws an edge connecting (250,250) back to (50,250).
  • -fill skyblue colors the interior of the polygon.
  • -stroke blue colors the perimeter.

Drawing Open Polygons

To draw an open polygon (a sequence of connected line segments without closing the final gap), use the polyline primitive. When creating open paths, set -fill none to prevent ImageMagick from attempting to fill the area between vertices.

Syntax

magick input.png -fill none -stroke <stroke_color> -strokewidth <width> -draw "polyline x1,y1 x2,y2 x3,y3 ... xN,yN" output.png

Example: Open Zig-Zag Path

magick -size 300x300 xc:white -fill none -stroke red -strokewidth 4 -draw "polyline 30,270 90,50 180,250 270,30" open_polygon.png

In this command:

  • polyline connects each sequential coordinate pair without drawing a closing line from (270,30) to (30,270).
  • -fill none ensures only the line segments are rendered.

Coordinate Formatting Rules

ImageMagick accepts several coordinate formatting conventions inside the -draw string:

  • Comma-separated coordinate pairs: x1,y1 x2,y2 x3,y3
  • Space-separated coordinates: x1 y1 x2 y2 x3 y3
  • Floating-point values: Subpixel rendering is supported (e.g., 50.5,120.25 150.75,30.5).

Essential Styling Properties

Configure these options before the -draw operator to control polygon rendering:

  • -stroke <color>: Defines the line color (e.g., black, #ff0000, rgba(0,0,0,0.5)).
  • -strokewidth <pixels>: Sets line thickness in pixels.
  • -fill <color>: Sets the interior fill color (use none to disable filling).
  • -stroke-linejoin <type>: Controls how corners connect (miter, round, or bevel).
  • -stroke-linecap <type>: Controls the end caps of open polylines (butt, round, or square).
