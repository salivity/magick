Draw Semi-Transparent Box in ImageMagick

This guide explains how to draw a semi-transparent colored box over an existing image using ImageMagick. By utilizing the -draw operator alongside RGBA or 8-digit hexadecimal color values, you can create translucent overlays for banners, watermarks, or dimmed backgrounds directly from the command line.

Basic Syntax and Example

To draw a semi-transparent rectangle over an image, use the magick command (or convert in ImageMagick v6) with the -fill and -draw options:

magick input.jpg -fill "rgba(0, 0, 0, 0.5)" -draw "rectangle 50,100 450,250" output.jpg

In ImageMagick v6, replace magick with convert:

convert input.jpg -fill "rgba(0, 0, 0, 0.5)" -draw "rectangle 50,100 450,250" output.jpg

Parameter Breakdown

  • input.jpg: The source image you want to modify.
  • -fill "rgba(r, g, b, a)": Sets the fill color and transparency level.
    • r, g, b: Red, green, and blue values ranging from 0 to 255.
    • a: Alpha (opacity) value ranging from 0.0 (completely transparent) to 1.0 (completely opaque).
  • -draw "rectangle x0,y0 x1,y1": Draws the rectangle.
    • x0,y0: The coordinates of the top-left corner (horizontal, vertical).
    • x1,y1: The coordinates of the bottom-right corner.
  • output.jpg: The name of the resulting output file.

Alternative Color Formats

You can also define semi-transparent colors using 8-character hexadecimal notation (#RRGGBBAA):

magick input.jpg -fill "#0000FF80" -draw "rectangle 100,100 300,300" output.jpg

In this example, #0000FF80 represents blue (#0000FF) with 50% opacity (80 in hexadecimal, equal to 128 out of 255).

Full-Width Banner Overlay

To create a full-width banner across the bottom of an image, dynamically specify coordinates or use the exact pixel dimensions:

magick input.jpg -fill "rgba(255, 255, 255, 0.6)" -draw "rectangle 0,400 800,500" output.jpg

This creates a white, 60% opaque strip running from x=0 to x=800 between the vertical coordinates y=400 and y=500.
