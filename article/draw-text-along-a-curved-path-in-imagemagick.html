Draw Text Along a Curved Path in ImageMagick

This article provides the syntax and practical commands for rendering text along curved and arched trajectories in ImageMagick. It covers the primary methods used to achieve this effect: the built-in -distort Arc operator for uniform circular curves and the Scalable Vector Graphics (SVG) <textPath> method for complex, arbitrary curves.

Method 1: Using the -distort Arc Operator

The most common and direct way to curve text in ImageMagick is by generating a text label and applying a circular arc distortion.

Basic Syntax

magick -background none -fill "<color>" -font "<font-name>" -pointsize <size> label:"<your text>" -virtual-pixel None -distort Arc "<angle> [rotation] [outer_radius] [inner_radius]" output.png

Parameter Breakdown

  • <angle>: The arc angle in degrees (e.g., 120 spreads the text over a 120-degree sweep; 360 wraps the text into a full circle).
  • [rotation] (optional): Rotates the curved text around the center point (default is 0, which centers the text at the top).
  • [outer_radius] (optional): The radius from the center point to the outer edge of the text.
  • [inner_radius] (optional): The radius to the inner edge of the text.

Example: Upward Arched Text

magick -background transparent -fill "#1E293B" -font Arial -pointsize 40 \
  label:"Curved Text with ImageMagick" \
  -virtual-pixel None \
  -distort Arc 100 \
  arched_text.png

Example: Inverted (Downward) Arc

To bend text downwards (like a smile rather than a rainbow), rotate the text by 180 degrees using the rotation argument:

magick -background transparent -fill "#1E293B" -font Arial -pointsize 40 \
  label:"Downward Curved Text" \
  -virtual-pixel None \
  -distort Arc "100 180" \
  downward_text.png

Method 2: Using SVG textPath for Arbitrary Curves

For non-circular, custom paths (such as Bezier curves or S-curves), use ImageMagick’s built-in SVG vector rendering engine.

Basic Syntax

magick -size <width>x<height> xc:none -draw '
  path "M <x1>,<y1> Q <cx>,<cy> <x2>,<y2>"
' text_on_curve.png

To bind text directly along the curve, embed an inline SVG text path:

magick inline:'<?xml version="1.0" encoding="UTF-8"?>
<svg xmlns="http://www.w3.org/2000/svg" xmlns:xlink="http://www.w3.org/1999/xlink" width="600" height="300">
  <defs>
    <path id="curve" d="M 50,200 Q 300,50 550,200" fill="none" />
  </defs>
  <text font-family="Arial" font-size="32" fill="#1E293B">
    <textPath xlink:href="#curve">
      Text following an arbitrary Bezier curve
    </textPath>
  </text>
</svg>' custom_curve.png

SVG Path Syntax Overview

  • M x,y: Move to starting coordinate (x, y).
  • Q cx,cy x,y: Quadratic Bezier curve using control point (cx, cy) ending at (x, y).
  • C cx1,cy1 cx2,cy2 x,y: Cubic Bezier curve with two control points.
