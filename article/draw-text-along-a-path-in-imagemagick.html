Draw Text Along a Path in ImageMagick

This article explains how to render text along an arbitrary vector path using ImageMagick. While standard raster manipulation commands handle linear text, curved or arbitrary path rendering in ImageMagick is achieved by executing an embedded Scalable Vector Graphics (SVG) <textPath> structure directly from the command line.

The Command

To draw text along an arbitrary path, pass an SVG definition containing a defined <path> and <textPath> element directly to the magick command (or convert in ImageMagick v6):

magick -size 600x400 xc:white \
  -font "Arial" -pointsize 24 -fill black \
  "svg:<svg width='600' height='400' xmlns='http://www.w3.org/2000/svg' xmlns:xlink='http://www.w3.org/1999/xlink'>
    <defs>
      <path id='curve' d='M 50 300 Q 300 50 550 300' fill='none' />
    </defs>
    <text font-family='Arial' font-size='24' fill='black'>
      <textPath href='#curve'>Text rendered along an arbitrary vector path.</textPath>
    </text>
  </svg>" \
  output.png

How It Works

  1. Canvas Initialization: -size 600x400 xc:white creates a blank background canvas.
  2. SVG Vector Path (<path d="..." />): The d attribute defines the arbitrary vector path using standard SVG path syntax (such as Move M, Cubic Bézier C, or Quadratic Bézier Q).
  3. Text Mapping (<textPath href="#curve">): The <textPath> element attaches the specified text string to the path referenced by the path's unique id.
  4. SVG Input Protocol (svg:...): Prefixing the vector code with svg: tells ImageMagick to process the string using its vector rendering delegate (such as librsvg or internal MSVG).
  5. Output: The rendered vector is drawn onto the raster canvas and saved as output.png.

Alternatively, if the SVG is stored in a separate file (e.g., path_text.svg), use the streamlined command:

magick path_text.svg output.png
