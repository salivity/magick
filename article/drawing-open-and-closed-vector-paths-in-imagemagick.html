Drawing Open and Closed Vector Paths in ImageMagick

ImageMagick enables the creation of complex 2D graphics using its -draw operator, which supports SVG-compliant path syntax to render both open and closed vector shapes. This guide details the command syntax, parameters, and practical examples for constructing open paths (lines, arcs, and curves without connected ends) and closed paths (fully enclosed shapes with fill and stroke options) directly from the command line.

The ImageMagick Path Syntax Structure

Vector paths are defined inside the -draw operator using the path keyword, followed by SVG path data enclosed in quotes:

magick -size <WIDTH>x<HEIGHT> xc:<BACKGROUND_COLOR> \
  -stroke <STROKE_COLOR> -strokewidth <PIXELS> -fill <FILL_COLOR> \
  -draw "path '<PATH_COMMANDS>'" output.png

Note: In ImageMagick v6, use convert instead of magick.

Rendering Open Vector Paths

An open path consists of a sequence of lines or curves where the starting point and ending point do not meet. In SVG path syntax, an open path simply omits the Z (closepath) command.

To render only the outline without unintended fill rendering, explicitly set -fill none.

Syntax:

magick -size 300x200 xc:white \
  -fill none -stroke blue -strokewidth 4 \
  -draw "path 'M 30,150 L 100,50 L 200,150 L 270,50'" \
  open_polyline.png

Curved Open Path (Cubic Bézier):

magick -size 300x200 xc:white \
  -fill none -stroke red -strokewidth 3 \
  -draw "path 'M 30,100 C 80,20 220,180 270,100'" \
  open_curve.png

Alternative Primitive for Open Paths:

You can also use the polyline primitive for basic multi-segment open lines:

magick -size 300x200 xc:white \
  -fill none -stroke black -strokewidth 2 \
  -draw "polyline 30,150 100,50 200,150 270,50" \
  polyline.png

Rendering Closed Vector Paths

A closed path forms a complete loop where the final coordinate connects back to the initial coordinate. This is accomplished using the Z or z command at the end of the path definition. Closed paths can be filled with a solid color, pattern, or left transparent.

Syntax:

magick -size 300x200 xc:white \
  -fill lightblue -stroke navy -strokewidth 3 \
  -draw "path 'M 50,150 L 150,30 L 250,150 Z'" \
  closed_triangle.png

Complex Closed Path with Arcs and Curves:

magick -size 300x200 xc:white \
  -fill orange -stroke black -strokewidth 2 \
  -draw "path 'M 60,100 C 60,40 140,40 140,100 C 140,160 220,160 220,100 L 220,170 L 60,170 Z'" \
  closed_shape.png

Alternative Primitive for Closed Paths:

You can also use the polygon primitive, which automatically connects the last coordinate back to the first:

magick -size 300x200 xc:white \
  -fill green -stroke darkgreen -strokewidth 2 \
  -draw "polygon 50,150 150,30 250,150" \
  polygon.png

Core Path Command Reference

The commands inside path '...' follow standard SVG syntax. Uppercase commands use absolute coordinates; lowercase commands use relative coordinates.

Command Name Description
M / m MoveTo Moves the pen to a starting coordinate without drawing.
L / l LineTo Draws a straight line to the target coordinate.
H / h Horizontal LineTo Draws a horizontal line to a given X coordinate.
V / v Vertical LineTo Draws a vertical line to a given Y coordinate.
C / c Cubic Bézier Draws a cubic Bézier curve using two control points.
S / s Smooth Cubic Bézier Draws a smooth cubic Bézier curve.
Q / q Quadratic Bézier Draws a quadratic curve with one control point.
T / t Smooth Quadratic Draws a smooth quadratic Bézier curve.
A / a Elliptical Arc Draws an arc segment based on radius and angles.
Z / z ClosePath Closes the current path by drawing a line to the initial M coordinate.
