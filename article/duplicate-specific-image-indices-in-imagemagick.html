Duplicate Specific Image Indices in ImageMagick

This article explains how the ImageMagick -duplicate operator creates copies of specific image indices within an active image sequence. It covers the underlying syntax, how the operator interprets zero-based and range-based index parameters, and how newly created duplicates are appended to the sequence in memory.

Syntax and Parameters

The -duplicate operator in ImageMagick allows you to duplicate one or more images from the current image sequence in memory. The basic syntax is:

-duplicate count[,indexes]

  • count: The number of copies to create for each specified image. This must be an integer of 1 or greater.
  • indexes: An optional parameter defining which specific image or range of images to duplicate. If omitted, ImageMagick defaults to duplicating the last image in the current sequence (index -1).

How Indexing Works

ImageMagick uses zero-based indexing for the image sequence held in memory:

  • 0 refers to the first image.
  • 1 refers to the second image.
  • Negative integers count backward from the end of the list, where -1 is the last image, -2 is the second-to-last image, and so forth.

You can target specific indices using individual numbers, comma-separated lists, or ranges:

  • Single index: 1,0 creates 1 duplicate of the image at index 0 (the first image).
  • Index range: 2,1-3 creates 2 duplicates of each image from index 1 through index 3.
  • Negative index: 1,-1 creates 1 duplicate of the last image in the list.

Image List Execution Behavior

When ImageMagick processes the -duplicate operator, it performs the following steps:

  1. Resolution: It resolves the specified index arguments against the current sequence of images.
  2. Cloning: For each matched index, ImageMagick creates in-memory clones matching the specified count. The original images remain unaltered at their original positions.
  3. Appending: The generated duplicates are appended sequentially to the very end of the current image sequence.

For example, consider an image sequence containing three images: [A (0), B (1), C (2)].

Running the command:

magick A.png B.png C.png -duplicate 2,1 output.png

ImageMagick targets index 1 (B.png) and creates two duplicates. It appends these duplicates to the end of the list, resulting in an output sequence of five images: [A, B, C, B, B].
