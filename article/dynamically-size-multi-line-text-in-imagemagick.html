Dynamically Size Multi-Line Text in ImageMagick

Rendering multi-line text dynamically to fit an exact box in ImageMagick is achieved using the built-in caption: input protocol. Unlike standard text-rendering options that require manual line breaks and fixed font sizes, caption: automatically calculates word wrapping and scales the font size up or down to maximize the text coverage within predefined dimensions.

The Solution: Using the caption: Protocol

To dynamically scale and wrap text into an exact bounding box, define the target width and height using the -size option and pass your text using caption:. Leave the -pointsize option unset (or explicitly set it to 0) so ImageMagick can automatically compute the optimal font size.

Here is the standard command for ImageMagick v7:

magick -size 400x300 \
       -background lightblue \
       -fill black \
       -font Arial \
       -gravity center \
       caption:"This is a block of dynamic multi-line text that will automatically wrap and scale to completely fill the specified box." \
       output.png

(Note: For ImageMagick v6, replace magick with convert.)

Overlaying Dynamic Text onto an Existing Image

To place the auto-sized text box over a specific region of an existing image, render the caption with a transparent background and composite it onto the base canvas.

magick base_image.jpg \
       \( -size 500x200 \
          -background none \
          -fill white \
          -font Helvetica-Bold \
          -gravity center \
          caption:"Dynamic headline sized perfectly to the region." \) \
       -geometry +50+100 \
       -composite \
       final_output.jpg

Key Parameters Explained

  • -size WIDTHxHEIGHT: Defines the strict boundary box. ImageMagick will continuously adjust the font size until the multi-line string fills this exact area without overflowing.
  • caption:"...": Instructs ImageMagick to perform automatic word wrapping and dynamic point size calculation. Do not use label:, as label: does not perform automatic line breaks.
  • -gravity: Controls the alignment of the text inside the bounding box. Options like center, northwest, or south determine horizontal alignment as well as vertical positioning if the text does not perfectly fill the height.
  • -background none: Makes the bounding box background transparent, ideal when compositing text over other graphics.
  • Avoid -pointsize: Defining a fixed -pointsize disables the dynamic sizing algorithm, which will cause the text to overflow if the box is too small.
