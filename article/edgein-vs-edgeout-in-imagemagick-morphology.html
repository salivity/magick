EdgeIn vs EdgeOut in ImageMagick Morphology

In ImageMagick, the -morphology operator provides specialized edge-detection methods designed to extract the outlines of shapes and objects within an image. While both EdgeIn and EdgeOut generate clean, precise boundary lines, they differ fundamentally in where the generated outline is placed relative to the original object's perimeter: EdgeIn draws the outline strictly within the interior of the shape, whereas EdgeOut generates the outline entirely on the outside in the adjacent background. This guide details the mathematical mechanics, visual differences, and practical use cases for both operators.

How Morphological Edge Detection Works

Morphological edge operators in ImageMagick rely on basic morphological operations—specifically Dilation (expanding white/foreground regions) and Erosion (shrinking white/foreground regions)—using a specified structuring element (kernel), such as Disk, Diamond, or Square.

When extracting edges, ImageMagick compares the modified image against the original image using subtraction.

What is EdgeIn?

EdgeIn (Internal Edge) generates a stroke along the perimeter of an object, drawn entirely inside the original boundaries of the shape.

  • Mathematical Formula: Original Image - Erode(Image)
  • Behavior: The operator first erodes (shrinks) the foreground shapes by the radius of the specified kernel. It then subtracts this shrunken version from the original image.
  • Output Characteristics: The outer edge of the resulting outline aligns exactly with the outer boundary of the original object. The thickness of the line grows inward toward the center of the shape.

CLI Example

magick input.png -morphology EdgeIn Disk:1 edge_in.png

What is EdgeOut?

EdgeOut (External Edge) generates an outline strictly outside the original boundaries of the shape.

  • Mathematical Formula: Dilate(Image) - Original Image
  • Behavior: The operator dilates (expands) the foreground shapes into the background by the radius of the specified kernel. It then subtracts the original shape from this expanded version.
  • Output Characteristics: The inner edge of the resulting outline touches the outer boundary of the original shape, but the stroke itself extends into the surrounding background. The original footprint of the object remains empty.

CLI Example

magick input.png -morphology EdgeOut Disk:1 edge_out.png

Key Differences

Feature EdgeIn EdgeOut
Placement Inside the object's boundary Outside the object's boundary
Operation Original - Eroded Dilated - Original
Total Dimensions Matches original object bounds Slightly larger than original bounds
Interior Cavity Preserved, stroke expands inward Preserved, untouched
Neighboring Pixels Does not bleed into adjacent objects Can bleed or merge into nearby objects

When to Choose EdgeIn vs. EdgeOut

  • Choose EdgeIn when you need an outline that does not exceed the original dimensions of the graphic or mask. This is useful in constrained layouts, UI icons, or segmentation masks where expanding outward would overlap adjacent elements.
  • Choose EdgeOut when you need to create halos, glows, borders, or selection highlights that frame an object without obscuring any of the object's internal features or text.
