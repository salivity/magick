Elliptical Crop Centered on Image in ImageMagick

This guide demonstrates how to crop an image into a centered ellipse using ImageMagick. You will learn the exact command-line syntax required to create an elliptical transparency mask matching your image's dimensions, apply it to the source image, and export the result to a format that supports transparency.

ImageMagick v7 Syntax

In ImageMagick v7, dynamic FX expressions allow you to calculate the exact center and radii automatically, regardless of the input image dimensions:

magick input.jpg \( +clone -alpha transparent -background none -fill white -draw "ellipse %[fx:w/2],%[fx:h/2] %[fx:w/2],%[fx:h/2] 0,360" \) -compose DstIn -composite output.png

Note for Windows Command Prompt: Remove the backslashes before the parentheses:

magick input.jpg ( +clone -alpha transparent -background none -fill white -draw "ellipse %[fx:w/2],%[fx:h/2] %[fx:w/2],%[fx:h/2] 0,360" ) -compose DstIn -composite output.png

ImageMagick v6 Syntax

For ImageMagick v6, use the convert binary with the same masking logic:

convert input.jpg \( +clone -alpha transparent -background none -fill white -draw "ellipse %[fx:w/2],%[fx:h/2] %[fx:w/2],%[fx:h/2] 0,360" \) -compose DstIn -composite output.png

Command Breakdown

  • input.jpg: Specifies the source image file.
  • \( +clone ... \): Creates an in-memory copy of the source image to match its width and height.
  • -alpha transparent -background none: Clears the cloned image canvas, making it fully transparent.
  • -fill white: Sets the drawing color to solid white for the mask area.
  • -draw "ellipse center_x,center_y radius_x,radius_y 0,360": Draws a complete ellipse. Using %[fx:w/2] and %[fx:h/2] sets the center and horizontal/vertical radii to half the image's dimensions, creating a centered ellipse spanning the entire canvas.
  • -compose DstIn -composite: Merges the original image with the mask, keeping only the pixels inside the ellipse and rendering the outer area transparent.
  • output.png: Specifies the output file. A format supporting alpha transparency (such as PNG or WebP) is required to preserve the transparent background.

Custom Ellipse Radii Example

If you want a specific ellipse size rather than filling the entire canvas, replace the FX expressions with explicit pixel values. For example, to crop a centered ellipse with a horizontal radius of 200px and a vertical radius of 100px:

magick input.jpg \( +clone -alpha transparent -background none -fill white -draw "ellipse %[fx:w/2],%[fx:h/2] 200,100 0,360" \) -compose DstIn -composite output.png
