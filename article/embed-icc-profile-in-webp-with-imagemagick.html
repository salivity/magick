Embed ICC Profile in WebP with ImageMagick

Embedding an ICC color profile into a WebP image ensures accurate and consistent color reproduction across different displays, browsers, and operating systems. This guide explains how to use ImageMagick to embed, convert, and verify color profiles in WebP images directly from the command line.

Basic Command to Embed an ICC Profile

To embed an ICC profile into a WebP image, use the -profile option followed by the path to your .icc or .icm profile file.

magick input.webp -profile path/to/profile.icc output.webp

If you are converting another image format (such as PNG or JPEG) into WebP while embedding the profile, the command structure remains the same:

magick input.jpg -profile path/to/profile.icc output.webp

Assigning vs. Converting Color Profiles

ImageMagick handles the -profile operator differently depending on how many times it is used in a single command:

  • Converting between profiles: If the source image already contains an embedded profile, using -profile target.icc converts the pixel data to the target color space and embeds the new profile.
  • Assigning a missing source profile: If the source image lacks a color profile, but you know its color space, invoke -profile twice. The first instance assigns the input profile without altering pixel data, and the second converts it to the destination profile:
magick input.webp -profile source_profile.icc -profile target_profile.icc output.webp

Preserving Existing Profiles During Conversion

ImageMagick automatically preserves embedded ICC profiles when converting files to WebP. Ensure you do not include the -strip flag, as this flag removes all metadata and embedded color profiles to reduce file size.

Verifying the Embedded Profile

To confirm that the ICC profile was successfully written to the WebP container, run the identify command:

magick identify -verbose output.webp

Look for the Profiles: section in the output. If the profile was successfully embedded, it will list Profile-icc along with its byte size and color space attributes. Alternatively, you can use ExifTool to check:

exiftool -ICC_Profile:all output.webp
