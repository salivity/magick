Embed IPTC Metadata in Images with ImageMagick

This guide explains how to embed IPTC (International Press Telecommunications Council) metadata profiles into digital images using ImageMagick. You will learn how to apply existing binary IPTC profile files directly to images, write individual IPTC fields using ImageMagick command-line parameters, and verify that the metadata was successfully embedded.

Prerequisites

Ensure you have ImageMagick installed on your system. Modern installations use the magick command (ImageMagick v7), while legacy versions use convert (ImageMagick v6).

Method 1: Embedding a Pre-Existing IPTC Profile File

If you have a binary IPTC profile file (commonly saved with a .iptc, .8bim, or .app13 extension), you can attach it directly to an image using the -profile operator.

Run the following command:

magick input.jpg -profile metadata.iptc output.jpg

This command injects the raw IPTC profile into the JPEG's APP13 header without altering image pixel data.

Method 2: Setting Specific IPTC Fields Directly

ImageMagick allows you to set specific IPTC tags using standard dataset identifiers via the -set option. IPTC datasets follow a Record:Dataset numbering format (for example, 2:05 represents the Image Name/Title, and 2:120 represents Caption/Abstract).

To embed standard IPTC fields into an image:

magick input.jpg \
  -set "IPTC:2:05" "Sample Image Title" \
  -set "IPTC:2:80" "Photographer Name" \
  -set "IPTC:2:116" "Copyright 2024, All Rights Reserved" \
  -set "IPTC:2:120" "A detailed description of the image content." \
  output.jpg

Common IPTC Record 2 Dataset Tags

  • IPTC:2:05 – Object Name / Title
  • IPTC:2:25 – Keywords
  • IPTC:2:80 – By-line (Creator/Author)
  • IPTC:2:85 – By-line Title
  • IPTC:2:110 – Credit
  • IPTC:2:115 – Source
  • IPTC:2:116 – Copyright Notice
  • IPTC:2:120 – Caption / Description

Method 3: Extracting and Transferring IPTC Profiles Between Images

You can copy an existing IPTC profile from a source image and apply it directly to a target image:

# Extract the IPTC profile to a standalone file
magick source.jpg iptc:extracted_profile.iptc

# Apply the extracted profile to the destination image
magick destination.jpg -profile extracted_profile.iptc output.jpg

Verifying Embedded IPTC Metadata

To confirm that the IPTC metadata has been successfully written to the target image file, inspect the image properties using identify:

magick identify -verbose output.jpg | grep -i "IPTC"

Alternatively, display specific IPTC metadata fields formatted directly:

magick identify -format "%[IPTC:2:05]\n%[IPTC:2:80]\n%[IPTC:2:120]\n" output.jpg
