Embed IPTC Metadata with ImageMagick

This article provides a concise guide on the syntax required to embed IPTC editorial metadata into image files using ImageMagick. You will learn how to inject individual IPTC tags directly from the command line, apply predefined IPTC profile files, and format multi-field editorial blocks using ImageMagick's 8BIM profile system.

Setting Individual IPTC Tags

To write specific IPTC metadata fields directly to an image without external files, use the -set operator followed by standard IPTC dataset identifiers:

magick input.jpg -set IPTC:2:120 "Editorial caption describing the event" -set IPTC:2:80 "Photographer Name" -set IPTC:2:110 "Credit Line" output.jpg

Common IPTC dataset tags include:

  • IPTC:2:05 - Object/Title Name
  • IPTC:2:25 - Keywords
  • IPTC:2:80 - Byline (Author/Creator)
  • IPTC:2:85 - Byline Title
  • IPTC:2:110 - Credit Line
  • IPTC:2:115 - Source
  • IPTC:2:116 - Copyright Notice
  • IPTC:2:120 - Caption / Abstract

Embedding a Binary IPTC Profile File

If you have an exported binary .iptc profile file, embed the entire block into the target image using the -profile flag:

magick input.jpg -profile metadata.iptc output.jpg

Embedding a Text-Based 8BIM Editorial Block

ImageMagick utilizes Photoshop 8BIM formatting to store IPTC metadata blocks. You can define multiple editorial fields inside a plain text file (editorial.txt) and embed it using the 8BIMTEXT delegate.

Create a text file named editorial.txt:

8BIM#1028="IPTC"
2#5="Headline"
2#25="news, editorial, press"
2#80="Jane Doe"
2#110="News Agency"
2#116="© 2025 News Agency"
2#120="A detailed description of the editorial subject matter."

Embed the text file using the following command:

magick input.jpg -profile 8BIMTEXT:editorial.txt output.jpg

Verifying Embedded IPTC Data

To confirm the IPTC block was written correctly, read the formatted properties using the identify command:

magick identify -verbose output.jpg | grep -i "IPTC"
