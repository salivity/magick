Embed Text Comments in Image Metadata Using ImageMagick

This guide explains how to embed custom text comments directly into an image's metadata using ImageMagick's command-line tools. Adding metadata comments is useful for copyright notices, descriptions, or tracking information without altering the visual appearance of the image. You will learn the exact commands to write inline comments, load comments from external text files, modify files in place, and verify the embedded metadata.

Embedding an Inline Comment

In ImageMagick 7, use the magick command along with the -set comment attribute to embed a custom string into an image:

magick input.jpg -set comment "Your custom text comment here" output.jpg

For ImageMagick 6 users, replace magick with convert:

convert input.jpg -set comment "Your custom text comment here" output.jpg

Embedding Comments from a Text File

If you have a multi-line comment, a lengthy description, or automated text stored in a file, prefix the filename with an @ symbol:

magick input.jpg -set comment "@description.txt" output.jpg

ImageMagick reads the contents of description.txt and embeds it directly into the image's comment field.

Modifying an Existing Image in Place

To update an image's comment without creating a new file, use the mogrify tool:

magick mogrify -set comment "Updated comment text" image.jpg

Note: This overwrites the original file permanently.

Reading and Verifying the Embedded Comment

To confirm that the comment was successfully written to the metadata, extract the comment using the identify command:

magick identify -format "%c\n" output.jpg

Alternatively, view all metadata properties (including EXIF and comment tags) by running:

magick identify -verbose output.jpg
