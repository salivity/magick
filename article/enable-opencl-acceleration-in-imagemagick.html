Enable OpenCL Acceleration in ImageMagick

This guide explains how to enable and verify OpenCL GPU hardware acceleration in ImageMagick to significantly speed up resource-intensive image processing tasks like resizing, blurring, and color adjustments.

1. Verify Existing OpenCL Support

Before making changes, check if your current ImageMagick installation already has OpenCL support built in.

Run the following command in your terminal:

magick -version

(On older versions, use convert -version)

Look at the Features line in the output. If OpenCL is listed, support is compiled into your binary:

Features: Cipher DPC HDRI Modules OpenMP OpenCL

2. Install GPU Drivers and OpenCL Runtimes

ImageMagick requires the appropriate OpenCL driver for your specific graphics hardware to utilize GPU acceleration:

  • NVIDIA: Install the proprietary NVIDIA GPU driver and the CUDA/OpenCL toolkit.
  • AMD: Install the AMD ROCm platform or proprietary AMDGPU-PRO drivers with OpenCL components.
  • Intel: Install the intel-opencl-icd or Intel Compute Runtime package.

To verify your system recognizes your OpenCL platform, run:

clinfo

3. Compile ImageMagick with OpenCL (If Not Enabled)

If your pre-built package lacks OpenCL support, you must compile ImageMagick from source with OpenCL enabled.

  1. Install OpenCL development headers (e.g., opencl-headers and ocl-icd-opencl-dev on Debian/Ubuntu).
  2. Configure the ImageMagick build with the --enable-opencl flag:
./configure --enable-opencl
  1. Verify that the configuration summary shows OpenCL: yes.
  2. Compile and install:
make
sudo make install
sudo ldconfig

4. Manage OpenCL via Environment Variables

When compiled with OpenCL support, ImageMagick will automatically attempt to use your GPU for compatible operations (such as -blur, -convolve, and -resize). You can control its behavior using environment variables.

  • Disable OpenCL temporarily:

    export MAGICK_OCL_DEVICE=OFF

  • Force OpenCL to use a specific device: Set the device index if you have multiple GPUs:

    export MAGICK_OCL_DEVICE=0

5. Test and Benchmark Performance

To verify that OpenCL is actively accelerating operations, run a computationally heavy filter and measure the execution time:

With OpenCL (Default):

time magick input.jpg -blur 0x15 output_gpu.jpg

Without OpenCL (CPU Only):

time MAGICK_OCL_DEVICE=OFF magick input.jpg -blur 0x15 output_cpu.jpg

Comparing the execution times will confirm that your GPU is properly processing the workload.
