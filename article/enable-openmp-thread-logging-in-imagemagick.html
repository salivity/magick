Enable OpenMP Thread Logging in ImageMagick

This article explains how to enable verbose OpenMP thread allocation logging in ImageMagick using dedicated environment variables. By configuring these variables, developers and system administrators can monitor thread pool activity, inspect dynamic thread allocation, and diagnose multithreaded performance bottlenecks across multi-core processors.

The primary environment variable used to log OpenMP thread allocation in ImageMagick is MAGICK_DEBUG. Setting this variable to Thread instructs ImageMagick's internal logging framework to capture and print detailed events regarding thread allocation, execution, and termination.

Enabling the Variable

To enable thread logging in a Linux or macOS terminal session, export the variable before running your ImageMagick command:

export MAGICK_DEBUG=Thread
magick input.jpg -resize 50% output.jpg

On Windows (Command Prompt):

set MAGICK_DEBUG=Thread
magick input.jpg -resize 50% output.jpg

On Windows (PowerShell):

$env:MAGICK_DEBUG="Thread"
magick input.jpg -resize 50% output.jpg

Combining Log Events

ImageMagick allows logging multiple operational subsystems simultaneously. If you require full visibility into OpenMP performance alongside memory and execution duration, separate the event names with commas:

export MAGICK_DEBUG="Thread,Resource,Cache"

To log all events supported by ImageMagick, set the value to All:

export MAGICK_DEBUG=All

Standard OpenMP Verbose Logging

Because ImageMagick relies on the system's underlying OpenMP implementation (such as GCC's libgomp or LLVM's libomp), you can also use native OpenMP environment variables in conjunction with MAGICK_DEBUG for deeper runtime diagnostics:

  • OMP_DISPLAY_ENV=VERBOSE: Forces the OpenMP runtime to print all active environment variables, core counts, and scheduling configurations upon initialization.
  • OMP_NUM_THREADS=n: Specifies the exact number of threads the runtime can allocate to parallel regions.

Combining MAGICK_DEBUG=Thread with OMP_DISPLAY_ENV=VERBOSE ensures that both ImageMagick's dispatch logic and the low-level OpenMP allocation details are written directly to standard error (stderr).
