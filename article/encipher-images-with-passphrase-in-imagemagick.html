Encipher Images with Passphrase in ImageMagick

This guide explains how to encipher and protect an image with a passphrase using ImageMagick's command-line tools. You will learn the exact syntax for both ImageMagick v7 and v6, how to prepare your passphrase file, and how to decipher the image back to its original state.

Preparing the Passphrase

ImageMagick requires the passphrase to be stored in a text file rather than passed directly as a command-line argument.

Create a standard text file (e.g., passphrase.txt) containing your secret key:

echo "YourStrongPasswordHere" > passphrase.txt

Syntax for Enciphering an Image

To encipher an image, use the -encipher operator followed by the path to the passphrase file.

ImageMagick 7 (Recommended)

magick input.png -encipher passphrase.txt output_encrypted.png

ImageMagick 6

convert input.png -encipher passphrase.txt output_encrypted.png

This operation scrambles the pixel data into pseudo-random noise, rendering the visual content unrecognizable without the correct key.

Syntax for Deciphering an Image

To restore the encrypted image to its original form, use the -decipher operator with the identical passphrase file.

ImageMagick 7

magick output_encrypted.png -decipher passphrase.txt restored_output.png

ImageMagick 6

convert output_encrypted.png -decipher passphrase.txt restored_output.png

Important Considerations

  • Lossless Formats: Always use lossless image formats (such as PNG, TIFF, or MIFF) for both the encrypted file and decrypted outputs. Lossy compression formats like JPEG alter pixel values, which corrupts the enciphered data and makes it impossible to decipher properly.
  • Passphrase Security: Secure or delete the passphrase.txt file after use, as anyone with access to the file can reverse the encryption.
