Encode Modular Mode JPEG XL with ImageMagick

This guide explains how to encode JPEG XL images in modular mode using ImageMagick from the command line. You will learn the specific -define directives needed to force the modular encoding path for both lossless graphics and lossy output, as well as how to fine-tune compression speed and quality settings.

What is Modular Mode in JPEG XL?

JPEG XL supports two primary encoding modes: VarDCT (Variable-Block Discrete Cosine Transform) and Modular. While VarDCT is optimized for lossy photographic imagery, Modular mode is engineered for lossless compression, non-photographic content (such as pixel art, UI graphics, and digital drawings), and specialized lossy applications.

Basic Command to Force Modular Mode

To force ImageMagick to encode using the modular architecture instead of VarDCT, use the jxl:modular=true definition flag:

magick input.png -define jxl:modular=true output.jxl

Encoding Lossless Modular Images

By default, setting the quality to 100 in ImageMagick often triggers the modular engine because VarDCT cannot perform mathematical lossless encoding. However, explicitly pairing -quality 100 with the modular definition ensures strict adherence to the modular lossless pipeline:

magick input.png -quality 100 -define jxl:modular=true output.jxl

Encoding Lossy Modular Images

Modular mode can also compress images lossily by applying quantization (controlled via the quality setting or direct distance controls):

magick input.png -quality 85 -define jxl:modular=true output.jxl

In this mode, lower quality values increase the internal error threshold, reducing file size while maintaining the structural sharpness characteristic of the modular pipeline.

Optimizing Compression Effort

You can control the computational effort ImageMagick instructs the libjxl encoder to use via the jxl:effort parameter. Values range from 1 (fastest encoding, larger file size) to 9 (slowest encoding, best compression density):

magick input.png -quality 100 -define jxl:modular=true -define jxl:effort=7 output.jxl

For most workflows, an effort level between 5 and 7 provides the best balance between CPU time and file size savings.

Verifying the Output

To verify the generated file and inspect its metadata, run ImageMagick's identify tool:

magick identify -verbose output.jxl

Alternatively, if you have the JPEG XL tools installed, run jxlinfo output.jxl to confirm that the image stream is tagged as Modular.
