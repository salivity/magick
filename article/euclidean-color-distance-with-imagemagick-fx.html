Euclidean Color Distance with ImageMagick FX

This article explains how to calculate the Euclidean color distance between images or against a target color using ImageMagick's -fx operator. You will learn the exact mathematical syntax required for the -fx expression, how to compare two separate images, how to evaluate an image against a constant color, and how to properly normalize the resulting output into a standard grayscale map.

The Euclidean Color Distance Formula

Euclidean color distance treats the Red, Green, and Blue channels of an image as coordinates in a three-dimensional space (\(R, G, B\)). The distance (\(d\)) between two colors \((R_1, G_1, B_1)\) and \((R_2, G_2, B_2)\) is defined as:

\[d = \sqrt{(R_1 - R_2)^2 + (G_1 - G_2)^2 + (B_1 - B_2)^2}\]

Because ImageMagick processes channel values in the range of 0.0 to 1.0, the maximum possible distance between two points (such as black [0, 0, 0] and white [1, 1, 1]) is \(\sqrt{1^2 + 1^2 + 1^2} = \sqrt{3} \approx 1.73205\). To prevent clipping and produce a standard normalized grayscale output where 0.0 represents identical colors and 1.0 represents maximum divergence, the result must be divided by \(\sqrt{3}\).

Syntax for Comparing Two Images

To calculate the Euclidean color distance between two different images pixel-by-pixel, load both images and use u to represent the first image and v to represent the second image:

magick image1.png image2.png -fx "sqrt((u.r - v.r)^2 + (u.g - v.g)^2 + (u.b - v.b)^2) / sqrt(3)" distance.png

For ImageMagick v6, replace magick with convert:

convert image1.png image2.png -fx "sqrt((u.r - v.r)^2 + (u.g - v.g)^2 + (u.b - v.b)^2) / sqrt(3)" distance.png

Expression Breakdown:

  • u.r, u.g, u.b: The Red, Green, and Blue channel values of the first image (image1.png).
  • v.r, v.g, v.b: The Red, Green, and Blue channel values of the second image (image2.png).
  • ^2: Squares the difference between each corresponding channel.
  • sqrt(...): Computes the square root of the summed squared differences.
  • / sqrt(3): Normalizes the final distance to fall strictly within the [0.0, 1.0] range.

Syntax for Comparing an Image to a Fixed Color

To measure the distance of every pixel in a single image relative to a fixed RGB reference color, substitute the v terms with static normalized float values between 0.0 and 1.0.

For example, to calculate the Euclidean distance of every pixel in input.png from pure red (RGB: 1.0, 0.0, 0.0):

magick input.png -fx "sqrt((u.r - 1.0)^2 + (u.g - 0.0)^2 + (u.b - 0.0)^2) / sqrt(3)" distance_from_red.png

If comparing against an 8-bit color such as rgb(128, 64, 255), divide each component by 255 before inserting it into the formula:

  • \(R = 128 / 255 \approx 0.5020\)
  • \(G = 64 / 255 \approx 0.2510\)
  • \(B = 255 / 255 = 1.0\)
magick input.png -fx "sqrt((u.r - 0.502)^2 + (u.g - 0.251)^2 + (u.b - 1.0)^2) / sqrt(3)" distance.png
