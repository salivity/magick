Euclidean Distance Maps in ImageMagick

This guide explains how to generate Euclidean distance maps using ImageMagick’s morphology operators. You will learn the core morphology syntax required to compute exact and approximate Euclidean distance transforms, how to properly format input binary masks, and how to normalize the resulting high-depth values for visualization and further image processing.

Understanding the Distance Transform in ImageMagick

A distance map (or distance transform) replaces each pixel's intensity with a value representing its physical distance to the nearest boundary or background pixel. ImageMagick calculates this using the -morphology Distance operator.

By default, ImageMagick measures distance from non-zero (white) pixels to the nearest zero (black) pixel. If you want to measure distance from the outside of an object toward its edge, the image must be inverted.

Basic Command Syntax

To compute a standard Euclidean distance map, use the Euclidean metric with the -morphology Distance operator:

magick input.png -threshold 50% -morphology Distance Euclidean output_distance.png

For ImageMagick v6, replace magick with convert.

Normalizing Values for Visualization

Because Euclidean distance values correspond to actual pixel counts, values quickly exceed standard 8-bit limits (0–255), leading to clipped white areas if saved directly to an 8-bit format.

To visualize the gradient across the entire shape, stretch the dynamic range using -auto-level:

magick input.png -threshold 50% -morphology Distance Euclidean -auto-level edm_visualized.png

If you need to preserve exact numerical distances rather than a normalized visual gradient, export the output to a 16-bit or 32-bit floating-point format such as TIFF, PFM, or MIFF without using -auto-level:

magick input.png -threshold 50% -morphology Distance Euclidean -depth 32 edm_raw.tiff

Measuring Distance from the Outside (External EDM)

To compute the distance field radiating away from an object rather than inside it, apply -negate before running the morphology operator:

magick input.png -threshold 50% -negate -morphology Distance Euclidean -auto-level external_edm.png

Euclidean Metric Variants

ImageMagick provides options to adjust how the Euclidean distance is calculated and scaled:

  • True Euclidean: Distance Euclidean calculates the exact standard geometric distance \(\sqrt{\Delta x^2 + \Delta y^2}\).
  • Squared Euclidean: Specifying Distance Euclidean:Squared computes \(\Delta x^2 + \Delta y^2\). This avoids square root calculations, resulting in faster processing times, which is ideal for mathematical modeling or watershed algorithms.
  • Scaling Factors: You can supply a divisor or scale factor, such as Distance Euclidean,10, to scale down the resulting distance intensities by a factor of 10.

Complete Example Workflow

To process a shape, calculate the internal Euclidean distance map, and apply a false-color spectrum for analysis:

magick input.png \
  -colorspace Gray \
  -threshold 50% \
  -morphology Distance Euclidean \
  -auto-level \
  -apply-color-map plasma:default \
  colored_edm.png
