Evaluate Multi-Image Pixel Formulas in ImageMagick

Evaluating pixel mathematical formulas across multiple image layers in ImageMagick is achieved primarily through the -fx operator. This feature allows you to execute custom, per-pixel mathematical expressions referencing multiple input images loaded into the current image sequence. By assigning variable names such as u and v (or index-based notations like u[0] and u[1]) to specific layers, ImageMagick can calculate complex pixel blending, channel arithmetic, and conditional logic to generate a newly synthesized image.

Referencing Multi-Image Layers

When running a command that loads multiple images, ImageMagick stores them in an image sequence list indexed starting at 0. Within the -fx expression, you can access individual images using specific identifiers:

  • u or u[0]: Represents the first image in the list.
  • v or u[1]: Represents the second image in the list.
  • u[n]: Represents the n-th image in the sequence (e.g., u[2] for the third image).
  • w or u[-1]: Represents the last image in the sequence.

Pixel color values in -fx are normalized to floating-point numbers between 0.0 (black/minimum) and 1.0 (white/maximum).

Channel-Specific Access

By default, an expression like u + v applies to all channels (Red, Green, Blue, Alpha) independently. To access specific channel values directly in formulas, append channel accessors:

  • u.r, u.g, u.b: Red, Green, and Blue channels of the first image.
  • u.a: Alpha channel of the first image.
  • u.k, u.c, u.m, u.y: CMYK channel values when working with CMYK images.
  • u.p{x,y}: Pixel value of image u at absolute coordinate (x, y).

Command Syntax and Examples

The general structure for running multi-image -fx operations requires listing the input files first, applying the -fx flag with a quoted expression, and defining the output image:

magick input1.png input2.png -fx "formula" output.png

1. Weighted Blending Between Two Images

To blend 70% of the first image with 30% of the second image:

magick base.png overlay.png -fx "0.7*u + 0.3*v" output.png

2. Absolute Difference Between Two Layers

To calculate the absolute pixel-by-pixel difference between two images:

magick frame1.png frame2.png -fx "abs(u - v)" difference.png

3. Conditional Multi-Layer Logic

Ternary conditional operators (condition ? true_val : false_val) allow dynamic layer selection based on pixel luminosity:

magick base.png highlight.png -fx "u > 0.5 ? v : u" conditional_output.png

4. Cross-Channel Formula Across Three Images

You can combine channels from three separate input images into a single RGB output:

magick red_source.png green_source.png blue_source.png \
  -fx "u[0].r + u[1].g + u[2].b" combined.png

Targeting Specific Output Channels

To limit the mathematical evaluation to a single output channel rather than all channels, use the -channel flag before -fx:

magick background.png mask.png -channel R -fx "u * v" +channel output.png

The +channel switch resets the channel mask so subsequent operations affect all color channels normally.

Performance Considerations

The -fx engine interprets formulas dynamically for every pixel and channel, which makes it significantly slower than built-in ImageMagick composite operators. For standard mathematical tasks (such as simple addition, subtraction, or multiplication across images), using -compose methods like Multiply, Difference, or Mathematics alongside -composite will yield significantly faster processing times on high-resolution images.
