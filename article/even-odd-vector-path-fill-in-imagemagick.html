Even-Odd Vector Path Fill in ImageMagick

This guide explains how to render complex, self-intersecting, or overlapping vector paths using the even-odd fill rule in ImageMagick. By setting the drawing fill rule to evenodd, ImageMagick alternates filling and creating cutouts for overlapping path segments, ensuring complex geometry renders with proper transparency in nested sections.

Understanding the Even-Odd Rule

When filling shapes with overlapping boundaries (such as a multi-pointed star, concentric loops, or donut shapes), rendering engines determine which areas are "inside" or "outside" using a fill rule.

  • Non-Zero (Default): Determines whether a point is inside the shape by drawing a ray to infinity and checking the direction of intersecting lines. Fully overlapping areas usually remain filled solid.
  • Even-Odd: Determines whether a point is inside by drawing a ray to infinity and counting the number of path segments it crosses. If the count is odd, the area is filled; if even, the area remains unfilled (transparent or background color).

ImageMagick CLI Syntax

To apply the even-odd rule, use the -draw operator and specify fill-rule evenodd before defining your vector path (path command) or polygon points.

Basic Command Example

magick -size 500x500 xc:white \
  -fill red -stroke black -strokewidth 2 \
  -draw "fill-rule evenodd path 'M 250,50 L 375,400 L 50,160 L 450,160 L 125,400 Z'" \
  star_evenodd.png

In this five-pointed star example:

  • The lines intersect at multiple points.
  • The fill-rule evenodd instruction leaves the central pentagon open (unfilled/white) because any ray from the center crosses an even number of boundary lines (two lines).
  • If fill-rule nonzero were used instead, the entire star, including the center, would be filled solid red.

Creating Holes and Cutouts

The even-odd rule is commonly used to create compound shapes with holes (such as a letter "O" or a donut) within a single path definition.

magick -size 400x400 xc:lightgray \
  -fill dodgerblue \
  -draw "fill-rule evenodd path 'M 50,50 H 350 V 350 H 50 Z M 120,120 H 280 V 280 H 120 Z'" \
  hollow_square.png
  • The first subpath (M 50,50 ... Z) defines a 300x300 outer square.
  • The second subpath (M 120,120 ... Z) defines a 160x160 inner square.
  • The even-odd rule treats the inner square as an "even" intersection zone, leaving the interior hollow.

Using Magick Vector Graphics (MVG) Files

For highly complex paths, you can write the drawing commands to an MVG file and render it directly:

  1. Create a file named shape.mvg:
viewbox 0 0 400 400
fill-rule evenodd
fill green
stroke black
path 'M 100,100 L 300,100 L 300,300 L 100,300 Z M 150,150 L 250,150 L 250,250 L 150,250 Z'
  1. Render the file with ImageMagick:
magick -size 400x400 xc:white -draw @shape.mvg output.png

Key Considerations

  • Scope of Rule: The fill-rule evenodd directive remains active for all subsequent paths within the same -draw string unless explicitly changed back to fill-rule nonzero.
  • ImageMagick Version: ImageMagick 7 uses the magick command. If you are using ImageMagick 6, replace magick with convert.
