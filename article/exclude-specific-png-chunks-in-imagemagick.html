Exclude Specific PNG Chunks in ImageMagick

This guide explains how to exclude specific PNG metadata chunks, such as tEXt and zTXt, when processing images using ImageMagick. By utilizing the format-specific -define option, you can selectively strip unwanted ancillary data to reduce file size or remove metadata while preserving necessary image properties.

The png:exclude-chunk Syntax

ImageMagick provides the png:exclude-chunk define to block specific chunks from being written to the output PNG file. The syntax requires specifying the key and a comma-separated list of target chunk types.

Basic Syntax:

magick input.png -define png:exclude-chunk=tEXt,zTXt output.png

(For ImageMagick v6, replace magick with convert.)

Targetable Text Chunks

PNG stores metadata across several standard chunks. You can exclude them individually or in combination:

  • tEXt: Stores uncompressed Latin-1 text (often used for basic comments and software tags).
  • zTXt: Stores compressed Latin-1 text (used for larger text blocks to save space).
  • iTXt: Stores international UTF-8 text (often used for XML, XMP metadata, and modern tags).

To exclude all three common text chunks simultaneously, pass them as a comma-separated list without spaces:

magick input.png -define png:exclude-chunk=tEXt,zTXt,iTXt output.png

Advanced Chunk Exclusion Options

ImageMagick also supports predefined categories and case-insensitive matching:

  • Exclude All Non-Critical Chunks: You can use the all keyword to strip all ancillary chunks while keeping only critical rendering chunks (IHDR, PLTE, IDAT, IEND). 
    magick input.png -define png:exclude-chunk=all output.png
  • Exclude Timestamps: Use the date keyword to avoid writing creation or modification timestamps (tIME chunk). 
    magick input.png -define png:exclude-chunk=date output.png

Unlike the broader -strip command, which removes all image profiles and comments, png:exclude-chunk gives you precise, granular control over the exact PNG structure generated during encoding.
