Export 1-Bit WBMP with ImageMagick

This article provides the exact ImageMagick syntax and command options required to generate 1-bit monochrome Wireless Application Protocol Bitmap (WBMP) files. WBMP is an uncompressed, 1-bit format consisting of a simple header followed by packed pixel data, making it ideal for resource-constrained microcontrollers driving monochrome OLED, LCD, and e-paper screens.

Basic Conversion Syntax

For ImageMagick version 7, use the magick command. For ImageMagick version 6, replace magick with convert.

The fundamental command to convert an input image to a 1-bit WBMP is:

magick input.png -colorspace Gray -monochrome output.wbmp

Complete Syntax for Microcontroller Displays

Embedded displays typically require specific target dimensions (such as 128x64 or 250x122) and strict control over dithering and bit polarity. The standard full command syntax is:

magick input.png -resize 128x64\! -colorspace Gray -dither FloydSteinberg -monochrome output.wbmp

Parameter Breakdown

  • -resize <width>x<height>\!: Resizes the image to the exact hardware resolution of your display. The exclamation mark (\! in Bash, or ! in Windows Command Prompt) forces the resize to ignore the original aspect ratio so it fits the display buffer completely.
  • -colorspace Gray: Converts color channels to a single grayscale channel before binary conversion, preventing color artifacts.
  • -dither <method>: Controls spatial dithering. Use FloydSteinberg to simulate shading on photographic inputs, or use None if converting pixel art, fonts, or UI schematics where crisp lines are required.
  • -monochrome: Forces the image buffer to strict 1-bit black-and-white.
  • output.wbmp: ImageMagick uses the .wbmp extension to automatically apply the Wireless Bitmap encoder. You can explicitly force the encoder by prefixing the filename with wbmp: (e.g., wbmp:output.bin).

Alternative: High-Contrast Thresholding (No Dithering)

If dithering creates unwanted visual noise on low-resolution embedded displays, substitute -monochrome with the -threshold operator to create solid black-and-white shapes:

magick input.png -resize 128x64\! -colorspace Gray -threshold 50% output.wbmp

Adjust the percentage value up or down to control how dark a pixel must be before turning completely black.

Inverting Pixel Polarity

Certain microcontroller display drivers (like the SSD1306 or SH1106) interpret a 1 bit as illuminated (white) and 0 as off (black), while others expect the reverse. To invert the bits directly during export, use the -negate flag:

magick input.png -resize 128x64\! -colorspace Gray -threshold 50% -negate output.wbmp

Verifying the Output

To verify that the output is strictly 1-bit before flashing it to your microcontroller:

magick identify -verbose output.wbmp

Look for Format: WBMP, Depth: 1-bit, and Colors: 2 in the metadata output to confirm hardware compatibility.
