Export Image Metadata to JSON with ImageMagick

This guide explains how to extract and export comprehensive image metadata into JSON format using the ImageMagick command-line interface. You will find the exact commands for both ImageMagick v7 and legacy ImageMagick v6, instructions for saving the JSON output directly to a file, and tips for formatting the resulting data.

The Primary Command

In ImageMagick 7, the simplest and most efficient command to output metadata in JSON format is:

magick input.jpg json:

For ImageMagick 6, the equivalent syntax uses the convert tool:

convert input.jpg json:

Saving JSON Output to a File

To redirect the standard output into a dedicated .json file rather than printing it to the terminal, append a filename or standard shell redirection:

Direct output specification:

magick input.jpg json:metadata.json

Shell redirection:

magick input.jpg json: > metadata.json

Alternative Method Using identify

You can also extract metadata using the identify utility paired with the JSON format specifier:

ImageMagick 7:

magick identify -format "%[json:]" input.jpg

ImageMagick 6:

identify -format "%[json:]" input.jpg

Understanding the Output

The generated JSON object contains an exhaustive list of image properties, including:

  • Image dimensions and geometry (width, height, resolution, color space)
  • Format profiles (JPEG, PNG, TIFF specifications)
  • Embedded metadata (EXIF, IPTC, and XMP tags)
  • Color statistics (depth, channels, and histogram details)
  • Privacy Policy
  • Terms and Conditions
