Export Raw Pixel Arrays to Floats in ImageMagick

Exporting raw pixel data as plain-text floating-point values is an essential task for scientific visualization, machine learning data pipelines, and custom rendering algorithms. This guide explains how to use ImageMagick from the command line to convert standard image formats into clean, human-readable floating-point text arrays, both with and without spatial coordinate metadata.

Method 1: Using the Built-In Text Enumeration Format (txt:)

ImageMagick includes a built-in format called ImageMagick Pixel Enumeration (txt:). This format outputs coordinates, raw quantum values, and color channel values as floating-point numbers or percentages.

To export an image to a .txt file:

magick input.png output.txt

If you are using ImageMagick v6, replace magick with convert:

convert input.png output.txt

Output Structure

The resulting text file will contain a header describing the image dimensions, depth, and colorspace, followed by lines formatted as:

# ImageMagick pixel enumeration: 2,2,0,65535,srgb
0,0: (65535,0,0)  #FF0000  red
1,0: (0,65535,0)  #00FF00  lime
0,1: (0,0,65535)  #0000FF  blue
1,1: (65535,65535,65535)  #FFFFFF  white

To enforce high-precision floating-point output in standard enumeration:

magick input.png -define quantum:format=floating-point -depth 32 output.txt

Method 2: Exporting Pure Raw Floating-Point Arrays (No Metadata)

When feeding pixel data directly into numerical software (such as NumPy, MATLAB, or C/C++ buffers), coordinate labels and color names are often unwanted. You can use ImageMagick's -format operator combined with the fx engine to output clean numeric text directly to standard output or a file.

1. Grayscale Floating-Point Array (0.0 to 1.0)

To export a single grayscale float per pixel, separated by newlines:

magick input.png -colorspace Gray -format "%[fx:u]\n" info:pixels.txt
  • %[fx:u] calculates the normalized intensity of the current pixel from 0.0 (black) to 1.0 (white).
  • info:pixels.txt writes the formatted string to pixels.txt.

2. Multi-Channel RGB Floating-Point Array

To export RGB values as space-separated floats per pixel:

magick input.png -format "%[fx:u.r] %[fx:u.g] %[fx:u.b]\n" info:pixels_rgb.txt
  • %[fx:u.r]: Red channel normalized between 0.0 and 1.0.
  • %[fx:u.g]: Green channel normalized between 0.0 and 1.0.
  • %[fx:u.b]: Blue channel normalized between 0.0 and 1.0.

3. RGBA Floating-Point Array (With Alpha)

To include the alpha (transparency) channel:

magick input.png -format "%[fx:u.r] %[fx:u.g] %[fx:u.b] %[fx:u.a]\n" info:pixels_rgba.txt

Method 3: Custom Scaling and Precision

By default, %[fx:...] normalizes values to the range [0.0, 1.0]. You can modify the expression directly in the command to scale values or alter the output range.

Export to a 0.0 to 255.0 Range

magick input.png -format "%[fx:u.r*255] %[fx:u.g*255] %[fx:u.b*255]\n" info:pixels_255.txt

Comma-Separated Values (CSV Format)

To output the data in CSV format for direct spreadsheet or database import:

magick input.png -format "%[fx:u.r],%[fx:u.g],%[fx:u.b]\n" info:pixels.csv

Custom Delimiters (Single Flattened Line)

To output the entire image array as a single space-separated sequence of floating-point values:

magick input.png -colorspace Gray -format "%[fx:u] " info:flat_array.txt
