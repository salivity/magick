Export Raw Pixel Values as RGB Floats in ImageMagick

This article provides the exact ImageMagick commands required to extract and export raw pixel data from an image as plain-text RGB floating-point lists. It covers the native Text Enumeration (txt:) format, how to normalize values to a 0.0–1.0 float scale, and how to filter out image metadata to obtain a clean list of RGB floating-point values.

The Primary Command

ImageMagick uses the built-in txt: delegate to dump pixel information into human-readable plain text. To export pixel values as normalized floating-point numbers ranging from 0.0 to 1.0, run:

magick input.png -depth 16 -define txt:quantum-format=floating-point output.txt

(Note: If using ImageMagick 6, replace magick with convert.)

Generating Plain-Text Floating-Point RGB to Standard Output

To view the raw pixel output directly in the terminal or pipe it to another process, export to standard output using txt:-:

magick input.png -define txt:quantum-format=floating-point txt:-

This command generates an enumerated text output structured as follows:

# ImageMagick pixel enumeration: width,height,depth,srgb
0,0: (0.133333,0.545098,0.133333)  #228B22  srgb(13.3333%,54.5098%,13.3333%)
1,0: (0.137255,0.54902,0.137255)   #238C23  srgb(13.7255%,54.902%,13.7255%)

Extracting Clean RGB Float Lists Without Metadata

If the target application requires only space-separated or comma-separated RGB floats per pixel (omitting coordinates, hex codes, and headers), pipe the output to awk:

magick input.png txt:- | awk -F'[(),]' 'NR>1 {print $2, $3, $4}' > rgb_floats.txt

This produces a clean plain-text list where each line represents a pixel's red, green, and blue components as floating-point values between 0.0 and 1.0:

0.133333 0.545098 0.133333
0.137255 0.54902 0.137255

Exporting Non-Normalized 0–255 Floats

To retain full float precision while mapping values to a standard 8-bit scale (0.0 to 255.0), compute the values dynamically:

magick input.png txt:- | awk -F'[(),]' 'NR>1 {printf "%.4f %.4f %.4f\n", $2*255, $3*255, $4*255}' > rgb_255_floats.txt
