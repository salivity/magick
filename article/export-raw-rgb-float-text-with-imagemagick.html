Export Raw RGB Float Text with ImageMagick

This article explains how to export raw image pixel arrays into pure RGB floating-point text format using ImageMagick. It covers the primary commands required to extract normalized 0.0–1.0 floating-point values, format the output without coordinate metadata or headers, and manage high-precision 32-bit floating-point conversions directly from the command line.

Primary Command for Pure RGB Floating-Point Text

To export pure RGB values where each pixel is represented as three floating-point numbers (ranging from 0.0 to 1.0) separated by spaces and delimited by newlines, use the following ImageMagick 7 command:

magick input.png -colorspace sRGB txt:- | awk -F'[(,)]' 'NR>1 {printf "%.6f %.6f %.6f\n", $2/65535, $3/65535, $4/65535}' > output.txt

(Note: If your ImageMagick build uses Q8 instead of Q16, divide by 255 instead of 65535).

Native ImageMagick Enumeration (Text Format)

ImageMagick provides a built-in txt: delegate (ImageMagick Pixel Enumeration). To output the raw pixel values directly into text format using floating-point percentages/fractions:

magick input.png -colorspace sRGB -depth 32 txt:output_raw.txt

This generates a file formatted as follows:

# ImageMagick pixel enumeration: width,height,depth,srgb
0,0: (0.141176,0.301961,0.486275)  #244D7C  srgb(14.1176%,30.1961%,48.6275%)
1,0: (0.145098,0.305882,0.490196)  #254E7D  srgb(14.5098%,30.5882%,49.0196%)

Exporting Binary Raw 32-Bit Floats to Text

If you need IEEE 754 32-bit single-precision floating-point values generated natively by ImageMagick and converted to pure ASCII text, combine ImageMagick's raw stream with standard formatting tools:

magick input.png -colorspace sRGB -depth 32 -define quantum:format=floating-point rgb:- | od -An -tfF -w12 > output_floats.txt

Parameter Breakdown:

  • -colorspace sRGB: Ensures colors are normalized to the standard sRGB color profile before extraction.
  • -depth 32: Sets quantum depth to 32 bits per channel.
  • -define quantum:format=floating-point: Forces pixel values to export as native floating-point representations rather than integers.
  • rgb:-: Streams raw, headerless RGB binary bytes directly to standard output.
  • od -An -tfF -w12: Formats the incoming 4-byte single-precision float stream into lines of three floating-point values (12 bytes per line) with address offsets removed.
