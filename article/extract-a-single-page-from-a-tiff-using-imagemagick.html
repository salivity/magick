Extract a Single Page from a TIFF Using ImageMagick

Extracting a specific page from a multi-directory or multipage TIFF file is a quick and simple process when using ImageMagick. This guide explains how to use ImageMagick's command-line tools to select and export any individual frame from a multi-page TIFF document into a separate single-page TIFF or another image format.

Understanding Zero-Based Indexing

ImageMagick identifies pages (or directories) within a multi-image file using a zero-based index enclosed in square brackets [] directly appended to the input filename:

  • input.tiff[0] refers to the first page.
  • input.tiff[1] refers to the second page.
  • input.tiff[2] refers to the third page, and so on.

The Basic Command

Depending on the version of ImageMagick installed on your system, you will use either the magick command (ImageMagick 7) or the convert command (ImageMagick 6).

ImageMagick 7

To extract the first page of a multi-directory TIFF file and save it as a new TIFF file:

magick input.tiff[0] output_page1.tiff

To extract the third page:

magick input.tiff[2] output_page3.tiff

ImageMagick 6

If you are using legacy ImageMagick 6, use the convert utility:

convert input.tiff[0] output_page1.tiff

Converting to Different Formats

You can change the output format simply by modifying the file extension of the target file. ImageMagick will automatically handle the conversion.

  • Extract to PNG:

    magick input.tiff[0] output_page1.png

  • Extract to JPEG:

    magick input.tiff[0] output_page1.jpg

Preserving Compression Settings

TIFF files often use specific compression algorithms (such as LZW, Zip, or Group4). To maintain or change the compression type during extraction, use the -compress flag:

magick input.tiff[0] -compress lzw output_page1.tiff

For black-and-white scanned documents, Group4 compression is commonly used:

magick input.tiff[0] -compress Group4 output_page1.tiff

Extracting Multiple Specific Pages

If you need to extract more than one page at a time:

  • Page range: Extract pages 1 through 3:

    magick input.tiff[0-2] output_pages.tiff

  • Non-consecutive pages: Extract pages 1 and 4:

    magick input.tiff[0] input.tiff[3] output_selected.tiff
