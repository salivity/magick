Extract a Specific Page from a TIFF Using ImageMagick

Multi-page or multi-directory TIFF files store multiple image frames inside a single file container. ImageMagick makes it easy to select, extract, and convert specific pages or directories from these files using index-based bracket notation. This guide outlines the exact commands needed to extract a single page, a range of pages, or all pages into separate files.

Understanding ImageMagick Frame Indexing

ImageMagick treats each directory or page in a multi-image TIFF as a frame. Frames use zero-based indexing:

  • Page 1 is index [0]
  • Page 2 is index [1]
  • Page N is index [N-1]

For ImageMagick version 7, use the magick command. If you are using legacy ImageMagick version 6, replace magick with convert.

Extracting a Single Page

To extract a specific page, append the zero-based index in square brackets directly after the input filename.

Extract the First Page (Page 1):

magick input.tiff[0] output_page_1.tiff

Extract a Specific Page (e.g., Page 4):

magick input.tiff[3] output_page_4.png

You can output the extracted page to any supported image format, such as TIFF, PNG, or JPEG.

Extracting a Range of Pages

To extract a consecutive sequence of pages into a new multi-page file or set of images, specify the start and end indices separated by a hyphen.

Extract Pages 1 to 3:

magick input.tiff[0-2] extracted_pages.tiff

Extracting Specific Non-Consecutive Pages

To extract select pages that are not in sequence, separate the index numbers with commas.

Extract Pages 1, 3, and 5:

magick input.tiff[0,2,4] selected_pages.tiff

Extracting All Pages into Separate Files

To break an entire multi-page TIFF into individual single-page files, use standard output formatting placeholders (%d for page numbers) along with +adjoin:

magick input.tiff +adjoin page_%03d.tiff

This command generates files named page_000.tiff, page_001.tiff, page_002.tiff, and so on.

Inspecting TIFF Directories

To view the number of pages and inspect their metadata before extracting, run the identify utility:

magick identify input.tiff

This outputs a list showing each sub-image index along with its resolution, color depth, and dimensions.
