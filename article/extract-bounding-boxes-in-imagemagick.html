Extract Bounding Boxes in ImageMagick

Extracting bounding boxes for all connected shapes in an image is a common computer vision task easily accomplished using ImageMagick's Connected Components Analysis (CCA) feature. By utilizing the -connected-components operator alongside verbose output definitions, ImageMagick can identify distinct objects, analyze their connectivity, and output the precise bounding box coordinates for each shape directly to the terminal or a text file.

The Command

To extract the bounding box coordinates for every connected component, run the following command:

magick input.png -define connected-components:verbose=true -connected-components 8 null:

(Note: If using ImageMagick version 6, replace magick with convert.)

Command Breakdown

  • input.png: The source image containing the shapes you want to analyze. For optimal results, ensure the image is binarized or thresholded to clearly separate foreground shapes from the background.
  • -define connected-components:verbose=true: Directs ImageMagick to print detailed metadata about each detected shape to standard output (stdout).
  • -connected-components 8: Applies the CCA algorithm using 8-way connectivity (diagonals included). You can change this to 4 for 4-way connectivity (orthogonal neighbors only).
  • null:: Discards the image output pipeline, ensuring no unnecessary new image file is written to disk while retaining the console text output.

Understanding the Output

The command prints a list of detected objects formatted with columns similar to the following:

Objects (id: bounding-box centroid area, mean-color):
  0: 500x500+0+0 250.0,250.0 240000 srgb(0,0,0)
  1: 45x60+120+45 142.5,75.0 2700 srgb(255,255,255)
  2: 80x80+300+210 340.0,250.0 6400 srgb(255,255,255)

The second column provides the bounding box in standard geometry format: widthxheight+x+y:

  • widthxheight: The horizontal and vertical dimensions of the shape.
  • +x+y: The X and Y offset coordinates of the upper-left corner of the shape relative to the image canvas.

Filtering Small Artifacts

To ignore noise or small specks and only extract bounding boxes for shapes exceeding a specific pixel area, use the area-threshold define:

magick input.png -define connected-components:verbose=true -define connected-components:area-threshold=50 -connected-components 8 null:

This ensures only connected regions containing 50 or more pixels are reported.
