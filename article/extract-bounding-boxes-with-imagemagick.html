Extract Bounding Boxes with ImageMagick

This article provides a direct guide on using ImageMagick's connected-components labeling feature to detect distinct objects within an image and extract their exact bounding box dimensions and coordinates.

The Command

To extract the bounding box coordinates of shapes in an image, run the following ImageMagick command:

magick input.png -define connected-components:verbose=true -connected-components 8 null:

(Note: If you are using ImageMagick version 6, replace magick with convert.)

How the Parameters Work

  • -define connected-components:verbose=true: Tells ImageMagick to print the detailed statistical data—including bounding boxes, centroids, and pixel areas—to the standard output console.
  • -connected-components 8: Executes the connected-components algorithm. The value 8 specifies 8-directional connectivity (pixels touching diagonally or orthogonally are treated as one shape). You can change this to 4 for strictly orthogonal connectivity.
  • null:: Discards the resulting visual image data so that only the text metadata is output to the terminal.

Understanding the Output

Running the command produces output structured in the following format:

Objects (id: bounding-box centroid area mean-color):
  0: 500x500+0+0 249.5,249.5 248650 srgb(0,0,0)
  1: 45x30+120+45 142.1,59.3 1350 srgb(255,255,255)

In the output line for each detected shape:

  • id: Unique identifier for the detected component (object 0 is typically the background).
  • bounding-box: Expressed as WidthxHeight+X-offset+Y-offset (e.g., 45x30+120+45).
  • centroid: The center coordinates of the shape (X,Y).
  • area: The total pixel count of the object.
  • mean-color: The average color value inside the boundary.

Filtering Small Artifacts and Noise

To exclude small specks or noise from being detected as valid shapes, add an area threshold define:

magick input.png -define connected-components:verbose=true -define connected-components:area-threshold=50 -connected-components 8 null:

This flag ignores any connected component containing fewer than 50 pixels.

Extracting Only Bounding Box Values

To parse only the bounding box coordinates from the output, pipe the command to standard command-line tools like awk:

magick input.png -define connected-components:verbose=true -connected-components 8 null: | awk 'NR>1 {print $2}'
