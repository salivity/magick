Extract Color Profiles with ImageMagick

This guide explains how to extract embedded ICC color profiles from images directly to standard output (stdout) using ImageMagick. You will find the exact command-line syntax for ImageMagick versions 6 and 7, an explanation of how stdout redirection works for color profiles, and practical examples of piping the extracted profile into other command-line utilities.

The Command

To extract an embedded ICC color profile and stream it directly to stdout, use the icc:- output format:

ImageMagick v7:

magick input.jpg icc:-

ImageMagick v6:

convert input.jpg icc:-

How It Works

  • icc: specifies the output format explicitly as a raw ICC (International Color Consortium) profile.
  • - represents standard output (stdout) instead of writing to a named file on disk.

When executed, ImageMagick reads the embedded color profile data from the source image (input.jpg) and prints the raw binary profile stream directly to the terminal output.

Common Use Cases

1. Redirecting to a File

You can use standard shell redirection to save the output:

magick input.png icc:- > profile.icc

2. Piping to Profile Inspection Tools

Extract and inspect the profile metadata in one command without creating temporary files:

magick input.jpg icc:- | icc-dump -

Or view the raw header using hexdump or xxd:

magick input.jpg icc:- | xxd | head -n 20

3. Handling ICM Profiles

For older or specific Windows color management profiles, the icm: delegate can be used interchangeably:

magick input.tif icm:-

Note: If the source image does not contain an embedded color profile, ImageMagick will return an error stating that no profile was found.
