Extract Connected Component Centroids in ImageMagick

This article provides a concise guide on using ImageMagick’s Connected Components Labeling (CCL) to detect isolated image features and extract their centroid coordinates for optical character recognition (OCR). By leveraging ImageMagick's built-in analysis directives and formatting output, you can efficiently identify distinct character glyphs, filter out noise, and retrieve precise center-of-mass coordinates.

The Connected Components Syntax

ImageMagick evaluates connected regions using the -connected-components operator. To expose component metadata, including centroid locations, you must enable verbose output using -define connected-components:verbose=true and redirect image processing to the null: output format.

The primary command structure is:

magick input.png -threshold 50% \
  -define connected-components:verbose=true \
  -connected-components 8 \
  null:

Understanding the Output Format

When verbose mode is enabled, ImageMagick outputs textual data directly to the standard output (stdout). The raw output is formatted in columns:

id: bounding-box centroid area mean-color
  • id: The unique identifier for the connected component.
  • bounding-box: The geometry of the component formatted as widthxheight+x+y.
  • centroid: The exact center-of-mass coordinates formatted as x,y (floating-point values).
  • area: The total number of pixels comprising the component.
  • mean-color: The average color value of the component.

For example, an individual entry looks like:

12: 14x22+105+40 111.4,50.8 198 srgb(0,0,0)

In this row, 111.4,50.8 represents the x,y centroid coordinates.

Extracting Only the Centroid Coordinates

For optical recognition workflows, you typically need to isolate the x,y centroid values while ignoring background objects and noise. You can achieve this by combining ImageMagick thresholds with command-line parsing tools like awk.

1. Filter by Area and Extract Centroids

To eliminate single-pixel noise and the large background component, specify an area threshold via -define connected-components:area-threshold=MIN_PIXELS, then use awk to print the centroid column:

magick input.png -threshold 50% \
  -define connected-components:verbose=true \
  -define connected-components:area-threshold=15 \
  -connected-components 8 \
  null: | awk 'NR>1 {print $3}'

2. Format Output as a Structured List

To generate coordinate data paired with component IDs for downstream OCR alignment:

magick input.png -threshold 50% \
  -define connected-components:verbose=true \
  -connected-components 8 \
  null: | awk 'NR>1 {print "Glyph " $1 " Centroid: " $3}'

This yields clean coordinate pairs (e.g., 111.4,50.8) ready to be mapped to individual character bounding regions or sorting algorithms in your optical recognition pipeline.
