Extract Depth Maps from Stereo Pairs with ImageMagick

Extracting a depth map from a stereoscopic photo pair involves measuring the horizontal disparity between the left and right perspective images. While dedicated stereo-matching algorithms exist in computer vision libraries, ImageMagick provides a lightweight command-line method to generate disparity and difference maps using the compare tool. This guide explains how to prepare your rectified stereo pairs, run the comparison command to highlight pixel displacement, and post-process the output into a normalized grayscale depth map.

1. Prepare and Rectify the Stereo Pair

For disparity extraction to work correctly, your left (left.png) and right (right.png) images must be rectified:

  • Both images must have identical dimensions.
  • Vertical alignment must be synchronized so that pixel shifts only occur along the horizontal axis (X-axis).

2. Generate the Disparity Map Using compare

ImageMagick's compare command compares two images pixel by pixel and outputs a visual representation of differences, where pixel shifts between viewpoints correspond to physical depth.

Run the following command in your terminal:

magick compare left.png right.png -compose difference disparity_raw.png

For ImageMagick v6, replace magick compare with compare.

This command overlays the two images and computes the absolute difference between corresponding pixels, generating an initial difference image where larger horizontal shifts (closer foreground objects) show higher contrast.

3. Normalize and Convert to a Grayscale Depth Map

The raw difference image must be converted to grayscale and normalized across the full dynamic range (0 to 255) so that disparity translates clearly into depth tones (white for near objects, black for far backgrounds).

Run the following post-processing command:

magick disparity_raw.png -colorspace Gray -auto-level -blur 0x2 depth_map.png
  • -colorspace Gray: Drops color channels to create a single-channel intensity map.
  • -auto-level: Stretches the tonal range so the highest disparity areas become fully white and identical areas become black.
  • -blur 0x2: Applies a light Gaussian blur to smooth out optical noise and compression artifacts.

4. Direct Single-Line Pipeline

To execute the entire extraction and post-processing pipeline in a single command without creating intermediate files, pipe the output directly:

magick compare left.png right.png -compose difference miff:- | magick - -colorspace Gray -auto-level -blur 0x1.5 depth_map.png

This generates a final depth_map.png ready for 3D mesh displacement, parallax effects, or spatial photo applications.
