Extract Dominant Color Palette With ImageMagick

Extracting a dominant color palette from an image is a common task in graphic design, web development, and image processing workflows. ImageMagick provides built-in color quantization tools that reduce an image to its primary colors and output the resulting palette as text data (hex/RGB values) or as a new visual image swatch.

The Basic Command (Hex and RGB Values)

To extract a list of dominant color values directly to your terminal, use the following command:

magick input.jpg +dither -colors 5 -unique-colors txt:-

Note: If you are using ImageMagick v6, replace magick with convert.

Breakdown of the Options:

  • +dither: Disables dithering to ensure solid, distinct colors rather than mixed pixel patterns.
  • -colors 5: Reduces the entire image to the specified number of dominant colors (change 5 to any desired palette size).
  • -unique-colors: Filters the quantized image down to a 1-pixel-per-color strip.
  • txt:-: Outputs the color data (pixel coordinates, sRGB values, and Hex codes) directly to the standard output.

Extracting Dominant Colors with Pixel Counts

If you need to see how frequently each dominant color appears, use the histogram:info: output format:

magick input.jpg -colors 5 -depth 8 -format "%c" histogram:info:

This output displays the exact pixel count for each extracted color alongside its RGB and hexadecimal representation, sorted from least to most prominent.

Creating a Visual Palette Image

To generate a standalone image file displaying the color swatches horizontally:

magick input.jpg +dither -colors 5 -unique-colors -scale 500x100! palette.png
  • -scale 500x100!: Resizes the single-row color pixels into a 500-pixel wide by 100-pixel tall image swatch.
  • palette.png: Saves the generated palette as a standard image file.
