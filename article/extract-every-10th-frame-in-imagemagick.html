Extract Every 10th Frame in ImageMagick

Extracting specific frames from an animated sequence or GIF is a common task in image processing, and ImageMagick provides a built-in frame selection syntax to accomplish this efficiently. By utilizing ImageMagick’s slicing notation directly in the file read operation, you can extract every tenth frame from an animation without manually processing the entire sequence.

The Command

To extract every tenth frame from an animated file (such as a GIF), use the following command:

For ImageMagick v7:

magick "animation.gif[0--1:10]" frame_%03d.png

For ImageMagick v6 (Legacy):

convert "animation.gif[0--1:10]" frame_%03d.png

How the Syntax Works

  • "animation.gif[0--1:10]": The brackets specify a frame range and step interval using Python-style slice notation:
    • 0: The starting frame index (indexing begins at 0).
    • -1: The ending frame index (-1 represents the last frame in the file).
    • 10: The step interval, which instructs ImageMagick to read only every 10th frame (e.g., frame 0, 10, 20, 30, etc.).
    • Note: Quotes are used around the input filename to prevent the terminal shell from interpreting the square brackets as shell wildcards.
  • frame_%03d.png: The output format pattern. %03d is a standard C-style format specifier that numbers the extracted output files sequentially with three-digit zero-padding (e.g., frame_000.png, frame_001.png, frame_002.png).
