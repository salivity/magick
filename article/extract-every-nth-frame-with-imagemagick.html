Extract Every Nth Frame with ImageMagick

This guide explains how to extract every Nth frame from an animated sequence, such as an animated GIF or video clip, using ImageMagick. By taking advantage of ImageMagick's sub-image selection and stepping syntax, you can sample frames at fixed intervals and export them directly into sequential image files without needing to extract the entire sequence first.

The ImageMagick Command

To extract every Nth frame from an animated file, use the sub-image range syntax [start-end:step] when specifying the input filename:

magick "input.gif[0--1:N]" frame_%03d.png

If you are using ImageMagick version 6, replace magick with convert:

convert "input.gif[0--1:N]" frame_%03d.png

How the Command Works

  • "input.gif[0--1:N]":
    • 0 represents the first frame index.
    • --1 represents the final frame index (the first - is a range separator, and -1 denotes the last element).
    • N is the step value (stride). Replace N with the interval you want (e.g., 2 for every second frame, 5 for every fifth frame).
    • Quotation marks around the filename prevent the shell from misinterpreting the brackets.
  • frame_%03d.png: Specifies the output file naming scheme. The %03d format specifier generates zero-padded numbers (such as frame_000.png, frame_001.png, etc.) for each saved frame.

Practical Examples

Extract Every 2nd Frame (Half-Rate Sampling)

magick "animation.gif[0--1:2]" output_%04d.png

This extracts frames 0, 2, 4, 6, and so on, saving them as output_0000.png, output_0001.png, etc.

Extract Every 5th Frame Starting from Frame 10

magick "animation.gif[10--1:5]" sample_%02d.jpg

This skips the first 10 frames and extracts frames 10, 15, 20, up to the end of the file, saving them in JPG format.
