Extract Every Second Frame in ImageMagick

This guide explains how to extract every second frame from an animation using ImageMagick's sub-frame bracket slicing syntax. By appending slice parameters directly to the input filename, you can downsample animated GIFs or multi-page formats quickly without extracting individual frames to disk first.

The Bracket Slice Syntax

ImageMagick allows image sequence indexing and slicing using square brackets appended to the filename:

filename[start-endxstep]
  • start: The index of the first frame (0-indexed).
  • end: The index of the last frame (use -1 to represent the final frame of the animation).
  • xstep: The step interval, prefixed by x.

Extracting Every Second Frame

To extract every other frame, set the step value to x2.

Even Frames (Frames 0, 2, 4, ...)

To start at the very first frame and select every second frame through to the end of the file:

magick input.gif[0--1x2] output.gif

(For ImageMagick v6, replace magick with convert)

In this command:

  • 0 begins extraction at the initial frame.
  • -1 targets the last frame of the sequence.
  • x2 skips forward by two frames on each step.

Odd Frames (Frames 1, 3, 5, ...)

If you want to extract alternate frames starting from the second frame instead:

magick input.gif[1--1x2] output.gif

Adjusting Animation Speed

When dropping every other frame, the resulting animation will play twice as fast if the frame delay remains untouched. To maintain the original playback duration, double the delay value:

magick input.gif[0--1x2] -set delay 10 output.gif

Alternatively, multiply the existing delay of each extracted frame dynamically:

magick input.gif[0--1x2] -set delay "%[fx:delay*2]" output.gif
