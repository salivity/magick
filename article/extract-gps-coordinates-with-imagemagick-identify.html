Extract GPS Coordinates with ImageMagick Identify

Extracting GPS metadata from images allows you to pinpoint where a photo was taken directly from the command line. ImageMagick's identify utility provides custom string formatting options that read embedded EXIF metadata tags, enabling you to extract raw latitude, longitude, and altitude values without needing third-party EXIF manipulation suites.

Inspect All GPS Metadata

To see every GPS-related EXIF tag stored within an image file, use the wildcard selector with the -format parameter:

magick identify -format "%[EXIF:GPS*]" photo.jpg

(Note: If you are using ImageMagick v6, replace magick identify with identify.)

This command outputs all available geolocation keys, including timestamp, altitude, latitude, longitude, and their corresponding reference directions.

Extract Latitude and Longitude Specifically

To extract only the essential coordinates, query the individual EXIF keys: GPSLatitude, GPSLatitudeRef, GPSLongitude, and GPSLongitudeRef.

Run the following command:

magick identify -format "Latitude: %[EXIF:GPSLatitude] %[EXIF:GPSLatitudeRef]\nLongitude: %[EXIF:GPSLongitude] %[EXIF:GPSLongitudeRef]\n" photo.jpg

Example Output

ImageMagick prints the coordinate values in Degrees, Minutes, and Seconds (DMS) formatted as rational fractions:

Latitude: 37/1, 48/1, 3600/100 N
Longitude: 122/1, 25/1, 1200/100 W

Parsing the Output into Decimal Degrees

The output fractions represent [Degrees]/1, [Minutes]/1, [Seconds*100]/100.

To convert the example above (37° 48' 36" N, 122° 25' 12" W) into standard decimal coordinates for mapping tools:

  1. Degrees: \(37\)
  2. Minutes: \(48 / 60 = 0.8\)
  3. Seconds: \((3600 / 100) / 3600 = 36 / 3600 = 0.01\)
  4. Total Latitude: \(37 + 0.8 + 0.01 = 37.81^\circ\text{ N}\) (\(+37.81\))
  5. Total Longitude: \(122 + (25 / 60) + (12 / 3600) = 122.42^\circ\text{ W}\) (\(-122.42\) for Western hemisphere)
