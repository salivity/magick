Extract ICC Profile from Image with ImageMagick

Extracting an embedded ICC color profile from an image file allows you to inspect, reuse, or standardize color management workflows across various design and publishing pipelines. This guide provides the exact command-line syntax required to extract embedded ICC profiles to an external file using ImageMagick, covering both modern and legacy versions of the software.

The Extraction Command

To extract an embedded ICC color profile to a standalone file, specify your source image followed by an output filename using the .icc or .icm extension.

ImageMagick 7 (Current):

magick input.jpg output.icc

ImageMagick 6 (Legacy):

convert input.jpg output.icc

Explicitly Specifying the ICC Format

To prevent ambiguity and ensure ImageMagick treats the destination strictly as a raw profile extraction, prefix the output file name with the icc: format delegate:

magick input.jpg icc:output.icc

How It Works

  • input.jpg: The source image containing the embedded ICC color profile (supports formats such as JPEG, PNG, TIFF, and PSD).
  • output.icc: The destination file where the raw profile data is saved. ImageMagick detects the .icc or .icm file extension and automatically extracts the profile payload without converting or altering image pixels.

Verifying the Extracted Profile

To confirm that an image contains an ICC profile before extraction, run the following command to check its metadata:

magick identify -verbose input.jpg | grep -i "Profile-icc"

If the profile exists, ImageMagick will display the profile name and byte length, confirming that it is available for extraction.
