Extract ICC Profile Using ImageMagick

This article provides the exact command-line syntax required to extract an embedded ICC color profile from an image and save it as a standalone .icc or .icm file using ImageMagick. You will learn the primary commands for both ImageMagick 7 and ImageMagick 6, along with methods to verify that an image contains a profile before extraction.

Basic Syntax

In ImageMagick, you extract an embedded color profile by specifying an output file with an .icc or .icm extension. ImageMagick automatically detects the extension and exports only the profile data instead of the image.

ImageMagick 7 (Current)

magick input_image.jpg output_profile.icc

ImageMagick 6 (Legacy)

convert input_image.jpg output_profile.icc

How It Works

  • input_image.jpg: The source image containing the embedded ICC profile (supports formats like JPEG, TIFF, and PNG).
  • output_profile.icc: The destination file. When given the .icc or .icm file extension, ImageMagick extracts the raw embedded profile byte stream directly to disk.

If the input image does not contain an embedded profile, ImageMagick will generate an error indicating that no color profile is present.

Verifying an Embedded Profile

To check if an image contains an embedded profile before attempting extraction, run:

magick identify -verbose input_image.jpg | grep -i "Profile-icc"

Or query the profiles directly using formatted output:

magick identify -format "%[profiles]" input_image.jpg

If the output lists icc or icm, you can safely run the extraction command.
