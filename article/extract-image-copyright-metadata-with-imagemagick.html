Extract Image Copyright Metadata with ImageMagick

This article provides the exact ImageMagick commands and shell script syntax required to extract copyright metadata from an image file. Whether the copyright details are stored in EXIF or IPTC profiles, you will learn how to capture this information directly into a shell variable for automated processing.

The Command to Extract Copyright Metadata

In ImageMagick version 7, you use the magick identify command combined with the -format option to target copyright tags. To store the extracted value inside a shell script variable, use command substitution $(...).

# Capture EXIF Copyright
COPYRIGHT=$(magick identify -format "%[exif:copyright]" input.jpg)

# Echo the result
echo "Copyright: $COPYRIGHT"

If you are using ImageMagick 6, replace magick identify with simply identify:

COPYRIGHT=$(identify -format "%[exif:copyright]" input.jpg)

Handling Different Metadata Profiles

Copyright information may be embedded under different metadata specifications depending on the software that created the image.

1. IPTC Copyright Notice

Many professional photography tools store copyright details in the IPTC dataset under tag 2:116 (Copyright Notice):

COPYRIGHT=$(magick identify -format "%[IPTC:2:116]" input.jpg)

2. Generic Copyright Property

ImageMagick often aliases standard metadata tags into simplified properties:

COPYRIGHT=$(magick identify -format "%[copyright]" input.jpg)

Complete Shell Script Example

Below is a robust shell script that checks for the copyright string across both EXIF and IPTC fields, falling back to a default message if no metadata is present:

#!/usr/bin/env bash

IMAGE_FILE="sample.jpg"

# Extract EXIF and IPTC copyright fields
EXIF_COPYRIGHT=$(magick identify -format "%[exif:copyright]" "$IMAGE_FILE" 2>/dev/null)
IPTC_COPYRIGHT=$(magick identify -format "%[IPTC:2:116]" "$IMAGE_FILE" 2>/dev/null)

# Prioritize IPTC, fall back to EXIF, or mark as Not Found
if [ -n "$IPTC_COPYRIGHT" ]; then
    COPYRIGHT="$IPTC_COPYRIGHT"
elif [ -n "$EXIF_COPYRIGHT" ]; then
    COPYRIGHT="$EXIF_COPYRIGHT"
else
    COPYRIGHT="No copyright metadata found"
fi

echo "File: $IMAGE_FILE"
echo "Copyright Notice: $COPYRIGHT"

To see all available metadata keys in an image to verify where copyright data is stored, run magick identify -verbose input.jpg in your terminal.
