Extract Image Width and Height Using ImageMagick

ImageMagick allows you to easily extract image dimensions directly from the command line using format specifiers. This guide demonstrates how to retrieve the width and height of an image as plain text strings and store them in environment variables across both Unix-like systems and Windows environments using modern ImageMagick commands.

The Basic Command

To print image dimensions as plain text without any extra metadata, use the identify tool with the -format parameter.

For ImageMagick v7:

magick identify -format "%w %h" image.jpg

For ImageMagick v6:

identify -format "%w %h" image.jpg
  • %w outputs the image width in pixels.
  • %h outputs the image height in pixels.

To get only the width:

magick identify -format "%w" image.jpg

To get only the height:

magick identify -format "%h" image.jpg

Storing Dimensions in Linux / macOS (Bash) Variables

To capture the width and height into separate shell variables using a single execution, use command substitution with the read command:

read WIDTH HEIGHT <<< $(magick identify -format "%w %h" image.jpg)

echo "Width: $WIDTH"
echo "Height: $HEIGHT"

Alternatively, you can assign them individually:

WIDTH=$(magick identify -format "%w" image.jpg)
HEIGHT=$(magick identify -format "%h" image.jpg)

Storing Dimensions in Windows Command Prompt (Batch)

In a Windows batch script (.bat), capture both dimensions into variables using a for /f loop:

@echo off
for /f "tokens=1,2" %%A in ('magick identify -format "%%w %%h" image.jpg') do (
    set WIDTH=%%A
    set HEIGHT=%%B
)

echo Width: %WIDTH%
echo Height: %HEIGHT%

Storing Dimensions in Windows PowerShell

In PowerShell, assign the output directly to variables:

$dimensions = magick identify -format "%w %h" image.jpg
$width, $height = $dimensions -split ' '

Write-Output "Width: $width"
Write-Output "Height: $height"
