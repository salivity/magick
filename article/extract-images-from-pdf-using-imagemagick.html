Extract Images from PDF Using ImageMagick

Extracting images from a PDF file using ImageMagick allows you to convert document pages into high-resolution raster formats such as PNG or JPEG directly from the command line. While ImageMagick achieves this by rasterizing the pages via Ghostscript rather than pulling raw binary streams from the PDF structure, setting the correct density, color depth, and quality parameters produces crisp, extracted images suitable for further editing or archiving.

Basic Extraction Command

In ImageMagick 7, the primary command-line tool is magick. In older installations (ImageMagick 6), the convert command is used.

To convert every page of a PDF document into a separate PNG image:

magick -density 300 input.pdf -quality 100 output_%03d.png

For ImageMagick 6:

convert -density 300 input.pdf -quality 100 output_%03d.png

Key Parameter Breakdown

  • -density 300: PDF documents are rendered at 72 DPI by default, which results in low-resolution, pixelated output. Specifying a density of 300 (or 600 for print-grade work) ensures that the rasterized output retains sharp detail. This flag must appear before the input file name so that the PDF is read into memory at the higher resolution.
  • input.pdf: The path to the source PDF file.
  • -quality 100: Determines the compression level. For PNG output, this specifies minimal compression; for JPEG output, it sets the highest visual fidelity.
  • output_%03d.png: The output filename pattern. The %03d token generates numbered sequences (e.g., output_000.png, output_001.png) for multi-page documents.

Extracting Specific Pages

To extract images from a specific page or a range of pages rather than the entire document, append the zero-indexed page number in square brackets immediately after the input file path:

  • Single page (Page 1): 
    magick -density 300 input.pdf[0] page_1.png
  • Page range (Pages 1 through 5): 
    magick -density 300 input.pdf[0-4] page_%d.png

Handling Transparency and Formats

If your PDF contains transparent layers and you want to extract images as JPEGs, set a white background to avoid black background artifacts caused by flattening:

magick -density 300 input.pdf -background white -alpha remove -alpha off -quality 95 output_%d.jpg

Rasterization vs. Raw Stream Extraction

ImageMagick processes PDFs by rasterizing the document pages as a whole, rendering text, vector paths, and embedded bitmaps onto a single flattened canvas.

If your goal is to extract purely raw, embedded bitmap files in their native dimensions without re-encoding or including surrounding page elements, consider using pdfimages from the Poppler utilities package:

pdfimages -png input.pdf extracted_img

However, if you need standardized output dimensions, format conversion, trimming, or automated filtering alongside extraction, ImageMagick's rendering pipeline remains the more versatile solution.

Troubleshooting Security Policies

Modern ImageMagick distributions disable PDF processing by default due to security considerations within Ghostscript. If you encounter a policy query: PDF not allowed error, edit your ImageMagick security configuration file (policy.xml, typically located in /etc/ImageMagick-7/ or /etc/ImageMagick-6/):

Find the following line:

<policy domain="coder" rights="none" pattern="PDF" />

Change rights="none" to:

<policy domain="coder" rights="read|write" pattern="PDF" />

Save the file, and ImageMagick will be able to process and extract PDF pages normally.
