Extract L Channel from Lab Image in ImageMagick

Extracting the Lightness (L*) channel from a CIELAB image using ImageMagick involves converting the input image into the CIELab color space, isolating the primary channel (channel 0), and separating it into a standalone grayscale image. This guide provides the exact command-line syntax required for both ImageMagick v7 and legacy ImageMagick v6.

Primary Command Syntax

For ImageMagick v7, use the magick command:

magick input.jpg -colorspace Lab -channel 0 -separate output_L.png

For ImageMagick v6, use the convert command:

convert input.jpg -colorspace Lab -channel 0 -separate output_L.png

Command Breakdown

  • input.jpg: The source image in any standard format (e.g., JPEG, PNG, TIFF).
  • -colorspace Lab: Converts the color representation from its native space (usually sRGB) into the CIELAB color space. In this space:
    • Channel 0 corresponds to L (Lightness).
    • Channel 1 corresponds to a (Green–Red axis).
    • Channel 2 corresponds to b (Blue–Yellow axis).
  • -channel 0 (or -channel R): Targets the first channel (Lightness) in the Lab image sequence.
  • -separate: Extracts the selected channel as an independent grayscale image.
  • output_L.png: The resulting file containing only the extracted Lightness data.

Alternative Method (Separating and Deleting Channels)

You can also split all three CIELAB channels simultaneously and discard the a and b channels:

magick input.jpg -colorspace Lab -separate -delete 1,2 output_L.png
  • -separate: Breaks the image into three separate layers (L, a, and b).
  • -delete 1,2: Removes the second and third layers (a and b), keeping only index 0 (the L channel).
