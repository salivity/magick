Extract Lightness Channel in ImageMagick

This guide explains how to extract the Lightness (L*) channel from an image using the LAB color space in ImageMagick. By converting an image to LAB and separating its first channel, you can isolate luminosity information while completely discarding color data (A* and B* channels).

The Command

For ImageMagick v7, use the following command:

magick input.jpg -colorspace LAB -channel 0 -separate lightness.png

For ImageMagick v6, use the legacy convert tool:

convert input.jpg -colorspace LAB -channel 0 -separate lightness.png

If the Input Image is Already in LAB Format

If your source file is already stored in the LAB color space (such as a specialized TIFF), omit the -colorspace LAB conversion flag:

magick input_lab.tif -channel 0 -separate lightness.png

Parameter Breakdown

  • input.jpg: The source image you want to process.
  • -colorspace LAB: Converts the image from its current color profile (typically sRGB) to the CIELAB color space, where channel 0 is Lightness (\(L^*\)), channel 1 is Green-Red (\(a^*\)), and channel 2 is Blue-Yellow (\(b^*\)).
  • -channel 0 (or -channel R): Selects the first channel of the colorspace, corresponding to Lightness (\(L^*\)).
  • -separate: Extracts the selected channel as a standalone grayscale image.
  • lightness.png: The resulting grayscale output file containing only the extracted lightness data.
