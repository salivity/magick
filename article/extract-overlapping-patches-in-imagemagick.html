Extract Overlapping Patches in ImageMagick

This article explains how to extract overlapping sub-patches from high-resolution images using ImageMagick for deep learning preprocessing. You will learn the core -crop geometry syntax, how to control pixel offsets, and how to automate a sliding window approach with a defined stride to generate overlapping dataset tiles.

Core Crop Syntax

ImageMagick uses the -crop operator to extract specific rectangular regions. To extract a single sub-patch at a specific coordinate, use the following syntax:

magick input.png -crop {width}x{height}+{x_offset}+{y_offset} +repage patch.png
  • {width}x{height}: The dimensions of the target patch (e.g., 256x256).
  • +{x_offset}+{y_offset}: The top-left starting coordinate for the patch.
  • +repage: Removes the canvas metadata offsets, ensuring the output image behaves as an independent patch rather than a cropped canvas view.

Generating Overlapping Patches with a Sliding Window

Standard ImageMagick grid splitting (-crop 256x256) only creates non-overlapping adjacent tiles. To create overlapping patches, you must slide the window across the \(X\) and \(Y\) axes using a stride smaller than the patch dimensions.

Here is a Bash script demonstrating automated overlapping patch generation:

#!/bin/bash
IMAGE="input.png"
PATCH_SIZE=256
STRIDE=128  # 50% overlap

# Read image dimensions
WIDTH=$(magick identify -format "%w" "$IMAGE")
HEIGHT=$(magick identify -format "%h" "$IMAGE")

# Loop over the image coordinates
for (( y=0; y<=HEIGHT-PATCH_SIZE; y+=STRIDE )); do
    for (( x=0; x<=WIDTH-PATCH_SIZE; x+=STRIDE )); do
        magick "$IMAGE" -crop "${PATCH_SIZE}x${PATCH_SIZE}+${x}+${y}" +repage "patch_${x}_${y}.png"
    done
done

Key Parameters for Deep Learning

  • Stride Calculation: Setting STRIDE equal to half the PATCH_SIZE produces a 50% overlap. Decrease the stride for denser spatial sampling.
  • Boundary Handling: The loop condition y<=HEIGHT-PATCH_SIZE ensures all extracted sub-patches strictly match the exact input dimensions required by deep neural network architectures without requiring padding.
