Extract Photoshop 8BIM Clipping Path in ImageMagick

This article provides a direct guide on how to identify, extract, and apply embedded Photoshop 8BIM clipping paths using ImageMagick. You will learn the command-line syntax required to export embedded vector paths to SVG/text formats, generate standalone black-and-white alpha masks, and crop images directly to their clipping paths.

1. Identify the Embedded 8BIM Path

Before extraction, verify that the image contains an embedded 8BIM profile with a path. Run the following command:

magick identify -verbose input.jpg | grep -A 10 "8BIM"

Alternatively, list only the embedded 8BIM profile information:

magick identify -format "%[8BIM:*]" input.jpg

2. Extract the Path as Vector Data (SVG or Text)

ImageMagick allows you to extract raw vector path coordinates defined in the 8BIM metadata using the 8BIM or 8BIMTEXT format delegates.

To extract the path directly as an SVG vector file:

magick input.jpg 8BIM:output.svg

To extract the path definition as plain text coordinates:

magick input.jpg 8BIMTEXT:path_data.txt

3. Extract the Clipping Path as an Alpha Mask

If you need a raster mask (black and white silhouette) representing the clipping path:

magick input.jpg -clip -negate -threshold 0 -background black -alpha off mask.png
  • -clip: Activates the first clipping path found in the 8BIM profile.
  • -negate: Inverts the selection area so the subject is preserved.
  • -threshold 0: Converts grayscale transitions into a pure binary mask.

4. Apply the Clipping Path and Export with Transparency

To extract the subject isolated by the clipping path directly to a transparent PNG:

magick input.jpg -clip -alpha transparent -strip output.png

If the image contains multiple named clipping paths, select a specific path by name using -clip-path:

magick input.jpg -clip-path "Path 1" -alpha transparent -strip output.png
  • -clip-path "Path 1": Specifies the exact path name defined in Photoshop.
  • -alpha transparent: Sets the area outside the clipping path to fully transparent.
  • -strip: Removes remaining metadata profiles to reduce file size.
