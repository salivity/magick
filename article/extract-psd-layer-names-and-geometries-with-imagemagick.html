Extract PSD Layer Names and Geometries with ImageMagick

ImageMagick provides robust command-line tools to inspect Adobe Photoshop (PSD) files and retrieve their internal metadata. By utilizing the identify tool with custom -format strings, you can parse a PSD file to extract every layer's name, dimensions, and canvas offset coordinates without needing to open Photoshop or manually export each asset.

The Core Command

In ImageMagick v7, use the magick identify command (or just identify in ImageMagick v6) paired with the -format parameter to read layer properties:

magick identify -format "Layer %[scene]: Name='%[label]' Geometry=%g\n" example.psd

Understanding the Format Specifiers

ImageMagick uses specific format properties to expose layer metadata:

  • %[scene] or %s: Returns the index number of the layer.
  • %[label]: Extracts the user-defined name of the PSD layer.
  • %[psd:layer.name]: An explicit property name used in certain ImageMagick releases to read PSD layer metadata if %[label] returns empty.
  • %g: Returns the complete geometry string in the format WidthxHeight+X+Y (e.g., 400x300+50+120), showing both layer size and offset relative to the canvas.
  • %w and %h: Return the individual width and height of the layer.
  • %X and %Y (or %O): Return the horizontal and vertical offset coordinates of the layer.

Advanced Usage and Filtering

1. Skipping the Flattened Composite

The first image in a PSD (index 0) is usually the pre-rendered, flattened composite image generated by Photoshop. To inspect only the actual individual layers, specify sub-image indexing:

magick identify -format "Name: %[label] | Bounds: %wx%h at %X,%Y\n" "example.psd[1--1]"

The [1--1] index tells ImageMagick to read from the first true layer to the last layer, ignoring layer 0.

2. Outputting to JSON

For automated scripts and pipelines, you can format the output directly into structured JSON:

magick identify -format "{\"index\": %[scene], \"name\": \"%[label]\", \"width\": %w, \"height\": %h, \"x\": %X, \"y\": %Y},\n" "example.psd[1--1]"

3. Handling Fallback Metadata

If a layer has no designated name, %[label] may be blank. You can query the verbose PSD artifact property as an alternative:

magick identify -format "Layer: %[psd:layer.name] (%g)\n" example.psd
