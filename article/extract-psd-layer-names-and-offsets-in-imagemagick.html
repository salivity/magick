Extract PSD Layer Names and Offsets in ImageMagick

Extracting metadata from Adobe Photoshop (PSD) files is a common requirement in automated graphic and web development workflows. ImageMagick treats individual PSD layers as separate image frames within a sequence, allowing you to use its command-line inspection utilities to read embedded layer names, canvas coordinates, and bounding boxes. By leveraging formatted strings in the identify command, you can quickly retrieve layer names and their exact canvas offset positions without opening Photoshop or writing complex parsing scripts.

The Basic Command

To read layer metadata, run the magick identify command (or identify in ImageMagick 6) with a customized -format string:

magick identify -format "Layer %[scene]: Name='%[label]', Offset=%X,%Y, Size=%wx%h\n" input.psd

Understanding the Format Specifiers

  • %[scene] or %s: The zero-based index of the layer frame.
  • %[label]: The layer name stored in the PSD metadata.
  • %X: The horizontal offset (X-coordinate) relative to the main canvas.
  • %Y: The vertical offset (Y-coordinate) relative to the main canvas.
  • %w and %h: The width and height of the layer's trimmed pixel data.
  • %g: Full geometry string, represented as (width)x(height)+(X)+(Y).
  • \n: A newline character to ensure each layer is output on a separate line.

Handling the Merged Composite Layer

In most PSD files, frame 0 (the first frame) is a pre-rendered, flattened composite of the entire document. The actual individual layers begin at frame index 1.

To ignore the merged composite and only read the individual sub-layers, specify a frame range starting from index 1:

magick identify -format "Name: %[label] | Position: +%X+%Y | Dimensions: %wx%h\n" "input.psd[1--1]"

The [1--1] syntax tells ImageMagick to read from frame index 1 through the last available frame (-1).

Exporting Metadata to Structured Formats

If you are integrating ImageMagick into automated scripts, you can format the output directly into structured data formats such as CSV or JSON.

CSV Output

magick identify -format "%[scene],\"%[label]\",%X,%Y,%w,%h\n" input.psd > layers.csv

JSON Output (ImageMagick 7)

ImageMagick 7 provides a native JSON output option that extracts all available PSD metadata, including layer hierarchy and offsets:

magick identify -verbose -format "%[json:]" input.psd

For targeted JSON extraction via the -format flag:

magick identify -format "{\"index\": %[scene], \"name\": \"%[label]\", \"x\": %X, \"y\": %Y, \"width\": %w, \"height\": %h}\n" "input.psd[1--1]"

Troubleshooting Missing Layer Names

In some instances where PSD files are saved by third-party applications or older Photoshop versions, the %[label] property might be empty. You can check alternative PSD-specific properties using:

magick identify -format "Layer %[scene]: Name='%[psd:layer-name]', Offset=+%X+%Y\n" input.psd

If %[psd:layer-name] is available, it will explicitly target the Photoshop layer property tag directly.
