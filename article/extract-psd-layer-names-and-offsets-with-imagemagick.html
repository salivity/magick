Extract PSD Layer Names and Offsets with ImageMagick

This guide explains how to read and extract Adobe Photoshop (PSD) layer metadata—specifically layer names and their X/Y offset coordinates—using the ImageMagick identify command-line tool. By leveraging custom formatting strings, you can quickly parse layer information directly from PSD files without opening Photoshop or running heavy graphical applications.

Understanding PSD Layer Structure in ImageMagick

When ImageMagick processes a PSD file, it reads the file as a multi-frame image.

  • Frame [0] typically represents the merged composite image.
  • Frames [1] and beyond correspond to the individual layers.

Each frame contains geometry and metadata attributes that expose its positioning and naming details.

Key Format Identifiers

The identify tool uses the -format flag with specific escape codes and properties:

  • %[psd:layer-name] or %[label]: Returns the layer name defined in Photoshop.
  • %X: The horizontal (X) offset relative to the canvas.
  • %Y: The vertical (Y) offset relative to the canvas.
  • %w: Layer width in pixels.
  • %h: Layer height in pixels.
  • %g: The full canvas geometry string (e.g., 100x150+20+40).
  • %s: The layer/frame index number.

Command Examples

Basic Extraction

To print the layer name, X offset, and Y offset for every layer in design.psd:

ImageMagick v7:

magick identify -format "Layer %[s]: '%[psd:layer-name]' | Offset: X=%X, Y=%Y\n" design.psd

ImageMagick v6:

identify -format "Layer %[s]: '%[psd:layer-name]' | Offset: X=%X, Y=%Y\n" design.psd

Fallback with %[label]

If %[psd:layer-name] returns blank values depending on the PSD version or ImageMagick build, %[label] serves as a reliable alternative:

magick identify -format "Layer %[s]: '%[label]' | Offset: +%X+%Y | Size: %[w]x%[h]\n" design.psd

Excluding the Merged Composite Layer

To skip the first frame (the merged composite) and extract data only from the actual layers, use frame range notation:

magick identify -format "%[psd:layer-name],%X,%Y,%w,%h\n" "design.psd[1--1]"
  • [1--1] instructs ImageMagick to read from index 1 through the final frame, omitting frame 0.

Exporting directly to CSV

You can format the output directly into a structured CSV file for use in scripts or data pipelines:

echo "LayerIndex,LayerName,OffsetX,OffsetY,Width,Height" > layers.csv
magick identify -format "%[s],\"%[psd:layer-name]\",%X,%Y,%w,%h\n" "design.psd[1--1]" >> layers.csv
