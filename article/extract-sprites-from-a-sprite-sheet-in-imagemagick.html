Extract Sprites from a Sprite Sheet in ImageMagick

Extracting individual frames from a sprite sheet or texture atlas is a common task in game development and animation workflows. This guide covers the exact ImageMagick syntax needed to automatically slice uniform sprite grids into sequentially numbered image files, as well as how to extract single frames using specific pixel coordinates and offsets.

Extracting All Frames from a Uniform Grid

When your sprite sheet is laid out in a regular grid where every frame shares the exact same width and height, you can split the entire sheet in a single command.

ImageMagick v7 Syntax:

magick input_sheet.png -crop [Width]x[Height] +repage frame_%03d.png

ImageMagick v6 Syntax:

convert input_sheet.png -crop [Width]x[Height] +repage frame_%03d.png

Parameter Breakdown:

  • -crop [Width]x[Height]: Defines the dimensions of a single frame in pixels (e.g., -crop 64x64). ImageMagick divides the source image from left to right, top to bottom, generating a tile for every segment matching these dimensions.
  • +repage: Crucial for removing the virtual canvas offsets. Without +repage, the output images retain metadata about their original position on the sheet, which causes rendering issues in many game engines and viewers.
  • frame_%03d.png: Specifies the output filename pattern. The %03d format specifier generates zero-padded numbers (e.g., frame_000.png, frame_001.png, frame_002.png).

Extracting a Single Specific Frame

To extract a single frame located at a known coordinate on the sprite sheet, add horizontal (+X) and vertical (+Y) offsets to the geometry string.

Syntax:

magick input_sheet.png -crop [Width]x[Height]+[X_Offset]+[Y_Offset] +repage single_frame.png

Example:

To extract a 32x32 frame starting at pixel position (64, 128):

magick atlas.png -crop 32x32+64+128 +repage extracted_sprite.png

Example: Slicing a 256x256 Sheet into 32x32 Tiles

If you have a character.png file that is 256x256 pixels containing an 8x8 grid of 32x32 sprites:

magick character.png -crop 32x32 +repage sprite_%02d.png

This generates 64 individual files named sprite_00.png through sprite_63.png.
