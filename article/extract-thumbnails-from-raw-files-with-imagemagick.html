Extract Thumbnails from RAW Files with ImageMagick

RAW camera files contain one or more embedded JPEG preview and thumbnail images used by cameras and operating systems for quick file browsing. ImageMagick can access these embedded image streams and export each of them directly into standalone JPEG files without needing to process or demosaic the heavy raw sensor data.

The Extraction Command

To extract all embedded preview images and thumbnails from a RAW photo file using ImageMagick 7, use the following command:

magick input_file.RAW embedded_%d.jpg

For ImageMagick 6, use the legacy convert tool:

convert input_file.RAW embedded_%d.jpg

Replace input_file.RAW with the filename and extension of your specific raw format (such as .CR2, .CR3, .NEF, .ARW, or .DNG).

How the Command Works

  • Multi-Scene Handling: ImageMagick reads the RAW file container and detects any embedded image layers or preview streams as separate image "scenes" or frames.
  • The %d Formatter: The %d token in the output filename specifies an integer placeholder. ImageMagick automatically writes each detected image frame to a numbered output file (e.g., embedded_0.jpg, embedded_1.jpg).

Extracting a Specific Embedded Image

If you only want to extract a specific embedded frame (such as the smallest thumbnail or the full-size embedded JPEG preview), you can append a zero-based index to the input file:

magick "input_file.RAW[0]" thumbnail.jpg

Batch Extracting from Multiple Files

To extract thumbnails from an entire directory of RAW files on Linux or macOS, use a standard shell loop:

for file in *.CR2; do
  magick "$file" "${file%.*}_thumb_%d.jpg"
done

On Windows Command Prompt:

for %f in (*.CR2) do magick "%f" "%~nf_thumb_%d.jpg"
