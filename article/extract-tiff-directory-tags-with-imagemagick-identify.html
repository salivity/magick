Extract TIFF Directory Tags with ImageMagick Identify

This guide explains how to extract all TIFF directory tags and embedded metadata using ImageMagick's identify command. You will learn the specific -format percent escapes required to dump all properties, isolate TIFF-specific directory tags, and handle multi-page TIFF files directly from the command line.

Extracting All Properties Using %[*]

ImageMagick stores TIFF directory tags as image properties, typically prefixed with tiff:. To output all metadata properties for an image, use the %[*] format directive:

magick identify -format "%[*]" input.tif

(For ImageMagick v6, replace magick identify with identify)

This command prints every embedded property, including standard TIFF tags such as tiff:make, tiff:model, tiff:photometric, tiff:rows-per-strip, and custom EXIF directory values in a key=value format.

Filtering Specifically for TIFF Tags

Because %[*] prints all metadata (including general image attributes, timestamps, and color profiles), you can pipe the output to filter specifically for TIFF directory tags:

magick identify -format "%[*]" input.tif | grep '^tiff:'

On Windows Command Prompt, use findstr:

magick identify -format "%[*]" input.tif | findstr /B "tiff:"

Extracting Directory Tags from Multi-Page TIFFs

TIFF files often contain multiple sub-directories (IFDs), representing different pages or pyramid levels. By default, identify without a sub-image index operates on all frames.

To display the tags along with the frame/page number:

magick identify -format "Page %[scene]:\n%[*]\n\n" input.tif | grep -E '^Page|^tiff:'

To extract tags from a specific directory or page, specify the zero-based index in brackets:

magick identify -format "%[*]" "input.tif[0]"

Outputting Tags as Structured JSON

If you need to parse the TIFF directory tags within automated scripts or external applications, ImageMagick provides a built-in JSON formatter:

magick identify -format "%[json]" input.tif

The resulting JSON includes a "properties" object containing every TIFF tag as individual key-value pairs.
