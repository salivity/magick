Extract Unique Colors with ImageMagick

Extracting unique colors from an image is a common requirement for palette generation, color analysis, and asset processing. This article demonstrates how to use ImageMagick to isolate every distinct color present in an image and export those unique values into a new, separate image file.

The Basic Command

ImageMagick provides a built-in operator called -unique-colors that analyzes the input image, discards duplicate color values, and outputs a new image consisting of a 1-pixel high strip containing only the unique colors.

For ImageMagick version 7:

magick input.png -unique-colors output_unique.png

For ImageMagick version 6:

convert input.png -unique-colors output_unique.png

If your input image contains 500 unique colors, the resulting output_unique.png will have a resolution of 500×1 pixels.

Scaling the Output for Visibility

Because a 1-pixel high output image is difficult to view directly, you can scale the height up using the -scale operator. Using -scale rather than -resize preserves the exact pixel values without applying anti-aliasing or blending intermediate colors:

magick input.png -unique-colors -scale 1000x50! palette.png

In this command:

  • -unique-colors reduces the image to a 1-pixel-tall bar of unique colors.
  • -scale 1000x50! forces the output to be 1000 pixels wide and 50 pixels tall, maintaining sharp boundaries between the color blocks.

Limiting the Color Palette Before Extraction

If an image contains thousands of subtle variations (such as in JPEG photos), you may want to quantize the colors before extracting them to keep the palette manageable:

magick input.png -colors 16 -unique-colors -scale 800x100! palette_16.png

This reduces the image to the 16 most prominent colors first, extracts them, and scales the final swatch for easy viewing.

Exporting Unique Colors as Text

If you need a list of color codes (such as HEX or RGB values) rather than an image file, you can output the unique colors directly to a text file:

magick input.png -unique-colors txt:unique_colors.txt

This generates a text file containing the coordinates, hex values, and RGB definitions of every unique color found in the source file.
