Extract Video Frames Using ImageMagick

ImageMagick enables users to read and extract image frames directly from video files by leveraging multimedia delegates such as FFmpeg. By using standard input syntax combined with frame-indexing brackets, you can extract a single frame, a specific range of frames, or the entire frame sequence into standard image formats like JPEG or PNG.

Core Command Syntax

To read frames directly from a video file in ImageMagick v7, use the magick command followed by the video file name and the target image output:

magick input.mp4 output_%03d.png

This command processes the entire video file and writes every frame as a numbered PNG file (e.g., output_000.png, output_001.png).

Selecting Specific Frames

ImageMagick uses bracket notation appended to the filename to target specific frame indices. Frame numbering starts at 0.

Extract a Single Frame

To extract only the first frame (index 0):

magick input.mp4[0] first_frame.jpg

To extract a specific frame later in the video, replace the index with the desired frame number:

magick input.mp4[120] frame_120.jpg

Extract a Range of Frames

To extract a sequence of specific frames, specify the start and end frame within the brackets separated by a hyphen:

magick input.mp4[50-100] frame_%03d.png

Requirements and Performance

For ImageMagick to read video files directly, FFmpeg must be installed on your system and configured as a delegate in ImageMagick's delegates.xml file. When you provide a video file as an input, ImageMagick automatically calls FFmpeg in the background to decode the video stream into raw image data before applying any transformations or writing the output.
