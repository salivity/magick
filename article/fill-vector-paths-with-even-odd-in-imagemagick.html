Fill Vector Paths with Even-Odd in ImageMagick

This article explains how to apply the even-odd fill rule to vector paths using ImageMagick. You will learn the correct command-line syntax for the fill-rule primitive, understand how to define paths with holes or self-intersecting boundaries, and see concrete examples demonstrating the even-odd filling behavior directly from the terminal.

Understanding the Even-Odd Fill Rule

The fill rule determines whether a given point lies inside or outside a complex vector path.

  • Non-Zero (Default): Determines insideness by counting path direction (winding number).
  • Even-Odd: Determines insideness by drawing a ray from the point toward infinity and counting how many path segments it crosses. If the total number of crossings is odd, the point is inside (filled); if even, it is outside (unfilled).

This rule is ideal for creating compound shapes with cutouts or self-intersecting polygons regardless of path winding direction.

Command-Line Syntax

In ImageMagick, vector paths are typically drawn using the -draw operator with Magick Vector Graphics (MVG) syntax. To set the fill rule to even-odd, place fill-rule evenodd inside the -draw string before the path definition.

magick -size 400x400 xc:white \
  -fill "#2563eb" \
  -draw "fill-rule evenodd path 'M 50,50 L 350,50 L 350,350 L 50,350 Z M 125,125 L 275,125 L 275,275 L 125,275 Z'" \
  output.png

(Note: For ImageMagick version 6, replace magick with convert.)

How the Command Works:

  1. -size 400x400 xc:white: Creates a blank white canvas of 400×400 pixels.
  2. -fill "#2563eb": Sets the fill color.
  3. -draw "fill-rule evenodd path '...'":
    • fill-rule evenodd instructs the renderer to use the even-odd method.
    • path '...' contains the standard SVG-compatible path data string.
    • The example draws an outer square followed by an inner square, creating a hollow frame.

Example: Self-Intersecting Star

A classic use case for the even-odd fill rule is a 5-pointed star where the inner pentagon remains transparent.

magick -size 300x300 xc:transparent \
  -fill "#e11d48" \
  -draw "fill-rule evenodd path 'M 150,20 L 190,140 L 310,140 L 210,210 L 250,330 L 150,250 L 50,330 L 90,210 L -10,140 L 110,140 Z'" \
  star_evenodd.png

Because the overlapping regions cross path segments an even number of times, the center of the star is excluded from the fill.

Using SVG Files Directly

If you are rendering an external vector path via SVG, you can specify the fill-rule attribute directly inside the SVG markup:

<svg width="400" height="400" xmlns="http://www.w3.org/2000/svg">
  <path fill="#059669" fill-rule="evenodd" d="M 50,50 L 350,50 L 350,350 L 50,350 Z M 150,150 L 250,150 L 250,250 L 150,250 Z" />
</svg>

Render it using ImageMagick:

magick input.svg output.png
