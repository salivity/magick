Filter Connected Components by Area in ImageMagick

Removing dust specks, scanner noise, and isolated artifacts is a common preprocessing task in image processing. This article provides a direct guide on using ImageMagick’s built-in connected-components labeling (CCL) feature to filter out small pixel clusters by defining an area threshold, effectively eliminating unwanted noise without blurring important image details.

Understanding the Connected Components Operator

ImageMagick includes the -connected-components operator, which analyzes an image, groups neighboring pixels into distinct objects (components), and computes statistics such as bounding box, centroid, and area (pixel count).

To remove dust specks, you define a minimum area threshold using -define connected-components:area-threshold=<pixels>. Any component smaller than this threshold is merged into the surrounding background color when combined with -define connected-components:mean-color=true.

Basic Command Syntax

For ImageMagick version 7, use the magick command:

magick input.png \
  -define connected-components:area-threshold=15 \
  -define connected-components:mean-color=true \
  -connected-components 8 \
  output.png

If you are using ImageMagick 6, replace magick with convert.

Step-by-Step Breakdown

  1. Thresholding (Optional but Recommended):
    Connected-components labeling works best on binary or high-contrast images. If working with scanned documents or line art, binarize the image first using -threshold:

    magick scan.png -threshold 50% \
  -define connected-components:area-threshold=20 \
  -define connected-components:mean-color=true \
  -connected-components 8 \
  cleaned.png

  2. Setting the Area Threshold (area-threshold):
    The value represents the size of the component in total pixels. A value of 15 means any isolated connected group of 14 or fewer pixels will be filtered out. Increase this number for larger specks or decrease it to preserve fine punctuation (like the dot of the letter "i").

  3. Merging Small Objects (mean-color=true):
    Setting mean-color=true tells ImageMagick to colorize the output objects. When an object falls below the area-threshold, it is replaced by the mean color of the surrounding region, making it disappear into the background.

  4. Connectivity (4 vs 8):
    The argument passed directly to -connected-components specifies neighbor connectivity:

    • 4: Checks orthogonal neighbors (up, down, left, right).
    • 8: Checks orthogonal and diagonal neighbors. Using 8 is recommended for dust removal to ensure diagonally touching noise pixels are treated as a single speck.

Advanced Usage: Inspecting Component Data

Before applying a destructive threshold, you can inspect the size of the specks in your image by generating a text report of all detected objects:

magick input.png -threshold 50% -connected-components 8 -auto-level output_labels.png > objects.txt

The resulting objects.txt file lists the ID, bounding box, centroid, area, and mean color of every component found, allowing you to choose the ideal pixel count for your area threshold.
