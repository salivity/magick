Filter Connected Components by Circularity in ImageMagick

This guide explains how to extract round punctuation marks, such as periods, colons, and the dots on "i"s and "j"s, from text images using ImageMagick's connected-components labeling. By binarizing the image, calculating shape properties like circularity and aspect ratio from the component statistics, and re-applying those filtered IDs as a mask, you can effectively isolate small circular marks from elongated letterforms.

Understanding the Process

ImageMagick provides the -connected-components operator to find and measure distinct blobs of pixels. While ImageMagick outputs core metrics such as area, bounding box coordinates, and centroids, isolating punctuation requires determining whether a component is roughly circular.

Circularity (\(C\)) is traditionally calculated as: \[C = \frac{4 \pi \times \text{Area}}{\text{Perimeter}^2}\]

For text extraction, an efficient approximation combines two checks:

  1. Aspect Ratio: The ratio of width to height (\(W / H\)) should be close to \(1.0\).
  2. Fill Factor / Area Ratio: The area of the component divided by the area of its bounding box (\(A / (W \times H)\)) should be close to \(\pi / 4 \approx 0.785\) for a solid circle.

Step 1: Preprocess the Image

Ensure the input image is converted to high-contrast black-and-white. This separates characters from the background clearly.

magick input.png -colorspace Gray -threshold 50% -negate binary.png

Note: Negating the image makes the text white on a black background, which is standard for connected-component analysis.

Step 2: Extract Connected Components Data

Run the connected-components analysis with verbose output to inspect the components:

magick binary.png \
  -define connected-components:verbose=true \
  -connected-components 8 \
  null: > components.txt

The output contains rows formatted like: id: bounding-box centroid area mean-color Example: 12: 8x8+142+85 145.5,88.5 48 srgb(255,255,255)

Step 3: Filter Component IDs by Circularity

Using a shell tool like awk, parse the components file to filter for punctuation marks based on:

  • Area limits: Exclude tiny noise speckles and large letters (e.g., \(10 \le \text{Area} \le 120\)).
  • Aspect ratio: Ensure width and height are nearly identical (\(0.8 \le W/H \le 1.25\)).
  • Fill factor: Ensure the pixel area closely matches that of a disk inside the bounding box (\(0.65 \le \text{Area} / (W \times H) \le 0.90\)).

Run the following script to generate a comma-separated list of matching IDs:

TARGET_IDS=$(awk '
NR > 1 {
  # Parse bounding box: WxH+X+Y
  split($2, bbox, /[x+]/);
  w = bbox[1];
  h = bbox[2];
  area = $4;
  color = $5;

  # Only inspect foreground components (white)
  if (color ~ /255/) {
    aspect = w / h;
    fill = area / (w * h);

    # Filter by size, aspect ratio, and circular fill factor
    if (area >= 10 && area <= 150 && aspect >= 0.75 && aspect <= 1.33 && fill >= 0.65 && fill <= 0.90) {
      # Extract ID (remove trailing colon)
      sub(/:/, "", $1);
      ids = (ids == "" ? $1 : ids "," $1);
    }
  }
}
END { print ids }
' components.txt)

Step 4: Isolate the Selected Punctuation

Once the IDs are identified, instruct ImageMagick to retain only those components using the connected-components:keep-ids define.

magick binary.png \
  -define connected-components:keep-ids="$TARGET_IDS" \
  -connected-components 8 \
  punctuation_only.png

If you need the result inverted back to standard black text on a white background:

magick punctuation_only.png -negate final_punctuation.png

Tips for Better Results

  • Scale Adjustments: If working with high-resolution scans, adjust the area threshold bounds to match the font size of the document.
  • Handling Semicolons and Exclamation Points: The dot of a semicolon or exclamation mark will be isolated, but the rest of the stroke will be discarded because its aspect ratio and fill factor do not meet the circularity criteria.
  • Alternative for True Circularity: If characters are distorted, morphology operations can be used prior to labeling: 
    magick binary.png -morphology Hit-and-Miss Disk:2 isolated_centers.png
    This can serve as a geometric pre-filter before running connected-components analysis.
