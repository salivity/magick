Find Brightest Pixel Coordinates in ImageMagick

This article explains how to quickly find the exact X and Y pixel coordinates of the brightest point in an image using ImageMagick. Whether you are analyzing astronomical images, locating hotspots in thermal data, or processing digital photos, ImageMagick provides built-in utilities to extract maximum luminance coordinates directly from the command line.

Method 1: Using the Built-in identify:locate Feature (Fastest)

The most efficient way to get the coordinates of the maximum brightness pixel is by using the -define identify:locate=maximum option.

ImageMagick v7

magick input.jpg -colorspace Gray -define identify:locate=maximum -identify null:

ImageMagick v6

convert input.jpg -colorspace Gray -define identify:locate=maximum -identify null:

How It Works:

  • -colorspace Gray converts the image to grayscale so that brightness (luminance) is evaluated across a single channel rather than individual R, G, and B channels.
  • -define identify:locate=maximum tells ImageMagick to search for the pixel with the highest intensity value.
  • -identify null: prints the image metadata (including the found coordinates) to standard output without saving an output image file.

The output will include a line specifying the coordinate and value, formatted like:

Gray: 255 (1) @ 412,185

Here, 412,185 represents the X,Y coordinate of the brightest pixel.

Method 2: Extracting Pure Coordinates via Text Output (Scripting)

If you need only the raw coordinates for use in automated shell scripts, you can export the image pixel data to the txt: format and sort by brightness.

magick input.jpg -colorspace Gray txt: | grep -v "^#" | sort -k 3 -r -n | head -n 1 | cut -d: -f1

How It Works:

  1. txt: outputs every pixel coordinate along with its grayscale value.
  2. grep -v "^#" removes the ImageMagick metadata header comment.
  3. sort -k 3 -r -n sorts the pixels numerically in descending order based on their brightness value.
  4. head -n 1 picks the first (brightest) pixel.
  5. cut -d: -f1 trims the output to show only the X,Y coordinates (e.g., 412,185).
