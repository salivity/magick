Find Darkest Pixel Coordinates in ImageMagick

This guide explains how to locate the exact X and Y coordinates of the darkest pixel in an image using ImageMagick from the command line. By converting the image to grayscale and exporting the pixel data into a sortable text format, you can quickly identify the minimum brightness value and its position.

The Command

To find the darkest pixel using ImageMagick v7, run the following command in your terminal:

magick input.png -colorspace Gray txt:- | sed '1d' | sort -k 3 -n | head -n 1

(Note: If using ImageMagick v6, replace magick with convert.)

How It Works

  1. -colorspace Gray: Converts the image into single-channel grayscale so pixel brightness can be evaluated by a single intensity value.
  2. txt:-: Instructs ImageMagick to output the pixel data as plain text to the standard output instead of saving a file. Each row represents a pixel with its X,Y coordinates and color values.
  3. sed '1d': Strips the header comment line generated at the top of the txt: output.
  4. sort -k 3 -n: Sorts the output numerically based on the third field (the pixel brightness value), placing the darkest pixels (closest to 0) at the beginning.
  5. head -n 1: Returns only the first line of the sorted results, which corresponds to the darkest pixel.

Extracting Only the X,Y Coordinates

To output solely the coordinate pair (e.g., 120,45), pipe the result into cut or awk:

magick input.png -colorspace Gray txt:- | sed '1d' | sort -k 3 -n | head -n 1 | cut -d: -f1

This strips all color values and hex codes, leaving only the X,Y coordinate of the darkest point in the image.
