Fisheye Lens Distortion in ImageMagick

This guide demonstrates how to simulate a fish-eye camera lens distortion effect on an image using ImageMagick. By utilizing the -distort Barrel operator, you can apply custom radial distortion coefficients to create wide-angle, spherical fisheye visuals directly from the command line.

The ImageMagick Fisheye Command

In ImageMagick (version 7 and newer), the primary command used to simulate a fisheye lens distortion is the magick command paired with the -distort Barrel operator:

magick input.jpg -virtual-pixel Black -distort Barrel "0.0 0.0 0.3 0.7" output.jpg

If you are using ImageMagick version 6, replace magick with convert:

convert input.jpg -virtual-pixel Black -distort Barrel "0.0 0.0 0.3 0.7" output.jpg

How the Parameters Work

The -distort Barrel method takes four coefficients: A B C D. These values define the radial polynomial equation \(R_{src} = r \cdot (A \cdot r^3 + B \cdot r^2 + C \cdot r + D)\) used to remap the pixels from the center of the image outward:

  • A (0.0): Controls cubic distortion at the outer perimeter.
  • B (0.0): Controls quadratic distortion.
  • C (0.3): Controls linear barrel/pincushion distortion. Positive values expand the center and compress the edges, producing the classic fisheye bulge.
  • D (0.7): Controls the overall image scaling. To prevent scaling changes at the center, the sum of \(A + B + C + D\) is typically set to 1.0 (for example, \(0.0 + 0.0 + 0.3 + 0.7 = 1.0\)).

Controlling the Image Boundary

When bending pixels outward, empty areas can appear around the corners:

  • -virtual-pixel Black: Fills the empty boundary areas created by the curvature with a solid black frame, mimicking an authentic circular lens hood.
  • -virtual-pixel HorizontalTile or Edge: Extends the outermost pixels to prevent a black border if a full-bleed frame is preferred.

Stronger Fisheye Effect Example

To achieve a more exaggerated, circular fisheye perspective, increase the C parameter and decrease the D scale parameter accordingly:

magick input.jpg -virtual-pixel Black -distort Barrel "0.0 0.0 0.5 0.5" output.jpg
