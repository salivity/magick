Fix Blurry Text When Converting PDF in ImageMagick

Converting vector PDF files into raster images using ImageMagick often leads to fuzzy, low-resolution text because ImageMagick defaults to rendering PDFs at 72 DPI. To eliminate blurry text outlines and achieve crisp typography, you must define the -density option before loading the input PDF, optionally combining it with a downscaling technique known as supersampling.

The Solution: The -density Option

The primary option to prevent fuzzy outlines is -density. When processing vector graphics like PDFs, ImageMagick relies on Ghostscript to rasterize the vector paths. If no density is specified, it renders at the standard screen resolution (72 DPI), causing visible pixelation and blurred edges when scaled.

You must place the -density option before specifying the input PDF so ImageMagick renders the vector source at a higher resolution from the start.

magick -density 300 input.pdf -quality 100 output.png

Optimal Method: High-Density Supersampling

While simply increasing -density 300 improves clarity, the cleanest method for generating a standard-sized image with razor-sharp text outlines is supersampling. This involves rendering the PDF at a high density (such as 300 or 600 DPI) and then resizing it down to your desired target dimensions.

magick -density 300 input.pdf -background white -alpha remove -alpha off -resize 25% output.png

Key Options Explained

  • -density 300 (or 600): Forces Ghostscript to interpret vector fonts at print resolution before ImageMagick rasterizes the file. It must precede the input filename.
  • -background white -alpha remove -alpha off: Flattens transparent PDF backgrounds to solid white, which prevents fuzzy dark halos around antialiased text boundaries.
  • -resize 25%: Scales a 300 DPI rasterization down to match standard 75 DPI display dimensions while preserving sharp, antialiased edge details.
  • +antialias (Optional): Disables font smoothing entirely if you require strict, binary-pixel text outlines without gradient edge pixels.
