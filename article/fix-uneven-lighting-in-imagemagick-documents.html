Fix Uneven Lighting in ImageMagick Documents

This guide demonstrates how to remove shadows and inconsistent lighting gradients from scanned or photographed documents using ImageMagick. By isolating the background illumination via a heavy blur and dividing the original image by that extracted background, you can effectively neutralize light variations. The result is a document with an evenly flattened, clean background that dramatically improves legibility, print quality, and optical character recognition (OCR) accuracy.

The Standard Flattening Command

To correct uneven lighting while preserving standard text contrast, run the following command (ImageMagick v7):

magick input.jpg ( +clone -blur 0x50 ) -compose Divide -composite -auto-level output.png

If you are using legacy ImageMagick (v6), use convert instead of magick:

convert input.jpg ( +clone -blur 0x50 ) -compose Divide -composite -auto-level output.png

How the Command Sequence Works

The process uses a multiplicative illumination model (\(I = R \times L\)), where illumination (\(L\)) is separated from the reflectance (\(R\)) of the page and divided out:

  1. input.jpg: Loads the source image.
  2. ( +clone -blur 0x50 ): Clones the original image in memory and applies an extensive Gaussian blur. The 0x50 parameter uses an auto-calculated kernel with a 50-pixel sigma. This blurs away fine details like text, leaving only the broad, uneven light gradient across the page.
  3. -compose Divide: Sets the composition operator to division.
  4. -composite: Divides the original image by the heavily blurred illumination map. Pixels in darker shadowed areas are divided by corresponding dark background pixels, scaling them back up to a uniform white baseline.
  5. -auto-level: Stretches the dynamic range of the final image so the text remains dark and the flattened paper reaches full white.

Producing Pure Black-and-White Output (for OCR)

For scanned text where a strictly binarized output is preferred over grayscale or color, incorporate a grayscale conversion and a threshold step:

magick input.jpg -colorspace gray ( +clone -blur 0x50 ) -compose Divide -composite -linear-stretch 1%x1% -threshold 85% output.png
  • -colorspace gray: Strips color noise from the source document before processing.
  • -linear-stretch 1%x1%: Clamps the bottom 1% and top 1% of pixel intensities to eliminate noise and clipping artifacts before thresholding.
  • -threshold 85%: Converts the final corrected image into crisp black text on a pure white background.

Parameter Tuning

  • Blur Radius (-blur 0x[radius]): The blur radius should be significantly larger than the thickness of the text, but small enough to track rapid illumination changes. For high-resolution mobile camera captures (12MP or higher), increase the blur value to 0x80 or 0x100.
  • Dark Border Artifacts: If shadows fall tightly along the extreme edges of the paper, crop the borders with -shave before processing to prevent edge-wrapping artifacts during the blur phase.
