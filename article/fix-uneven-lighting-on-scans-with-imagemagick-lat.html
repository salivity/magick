Fix Uneven Lighting on Scans with ImageMagick LAT

The -lat (Local Adaptive Threshold) operator in ImageMagick removes uneven lighting, shadows, and gradients from scanned documents by evaluating each pixel against its immediate surroundings rather than applying a single global threshold to the entire image. This process dynamically isolates text from dark or inconsistent backgrounds, producing clean, high-contrast black-and-white documents suitable for archiving or Optical Character Recognition (OCR).

How Global Thresholding Fails on Scans

Standard global thresholding compares every pixel in an image to a single brightness value. When a scan has uneven lighting—such as a shadow cast by a phone camera, a curled book spine, or a weak scanner bulb—a global threshold fails. If the threshold is set to capture faint text in bright areas, shadowed areas turn completely black. Conversely, if it is tuned for shadowed regions, text in the well-lit areas disappears entirely.

How the -lat Operator Works

The -lat operator solves this problem by calculating a unique threshold for every individual pixel based on the average brightness of a local window of neighboring pixels.

The syntax for the operator is:

-lat {width}x{height}{+-}{offset}[%]

  • width x height: Defines the pixel dimensions of the local neighborhood window centered around the target pixel.
  • offset: A brightness difference value (or percentage) subtracted from (or added to) the local neighborhood average.

When processing a pixel:

  1. ImageMagick calculates the average pixel intensity within the specified width x height box.
  2. It subtracts the offset value from this local average to establish the threshold for that specific pixel.
  3. If the pixel's brightness is greater than the resulting threshold, it is converted to white (background). If it is darker, it is converted to black (text).

Why -lat Eliminates Uneven Lighting

Because the operator only looks at local windows, slow-changing variations across the page—such as dark gradients across the paper or harsh edge shadows—are treated as the local baseline.

Even if a portion of the document is heavily shaded, the text inside that shadow is still darker than the paper directly beneath it. The -lat operator measures that local contrast difference, allowing dark text inside a shadow to be recognized just as accurately as dark text under bright light, while the shadow itself is flattened to pure white.

Recommended Usage and Parameter Tuning

To achieve optimal results on a scanned document:

magick input.jpg -colorspace Gray -lat 25x25-10% output.png
  • Window Size (25x25): The window must be larger than the stroke width of the thickest characters on the page, but small enough to adapt to rapid changes in lighting. A window between 20x20 and 50x50 pixels typically works well for standard document resolutions (300 DPI). If the window is too small, the centers of thick letters may hollow out into white.
  • Offset (-10% or -5): A negative offset requires a pixel to be distinctly darker than its local background to become black. This suppresses paper grain, texture, and faint background bleed-through. If the offset is too large, thin text will break apart; if it is too small, digital noise and paper speckles will appear as black dots.
