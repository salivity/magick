Flatten PSD Layers to Image with ImageMagick

This guide explains how to flatten all visible layers of an Adobe Photoshop (PSD) file into a single image format using ImageMagick. You will learn the exact command-line syntax needed for flattening, the difference between collapsing individual layers and extracting Photoshop's embedded composite image, and how to properly preserve transparency during conversion.

The Standard Flatten Command

To merge all individual layers of a PSD file into a single flattened image, use the -flatten operator (or -layers flatten in ImageMagick 7).

ImageMagick 7 (recommended):

magick input.psd -flatten output.png

ImageMagick 6:

convert input.psd -flatten output.png

This command reads all the layers inside the PSD, composites them from bottom to top according to their layer offsets and blending modes, and exports the final result to your designated format (e.g., .png, .jpg, .webp).

Extracting the Pre-Rendered Composite ([0])

Photoshop files typically store a pre-rendered, flattened composite image as the very first layer (index 0). If you want the exact view saved by Photoshop without forcing ImageMagick to re-calculate layer blend modes, select layer index [0]:

magick input.psd[0] output.png

Using [0] is significantly faster for large PSD files with numerous layers, as it skips processing each layer individually.

Preserving Transparency

By default, flattening onto certain formats may fill transparent areas with a default background color (usually white). To maintain a transparent background when exporting to PNG or WebP, specify -background none:

magick input.psd -background none -flatten output.png

Handling Hidden Layers

If your PSD contains hidden layers, ImageMagick might include them depending on how the PSD was saved. If hidden layers are interfering with the -flatten command, using the composite index [0] is the most reliable method, as Photoshop's built-in composite only renders currently visible layers at the time of saving.

Batch Flattening Multiple PSD Files

To flatten an entire directory of PSD files into PNG format, use the mogrify command:

magick mogrify -format png -flatten *.psd
