Flatten PSD Layers with ImageMagick

This article provides the exact command-line syntax required to flatten visible Adobe Photoshop (PSD) layers into a single image using ImageMagick. You will learn the standard commands for modern ImageMagick installations, how to preserve transparency during the flattening process, and how to extract the pre-rendered composite layer for faster execution.

The Standard Flatten Command

To merge all layers of a PSD file into a single flat image (such as PNG or JPG), use the -flatten operator.

For ImageMagick v7:

magick input.psd -flatten output.png

For ImageMagick v6:

convert input.psd -flatten output.png

Preserving Transparency

By default, flattening may apply a white canvas background if not explicitly configured. To preserve transparency in layers that contain alpha channels, define the background as transparent before applying the flatten operation:

magick input.psd -background none -flatten output.png

Alternative: Using the Layers Merge Operator

You can also use the -layers merge operator, which computes the overall canvas dimensions and combines all visible layers accordingly:

magick input.psd -background none -layers merge output.png

Fastest Method: Extracting the Cached Composite Layer

When Adobe Photoshop saves a PSD file with "Maximize Compatibility" enabled, it stores a pre-rendered, flattened preview as frame index 0. Instead of processing and merging every individual layer, you can extract this layer directly to save processing time:

magick input.psd[0] output.png

Note: If the PSD was saved without maximum compatibility or contains hidden layers that were altered outside Photoshop, use the -flatten command instead of [0] to ensure an accurate render of the layer stack.
