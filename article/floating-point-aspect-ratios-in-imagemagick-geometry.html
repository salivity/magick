Floating-Point Aspect Ratios in ImageMagick Geometry

This article provides a quick overview of how to define and apply floating-point aspect ratios in ImageMagick using geometry strings, dimensional flags, and command-line options. While ImageMagick traditionally processes pixel dimensions as integers, modern versions support decimal values and dynamic expressions to enforce exact proportional scaling, cropping, and canvas sizing. Below, you will learn the precise syntax and flags required to achieve floating-point aspect ratios across your image processing workflows.

Understanding ImageMagick Geometry Syntax

In ImageMagick, geometry specifications follow the basic format [width][xheight][+x+y][flags]. By default, omitting either the width or height causes ImageMagick to preserve the original image's aspect ratio. However, when forcing a specific non-integer ratio, standard integers are often insufficient.

ImageMagick 7 and modern releases of ImageMagick 6 allow floating-point values directly within geometry specifications, which the renderer rounds to nearest whole pixels during final rasterization.

Using Direct Floating-Point Dimensions with the Force Flag (!)

To force an image into an exact floating-point aspect ratio, you can provide the ratio directly as a base dimension combined with the exclamation mark (!) flag. The ! flag instructs ImageMagick to ignore the input image's native proportions.

For example, to enforce a modern widescreen 16:9 ratio (which equates to approximately 1.7778:1), you can run:

magick input.jpg -resize "177.78x100!" output.jpg

Alternatively, you can scale to an exact pixel bounding box while enforcing the float ratio:

magick input.jpg -resize "1920x1079.98!" output.jpg

Specifying Aspect Ratios with the -aspect Flag

ImageMagick includes a dedicated -aspect setting that accepts both integer ratios and floating-point representations. This flag alters the pixel aspect ratio or canvas metadata, which can be applied during operations or when outputting to formats that store aspect metadata.

Pass the decimal value directly to the -aspect flag:

magick input.jpg -aspect 1.7778 output.png

To adjust an image visually according to this aspect ratio, follow -aspect with a resize or resample operation that relies on image metadata.

Using Percentage Flags (%) for Proportional Adjustments

The percent flag (%) allows you to resize widths and heights independently using floating-point scaling factors. This is useful for reshaping an image to a custom proportion without computing explicit pixel widths.

magick input.jpg -resize "100x56.25%!" output.jpg

In this command:

  • 100% retains the original width.
  • 56.25% sets the height to 9/16th of the original, converting a 1:1 input to a 16:9 ratio.
  • The ! flag forces independent horizontal and vertical scaling.

Dynamic Aspect Ratios with FX Expressions (ImageMagick 7)

ImageMagick 7 introduced embedded mathematical calculations inside geometry arguments using the %[fx:...] syntax. This is the most accurate method for applying floating-point aspect ratios, as it computes dimensions dynamically based on input properties.

To crop an image to a floating-point aspect ratio of 2.39:1 (anamorphic cinema standard) while anchoring it to the center:

magick input.jpg -gravity center -crop "%[fx:w]x%[fx:w/2.39]+0+0" +repage output.jpg

To fit an image within a floating-point bounding area using the fill flag (^):

magick input.jpg -resize "%[fx:w]x%[fx:w/1.3333]^" output.jpg

Summary of Geometry Flags for Aspect Adjustments

  • ! (Force): Overrides native aspect ratio and forces the specified floating-point dimensions.
  • ^ (Fill/Minimum): Scales the image to completely fill the floating-point dimensions while preserving native proportions.
  • % (Percentage): Interprets floating-point numbers as percentage multipliers.
  • +repage: Removes virtual canvas offsets after cropping to a new aspect ratio.
