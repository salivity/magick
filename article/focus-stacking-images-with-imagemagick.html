Focus Stacking Images with ImageMagick

Focus stacking is a digital image processing technique that combines multiple images taken at different focus distances to create a single composite image with an extended depth of field. ImageMagick enables you to perform this technique entirely from the command line by aligning source images, generating edge-detection masks to identify the sharpest regions of each frame, and blending them together into a fully sharp result.

Prerequisites: Image Alignment

Before blending focus slices, the images must be perfectly aligned. If your camera shifted slightly between shots, use align_image_stack (part of the Hugin toolset) to prepare the files:

align_image_stack -m -a aligned_ input_*.tif

The ImageMagick Focus Stacking Command

ImageMagick achieves focus stacking by evaluating the high-frequency detail (edges) in each image and compositing the sharpest areas together.

For ImageMagick v7, the complete command to stack aligned images is:

magick aligned_*.tif \
    \( -clone 0--1 -colorspace Gray -morphology EdgeLaplacian Diamond \) \
    -evaluate-sequence Max \
    -compose Over -composite \
    output_stacked.tif

For ImageMagick v6, replace magick with convert:

convert aligned_*.tif \
    \( -clone 0--1 -colorspace Gray -morphology EdgeLaplacian Diamond \) \
    -evaluate-sequence Max \
    -compose Over -composite \
    output_stacked.tif

How the Command Works

  • aligned_*.tif: Loads all pre-aligned source images into the image sequence.
  • \( -clone 0--1 -colorspace Gray -morphology EdgeLaplacian Diamond \): Duplicates all loaded images into memory, converts them to grayscale, and applies a Laplacian edge-detection filter to highlight areas of high contrast and sharp focus.
  • -evaluate-sequence Max: Compares the edge-detected masks across all layers to locate which image contains the sharpest pixel at every coordinate.
  • -compose Over -composite: Blends the highest-contrast pixels from the source images into the final output.
  • output_stacked.tif: Writes the resulting all-in-focus image to disk.

Alternative: Integrating with Enfuse

While ImageMagick can generate masks natively, the standard production pipeline pairs ImageMagick with enfuse for advanced multi-resolution spline blending, which reduces halo artifacts:

enfuse --exposure-weight=0 --saturation-weight=0 --contrast-weight=1 --hard-mask aligned_*.tif -o output_stacked.tif

You can then use ImageMagick for post-processing and final adjustments:

magick output_stacked.tif -auto-level -unsharp 0x1 output_final.jpg
