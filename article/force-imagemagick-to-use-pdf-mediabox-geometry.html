Force ImageMagick to Use PDF MediaBox Geometry

When converting PDF documents to raster images, ImageMagick determines page dimensions based on PDF boundary boxes such as the MediaBox, CropBox, or TrimBox. By default, ImageMagick and its underlying PostScript/PDF delegate (Ghostscript) may evaluate the CropBox to trim whitespace or respect user-defined crops. To force ImageMagick to ignore cropping boundaries and render the document using its complete, unclipped MediaBox dimensions, you must pass the -define pdf:use-cropbox=false flag.

The MediaBox Define Flag

The specific flag required is:

-define pdf:use-cropbox=false

To ensure that neither the CropBox nor the TrimBox overrides the MediaBox, you can also explicitly disable the TrimBox:

-define pdf:use-cropbox=false -define pdf:use-trimbox=false

Command Usage Examples

The define flag must be placed before the input PDF file on the command line so that ImageMagick passes the appropriate parameters to Ghostscript during the decoding stage.

ImageMagick v7:

magick -define pdf:use-cropbox=false input.pdf output.png

ImageMagick v6:

convert -define pdf:use-cropbox=false input.pdf output.png

If you need to guarantee high-resolution rendering while keeping the MediaBox bounds, include the density setting prior to reading the input:

magick -density 300 -define pdf:use-cropbox=false -define pdf:use-trimbox=false input.pdf output.png

How It Works

PDF documents define multiple nested boundary rectangles:

  • MediaBox: Defines the full physical medium size of the page (e.g., standard Letter or A4 dimensions).
  • CropBox: Defines the region to which page contents are clipped when displayed or printed.
  • TrimBox: Defines the intended dimensions of the finished page after trimming.

ImageMagick relies on Ghostscript to interpret PDF files. When Ghostscript processes a page, it applies -dUseCropBox if pdf:use-cropbox is set to true. Setting -define pdf:use-cropbox=false prevents the -dUseCropBox argument from being forwarded, forcing the interpreter to fall back to the root container dimensions defined by the MediaBox.
