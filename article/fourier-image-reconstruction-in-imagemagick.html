Fourier Image Reconstruction in ImageMagick

Reconstructing an image from its frequency domain components involves combining its magnitude and phase spectra back into spatial domain pixels. This article provides the exact command-line syntax to perform an Inverse Discrete Fourier Transform in ImageMagick using the -ift operator, outlines input requirements, and provides practical examples for both ImageMagick v7 and v6.

The Reconstruction Command

To reconstruct an image from its Fourier magnitude and phase components, use the -ift (Inverse Fourier Transform) operator. The command requires the magnitude image followed by the phase image as input arguments.

ImageMagick v7

magick magnitude.png phase.png -ift reconstructed.png

ImageMagick v6

convert magnitude.png phase.png -ift reconstructed.png

How It Works

  1. Input Order: ImageMagick expects the magnitude image as the first input ([0]) and the phase image as the second input ([1]).
  2. The -ift Operator: Merges the two frequency-domain images and calculates the inverse transform, outputting a single spatial-domain image.
  3. HDRI Requirement: Fourier transforms require floating-point data to preserve frequency information accurately. Ensure your ImageMagick build has HDRI (High Dynamic Range Imaging) enabled, which is the default in ImageMagick 7.

Full Forward and Inverse Transform Example

To test the entire process from an original image to its Fourier components and back:

# Step 1: Forward transform (creates input_0.png for magnitude, input_1.png for phase)
magick original.png -fft input_%d.png

# Step 2: Inverse transform (reconstructs the image)
magick input_0.png input_1.png -ift reconstructed.png
