Frei-Chen Edge Detection in ImageMagick

Frei-Chen edge detection is an isotropic, gradient-based image processing technique that evaluates spatial intensity changes using a specific set of 3x3 orthogonal convolution matrices. This article explains how to implement the Frei-Chen edge detection operator using ImageMagick from the command line, covering built-in kernel commands, custom convolution matrices, and magnitude composition.

Understanding the Frei-Chen Kernels

Unlike standard Sobel operators that use integer weights, Frei-Chen masks use weights scaled by \(\sqrt{2} \approx 1.4142\). This provides a more accurate approximation of the gradient magnitude regardless of edge orientation.

The primary orthogonal Frei-Chen masks are:

  • Horizontal Gradient (\(G_1\)): \[ \begin{bmatrix} 1 & \sqrt{2} & 1 \\ 0 & 0 & 0 \\ -1 & -\sqrt{2} & -1 \end{bmatrix} \]

  • Vertical Gradient (\(G_2\)): \[ \begin{bmatrix} 1 & 0 & -1 \\ \sqrt{2} & 0 & -\sqrt{2} \\ 1 & 0 & -1 \end{bmatrix} \]

Method 1: Using ImageMagick Built-In FreiChen Kernels

ImageMagick includes native support for Frei-Chen convolution kernels via the -morphology operator.

Omnidirectional Edge Detection

To quickly apply Frei-Chen edge detection across all directions and combine the maximum response, use:

magick input.jpg -colorspace Gray -define morphology:compose=Lighten -morphology Convolve FreiChen output.jpg
  • -colorspace Gray: Converts the input to grayscale for standard intensity evaluation.
  • -define morphology:compose=Lighten: Merges the multi-directional kernel responses using the maximum (Lighten) composition.
  • -morphology Convolve FreiChen: Convolves the image using the predefined directional Frei-Chen kernel set.

Method 2: Calculating Exact Gradient Magnitude (\(G = \sqrt{G_1^2 + G_2^2}\))

For precise mathematical edge detection, compute the horizontal and vertical components separately, square them, add them, and take the square root.

magick input.jpg -colorspace Gray \
  \( -clone 0 -morphology Convolve "FreiChen:0" \) \
  \( -clone 0 -morphology Convolve "FreiChen:90" \) \
  -delete 0 \
  -solarize 50% -level 0,50% \
  -compose Mathematics -set option:compose:args "1,0,0,0" -composite \
  output_magnitude.jpg

Alternatively, compute the Euclidean norm of horizontal and vertical passes directly:

magick input.jpg -colorspace Gray \
  \( -clone 0 -morphology Convolve "FreiChen:0" \) \
  \( -clone 0 -morphology Convolve "FreiChen:90" \) \
  -delete 0 \
  -compose Multiply -composite \
  output_magnitude.jpg

Method 3: Using Custom 3x3 Convolution Matrices

You can define explicit floating-point kernels using ImageMagick’s user-defined kernel format:

1. Horizontal Pass

magick input.jpg -colorspace Gray \
  -morphology Convolve "3x3: 1, 1.4142, 1, 0, 0, 0, -1, -1.4142, -1" \
  horizontal.jpg

2. Vertical Pass

magick input.jpg -colorspace Gray \
  -morphology Convolve "3x3: 1, 0, -1, 1.4142, 0, -1.4142, 1, 0, -1" \
  vertical.jpg

3. Combined Magnitude Pass

Run both orthogonal passes and blend them:

magick input.jpg -colorspace Gray \
  \( -clone 0 -morphology Convolve "3x3: 1, 1.4142, 1, 0, 0, 0, -1, -1.4142, -1" \) \
  \( -clone 0 -morphology Convolve "3x3: 1, 0, -1, 1.4142, 0, -1.4142, 1, 0, -1" \) \
  -delete 0 \
  -define morphology:compose=Lighten -composite \
  frei_chen_edges.jpg
