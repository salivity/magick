Frei-Chen Edge Detection with ImageMagick

This article provides a complete guide to implementing Frei-Chen edge detection in ImageMagick using custom user-defined convolution kernels. You will learn the mathematical foundation of the Frei-Chen masks, how to define them in ImageMagick syntax, and how to execute the commands to generate clean edge maps using both two-kernel gradient and four-kernel edge-subspace approaches.

Understanding the Frei-Chen Operator

The Frei-Chen edge detector uses a set of orthonormal basis templates to calculate gradient magnitude. Unlike standard Sobel filters that weight adjacent pixels by \(2\), Frei-Chen uses \(\sqrt{2} \approx 1.414214\), making the operator isotropic and minimizing directional bias.

The two primary gradient kernels are:

  • Horizontal (\(K_1\)): \[\begin{bmatrix} 1 & \sqrt{2} & 1 \\ 0 & 0 & 0 \\ -1 & -\sqrt{2} & -1 \end{bmatrix}\]

  • Vertical (\(K_2\)): \[\begin{bmatrix} 1 & 0 & -1 \\ \sqrt{2} & 0 & -\sqrt{2} \\ 1 & 0 & -1 \end{bmatrix}\]

2-Kernel Frei-Chen Edge Detection

To apply the standard 2-directional Frei-Chen operator, convert the image to grayscale, convolve the image separately with both kernels, and combine them using the Euclidean norm (root-sum-of-squares).

ImageMagick v7 Command:

magick input.jpg -colorspace Gray \
  \( -clone 0 -define morphology:compose=Euclidean \
     -morphology Convolve '3x3: 1,1.414214,1, 0,0,0, -1,-1.414214,-1' \
     -morphology Convolve '3x3: 1,0,-1, 1.414214,0,-1.414214, 1,0,-1' \) \
  -delete 0 frei_chen_edges.png

Explanation of Parameters:

  • -colorspace Gray: Ensures edge detection processes luminance values without color artifacts.
  • -morphology Convolve '3x3: ...': Applies the custom 3x3 convolution matrix representing each Frei-Chen mask.
  • -define morphology:compose=Euclidean: Automatically computes \(\sqrt{K_1^2 + K_2^2}\) across the convolved kernel outputs.
  • -delete 0: Removes the original grayscale clone, leaving only the combined edge map.

4-Kernel Edge Subspace Detection

Frei-Chen also defines diagonal edge kernels to capture structural lines along with horizontal and vertical gradients:

  • Diagonal 1 (\(K_3\)): \[\begin{bmatrix} 0 & -1 & \sqrt{2} \\ 1 & 0 & -1 \\ -\sqrt{2} & 1 & 0 \end{bmatrix}\]

  • Diagonal 2 (\(K_4\)): \[\begin{bmatrix} \sqrt{2} & -1 & 0 \\ -1 & 0 & 1 \\ 0 & 1 & -\sqrt{2} \end{bmatrix}\]

To include all four edge-subspace bases for enhanced edge accuracy:

magick input.jpg -colorspace Gray \
  \( -clone 0 -define morphology:compose=Euclidean \
     -morphology Convolve '3x3: 1,1.414214,1, 0,0,0, -1,-1.414214,-1' \
     -morphology Convolve '3x3: 1,0,-1, 1.414214,0,-1.414214, 1,0,-1' \
     -morphology Convolve '3x3: 0,-1,1.414214, 1,0,-1, -1.414214,1,0' \
     -morphology Convolve '3x3: 1.414214,-1,0, -1,0,1, 0,1,-1.414214' \) \
  -delete 0 frei_chen_4subspace.png

Post-Processing and Normalization

To enhance visibility and suppress subtle noise from the resulting edge output, apply auto-leveling and optional thresholding:

magick frei_chen_edges.png -auto-level -threshold 20% frei_chen_clean.png
  • -auto-level: Stretches the dynamic range so edge gradients span the full black-to-white spectrum.
  • -threshold 20%: Filters out low-amplitude texture noise, preserving only significant structural boundaries.
