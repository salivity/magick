Gaussian Blur in C++ Using ImageMagick Magick++

This guide demonstrates how to apply a Gaussian blur effect to an image using ImageMagick's C++ library, Magick++. It covers the essential setup, explains the gaussianBlur method parameters, provides a complete C++ code example, and details how to compile and run the program.

Understanding the gaussianBlur Method

In Magick++, the Magick::Image class provides the gaussianBlur() method to convolve an image with a Gaussian operator. The method signature is:

void gaussianBlur(const double radius_, const double sigma_);
  • radius: The radius of the Gaussian operator in pixels, excluding the center pixel. Passing 0.0 tells ImageMagick to automatically calculate a suitable radius based on the sigma value.
  • sigma: The standard deviation of the Gaussian operator. This is the primary parameter controlling the intensity or spread of the blur. A larger sigma produces a stronger blur effect.

Complete C++ Code Example

To blur an image, initialize the Magick++ library, construct an Image object by loading a file, invoke gaussianBlur(), and write the modified image to disk.

#include <Magick++.h>
#include <iostream>

int main(int argc, char** argv) {
    // Initialize Magick++ environment
    Magick::InitializeMagick(*argv);

    try {
        // Load the image from disk
        Magick::Image image("input.jpg");

        // Set Gaussian blur parameters
        double radius = 0.0; // Auto-compute based on sigma
        double sigma = 4.0;  // Blur strength

        // Apply the Gaussian blur
        image.gaussianBlur(radius, sigma);

        // Save the blurred result
        image.write("output_blurred.jpg");

        std::cout << "Image blurred successfully." << std::endl;
    } 
    catch (Magick::Exception &error) {
        std::cerr << "Magick++ Error: " << error.what() << std::endl;
        return 1;
    }

    return 0;
}

Compiling the Code

To compile the C++ code with GCC on a Linux or macOS system where ImageMagick is installed, use the Magick++-config tool to supply the required compiler and linker flags:

g++ -O2 blur.cpp $(Magick++-config --cppflags --cxxflags) $(Magick++-config --ldflags --libs) -o blur

Run the compiled executable with:

./blur
