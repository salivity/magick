Generate Color Calibration Charts in ImageMagick

Generating calibration target color charts with ImageMagick allows photographers, print technicians, and imaging engineers to verify color accuracy, create 3D Look-Up Tables (LUTs), and test output profiles. This guide outlines the exact ImageMagick syntax needed to generate standard SMPTE color bars, identity Hald CLUT calibration charts, stepped grayscale wedges, and custom multi-patch color matrices directly from the command line.

Built-In SMPTE Color Bars

ImageMagick provides a built-in generator for standard SMPTE (Society of Motion Picture and Television Engineers) color calibration charts. You define the canvas size using the -size parameter followed by the smpte: format operator.

magick -size 1920x1080 smpte: smpte_calibration.png

For ImageMagick v6, replace magick with convert:

convert -size 1920x1080 smpte: smpte_calibration.png

Hald CLUT Calibration Targets

A Hald CLUT (Color Look-Up Table) is a standard matrix image representing an entire 3D color space, widely used for color grading calibration and profile verification. ImageMagick uses the hald: coder where the number defines the matrix level. A level of \(N\) produces an image of dimensions \(N^2 \times N^2\) containing \(N^3 \times N^3\) distinct color samples.

To generate a standard 8-level Hald CLUT target (512x512 pixels):

magick hald:8 hald8_identity.png

To generate a high-precision 16-level Hald CLUT target (4096x4096 pixels):

magick hald:16 hald16_identity.png

Grayscale Step Wedge Targets

Step wedges are used to calibrate dynamic range, gamma response, and contrast linearity. You can generate a discrete step wedge by defining individual color patches and combining them horizontally using +append.

magick -size 100x400 \
  xc:"rgb(0,0,0)" \
  xc:"rgb(51,51,51)" \
  xc:"rgb(102,102,102)" \
  xc:"rgb(153,153,153)" \
  xc:"rgb(204,204,204)" \
  xc:"rgb(255,255,255)" \
  +append grayscale_steps.png

To create a smooth 256-level linear gradient ramp:

magick -size 512x100 gradient:black-white linear_ramp.png

Custom Multi-Patch Color Charts

To build a custom color matrix (such as an IT8 or Macbeth-style target), use individual color definitions piped directly into the montage tool. This arranges the swatches into a specified grid layout with borders.

magick -size 120x120 \
  xc:"#735244" xc:"#c29682" xc:"#627a9d" xc:"#576c43" \
  xc:"#8580b1" xc:"#67bdaa" xc:"#d67e2c" xc:"#505ba6" \
  xc:"#c15a63" xc:"#5e3c6c" xc:"#9dbc40" xc:"#e0a32e" \
  miff:- | magick montage - -tile 4x3 -geometry +10+10 -background "#1a1a1a" color_chart.png
  • -tile 4x3: Sets the layout to 4 columns and 3 rows.
  • -geometry +10+10: Adds a 10-pixel gap between swatches.
  • -background "#1a1a1a": Sets the backing chart border color.
