Generate DDS Mipmaps Automatically in ImageMagick

This guide explains how to automatically generate mipmaps when exporting DirectDraw Surface (DDS) textures using ImageMagick. By applying specialized command-line definitions, you can produce complete mipmap chains during format conversion to optimize texture rendering and level-of-detail (LOD) performance in game engines and 3D graphics applications.

The Basic Command

To generate a complete set of mipmaps down to a 1x1 pixel texture automatically, use the -define dds:mipmaps=all flag.

For ImageMagick v7:

magick input.png -define dds:mipmaps=all output.dds

For ImageMagick v6:

convert input.png -define dds:mipmaps=all output.dds

Controlling Compression Formats

DDS files typically use block compression such as DXT1 (BC1) or DXT5 (BC3). You can pair mipmap generation with specific compression settings using -define dds:compression:

  • DXT1 (for opaque images or simple 1-bit alpha):

    magick input.png -define dds:compression=dxt1 -define dds:mipmaps=all output.dds

  • DXT5 (for textures with complex alpha channels):

    magick input.png -define dds:compression=dxt5 -define dds:mipmaps=all output.dds

  • Uncompressed (RGBA):

    magick input.png -define dds:compression=none -define dds:mipmaps=all output.dds

Mipmap Define Values

The dds:mipmaps parameter accepts different arguments depending on your project requirements:

  • all: Automatically generates a full mipmap chain down to a 1x1 dimension.
  • [number]: Limits the mipmap chain to an explicit number of levels (for example, -define dds:mipmaps=4).
  • none: Disables mipmap generation entirely (default behavior).
  • from-image: Uses separate images/frames in a multi-layer file as explicit mipmap levels rather than downscaling automatically.

Adjusting Downsampling Quality

ImageMagick utilizes its internal resize filter when generating automatic mipmap levels. You can modify the filtering algorithm using the -filter option before writing the output file:

magick input.png -filter Lanczos -define dds:mipmaps=all -define dds:compression=dxt5 output.dds

Common filters include Box (nearest-neighbor style, sharpest transitions), Triangle (bilinear, smooth), and Lanczos (high-quality sinc interpolation).

Batch Processing Textures

To batch-convert an entire directory of PNG textures to DDS files with mipmaps, use the mogrify tool:

magick mogrify -format dds -define dds:compression=dxt5 -define dds:mipmaps=all *.png
