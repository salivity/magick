Generate Empty Hald CLUT in ImageMagick

This guide provides the exact command-line syntax for creating an empty, neutral (identity) Hald CLUT image using ImageMagick. You will learn the standard command structure for both ImageMagick v7 and v6, understand how the Hald level parameter defines image resolution and color precision, and see how to generate a baseline image ready for color grading workflows.

Basic Syntax

In ImageMagick, an identity Hald CLUT is created using the built-in hald: coder. The number directly following the colon defines the color matrix level.

ImageMagick v7 (Current)

magick hald:8 identity_hald8.png

ImageMagick v6 (Legacy)

convert hald:8 identity_hald8.png

Understanding Hald Levels

The Hald level determines the color depth and the resulting dimensions of the output image. A Hald CLUT is always a square image with dimensions calculated by \(L^3 \times L^3\), where \(L\) is the level.

  • Level 8 (hald:8): Generates a 512×512 pixel image (\(8^3 = 512\)). This is the standard size for most color grading and photo editing applications, providing 16.7 million discrete color points (24-bit color).
  • Level 16 (hald:16): Generates a 4096×4096 pixel image (\(16^3 = 4096\)). This provides higher precision for 16-bit color depth pipelines, though it produces significantly larger files.
  • Level 4 (hald:4): Generates a 64×64 pixel image (\(4^3 = 64\)). Suitable for testing or low-complexity operations.

Complete Workflow Example

  1. Generate the neutral Hald CLUT:

    magick hald:8 original_hald.png

  2. Apply color adjustments: Open original_hald.png in any image editor (such as Photoshop, GIMP, or Darktable), apply your color corrections, and export the file as modified_hald.png without changing the image dimensions.

  3. Apply the modified CLUT to a target image:

    magick input.jpg modified_hald.png -hald-clut output.jpg
