Generate Hex Color Swatches in ImageMagick

Creating solid color swatch images using specific hex values is a straightforward process in ImageMagick. This guide demonstrates how to generate custom-sized solid color images using the command line across different versions of ImageMagick, ensuring proper shell escaping and support for standard and alpha-channel hex codes.

The Basic Command Syntax

ImageMagick utilizes the canvas: or xc: (X11 Color) prefix to generate blank or solid-colored canvases. To create a solid color swatch from a hexadecimal code, define the dimensions with the -size option and specify the hex code as the canvas color.

For ImageMagick version 7 and newer:

magick -size 200x200 xc:"#3498db" swatch_blue.png

For ImageMagick version 6 (legacy):

convert -size 200x200 xc:"#3498db" swatch_blue.png

Key Parameters Explained

  • -size <width>x<height>: Defines the dimensions of the output image in pixels (e.g., 300x300 or 1920x1080).
  • xc:"#HEXVALUE": Specifies the color canvas. Always wrap the hex value in quotes because the # symbol acts as a comment character in most command-line shells (like Bash and Zsh).
  • output_filename.ext: The desired file name and format (e.g., .png, .jpg, .webp).

Using Hex Codes with Transparency (Alpha Channel)

ImageMagick supports 8-digit hexadecimal values where the last two digits represent the alpha (transparency) channel (#RRGGBBAA).

To generate a semi-transparent swatch, use an image format that supports alpha channels, such as PNG:

magick -size 150x150 xc:"#FF573380" semi_transparent_orange.png

In this example, 80 sets the opacity to roughly 50%.

Short Hex Notation

Three-digit hex codes (#RGB) and four-digit hex codes with alpha (#RGBA) are also fully supported:

magick -size 100x100 xc:"#F00" pure_red.png

This creates a 100x100 pixel solid red image equivalent to #FF0000.
