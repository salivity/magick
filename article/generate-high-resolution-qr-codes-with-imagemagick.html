Generate High-Resolution QR Codes with ImageMagick

This guide demonstrates how to generate crisp, high-resolution QR codes directly from the command line using ImageMagick's delegate system. You will learn the exact command syntax required to invoke external encoding delegates such as qrencode, scale the output properly without introducing blurriness, and export print-ready, high-density image files.

The Command

To generate a clean, high-resolution QR code, use the following ImageMagick command:

magick "qrencode:https://example.com" -filter point -resize 2048x2048 qr_high_res.png

If you are using an older version (ImageMagick 6), replace magick with convert:

convert "qrencode:https://example.com" -filter point -resize 2048x2048 qr_high_res.png

How the Command Works

  • qrencode:...: Invokes the qrencode delegate configured within ImageMagick's delegates.xml file. ImageMagick passes the text or URL directly to the delegate to generate the initial base matrix.
  • -filter point: Forces ImageMagick to use nearest-neighbor interpolation during the resize process. This eliminates anti-aliasing, ensuring the edges of the QR modules remain sharp and fully readable by scanners.
  • -resize 2048x2048 (or -sample 2048x2048): Upscales the low-resolution delegate output to a high-resolution canvas while maintaining a 1:1 aspect ratio.
  • qr_high_res.png: Specifies the output format and file path. You can output to PNG, TIFF, or any other supported raster format.

Generating High-DPI Print Outputs

For print media requiring specific metadata density (such as 300 DPI or 600 DPI), define the density parameter before writing the output:

magick "qrencode:https://example.com" -filter point -resize 3000x3000 -density 300 -units PixelsPerInch qr_print.png

Delegate Requirements

To ensure this command executes successfully, your system must have libqrencode or the qrencode command-line utility installed, and ImageMagick must be compiled with delegate support enabled. You can verify available delegates by running magick -version or inspecting your system's delegates.xml configuration.
