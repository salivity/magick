Generate Image Difference Heatmap with ImageMagick

This guide explains how to visually identify pixel differences between two images by generating a difference heatmap using ImageMagick's compare utility. You will learn the basic comparison commands, how to customize highlight and lowlight colors, and how to create a smooth, graded heatmap using color lookup tables.

Basic Difference Generation

The compare command in ImageMagick compares two images of the same dimensions and outputs an image highlighting the discrepancies.

To generate a basic difference map:

magick compare image1.png image2.png difference.png

(Note: On ImageMagick v6, use compare directly without the magick prefix.)

By default, ImageMagick overlays the differences in red over a pale, semi-transparent version of the original image.

Customizing Highlight and Lowlight Colors

To produce a starker, high-contrast visualization, you can define specific colors for modified pixels (-highlight-color) and unchanged pixels (-lowlight-color):

magick compare -highlight-color red -lowlight-color black image1.png image2.png high_contrast_diff.png

In this output, all changed pixels appear strictly in red, while unchanged regions remain black.

Generating a Graded Heatmap (Intensity-Based)

To display a true heatmap where the color corresponds to the magnitude of the difference (e.g., subtle changes appear cool, while large shifts appear hot), use a mathematical metric combined with a Color Look-Up Table (CLUT).

Step 1: Generate a Grayscale Difference Map

Use the Root Mean Squared Error (RMSE) metric to output differences as raw pixel intensity variations:

magick compare -metric RMSE image1.png image2.png -compose src diff_gray.png

This generates a grayscale image where pure black indicates no change, and brighter pixels represent larger deviations.

Step 2: Apply a Thermal Color Gradient

Map the grayscale values to a color gradient using -clut:

magick diff_gray.png ( -size 1x256 gradient:blue-cyan-green-yellow-red ) -clut heatmap.png

All-in-One Command

You can combine both steps into a single execution without saving an intermediate grayscale file:

magick compare -metric RMSE image1.png image2.png -compose src miff:- | magick - ( -size 1x256 gradient:blue-cyan-green-yellow-red ) -clut final_heatmap.png

Useful Metric Options

You can adjust how differences are calculated using the -metric flag:

  • AE (Absolute Error): Simple count of differing pixels.
  • RMSE (Root Mean Squared Error): Best for continuous gradients and visual heatmaps.
  • PAE (Peak Absolute Error): Highlights the single largest pixel difference.
  • MAE (Mean Absolute Error): Average difference across all color channels.
