Generate Neutral Hald CLUT in ImageMagick

This guide explains how to generate a neutral Hald Color Lookup Table (Hald CLUT) image using ImageMagick. A neutral Hald CLUT acts as an identity color map that represents an unmodified color space, serving as the starting baseline for creating, editing, and applying custom color grading profiles.

Command Syntax

In ImageMagick, neutral Hald CLUT images are generated using the built-in hald: coder. The basic syntax specifies the coder followed by the desired level:

For ImageMagick 7:

magick hald:<level> output.png

For ImageMagick 6:

convert hald:<level> output.png

Understanding the Level Parameter

The <level> integer defines the bit depth and sampling density of the color grid. The total width and height of the resulting square image will be level^3 pixels (or level^2 cells along each axis).

  • Level 8 (Standard): magick hald:8 neutral_hald.png
    This creates a 512x512 pixel image (\(8^3 = 512\)). Level 8 is the industry standard for 8-bit per channel color grading, providing 16,777,216 distinct color points.
  • Level 16 (High Precision): magick hald:16 neutral_hald16.png
    This creates a 4096x4096 pixel image (\(16^3 = 4096\)) used for high-bit-depth workflows, such as 16-bit TIFF processing.

Workflow Example

  1. Generate the base identity image:

    magick hald:8 identity.png

  2. Apply adjustments in your preferred software:
    Open identity.png in an image editor, apply non-spatial color adjustments (curves, saturation, LUTs), and save it as modified.png without resizing or cropping.

  3. Apply the modified CLUT to target images:

    magick input.jpg modified.png -hald-clut output.jpg
