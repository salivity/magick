Generate Plasma Fractal Images in ImageMagick

ImageMagick includes a built-in generator called plasma: that allows you to create randomized, multi-colored fractal cloud patterns without needing external image assets. This guide explains how to use the command-line interface to generate standard plasma fractals, control color schemes, adjust fractal roughness, and export the resulting images in various formats.

Basic Plasma Generation

To generate a basic plasma fractal, specify the canvas dimensions using the -size operator followed by the plasma: protocol and the output filename.

magick -size 800x600 plasma: output.png

By default, this creates a fully randomized multi-colored fractal using the standard RGB color spectrum.

Controlling Colors with Gradients

You can restrict the plasma generator to specific color palettes by defining two boundary colors separated by a hyphen after the plasma: keyword.

magick -size 800x600 plasma:blue-deepskyblue cool_plasma.png

To create a warm fire-like texture:

magick -size 800x600 plasma:red-yellow fire_plasma.png

If you specify one named color and use none or transparent as the second color, the plasma will render with transparency:

magick -size 800x600 plasma:navy-none transparent_plasma.png

Adjusting Fractal Complexity and Roughness

The plasma: generator allows you to control the depth of recursion and the roughness of the fractal by appending parameters. The full syntax is:

plasma:color1-color2 or plasma:fractal

To control the smoothness or roughness, use the numeric sub-parameters appended to the plasma argument:

  • plasma:fractal — Generates a standard complete fractal recursion.
  • plasma:fractal[roughness] — Adjusts the roughness value (where values typically range between 0 and 6).

Example with reduced roughness for smoother clouds:

magick -size 800x600 plasma:fractal[2] smooth_fractal.png

Example with higher roughness for high-frequency noise:

magick -size 800x600 plasma:fractal[6] rough_fractal.png

Generating Monochromatic and Grayscale Fractals

To produce grayscale heightmaps or cloud displacement maps, convert the generated plasma to a single channel using the -colorspace operator:

magick -size 800x600 plasma: -colorspace Gray heightmap.png

Alternatively, specify a black-to-white color transition directly:

magick -size 800x600 plasma:black-white grayscale_plasma.png

Reproducible Plasma with Random Seeds

Because the plasma algorithm relies on random mid-point displacement, every execution generates a unique pattern. To generate a reproducible fractal, set the random seed using -seed before calling the plasma generator:

magick -seed 12345 -size 800x600 plasma:red-blue fixed_plasma.png
