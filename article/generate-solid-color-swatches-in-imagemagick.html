Generate Solid Color Swatches in ImageMagick

ImageMagick provides a simple and efficient way to create solid color background swatches using built-in canvas primitives. By combining the -size setting with the canvas: or xc: pseudo-image formats, you can generate images of exact dimensions, custom color definitions, and standard file formats directly from the command line. This guide covers the basic syntax, supported color formats, and practical examples for generating swatches.

Basic Syntax

To create a solid color swatch, define the dimensions with the -size option, specify the color using canvas:, and provide an output filename.

magick -size 300x300 canvas:skyblue swatch.png

Note: In ImageMagick version 6 and earlier, use the convert command instead of magick.

Canvas Primitives: canvas: vs xc:

ImageMagick provides two identical pseudo-image delegates for creating single-color canvases:

  • canvas: – The modern, standard descriptor for generating solid-color images.
  • xc: – An abbreviation for "X Color," historically used in ImageMagick and fully interchangeable with canvas:.
magick -size 200x200 xc:coral swatch_xc.png

Specifying Colors

ImageMagick supports various color input formats:

1. Named Colors

You can use standard SVG/X11 color names:

magick -size 400x200 canvas:forestgreen named_swatch.png

2. Hexadecimal Codes

Hex values must be quoted or escaped in the terminal to prevent shell interpretation of the # symbol:

magick -size 250x250 canvas:"#4A90E2" hex_swatch.png

3. RGB and RGBA Values

For standard RGB or semi-transparent swatches, use rgb() or rgba() notation inside quotes:

# Solid RGB
magick -size 300x300 canvas:"rgb(255, 87, 34)" rgb_swatch.png

# Semi-transparent RGBA (PNG format required for transparency)
magick -size 300x300 canvas:"rgba(33, 150, 243, 0.5)" transparent_swatch.png

4. HSL Values

Hue, Saturation, and Lightness can also be passed directly:

magick -size 200x200 canvas:"hsl(120, 100%, 50%)" hsl_swatch.png

Batch Generating Multiple Swatches

To generate multiple color variations quickly, you can run sequential commands or combine them in a loop:

for color in red green blue "#333333"; do
  magick -size 150x150 canvas:"$color" "swatch_${color/#\#/}.png"
done
