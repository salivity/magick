Get Average Color Hex Code Using ImageMagick

Extracting the average color of an image is a common requirement for generating placeholders, dynamic UI backgrounds, or color palette analysis. ImageMagick makes this process straightforward by allowing you to downscale an entire image to a single pixel representing the average color value and outputting that pixel directly as a hexadecimal string in your terminal.

The Command

To get the 6-character hexadecimal color code for any image, run the following command in your terminal:

ImageMagick v7:

magick input.jpg -scale 1x1! -alpha off -format "#%[hex:u.p{0,0}]\n" info:

ImageMagick v6:

convert input.jpg -scale 1x1! -alpha off -format "#%[hex:u.p{0,0}]\n" info:

How It Works

  • input.jpg: Specifies your source image file (supports PNG, JPG, WEBP, GIF, and other formats).
  • -scale 1x1!: Resizes the image to exactly 1 pixel by 1 pixel. Using -scale performs a simple box average of all the pixels in the image, effectively calculating the mean color. The exclamation mark (!) forces the resize regardless of the original aspect ratio.
  • -alpha off: Disables the alpha channel to guarantee a standard 6-character hex code (#RRGGBB). If you omit this on an image containing transparency, ImageMagick may return an 8-character hex code (#RRGGBBAA).
  • -format "#%[hex:u.p{0,0}]\n": Formats the output. The string prefix # prepends the hash symbol, while %[hex:u.p{0,0}] queries the hexadecimal value of the pixel at coordinate (0,0).
  • info:: Tells ImageMagick to print the formatted metadata directly to standard output (stdout) rather than writing the 1x1 pixel to a new file on disk.

Storing in a Variable

If you are using a Bash script, you can capture the resulting hex code directly into a shell variable:

AVG_COLOR=$(magick input.jpg -scale 1x1! -alpha off -format "#%[hex:u.p{0,0}]" info:)
echo "The average color is $AVG_COLOR"
