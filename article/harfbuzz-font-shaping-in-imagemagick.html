HarfBuzz Font Shaping in ImageMagick

HarfBuzz font shaping enables ImageMagick to properly render complex text layouts, ligatures, bidirectional scripts, and OpenType features. This guide explains how to verify HarfBuzz support in your ImageMagick installation, configure text direction and language options, and render shaped text using both native delegates and Pango.

Prerequisites and Verification

ImageMagick does not interact with HarfBuzz directly; instead, it utilizes HarfBuzz through the libraqm library (which wraps FreeType, HarfBuzz, and FriBidi) or through the Pango delegate.

To check if your ImageMagick build supports HarfBuzz font shaping via Raqm, run:

magick -version

Look for raqm in the Delegates (built-in) line. If raqm is present, HarfBuzz is actively linked and available for shaping text. If it is missing, ImageMagick must be recompiled from source with the --with-raqm flag after installing libraqm-dev (or raqm-devel) on your operating system.

Rendering Shaped Text Using Raqm

When the raqm delegate is enabled, ImageMagick automatically applies HarfBuzz shaping to text rendered with commands such as -annotate or the caption: and label: operators.

Setting Text Direction

For bidirectional or right-to-left (RTL) scripts such as Arabic or Hebrew, specify the reading direction using the -direction setting:

magick -size 800x200 xc:white \
  -font "Amiri-Regular.ttf" \
  -pointsize 48 \
  -fill black \
  -direction right-to-left \
  -gravity center \
  -annotate +0+0 "مرحبا بالعالم" \
  output_arabic.png

Valid -direction values include left-to-right and right-to-left.

Advanced Font Shaping via Pango

For fine-grained control over OpenType font features handled by HarfBuzz (such as discretionary ligatures, small caps, or stylistic alternates), the pango: delegate offers the most robust interface. Pango natively uses HarfBuzz under the hood for all text shaping.

Verify that pango appears in your magick -version delegates list, then use Pango markup to control HarfBuzz features:

magick -background white \
  pango:"<span font_family='Calibri' font_features='dlig 1, smcp 1' font_size='36pt'>Activating Ligatures & Small Caps</span>" \
  output_pango.png

In this command:

  • font_features: Accepts standard four-letter OpenType tags parsed by HarfBuzz (e.g., dlig for discretionary ligatures, hlig for historical ligatures, kern for kerning).
  • The value 1 enables the feature, while 0 disables it. Multiple features can be separated by commas.
