Hebrew BiDi Text Rendering with ImageMagick and Pango

Rendering bidirectional (BiDi) scripts like Hebrew in ImageMagick often leads to reversed text, misplaced punctuation, and broken word order when using default drawing tools. This guide explains how to properly configure and use ImageMagick alongside the Pango text layout engine to achieve accurate, high-quality Hebrew text rendering.

Why Standard ImageMagick Text Rendering Fails

By default, ImageMagick primitives like label:, caption:, and -annotate rely on standard FreeType rendering. FreeType handles font rasterization but lacks a full bidirectional text layout engine. Consequently, Hebrew text is rendered Left-to-Right (LTR) rather than Right-to-Left (RTL), causing reversed characters and improper placement of mixed alphanumeric strings (such as numbers or English words embedded in Hebrew).

The Solution: Pango Integration

Pango is a library designed for the layout and rendering of internationalized text. It incorporates HarfBuzz for text shaping and FriBidi for bidirectional processing, ensuring that complex text layouts, RTL text, and mixed-direction strings render accurately.

Step 1: Verify Pango Support

Before rendering, ensure your ImageMagick build has the Pango delegate enabled. Run the following command:

magick -list format | grep -i pango

If Pango is available, you will see output indicating read/write support:

PANGO*  r--   Pango Markup Language

Step 2: Render Hebrew Text Using Pango

To render Hebrew text, prefix your input string with pango:. Ensure the string is encoded in UTF-8.

magick -background white -fill black \
  pango:"<span font='David, Arial 24'>שלום עולם! Hello 123</span>" \
  output.png

Step 3: Proper RTL Alignment and Text Direction

For multi-line text or dedicated RTL paragraphs, use Pango markup to explicitly define the text direction and alignment:

magick -size 400x200 -background lightgray -fill black \
  pango:"<span font='Arial 20' dir='rtl'>זהו משפט בעברית עם מספרים 2024 ומילים באנגלית: ImageMagick.</span>" \
  hebrew_rendered.png

Key attributes used:

  • dir='rtl': Enforces Right-to-Left base direction.
  • font='[Font Name] [Size]': Ensures a font with full Hebrew glyph support is utilized.

Step 4: Reading Hebrew Text from a File

For longer texts, passing raw strings in the command line can introduce shell encoding issues. Store the UTF-8 Hebrew text in a file and reference it directly:

magick -background white -fill black pango:@input_hebrew.txt output.png

Inside input_hebrew.txt:

<markup>
  <span font="Assistant 18" dir="rtl">
    שלום! זוהי פסקה ארוכה המעוצבת באמצעות Pango ו-ImageMagick.
  </span>
</markup>

Summary of Best Practices

  • Always use the pango: prefix instead of label: or caption: for Hebrew.
  • Specify a font with native Hebrew glyphs (such as Arial, Assistant, Tahoma, or David).
  • Always encode input text as UTF-8 to avoid character corruption.
  • Set dir='rtl' within the Pango markup to ensure correct punctuation and mixed-language ordering.
