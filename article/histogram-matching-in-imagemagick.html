Histogram Matching in ImageMagick

Histogram matching, also known as histogram specification, modifies the tonal distribution of a target image to match the color profile and luminance of a reference image. This guide demonstrates how to achieve histogram and color profile matching between two images using ImageMagick via direct command-line techniques, statistical color transfer, and specialized scripts.

Method 1: Using Fred's ImageMagick histmatch Script

Native ImageMagick does not feature a single built-in flag for exact non-linear cumulative histogram matching. The standard solution in the ImageMagick community is the specialized histmatch shell script (developed by Fred Weinhaus).

Syntax and Execution

# Make the script executable
chmod +x histmatch

# Perform histogram matching across all RGB channels
./histmatch -c rgb source.jpg reference.jpg output.jpg

Key Options

  • -c <mode>: Color mode to match. Common options include:
    • rgb: Matches each RGB channel independently.
    • yiq or lab: Matches luminance while preserving chrominance.
    • luminance: Matches only the brightness distribution.
  • -s <type>: Match type (e.g., cumulative for exact CDF matching).

Method 2: Color Palette Remapping (-remap)

If you want the source image to adopt the discrete color distribution and palette of the reference image, use the native -remap operator.

ImageMagick v7 Command

magick source.jpg -remap reference.jpg output.jpg

With Dithering Disabled

To map exact nearest colors without introducing diffusion noise:

magick source.jpg +dither -remap reference.jpg output.jpg

Method 3: Statistical Color Distribution Matching

For smooth, natural tonal adjustments without quantization artifacts, you can calculate the mean and standard deviation of the reference image and apply those parameters to the source image using channel-wise scaling.

Step 1: Extract Statistics from the Reference Image

Run the following command to get the mean and standard deviation:

magick reference.jpg -format "%[mean],%[standard_deviation]" info:

Step 2: Apply the Levels to the Source Image

Adjust the black and white points to align luminance distributions:

magick source.jpg -auto-level -level-colors "rgb(15,10,20)","rgb(240,230,210)" output.jpg

Method 4: 3D Color LUT Transfer (Hald CLUT)

For professional workflows, you can match complex color grades using a Hald Color Lookup Table (CLUT).

  1. Generate a neutral identity Hald image: 
    magick hald:8 hald_identity.png
  2. Apply the desired reference color adjustments or color-matching matrix to hald_identity.png to create hald_matched.png.
  3. Apply the modified Hald CLUT to the source image: 
    magick source.jpg hald_matched.png -hald-clut output.jpg

Summary of Approaches

  • Use histmatch when true mathematical histogram equalization and matching across continuous tones is required.
  • Use -remap when you need strict color palette reduction and indexing based on the reference image.
  • Use -hald-clut when transferring complex non-linear color grading profiles across multiple assets.
