How Can I Convert a GIF to AVIF Using ImageMagick?

Converting GIF animations or static images to the modern AVIF format dramatically reduces file size while preserving high visual fidelity and alpha transparency. With ImageMagick 7 and the proper delegate libraries installed, the conversion process can be executed directly from your terminal using simple command-line arguments.

Prerequisites and Format Verification

ImageMagick relies on external delegates, typically libheif built with an AV1 codec such as aom or dav1d, to read and write AVIF files. Before attempting a conversion, confirm your installation includes AVIF support.

Run the following command:

magick identify -list format | grep -i avif

If AVIF is available, the terminal outputs a line listing AVIF with read/write permissions (rw+ or rw-). If no output appears, install libheif through your operating system package manager (such as brew install libheif on macOS or apt install libheif-dev on Debian/Ubuntu) and recompile or reinstall ImageMagick.

Basic Conversion Command

To convert a standard or animated GIF into an AVIF file using default compression settings, pass the input path followed by the desired output filename:

magick input.gif output.avif

Optimizing Quality and File Size

Because AVIF uses advanced AV1 compression algorithms, adjusting compression levels allows fine control over output size and image detail:

  • Control visual quality: Use the -quality flag followed by a value from 0 to 100. Values between 50 and 70 typically produce optimal compression for web delivery without noticeable degradation.
  • Preserve animation looping: Use the -loop flag to specify looping behavior (0 indicates infinite looping).
  • Frame rate management: Adjust timing between frames using -delay if frame durations need modification during the process.

To convert an animated GIF with custom quality and infinite playback, run:

magick input.gif -quality 65 -loop 0 output.avif

Extracting a Static Frame to AVIF

If only the first frame of an animated GIF is needed as a static image, specify frame index [0] immediately after the input file path:

magick input.gif[0] -quality 75 output_still.avif
