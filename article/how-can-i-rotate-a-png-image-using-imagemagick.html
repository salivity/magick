How Can I Rotate a PNG Image Using ImageMagick?

Rotating a PNG image with ImageMagick is a fast, command-line process that allows you to turn graphics by specific angles, correct orientation based on camera metadata, and preserve background transparency. This guide covers the essential commands for both ImageMagick v7 (magick) and legacy ImageMagick v6 (convert), demonstrating how to perform standard 90-degree turns, arbitrary degree rotations, transparent background handling, and batch operations.

Basic Image Rotation

The primary operator for turning an image in ImageMagick is -rotate. The operator accepts a numeric degree value: positive numbers rotate clockwise, while negative numbers rotate counterclockwise.

For ImageMagick v7, use the magick command:

magick input.png -rotate 90 output.png

For ImageMagick v6, use the convert command:

convert input.png -rotate 90 output.png

To rotate 90 degrees counterclockwise, pass -90 or 270:

magick input.png -rotate -90 output.png

To perform a half-turn (upside down), rotate by 180:

magick input.png -rotate 180 output.png

Handling Arbitrary Angles and Transparency

Rotating an image by angles other than multiples of 90 degrees (such as 45 degrees) creates empty corners around the canvas because the overall bounding box expands. By default, ImageMagick attempts to fill these new canvas areas.

Because PNG files support an alpha channel, you can ensure empty corners remain fully transparent by setting -background none:

magick input.png -background none -rotate 45 output.png

If you prefer a solid fill for the newly revealed background space instead of transparency, specify a standard color name or hex code:

magick input.png -background white -rotate 45 output.png
magick input.png -background "#1A1A1A" -rotate 30 output.png

Conditional Rotation Flags

ImageMagick provides optional symbols appended directly to the degree value to execute conditional rotations based on dimensions:

  • >: Rotate only if the image's width exceeds its height (landscape to portrait).
  • <: Rotate only if the image's height exceeds its width (portrait to landscape).

In most terminal shells (such as Bash or Zsh), the angle and symbol must be quoted to prevent the shell from interpreting the character as an I/O redirection:

magick input.png -rotate "90>" output.png

Auto-Rotating via EXIF Metadata

Digital cameras and smartphones often save images oriented sideways along with an internal EXIF orientation tag. You can read this metadata and apply the correct rotation automatically using -auto-orient:

magick input.png -auto-orient output.png

This ensures the image renders in its intended upright orientation without needing to guess the angle manually.

Overwriting the Original File

If you want to modify a PNG directly without creating a separate output file, ImageMagick v7 allows using mogrify:

magick mogrify -rotate 90 photo.png

For ImageMagick v6 systems:

mogrify -rotate 90 photo.png

Batch Rotating Multiple PNG Images

To process an entire folder of PNG images in a single command, apply mogrify with a wildcard pattern:

magick mogrify -background none -rotate 90 *.png

To process multiple files while preserving originals and placing outputs into a subfolder:

mkdir -p rotated && magick mogrify -path ./rotated -background none -rotate 90 *.png
