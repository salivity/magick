How Can I Rotate a WebP Image Using ImageMagick?

Rotating a WebP image using ImageMagick is a straightforward task accomplished via command-line utilities. Whether you need a standard 90-degree turn, an arbitrary angle adjustment, or an automatic orientation fix based on EXIF metadata, ImageMagick provides dedicated flags like -rotate and -auto-orient. This guide outlines the necessary commands for both legacy and modern ImageMagick versions, highlights how to preserve WebP quality, and explains how to batch-process entire directories of WebP files.

Verifying WebP Support

Before executing rotation commands, verify that your local ImageMagick installation includes delegates for the WebP format. Run the following command in your terminal:

magick -version

Look for webp in the list of delegates. Alternatively, you can query delegate support directly:

magick identify -list format | grep -i webp

If WEBP appears with read and write permissions (rw- or r--), your system is ready to process WebP files.

Basic 90, 180, and 270-Degree Rotations

In modern ImageMagick (version 7 and later), the primary command-line tool is magick. In ImageMagick 6, the legacy command convert is used instead.

To rotate an image 90 degrees clockwise:

magick input.webp -rotate 90 output.webp

To rotate an image 90 degrees counter-clockwise, use 270 or -90:

magick input.webp -rotate 270 output.webp

To flip the image upside-down (180 degrees):

magick input.webp -rotate 180 output.webp

Rotating by Arbitrary Angles and Background Handling

When rotating an image by an angle that is not a multiple of 90 degrees (such as 45 degrees), the canvas expands to fit the rotated dimensions. By default, ImageMagick may fill the exposed empty corners with a solid background color.

To rotate by 45 degrees while maintaining a transparent background:

magick input.webp -background none -rotate 45 output.webp

If you prefer a solid background color instead of transparency, specify the color name or hex code:

magick input.webp -background white -rotate 45 output.webp

Preserving WebP Compression Quality

Rotating a raster image like WebP involves re-encoding the pixel data. To prevent unintended quality degradation or excessive compression artifacts, define the output quality explicitly using the -quality flag, which accepts a value from 0 to 100:

magick input.webp -rotate 90 -quality 90 output.webp

If your original WebP file is lossless and you wish to retain complete lossless fidelity:

magick input.webp -rotate 90 -define webp:lossless=true output.webp

Automatic Rotation Using EXIF Metadata

Digital cameras and smartphones often store orientation instructions inside the image's EXIF data rather than physically rotating the pixel grid. To rotate the WebP image to its intended viewing orientation and reset the EXIF tag automatically, use the -auto-orient operator:

magick input.webp -auto-orient output.webp

Batch Rotating Multiple WebP Files

To rotate multiple WebP files at once without overwriting them one by one, use the mogrify command. Be aware that mogrify overwrites the original files in place unless an alternative output directory is specified.

To overwrite all WebP images in the current directory with a 90-degree rotation:

magick mogrify -rotate 90 *.webp

To safely output rotated versions into a dedicated subfolder (such as rotated/):

mkdir -p rotated
magick mogrify -path rotated -rotate 90 *.webp
