How ImageMagick Chop Removes Vertical Slices

The ImageMagick -chop operator removes a targeted rectangular section of pixels from an image and collapses the remaining canvas to fill the empty space. When used to cut vertical slices, -chop deletes a defined column width across the height of the image, shifts the separated portions inward to close the gap, and reduces the image's overall width while keeping the height intact.

How the Vertical Chop Mechanism Works

Unlike cropping, which keeps only the selected region and discards the rest, -chop extracts and deletes the specified area. When removing a vertical slice:

  1. Pixel Deletion: ImageMagick removes a strip of pixels of a specified width starting at a given X-axis offset.
  2. Canvas Collapse: The content to the right of the deleted slice automatically shifts to the left by the width of the removed slice.
  3. Dimension Reduction: The final image's width is reduced by the width of the chopped slice, while the height remains unchanged.

Syntax and Geometry for Vertical Slices

The standard syntax for the -chop geometry argument is:

-chop {width}x{height}+{x}+{y}

To remove a complete vertical slice from the top to the bottom of the image, the height parameter is typically set to 0 (which implies the entire image height) and the Y-offset is set to +0.

Example Command

magick input.jpg -chop 100x0+250+0 output.jpg

In this command:

  • 100: The slice removed is 100 pixels wide.
  • 0: The operation extends through the full vertical height of the image.
  • +250: The cut begins 250 pixels from the left edge.
  • +0: The vertical starting point begins at the top.

The resulting output.jpg will be 100 pixels narrower than input.jpg, with the gap between pixel column 250 and pixel column 350 seamlessly closed.

The Influence of Gravity

The starting coordinate for a vertical cut is determined by the -gravity setting.

  • Default (NorthWest): The X-offset measures from the left edge toward the right.
  • East / NorthEast / SouthEast: The X-offset measures from the right edge inward.
  • Center: The cut is calculated relative to the horizontal midpoint of the canvas.

For example, to remove a 50-pixel vertical slice directly from the right-hand edge:

magick input.jpg -gravity East -chop 50x0 output.jpg
