How ImageMagick Compare Calculates Image Similarity

ImageMagick’s compare command determines visual and mathematical similarity between two images by evaluating corresponding pixels across their color channels. By subtracting, squaring, or statistically modeling the differences between pixel values at identical coordinate locations, the tool produces numeric error metrics and optional visual difference maps. This article explains the underlying mathematics and algorithms ImageMagick uses to compute standard image similarity metrics.

Pixel-Level Evaluation and Normalization

Before computing similarity metrics, ImageMagick standardizes the input images. Both images must share identical dimensions; if they do not, an error occurs unless sub-image searching or canvas adjustment is specified.

ImageMagick processes pixels channel by channel (Red, Green, Blue, Alpha) based on the build's Quantum range (\(Q\)), typically 8-bit (\(Q=255\)) or 16-bit (\(Q=65535\)). The basic unit of comparison is the difference between the intensity of a pixel in the reference image (\(I_1\)) and the target image (\(I_2\)) at coordinate \((x, y)\) for channel \(c\):

\[\Delta(x, y, c) = |I_1(x, y, c) - I_2(x, y, c)|\]

When metrics are normalized, results are expressed in a range of \([0.0, 1.0]\), representing the proportion of distortion relative to the maximum possible channel value (\(Q\)).

Absolute Error Metrics

1. Absolute Error (AE)

The Absolute Error metric simply counts the total number of pixels that differ between two images. If a fuzz factor (-fuzz) is applied, a pixel is only counted as different if the Euclidean distance between its color values exceeds the specified threshold.

2. Mean Absolute Error (MAE)

MAE calculates the average absolute difference across all pixels and color channels:

\[\text{MAE} = \frac{1}{N \cdot C} \sum_{x,y} \sum_{c} |I_1(x, y, c) - I_2(x, y, c)|\]

where \(N\) is the total number of pixels and \(C\) is the number of evaluated channels. MAE provides a linear scale of average pixel intensity deviation.

3. Peak Absolute Error (PAE)

PAE identifies the maximum single difference found among all corresponding pixels and channels:

\[\text{PAE} = \max_{x, y, c} |I_1(x, y, c) - I_2(x, y, c)|\]

This metric isolates the worst-case distortion in an image, regardless of how similar the rest of the pixels are.

Squared Error Metrics

1. Mean Squared Error (MSE)

MSE squares the difference between pixel values before computing the average:

\[\text{MSE} = \frac{1}{N \cdot C} \sum_{x,y} \sum_{c} (I_1(x, y, c) - I_2(x, y, c))^2\]

Squaring penalizes large single-pixel deviations significantly more than widespread, minor color shifts.

2. Root Mean Squared Error (RMSE)

RMSE is the square root of the MSE:

\[\text{RMSE} = \sqrt{\text{MSE}}\]

RMSE returns the error metric to the original scale of the pixel values, making it one of the most common metrics for general image quality assessment. ImageMagick outputs both the raw quantum value and the normalized float in parentheses.

Signal and Perceptual Metrics

1. Peak Signal-to-Noise Ratio (PSNR)

PSNR assesses image degradation using a logarithmic decibel (\(\text{dB}\)) scale. It is calculated using the maximum possible pixel value (\(MAX_I\)) and the MSE:

\[\text{PSNR} = 10 \cdot \log_{10}\left(\frac{MAX_I^2}{\text{MSE}}\right)\]

Higher PSNR values indicate greater similarity. If the two images are identical, \(\text{MSE} = 0\), and ImageMagick returns infinity (inf).

2. Structural Similarity Index (SSIM)

Unlike error-summation metrics, SSIM evaluates visual degradation based on human visual system perception. It compares local windowed regions for three components:

  • Luminance: Mean intensity comparison.
  • Contrast: Standard deviation comparison.
  • Structure: Cross-correlation of normalized signals.

SSIM yields a value between \(-1\) and \(1\), where \(1\) indicates identical structural quality.

3. Normalized Cross Correlation (NCC)

NCC computes the cosine similarity between the pixel intensity vectors of both images:

\[\text{NCC} = \frac{\sum_{x,y} (I_1(x, y) \cdot I_2(x, y))}{\sqrt{\sum_{x,y} I_1(x,y)^2 \cdot \sum_{x,y} I_2(x,y)^2}}\]

A result of \(1.0\) signifies a perfect correlation in lighting and contrast structures.

Generating the Visual Difference Image

When an output filename is provided with compare, ImageMagick constructs a visual difference map alongside the numerical output:

  • Unchanged pixels are desaturated and dimmed to form a pale background context.
  • Changed pixels are highlighted in red (customizable with -highlight-color).
  • Masked or fuzz-tolerated areas are rendered according to user-defined lowlight settings.
