How ImageMagick Converts RGB to xyY Color

ImageMagick converts RGB pixels into the CIE xyY color model by executing a multi-step mathematical transformation that separates color chromaticity from luminance. Because standard RGB pixel values are non-linear and device-dependent, ImageMagick first linearizes the RGB channels, maps them into the standard CIE 1931 XYZ color space using a transformation matrix, and finally projects the XYZ values into chromaticity coordinates \((x, y)\) while retaining the luminance component (\(Y\)).

Step 1: Linearization of sRGB Values

Standard digital RGB images usually utilize the sRGB color space, which applies a non-linear gamma curve to optimize bit depth for human perception. ImageMagick normalizes the RGB values to the range \([0.0, 1.0]\) and removes this gamma encoding to obtain linear RGB values (\(R_{linear}, G_{linear}, B_{linear}\)):

  • If \(C_{sRGB} \le 0.04045\):
    \[C_{linear} = \frac{C_{sRGB}}{12.92}\]
  • If \(C_{sRGB} > 0.04045\):
    \[C_{linear} = \left(\frac{C_{sRGB} + 0.055}{1.055}\right)^{2.4}\]

Where \(C\) represents each individual red, green, and blue channel.

Step 2: Transformation from Linear RGB to CIE XYZ

Once linearized, the RGB values are converted into the CIE 1931 XYZ tristimulus space. ImageMagick performs a \(3 \times 3\) matrix multiplication calibrated to the standard D65 illuminant white point:

\[X = 0.4124564 \cdot R_{linear} + 0.3575761 \cdot G_{linear} + 0.1804375 \cdot B_{linear}\] \[Y = 0.2126729 \cdot R_{linear} + 0.7151522 \cdot G_{linear} + 0.0721750 \cdot B_{linear}\] \[Z = 0.0193339 \cdot R_{linear} + 0.1191920 \cdot G_{linear} + 0.9503041 \cdot B_{linear}\]

In this coordinate space, \(Y\) directly represents the perceived luminance (brightness) of the color, while \(X\) and \(Z\) define color information.

Step 3: Derivation of the xyY Chromaticity Coordinates

The final stage isolates the chromaticity coordinates \((x, y)\) from the total tristimulus energy:

  1. Calculate the sum of all tristimulus values:
    \[S = X + Y + Z\]
  2. Compute chromaticity coordinates:
    \[x = \frac{X}{S}\]
    \[y = \frac{Y}{S}\]
  3. Preserve the luminance component:
    \[Y = Y\]

If \(S = 0\) (representing pure black), ImageMagick avoids division-by-zero errors by assigning \(x\) and \(y\) to the chromaticity coordinates of the reference illuminant (typically \(x \approx 0.3127, y \approx 0.3290\) for D65) or setting them directly to zero.

ImageMagick Command-Line Usage

This transformation can be invoked directly in ImageMagick using the -colorspace operator:

magick input.png -colorspace xyY output.tiff

When saved into an image format, ImageMagick normalizes the resulting floating-point \(x, y,\) and \(Y\) channels across the supported bit depth of the target container format.
