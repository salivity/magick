How ImageMagick -distort Resize Calculates Coordinates

ImageMagick’s -distort Resize operator provides sub-pixel accurate image scaling by evaluating images within a continuous two-dimensional coordinate space and applying Elliptical Weighted Average (EWA) resampling. Unlike standard -resize, which utilizes two independent, orthogonal one-dimensional filtering passes, -distort Resize frames resizing as a full geometric affine transformation. This mathematical approach eliminates rounding anomalies, avoids phase shifts, and ensures exact boundary alignment through floating-point precision mapping.

Continuous Coordinate Space and Pixel Centers

Standard resizing routines in digital image processing often index pixels via discrete integer coordinates, leading to truncation and rounding offsets. ImageMagick's -distort Resize treats pixels as areas rather than points, placing the center of any given pixel \((x, y)\) at the continuous floating-point coordinate \((x + 0.5, y + 0.5)\).

The entire image canvas spans continuously from \((0.0, 0.0)\) at the top-left edge to \((\text{width}, \text{height})\) at the bottom-right edge. When calculating a new target size, the operator maps the continuous boundary of the original image to the continuous boundary of the target image:

\[\text{scale}_x = \frac{\text{width}_{\text{target}}}{\text{width}_{\text{source}}}, \quad \text{scale}_y = \frac{\text{height}_{\text{target}}}{\text{height}_{\text{source}}}\]

Every target pixel center \((u + 0.5, v + 0.5)\) is projected directly back into the source image's continuous domain using an inverse mapping function:

\[x_{\text{source}} = \frac{u + 0.5}{\text{scale}_x}, \quad y_{\text{source}} = \frac{v + 0.5}{\text{scale}_y}\]

Because this calculation operates entirely on 64-bit double-precision floating-point numbers, sub-pixel locations remain exact, preventing the half-pixel phase drift frequently encountered in traditional multi-pass resampling.

The Affine Transformation Matrix

Under the hood, -distort Resize constructs an affine transformation matrix tailored strictly to coordinate scaling:

\[\begin{bmatrix} x \\ y \\ 1 \end{bmatrix} = \begin{bmatrix} \frac{1}{\text{scale}_x} & 0 & 0 \\ 0 & \frac{1}{\text{scale}_y} & 0 \\ 0 & 0 & 1 \end{bmatrix} \begin{bmatrix} u + 0.5 \\ v + 0.5 \\ 1 \end{bmatrix}\]

This matrix defines the partial derivatives of the coordinate mapping:

\[\frac{\partial x}{\partial u} = \frac{1}{\text{scale}_x}, \quad \frac{\partial y}{\partial v} = \frac{1}{\text{scale}_y}, \quad \frac{\partial x}{\partial v} = 0, \quad \frac{\partial y}{\partial u} = 0\]

These partial derivatives directly define the geometry and orientation of the reconstruction filter footprint for every rendered pixel.

Elliptical Weighted Average (EWA) Resampling

Instead of sampling along rows and then columns, -distort Resize evaluates a unified 2D filter footprint in the source image space.

When minifying an image (\(\text{scale} < 1.0\)), a point in the target image corresponds to an expanded region in the source image. The operator uses the partial derivatives to construct an ellipse that encompasses all source pixels contributing to that destination pixel.

The distance metric \(Q\) from the center of the sampling footprint to any nearby source pixel \((x_k, y_k)\) is calculated as an elliptical quadratic form:

\[Q(x_k, y_k) = A(x_k - x_{\text{source}})^2 + B(x_k - x_{\text{source}})(y_k - y_{\text{source}}) + C(y_k - y_{\text{source}})^2\]

Where coefficients \(A\), \(B\), and \(C\) are derived from the scaling matrix. A radial filter function (such as Robidoux, Mitchell-Netravali, or Gaussian) is evaluated as a function of \(\sqrt{Q}\). ImageMagick integrates all pixels within the support radius of this ellipse, normalizing the sum of the weights to \(1.0\) to ensure energy conservation and prevent brightness changes.

When magnifying (\(\text{scale} > 1.0\)), the sampling footprint is clamped to the reconstruction filter’s native support size to prevent severe blurring, operating as a high-precision reconstruction filter centered on continuous coordinates.

Boundary Preservation

Because the transformation strictly equates the source coordinate range \([0, W]\) with the destination coordinate range \([0, W']\), edge pixels are handled symmetrically. Rather than duplicating edge rows or artificially truncating filter weights, the EWA integration smoothly handles the image perimeter by referencing continuous virtual pixel methods (such as transparent, edge clamping, or reflection) exactly where the continuous elliptical footprint extends past the image bounds. This eliminates the edge artifacts and asymmetric border clipping typical of standard 1D discrete filtering.
