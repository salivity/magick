How ImageMagick Handles Display P3 Color Profiles

ImageMagick processes wide-gamut Display P3 embedded profiles through integrated color management engines like Little CMS (lcms2), reading the embedded International Color Consortium (ICC) profile to interpret color values accurately. This article explains how ImageMagick identifies Display P3 profiles, handles color conversions, applies transformation commands, and avoids common pitfalls such as color degradation when converting to standard color spaces like sRGB.

Profile Detection and Color Management

When an image containing an embedded Display P3 profile is loaded, ImageMagick extracts the metadata and identifies the ICC color profile attached to the file. Display P3 covers a color space approximately 25% larger than standard sRGB, particularly in green and red spectrums.

ImageMagick relies on Little CMS to perform color space math. If compiled without LCMS support, ImageMagick cannot perform true ICC-based gamut mapping, meaning it will treat the RGB coordinates as generic values rather than coordinates mapped to the P3 color space.

Profile Conversion vs. Profile Assignment

ImageMagick distinguishes between transforming color data and simply tagging or changing the metadata:

  • Transforming with -profile: To convert an image from Display P3 to sRGB while maintaining perceived visual appearance, the -profile operator must be used. When invoked with a target profile (e.g., sRGB.icc), ImageMagick calculates the chromatic shift using rendering intents (perceptual, relative colorimetric, etc.) and remaps the wide-gamut values to fit inside the target gamut: 
    magick input_p3.jpg -profile sRGB.icc output_srgb.jpg
  • Assigning Profiles: If an image contains Display P3 data but lacks the embedded tag, passing the P3 profile first applies the profile, and passing a second profile converts it: 
    magick untagged_p3.png -profile DisplayP3.icc -profile sRGB.icc output.png

The Difference Between -colorspace and -profile

A frequent mistake in processing Display P3 files is using the -colorspace sRGB command instead of ICC profiles.

  • The -colorspace operator mathematically alters raw pixel values based on algorithmic definitions rather than ICC profile tables.
  • Running -colorspace sRGB on an image with a Display P3 profile does not perform gamut mapping. It can strip or disregard the embedded profile, resulting in undersaturated or distorted colors.
  • To accurately map Display P3 to standard outputs for web or non-wide-gamut displays, ICC color profile workflows using Little CMS are strictly required.

Stripping Profiles

Executing the -strip command removes the embedded Display P3 profile from the image file to reduce file size. If an image is stripped without first being converted to sRGB, image viewers and web browsers will assume the file is standard sRGB. This causes the wide-gamut colors to render washed-out and dull, as the Display P3 coordinates are misinterpreted in the smaller sRGB color space.
