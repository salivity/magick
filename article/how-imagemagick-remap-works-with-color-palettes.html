How ImageMagick -remap Works with Color Palettes

The ImageMagick -remap operator transforms the colors of an input image by replacing them with the closest matching colors found in an external reference image or palette. This article explains how the -remap operator functions, how it handles color distance and dithering, how to construct the command, and the most common practical use cases for palette remapping.

Core Functionality

When you pass an external image file to the -remap operator, ImageMagick performs the following steps:

  1. Extracts the Palette: It reads the reference image and extracts all unique colors to build a defined color lookup table. The reference image can be a custom palette graphic, a grid of color swatches, or an existing photo whose color scheme you want to replicate.
  2. Measures Color Distance: It evaluates every pixel in the source image and calculates the mathematical distance between that pixel's color and each color in the extracted palette (typically using Euclidean distance in RGB or the current colorspace).
  3. Replaces Pixels: It assigns each pixel to the nearest matching color from the external palette, ensuring that the output image contains only colors present in the reference file.

Basic Syntax

In ImageMagick version 7, the standard syntax for remapping is:

magick input.png -remap palette.png output.png

For ImageMagick version 6, the legacy command is:

convert input.png -remap palette.png output.png

Controlling Dithering

By default, the -remap operator applies Floyd-Steinberg dithering. Dithering mixes adjacent pixels of available palette colors to simulate intermediate shades and gradients, reducing harsh color banding.

  • With Dithering (Default): Produces smoother transitions at the expense of a patterned or noisy texture.
  • Without Dithering (+dither): To map each pixel strictly to its single closest color without diffusion patterns, place the +dither flag immediately before the -remap operator:
magick input.png +dither -remap palette.png output.png

Common Use Cases

  • Retro and Pixel Art Styling: Applying limited color palettes (such as Game Boy, CGA, or Commodore 64 palettes) to modern graphics or photos.
  • Consistent Branding: Standardizing user-uploaded assets or batch images so they strictly adhere to an organization's predefined corporate color palette.
  • GIF Optimization: Enforcing a single global color table across all frames of an animated GIF to reduce file size and eliminate frame-to-frame color flickering.
