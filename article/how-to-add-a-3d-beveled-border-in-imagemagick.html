How to Add a 3D Beveled Border in ImageMagick

This guide explains how to generate a 3D-looking beveled border around an image using ImageMagick command-line tools. You will learn the exact syntax for the -raise and -frame operators to quickly apply raised, lowered, and customizable three-dimensional framing effects to any image.

Method 1: The -raise Operator

The -raise operator creates a 3D beveled edge directly inside the boundaries of the image by lightening the top and left edges while darkening the bottom and right edges.

Basic Syntax

magick input.jpg -raise {width}x{height} output.jpg
  • For ImageMagick version 6, replace magick with convert.
  • {width}: The horizontal thickness of the bevel in pixels.
  • {height}: The vertical thickness of the bevel in pixels.

Examples

Create a Raised 3D Border (5 pixels wide):

magick input.jpg -raise 5x5 output.jpg

Create an Inset / Lowered 3D Border: Use +raise instead of -raise to invert the shading and make the image look pressed down into the page:

magick input.jpg +raise 5x5 output.jpg

Method 2: The -frame Operator

If you want to add an external border around the image rather than beveling the image edges themselves, use the -frame operator. This allows you to specify a base frame color along with separate inner and outer 3D bevel depths.

Basic Syntax

magick input.jpg -mattecolor "{color}" -frame {width}x{height}+{outer_bevel}+{inner_bevel} output.jpg

Parameter Breakdown

  • -mattecolor "{color}": Defines the base color of the frame (e.g., #CCCCCC, gray, navy). The 3D highlights and shadows are automatically computed from this color.
  • {width}x{height}: The total thickness of the border added to the sides and top/bottom.
  • {outer_bevel}: The pixel width of the outer beveled edge.
  • {inner_bevel}: The pixel width of the inner beveled edge adjacent to the image.

Examples

Standard 3D Picture Frame: Adds a 10px wide gray border with a 3px outer bevel and a 3px inner bevel:

magick input.jpg -mattecolor "#c0c0c0" -frame 10x10+3+3 output.jpg

Heavy Outer Bevel Only: Adds a 15px border where the entire frame slopes inward in 3D:

magick input.jpg -mattecolor "#808080" -frame 15x15+15+0 output.jpg
