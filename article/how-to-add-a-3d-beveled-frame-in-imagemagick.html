How to Add a 3D Beveled Frame in ImageMagick

Adding a 3D beveled frame to a photo is a quick way to give digital images depth and a polished, professional finish. This article explains how to use ImageMagick's built-in -frame and -mattecolor options to generate realistic three-dimensional borders, break down the command-line geometry syntax, and adjust lighting effects to create raised, sunken, or decorative edges around your photos.

The Basic 3D Frame Command

ImageMagick provides the -frame option to generate a border with simulated lighting, highlights, and shadows. The color of the frame is determined by the -mattecolor option.

To apply a standard raised 3D frame, use the following syntax:

magick input.jpg -mattecolor "#808080" -frame 20x20+6+6 output.jpg

(Note: If you are using ImageMagick v6, replace magick with convert.)

Understanding the Frame Geometry Syntax

The -frame parameter uses the geometry format [width]x[height]+[outer_bevel]+[inner_bevel]:

  • widthxheight: The total horizontal and vertical thickness added to each side of the image. For example, 20x20 adds a 20-pixel border to all sides.
  • outer_bevel: The thickness in pixels of the outer beveled edge that catches the light.
  • inner_bevel: The thickness in pixels of the inner beveled edge adjacent to the image.

The sum of the outer and inner bevel values cannot exceed the total width and height of the frame. Any remaining pixels between the bevels will appear as a flat surface in the base frame color.

Customizing Colors and Shading

ImageMagick automatically creates lighter highlight tones on the top/left edges and darker shadow tones on the bottom/right edges based on the color provided to -mattecolor.

Classic Gallery White Frame

magick input.jpg -mattecolor "#F0F0F0" -frame 25x25+4+4 white_framed.jpg

Metallic Gold Frame

magick input.jpg -mattecolor "#D4AF37" -frame 30x30+8+8 gold_framed.jpg

Creating Different Bevel Styles

By modifying the bevel values, you can alter the simulated depth and angle of the border.

Sharp Chiseled Border

To create a fully angled border with no flat surface in the middle, set the sum of the inner and outer bevels equal to the total border width:

magick input.jpg -mattecolor "#A0A0A0" -frame 20x20+10+10 sharp_bevel.jpg

Sunken / Inset Picture Effect

To make the photo appear recessed inside the frame rather than raised, increase the inner bevel and reduce or eliminate the outer bevel:

magick input.jpg -mattecolor "#555555" -frame 20x20+0+8 sunken_frame.jpg

Double-Beveled Picture Molding

You can chain multiple -mattecolor and -frame commands in a single execution to create complex, multi-layered picture moldings:

magick input.jpg \
  -mattecolor "#333333" -frame 6x6+2+2 \
  -mattecolor "#EAEAEA" -frame 30x30+0+0 \
  -mattecolor "#555555" -frame 10x10+4+4 \
  molding_framed.jpg

This sequence creates a small inner bevel directly around the photo, surrounded by a wide flat mat, encased in a thicker outer beveled frame.
