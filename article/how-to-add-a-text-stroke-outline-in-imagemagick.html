How to Add a Text Stroke Outline in ImageMagick

This article provides the exact command-line syntax for creating stroked text outlines in ImageMagick. You will learn the core parameters required to define stroke color, outline thickness, interior fill, and proper layer order to produce clean, legible text borders.

Basic Syntax

To create an outline around text in ImageMagick, you define the outline using -stroke and -strokewidth, and the interior color using -fill.

ImageMagick v7 (Recommended)

magick -size 600x150 xc:white \
  -font Arial -pointsize 48 \
  -fill white -stroke black -strokewidth 3 \
  -gravity center -annotate +0+0 "Outlined Text" \
  output.png

ImageMagick v6

convert -size 600x150 xc:white \
  -font Arial -pointsize 48 \
  -fill white -stroke black -strokewidth 3 \
  -gravity center -annotate +0+0 "Outlined Text" \
  output.png

Parameter Breakdown

  • -stroke <color>: Specifies the color of the outline (e.g., black, #000000, rgb(0,0,0)).
  • -strokewidth <integer>: Sets the thickness of the border in pixels.
  • -fill <color>: Defines the inner color of the characters.
  • -font <name/path>: Sets the typeface.
  • -pointsize <size>: Sets the font size.
  • -gravity <position>: Aligns the text within the canvas (e.g., center, northwest).
  • -annotate <offset> "text": Draws the text onto the image with specified coordinates.

Generating Transparent Text with Only an Outline

To render text that has an outline but a transparent center, set the -fill value to none:

magick -size 600x150 xc:transparent \
  -font Arial -pointsize 48 \
  -fill none -stroke red -strokewidth 2 \
  -gravity center -annotate +0+0 "Hollow Text" \
  hollow_text.png

Creating Crisp Outlines (Two-Pass Method)

When thick stroke widths are applied, the stroke expands both outward and inward, which can distort thin letterforms. To keep the inside of the font sharp, draw the stroke first and then overlay the plain text on top:

magick -size 600x150 xc:white -font Arial -pointsize 54 -gravity center \
  -stroke black -strokewidth 8 -fill none -annotate +0+0 "Clean Outline" \
  -stroke none -fill yellow -annotate +0+0 "Clean Outline" \
  clean_stroke.png

Using the label: Protocol

For automatically sized images that fit the text dimensions:

magick -background none -font Arial -pointsize 60 \
  -fill cyan -stroke navy -strokewidth 2 \
  label:"Dynamic Size Text" \
  label_output.png
