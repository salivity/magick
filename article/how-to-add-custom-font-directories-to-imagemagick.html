How to Add Custom Font Directories to ImageMagick

ImageMagick allows users to render text onto images using custom typography, but it needs to know where your TrueType (.ttf) and OpenType (.otf) files are stored. This guide demonstrates how to make custom font directories accessible to ImageMagick using environment variables, configuration files, and direct path declarations.

Method 1: Use the MAGICK_FONT_PATH Environment Variable

The fastest way to register an entire directory of TrueType and OpenType fonts without modifying configuration files is by setting the MAGICK_FONT_PATH environment variable.

On Linux and macOS

Add the font directory path to your current shell session or permanent configuration:

# Temporary (current session)
export MAGICK_FONT_PATH="/path/to/custom/fonts"

# Permanent (add to ~/.bashrc or ~/.zshrc)
echo 'export MAGICK_FONT_PATH="/path/to/custom/fonts"' >> ~/.bashrc
source ~/.bashrc

To include multiple directories, separate them with a colon (:):

export MAGICK_FONT_PATH="/usr/local/share/fonts/custom:/home/user/my-fonts"

On Windows

Set the variable via Command Prompt or PowerShell:

:: Command Prompt
setx MAGICK_FONT_PATH "C:\path\to\custom\fonts"
# PowerShell
[Environment]::SetEnvironmentVariable("MAGICK_FONT_PATH", "C:\path\to\custom\fonts", "User")

Multiple paths on Windows should be separated by a semicolon (;).

Method 2: Configure type.xml

To register fonts permanently within ImageMagick's system mapping, you can define them in a type.xml or type-local.xml configuration file.

  1. Locate your ImageMagick configuration path:

    magick -list configure | grep CONFIGURE_PATH

  2. Open or create type-local.xml in that directory (e.g., /etc/ImageMagick-7/type-local.xml or ~/.config/ImageMagick/type.xml).

  3. Define your custom fonts inside the <typemap> block:

    <?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE typemap [
  <!ELEMENT typemap (type)+>
  <!ELEMENT type EMPTY>
  <!ATTLIST type name CDATA #REQUIRED>
  <!ATTLIST type fullname CDATA #IMPLIED>
  <!ATTLIST type family CDATA #IMPLIED>
  <!ATTLIST type foundry CDATA #IMPLIED>
  <!ATTLIST type weight CDATA #IMPLIED>
  <!ATTLIST type style CDATA #IMPLIED>
  <!ATTLIST type stretch CDATA #IMPLIED>
  <!ATTLIST type format CDATA #IMPLIED>
  <!ATTLIST type metrics CDATA #IMPLIED>
  <!ATTLIST type glyphs CDATA #REQUIRED>
]>
<typemap>
  <type name="CustomFont" fullname="Custom Font Regular" family="CustomFont" format="ttf" glyphs="/path/to/custom/fonts/CustomFont.ttf"/>
  <type name="OpenSans-Bold" fullname="Open Sans Bold" family="Open Sans" format="otf" glyphs="/path/to/custom/fonts/OpenSans-Bold.otf"/>
</typemap>

Method 3: Reference Font Files Directly in Commands

If you do not want to register directories globally, you can provide the direct filesystem path to any .ttf or .otf file directly within your command using the -font parameter.

magick -background lightblue -fill blue -font "/path/to/custom/fonts/CustomFont.ttf" -pointsize 36 label:"Sample Text" output.png

Verifying Font Availability

To check if ImageMagick recognizes your added fonts, run:

magick -list font

Or search for a specific font name:

magick -list font | grep -i "CustomFont"
