How to Add Drop Shadows in ImageMagick Montage

This guide explains how to generate drop shadows under individual thumbnail images when creating grids with the ImageMagick montage tool. By utilizing the -shadow operator alongside proper spacing and background configurations, you can create polished, visually appealing image arrangements directly from the command line.

Basic Drop Shadow Command

To add a drop shadow beneath each thumbnail in a montage, pass the -shadow argument to the montage command. You must also allocate sufficient spacing via the -geometry parameter so neighboring shadows do not overlap or get clipped.

For ImageMagick v7:

magick montage *.jpg -shadow -background white -geometry 200x200+10+10 output.png

For ImageMagick v6:

montage *.jpg -shadow -background white -geometry 200x200+10+10 output.png

Parameter Breakdown

  • *.jpg: The input images to assemble into the montage.
  • -shadow: Enables the drop shadow effect under each thumbnail tile.
  • -background white: Sets the canvas background color. You can replace white with any color name or hex code (e.g., "#f0f0f0").
  • -geometry 200x200+10+10:
    • 200x200 restricts the maximum thumbnail width and height.
    • +10+10 defines the horizontal and vertical margins between tiles. These offsets provide the necessary clearance for the shadow to render without being cut off.
  • output.png: The final output file containing the assembled grid.

Creating a Transparent Background

If you need a transparent backdrop behind your shadowed thumbnails, set the background to none and ensure your output format supports an alpha channel (such as PNG):

magick montage *.jpg -shadow -background none -geometry 150x150+15+15 montage_transparent.png

Adding Frames and Borders with Shadows

To create a framed gallery effect, combine the -frame option with -shadow. The frame geometry controls the border size and beveling around each thumbnail:

magick montage *.jpg -frame 5 -shadow -background "#e0e0e0" -geometry 180x180+12+12 framed_montage.jpg
  • -frame 5: Adds a 5-pixel 3D frame around each image before applying the drop shadow underneath.

Controlling Grid Layout

By default, ImageMagick calculates the number of rows and columns automatically. You can explicitly define the layout using the -tile flag:

magick montage *.jpg -tile 3x -shadow -background white -geometry 250x250+15+15 3_column_montage.png
  • -tile 3x: Forces the montage into 3 columns, automatically scaling rows as needed based on the total number of input images.
