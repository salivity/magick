How to Add Drop Shadows to Text in ImageMagick

Adding drop shadows behind rendered text in ImageMagick gives typography depth and improves readability against varied backgrounds. This guide details the exact command-line syntax using ImageMagick’s magick (ImageMagick 7) and convert (ImageMagick 6) tools, explaining the shadow parameters, layer cloning, and compositing steps needed to generate high-quality text effects.

Basic Syntax for Text with Drop Shadow

To create a drop shadow, you render the text on a transparent background, duplicate the text layer to generate a blurred shadow, place the shadow underneath the original text, and merge the layers onto your final background.

magick -size 600x200 xc:none -gravity center \
  -font DejaVu-Sans-Bold -pointsize 48 -fill white -annotate +0+0 "Shadowed Text" \
  \( +clone -background black -shadow 80x4+5+5 \) \
  +swap -background "#336699" -layers merge +repage output.png

Understanding the -shadow Parameter

The shadow effect is controlled by the -shadow operator, which accepts four values in the format PercentxSigma+X+Y:

  • Percent (80): Sets the opacity of the shadow (0 to 100).
  • Sigma (4): Controls the blur radius in pixels. A higher number produces a softer, more diffused shadow.
  • +X (+5): The horizontal offset in pixels. Positive values move the shadow right; negative values move it left.
  • +Y (+5): The vertical offset in pixels. Positive values move the shadow down; negative values move it up.

Step-by-Step Command Breakdown

  1. Create Canvas and Text: -size 600x200 xc:none creates a transparent canvas. -fill white -annotate +0+0 "Text" renders the foreground text.
  2. Generate the Shadow: \( +clone -background black -shadow 80x4+5+5 \) clones the text layer, sets the shadow color to black, and applies the blur, opacity, and offset parameters inside an isolated sub-expression.
  3. Order the Layers: +swap reorders the images so the shadow sits behind the original text layer.
  4. Flatten the Image: -background "#336699" -layers merge +repage assigns the canvas background color, combines all layers together, and removes any canvas offsets before saving to output.png.

Applying Shadows to Existing Background Images

To place shadowed text over an existing image rather than a solid color:

magick input.jpg \
  \( -size 600x200 xc:none -gravity center \
     -font Arial-Bold -pointsize 48 -fill white -annotate +0+0 "Overlay Text" \
     \( +clone -background black -shadow 90x5+6+6 \) \
     +swap -layers merge \) \
  -gravity center -composite result.jpg

This renders the text and shadow together as a self-contained transparent overlay before compositing the finished text block directly onto input.jpg.
