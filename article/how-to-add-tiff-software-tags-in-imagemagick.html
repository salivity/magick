How to Add TIFF Software Tags in ImageMagick

This article demonstrates how to inject custom ASCII software tags into a TIFF image header using the ImageMagick command-line suite. You will learn the exact syntax for modifying the standard TIFF Software metadata field (Tag 305), writing arbitrary ASCII tags, and verifying that the updated header information has been properly written to the file.

Writing to the Standard TIFF Software Tag

The TIFF specification designates Tag 305 (hexadecimal 0x0131) as the standard ASCII field to identify the software used to create or modify an image. In ImageMagick, you can set this field using the -set operator followed by the tiff:software property key.

For ImageMagick v7, use the magick command:

magick input.tif -set "tiff:software" "MyCustomSoftware v1.0" output.tif

For ImageMagick v6, replace magick with convert:

convert input.tif -set "tiff:software" "MyCustomSoftware v1.0" output.tif

Adding Arbitrary or Custom ASCII Tags

If you need to write custom ASCII tags outside the standard tiff:software property, ImageMagick supports passing arbitrary TIFF tags via the -define operator using the tag ID number and type.

To add a generic ASCII tag, define the tag identifier and append the string value:

magick input.tif -define tiff:tag:65000="Custom ASCII Payload" output.tif

Note: Ensure custom tag numbers avoid reserved baseline TIFF ranges (1–37000) to prevent conflicts with standard readers.

Verifying the Tag in the TIFF Header

After writing the file, confirm the ASCII tag exists within the header using ImageMagick's identify tool:

magick identify -verbose output.tif | grep "tiff:software"

The output will display the custom string set during processing:

tiff:software: MyCustomSoftware v1.0
