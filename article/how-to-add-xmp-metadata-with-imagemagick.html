How to Add XMP Metadata with ImageMagick

This guide explains how to create and embed an Extensible Metadata Platform (XMP) metadata block into an image using ImageMagick. You will learn the exact command-line syntax required to inject external .xmp files into supported image formats like JPEG, PNG, and TIFF, set specific XMP properties directly, and verify that the metadata was successfully embedded.

Embedding an External XMP File

The standard method to insert a complete XMP metadata block into an image is by applying an existing .xmp file using the -profile option.

ImageMagick v7 Syntax:

magick input.jpg -profile metadata.xmp output.jpg

ImageMagick v6 Syntax:

convert input.jpg -profile metadata.xmp output.jpg

This command embeds the XML content from metadata.xmp directly into the output image file under the standard XMP profile identifier.

Setting Inline XMP Properties

If you want to set specific XMP fields without preparing a separate .xmp file, you can define properties directly using the -set operator.

magick input.jpg -set "xmp:dc:title" "Sample Image Title" -set "xmp:dc:creator" "Author Name" output.jpg

Verifying the Embedded XMP Block

To confirm that the XMP metadata has been successfully embedded, you can inspect the image properties or extract the XMP block directly.

Check with Identify:

magick identify -verbose output.jpg

Look for the Profile-xmp section in the output text.

Extract the XMP Block to a File:

magick output.jpg xmp:extracted.xmp

This extracts the raw XMP payload and saves it into extracted.xmp for validation.
