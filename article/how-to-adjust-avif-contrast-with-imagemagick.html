How to Adjust AVIF Contrast with ImageMagick?

Adjusting the contrast of an AVIF image using ImageMagick can be accomplished directly from the command line using operators like -brightness-contrast, -level, or -sigmoidal-contrast. This guide explains how to install the required delegates for AVIF support, walk through the essential contrast adjustment flags, and fine-tune output quality while preserving the compression benefits of the AVIF format.

Prerequisites: Ensuring AVIF Delegate Support

ImageMagick relies on external libraries—specifically libheif—to read and encode AVIF files. Before running processing commands, confirm your ImageMagick build includes AVIF support by querying the installed delegates.

magick -version

Look for heic or avif in the Delegates (built-in) list. You can also inspect the format handler directly:

magick identify -list format | grep -i avif

If the mode displays rw+, your build can both decode and encode AVIF files. If support is missing, update ImageMagick using a package manager with libheif enabled (such as brew install imagemagick on macOS or configuring packages with libheif-dev on Linux).

Method 1: The Brightness-Contrast Operator

The most straightforward way to shift contrast is the -brightness-contrast flag. It accepts values formatted as {brightness}x{contrast} using percentages ranging from -100 to 100.

To increase contrast by 20% while leaving brightness unchanged:

magick input.avif -brightness-contrast 0x20 output.avif

To decrease contrast by 15%:

magick input.avif -brightness-contrast 0x-15 output.avif

This operator scales contrast symmetrically around the midpoint of the tonal range, making it ideal for quick corrections.

Method 2: Non-Linear Contrast with Sigmoidal Contrast

For photographic images, linear contrast adjustments often clip highlights or crush shadows prematurely. The -sigmoidal-contrast operator provides an S-curve tone mapping that increases perceived midtone contrast while protecting highlights and shadow detail.

The syntax requires two parameters: {contrast}x{midpoint}%:

magick input.avif -sigmoidal-contrast 5x50% output.avif
  • The first value (e.g., 5) represents the steepness of the curve. Higher numbers yield stronger contrast. Typical values range from 3 to 10.
  • The second value (e.g., 50%) sets the center point around which the contrast pivots.

To decrease contrast using the same S-curve, invoke the +sigmoidal-contrast operator variant:

magick input.avif +sigmoidal-contrast 5x50% output.avif

Method 3: Precise Dynamic Range Remapping with Level

If your AVIF appears flat or washed out due to unused tonal range at the extremes, use -level to manually stretch black and white points:

magick input.avif -level 5%,95%,1.0 output.avif
  • 5%: Any pixel values at or below 5% are mapped to pure black.
  • 95%: Any pixel values at or above 95% are mapped to pure white.
  • 1.0: Gamma setting (values above 1.0 lighten midtones; values below 1.0 darken midtones).

Preserving Encoding Quality and Compression

AVIF re-compression is lossy by default. When modifying contrast, specify the output encoding quality to prevent degradation:

magick input.avif -sigmoidal-contrast 4x50% -quality 65 output.avif

AVIF quality levels differ significantly from standard JPEG metrics:

  • -quality 50 to 65: Produces excellent visual fidelity for photographic web content.
  • -quality 80 or higher: Near-lossless output with substantially larger file footprints.
  • -define heic:speed=X: Accepts values between 0 (slowest compression, optimal size) and 9 (fastest execution). Adding -define heic:speed=4 balances processing speed and efficient output sizing.
