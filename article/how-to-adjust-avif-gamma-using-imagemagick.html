How to Adjust AVIF Gamma Using ImageMagick?

Adjusting the gamma of an AVIF file using ImageMagick requires calling the -gamma operator on the command line to modify image midtones without clipping highlights or shadows. Because AVIF is an efficient, modern image format based on the AV1 video codec, modifying its gamma involves reading the file with an AVIF-capable ImageMagick build (using libheif), applying the tonal adjustment factor, and re-encoding the result to AVIF.

Prerequisites

Before executing gamma adjustments on AVIF images, verify that your ImageMagick installation includes AVIF delegate support. Run the following command to check:

magick -list format | grep -i avif

If the output lists AVIF with read and write (rw+) support, your binary is equipped with the necessary libheif library. If not, upgrade or recompile ImageMagick with libheif enabled.

Basic Gamma Adjustment Syntax

In ImageMagick 7, the primary tool is magick. The -gamma operator takes a numerical value:

  • Values greater than 1.0 (e.g., 1.5, 2.2) brighten the midtones.
  • Values less than 1.0 (e.g., 0.7, 0.45) darken the midtones.
  • A value of 1.0 leaves the image unchanged.

To apply a basic gamma adjustment and save the output:

magick input.avif -gamma 1.4 output.avif

If you are using legacy ImageMagick 6, replace magick with convert:

convert input.avif -gamma 1.4 output.avif

Preserving Quality and Compression Settings

AVIF encoding is lossy by default unless specified otherwise. When re-encoding an adjusted image, preserve visual fidelity by defining the quality setting with -quality:

magick input.avif -gamma 1.25 -quality 75 output.avif

A quality range of 60 to 80 generally produces strong visual fidelity with compact file sizes. For lossless re-encoding, use a quality value of 100:

magick input.avif -gamma 1.25 -quality 100 output.avif

Channel-Specific Gamma Correction

To correct color casts or adjust specific color profiles, target individual channels using comma-separated values for red, green, and blue:

magick input.avif -gamma 1.2,1.0,0.9 output.avif

In this example:

  • Red midtones increase by a factor of 1.2.
  • Green midtones remain at 1.0.
  • Blue midtones decrease to 0.9.

Batch Processing Multiple AVIF Images

To apply the same gamma adjustment across an entire folder of AVIF files, use the mogrify command:

magick mogrify -gamma 1.3 -path ./processed/ *.avif

The -path flag directs the updated files into a designated directory to prevent overwriting your original images.
