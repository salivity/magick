How to Adjust AVIF Image Brightness with ImageMagick?

Adjusting the brightness of an AVIF image using ImageMagick requires using specific command-line operators such as -modulate or -evaluate while ensuring your ImageMagick build includes libheif support for AVIF reading and writing. This guide outlines the prerequisites for AVIF compatibility, demonstrates the best operators to brighten or darken images, and covers common flags needed to preserve visual quality.

Prerequisites for AVIF Handling

ImageMagick processes AVIF files through an external delegate library, typically libheif. Before running adjustments, verify that your installation supports AVIF by executing:

magick -version

Look for heic or avif in the Delegates (built-in) list. If the delegate is absent, ImageMagick will fail to decode or encode the AVIF format, requiring an update or a build configured with libheif.

Adjusting Brightness Using the Modulate Operator

The simplest and most visually balanced method to change brightness is the -modulate operator. This modifies the image in the HSL (Hue, Saturation, Lightness) color space.

The -modulate flag accepts values in the order of brightness[,saturation[,hue]]. A value of 100 represents no change. Values above 100 brighten the image, while values below 100 darken it.

Brightening an Image

To increase brightness by 20% while leaving saturation and hue unchanged:

magick input.avif -modulate 120 output.avif

Darkening an Image

To decrease brightness by 15%:

magick input.avif -modulate 85 output.avif

Fine-Tuning Brightness with Evaluate and Level

For more precise mathematical control over pixel brightness, ImageMagick offers the -evaluate and -level operators.

Linear Scaling with Evaluate Multiply

The -evaluate multiply option directly scales RGB channel values:

magick input.avif -evaluate multiply 1.25 output.avif

A multiplier greater than 1 increases brightness, while a multiplier between 0 and 1 darkens the image.

Dynamic Range Adjustments with Level

The -level operator adjusts the black point, white point, and midtones (gamma). To brighten midtones without clipping the highlights:

magick input.avif -level 0%,100%,1.3 output.avif

The third parameter represents gamma; values greater than 1 brighten shadow and midtone details.

Preserving Quality During Re-Encoding

Re-encoding an AVIF image introduces compression loss unless explicit compression settings are defined. To maintain visual fidelity, use the -quality flag:

magick input.avif -modulate 115 -quality 80 output.avif

Setting -quality between 75 and 85 provides a solid balance between file size and image clarity for AVIF exports.
