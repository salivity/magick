How to Adjust AVIF Saturation with ImageMagick?

Adjusting the color saturation of an AVIF image with ImageMagick is a straightforward command-line process that utilizes the -modulate operator. This guide covers how to prepare ImageMagick for AVIF handling, how to target the saturation parameter precisely, and how to execute single-file and batch adjustments without unintentionally altering brightness or hue.

ImageMagick provides the -modulate option to manipulate three core color properties simultaneously: brightness, saturation, and hue. When configuring this setting, values are represented as percentages where 100% signifies no change. The parameter syntax follows the order brightness,saturation,hue. To adjust only saturation while leaving brightness and hue intact, the first and third values must remain set to 100.

Before running conversion commands, verify that your ImageMagick installation includes AVIF delegate support. You can test your system by executing magick -version or magick identify -list format | grep AVIF. If AVIF is listed with read and write capabilities, ImageMagick can decode and encode the format directly.

To increase the color saturation of an AVIF file by 30%, run:

magick input.avif -modulate 100,130,100 output.avif

To decrease color saturation by 50% for a muted or semi-desaturated look, use a value lower than 100 for the middle argument:

magick input.avif -modulate 100,50,100 output.avif

Setting the saturation value to 0 completely removes color information, converting the image to grayscale:

magick input.avif -modulate 100,0,100 output.avif

AVIF encoding involves compression settings that influence final visual quality and file size. When writing back to the AVIF format, you can control output quality using the -quality flag, where values typically range from 1 to 100:

magick input.avif -modulate 100,125,100 -quality 75 output.avif

If you need to process an entire folder of AVIF files, the mogrify tool applies changes in place or writes them to a designated directory:

magick mogrify -path ./processed -modulate 100,120,100 -format avif *.avif

This batch command reads every .avif file in the current directory, boosts saturation by 20%, and saves the newly generated files into a ./processed folder while preserving the original source images.
