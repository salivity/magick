How to Adjust Gamma of a WebP Image in ImageMagick?

Adjusting the gamma of a WebP image using ImageMagick is a straightforward process achieved primarily through the -gamma operator in the command-line interface. This guide covers the basic syntax for modifying midtone luminance, explains how gamma values affect image exposure, demonstrates separate color channel adjustments, and provides methods for batch-processing WebP files.

Understanding the Gamma Operator

Gamma correction controls an image's overall brightness by altering the non-linear relationship between pixel values and displayed luminance. Unlike linear brightness adjustments, gamma correction primarily targets midtones while leaving the absolute black and pure white points largely intact.

In ImageMagick, the -gamma operator uses numeric values where:

  • 1.0 represents no change.
  • Values greater than 1.0 (such as 1.4 or 2.2) brighten the midtones.
  • Values between 0.0 and 1.0 (such as 0.7 or 0.45) darken the midtones.

ImageMagick natively supports the WebP format, provided the libwebp delegate library was compiled with your installation.

Basic Syntax for ImageMagick v7 and v6

The standard command structure depends on the major version of ImageMagick running on your system.

ImageMagick 7 (Recommended)

ImageMagick 7 uses the unified magick binary:

magick input.webp -gamma 1.5 output.webp

ImageMagick 6

ImageMagick 6 utilizes the legacy convert utility:

convert input.webp -gamma 1.5 output.webp

In both examples, input.webp is loaded, the midtone values are brightened using a gamma factor of 1.5, and the result is encoded directly into output.webp.

Adjusting Individual Color Channels

ImageMagick allows gamma adjustment across specific color channels rather than applying a uniform correction to the entire RGB spectrum. This technique is useful for correcting color casts or creating stylized color grading.

You can supply individual comma-separated values for red, green, and blue:

magick input.webp -gamma 1.2,1.0,0.8 output.webp

In this command:

  • The Red channel gamma is raised to 1.2, brightening red midtones.
  • The Green channel remains unchanged at 1.0.
  • The Blue channel gamma is reduced to 0.8, cooling blue midtones.

Alternatively, you can isolate a channel using the -channel flag before applying the correction:

magick input.webp -channel R -gamma 1.3 +channel output.webp

The +channel switch resets channel targeting back to normal after the operation completes.

Preserving WebP Compression and Quality

When re-encoding a WebP file after modifying gamma, ImageMagick applies its default WebP encoding parameters unless specified otherwise. To preserve visual fidelity or manage file size, configure the quality and compression method explicitly:

magick input.webp -gamma 1.2 -quality 85 -define webp:method=6 output.webp
  • -quality 85 specifies the lossy compression level on a scale from 0 to 100.
  • -define webp:lossless=true can replace the -quality flag if you require a lossless output.
  • -define webp:method=6 balances processing speed and compression density, with 6 producing the smallest file size at the cost of slower encoding.

Batch Processing WebP Images

If you have an entire directory of WebP images requiring identical gamma adjustments, use the ImageMagick mogrify tool. Unlike magick, mogrify modifies files in place or exports them to an alternate destination directory.

To process files and save them to a subfolder named adjusted:

mkdir -p adjusted
magick mogrify -path adjusted -gamma 1.25 *.webp

To overwrite existing files directly in the working directory:

magick mogrify -gamma 1.25 *.webp
