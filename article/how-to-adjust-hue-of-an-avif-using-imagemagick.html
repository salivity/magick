How to Adjust Hue of an AVIF Using ImageMagick?

Adjusting the hue of an AVIF image using ImageMagick requires the -modulate operator and an ImageMagick build compiled with AVIF delegate support. This guide outlines the prerequisite check for AVIF capability, explains the syntax of the -modulate parameter, and provides concrete command-line examples for shifting color values, batch processing files, and preserving image quality.

Prerequisites and AVIF Support Check

ImageMagick relies on external delegates, typically libheif, to decode and encode AVIF files. Before running image transformation commands, verify that your local ImageMagick installation supports the format.

Run the following command in your terminal:

magick identify -list format | grep -i AVIF

If AVIF support is installed, the output will indicate read and write capabilities (rw+ or rw-):

AVIF* AVIF      rw+   AV1 Image File Format

If no output appears, update ImageMagick or install libheif support via your operating system's package manager.

Understanding the -modulate Operator

The primary tool for altering hue in ImageMagick is the -modulate operator. The operator takes up to three comma-separated percentage values in the following order:

-modulate Brightness,Saturation,Hue

When modifying hue:

  • 100 represents no change (the baseline state).
  • 0 represents a -180 degree rotation on the color wheel.
  • 200 represents a +180 degree rotation on the color wheel.
  • Values between 0 and 200 map proportionally to the 360-degree color circle (for example, 150 shifts the hue by +90 degrees, and 50 shifts it by -90 degrees).

Leaving brightness and saturation at 100 ensures only the color spectrum is rotated while keeping lightness and color intensity intact.

Adjusting Hue on a Single AVIF Image

To rotate the hue by +90 degrees on an AVIF file using ImageMagick 7, use the magick command:

magick input.avif -modulate 100,100,150 output.avif

If using legacy ImageMagick 6, replace magick with convert:

convert input.avif -modulate 100,100,150 output.avif

To rotate the hue by 180 degrees (inverting color tones while maintaining luminance):

magick input.avif -modulate 100,100,200 output.avif

Controlling AVIF Output Quality and Compression

Re-encoding an image into AVIF format re-compresses pixel data. To avoid unintended compression artifacts or excessive file bloat, specify quality and compression speed options alongside the hue adjustment:

magick input.avif -modulate 100,100,133 -quality 80 -define heic:speed=4 output.avif
  • -quality 80: Sets the AVIF encoding quality (ranging from 0 to 100, where 70 to 85 offers a strong balance of quality and file size).
  • -define heic:speed=4: Sets encoding CPU effort (values typically range from 0 to 9, where lower values yield slower encoding with tighter compression).

Batch Processing Multiple AVIF Files

To apply the same hue shift across multiple AVIF files within a directory, utilize ImageMagick's mogrify tool.

Create a separate output directory first to avoid overwriting original assets:

mkdir modified_avif
magick mogrify -path modified_avif -modulate 100,100,160 *.avif

This command processes every .avif file in the current directory, alters the hue to the specified target, and writes the resulting images to the modified_avif directory.
