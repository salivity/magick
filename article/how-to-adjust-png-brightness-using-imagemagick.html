How to Adjust PNG Brightness Using ImageMagick?

Adjusting the brightness of a PNG image using ImageMagick can be done quickly from the command line using tools like -modulate, -brightness-contrast, or -evaluate. Depending on whether you use ImageMagick version 6 (convert) or version 7 (magick), these options give you precise control over overall illumination, linear exposure, and midtone retention while preserving PNG transparency.

1. Using the -modulate Option

The most common method to change brightness while preserving color balance is the -modulate operator. It adjusts Brightness, Saturation, and Hue using percentages, where 100% represents the unchanged default.

To increase brightness by 20%:

magick input.png -modulate 120,100,100 output.png

To decrease brightness by 25%:

magick input.png -modulate 75,100,100 output.png

If you only pass one value (e.g., -modulate 120), ImageMagick applies it strictly to brightness and leaves saturation and hue at 100%.

2. Using the -brightness-contrast Operator

If you prefer adjusting brightness on a scale similar to standard photo editors, use -brightness-contrast. This operator accepts values typically between -100 and 100, where 0 indicates no change.

To increase brightness by 15 without altering contrast:

magick input.png -brightness-contrast 15x0 output.png

To darken the image and slightly increase contrast:

magick input.png -brightness-contrast -20x10 output.png

3. Using the -evaluate Operator for Direct Channel Scaling

For a simple linear brightness boost, the -evaluate Multiply operation scales pixel values across the color channels directly:

magick input.png -evaluate Multiply 1.2 output.png

A value greater than 1.0 brightens the image, while a fraction (e.g., 0.8) darkens it.

Handling ImageMagick 6 vs. ImageMagick 7

  • ImageMagick 7: Use the modern magick command as shown above.
  • ImageMagick 6: Replace magick with convert (e.g., convert input.png -modulate 115 output.png).

Preserving Alpha Transparency

PNG files often contain an alpha channel. If an operation unintentionally shifts transparency, isolate the RGB channels before applying adjustments:

magick input.png -channel RGB -modulate 120 +channel output.png

The +channel switch resets the active channel selection to ensure the final PNG writes correctly with transparent areas intact.
