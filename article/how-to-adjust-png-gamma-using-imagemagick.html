How to Adjust PNG Gamma Using ImageMagick?

Adjusting the gamma of a PNG image using ImageMagick is a straightforward task done via the command line with the -gamma operator. Gamma correction modifies the midtone luminance of an image without altering the absolute black or white reference points, making it ideal for brightening underexposed details or toning down washed-out images. By targeting either the overall image or individual RGB color channels, you can quickly achieve balanced contrast and accurate color presentation directly through the terminal.

Understanding the Gamma Operator

ImageMagick provides the -gamma option to apply a power-law transformation to pixel values. The syntax interprets values relative to 1.0, which acts as the neutral default:

  • Values greater than 1.0 (e.g., 1.5, 2.2): Brighten the midtones while preserving shadows and highlights.
  • Values less than 1.0 (e.g., 0.7, 0.5): Darken the midtones.
  • A value of 1.0: Leaves the luminance curve unchanged.

Unlike adjusting brightness or linear exposure, gamma adjustment preserves true black (0) and true white (255 in 8-bit depth), preventing the clipping or flattening of extreme values.

Basic Gamma Adjustment Commands

Depending on the version of ImageMagick installed on your system, the command-line interface uses either magick (ImageMagick 7) or convert (ImageMagick 6).

For ImageMagick 7 (Recommended)

To brighten an image:

magick input.png -gamma 1.6 output.png

To darken an image:

magick input.png -gamma 0.7 output.png

For ImageMagick 6

convert input.png -gamma 1.6 output.png

In both examples, ImageMagick reads the source file input.png, applies the non-linear gamma curve across all color channels uniformly, and writes the corrected image to output.png.

Adjusting Individual Color Channels

Gamma adjustments do not need to be uniform across the entire image. You can specify different gamma values for individual color channels using comma-separated values:

magick input.png -gamma 1.2,1.0,0.8 output.png

The arguments correspond to the Red, Green, and Blue channels in order:

  • Red: Adjusted to 1.2 (brightened)
  • Green: Set to 1.0 (unaltered)
  • Blue: Adjusted to 0.8 (darkened)

This approach is particularly useful for correcting unnatural color casts caused by uneven lighting or legacy display calibration profiles.

Handling PNG Gamma Metadata

PNG files can store an embedded gAMA metadata chunk that instructs image viewers how to render the file based on the display monitor's profile. When ImageMagick edits a PNG, it updates this metadata by default.

If you need to strip embedded color profiles or metadata chunks so the pixel values display identically across all software regardless of profile rendering, combine the -gamma operator with -strip:

magick input.png -gamma 1.5 -strip output.png

Batch Processing Multiple PNG Images

If you need to correct the gamma for an entire directory of PNG files, you can use the mogrify command to apply the operation in place or output them to a designated folder:

magick mogrify -path ./corrected/ -gamma 1.4 *.png

This processes all PNG files in the active directory, applies a gamma correction of 1.4, and saves the modified files into the corrected folder while preserving the original source files.
