How to Adjust PNG Saturation with ImageMagick?

Adjusting the color saturation of a PNG image using ImageMagick can be accomplished quickly via the command line by using the -modulate operator or colorspace transformations. This guide covers the essential syntax for ImageMagick v7 (magick) and v6 (convert), demonstrates how the percentage-based modulate scale functions, and provides practical examples for desaturating, boosting colors, and batch processing multiple PNG files.

Understanding the Modulate Operator

The primary and most straightforward tool for altering saturation in ImageMagick is the -modulate flag. This command accepts three values formatted as:

-modulate brightness[,saturation[,hue]]

When specifying values with -modulate, 100 represents baseline identity (no change). Any values above 100 increase the property, while values below 100 decrease it.

If you only want to change the saturation:

  • Keep brightness at 100.
  • Enter your desired saturation value as the second parameter.
  • Omit the hue parameter entirely (it will remain unchanged at 100).

Basic Command Syntax

ImageMagick Version 7 (Current)

Modern ImageMagick installations use the primary magick binary:

magick input.png -modulate 100,150 output.png

In this command:

  • 100 keeps original brightness intact.
  • 150 increases the saturation by 50%.

ImageMagick Version 6 (Legacy)

Legacy installations typically invoke the convert tool:

convert input.png -modulate 100,150 output.png

Common Saturation Scenarios

Increasing Color Vibrancy

To make colors appear more vivid, set the saturation value anywhere between 110 and 200:

magick photo.png -modulate 100,140 vibrant_photo.png

Muting Colors (Partial Desaturation)

To wash out vivid tones and give a muted, pastel look, set the value between 1 and 99:

magick photo.png -modulate 100,60 muted_photo.png

Converting to Grayscale (Complete Desaturation)

Setting the saturation value to 0 removes all chromatic color, leaving an effective grayscale PNG while preserving the alpha transparency channel:

magick photo.png -modulate 100,0 grayscale.png

Handling PNG Transparency

A common concern when modifying PNGs is preserving alpha channels or partial transparency. The -modulate operator naturally processes the color channels without stripping transparency metadata.

If your input image utilizes indexed color palettes (such as PNG8), convert the image to standard RGBA format before outputting to ensure smooth gradation:

magick input.png -colorspace sRGB -modulate 100,130 PNG32:output.png

Batch Processing Multiple PNG Images

To modify an entire folder of PNG assets simultaneously without overwriting files manually:

Linux / macOS (Bash Loop)

for file in *.png; do
  magick "$file" -modulate 100,125 "saturated_${file}"
done

Windows (PowerShell)

Get-ChildItem -Filter *.png | ForEach-Object {
    magick $_.FullName -modulate 100,125 "saturated_$($_.Name)"
}

Using the -modulate flag gives you exact numeric control over your PNG color profiles while fitting cleanly into automated command-line scripts and build pipelines.
