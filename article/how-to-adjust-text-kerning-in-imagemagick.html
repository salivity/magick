How to Adjust Text Kerning in ImageMagick

Adjusting letter spacing in ImageMagick is handled using the -kerning command-line option. This guide details the proper syntax for applying both positive and negative kerning adjustments when rendering text, complete with practical code examples for ImageMagick v6 and v7 using the label: and -annotate methods.

The -kerning Option

The -kerning option modifies the spacing between characters. It accepts an integer or a floating-point value:

  • Positive values (e.g., -kerning 5) expand the space between characters.
  • Negative values (e.g., -kerning -2) condense the space, pulling letters closer together.
  • Default value is 0, which uses the font's native spacing metrics.

The setting must be placed before the text rendering operator (such as label:, caption:, or -annotate) so ImageMagick can apply the metric before drawing the glyphs.

Syntax for ImageMagick 7

In ImageMagick 7, commands use the magick binary.

Example Using label:

magick -background white -fill black \
       -font Arial -pointsize 48 \
       -kerning 4 \
       label:"SPACED TEXT" \
       output_spaced.png

Example Using -annotate

magick -size 600x150 xc:white -fill black \
       -font Helvetica -pointsize 36 \
       -kerning -1.5 \
       -gravity center -annotate 0 "TIGHT TEXT" \
       output_tight.png

Syntax for ImageMagick 6

In ImageMagick 6, use the legacy convert command:

convert -background lightblue -fill navy \
        -font DejaVu-Sans -pointsize 40 \
        -kerning 8 \
        label:"EXPANDED" \
        output_im6.png

Key Considerations

  • Font Compatibility: The -kerning option works with TrueType (.ttf) and OpenType (.otf) vector fonts.
  • Negative Kerning Limits: Excessive negative kerning can cause glyphs to overlap or clip against the image boundary if canvas sizes are tightly bounded.
  • Resetting Kerning: If rendering multiple text elements within the same command pipeline, reset the spacing back to default by setting -kerning 0 before the subsequent text layer.
