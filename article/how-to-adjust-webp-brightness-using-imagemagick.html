How to Adjust WebP Brightness Using ImageMagick?

Adjusting the brightness of a WebP image using ImageMagick can be achieved through command-line operations using either the -modulate or -evaluate multiply flags. This guide explains how to increase or decrease the luminance of individual files or entire batches of WebP images, details the key syntax options, and outlines best practices to prevent unintended color distortion or quality loss during the conversion process.

Prerequisites and Compatibility

Before executing brightness transformations, ensure that your installed version of ImageMagick includes built-in support for the WebP format.

To verify your installation, run the delegate check in your terminal:

magick -version

Look for webp under the Delegates (built-in) line. If you are using ImageMagick 6, replace magick with convert for the commands listed throughout this guide.

Method 1: Using the -modulate Operator

The -modulate operator adjusts brightness, saturation, and hue simultaneously using a percentage scale where 100 represents the original, unchanged baseline.

Increasing Brightness

To increase image brightness by 20%, set the brightness parameter to 120:

magick input.webp -modulate 120,100,100 output.webp
  • The first value (120) modifies brightness.
  • The second value (100) keeps saturation unchanged.
  • The third value (100) preserves the existing hue.

If you omit the trailing values, ImageMagick defaults saturation and hue to 100%:

magick input.webp -modulate 120 output.webp

Decreasing Brightness

To reduce brightness by 25%, lower the first value to 75:

magick input.webp -modulate 75,100,100 output.webp

Method 2: Using the -evaluate multiply Operator

The -evaluate multiply operator applies a mathematical multiplier directly to color channel values. This method provides linear luminance scaling across pixel values.

Increasing Brightness

To brighten the image by a factor of 1.2:

magick input.webp -evaluate multiply 1.2 output.webp

Decreasing Brightness

To darken the image to 80% of its original level:

magick input.webp -evaluate multiply 0.8 output.webp

Note that multiplying directly can cause highlight clipping if pixel values exceed the maximum threshold for the color channel.

Controlling Output Quality and Compression

When rewriting to the WebP format, ImageMagick applies default compression settings unless explicitly configured. You can specify whether the output should use lossy or lossless compression along with an explicit quality factor using the -quality and -define flags.

magick input.webp -modulate 115 -quality 85 output.webp

For bit-exact, lossless WebP output:

magick input.webp -modulate 110 -define webp:lossless=true output.webp

Batch Processing Multiple WebP Images

To adjust the brightness of multiple WebP files within a directory simultaneously, use ImageMagick's mogrify tool. The following command increases the brightness of every .webp file in the working directory by 15%:

magick mogrify -modulate 115,100,100 *.webp

Because mogrify overwrites existing files in place, create a backup or specify an alternative output directory using the -path flag prior to execution:

magick mogrify -path ./brightened -modulate 115,100,100 *.webp
