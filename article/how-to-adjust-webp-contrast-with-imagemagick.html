How to Adjust WebP Contrast with ImageMagick?

Adjusting the contrast of a WebP image using ImageMagick can be accomplished quickly via the command line using operations like sigmoid-contrast, brightness-contrast, or level adjustments. ImageMagick natively supports the WebP format, allowing you to read, modify tone curves, and output high-quality compressed images without complex multi-step conversions.

Prerequisites and Verification

Before processing your files, ensure your ImageMagick build has WebP delegate support compiled in. You can confirm this by checking your installed delegates:

magick -version

Look for webp in the Delegates (built-in) list. Note that ImageMagick 7 uses the magick command, while ImageMagick 6 uses convert. The examples below use the modern magick syntax.

Recommended Method: Sigmoidal Contrast

The -sigmoidal-contrast operator provides smooth, natural contrast enhancement without abruptly clipping shadow or highlight detail. It adjusts contrast along an S-curve defined by two values: contrast factor and mid-point.

To increase contrast:

magick input.webp -sigmoidal-contrast 5x50% output.webp

In this command:

  • 5 represents the intensity of the contrast adjustment. Higher numbers yield stronger contrast, while lower numbers produce subtler changes.
  • 50% designates the mid-point around which tones expand. A 50% value preserves overall midtone balance.

To decrease contrast instead, prefix the flag with a plus sign:

magick input.webp +sigmoidal-contrast 5x50% output.webp

Linear Adjustments: Brightness and Contrast

If you need a straightforward linear shift, the -brightness-contrast operator provides familiar controls similar to standard graphic editors:

magick input.webp -brightness-contrast 0x20 output.webp

The parameter format is {brightness}x{contrast}:

  • 0 leaves the overall brightness unchanged.
  • 20 increases contrast by 20 percent. Negative values reduce contrast.

Histogram Stretching: The Level Operator

For images that appear flat due to poor dynamic range, stretching the tonal histogram often yields the best results:

magick input.webp -auto-level output.webp

The -auto-level flag automatically maps the darkest pixel in the input to pure black and the lightest pixel to pure white.

If you prefer manual control over white, black, and gamma points, use -level:

magick input.webp -level 10%,90%,1.0 output.webp

This sets all pixels at or below 10% brightness to black, all pixels at or above 90% brightness to white, and applies a gamma correction of 1.0 to midtones.

Preserving WebP Compression Settings

When writing output back to WebP format, ImageMagick applies default compression unless configured otherwise. To retain fine details and control output size, specify the quality flag:

magick input.webp -sigmoidal-contrast 4x50% -quality 85 output.webp

For completely lossless output, append the -define flag:

magick input.webp -sigmoidal-contrast 4x50% -define webp:lossless=true output.webp

Batch Processing WebP Files

To adjust contrast across an entire folder of WebP images simultaneously, use the mogrify utility:

magick mogrify -path ./processed -sigmoidal-contrast 5x50% -quality 85 *.webp

This applies the contrast curve to every .webp file in the current directory and writes the updated files into a subdirectory named processed, preventing accidental overwrites of original assets.
