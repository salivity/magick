How to Apply 3D LUT Cube Files in ImageMagick

This guide explains how to apply 3D Look-Up Table (.cube) color grading files to images using modern releases of ImageMagick (version 7 and newer). You will learn the direct command-line syntax to apply a LUT, how to convert .cube files into Hald-CLUT PNG format for faster batch processing, and how to maintain color precision throughout the transformation.

Direct 3D LUT Application

Modern ImageMagick installations feature built-in support for reading the Adobe 3D Cube format. You can apply a .cube file directly to an input image by passing both files to the magick command and executing the -hald-clut operator.

Run the following command in your terminal:

magick input.jpg lut.cube -hald-clut output.jpg

In this command:

  • input.jpg is your source image.
  • lut.cube is your 3D LUT file.
  • -hald-clut processes the .cube data internally as a 3D color lookup table and applies the color grading to input.jpg.
  • output.jpg is the final graded image.

Creating and Using a Hald-CLUT PNG

Parsing a text-based .cube file on every execution can add CPU overhead when processing multiple files. To optimize batch workflows, convert the .cube file into an intermediate Hald-CLUT image (such as an uncompressed PNG or TIFF).

1. Convert the .cube File to an Image

magick lut.cube hald_lut.png

2. Apply the Converted Hald-CLUT Image

magick input.jpg hald_lut.png -hald-clut output.jpg

This two-step method yields identical color grading to the direct .cube method while significantly speeding up execution times for high-volume jobs.

Batch Processing Multiple Images

To apply the same .cube file across an entire directory of images, use ImageMagick's mogrify command or a shell loop.

Using magick mogrify with a Hald-CLUT PNG

magick mogrify -path ./graded_output -hald-clut hald_lut.png *.jpg

Using a Bash Loop

for img in *.jpg; do
    magick "$img" lut.cube -hald-clut "graded_${img}"
done

Maintaining Bit Depth and Color Precision

To prevent banding or clipping artifacts—especially in smooth gradients or dark tones—ensure that ImageMagick operates with sufficient bit depth and proper color space settings:

  1. Use 16-bit Depth: Modern ImageMagick builds default to Q16 (16 bits per channel). Explicitly define depth when saving to formats like PNG or TIFF:

    magick input.png lut.cube -depth 16 -hald-clut output.png

  2. Match Color Profiles: 3D LUTs are generated for specific color profiles (typically sRGB or Rec.709). Ensure your input image is converted to the intended color profile before applying the LUT to avoid unexpected tinting or incorrect contrast levels:

    magick input.jpg -colorspace sRGB lut.cube -hald-clut output.jpg
