How to Apply a Sobel Filter in ImageMagick

This article provides a direct guide on implementing the Sobel edge detection filter in ImageMagick using the convolution operator. You will learn the specific kernel matrices for horizontal and vertical gradient detection, how to execute them using the command-line interface, and how to combine both directions to generate a complete edge-detected image.

Understanding the Sobel Kernels

The Sobel filter computes the image gradient magnitude at each pixel by convolving the image with two 3×3 kernels: one for horizontal changes (\(G_x\)) and one for vertical changes (\(G_y\)).

Horizontal Kernel (\(G_x\)):

-1  0  1
-2  0  2
-1  0  1

Vertical Kernel (\(G_y\)):

-1 -2 -1
 0  0  0
 1  2  1

Applying Horizontal and Vertical Convolution

In ImageMagick, you define custom 3×3 convolution matrices using the -morphology Convolve operator or the legacy -convolve operator.

To compute the horizontal gradient:

magick input.jpg -colorspace Gray -morphology Convolve '3x3: -1, 0, 1, -2, 0, 2, -1, 0, 1' sobel_x.png

To compute the vertical gradient:

magick input.jpg -colorspace Gray -morphology Convolve '3x3: -1, -2, -1, 0, 0, 0, 1, 2, 1' sobel_y.png

Generating the Complete Sobel Edge Detection

To produce a full edge map, both gradients are computed, squared, added together, and square-rooted (\(\sqrt{G_x^2 + G_y^2}\)). You can perform this in a single ImageMagick command:

magick input.jpg -colorspace Gray \
  \( -clone 0 -morphology Convolve '3x3: -1, 0, 1, -2, 0, 2, -1, 0, 1' -evaluate Pow 2 \) \
  \( -clone 0 -morphology Convolve '3x3: -1, -2, -1, 0, 0, 0, 1, 2, 1' -evaluate Pow 2 \) \
  -delete 0 \
  -evaluate-sequence Add \
  -evaluate Pow 0.5 \
  sobel_edge_detected.png

Explanation of the Steps

  1. -colorspace Gray: Converts the source image to grayscale, which is required for standard intensity-based edge detection.
  2. \( -clone 0 ... \): Creates isolated branches to process the horizontal and vertical convolution passes independently.
  3. -evaluate Pow 2: Squares the pixel values for each gradient axis.
  4. -delete 0: Removes the original grayscale input, leaving only the processed \(G_x^2\) and \(G_y^2\) layers.
  5. -evaluate-sequence Add: Sums the squared horizontal and vertical gradient components.
  6. -evaluate Pow 0.5: Takes the square root of the sum to produce the final gradient magnitude.
