How to Apply Affine Transformation in ImageMagick

This guide explains how to apply a 2D affine transformation matrix to an image using ImageMagick from the command line. You will learn the standard 6-element matrix format, the primary ImageMagick operators used to execute the transformation, and practical examples covering scaling, rotation, shearing, and translation.

The Affine Matrix Structure

An affine transformation maps coordinate points \((x, y)\) to new coordinates \((x', y')\) while preserving straight lines and parallelism. In 2D graphics, this is represented by a \(3 \times 3\) matrix with 6 adjustable parameters:

\[ \begin{bmatrix} x' \\ y' \\ 1 \end{bmatrix} = \begin{bmatrix} sx & rx & tx \\ ry & sy & ty \\ 0 & 0 & 1 \end{bmatrix} \begin{bmatrix} x \\ y \\ 1 \end{bmatrix} \]

The parameters represent:

  • sx: Horizontal scaling
  • rx: Horizontal shearing (or rotation component)
  • ry: Vertical shearing (or rotation component)
  • sy: Vertical scaling
  • tx: Horizontal translation (X offset in pixels)
  • ty: Vertical translation (Y offset in pixels)

Method 1: Using -distort AffineProjection (Recommended)

The -distort AffineProjection operator is the preferred method in modern ImageMagick (ImageMagick 6 and 7). It automatically recalculates the output canvas dimensions and applies high-quality area resampling (anti-aliasing).

Syntax

magick input.png -distort AffineProjection "sx, rx, ry, sy, tx, ty" output.png

(For ImageMagick 6, replace magick with convert.)

Matrix Arguments

Pass the coefficients as a comma- or space-delimited string: "sx, rx, ry, sy, tx, ty".

Method 2: Using -affine and -transform (Legacy)

The classic approach sets the internal affine matrix state with -affine and applies it with -transform.

Syntax

magick input.png -affine sx,rx,ry,sy,tx,ty -transform output.png

Note: The -transform operator can crop parts of the image that fall outside original bounds unless explicit canvas adjustments are made.

Practical Examples

1. Pure Translation (Shift by 50px X, 100px Y)

  • Identity scale (sx=1, sy=1), no shear (rx=0, ry=0), translation (tx=50, ty=100):
magick input.png -distort AffineProjection "1.0, 0.0, 0.0, 1.0, 50, 100" output.png

2. Scaling (2x Width, 0.5x Height)

  • Scale factors (sx=2.0, sy=0.5):
magick input.png -distort AffineProjection "2.0, 0.0, 0.0, 0.5, 0, 0" output.png

3. Horizontal Shear

  • Shear factor along the X-axis (rx=0.3):
magick input.png -distort AffineProjection "1.0, 0.3, 0.0, 1.0, 0, 0" output.png

4. Rotation (30 Degrees Clockwise)

For an angle \(\theta\) (in radians or evaluated directly):

  • \(sx = \cos(\theta) \approx 0.866\)
  • \(rx = \sin(\theta) \approx 0.500\)
  • \(ry = -\sin(\theta) \approx -0.500\)
  • \(sy = \cos(\theta) \approx 0.866\)
magick input.png -distort AffineProjection "0.866, 0.500, -0.500, 0.866, 0, 0" output.png

Controlling the Output Canvas Size

By default, -distort expands the image canvas to fit the transformed result. To retain the exact dimensions and offset of the original image, use the +distort variant:

magick input.png +distort AffineProjection "1.0, 0.2, 0.0, 1.0, 0, 0" output.png
