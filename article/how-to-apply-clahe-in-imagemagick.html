How to Apply CLAHE in ImageMagick

Contrast Limited Adaptive Histogram Equalization (CLAHE) is an advanced image processing technique used to improve local contrast and enhance detail without over-amplifying noise. This guide provides a straightforward overview of how to apply CLAHE using ImageMagick v7, explaining the command syntax, the core parameters, and how to process color images without introducing unwanted color distortion.

The Basic CLAHE Command

ImageMagick provides the native -clahe operator to perform adaptive histogram equalization. The basic command syntax is:

magick input.jpg -clahe <width>x<height>{%}+<bins>+<clip-limit>{%} output.jpg

Example

To apply CLAHE with a tile size of 50x50 pixels, 128 histogram bins, and a clip limit of 3:

magick input.jpg -clahe 50x50+128+3 output.jpg

You can also define tile dimensions as percentages of the image size:

magick input.jpg -clahe 25x25%+256+2% output.jpg

Understanding CLAHE Parameters

The -clahe option takes four values formatted as WidthxHeight+Bins+ClipLimit:

  1. Width x Height (Tile Size): Defines the dimensions of the local grid tiles (contextual regions) into which the image is divided. Smaller regions provide more localized contrast enhancement, while larger regions approach standard global histogram equalization.
  2. Bins (Number of Histogram Bins): Specifies the dynamic range division for the local histogram (commonly set between 128 and 256).
  3. Clip Limit: Sets the threshold for limiting contrast enhancement within each tile. Pixels exceeding this limit are redistributed across other bins before equalization to prevent extreme noise amplification. Higher values yield stronger contrast, while lower values preserve the original tonal distribution.

Applying CLAHE to Color Images

Applying CLAHE directly across standard RGB channels can cause severe color artifacts and tint shifts. To enhance contrast while preserving original colors, apply CLAHE exclusively to the lightness or luminance channel using the LAB colorspace:

magick input.jpg -colorspace LAB -channel 0 -clahe 50x50%+128+3 +channel -colorspace sRGB output.jpg

Breakdown of the Steps:

  • -colorspace LAB: Converts the image to the CIELAB color space.
  • -channel 0: Restricts subsequent operations to the first channel (Lightness/L*).
  • -clahe 50x50%+128+3: Executes CLAHE only on the lightness data.
  • +channel: Resets the channel restriction so all channels are processed together again.
  • -colorspace sRGB: Converts the final output back to standard RGB.
