How to Apply Hald CLUT in ImageMagick

Applying a Hald CLUT (Color Look-Up Table) in ImageMagick is an efficient way to transfer complex color transformations and grading presets across single or batch images. This guide explains how to generate a neutral Hald CLUT identity image, modify it in your photo editing software of choice, and use ImageMagick's command-line tools to apply the resulting color profile to target images.

What is a Hald CLUT?

A Hald CLUT is a 2D image representation of a 3D color cube. It maps every possible color channel combination to a specific coordinate. When you alter the colors of a Hald CLUT image in an editing program and apply it back through ImageMagick, the software maps every pixel of your target image according to the exact same color transformations.

Step 1: Generate a Hald Identity Image

Before applying a color grade, generate a neutral Hald identity image directly via ImageMagick. The number after hald: determines the color depth resolution (level 8 is standard and provides a 512×512 pixel image representing \(64^3\) colors).

Run the following command:

magick hald:8 hald_identity.png

Note: For ImageMagick v6, use convert hald:8 hald_identity.png.

Step 2: Color Grade the Hald Image

Open hald_identity.png in your preferred graphic or photo editing software (such as Adobe Photoshop, Lightroom, GIMP, or DaVinci Resolve) and apply your desired color adjustments, including:

  • Curves and Levels
  • Hue, Saturation, and Lightness adjustments
  • Split toning and color balance
  • 3D LUT presets

Important Rules:

  • Do not resize, crop, rotate, or blur the image.
  • Avoid spatial filters like sharpening, noise reduction, or vignette effects.
  • Save the graded image in a lossless format (such as PNG or TIFF) as hald_graded.png.

Step 3: Apply the Graded Hald CLUT to an Image

Once you have your hald_graded.png, use the -hald-clut operator to apply the grade to any target image:

magick input.jpg hald_graded.png -hald-clut output.jpg

Batch Processing Multiple Images

To apply the same color grade across an entire directory of images, use mogrify or a shell loop.

Using mogrify:

magick mogrify -hald-clut hald_graded.png -path ./output_folder *.jpg

Using a Bash Loop:

for img in *.jpg; do
  magick "$img" hald_graded.png -hald-clut "graded_${img}"
done
