How to Apply Morphological Dilation in ImageMagick

Morphological dilation is an image processing technique that expands bright regions and fills small holes or gaps within an image. In ImageMagick, this operation is performed using the -morphology operator paired with the Dilate method and a chosen structuring element (kernel). This guide explains the core command syntax, the available kernel shapes, and practical examples for applying dilation to both binary and grayscale images.

The Basic Command Syntax

In ImageMagick version 7, use the magick command (or convert for ImageMagick v6) along with the -morphology option:

magick input.png -morphology Dilate KernelShape:Radius output.png
  • Dilate: Specifies the morphological operation.
  • KernelShape: Defines the geometry of the dilation (e.g., Disk, Diamond, Square, Octagon).
  • Radius: Determines the size or reach of the dilation effect in pixels.

Common Structuring Elements (Kernels)

The kernel shape dictates the pattern in which neighboring pixels are evaluated and expanded.

1. Disk Kernel

The Disk kernel produces smooth, rounded edges. It is the most commonly used kernel for natural images and general smoothing.

magick input.png -morphology Dilate Disk:3 output.png

Applies a circular dilation with a 3-pixel radius.

2. Diamond Kernel

The Diamond kernel expands pixels along the 4-connected cardinal directions (up, down, left, right), resulting in diamond-shaped expansions.

magick input.png -morphology Dilate Diamond:2 output.png

3. Square and Rectangle Kernels

The Square kernel expands across an 8-connected grid, creating boxy, sharp-cornered expansions.

magick input.png -morphology Dilate Square:1 output.png

You can also define a non-uniform rectangular kernel using Rectangle:WidthxHeight:

magick input.png -morphology Dilate Rectangle:5x1 output.png

Expands the image purely along the horizontal axis.

Advanced Dilation Techniques

Multiple Iterations

To repeat the dilation multiple times without calculating large radius values, append an iteration count using an integer or > symbol:

magick input.png -morphology Dilate:3 Diamond:1 output.png

Applies a 1-pixel Diamond dilation 3 consecutive times.

Dilation on Multi-Channel Color Images

By default, the dilation operator applies to all active color channels independently. This means brighter color values will expand over darker ones. To restrict the operation to a specific channel (such as the alpha mask or a single color channel), use the -channel flag:

magick input.png -channel A -morphology Dilate Disk:2 +channel output.png

Dilates only the Alpha (transparency) channel by 2 pixels while leaving the RGB color data intact.
