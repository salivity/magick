How to Bulk Convert Images to AVIF Using ImageMagick?

Bulk converting images to AVIF format with ImageMagick allows you to drastically reduce file sizes while maintaining superior visual fidelity. This guide walks through verifying your system's AVIF delegate support, selecting optimal compression settings, and executing batch conversions across folders using ImageMagick’s native tools and shell scripts on Linux, macOS, and Windows.

Verifying AVIF Support in ImageMagick

Before running batch operations, ensure your ImageMagick installation includes the delegate required to encode AVIF files (typically libheif).

Run the following command in your terminal:

magick -list format | grep -i avif

If AVIF is properly supported, the output will list AVIF with read/write permissions (rw+ or rw-). If the output is empty, update your ImageMagick build or install libheif support via your operating system's package manager.

Key AVIF Compression Parameters

AVIF encoding can be resource-intensive. Fine-tuning quality and speed flags ensures fast processing without compromising visual clarity:

  • -quality [0-100]: Sets the compression level. A quality setting between 50 and 65 generally yields smaller sizes than standard JPEGs while retaining sharp detail.
  • -define heic:speed=[0-9]: Controls encoding effort. Higher numbers (such as 6 to 8) encode significantly faster with minor trade-offs in compression ratio, making them ideal for large batches.

Bulk Converting with mogrify

The quickest way to convert an entire directory in-place is using ImageMagick’s mogrify command. This tool processes multiple files matching a specific pattern without requiring explicit loops.

To convert all JPEG and PNG files in the current folder:

magick mogrify -format avif -quality 60 -define heic:speed=6 *.jpg *.jpeg *.png

This command generates an .avif duplicate for each source file in the same directory, leaving the original source files intact.

Batch Processing via Shell Loops (Linux and macOS)

When you need to output converted files to a dedicated folder or recursively traverse subdirectories, a Bash for loop provides greater control.

Converting to a Dedicated Output Folder

mkdir -p avif_output

for img in *.{jpg,jpeg,png}; do
  [ -f "$img" ] || continue
  magick "$img" -quality 60 -define heic:speed=6 "avif_output/${img%.*}.avif"
done

Recursive Directory Conversion

To process nested folders while preserving directory structure:

find . -type f \( -iname "*.jpg" -o -iname "*.png" \) | while read -r img; do
  magick "$img" -quality 60 -define heic:speed=6 "${img%.*}.avif"
done

Batch Processing on Windows

Windows users can automate bulk conversions using Command Prompt or PowerShell.

Using Windows Command Prompt

Run this command inside your target directory:

for %i in (*.jpg *.png) do magick "%i" -quality 60 -define heic:speed=6 "%~ni.avif"

If you are using this command inside a .bat file, double the percent signs (%%i and %%~ni).

Using Windows PowerShell

PowerShell offers a flexible syntax for modern batch workflows:

Get-ChildItem -Include *.jpg, *.png -File | ForEach-Object {
    $out = [System.IO.Path]::ChangeExtension($_.FullName, ".avif")
    magick $_.FullName -quality 60 -define heic:speed=6 $out
}

Optimizing Multi-Threaded Performance

AVIF encoding benefits heavily from parallel execution. If you have hundreds or thousands of files, running conversions sequentially can take significant time.

On Linux and macOS, combine ImageMagick with xargs to distribute tasks across all CPU cores:

find . -maxdepth 1 -type f \( -iname "*.jpg" -o -iname "*.png" \) | xargs -P "$(nproc)" -I {} sh -c 'magick "$1" -quality 60 -define heic:speed=6 "${1%.*}.avif"' _ {}

This approach maximizes CPU utilization, reducing total conversion time across massive image libraries.
