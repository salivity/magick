How to Bulk Convert Images to PNG Using ImageMagick?

Converting large batches of images to PNG format is simple and efficient using ImageMagick on the command line. Whether you are working with JPG, WEBP, or TIFF files, ImageMagick provides dedicated batch tools like mogrify for in-place conversions, as well as native shell loops with magick for preserving original files. This guide covers how to convert entire directories of images, maintain source assets, and apply compression settings to optimize the resulting PNG files.

Prerequisites and Syntax Overview

Before running conversion commands, ensure ImageMagick is installed on your system. You can verify your installation by running magick -version in your terminal or command prompt.

ImageMagick 7 uses the magick command line interface, alongside utility tools like magick mogrify. Understanding the difference between magick and mogrify determines whether your original images will be replaced or preserved:

  • mogrify: Designed specifically for batch processing. It can convert multiple files in a single pass without needing a shell loop, but it overwrites or alters files in place if not redirected to an output directory.
  • magick: Designed for processing individual operations. When paired with a bash or PowerShell loop, it offers granular control over output naming and destination paths.

Method 1: Using mogrify for Fast In-Place Batch Conversion

The fastest method to convert every image of a specific format inside a directory is with the mogrify command.

To convert all JPG images in your current working directory to PNG:

magick mogrify -format png *.jpg

This scans for all files ending in .jpg, generates an equivalent file with a .png extension, and leaves the original .jpg files intact alongside the new files.

If you want to place the newly created PNG files into a dedicated directory to keep your folder organized, create a target directory and pass the -path flag:

mkdir converted_pngs
magick mogrify -path converted_pngs -format png *.jpg

Method 2: Batch Converting via Shell Loops

When you have mixed formats (such as converting both .jpeg and .webp at the same time) or want clear logging per file, a shell loop using the standard magick command is the most robust approach.

Linux and macOS (Bash/Zsh)

Run this loop in your terminal to process all .jpg and .webp files:

mkdir -p png_output
for img in *.{jpg,jpeg,webp}; do
  [ -f "$img" ] || continue
  magick "$img" "png_output/${img%.*}.png"
done

Windows (PowerShell)

In PowerShell, use Get-ChildItem to iterate through matching images:

New-Item -ItemType Directory -Force -Path .\png_output
Get-ChildItem -Include *.jpg, *.jpeg, *.webp -File | ForEach-Object {
    $outPath = Join-Path .\png_output ($_.BaseName + ".png")
    magick $_.FullName $outPath
}

Optimizing PNG Output Quality and Compression

PNG is a lossless compression format, but ImageMagick allows you to adjust the compression level and strip unnecessary metadata to reduce overall file sizes without degrading pixel quality.

You can append the -strip flag to remove camera profiles, timestamps, and EXIF metadata, alongside -quality to tune compression:

magick mogrify -path converted_pngs -strip -quality 95 -format png *.jpg

For PNG files in ImageMagick, the quality setting uses a two-digit notation where the tens digit defines the zlib compression level (0 to 9) and the units digit defines the filter type. A setting of 95 applies high zlib compression with adaptive filtering, creating compact PNG images suitable for web and storage use.
