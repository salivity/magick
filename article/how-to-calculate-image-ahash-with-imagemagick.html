How to Calculate Image aHash with ImageMagick

An Average Hash (aHash) is a perceptual hashing algorithm that creates a compact 64-bit fingerprint of an image based on its low-frequency visual structure. Calculating an aHash using ImageMagick involves resizing the image to an 8x8 grid, converting it to grayscale, determining the mean pixel brightness, and thresholding each pixel against that mean to generate a 64-bit binary value represented as a 16-character hexadecimal string.

The aHash Algorithm Steps

The average hash algorithm follows four deterministic steps:

  1. Reduce dimensions: Scale the image down to an 8x8 square (64 total pixels) to discard high-frequency details.
  2. Reduce color: Convert the 8x8 image to grayscale to focus solely on luminance.
  3. Compute the mean: Calculate the average luminance of all 64 pixels.
  4. Binarize and encode: Set each pixel to 1 if its value is greater than or equal to the average, or 0 if it is below. The resulting 64 bits are grouped into 8 bytes and converted to hexadecimal.

The ImageMagick Command

You can compute the full aHash in a single terminal pipeline using ImageMagick 7 and xxd (or any equivalent hex dumper):

magick input.jpg -resize 8x8! -colorspace Gray \
  -threshold "%[fx:mean*100]%" -depth 1 mono:- | xxd -p

For ImageMagick 6, replace magick with convert:

convert input.jpg -resize 8x8! -colorspace Gray \
  -threshold "%[fx:mean*100]%" -depth 1 mono:- | xxd -p

Command Breakdown

  • input.jpg: The source image file.
  • -resize 8x8!: Forces the image dimensions to exactly 8x8 pixels. The exclamation mark (!) ignores the original aspect ratio so the image maps directly to an 8x8 matrix.
  • -colorspace Gray: Converts the color profile to single-channel 8-bit grayscale.
  • -threshold "%[fx:mean*100]%": Evaluates the image's overall mean luminance using ImageMagick's built-in FX expression parser (%[fx:mean*100]%) and thresholds the pixels dynamically. Pixels above or equal to the mean become white (1), and pixels below become black (0).
  • -depth 1 mono:-: Packs the 64 binary pixels into raw 1-bit format (8 bytes total) and streams the raw binary output directly to stdout.
  • | xxd -p: Reads the raw 8 bytes from standard input and prints the final 16-character hexadecimal hash string.

Comparing Two Hashes

To determine how similar two images are, compare their hashes using the Hamming distance (the count of positions at which the corresponding bits differ). A Hamming distance of 0 denotes an identical or nearly identical image structure, while a distance between 1 and 10 generally indicates slight variations, edits, or re-encodings of the same source image.
