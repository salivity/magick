How to Calculate Image Entropy Using ImageMagick

Image entropy is a statistical measure of randomness used to quantify the information density, complexity, and texture detail within an image. This guide demonstrates how to calculate Shannon entropy using ImageMagick via the command line, how to extract per-channel and overall values, and how to interpret the resulting metrics for image analysis.

Understanding Image Entropy

In digital image processing, entropy measures the degree of randomness or uncertainty in pixel intensity distributions.

  • Low Entropy: Indicates an image with uniform regions, low detail, or large flat areas (e.g., a clear sky or a solid background).
  • High Entropy: Indicates high visual complexity, rich textures, sharp edges, or noise.

ImageMagick normalizes entropy values to a range between 0.0 (minimum information density/completely uniform) and 1.0 (maximum information density/pure random noise).

Basic Command to Calculate Entropy

ImageMagick allows you to query image properties directly using the -format flag with the %[entropy] property string.

For ImageMagick v7, run:

magick input.jpg -format "%[entropy]\n" info:

For ImageMagick v6, run:

identify -format "%[entropy]\n" input.jpg

This command outputs a single floating-point number representing the overall normalized entropy of the image.

Calculating Per-Channel and Grayscale Entropy

Entropy can be calculated across all color channels combined, per individual color channel, or converted to grayscale for a single luminance-based measurement.

1. Per-Channel Entropy

To see the entropy breakdown for each color channel (Red, Green, Blue, Alpha), use the -verbose flag:

magick identify -verbose input.jpg | grep -A 6 "Entropy:"

The output will display the individual entropy values for each channel along with the combined overall metric:

Entropy:
  Red: 0.841235
  Green: 0.812490
  Blue: 0.795112
  Overall: 0.816279

2. Grayscale Entropy (Luminance Density)

If you need a single metric based strictly on light and dark variation rather than color separation, convert the image to grayscale before computing:

magick input.jpg -colorspace Gray -format "%[entropy]\n" info:

Interpreting the Results

  • 0.00 – 0.30: Very low density. Simple graphics, flat vector artwork, or near-solid backgrounds.
  • 0.31 – 0.70: Moderate density. Standard portrait photography or images with smooth gradients and focused subjects.
  • 0.71 – 0.95: High density. Highly detailed photographs such as foliage, urban landscapes, or textured fabrics.
  • 0.96 – 1.00: Extreme density. High-frequency digital noise, heavy film grain, or uncompressed random static.

Automating Entropy Checks with a Shell Script

You can use the entropy value inside shell scripts to automatically filter out blank or corrupt images:

#!/bin/bash

IMAGE="input.jpg"
THRESHOLD=0.10

ENTROPY=$(magick "$IMAGE" -format "%[entropy]" info:)

echo "Calculated Entropy: $ENTROPY"

if (( $(echo "$ENTROPY < $THRESHOLD" | bc -l) )); then
    echo "Warning: Image has low information density and may be blank."
else
    echo "Image contains sufficient detail."
fi
