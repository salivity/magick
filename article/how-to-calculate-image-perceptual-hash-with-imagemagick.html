How to Calculate Image Perceptual Hash with ImageMagick

This article provides a concise guide on using ImageMagick to calculate the perceptual hash (pHash) of an image. Perceptual hashing generates a fingerprint based on visual features rather than exact pixel data, making it an effective method for identifying visually similar or duplicate images despite resizing, compression, or minor color adjustments.

The Perceptual Hash Command

To extract the perceptual hash string directly, use the identify command with the %[phash] format specifier.

For ImageMagick 7 (Recommended)

magick identify -format "%[phash]\n" input.jpg

Alternatively:

magick input.jpg -format "%[phash]\n" info:

For ImageMagick 6

identify -format "%[phash]\n" input.jpg

This output produces a 42-character alphanumeric string representing the color and spatial frequency characteristics of the image.

Viewing Full Perceptual Moments

If you require the detailed numerical data behind the hash (such as color channels and invariant moment values), use the -moments flag:

magick identify -verbose -moments input.jpg

Look for the PHash section in the output, which breaks down the visual hash across separate color channels (such as Red, Green, Blue, or Luma/Chroma).

Comparing Two Images Using Perceptual Hash

To directly measure the visual difference between two images using perceptual hashing, use the compare command with the phash metric:

magick compare -metric phash image1.jpg image2.jpg null:

Interpreting the Output

  • 0: The images are perceptually identical.
  • Low values (e.g., < 0.05): The images have minor visual differences (e.g., compression artifacts or minor scaling).
  • High values: The images are noticeably different or completely distinct.
