How to Calculate MAE Using ImageMagick Compare

Mean Absolute Error (MAE) measures the average magnitude of pixel-by-pixel errors between two images without considering their direction. This article provides the exact syntax and usage guidelines for calculating the MAE metric using ImageMagick's compare tool, enabling automated image quality verification, visual regression testing, and image processing analysis.

Basic Syntax

To evaluate the Mean Absolute Error between two images, use the -metric MAE parameter with the compare command.

ImageMagick Version 7:

magick compare -metric MAE image1.png image2.png difference.png

ImageMagick Version 6:

compare -metric MAE image1.png image2.png difference.png

Command Parameters

  • -metric MAE: Specifies Mean Absolute Error as the comparison metric.
  • image1.png: The reference/original image.
  • image2.png: The modified/reconstructed image to compare against the reference.
  • difference.png: The output visual difference map showing where pixel values diverge.

Outputting Numerical Values Without an Image File

If you only need the numerical MAE value without saving a difference image to disk, redirect the output image to null: (on Linux/macOS) or NULL: (on Windows):

magick compare -metric MAE image1.png image2.png null:

Understanding the Output

ImageMagick prints the calculated MAE to the standard error stream (stderr). The output typically appears in this format:

2550 (0.0389105)
  1. Absolute Value (First Number): Represents the raw sum of absolute differences divided by the total pixel count across all channels, scaled to the quantum depth of your ImageMagick build (e.g., Q16 = 0 to 65,535).
  2. Normalized Value (In Parentheses): Represents the MAE normalized to a floating-point range between 0.0 (identical images) and 1.0 (maximum possible difference).
