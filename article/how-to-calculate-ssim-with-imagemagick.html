How to Calculate SSIM with ImageMagick

Measuring image quality and compression artifacts using the Structural Similarity Index Measure (SSIM) is a standard method for evaluating perceived visual fidelity. This guide explains how to use ImageMagick's compare tool to compute the SSIM score between two images, interpret the output metrics, and automate the process without generating unnecessary difference files.

Prerequisites

To calculate SSIM, ensure both images have identical pixel dimensions (width and height). ImageMagick will produce an error if the dimensions do not match.

The Basic SSIM Command

ImageMagick includes a dedicated -metric parameter to run SSIM comparisons.

For ImageMagick 7, use the magick compare command:

magick compare -metric SSIM reference.png target.png diff.png

For ImageMagick 6, use:

compare -metric SSIM reference.png target.png diff.png

In this command:

  • reference.png is the original image.
  • target.png is the modified or compressed image.
  • diff.png is the output image visually highlighting where structural differences occur.

ImageMagick prints the SSIM score directly to standard error (stderr).

Getting the Score Without Creating an Output Image

If you only need the numerical SSIM value and do not want to save a visual difference image, redirect the output to null::

magick compare -metric SSIM reference.png target.png null:

On Windows, use NULL: instead:

magick compare -metric SSIM reference.png target.png NULL:

Interpreting the Output

The SSIM score returned by ImageMagick is a floating-point number typically ranging between 0 and 1:

  • 1.0: Perfect match; the images are structurally identical.
  • 0.90 to 0.99: High visual similarity; differences are minor and often imperceptible.
  • < 0.80: Significant visual distortion or noticeable differences.

Using DSSIM (Structural Dissimilarity)

ImageMagick also supports DSSIM, which measures dissimilarity rather than similarity:

magick compare -metric DSSIM reference.png target.png null:

With DSSIM:

  • 0.0: The images are identical.
  • Values > 0.0: Larger numbers represent greater divergence between the images.

Comparing Images of Different Sizes

If the two images have different resolutions, resize the secondary image on the fly using ImageMagick before running the metric:

magick compare -metric SSIM reference.png target.png[x1000] diff.png

Alternatively, resize the images explicitly beforehand so that their aspect ratios and dimensions match perfectly.
