How to Change PPI and PPCM in ImageMagick

Changing the spatial resolution units between pixels-per-inch (PPI) and pixels-per-centimeter (PPCM) in ImageMagick is essential for preparing digital assets for specific print layouts and digital standards. This guide explains how to use the -units and -density flags to switch resolution measurement units, recalculate density values, and verify the metadata of your image files directly from the command line.

Understanding the -units Option

ImageMagick provides the -units flag to define how the spatial resolution (density) of an image is measured. The two primary values used for spatial resolution are:

  • PixelsPerInch (PPI)
  • PixelsPerCentimeter (PPCM)

When adjusting units, ImageMagick does not automatically recalculate the numerical -density value. Therefore, you must specify both the target unit and the corresponding density value to ensure the physical dimensions remain accurate.

Converting Resolution Units

To change resolution units, calculate the density conversion (1 inch = 2.54 centimeters) and apply both the -units and -density flags.

1. Converting Pixels-per-Inch to Pixels-per-Centimeter

To convert a standard 300 PPI image to PPCM, divide 300 by 2.54, which equals approximately 118.11 PPCM.

magick input.jpg -units PixelsPerCentimeter -density 118.11 output.jpg

For legacy ImageMagick versions (ImageMagick 6), use convert:

convert input.jpg -units PixelsPerCentimeter -density 118.11 output.jpg

2. Converting Pixels-per-Centimeter to Pixels-per-Inch

To convert an image defined at 118.11 PPCM back to PPI, multiply by 2.54 to get 300 PPI.

magick input.jpg -units PixelsPerInch -density 300 output.jpg

Resampling vs. Changing Metadata

  • Metadata Only (-density): The commands above alter only the metadata tags of the image without changing the actual pixel dimensions (width and height in pixels remain the same).
  • Pixel Resampling (-resample): If you want to change the physical resolution while automatically adjusting the total pixel count to maintain the current print dimensions, use the -resample flag along with -units:
magick input.jpg -units PixelsPerCentimeter -resample 118.11 output.jpg

Verifying the Spatial Resolution

To confirm that the resolution units and density values were updated correctly, use the identify command with formatting options:

magick identify -format "%x x %y %U\n" output.jpg
  • %x: Horizontal resolution
  • %y: Vertical resolution
  • %U: Resolution unit type (PixelsPerInch or PixelsPerCentimeter)
