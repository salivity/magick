How to Check ImageMagick Resource Limits with Identify

ImageMagick relies on strict resource limits to manage memory, disk space, and execution time during image processing tasks. This guide explains how to use the identify command to inspect your system's active security and performance limits, understand the output, and ensure ImageMagick operates without unexpected memory allocation crashes or system resource exhaustion.

The Command to Inspect Resource Limits

To inspect the effective resource limits using ImageMagick's identify tool, run the following command in your terminal:

identify -list resource

If you are using ImageMagick version 7 or newer, the recommended syntax is:

magick identify -list resource

Understanding the Output

Executing this command displays a table of configured thresholds that ImageMagick enforces during execution. Below is a breakdown of the primary metrics reported:

  • Width / Height: The maximum pixel dimensions allowed for an image before processing is rejected.
  • Area: The maximum aggregate pixel area (width × height) that can be cached in physical memory.
  • Memory: The maximum amount of RAM allocated for pixel caches before ImageMagick starts using disk caching.
  • Map: The maximum amount of memory-mapped disk space permitted for pixel caching.
  • Disk: The maximum disk space ImageMagick may consume when memory and map allocations are exhausted.
  • File: The maximum number of concurrently open files.
  • Thread: The maximum number of processing threads used for OpenMP parallel processing.
  • Time: The maximum execution time (in seconds) allowed for a command before it automatically terminates.

Where Effective Limits Are Configured

The limits reported by identify -list resource reflect settings derived from ImageMagick's security and resource policies. These defaults are defined in the policy.xml configuration file, typically found in /etc/ImageMagick-6/, /etc/ImageMagick-7/, or your system's global configuration directory.

You can temporarily override these effective limits for individual sessions by setting environment variables (such as MAGICK_MEMORY_LIMIT=2GiB) or by passing the -limit flag directly within standard commands:

identify -limit memory 2GiB -list resource
