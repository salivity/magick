How to Check ImageMagick Version and Configuration

Checking the installed version and build configuration of ImageMagick is essential for troubleshooting, verifying security patches, and confirming support for specific image formats. This guide provides the exact terminal commands required to inspect your ImageMagick version, enabled features, delegate libraries, and detailed compilation parameters across ImageMagick 6 and ImageMagick 7.

1. Check ImageMagick Version

The command used to check the version depends on whether you have ImageMagick 7 or the legacy ImageMagick 6 installed.

For ImageMagick 7 (Current):

magick -version

For ImageMagick 6 (Legacy):

convert -version

(Alternatively, identify -version works on both versions).

Understanding the Output: Running this command displays output similar to the following:

Version: ImageMagick 7.1.1-29 Q16-HDRI x86_64 22005 https://imagemagick.org
Copyright: (C) 1999 ImageMagick Studio LLC
License: https://imagemagick.org/script/license.php
Features: Cipher DPC HDRI Modules OpenMP(4.5) 
Delegates (built-in): bzlib fontconfig freetype heic jng jp2 jpeg lcms lqr ltdl lzma openexr png tiff webp xml zlib
  • Version: The release number and build date.
  • Quantum Depth (e.g., Q16 / Q8): The number of bits used to store pixel component values.
  • HDRI: Indicates whether High Dynamic Range Imaging is enabled.
  • Features: Compiled capabilities like OpenMP (multithreading) and Cipher.
  • Delegates: External third-party libraries currently enabled for decoding specific formats (e.g., jpeg, png, webp, heic).

2. Check Detailed Build Configuration

To view the complete configuration, including compiler flags, installation paths, and environment settings used during compilation, run:

For ImageMagick 7:

magick -list configure

For ImageMagick 6:

convert -list configure

Output Details: This outputs key-value pairs showing the build environment, such as:

  • CC / CFLAGS: The C compiler and flags used during compilation.
  • DELEGATES: The full list of linked delegate libraries.
  • CONFIGURE_ARGS: The exact arguments passed to ./configure when ImageMagick was built from source.

3. Check Supported Formats and Delegates

If you need to verify whether a specific format (such as WebP, HEIC, or PDF) is supported by your installation:

List all supported image formats:

magick -list format

List configured delegates and decoding rules:

magick -list delegate

Search for a specific format (e.g., WebP) on Linux/macOS:

magick -list format | grep -i webp
