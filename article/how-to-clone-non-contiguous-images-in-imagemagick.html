How to Clone Non-Contiguous Images in ImageMagick

This article explains how to use ImageMagick's -clone operator to duplicate non-contiguous images from the current in-memory image sequence. You will learn how ImageMagick indexes images within its internal stack, how to target specific, non-adjacent frames using comma-separated arguments, and how to safely manipulate these cloned frames within complex command-line workflows.

Understanding the Image Stack and Indexing

When ImageMagick reads images, it stores them in an internal memory list called the image sequence or stack. Each image in this sequence is assigned a zero-based index:

  • The first image loaded is index 0.
  • The second image is index 1.
  • The third image is index 2, and so on.

ImageMagick also supports negative indices to count backward from the end of the stack, where -1 represents the last image, -2 represents the second-to-last image, and so forth.

Duplicating Non-Contiguous Images

The -clone operator makes copies of existing images in the sequence without reloading them from disk. While contiguous ranges are specified using a hyphen (such as 0-2), non-contiguous images are selected by passing a comma-delimited list of individual indices directly to the -clone operator.

Syntax

magick image0.png image1.png image2.png image3.png -clone 0,2,3 output.png

In this command:

  1. Four separate images are read into memory at indices 0, 1, 2, and 3.
  2. -clone 0,2,3 creates duplicates of the images at index 0, index 2, and index 3, skipping index 1.
  3. The cloned images are appended to the end of the current stack as new entries (indices 4, 5, and 6).

You can also combine discrete indices with ranges. For example, -clone 0,3-5 duplicates the first image along with the fourth, fifth, and sixth images.

Using Negative Indices for Non-Contiguous Clones

Negative indices can be mixed with positive indices to select non-adjacent images relative to the end of the list:

magick a.jpg b.jpg c.jpg d.jpg e.jpg -clone 0,-1 result.png

This operation clones the very first image (0) and the very last image (-1), ignoring the intermediate frames.

Scoping Clones with Parentheses

When duplicating non-contiguous images for specific modifications, isolate the operation inside parentheses. This prevents subsequent operators from altering the original source images:

magick frame0.png frame1.png frame2.png frame3.png \
  \( -clone 0,2 -resize 50% \) \
  -delete 0-3 output_%d.png

In this workflow:

  1. All four frames are loaded into memory.
  2. Inside the sub-shell \( ... \), frames 0 and 2 are cloned and resized.
  3. Once the sub-shell closes, the resized clones enter the main sequence.
  4. The -delete 0-3 operator clears the original, unresized frames, leaving only the processed duplicates to be saved.
