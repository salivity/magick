How to Compare Images Using ImageMagick Signatures

This article explains how to determine if two images contain identical pixel data using ImageMagick cryptographic signatures. You will learn what an image signature is, how to generate it using the command line, and how to compare signatures to verify pixel identity across different file formats or metadata variations.

What is an ImageMagick Signature?

An ImageMagick signature is a unique SHA-256 hash calculated strictly from an image's raw pixel data (canvas geometry, colormap, and pixel components). Unlike standard file-level checksums (like standard MD5 or SHA-256 hashes) which change whenever metadata, timestamps, or container formats change, an ImageMagick signature remains identical as long as the visual pixel content does not change. This allows you to verify that two images are visually identical even if one is a PNG and the other is a TIFF or BMP.

Generating an Image Signature

To compute the signature of an image, use the identify tool with the %# format specifier.

For ImageMagick v7:

magick identify -format "%#\n" image1.png

For ImageMagick v6:

identify -format "%#\n" image1.png

This command outputs a 64-character hexadecimal SHA-256 string representing the pixel stream of the file.

Verifying If Two Images Have Identical Pixels

To verify whether two files have identical pixel data, generate the signature for both files and compare them.

Method 1: Visual Inspection or Comparison in Bash

Run the identification command on both images simultaneously:

magick identify -format "%f: %#\n" image1.png image2.jpg

If the 64-character hash strings match, the pixel values are 100% identical.

Method 2: Automated Comparison via Scripting

In a Unix/Linux shell environment, you can automate the verification test using a conditional statement:

SIG1=$(magick identify -format "%#" image1.png)
SIG2=$(magick identify -format "%#" image2.png)

if [ "$SIG1" = "$SIG2" ]; then
    echo "The pixel data is identical."
else
    echo "The pixel data differs."
fi

Method 3: Using test with Process Substitution

You can execute an inline check without saving variables:

[ "$(magick identify -format '%#' image1.png)" = "$(magick identify -format '%#' image2.png)" ] && echo "Identical" || echo "Different"

When to Use Signatures vs. ImageMagick compare

  • Use Signatures (%#) when you need a fast, exact, binary match of pixel data without generating visual diff files or calculating error metrics.
  • Use magick compare when the images differ and you need to measure the degree of difference (such as RMSE or PSNR) or output a visual delta map.
