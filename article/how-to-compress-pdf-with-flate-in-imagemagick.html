How to Compress PDF with Flate in ImageMagick

This guide outlines the precise ImageMagick command-line syntax required to compress PDF documents using Flate compression. You will learn the exact flags to use, how Flate relates to the Zip compression algorithm in ImageMagick, and how to apply these options to reduce PDF file sizes effectively without introducing lossy compression artifacts.

The Flate Compression Syntax

In ImageMagick, Flate compression uses the Deflate algorithm (the standard compression method used in ZIP and PNG formats). You can specify Flate compression using either the Flate or Zip keyword, as ImageMagick treats them as equivalents.

Basic Command Syntax (ImageMagick v7)

magick input.pdf -compress Flate output.pdf

Alternatively, using the Zip alias:

magick input.pdf -compress Zip output.pdf

Legacy Syntax (ImageMagick v6)

If you are using ImageMagick version 6, use the convert tool:

convert input.pdf -compress Flate output.pdf

Recommended Parameters for PDF Optimization

When processing PDFs with ImageMagick, rendering resolution and raster quality significantly impact the final output size. Combining -compress Flate with density and quality settings ensures predictable file sizes and visual clarity:

magick -density 150 input.pdf -compress Flate -quality 9 output.pdf

Parameter Breakdown

  • -density <dpi>: Sets the horizontal and vertical resolution (e.g., 150 or 300 DPI) at which the vector or PDF pages are rendered. Place this before the input file to ensure proper rasterization.
  • input.pdf: The source PDF file.
  • -compress Flate: Instructs ImageMagick to encode the PDF output streams using lossless Flate (Deflate) compression.
  • -quality <level>: For Flate/Zip compression, the -quality flag controls the zlib compression level, ranging from 1 (fastest, lowest compression) to 9 (slowest, best compression). The default is typically 7.
  • output.pdf: The compressed destination file.

Converting Images to a Flate-Compressed PDF

The same syntax applies when compiling raster images (such as TIFF, PNG, or JPEG) into a single, Flate-compressed PDF document:

magick page1.png page2.png -compress Flate -quality 9 combined_output.pdf
