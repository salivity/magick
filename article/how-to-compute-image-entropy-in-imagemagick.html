How to Compute Image Entropy in ImageMagick

Image information entropy measures the statistical randomness and distribution of pixel intensity values, making it an essential metric for quantifying texture complexity, visual detail, and noise levels in an image. This guide explains how to calculate Shannon entropy directly from the command line using ImageMagick tools, interpret the resulting values, and apply these measurements to assess texture complexity across individual channels or entire image datasets.

Understanding Image Entropy

Shannon entropy measures the uncertainty or average information content within a dataset. In digital image processing, entropy (\(H\)) is calculated based on the normalized histogram of pixel intensities:

\[H = -\sum_{i=0}^{N-1} p_i \log_2(p_i)\]

Where \(p_i\) represents the probability of a pixel possessing intensity value \(i\), and \(N\) is the total number of intensity levels (such as 256 for an 8-bit image).

When evaluating texture complexity:

  • High Entropy: Indicates a wide, uniform distribution of pixel intensities, corresponding to complex textures, high detail, fine grain, or noise.
  • Low Entropy: Indicates redundant or clustered pixel values, corresponding to flat, smooth, or low-contrast areas (such as clear skies or solid backgrounds).

Basic Entropy Computation

ImageMagick provides built-in format properties to retrieve entropy values without requiring custom external scripts. In ImageMagick 7, use the magick command paired with the info: output format:

magick input.jpg -format "%[entropy]\n" info:

For ImageMagick 6 installations, use the identify utility:

identify -format "%[entropy]\n" input.jpg

ImageMagick returns the entropy as a normalized floating-point value ranging from 0.0 (minimum complexity, single solid color) to 1.0 (maximum complexity, uniform random distribution).

Computing Grayscale Entropy for Pure Texture

Color images calculate entropy across multiple channels (Red, Green, Blue), which can sometimes conflate color variance with structural texture complexity. To evaluate purely structural texture, convert the image to grayscale before computing entropy:

magick input.jpg -colorspace Gray -format "%[entropy]\n" info:

Retrieving Per-Channel Entropy Metrics

To view comprehensive image statistics, including individual channel entropy values along with standard deviation and mean:

magick identify -verbose input.jpg

Under the Image statistics: section of the output, each channel lists an Entropy property alongside an overall multi-channel aggregate:

Image statistics:
  Overall:
    min: 0
    max: 255
    mean: 118.42
    standard deviation: 58.12
    entropy: 0.88421

You can extract specific channel entropy programmatically using channel-specific format properties:

# Red Channel Entropy
magick input.jpg -format "%[channel:entropy.red]\n" info:

# Green Channel Entropy
magick input.jpg -format "%[channel:entropy.green]\n" info:

# Blue Channel Entropy
magick input.jpg -format "%[channel:entropy.blue]\n" info:

Batch Processing and Texture Ranking

To compare texture complexity across multiple images in a directory and sort them from lowest to highest complexity, use a standard shell pipeline:

for img in *.jpg; do
  score=$(magick "$img" -colorspace Gray -format "%[entropy]" info:)
  echo "$score $img"
done | sort -n

This output lists all analyzed images alongside their normalized entropy score, enabling fast automated filtering of smooth surfaces versus textured regions.
