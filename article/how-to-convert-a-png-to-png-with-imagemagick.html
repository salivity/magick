How to Convert a PNG to PNG with ImageMagick?

Converting a PNG to a PNG using ImageMagick is a standard operation used to re-encode image data, strip unnecessary metadata, optimize file size, or apply programmatic color adjustments. Whether you are running legacy ImageMagick versions or modern releases, passing a PNG file as both the input and output allows the underlying encoder to rewrite the file according to specified compression, bit depth, and filtering flags.

Basic Syntax

The most straightforward way to process a PNG back into a PNG is by passing the source file and specifying a new destination filename.

For ImageMagick 7 and newer:

magick input.png output.png

For ImageMagick 6 (legacy syntax):

convert input.png output.png

This rewrites the image data while retaining the visual appearance, applying ImageMagick's default PNG encoder settings to the new file.

Optimizing File Size and Stripping Metadata

Digital cameras, graphic editors, and web tools often embed non-essential metadata into PNG files, including color profiles, timestamps, and editing history. You can remove this extra data and tune the compression level using the -strip and -quality parameters:

magick input.png -strip -quality 95 output.png

In ImageMagick, the -quality argument for PNGs functions differently than it does for JPEGs. The value is a two-digit number:

  • The first digit specifies the zlib compression level (ranging from 1 to 9, where 9 provides maximum compression).
  • The second digit represents the PNG filter type (ranging from 0 to 5, where 5 chooses an adaptive filter).

A setting of -quality 95 applies maximum compression alongside adaptive row filtering to produce small, clean file sizes.

Modifying Color Depth and Formats

Re-encoding PNG to PNG also allows you to control the color space and indexing. If an image only contains a limited number of colors, converting truecolor 24-bit or 32-bit PNGs to an 8-bit palette can significantly reduce file weight:

magick input.png -colors 256 PNG8:output.png

Using the explicit PNG8: prefix forces the encoder to write an 8-bit palette image, while PNG24: preserves standard RGB colors without transparency, and PNG32: retains full 8-bit alpha transparency.

Batch Converting PNGs

To re-encode multiple PNG files within a single directory, the mogrify tool provides in-place processing or directory-to-directory exports:

magick mogrify -path ./optimized -strip -quality 95 *.png

This command reads all .png files in the current working path, applies the optimization flags, and saves the freshly encoded files into an optimized folder without altering the original files.
