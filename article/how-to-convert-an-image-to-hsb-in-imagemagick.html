How to Convert an Image to HSB in ImageMagick

This guide explains how to convert an image to the HSB (Hue, Saturation, Brightness) color space using ImageMagick. By utilizing the command-line -colorspace operator, you can transform images into HSB components for advanced image processing, color analysis, or channel manipulation across both modern and legacy versions of the software.

The ImageMagick HSB Conversion Command

In ImageMagick version 7, use the magick command paired with the -colorspace HSB argument:

magick input.jpg -colorspace HSB output.png

If you are using ImageMagick version 6, use the legacy convert command:

convert input.jpg -colorspace HSB output.png

Understanding HSB vs. HSV in ImageMagick

In ImageMagick, HSB and HSV (Hue, Saturation, Value) refer to the exact same color model and are interchangeable. Running either of the following commands produces identical results:

magick input.jpg -colorspace HSB output.png
magick input.jpg -colorspace HSV output.png

Extracting Individual HSB Channels

Converting to HSB is often done to inspect or edit the Hue, Saturation, or Brightness channels independently. You can separate an image into three grayscale representations of each channel using the -separate operator:

magick input.jpg -colorspace HSB -separate channel_%d.png

This generates three distinct files:

  • channel_0.png: Hue channel
  • channel_1.png: Saturation channel
  • channel_2.png: Brightness (Value) channel

Converting Back to sRGB

After processing individual HSB channels or adjusting the image, return the image to the standard sRGB color space for proper display on monitors and web browsers:

magick hsb_image.png -colorspace sRGB final_output.jpg
