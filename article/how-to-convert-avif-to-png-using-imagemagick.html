How to Convert AVIF to PNG Using ImageMagick?

Converting AVIF images to standard PNG format is a straightforward command-line process using ImageMagick's conversion tools. This guide covers the essential commands required to convert single AVIF files, execute batch conversions across entire folders, verify that your local ImageMagick installation supports AVIF decoding, and adjust output settings for maximum image quality.

Checking for AVIF Support

Before converting files, confirm that your ImageMagick installation includes the delegate library needed to decode AVIF images, typically libheif.

Run the following command in your terminal or command prompt:

magick identify -list format | grep -i avif

If AVIF is supported, the output will list AVIF with read and write permissions (indicated by rw+ or r--). If no output appears or the command returns an error, update ImageMagick or install the libheif delegate package via your operating system's package manager.

Converting a Single AVIF Image to PNG

ImageMagick 7 uses the unified magick command. To convert a single .avif file into a .png file, specify the input file followed by the desired output filename:

magick input.avif output.png

ImageMagick detects the source format automatically from the file header and encodes the target file based on the extension provided.

Controlling PNG Compression and Quality

PNG is a lossless format, but ImageMagick allows you to adjust compression levels to balance file size against processing speed. You can apply the -quality flag:

magick input.avif -quality 95 output.png

For PNG output in ImageMagick, the first digit of the quality parameter represents the zlib compression level (from 0 to 9), while the second digit specifies the filter type. A setting of 95 applies high compression alongside adaptive filtering to produce smaller PNG file sizes without any visual degradation.

Batch Converting Multiple AVIF Files

To convert multiple AVIF files within a directory at once, use the following commands depending on your operating system.

Linux and macOS (Bash/Zsh)

Process all AVIF files in the current folder using a standard shell loop:

for file in *.avif; do
    magick "$file" "${file%.avif}.png"
done

Windows Command Prompt

Run this loop directly inside your directory:

for %f in (*.avif) do magick "%f" "%~nf.png"

Windows PowerShell

Execute a ForEach-Object pipeline command:

Get-ChildItem -Filter *.avif | ForEach-Object {
    magick $_.FullName "$($_.DirectoryName)\$($_.BaseName).png"
}

Legacy ImageMagick 6 Command

If your system runs ImageMagick version 6, replace the magick command with the legacy convert binary:

convert input.avif output.png
