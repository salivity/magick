How to Convert AVIF to WebP Using ImageMagick?

Converting AVIF images to WebP format using ImageMagick is a fast, command-line-driven process that helps optimize images for web compatibility and performance. Both formats offer modern compression, but WebP has broader support across older browsers and image editors. This guide explains how to verify that your ImageMagick installation supports both formats, perform basic conversions, tune compression quality, and batch process multiple files at once.

Prerequisites and Format Support

Before converting files, confirm that your ImageMagick installation includes the delegates for both AVIF (typically libheif) and WebP (libwebp).

Run this command in your terminal to verify support:

magick identify -list format | grep -iE 'avif|webp'

If you are using an older version (ImageMagick 6), replace magick with convert:

identify -list format | grep -iE 'avif|webp'

Look for r (read) next to AVIF and w (write) next to WebP in the command output. If either is missing, install the required libraries via your system package manager (such as Homebrew on macOS or APT on Ubuntu/Debian) and rebuild or reinstall ImageMagick.

Basic Conversion Command

To perform a direct conversion using default quality settings, run:

magick input.avif output.webp

ImageMagick automatically infers the input and output formats from the file extensions.

Controlling Output Quality and Compression

By default, ImageMagick applies lossy WebP compression at a sensible baseline. You can control file size and image fidelity using the -quality flag, which accepts values between 0 (smallest file size, lowest quality) and 100 (highest quality).

For standard web assets, a quality value between 75 and 85 provides a good balance:

magick input.avif -quality 80 output.webp

To perform a lossless conversion, set the quality parameter to 100 or define the WebP compression method explicitly:

magick input.avif -define webp:lossless=true output.webp

Batch Converting Multiple Files

If you need to convert an entire directory of AVIF files to WebP, you can use a shell loop or the mogrify tool.

Using a Bash Loop

A for loop provides clean control and avoids accidental overwrites:

for file in *.avif; do
    magick "$file" -quality 80 "${file%.avif}.webp"
done

Using Mogrify

ImageMagick includes mogrify, designed specifically for batch processing. This command converts all .avif files in the current folder to .webp while leaving the original files intact:

magick mogrify -format webp -quality 80 *.avif
