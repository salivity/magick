How to Convert GIF to PNG Using ImageMagick?

Converting GIF images to PNG format using ImageMagick requires selecting the right command depending on whether the source file is static or animated. This guide covers how to perform a straightforward conversion, extract specific frames from an animated GIF, split all frames into individual PNG files, or coalesce animations to prevent transparency artifacts.

Basic Conversion for Static GIFs

For a standard, single-frame GIF, conversion only requires passing the input and output filenames to the magick command (or convert in ImageMagick version 6):

magick input.gif output.png

This processes the image and writes a lossless PNG file preserving the original resolution and color palette.

Extracting All Frames from an Animated GIF

When running a basic conversion on an animated GIF, ImageMagick automatically splits every frame into a separate PNG file, appending numerical indices to the filename:

magick animation.gif frame-%d.png

Using the %d format specifier generates sequentially numbered files such as frame-0.png, frame-1.png, and so on.

Handling Transparency with Coalesce

Animated GIFs often optimize file size by saving only the pixels that change between frames, leaving unchanged areas transparent. Converting these frames directly can result in incomplete or broken images. Use the -coalesce flag to reconstruct full frames before saving:

magick animation.gif -coalesce frame-%02d.png

The -coalesce parameter rebuilds each frame's full visual state, and %02d creates zero-padded filenames like frame-00.png.

Extracting a Specific Single Frame

To extract only one frame rather than the entire animation, specify the frame's zero-based index in brackets immediately after the input filename:

magick animation.gif[0] first-frame.png

Replacing [0] with [5] will extract the sixth frame of the sequence.
