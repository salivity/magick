How to Convert GIF to WebP Using ImageMagick?

Converting animated or static GIF files into the modern WebP format significantly reduces file sizes while maintaining sharp image quality. This guide walks through the exact ImageMagick commands required to perform direct conversions, fine-tune compression levels, control animation loops, and batch-process entire directories from the command line.

ImageMagick provides built-in support for animated WebP encoding through the magick command (or convert on legacy versions). Because animated GIFs often suffer from large file footprints and color banding, transcoding them to WebP cuts bandwidth usage while supporting 24-bit color and alpha transparency.

Prerequisites and Version Check

Ensure ImageMagick is installed with WebP delegate support enabled. Run the following command in your terminal:

magick -version

Look for webp in the Delegates line. If it is missing, reinstall ImageMagick with WebP support via your package manager (such as brew install imagemagick on macOS or apt install imagemagick webp on Ubuntu/Debian).

Basic Conversion Command

The standard conversion requires specifying the source GIF and the output .webp filename:

magick input.gif output.webp

ImageMagick detects the multi-frame structure of the GIF and preserves the frame sequence and timing automatically in the resulting WebP file.

Optimizing Quality and File Size

To strike the best balance between visual fidelity and payload weight, use explicit compression flags:

  • Lossy Compression: Ideal for photographic or complex animations. Use -quality with a value between 0 and 100 (75–85 is recommended):
magick input.gif -quality 80 -define webp:method=6 output.webp
  • Lossless Compression: Best for flat graphics, pixel art, or screencasts with high-contrast text:
magick input.gif -define webp:lossless=true output.webp
  • Compression Effort: The flag -define webp:method=6 forces the encoder to use the highest compression effort (ranges from 0 to 6), yielding smaller files at the cost of slightly slower encoding time.

Handling Animation Loops

GIFs often contain looping metadata that needs preservation or adjustment:

  • Infinite Loop: Ensure the animated WebP loops continuously:
magick input.gif -loop 0 output.webp
  • Play Once: Prevent repeated looping by setting the loop flag to 1:
magick input.gif -loop 1 output.webp

Batch Processing Multiple Files

To convert every GIF inside a directory using bash:

for file in *.gif; do
    magick "$file" -quality 80 -define webp:method=6 "${file%.gif}.webp"
done

This script extracts the base filename and outputs an optimized .webp equivalent alongside each original file.
