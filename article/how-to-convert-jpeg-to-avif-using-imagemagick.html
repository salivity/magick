How to Convert JPEG to AVIF Using ImageMagick?

Converting JPEG images to the modern AVIF format with ImageMagick allows you to significantly reduce file sizes while preserving high visual fidelity. This guide walks through the required ImageMagick command syntax, key quality and compression settings, delegate verification to ensure your system supports AVIF encoding, and automated batch conversion techniques.

Prerequisites and AVIF Support

Before converting images, you must ensure that your ImageMagick installation includes AVIF support. AVIF encoding typically relies on the libheif or libaom delegates.

You can verify whether your installed version of ImageMagick supports AVIF by running the following command in your terminal:

magick identify -list format | grep -i avif

(Note: On older installations using ImageMagick 6, replace magick identify with identify.)

If the output lists AVIF with read (r) and write (w) permissions, your setup is ready to encode. If AVIF is missing, update ImageMagick or install libheif using your operating system's package manager.

Basic Conversion Command

To convert a single JPEG image to an AVIF image with default settings, run:

magick input.jpg output.avif

ImageMagick inspects the file extension of the target file (.avif) and invokes the appropriate encoder automatically.

Fine-Tuning Quality and Compression

Default conversion settings may not always yield the optimal balance between file size and visual fidelity. ImageMagick provides several flags to fine-tune AVIF output:

magick input.jpg -quality 65 -define heic:speed=4 output.avif

Key Parameters

  • Quality (-quality): AVIF uses a scale from 0 to 100. A value between 50 and 75 typically produces excellent visual quality while maintaining substantial file size savings compared to JPEG. Setting the quality to 100 activates lossless compression, resulting in significantly larger files.
  • Encoding Speed (-define heic:speed=X): Values generally range from 0 (slowest compression, optimal size) to 8 or 9 (fastest compression, slightly larger file size). A value around 4 offers a practical balance between conversion duration and compression efficiency.
  • Chroma Subsampling (-sampling-factor): By default, standard 4:2:0 subsampling is applied. If sharp color boundaries are critical (such as image assets containing fine text), you can specify 4:4:4 subsampling:
magick input.jpg -quality 65 -sampling-factor 4:4:4 output.avif

Batch Converting Multiple JPEG Files

To process an entire folder of JPEG images, you can use built-in batch utilities or native shell loops.

Using ImageMagick Mogrify

The mogrify tool batch processes multiple files in place. The following command converts all .jpg files in the current directory to .avif:

magick mogrify -format avif -quality 65 *.jpg

Using a Bash Loop (Linux/macOS)

A shell loop gives you greater control over naming patterns and output directories:

for file in *.jpg; do
  magick "$file" -quality 65 "${file%.jpg}.avif"
done

Using PowerShell (Windows)

On Windows systems, you can execute a batch conversion using PowerShell:

Get-ChildItem -Filter *.jpg | ForEach-Object {
    $outputName = [System.IO.Path]::ChangeExtension($_.Name, ".avif")
    magick $_.FullName -quality 65 $outputName
}
