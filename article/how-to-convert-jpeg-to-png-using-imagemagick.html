How to Convert JPEG to PNG Using ImageMagick?

Converting a JPEG image to PNG format using ImageMagick is a straightforward command-line process that handles basic format conversion as well as advanced batch processing, transparency management, and compression settings. Whether you are using modern ImageMagick version 7 or the legacy ImageMagick version 6, this guide covers the core terminal commands needed to convert single files, optimize output quality, and automate bulk conversions across entire directories.

Basic Image Conversion

ImageMagick infers the desired output format automatically from the file extension provided at the end of the command.

ImageMagick Version 7

On ImageMagick 7 and newer releases, all commands standardise around the primary magick binary:

magick input.jpg output.png

ImageMagick Version 6

If you are running ImageMagick 6, the legacy utility binary convert is used instead:

convert input.jpg output.png

Both commands read the source JPEG file, decode the compressed pixels, and encode the data into a standard lossless PNG container without requiring extra parameters.

Handling Quality and Compression

JPEGs use lossy compression, whereas PNGs use lossless compression. When exporting to PNG, the -quality flag controls the PNG zlib compression level and filter type rather than visual degradation.

In ImageMagick, a PNG quality setting takes a two-digit integer:

  • The first digit specifies the zlib compression level (0 to 9, where 9 provides maximum compression).
  • The second digit selects the PNG filtering strategy (often set to 5 for adaptive filtering).

To generate a well-compressed PNG with minimal file size:

magick input.jpg -quality 95 output.png

If speed is prioritized over disk footprint, lowering the value (such as -quality 10) speeds up the write process significantly.

Adding Transparency

JPEG files do not support alpha channels or transparency. If you want a specific solid background color from the JPEG (such as a pure white studio background) to become transparent in the resulting PNG, use the -transparent and -fuzz flags:

magick input.jpg -fuzz 5% -transparent white output.png
  • -fuzz 5% accommodates slight compression artifacts or near-white pixels near the borders.
  • -transparent white replaces pixels matching that color threshold with complete transparency.

Batch Converting Multiple JPEGs to PNG

Converting dozens or hundreds of files manually is inefficient. ImageMagick provides flexible options for batch operations depending on your operating system and shell environment.

Using the Mogrify Command

The mogrify tool processes multiple files in place. To convert every .jpg in the current folder to .png:

magick mogrify -format png *.jpg

For ImageMagick 6 installations:

mogrify -format png *.jpg

This retains original .jpg files alongside the newly generated .png counterparts.

Using a Bash Loop (Linux and macOS)

A shell loop gives you greater control over naming structures and avoids command line argument length limits:

for file in *.jpg; do
    magick "$file" "${file%.jpg}.png"
done

Using Windows PowerShell

In Windows PowerShell, pipe directory contents directly to the magick command:

Get-ChildItem -Filter *.jpg | ForEach-Object {
    magick $_.FullName "$($_.BaseName).png"
}
