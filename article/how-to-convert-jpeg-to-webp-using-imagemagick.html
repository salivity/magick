How to Convert JPEG to WebP Using ImageMagick?

Converting JPEG images to the modern WebP format using ImageMagick provides superior compression and faster website load times with minimal effort. This guide explains how to use ImageMagick's command-line interface to convert single files, adjust quality and compression settings for optimal output, and run batch conversions across entire image folders.

Prerequisites and Installation

Ensure that ImageMagick and its WebP delegate library (libwebp) are installed on your machine. You can verify your setup by checking supported formats in your terminal:

magick -version

Look for webp under the listed delegates. If it is missing, install ImageMagick through your package manager:

  • macOS (Homebrew): brew install imagemagick
  • Ubuntu/Debian: sudo apt install imagemagick webp
  • Windows: Download the binary installer from the official ImageMagick website, ensuring "Install legacy utilities" or environment path options are selected.

Basic Single-File Conversion

ImageMagick 7 uses the magick command (ImageMagick 6 uses convert). The simplest command to convert a JPEG to WebP is:

magick input.jpg output.webp

This takes the source file input.jpg, processes the image data, and writes output.webp using default WebP encoding parameters.

Controlling Compression and Quality

WebP supports both lossy and lossless modes. Fine-tuning compression levels ensures you preserve visual fidelity while cutting file size.

Adjusting Lossy Quality

Use the -quality flag followed by a value from 0 to 100 to adjust compression. A setting between 75 and 85 typically delivers indistinguishable visual quality from the original JPEG at a fraction of the file size:

magick input.jpg -quality 80 output.webp

Lossless Conversion

While JPEGs are inherently lossy, you can convert them into a lossless WebP container using the webp:lossless define:

magick input.jpg -define webp:lossless=true output.webp

Advanced Encoding Flags

ImageMagick allows access to libwebp encoding parameters via -define:

  • Compression Effort (webp:method): Controls the trade-off between encoding speed and file size reduction (values range from 0 to 6, with 6 providing maximum compression effort):
magick input.jpg -quality 82 -define webp:method=6 output.webp
  • Strip Metadata (-strip): Strips EXIF data, color profiles, and timestamps to shave off extra kilobytes:
magick input.jpg -strip -quality 80 output.webp

Batch Converting Multiple JPEG Files

To process multiple images simultaneously without writing separate commands for each file, use shell loops or ImageMagick's mogrify tool.

Using mogrify

The mogrify command is designed for batch operations. To convert every .jpg in the current working directory to .webp:

magick mogrify -format webp -quality 80 *.jpg

This generates a .webp copy for every .jpg file while leaving the original files intact.

Using a Bash Loop

A shell loop gives you precise naming control and lets you monitor progress across complex directory structures:

for file in *.jpg; do
    magick "$file" -strip -quality 80 "${file%.jpg}.webp"
done

Using Windows PowerShell

In PowerShell, loop through your files with:

Get-ChildItem -Filter *.jpg | ForEach-Object {
    magick $_.FullName -strip -quality 80 ($_.DirectoryName + "\" + $_.BaseName + ".webp")
}
