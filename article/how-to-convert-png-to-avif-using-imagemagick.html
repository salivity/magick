How to Convert PNG to AVIF Using ImageMagick?

Converting PNG images to AVIF format with ImageMagick allows you to significantly reduce file sizes while maintaining high visual fidelity. This guide walks you through the essential command-line syntax, fine-tuning compression settings like quality and effort levels, handling batch conversions, and verifying that your installed version of ImageMagick includes AVIF delegate support.

Verifying AVIF Support in ImageMagick

Before running conversion commands, verify that your local installation of ImageMagick was built with AVIF delegate support (typically provided via libheif or libavif). Run the following command in your terminal:

magick -version

Look for heic or avif listed under the Delegates output. Alternatively, check format support directly:

magick identify -list format | grep -i avif

If AVIF appears with read and write permissions (rw- or rw+), your environment is ready to process conversions.

Basic PNG to AVIF Conversion

ImageMagick 7 uses the magick command (or convert in ImageMagick 6). The simplest command syntax requires only the input file and the target output path with the .avif extension:

magick input.png output.avif

ImageMagick automatically invokes the appropriate encoder based on the file extension and applies standard default compression parameters.

Controlling Quality and Encoding Speed

AVIF relies on modern video-coding standards (AV1), meaning compression parameters significantly influence both visual quality and processing time.

Adjusting Quality

The -quality flag controls visual lossiness on a scale from 0 to 100:

magick input.png -quality 65 output.avif
  • Values between 50 and 70 generally provide the optimal balance of sharp details and low file weight for web graphics.
  • A value of 100 does not always guarantee lossless output in standard delegates unless specific lossless flags are passed.

Configuring Compression Effort

Encoding AVIF files requires substantial CPU resources. You can adjust the encoding speed versus file density trade-off using the heic:speed define:

magick input.png -define heic:speed=4 -quality 65 output.avif

Speed values range from 0 (slowest processing, highest compression density) to 9 (fastest encoding, larger resulting file size). A setting between 4 and 6 works well for routine production pipelines.

Lossless Conversion

If you need a bit-exact, lossless version of a PNG graphic, set the lossless definition flag:

magick input.png -define heic:lossless=true output.avif

Lossless AVIF compression typically creates files smaller than standard PNGs, though savings are smaller compared to lossy encoding.

Batch Converting Multiple PNG Files

To convert an entire folder of PNG images to AVIF simultaneously, utilize standard shell utilities alongside ImageMagick.

Linux and macOS (Bash/Zsh)

for file in *.png; do
  magick "$file" -quality 65 "${file%.png}.avif"
done

Windows (PowerShell)

Get-ChildItem -Filter *.png | ForEach-Object {
  magick $_.FullName -quality 65 ($_.BaseName + ".avif")
}

Using these commands, you can integrate lightweight, modern AVIF images across your websites and graphic asset pipelines directly from your terminal.
