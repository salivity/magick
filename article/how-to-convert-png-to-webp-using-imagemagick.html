How to Convert PNG to WebP Using ImageMagick?

Converting PNG images to the modern WebP format using ImageMagick allows you to significantly reduce file sizes while maintaining high visual fidelity or transparency. This guide covers the basic syntax for single conversions, fine-tuning image quality and compression methods, handling transparency, and running batch operations across entire directories using the command line.

Basic Single Image Conversion

ImageMagick handles format conversion natively based on file extensions. Depending on your installed version, you will use either the magick command (ImageMagick 7) or the legacy convert command (ImageMagick 6).

To convert a single PNG file to WebP with default settings:

# ImageMagick 7
magick input.png output.webp

# ImageMagick 6
convert input.png output.webp

Controlling Compression and Quality

WebP supports both lossy and lossless compression. ImageMagick uses the -quality flag to determine how compression is applied.

Lossy Compression

For lossy WebP encoding, the -quality value ranges from 0 (lowest quality, smallest file) to 100 (highest quality, larger file). A setting between 75 and 85 typically delivers an optimal balance between quality and file size:

magick input.png -quality 80 output.webp

Lossless Compression

If you need an exact pixel-by-pixel match—such as for logos, sharp line art, or text graphics—use the -define flag to force lossless mode:

magick input.png -define webp:lossless=true output.webp

When lossless mode is enabled, the -quality flag changes its behavior: values from 0 to 100 control the compression effort (encoding speed vs. file size) rather than visual quality degradation.

Preserving Transparency and Alpha Channels

PNG files frequently contain alpha transparency. ImageMagick preserves alpha channels when converting to WebP by default, but you can explicitly control the compression applied to the transparency layer using the webp:alpha-quality definition:

magick input.png -quality 82 -define webp:alpha-quality=90 output.webp

Advanced Encoding Options

ImageMagick exposes specific libwebp encoding controls via additional defines:

  • Target Method/Effort: Adjust the trade-off between encoding speed and compressed size with webp:method (values 0–6, where 6 is the slowest and produces the smallest output).
  • Target Size: Set a strict ceiling for the resulting file size in bytes using webp:target-size.
magick input.png -quality 85 -define webp:method=6 output.webp

Batch Converting Multiple PNG Files

If you need to process dozens or hundreds of PNGs at once, ImageMagick provides the mogrify tool to transform images in place, or you can use a command-line loop to preserve the originals.

Using Mogrify

To convert all PNG files in the current directory directly to WebP:

magick mogrify -format webp -quality 80 *.png

Using a Bash Loop (Linux/macOS)

A shell loop allows you to maintain fine-grained control over names and output directories:

for file in *.png; do
    magick "$file" -quality 80 "${file%.png}.webp"
done

Using PowerShell (Windows)

For Windows users working in PowerShell:

Get-ChildItem -Filter *.png | ForEach-Object {
    $outName = [System.IO.Path]::ChangeExtension($_.Name, ".webp")
    magick $_.Name -quality 80 $outName
}
