How to Convert sRGB to Adobe RGB in ImageMagick

Converting images between color spaces is an essential task for preparing digital assets for high-end photography, design workflows, and professional printing. This guide provides a straightforward explanation of how to transform an image from the standard sRGB color profile to the wider Adobe RGB (1998) color space using the ImageMagick command-line tool, detailing the required syntax, profile handling, and commands for both ImageMagick v7 and v6.

Prerequisites: ICC Color Profiles

To perform a profile conversion, you need the target ICC profile file: AdobeRGB1998.icc (or .icm). If your input image does not already have an embedded sRGB profile, you will also need the sRGB.icc profile file.

Place these ICC files in your working directory, or specify their full system paths in the command.

The Conversion Command

ImageMagick handles color conversions using the -profile operator.

1. When the Source Image Already Contains an sRGB Profile

If the source image already has the sRGB color profile embedded, apply the destination profile once. ImageMagick will automatically read the existing profile and convert the pixel values to the new color space.

ImageMagick v7:

magick input.jpg -profile "AdobeRGB1998.icc" output.jpg

ImageMagick v6:

convert input.jpg -profile "AdobeRGB1998.icc" output.jpg

2. When the Source Image Lacks an Embedded Profile

If the input image is an untagged sRGB file, you must specify the -profile operator twice:

  1. The first -profile assigns the source color space (sRGB) without changing the pixel data.
  2. The second -profile translates the pixel data into the target color space (Adobe RGB 1998).

ImageMagick v7:

magick input.jpg -profile "sRGB.icc" -profile "AdobeRGB1998.icc" output.jpg

ImageMagick v6:

convert input.jpg -profile "sRGB.icc" -profile "AdobeRGB1998.icc" output.jpg

Verifying the Conversion

To confirm that the output image is correctly tagged with the Adobe RGB (1998) color space, inspect the image metadata using the magick identify command:

magick identify -verbose output.jpg | grep -A 5 "Profile-icc"

Look for the description field in the output; it should state Adobe RGB (1998).
