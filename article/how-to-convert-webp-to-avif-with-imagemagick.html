How to Convert WebP to AVIF with ImageMagick?

Converting WebP images to AVIF using ImageMagick allows you to take advantage of next-generation compression algorithms, yielding smaller file sizes at comparable or superior visual quality. This guide walks through checking your system prerequisites, executing the core conversion command, adjusting compression quality parameters, and automating the process across multiple files in batch.

Prerequisites and Delegate Verification

ImageMagick relies on external delegate libraries to handle modern image formats. Specifically, AVIF support depends on libheif compiled with an AV1 encoder such as aom or rav1e.

Before running conversions, verify that your ImageMagick build supports both WebP and AVIF. Run the following command in your terminal:

magick -version

Look for webp and heic (which covers AVIF via libheif) in the Delegates output string. You can also explicitly test format support by querying:

magick identify -list format | grep -iE 'webp|avif'

If AVIF shows read and write capabilities (rw+ or rw-), your installation is ready.

Basic WebP to AVIF Conversion

For ImageMagick version 7 and newer, the standard command syntax uses the magick binary:

magick input.webp output.avif

If you are using legacy ImageMagick version 6, replace magick with convert:

convert input.webp output.avif

This single command reads the WebP container, decompresses the raster data, and encodes it into an AVIF container using default quality and speed profiles.

Optimizing Compression and Quality

AVIF default settings may not always strike the right balance between processing time and file size. ImageMagick lets you control visual fidelity and encoder behavior using options:

magick input.webp -quality 65 -define heic:speed=6 output.avif

Quality (-quality)

The -quality parameter ranges from 0 to 100. For AVIF, values between 50 and 75 typically match or surpass standard WebP visual fidelity while cutting file size considerably. A setting of 60 to 65 is widely considered the sweet spot for web assets.

Compression Speed (-define heic:speed)

The heic:speed definition accepts integer values from 0 to 9. Lower numbers yield better compression efficiency at the expense of slower CPU encoding times. A speed setting between 4 and 6 provides a practical tradeoff for production pipelines.

Preserving Color Profiles

To ensure color accuracy between formats, retain or assign standard sRGB profiles:

magick input.webp -colorspace sRGB -quality 65 output.avif

Batch Converting WebP Files to AVIF

When managing asset directories, converting files one by one is inefficient. You can automate conversions across an entire folder using shell loops.

Linux and macOS (Bash / Zsh)

for file in *.webp; do
  magick "$file" -quality 65 "${file%.webp}.avif"
done

Windows (PowerShell)

Get-ChildItem -Filter *.webp | ForEach-Object {
  $outputName = [System.IO.Path]::ChangeExtension($_.Name, ".avif")
  magick $_.FullName -quality 65 $outputName
}

Verifying Conversion Results

To ensure the newly created AVIF image maintains integrity and metadata, inspect it directly using ImageMagick:

magick identify output.avif

The output will confirm the resolution, color depth, format specification, and container attributes.
