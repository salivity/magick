How to Convert WebP to PNG Using ImageMagick?

Converting WebP images to PNG format using ImageMagick requires only a single terminal command, preserving image transparency while ensuring compatibility across systems that lack native WebP support. Depending on your version of ImageMagick, you will execute either the magick or legacy convert command with basic input and output parameters. This guide covers the essential syntax for single-file conversion, quality retention settings, and batch-processing entire directories of images efficiently.

Basic Single-Image Conversion

ImageMagick automatically detects the source and destination formats from the file extensions provided in the command line arguments.

For ImageMagick version 7 and newer:

magick input.webp output.png

For ImageMagick version 6 (legacy installations):

convert input.webp output.png

This operation reads input.webp, decodes the compressed pixel data, and encodes it into output.png without requiring explicit format flags.

Preserving Transparency and Quality Settings

WebP supports both lossy and lossless compression, as well as full alpha channel transparency. PNG is inherently a lossless format, meaning that converting from WebP to PNG will not degrade visual quality further, but file size can be optimized through PNG compression levels.

To ensure transparency channels are cleanly preserved, include the -alpha on flag:

magick input.webp -alpha on output.png

To control PNG compression level (which affects file size and encoding time, but not visual quality):

magick input.webp -quality 95 output.png

In ImageMagick, the first digit of the -quality argument for PNG specifies the zlib compression level (0–9), while the second digit specifies the filter type (0–5). Setting -quality 95 applies maximum compression alongside adaptive filtering.

Batch Converting Multiple WebP Files to PNG

To convert multiple files within a single directory, you can utilize ImageMagick’s built-in mogrify tool or a standard shell loop.

Using the Mogrify Tool

The mogrify command is designed for batch operations. When specifying a new format, it writes new files rather than overwriting originals:

magick mogrify -format png *.webp

For ImageMagick 6 installations, run:

mogrify -format png *.webp

Using a Bash Loop

A shell loop gives you precise control over filenames and execution handling on Linux and macOS systems:

for file in *.webp; do
    magick "$file" "${file%.webp}.png"
done

This pattern iterates through every .webp file in the current directory, strips the .webp extension, and produces a corresponding .png file.

Using Windows PowerShell

On Windows environments running PowerShell, use the following loop command:

Get-ChildItem -Filter *.webp | ForEach-Object {
    magick $_.FullName "$($_.DirectoryName)\$($_.BaseName).png"
}

Troubleshooting Common Issues

WebP Delegate Missing

If you encounter an error stating no decode delegate for this image format 'WEBP', your ImageMagick build was compiled without the libwebp library. You can verify available delegates by running:

magick -version

Look for webp in the Delegates (built-in) line. If missing, reinstall ImageMagick via your package manager with WebP support enabled (for example, using Homebrew on macOS via brew install imagemagick or installing libwebp-dev before compiling on Linux distributions).
