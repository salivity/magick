How to Count Unique Colors Using ImageMagick

Counting the exact number of unique colors in an image is essential for palette analysis, compression optimization, and digital asset management. This guide provides the exact ImageMagick commands required to calculate unique color totals quickly using the command line, covering both ImageMagick version 6 and version 7 syntax.

The Standard Method: Using the %k Format Specifier

The fastest and most direct way to count unique colors is using the %k format option with the identify or magick command. This flag analyzes the image and returns only the integer count of distinct colors.

For ImageMagick 7:

magick input.png -format "%k\n" info:

For ImageMagick 6:

identify -format "%k\n" input.png

Alternative Method: Using -unique-colors

ImageMagick provides the -unique-colors operator, which reduces an image to a single-row strip containing one pixel for every distinct color present in the source file. The width (%w) of this resulting strip equals the exact number of unique colors.

To get the count:

magick input.png -unique-colors -format "%w\n" info:

To export the unique colors as a readable text list containing pixel coordinates, hex codes, and color names:

magick input.png -unique-colors txt:

Handling Transparency and Alpha Channels

By default, ImageMagick treats pixels with identical RGB values but different opacity (alpha) values as distinct colors. If you want to count unique colors based strictly on RGB data while ignoring transparency, strip the alpha channel prior to calculation:

magick input.png -alpha off -format "%k\n" info:
