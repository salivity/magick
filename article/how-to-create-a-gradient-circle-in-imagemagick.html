How to Create a Gradient Circle in ImageMagick

This guide demonstrates how to generate a smooth, anti-aliased circle filled with a gradient using ImageMagick. By combining gradient canvas generation with vector shape masking, you can produce crisp, anti-aliased edges and custom color blends for both radial and linear gradients.

The ImageMagick Command

To render a 400x400 anti-aliased circle filled with a radial gradient on a transparent background, run the following command in ImageMagick 7:

magick -size 400x400 radial-gradient:gold-crimson \
\( -size 400x400 xc:none -fill white -draw "circle 200,200 200,20" \) \
-compose DstIn -composite gradient_circle.png

For ImageMagick 6, replace magick with convert:

convert -size 400x400 radial-gradient:gold-crimson \
\( -size 400x400 xc:none -fill white -draw "circle 200,200 200,20" \) \
-compose DstIn -composite gradient_circle.png

How the Command Works

  1. -size 400x400 radial-gradient:gold-crimson: Creates the base canvas with a radial color transition starting from gold at the center to crimson at the edges.
  2. \( -size 400x400 xc:none -fill white -draw "circle 200,200 200,20" \): Creates an in-memory mask.
    • xc:none establishes a fully transparent background.
    • -draw "circle 200,200 200,20" draws a circle with the center at coordinate (200, 200) and a perimeter point at (200, 20), resulting in a radius of 180 pixels. ImageMagick applies anti-aliasing to vector drawings by default.
  3. -compose DstIn -composite: Applies the mask to the gradient. The DstIn composition operator retains the gradient only where the mask contains pixels, smoothly preserving the anti-aliased edges.
  4. gradient_circle.png: Outputs the result as a PNG file supporting alpha transparency.

Using a Linear Gradient

To use a linear gradient instead of a radial gradient, replace radial-gradient: with gradient: and specify your angle using -define:

magick -size 400x400 -define gradient:angle=45 gradient:#00c6ff-#0072ff \
\( -size 400x400 xc:none -fill white -draw "circle 200,200 200,20" \) \
-compose DstIn -composite linear_gradient_circle.png
