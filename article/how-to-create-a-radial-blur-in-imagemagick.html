How to Create a Radial Blur in ImageMagick

Creating a radial blur effect from the center of an image in ImageMagick is a straightforward process using the command-line interface. This guide demonstrates how to apply a rotational blur radiating from the center of an image using ImageMagick 7 and legacy ImageMagick 6 commands, along with examples for adjusting blur strength.

ImageMagick 7 Command

In ImageMagick version 7, the -rotational-blur operator is used to create a radial blur effect centered on the image.

magick input.jpg -rotational-blur 10 output.jpg
  • input.jpg: Your source image file.
  • -rotational-blur 10: Specifies the blur angle in degrees. Higher values produce a stronger, more pronounced spin effect originating from the exact center.
  • output.jpg: The resulting blurred image.

ImageMagick 6 Command (Legacy)

If you are using ImageMagick 6, the operator was named -radial-blur:

convert input.jpg -radial-blur 10 output.jpg

Note: In ImageMagick 7, -radial-blur is an alias for -rotational-blur to maintain backward compatibility, but using -rotational-blur is recommended.

Adjusting the Center of the Blur

By default, the blur centers perfectly on the image dimensions. To apply a rotational blur around a custom center coordinate rather than the default center, you can offset the image using virtual-pixel settings and distort coordinates, or crop and pad around your desired focal point before applying -rotational-blur.
