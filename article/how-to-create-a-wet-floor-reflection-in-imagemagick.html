How to Create a Wet Floor Reflection in ImageMagick

Creating a wet floor reflection effect involves duplicating an image, flipping it vertically, applying a fading gradient mask, and appending it below the original image. This guide provides the exact ImageMagick command syntax required to generate a clean, customizable reflection effect directly from the command line.

Basic Wet Floor Reflection Syntax

In ImageMagick version 7, you can create the reflection using the magick command in a single operation:

magick input.png \
  \( +clone -flip \
     \( +clone -size %[fx:w]x%[fx:h] gradient:white-black \) \
     -alpha off -compose CopyOpacity -composite \) \
  -append output.png

For ImageMagick version 6, replace magick with convert.

Command Breakdown

  • input.png: The original source image file.
  • \( +clone -flip ... \): Creates a copy of the source image and flips it vertically to serve as the base for the reflection.
  • \( +clone -size %[fx:w]x%[fx:h] gradient:white-black \): Generates a linear gradient mask matching the exact dimensions of the image, fading from solid white at the top to solid black at the bottom.
  • -alpha off -compose CopyOpacity -composite: Applies the gradient as an alpha transparency mask, causing the reflection to fade out gradually.
  • -append: Combines the original image and the faded reflection vertically into a single file.
  • output.png: The final output image containing the combined wet floor effect.

Adding a Gap Between the Image and Reflection

To simulate thickness or surface separation, you can insert a transparent spacer between the original image and the reflection:

magick input.png \
  \( -size %[fx:w]x5 xc:none \) \
  \( input.png -flip \
     \( -size %[fx:w]x%[fx:h] gradient:rgba(255,255,255,0.7)-transparent \) \
     -compose DstIn -composite \) \
  -append output.png

In this variation, -size %[fx:w]x5 xc:none creates a 5-pixel transparent gap, and the gradient starts at 70% opacity (rgba(255,255,255,0.7)) to provide a subtler, more realistic reflection intensity.
