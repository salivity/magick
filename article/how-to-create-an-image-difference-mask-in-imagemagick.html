How to Create an Image Difference Mask in ImageMagick

Generating a visual difference mask allows you to isolate and highlight pixel-level discrepancies between two images. This guide explains how to use ImageMagick's command-line tools to compare two images of identical dimensions and output a clear mask showing exactly what has changed.

Method 1: Using the magick compare Command

The built-in compare utility provides the most direct way to create a difference mask. You can configure it to output a pure black-and-white mask where modified areas are pure white and unchanged areas are pure black.

Run the following command:

magick compare -highlight-color white -lowlight-color black image1.png image2.png difference_mask.png
  • -highlight-color white: Sets the color for pixels that differ between the two images.
  • -lowlight-color black: Sets the color for identical pixels.
  • image1.png and image2.png: The source images to compare.
  • difference_mask.png: The resulting mask file.

Method 2: Using Compose Difference with Thresholding

Another approach is to subtract one image from the other using mathematical difference composition and then apply a threshold to create a binary mask.

Run the following command:

magick image1.png image2.png -compose difference -composite -threshold 0 -negate mask.png
  • -compose difference -composite: Calculates the absolute color difference per pixel between the two images.
  • -threshold 0: Converts any non-zero difference into a solid color.
  • -negate: Inverts the mask colors if you prefer white-on-black or black-on-white.

Handling Image Noise with Fuzz

If your images contain minor compression artifacts (such as JPEG noise) that you want to ignore, use the -fuzz parameter to define an acceptable tolerance level:

magick compare -fuzz 5% -highlight-color white -lowlight-color black image1.jpg image2.jpg difference_mask.png

The -fuzz 5% flag ensures that pixel variations under 5% difference are treated as identical. Adjust this percentage higher or lower depending on the compression level of your source files.
