How to Create an XPM File Using ImageMagick

This guide explains how to create and convert images into the X PixMap (XPM) format using ImageMagick. You will find the exact command-line syntax for converting existing image files, generating blank XPM images from scratch, and optimizing color palettes for the format.

Basic Conversion Command

To convert an existing image (such as PNG, JPEG, or GIF) into an XPM file, use the primary ImageMagick magick command (or convert for ImageMagick version 6):

magick input.png output.xpm

ImageMagick detects the desired format automatically based on the .xpm file extension.

Creating an XPM File from Scratch

If you want to generate a new, solid-color XPM image without an existing source file, define the canvas size and background color:

magick -size 64x64 xc:blue output.xpm

This creates a 64x64 pixel image filled with blue in the XPM format.

Reducing Colors for XPM

Because XPM is a plain-text format where each pixel is represented by characters mapped to a color table, reducing the total number of colors keeps the file size smaller and easier to read.

To limit the color palette during conversion:

magick input.png -colors 16 output.xpm

To disable dithering and force flat colors:

magick input.png +dither -colors 16 output.xpm

Preserving Transparency

XPM supports 1-bit transparency. If your source image contains an alpha channel, ensure transparency is handled properly:

magick input.png -background none output.xpm
