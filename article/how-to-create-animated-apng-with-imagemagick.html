How to Create Animated APNG with ImageMagick

This article provides the exact ImageMagick commands required to generate animated APNG (Animated Portable Network Graphics) files from a sequence of static images. You will learn the core command syntax, how to control frame rates and looping behavior, and how to properly format your output for lossless, transparent animations.

The Basic Command

To create an animated APNG file using ImageMagick 7, use the magick command followed by the frame delay, loop count, input files, and output filename:

magick -delay 10 -loop 0 input_*.png output.apng

(Note: If you are using ImageMagick 6, replace magick with convert.)

Command Parameter Breakdown

  • -delay <value>: Sets the duration each frame is displayed. The default unit is hundredths of a second (ticks). For example:
    • -delay 10 displays each frame for 10/100 of a second (10 frames per second).
    • -delay 1x30 sets the timing precisely for 30 frames per second.
    • -delay 1x60 sets the timing precisely for 60 frames per second.
  • -loop <count>: Controls how many times the animation repeats.
    • 0 sets the animation to loop indefinitely.
    • Any positive integer (e.g., 3) will play the animation that specific number of times and then stop.
  • input_*.png: Specifies your input images in alphabetical or numerical sequence. You can list individual files (e.g., frame1.png frame2.png frame3.png) or use a wildcard pattern.
  • output.apng: The destination file. Using the .apng extension automatically instructs ImageMagick to encode the output as an Animated Portable Network Graphic.

Alternative File Extensions

If you prefer to keep a standard .png file extension while retaining animation, explicitly prepend the format driver prefix:

magick -delay 10 -loop 0 input_*.png APNG:output.png

Setting Different Delays for Individual Frames

To customize the duration of specific frames (such as pausing on the final frame), specify the -delay parameter before each individual frame:

magick -loop 0 -delay 10 frame1.png frame2.png -delay 50 frame3.png output.apng

In this example, frame1.png and frame2.png display for 0.1 seconds each, while frame3.png pauses for 0.5 seconds before the animation restarts.
