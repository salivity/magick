How to Create Beveled Photo Frames in ImageMagick

This guide explains how to add a three-dimensional beveled picture frame around any photo using ImageMagick. You will learn how to use the built-in -frame and -raise command-line operators, configure bevel dimensions and light angles, and combine matte borders to produce professional framing effects.

Method 1: Using the -frame Operator

The most efficient way to generate a beveled frame is the -frame operator. This command creates a bordered area around your photo with automatically shaded top-left highlights and bottom-right shadows to simulate depth.

Basic Command

magick input.jpg -mattecolor "#5A3D28" -frame 20x20+4+4 output.jpg

(Note: If you are using ImageMagick v6, replace magick with convert.)

Parameter Breakdown

  • -mattecolor <color>: Sets the base color of the frame. You can use standard color names (like gray, navy, black) or hex codes (such as #5A3D28 for a wooden tone).
  • -frame <width>x<height>+<outer_bevel>+<inner_bevel>:
    • 20x20: Sets the total thickness of the horizontal and vertical frame borders in pixels.
    • +4: Defines the pixel width of the outer bevel edge.
    • +4: Defines the pixel width of the inner bevel edge (adjacent to the photo).

To create a flat frame with only an outer bevel, set the inner bevel to zero:

magick input.jpg -mattecolor "#222222" -frame 25x25+5+0 output.jpg

Method 2: Applying a Direct Bevel with -raise

If you want to apply a 3D bevel directly onto the edges of the image itself without expanding its canvas dimensions, use the -raise operator.

Raised (Extruded) Bevel

magick input.jpg -raise 10 output.jpg

This lightens the top and left borders by 10 pixels and darkens the bottom and right borders, making the image appear raised toward the viewer.

Sunken (Inset) Bevel

magick input.jpg +raise 10 output.jpg

Using a plus sign (+raise) reverses the light source, darkening the top and left edges to make the image appear pressed into the background.

Method 3: Multi-Layer Picture Frame with Matte

To achieve a realistic gallery look, combine a flat inner photo mat with an outer beveled wooden or metal frame.

magick input.jpg -bordercolor "#F5F5F0" -border 20 -mattecolor "#2E1A0F" -frame 30x30+6+6 output.jpg

How It Works:

  1. -bordercolor "#F5F5F0" -border 20: Adds a 20-pixel off-white inner mat directly around the photo.
  2. -mattecolor "#2E1A0F" -frame 30x30+6+6: Wraps the matted image in a 30-pixel dark brown frame featuring 6-pixel outer and inner bevels.
