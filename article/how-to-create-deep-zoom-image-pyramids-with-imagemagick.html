How to Create Deep Zoom Image Pyramids with ImageMagick

This article explains how to generate zoomable, multi-resolution image pyramids using ImageMagick for use in deep-zoom viewers like OpenSeadragon. It covers the primary command for creating Pyramidal TIFF files (the multi-resolution format natively supported by ImageMagick), how to configure tile sizes and compression, and how to work with standard deep-zoom workflows.

The ImageMagick Pyramidal TIFF Command

ImageMagick creates multi-resolution, deep-zoom pyramids using the Pyramidal TIFF (ptif:) output format. Web viewers such as OpenSeadragon and IIIF image servers can consume these files directly or convert them on the fly.

Use the following command in ImageMagick 7:

magick input.jpg -define tiff:tile-geometry=256x256 -compress jpeg ptif:output.tif

For ImageMagick 6, replace magick with convert:

convert input.jpg -define tiff:tile-geometry=256x256 -compress jpeg ptif:output.tif

Breakdown of the Command Options

  • input.jpg: The source image you want to convert (can be JPEG, PNG, TIFF, or any format supported by ImageMagick).
  • -define tiff:tile-geometry=256x256: Specifies the width and height of each individual tile within the pyramid layers. The standard size for web viewers is 256x256 or 512x512.
  • -compress jpeg: Applies JPEG compression to each tile to keep file size manageable. You can also use zip, lzw, or none.
  • ptif:output.tif: Instructs ImageMagick to structure the output file as a multi-resolution Pyramidal TIFF containing downsampled layers from full resolution down to a single tile.

Generating Custom Tile Sets with ImageMagick

If your viewer requires loose directory-based tiles rather than a single ptif container, you can export individual tiles at a specific resolution level using the -crop operator:

magick input.jpg -crop 256x256 -set filename:tile "%[fx:page.x/256]_%[fx:page.y/256]" +repage +adjoin "tile_%[filename:tile].jpg"

This segments the base image into a 256x256 grid and names each tile with its corresponding X and Y coordinate indices.

Working with Native XML-based DZI Formats

The native Deep Zoom Image schema (consisting of a .dzi XML descriptor file alongside a _files folder containing numbered zoom folders) is a specialized export format. While ImageMagick relies on ptif: for pyramid storage, you can serve the generated ptif:output.tif directly to deep-zoom web viewers or process the image with libvips using the command vips dzsave input.jpg output if your implementation strictly requires the legacy XML folder tree.
