How to Create Duotone Images with ImageMagick

Converting a color photograph into a two-color duotone image using ImageMagick involves desaturating the original image to grayscale and mapping its tonal range between two distinct target colors. This guide provides the exact command-line syntax required to generate clean duotone effects using ImageMagick's built-in color-mapping operators.

Standard Duotone Syntax (+level-colors)

The fastest and most common method to create a duotone in ImageMagick is by combining -colorspace gray with the +level-colors operator.

ImageMagick 7 (Current)

magick input.jpg -colorspace gray +level-colors "navy,gold" output.jpg

ImageMagick 6 (Legacy)

convert input.jpg -colorspace gray +level-colors "navy,gold" output.jpg

Understanding the Command Parameters

  • input.jpg: The path to your source image.
  • -colorspace gray: Converts the color input into a high-contrast, linear grayscale image to prepare the brightness values for remapping.
  • +level-colors "<dark_tone>,<light_tone>": Maps the lowest tonal values (shadows) to the first specified color and the highest tonal values (highlights) to the second specified color. All midtones are smoothly interpolated between the two.
  • output.jpg: The resulting duotone image file.

Using Hex Color Codes

ImageMagick accepts standard hexadecimal color codes. When using hex codes in terminal commands, enclose the parameter in quotes to prevent shell interpretation of the # symbol.

magick input.jpg -colorspace gray +level-colors "#1a2a6c,#fdbb2d" duotone_hex.jpg

Alternative Method: Using Color Lookup Tables (CLUT)

For greater control over gradients and transitions, you can generate a 1D gradient in memory and apply it using the -clut operator:

magick input.jpg -colorspace gray ( -size 1x256 gradient:"#0f2027-#2c5364" ) -clut output_clut.jpg

This method produces the same basic duotone effect as +level-colors but allows you to substitute complex multi-stop gradients if you decide to expand beyond two colors later.
