How to Create DZI Pyramids with ImageMagick

Deep Zoom Images (DZI) allow users to smoothly pan and zoom through extremely high-resolution images on the web by breaking the source image into a pyramid of smaller tiles. ImageMagick includes built-in support for the DZI format, enabling you to generate the required XML descriptor and hierarchical image tiles with a single command.

The Basic Command

To convert an image into a Deep Zoom Image pyramid using ImageMagick 7, use the magick command followed by your source image and an output filename with the .dzi extension:

magick input.jpg output.dzi

For ImageMagick version 6, use the legacy convert command:

convert input.jpg output.dzi

Generated Files

Running this command creates two components in your working directory:

  1. output.dzi: An XML file containing metadata such as original image dimensions, tile size, overlap, and image format.
  2. output_files/: A folder containing subdirectories numbered by zoom level (e.g., 0, 1, 2, ..., N), each containing the individual square image tiles.

Advanced Configuration Options

ImageMagick provides several -define arguments to customize the DZI output to fit your viewer requirements (such as OpenSeadragon).

  • Tile Size: Sets the width and height of individual tiles in pixels (default is usually 254).
  • Overlap: Sets the pixel overlap between adjacent tiles (default is usually 1).
  • Format: Specifies the file format for individual tiles (e.g., jpg or png).

Custom Example Command

magick large_image.tif -define dzi:tile-size=256 -define dzi:overlap=1 -define dzi:format=jpg -quality 85 output.dzi

In this command:

  • large_image.tif is the high-resolution input file.
  • -define dzi:tile-size=256 generates tiles that are 256x256 pixels.
  • -define dzi:overlap=1 adds a 1-pixel border overlap around tiles for seamless stitching.
  • -define dzi:format=jpg outputs the generated tiles as JPEGs.
  • -quality 85 compresses the JPEG tiles to reduce total file size.
  • output.dzi defines the target output.
