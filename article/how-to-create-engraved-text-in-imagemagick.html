How to Create Engraved Text in ImageMagick

Creating an engraved or sunken text effect in ImageMagick involves manipulating light and shadow to trick the eye into perceiving depth. This guide provides the exact commands needed to render carved text onto a surface, utilizing offset highlight and shadow layers to produce a convincing three-dimensional recessed look.

The Standard Engraved Text Command

To achieve a sunken text effect, the top and left edges of the text must be dark (simulating an interior shadow cast by ambient light), while the bottom and right edges must be light (simulating an illuminated lower lip).

The following command generates an image with an engraved text effect on a solid background:

magick -size 600x200 xc:#707070 \
  -font Arial-Bold -pointsize 64 \
  -fill "#404040" -annotate +50+129 "ENGRAVED TEXT" \
  -fill "#9a9a9a" -annotate +52+131 "ENGRAVED TEXT" \
  -fill "#606060" -annotate +51+130 "ENGRAVED TEXT" \
  engraved_text.png

If you are using ImageMagick version 6, replace magick with convert.

Parameter Breakdown

  • -size 600x200 xc:#707070: Creates a canvas of 600 by 200 pixels with a neutral gray background.
  • -font Arial-Bold -pointsize 64: Specifies the font face and text size. Bolder typefaces work best for carved effects.
  • -fill "#404040" -annotate +50+129: The inner shadow. It is darker than the background and positioned 1 pixel up and left from the center text.
  • -fill "#9a9a9a" -annotate +52+131: The highlighted edge. It is lighter than the background and positioned 1 pixel down and right from the center text.
  • -fill "#606060" -annotate +51+130: The main body of the text. Setting this slightly darker than the canvas color enhances the recessed look.

Realistic Carved Effect Using Shade and Blur

For a softer, more realistic carved effect on textures, generate a displacement mask using a Gaussian blur and apply a directional light source using the -shade operator:

magick -size 600x200 xc:black \
  -font Arial-Black -pointsize 64 -fill white \
  -annotate +50+130 "ENGRAVED TEXT" \
  -gaussian-blur 0x2 -shade 135x45 \
  -normalize \
  \( -size 600x200 xc:#707070 \) +swap \
  -compose Overlay -composite \
  engraved_shaded.png

Parameter Breakdown

  • -gaussian-blur 0x2: Softens the text edges to create a sloping bevel instead of a flat edge.
  • -shade 135x45: Simulates light falling across the surface at an azimuth of 135 degrees and an elevation of 45 degrees.
  • -normalize: Maximizes the contrast between the highlighted and shadowed bevels.
  • -compose Overlay -composite: Blends the generated depth map over the background color to create the final recessed effect.
