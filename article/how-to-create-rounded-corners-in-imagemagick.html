How to Create Rounded Corners in ImageMagick

This guide explains how to apply rounded corners to images using ImageMagick's masking techniques. By generating an in-memory alpha mask with rounded dimensions and compositing it onto your source image using the DstIn composition method, you can dynamically create clean, antialiased, transparent rounded corners directly from the command line.

The Standard Masking Command

In ImageMagick 7, you can create rounded corners in a single, self-contained command without needing to pre-calculate image dimensions or create temporary mask files on disk.

magick input.jpg \
  \( +clone -alpha extract \
     -draw "fill black polygon 0,0 0,15 15,0 fill white circle 15,15 15,0" \
     \( +clone -flip \) -compose Multiply -composite \
     \( +clone -flop \) -compose Multiply -composite \) \
  -alpha off -compose CopyOpacity -composite output.png

Alternatively, the modern and most efficient approach uses the roundrectangle draw primitive combined with -compose DstIn:

magick input.jpg \
  \( +clone -alpha transparent -background none \
     -fill white -draw "roundrectangle 0,0,%[fx:w-1],%[fx:h-1],20,20" \) \
  -alpha set -compose DstIn -composite output.png

How the Masking Process Works

  1. Load the Source Image: magick input.jpg loads the target image into memory.
  2. Clone and Create the Mask: The parentheses \( ... \) isolate operations on a duplicate of the image:
    • +clone makes a duplicate of the original image dimensions.
    • -alpha transparent clears the clone so it acts as a blank canvas.
    • -draw "roundrectangle 0,0,%[fx:w-1],%[fx:h-1],rx,ry" draws a solid white rectangle with rounded corners covering the full width and height. Replace 20,20 with your desired horizontal and vertical corner radius in pixels.
  3. Composite with DstIn:
    • -alpha set ensures the source image has an active alpha channel.
    • -compose DstIn -composite applies the mask. The DstIn operator retains only the parts of the original image that overlap with the opaque white areas of the mask, making the outer corners transparent.
  4. Save Output: The result must be saved in a format that supports transparency, such as PNG, WebP, or TIFF.

Applying to Fixed Dimensions

If you are resizing the image and applying rounded corners simultaneously, you can specify exact pixel values instead of dynamic properties:

magick input.jpg -resize 400x400^ -gravity center -extent 400x400 \
  \( +clone -alpha transparent \
     -fill white -draw "roundrectangle 0,0,399,399,30,30" \) \
  -alpha set -compose DstIn -composite output.png

This command crops the image to a square 400x400 dimension and applies a 30-pixel rounded corner radius cleanly across all four edges.
