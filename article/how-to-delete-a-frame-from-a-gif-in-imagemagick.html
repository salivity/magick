How to Delete a Frame from a GIF in ImageMagick

This guide demonstrates how to remove specific frames from an animated GIF using ImageMagick's command-line interface. You will learn the correct command syntax for ImageMagick v7 and v6, how zero-based frame indexing works, how to delete individual or multiple frame ranges, and how to maintain proper GIF optimization during the process.

The Basic Syntax

ImageMagick uses the -delete operator to remove frames from an image sequence in memory before writing to the output file.

For ImageMagick 7, use the magick command:

magick input.gif -delete [index] output.gif

For ImageMagick 6, use the convert command:

convert input.gif -delete [index] output.gif

Understanding Frame Indexing

ImageMagick utilizes zero-based indexing, meaning the frame count starts at 0:

  • Frame 1 = index 0
  • Frame 2 = index 1
  • Frame 3 = index 2
  • Last frame = index -1

Common Usage Examples

Delete a Single Frame

To delete the third frame (index 2) from an animated GIF:

magick input.gif -delete 2 output.gif

To delete the first frame:

magick input.gif -delete 0 output.gif

To delete the last frame:

magick input.gif -delete -1 output.gif

Delete Multiple Specific Frames

To delete multiple non-consecutive frames, separate the indices with commas:

magick input.gif -delete 1,4,7 output.gif

Delete a Range of Frames

To delete a consecutive sequence of frames, define the range with a hyphen (e.g., removing frames 3 through 6):

magick input.gif -delete 2-5 output.gif

Handling Optimized or Layered GIFs

Many GIFs use frame optimization where subsequent frames only contain changed pixels (differential frames). Deleting a frame from an optimized GIF can cause visual glitches or timing errors.

To prevent artifacts, unpack the frames with -coalesce before deletion, and re-optimize them with -layers optimize afterward:

magick input.gif -coalesce -delete 2 -layers optimize output.gif
