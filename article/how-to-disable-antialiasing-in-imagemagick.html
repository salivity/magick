How to Disable Antialiasing in ImageMagick

This article explains how to disable antialiasing during vector shape and text rasterization in ImageMagick. By default, ImageMagick applies smoothing algorithms to blend vector edges with surrounding pixels. Learning how to turn off this feature allows you to produce crisp, pixelated edges, generate binary masks, or maintain strict color palettes without intermediate blended pixels.

The +antialias Parameter

The parameter used to disable antialiasing in ImageMagick is +antialias.

In ImageMagick's command-line syntax, a minus sign (-) typically enables a feature, while a plus sign (+) disables it. Therefore, while -antialias enables edge smoothing (which is active by default), +antialias forces ImageMagick to rasterize shapes and fonts with hard, aliased edges.

Using +antialias with Vector Drawing Primitives

When drawing vector shapes directly using the -draw operator, place +antialias before the draw operation to prevent edge smoothing.

magick -size 200x200 xc:white +antialias -fill black -draw "circle 100,100 100,20" output.png

In this command:

  • xc:white creates a white canvas.
  • +antialias disables pixel blending for subsequent operations.
  • -draw "circle ..." draws a circle with hard, jagged pixel boundaries.

Disabling Antialiasing for Text

You can also apply +antialias when rendering typography to achieve a retro, pixelated look or when creating sharp text masks:

magick -size 300x100 xc:black +antialias -font Arial -pointsize 32 -fill white -annotate +20+60 "Sample Text" text.png

Rasterizing Vector Files (SVG, PDF, EPS)

When converting vector files like SVG or PDF to raster formats (such as PNG or JPEG), +antialias must appear before the input file to ensure the rasterizer interprets the vector paths without edge filtering.

magick +antialias input.svg output.png

Placing the parameter before reading the input ensures that the rendering engine skips anti-aliasing during the initial rasterization step.
