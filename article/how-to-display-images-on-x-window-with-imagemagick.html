How to Display Images on X Window with ImageMagick

This guide explains how to use ImageMagick's display utility to render images directly onto an X Window System (X11) server. You will learn the basic command syntax, how to target specific local or remote X displays using command-line options and environment variables, how to project images onto the root desktop window, and how to manage standard X11 display permissions.

Basic Image Display

To open and display an image on the current default X display, run the display command followed by the file path:

display image.png

This opens an X11 window showing the specified image. Clicking on the image opens the interactive ImageMagick control menu.

Targeting a Specific X Server

If you are working across multiple monitors, virtual screens, or remote machines, you can explicitly direct output to a specific X server using the -display option.

Syntax

display -display <hostname>:<display_number>.<screen_number> <filename>

Examples

  • Local default screen:

    display -display :0.0 image.png

  • Local secondary screen:

    display -display :0.1 image.png

  • Remote X server over a network:

    display -display 192.168.1.50:0.0 image.png

Alternatively, you can set the DISPLAY environment variable in your shell before running the command:

export DISPLAY=:0.0
display image.png

Setting the Image to the Root Window (Wallpaper)

To display an image directly onto the X server's root window (the desktop background) rather than in a standalone application window, use the -window root option:

display -window root -resize 1920x1080! image.png
  • The -resize flag scales the image to match your display resolution.
  • Adding the exclamation mark (!) forces the exact dimensions, ignoring the original aspect ratio.

Handling X11 Permissions and Authentication

When displaying an image to an X server from another user account (such as root) or over a network, access might be denied by default.

Granting Access with xhost

Run this on the host running the X server to allow incoming connections:

  • Allow a specific user or IP: 
    xhost +SI:localuser:username
xhost +192.168.1.100

Using MIT-MAGIC-COOKIE (xauth)

For secure environments, ensure the current session has access to the user's .Xauthority file:

export XAUTHORITY=/home/username/.Xauthority
display -display :0.0 image.png

Useful Display Options

  • Full screen backdrop: -backdrop centers the image surrounded by a solid background.
  • Immutable view: -immutable disables user interaction and the pop-up menu.
  • Timed display: -delay <seconds> controls playback when displaying multiple images sequentially.
