How to Draw a Cubic Bezier Curve in ImageMagick

Drawing a cubic Bezier curve in ImageMagick involves using the -draw operator with the bezier graphic primitive. By supplying four coordinate pairs representing the start point, two control points, and the end point, you can render smooth, vector-based curves directly onto any image canvas from the command line.

The Cubic Bezier Syntax

A cubic Bezier curve requires four control points:

  1. \(P_0\) (Start Point): Where the curve begins (\(x_0, y_0\)).
  2. \(P_1\) (First Control Point): Determines the initial direction and curvature (\(x_1, y_1\)).
  3. \(P_2\) (Second Control Point): Determines the incoming direction toward the end (\(x_2, y_2\)).
  4. \(P_3\) (End Point): Where the curve terminates (\(x_3, y_3\)).

In ImageMagick, the syntax inside the -draw parameter is formatted as:

-draw "bezier x0,y0 x1,y1 x2,y2 x3,y3"

Basic Command Example

To create a new canvas and draw a cubic Bezier curve using ImageMagick v7 (magick), run the following command:

magick -size 500x500 xc:white \
  -stroke blue -strokewidth 4 -fill none \
  -draw "bezier 50,450 100,50 400,50 450,450" \
  bezier_output.png

(Note: For ImageMagick v6, replace magick with convert.)

Command Breakdown

  • -size 500x500 xc:white: Creates a blank 500x500 pixel canvas with a white background.
  • -stroke blue: Sets the line color of the curve.
  • -strokewidth 4: Sets the line thickness in pixels.
  • -fill none: Prevents ImageMagick from filling the area enclosed by the curve with color. If a fill color is specified, the region between the curve and the baseline connecting the start and end points will be filled.
  • -draw "bezier ...": Specifies the four coordinate pairs defining the cubic curve.
  • bezier_output.png: The final output file name.

Drawing Connected Cubic Bezier Segments

ImageMagick allows you to chain multiple cubic Bezier segments together in a single command. To create continuous cubic curves, provide \(3n + 1\) points (such as 7, 10, or 13 points), where the end point of the previous segment serves as the start point of the next segment:

magick -size 600x300 xc:white \
  -stroke red -strokewidth 3 -fill none \
  -draw "bezier 50,150 100,50 200,50 250,150 300,250 400,250 450,150" \
