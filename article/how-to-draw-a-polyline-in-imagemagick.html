How to Draw a Polyline in ImageMagick

This guide explains how to draw an open, multi-segment vector line using ImageMagick's -draw 'polyline' primitive. You will learn the exact command syntax, how coordinates are structured, and how to apply essential styling options such as stroke color, stroke width, and fill properties to ensure the line remains open and clear.

The Basic Polyline Command

To draw an open multi-segment vector line, use the magick command (or convert in ImageMagick v6) along with the -draw option defining the polyline primitive followed by coordinate pairs:

magick -size 400x400 xc:white -stroke blue -strokewidth 3 -fill none -draw "polyline 50,50 150,200 250,100 350,300" output.png

Command Breakdown

  • -size 400x400 xc:white: Creates a blank canvas measuring 400 by 400 pixels with a white background.
  • -stroke blue: Defines the color of the vector line. You can use standard color names, hex codes (e.g., '#0000FF'), or RGB/RGBA values.
  • -strokewidth 3: Sets the thickness of the line segments in pixels.
  • -fill none: Crucial for open polylines. By default, ImageMagick applies a fill color to the area enclosed by the coordinates. Setting -fill none ensures that only the line segments are rendered without filling the space between them.
  • -draw "polyline x0,y0 x1,y1 ... xn,yn": Specifies the vertices of the line. ImageMagick connects each consecutive pair of x,y coordinates with a straight line segment, starting from the first point and ending at the last point without closing the path back to the origin.
  • output.png: The destination file where the resulting image is saved.

Coordinate Formatting

Coordinates inside the polyline primitive can be separated by spaces or commas. The following formats are both valid and produce the same result:

  • Space-separated pairs: -draw "polyline 20,20 80,120 150,40"
  • Comma-separated values: -draw "polyline 20 20, 80 120, 150 40"

Unlike the polygon primitive, polyline does not automatically connect the final coordinate to the starting coordinate, leaving the path open.
