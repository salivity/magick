How to Draw a Stroked Polygon in ImageMagick

This article provides a concise guide on using ImageMagick to draw stroked polygons on existing images or blank canvases. By utilizing the -draw operator alongside stroke and fill styling parameters, you can easily control the outline color, line thickness, and interior fill of any multi-sided geometric shape via the command-line interface.

Basic Syntax

In ImageMagick (version 7+ uses magick, while version 6 uses convert), a stroked polygon is drawn using the -draw option with the polygon primitive, combined with -stroke, -strokewidth, and -fill settings.

magick input.jpg -stroke <color> -strokewidth <pixels> -fill <fill_color> -draw "polygon x1,y1 x2,y2 x3,y3 ..." output.jpg

Parameter Breakdown

  • -stroke <color>: Defines the outline color. Accepts standard color names (e.g., red, blue), hex codes ("#FF5733"), or RGB values ("rgb(255,0,0)").
  • -strokewidth <width>: Sets the thickness of the polygon border in pixels.
  • -fill <color>: Sets the interior color. Set this to none if you only want the stroke (hollow polygon).
  • -draw "polygon ...": Defines the shape. Coordinates are specified as sequential X,Y pairs (x1,y1 x2,y2 x3,y3 ...). ImageMagick automatically connects the last point back to the first point to close the shape.

Examples

1. Draw a Stroked Polygon with a Solid Fill

To draw a triangle with a blue border of 4 pixels and a yellow interior on an existing image:

magick input.png -stroke blue -strokewidth 4 -fill yellow -draw "polygon 100,50 200,200 50,200" output.png

2. Draw an Outlined (Hollow) Polygon

To draw only the stroke without filling the center, set -fill to none:

magick input.png -stroke red -strokewidth 3 -fill none -draw "polygon 50,50 150,30 220,100 180,200 80,180" output.png

3. Draw on a New Canvas

To generate a new image canvas from scratch with a stroked polygon:

magick -size 400x400 xc:white -stroke "#333333" -strokewidth 5 -fill "#66CCFF" -draw "polygon 200,40 340,140 280,320 120,320 60,140" polygon_canvas.png
