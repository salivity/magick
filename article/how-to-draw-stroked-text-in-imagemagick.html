How to Draw Stroked Text in ImageMagick

This guide demonstrates how to render text with a contrasting stroke or outline in ImageMagick using straightforward command-line syntax. You will learn the specific options required to set the interior color, outline color, and border thickness, as well as a technique to keep the inner font sharp when using thick outlines.

Basic Syntax

To create stroked text, use the -stroke option for the outline color, -strokewidth for the thickness in pixels, and -fill for the interior text color.

In ImageMagick version 7, the syntax is:

magick input.jpg -font Arial -pointsize 48 \
  -stroke black -strokewidth 3 -fill white \
  -gravity center -annotate +0+0 "Sample Text" \
  output.jpg

(Note: For ImageMagick version 6, replace magick with convert.)

Key Parameters Explained

  • -stroke <color>: Sets the color of the text outline (e.g., black, #000000).
  • -strokewidth <integer>: Sets the thickness of the outline in pixels.
  • -fill <color>: Sets the fill color of the text interior (e.g., white, #FFFFFF).
  • -font <font_name>: Specifies the font file or system font name.
  • -pointsize <points>: Controls the text size.
  • -gravity <position>: Sets the anchor point (e.g., center, northwest).
  • -annotate +X+Y "Text": Draws the text at the specified offset coordinates.

Preventing Overlap on Thick Borders

When using a large -strokewidth, the stroke expands both outward and inward, which can clip and distort the inner fill of thin font characters. To fix this, draw the text twice in a single command: first with the stroke, and then over top with only the fill.

magick input.jpg -font Arial-Bold -pointsize 60 -gravity center \
  -stroke black -strokewidth 8 -fill none -annotate +0+0 "Crisp Outline" \
  -stroke none -fill white -annotate +0+0 "Crisp Outline" \
  output.jpg

This method ensures the outline expands purely outward, maintaining the original legibility and shape of the font face.
