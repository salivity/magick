How to Embed IPTC Copyright in ImageMagick

This guide explains how to embed IPTC copyright notices directly into image files using ImageMagick. While ImageMagick is primarily an image processing utility, it manages IPTC metadata via Photoshop 8BIM resource profiles. Below, you will find the exact syntax, configuration formats, inline command variations, and verification steps required to add copyright information to single images or batches.

Understanding IPTC Tags in ImageMagick

IPTC data is structured into records and dataset tags. The IPTC standard designates record 2, dataset 116 specifically for the Copyright Notice. In ImageMagick, IPTC data cannot always be written as a simple string flag on the command line; instead, it is injected via the 8BIMTEXT profile format.

The syntax for an IPTC entry in ImageMagick is: 2#<dataset_number>#<dataset_name>="<value>"

For a copyright notice, the entry looks like this: 2#116#Copyright Notice="Copyright (c) 2024 Your Name. All Rights Reserved."

Method 1: Embedding via a Metadata Text File

The most reliable way to apply IPTC copyright metadata across all operating systems is using a dedicated text definition file.

  1. Create a plain text file named copyright.txt.
  2. Add the IPTC copyright specification:
2#116#Copyright Notice="Copyright (c) 2024 Your Name. All Rights Reserved."
  1. Run the ImageMagick command to combine the image and the profile:

ImageMagick v7:

magick input.jpg 8BIMTEXT:copyright.txt output.jpg

ImageMagick v6:

convert input.jpg 8BIMTEXT:copyright.txt output.jpg

Method 2: Inline Single-Command Syntax (Linux / macOS)

If you are using a Unix-like shell (such as Bash or Zsh), you can use process substitution to pass the IPTC string directly without saving a temporary text file.

ImageMagick v7:

magick input.jpg 8BIMTEXT:<(printf '2#116#Copyright Notice="Copyright (c) 2024 Your Name. All Rights Reserved."') output.jpg

ImageMagick v6:

convert input.jpg 8BIMTEXT:<(printf '2#116#Copyright Notice="Copyright (c) 2024 Your Name. All Rights Reserved."') output.jpg

Method 3: Batch Processing with Mogrify

To apply the copyright notice in-place across multiple images within a directory, use mogrify along with your copyright.txt profile file.

ImageMagick v7:

magick mogrify -profile 8BIMTEXT:copyright.txt *.jpg

ImageMagick v6:

mogrify -profile 8BIMTEXT:copyright.txt *.jpg

Verifying the Embedded IPTC Copyright

To ensure the copyright metadata was successfully written to the file, query the IPTC:2:116 tag using the identify utility:

ImageMagick v7:

magick identify -format "%[IPTC:2:116]\n" output.jpg

ImageMagick v6:

identify -format "%[IPTC:2:116]\n" output.jpg

If applied correctly, the terminal will print the copyright string embedded in the file.
