How to Embed XMP Metadata with ImageMagick

This article provides a concise guide on how to inject or embed an external XMP (Extensible Metadata Platform) sidecar file into an image using ImageMagick. You will learn the exact command-line syntax required to write XMP profile blocks into supported image formats like JPEG, PNG, and TIFF.

The Command to Embed XMP Metadata

To embed an external XMP metadata file into an image file, use the -profile operator prefixed with xmp:.

ImageMagick v7 Syntax

magick input.jpg -profile "xmp:metadata.xmp" output.jpg

ImageMagick v6 Syntax

convert input.jpg -profile "xmp:metadata.xmp" output.jpg

Modifying Images In-Place

If you want to apply an XMP sidecar file directly to an existing image without creating a new output file, use the mogrify command:

magick mogrify -profile "xmp:metadata.xmp" input.jpg

(For ImageMagick v6, omit magick and run mogrify -profile "xmp:metadata.xmp" input.jpg)

How It Works

  • -profile "xmp:filename.xmp": Tells ImageMagick to read the specified file as raw XML/XMP data and attach it to the image container's standard XMP metadata segment (such as the APP1 segment in JPEG files).
  • Format Support: This method works across various formats that support embedded profiles, including JPEG, TIFF, PNG, and WebP.

Verifying the Embedded XMP Profile

To confirm that the XMP metadata has been successfully embedded into the image, run:

magick identify -verbose output.jpg | grep -i xmp

To extract and view the entire embedded XMP block:

magick output.jpg xmp:-
