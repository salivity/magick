How to Encode Lossless WebP in ImageMagick

This guide explains how to convert images to the WebP format using lossless compression with ImageMagick. By using specific command-line arguments and definitions, you can ensure that your images retain pixel-perfect quality while taking advantage of WebP's superior file-size reduction compared to traditional formats like PNG.

The Basic Command for Lossless WebP

To encode an image as a lossless WebP file in ImageMagick (version 7 and later), use the magick command paired with the webp:lossless=true definition flag:

magick input.png -define webp:lossless=true output.webp

If you are using ImageMagick version 6, replace magick with the legacy convert command:

convert input.png -define webp:lossless=true output.webp

Controlling Compression Effort and File Size

In lossless WebP encoding, the -quality parameter changes function. Instead of degrading image quality, it controls the computational effort spent trying to achieve the smallest possible file size:

  • Lower values (e.g., -quality 0): Faster compression, larger file size.
  • Default value (-quality 75): Balanced compression speed and file size.
  • Higher values (e.g., -quality 100): Slowest compression, smallest file size.

Example with Maximum Compression:

magick input.png -define webp:lossless=true -quality 100 output.webp

Advanced Lossless Compression Flags

You can further fine-tune the lossless encoding process using additional -define parameters:

1. Compression Method (webp:method)

The method parameter ranges from 0 (fastest) to 6 (slowest and best compression).

magick input.png -define webp:lossless=true -define webp:method=6 output.webp

2. Alpha Channel Filtering

To preserve transparent backgrounds properly while maintaining lossless compression, the default settings will automatically preserve alpha data. You can explicitly adjust how the alpha channel is compressed using:

magick input.png -define webp:lossless=true -define webp:alpha-quality=100 output.webp

Batch Converting Images to Lossless WebP

To convert multiple PNG files in a directory to lossless WebP using ImageMagick:

Linux / macOS (Bash):

for file in *.png; do
    magick "$file" -define webp:lossless=true "${file%.png}.webp"
done

Windows (Command Prompt):

for %f in (*.png) do magick "%f" -define webp:lossless=true "%~nf.webp"
