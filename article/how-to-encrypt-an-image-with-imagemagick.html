How to Encrypt an Image with ImageMagick

ImageMagick includes a built-in -encipher operator that allows users to convert visual image data into encrypted visual noise using a passphrase file. This article explains how to prepare a key file, execute the encipher command from the terminal, avoid common format pitfalls, and decrypt the resulting image using the -decipher operator.

1. Create a Passphrase File

The -encipher operator requires a standard text file containing your passphrase to handle the encryption key.

Create a plain text file named passphrase.txt and enter your desired password:

echo "YourStrongPassphraseHere" > passphrase.txt

2. Encrypt the Image Using -encipher

Run the ImageMagick command by specifying the input image, the -encipher operator pointing to your passphrase file, and the output filename.

For ImageMagick v7+:

magick input.jpg -encipher passphrase.txt encrypted.png

For ImageMagick v6:

convert input.jpg -encipher passphrase.txt encrypted.png

The resulting encrypted.png file will appear as random visual static or pixel noise.

3. Critical Requirement: Use Lossless Formats

Encrypted images must be saved in a lossless format, such as PNG, TIFF, or MIFF.

Do not save the encrypted output as a JPEG. JPEG applies lossy compression, which alters the exact pixel values upon saving. If encrypted pixel values are modified by compression artifacts, the image cannot be decrypted and will be permanently corrupted.

4. Decrypt the Image Using -decipher

To restore the encrypted image back to its original visual state, run the command using the -decipher operator with the same passphrase file:

For ImageMagick v7+:

magick encrypted.png -decipher passphrase.txt decrypted.png

For ImageMagick v6:

convert encrypted.png -decipher passphrase.txt decrypted.png

If the passphrase matches and the encrypted file was saved in a lossless format, decrypted.png will match the original image.
