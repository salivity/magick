How to Execute the ImageMagick 7 Magick Command

ImageMagick 7 introduces a unified command-line tool that consolidates previously separate utilities—such as convert, identify, and mogrify—into a single executable called magick. This guide explains how to execute the unified magick binary, run legacy subcommands, and perform essential image-processing tasks using modern command structures.

The Basic Command Syntax

In ImageMagick 7, the primary binary is invoked directly by typing magick followed by the input image, any processing operations, and the output path:

magick input.jpg [operations] output.png

Unlike ImageMagick 6, operations are processed strictly from left to right. This means you should read the image file before applying filters or geometry transformations to ensure proper execution.

Replacing Legacy Commands

In previous versions, each operation had its own binary (such as convert). In ImageMagick 7, convert is deprecated to prevent collisions with built-in operating system utilities (like Windows convert.exe).

To replace convert, use magick directly:

  • Old (ImageMagick 6): convert input.jpg -resize 50% output.jpg
  • New (ImageMagick 7): magick input.jpg -resize 50% output.jpg

Calling Other ImageMagick Utilities

Traditional utilities other than convert are executed by passing the utility name as the first argument after magick:

  • Identify: Inspect image metadata. 
    magick identify photo.jpg
  • Mogrify: Overwrite images or perform batch edits in place. 
    magick mogrify -resize 800x600 *.png
  • Composite: Combine two images into one. 
    magick composite overlay.png base.jpg result.jpg
  • Compare: Highlight differences between two images. 
    magick compare original.png modified.png difference.png
  • Montage: Create a composite grid of image thumbnails. 
    magick montage *.jpg -geometry +2+2 grid.jpg

Practical Execution Examples

Convert Image Formats Change a PNG file to a modern WebP format:

magick input.png output.webp

Resize and Compress Resize an image to a specific width while maintaining aspect ratio and adjusting JPEG quality:

magick input.jpg -resize 1920x -quality 85 output.jpg

Chain Multiple Operations Crop an image, apply a grayscale effect, and rotate it in a single command execution:

magick input.jpg -crop 500x500+50+50 -colorspace Gray -rotate 90 processed.jpg

Execute Scripts via magick-script ImageMagick 7 also includes magick-script, allowing you to execute complex operations from a script file without reloading the binary repeatedly:

magick -script script.mgk
