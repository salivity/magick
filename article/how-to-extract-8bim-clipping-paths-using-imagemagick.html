How to Extract 8BIM Clipping Paths Using ImageMagick

This article provides a complete guide on how to identify, extract, and apply embedded Photoshop 8BIM clipping paths using ImageMagick. You will learn the exact command-line syntax required to check for existing vector paths, export them as standalone SVG vector files or raw metadata, and use the paths directly to cut out backgrounds and generate transparent images.

Understanding 8BIM Clipping Paths

Adobe Photoshop stores vector clipping paths inside image metadata as an 8BIM profile resource (specifically resource ID 1999 for the active path). ImageMagick natively recognizes these profiles in formats like JPEG, TIFF, and PSD, allowing you to manipulate or export them without needing Adobe software.

Step 1: Check for Embedded Clipping Paths

Before extracting, verify that the image contains an embedded clipping path.

Run the following command in ImageMagick 7:

magick identify -verbose input.jpg | grep -i "Clipping Path"

(For ImageMagick 6, replace magick with identify.)

If a path is present, the output will list the name of the clipping path (for example, Clipping Path 1 or Path 1) along with the 8BIM profile details.

Step 2: Extract the Clipping Path as an SVG File

ImageMagick can automatically translate the embedded Photoshop vector bezier curve data into a standard SVG vector file.

To export the path as an SVG, use:

magick input.jpg output_path.svg

This generates a standalone SVG file containing the coordinates of the clipping path, which can be opened and edited in vector graphic software like Adobe Illustrator or Inkscape.

Step 3: Extract the Raw 8BIM Profile

If you need the raw 8BIM binary metadata block or a text representation of the path coordinates, use the 8BIM format specifiers:

To export raw 8BIM binary data:

magick input.jpg 8BIM:profile.8bim

To export the 8BIM path data as text:

magick input.jpg 8BIMTEXT:path.txt

Step 4: Apply the Clipping Path to Create a Cutout

If your goal is to extract the subject defined by the clipping path onto a transparent background, you can apply the path directly to the image using the -clip and -alpha operators.

Exporting an Isolated Subject (PNG)

magick input.jpg -clip -alpha transparent output.png

If the image contains multiple paths and you need to specify a path by name:

magick input.jpg -clip-path "Path 1" -alpha transparent output.png

Inverting the Selection

If the clipping path isolates the background instead of the subject, invert the mask during conversion:

magick input.jpg -clip -negate -alpha transparent output.png

Step 5: Extract the Clipping Mask as a Grayscale Matte

To extract the clipping path as an 8-bit black-and-white mask image (where white represents the retained area and black represents the clipped area):

magick input.jpg -clip -alpha transparent -alpha extract mask.png
