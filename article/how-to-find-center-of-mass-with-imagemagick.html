How to Find Center of Mass with ImageMagick

Computing the center of mass (centroid) of an isolated object in ImageMagick involves isolating the target shape onto a binary or transparent background and using image moments to extract the precise \((X, Y)\) coordinate. This guide explains how to preprocess the image and run the calculation using ImageMagick's built-in moment analysis tools.

Step 1: Preprocess the Image

To get an accurate center of mass, the object must be represented by non-zero pixel values (white or foreground), while the background must be pure zero (black). If your image has a non-black background, convert it using thresholding or alpha separation.

For a grayscale or color image on a white background:

magick input.png -colorspace Gray -negate -threshold 50% mask.png

For an image with a transparent background:

magick input.png -alpha extract mask.png

Step 2: Calculate the Centroid Using Image Moments

ImageMagick provides a -moments operator that calculates spatial moments, directly outputting the centroid of all foreground pixels.

Run the following command to print the X and Y coordinates:

magick mask.png -moments -format "Center of Mass: X = %[moments:Centroid.X], Y = %[moments:Centroid.Y]\n" info:

Step 3: Direct Single-Command Execution

You can combine preprocessing and coordinate extraction into a single command without creating intermediate files:

magick input.png -alpha extract -moments -format "%[moments:Centroid.X],%[moments:Centroid.Y]\n" info:

Alternative: Custom Calculation Using FX Expressions

If you need intensity-weighted center of mass calculations (where brighter pixels contribute more mass than dimmer pixels), compute it directly using ImageMagick's fx engine:

magick input.png -colorspace Gray -format "X: %[fx:mean.x*w], Y: %[fx:mean.y*h]\n" info:
  • %[moments:Centroid.X] and %[moments:Centroid.Y] provide standard spatial center-of-gravity coordinates.
  • mean.x*w and mean.y*h calculate the normalized first-order moment scaled to the pixel dimensions of the image.
