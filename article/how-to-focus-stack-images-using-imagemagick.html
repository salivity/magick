How to Focus Stack Images Using ImageMagick

Focus stacking is a digital image processing technique that combines multiple photos taken at varying focus distances to create a single composite image with an extended depth of field. ImageMagick can perform focus stacking natively via the command line by analyzing image sharpness through edge detection, generating mask layers for the highest-contrast regions, and blending the focused areas into a final composite.

Prerequisites

Before focus stacking, all source images must be precisely aligned and of the identical dimension. If the images are handheld or have slight focal breathing shifts, align them first using an alignment tool like align_image_stack before processing with ImageMagick.

Basic Syntax for Two-Image Focus Stacking

For two aligned images (focus1.jpg and focus2.jpg), the process involves detecting the high-contrast edges of each image to determine which pixels are in focus, creating a mask, and compositing them:

magick focus1.jpg focus2.jpg \
  \( -clone 0 -colorspace Gray -edge 2 \) \
  \( -clone 1 -colorspace Gray -edge 2 \) \
  \( -clone 2,3 -compose Difference -composite -threshold 0 \) \
  -delete 2,3 \
  -compose Over -composite \
  stacked_output.jpg

Explanation of the Parameters:

  • magick focus1.jpg focus2.jpg: Loads the input images into the sequence (indexes 0 and 1).
  • \( -clone 0 -colorspace Gray -edge 2 \): Creates a grayscale copy of the first image and applies an edge-detection filter to isolate sharp details.
  • \( -clone 1 -colorspace Gray -edge 2 \): Applies the same edge-detection filter to the second image.
  • \( -clone 2,3 -compose Difference -composite -threshold 0 \): Compares the sharpness maps of both images to create a binary mask distinguishing sharper regions.
  • -delete 2,3: Removes intermediate edge-detection layers to free memory.
  • -compose Over -composite: Uses the calculated mask to blend the sharpest sections of the second image onto the first image.
  • stacked_output.jpg: The resulting composite with extended depth of field.

Advanced Multi-Image Focus Stacking Syntax

When working with three or more images, you can evaluate the local variance (Laplacian sharpness metric) across the stack to construct weighted composite layers:

magick input_*.jpg \
  \( -clone 0--1 -colorspace Gray -morphology Edge Diamond:1 -blur 0x3 \) \
  -insert 0 \
  -compose Blend -composite \
  final_stacked_output.jpg
  • input_*.jpg: Loads all sequenced input images.
  • -clone 0--1: Selects all loaded images.
  • -morphology Edge Diamond:1: Extracts edge details across each layer to evaluate focus regions.
  • -blur 0x3: Smooths the mask transitions to prevent hard, visible seams between blended focal planes.
  • -compose Blend -composite: Merges the layers based on the highest focus weights.
