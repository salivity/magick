How to Gaussian Blur a PNG Image Using ImageMagick?

Applying a Gaussian blur to a PNG image in ImageMagick is a straightforward process handled entirely from the command line. This guide demonstrates how to use the -gaussian-blur and -blur operators across both ImageMagick v7 and legacy v6 versions, explains the math behind radius and sigma parameters, and details how to handle PNG transparency without edge bleeding.

Basic Gaussian Blur Command

In modern ImageMagick (version 7+), operations are executed using the magick command. The primary operator for a Gaussian filter is -gaussian-blur.

magick input.png -gaussian-blur 0x8 output.png

If you are using ImageMagick version 6, the legacy syntax utilizes convert:

convert input.png -gaussian-blur 0x8 output.png

Understanding the Geometry Argument ({radius}x{sigma})

The argument following the blur flag uses the format {radius}x{sigma}:

  • Radius (first value): Specifies the size of the convolution matrix kernel in pixels. Setting this to 0 instructs ImageMagick to calculate an optimal radius automatically based on the sigma value, ensuring a clean falloff without clipping the edges of the blur.
  • Sigma (second value): Represents the standard deviation of the Gaussian distribution, measured in pixels. This is the primary value that dictates the actual strength of the blur. A higher sigma produces a stronger, softer blur.

Setting the radius to 0 and adjusting only the sigma (such as 0x2 for subtle softening, or 0x16 for heavy blurring) is the recommended standard practice.

Difference Between -gaussian-blur and -blur

ImageMagick provides two similar blur operations:

  • -gaussian-blur: Performs a true 2D mathematical Gaussian convolution. It calculates the full matrix directly, which is precise but can become slow on very large dimensions.
  • -blur: Approximates a Gaussian blur by separating the convolution into two 1D passes (one horizontal and one vertical). In visual terms, the output is nearly indistinguishable from -gaussian-blur, but processing speed is significantly faster on large images.

For batch processing or high-resolution PNGs, consider using -blur:

magick input.png -blur 0x8 output.png

Preserving PNG Transparency

When applying a blur to a PNG containing an alpha channel, semi-transparent pixels near the boundaries may interact unpredictably with adjacent transparent space, causing dark or discolored halos. To ensure alpha channels blend smoothly, enable alpha blending during the blur operation:

magick input.png -channel RGBA -blur 0x6 +channel output.png

The -channel RGBA parameter ensures that the red, green, blue, and alpha channels are blurred concurrently, while +channel resets channel selection back to the default state for writing the output.
