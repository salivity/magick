How to Gaussian blur a WebP image using ImageMagick?

This guide provides a quick overview of how to apply a Gaussian blur effect to a WebP image using ImageMagick command-line tools. You will learn the precise command syntax, the parameters required to control the intensity of the blur, and how to handle WebP-specific compression settings to preserve image quality.

ImageMagick is a versatile, open-source software suite used for editing, converting, and manipulating digital images. Because WebP is a modern image format supported natively by modern versions of ImageMagick, processing these files is straightforward once you have the correct operators in place.

Basic Syntax for Gaussian Blur

The primary command for applying a Gaussian blur in ImageMagick is -blur. The operator accepts a geometry argument consisting of a radius and a standard deviation, formatted as radiusxsigma.

To apply a standard blur to a WebP file, open your terminal or command prompt and run the following command:

magick input.webp -blur 0x8 output.webp

In this command:

  • input.webp is your source image.
  • -blur 0x8 specifies the blur parameters where 0 lets ImageMagick choose an optimal radius automatically, and 8 is the sigma value (the standard deviation) that determines the strength of the blur. Higher numbers result in a more heavily blurred image.
  • output.webp is the resulting file saved in WebP format.

Adjusting Blur Intensity

Controlling the look of your blur requires understanding how the radius and sigma interact. The radius defines the size of the Gaussian operator's pixel footprint, while sigma defines the spread of the blur curve.

Setting the radius to 0 is generally recommended for most workflows because it allows ImageMagick to calculate an appropriate filter matrix size automatically based on your sigma value, preventing harsh artifacts.

  • Subtle softening: Use a low sigma value, such as -blur 0x2, to gently soften background details or portraits.
  • Heavy background blur (Bokeh effect): Use a higher sigma value, such as -blur 0x15 or greater, to obscure sensitive information or create depth of field.

Managing WebP Quality and Compression

ImageMagick preserves WebP formatting automatically based on the file extension of the output file. However, you may want to explicitly control compression quality or choose between lossy and lossless compression during the blur process to balance file size and visual fidelity.

To specify the quality of the output WebP file, use the -quality setting:

magick input.webp -blur 0x8 -quality 85 output.webp

The quality value ranges from 0 to 100. A setting of 85 provides a strong balance of high visual quality and efficient compression. If you require absolute pixel-for-pixel accuracy without any lossy compression artifacts, you can enforce lossless compression using the define option:

magick input.webp -blur 0x8 -define webp:lossless=true output.webp

Batch Processing Multiple WebP Images

If you need to apply the same Gaussian blur effect to an entire directory of WebP images, you can leverage ImageMagick's built-in mogrify tool. Unlike the magick command which outputs a single file, mogrify processes files in-place or routes them to a new folder.

To blur all WebP files in a folder and save them into a designated destination directory, create the target folder first and run:

magick mogrify -path ./blurred_images/ -blur 0x8 *.webp

This command scans the current directory for any file ending in .webp, applies the 8-sigma Gaussian blur to each one, and deposits the finished results directly into the blurred_images folder while maintaining their original filenames.
