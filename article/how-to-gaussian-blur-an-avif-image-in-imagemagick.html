How to Gaussian Blur an AVIF Image in ImageMagick?

This guide explains how to apply a Gaussian blur to an AVIF (AV1 Image File Format) image using ImageMagick's command-line interface. You will learn the exact syntax required, how to configure the radius and sigma parameters to control blur intensity, and how to verify that your ImageMagick build includes proper AVIF support.

Prerequisites: Verifying AVIF Support

Before processing AVIF files, ensure that your ImageMagick installation includes the libheif delegate, which enables reading and writing AVIF containers.

Run the following command in your terminal:

magick -version

Look for heic or avif in the Delegates (built-in) output line. Alternatively, verify delegate registration directly:

magick identify -list format | grep -i avif

If the output lists AVIF with read (r) and write (w) support, your environment is ready. If AVIF support is missing, update ImageMagick or install libheif through your operating system's package manager.

The Basic Gaussian Blur Command

ImageMagick provides the -gaussian-blur operator to apply a convolution matrix based on a Gaussian distribution.

The basic command structure for modern ImageMagick (version 7 and later) is:

magick input.avif -gaussian-blur {radius}x{sigma} output.avif

If you are using legacy ImageMagick (version 6), replace magick with convert:

convert input.avif -gaussian-blur {radius}x{sigma} output.avif

Understanding Radius and Sigma

The -gaussian-blur operator takes two geometry values formatted as {radius}x{sigma}:

  • Radius: The size of the convolution matrix kernel in pixels.
  • Sigma: The standard deviation of the Gaussian distribution, measured in pixels.

Sigma is the primary control for the blur's visible strength. A higher sigma produces a softer, more diffuse blur.

In most workflows, the radius should be set to 0. When radius is 0, ImageMagick automatically calculates an optimal kernel size based on sigma (typically about three times sigma):

magick input.avif -gaussian-blur 0x5 output.avif

In this example, 0x5 applies a moderate blur with an automatically selected radius and a standard deviation of 5 pixels.

Practical Examples

Subtle Blur for Softening Background Noise

Use a low sigma value between 1 and 2 to smooth minor compression artifacts or grain without losing core subject outlines:

magick input.avif -gaussian-blur 0x1.5 blurred_subtle.avif

Heavy Blur for Background Placeholders

Use a higher sigma value between 10 and 20 to obscure details, useful for generating low-quality image placeholders (LQIP) or UI backdrops:

magick input.avif -gaussian-blur 0x15 blurred_heavy.avif

Controlling AVIF Output Quality

AVIF encoding can be fine-tuned alongside the blur operator. Use the -quality flag to balance file size and compression efficiency:

magick input.avif -gaussian-blur 0x8 -quality 65 blurred_compressed.avif

Setting quality between 50 and 70 generally provides high fidelity for blurred backgrounds while maintaining compact file sizes.
