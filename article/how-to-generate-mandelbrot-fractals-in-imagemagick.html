How to Generate Mandelbrot Fractals in ImageMagick

This guide explains how to generate Mandelbrot fractal images using ImageMagick command-line tools. You will learn the core syntax for rendering the built-in fractal pattern, how to adjust its dimensions, apply custom color palettes, and utilize the mathematical -fx operator for advanced fractal rendering.

Basic Mandelbrot Syntax

ImageMagick includes a built-in pseudo-image pattern named pattern:fractal, which renders the standard Mandelbrot set.

ImageMagick 7 Syntax

magick -size 800x800 pattern:fractal mandelbrot.png

ImageMagick 6 Syntax

convert -size 800x800 pattern:fractal mandelbrot.png
  • -size [width]x[height]: Defines the pixel dimensions of the generated image canvas.
  • pattern:fractal: Tells ImageMagick to draw the Mandelbrot fractal.
  • mandelbrot.png: The output filename and image format.

Adding Color to the Fractal

By default, pattern:fractal outputs a grayscale image. You can add color transitions across the fractal using color mapping options such as +level-colors or -auto-level combined with color gradients.

Applying a Two-Color Gradient

magick -size 800x800 pattern:fractal +level-colors "navy,gold" mandelbrot_colored.png

Applying a Multi-Stop Gradient via a Palette

magick -size 800x800 pattern:fractal \
  ( -size 1x256 gradient:"black-blue-magenta-yellow-white" ) \
  -clut mandelbrot_palette.png

In this command:

  • gradient:... creates a color lookup table (CLUT).
  • -clut replaces the fractal's grayscale intensity values with the colors from the gradient.

Custom Coordinates and Iterations Using -fx

If you need precise control over the complex plane coordinates, zoom levels, or iteration limits, you can compute the Mandelbrot formula directly using the -fx operator instead of the static pattern:fractal template.

magick -size 500x500 xc:black -fx '
  cr = (i/w)*3.0 - 2.0;
  ci = (j/h)*3.0 - 1.5;
  zr = 0; zi = 0;
  for (n = 0; n < 50; n++,
    tr = zr*zr - zi*zi + cr;
    zi = 2*zr*zi + ci;
    zr = tr;
    if (zr*zr + zi*zi > 4, break)
  );
  n / 50
' -auto-level mandelbrot_custom.png
  • cr and ci map pixel coordinates (i, j) to the complex plane.
  • The for loop calculates the \(Z_{n+1} = Z_n^2 + C\) escape-time formula up to 50 iterations.
  • n / 50 normalizes the iteration count to set each pixel's brightness level.
