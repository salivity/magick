How to Generate Vector QR Codes in ImageMagick

This article provides a complete guide on how to generate resolution-independent, vector-based QR codes using ImageMagick's delegate system. By integrating ImageMagick with external rendering delegates such as libqrencode and vector graphic outputs like SVG or EPS, you can automate the creation of scalable QR codes suitable for high-resolution print and responsive web design.

Understanding ImageMagick Delegates

ImageMagick utilizes external programs and libraries—known as delegates—to decode and encode formats that it does not natively process. For QR codes, ImageMagick can be configured to delegate the generation task to a utility such as qrencode, which can output raw vector data (like SVG or EPS) that ImageMagick then processes and packages into your desired vector format.

Prerequisites

To generate vector QR codes via delegates, ensure you have the following packages installed on your system:

  • ImageMagick 7+ (with delegate support enabled)
  • qrencode (a fast C library and CLI utility for QR code generation)
  • librsvg or Ghostscript (delegates for rendering and converting vector files)

On Debian/Ubuntu-based systems, install these dependencies using:

sudo apt-get update
sudo apt-get install imagemagick qrencode librsvg2-bin

Configuring the Delegate in ImageMagick

ImageMagick manages external delegate commands through its delegates.xml file. To allow ImageMagick to generate QR codes directly using a custom protocol format, you can define a delegate rule.

  1. Locate your delegates.xml file (typically in /etc/ImageMagick-7/delegates.xml or ~/.config/ImageMagick/delegates.xml).
  2. Add a custom delegate definition inside the <delegatemap> block:
<delegate decode="qrcode" command="&quot;qrencode&quot; -t SVG -o &quot;%o&quot; &quot;%i&quot;"/>

This configuration tells ImageMagick that any file or protocol passed as qrcode: should execute qrencode, generate an SVG vector file, and output it to the internal ImageMagick pipeline.

Generating the Vector QR Code

Once the delegate is configured, you can generate vector QR codes directly from the command line by calling the input delegate and specifying a vector extension (.svg, .eps, or .pdf).

1. Generate an SVG QR Code

magick qrcode:"https://example.com" output.svg

2. Generate an EPS (Encapsulated PostScript) QR Code

magick qrcode:"https://example.com" output.eps

3. Generate a Vector PDF QR Code

magick qrcode:"https://example.com" output.pdf

Direct Vector Generation via Inline Delegate Pipeline

If you cannot edit delegates.xml, you can pipe the vector output of qrencode directly into ImageMagick to maintain a purely vector-based workflow without intermediate rasterization:

qrencode -t SVG -o - "https://example.com" | magick svg:- output.eps

Adjusting QR Code Parameters

When generating vector QR codes, you can adjust error correction and sizing parameters through the delegate command:

  • Error Correction Level: Use qrencode -l H for High error correction (30% recovery capability), which is ideal if you plan to overlay a logo in the center.
  • Margin/Padding: Use qrencode -m 2 to reduce the white quiet-zone border around the QR code.
  • Color Modifications: Since the intermediate and final formats are vector (SVG/EPS), you can use ImageMagick's vector-safe operators or modify fill colors directly within the delegate command:
<delegate decode="qrcode" command="&quot;qrencode&quot; -t SVG --foreground=&quot;003366&quot; --background=&quot;FFFFFF&quot; -o &quot;%o&quot; &quot;%i&quot;"/>

Using delegates ensures that the generated QR codes remain mathematical vector paths, allowing you to scale them infinitely without any loss of clarity or scanning fidelity.
