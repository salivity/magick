How to Install ImageMagick from Source on Linux

Installing ImageMagick from source on a Linux distribution allows you to access the latest features, security patches, and custom configuration options not always available in default distribution repositories. This guide walks you through the entire process, including installing required build dependencies, downloading the latest source code, compiling the software, and verifying the final installation on your system.

Step 1: Install Prerequisites and Dependencies

Before compiling ImageMagick, install the basic compilation tools and development libraries for image formats (such as JPEG, PNG, and TIFF) you want ImageMagick to support.

On Debian / Ubuntu:

sudo apt update
sudo apt install -y build-essential make gcc pkg-config \
  libpng-dev libjpeg-dev libtiff-dev libwebp-dev libfreetype6-dev libxml2-dev

On RHEL / CentOS / Fedora:

sudo dnf groupinstall -y "Development Tools"
sudo dnf install -y gcc make pkgconfig \
  libpng-devel libjpeg-turbo-devel libtiff-devel libwebp-devel freetype-devel libxml2-devel

Step 2: Download and Extract the Source Code

Download the latest release tarball directly from the official ImageMagick server or clone the official repository.

wget https://download.imagemagick.org/ImageMagick/download/ImageMagick.tar.gz
tar -xvzf ImageMagick.tar.gz
cd ImageMagick-*

Step 3: Configure the Build Environment

Run the configuration script to prepare the build and check for required libraries. You can pass flags to enable or disable specific features if needed.

./configure

Check the configuration summary printed at the end of the output to ensure that key image delegates (like JPEG, PNG, and WebP) are marked as yes.

Step 4: Compile and Install

Compile the source code using the make command, then install the binaries to your system. Using the -j flag with the number of available CPU cores speeds up the compilation process.

make -j$(nproc)
sudo make install

Step 5: Configure Dynamic Linker Bindings

Update the dynamic linker run-time bindings so the operating system can find the newly installed shared libraries:

sudo ldconfig /usr/local/lib

Step 6: Verify the Installation

Confirm that ImageMagick was installed successfully and check the active version and supported delegates:

magick -version

If the command outputs the version information and the list of enabled delegates, ImageMagick is ready to use.
