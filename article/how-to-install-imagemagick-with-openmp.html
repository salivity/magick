How to Install ImageMagick with OpenMP

This guide provides a straightforward walkthrough for compiling and installing ImageMagick from source with OpenMP multi-threading enabled. Enabling OpenMP allows ImageMagick to distribute compute-intensive image processing tasks across multiple CPU cores, significantly improving execution speed.

Step 1: Install Required Build Tools and Dependencies

To compile ImageMagick with OpenMP, you need a C/C++ compiler with OpenMP support (like GCC) and the necessary image format libraries.

On Ubuntu / Debian:

sudo apt update
sudo apt install -y build-essential libgomp1 libpng-dev libjpeg-dev libtiff-dev libwebp-dev git

On CentOS / RHEL / Fedora:

sudo dnf groupinstall -y "Development Tools"
sudo dnf install -y libgomp libpng-devel libjpeg-turbo-devel libtiff-devel libwebp-devel git

Step 2: Download the ImageMagick Source Code

Clone the official ImageMagick repository:

git clone https://github.com/ImageMagick/ImageMagick.git
cd ImageMagick

Alternatively, download and extract the latest tarball:

wget https://download.imagemagick.org/ImageMagick/download/ImageMagick.tar.gz
tar -xzf ImageMagick.tar.gz
cd ImageMagick-*

Step 3: Configure the Build with OpenMP

Run the configure script and explicitly pass the --enable-openmp flag.

./configure --enable-openmp --with-modules

After the configuration script completes, check the summary output at the end. Ensure that the OpenMP feature is listed as enabled:

OpenMP          --enable-openmp=yes             yes

Step 4: Compile and Install

Compile the source using all available processor cores and install the binaries:

make -j$(nproc)
sudo make install
sudo ldconfig /usr/local/lib

Step 5: Verify OpenMP Support

Verify that ImageMagick has been successfully installed with OpenMP support by checking the version information:

magick -version

Look for OpenMP in the Features line of the output:

Version: ImageMagick 7.x.x
Features: Cipher DPC HDRI Modules OpenMP

If OpenMP appears in the Features list, multi-threaded processing is active and configured. You can control the number of threads ImageMagick uses at runtime by setting the MAGICK_THREAD_LIMIT environment variable or using the -limit thread CLI option.
