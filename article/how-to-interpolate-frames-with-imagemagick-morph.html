How to Interpolate Frames with ImageMagick Morph

This guide explains how to generate intermediate transition frames between two or more images using ImageMagick’s built-in -morph operator. You will learn the core command syntax, how to control the number of interpolated frames, how to set playback delays for animated GIFs, and how to export the generated frames as individual static image files.

Basic Syntax

The -morph command creates a linear blend (cross-dissolve) between consecutive images by generating a specified number of in-between frames.

In ImageMagick v7, the standard command format is:

magick image1.jpg image2.jpg -morph 10 output.gif

(For ImageMagick v6, replace magick with convert.)

The integer following -morph (in this case, 10) specifies the number of intermediate frames created between each pair of input images. The total frame count in the resulting output equals your original images plus the newly generated morph frames.

Creating a Smooth Animated GIF

To convert the morph sequence into a continuous, looping animated GIF, combine -morph with the -set delay and -loop parameters:

magick start.png end.png -morph 20 -set delay 5 -loop 0 morph_animation.gif
  • -morph 20: Generates 20 intermediate blend frames between start.png and end.png.
  • -set delay 5: Sets the duration of each frame to 5/100ths of a second (50 milliseconds).
  • -loop 0: Ensures the generated GIF loops indefinitely.

Morphing Multiple Images in Sequence

You can chain more than two images. ImageMagick will insert the specified number of morph frames between each successive pair:

magick frameA.jpg frameB.jpg frameC.jpg -morph 15 -set delay 8 -loop 0 multi_morph.gif

In this example, 15 frames are generated between frameA.jpg and frameB.jpg, and another 15 frames are generated between frameB.jpg and frameC.jpg.

Exporting Frames as Individual Image Files

If you need the interpolated frames as separate image files (for video editing, further processing, or sprite sheets), specify an indexed image sequence pattern for the output filename:

magick frameA.png frameB.png -morph 10 frame_%03d.png

This command outputs frame_000.png through frame_011.png, saving each original and interpolated frame sequentially to your directory.

Best Practices for Best Results

  • Matching Dimensions: Ensure all input images have the exact same width, height, and color space before running the command to prevent distortion.
  • Blending Style: The -morph operator performs a pixel-by-pixel cross-fade rather than motion-vector warping. For optimal visual transitions, use input images with similar compositions, framing, and backgrounds.
