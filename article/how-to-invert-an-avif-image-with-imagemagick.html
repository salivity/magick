How to Invert an AVIF Image with ImageMagick?

Inverting or negating an AVIF image using ImageMagick requires the -negate operator applied to the color channels while preserving or managing alpha transparency. This guide details the essential command-line syntax for ImageMagick versions 7 and 6, covers how to handle transparency safely, explains batch processing for multiple files, and addresses common format support issues.

Basic Inversion Command

ImageMagick uses the -negate operator to replace each pixel color with its complementary color. In ImageMagick 7, the primary tool is magick.

To invert a basic AVIF file, run:

magick input.avif -negate output.avif

If you are using ImageMagick 6, the command relies on convert:

convert input.avif -negate output.avif

This replaces light pixels with dark pixels and dark with light, flipping colors across the RGB channels.

Handling Alpha Channels and Transparency

By default in newer ImageMagick releases, -negate affects all color channels while leaving the alpha (transparency) channel intact. However, older builds or specific color profiles may inadvertently invert the opacity, causing transparent areas to become opaque and visible pixels to disappear.

To guarantee that only the RGB color channels invert while preserving the alpha mask:

magick input.avif -channel RGB -negate +channel output.avif
  • -channel RGB restricts subsequent operations solely to Red, Green, and Blue.
  • +channel resets the active channel selection back to the default so that file encoding writes properly.

If your specific goal is to invert the transparency mask along with the colors, run:

magick input.avif -channel RGBA -negate +channel output.avif

Preserving Color Quality and Bit Depth

AVIF files frequently use 10-bit or 12-bit color depths and high dynamic range (HDR) profiles. When inverting, you can explicitly preserve depth and adjust compression quality:

magick input.avif -depth 10 -quality 75 -channel RGB -negate +channel output.avif

The -quality flag controls the AVIF encoder's compression level (typically on a 1–100 scale, where 60–80 provides a balanced ratio of fidelity to size). Setting -depth prevents downsampling high-bit-depth images to standard 8-bit.

Batch Processing Multiple AVIF Files

To invert an entire directory of AVIF images simultaneously, use ImageMagick's mogrify command or standard shell loops.

Using mogrify to overwrite existing files in place:

magick mogrify -channel RGB -negate +channel *.avif

To write inverted images to an alternative folder without altering the originals:

mkdir -p inverted_output
magick mogrify -path inverted_output -channel RGB -negate +channel *.avif

On Linux or macOS using a Bash loop:

for img in *.avif; do
  magick "$img" -channel RGB -negate +channel "inverted_${img}"
done

On Windows Command Prompt:

for %f in (*.avif) do magick "%f" -channel RGB -negate +channel "inverted_%f"

Verifying AVIF Support

If ImageMagick returns an error stating no decode delegate for this image format 'AVIF', your local build lacks AVIF delegate libraries (libheif or libavif).

Check whether your installed delegate list includes AVIF:

magick -version

Look for heic or avif in the Delegates (built-in) line. Alternatively, query format support directly:

magick identify -list format | grep -i avif

If missing, update ImageMagick through a package manager that includes the delegate library:

  • macOS (Homebrew): brew install imagemagick (includes AVIF by default).
  • Ubuntu/Debian: Install libheif-dev or the latest precompiled static binary from the ImageMagick distribution page.
  • Windows: Reinstall using the official ImageMagick installer and select the option to install optional third-party delegates.
