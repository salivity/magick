How to Justify Text in ImageMagick

In ImageMagick, text justification—aligning text to the left, center, or right—is controlled primarily by the -gravity parameter. This article outlines how to use -gravity to control text alignment for both single-line and multi-line strings, provides practical command-line examples using standard rendering operators, and covers alternative methods for achieving full margin-to-margin justification.

The -gravity Parameter

The -gravity parameter dictates the alignment and placement of text within a defined canvas or bounding box. When rendering multi-line text, it acts as the text justification setting:

  • Left Justification: Use -gravity West (or NorthWest / SouthWest).
  • Center Justification: Use -gravity Center (or North / South).
  • Right Justification: Use -gravity East (or NorthEast / SouthEast).

The parameter must be specified before defining the text operation in your command sequence so ImageMagick knows how to align the text lines relative to one another.

Aligning Text with caption:

The caption: operator automatically wraps text into multiple lines within a specified size. Setting -gravity before calling caption: aligns each line within that boundary.

Left-Justified Text:

magick -size 400x200 -gravity West caption:"This is a multi-line string aligned to the left margin." output_left.png

Center-Justified Text:

magick -size 400x200 -gravity Center caption:"This is a multi-line string centered within the canvas." output_center.png

Right-Justified Text:

magick -size 400x200 -gravity East caption:"This is a multi-line string aligned to the right margin." output_right.png

Aligning Text with -annotate

When adding text over an existing image using -annotate, -gravity establishes the anchor point on the canvas and dictates the text alignment relative to that anchor.

magick input.png -font Arial -pointsize 24 -gravity NorthWest -annotate +20+20 "Left-aligned text" output.png

In this case, NorthWest anchors the text to the top-left corner and ensures lines flow from left to right. Using NorthEast causes lines to align along the right boundary.

Achieving Full Justification

ImageMagick’s standard caption: and label: operators do not support full justification (where text stretches with variable spacing to touch both the left and right margins).

To achieve full justification, use the pango: delegate. Pango supports formatting tags that permit fully justified text blocks:

magick -size 400x -font Arial pango:"<span align=\"justify\">This paragraph is rendered with full justification across both the left and right borders using Pango markup.</span>" output_justified.png
