How to Limit ImageMagick Disk Pixel Cache

This guide explains how to restrict ImageMagick's disk-backed pixel cache usage to prevent the program from exhausting system disk space during heavy image processing tasks. You will learn the exact command-line flags, environment variables, and policy file configurations required to set strict disk limits.

The Command-Line Flag

To limit disk-backed pixel cache usage directly in a command, use the -limit disk option followed by the maximum allowed size (e.g., KB, MB, GB, or GiB).

magick input.jpg -limit disk 1GB output.png

For legacy ImageMagick versions (ImageMagick 6), use:

convert input.jpg -limit disk 1GB output.png

To completely disable disk-backed cache and force operations to remain entirely in RAM (or fail if RAM is exhausted), set the value to 0:

magick input.jpg -limit disk 0 output.png

Environment Variable Method

You can restrict disk cache usage across your entire session without repeating the flag for every command by setting the MAGICK_DISK_LIMIT environment variable:

export MAGICK_DISK_LIMIT=2GB

Permanent System-Wide Configuration

To enforce disk cache restrictions globally for all users and processes, edit the ImageMagick security policy file (policy.xml), typically located at /etc/ImageMagick-7/policy.xml or /etc/ImageMagick-6/policy.xml.

Add or update the following resource policy inside the <policymap> block:

<policy domain="resource" name="disk" value="1GiB"/>

Setting this limit prevents ImageMagick from creating excessively large temporary pixel cache files in your temporary directory (e.g., /tmp).
