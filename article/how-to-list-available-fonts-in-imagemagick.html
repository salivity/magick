How to List Available Fonts in ImageMagick

This article provides the exact commands required to list all fonts recognized by ImageMagick on your system. It covers the primary commands for both ImageMagick 7 and ImageMagick 6, along with practical filtering methods to display only font names for quick reference.

Primary Command for ImageMagick 7

In ImageMagick 7, use the magick utility with the -list font argument to output all recognized fonts and their detailed configurations:

magick -list font

Primary Command for ImageMagick 6

If you are using an older version (ImageMagick 6), use the convert or identify command:

convert -list font

or

identify -list font

Listing Only Font Names

The standard -list font command outputs verbose metadata for each font, including family, style, metrics, and file paths. To retrieve a clean, concise list containing only the font names, filter the output using command-line tools:

On Linux and macOS:

magick -list font | grep -i "Font:" | awk '{print $2}'

On Windows (Command Prompt):

magick -list font | findstr /i "Font:"

On Windows (PowerShell):

magick -list font | Select-String "Font:"

Checking Font Configuration Files

ImageMagick locates fonts through its type.xml configuration files. To verify which font configuration files ImageMagick is currently reading, run:

magick -list type
