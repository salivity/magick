How to List ImageMagick Compose Operators

ImageMagick provides a comprehensive suite of blending and pixel composition methods for combining images. This guide explains how to inspect all supported pixel composition operators installed on your system using the -list compose command. You will learn the correct command-line syntax for both modern and legacy ImageMagick versions, how to filter the results, and how to reference these operators in image-processing tasks.

Running the Command

To view the complete list of available composition operators, open your terminal or command prompt and run the standard utility command with the -list compose argument.

For ImageMagick version 7 and newer, use the unified magick tool:

magick -list compose

For ImageMagick version 6 (legacy), use the convert or composite command:

convert -list compose

Understanding the Output

Executing the command outputs an alphabetical list of every blend and composition mode supported by your specific build. Typical outputs include standard Porter-Duff operators, blend modes, and mathematical operations, such as:

  • Over: The default compositing method where the source image is layered on top of the destination.
  • Multiply: Multiplies the color values of the overlapping pixels, creating a darker result.
  • Screen: Inverts, multiplies, and inverts back, yielding a lighter composite.
  • Difference: Subtracts the darker pixel from the lighter pixel between the two layers.
  • Dissolve: Blends source and destination based on transparency percentages.
  • Src / Dst variants: Specific channel operations like SrcOver, DstIn, and SrcAtop.

Because the list depends on the compile-time options and version of ImageMagick installed, checking this output ensures the operator you plan to use is supported.

Filtering and Searching the List

If you need to verify whether a specific operator is available, pipe the command output into a search utility like grep on Linux/macOS or findstr on Windows.

To check for a specific mode on Unix-like systems:

magick -list compose | grep -i "blend"

To check for a specific mode on Windows Command Prompt:

magick -list compose | findstr /I "blend"

Applying Listed Operators

Once you identify the required operator from the list, apply it using the -compose setting followed by the -composite operator in your command pipeline:

magick base.png overlay.png -compose Multiply -composite output.png

This applies the selected operator to combine the two source files into the final output image.
