How to Mask Images in ImageMagick Using DstIn

This article provides a practical guide on using ImageMagick’s DstIn (Destination In) composition operator to mask an image using an alpha shape. You will learn the mechanics behind the DstIn alpha composition model, the proper order of source and destination layers, and specific command-line examples for clipping images into custom shapes with transparent backgrounds.

Understanding the DstIn Operator

The DstIn operator is one of the classic Porter-Duff compositing operators. In ImageMagick:

  • Destination (Dst): The first (background) image, which is the main graphic or photo you want to keep.
  • Source (Src): The second (overlay) image, which acts as the alpha mask defining the shape.
  • In: The operation keeps the parts of the Destination that lie Inside the non-transparent areas of the Source.

When applying DstIn, ImageMagick multiplies the alpha channel of the destination image by the alpha channel of the source image. Any area of the destination image that overlaps with fully transparent pixels in the source mask becomes completely transparent in the final output.

Basic Syntax

In ImageMagick 7, the standard syntax for applying a mask with DstIn is:

magick destination.png mask.png -alpha set -compose DstIn -composite output.png
  • destination.png: The target image you want to mask.
  • mask.png: The shape image containing transparent and opaque areas.
  • -alpha set: Ensures the destination image has an active alpha channel.
  • -compose DstIn: Selects the Destination In blending mode.
  • -composite: Executes the composite operation on the two loaded images.
  • output.png: The resulting masked image (must be saved in a format supporting transparency, such as PNG, WebP, or TIFF).

Step-by-Step Examples

1. Masking with a Pre-existing Alpha Mask

If you have a base photo (photo.jpg) and a separate PNG mask containing a shape with transparency (shape.png):

magick photo.jpg shape.png -alpha set -compose DstIn -composite masked_photo.png

2. Generating a Mask Dynamically (e.g., Circle Mask)

You can generate a mask on the fly using parenthesis sub-commands so you do not need an external mask file:

magick photo.jpg \
  \( -size 500x500 xc:none -fill white -draw "circle 250,250 250,10" \) \
  -alpha set -compose DstIn -composite circle_output.png

In this command:

  1. photo.jpg is loaded as the destination.
  2. A 500x500 transparent canvas (xc:none) with a white circle is generated as the source.
  3. -compose DstIn -composite crops photo.jpg to the dimensions and soft edges of the drawn circle.

3. Masking with Soft / Anti-Aliased Edges

The DstIn operator supports variable transparency (8-bit alpha channels). If the source mask has semi-transparent or blurred edges, those soft edges will carry over into the masked image:

magick photo.jpg \
  \( -size 500x500 xc:none -fill white -draw "roundrectangle 20,20 480,480 50,50" -blur 0x5 \) \
  -alpha set -compose DstIn -composite feathered_box.png

Important Considerations

  • Layer Order: If the order is reversed (mask.png photo.jpg -compose DstIn), ImageMagick will keep the pixels of the mask where the photo exists. To use the reverse order without changing the file sequence, use -compose SrcIn instead.
  • File Formats: Always save the final output to a format that supports an alpha channel (such as .png or .webp). Saving to .jpg will flatten the image and replace transparent areas with a solid background color (usually white or black).
