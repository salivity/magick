How to Match Histograms in ImageMagick

Histogram matching adjusts the tonal distribution and color balance of a target image to match those of a reference image. This article covers the most effective methods to perform histogram specification and color matching using ImageMagick command-line tools, ranging from native color lookup table (CLUT) transfers to full cumulative distribution function matching.

Method 1: Hald-CLUT Color Matching (ImageMagick 6 and 7)

The Hald-CLUT (Color Look-Up Table) method captures the global color and tonal mapping between a base state and your reference target, allowing you to transfer the look precisely.

Step 1: Generate a Neutral Hald-CLUT

Generate an identity Hald image (typically level 8, which creates a 512x512 image covering all color spaces):

magick hald:8 identity.png

Step 2: Apply the Reference Color Profile

Map the reference image’s tonal balance onto the identity matrix or generate a LUT based on the reference:

magick identity.png reference.png -interpolate Mesh -clut hald_matched.png

Step 3: Apply the Hald-CLUT to the Target Image

Apply the modified Hald table to your target image:

magick target.png hald_matched.png -hald-clut output.png

Method 2: Color Palette Remapping with -remap

If you want the target image to conform strictly to the color distribution and palette of the reference image, the -remap operator provides a fast, built-in solution.

magick target.png -remap reference.png output.png

To prevent dithering artifacts during the remapping process, disable dithering:

magick target.png +dither -remap reference.png output.png

Method 3: Histogram Equalization Alignment

When images need matching luminance and contrast across separate RGB channels, you can equalize both images to a uniform distribution and transfer the values:

magick target.png -channel RGB -equalize target_eq.png
magick reference.png -channel RGB -equalize ref_eq.png

To normalize the target image directly against the reference's statistical profile:

magick target.png \( reference.png -colorspace Lab -separate \) -colorspace Lab -recolor output.png

Method 4: True Cumulative Distribution Matching via Scripting

ImageMagick’s core CLI does not include a single-flag cumulative distribution function (CDF) histogram matcher. For mathematically exact per-channel CDF histogram matching, use Fred Weinhaus's histmatch shell script (built for ImageMagick on Unix-like environments):

# Match all color channels independently
./histmatch -c separate target.png reference.png output.png

# Match luminance only (preserving original hues)
./histmatch -c luminance target.png reference.png output.png

Key Parameters:

  • -c separate: Matches the histogram of each RGB channel independently for complete color and tone alignment.
  • -c luminance: Converts images to a luminance-chrominance space, matches only the brightness distribution, and retains the target's original color hues.
  • -c global: Computes a single grayscale histogram across all channels simultaneously.
