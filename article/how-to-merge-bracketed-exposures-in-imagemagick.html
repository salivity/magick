How to Merge Bracketed Exposures in ImageMagick

This guide explains how to merge bracketed exposure sequences into a High Dynamic Range (HDR) image using ImageMagick. You will learn the required command-line operations to blend multiple bracketed exposures—capturing shadow, midtone, and highlight detail—and export the combined result into high-bit-depth HDR file formats such as .hdr or .exr.

Prerequisites and Preparation

Before combining exposures, ensure all images in your sequence are aligned. ImageMagick does not feature automatic feature-based alignment, so your source images should either be shot on a sturdy tripod or pre-aligned using a tool like align_image_stack.

For best results, work with linear, uncompressed source files like 16-bit TIFFs or linear PPMs rather than 8-bit JPEGs with non-linear tone curves applied.

Merging Exposures into an HDR File

ImageMagick provides the -evaluate-sequence operator, which computes pixel values across an entire image sequence. To calculate the arithmetic mean of your bracketed images and output directly to a 32-bit floating-point Radiance HDR or OpenEXR format, run:

magick exposure_under.tif exposure_normal.tif exposure_over.tif -evaluate-sequence mean output.hdr

For OpenEXR output (which supports floating-point data natively), run:

magick exposure_under.tif exposure_normal.tif exposure_over.tif -evaluate-sequence mean output.exr

Exposure Blending Using Masking and Composition

If you want a more refined exposure fusion that prioritizes well-exposed regions from each shot, you can calculate luminance weights and composite them:

  1. Extract Luminance and Weighting: Apply a bell-curve weighting to favor midtones over clipped highlights and noisy shadows.
  2. Blend Exposures Sequentially: Combine the darkest exposure (for highlights) and the brightest exposure (for shadows) with your base exposure:
magick exposure_normal.tif exposure_under.tif \
  \( -clone 0 -colorspace Gray -solarize 50% -level 0,50% \) \
  -composite blended_highlights.tif

magick blended_highlights.tif exposure_over.tif \
  \( -clone 0 -colorspace Gray -negate \) \
  -composite final_composite.hdr

Converting HDR to 16-Bit TIFF or Tone-Mapped Output

If you need to compress the dynamic range of an HDR file for standard 8-bit or 16-bit display pipelines, use non-linear adjustments such as gamma correction, logarithmic scaling, or sigmoid contrast:

magick output.hdr -gamma 2.2 -sigmoidal-contrast 5,50% tonemapped.png

By utilizing -evaluate-sequence for direct averaging or alpha composition masks for targeted blending, ImageMagick provides a flexible, scriptable workflow for creating HDR composites directly from the terminal.
