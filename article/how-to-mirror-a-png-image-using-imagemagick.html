How to Mirror a PNG Image Using ImageMagick?

Mirroring a PNG image using ImageMagick can be accomplished directly from the command line using either horizontal or vertical reflection operations. This guide covers the primary commands required to mirror images horizontally using the -flop operator, reflect them vertically using the -flip operator, and batch-process entire directories of PNG files efficiently using modern ImageMagick syntax.

Understanding the Flip and Flop Operators

ImageMagick provides two distinct built-in operators for creating mirror reflections:

  • Horizontal Mirroring (-flop): Reflects the pixels across the central vertical axis, creating a left-to-right mirror image.
  • Vertical Mirroring (-flip): Reflects the pixels across the central horizontal axis, creating an upside-down mirror reflection.

Both operations preserve image dimensions, color profiles, and transparent alpha channels native to the PNG format without requiring manual cropping or repositioning.

Mirroring a Single PNG Horizontally

To create a standard left-to-right mirror reflection, supply your source file, apply the -flop command, and specify an output filename.

For ImageMagick version 7 and later, run:

magick input.png -flop output_mirrored.png

If you are using legacy ImageMagick (version 6), use the convert binary instead:

convert input.png -flop output_mirrored.png

Mirroring a Single PNG Vertically

To mirror an image vertically so the top and bottom switch places, replace -flop with the -flip operator:

magick input.png -flip output_vertical.png

To flip and flop simultaneously (equivalent to an 180-degree rotation), chain both arguments together:

magick input.png -flip -flop output_both.png

Overwriting the Original File

If you prefer to overwrite the original PNG file in place rather than generating a new file, invoke the mogrify tool. Exercise caution with this command, as the modification cannot be undone automatically:

magick mogrify -flop input.png

On ImageMagick 6, the command is:

mogrify -flop input.png

Batch Mirroring Multiple PNG Images

When working with a folder containing many PNG images, you can process them all in a single command using mogrify.

To mirror all PNG files in the current directory horizontally:

magick mogrify -flop *.png

To prevent overwriting original assets during a batch operation, direct the output to an alternate directory using the -path flag:

mkdir -p mirrored_output
magick mogrify -path mirrored_output -flop *.png

This processes every PNG in the active directory and saves the mirrored copies inside the mirrored_output directory while preserving their original filenames.
