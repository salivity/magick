How to Mirror a WebP Image with ImageMagick?

Mirroring a WebP image using ImageMagick is a straightforward task accomplished via command-line utilities using either horizontal or vertical reflection operators. This guide covers the specific commands needed to flip WebP files horizontally and vertically using ImageMagick versions 6 and 7, how to automate the transformation across entire directories, and how to maintain optimal WebP compression quality during processing.

Understanding Mirroring Commands in ImageMagick

ImageMagick provides two primary operators to mirror images across different axes:

  • Horizontal Mirroring (-flop): Flips the image across the vertical axis, creating a standard left-to-right mirror reflection.
  • Vertical Mirroring (-flip): Flips the image across the horizontal axis, producing an upside-down reflection.

ImageMagick Version 7 introduces the magick binary, which replaces the standalone convert utility used in ImageMagick Version 6. Both commands support full WebP decoding and encoding provided libwebp delegates are installed on your system.

Horizontal Mirroring (Left to Right)

To produce a standard horizontal reflection of a WebP graphic, pass the -flop argument.

For ImageMagick 7:

magick input.webp -flop output_mirrored.webp

For ImageMagick 6:

convert input.webp -flop output_mirrored.webp

Vertical Mirroring (Top to Bottom)

To reflect the image vertically along the horizontal midline, pass the -flip argument.

For ImageMagick 7:

magick input.webp -flip output_flipped.webp

For ImageMagick 6:

convert input.webp -flip output_flipped.webp

Preserving WebP Compression and Quality

When ImageMagick writes to WebP format, it applies compression settings during output generation. You can fine-tune output size and fidelity using specific quality parameters:

  • Lossless Compression: To ensure no compression artifacts are introduced during the mirror operation, add -define webp:lossless=true.
  • Quality Setting: For standard lossy WebP files, control the compression factor using the -quality flag followed by an integer from 0 to 100.

Lossless mirror example:

magick input.webp -flop -define webp:lossless=true output_lossless.webp

Lossy mirror with defined quality factor:

magick input.webp -flop -quality 85 output_q85.webp

Batch Processing Multiple WebP Images

To mirror several WebP files in a single pass, utilize the mogrify command or a shell loop.

Using mogrify to overwrite existing files in place:

magick mogrify -flop *.webp

Using a shell loop to preserve original assets and append a suffix:

for file in *.webp; do
    magick "$file" -flop "${file%.webp}_mirrored.webp"
done
