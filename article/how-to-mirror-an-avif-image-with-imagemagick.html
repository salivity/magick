How to Mirror an AVIF Image with ImageMagick?

Mirroring an AVIF image using ImageMagick is a straightforward task that requires using the appropriate CLI orientation flags alongside a build that supports AVIF encoding via libraries like libheif. This guide explains the distinction between horizontal and vertical mirroring, provides the exact command-line syntax for ImageMagick versions 6 and 7, details how to verify AVIF format support, and covers batch operations for multiple files.

Verifying AVIF Support

Before processing files, ensure your ImageMagick installation includes AVIF read and write delegates. Run the following command in your terminal:

magick identify -list format | grep -i AVIF

(For ImageMagick v6, replace magick identify with identify.)

If the output lists AVIF with read/write (rw+ or rw-) permissions, your system is ready to read and export AVIF images. If it does not appear, upgrade ImageMagick or install the libheif library package for your operating system.

Horizontal Mirroring (Flop)

In ImageMagick terminology, a horizontal reflection across the vertical axis is called a flop. This produces the standard mirror-reflection effect where left and right are reversed.

For ImageMagick 7:

magick input.avif -flop output.avif

For ImageMagick 6:

convert input.avif -flop output.avif

Vertical Mirroring (Flip)

If you need an upside-down reflection across the horizontal axis, ImageMagick designates this operation as a flip.

For ImageMagick 7:

magick input.avif -flip output.avif

For ImageMagick 6:

convert input.avif -flip output.avif

Controlling Output Quality and Compression

AVIF utilizes modern video-derived compression algorithms (AV1), making quality and compression settings important when re-encoding. You can control the output compression quality using the -quality flag, typically set between 1 and 100:

magick input.avif -flop -quality 80 output.avif

A quality value between 65 and 80 generally offers a strong balance between visual fidelity and small file footprint for AVIF images.

Batch Mirroring Multiple AVIF Files

To mirror multiple AVIF images simultaneously, you can use either the mogrify tool or a standard shell loop.

In-Place Batch Processing with Mogrify

The mogrify utility modifies files directly or writes them to a designated output directory:

magick mogrify -path ./mirrored/ -flop *.avif

This processes every .avif file in the current working directory and outputs the mirrored versions into a folder named mirrored.

Batch Processing with a Bash Loop

To preserve your original files while generating distinct output names without extra directories, use a bash loop:

for img in *.avif; do
  magick "$img" -flop "${img%.avif}_mirrored.avif"
done
