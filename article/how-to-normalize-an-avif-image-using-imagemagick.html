How to Normalize an AVIF Image Using ImageMagick?

Normalizing an AVIF image with ImageMagick allows you to enhance dynamic range and contrast by stretching pixel values to span the full spectrum from black to white. This guide covers the exact command-line syntax needed to perform standard normalization, alternative contrast adjustments, and batch processing for AVIF files using modern ImageMagick tools.

Prerequisites and AVIF Support

Before running normalization commands, verify that your local ImageMagick installation includes AVIF delegate support (typically provided via libheif).

Check whether the AVIF decoder and encoder are available by executing:

magick -list format | grep -i avif

If the output lists AVIF with read (r) and write (w) permissions, your environment is ready to read and export AVIF images.

Basic Normalization Command

ImageMagick provides the -normalize operator, which automatically stretches the dynamic range of an image by scaling the lowest intensity values to pure black and the highest to pure white while clipping a tiny fraction of extreme highlights and shadows.

In ImageMagick 7, use the magick utility:

magick input.avif -normalize output.avif

If you are using legacy ImageMagick 6 installations, use convert:

convert input.avif -normalize output.avif

Advanced Dynamic Range Adjustments

Depending on the distribution of lighting in the image, alternative operators might yield better tonal results than standard normalization.

Contrast Stretching

The -contrast-stretch operator provides fine-grained control over how much shadow and highlight data gets clipped. The parameters represent the black and white point clipping thresholds (often expressed as percentages):

magick input.avif -contrast-stretch 0.15%x0.05% output.avif

Auto-Leveling

To map the exact minimum pixel value to 0% and the exact maximum pixel value to 100% without any clipping of shadow or highlight detail, use the -auto-level operator:

magick input.avif -auto-level output.avif

Histogram Equalization

For images with flat or clustered tonal distributions, histogram equalization distributes lightness evenly across the entire dynamic range:

magick input.avif -equalize output.avif

Preserving Color Balance

By default, applying -normalize to a standard RGB image processes each color channel independently. In some photographs, this can cause an undesirable color shift.

To adjust brightness without skewing color relationships, convert the color space to HSL or Lab, normalize only the lightness channel, and convert back:

magick input.avif -colorspace Lab -channel 0 -normalize +channel -colorspace sRGB output.avif

Batch Processing Multiple AVIF Files

To normalize multiple AVIF images inside a directory simultaneously, use ImageMagick’s mogrify tool.

Create a dedicated output directory and run:

mkdir -p normalized_output
magick mogrify -path normalized_output -normalize *.avif

This command applies normalization across all AVIF files in the current working directory and writes the newly balanced assets into the target directory while preserving the originals.
