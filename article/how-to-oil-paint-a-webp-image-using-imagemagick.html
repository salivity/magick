How to Oil Paint a WebP Image Using ImageMagick?

ImageMagick provides a built-in -paint effect that simulates the look of an oil painting on raster images, including the WebP format. By adjusting the brush radius parameter alongside preprocessing techniques like contrast enhancement and edge sharpening, you can transform flat WebP photos into rich, textured digital paintings directly from the command line.

Prerequisites and Setup

Before processing WebP files, ensure your ImageMagick installation includes the WebP delegate library (libwebp). Modern distributions usually bundle this automatically.

You can verify WebP support on your machine with:

magick -version

Look for webp under the listed delegates. In modern versions (ImageMagick 7+), use the unified magick command instead of the legacy convert executable.

The Core Oil Paint Command

The primary operator for this effect is -paint <radius>. The radius value dictates the simulated stroke size: larger values smooth out fine details and mimic broad brush strokes, while smaller values preserve finer lines.

magick input.webp -paint 4 output.webp

A radius between 3 and 8 works best for standard photography. A radius below 3 produces a subtle canvas stippling effect, whereas values above 10 can blur out facial features and fine subjects entirely.

Enhancing the Oil Paint Aesthetic

A raw -paint pass can occasionally leave images looking flat or washed out. To produce a more convincing artistic medium, chain additional ImageMagick operators to boost brushstroke contrast, dynamic range, and texture.

magick input.webp -modulate 105,130,100 -paint 5 -unsharp 0x2+1.5+0.05 -define webp:lossless=true output.webp

This pipeline performs several steps in a single execution:

  • -modulate 105,130,100: Slightly lifts overall brightness (105%) and intensifies color saturation (130%) to mirror vibrant oil pigments.
  • -paint 5: Applies the paint filter using a 5-pixel circular sampling radius.
  • -unsharp 0x2+1.5+0.05: Runs an unsharp mask over the blended strokes, emphasizing simulated impasto ridges and stroke edges.
  • -define webp:lossless=true: Writes the resulting WebP using lossless compression so fine texture edges do not suffer from compression artifacts.

Batch Processing WebP Directories

To apply the oil painting transformation across an entire folder of WebP images, use a shell loop.

On Linux or macOS using Bash:

for file in *.webp; do
    magick "$file" -paint 4 -unsharp 0x1+1+0.05 "painted_${file}"
done

On Windows Command Prompt:

for %f in (*.webp) do magick "%f" -paint 4 -unsharp 0x1+1+0.05 "painted_%f"

These loops process each WebP file sequentially, creating a new file prefixed with painted_ while preserving your original source images.
