How to Oil Paint an AVIF Image With ImageMagick?

Applying an oil painting effect to modern AVIF images is a straightforward process using ImageMagick’s built-in filtering tools. This guide explains how to verify AVIF format support, apply the -paint operator from the command line, and adjust effect radii to produce realistic artistic textures without leaving your terminal.

Prerequisites and AVIF Support

Before processing files, ensure your ImageMagick installation includes support for the AVIF format. AVIF encoding and decoding rely on underlying libraries such as libheif.

You can verify whether your installed version supports AVIF by running:

magick -version

Look for heic or avif in the Delegates list. Alternatively, query the format list directly:

magick identify -list format | grep -i avif

If the output lists AVIF with read/write permissions (rw- or r--), your installation is ready. If AVIF is missing, update ImageMagick or install libheif using your operating system's package manager.

The Basic Oil Paint Command

ImageMagick applies painterly textures via the -paint operator. This filter simulates an oil painting by analyzing circular neighborhoods around each pixel and assigning the most common color intensity.

To convert an AVIF file using the default settings:

magick input.avif -paint 3 output.avif

In this command:

  • input.avif specifies the source image.
  • -paint 3 dictates the radius of the circular neighborhood examined for the brush effect.
  • output.avif writes the finished result directly back into AVIF format.

Fine-Tuning the Effect Radius

The value passed to -paint represents the radius of the brush stroke in pixels. Adjusting this parameter determines how pronounced the painted texture appears:

  • Subtle texture (-paint 1 to -paint 2): Ideal for preserving fine photographic details while adding a light canvas-like softness.
  • Balanced oil paint (-paint 3 to -paint 5): Well-suited for general photography, clearly turning smooth gradients into distinct painted swatches.
  • Heavy abstraction (-paint 6 and higher): Blurs fine lines together into broad, impressionistic color patches.

For a 4K or high-resolution AVIF photo, you may need a larger radius such as 6 or 8 to achieve noticeable brush marks across the wider pixel grid.

Enhancing Brush Strokes and Contrast

A standard -paint filter can occasionally soften edges too much. Combining it with subtle color adjustments or edge sharpening before and after the paint pass yields a more dynamic canvas look:

magick input.avif -modulate 105,120 -paint 4 -unsharp 0x1 output.avif
  • -modulate 105,120 raises brightness by 5% and saturation by 20%, mimicking the vivid pigment of oil paints.
  • -paint 4 applies the brush effect.
  • -unsharp 0x1 sharpens the edges of the newly generated brush strokes to make the strokes stand out.

Batch Processing AVIF Images

To convert an entire folder of AVIF images while retaining the same file format, use the mogrify tool included with ImageMagick:

magick mogrify -path ./painted_output -paint 4 *.avif

This processes every .avif file in the current directory and places the painted versions inside the painted_output folder, keeping original files safe from unintended overwrites.
