How to Outline Text in ImageMagick Using Draw

This guide explains how to use the ImageMagick -draw command to render text with a stroked outline. You will learn the specific command-line syntax, how to configure the stroke color and width, how to set the text fill color, and how to create hollow or transparent outlined text.

The ImageMagick Draw Command Syntax

To add a stroked outline around text in ImageMagick, you define the stroke color, stroke thickness, fill color, and text coordinates within the -draw option or via pre-draw parameters.

Here is the standard command structure:

magick -size 600x200 xc:lightgray -font Arial -pointsize 48 \
-stroke black -strokewidth 3 -fill white \
-draw "text 50,120 'Sample Outlined Text'" output.png

For ImageMagick version 6, replace magick with convert.

Defining Stroke Attributes Inside the Draw String

You can also encapsulate all styling attributes directly within the -draw argument itself:

magick -size 600x200 xc:lightgray -font Arial -pointsize 48 \
-draw "stroke black stroke-width 3 fill white text 50,120 'Sample Outlined Text'" output.png

Parameter Breakdown

  • stroke <color>: Sets the color of the text border. Accepts standard color names (e.g., black, red) or hex values (e.g., '#000000').
  • stroke-width <number> (or -strokewidth): Defines the border thickness in pixels.
  • fill <color>: Sets the interior color of the font glyphs.
  • text <x,y> '<string>': Specifies the starting baseline coordinates (X and Y offset from the top-left corner) followed by the text string enclosed in quotes.

Creating Hollow (Transparent) Outlined Text

If you want an outline-only effect where the background shows through the center of the letters, set the fill property to none:

magick -size 600x200 xc:lightblue -font Arial -pointsize 48 \
-stroke navy -strokewidth 2 -fill none \
-draw "text 50,120 'Hollow Text'" hollow_output.png

Preventing Stroke Distortion

Applying a heavy stroke width can cause the outline to bleed inward and obscure fine font details. To keep the interior clean while maintaining a thick outer border, draw the text twice—first with the thick stroke, then over top with the fill:

magick -size 600x200 xc:white -font Arial-Bold -pointsize 60 \
-stroke black -strokewidth 8 -fill none -draw "text 50,130 'Clean Border'" \
-stroke none -fill yellow -draw "text 50,130 'Clean Border'" \
