How to Pass Script Files to ImageMagick 7 CLI

ImageMagick 7 introduced a dedicated scripting mode that allows you to execute complex command chains directly from external files instead of passing long, escape-heavy strings through your shell. This guide explains how to use the -script option, format script files without shell-escape syntax, run scripts as standalone executables, and pipe commands dynamically through standard input.

The -script Option

To pass an external script file to the ImageMagick 7 CLI, use the -script flag followed by the path to your file:

magick -script process_images.mgk

When using -script, ImageMagick switches to an internal parser that reads commands line by line or token by token, bypassing the native operating system shell entirely.

Structuring the Script File

Writing an ImageMagick script removes the need for shell escaping. You do not need backslashes for parentheses or multi-line breaks.

Syntax Rules

  • Whitespace: Arguments can be separated by spaces or newlines.
  • Parentheses: Use raw parentheses ( and ) instead of escaping them with \( and \).
  • Comments: Any line beginning with # is treated as a comment and ignored.
  • Quotes: Shell quoting rules do not apply, though standard quotes can still be used around file paths containing spaces.

Example Script (watermark.mgk)

# Load base image
input.jpg

# Resize base image
-resize 1920x1080^
-gravity center
-extent 1920x1080

# Load watermark in a separate layer
(
    logo.png
    -resize 200x200
)

# Composite and save
-gravity southeast
-geometry +50+50
-composite

# Write final output
output.jpg

Execute this script by running:

magick -script watermark.mgk

Creating Executable Scripts with a Shebang

On Unix-like systems (Linux, macOS), you can make the script directly executable by adding a shebang line at the top.

  1. Add the shebang pointing to the magick binary:
#!/usr/bin/env -S magick -script

input.png
-bordercolor black
-border 10x10
output.png
  1. Mark the file as executable:
chmod +x process.mgk
  1. Run the script directly:
./process.mgk

Passing Arguments to Scripts

ImageMagick 7 allows you to pass CLI arguments to scripts. Positional parameters are referenced inside the script using %[1], %[2], and so on.

Script (resize_custom.mgk)

# Read input from argument 1
%[1]

# Resize using dimensions from argument 2
-resize %[2]

# Write to output specified in argument 3
%[3]

Execution

magick -script resize_custom.mgk photo.jpg 800x600 photo_resized.jpg

Using Standard Input (stdin)

If you generate complex ImageMagick instructions dynamically from another program or bash script, pass - as the script filename to instruct ImageMagick to read commands from standard input:

cat << 'EOF' | magick -script -
image1.jpg
-resize 50%
image2.jpg
+append
combined.jpg
EOF
