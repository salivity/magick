How to Prevent Blurry Text in ImageMagick PDF Conversion

Converting vector PDF pages to raster image formats using ImageMagick often results in blurry, unreadable text because the default rasterization resolution is set too low. The primary solution is using the -density option, which controls the Dots Per Inch (DPI) at which the vector data is rendered. By defining this parameter before loading the input file, you ensure that text and vector paths are rendered sharply at high resolution rather than pixelated.

The Key Option: -density

The default rendering resolution in ImageMagick for PDF files is 72 DPI, which is insufficient for clear text reproduction. To fix this, use the -density flag with a higher value, typically 300 DPI for print quality or general crispness, or 150 DPI for standard web display.

Correct Command Syntax

The placement of the -density option is critical. It must appear before the input PDF file in the command line. If placed after the input file, ImageMagick reads the PDF at the default 72 DPI and merely resizes the resulting blurry bitmap.

ImageMagick v7 Command:

magick -density 300 input.pdf -quality 100 output.png

ImageMagick v6 Command:

convert -density 300 input.pdf -quality 100 output.png

Advanced Technique: Supersampling for Ultra-Sharp Text

If you need a specific output dimension but want maximum text clarity without jagged edges, render at a higher density (supersampling) and then scale down using -resize:

magick -density 600 input.pdf -resize 50% output.png

This technique renders the vector text at 600 DPI and scales it down to the equivalent of 300 DPI, smoothing out font antialiasing and producing exceptionally crisp text.

Handling Transparent Backgrounds

PDFs with vector text often have transparent backgrounds that can cause rendering artifacts. Add -background white -alpha remove -alpha off after setting the density to guarantee a clean, solid background behind the text:

magick -density 300 input.pdf -background white -alpha remove -alpha off output.png
