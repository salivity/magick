How to Process DICOM Medical Images in ImageMagick

This article provides a practical guide on using ImageMagick to handle Digital Imaging and Communications in Medicine (DICOM) files. You will learn the essential command-line techniques for converting medical .dcm files to standard image formats like PNG and JPEG, handling multi-frame datasets, adjusting image contrast and brightness, extracting metadata, and performing batch conversions efficiently.

Understanding DICOM Support in ImageMagick

ImageMagick includes native read-and-write support for DICOM (.dcm) files. Because medical scans (such as X-rays, CTs, and MRIs) often use high bit-depths (12-bit to 16-bit grayscale), direct conversion without adjustment may result in dark or washed-out images. Using ImageMagick's built-in image operators ensures that the pixel data renders accurately for standard screens.

1. Converting DICOM to Standard Image Formats

To convert a single DICOM slice to a standard web-friendly format such as PNG or JPEG:

magick input.dcm output.png

For high-quality JPEG output:

magick input.dcm -quality 95 output.jpg

2. Handling Multi-Frame DICOM Files

Certain DICOM files (such as CT series, cine loops, or multi-slice MRIs) contain multiple layers or frames within a single file.

  • Extract all frames into separate numbered images:

    magick multi_frame.dcm frame_%03d.png

  • Extract a specific frame (e.g., the first frame at index 0):

    magick multi_frame.dcm[0] single_frame.png

  • Convert a multi-frame DICOM into an animated GIF:

    magick -delay 10 multi_frame.dcm -loop 0 scan_animation.gif

3. Adjusting Brightness, Contrast, and Windowing

Medical images often store raw sensor values that require windowing (adjusting the visible range of grayscale values).

  • Auto-leveling contrast: Stretches the color range across the full dynamic spectrum.

    magick input.dcm -auto-level output.png

  • Normalizing image data: Enhances contrast while preventing clipping at extreme black and white points.

    magick input.dcm -normalize output.png

  • Manual brightness and contrast adjustments: Use the -brightness-contrast operator (values are in percentages: brightness,contrast).

    magick input.dcm -brightness-contrast 10x30 output.png

4. Reading DICOM Metadata

DICOM files store crucial patient and technical metadata in their headers. To inspect this data:

  • View all metadata in the terminal:

    magick identify -verbose input.dcm

  • Export metadata to a text file:

    magick identify -verbose input.dcm > metadata.txt

  • Extract specific attributes (e.g., image dimensions and format):

    magick identify -format "%f: %wx%h, %r, %z-bit\n" input.dcm

5. Anonymizing and Stripping Metadata

When sharing images publicly or for research, remove embedded personal health information (PHI):

magick input.dcm -strip anonymized_output.png

The -strip command removes all DICOM header tags and profiles from the output file.

6. Batch Processing Entire Directories

To convert an entire folder of .dcm files to .png format simultaneously:

  • Using mogrify:

    magick mogrify -format png -auto-level *.dcm

  • Using a Bash loop (preserves originals in a separate directory):

    mkdir -p converted
for file in *.dcm; do
    magick "$file" -auto-level "converted/${file%.dcm}.png"
done
