How to Re-encode WebP to WebP Using ImageMagick?

Re-encoding an existing WebP file into a new WebP image using ImageMagick allows you to adjust compression levels, reduce file size, strip metadata, or switch between lossy and lossless formats. This guide explains the core ImageMagick commands required to process a WebP file back into WebP, covers essential quality and compression flags, and demonstrates how to batch process multiple files at once.

Prerequisites and Verification

Before running conversion commands, verify that your ImageMagick installation includes native WebP delegate support. Run the following command in your terminal:

magick -version

Look for webp in the list under the "Delegates (built-in)" section. If you are using an older version of ImageMagick (version 6), substitute magick with convert for the commands listed below.

Basic WebP to WebP Conversion

To re-encode a WebP file with standard settings, specify the source file and provide a destination filename ending in the .webp extension:

magick input.webp output.webp

This basic syntax decodes the source pixels and re-compresses them using ImageMagick's default WebP encoder settings.

Adjusting Quality and Compression

The primary reason to convert WebP to WebP is to fine-tune the balance between visual fidelity and storage footprint.

Lossy Compression

To reduce the file size of an existing WebP, apply the -quality flag followed by a value from 0 to 100:

magick input.webp -quality 75 output.webp

A quality setting between 75 and 82 generally offers a good tradeoff between low file size and high visual fidelity for web delivery.

Lossless Compression

If you want to preserve pixel accuracy while optimizing the internal compression structure, configure the output for lossless mode:

magick input.webp -define webp:lossless=true output.webp

Stripping Metadata

Camera information, profiles, and timestamps can add unnecessary bytes to an image. Use the -strip flag to remove all embedded metadata during re-encoding:

magick input.webp -strip -quality 80 output.webp

Advanced Encoder Settings

ImageMagick provides specific flags via the -define operator to target Google's libwebp encoder features directly:

  • Compression Effort: Control the trade-off between encoding speed and file efficiency using values from 0 (fastest) to 6 (smallest file size):
magick input.webp -define webp:method=6 -quality 80 output.webp
  • Target Size: Instruct the encoder to meet a specific byte count:
magick input.webp -define webp:target-size=50000 output.webp
  • Alpha Channel Quality: Compress transparency separately from color channels:
magick input.webp -define webp:alpha-quality=85 output.webp

Batch Converting Multiple WebP Files

To re-encode an entire directory of WebP images without overwriting original files, use ImageMagick's mogrify utility alongside an output directory flag:

mkdir -p optimized
magick mogrify -path optimized -strip -quality 80 *.webp

This processes every .webp file in the current working directory, strips metadata, recompresses to 80% quality, and outputs the newly encoded images inside the optimized folder.
