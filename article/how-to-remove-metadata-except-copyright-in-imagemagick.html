How to Remove Metadata Except Copyright in ImageMagick

This article demonstrates how to strip non-essential metadata—such as EXIF camera settings, GPS coordinates, and device profiles—from an image using ImageMagick while preserving the copyright string. You will learn the exact ImageMagick command syntax required to dynamically capture existing copyright notices before purging unwanted chunks, as well as how to apply the process in batch operations.

The Command

By default, ImageMagick’s -strip operator removes all metadata profiles (EXIF, IPTC, XMP, and ICM) without exception. To retain existing copyright information, you must temporarily store the copyright string into an internal property, execute the strip operation, and reassign the copyright back to the file.

Use the following command in ImageMagick 7:

magick input.jpg -set temp_copy "%[EXIF:Copyright]" -strip -set Copyright "%[temp_copy]" output.jpg

For ImageMagick 6, replace magick with convert:

convert input.jpg -set temp_copy "%[EXIF:Copyright]" -strip -set Copyright "%[temp_copy]" output.jpg

How the Command Works

  1. -set temp_copy "%[EXIF:Copyright]": Reads the existing EXIF copyright tag from input.jpg and assigns its value to an internal memory variable named temp_copy. If your file stores copyright inside IPTC or XMP instead, replace "%[EXIF:Copyright]" with "%[IPTC:2:116]" or "%[xmp:Rights]".
  2. -strip: Purges all profiles, timestamps, GPS locations, camera settings, and comments from the image payload.
  3. -set Copyright "%[temp_copy]": Restores the stored copyright string back into the output file's metadata headers.
  4. output.jpg: Writes the clean image to the new file path.

Stripping All Metadata and Setting a Hardcoded Copyright

If your images lack existing metadata tags, or if you want to standardize the copyright string across all stripped files, you can strip all chunks and write a new copyright attribute directly in one step:

magick input.jpg -strip -set Copyright "Copyright (c) 2024 Your Name. All rights reserved." output.jpg

Batch Processing Multiple Files

To process an entire folder of JPEG images and save the cleaned files into a dedicated output directory:

magick mogrify -path ./cleaned_images/ -set temp_copy "%[EXIF:Copyright]" -strip -set Copyright "%[temp_copy]" *.jpg

Ensure the ./cleaned_images/ directory exists before executing the command to prevent overwriting your original files.
