How to Reset Canvas Offsets with ImageMagick +repage

When cropping images with ImageMagick, the software often preserves the original image dimensions and positional coordinates as a virtual canvas or page offset. This guide explains why these canvas offsets persist in cropped files and demonstrates how to use the +repage operator to completely remove them, ensuring your cropped images render at their actual pixel dimensions without unwanted margins or misalignments.

Understanding the Virtual Canvas Problem

When you crop an image using ImageMagick’s -crop operator (for example, -crop 400x300+50+50), ImageMagick extracts the requested pixel area but retains the original canvas geometry in formats that support canvas metadata, such as PNG, GIF, and TIFF.

Instead of an isolated 400x300 image, the file retains metadata stating it is a 400x300 sub-region positioned at an offset of +50+50 within the original canvas. When viewed in web browsers, document processors, or image viewers that read canvas geometry, the image may appear shifted, embedded within empty space, or improperly layered.

Using the +repage Operator

The +repage operator resets the virtual canvas metadata, setting the canvas dimensions to match the cropped image's exact dimensions and resetting the offset coordinates to +0+0.

To reset the canvas offset immediately after cropping, place +repage directly after the -crop argument in your command.

Basic Syntax (ImageMagick v7)

magick input.png -crop 400x300+50+50 +repage output.png

Legacy Syntax (ImageMagick v6)

convert input.png -crop 400x300+50+50 +repage output.png

Batch Cropping and Resetting with Mogrify

If you need to crop multiple images in-place and ensure the offsets are removed across all files, use mogrify with +repage:

magick mogrify -crop 300x300+20+20 +repage *.png

Difference Between -repage and +repage

  • +repage (Plus sign): Completely strips existing virtual canvas offsets and sets the page geometry to the current image dimensions with an offset of +0+0. This is the standard operator for finalizing a crop.
  • -repage (Minus sign): Manually defines a new virtual canvas size and offset (for example, -repage 800x600+10+10). Use this only if you want to assign custom canvas parameters rather than clearing them.
