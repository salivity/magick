How to Resize a PNG Image Using ImageMagick?

Resizing PNG files using ImageMagick provides full control over resolution, aspect ratios, and compression directly from your terminal. Whether scaling down for web delivery, creating thumbnails, or batch-processing large directories of assets, ImageMagick handles these operations efficiently through its command-line utilities. This guide covers the essential commands for basic scaling, exact dimension fitting, percentage adjustments, and batch processing.

Basic Proportional Resizing

The most common way to resize an image while preserving its aspect ratio is using the magick command (or convert on ImageMagick 6).

magick input.png -resize 800x600 output.png

When given width and height values, ImageMagick fits the image within the bounding box of 800 by 600 pixels without distorting proportions. If the input image is square, it will scale to 600 by 600 pixels.

To constrain only by width while letting the height adjust automatically, leave the height blank:

magick input.png -resize 800x output.png

Similarly, specifying only height preserves the aspect ratio:

magick input.png -resize x600 output.png

Forcing Exact Dimensions

To ignore the original aspect ratio and force the output to match exact dimensions, append an exclamation mark (!) to the geometry argument. On Unix-based shells (such as Bash or Zsh), escape the exclamation mark with a backslash or wrap the parameter in quotes to prevent shell expansion.

magick input.png -resize "800x600!" output.png

Resizing by Percentage

Scaling by a relative ratio instead of absolute pixel dimensions uses a percentage sign:

magick input.png -resize 50% output.png

This reduces both the width and the height to 50% of their original values, quartering the overall pixel area.

Cropping to Fill Exact Dimensions

If an image needs to fill a specific dimension completely without stretching, combine -resize with -gravity and -extent:

magick input.png -resize 800x600^ -gravity center -extent 800x600 output.png
  • The caret (^) resizes the image so that it covers the entire 800x600 area, meaning one dimension will likely overshoot the target.
  • -gravity center anchors the crop position to the middle.
  • -extent 800x600 crops away the excess overflow.

Batch Resizing Multiple PNGs

To process an entire directory of PNG images, use the mogrify tool. Unlike magick, mogrify modifies files in place unless an output directory is specified.

To safely output resized files into a separate folder:

mkdir -p resized
magick mogrify -path ./resized -resize 800x *.png

To overwrite files in place across an entire folder:

mogrify -resize 800x *.png

Maintaining Transparency and Optimizing Output

PNG files frequently contain alpha transparency. ImageMagick preserves alpha channels during resizing operations by default. When exporting, you can control PNG compression levels using the -quality flag:

magick input.png -resize 800x -quality 95 output.png

For PNG files in ImageMagick, the tens digit sets the zlib compression level (0 to 9), while the units digit controls the filter type (typically 5 for adaptive filtering). A value of 95 applies maximum compression with adaptive filtering to yield small file sizes without affecting image clarity.
