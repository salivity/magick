How to Resize a WebP Image with ImageMagick?

Resizing a WebP image using ImageMagick is a straightforward process performed through the command-line interface. This guide covers how to set up ImageMagick with WebP support, resize single images by exact dimensions or percentages, maintain proper aspect ratios, preserve animation frames, and run batch processing across entire directories.

Prerequisites and Installation

ImageMagick requires the libwebp delegate library to read and write WebP files. Modern installations typically include this out of the box, but you should confirm your system configuration before running conversion commands.

To verify WebP support on your installation, run:

magick -version

Look for webp under the Delegates list. If it is missing, install the WebP libraries and ImageMagick using your system's package manager:

  • Ubuntu / Debian:
sudo apt update
sudo apt install imagemagick libwebp-dev
  • macOS (Homebrew):
brew install imagemagick webp
  • Windows: Download and install the pre-compiled binary from the official ImageMagick website, ensuring the option to add the utility to your system path is checked.

Note: In ImageMagick 7 and newer, use the magick command. For legacy ImageMagick 6 installations, replace magick with convert.

Basic Resizing Commands

The -resize parameter handles dimension adjustments while automatically preserving the original aspect ratio.

Resizing to Fit Specified Dimensions

To constrain an image within specific maximum boundaries (e.g., 800px wide by 600px tall) without distorting the image:

magick input.webp -resize 800x600 output.webp

ImageMagick fits the image inside this box, scaling proportionally based on whichever axis hits the limit first.

Resizing by Width or Height Only

If you only need to match a single dimension and let the other scale proportionally, omit the second measurement:

  • Specify Width (800px):
magick input.webp -resize 800x output.webp
  • Specify Height (600px):
magick input.webp -resize x600 output.webp

Resizing by Percentage

To scale an image relative to its original size:

magick input.webp -resize 50% output.webp

Advanced Resizing Options

Forcing Exact Dimensions

If you need an image to match exact pixel dimensions regardless of distortion, append an exclamation point (!) to the geometry argument. In many shells, escape the exclamation mark to avoid syntax errors:

magick input.webp -resize "800x600\!" output.webp

Only Shrinking Larger Images

To avoid upscaling small images and only resize images that exceed target dimensions, append the greater-than symbol (>):

magick input.webp -resize "1200x1200>" output.webp

Controlling Output Quality and Compression

WebP supports both lossy and lossless modes. Use the -quality flag to balance file size against visual clarity:

magick input.webp -resize 800x -quality 80 output.webp

For lossless WebP resizing, specify the define parameter:

magick input.webp -resize 800x -define webp:lossless=true output.webp

Handling Animated WebP Files

Resizing an animated WebP file without special flags can break frame delays or strip animation completely. Use -coalesce before resizing and include your output configuration to maintain proper frame timing:

magick input.webp -coalesce -resize 400x -layers optimize output.webp

The -coalesce option ensures each frame has a full canvas to prevent tearing during resizing, and -layers optimize removes redundant frame data to keep the file size minimal.

Batch Resizing Multiple WebP Files

To resize multiple files at once, use ImageMagick's mogrify tool or shell scripting loops.

Using Mogrify

mogrify modifies files in place or writes them to a specific output path:

magick mogrify -path ./resized/ -resize 800x *.webp

This processes every .webp file in the current directory and places the resized versions inside the resized folder.

Using a Bash Loop

A shell loop allows you to retain original filenames while writing to a structured output format:

for file in *.webp; do
  magick "$file" -resize 800x "resized_${file}"
done
