How to Resize an Animated GIF in ImageMagick

Resizing an animated GIF using ImageMagick requires processing every frame correctly to avoid visual corruption and bloated file sizes. This guide explains the exact command-line syntax required to scale all frames of an animated GIF to fit within a specific bounding box while preserving the original aspect ratio.

The Basic Syntax

To resize an animated GIF to fit within a bounding box (for example, 300x300 pixels), use the following command:

ImageMagick v7:

magick input.gif -coalesce -resize 300x300 -layers optimize output.gif

ImageMagick v6:

convert input.gif -coalesce -resize 300x300 -layers optimize output.gif

How the Command Works

  • input.gif: The path to your source GIF file.
  • -coalesce: Rebuilds the complete image for each frame. Animated GIFs often store only the pixels that change between frames (delta frames). Without -coalesce, resizing will cause ghosting, artifacts, or distortion across the animation.
  • -resize 300x300: Sets the bounding box. By default, ImageMagick preserves the aspect ratio and scales the image so that neither dimension exceeds the specified width and height. For example, a 600x400 GIF resized with 300x300 will become 300x200.
  • -layers optimize: Re-optimizes the frames after resizing. This removes duplicate pixels across frames and shrinks the final file size.
  • output.gif: The path where the resized GIF will be saved.

Common Bounding Box Variations

ImageMagick geometry strings allow you to adjust the resizing behavior:

  • Fit within box (default): -resize 300x300 ensures the image fits within a 300x300 box without changing the aspect ratio.
  • Fill box and crop (cover): -resize 300x300^ -gravity center -extent 300x300 scales the image to completely fill the 300x300 dimensions and crops any overflow.
  • Force exact dimensions (ignore aspect ratio): -resize 300x300! stretches or squishes the frames to match the exact dimensions.
  • Shrink only if larger: -resize 300x300\> only resizes the GIF if its original dimensions are larger than the specified bounding box.
