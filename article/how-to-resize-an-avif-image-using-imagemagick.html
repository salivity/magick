How to Resize an AVIF Image Using ImageMagick?

Resizing an AVIF image with ImageMagick requires using the magick command paired with the -resize flag, provided your installation includes AVIF delegate support via libheif. This guide covers how to check your ImageMagick version for AVIF compatibility, run standard and proportional resize commands, control compression quality, and batch process multiple AVIF files directly from the terminal.

Prerequisites and AVIF Support Check

Before executing resize commands, ensure ImageMagick can decode and encode AVIF files. AVIF processing depends on the libheif delegate library.

Run the following command in your terminal to verify support:

magick -version

Look for heic or heif in the Delegates (built-in) list. You can also explicitly check format capabilities:

magick identify -list format | grep -i avif

If the output lists AVIF* rw+ (or rw-), your installation can read and write AVIF files. If it returns nothing, update ImageMagick or install libheif support via your system package manager.

Resizing a Single AVIF Image

ImageMagick 7 uses the unified magick binary. Resizing is handled via the -resize geometry operator.

1. Maintain Aspect Ratio by Specifying Width

To resize an image to a specific width (for example, 800 pixels) while automatically adjusting the height to prevent distortion:

magick input.avif -resize 800x output.avif

2. Maintain Aspect Ratio by Specifying Height

To scale an image by height (for example, 600 pixels) and let the width adjust automatically:

magick input.avif -resize x600 output.avif

3. Fit Within a Maximum Bounding Box

Specifying both width and height scales the image down so that it fits inside the specified boundary without altering the original aspect ratio:

magick input.avif -resize 1200x800 output.avif

4. Force Exact Dimensions

To force exact dimensions regardless of distortion, append an exclamation point (!) to the geometry. In bash or zsh, escape the exclamation point with a backslash or wrap the parameter in quotes:

magick input.avif -resize "800x600\!" output.avif

5. Resize by Percentage

To scale down an image by a percentage (for example, 50% of its original size):

magick input.avif -resize 50% output.avif

Controlling Output Quality and Speed

AVIF relies heavily on compression efficiency. By default, ImageMagick applies standard compression, but fine-tuning parameters ensures optimal file sizes.

Adjusting Quality

The -quality flag controls AVIF visual fidelity. Values typically range from 1 to 100, where 50 to 75 offers an effective balance between small file size and clear detail:

magick input.avif -resize 1024x -quality 65 output.avif

Compression Effort

You can adjust encoding speed and efficiency using the heif:speed define. Setting a higher speed value (from 0 to 9) speeds up encoding at the expense of a slightly larger file size:

magick input.avif -resize 1024x -define heif:speed=6 output.avif

Batch Resizing AVIF Images

To process an entire folder of AVIF images, use mogrify or a shell loop.

In-Place Batch Resizing with Mogrify

The mogrify command overwrites original files unless an output directory is explicitly specified:

mkdir -p resized
magick mogrify -path resized -resize 1200x *.avif

This processes all .avif files in the current folder, resizes each to 1200 pixels wide proportionally, and writes the output files into the resized directory.

Shell Loop for Safer Processing

Using a bash loop provides better control over naming patterns:

for file in *.avif; do
    magick "$file" -resize 1200x -quality 70 "${file%.avif}-resized.avif"
done

This iterates through every AVIF file in the current working directory, scales it down, applies quality compression, and appends -resized to the filename.
