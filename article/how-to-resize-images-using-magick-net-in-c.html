How to Resize Images Using Magick.NET in C#

Resizing images programmatically is a common requirement in modern .NET applications, and Magick.NET provides a robust C# wrapper around the ImageMagick library to handle this efficiently. This article provides the essential syntax and patterns required to resize images using Magick.NET, including scaling to specific dimensions, preserving or ignoring aspect ratios, and resizing by a percentage.

Installing the Package

Before using the code, install the Magick.NET NuGet package via the .NET CLI or Package Manager Console:

dotnet add package Magick.NET-Q8-AnyCPU

Basic Resizing (Preserving Aspect Ratio)

By default, passing dimensions into MagickGeometry fits the image within the specified bounding box while maintaining its original aspect ratio.

using ImageMagick;

using (var image = new MagickImage("input.jpg"))
{
    // Resizes to fit within an 800x600 box without distorting the image
    var size = new MagickGeometry(800, 600);
    image.Resize(size);

    image.Write("output_proportional.jpg");
}

Forcing Exact Dimensions (Ignoring Aspect Ratio)

To force an image into exact pixel dimensions regardless of distortion, set the IgnoreAspectRatio property on MagickGeometry to true.

using ImageMagick;

using (var image = new MagickImage("input.jpg"))
{
    var size = new MagickGeometry(800, 600)
    {
        IgnoreAspectRatio = true
    };

    image.Resize(size);
    image.Write("output_exact.jpg");
}

Resizing by Width or Height Only

If you only specify one dimension (setting the other to 0), Magick.NET calculates the missing dimension automatically to maintain the aspect ratio.

using ImageMagick;

using (var image = new MagickImage("input.jpg"))
{
    // Scales to a width of 500px; height adjusts automatically
    var size = new MagickGeometry(500, 0);
    image.Resize(size);

    image.Write("output_width.jpg");
}

Resizing by Percentage

You can scale an image relative to its original dimensions using the Percentage struct.

using ImageMagick;

using (var image = new MagickImage("input.jpg"))
{
    // Reduces the image dimensions to 50% of the original size
    var scale = new Percentage(50);
    image.Resize(scale);

    image.Write("output_half.jpg");
}

Adaptive Resizing

For downscaling photos and complex images, the AdaptiveResize method provides slightly better visual fidelity by applying data-dependent triangulation:

using ImageMagick;

using (var image = new MagickImage("input.jpg"))
{
    var size = new MagickGeometry(400, 300);
    image.AdaptiveResize(size);

    image.Write("output_adaptive.jpg");
}
