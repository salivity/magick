How to Reverse an Animated GIF with ImageMagick

Reversing an animated GIF allows you to play the animation backward from the final frame to the first. Using ImageMagick, a versatile command-line image manipulation tool, you can invert the frame order of any animated GIF with a single command. This guide demonstrates the exact commands needed to reverse a GIF's playback order properly while preserving visual quality and optimizing file size.

The Basic Command

To reverse the frame order of an animated GIF, use the -reverse operator.

For ImageMagick v7:

magick input.gif -coalesce -reverse -layers Optimize output.gif

For ImageMagick v6:

convert input.gif -coalesce -reverse -layers Optimize output.gif

How It Works

  1. -coalesce: Animated GIFs often only store the pixels that change between frames to save file size. The -coalesce operator fully renders each complete frame before altering the order, preventing graphical glitches and artifacts in the reversed animation.
  2. -reverse: Inverts the sequence of all frames currently loaded in memory, making the last frame first and the first frame last.
  3. -layers Optimize: Re-compresses the reversed frames by removing redundant pixel data, ensuring the final output file size remains as small as possible.

Optional Adjustments

  • Set Infinite Looping: If your reversed GIF stops after one play, add -loop 0 before the output filename to ensure it loops continuously:

    magick input.gif -coalesce -reverse -loop 0 -layers Optimize output.gif

  • Adjust Playback Speed: To change the delay between frames during reversal, apply the -delay setting (measured in hundredths of a second):

    magick input.gif -coalesce -reverse -delay 10 -layers Optimize output.gif
