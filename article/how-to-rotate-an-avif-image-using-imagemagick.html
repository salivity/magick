How to Rotate an AVIF Image Using ImageMagick?

Rotating an AVIF (AV1 Image File Format) image with ImageMagick requires the command-line tool paired with the libheif delegate to decode and encode AVIF files properly. By using the -rotate or -auto-orient options in ImageMagick's magick command, you can execute clockwise, counterclockwise, or metadata-driven rotations without losing visual clarity. This guide explains how to verify AVIF support, run basic and advanced rotation commands, and batch-process multiple AVIF files at once.

Verifying AVIF Support in ImageMagick

Before running rotation commands, ensure your ImageMagick installation supports the AVIF format through libheif. You can check this by querying your installed delegates in your terminal:

magick -version

Look for heic or heif in the Delegates (built-in) line. Alternatively, verify explicit support for AVIF format handling:

magick identify -list format | grep -i avif

If AVIF appears with read and write permissions (rw+ or rw-), your build is ready to process AVIF images. If it is missing, you must install libheif via your operating system's package manager (such as brew install libheif imagemagick on macOS or compiling with libheif-dev on Linux).

Basic Image Rotation Commands

ImageMagick uses the magick command (or convert in legacy ImageMagick 6 installations) to load, manipulate, and export images. The -rotate operator accepts angles in degrees, applying clockwise rotations for positive values and counterclockwise rotations for negative values.

To rotate an AVIF image 90 degrees clockwise:

magick input.avif -rotate 90 output.avif

To rotate an image 90 degrees counterclockwise (270 degrees clockwise):

magick input.avif -rotate 270 output.avif

Or using a negative value:

magick input.avif -rotate -90 output.avif

To rotate an image upside down (180 degrees):

magick input.avif -rotate 180 output.avif

Rotating Based on EXIF Metadata

Digital cameras and smartphones often save orientation data inside the image EXIF tags rather than physically rotating the pixel grid. If an AVIF file appears sideways in some viewers and correct in others, use -auto-orient to read the EXIF orientation flag, rotate the pixel buffer accordingly, and reset the orientation tag:

magick input.avif -auto-orient output.avif

Preserving Compression Quality

Re-encoding an AVIF image defaults to ImageMagick's built-in compression settings, which may alter file size or fidelity. You can control the visual quality using the -quality flag, where values range from 1 (lowest quality, smallest size) to 100 (near-lossless):

magick input.avif -rotate 90 -quality 80 output.avif

For strictly lossless rotation:

magick input.avif -rotate 90 -define heic:lossless=true output.avif

Batch Rotating Multiple AVIF Files

To rotate multiple AVIF files in a single directory without overwriting the originals, use ImageMagick's mogrify tool with a dedicated output directory.

First, create a destination folder:

mkdir rotated

Then process all AVIF files in the current folder:

magick mogrify -path rotated -rotate 90 *.avif

This processes every .avif file, applies a 90-degree clockwise rotation, and saves the resulting files into the rotated directory under their original filenames.
