How to Rotate Text with ImageMagick Annotate Angle

This guide explains how ImageMagick’s -annotate command handles text rotation and shearing using its angle syntax. You will learn the mechanics behind the single and dual angle arguments, how they manipulate the coordinate axes, and how to control the anchor point to rotate text around an arbitrary position on an image canvas.

Understanding the -annotate Geometry Syntax

In ImageMagick, the standard syntax for -annotate accepts a geometry argument formatted as:

-annotate [degrees_x]x[degrees_y]+X+Y "Text"

While many users provide a single numeric value for a basic 2D rotation, the full specification accepts two distinct angles separated by an x. These two values explicitly define the rotation of the local coordinate axes:

  • degrees_x (X-axis angle): Rotates the text baseline relative to the horizontal axis.
  • degrees_y (Y-axis angle): Rotates the vertical stroke (upright stems) of the text relative to the vertical axis.

Rotating Text Along an Arbitrary Axis via Shearing

When rotating standard 2D text, both axes rotate simultaneously by the same amount. Providing a single value like -annotate 45+100+100 is shorthand for setting both degrees_x and degrees_y to 45.

To simulate rotation along an arbitrary, non-perpendicular axis (such as an isometric projection or perspective skew), you supply different values for the X and Y angles:

magick input.png -annotate 30x0+100+100 "Sheared Text" output.png

In this example, the baseline tilts upward by 30 degrees, while the letter stems remain strictly vertical (0 degrees), shearing the text horizontally. Conversely:

magick input.png -annotate 0x30+100+100 "Vertical Skew" output.png

This keeps the baseline flat while leaning the vertical stems forward by 30 degrees. By manipulating both angles independently, you transform the orthogonal coordinate system into an affine grid oriented along an arbitrary directional vector.

Controlling the Rotation Pivot Point

Text rotates around its origin point. By default, this origin is the left-edge baseline of the text string at offset +0+0. To rotate along an arbitrary center or pivot point:

  1. Set -gravity: The gravity setting determines the anchor point of the text box. Using -gravity Center places the origin in the exact center of the text string, causing rotation to occur around its geometric midpoint rather than its bottom-left baseline.
  2. Apply Offset Coordinates: The +X+Y offset specifies the exact pixel location on the canvas where this pivot anchor is placed.

For example, to rotate text 45 degrees around its exact center at canvas coordinates (300, 200):

magick input.png -gravity Center -annotate 45+300+200 "Centered Rotation" output.png

For complex, true 3D rotations where text must rotate around arbitrary vectors in three-dimensional space, -annotate is paired with -distort Perspective or -affine transformation matrices, but for two-dimensional planar transformations and skew-based axis adjustments, the dual-angle -annotate degrees_x x degrees_y provides direct native control.
