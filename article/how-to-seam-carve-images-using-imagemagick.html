How to Seam Carve Images Using ImageMagick

Content-aware image resizing, also known as seam carving, reduces or expands an image's dimensions by removing or inserting pixels in areas with low visual detail while preserving key subjects. ImageMagick accomplishes this technique via the -liquid-rescale operator, which utilizes the open-source Liquid Rescale library (liblqr). This guide covers how to verify support, execute basic seam carving commands, fine-tune parameters, and use masks to protect or remove specific image elements.

1. Verify Liquid Rescale Support

Before using seam carving, ensure your ImageMagick installation includes the liblqr delegate. Run the following command in your terminal:

magick -version

Look for lqr in the Delegates (built-in) list. If it is missing, you must install liblqr and rebuild or reinstall ImageMagick (e.g., using brew install imagemagick on macOS or your Linux distribution's package manager).

2. Basic Seam Carving Command

To resize an image using content-aware scaling, replace the standard -resize operator with -liquid-rescale.

To reduce the width to 600 pixels while keeping the original height (e.g., original is 800x600):

magick input.jpg -liquid-rescale 600x600! output.jpg

Note: The exclamation point (!) forces ImageMagick to ignore the original aspect ratio and strictly apply the requested dimensions, which is necessary for seam carving to alter the image's proportions.

You can also use percentages:

magick input.jpg -liquid-rescale 70x100%! output.jpg

3. Fine-Tuning Seam Carving Parameters

The -liquid-rescale operator accepts optional parameters to control rigidity and maximum seam step size using the following format:

geometry{+rigidity}{+max_step}

  • Rigidity: Adds a bias to non-straight seams to prevent distortion of linear structures (default is 0).
  • Max Step: Determines the maximum transverse step that seams can take, where larger values allow more flexible seam paths (default is 1).

Example applying a rigidity factor:

magick input.jpg -liquid-rescale 600x600+2+1! output.jpg

4. Protecting and Removing Features with Masks

You can guide the seam carving algorithm by using an auxiliary grayscale mask. White areas prioritize preservation, while black areas mark features for removal.

Protecting Specific Areas

To protect a subject, create a mask matching the image dimensions where the protected subject is white and the background is black, then apply it as an energy map:

magick input.jpg mask.png -liquid-rescale 600x600! output.jpg

Object Removal

To force the algorithm to carve away a specific object, paint the target object black (0% energy) and the rest of the image white, then reduce the image width or height by the approximate width of the object:

magick input.jpg removal_mask.png -liquid-rescale 500x600! output.jpg

5. Combining Standard Resizing with Seam Carving

For drastic aspect ratio changes, applying seam carving to the entire reduction can cause artifacts. A standard approach is to scale the image proportionally first, then apply seam carving for the final aspect adjustment:

magick input.jpg -resize 800x600^ -liquid-rescale 600x600! output.jpg
