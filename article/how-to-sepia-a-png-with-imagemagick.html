How to Sepia a PNG with ImageMagick?

Applying a sepia tone gives modern digital images a warm, vintage, brown-tinted aesthetic reminiscent of early photography. ImageMagick makes this transformation fast and scriptable using the dedicated -sepia-tone operator from the command line. This guide demonstrates how to apply a sepia filter to a PNG file, adjust tone intensity, handle PNG transparency safely, and process multiple files in batch.

The Basic Sepia Command

ImageMagick provides a built-in -sepia-tone operator that requires a single numeric threshold argument, usually specified as a percentage. In modern ImageMagick (version 7 and later), use the magick command:

magick input.png -sepia-tone 80% output.png

If you are running ImageMagick version 6, replace magick with convert:

convert input.png -sepia-tone 80% output.png

Tuning Sepia Intensity

The threshold parameter controls the strength and warmth of the toning effect:

  • 80% to 85%: The standard, balanced sepia look that preserves good dynamic contrast while applying rich warm tones.
  • 90% to 95%: A subtle, gentle tint where highlights stay relatively bright and shadows take on a soft amber hue.
  • 60% to 70%: A heavy, deeply aged treatment that aggressively flattens tonal ranges into deep coppers and dark browns.

You can test different values to achieve the desired mood:

magick input.png -sepia-tone 90% subtle.png
magick input.png -sepia-tone 65% intense.png

Preserving PNG Transparency

PNG files often contain an alpha channel for transparent backgrounds. Applying global operations can sometimes tint transparent areas or cause unexpected fringing along soft edges. To ensure the sepia effect only modifies the visible RGB channels while keeping the original alpha intact, restrict the operation:

magick input.png -channel RGB -sepia-tone 80% +channel output.png

The -channel RGB flag limits the color shift to visible pixels, and +channel resets channel selection so subsequent writing processes write the original alpha channel back out correctly.

Batch Processing Multiple PNGs

To apply the sepia effect across an entire folder of PNG images without writing complex loops, use ImageMagick's mogrify tool.

To overwrite the files directly:

magick mogrify -channel RGB -sepia-tone 80% +channel *.png

To save the converted files into a dedicated subfolder instead of overwriting the originals, specify a target path:

mkdir -p sepia_output
magick mogrify -path sepia_output -channel RGB -sepia-tone 80% +channel *.png
