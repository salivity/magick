How to Sepia a WebP Image with ImageMagick?

Applying a sepia tone gives modern digital photos a warm, antique aesthetic reminiscent of early photography. ImageMagick makes this transformation simple and highly scriptable across single files or large batches of WebP images. By using ImageMagick’s built-in sepia operator, you can quickly convert any WebP image into a vintage-toned output while controlling the exact intensity of the tint.

Understanding the Sepia Tone Operator

ImageMagick provides a dedicated operator called -sepia-tone that maps the luminance of an image to a dual-tone warm palette. The parameter passed to this operator represents the sepia threshold percentage, usually between 80% and 95%. A value of 80% produces a subtle, soft antique look, while 90% or 95% yields a stronger, classic dark-amber tint.

Basic Command Syntax

In modern installations using ImageMagick 7, commands use the magick binary:

magick input.webp -sepia-tone 80% output.webp

If you are using legacy ImageMagick (version 6), substitute magick with convert:

convert input.webp -sepia-tone 80% output.webp

Tuning Tone and Contrast

For images that end up looking washed out after the color shift, combining the sepia operation with slight contrast or level adjustments creates a richer finish.

magick input.webp -sepia-tone 85% -level 5%,95% output.webp

This command applies an 85% sepia effect while trimming extreme clipping points, deepening the shadows and brightening the mid-tones.

Preserving Quality and Compression

WebP supports both lossy and lossless compression. ImageMagick defaults to its own standard compression metrics unless specified otherwise. To maintain high fidelity in your final image, supply the -quality flag alongside your command:

magick input.webp -sepia-tone 80% -quality 90 output.webp

Setting quality between 85 and 90 retains high textural detail while taking full advantage of the efficient WebP compression format.

Batch Processing Multiple WebP Files

To apply the sepia effect across an entire directory of WebP images without processing them one by one, use ImageMagick’s batch processing tool:

magick mogrify -format webp -path ./sepia_output -sepia-tone 80% *.webp

Ensure the destination folder exists before running this command. It reads every .webp file in the current folder, applies the sepia adjustment, and writes the transformed copies to the designated output path without overwriting the original files.
