How to Sepia an AVIF Image in ImageMagick?

This guide explains how to convert an AVIF image into a classic sepia tone using ImageMagick via the command line. You will learn the exact syntax required for both ImageMagick 7 and legacy ImageMagick 6, how to adjust the intensity of the sepia-toning effect, and how to preserve the AVIF format while controlling output quality.

Prerequisites and AVIF Support

Before running commands, ensure your ImageMagick installation includes AVIF delegate support (typically provided via libheif). You can verify if ImageMagick can decode and encode AVIF files by executing:

magick identify -list format | grep -i avif

If AVIF appears with read and write permissions (rw- or r--), your system is ready.

Basic Sepia Tone Conversion

ImageMagick provides a built-in -sepia-tone operator that simulates the warm, brownish monochrome tint of vintage photography. The operator takes a threshold percentage representing the intensity of the toning effect, typically set around 80%.

ImageMagick 7 (Recommended)

magick input.avif -sepia-tone 80% output.avif

ImageMagick 6 (Legacy)

convert input.avif -sepia-tone 80% output.avif

Adjusting Sepia Tone Intensity

The percentage passed to -sepia-tone alters the tone's intensity:

  • Lower percentages (e.g., 60% to 70%): Yields a subtle, softer brownish tint with higher contrast retained in midtones.
  • Standard values (e.g., 80%): Provides a balanced, traditional sepia photo look.
  • Higher percentages (e.g., 90% to 95%): Produces a deep, amber-heavy effect that mimics heavily aged paper.

To apply a subtler tone:

magick input.avif -sepia-tone 65% subtle_sepia.avif

Controlling AVIF Compression and Quality

Because AVIF is a modern, highly compressed format, applying an image transformation requires re-encoding. You can control the visual fidelity and file size using the -quality flag:

magick input.avif -sepia-tone 80% -quality 65 output_compressed.avif

Setting -quality between 50 and 70 typically achieves a good balance between small file size and sharp visual quality for AVIF outputs.

Batch Processing Multiple AVIF Files

To apply sepia toning to an entire directory of AVIF images on Linux or macOS, use a shell loop:

for file in *.avif; do
  magick "$file" -sepia-tone 80% "sepia_${file}"
done

On Windows Command Prompt, run:

for %f in (*.avif) do magick "%f" -sepia-tone 80% "sepia_%f"
