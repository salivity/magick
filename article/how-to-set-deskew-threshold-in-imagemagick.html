How to Set Deskew Threshold in ImageMagick

ImageMagick provides the -deskew parameter to automatically straighten tilted or rotated scanned images. This article explains how to use the threshold percentage setting with the -deskew operator, how the percentage influences the alignment process, and how to properly execute the command for clean, upright documents.

The -deskew Parameter

The parameter that sets the deskew threshold percentage in ImageMagick is -deskew. It takes a single argument representing the threshold value, typically formatted as a percentage.

magick input.png -deskew 40% output.png

(Note: In ImageMagick version 6, replace magick with convert.)

How the Threshold Percentage Works

The threshold percentage tells ImageMagick how sensitive it should be when detecting horizontal or vertical text lines:

  • Default Recommendation (40%): A setting of 40% is standard for typical black-and-white or high-contrast scanned text. It effectively ignores minor background noise and focuses on dominant text baselines.
  • Higher Percentages (e.g., 60%–80%): Increases the stringency of line detection. This is useful for noisy, low-contrast, or faint documents where stray artifacts might otherwise be mistaken for text.
  • Lower Percentages (e.g., 20%–30%): Makes the algorithm more sensitive, allowing it to detect alignment angles on sparse pages or documents with very short lines of text.

Example Usage

To deskew a document while preserving the original canvas size and background color, you can combine -deskew with background-filling options:

magick scan.pdf -background white -deskew 40% straightened.pdf

If you omit the percentage and run -deskew 0, ImageMagick uses a default threshold equivalent to 40%.
