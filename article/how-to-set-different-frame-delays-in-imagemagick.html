How to Set Different Frame Delays in ImageMagick

Setting variable frame delays in an animated GIF using ImageMagick allows you to control the exact duration of each frame individually rather than applying a uniform speed across the entire animation. By applying the -delay operator before specific input files during creation, or by using the -set delay attribute on specific frame indices for existing GIFs, you can pause on important frames, speed through transitions, and optimize overall animation timing.

Understanding the Delay Unit

ImageMagick measures animation delays in ticks per second, where the default is 100 ticks per second (centiseconds).

  • -delay 10 = 0.10 seconds (100 ms)
  • -delay 50 = 0.50 seconds (500 ms)
  • -delay 100 = 1.00 second (1000 ms)
  • -delay 200 = 2.00 seconds (2000 ms)

Creating a New GIF with Variable Frame Delays

To set different delays when generating a GIF from a sequence of images, place the -delay parameter directly before each frame or set of frames. The delay setting applies to all subsequent images until a new -delay value is encountered.

magick -delay 100 frame1.png -delay 20 frame2.png frame3.png -delay 200 frame4.png -loop 0 output.gif

In this example:

  • frame1.png is displayed for 1.00 second (-delay 100).
  • frame2.png and frame3.png are displayed for 0.20 seconds each (-delay 20).
  • frame4.png is displayed for 2.00 seconds (-delay 200).
  • -loop 0 ensures the animation loops infinitely.

(Note: If you are using ImageMagick 6, replace magick with convert.)

Modifying Delays in an Existing GIF

If you already have a compiled GIF and want to change individual frame durations without breaking the file into separate image files first, use the -set delay property.

1. Setting Individual Frame Delays by Index

In ImageMagick 7, you can modify specific frames directly using their zero-based index:

magick input.gif -set delay 20 -set delay[0] 100 -set delay[3] 300 output.gif

In this command:

  • -set delay 20 sets the base speed to 0.20 seconds for all frames.
  • -set delay[0] 100 overrides the first frame's duration to 1.00 second.
  • -set delay[3] 300 overrides the fourth frame's duration to 3.00 seconds.

2. Modifying Specific Frame Ranges Using Parentheses

You can also isolate frames inside explicit operational blocks:

magick input.gif \( -clone 0 -set delay 150 \) -swap 0,-1 +delete \( -clone 5 -set delay 250 \) -swap 5,-1 +delete output.gif

This method clones the target frame, applies the new delay, swaps it into the original position, and deletes the temporary clone.

Pausing on the First and Last Frames

A common requirement is pausing on the first or final frame of a looping animation while keeping the intermediate frames fast:

magick -delay 200 first_frame.png -delay 5 mid_frame*.png -delay 300 last_frame.png -loop 0 presentation.gif

This ensures a 2-second hold at the start, rapid playback through intermediate transitions, and a 3-second hold on the concluding frame before the loop restarts.
