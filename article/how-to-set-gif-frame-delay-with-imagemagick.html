How to Set GIF Frame Delay with ImageMagick

Changing the playback speed of an animated GIF is simple using ImageMagick's -delay parameter. This guide covers the exact command syntax needed to adjust frame durations on an existing GIF, create a new animated GIF from individual image files with a custom speed, and understand how ImageMagick calculates delay units.

Understanding the Delay Unit

ImageMagick measures the -delay option in hundredths of a second (centiseconds, or ticks of 1/100th of a second).

  • -delay 10 = 10/100 of a second (100 milliseconds per frame, or 10 frames per second).
  • -delay 50 = 50/100 of a second (500 milliseconds / 0.5 seconds per frame).
  • -delay 100 = 100/100 of a second (1 full second per frame).

Command to Change Delay on an Existing GIF

To change the frame delay of an existing animated GIF across all frames, use the following command:

ImageMagick v7 (Current Version)

magick input.gif -delay 20 -layers optimize output.gif

ImageMagick v6 (Legacy Version)

convert input.gif -delay 20 -layers optimize output.gif

Note: Adding -layers optimize ensures the output GIF remains properly compressed and removes redundant frame artifacts.

Setting Delay When Creating a GIF from Still Images

If you are assembling a series of static images (such as PNG or JPEG files) into an animated GIF, place the -delay flag before the input files:

magick -delay 15 -loop 0 frame*.png output.gif
  • -delay 15: Sets the duration of each image to 150 milliseconds.
  • -loop 0: Ensures the resulting GIF loops infinitely (use 1, 2, etc., for a specific number of repetitions).

Setting Different Delays for Specific Frames

You can assign different delays to individual frames by applying the -delay flag dynamically before specific inputs or by targeting frame indices:

magick frame1.png -delay 50 frame2.png frame3.png -delay 200 frame4.png -loop 0 output.gif

In this example, the transition between frame1.png, frame2.png, and frame3.png runs at 50 centiseconds, while frame4.png pauses for 2 seconds (200 centiseconds) before looping.
