How to Set ImageMagick Temporary Directory Path

When processing large image files or handling complex batches, ImageMagick often exceeds system memory and writes pixel cache data to a temporary disk location. If your default temporary partition runs out of space, the process will fail. This article explains how to change the ImageMagick temporary directory path using environment variables, configuration files, and one-off commands to prevent disk space errors and optimize performance.

Method 1: Use Environment Variables (Recommended)

The most flexible way to define a custom temporary directory is by setting ImageMagick-specific environment variables.

On Linux and macOS:

Set the MAGICK_TEMPORARY_PATH variable to your desired directory:

export MAGICK_TEMPORARY_PATH="/path/to/large_disk/tmp"

To make this permanent, add the line above to your shell profile file (e.g., ~/.bashrc, ~/.zshrc, or /etc/environment).

Alternatively, ImageMagick also respects standard system variables if MAGICK_TEMPORARY_PATH is not defined:

export TMPDIR="/path/to/large_disk/tmp"

On Windows:

Set the variable in the Command Prompt:

set MAGICK_TEMPORARY_PATH=D:\ImageMagickTemp

In PowerShell:

$env:MAGICK_TEMPORARY_PATH = "D:\ImageMagickTemp"

To make it permanent in Windows, add MAGICK_TEMPORARY_PATH to your System Environment Variables via the System Properties control panel.

Method 2: Configure policy.xml

You can enforce a temporary directory globally across all users and scripts by updating ImageMagick's security and resource configuration file.

  1. Locate your policy.xml file. Common paths include /etc/ImageMagick-7/policy.xml or /etc/ImageMagick-6/policy.xml on Linux.
  2. Open the file in a text editor with administrative privileges.
  3. Add or modify the temporary-path resource policy inside the <policymap> section:
<policymap>
  <policy domain="resource" name="temporary-path" value="/path/to/large_disk/tmp"/>
</policymap>
  1. Save the file. Ensure the specified directory exists and has appropriate read/write permissions for the user executing ImageMagick.

Method 3: Set Path for a Single Command

If you only need a custom location for a single intensive command, define the environment variable inline before executing your operation.

Linux / macOS:

MAGICK_TEMPORARY_PATH="/path/to/large_disk/tmp" magick convert large_input.tif -resize 50% output.tif

Windows (Command Prompt):

cmd /C "set MAGICK_TEMPORARY_PATH=D:\Temp && magick convert large_input.tif -resize 50% output.tif"

Verifying the Configuration

To verify that ImageMagick recognizes your resource configuration and temporary path, run the following command:

magick identify -list resource

(Use convert -list resource for ImageMagick v6)

Check the output line for Temporary path to ensure it reflects your new directory path.
