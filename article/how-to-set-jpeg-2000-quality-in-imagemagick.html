How to Set JPEG 2000 Quality in ImageMagick

This guide explains how to configure compression quality rates for JPEG 2000 (JP2) images using ImageMagick. It covers setting lossy versus lossless modes, applying quality percentages, and using delegate-specific definitions to control exact compression ratios and bitrates across your image workflows.

Prerequisites and Delegates

ImageMagick relies on external delegates to handle JPEG 2000 files, most commonly OpenJPEG (libopenjp2) or JasPer. Modern builds of ImageMagick (version 7 and recent version 6 releases) use OpenJPEG. Ensure your ImageMagick build has JP2 support by running:

magick -list format | grep JP2

Basic Quality Configuration

The primary mechanism for adjusting quality in ImageMagick is the -quality flag. For JPEG 2000, the behavior of the -quality flag differs slightly from standard JPEG.

1. Lossless Compression

A quality setting of 100 instructs the encoder to use reversible (lossless) wavelet transformations:

magick input.png -quality 100 output.jp2

In lossless mode, no image data is discarded, ensuring an exact pixel-by-pixel reproduction at the cost of a larger file size.

2. Lossy Compression

Any value below 100 enables lossy compression using irreversible wavelet filters. Lower values increase the compression ratio, resulting in smaller files with reduced visual fidelity:

magick input.png -quality 75 output.jp2

In OpenJPEG, a quality value between 1 and 99 maps directly to target Peak Signal-to-Noise Ratio (PSNR) values or internal rate-distortion targets depending on the underlying delegate version.

Advanced Rate Control Using Definitions

For precise control over file sizes and compression ratios, use coder-specific -define arguments rather than arbitrary quality percentages.

Setting Exact Compression Ratios

You can define explicit compression ratios using the jp2:rate option. The value represents the compression factor relative to uncompressed raw data:

# Compresses the image to roughly 20:1 ratio
magick input.tif -define jp2:rate=20 output.jp2

# Compresses the image to roughly 50:1 ratio (higher compression)
magick input.tif -define jp2:rate=50 output.jp2

Setting Multiple Quality Layers

JPEG 2000 supports progressive decoding via multiple quality layers. You can define multiple target rates or PSNR values separated by commas:

# Encodes three progressive quality layers
magick input.tif -define jp2:quality=30,40,50 output.jp2

This allows applications reading the file to decode a coarse version quickly before rendering the higher-quality layers.

Verifying Output Quality and Compression

To verify the achieved compression ratio and ensure that the output matches your constraints, inspect the output image metadata:

magick identify -verbose output.jp2

Check the Filesize and Compression properties to confirm the file has achieved your desired target footprint.
