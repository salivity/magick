How to Set JPEG 4:4:4 Chroma Subsampling in ImageMagick

This guide explains how to configure ImageMagick to output JPEG images using 4:4:4 chroma subsampling. By default, JPEG compression downsamples color data (typically to 4:2:0) to reduce file size, which often introduces blur or artifacts around sharp colored edges, graphical user interfaces, and text. Setting the chroma subsampling to 4:4:4 retains all horizontal and vertical color resolution, ensuring maximum image fidelity.

The -sampling-factor Option

In ImageMagick, chroma subsampling for JPEG compression is controlled using the -sampling-factor option. To disable chroma downsampling and force a 4:4:4 ratio, set the sampling factor to 4:4:4 or explicitly define the channel dimensions as 1x1,1x1,1x1.

Basic Command Usage

For ImageMagick version 7, use the magick tool:

magick input.png -sampling-factor 4:4:4 output.jpg

If you are using ImageMagick version 6, use the legacy convert command:

convert input.png -sampling-factor 4:4:4 output.jpg

You can also achieve the exact same 4:4:4 result by explicitly defining the horizontal and vertical frequency factors for the Y, Cb, and Cr channels:

magick input.png -sampling-factor 1x1,1x1,1x1 output.jpg

Combining Subsampling with Quality Settings

The -sampling-factor flag operates independently of the compression quality flag (-quality). When converting graphics or screenshots where color accuracy is critical, combine both options:

magick input.png -sampling-factor 4:4:4 -quality 92 output.jpg

Note: Placing -sampling-factor before the output file name ensures it is applied during the JPEG encoding phase.

How to Verify the Output Subsampling

To confirm that the output JPEG was properly encoded without chroma downsampling, query the image metadata using magick identify:

magick identify -format "%[jpeg:sampling-factor]\n" output.jpg

For a 4:4:4 encoded JPEG, the output will return 1x1,1x1,1x1 (or in some builds, 2x2,2x2,2x2), indicating that the chroma channels (Cb and Cr) match the full resolution of the luma channel (Y).
