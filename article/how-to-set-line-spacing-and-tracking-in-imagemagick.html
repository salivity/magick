How to Set Line Spacing and Tracking in ImageMagick

Controlling text layout in ImageMagick requires adjusting vertical and horizontal distances between characters and lines. This guide explains how to use the -interline-spacing and -kerning settings to configure inter-line spacing (leading) and text tracking (letter spacing) when rendering text using tools like label:, caption:, or -annotate.

Adjusting Inter-Line Spacing

Inter-line spacing controls the vertical distance between consecutive lines of multi-line text. In ImageMagick, this is configured using the -interline-spacing option followed by a pixel value.

  • Positive values add extra space between lines.
  • Negative values reduce the default gap, pulling lines closer together.

Example syntax:

magick -size 500x300 -background white -fill black \
  -font Arial -pointsize 24 \
  -interline-spacing 15 \
  caption:"This is an example of text with increased vertical line spacing." \
  output_interline.png

Adjusting Text Tracking (Kerning)

Tracking refers to the uniform horizontal spacing applied across an entire block of text. In ImageMagick, tracking is controlled using the -kerning setting.

  • Positive values expand the horizontal gap between characters (loose tracking).
  • Negative values tighten the gap between characters (tight tracking).

Example syntax:

magick -size 500x100 -background white -fill black \
  -font Arial -pointsize 28 \
  -kerning 4 \
  label:"EXPANDED TRACKING" \
  output_tracking.png

Combining Line Spacing and Tracking

You can apply both parameters simultaneously to achieve full typographic control over paragraph blocks:

magick -size 600x400 xc:white \
  -font Helvetica -pointsize 20 -fill "#333333" \
  -kerning 2 \
  -interline-spacing 10 \
  -gravity center \
  -annotate +0+0 "Line tracking and inter-line spacing\ncan be applied together\nfor precise typography." \
  output_combined.png

Both -interline-spacing and -kerning must be defined before the text-rendering operation (caption:, label:, or -annotate) in your command sequence for the settings to take effect.
