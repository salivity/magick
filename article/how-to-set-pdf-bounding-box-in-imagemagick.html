How to Set PDF Bounding Box in ImageMagick

When rendering or converting PDF files using ImageMagick, the software relies on Ghostscript to interpret the document dimensions defined by various PDF page boundaries. By default, ImageMagick often falls back to the CropBox or MediaBox. However, you can explicitly specify which bounding box—such as CropBox, TrimBox, BleedBox, or ArtBox—to use during rasterization by passing dedicated -define options before reading the input PDF.

Understanding PDF Bounding Boxes

PDF documents can define up to five distinct bounding boxes per page:

  • MediaBox: The physical size of the medium/page (default fallback if others are missing).
  • CropBox: The region displayed on screen or printed by default.
  • BleedBox: The region including the extra margin required for professional printing bleeds.
  • TrimBox: The intended final dimensions of the printed page after trimming.
  • ArtBox: The meaningful content area of the page.

Using -define to Select a Bounding Box

To specify a bounding box, apply the -define option before the input file path in your ImageMagick command.

1. Using the CropBox

To force ImageMagick to use the CropBox:

magick -define pdf:use-cropbox=true input.pdf output.png

2. Using the TrimBox

To render only the trimmed area of a print-ready PDF:

magick -define pdf:use-trimbox=true input.pdf output.png

3. Using the BleedBox

To include printing bleed margins:

magick -define pdf:use-bleedbox=true input.pdf output.png

4. Using the ArtBox

To render according to the content boundaries defined in the ArtBox:

magick -define pdf:use-artbox=true input.pdf output.png

5. Using the MediaBox

To revert to the full physical media dimensions, disable the other boxes (or ensure cropbox is set to false):

magick -define pdf:use-cropbox=false input.pdf output.png

Legacy ImageMagick (v6) Syntax

For ImageMagick version 6, replace magick with convert:

convert -define pdf:use-trimbox=true input.pdf output.png

Important Considerations

  • Placement Matters: The -define flag must precede the input PDF filename. If placed after, ImageMagick will read the PDF using its default settings before the rule is applied.
  • Resolution/Density: When converting vector PDFs to raster formats, pair the bounding box define with the -density flag (placed before the input file) to maintain image clarity.
magick -density 300 -define pdf:use-trimbox=true input.pdf output.png
