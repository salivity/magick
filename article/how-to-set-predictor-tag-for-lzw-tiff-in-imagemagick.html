How to Set Predictor Tag for LZW TIFF in ImageMagick

This article explains how to set the predictor tag for LZW-compressed TIFF files using ImageMagick. By applying a predictor, you can significantly improve the compression efficiency of LZW-compressed continuous-tone TIFF images without losing image data.

Setting the Predictor Flag

To define the TIFF predictor in ImageMagick, use the -define tiff:predictor= setting in conjunction with -compress lzw.

The syntax for ImageMagick v7 is:

magick input.png -compress lzw -define tiff:predictor=2 output.tif

For ImageMagick v6, use the convert command:

convert input.png -compress lzw -define tiff:predictor=2 output.tif

Predictor Tag Values

The TIFF specification supports three main values for the predictor tag:

  • 1 (None): No prediction scheme is used. Pixel values are compressed as-is.
  • 2 (Horizontal Differencing): Calculates the difference between adjacent horizontal pixels before compression. This is the standard setting to maximize LZW compression for standard 8-bit and 16-bit photographic and continuous-tone imagery.
  • 3 (Floating Point): Used specifically for floating-point data to rearrange bytes and calculate differences for better compression.

Why Use a Predictor with LZW?

LZW (Lempel-Ziv-Welch) compression works by finding repeating patterns. In continuous-tone images, adjacent pixels often have similar values, but rarely identical raw byte sequences.

When you set tiff:predictor=2, ImageMagick encodes only the difference from the preceding pixel. This produces long sequences of zeros or small, repeating numbers, allowing the LZW algorithm to achieve substantially smaller file sizes.

Verifying the TIFF Predictor

To verify that the predictor tag was correctly written to the output file, use ImageMagick's identify tool:

magick identify -verbose output.tif | grep "tiff:predictor"

Alternatively, if you have libtiff utilities installed, you can inspect the file with tiffinfo:

tiffinfo output.tif

Look for the Predictor: horizontal differencing (2) line in the output metadata to confirm the tag is active.
