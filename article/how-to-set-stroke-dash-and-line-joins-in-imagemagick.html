How to Set Stroke Dash and Line Joins in ImageMagick

This guide explains how to customize line appearances in ImageMagick by configuring stroke dash patterns and line join styles. Using ImageMagick’s vector drawing capabilities, you can control the spacing, length, and starting offset of dashed lines, as well as define how corners and intersections connect using miter, round, or bevel joins.

Setting Stroke Dash Patterns

ImageMagick controls dash patterns using two primary properties: the dash array and the dash offset. These can be defined either via command-line options or directly inside the -draw primitive string using Magick Vector Graphics (MVG) syntax.

1. The Dash Array

The dash array defines the lengths of alternating painted segments (dashes) and unpainted segments (gaps).

  • Command-line syntax: -strokedasharray <dash_length>,<gap_length>,...
  • Draw primitive syntax: stroke-dasharray <dash_length> <gap_length> ...

For example, a pattern of 10 pixels on and 5 pixels off:

magick -size 400x200 xc:white -stroke black -strokewidth 4 \
  -strokedasharray 10,5 -draw "line 20,100 380,100" dashed_line.png

You can define complex patterns with multiple values (e.g., 15,5,5,5 creates a dash-dot pattern).

2. The Dash Offset

The dash offset determines the starting phase of the pattern along the stroke path.

  • Command-line syntax: -strokedashoffset <value>
  • Draw primitive syntax: stroke-dashoffset <value>
magick -size 400x200 xc:white -stroke black -strokewidth 4 \
  -strokedasharray 10,5 -strokedashoffset 5 \
  -draw "line 20,100 380,100" offset_line.png

Configuring Line Join Styles

Line joins determine how the corner looks where two stroke segments meet at an angle. ImageMagick supports three standard line join styles:

  • miter: Extends the outer edges of the lines until they meet at a sharp point (default).
  • round: Renders a rounded corner with a radius equal to half the stroke width.
  • bevel: Chops off the corner with a straight diagonal segment across the junction.

Using the Line Join Option

To set the join style, use -strokelinejoin or the MVG stroke-linejoin command:

# Round Join
magick -size 300x300 xc:white -fill none -stroke blue -strokewidth 12 \
  -strokelinejoin round -draw "polyline 50,250 150,50 250,250" round_join.png

# Bevel Join
magick -size 300x300 xc:white -fill none -stroke red -strokewidth 12 \
  -strokelinejoin bevel -draw "polyline 50,250 150,50 250,250" bevel_join.png

# Miter Join
magick -size 300x300 xc:white -fill none -stroke green -strokewidth 12 \
  -strokelinejoin miter -draw "polyline 50,250 150,50 250,250" miter_join.png

Controlling Miter Limits

When using miter, sharp angles can produce excessively long spikes. Use -strokemiterlimit (or stroke-miterlimit in -draw) to specify the ratio limit where a miter join automatically converts to a bevel join:

magick -size 300x300 xc:white -fill none -stroke black -strokewidth 10 \
  -strokelinejoin miter -strokemiterlimit 2 \
  -draw "polyline 50,250 150,50 250,250" miter_limit.png

Combined Example

You can combine dash arrays, dash offsets, and line joins within a single command to create styled shapes:

magick -size 400x400 xc:white -fill none -stroke darkred -strokewidth 6 \
  -strokelinejoin round \
  -strokedasharray 12,6 \
  -strokedashoffset 3 \
  -draw "polygon 200,40 360,340 40,340" styled_triangle.png
