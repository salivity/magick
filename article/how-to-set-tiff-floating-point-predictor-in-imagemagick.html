How to Set TIFF Floating-Point Predictor in ImageMagick

This guide explains how to enable the floating-point predictor tag for Zip-compressed TIFF images using ImageMagick. You will learn the exact command-line syntax required to activate TIFF Predictor 3, how to ensure the image data is formatted as floating-point, and how to verify that the tag was successfully written to the output file's metadata.

The Floating-Point Predictor

The TIFF specification defines the Predictor tag (Tag 317) to improve lossless compression ratios for LZW and Deflate/Zip algorithms. While Predictor 2 applies horizontal differencing for integer data, Predictor 3 is specifically designed for IEEE floating-point values. It reorganizes the bytes of floating-point numbers across pixels to group high-order exponent bytes together, significantly reducing file sizes for HDR, scientific, and 3D rendering data.

ImageMagick Command Syntax

To set the floating-point predictor, you must configure Zip compression, specify the predictor value using a -define flag, and ensure the pixel data is encoded as floating-point numbers.

For ImageMagick v7, use the following syntax:

magick input.exr -define quantum:format=floating-point -depth 32 -compress zip -define tiff:predictor=3 output.tif

For ImageMagick v6, replace magick with convert:

convert input.exr -define quantum:format=floating-point -depth 32 -compress zip -define tiff:predictor=3 output.tif

Parameter Breakdown

  • -compress zip: Applies the Deflate/Zip lossless compression algorithm to the TIFF image strips or tiles.
  • -define tiff:predictor=3: Sets TIFF Tag 317 to 3 (Floating-point predictor).
  • -define quantum:format=floating-point: Forces ImageMagick to write pixel channels as IEEE floating-point values rather than standard integers.
  • -depth 32 (or -depth 16): Defines the bit depth. Predictor 3 requires either half-precision (16-bit) or single-precision (32-bit) floating-point data.

Verifying the Predictor Tag

To verify that the tag has been properly written to the file header, use the tiffinfo utility provided by libtiff:

tiffinfo output.tif

Look for the following entries in the output:

Sample Format: IEEE floating point
Compression Scheme: Deflate
Predictor: floating point predictor (3)

Alternatively, you can inspect the file using ImageMagick itself:

magick identify -verbose output.tif | grep "tiff:predictor"
