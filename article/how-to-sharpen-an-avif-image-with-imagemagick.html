How to Sharpen an AVIF Image With ImageMagick?

Sharpening an AVIF file using ImageMagick requires invoking the CLI utility with dedicated sharpening operators like -sharpen or -unsharp, while ensuring your ImageMagick build includes libheif support for reading and writing AVIF containers. This guide covers the essential commands, parameter tuning for radius and sigma, preserving output quality, and batch-processing entire directories of AVIF files.

Verifying AVIF Support in ImageMagick

Before attempting to process AVIF files, confirm that your ImageMagick installation includes the appropriate delegate library:

magick -version

Look for heic or heif in the Delegates (built-in) list. Alternatively, inspect format support directly:

magick identify -list format | grep -i avif

If AVIF appears with read and write permissions (rw+ or rw-), your installation is ready.

Basic Sharpening Using the -sharpen Operator

The simplest way to enhance edge contrast is the standard -sharpen operator, which accepts a radius and sigma value formatted as {radius}x{sigma}:

magick input.avif -sharpen 0x1.0 output.avif

A radius of 0 directs ImageMagick to automatically calculate a suitable neighborhood size based on the sigma value. For general adjustments:

  • Subtle sharpness: 0x0.5 to 0x0.8
  • Noticeable boost: 0x1.0 to 0x1.5
  • Aggressive clarity: 0x2.0 (risks adding halos around high-contrast edges)

Advanced Sharpening Using the -unsharp Operator

For greater control over artifacts, use an unsharp mask via the -unsharp operator. This option allows you to set a sharpening threshold to avoid exaggerating background noise or sensor grain:

magick input.avif -unsharp 0x1.0+1.0+0.02 output.avif

The parameter format is {radius}x{sigma}+{amount}+{threshold}:

  • Radius: Neighborhood size in pixels (leave as 0 for auto-selection).
  • Sigma: Blur standard deviation; governs the width of the edge enhancement (typically 0.5 to 1.5).
  • Amount: The percentage multiplier applied to the difference between the blurred version and the original (a value between 0.5 and 2.0 is standard).
  • Threshold: Minimum brightness difference required before a pixel is sharpened (ranging from 0.01 to 0.05), preventing smooth gradients from becoming noisy.

Maintaining Compression Quality and Speed

Sharpening adds micro-contrast, which naturally increases file size during AVIF encoding. You can control compression parameters using the -quality and -define flags:

magick input.avif -unsharp 0x1.0+1.0+0.02 -quality 65 -define heic:speed=4 output.avif
  • -quality 65: Maintains a solid balance between visual fidelity and small file footprints for AVIF.
  • -define heic:speed=4: Sets encoder CPU effort (values range from 0 for slowest and smallest to 9 for fastest and largest; 4 or 6 offers a fast middle ground).

Batch Processing Multiple AVIF Files

To process multiple AVIF files within a single folder, run a shell loop.

On Linux or macOS (Bash/Zsh):

mkdir -p sharpened
for file in *.avif; do
  magick "$file" -unsharp 0x1.0+1.0+0.02 -quality 65 "sharpened/$file"
done

On Windows (PowerShell):

New-Item -ItemType Directory -Force -Path sharpened
Get-ChildItem -Filter *.avif | ForEach-Object {
    magick $_.FullName -unsharp 0x1.0+1.0+0.02 -quality 65 "sharpened/$($_.Name)"
}
