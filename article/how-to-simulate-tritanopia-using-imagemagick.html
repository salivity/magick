How to Simulate Tritanopia Using ImageMagick

Simulating tritanopia (blue-yellow color blindness) in digital images can be achieved efficiently using ImageMagick's -color-matrix operator. This article outlines the exact color matrix coefficients required to model tritanopia and provides the command-line syntax needed to process both single images and batch files.

The Tritanopia Color Matrix

Tritanopia is a condition where the retina lacks functional blue-sensitive cone cells (S-cones). To simulate this effect digitally, the image's original RGB values must be transformed into a restricted color space where blue hues shift toward greens or reds, and yellows desaturate.

A widely used 3x3 transformation matrix for simulating tritanopia is:

[ 0.95000   0.05000   0.00000 ]
[ 0.00000   0.43333   0.56667 ]
[ 0.00000   0.47500   0.52500 ]

Each row dictates how much of the original Red, Green, and Blue channels contribute to the output Red, Green, and Blue channels respectively.

ImageMagick Command

To apply this matrix in ImageMagick (version 7+), use the magick command paired with the -color-matrix parameter:

magick input.jpg -color-matrix "0.95 0.05 0 0 0.43333 0.56667 0 0.475 0.525" output_tritanopia.jpg

If you are using ImageMagick version 6, replace magick with convert:

convert input.jpg -color-matrix "0.95 0.05 0 0 0.43333 0.56667 0 0.475 0.525" output_tritanopia.jpg

Color Space Considerations

For mathematically accurate simulation, transformations should ideally occur in a linear color space rather than gamma-corrected sRGB:

magick input.jpg -colorspace RGB -color-matrix "0.95 0.05 0 0 0.43333 0.56667 0 0.475 0.525" -colorspace sRGB output_tritanopia.jpg

Batch Processing Images

To simulate tritanopia across an entire directory of images on Unix-like systems (Linux, macOS):

for file in *.jpg; do
  magick "$file" -colorspace RGB -color-matrix "0.95 0.05 0 0 0.43333 0.56667 0 0.475 0.525" -colorspace sRGB "tritanopia_${file}"
done

On Windows (Command Prompt):

for %f in (*.jpg) do magick "%f" -colorspace RGB -color-matrix "0.95 0.05 0 0 0.43333 0.56667 0 0.475 0.525" -colorspace sRGB "tritanopia_%f"
