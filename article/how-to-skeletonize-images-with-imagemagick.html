How to Skeletonize Images with ImageMagick

Skeletonization is a morphological technique used to reduce binary shapes to their center-line structural representations, producing a one-pixel-thick wireframe. This guide explains how to extract the morphological skeleton of a binary graphic using ImageMagick's command-line morphology tools, detailing the specific commands and parameters required for both ImageMagick v7 and v6.

The ImageMagick Skeletonization Command

To skeletonize a binary image using ImageMagick v7, execute the following command:

magick input.png -morphology Thinning:-1 Skeleton output.png

For ImageMagick v6, replace magick with convert:

convert input.png -morphology Thinning:-1 Skeleton output.png

Command Breakdown

  • input.png: The source file. For best results, this should be a clean binary image where the foreground shape is white (value 1) and the background is black (value 0).
  • -morphology: Invokes ImageMagick's mathematical morphology operator.
  • Thinning: The morphological method applied. Thinning iteratively erodes foreground pixels that match specific pattern kernels without breaking the connectivity of the shape.
  • :-1: Specifies the iteration limit. Using -1 forces the thinning process to repeat until convergence (i.e., until no further pixels can be removed).
  • Skeleton: The predefined kernel matrix designed specifically to preserve line topology while stripping away outer layers.
  • output.png: The resulting image containing the one-pixel-wide skeleton.

Handling Non-Binary Inputs

If your input graphic is grayscale or has inverted colors, apply preprocessing steps directly in the command pipeline:

Thresholding Grayscale Images

Ensure the graphic is strictly black and white before skeletonizing:

magick input.png -threshold 50% -morphology Thinning:-1 Skeleton output.png

Inverting Shapes (Black on White)

Morphology thinning expects a white shape on a black background. If your source image has a black shape on a white background, invert it using -negate:

magick input.png -threshold 50% -negate -morphology Thinning:-1 Skeleton -negate output.png
