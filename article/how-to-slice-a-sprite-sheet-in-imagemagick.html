How to Slice a Sprite Sheet in ImageMagick

This guide demonstrates how to quickly slice a uniform sprite sheet into individual animation frames using ImageMagick. By applying the -crop geometry option alongside the +repage operator, you can automatically divide an evenly spaced grid of sprites into sequentially numbered image files directly from the command line.

Basic Syntax

To slice an image into uniform tiles, specify the width and height of a single frame using the -crop operator without providing offset coordinates:

ImageMagick v7:

magick input_sheet.png -crop WIDTHxHEIGHT +repage frame_%02d.png

ImageMagick v6 (Legacy):

convert input_sheet.png -crop WIDTHxHEIGHT +repage frame_%02d.png

Parameter Breakdown

  • input_sheet.png: The source sprite sheet image containing the animation frames.
  • -crop WIDTHxHEIGHT: The exact pixel dimensions of a single frame (for example, 64x64 or 32x48). ImageMagick automatically traverses the image from left to right, top to bottom, cutting tiles of this size across the entire sheet.
  • +repage: Crucial for resetting the virtual canvas offsets. Without this, individual frame files may retain positional metadata from the original sheet, causing alignment issues in game engines or editors.
  • frame_%02d.png: The output naming format using C-style printf notation. %02d creates zero-padded two-digit integers (frame_00.png, frame_01.png), while %03d creates three-digit integers (frame_000.png).

Example

To slice a 256x64 pixel sprite sheet containing four 64x64 frames into separate PNG files:

magick character_run.png -crop 64x64 +repage run_frame_%02d.png

This generates run_frame_00.png, run_frame_01.png, run_frame_02.png, and run_frame_03.png.
