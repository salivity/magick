How to Solarize a WebP Image with ImageMagick?

Applying a solarization effect to a WebP image using ImageMagick can be accomplished in a single command-line step using the -solarize operator. This guide covers how the solarization process works, the syntax required for both ImageMagick v7 and v6, how to fine-tune threshold values, and how to preserve or adjust WebP compression settings during processing.

Understanding ImageMagick Solarization

In photography, solarization (the Sabattier effect) occurs when an image recorded on a photographic plate is briefly exposed to light during development, partially inverting the tones.

In ImageMagick, the -solarize operator mimics this effect digitally. It compares each pixel channel's intensity against a specified threshold. Any pixel value that exceeds the threshold is inverted, while pixels falling below the threshold remain unaffected. This creates high-contrast, surreal visual results with distinctive edge halos.

Basic Syntax and Commands

ImageMagick natively supports WebP input and output as long as the underlying libwebp delegate library is installed on your system.

ImageMagick Version 7 (Modern)

In ImageMagick v7, the primary tool executable is magick:

magick input.webp -solarize 50% output.webp

ImageMagick Version 6 (Legacy)

If your environment uses ImageMagick v6, use the convert binary:

convert input.webp -solarize 50% output.webp

Selecting the Threshold Value

The parameter passed to -solarize determines the cutoff point for tone inversion:

  • Percentage Values: Specifying a percentage (e.g., -solarize 60%) is the most predictable method. A threshold of 50% inverts all tones brighter than mid-gray. Lowering the value to 20% inverts nearly the entire image, while a high threshold like 80% inverts only the brightest highlights.
  • Absolute Values: If you pass a raw integer (e.g., -solarize 32768), ImageMagick evaluates it against the build's quantum depth (typically Q16, where maximum intensity is 65,535). Using percentages avoids dependency on specific quantum depths.

Maintaining WebP Output Quality

When rewriting WebP files, ImageMagick applies default compression settings unless explicitly told otherwise. You can specify quality or lossless compression alongside the solarization effect.

Lossy WebP with Defined Quality

Control the visual fidelity and file size by specifying the -quality flag:

magick input.webp -solarize 65% -quality 85 output.webp

Lossless WebP Output

To retain maximum pixel integrity without compression artifacts, define the WebP lossless option:

magick input.webp -solarize 50% -define webp:lossless=true output.webp

Batch Processing Multiple WebP Files

To apply solarization across multiple WebP images in a single directory, you can utilize the mogrify command (which overwrites files in place) or shell loops.

To safely process files to a separate output directory:

mkdir -p solarized_output
for file in *.webp; do
  magick "$file" -solarize 50% -quality 85 "solarized_output/$file"
done
