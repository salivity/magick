How to Solarize an AVIF Image Using ImageMagick?

Solarizing an image mimics a classic darkroom phenomenon—also known as the Sabattier effect—where exposed photo paper is briefly re-exposed to light during development, partially inverting the tones and creating distinctive glowing halos along edges. ImageMagick enables you to apply this surreal, high-contrast effect to modern AVIF (AV1 Image File) files directly from the command line using the -solarize operator. This guide details the exact syntax needed to process AVIF images, explains how the threshold parameter alters your output, and covers essential settings to maintain image quality.

Prerequisites and AVIF Support

Before processing AVIF files, ensure your ImageMagick build has delegate support for the AVIF format (typically provided via libheif). You can verify your configuration by executing:

magick -version

Look for heic or avif within the Delegates list. In ImageMagick version 7, commands use the magick binary, whereas ImageMagick version 6 uses convert.

Basic Command Syntax

The core operator for this effect is -solarize <threshold>. The threshold determines the cutoff point: any pixel with an intensity above the threshold value is inverted, while darker pixels remain unchanged. The threshold can be defined as an absolute value or, more commonly, as a percentage.

To solarize an AVIF image and save the result back to AVIF:

magick input.avif -solarize 50% output.avif

In ImageMagick 6, the equivalent command is:

convert input.avif -solarize 50% output.avif

How the Threshold Percentage Works

Adjusting the percentage changes how much of the dynamic range undergoes tone inversion:

  • High Threshold (e.g., 70% to 90%): Only the brightest highlights are inverted, leaving midtones and shadows natural while creating subtle edge outlines around bright areas.
  • Mid Threshold (e.g., 50%): Half of the tonal range is flipped, producing the classic Sabattier darkroom look with prominent border effects and pronounced contrast.
  • Low Threshold (e.g., 10% to 30%): Nearly the entire image is inverted, approaching a negative image with only the deepest shadows retaining their original luminance values.

For example, to produce a subtle solarization effect focused only on bright highlights:

magick input.avif -solarize 75% output_subtle.avif

Preserving Color and Quality

Because AVIF employs modern, lossy compression by default, applying visual modifications and re-encoding can introduce compression artifacts unless compression settings are explicitly managed.

Adjusting Quality

Use the -quality flag to control AVIF compression fidelity. A range between 60 and 80 generally balances high fidelity with efficient file size:

magick input.avif -solarize 60% -quality 75 output.avif

Solarizing Luminance Only

By default, -solarize applies the threshold across each color channel independently, which often results in dramatic, unexpected shifts in hue. If your goal is to invert luminance while preserving original color relationships, convert the color space to HSL or Lab, isolate the lightness channel, apply the effect, and reconstruct the image:

magick input.avif -colorspace HSL -channel Lightness -solarize 50% +channel -colorspace sRGB output_luminance.avif

Batch Processing Multiple AVIF Files

To apply the same solarization setting across an entire directory of AVIF files, ImageMagick provides the mogrify tool. To overwrite all AVIF files in a folder:

magick mogrify -solarize 50% *.avif

To avoid overwriting original files, specify an alternate destination directory using the -path option:

mkdir solarized_results
magick mogrify -path ./solarized_results -solarize 50% *.avif
