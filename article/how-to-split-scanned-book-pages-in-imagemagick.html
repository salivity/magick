How to Split Scanned Book Pages in ImageMagick

Digitizing books often results in double-page spreads where two facing pages are captured within a single image file. Splitting these spreads into individual, sequential pages is essential for standard PDF creation and e-readers. ImageMagick allows you to automate this process via the command line by dividing the image directly down the center and outputting the halves in correct reading order.

Basic Command for a Single Spread

To cut a two-page scan vertically into two equal halves (left page first, right page second), use the following ImageMagick command:

magick input_spread.jpg -crop 50%x100% +repage page_%03d.jpg

(Note: If you are using ImageMagick v6 or earlier, replace magick with convert.)

Explanation of Parameters

  • input_spread.jpg: The source image containing the two-page scan.
  • -crop 50%x100%: Instructs ImageMagick to divide the image horizontally into two 50% wide sections while maintaining 100% of the original height.
  • +repage: Resets the canvas coordinates (virtual canvas metadata) so each generated image behaves as a standalone file.
  • page_%03d.jpg: The output naming template. The %03d format specifier generates sequential, zero-padded numbering (e.g., page_000.jpg for the left page and page_001.jpg for the right page).

Handling Right-to-Left (RTL) Book Layouts

For right-to-left reading materials (such as manga or Arabic/Hebrew texts), the right side of the spread is read before the left side. You can reverse the resulting layer order using the -reverse operator before saving:

magick rtl_spread.jpg -crop 50%x100% +repage -reverse page_%03d.jpg

This ensures the right-hand page is output as the first sequential image and the left-hand page as the second.

Batch Processing Multiple Spreads

To process an entire folder of scanned spreads while maintaining chronological sequence, run a simple loop in your terminal:

Linux / macOS (Bash/Zsh):

counter=1
for file in *.jpg; do
  magick "$file" -crop 50%x100% +repage temp_%d.jpg
  mv temp_0.jpg "page_$(printf "%04d" $counter).jpg"
  counter=$((counter + 1))
  mv temp_1.jpg "page_$(printf "%04d" $counter).jpg"
  counter=$((counter + 1))
done

Windows (Command Prompt):

setlocal enabledelayedexpansion
set /a counter=1
for %%f in (*.jpg) do (
    magick "%%f" -crop 50%x100% +repage temp_%%d.jpg
    set "formatted=!counter!"
    if !counter! lss 10 set "formatted=0!counter!"
    if !counter! lss 100 set "formatted=0!formatted!"
    ren temp_0.jpg "page_!formatted!.jpg"
    set /a counter+=1
    set "formatted=!counter!"
    if !counter! lss 10 set "formatted=0!counter!"
    if !counter! lss 100 set "formatted=0!formatted!"
    ren temp_1.jpg "page_!formatted!.jpg"
    set /a counter+=1
)
