How to Threshold a PNG Image in ImageMagick?

Thresholding a PNG image using ImageMagick converts grayscale or color pixels into pure black and white based on defined intensity values, making it an essential technique for document scanning, OCR preprocessing, and graphic simplification. This guide explains how to apply basic global thresholds, percentage-based cutoffs, and adaptive local thresholding commands directly from your terminal using ImageMagick's magick (ImageMagick 7) and convert (ImageMagick 6) utilities.

Understanding ImageMagick Thresholding

Thresholding evaluates each pixel's brightness against a target value. Pixels above the threshold value turn white, while pixels at or below it turn black. Because PNG images frequently contain color channels and alpha transparency, converting the image to grayscale and handling alpha layers ensures clean binary output.

Basic Global Thresholding

The simplest way to threshold an image is using a fixed percentage value with the -threshold operator.

For ImageMagick 7:

magick input.png -colorspace gray -threshold 50% output.png

For ImageMagick 6:

convert input.png -colorspace gray -threshold 50% output.png

The -colorspace gray parameter strips out color data first so the threshold operator works strictly on luminance. The 50% argument sets the midpoint: pixels lighter than 50% gray turn pure white, while darker pixels become pure black.

Adjusting the Threshold Value

You can fine-tune the sensitivity by adjusting the percentage:

  • Higher percentage (e.g., -threshold 70%): More pixels fall below the cutoff, producing a darker output image with thicker dark lines.
  • Lower percentage (e.g., -threshold 30%): Fewer pixels fall below the cutoff, producing a brighter image with thinner lines.

You can also provide absolute raw integer values corresponding to your installation's Quantum Depth (such as 0 to 65535 for Q16), but using percentages is universally portable across all builds.

Preserving or Stripping Transparency

PNG files often contain an alpha channel that can interfere with binarization:

  • Flatten against white: If your input PNG has transparent areas you want treated as white background:
magick input.png -background white -flatten -colorspace gray -threshold 50% output.png
  • Remove alpha entirely:
magick input.png -alpha off -threshold 50% output.png

Adaptive Thresholding for Uneven Lighting

Standard global thresholding often fails when an image has shadows or uneven illumination, such as a photograph of a document. In these cases, adaptive thresholding calculates a dynamic threshold for each pixel based on the surrounding neighborhood.

Use the -lat (local adaptive threshold) operator:

magick input.png -negate -lat 25x25+10% -negate output.png

The 25x25 parameter defines the pixel window size around each target pixel, and +10% defines the offset from the local average. The -negate commands are often paired with -lat because the operation by default detects dark features on light backgrounds in inverse polarities.

Common Command Recipes

  • High-contrast document cleanup:
magick input.png -colorspace gray -contrast-stretch 1%x1% -threshold 60% output.png
  • Two-color monochrome palette output:
magick input.png -colorspace gray -threshold 50% -type bilevel output.png
