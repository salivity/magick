How to Threshold an AVIF Image Using ImageMagick?

Thresholding an AVIF image with ImageMagick converts color or grayscale pixel data into high-contrast black-and-white values based on specific intensity limits. This guide covers how to verify AVIF support in your ImageMagick installation, execute standard and adaptive thresholding commands, fine-tune percentage cutoffs, and export the resulting binary image directly back into AVIF or alternative formats.

Verifying AVIF Support in ImageMagick

Before attempting to process AVIF files, ensure that your ImageMagick installation was compiled with libheif support. Run the following command in your terminal:

magick identify -list format | grep -i avif

If the output lists AVIF with read and write permissions (indicated by rw- or r--), ImageMagick is ready to handle AVIF files natively. On older versions using ImageMagick 6, replace magick identify with identify.

Applying Basic Thresholding

Simple thresholding evaluates each pixel against a fixed intensity cut-off. Any pixel brighter than the threshold becomes pure white, while any pixel darker becomes pure black.

To convert an AVIF image to grayscale and apply a 50% threshold:

magick input.avif -colorspace Gray -threshold 50% output.avif

You can adjust the threshold percentage to fit your image source:

  • Lower values (such as 30%) preserve fewer white pixels and convert more midtones to black.
  • Higher values (such as 70%) convert more midtones to white.

Using Adaptive Thresholding for Uneven Lighting

Standard thresholding often fails on images with uneven illumination, shadows, or gradients. Adaptive thresholding calculates a local threshold for each pixel based on a surrounding pixel window.

Use the -lat (local adaptive threshold) operator:

magick input.avif -colorspace Gray -lat 25x25+10% output.avif

The geometry parameter 25x25+10% consists of:

  • 25x25: The width and height of the neighboring pixel window used to compute the local average.
  • +10%: The offset percentage below the local average that determines the threshold boundary.

Fine-Tuning with Two-Sided Thresholds

If you need to isolate a specific band of luminosity rather than a hard single cut-off, combine the -black-threshold and -white-threshold operators:

magick input.avif -colorspace Gray -black-threshold 20% -white-threshold 80% output.avif

This command forces pixels darker than 20% to absolute black and pixels lighter than 80% to absolute white, while preserving intermediate tones between the two limits. To convert the result strictly to binary values afterward, follow it with a standard -threshold 50% pass.

Exporting and Optimizing Binary Output

AVIF is an advanced lossy and lossless image container based on the AV1 video codec. When saving thresholded binary images back to AVIF, specify lossless compression to prevent compression artifacts along sharp black-and-white edges:

magick input.avif -colorspace Gray -threshold 50% -define heic:lossless=true output.avif

If target compatibility requires standard formats for monochrome work, ImageMagick can also output directly to PNG, TIFF, or WebP using the exact same thresholding pipeline:

magick input.avif -colorspace Gray -threshold 50% -monochrome output.png
