How to Trim an AVIF Image Using ImageMagick?

Trimming an AVIF image with ImageMagick allows you to automatically remove solid backgrounds, borders, or excess whitespace from modern high-compression image files directly from the command line. This guide walks through the required ImageMagick commands, syntax adjustments for fuzzy background colors, and how to preserve AVIF canvas geometry and quality during processing.

Prerequisites and AVIF Support

Before processing AVIF files, ensure your ImageMagick build includes AVIF delegate support (typically libheif or libavif).

Run the following command in your terminal:

magick -version

Look for heic or avif in the Delegates list. If AVIF support is missing, update ImageMagick or install the libheif delegate via your system's package manager.

Basic Automatic Trim

The -trim operator removes edges that are the exact same color as the outer corners of the image.

To perform a basic trim on an AVIF file:

magick input.avif -trim +repage output.avif

Why Use +repage?

When ImageMagick trims an image, it retains the original canvas dimensions and offsets in the image metadata by default. The +repage operator completely removes this virtual canvas, resetting the new image dimensions to match the trimmed bounds and preventing display issues in web browsers.

Handling Inexact Backgrounds with Fuzz

If the background is not completely uniform—such as an image with subtle gradients, compression artifacts, or slight noise—a strict trim will not remove all excess borders. Use the -fuzz option to define a tolerance threshold.

magick input.avif -fuzz 5% -trim +repage output.avif

A fuzz value between 1% and 10% usually removes compression noise without clipping into the main content.

Controlling Output Quality and Compression

Re-encoding into AVIF can alter the file's visual fidelity and compression level if not specified. Use -quality to control output compression:

magick input.avif -fuzz 5% -trim +repage -quality 80 output.avif

A quality setting between 75 and 85 typically provides an optimal balance between low file size and visual clarity.

Batch Trimming Multiple AVIF Files

To trim all AVIF files in a single directory, use ImageMagick's mogrify command:

magick mogrify -fuzz 5% -trim +repage -path ./trimmed_output *.avif

This command processes every .avif file in the current directory and saves the trimmed versions into the trimmed_output folder without overwriting the originals.
