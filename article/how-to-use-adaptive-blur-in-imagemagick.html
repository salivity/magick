How to Use Adaptive Blur in ImageMagick

This guide explains how to apply an adaptive-blur filter in ImageMagick to reduce image noise while keeping sharp edges intact. By evaluating the local variance in an image, the adaptive-blur operation applies stronger smoothing to flat, uniform regions and decreases blur intensity near distinct edges. Below, you will find the command-line syntax, parameter explanations, and practical examples for effective edge-preserving blurring.

Understanding the -adaptive-blur Operator

Standard Gaussian blur applies an even smoothing effect across an entire image, which often softens sharp edges and fine details. The -adaptive-blur operator solves this by calculating the local edge variance for each pixel's neighborhood.

  • High variance (Edges): The blur strength decreases, preserving lines, borders, and fine transitions.
  • Low variance (Flat areas): The blur strength increases, smoothing out noise, gradients, or compression artifacts.

Command Syntax and Parameters

The basic syntax for applying an adaptive blur is:

magick input.jpg -adaptive-blur {radius}x{sigma} output.jpg

(Note: If you are using ImageMagick version 6, replace magick with convert.)

Parameter Definitions

  • Radius ({radius}): The size of the pixel neighborhood to evaluate. Setting this to 0 allows ImageMagick to automatically calculate the optimal radius based on the sigma value.
  • Sigma ({sigma}): The standard deviation of the Gaussian operator, measured in pixels. It controls the actual strength of the blur. A higher sigma results in more noticeable smoothing in low-variance areas.

Practical Examples

1. Subtle Denoising

To lightly denoise flat surfaces while keeping text or borders crisp, use a low sigma value:

magick input.png -adaptive-blur 0x1 output.png

2. Moderate Artifact Smoothing

For photographs with noticeable compression noise or grain:

magick photo.jpg -adaptive-blur 0x2.5 smoothed_photo.jpg

3. Explicit Radius Definition

While letting ImageMagick calculate the radius automatically (0x{sigma}) is recommended, you can specify an exact pixel radius if you need strict computational bounds:

magick input.png -adaptive-blur 5x2 output.png

This restricts the neighborhood calculation strictly within a 5-pixel radius while applying a sigma of 2.
