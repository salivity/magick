How to Use Conditionals in ImageMagick FX

This article explains how to write and apply conditional expressions within ImageMagick using the -fx special effects operator. You will learn the core syntax of ternary operators, available logical and comparison operators, and practical examples showing how to manipulate pixels dynamically based on color values, coordinates, and channel thresholds.

Basic Syntax

ImageMagick's -fx operator uses standard ternary conditional syntax (similar to C, JavaScript, or C++):

condition ? expression_if_true : expression_if_false

If the condition evaluates to any non-zero value (true), the expression returns the first value; if it evaluates to zero (false), it returns the second value.

In a command-line interface, the entire expression must be enclosed in quotes:

magick input.png -fx "condition ? true_val : false_val" output.png

(Note: In ImageMagick version 6, replace magick with convert.)

Comparison and Logical Operators

Inside an -fx expression, you can use the following comparison operators:

  • Equal to: == or =
  • Not equal to: !=
  • Less than: <
  • Less than or equal to: <=
  • Greater than: >
  • Greater than or equal to: >=

You can combine multiple criteria using logical operators:

  • Logical AND: &&
  • Logical OR: ||
  • Logical NOT: !

Common Variables

  • u: The current pixel value of the first image in the sequence (normalized between 0.0 and 1.0).
  • u.r, u.g, u.b, u.a: Red, green, blue, and alpha channel values of image u.
  • i, j: The current pixel's X and Y coordinates.
  • w, h: Image width and height.

Practical Examples

1. Simple Thresholding

Set any pixel with a luminance greater than 50% (0.5) to white (1.0), and all other pixels to black (0.0):

magick input.png -fx "u > 0.5 ? 1.0 : 0.0" threshold.png

2. Selective Channel Manipulation

Check if the red channel is the dominant color. If true, keep the pixel red; otherwise, convert it to grayscale:

magick input.png -fx "(u.r > u.g && u.r > u.b) ? u : (u.r + u.g + u.b) / 3" red_isolate.png

3. Coordinate-Based Masking

Create a split effect where the left half of the image retains its original value and the right half is inverted:

magick input.png -fx "i < (w / 2) ? u : (1.0 - u)" split.png

4. Nested Conditionals

You can nest conditions to handle three or more states. This example segments brightness into black, gray, and white:

magick input.png -fx "u < 0.33 ? 0.0 : (u < 0.66 ? 0.5 : 1.0)" posterize.png

Shell Escaping Considerations

  • Windows Command Prompt (cmd): Use double quotes ("u > 0.5 ? 1 : 0").
  • Linux/macOS Bash: Use single quotes ('u > 0.5 ? 1 : 0') or double quotes to prevent the shell from interpreting characters like <, >, and &.
