How to Use ImageMagick Affinity for Color Matching

The ImageMagick -affinity operator forces an image to adopt the exact color palette of an external reference image. By extracting the unique colors from a reference file and mapping each pixel of the target image to the nearest equivalent in that palette, -affinity enables precise color quantization, retro-style palletization, and visual consistency across different graphics.

How the -affinity Operator Works

When you supply an external file to the -affinity operator, ImageMagick performs a multi-step process to remap colors:

  1. Palette Extraction: ImageMagick reads the external reference file and generates a color map consisting exclusively of the unique colors present in that file. If the reference file is a dedicated palette strip or an indexed image, only those specific values are registered.
  2. Nearest-Neighbor Mapping: ImageMagick inspects every pixel in the target image. It calculates the color distance (typically using Euclidean distance in the RGB or Lab color space) between the target pixel and every available color in the extracted palette.
  3. Color Replacement: The original pixel value is overwritten with the closest matching color found in the reference palette. No new colors outside of the reference image are introduced into the final output.

Command-Line Syntax

The basic syntax places the target image first, followed by the -affinity operator and the path to the reference palette image:

magick input.png -affinity palette.png output.png

In legacy versions (ImageMagick 6), the command uses convert:

convert input.png -affinity palette.png output.png

Controlling Dithering

By default, ImageMagick may apply dithering when mapping to a constrained palette to simulate gradients and missing shades. You can control this behavior using the -dither option:

  • Disable Dithering: To force flat, solid color replacement (useful for pixel art or strict branding constraints), disable dithering before calling -affinity:
magick input.png -dither None -affinity palette.png output.png
  • Enable Dithering: To preserve smoother transitions across gradients using patterns, specify a dithering algorithm such as Floyd-Steinberg:
magick input.png -dither FloydSteinberg -affinity palette.png output.png

Key Differences Between -affinity and Other Operators

While the -remap operator achieves a similar outcome, -affinity is specifically designed to operate across image sequences or pull palettes from external inputs without necessarily altering the internal colormap attributes of the output file format if not desired. It guarantees that the target image strictly conforms to the color boundaries defined by the external file.
