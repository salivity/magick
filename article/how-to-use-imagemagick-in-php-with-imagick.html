How to Use ImageMagick in PHP with Imagick

This guide explains how to perform common ImageMagick operations directly within PHP using the Imagick extension class. You will learn how to verify your installation, load and manipulate images—including resizing, cropping, and format conversion—and efficiently save or output the final results.

1. Verifying the Extension

Before running operations, ensure the imagick extension is installed and active in your PHP environment.

if (!extension_loaded('imagick')) {
    die('The Imagick extension is not installed or enabled.');
}

2. Initializing and Reading an Image

Create an instance of the Imagick class and pass the file path to load the image into memory.

try {
    $image = new Imagick('path/to/input.jpg');
} catch (ImagickException $e) {
    die('Error loading image: ' . $e->getMessage());
}

3. Resizing and Scaling

To resize an image, use thumbnailImage() for optimized, fast scaling, or resizeImage() for granular filter control. Setting one dimension to 0 maintains the aspect ratio.

// Resize to 300px wide, maintaining proportional height
$image->thumbnailImage(300, 0);

// Alternative using resizeImage with Lanczos filtering
$image->resizeImage(300, 200, Imagick::FILTER_LANCZOS, 1, true);

4. Cropping an Image

Crop an image by defining the target width, target height, and the starting X and Y coordinates.

// Crop a 200x200 square starting from coordinates (50, 50)
$image->cropImage(200, 200, 50, 50);

// Reset canvas page coordinates after cropping
$image->setImagePage(0, 0, 0, 0);

5. Adjusting Quality and Changing Formats

You can convert the image format and control compression quality using setImageFormat() and setImageCompressionQuality().

// Change format to WebP
$image->setImageFormat('webp');

// Set compression quality (1-100)
$image->setImageCompressionQuality(85);

6. Applying Effects

The Imagick class includes hundreds of built-in filters. For example, to apply a blur effect or convert to grayscale:

// Apply a Gaussian blur (radius: 5, sigma: 2)
$image->gaussianBlurImage(5, 2);

// Convert to grayscale
$image->setImageType(Imagick::IMGTYPE_GRAYSCALE);

7. Saving or Outputting the Image

You can save the modified image to disk or output it directly to the browser.

Save to disk:

$image->writeImage('path/to/output.webp');

Stream to browser:

header('Content-Type: image/webp');
echo $image->getImageBlob();

8. Freeing Memory

Large image processing tasks can consume significant memory. Always clear and destroy the object when processing completes.

$image->clear();
$image->destroy();
