How to Use ImageMagick Shave to Crop Margins

This guide explains how to use the ImageMagick -shave operator to quickly and evenly remove borders from images. You will learn the underlying command syntax, how the operator processes pixel and percentage values, and practical examples for trimming uniform margins from all four sides of single files or entire batches of images.

Understanding the Shave Syntax

The -shave operator removes pixels from the edges of an image. Its basic syntax is:

magick input.jpg -shave {Width}x{Height} output.jpg

(Note: In ImageMagick version 6, replace magick with convert.)

The parameters work symmetrically:

  • Width: The number of pixels removed from both the left and right edges (reducing total width by Width * 2).
  • Height: The number of pixels removed from both the top and bottom edges (reducing total height by Height * 2).

Cropping Equal Margins in Pixels

To crop the exact same margin from all four sides, set the Width and Height values to the same number.

For example, to remove 25 pixels from the top, bottom, left, and right:

magick input.png -shave 25x25 output.png

This command reduces the original image's total width by 50 pixels and total height by 50 pixels while keeping the center intact.

Cropping Equal Margins by Percentage

You can also use percentage values instead of fixed pixel dimensions. When using percentages, the calculation is relative to the original dimensions of the image.

To crop 5% from all four sides:

magick input.png -shave 5x5% output.png

This removes 5% from the left and 5% from the right (10% total width reduction), along with 5% from the top and 5% from the bottom (10% total height reduction).

Batch Processing Multiple Images

To apply identical margin crops to multiple images at once, use the mogrify command. Be aware that mogrify overwrites original files unless an output path or format is specified:

magick mogrify -shave 30x30 *.jpg

To save the cropped files into a specific folder without overwriting originals:

magick mogrify -path ./cropped_output -shave 30x30 *.jpg
