How to Use PDF BleedBox in ImageMagick

When converting a print-ready PDF to a raster image format, standard conversion commands often default to the CropBox or MediaBox, cutting off necessary print bleed areas. ImageMagick allows you to target specific boundary boxes defined in the PDF standard—including the BleedBox—by passing specialized internal directives to its PDF delegate, Ghostscript. This guide explains how to define the BleedBox during rasterization to ensure your output images retain full bleed margins.

The pdf:page-box Define

To force ImageMagick to read the BleedBox dimensions, use the -define command with the pdf:page-box key set to bleedbox. This option must appear before the input file in the command line so that ImageMagick applies the setting while interpreting the PDF structure.

Basic Syntax

For ImageMagick version 7:

magick -define pdf:page-box=bleedbox input.pdf output.png

For ImageMagick version 6 (legacy):

convert -define pdf:page-box=bleedbox input.pdf output.png

Recommended Production Command

PDF files are vector-based, meaning they lack a fixed pixel resolution until rendered. When rasterizing for print inspection or proofing, you should explicitly set the rendering density before calling the input file:

magick -density 300 -define pdf:page-box=bleedbox input.pdf -quality 100 output.png
  • -density 300: Renders the PDF at 300 DPI, ensuring the bleed area is rasterized with sufficient detail.
  • -define pdf:page-box=bleedbox: Instructs the Ghostscript delegate to clip the rasterization region to the document's BleedBox.
  • -quality 100: Ensures the output image preserves maximum clarity without aggressive compression artifacts.

Available PDF Boundary Options

The pdf:page-box parameter supports all five standard PDF page boundaries:

  • mediabox: The full physical medium size, typically the largest boundary.
  • cropbox: The default viewing area displayed on screen in PDF viewers.
  • bleedbox: The area including the page content plus the intended bleed margin for cutting.
  • trimbox: The intended final dimensions of the printed page after trimming.
  • artbox: The boundary enclosing the meaningful content/artwork of the page.

If the source PDF does not contain an explicit BleedBox in its metadata, ImageMagick will fall back automatically to the CropBox or MediaBox boundaries.
