How to Use PDF TrimBox in ImageMagick

When importing PDF documents into ImageMagick, the software renders the pages according to specific bounding boxes defined in the PDF standard. By default, ImageMagick often defaults to the CropBox or MediaBox. To target the printable or trimmed dimensions instead, you must explicitly instruct ImageMagick to respect the TrimBox. This guide covers the exact parameter required, how to structure the command, and how the setting affects your output.

The TrimBox Parameter

The parameter that instructs ImageMagick to use the TrimBox is:

-define pdf:use-trimbox=true

Command Syntax and Placement

To ensure ImageMagick applies the setting during the initial decoding stage of the PDF, the -define directive must appear before the input file in your command line.

ImageMagick v7 Example:

magick -define pdf:use-trimbox=true input.pdf output.png

ImageMagick v6 Example:

convert -define pdf:use-trimbox=true input.pdf output.png

Placing the parameter after the input PDF will result in ImageMagick ignoring the instruction, as the underlying Ghostscript delegate reads bounding box configurations during file ingestion.

Why Use the TrimBox?

A PDF can contain up to five different boundaries:

  • MediaBox: The full physical size of the page medium.
  • CropBox: The region displayed or printed by standard viewers.
  • BleedBox: The area including production print bleeds.
  • TrimBox: The intended final dimensions of the finished page after commercial cutting.
  • ArtBox: The extent of the meaningful content on the page.

If your PDF includes printer marks, color bars, or bleed margins, rendering with the default settings will include these unwanted elements. Using -define pdf:use-trimbox=true crops out the bleed and registration marks, exporting only the final intended page dimensions.

Combining with Resolution Settings

Because PDF is a vector format, defining the rendering density (DPI) alongside the TrimBox ensures a sharp raster output:

magick -density 300 -define pdf:use-trimbox=true input.pdf -quality 100 output.png

Setting -density prior to the input file rasterizes the TrimBox area at 300 DPI, yielding high-resolution images cropped strictly to the document's trim boundary.
