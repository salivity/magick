How to Use PegtopLight Composite in ImageMagick

This guide explains how to apply the PegtopLight blend operator using ImageMagick to achieve smooth, natural lighting effects between two images. You will learn the command-line syntax for both ImageMagick v7 and v6, understand how the algorithm affects highlights and midtones, and see how to properly control layer order and intensity for optimal composition results.

Understanding the PegtopLight Operator

PegtopLight is an alternative implementation of the standard Soft Light blending mode. While traditional Soft Light can cause abrupt contrast shifts or clipping near extreme shadows and highlights, PegtopLight uses a continuous mathematical curve that eliminates sharp transitions. It gently lightens or darkens the underlying image based on the luminance of the source image, making it ideal for applying subtle textures, vignette effects, or soft daylight simulations without blowing out detail.

ImageMagick 7 Command-Line Usage

In ImageMagick 7, compositing operations are handled natively by the unified magick utility. The primary syntax requires loading the background image first, followed by the overlay image, defining the -compose operator, and executing the operation with -composite.

magick background.png overlay.png -compose PegtopLight -composite output.png

In this command:

  • background.png acts as the destination image (the layer underneath).
  • overlay.png acts as the source image providing the lighting and tonal modulation.
  • -compose PegtopLight defines the blend algorithm.
  • -composite performs the merge and produces output.png.

Legacy ImageMagick 6 Syntax

If you are working with ImageMagick 6, you can use either the dedicated composite command or the general convert tool. Note that argument ordering differs between these commands.

Using the composite command (the source/overlay is specified first):

composite -compose PegtopLight overlay.png background.png output.png

Using the convert tool (matches the ImageMagick 7 image sequence):

convert background.png overlay.png -compose PegtopLight -composite output.png

Controlling Blend Intensity

Because the PegtopLight operator does not accept a direct numeric blending percentage argument, the intensity of the effect is controlled by the transparency of the overlay image.

To reduce the strength of the PegtopLight effect, modify the alpha channel of the overlay before compositing:

magick background.png \( overlay.png -alpha set -channel A -evaluate multiply 0.5 +channel \) -compose PegtopLight -composite output.png

In this example, -evaluate multiply 0.5 sets the overlay's opacity to 50%, softening the PegtopLight effect and creating a more subtle blend over the background.
