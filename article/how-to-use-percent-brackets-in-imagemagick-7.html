How to Use Percent Brackets in ImageMagick 7

This guide explains how to use ImageMagick 7 inline calculation strings using percent brackets to dynamically compute values within command-line operations. You will learn the syntax rules, how to access image properties, perform mathematical operations directly inside arguments, and avoid common shell-escaping pitfalls.

Understanding the %[...] Syntax

In ImageMagick 7, the magick command introduced streamlined inline expressions that eliminate the need for external shell calculations or multiple processing steps. The percent bracket notation—%[...]—allows you to query image metadata, compute values, or run internal scripts right where an argument expects a numerical or string input.

To perform mathematical calculations, you use the fx: prefix inside the brackets:

%[fx:expression]

This invokes ImageMagick’s built-in FX expression parser to evaluate formulas dynamically based on the current image's attributes.

Common Image Attributes in Calculations

Within an fx: expression, you can reference several intrinsic image properties:

  • w: Width of the image in pixels.
  • h: Height of the image in pixels.
  • u: Refers to the first image in the current sequence (or current image context).
  • v: Refers to the second image in the sequence.
  • t: Index of the current image in the sequence.
  • n: Total number of images in the sequence.

Practical Examples

1. Dynamic Cropping

Instead of hardcoding crop dimensions, calculate offsets and sizes relative to the image itself. To crop an image to the center with half its original width and height:

magick input.jpg -crop "%[fx:w*0.5]x%[fx:h*0.5]+%[fx:w*0.25]+%[fx:h*0.25]" +repage output.jpg

2. Calculated Resizing

To resize an image to a calculated aspect ratio or dynamic threshold, pass the calculated values into the -resize operator:

magick input.jpg -resize "%[fx:w*1.5]x%[fx:h*1.5]" output.jpg

3. Setting Dynamic Canvas and Geometry

You can define canvas dimensions based on an existing image's dimensions. For example, creating a background canvas that is twice as wide as the input image:

magick input.jpg ( -size "%[fx:u.w*2]x%[fx:u.h]" xc:white ) +swap -gravity west -composite output.jpg

4. Annotating with Calculated Values

You can print computed values directly onto an image using -annotate:

magick input.jpg -gravity northwest -pointsize 24 -fill white \
-annotate +10+10 "Aspect Ratio: %[fx:w/h]" output.jpg

Shell Escaping Considerations

Because characters such as %, [, ], and * carry special meanings in many command-line shells (like Bash, Zsh, or Windows Command Prompt), keep the following practices in mind:

  • Quotation: Always enclose arguments containing %[fx:...] in double quotes in Unix/Linux and Windows to prevent shell globbing and variable expansion.
  • Multiplication Symbol: In some shells, an unquoted * acts as a wildcard. Quoting the whole argument prevents the shell from expanding it.
  • Windows Batch Files: If executing inside a Windows batch script (.bat), escape the percent sign by doubling it (%%[fx:...]).
