How to Use the ImageMagick Granite Pattern

This article provides a quick overview of the built-in granite: protocol in ImageMagick, detailing how this specialized pseudo-image generator produces a realistic granite stone texture without requiring external source files. You will learn the command-line syntax for generating the texture, how to adjust its dimensions, and how to apply styling adjustments like tinting and tiling to integrate the pattern into graphic workflows.

ImageMagick includes several built-in image generators—often referred to as pseudo-image formats—that generate procedural textures and test patterns dynamically. The built-in generator responsible for producing a mottled stone texture is the granite: protocol. When invoked, ImageMagick renders an embedded, predefined pattern resembling a natural gray granite surface.

To generate a standard granite texture file, run the basic command:

magick granite: granite_output.png

For legacy ImageMagick versions (ImageMagick 6), replace magick with convert:

convert granite: granite_output.png

By default, the granite: operator generates a tileable image with a fixed default resolution of 128×128 pixels. Because the texture is designed to repeat seamlessly, it can be tiled across larger canvases or resized to meet project requirements.

To generate a granite texture at a specific size without tiling artifacts, define the canvas size using the -size option before declaring the protocol, or resize it afterward:

magick -size 500x500 tile:granite: large_granite.png

In this command, the tile: protocol references the granite: source and repeats it across a newly defined 500×500 pixel canvas.

The native output of the granite: generator is neutral and grayscale. You can alter its appearance by applying tinting, colorization, or contrast adjustments:

magick granite: -fill "#8b5a2b" -tint 50% brown_granite.png

The granite: built-in pattern is frequently employed as a displacement map, a background fill for composite graphics, or an overlay texture to add tactile roughness and organic noise to flat vector shapes and text.
