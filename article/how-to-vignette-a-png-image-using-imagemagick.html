How to Vignette a PNG Image Using ImageMagick?

Applying a vignette effect to a PNG image with ImageMagick is a straightforward process that darkens or fades the outer edges while keeping the center clear. This article covers the essential ImageMagick commands required to add both basic and customized vignette effects to PNG files, control blur radius, adjust background transparency, and preserve alpha channels via the command line.

ImageMagick provides a dedicated -vignette operator designed specifically for this purpose. The standard syntax for the operator is:

magick input.png -vignette {radius}x{sigma}+{x}+{y} output.png

For older versions (ImageMagick 6), replace magick with convert.

Basic Vignette Command

To apply a soft, classic vignette using default settings, execute:

magick input.png -vignette 0x20 output.png

In this command:

  • 0 represents the blur radius. Leaving this at 0 allows ImageMagick to calculate an optimal radius automatically.
  • 20 represents the sigma (the standard deviation of the Gaussian blur). Increasing this number expands the soft transition deeper toward the center of the image.

Customizing Dimensions and Offsets

The geometry parameter {radius}x{sigma}+{x}+{y} gives you granular control over where the vignette begins and how far it extends:

  • Offset X and Y (+{x}+{y}): These values dictate the horizontal and vertical margins from the edge where the feathering starts.

For example, to pull the darkening effect 10% inward from both the horizontal and vertical borders:

magick input.png -vignette 0x30+10+10 output.png

Handling Transparency and Background Colors

By default, the -vignette operator feathers into the current background color. For a standard PNG, this often defaults to white or transparent depending on your environment settings.

To create a dark, cinematic black edge:

magick input.png -background black -vignette 0x40+0+0 output.png

To vignette into a transparent border—useful for layering over web layouts:

magick input.png -background none -vignette 0x30+0+0 output.png

Preserving Existing PNG Alpha Channels

If the input PNG contains transparent areas that must remain untouched by the vignette mask, compose an elliptical gradient over the image instead of applying the destruction directly to the full canvas:

magick input.png \( +clone -background black -shadow 100x20+0+0 \) -compose Dst_In -composite output.png

Alternatively, generating a separate radial gradient mask allows full control over blending modes without modifying the source image's existing transparency data:

magick input.png \( -size 100x100% radial-gradient:white-black \) -compose Multiply -composite output.png

Using these parameters ensures fast, scriptable adjustments for batch processing PNG assets directly from the terminal.
