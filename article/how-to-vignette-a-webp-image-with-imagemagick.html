How to Vignette a WebP Image with ImageMagick?

Applying a vignette effect to a WebP image in ImageMagick darkens the outer edges while keeping the central subject illuminated, drawing focus toward the center. This tutorial explains how to apply the built-in -vignette operator, customize inner and outer radius offsets, and use custom radial masks to achieve precise, non-destructive edge gradients directly on .webp files.

Understanding the Basic Vignette Command

ImageMagick provides a dedicated operator called -vignette designed specifically to soften edges into a vignette. When working with modern formats like WebP, the processing syntax remains identical to other raster formats.

magick input.webp -vignette 0x20 output.webp

In this syntax:

  • input.webp is your source image.
  • -vignette {radius}x{sigma}[{+|-}x{+|-}y] controls the blur extent and geometry.
  • 0 instructs ImageMagick to automatically calculate the optimal pixel radius based on the image size.
  • 20 (the sigma value) controls the spread and softness of the blur falloff toward the corners.
  • output.webp writes the result directly back out to the WebP format.

Adjusting Vignette Radius and Offset

The parameters of the -vignette operator accept an optional coordinate offset to reposition the vignette's center or alter its coverage area.

The general geometry format is:

-vignette {radius}x{sigma}+{x}+{y}
  • Radius: Determines how far inward the vignette cuts. Setting this to 0 lets ImageMagick determine the default radius based on image dimensions, whereas a positive integer restricts the effect boundary.
  • Sigma: Controls the feathering gradient. Higher values produce a smooth, gradual transition, while lower values create a sharper boundary.
  • X and Y Offsets: By default, the vignette centers at +0+0. Supplying pixel values shifts the center point. For example, +50+0 shifts the clear center area 50 pixels to the right.

To create a deep, dramatic edge darkening that starts further outside the frame:

magick input.webp -vignette 0x40+10+10 output.webp

Creating Custom Vignette Colors and Blends

The standard -vignette operator blends the edge of the image toward the current background color. By default, this is black, but changing the background color alters the vignette tone.

To create a light or white vignette:

magick input.webp -background white -vignette 0x30 output_white_vignette.webp

To create a sepia-toned or custom-colored edge fade:

magick input.webp -background "#2e1f10" -vignette 0x35 output_toned.webp

Advanced Control Using Radial Gradient Masks

For precise control over contrast, falloff curvature, and transparency, generate a custom radial mask and composite it over the original image instead of relying solely on the built-in -vignette shorthand.

magick input.webp \( -size 1000x1000 radial-gradient:none-black -resize 100%x100%! \) \
  -compose Multiply -composite output_custom.webp

This pipeline generates a smooth black radial gradient sized to the base image and multiplies it across the pixel channels, leaving the center intact while darkening the corners with a natural optical curve.

Preserving WebP Compression and Quality

When exporting to WebP after applying the vignette, ensure you preserve visual clarity by defining quality parameters explicitly:

magick input.webp -vignette 0x25 -quality 85 -define webp:method=6 output.webp

The -define webp:method=6 flag tells ImageMagick's WebP encoder to use the highest compression effort, preventing banding artifacts along the subtle gradient edges created by the vignette.
