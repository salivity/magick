How to Vignette an AVIF Image in ImageMagick?

Applying a vignette to an AVIF image using ImageMagick allows you to soften or darken the edges of a picture to draw focus toward the center, all while retaining modern high-efficiency compression. By using ImageMagick’s dedicated -vignette operator or combining a custom radial gradient mask with composition flags, you can quickly achieve subtle photographic fading or dramatic edge shadow effects directly from the command line.

Prerequisites and AVIF Support

ImageMagick requires support for the AVIF format through an underlying delegate library, typically libheif. Before running vignette operations, verify that your ImageMagick installation can read and write AVIF files by checking your delegates:

magick -version

Look for heic or avif in the Delegates (built-in) line. If AVIF support is present, ImageMagick will seamlessly read .avif input files and write them back to disk without requiring format conversion steps.

The Basic Vignette Command

ImageMagick 7 provides a built-in -vignette geometry operator. The syntax accepts values for radius, sigma (blur intensity), and optional coordinate offsets:

magick input.avif -vignette 0x20 output.avif

In this command:

  • input.avif is the original image.
  • -vignette 0x20 applies an elliptical fade. A radius of 0 instructs ImageMagick to automatically calculate a suitable radius, while 20 sets the standard deviation (sigma) of the Gaussian blur along the outer edge.
  • output.avif saves the processed result as an AVIF file.

To create a heavier, more dramatic fade inward, increase the sigma value:

magick input.avif -vignette 0x50 output.avif

Adjusting Vignette Offsets

The -vignette operator also accepts horizontal and vertical offsets using the syntax radiusxsigma+x+y. Adding offset values shifts the start of the vignette inwards:

magick input.avif -vignette 0x30+10+10 output.avif

The +10+10 parameter pulls the fade boundary 10 pixels inward from both the horizontal and vertical margins, creating a tighter frame around the central subject.

Custom Dark Vignettes Using Radial Gradients

The default -vignette operator fades the image towards the active background color (defaulting to white or transparent depending on your alpha settings). If you want a traditional dark photographic vignette, use a black background or composite a radial gradient over the image.

To apply a dark vignette using -background:

magick input.avif -background black -vignette 0x40 output.avif

For precise artistic control over falloff, you can generate a radial gradient and composite it onto the image using the Multiply blend mode:

magick input.avif \( -size 100%x100% radial-gradient:white-black \) -compose Multiply -composite output.avif

This technique ensures the center remains fully illuminated while the perimeter smoothly blends into deep shadow.
