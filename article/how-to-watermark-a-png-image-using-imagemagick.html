How to Watermark a PNG Image Using ImageMagick?

Watermarking a PNG image with ImageMagick allows you to protect your visual content or stamp branding directly from the command line. This guide demonstrates how to apply both text-based overlays and transparent image-based watermarks onto a PNG using ImageMagick’s magick and composite tools. You will learn the exact syntax required for positioning, adjusting opacity, and batch-processing entire folders of PNG files.

Prerequisites

Ensure you have ImageMagick installed and accessible in your system terminal or command prompt. In ImageMagick version 7 and later, the primary command is magick. For ImageMagick version 6, commands like convert and composite are used directly.

Verify your installation by running:

magick -version

Adding a Text Watermark

To place text directly onto a target PNG, use the -draw or -annotate options. The -annotate flag provides straightforward control over text placement, font, size, and rotation.

magick input.png -font Arial -pointsize 36 -fill "rgba(255,255,255,0.5)" -gravity southeast -annotate +20+20 "Copyright 2026" output.png
  • -fill "rgba(255,255,255,0.5)": Defines the text color and opacity. The 0.5 alpha channel value makes the white text 50% transparent.
  • -gravity southeast: Anchors the coordinate system to the bottom-right corner.
  • -annotate +20+20: Sets an offset of 20 pixels horizontally and 20 pixels vertically away from the anchor point.

Adding an Image or Logo Watermark

If you have a separate transparent PNG logo, you can composite it over the base image using the magick composite command or standard magick syntax.

Using the Composite Command

magick composite -dissolve 40% -gravity southeast -geometry +25+25 logo.png input.png output.png
  • -dissolve 40%: Blends the logo onto the source image with 40% opacity.
  • -gravity southeast: Positions the watermark in the bottom-right corner.
  • -geometry +25+25: Adds a 25-pixel margin from the edge.

Using In-Line Composition

You can achieve the same result in a single pipeline without invoking the standalone composite tool:

magick input.png \( logo.png -alpha set -channel A -evaluate multiply 0.4 +channel \) -gravity center -composite output.png

This syntax reads the base image, modifies the alpha channel of the logo independently to 40% opacity, centers it, and merges the two layers.

Batch Processing Multiple PNG Images

To watermark multiple PNG files within a single directory, you can loop through the files using a shell script.

Bash (Linux / macOS)

mkdir -p watermarked
for img in *.png; do
  magick "$img" -gravity southeast -pointsize 28 -fill "rgba(255,255,255,0.6)" -annotate +15+15 "MyBrand" "watermarked/$img"
done

PowerShell (Windows)

New-Item -ItemType Directory -Force -Path .\watermarked
Get-ChildItem -Filter *.png | ForEach-Object {
    magick $_.Name -gravity southeast -pointsize 28 -fill "rgba(255,255,255,0.6)" -annotate +15+15 "MyBrand" "watermarked\$($_.Name)"
}

These scripts iterate through every .png file in the current directory, stamp the watermark in the corner, and save the updated file to a designated watermarked folder without overwriting the originals.
