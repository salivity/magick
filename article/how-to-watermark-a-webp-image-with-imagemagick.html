How to Watermark a WebP Image with ImageMagick?

Watermarking WebP images using ImageMagick provides an automated, efficient way to protect your intellectual property without compromising modern compression benefits. This guide walks through watermarking both single WebP files and entire directories using text overlays or graphic logos. You will learn the exact command-line syntax for controlling watermark positioning, opacity, and output quality using ImageMagick version 7 and version 6.

Prerequisites and Verification

Before manipulating WebP files, ensure ImageMagick is installed with WebP delegate support enabled. Run the following command in your terminal:

magick -version

Look for webp in the Delegates (built-in) line. If you are using ImageMagick 6, replace magick with convert or composite throughout these examples.

Adding a Text Watermark

A text watermark is ideal for copyright notices, URLs, or photographer attribution. ImageMagick allows you to set the font, point size, color, transparency, and positioning using the -annotate operator.

The following command places semi-transparent white text in the bottom-right corner of an image:

magick input.webp \
  -gravity SouthEast \
  -font Arial \
  -pointsize 24 \
  -fill "rgba(255,255,255,0.6)" \
  -annotate +20+20 "© 2026 Your Name" \
  -quality 85 \
  output.webp

Key parameters:

  • -gravity SouthEast: Anchors the coordinate system to the bottom-right corner.
  • -fill "rgba(255,255,255,0.6)": Defines the text color using red, green, blue, and alpha channels. An alpha value of 0.6 represents 60% opacity.
  • -annotate +20+20: Offsets the text 20 pixels horizontally and 20 pixels vertically away from the anchor corner.
  • -quality 85: Specifies the WebP compression factor for the exported file.

Applying an Image or Logo Watermark

If you have a transparent PNG logo, use the composite operation inside ImageMagick to overlay it directly onto your target WebP graphic.

magick input.webp watermark.png \
  -gravity SouthEast \
  -geometry +30+30 \
  -compose over \
  -composite \
  -quality 85 \
  output.webp

Adjusting Logo Opacity Dynamically

If your logo file is completely opaque and you want to reduce its prominence during the merge, adjust its alpha channel using the dissolve blend mode:

magick input.webp watermark.png \
  -gravity Center \
  -define compose:args=40,100 \
  -compose dissolve \
  -composite \
  -quality 85 \
  output.webp

In this command, compose:args=40,100 instructs ImageMagick to render the overlaid watermark at 40% opacity while preserving 100% of the underlying background.

Batch Processing Multiple WebP Files

To process a collection of WebP images within a folder, use the magick mogrify utility. Create a separate destination directory to avoid accidentally overwriting original media files.

mkdir -p watermarked

magick mogrify \
  -path watermarked \
  -gravity SouthEast \
  -font Arial \
  -pointsize 20 \
  -fill "rgba(255,255,255,0.5)" \
  -annotate +15+15 "Sample Watermark" \
  -quality 85 \
  -format webp *.webp

The -path watermarked flag tells the utility to save newly generated files into the target folder, retaining the original filenames and applying the specified annotations to every .webp file matched by the wildcard.
