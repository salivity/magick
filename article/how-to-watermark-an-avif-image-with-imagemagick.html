How to Watermark an AVIF Image With ImageMagick?

Applying a watermark to an AVIF image with ImageMagick involves compositing either a text string or a secondary graphic onto your base AVIF file while preserving AVIF encoding parameters. This guide covers how to verify your ImageMagick build supports the AVIF format, how to apply both text and transparent image watermarks using command-line syntax, and how to automate the procedure across batch folders.

Verifying AVIF Support in ImageMagick

Before running conversion commands, verify that your local installation of ImageMagick includes support for the AVIF format via libheif. Open your terminal or command prompt and check the recognized delegates:

magick -version

Look for heic or heif in the Delegates line. You can also query the format decoder list directly:

magick identify -list format | grep -i avif

If the output lists AVIF with read and write (rw+) capabilities, your installation is ready. If AVIF support is missing, update ImageMagick using a package manager that includes libheif support (such as Homebrew on macOS via brew install imagemagick or the official precompiled binaries on Linux and Windows).

Adding a Text Watermark to an AVIF Image

To overlay text such as copyright notices or domain names directly onto an AVIF image, use the magick command with the -annotate or -draw options.

Basic Corner Text Watermark

The following command places a semi-transparent text watermark in the bottom-right corner of the image:

magick input.avif \
  -font Arial -pointsize 28 \
  -fill "rgba(255, 255, 255, 0.6)" \
  -gravity Southeast -annotate +20+20 "© 2026 Your Name" \
  output.avif

Breakdown of Parameters

  • input.avif: The original image file.
  • -font: Specifies the typeface to use for the overlay.
  • -pointsize: Defines the text size in points.
  • -fill "rgba(255, 255, 255, 0.6)": Sets the text color to white with 60% opacity.
  • -gravity Southeast: Anchors the positioning to the bottom-right corner.
  • -annotate +20+20: Offsets the text 20 pixels inwards from the right and bottom edges.
  • output.avif: The destination AVIF image.

Adding an Image or Logo Watermark to an AVIF Image

If you have a transparent PNG logo, you can composite it over the base AVIF image using the -composite operator.

Standard Logo Overlay

magick input.avif logo.png \
  -gravity Center \
  -geometry +0+0 \
  -composite \
  output.avif

Controlling Logo Transparency

If your logo image is completely opaque, you can blend it dynamically using the -blend flag with the composite tool:

magick composite -blend 35% -gravity SouthEast -geometry +15+15 logo.png input.avif output.avif

This ensures the watermark stays subtle without totally obscuring the underlying picture content.

Preserving Compression Quality

AVIF uses advanced compression profiles. By default, ImageMagick applies standard compression settings when writing to an AVIF container, but you can explicitly define quality levels to avoid unwanted file size inflation or excessive degradation:

magick input.avif logo.png \
  -gravity Southeast -geometry +20+20 -composite \
  -quality 65 \
  -define heic:speed=4 \
  output.avif

Setting -quality 65 provides an optimal balance between visual fidelity and small file size for AVIF files, while -define heic:speed=4 sets the encoding speed preset.

Batch Watermarking Multiple AVIF Files

To process an entire folder of AVIF files at once on Linux or macOS, use a shell loop:

mkdir -p watermarked_output
for img in *.avif; do
  magick "$img" logo.png -gravity Southeast -geometry +20+20 -composite -quality 65 "watermarked_output/$img"
done

On Windows Command Prompt, run:

mkdir watermarked_output
for %i in (*.avif) do magick "%i" logo.png -gravity Southeast -geometry +20+20 -composite -quality 65 "watermarked_output\%i"

This iterates through every .avif file in the current working directory, applies the specified watermark, and outputs the result into a separate folder without altering your original files.
