How to Wave a PNG Image Using ImageMagick?

Applying a sine wave distortion to a PNG image in ImageMagick is achieved primarily using the built-in -wave operator. This article covers the exact command-line syntax for both legacy ImageMagick 6 and modern ImageMagick 7, explains how the wave parameters control amplitude and wavelength, and details how to manage the resulting canvas background and transparency.

Understanding the Wave Operator

The -wave operator shifts image pixels vertically along a sine curve across the width of the canvas. The command accepts two primary numeric arguments separated by an x:

-wave {amplitude}x{wavelength}
  • Amplitude: The height of the wave crests and troughs in pixels. A larger number produces deeper, more dramatic peaks and valleys.
  • Wavelength: The distance in pixels from one wave peak to the next. A smaller number creates many tight ripples across the image, while a larger number creates a gentle, rolling undulation.

Because waving an image bends pixels beyond their original vertical boundaries, the final output dimensions expand automatically to accommodate the crests and troughs.

Basic ImageMagick Commands

The command syntax varies slightly depending on the ImageMagick release installed on your system.

ImageMagick 7 (Recommended)

In ImageMagick 7, the unified magick utility replaces the older tool binaries:

magick input.png -wave 10x100 output.png

This command takes input.png, applies a wave with an amplitude of 10 pixels and a wavelength of 100 pixels, and writes the result to output.png.

ImageMagick 6 (Legacy)

For older installations using ImageMagick 6, use the convert binary:

convert input.png -wave 10x100 output.png

Controlling Transparency and Background Color

When the wave operator displaces pixels, empty space is exposed along the edges of the curved image. By default, ImageMagick fills this exposed area with the current background setting.

Preserving a Transparent Background

For PNG graphics with existing alpha channels (such as logos, icons, or cutouts), set the -background parameter to none before applying the wave distortion:

magick input.png -background none -wave 15x120 output.png

This ensures the newly exposed canvas area remains fully transparent rather than filling with black or white pixels.

Filling with a Solid Background Color

To fill the displacement margins with a specific color instead of transparency, declare the color name or hex code with the -background flag:

magick input.png -background "#ffffff" -wave 15x120 output.png

Creating Horizontal Waves

The -wave operator only distorts images vertically along the horizontal axis. To distort an image horizontally along the vertical axis, rotate the image by 90 degrees before applying the wave, then rotate it back:

magick input.png -background none -rotate 90 -wave 10x80 -rotate -90 output.png

This technique allows fine control over the wave direction while retaining transparency throughout the transformation pipeline.
