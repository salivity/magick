How to Wave an AVIF Image with ImageMagick?

Applying a sine wave distortion to an AVIF graphic using ImageMagick requires calling the -wave operator alongside appropriate amplitude and wavelength parameters. This guide covers how to verify AVIF read/write support in your ImageMagick installation, construct the wave transformation command, control wave geometry, and manage edge transparency or background fills to maintain high-quality visual output.

Prerequisites and AVIF Support

ImageMagick uses external delegates to handle modern compression formats like AVIF. Before processing AVIF files, ensure your environment includes libheif support.

You can verify whether your installed binary supports AVIF by running:

magick -version

Look for heic or avif in the Delegates (built-in) list. Alternatively, query the format directly:

magick identify -list format | grep -i avif

If the output lists rw+ next to AVIF, ImageMagick can read, write, and manipulate AVIF files natively.

Understanding the -wave Parameter Syntax

The -wave operator shifts pixel columns vertically according to a sine curve across the width of the image. The syntax accepts two values formatted as:

-wave <amplitude>x<wavelength>
  • Amplitude: The height or crest of the wave in pixels. Higher values create deeper, more dramatic peaks and troughs.
  • Wavelength: The horizontal distance in pixels between wave peaks. Smaller numbers create tightly packed ripples, while larger values produce a broad, gentle roll.

Basic Command Structure

In modern ImageMagick (version 7 and above), run the magick tool, specify the input AVIF, supply the -wave geometry, and designate an output AVIF filename:

magick input.avif -wave 15x120 output.avif

This command distorts input.avif with a vertical displacement amplitude of 15 pixels across an oscillation period of 120 pixels, saving the altered result to output.avif.

Handling Canvas Bounds and Transparency

Applying a wave distortion displaces pixels away from their original coordinates, introducing empty canvas areas along the top and bottom edges. By default, ImageMagick fills newly exposed canvas regions with the current background color.

Preserving Transparent Backgrounds

If your input is an alpha-transparent graphic (such as a logo, sticker, or cutout), define a transparent background and a transparent virtual pixel mode to avoid opaque borders:

magick input.avif -background transparent -virtual-pixel transparent -wave 20x150 output.avif

Setting a Specific Background Fill

If the target composition uses a solid background, explicitly set -background to match the target color palette before applying the wave:

magick input.avif -background "#1a1a1a" -wave 10x80 output.avif

Adjusting AVIF Compression Quality

Because AVIF employs efficient lossy or lossless AV1 video frame encoding, manipulating an image will re-encode the output. To preserve detail and control artifacting, pass the -quality flag:

magick input.avif -background none -wave 12x100 -quality 85 output.avif

A quality rating between 75 and 85 delivers high visual fidelity while maintaining compact file sizes typical of the AVIF format.
