How to Write 32-Bit Floating Point TIFF in ImageMagick

This article provides a direct guide on how to export 32-bit floating-point TIFF files using the ImageMagick command-line utility. It covers the specific flags needed to format high-dynamic-range pixel data, prerequisites regarding ImageMagick's High Dynamic Range Imaging (HDRI) build, and verification steps to confirm the output format.

Prerequisites

To write 32-bit floating-point values, your ImageMagick installation must have HDRI enabled. ImageMagick 7 includes HDRI by default in standard builds. You can verify your version by running:

magick -version

Ensure HDRI appears in the Features line of the output (for example, Features: Cipher DPC HDRI Modules OpenMP).

The Conversion Command

To save a TIFF image with 32-bit floating-point precision, set the bit depth to 32 and use the quantum:format define flag set to floating-point:

magick input.png -depth 32 -define quantum:format=floating-point output.tif

If you are using legacy ImageMagick (v6), replace magick with convert:

convert input.png -depth 32 -define quantum:format=floating-point output.tif

Parameter Breakdown

  • -depth 32: Sets the number of bits per color channel to 32.
  • -define quantum:format=floating-point: Forces the TIFF coder to write IEEE floating-point values rather than standard unsigned integers. Without this flag, -depth 32 will write standard 32-bit integer data.

Handling Compression

Uncompressed 32-bit TIFFs require substantial disk space. You can apply lossless compression suitable for floating-point data using the -compress option:

magick input.exr -depth 32 -define quantum:format=floating-point -compress zip output.tif

Supported compression formats for TIFF include zip (Deflate), lzw, or none.

Generating a Float Image from Scratch

You can generate synthetic high-dynamic-range test images directly from the command line:

magick -size 256x256 gradient:black-white -depth 32 -define quantum:format=floating-point gradient_float32.tif

Verifying the Output

To confirm that the output file is a true 32-bit floating-point TIFF, inspect the metadata with the identify command:

magick identify -verbose output.tif

Look for the following properties in the output:

  • Depth: 32-bit
  • Format: TIFF
  • tiff:sampleformat: floating point (or indicated under quantum:format: floating-point)
