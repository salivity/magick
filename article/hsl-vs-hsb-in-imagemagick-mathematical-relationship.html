HSL vs HSB in ImageMagick: Mathematical Relationship

This article provides an overview of how ImageMagick represents and translates colors between the HSL (Hue, Saturation, Lightness) and HSB (Hue, Saturation, Brightness, also known as HSV) color spaces. While both models map color data cylindrically around a shared Hue coordinate, their treatment of saturation and luminance yields distinct mathematical transformations. Understanding these underlying equations is essential for accurate color space conversion and channel manipulation in ImageMagick.

The Shared Hue Component

In both HSL and HSB, the Hue (\(H\)) calculation is identical. It represents the dominant wavelength on a color circle from \(0^\circ\) to \(360^\circ\):

\[H_{HSL} = H_{HSB}\]

In ImageMagick, Hue is normalized internally across the system's quantum depth (from \(0\) to QuantumRange, or \(0\%\) to \(100\%\)).

Fundamental Definitions from RGB

Given normalized RGB values where \(R, G, B \in [0, 1]\):

  • \(M = \max(R, G, B)\)
  • \(m = \min(R, G, B)\)
  • \(C = M - m\) (Chroma)

ImageMagick calculates the intensity and saturation components differently for each model:

  • HSB Model:

    • Brightness (\(B\) or \(V\)): \(B = M\)
    • Saturation (\(S_{B}\)): \[S_{B} = \begin{cases} 0 & \text{if } B = 0 \\ \frac{C}{B} & \text{if } B > 0 \end{cases}\]

  • HSL Model:

    • Lightness (\(L\)): \(L = \frac{M + m}{2}\)
    • Saturation (\(S_{L}\)): \[S_{L} = \begin{cases} 0 & \text{if } L = 0 \text{ or } L = 1 \\ \frac{C}{1 - |2L - 1|} & \text{if } 0 < L < 1 \end{cases}\]

Direct Conversion: HSB to HSL

When converting from an HSB coordinate \((H, S_{B}, B)\) to HSL \((H, S_{L}, L)\):

  1. Calculate Lightness (\(L\)): \[L = B \left(1 - \frac{S_{B}}{2}\right)\]

  2. Calculate HSL Saturation (\(S_{L}\)): \[S_{L} = \begin{cases} 0 & \text{if } L = 0 \text{ or } L = 1 \\ \frac{B - L}{\min(L, 1 - L)} & \text{otherwise} \end{cases}\]

    Alternatively expressed strictly in terms of HSB parameters: \[S_{L} = \begin{cases} 0 & \text{if } L = 0 \text{ or } L = 1 \\ \frac{B \cdot S_{B}}{1 - |2L - 1|} & \text{otherwise} \end{cases}\]

Direct Conversion: HSL to HSB

When converting from an HSL coordinate \((H, S_{L}, L)\) to HSB \((H, S_{B}, B)\):

  1. Calculate Brightness (\(B\)): \[B = L + S_{L} \cdot \min(L, 1 - L)\]

  2. Calculate HSB Saturation (\(S_{B}\)): \[S_{B} = \begin{cases} 0 & \text{if } B = 0 \\ 2 \left(1 - \frac{L}{B}\right) & \text{otherwise} \end{cases}\]

ImageMagick Implementation Details

When executing conversions via -colorspace HSL or -colorspace HSB (or -colorspace HSV), ImageMagick applies these transforms to each pixel component:

  • Channel 0: Hue (\(H\)) remains numerically invariant during direct HSL-to-HSB or HSB-to-HSL conversions.
  • Channel 1: Saturation (\(S\)) is rescaled non-linearly depending on the target space's lightness or brightness value.
  • Channel 2: Lightness (\(L\)) or Brightness (\(B\)) is evaluated using the respective mid-range or maximum RGB channel projection.
