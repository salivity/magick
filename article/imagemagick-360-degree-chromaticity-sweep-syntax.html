ImageMagick 360 Degree Chromaticity Sweep Syntax

This article provides the exact ImageMagick command syntax needed to generate a full 360-degree chromaticity (hue) sweep. It covers the commands for both a horizontal linear spectrum sweep and a continuous circular polar sweep, along with breakdowns of the required color space operations.

Linear 360-Degree Chromaticity Sweep

To generate a linear horizontal chromaticity bar representing the full 360 degrees of hue at maximum saturation and normal lightness, use the following ImageMagick command:

magick -size 360x60 gradient: \
  ( -clone 0 ) \
  ( -size 360x60 xc:white ) \
  ( -size 360x60 xc:"gray(50%)" ) \
  -delete 0 -combine -set colorspace HSL -colorspace sRGB \
  linear_chromaticity_sweep.png

Syntax Breakdown:

  • -size 360x60 gradient: creates a base grayscale gradient representing values from 0.0 to 1.0 (mapping to 0°–360°).
  • ( -clone 0 ): Uses the gradient values to define the Hue channel.
  • ( -size 360x60 xc:white ): Sets the Saturation channel to 100%.
  • ( -size 360x60 xc:"gray(50%)" ): Sets the Lightness channel to 50% for standard chromaticity.
  • -combine -set colorspace HSL: Merges the three channels into an HSL image.
  • -colorspace sRGB: Converts the final result to standard sRGB for proper display.

Circular 360-Degree Polar Chromaticity Sweep

To render the sweep as a continuous 360-degree color wheel, apply a polar distortion to the linear gradient:

magick -size 1x360 gradient: \
  -rotate 90 \
  -virtual-pixel HorizontalTile \
  -distort Polar 0 \
  ( -clone 0 ) \
  ( +clone -fill white -colorize 100% ) \
  ( +clone -fill "gray(50%)" -colorize 100% ) \
  -delete 0 -combine -set colorspace HSL -colorspace sRGB \
  circular_chromaticity_sweep.png

Syntax Breakdown:

  • -size 1x360 gradient: -rotate 90: Generates a gradient mapped horizontally across 360 units.
  • -distort Polar 0: Distorts the 0–360 linear span radially around a center point, forming a complete 360-degree circle without a seam.
  • -virtual-pixel HorizontalTile: Ensures smooth wrap-around where the 0° (red) and 360° (red) boundaries meet.
