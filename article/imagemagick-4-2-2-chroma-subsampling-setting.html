ImageMagick 4:2:2 Chroma Subsampling Setting

This guide explains the specific -sampling-factor parameter required to achieve 4:2:2 chroma subsampling when processing JPEG images in ImageMagick. It covers the exact syntax to use in the command line, explains how ImageMagick maps sampling factors to the YCbCr color channels, and provides a command to verify your output.

In ImageMagick, the setting that corresponds to 4:2:2 chroma subsampling is -sampling-factor 2x1 (or fully expanded as 2x1,1x1,1x1).

How the Setting Works

JPEG compression divides the image into luminance (Y) and two chrominance channels (Cb and Cr). The -sampling-factor argument accepts horizontal and vertical frequency values (HxV) for each component in the order of Y, Cb, and Cr:

  • Y (Luminance): 2x1 (sampled at twice the horizontal resolution of the chroma channels)
  • Cb (Blue-difference chroma): 1x1
  • Cr (Red-difference chroma): 1x1

When specifying 2x1, ImageMagick automatically assigns the 1x1 factor to the remaining chroma channels.

Example Command

To convert an image using 4:2:2 chroma subsampling, run the following command in your terminal:

magick input.png -sampling-factor 2x1 output.jpg

(Note: If you are using ImageMagick 6, replace magick with convert.)

How to Verify the Output

You can verify that the image was encoded with 4:2:2 subsampling using the identify command:

magick identify -verbose output.jpg

Look for the jpeg:sampling-factor line under the image properties. For a properly formatted 4:2:2 image, the output will display:

jpeg:sampling-factor: 2x1,1x1,1x1
