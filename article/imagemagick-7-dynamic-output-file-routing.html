ImageMagick 7 Dynamic Output File Routing

ImageMagick 7 uses the -set filename: directive to assign formatted metadata to an image in memory, enabling automated, dynamic destination paths for batch operations. By defining a custom property such as filename:output using percent-escape parameters like %[t], users can extract base filenames, append custom tags, and route processed images to unique filenames or directories in a single command sequence.

The Mechanism of -set filename:output

The -set filename:property setting creates an image-level artifact specifically designated for filename resolution. In ImageMagick 7, string formatting and percent escapes are evaluated on a per-image basis. When processing multiple inputs, this ensures that each file in the sequence calculates its own distinct output path rather than overwriting a static file.

The parameter string '%[t]_processed' relies on percent-escape formatting:

  • %[t]: Expands to the input image's base filename (its "title"), stripped of directory paths and file extensions.
  • _processed: A literal string appended directly to the base name.

Once defined, this string does not alter the image data itself; instead, it assigns the resulting text to a temporary key named filename:output.

Referencing the Dynamic Property at Output

Setting the variable does not automatically write the file. The property must be explicitly referenced in the final output argument using the %[filename:key] syntax:

magick input.jpg -set filename:output "%[t]_processed" "%[filename:output].png"

In this command:

  1. magick reads input.jpg.
  2. The -set filename:output "%[t]_processed" evaluates input.jpg into the string "input_processed".
  3. The output destination string "%[filename:output].png" reads the key, producing input_processed.png.

Batch Processing and Path Redirection

This technique is most powerful during multi-file operations. Because ImageMagick 7 processes sequence lists iteratively, wildcard inputs can be transformed and renamed uniquely in a single execution:

magick *.png -resize 50% -set filename:output "converted/%[t]_processed" "%[filename:output].jpg"

In this scenario, each matching file has its basename extracted, is scaled by 50%, appended with _processed, routed into the converted/ subdirectory, and converted to the JPEG format. The dynamic expansion handles path creation (provided the target directory exists) and extension changes simultaneously without requiring external shell loops.
