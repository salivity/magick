ImageMagick Adaptive Thresholding Syntax

This article provides a concise guide to performing adaptive thresholding over a moving neighborhood using ImageMagick. It details the exact command-line syntax, explains the required parameters for defining local pixel windows, and demonstrates practical examples to achieve clean binarization on unevenly lit images.

The Adaptive Threshold Syntax

In ImageMagick, adaptive thresholding over a moving local neighborhood is executed using the -lat (Local Adaptive Threshold) or -adaptive-threshold operator.

The standard syntax is:

magick input.jpg -lat <width>x<height>{+-}<offset>[%] output.png

(Note: In ImageMagick 6, replace magick with convert.)

Parameter Breakdown

  • <width>x<height>: Defines the size of the moving pixel neighborhood (window) centered around each target pixel. A larger window accounts for broader variations in illumination, while a smaller window targets fine, local contrast. If only a single dimension is specified (e.g., 25), ImageMagick assumes a square window (25x25).
  • {+-}<offset>: The threshold offset value subtracted from (or added to) the calculated average of the local neighborhood.
    • A positive offset (+offset) subtracts value from the local average, making it easier for pixels to turn white (useful for text extraction on dark backgrounds).
    • A negative offset (-offset) adds to the threshold, causing more pixels to turn black.
  • [%] (Optional): Designates the offset as a percentage of the image's maximum quantum value (e.g., 5% or 10%) rather than an absolute raw pixel value.

Practical Examples

1. Document Binarization with Percentage Offset

To clean up a scanned document with non-uniform lighting using a 25x25 moving window and a 10% offset:

magick scan.jpg -lat 25x25+10% binary_scan.png

2. High-Detail Thresholding with a Small Neighborhood

To preserve fine details or small text artifacts, reduce the moving neighborhood size:

magick input.png -lat 10x10+5% detailed_output.png

3. Using Absolute Raw Pixel Values

If you prefer exact quantum values rather than percentages:

magick input.png -lat 30x30+4096 output.png

How It Works

  1. For every pixel in the image, ImageMagick calculates the mean pixel value within the defined width × height bounding box.
  2. It computes the threshold value: local_threshold = local_mean - offset.
  3. If the central pixel's intensity is greater than local_threshold, it is assigned to maximum intensity (white); otherwise, it is assigned to minimum intensity (black).
