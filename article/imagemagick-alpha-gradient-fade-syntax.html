ImageMagick Alpha Gradient Fade Syntax

This guide demonstrates the exact command-line syntax required to apply an alpha transparency gradient fade to an image using ImageMagick. You will learn how to smoothly transition an image from fully opaque to completely transparent using built-in gradient masks and composition operators.

Basic Syntax for a Vertical Alpha Fade

To fade an image from top (opaque) to bottom (transparent), generate a black-and-white gradient matching the dimensions of the input image and apply it using the CopyOpacity composition operator.

For ImageMagick v7:

magick input.png ( +clone -channel A -separate +channel -size %wx%h gradient:white-black ) -alpha off -compose CopyOpacity -composite output.png

For ImageMagick v6 (convert):

convert input.png ( +clone -size %wx%h gradient:white-black ) -alpha off -compose CopyOpacity -composite output.png

Syntax for a Horizontal Alpha Fade

To create a horizontal fade that transitions from left (opaque) to right (transparent), rotate the generated gradient before compositing:

magick input.png ( +clone -size %wx%h gradient:white-black -rotate 90 ) -alpha off -compose CopyOpacity -composite output.png

Alternatively, swap the dimensions and rotate to fit the original aspect ratio:

magick input.png ( -size %hx%w gradient:white-black -rotate 90 ) -alpha off -compose CopyOpacity -composite output.png

Alternative Method: Using DstIn Composition

You can also apply an alpha gradient by compositing a gradient ranging from full transparency (none) to opaque (black):

magick input.png ( -size %wx%h gradient:black-none ) -compose DstIn -composite output.png

Breakdown of Key Parameters

  • +clone: Duplicates the source image in memory to read its exact dimensions (%wx%h).
  • gradient:white-black: Creates a grayscale mask where white represents full opacity and black represents full transparency. Inverting the colors (gradient:black-white) reverses the fade direction.
  • -alpha off: Disables existing alpha channels on the generated mask to ensure the grayscale values map directly to opacity levels.
  • -compose CopyOpacity: Tells ImageMagick to replace the alpha channel of the primary image with the grayscale intensity values of the mask.
  • -composite: Executes the blend between the source image and the gradient mask.
