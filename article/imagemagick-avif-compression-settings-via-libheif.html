ImageMagick AVIF Compression Settings via libheif

When converting images to AVIF using ImageMagick backed by libheif, specific -define directives and standard CLI options govern the underlying AV1 compression behavior. This article details the primary heic: defines used by ImageMagick's libheif coder to control encoding speed, chroma subsampling, lossless modes, encoder backend selection, and custom low-level parameters to balance visual fidelity against file size.

The Delegate Prefix

In ImageMagick, AVIF encoding is handled by the HEIC/HEIF coder module (coders/heic.c) via the libheif library. Because both HEIC and AVIF share this module, configuration options use the heic: prefix rather than avif:.

Core Compression Defines

1. Encoding Speed and Effort

  • Directive: -define heic:speed=<value>
  • Values: Integer from 0 (slowest, best compression) to 10 (fastest, lowest compression).
  • Behavior: Maps directly to the underlying AV1 encoder's CPU effort setting (such as cpu-used in aom or preset in svt-av1). Values around 4 to 6 provide a balanced compromise between compression efficiency and encoding time.

2. Lossless Compression

  • Directive: -define heic:lossless=true (or false)
  • Behavior: Disables lossy quantization and encodes the image using mathematically lossless AV1 compression. When set to true, standard quality settings are ignored.

3. Chroma Subsampling

  • Directive: -define heic:chroma=<subsampling>
  • Values: 420, 422, or 444
  • Behavior: Controls color resolution relative to luma:
    • 420 (default): Best for photographic content and maximum file size reduction.
    • 444: Retains full color detail, ideal for UI screenshots, graphics, and sharp text.

4. Encoder Engine Selection

  • Directive: -define heic:encoder=<encoder_name>
  • Values: Typically aom, svt, or rav1e (depending on what libheif was compiled with).
  • Behavior: Directs libheif to use a specific AV1 plugin installed on the system if more than one AV1 encoder is present.

5. Advanced Encoder Parameters

  • Directive: -define heic:raw-params="<param1>=<val1>,<param2>=<val2>"
  • Behavior: In newer ImageMagick and libheif builds, this passes raw key-value string arguments directly through to the underlying AV1 implementation. This allows access to native encoder features not exposed via top-level ImageMagick defines (such as tiling, rate-control tuning, or threading models).

Complementary Standard Options

While not prefixed with -define, the following standard ImageMagick switches directly affect AV1 output through libheif:

  • -quality <0-100>: Sets the target quality level. ImageMagick maps this scale to the AV1 encoder's Constant Rate Factor (CRF). A quality of 100 results in near-lossless output, while typical web delivery targets fall between 50 and 75.
  • -depth <8|10|12>: Dictates output bit depth. AVIF supports high dynamic range (HDR) and wide color gamuts; setting -depth 10 leverages 10-bit AV1 profiles to reduce color banding at low bitrates.

Command Example

magick input.png \
  -quality 65 \
  -depth 10 \
  -define heic:speed=4 \
  -define heic:chroma=420 \
  output.avif
