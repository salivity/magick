ImageMagick AVIF Quality Configuration

This guide explains how to configure quality and compression settings for AVIF image output using ImageMagick. You will learn the correct usage of the -quality parameter, recommended value ranges for web use, lossless encoding methods, and advanced encoder defines to optimize file size and encoding performance.

The ImageMagick AVIF Quality Setting

ImageMagick controls AVIF compression primarily through the standard -quality command-line option. When writing AVIF files (typically via the libheif delegate with an underlying AV1 encoder such as libaom or rav1e), the quality setting accepts values from 1 to 100.

Basic Syntax

magick input.jpg -quality 60 output.avif

Recommended Quality Ranges

  • 1–40 (High Compression): Noticeable reduction in visual quality; best suited for extreme bandwidth constraints or small thumbnails.
  • 50–65 (Recommended for Web): The sweet spot for most web photographs. This range provides visually lossless results with significant file size savings compared to JPEG or WebP.
  • 70–85 (High Fidelity): Near-flawless quality for high-resolution photography, preserving fine grain and subtle gradients.
  • 90–100 (Maximum / Lossless): Produces the largest file sizes. Setting -quality 100 targets the highest visual fidelity or lossless mode depending on the delegate configuration.

Lossless AVIF Encoding

To guarantee true lossless compression when converting graphics, diagrams, or archival images to AVIF, set -quality 100 or use the explicit heic:lossless define:

magick input.png -define heic:lossless=true output.avif

Advanced Encoder Settings

ImageMagick supports -define options to fine-tune the AVIF encoder's speed, compression efficiency, and color handling.

1. Encoding Speed (heic:speed)

AV1 encoding can be CPU-intensive. You can control the trade-off between encoding time and file size using the heic:speed define (values typically range from 0 to 9):

  • 0 (Slowest): Maximum compression efficiency.
  • 6 (Default/Balanced): Good balance of encoding speed and compression.
  • 9 (Fastest): Quickest conversion, resulting in slightly larger output files.
magick input.jpg -quality 65 -define heic:speed=4 output.avif

2. Chroma Subsampling (heic:chroma)

By default, AVIF uses 4:2:0 subsampling (420) to minimize file size. For pixel art, text, or sharp user-interface graphics, use 4:4:4 subsampling (444) to avoid color bleeding:

magick graphic.png -quality 80 -define heic:chroma=444 output.avif

Example: Production-Ready Optimization

For general web delivery, combining a balanced quality setting with a moderate speed profile yields optimal results:

magick photo.jpg -quality 60 -define heic:speed=4 -define heic:chroma=420 optimized.avif
