ImageMagick Bezier Curves with Four Coordinate Points

In ImageMagick, using the -draw 'bezier' primitive with four coordinate points produces a cubic Bézier curve. This article explains the mechanics of cubic Bézier curves, how ImageMagick interprets the four given coordinates, and the mathematical properties governing the resulting vector path.

Understanding the Cubic Bézier Curve

A Bézier curve is a parametric curve defined by a set of control points. The degree of the polynomial defining the curve is always one less than the number of control points (\(n - 1\)). When you supply exactly four coordinate points to ImageMagick, it computes a 3rd-degree polynomial, resulting in a cubic Bézier curve.

The parametric formula for a cubic Bézier curve over the interval \(t \in [0, 1]\) is:

\[B(t) = (1-t)^3 P_0 + 3(1-t)^2 t P_1 + 3(1-t) t^2 P_2 + t^3 P_3\]

Role of the Four Coordinate Points

When executing a command such as -draw "bezier x0,y0 x1,y1 x2,y2 x3,y3", ImageMagick assigns specific roles to each point:

  1. \(P_0\) (Start Anchor Point): The curve begins precisely at this coordinate \((x_0, y_0)\) when \(t = 0\).
  2. \(P_1\) (First Control Handle): This point determines the initial direction and velocity of the curve as it leaves \(P_0\). The line segment \(P_0 \to P_1\) forms the tangent vector at the start.
  3. \(P_2\) (Second Control Handle): This point influences the curve's path as it approaches the end. The line segment \(P_2 \to P_3\) forms the tangent vector at the destination.
  4. \(P_3\) (End Anchor Point): The curve terminates precisely at this coordinate \((x_3, y_3)\) when \(t = 1\).

Points \(P_1\) and \(P_2\) are non-interpolating control points, meaning the curve generally does not pass directly through them. Instead, they exert directional pull on the path.

Command Syntax and Rendering

In ImageMagick, the primitive is typically called using the following command structure:

magick -size 600x400 xc:white -stroke black -fill none -strokewidth 2 -draw "bezier 50,350 150,50 450,50 550,350" curve.png

In this command:

  • 50,350 serves as the initial anchor point (\(P_0\)).
  • 150,50 pulls the curve upward toward the upper left (\(P_1\)).
  • 450,50 maintains the elevation toward the upper right (\(P_2\)).
  • 550,350 sets the final anchor point (\(P_3\)).

Key Characteristics of the Generated Path

  • Endpoint Interpolation: The path always connects \(P_0\) directly to \(P_3\).
  • Convex Hull Property: The generated curve is strictly contained within the convex polygon formed by the four control points, preventing unpredictable rendering outside that boundary.
  • Smoothness: A single cubic curve provides \(C^\infty\) continuity along its length, guaranteeing a smooth vector stroke without abrupt changes in curvature.
