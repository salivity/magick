ImageMagick Binarize Document with Threshold Percentage

Binarization converts scanned color or grayscale documents into pure two-tone, black-and-white images, which drastically reduces file sizes and improves optical character recognition (OCR) accuracy. ImageMagick accomplishes this through the -threshold operator, where supplying a percentage string sets a relative brightness cutoff point to separate foreground text from the paper background.

The Basic Command Syntax

In modern ImageMagick (version 7+), use the magick tool (or convert in ImageMagick 6) with the -threshold option followed by a percentage value:

magick input_document.png -colorspace Gray -threshold 55% output_binary.png

In this command:

  • -colorspace Gray ensures that color channels are merged into a single luminance channel, preventing unexpected channel-specific thresholding.
  • -threshold 55% evaluates pixel intensity across the 0% (pure black) to 100% (pure white) scale. Any pixel with a brightness value strictly greater than 55% becomes pure white, while any pixel at or below 55% becomes pure black.

Choosing the Right Percentage

The choice of percentage dictates how aggressively faint marks are captured versus how much background noise is suppressed:

  • 50%: The standard baseline for clean documents with high contrast between ink and paper.
  • 55% to 65%: Recommended for light text, faded ink, or pencil marks. Raising the threshold turns more mid-tone gray pixels to black text.
  • 35% to 45%: Recommended for documents with dark paper, yellowed pages, or ink bleed-through from the reverse side. Lowering the threshold forces mid-tone grays into white background.

Document Pre-Processing Before Thresholding

Applying global thresholding directly to raw scans often produces uneven results if lighting or scanning exposure varies across the page. Combining -threshold with normalization operators yields better binarization:

magick scan.tif -colorspace Gray -auto-level -threshold 60% binarized.tif
  • -auto-level stretches the dynamic range so the darkest pixel becomes pure black and the brightest becomes pure white prior to applying the percentage cutoff.

Automating with a Shell Script

To process a batch of scanned documents within a directory, you can integrate the command into a shell loop:

#!/usr/bin/env bash

THRESHOLD="58%"
OUTPUT_DIR="./binarized_output"

mkdir -p "$OUTPUT_DIR"

for file in *.png *.jpg *.tif; do
  [ -e "$file" ] || continue
  filename=$(basename "$file")
  magick "$file" \
    -colorspace Gray \
    -auto-level \
    -threshold "$THRESHOLD" \
    -type Bilevel \
    "$OUTPUT_DIR/${filename%.*}.png"
done

The -type Bilevel flag explicitly forces the final output image format to store the data as a 1-bit monochrome image, ensuring maximum compression efficiency.
