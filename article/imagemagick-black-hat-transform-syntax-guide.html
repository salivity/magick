ImageMagick Black Hat Transform Syntax Guide

This guide provides the exact command-line syntax for applying a Black-Hat morphological transform in ImageMagick. The Black-Hat operation—referred to as BottomHat in ImageMagick—isolates dark details, narrow gaps, and valleys that are smaller than the specified structuring element on a brighter background. Below, you will find the fundamental syntax, standard kernel choices, and clear examples for both ImageMagick v7 and v6.

Basic Syntax

In ImageMagick, the Black-Hat transform is executed using the -morphology operator with the BottomHat method:

ImageMagick v7

magick input.png -morphology BottomHat <Kernel> output.png

ImageMagick v6

convert input.png -morphology BottomHat <Kernel> output.png

How the Transform Works

The Black-Hat transform is mathematically defined as the morphological closing of an image minus the original image:

\[\text{Black Hat} = \text{Closing}(I) - I = (I \bullet K) - I\]

Because closing fills in dark structures that are smaller than the kernel, subtracting the original image reveals only those dark regions, displaying them as bright artifacts on a black background.

Common Kernel Options

The <Kernel> argument defines the shape and size of the structuring element used to detect features. The syntax is formatted as KernelName:Radius or KernelName:WidthxHeight.

  • Disk: Useful for rounded, uniform, or organic structures.
    • Example: Disk:3 or Disk:5.5
  • Diamond: Common for pixel-art or diamond-shaped filtering.
    • Example: Diamond:2
  • Square / Rectangle: Best for rectilinear structures, text extraction, or grid lines.
    • Example: Square:3 or Rectangle:5x1 (horizontal features)

Concrete Examples

1. Standard Circular Kernel

To detect dark spots or thin dark text with a circular footprint of radius 3:

magick input.jpg -morphology BottomHat Disk:3 output.png

2. Directional Kernel for Line Detection

To detect vertical dark lines smaller than 7 pixels in height:

magick input.jpg -morphology BottomHat Rectangle:1x7 output.png

3. Converting to Grayscale Before Processing

Because morphological operations analyze channel intensity, it is common practice to convert color images to grayscale first:

magick input.jpg -colorspace Gray -morphology BottomHat Octagon:4 output.png
