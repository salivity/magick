ImageMagick Blend Images with Custom Ratios

Blending two images using ImageMagick's Blend compose operator allows you to merge visuals smoothly with precise control over the opacity of each layer. This guide covers how to implement the Blend compose method using custom percentage ratios in ImageMagick 7, explains the syntax for defining individual layer weights, and provides clear examples for different blending scenarios.

The ImageMagick 7 Blend Command

To blend two images using custom ratios in modern ImageMagick (v7+), use the magick tool combined with the -compose Blend operator and the -define compose:args setting.

magick background.jpg overlay.jpg -compose Blend -define compose:args=40,60 -composite output.jpg

In this command:

  • background.jpg is the destination image.
  • overlay.jpg is the source image.
  • -compose Blend specifies the blending algorithm.
  • -define compose:args=40,60 sets the percentage ratios.
  • -composite executes the blend operation.
  • output.jpg is the resulting image file.

Understanding Custom Blending Ratios

The compose:args option controls the contribution of each image based on the arguments provided:

Two-Value Ratios (src_percent,dst_percent)

When specifying two comma-separated values, the first value dictates the percentage of the source image (overlay.jpg), and the second value dictates the percentage of the destination image (background.jpg).

  • Equal Blend (50/50): 
    magick background.jpg overlay.jpg -compose Blend -define compose:args=50,50 -composite output.jpg
  • Dominant Overlay (70% Overlay, 30% Background): 
    magick background.jpg overlay.jpg -compose Blend -define compose:args=70,30 -composite output.jpg
  • Values Not Totaling 100%: The values do not have to sum to 100. For instance, compose:args=50,20 will produce a darker, semi-transparent blend because the total opacity is only 70%. Values totaling more than 100 will brighten overlapping areas.

Single-Value Ratio (src_percent)

If you provide only one value, ImageMagick automatically calculates the inverse for the background image so that the total equals 100%.

magick background.jpg overlay.jpg -compose Blend -define compose:args=25 -composite output.jpg

In this example, overlay.jpg is assigned 25% opacity, and background.jpg automatically receives 75% opacity.

Legacy Syntax (ImageMagick 6 / Composite Command)

If you are using legacy ImageMagick versions or the standalone composite command, use the -blend flag with an XxY format:

composite -blend 40x60 overlay.jpg background.jpg output.jpg

Note that with the standalone composite command, the source image (overlay.jpg) is listed first, followed by the destination image (background.jpg).
