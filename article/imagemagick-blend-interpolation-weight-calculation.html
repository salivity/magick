ImageMagick Blend Interpolation Weight Calculation

The -interpolate Blend operator in ImageMagick calculates the value of a target point at fractional coordinates by performing standard bilinear interpolation across the four surrounding pixel neighbors. This article explains how ImageMagick determines the coordinates of these four bounding pixels, derives the fractional offsets, and applies rectangular area weighting to calculate each neighbor's contribution to the final interpolated pixel.

Identifying the Four Surrounding Pixels

When a coordinate \((x, y)\) falls at a non-integer position, ImageMagick selects the four neighboring pixels forming a \(1 \times 1\) bounding square around that point.

The bounding coordinates are defined using the floor function:

  • Top-Left (\(P_{00}\)): \((x_0, y_0) = (\lfloor x \rfloor, \lfloor y \rfloor)\)
  • Top-Right (\(P_{10}\)): \((x_1, y_0) = (x_0 + 1, y_0)\)
  • Bottom-Left (\(P_{01}\)): \((x_0, y_1) = (x_0, y_0 + 1)\)
  • Bottom-Right (\(P_{11}\)): \((x_1, y_1) = (x_0 + 1, y_0 + 1)\)

Calculating Fractional Offsets

Once the integer grid coordinates are established, ImageMagick computes the fractional distance (offset) from the top-left pixel to the target point:

\[\Delta x = x - x_0\] \[\Delta y = y - y_0\]

Because \(x_0 \le x < x_1\) and \(y_0 \le y < y_1\), both \(\Delta x\) and \(\Delta y\) always fall within the interval \([0, 1)\).

Computing Neighbor Weights

ImageMagick's Blend method assigns weights to each of the four pixels proportional to the area of the opposing sub-rectangle created by dividing the bounding cell at \((\Delta x, \Delta y)\). The closer the target coordinate is to a neighboring pixel, the larger the opposing area and the higher that pixel's weight.

The weights for the four neighbors are calculated as follows:

  • Top-Left Weight (\(w_{00}\)): \((1 - \Delta x) \times (1 - \Delta y)\)
  • Top-Right Weight (\(w_{10}\)): \(\Delta x \times (1 - \Delta y)\)
  • Bottom-Left Weight (\(w_{01}\)): \((1 - \Delta x) \times \Delta y\)
  • Bottom-Right Weight (\(w_{11}\)): \(\Delta x \times \Delta y\)

These weights naturally sum to \(1.0\):

\[w_{00} + w_{10} + w_{01} + w_{11} = 1.0\]

Final Color and Alpha Integration

For fully opaque images, the resulting channel value \(C\) is the sum of each neighbor's channel value multiplied by its respective geometric weight:

\[C = w_{00} C_{00} + w_{10} C_{10} + w_{01} C_{01} + w_{11} C_{11}\]

When transparency is present, ImageMagick factors each pixel's alpha channel into the calculation. The effective weight of each pixel becomes \(w_{ij} \times \alpha_{ij}\). The color channels are summed using these alpha-weighted factors and normalized by the total accumulated alpha weight, preventing fully or partially transparent pixels from incorrectly skewing the color values of neighboring opaque pixels.
