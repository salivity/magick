ImageMagick Booklet Imposition for Printing

This article explains how to create a 2-up booklet imposition layout from individual images or multi-page documents using ImageMagick. You will learn the specific command structure, how to correctly sequence page pairs for fold-and-staple binding, and the key parameters required to assemble print-ready sheets.

The Core Command

Booklet imposition requires arranging pages side-by-side (2-up) in a specific non-sequential order so that, once printed double-sided and folded, the pages read chronologically. In ImageMagick, the primary tool for this layout is the montage command combined with page index selection and tiling flags.

For an 8-page booklet sourced from a multi-page PDF or an image sequence, the command in ImageMagick 7 is:

magick montage input.pdf[7,0,1,6,5,2,3,4] -tile 2x1 -geometry +0+0 -density 300 booklet_sheet_%d.pdf

(Note: For ImageMagick 6, replace magick montage with just montage.)

Understanding Page Ordering

ImageMagick uses zero-based indexing (0 is page 1, 1 is page 2, etc.). For a standard saddle-stitch (folded) booklet, your total page count must be a multiple of 4. If necessary, add blank pages to reach a multiple of 4.

The pages are grouped into pairs per sheet side:

  • Sheet 1 Front: Last Page & Page 1 (input.pdf[7,0])
  • Sheet 1 Back: Page 2 & Second-to-Last Page (input.pdf[1,6])
  • Sheet 2 Front: Third-to-Last Page & Page 3 (input.pdf[5,2])
  • Sheet 2 Back: Page 4 & Fourth-to-Last Page (input.pdf[3,4])

Combining Individual Image Files

If your pages are separate image files rather than a single document, specify the files in the imposition order directly:

magick montage page_08.png page_01.png page_02.png page_07.png page_06.png page_03.png page_04.png page_05.png -tile 2x1 -geometry +0+0 booklet_sheet_%d.png

Parameter Breakdown

  • -tile 2x1: Places two consecutive pages horizontally on each output sheet.
  • -geometry +0+0: Preserves original image dimensions and eliminates spacing or borders between paired images.
  • -density 300: Sets the rasterization resolution to 300 DPI, which is standard for high-quality printing.
  • %d: A naming format specifier that outputs each spread as a sequentially numbered file (e.g., booklet_sheet_0.pdf, booklet_sheet_1.pdf).
