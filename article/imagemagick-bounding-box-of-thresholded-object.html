ImageMagick Bounding Box of Thresholded Object

This guide explains how to isolate an object and extract its bounding box coordinates using ImageMagick directly from the command line. By applying a threshold to create a high-contrast binary mask, you can use ImageMagick's built-in trim property escape codes to output the exact dimensions and offset of the target object without generating intermediate image files.

The Command

To get the bounding box of a thresholded object, use the -format "%@" property combined with info::

magick input.png -threshold 50% -format "%@" info:

(Note: If you are using ImageMagick version 6, replace magick with convert.)

How It Works

  • input.png: The source image you want to evaluate.
  • -threshold 50%: Converts the image into a high-contrast black-and-white mask. Pixels brighter than 50% become white, while darker pixels become black. Adjust this percentage depending on the brightness of your subject relative to the background.
  • -format "%@": The %@ format specifier calculates the minimal bounding box required to trim the image down to its non-background pixels (the ImageMagick "trim bounding box").
  • info:: Instructs ImageMagick to print the formatted metadata directly to standard output (stdout) rather than saving a new file.

Output Format

The command returns the bounding box in standard X11 geometry format:

WIDTHxHEIGHT+X+Y
  • WIDTH: The total pixel width of the bounding box.
  • HEIGHT: The total pixel height of the bounding box.
  • +X: The horizontal offset (in pixels) from the top-left corner of the image to the left edge of the object.
  • +Y: The vertical offset (in pixels) from the top-left corner of the image to the top edge of the object.

Handling Dark Objects on Light Backgrounds

The %@ operator trims away background colors starting from the outer canvas edges. If your target object turns black and the background turns white after thresholding, invert the colors using -negate so the object is treated as the foreground:

magick input.png -threshold 50% -negate -format "%@" info:
