ImageMagick Brightness Standard Deviation Syntax

This guide provides the exact ImageMagick syntax needed to compute the standard deviation of brightness across an entire image. Measuring the standard deviation of brightness is useful for evaluating image contrast, lighting uniformity, and dynamic range in automated image processing pipelines.

The Basic Command

To calculate brightness, the image is converted to a grayscale color space, and the standard deviation property is extracted using the info: output format.

For ImageMagick v7:

magick input.jpg -colorspace Gray -format "%[standard_deviation]" info:

For ImageMagick v6:

convert input.jpg -colorspace Gray -format "%[standard_deviation]" info:

Normalized Standard Deviation (0.0 to 1.0)

The standard %[standard_deviation] escape returns values scaled to your ImageMagick build's quantum depth (e.g., 0 to 65535 for Q16 or 0 to 255 for Q8). To get a normalized floating-point value between 0.0 (completely uniform) and 1.0 (maximum contrast), use the FX expression syntax:

magick input.jpg -colorspace Gray -format "%[fx:standard_deviation]\n" info:

Choosing the Brightness Model

ImageMagick provides different ways to define "brightness":

  1. Perceptual Luminance (Default Grayscale): Uses standard Rec709 luma weighting.

    magick input.jpg -colorspace Gray -format "%[fx:standard_deviation]\n" info:

  2. HSB/HSV Brightness (Value/Max Channel): Measures the standard deviation of the brightest RGB component per pixel.

    magick input.jpg -colorspace HSB -channel 2 -separate -format "%[fx:standard_deviation]\n" info:

  3. HSL Lightness: Measures standard deviation across the lightness channel (average of the highest and lowest RGB components).

    magick input.jpg -colorspace HSL -channel 2 -separate -format "%[fx:standard_deviation]\n" info:

Storing the Result in a Shell Variable

To capture the standard deviation directly into a Bash variable for scripting:

std_dev=$(magick input.jpg -colorspace Gray -format "%[fx:standard_deviation]" info:)
echo "Brightness Standard Deviation: $std_dev"
