ImageMagick Calculate Dynamic Aspect Ratio with FX

This article explains how to determine and utilize the dynamic aspect ratio of an unknown image in ImageMagick using the embedded FX expression parser. By leveraging ImageMagick's internal math engine, you can calculate the ratio of image width to height directly from the command line or within processing pipelines without relying on external scripts or knowing the source image dimensions in advance.

The Basic FX Aspect Ratio Formula

In ImageMagick, the FX engine provides internal symbols for image attributes, where w represents the image width and h represents the image height in pixels. To calculate the dynamic aspect ratio (width divided by height), use the formula expression w/h.

To print the calculated decimal aspect ratio directly to the console, use the %[fx:...] format escape inside the identify or magick command:

magick identify -format "%[fx:w/h]\n" input_image.jpg

For ImageMagick version 6 legacy installations:

identify -format "%[fx:w/h]\n" input_image.jpg

If input_image.jpg has dimensions of 1920x1080, this command dynamically outputs 1.77778.

Rounding and Formatting the Ratio

The FX engine automatically handles floating-point math. If you require a cleaner or rounded value (for example, limiting output to two decimal places), incorporate the round() function:

magick identify -format "%[fx:round((w/h)*100)/100]\n" input_image.jpg

Using the Calculated Ratio in Image Processing

The power of an inline FX formula is its ability to be evaluated dynamically during an image transformation sequence without reading dimensions beforehand.

Storing Dynamic Aspect Ratio as Metadata

You can calculate and store the aspect ratio directly as an internal property or artifact:

magick input_image.jpg -set option:aspect_ratio "%[fx:w/h]" -print "Aspect Ratio: %[aspect_ratio]\n" output.jpg

Conditional Logic Using Aspect Ratio

FX expressions support ternary operators (condition ? true_value : false_value), allowing automated orientation detection:

magick identify -format "%[fx:w/h >= 1 ? 1 : 0]\n" input_image.jpg
  • Returns 1 if the image is landscape or square.
  • Returns 0 if the image is portrait.

Dynamic Canvas Resizing Based on Ratio

You can combine the calculated ratio with dynamic dimensions to expand or crop images automatically. For instance, creating a dynamic proportional border or adjusting canvas bounds:

magick input_image.jpg -resize "%[fx:w]x%[fx:w/(16/9)]^" output.jpg

This inline evaluation calculates target dimensions dynamically from the input file's existing geometry, allowing seamless batch operations across heterogeneous image collections.
