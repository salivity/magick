ImageMagick: Calculate RMSE Between Two Images

Calculating the Root Mean Square Error (RMSE) between two images allows you to quantitatively measure visual differences, compression artifacts, or distortions. This guide demonstrates how to use ImageMagick's built-in comparison tools to compute the RMSE directly from the command line, interpret the resulting metrics, and output the data efficiently without generating unnecessary files.

The Basic RMSE Command

ImageMagick provides the compare tool specifically for calculating differences between two images. To calculate the RMSE, run the command in your terminal using the -metric RMSE flag.

For ImageMagick v7:

magick compare -metric RMSE image1.png image2.png difference.png

For ImageMagick v6:

compare -metric RMSE image1.png image2.png difference.png

This command compares image1.png and image2.png, prints the error value to the standard error stream (stderr), and outputs a visual representation of the differences to difference.png.

Getting the Metric Without Saving an Image

If you only need the numerical RMSE value and do not want to generate a visual difference file, route the output image to null:.

magick compare -metric RMSE image1.png image2.png null:

Understanding the Output

ImageMagick returns the RMSE result in two formats simultaneously:

1452.32 (0.022161)
  1. Absolute Value (First Number): Represents the raw root mean square error based on the Quantum depth of your ImageMagick build (typically 16-bit, ranging from 0 to 65535, or 8-bit, ranging from 0 to 255).
  2. Normalized Value (In Parentheses): Represents the error on a scale from 0.0 to 1.0, where 0.0 means the images are identical and 1.0 means complete inverse disparity.

For most standardized reporting and scripts, the normalized value inside the parentheses is the standard metric used.

Capturing Only the Normalized Value in Scripts

Because ImageMagick prints comparison metrics to stderr rather than stdout, you must redirect the output to capture it in automated scripts.

Bash (Linux/macOS)

rmse=$(magick compare -metric RMSE image1.png image2.png null: 2>&1 | awk -F '[()]' '{print $2}')
echo "Normalized RMSE: $rmse"

Windows (PowerShell)

$output = magick compare -metric RMSE image1.png image2.png null: 2>&1
$rmse = [regex]::Match($output, '\((.*?)\)').Groups[1].Value
Write-Host "Normalized RMSE: $rmse"

Requirements and Considerations

  • Image Dimensions: Both images must have the exact same width and height. If the dimensions differ, ImageMagick will throw an error. Resize or crop the images prior to comparison if necessary.
  • Color Channels: Ensure both images use the same colorspace (such as sRGB) to prevent false-positive error readings caused by color profile mismatches.
