ImageMagick Canny Edge Detector Configuration

ImageMagick provides an implementation of the Canny edge detection algorithm through its -canny command-line operator. This article explains how to configure the operator's geometry parameters—specifically Gaussian radius, sigma, lower threshold, and upper threshold—to accurately extract edges from images while suppressing unwanted noise.

The Canny Operator Syntax

In ImageMagick, the Canny edge detector is invoked using the -canny option followed by a geometry argument formatted as follows:

magick input.jpg -canny {radius}x{sigma}+{lower_percent}%+{upper_percent}% output.png

For ImageMagick version 6, replace magick with convert.

Parameter Breakdown

The parameter string {radius}x{sigma}+{lower}%+{upper}% consists of four distinct values that control the algorithm's multi-stage filtering process:

  1. Radius (radius): The size of the Gaussian blur kernel used to smooth the image before calculating gradients. Setting this value to 0 instructs ImageMagick to calculate an optimal radius automatically based on the sigma value.
  2. Sigma (sigma): The standard deviation of the Gaussian filter. This controls the degree of blur applied to eliminate high-frequency noise. Smaller values (e.g., 0.5 to 1.0) preserve fine details, while larger values (e.g., 2.0 to 5.0) smooth out texture and preserve only major contours.
  3. Lower Threshold (lower%): The lower bound for hysteresis thresholding, defined as a percentage of the maximum gradient magnitude (typically between 0% and 100%). Weak edge pixels are retained only if they are connected to strong edge pixels.
  4. Upper Threshold (upper%): The upper bound for hysteresis thresholding. Any gradient value above this percentage is immediately accepted as a strong edge.

Recommended Configuration Practices

1. Baseline Edge Detection

A balanced configuration for standard photographic images uses an automatic radius, a modest sigma, and a standard 1:3 ratio for the hysteresis thresholds:

magick input.jpg -canny 0x1+10%+30% output.png

2. High-Noise Images

If an image has significant digital grain or background texture, increase sigma to filter the noise, and raise the lower threshold:

magick input.jpg -canny 0x2.5+15%+40% output.png

3. Fine-Detail Extraction

For technical drawings, text, or clean graphics where thin lines must be preserved:

magick input.jpg -canny 0x0.5+5%+15% output.png

Preprocessing and Postprocessing

While the -canny operator can run directly on color images, ImageMagick internally computes gradients based on luminance. You can ensure consistent output by converting the image to grayscale and inverting the output if black lines on a white background are preferred:

magick input.jpg -colorspace Gray -canny 0x1+10%+30% -negate edges_inverted.png
