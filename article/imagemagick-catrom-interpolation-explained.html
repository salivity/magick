ImageMagick Catrom Interpolation Explained

This article explains how ImageMagick calculates intermediate pixel values when using the -interpolate Catrom operator. It covers the underlying mathematical principles of the Catmull-Rom cubic spline, the 4x4 pixel neighborhood sampling mechanism, and the two-dimensional separable calculation process used to determine fractional pixel colors during image transformations.

The Catmull-Rom Spline Basis

ImageMagick's Catrom interpolation implements the Catmull-Rom spline, a specific instance of a cubic Hermite spline. In the generalized Mitchell-Netravali cubic filter family parameterized by \(B\) and \(C\), Catrom sets \(B = 0\) and \(C = 0.5\).

This configuration creates an interpolating spline rather than a smoothing or approximating one. As a result, when an evaluation point falls precisely on an existing integer pixel coordinate, the resulting value matches the original pixel value exactly.

The standard one-dimensional Catmull-Rom weighting function \(W(d)\) evaluates the distance \(d\) from the target sub-pixel coordinate to a neighboring sample:

\[W(d) = \begin{cases} 1.5|d|^3 - 2.5|d|^2 + 1.0 & \text{for } |d| < 1 \\ -0.5|d|^3 + 2.5|d|^2 - 4.0|d| + 2.0 & \text{for } 1 \le |d| < 2 \\ 0 & \text{for } |d| \ge 2 \end{cases}\]

Because \(W(d)\) takes on negative values between \(1\) and \(2\), Catrom retains edge sharpness, though it can introduce subtle ringing artifacts near high-contrast transitions.

Neighborhood Selection

To evaluate an arbitrary floating-point coordinate \((x, y)\), ImageMagick determines the integer floor coordinate:

\[x_1 = \lfloor x \rfloor, \quad y_1 = \lfloor y \rfloor\]

The relative fractional offsets within the grid cell are:

\[u = x - x_1, \quad v = y - y_1\]

Where \(u, v \in [0, 1)\).

Catrom interpolation requires a support radius of 2 pixels in every direction. ImageMagick selects a \(4 \times 4\) grid of surrounding reference pixels spanning \(x \in \{x_1 - 1, x_1, x_1 + 1, x_1 + 2\}\) and \(y \in \{y_1 - 1, y_1, y_1 + 1, y_1 + 2\}\).

The 1D Polynomial Calculation

Along any single axis with four consecutive pixel values \(P_0, P_1, P_2, P_3\) and fractional offset \(t \in [0, 1)\), the interpolated value \(P(t)\) is computed using the standard matrix formulation:

\[P(t) = 0.5 \cdot \begin{bmatrix} 1 & t & t^2 & t^3 \end{bmatrix} \begin{bmatrix} 0 & 2 & 0 & 0 \\ -1 & 0 & 1 & 0 \\ 2 & -5 & 4 & -1 \\ -1 & 3 & -3 & 1 \end{bmatrix} \begin{bmatrix} P_0 \\ P_1 \\ P_2 \\ P_3 \end{bmatrix}\]

Expanding this produces the explicit polynomial:

\[P(t) = P_1 + 0.5 \cdot t \cdot \left( (P_2 - P_0) + t \cdot \left( (2P_0 - 5P_1 + 4P_2 - P_3) + t \cdot (-P_0 + 3P_1 - 3P_2 + P_3) \right) \right)\]

This formulation enforces \(C^1\) continuity, ensuring that both the interpolated values and their first derivatives are continuous across pixel boundaries.

2D Separable Evaluation

ImageMagick extends this operation to two dimensions using separable evaluation:

  1. Row Evaluation: For each of the four rows \(j \in \{-1, 0, 1, 2\}\), ImageMagick extracts the four horizontal neighbors at \(y_1 + j\) and evaluates the 1D Catrom polynomial using horizontal offset \(u\). This produces four intermediate row values: \(R_{-1}, R_0, R_1, R_2\).
  2. Column Evaluation: ImageMagick feeds these four intermediate values into a final 1D Catrom evaluation using vertical offset \(v\).

The final result represents the interpolated color channel value. This procedure is performed independently for every color channel in the image (such as Red, Green, Blue, and Alpha).

Clamping and Boundary Handling

Because Catrom includes negative lobes, the final reconstructed value can exceed the original input range (underflow below 0 or overflow above the quantum limit). ImageMagick clamps the resulting value to the valid range of the image's bit depth (e.g., \([0, 65535]\) for Q16 builds) to prevent color wrapping or inversion. When pixel coordinates fall near image boundaries, ImageMagick consults its defined virtual pixel method (such as edge replication, reflection, or transparent padding) to populate the required \(4 \times 4\) support region.
