ImageMagick: Center Image on a Square Canvas

Centering an image on an exact square canvas is a common requirement for creating standardized product photos, thumbnails, and profile pictures. This guide demonstrates how to use ImageMagick’s -gravity and -extent operators to position any image directly into the center of a square canvas without cropping the contents or distorting the original aspect ratio.

The Basic Command

To place an image onto a fixed-size square canvas (for example, 1000x1000 pixels), use the following syntax:

ImageMagick v7:

magick input.jpg -background white -gravity center -extent 1000x1000 output.jpg

ImageMagick v6:

convert input.jpg -background white -gravity center -extent 1000x1000 output.jpg

How the Parameters Work

The order of the arguments is critical to achieve the correct result:

  1. -background <color>: Specifies the color used to fill the empty space added around the original image. You can specify named colors like white or black, hex codes like "#ffffff", or none/transparent if working with formats that support transparency (such as PNG).
  2. -gravity center: Defines the anchor point for positioning the source image. Setting this to center ensures that equal padding is distributed to the top and bottom or left and right sides.
  3. -extent <width>x<height>: Changes the canvas size to the specified dimensions without scaling or distorting the original pixels. Because -gravity center precedes this flag, the image remains centered within the new bounds.

Creating an Automatic Square Based on the Largest Dimension

If you want to create a square canvas without hardcoding specific pixel values, you can use ImageMagick 7’s built-in FX expressions to calculate the largest side automatically:

magick input.jpg -background white -gravity center -extent "%[fx:max(w,h)]x%[fx:max(w,h)]" output.jpg

In this command:

  • w represents the input image's original width.
  • h represents the input image's original height.
  • max(w,h) identifies whichever side is longer and sets both the canvas width and height to that value, resulting in a perfect square matched to the source image's largest dimension.

Scaling Down to Fit Before Centering

If the input image is larger than the target square dimensions, scale it down first using -resize while preserving its aspect ratio, then apply the canvas extent:

magick input.jpg -resize 1000x1000 -background white -gravity center -extent 1000x1000 output.jpg

The -resize 1000x1000 argument shrinks the image so its longest edge fits within 1000 pixels, and -extent 1000x1000 pads the shorter edge to complete the square.
