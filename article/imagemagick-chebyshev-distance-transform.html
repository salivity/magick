ImageMagick Chebyshev Distance Transform

This guide explains how to calculate and apply a Chebyshev distance transform using ImageMagick's built-in morphology operators. You will learn the exact command-line syntax required to generate this transform, how the Chebyshev metric evaluates spatial relationships on a pixel grid, and how to properly prepare your input masks and scale the output values for visualization.

Understanding the Chebyshev Distance

The Chebyshev distance, also known as chessboard distance or the \(L_\infty\) metric, measures the distance between two points as the greatest difference along any coordinate dimension:

\[\text{Distance} = \max(|x_1 - x_2|, |y_1 - y_2|)\]

In digital image processing, this corresponds to an 8-connected grid where diagonal steps cost the same as horizontal or vertical steps. Applying this transform to a binary shape produces square-shaped contour rings expanding outward or inward from the boundary.

Prerequisites for Input Images

ImageMagick's distance morphology expects a high-contrast or binary image. By default:

  • The foreground (features of interest) should be white (#FFFFFF).
  • The background (the boundaries from which distance is measured) should be black (#000000).

If your image is not already binary, convert it to grayscale and threshold it before running the transform.

Basic Command Syntax

In ImageMagick 7, use the magick command (or convert in ImageMagick 6) with the -morphology operator set to Distance and the kernel set to Chebyshev.

magick input.png -colorspace Gray -threshold 50% -morphology Distance Chebyshev output.png

This command converts the source image to binary format and calculates the Chebyshev distance of every white pixel to the nearest black pixel.

Normalizing the Output for Visualization

Because raw distance values correspond directly to pixel units, a pixel 10 units away from the edge has a value of 10. In an 8-bit or 16-bit image, these raw values often appear completely black or very dark.

To stretch the gradient across the full dynamic range for visual inspection, append the -auto-level operator:

magick input.png -colorspace Gray -threshold 50% -morphology Distance Chebyshev -auto-level output_visual.png

Inverting Foreground and Background

If you need to measure the distance from the outside of an object toward its boundary (external distance transform), invert the binary mask using -negate before applying the morphology operator:

magick input.png -colorspace Gray -threshold 50% -negate -morphology Distance Chebyshev -auto-level output_external.png

Scaling and Customizing the Kernel

You can control how distances are scaled during calculation by providing parameters to the kernel definition. The syntax follows Chebyshev:radius[,scale]:

magick input.png -morphology Distance "Chebyshev:1,10" scaled_distance.png

In this command, each distance unit is multiplied by 10 before being written to the output, allowing you to tailor numerical outputs directly for specific computational pipelines.
