ImageMagick Checkerboard Pattern Syntax

This guide explains the command-line syntax required to generate a checkerboard background canvas using ImageMagick's built-in patterns. You will learn the primary commands for both ImageMagick 7 and ImageMagick 6, as well as how to specify canvas dimensions and customize the colors of the squares.

Basic Syntax for ImageMagick 7

In ImageMagick 7, the magick command uses the internal pattern:checkerboard delegate to generate the pattern. You must define the canvas size using the -size flag prior to calling the pattern.

magick -size 300x300 pattern:checkerboard output.png

Syntax for ImageMagick 6

If you are using legacy ImageMagick 6, use the convert command instead of magick:

convert -size 300x300 pattern:checkerboard output.png

Customizing Checkerboard Colors

By default, pattern:checkerboard renders in black and white with 8x8 pixel tiles. To alter the default colors, map new values using the +level-colors operator directly after generating the pattern.

The syntax assigns the first color to the dark squares and the second color to the light squares:

magick -size 400x400 pattern:checkerboard +level-colors "#e0e0e0","#ffffff" checkerboard.png

Using the Checkerboard as a Background for Other Images

To overlay a transparent image onto a generated checkerboard canvas, create the checkerboard pattern first, load your foreground image, and composite them together:

magick -size 500x500 pattern:checkerboard +level-colors gray80,white transparent_image.png -composite final_render.png
