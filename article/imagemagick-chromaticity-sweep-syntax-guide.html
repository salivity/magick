ImageMagick Chromaticity Sweep Syntax Guide

This guide provides the exact ImageMagick syntax to generate a full chromaticity sweep image. You will learn the commands required to produce both rectangular 2D chromaticity maps (varying hue and saturation) and radial polar color sweeps using ImageMagick's built-in gradient and colorspace transformation tools.

Rectangular Chromaticity Sweep (Hue vs. Saturation)

The most direct way to generate a 2D rectangular chromaticity sweep—where the horizontal axis represents Hue (\(0^\circ\) to \(360^\circ\)) and the vertical axis represents Saturation (\(100\%\) to \(0\%\)) at a constant lightness—is using the -fx operator.

Syntax:

magick -size 360x200 xc: -fx "hsl(i/w, 1.0 - j/h, 0.5)" chromaticity_sweep.png

Explanation of Parameters:

  • -size 360x200: Defines the output dimensions (width \(\times\) height in pixels). A width of 360 conveniently maps to 360 degrees of hue.
  • xc:: Creates a blank canvas to be evaluated.
  • -fx "hsl(i/w, 1.0 - j/h, 0.5)": Computes color values per pixel:
    • i/w: Normalizes the horizontal pixel coordinate (\(x\)) from \(0.0\) to \(1.0\) to sweep across all hues.
    • 1.0 - j/h: Normalizes the vertical pixel coordinate (\(y\)) so saturation is \(1.0\) (fully saturated) at the top and \(0.0\) (neutral gray) at the bottom.
    • 0.5: Sets constant 50% lightness across the entire sweep.

High-Performance Method (Channel Combination)

For generating high-resolution sweeps without the performance overhead of the -fx interpreter, you can combine linear gradient channels directly in the HSL colorspace.

Syntax:

magick \( -size 200x360 gradient: -rotate 90 \) \
       \( -size 360x200 gradient:white-black \) \
       \( -size 360x200 xc:gray50 \) \
       -set colorspace HSL -combine -colorspace sRGB chromaticity_sweep.png

Explanation of Steps:

  1. Hue Channel (Red channel in HSL): Creates a horizontal gradient from \(0\) to full scale.
  2. Saturation Channel (Green channel in HSL): Creates a vertical gradient from full saturation (white) to zero saturation (black).
  3. Lightness Channel (Blue channel in HSL): Creates a uniform mid-tone plane (gray50).
  4. -set colorspace HSL -combine: Merges the three separate grayscale images into a single image treated as HSL channels.
  5. -colorspace sRGB: Converts the resulting HSL image back to standard sRGB for proper display and export.

Polar / Circular Chromaticity Sweep (Color Wheel)

If you require a circular chromaticity diagram where hue sweeps around an angle and saturation increases radially from the center outward, use the -distort Arc operator on a horizontal gradient.

Syntax:

magick -size 300x300 gradient: -rotate 90 \
       \( -size 300x300 gradient:black-white \) \
       \( -size 300x300 xc:gray50 \) \
       -set colorspace HSL -combine -colorspace sRGB \
       -virtual-pixel White -distort Arc "360 0 150 0" \
       chromaticity_wheel.png

Explanation of Parameters:

  • -distort Arc "360 0 150 0": Warps the rectangular hue and saturation mapping into a complete \(360^\circ\) arc with an outer radius of 150 pixels.
  • -virtual-pixel White: Fills the canvas area outside the circular sweep with a white background.
