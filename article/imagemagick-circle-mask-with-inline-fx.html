ImageMagick Circle Mask With Inline FX

This article provides a concise guide to generating a mathematical circle mask dynamically using ImageMagick's inline -fx operator. It explains the exact command syntax, breaks down the underlying mathematical formula, and demonstrates how to adjust dimensions, coordinates, and edge feathering to create custom binary or anti-aliased circular masks directly from the command line.

Basic Syntax for a Circular Mask

To generate a black-and-white circle mask from scratch, initialize a blank canvas with -size and apply the mathematical circle equation using -fx:

magick -size 500x500 xc:black -fx "hypot(i - w/2, j - h/2) <= (min(w,h)/2) ? 1 : 0" circle_mask.png

(Note: In ImageMagick 6, replace magick with convert.)

Syntax Breakdown

The -fx option evaluates mathematical expressions per pixel across the canvas:

  • i and j: Represent the zero-based horizontal (\(x\)) and vertical (\(y\)) coordinates of the current pixel.
  • w and h: Represent the total width and height of the image canvas.
  • w/2 and h/2: Define the center origin of the circle.
  • hypot(dx, dy): Computes the Euclidean distance \(\sqrt{dx^2 + dy^2}\) from the center \((w/2, h/2)\) to the target pixel \((i, j)\).
  • min(w,h)/2: Calculates the maximum radius that fits within the canvas dimensions.
  • ? 1 : 0: A ternary conditional operator. If the distance from the center is less than or equal to the radius, the pixel value is set to 1 (white); otherwise, it is set to 0 (black).

Alternative Algebraic Formula

If you prefer explicit polynomial math without the hypot function, the equation of a circle \((x - x_0)^2 + (y - y_0)^2 \le r^2\) can be expressed as:

magick -size 500x500 xc:black -fx "(i - w/2)^2 + (j - h/2)^2 <= (w/2)^2 ? 1 : 0" circle_mask.png

Creating an Anti-Aliased (Soft-Edged) Circle Mask

Strict binary evaluation produces aliased, jagged edges. You can introduce a smooth transition by using an interpolation range across the boundary edge:

magick -size 500x500 xc:black -fx "r=w/2; d=hypot(i-w/2, j-h/2); clamp((r - d + 0.5))" soft_circle_mask.png

In this syntax:

  • r=w/2; assigns the target radius to variable r.
  • d=hypot(...) stores the pixel distance.
  • clamp((r - d + 0.5)) blends the pixel values between 0 and 1 across a one-pixel transition boundary to create smooth anti-aliased edges.

Applying the Mask Directly to an Image

To apply the generated mask directly to an existing image without saving intermediate files, read the image, clone it to define the mask dimensions, generate the alpha mask with -fx, and compose it:

magick input.jpg \( +clone -fx "hypot(i - w/2, j - h/2) <= (min(w,h)/2) ? 1 : 0" \) -alpha off -compose CopyOpacity -composite output.png
