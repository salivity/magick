ImageMagick -clut vs -hald-clut for Color Grading

Color grading in ImageMagick relies heavily on lookup tables, with -clut and -hald-clut serving as the two primary operators for applying color transformations. While both operators replace original colors with values defined in an external reference image, they differ fundamentally in dimensionality, precision, and practical application. This article explains the technical differences between 1D and 3D color mapping in ImageMagick, details how each operator functions, and outlines when to use each for digital image processing.

Understanding the -clut Operator

The -clut (Color Look-Up Table) operator performs a one-dimensional color transformation. It typically maps an image's pixel values against a single-dimensional gradient strip.

When you apply -clut, ImageMagick evaluates the intensity (luminance) or the individual color channel values of the target image and matches them to the corresponding position along the lookup table image.

  • Dimensionality: 1D mapping. Each channel or the overall luminance is mapped independently along a linear axis.
  • Input Lookup Format: Usually a thin image strip (such as 256x1 or 1x256 pixels) containing a color gradient.
  • Behavior: If applied across all channels simultaneously, it maps lightness directly to the gradient. If channels are separated, it maps individual red, green, and blue values along the gradient.

Because -clut maps colors linearly or per-channel in isolation, it cannot account for complex inter-channel relationships, such as shifting a specific hue while leaving other colors at the same luminance untouched.

Understanding the -hald-clut Operator

The -hald-clut operator performs a three-dimensional color transformation. It is ImageMagick’s implementation of a 3D LUT (Look-Up Table), encoded into a 2D matrix known as a Hald image.

A Hald image represents an entire 3D color cube (RGB space) flattened into a 2D grid. When using -hald-clut, ImageMagick reads the red, green, and blue values of a source pixel simultaneously, locates the exact coordinate inside the 3D color cube, and replaces it with the corresponding graded output color.

  • Dimensionality: 3D mapping. Colors are evaluated as coordinates in a 3D volume rather than isolated channels.
  • Input Lookup Format: A square Hald pattern (e.g., hald:8 generates a 512x512 pixel image representing an 8-bit color cube).
  • Behavior: Enables selective adjustments such as hue shifts, split toning, saturation changes based on luminance, and complex photographic film emulations.

Key Differences

Feature -clut -hald-clut
LUT Type 1D LUT 3D LUT
Color Complexity Simple linear mapping and tinting Non-linear, complex multi-channel grading
Reference File 1D color gradient 2D matrix representing a 3D cube (Hald)
Channel Independence Channels are mapped independently or to luminance Channels are mapped as interconnected 3D coordinates
Primary Use Cases Duotones, false color, heatmaps, gradient maps Film emulation, creative color grading, LUT conversion

Workflow Differences in Color Grading

The workflow for creating and applying each lookup table differs significantly based on the desired output.

Workflow with -clut

Using -clut is best suited for tonal mapping, such as creating thermal imagery, duotones, or mapping contrast curves.

  1. Create a 1D gradient representing the color spectrum you want to apply.
  2. Run the command: 
    magick input.jpg gradient.png -clut output.jpg

This maps the shadows, midtones, and highlights of input.jpg directly to the colors defined in gradient.png.

Workflow with -hald-clut

Using -hald-clut is the industry standard approach for replicating complex visual grades generated in software like Adobe Photoshop, Lightroom, or DaVinci Resolve.

  1. Generate a neutral Hald image using ImageMagick: 
    magick hald:8 neutral_hald.png
  2. Open neutral_hald.png in your preferred image editor.
  3. Apply any combination of color adjustments (curves, selective color, saturation, LUTs) to the Hald image and export it as graded_hald.png.
  4. Apply the exact transformation to your target image: 
    magick input.jpg graded_hald.png -hald-clut output.jpg

When to Use Which

Use -clut when you need simple color replacement based purely on brightness, such as creating false-color scientific visualizations, gradient maps, or vintage monochrome duotones.

Use -hald-clut for comprehensive, modern color grading. Because it captures complex color interactions across all three RGB dimensions, -hald-clut allows you to transfer professional photographic grades and film looks accurately without color distortion.
