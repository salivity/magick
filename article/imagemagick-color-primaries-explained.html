ImageMagick Color Primaries Explained

This guide explains how the -red-primary, -green-primary, and -blue-primary options function within ImageMagick. These command-line settings establish the chromaticity coordinates for an image's red, green, and blue color channels, transforming raw, device-dependent RGB numbers into calibrated, physically meaningful colors in a standardized color space.

Establishing Chromaticity Coordinates

In digital imaging, raw RGB values are merely relative intensity levels (typically ranging from 0 to 255 or 0 to 65535). Without a specified color profile or coordinate system, an RGB value of (255, 0, 0) does not correspond to a defined shade of red in the physical world.

The -red-primary, -green-primary, and -blue-primary options define the exact chromaticity coordinates of the red, green, and blue color emitters or reference points in the standard CIE 1931 xy color space.

Each option takes an x,y coordinate pair as its parameter:

magick input.raw -red-primary 0.64,0.33 -green-primary 0.30,0.60 -blue-primary 0.15,0.06 output.png

Defining the Color Gamut

Together, these three coordinates define the boundaries of the image's color gamut—the entire range of colors that the RGB system can reproduce:

  • Vertices of the Gamut Triangle: On the CIE 1931 chromaticity diagram, the red, green, and blue primaries form the three vertices of a triangle. Any color the image can represent must fall within the area enclosed by these points.
  • Anchor for Raw Data: When processing raw or headerless pixel data, setting these values explicitly tells ImageMagick where the edges of the color space reside, preventing color shifts during subsequent processing.
  • White Point Interaction: While the primaries define the outer boundaries, they are typically paired with the -white-point <x,y> option. Together, the three primaries and the white point fully define an absolute RGB color space (such as sRGB, Adobe RGB, or DCI-P3).

Metadata and Output File Integration

When applied to an image, ImageMagick uses these options in two ways:

  1. Color Transformations: If converting an image to another color space or format, ImageMagick uses these coordinates to calculate the mathematical matrix required to translate the raw RGB data into a device-independent color model like CIE XYZ or LAB.
  2. Metadata Tagging: For file formats that support explicit chromaticity metadata—such as the cHRM chunk in PNG files or the PrimaryChromaticities tag in TIFF files—these options populate those tags directly. This ensures downstream applications can correctly interpret the color gamut without embedding a complete ICC color profile.
