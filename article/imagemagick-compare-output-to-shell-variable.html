ImageMagick Compare Output to Shell Variable

This article demonstrates how to extract numerical comparison metrics between two images using ImageMagick and assign that result directly to a shell variable without creating a difference image file. By redirecting the output image to a null sink and capturing standard error, you can efficiently automate image regression tests and difference checks entirely in memory.

The Challenge

By default, the ImageMagick compare command requires an output image argument to draw a visual difference map. Additionally, ImageMagick prints the calculated metric to standard error (stderr) rather than standard output (stdout).

To store the numerical score directly into a shell variable without saving unwanted image files to your disk, you must:

  1. Direct the visual difference output to the null: sink.
  2. Redirect standard error (2>&1) to standard output so shell command substitution can capture it.

Basic Syntax

In Bash, Zsh, or POSIX-compliant shells, capture the metric directly using command substitution:

# ImageMagick v7
METRIC_VAL=$(magick compare -metric RMSE image1.png image2.png null: 2>&1)

# ImageMagick v6
METRIC_VAL=$(compare -metric RMSE image1.png image2.png null: 2>&1)

Explanation of Arguments:

  • -metric RMSE: Specifies the metric to calculate (options include AE, MAE, MSE, RMSE, PAE, PSNR, SSIM).
  • image1.png image2.png: The reference image and the comparison image.
  • null:: ImageMagick's built-in target that discards the generated difference image instead of writing to disk.
  • 2>&1: Redirects stderr to stdout, allowing $() to capture the printed value.

Handling Formats and Parsing Output

Different metrics return different string formats:

1. Absolute Error (AE)

The AE metric returns a single integer representing the exact count of different pixels:

PIXEL_DIFF=$(magick compare -metric AE image1.png image2.png null: 2>&1)
echo "Different pixels: $PIXEL_DIFF"

2. Root Mean Squared Error (RMSE)

The RMSE metric returns both the raw value and the normalized value in parentheses, such as 1285.3 (0.0196126). To isolate only the normalized float value:

# Extract the normalized value inside parentheses
NORMALIZED_RMSE=$(magick compare -metric RMSE image1.png image2.png null: 2>&1 | awk -F '[()]' '{print $2}')
echo "Normalized RMSE: $NORMALIZED_RMSE"

To isolate only the raw value before the parentheses:

RAW_RMSE=$(magick compare -metric RMSE image1.png image2.png null: 2>&1 | awk '{print $1}')
echo "Raw RMSE: $RAW_RMSE"

Conditional Logic Example

You can use the captured variable in shell scripts to automate threshold validation:

#!/bin/bash

IMG1="baseline.png"
IMG2="current.png"
THRESHOLD=0.05

# Get the normalized RMSE value
DIFF=$(magick compare -metric RMSE "$IMG1" "$IMG2" null: 2>&1 | awk -F '[()]' '{print $2}')

# Compare floating-point numbers using bc
IS_OVER_THRESHOLD=$(echo "$DIFF > $THRESHOLD" | bc -l)

if [ "$IS_OVER_THRESHOLD" -eq 1 ]; then
    echo "Image check failed: Difference ($DIFF) exceeds threshold ($THRESHOLD)"
    exit 1
else
    echo "Image check passed: Difference ($DIFF) is within tolerance."
    exit 0
fi
