ImageMagick Conjure Command and MSL Guide

The ImageMagick conjure command-line utility is specifically designed to execute image processing tasks written in Magick Scripting Language (MSL). This guide explains the purpose of conjure, how it interprets MSL scripts, and how developers and system administrators use it to automate complex, multi-step graphic manipulation workflows.

What is the Conjure Command?

In the ImageMagick suite, conjure serves as an interpreter for MSL scripts. While standard ImageMagick commands like magick, convert, or mogrify rely on long command-line arguments and flags, conjure delegates the processing logic to an external script file.

The basic syntax for running an MSL script is:

conjure script.msl

Understanding Magick Scripting Language (MSL)

Magick Scripting Language (MSL) is an XML-based language designed to describe image creation, modification, and conversion pipelines. Instead of chaining dozens of command-line flags together, operations are defined declaratively using XML tags.

An MSL document typically contains:

  • Root tags like <image> or <group> to encapsulate the task.
  • Input instructions such as <read filename="input.jpg"/>.
  • Transformation operations such as <resize geometry="800x600"/>, <rotate degrees="90"/>, or <blur radius="0" sigma="3"/>.
  • Output instructions such as <write filename="output.png"/>.

Key Capabilities of Conjure and MSL

  1. Structured and Maintainable Workflows
    Complex transformations that involve multiple layers, compositions, masking, and format conversions can become unreadable when written as a single CLI command. MSL scripts organize these operations into a structured, readable hierarchy that is easy to version control and maintain.

  2. Dynamic Variable Substitution
    The conjure command supports variable passing from the command line using the -define option. This allows static MSL templates to accept dynamic inputs at runtime:

    conjure -define width=1200 -define input=photo.jpg process.msl

    Inside the MSL script, variables are referenced using the get attribute (e.g., geometry="%[width]x").

  3. Multi-Image Batch Processing
    A single MSL script executed by conjure can load multiple source images, apply independent processing steps to each, combine or composite them, and output multiple resulting files in different formats simultaneously.

  4. Programmatic Generation
    Because MSL is standard XML, backend applications written in languages like Python, PHP, or Node.js can easily generate MSL files dynamically and invoke conjure to render the final assets.

Summary

The conjure command is ImageMagick's dedicated XML script runner. By pairing conjure with Magick Scripting Language (MSL), users can replace fragile, lengthy shell commands with robust, reusable, and parameter-driven image processing templates.
