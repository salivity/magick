ImageMagick Connected Components Binary Mask Syntax

This guide explains the syntax and methods for creating binary object masks using ImageMagick’s connected-components labeling algorithm. It covers the core command structure, key configuration options for filtering artifacts, and practical examples to extract clean binary foreground masks from images.

Basic Syntax

In ImageMagick (version 7), the standard syntax for creating a binary object mask is:

magick input.png -threshold 50% \
  -define connected-components:area-threshold=100 \
  -define connected-components:mean-color=true \
  -connected-components 8 \
  output_mask.png

For ImageMagick version 6, replace magick with convert.

Parameter Breakdown

  • -threshold <value>%: Prepares the image by converting it into high-contrast binary data (black and white). This ensures connected components are evaluated purely as foreground and background objects.
  • -define connected-components:area-threshold=<pixels>: Suppresses any connected component with a total pixel area smaller than the specified value. The pixels of removed regions are merged into the surrounding background.
  • -define connected-components:mean-color=true: Replaces the pixel values of each detected component with the mean color of that component. When used on a thresholded image, this keeps the surviving objects pure white (#FFFFFF) and the background pure black (#000000), outputting a valid binary mask.
  • -connected-components <4|8>: Executes the labeling algorithm. Use 4 to check only orthogonal neighbors (up, down, left, right) or 8 to check orthogonal and diagonal neighbors.

Advanced Masking Options

1. Removing Background Holes (Morphology Cleanup)

To remove small black holes inside larger white objects while creating the mask:

magick input.png -threshold 50% \
  -define connected-components:area-threshold=200 \
  -define connected-components:mean-color=true \
  -connected-components 8 \
  -negate \
  -define connected-components:area-threshold=50 \
  -define connected-components:mean-color=true \
  -connected-components 8 \
  -negate \
  mask.png

2. Inspecting Component Data

To see the bounding boxes, centroids, and area sizes of detected components in the console while generating the mask, add the verbose directive:

magick input.png -threshold 50% \
  -define connected-components:verbose=true \
  -define connected-components:area-threshold=50 \
  -define connected-components:mean-color=true \
  -connected-components 8 \
  mask.png
