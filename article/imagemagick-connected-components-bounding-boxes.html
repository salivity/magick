ImageMagick Connected Components Bounding Boxes

This guide covers the syntax and commands required to calculate image bounding boxes using ImageMagick's connected-components labeling feature. By analyzing pixel connectivity, ImageMagick can identify distinct objects within an image and output their geometric dimensions, offsets, areas, and centroid coordinates.

Basic Syntax

To extract bounding box data, combine the -connected-components operator with the verbose output definition. Directing the output to null: prevents writing an unnecessary output image file.

magick input.png -define connected-components:verbose=true -connected-components 8 null:

Note: For ImageMagick version 6, replace magick with convert.

Command Options and Parameters

ImageMagick provides several -define options to control how objects are analyzed and reported:

  • Connectivity (4 or 8): The integer passed to -connected-components defines pixel neighbors.
    • 4: Analyzes adjacent pixels (top, bottom, left, right).
    • 8: Analyzes adjacent and diagonal pixels.
  • -define connected-components:verbose=true: Prints the text report containing component IDs, bounding box geometries, centroids, areas, and mean colors to standard output.
  • -define connected-components:area-threshold=<value>: Excludes objects smaller than the specified pixel count to eliminate noise.
  • -define connected-components:mean-color=true: Replaces the color of each labeled region with its mean color (useful when outputting an image visualization).

Practical Example

To find bounding boxes while filtering out noise smaller than 100 pixels:

magick objects.png \
  -define connected-components:verbose=true \
  -define connected-components:area-threshold=100 \
  -connected-components 8 \
  null:

Understanding the Output

The verbose flag outputs a structured table. A typical output row looks like this:

Objects (id: box centroid area mean-color):
  0: 500x400+0+0 249.5,199.5 200000 srgb(0,0,0)
  1: 64x64+120+45 151.5,76.5 4096 srgb(255,255,255)

The fields are defined as follows:

  • id: The index assigned to the detected component (ID 0 is usually the background).
  • box: The bounding box geometry formatted as WIDTHxHEIGHT+X+Y, where WIDTH and HEIGHT represent the dimensions, and +X+Y represents the top-left coordinate.
  • centroid: The center coordinate (X,Y) of the object.
  • area: The total count of pixels contained within the object.
  • mean-color: The average color of the component.
