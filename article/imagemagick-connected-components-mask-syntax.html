ImageMagick Connected Components Mask Syntax

ImageMagick's -connected-components operator performs Connected Component Analysis (CCA) to uniquely label and segment discrete regions within an image. This guide outlines the required command-line syntax, configuration defines, and practical examples for generating distinct segmented object masks and filtering noise.

Basic Syntax

To generate a segmented mask from an image, the basic ImageMagick v7 syntax is:

magick input.png -threshold 50% -define connected-components:verbose=true -define connected-components:mean-color=true -connected-components 8 output_mask.png

For ImageMagick v6, replace magick with convert.

Syntax Components and Options

Generating masks relies on binarization, defining CCA parameters, and executing the operator:

  • Preprocessing (-threshold <value> or -negate): CCA works best on binary (black and white) or grayscale images. Objects of interest should ideally be white (foreground) on a black background.
  • Connectivity (-connected-components <4|8>): Specifies neighbor pixel connectivity. Use 4 for orthogonal neighbors (up, down, left, right) or 8 to include diagonal neighbors.
  • -define connected-components:verbose=true: Outputs component metadata to the terminal, including object ID, bounding box dimensions, centroid, pixel area, and color value.
  • -define connected-components:mean-color=true: Replaces each detected connected component with its average color, generating a segmented visual mask where distinct objects receive distinct shades.
  • -define connected-components:area-threshold=<pixels>: Removes objects smaller than the specified pixel count, merging them into the surrounding background to eliminate noise.

Common Mask Generation Examples

1. Distinct Gray-Level Segmented Mask

To generate an image where every connected object is labeled with a distinct grayscale value:

magick input.png \
  -colorspace gray \
  -threshold 50% \
  -define connected-components:mean-color=true \
  -connected-components 8 \
  -auto-level \
  segmented_mask.png

Note: -auto-level stretches the gray values across the full 0–100% range to make distinct segments visually visible.

2. Filtering Small Noise Objects

To segment foreground objects while ignoring artifacts smaller than 100 pixels:

magick input.png \
  -threshold 50% \
  -define connected-components:area-threshold=100 \
  -define connected-components:mean-color=true \
  -connected-components 8 \
  clean_mask.png

3. Extracting a Specific Segment Mask

When verbose mode outputs object IDs, individual components can be isolated into a binary mask by matching their specific grayscale intensity:

magick input.png \
  -threshold 50% \
  -define connected-components:verbose=true \
  -define connected-components:keep-ids=2,4 \
  -connected-components 8 \
  isolated_objects_mask.png

The keep-ids define keeps only the objects matching the provided IDs (available in ImageMagick 7.0.8-68+), rendering everything else black.
