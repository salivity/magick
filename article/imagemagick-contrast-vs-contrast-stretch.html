ImageMagick -contrast vs -contrast-stretch

ImageMagick provides multiple methods for enhancing the tonal range of an image, most notably through the -contrast and -contrast-stretch operators. While both commands increase the visual distinction between light and dark areas, they operate on completely different mathematical principles. The -contrast operator applies a non-linear S-curve adjustment to midtones without clipping dynamic range, whereas -contrast-stretch performs a histogram stretch that expands the tonal range across the entire spectrum by intentionally clipping specified thresholds of shadow and highlight pixels.

The -contrast Command

The -contrast operator alters the intensity values of an image using a fixed, non-linear S-curve centered on the midtones.

  • Mechanism: It brightens pixels that are already above 50% brightness and darkens pixels that are below 50% brightness.
  • Dynamic Range & Clipping: It does not change the absolute minimum (black) or maximum (white) data limits, meaning it preserves highlight and shadow details without hard clipping.
  • Parameters: The command takes no direct numerical arguments. To increase contrast further, you repeat the flag in the command chain (e.g., -contrast -contrast). To reduce contrast, ImageMagick uses the inverse operator +contrast.
# Increase contrast using a non-linear curve
magick input.jpg -contrast output.jpg

# Decrease contrast
magick input.jpg +contrast output.jpg

The -contrast-stretch Command

The -contrast-stretch operator adjusts contrast by analyzing the image histogram, clipping a defined amount of the darkest and brightest pixels, and linearly stretching the remaining values across the full dynamic range (from 0 to maximum intensity).

  • Mechanism: It creates a cumulative histogram to find the intensity thresholds corresponding to your specified black and white points, forces everything outside those bounds to pure black and pure white, and linearly scales the intermediate levels.
  • Dynamic Range & Clipping: It alters the absolute minimum and maximum values, effectively maximizing the image's dynamic range at the expense of clipping detail in extreme shadows and highlights.
  • Parameters: It requires arguments in the format black-point x white-point, which can be specified in absolute pixel counts or percentages (e.g., 0.15x0.05% or 1000x1000).
# Stretch contrast by clipping 1% of dark pixels and 1% of light pixels
magick input.jpg -contrast-stretch 1%x1% output.jpg

# Stretch contrast by clipping 500 dark pixels and 500 light pixels
magick input.jpg -contrast-stretch 500x500 output.jpg

Key Differences

Feature -contrast -contrast-stretch
Algorithm Non-linear S-curve midtone adjustment Linear histogram remapping with clipping
Pixel Clipping None (preserves shadow/highlight detail) Yes (forces extreme values to pure black/white)
Parameters None (can be repeated or inverted with +) Requires black-point x white-point (counts or %)
Dynamic Range Preserves existing tonal boundaries Expands values across the entire 0–100% range

When to Use Each

  • Use -contrast when you need subtle tonal enhancements on well-exposed images where you cannot afford to blow out highlights or crush shadow details.
  • Use -contrast-stretch when dealing with washed-out photos, flat document scans, or images with poor dynamic range where the darks are not fully black and the lights are not fully white.
