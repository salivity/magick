ImageMagick Cosine Transform on Luminance

This article provides the exact command-line syntax and process for computing a Forward Discrete Cosine Transform (DCT) on image pixel luminances using ImageMagick. It covers extracting the luminance component, applying the DCT operator, saving frequency coefficients, and reconstructing the image using the inverse transform.

Basic Syntax

To compute the Discrete Cosine Transform on the luminance of an image, use the magick command (ImageMagick 7) or convert (ImageMagick 6) with the -colorspace Gray and -dct options:

magick input.jpg -colorspace Gray -dct output_dct.png

Step-by-Step Command Breakdown

  1. input.jpg: Specifies the source image.
  2. -colorspace Gray (or -grayscale Rec709Luminance): Converts the input into a single-channel grayscale representation based on standard luminance weights.
  3. -dct: Computes the Forward Discrete Cosine Transform, converting the spatial luminance data into frequency coefficients.
  4. output_dct.png: Specifies the output file to store the resulting frequency image.

Recommended Syntax for High Dynamic Range (HDRI)

DCT coefficients include negative and high-magnitude floating-point values that standard 8-bit integer formats (such as JPEG or standard PNG) will clip or quantize. To preserve precision, export to a floating-point format such as PFM, EXR, or MIFF using an HDRI-enabled build of ImageMagick:

magick input.jpg -grayscale Rec709Luminance -dct output_dct.pfm

Inverse Discrete Cosine Transform Syntax

To convert the DCT frequency data back into spatial luminance values, use the +dct operator:

magick output_dct.pfm +dct reconstructed.png
