ImageMagick Cross Dissolve Frame Sequence Syntax

This guide explains how to generate a smooth cross-dissolve frame sequence between two or more images using ImageMagick. By utilizing the -morph operator, ImageMagick interpolates pixel values across a specified number of intermediate steps, outputting sequentially numbered image files ready for video encoding or animation.

Basic Syntax

The primary operator for creating a cross-dissolve sequence in ImageMagick is -morph.

For ImageMagick v7:

magick image1.jpg image2.jpg -morph <frame_count> frame_%04d.png

For ImageMagick v6:

convert image1.jpg image2.jpg -morph <frame_count> frame_%04d.png

Parameter Breakdown

  • image1.jpg image2.jpg: The input source and target images. They should have identical dimensions and color spaces for optimal results.
  • -morph <frame_count>: Specifies the number of intermediate transition frames to generate between the input images.
  • frame_%04d.png: The output filename pattern. %04d generates zero-padded numerical sequences (e.g., frame_0000.png, frame_0001.png), which is standard for video frame sequences.

Practical Examples

Generating a 30-Frame Dissolve Sequence

To create a 1-second transition at 30 fps between two 1920x1080 images:

magick start.png end.png -resize 1920x1080^ -gravity center -extent 1920x1080 -morph 28 frame_%03d.png

Note: Setting -morph 28 alongside the 2 input images yields a total sequence of 30 frames (input 1 + 28 generated frames + input 2).

Multi-Image Transitions

You can chain multiple images in a single command. The -morph command will generate the specified number of transition frames between each pair in the sequence:

magick scene1.jpg scene2.jpg scene3.jpg scene4.jpg -morph 15 sequence_%04d.jpg

This generates 15 intermediate frames between scene1 and scene2, 15 between scene2 and scene3, and 15 between scene3 and scene4.

Alternative Manual Blend Syntax

If you require non-linear easing curves instead of the linear interpolation provided by -morph, use the -blend operator with explicit percentages inside a shell loop:

for i in $(seq 0 5 100); do
  magick composite -blend ${i}% image2.png image1.png $(printf "frame_%03d.png" $i)
done
