ImageMagick Cross Dissolve Transition Syntax

This guide explains how to generate a smooth cross-dissolve transition between images using ImageMagick. You will learn the exact command-line syntax, understand the core parameters such as the -morph operator, and see how to export the transition directly as a video file or an image sequence.

Basic Syntax

To create a cross-dissolve effect between two images in ImageMagick (version 7+), use the following syntax:

magick input1.png input2.png -morph 30 -delay 3 transition.mp4

For ImageMagick version 6, replace magick with convert:

convert input1.png input2.png -morph 30 -delay 3 transition.mp4

Parameter Breakdown

  • input1.png and input2.png: The starting and ending source images for the transition. Both images should have the same dimensions for optimal results.
  • -morph <number>: Generates intermediate blended frames between the two images. For example, -morph 30 creates 30 interpolated frames, producing a gradual dissolve.
  • -delay <ticks>: Sets the display duration for each frame in hundredths of a second (ticks). A value of 3 or 4 results in approximately 25–33 frames per second, ensuring smooth playback.
  • transition.mp4: The output file format. ImageMagick uses delegate libraries (such as FFmpeg) to encode the morph sequence into .mp4, .webm, .avi, or .gif.

Generating an Image Sequence for External Video Editors

If you prefer to export individual frames instead of a rendered video file, use a formatted filename:

magick input1.png input2.png -morph 30 frame_%03d.png

This outputs frame_000.png through frame_031.png, which can be imported directly as an image sequence into any non-linear video editing software.

Multi-Image Dissolve Syntax

You can dissolve across more than two images in a continuous sequence by listing them in order:

magick slide1.jpg slide2.jpg slide3.jpg -morph 24 -delay 4 slideshow.mp4

ImageMagick applies the 24-frame dissolve between slide1 and slide2, followed immediately by another 24-frame dissolve between slide2 and slide3.
