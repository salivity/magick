ImageMagick Custom Emboss Kernel Syntax

ImageMagick allows users to apply custom convolution matrices to produce visual effects such as embossing, which simulates a 3D raised or stamped texture on an image. By using either the modern -morphology Convolve method or the traditional -convolve operator with a midpoint gray bias, you can precisely control the directional lighting and depth of the embossed result. This guide provides the exact command-line syntax and matrix formatting needed to build a custom embossing filter in ImageMagick.

The Emboss Kernel Matrix

An embossing kernel typically calculates directional differences between neighboring pixels. A standard 3x3 matrix representing light coming from the top-left looks like this:

-2 -1 0
-1 1 1
0 1 2

Because standard convolution can produce negative values, embossing requires shifting the base pixel values to neutral gray (50% intensity) so both shadows (negative values) and highlights (positive values) are visible.

Modern Syntax: -morphology Convolve

In ImageMagick 6 and 7, the recommended approach for custom convolution is the -morphology operator. You define the kernel size and values directly inside the kernel string.

magick input.png -define morphology:compose=Lighten -bias 50% -morphology Convolve "3x3: -2,-1,0 -1,1,1 0,1,2" output.png

Syntax Breakdown:

  • 3x3:: Defines the matrix dimensions (Width x Height:).
  • -2,-1,0 -1,1,1 0,1,2: The comma- or space-separated values read from top-left to bottom-right.
  • -bias 50%: Shifts the output range so zero-sum differences render as 50% gray instead of clipping to black.

Legacy Syntax: -convolve

You can also use the direct -convolve operator by supplying a comma-separated list of the 9 kernel values:

magick input.png -bias 50% -convolve "-2,-1,0,-1,1,1,0,1,2" output.png

(Note: If using ImageMagick v6, replace magick with convert.)

Directional Variants

You can adjust the angle of the simulated light source by rotating the values around the center of the matrix:

  • Top-to-Bottom Emboss:

    "3x3: -1,-2,-1  0,1,0  1,2,1"

  • Left-to-Right Emboss:

    "3x3: -1,0,1 -2,1,2 -1,0,1"

  • High-Pass Emboss (Edge Emphasis):

    "3x3: -1,-1,-1 -1,8,-1 -1,-1,-1"
