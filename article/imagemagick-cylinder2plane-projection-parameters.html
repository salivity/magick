ImageMagick Cylinder2Plane Projection Parameters

This article provides a direct overview of the parameters that define the Cylinder2Plane distortion method in ImageMagick. The Cylinder2Plane projection is used to unroll or map cylindrical panoramic imagery back onto a flat, perspective planar surface. Understanding its arguments allows you to accurately align perspectives, correct panoramic distortion, and control the focal scale of the resulting image.

Overview of the Cylinder2Plane Distortion

In ImageMagick, the Cylinder2Plane operation is invoked using the -distort operator:

magick input.png -distort Cylinder2Plane "parameters" output.png

The transformation takes up to three arguments, formatted as a space-separated or comma-separated list of floating-point values:

"FOV [center_x center_y]"

The Defining Parameters

1. FOV (Field of View)

  • Status: Required
  • Unit: Degrees (floating-point)
  • Description: Specifies the horizontal Field of View (FOV) of the input cylindrical image.
  • Details: This is the primary parameter governing the projection. It defines the angular span represented across the full width of the cylindrical source. A standard value corresponds to the camera's horizontal viewing angle when capturing the panorama. If the specified FOV matches the true capture angle, the straight lines in the physical world will render as straight lines on the planar output. Supplying a value that is too large will over-stretch the edges, while a value that is too small will cause under-correction.

2. Center X (center_x)

  • Status: Optional
  • Unit: Pixels
  • Default: Center of the input image ((width - 1) / 2)
  • Description: Defines the horizontal coordinate of the projection center (optical center).
  • Details: Changing this parameter shifts the center of perspective horizontally across the cylinder, allowing you to re-center the planar perspective on a specific subject rather than the geometric midpoint of the image.

3. Center Y (center_y)

  • Status: Optional
  • Unit: Pixels
  • Default: Center of the input image ((height - 1) / 2)
  • Description: Defines the vertical coordinate of the projection center (optical center).
  • Details: Adjusting this parameter shifts the vertical vanishing point. It is particularly useful if the camera was tilted up or down during capture or if the input image has been cropped asymmetrically along the vertical axis.

Usage Syntax Examples

  • FOV Only: Uses the default image center for both horizontal and vertical coordinates.

    magick panorama.jpg -distort Cylinder2Plane "90" output.jpg

  • FOV with Custom Center Coordinates: Applies a 100-degree horizontal field of view centered at coordinates (1200, 600).

    magick panorama.jpg -distort Cylinder2Plane "100 1200 600" output.jpg

Practical Considerations

  • Inverse Mapping: Cylinder2Plane is the mathematical inverse of the Plane2Cylinder distortion. The same parameter values will reverse a transformation between the two projections.
  • Canvas Sizing: Planar projections expand significantly toward the edges as the FOV approaches or exceeds 120 degrees. Using the +distort variant instead of -distort ensures that the output image canvas dynamically expands to contain the entire transformed output rather than clipping at original image boundaries.
