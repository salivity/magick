ImageMagick DDS DXT1 to DXT5 Compression Guide

DirectDraw Surface (DDS) textures are widely used in real-time rendering and game development to store compressed texture data directly readable by the GPU. In ImageMagick, converting standard images into DDS format with specific compression formats from DXT1 through DXT5 is handled using the -define dds:compression option. This guide explains the exact command syntax and settings required to apply DXT1, DXT3, and DXT5 compression profiles when exporting DDS files.

The Core Command Option

ImageMagick controls DDS compression via the -define operational flag. The standard syntax is:

magick input.png -define dds:compression=TYPE output.dds

(Note: In ImageMagick v6, replace magick with convert.)

Supported DXT Compression Formats

The value assigned to dds:compression determines the block-compression algorithm applied to the image data:

  • DXT1 (dxt1): Best for opaque RGB textures or textures requiring simple 1-bit (on/off) alpha transparency. DXT1 provides a 6:1 compression ratio (or 8:1 for RGBA) by using 4-bit per pixel block encoding.
  • DXT3 (dxt3): Best for textures with sharp, explicit alpha transitions. It compresses color data similarly to DXT1 but stores uncompressed 4-bit explicit alpha values, giving an overall 4:1 compression ratio.
  • DXT5 (dxt5): Best for textures requiring smooth transparency gradients and soft edges. It compresses color data like DXT1 and uses interpolated 8-bit alpha blocks to provide higher quality alpha blending at a 4:1 compression ratio.
  • None (none): Produces an uncompressed DDS file (typically RGBA8888).

ImageMagick also recognizes dxt2 and dxt4, though they are rarely used as they rely on premultiplied alpha channels equivalent to DXT3 and DXT5, respectively.

Command Examples

Compressing with DXT1 (Opaque or 1-Bit Alpha)

magick diffuse.png -define dds:compression=dxt1 diffuse.dds

Compressing with DXT3 (Explicit Alpha)

magick fence.png -define dds:compression=dxt3 fence.dds

Compressing with DXT5 (Smooth Gradient Alpha)

magick glass.png -define dds:compression=dxt5 glass.dds

Additional DDS Compression Modifiers

When generating DXT-compressed textures, other -define flags can be combined to optimize output quality and mipmap generation:

  • Mipmaps (dds:mipmaps): Controls the generation of mip levels. Set to 0 or from-image to generate a full mip chain: 
    magick input.png -define dds:compression=dxt5 -define dds:mipmaps=0 output.dds
  • Cluster Fit (dds:cluster-fit): Improves color-matching quality during block encoding at the expense of processing speed: 
    magick input.png -define dds:compression=dxt1 -define dds:cluster-fit=true output.dds
  • Weighting Channels (dds:weight-by-alpha): Biases color compression weighting based on alpha transparency: 
    magick input.png -define dds:compression=dxt5 -define dds:weight-by-alpha=true output.dds
