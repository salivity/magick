ImageMagick -delay Syntax for Custom Tick Rates

ImageMagick sets animation frame delays in centiseconds (1/100th of a second) by default, but you can define custom time bases such as 1/60th of a second using an extended syntax. This guide explains how to format the -delay option to use custom ticks per second, how ImageMagick calculates the resulting frame rate, and practical command-line examples.

The -delay Tick Rate Syntax

To specify a custom tick rate, use the format:

-delay <ticks>x<ticks-per-second>

To assign a delay of 1/60th of a second, the command is:

magick -delay 1x60 input_frames*.png output.gif

In this syntax:

  • 1 represents the number of ticks to display each frame.
  • 60 defines the base tick rate (ticks per second).

How ImageMagick Interprets the Values

When you provide a single integer (such as -delay 2), ImageMagick assumes a default tick rate of 100 ticks per second (centiseconds), interpreting it as 2x100 (0.02 seconds).

Adding the x<ticks-per-second> modifier replaces the default denominator:

  • 1/60th of a second (60 FPS): -delay 1x60
  • 1/30th of a second (30 FPS): -delay 1x30
  • 1/24th of a second (24 FPS): -delay 1x24
  • 2/60th of a second (30 FPS using a 60 Hz base): -delay 2x60

Per-Frame Variable Rates

You can adjust delays for individual frames by placing -delay settings before specific images in the command sequence:

magick -delay 1x60 frame1.png frame2.png -delay 10x60 frame3.png output.mp4

In this example, frame1.png and frame2.png display for 1/60th of a second, while frame3.png pauses for 10/60th of a second (1/6th of a second).

Format Constraints

While ImageMagick supports arbitrary tick rates internally and in formats like APNG, WebP, or MP4, standard GIF files store frame delays strictly as integer units of hundredths of a second (1/100s). When saving to GIF, ImageMagick converts fractions like 1x60 (~0.0166s) to the nearest centisecond integer (typically 2/100s or 50 FPS). For exact 60 FPS playback, container formats such as MP4, WebP, or APNG are recommended.
