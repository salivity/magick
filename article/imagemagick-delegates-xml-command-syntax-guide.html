ImageMagick delegates.xml Command Syntax Guide

This guide provides a straightforward overview of the syntax used to configure external delegate commands in ImageMagick’s delegates.xml file. It covers the structure of the <delegate> XML tag, the primary attributes required for decoding and encoding formats, the substitution format specifiers used in execution strings, and practical syntax examples for custom workflows.

Understanding delegates.xml

ImageMagick uses the delegates.xml configuration file to pass image processing tasks to external programs (such as Ghostscript, FFmpeg, or Inkscape) when native support for a file format is unavailable.

Basic XML Structure

Delegate rules are defined as child <delegate> elements inside a <delegatemap> root element:

<delegatemap>
  <delegate decode="format" encode="format" mode="bi|read|write" command="shell_command" />
</delegatemap>

Delegate Tag Attributes

  • decode: Specifies the source format or protocol that the delegate is responsible for reading (e.g., decode="pdf" or decode="https").
  • encode: Specifies the target format that the delegate writes (e.g., encode="png").
  • mode: Defines the operation mode:
    • read: Converts an external format into an ImageMagick-readable format.
    • write: Converts an ImageMagick internal image into the external format.
    • bi: Bidirectional (can handle both input reading and output writing).
  • command: The exact shell command string executed to process the file. Must contain substitution tokens for file paths and options.
  • spawn: (Optional) Set to "True" or "False". If True, the external process runs asynchronously.
  • stealth: (Optional) Set to "True" to hide the delegate from standard listings (magick identify -list delegate).

Command Substitution Tokens

Inside the command attribute string, ImageMagick replaces specific % tokens with runtime values:

Token Description
%i Input filename or standard input indicator
%o Output filename or standard output indicator
%u Unique temporary filename for input
%v Unique temporary filename for output
%s Scene or page number
%p Page number index
%w Image width
%h Image height
%q Quantum depth (e.g., 8, 16)
%d Directory component of file path
%f Filename without directory path
%[property] Value of an embedded ImageMagick artifact/property

Syntax Examples

1. Simple Read Delegate (Decoding)

To delegate the decoding of a custom raw format to an external utility:

<delegate decode="myraw" mode="read" command="&quot;myraw_decoder&quot; -input &quot;%i&quot; -output &quot;%u.png&quot;" />

2. Multi-Page Format with Standard Substitutions

A Ghostscript-style invocation for reading PostScript/PDF files:

<delegate decode="ps:alpha" mode="read" command="&quot;gs&quot; -sDEVICE=pngalpha -o &quot;%v&quot; -r%s &quot;%i&quot;" />

3. Piping via Stdin/Stdout

When utilizing pipes, use standard shell redirection symbols:

<delegate decode="svg" mode="read" command="&quot;rsvg-convert&quot; -f png &quot;%i&quot; -o &quot;%o&quot;" />

XML Escaping Rules

Because delegate rules reside inside an XML attribute, shell special characters must follow standard XML escaping:

  • Double quote ("): &quot;
  • Ampersand (&): &amp;
  • Less than (<): &lt;
  • Greater than (>): &gt;
