ImageMagick Detect Bounding Box Coordinates

This guide explains how to detect the bounding coordinates of non-background content in an image using ImageMagick. By using specific format specifiers, ImageMagick can calculate the exact dimensions and offset coordinates of the foreground content without altering the original file.

The Bounding Box Command

In ImageMagick (version 7), use the -format "%@" string with the info: output to extract the bounding coordinates:

magick input.png -format "%@" info:

For ImageMagick version 6, use the identify command:

identify -format "%@" input.png

Understanding the Output

The command outputs a standard ImageMagick geometry string formatted as:

WIDTHxHEIGHT+X+Y
  • WIDTH: The width of the bounding box containing the non-background content.
  • HEIGHT: The height of the bounding box.
  • +X: The horizontal offset (number of pixels from the left edge to the start of the bounding box).
  • +Y: The vertical offset (number of pixels from the top edge to the start of the bounding box).

For example, an output of 450x300+25+10 indicates that the non-background content is 450 pixels wide, 300 pixels high, starts 25 pixels from the left, and 10 pixels from the top.

Handling Non-Solid or Noisy Backgrounds

If the background is not a pure uniform color (e.g., JPEG artifacts or slight color variations), you can use the -fuzz option to allow a tolerance threshold:

magick input.jpg -fuzz 5% -format "%@" info:

Extracting Individual Coordinate Values

If you need the coordinates separated into distinct variables for scripting, you can format them individually using properties:

magick input.png -format "Width: %w, Height: %h, X: %X, Y: %Y" -trim info:
