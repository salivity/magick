ImageMagick Difference of Gaussians Syntax

This guide provides the exact command-line syntax for applying a Difference of Gaussians (DoG) bandpass filter in ImageMagick. You will learn the required operators, how to configure the kernel parameters, and how to handle output normalization for tasks like edge detection and frequency-based image enhancement.

The Basic DoG Syntax

In ImageMagick, the Difference of Gaussians filter is built into the -morphology operator using the Convolve method.

For ImageMagick version 7:

magick input.jpg -morphology Convolve "DoG:radius,sigma1,sigma2" output.jpg

For ImageMagick version 6:

convert input.jpg -morphology Convolve "DoG:radius,sigma1,sigma2" output.jpg

Parameter Definitions

The DoG kernel takes up to three comma-separated arguments:

  • radius: The size of the convolution matrix. Setting this to 0 allows ImageMagick to automatically calculate the optimal matrix size based on the largest sigma value.
  • sigma1: The standard deviation of the smaller (inner) Gaussian blur. This controls the high-frequency cutoff.
  • sigma2: The standard deviation of the larger (outer) Gaussian blur. This controls the low-frequency cutoff.

To act as a standard edge-detecting bandpass filter, sigma1 must be smaller than sigma2.

Practical Examples

1. Standard Bandpass Filtering (Edge Detection)

To isolate medium-frequency details while filtering out both high-frequency noise and low-frequency gradients:

magick input.jpg -morphology Convolve "DoG:0,1.0,2.0" output.jpg

2. Preserving Negative Values with a 50% Bias

Because the Difference of Gaussians subtraction results in both positive and negative pixel values, raw output may clip negative values to black. Adding a 50% bias centers zero at mid-gray:

magick input.jpg -define morphology:compose=Lighten -bias 50% -morphology Convolve "DoG:0,0.5,2.0" output.jpg

3. Highlighting and Normalizing Edges

To maximize the contrast of the extracted frequency band, follow the convolution with -auto-level:

magick input.jpg -morphology Convolve "DoG:0,1.0,3.0" -auto-level output.jpg

Alternative Method: Explicit Blurring and Subtraction

If you prefer to perform the operations explicitly rather than using the morphology kernel, you can generate two blurred versions and subtract them:

magick input.jpg \( +clone -gaussian-blur 0x1.0 \) \( +clone -gaussian-blur 0x3.0 \) -delete 0 -compose Mathematics -set option:compose:args "0,1,-1,0.5" -composite output.jpg

In this alternative syntax, 0x1.0 and 0x3.0 represent radius x sigma, and the Mathematics composition subtracts the second blurred layer from the first while adding a 0.5 (50%) offset to retain negative values.
