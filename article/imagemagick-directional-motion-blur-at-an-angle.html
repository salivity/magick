ImageMagick Directional Motion Blur at an Angle

Applying a directional motion blur at an arbitrary angle in ImageMagick is achieved using the built-in -motion-blur operator. This guide explains the correct syntax for specifying the blur radius, strength, and angle, providing direct command-line examples for both ImageMagick v7 and v6 so you can accurately simulate directional movement in any image.

The -motion-blur Syntax

The operator uses the following geometry parameter format:

-motion-blur {radius}x{sigma}+{angle}
  • radius: The size of the blur matrix in pixels. Setting this to 0 allows ImageMagick to calculate an optimal radius automatically based on the sigma value.
  • sigma: The standard deviation of the blur. This effectively controls the distance/length of the motion streak.
  • angle: The direction of the blur in degrees, measured counter-clockwise from the horizontal axis:
    • 0: Horizontal blur (left-to-right / right-to-left)
    • 45: Diagonal blur (bottom-left to top-right)
    • 90: Vertical blur (straight up and down)
    • 135, 180, 270: Custom arbitrary angles

Basic Command Examples

ImageMagick v7 (Current Standard)

To apply a motion blur of length 20 at a 45-degree angle:

magick input.jpg -motion-blur 0x20+45 output.jpg

ImageMagick v6 (Legacy)

For older installations using the convert binary:

convert input.jpg -motion-blur 0x20+45 output.jpg

Common Angle Configurations

  • Horizontal Motion Blur (0°):

    magick input.jpg -motion-blur 0x15+0 output_horizontal.jpg

  • Vertical Motion Blur (90°):

    magick input.jpg -motion-blur 0x15+90 output_vertical.jpg

  • Diagonal Motion Blur (60°):

    magick input.jpg -motion-blur 0x25+60 output_diagonal.jpg

Handling Blur Intensity and Edges

  1. Increasing Streak Length: Increase the sigma value (e.g., 0x40+30 creates a much longer blur trail than 0x10+30).
  2. Preventing Edge Artifacts: High-sigma values near image borders can cause dark edges. To mitigate this, add a virtual pixel setting before applying the blur: 
    magick input.jpg -virtual-pixel Mirror -motion-blur 0x30+45 output.jpg
