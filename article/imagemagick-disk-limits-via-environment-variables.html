ImageMagick Disk Limits via Environment Variables

This article provides a concise guide on configuring ImageMagick's disk usage limits using environment variables. ImageMagick uses disk cache when pixel data exceeds available memory, and setting strict thresholds prevents runaway processes from exhausting server storage. Below, you will learn which environment variables to set, valid syntax formats, and how to verify that your resource restrictions are actively applied.

Key Environment Variable for Disk Limits

ImageMagick provides the MAGICK_DISK_LIMIT environment variable to control the maximum amount of disk space the tool is permitted to use for intermediate pixel storage.

When processing large files, ImageMagick stages pixel sequences in temporary disk cache once memory (MAGICK_MEMORY_LIMIT) and memory-mapped files (MAGICK_MAP_LIMIT) are exhausted. Setting MAGICK_DISK_LIMIT restricts this fallback storage.

Supported Measurement Units

Values assigned to MAGICK_DISK_LIMIT accept standard metric and binary size suffixes:

  • KB or KiB (Kilobytes)
  • MB or MiB (Megabytes)
  • GB or GiB (Gigabytes)
  • TB or TiB (Terabytes)
  • Raw integer values represent bytes directly.

Setting the Variable

1. Per-Command Execution

You can prepend the variable directly before the ImageMagick command:

MAGICK_DISK_LIMIT="2GiB" magick input.tif -resize 50% output.jpg

2. Shell Session / Linux Environment

Export the variable to enforce limits across the current shell session:

export MAGICK_DISK_LIMIT="5GB"

To make this persistent across reboots, add the export line to your shell profile (~/.bashrc, ~/.zshrc) or system-wide configuration files such as /etc/environment.

3. Docker Containers

If running ImageMagick inside containerized environments, declare the variable inside your Dockerfile:

ENV MAGICK_DISK_LIMIT=1GiB

Or pass it at runtime:

docker run -e MAGICK_DISK_LIMIT=1GiB my-imagemagick-app

Controlling the Temporary File Directory

If you need to redirect disk usage to a dedicated mount point alongside your disk limits, configure the MAGICK_TEMPORARY_PATH variable:

export MAGICK_TEMPORARY_PATH="/mnt/scratch"

Verifying Resource Limits

To ensure your environment variable is successfully picked up by ImageMagick, execute the following command:

magick identify -list resource

(Note: Use identify -list resource if working with ImageMagick 6.)

Locate the Disk entry in the output to confirm that the assigned limit matches your configured environment variable:

Resource limits:
  ...
  Memory: 4GiB
  Map: 8GiB
  Disk: 2GiB
  ...
