ImageMagick Displace Operator and Displacement Maps

This guide provides a comprehensive overview of the ImageMagick -displace operator and the underlying mechanics of displacement maps. You will learn what displacement mapping is, how pixel luminance dictates coordinate shifting, how two-dimensional displacement operates using color channels, and how to construct practical ImageMagick commands to achieve visual distortion effects like ripples, wraps, and surface textures.

What is a Displacement Map?

A displacement map is a secondary image used to warp or shift the pixels of a target image based on color or brightness values. Instead of altering pixel colors directly, the map changes the spatial coordinates from which pixels are sampled.

In standard displacement mapping, neutral gray (50% brightness) represents zero displacement, meaning the target pixels remain in their original positions. Brightness values above 50% shift pixels in one direction, while values below 50% shift them in the opposite direction. Pure white and pure black represent the maximum possible shifts defined by the user.

How the ImageMagick Displace Operator Works

ImageMagick implements this technique through the -displace operator. It takes a source image and a displacement map, altering the source image's geometry according to the intensity values found in the map.

The operator accepts horizontal and vertical scale arguments:

magick source.png map.png -displace <X-scale>x<Y-scale> output.png

The <X-scale> and <Y-scale> parameters define the maximum distance, in pixels, that a point can be shifted horizontally and vertically.

The Displacement Math

For any given pixel:

  • 50% Gray (Value 0.5 or 128 in 8-bit): Displacement distance is 0 * Scale = 0. No movement occurs.
  • 100% White (Value 1.0 or 255 in 8-bit): Displacement distance is +1.0 * Scale. Pixels shift by the maximum positive offset.
  • 0% Black (Value 0.0 or 0 in 8-bit): Displacement distance is -1.0 * Scale. Pixels shift by the maximum negative offset.

Two-Dimensional Mapping (X and Y Displacement)

Displacement maps can control both horizontal and vertical shifts simultaneously using color channels:

  1. Single Grayscale Map: If a single grayscale image is provided, ImageMagick applies the same shift values to both the X and Y axes, scaled respectively by the provided <X-scale> and <Y-scale> multipliers.
  2. Two-Channel (RGB) Map: When an RGB image is used as the map, ImageMagick separates the axes:
    • The Red channel dictates horizontal (X-axis) displacement.
    • The Green channel dictates vertical (Y-axis) displacement.
    • The Blue channel is ignored.

Practical Applications

  • Mockup Generation: Wrapping flat logos or graphics naturally around 3D surfaces, such as apparel folds, cylinders, or textured paper.
  • Glass and Water Effects: Simulating refraction by applying smooth gradient noise or wave patterns to distort the underlying background.
  • Glitch and Wave Distortions: Applying high-contrast patterns or scanlines to create stylized digital artifacts.
