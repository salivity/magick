ImageMagick Displace Operator and Displacement Vectors

The ImageMagick -displace operator is a distortion tool used to warp a source image using the pixel values of a secondary control image known as a displacement map. This article explains what the -displace operator does, how displacement vectors use color values to calculate pixel shifts, and how to control the scale and direction of the distortion effect.

What is the -displace Operator?

In ImageMagick, -displace is a composite operator that shifts pixels in a base image according to the brightness values of a displacement map. Rather than applying a uniform geometric transformation (such as a rotation or perspective change), -displace enables localized, pixel-by-pixel transformations. This makes it ideal for simulating optical effects like glass refraction, water ripples, heat hazes, and custom texture wrapping.

The basic syntax requires two images: the background (source image) and the overlay (displacement map):

magick source.png displacement_map.png -displace <X-scale>x<Y-scale> output.png

The scale arguments determine the maximum distance (in pixels) that source pixels can be moved along the horizontal (X) and vertical (Y) axes.

How Displacement Vectors Work

A displacement vector defines the direction and distance a source pixel will move to its new location. In ImageMagick, these vectors are calculated on a relative lookup basis: the operator looks at a target pixel coordinate, samples the displacement map, and fetches the color from an offset coordinate in the source image.

Displacement vectors are encoded directly into the color channels of the displacement map:

  • Red Channel (X Vector): Controls horizontal displacement (left or right).
  • Green Channel (Y Vector): Controls vertical displacement (up or down).
  • Grayscale Image: If a single grayscale image is used, the same values are applied to both the X and Y vectors equally.

The 50% Neutral Point

Displacement uses a signed offset system centered at mid-gray (50% intensity):

  • 50% Gray (RGB 128, 128, 128): Represents a vector value of zero. Pixels at this point experience no displacement and remain in their original positions.
  • Values Greater Than 50% (51% to 100% / White): Produce a positive displacement vector, shifting pixels down and to the right.
  • Values Less Than 50% (0% / Black to 49%): Produce a negative displacement vector, shifting pixels up and to the left.

Calculating Pixel Offsets

The formula for the final displacement offset \(D\) for any axis is:

\[D = \text{Scale} \times \left(\frac{\text{Channel Value} - \text{Midpoint}}{\text{Midpoint}}\right)\]

For an 8-bit image where the midpoint is 128:

  • A pixel value of 255 (pure white) with a scale of 20 results in a \(+20\text{px}\) shift: \(20 \times (255 - 128) / 127 \approx +20\text{px}\).
  • A pixel value of 0 (pure black) with a scale of 20 results in a \(-20\text{px}\) shift: \(20 \times (0 - 128) / 128 = -20\text{px}\).

Displacement Map Configuration

By designing smooth gradients in the red and green channels, you can construct complex vector fields. A smooth linear gradient from black to white creates a continuous stretching effect, while a radial gradient creates spherical bulge or pinch distortions. Using interpolated lookups, ImageMagick ensures that sub-pixel vector offsets remain smooth without producing jagged aliasing artifacts.
