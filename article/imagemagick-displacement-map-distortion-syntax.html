ImageMagick Displacement Map Distortion Syntax

Displacement mapping in ImageMagick allows you to distort a base image by shifting its pixels according to the color values of a secondary control image, known as a displacement map. This guide explains the precise command-line syntax, parameters, and channel behaviors required to apply both one-dimensional and two-dimensional displacement distortions using modern ImageMagick commands.

Basic Displacement Syntax

In ImageMagick 7, the standard syntax for applying a displacement map combines the source image and the map using the -displace operator:

magick source.png map.png -displace <X_scale>[x<Y_scale>] output.png

Alternatively, you can use the explicit composite syntax:

magick source.png map.png -compose Displace -set option:compose:args <X_scale>[x<Y_scale>] -composite output.png

Parameter Breakdown

  • source.png: The target image you want to warp or distort.
  • map.png: The displacement map image that dictates the direction and magnitude of the pixel shift.
  • <X_scale>: The maximum horizontal shift distance in pixels.
  • <Y_scale>: (Optional) The maximum vertical shift distance in pixels. If omitted, the value defaults to <X_scale>.
  • output.png: The resulting distorted image.

How the Displacement Map Works

ImageMagick calculates pixel movement relative to a 50% neutral gray baseline:

  • 50% Gray (#808080 / gray(50%)): Results in zero displacement.
  • 0% Black (#000000): Moves the pixel to the maximum negative offset (left or up by the full scale amount).
  • 100% White (#FFFFFF): Moves the pixel to the maximum positive offset (right or down by the full scale amount).

1D Displacement (Grayscale Map)

When using a single grayscale image as the map:

  • The grayscale values modulate the horizontal displacement according to <X_scale>.
  • If a <Y_scale> is provided, the same grayscale channel simultaneously dictates the vertical displacement.
magick input.jpg gradient_map.png -displace 20x10 output.jpg

In this example, pixels shift horizontally up to ±20 pixels and vertically up to ±10 pixels based on the single brightness value of gradient_map.png.

2D Displacement (Two-Channel Map)

To control horizontal and vertical displacement independently, use a color image where separate color channels dictate each axis:

  • Red Channel: Controls horizontal (X-axis) displacement.
  • Green Channel: Controls vertical (Y-axis) displacement.
magick input.jpg rg_displacement_map.png -displace 30x30 output.jpg

Percentage and Absolute Scaling

By default, scaling values are treated as absolute pixel measurements. To scale relative to the image dimensions, append a percentage sign (%):

magick input.jpg map.png -displace 5%x5% output.jpg

To prevent displacement values from being centered at 50% neutral gray (interpreting 0% black as zero shift instead of negative shift), define the displacement type using the absolute mapping option:

magick input.jpg map.png -define compose:displace=absolute -displace 20x20 output.jpg
