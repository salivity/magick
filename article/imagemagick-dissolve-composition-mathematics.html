ImageMagick Dissolve Composition Mathematics

This article provides an overview of the mathematical operations governing the Dissolve compose method in ImageMagick. It details how alpha channels are adjusted based on user-defined percentages, how linear interpolation blends color values, and how the underlying Porter-Duff Over composite operator calculates the final pixel output.

In ImageMagick, the Dissolve composition operates as a weighted blend of two images: the source (overlay) and the destination (background). Mathematically, it relies on scaling the alpha (transparency) channels of both images and then combining them using the standard Porter-Duff Over compositing operator.

1. Alpha Channel Scaling

When you define a dissolve percentage \(P\) (where \(0 \le P \le 100\)), ImageMagick first recalculates the alpha channel values for both images.

If a single percentage \(P\) is provided:

  • Source Alpha Multiplier: \(w_s = \frac{P}{100}\)
  • Destination Alpha Multiplier: \(w_d = \frac{100 - P}{100}\)

The intermediate alpha values (\(\alpha_s'\) and \(\alpha_d'\)) become: \[\alpha_s' = \alpha_s \times w_s\] \[\alpha_d' = \alpha_d \times w_d\]

If a dual percentage is specified (e.g., -dissolve src_percent,dst_percent), each alpha multiplier is set independently to \(\frac{P_s}{100}\) and \(\frac{P_d}{100}\).

2. The Over Composite Operator

After the alpha channels are modified, ImageMagick executes a Porter-Duff Over composition. The output alpha (\(\alpha_{out}\)) is computed as:

\[\alpha_{out} = \alpha_s' + \alpha_d' \times (1 - \alpha_s')\]

The output color (\(C_{out}\)) for each color channel (Red, Green, Blue) is calculated using premultiplied alpha mathematics:

\[C_{out} = \frac{C_s \times \alpha_s' + C_d \times \alpha_d' \times (1 - \alpha_s')}{\alpha_{out}}\]

3. Simplification for Opaque Images

When both the source and destination images are completely opaque (\(\alpha_s = 1\) and \(\alpha_d = 1\)), the math reduces to standard linear interpolation (LERP):

\[C_{out} = C_s \times \left(\frac{P}{100}\right) + C_d \times \left(1 - \frac{P}{100}\right)\]

In this state, each color channel is simply the weighted average of the two source pixels according to the chosen dissolve percentage.
