ImageMagick Distance Transform on Monochrome Images

This article provides a concise guide on applying a distance transform to a monochrome image using ImageMagick. It covers the core syntax of the morphology operator, the different distance metrics available, and how to normalize the resulting values for clear visualization.

Understanding the Distance Transform in ImageMagick

The distance transform calculates the distance of each foreground pixel to the nearest background pixel (or vice versa). ImageMagick performs this operation using the -morphology Distance operator.

To achieve accurate results, ensure your input image is strictly binary (monochrome), containing only pure black (#000000) and pure white (#FFFFFF) pixels.

Basic Syntax

In ImageMagick 7, use the magick command. For ImageMagick 6, replace magick with convert.

magick input.png -morphology Distance <Metric> output.png

By default, ImageMagick measures the distance from non-zero (white) pixels to the nearest zero (black) background pixel.

Available Distance Metrics

ImageMagick supports several distance metrics depending on your requirements:

  • Euclidean: Measures true straight-line distance. You can specify a scale factor (e.g., Euclidean:4 for a radius of 4-pixel precision).
  • Manhattan: Measures distance along grid axes (city-block distance).
  • Chebyshev: Measures distance as the maximum coordinate difference (chessboard distance).

Practical Examples

1. Basic Euclidean Distance Transform with Normalization

Raw distance values can exceed standard 8-bit image limits or appear too dark. Use -auto-level to stretch the dynamic range from black (minimum distance) to white (maximum distance) for viewing:

magick input.png -morphology Distance Euclidean:4 -auto-level distance_map.png

2. Manhattan (City Block) Distance

To calculate grid-based distances:

magick input.png -morphology Distance Manhattan -auto-level manhattan_map.png

3. Measuring Distance from Objects Instead of Background

If you want to measure the distance from the edges of white objects outwards into the black background, invert the image using -negate before applying the transform:

magick input.png -negate -morphology Distance Euclidean:4 -auto-level outward_distance.png

4. Converting a Grayscale Image to Monochrome First

If your source image is not strictly binary, threshold it before applying the distance morphology:

magick input.jpg -threshold 50% -morphology Distance Euclidean:4 -auto-level output.png
