ImageMagick +distort vs -distort Explained

In ImageMagick, the difference between invoking -distort and +distort comes down to output canvas sizing and viewport calculation. While the standard -distort operator restricts the output image to the original image dimensions and clips any transformed content outside those boundaries, +distort automatically calculates a "best-fit" canvas that expands or adjusts to contain the entire transformed image without clipping.

Output Geometry and Viewport Behavior

When -distort is used, ImageMagick preserves the source image's existing canvas size, offset, and aspect ratio. Any pixels that map outside the original image bounds during transformation (such as a 45-degree rotation or a wide-angle perspective projection) are clipped and lost from the final frame.

When +distort is used, ImageMagick overrides the fixed canvas restriction. The operator calculates the minimum bounding box necessary to enclose all transformed pixels. It then automatically generates a new viewport and sets the output image's width and height accordingly, ensuring that zero visual data is clipped by canvas boundaries.

Virtual Canvas and Coordinate Offsets

In addition to resizing the canvas, +distort modifies the virtual canvas metadata (page geometry). It sets the image's top-left corner coordinates relative to the original 0,0 origin.

Depending on the transformation, this can introduce positive or negative X and Y offsets. For instance:

  • If an image expands outward in all directions, +distort may assign negative offsets (e.g., -20-30) so the original center remains anchored in global space.
  • File formats that preserve virtual canvases (such as PNG, MIFF, or TIFF) retain these offsets, which affects how layers interact in subsequent composition operations.
  • File formats that do not support virtual canvas offsets (such as JPEG) will simply render the new bounding box without positioning data.

To discard the offset coordinates after using +distort and treat the newly sized image as a standard standalone graphic, the +repage operator is typically appended immediately afterward.

Summary of Differences

  • -distort (Standard): Keeps the original canvas dimensions, anchors to the original viewport, and clips any data falling outside the source dimensions.
  • +distort (Plus Operator): Dynamically resizes the canvas to create a best-fit bounding box, retains all distorted pixels, and updates the virtual canvas page offsets.
