ImageMagick Draw RoundRectangle Syntax Guide

ImageMagick allows users to generate vector graphics directly onto a canvas using the -draw operator. This guide details the syntax and parameter specifications for the roundRectangle primitive, which creates rectangular shapes with smoothed, curved corners. Understanding how to define coordinate positions and corner curvature values will allow you to generate custom frames, cards, and UI elements directly from the command line.

Basic Syntax

The roundRectangle primitive is passed as an argument to the -draw option. The basic syntax is defined as follows:

-draw "roundRectangle x0,y0 x1,y1 wc,hc"

The arguments represent the following values:

  • x0,y0: The coordinate of the top-left corner of the rectangle.
  • x1,y1: The coordinate of the bottom-right corner of the rectangle.
  • wc,hc: The width and height of the corner rounding (the horizontal and vertical radii of the corner ellipse).

Points can be separated by commas, spaces, or a combination of both (e.g., x0,y0,x1,y1,wc,hc or x0,y0 x1,y1 wc,hc).

Parameter Breakdown

  • Top-Left Point (x0,y0): Defines the starting point of the rectangle relative to the top-left corner of the canvas (which is 0,0).
  • Bottom-Right Point (x1,y1): Defines the terminating corner of the shape. The overall width of the rectangle is x1 - x0, and the overall height is y1 - y0.
  • Corner Radius (wc,hc): Controls the curvature of all four corners. If wc and hc are equal, the corner curve forms a circular arc. If wc and hc differ, the curve forms an elliptical arc. Setting both values to 0,0 results in a standard rectangle with sharp corners.

Practical Example

In ImageMagick 7, use the magick command (or convert in ImageMagick 6) to create a new canvas and render the shape:

magick -size 400x300 xc:white \
  -fill lightblue \
  -stroke steelblue \
  -strokewidth 3 \
  -draw "roundRectangle 40,40 360,260 25,25" \
  rounded_rectangle.png

In this command:

  • -size 400x300 xc:white creates a 400-by-300 pixel white background.
  • -fill lightblue sets the interior color of the shape.
  • -stroke steelblue and -strokewidth 3 configure a 3-pixel-wide border.
  • -draw "roundRectangle 40,40 360,260 25,25" draws a rounded rectangle from point (40,40) to (360,260) with a corner radius of 25 pixels along both axes.
