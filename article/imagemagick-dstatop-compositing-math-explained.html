ImageMagick DstAtop Compositing Math Explained

The DstAtop (Destination Atop) compositing operation in ImageMagick is a Porter-Duff alpha blending mode that places the destination image over the source image, but restricts the visible output strictly to the shape and boundaries of the source. Mathematically, this operation determines the final color and opacity of each pixel by scaling the destination by the source's alpha value and filling any remaining background areas with the source image. As a result, the output image inherits the exact alpha profile of the source image while displaying destination content wherever the two layers overlap.

Core Variables and Normalized Values

For every individual pixel, the color channels (Red, Green, Blue) and Alpha channel are evaluated after normalizing their values to the range \([0.0, 1.0]\):

  • Source Color and Alpha: \(C_s\) and \(\alpha_s\)
  • Destination Color and Alpha: \(C_d\) and \(\alpha_d\)
  • Resulting Color and Alpha: \(C_r\) and \(\alpha_r\)

Porter-Duff Weighting Factors

Porter-Duff compositing determines how much of the source and destination contribute to the final pixel using blending factors (\(F_s\) and \(F_d\)). For DstAtop, these factors are defined as:

  • \(F_d = \alpha_s\) (Destination is kept only where the Source is opaque)
  • \(F_s = 1 - \alpha_d\) (Source is kept only where the Destination is transparent)

Alpha Channel Calculation

The output alpha (\(\alpha_r\)) is calculated by combining each layer multiplied by its respective factor:

\[\alpha_r = (\alpha_d \times F_d) + (\alpha_s \times F_s)\]

Substituting the weighting factors into the equation:

\[\alpha_r = (\alpha_d \times \alpha_s) + (\alpha_s \times (1 - \alpha_d))\] \[\alpha_r = \alpha_d \alpha_s + \alpha_s - \alpha_d \alpha_s\] \[\alpha_r = \alpha_s\]

Mathematically, the output alpha channel is always identical to the source alpha channel (\(\alpha_r = \alpha_s\)). If the source pixel is completely transparent, the resulting pixel will always be transparent, regardless of the destination's opacity.

Color Channel Calculation

ImageMagick processes color channels depending on whether colors are premultiplied by their alpha values.

Premultiplied Color Space

In premultiplied representation, where color values are stored as \(c' = C \times \alpha\):

\[c'_r = (c'_d \times \alpha_s) + (c'_s \times (1 - \alpha_d))\]

Non-Premultiplied (Standard) Color Space

When evaluating standard, non-premultiplied RGB values, the premultiplied result is divided by the resulting alpha (\(\alpha_r\)):

\[C_r = \frac{(C_d \times \alpha_d \times \alpha_s) + (C_s \times \alpha_s \times (1 - \alpha_d))}{\alpha_r}\]

Because \(\alpha_r = \alpha_s\), the source alpha cancels out (for any non-zero \(\alpha_s\)):

\[C_r = (C_d \times \alpha_d) + (C_s \times (1 - \alpha_d)) \quad \text{for } \alpha_s > 0\]

If \(\alpha_s = 0\), the pixel is entirely empty, and \(C_r = 0\).

Practical Mathematical Outcomes

  1. Where Source is Fully Transparent (\(\alpha_s = 0\)): The output is completely cleared to transparent black (\(\alpha_r = 0\), \(C_r = 0\)). Destination content outside the source mask is entirely clipped out.
  2. Where Destination is Fully Opaque (\(\alpha_d = 1\)) and Source Exists (\(\alpha_s > 0\)): The term \((1 - \alpha_d)\) becomes zero, eliminating source color and leaving only destination color: \(C_r = C_d\), with \(\alpha_r = \alpha_s\).
  3. Where Destination is Fully Transparent (\(\alpha_d = 0\)) and Source Exists (\(\alpha_s > 0\)): The destination contributes nothing, allowing the source color to show through: \(C_r = C_s\), with \(\alpha_r = \alpha_s\).
