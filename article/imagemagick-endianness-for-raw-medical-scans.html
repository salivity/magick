ImageMagick Endianness for Raw Medical Scans

Importing raw medical scan data such as MRI or CT files into ImageMagick requires defining low-level image parameters, including dimensions, bit depth, and byte ordering. This guide explains how to explicitly configure data endianness using ImageMagick command-line tools to prevent byte-swapping artifacts and ensure pixel intensities render accurately.

The -endian Option

ImageMagick provides the -endian flag to determine the byte order of multi-byte binary files, such as 16-bit or 32-bit raw integer data.

The flag accepts three primary arguments:

  • MSB: Most Significant Byte first (Big-Endian), commonly used in network formats and older imaging hardware.
  • LSB: Least Significant Byte first (Little-Endian), the standard for x86/x64 systems and many modern DICOM/raw exports.
  • Native: Uses the host system's native byte order.

Command Syntax and Order of Operations

Because raw files lack headers describing the data layout, you must define the endianness, dimensions, and depth before specifying the input file stream.

Using ImageMagick v7 (magick):

magick -size 512x512 -depth 16 -endian LSB gray:scan_data.raw output.png

For Big-Endian data:

magick -size 512x512 -depth 16 -endian MSB gray:scan_data.raw output.png

If using ImageMagick v6, replace magick with convert.

Handling Signed Data and Floating Point Formats

Medical imaging files often store values as signed integers or 32-bit floating-point data rather than unsigned integers. You can combine the -endian flag with -define quantum:format to ensure proper numerical interpretation:

magick -size 512x512 -depth 32 -endian LSB -define quantum:format=floating-point gray:scan_data.raw output.png

Identifying Endianness Mismatches

If an imported image appears as high-frequency static noise, exhibits extreme banding, or separates into stark pixelated artifacts, the endianness is likely inverted. Switching between -endian LSB and -endian MSB will quickly resolve the issue without needing to modify the underlying raw dataset.
