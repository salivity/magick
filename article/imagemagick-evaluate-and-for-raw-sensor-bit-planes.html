ImageMagick Evaluate And for Raw Sensor Bit Planes

This article explains how to isolate specific bit planes in raw sensor graphics using ImageMagick's -evaluate And operator. Digital camera sensors capture radiometric data stored as multi-bit integers, where each bit position conveys distinct signal characteristics ranging from high-level scene geometry down to analog-to-digital converter noise. By applying a bitwise AND mask across an uncompressed, linear image, the -evaluate And operator clears non-target bits to zero, allowing imaging engineers and researchers to inspect discrete bit planes for hardware diagnostics, noise profiling, and embedded metadata.

Fundamentals of Raw Sensor Bit Planes

Raw sensor graphics contain un-demosaiced pixel values directly generated by an analog-to-digital converter (ADC), typically at 10-bit, 12-bit, 14-bit, or 16-bit depths. Every pixel is a binary integer composed of individual bits ordered from the least significant bit (LSB, bit 0) to the most significant bit (MSB).

A bit plane represents a two-dimensional grid composed of a single bit position extracted across every pixel in the sensor matrix.

  • Most Significant Bits (MSBs): Contain the coarse structural information and major luminance values of the captured scene.
  • Least Significant Bits (LSBs): Contain fine textures, photon shot noise, sensor read noise, and thermal dark current.
  • Intermediate Bits: Transition gradually from structural scene visibility to purely stochastic noise.

The Mechanics of the -evaluate And Operator

ImageMagick's -evaluate command applies an arithmetic or logical operation to all pixels in an image channel. The And operator executes a bitwise logical AND between each pixel value and a user-defined integer mask.

In binary arithmetic, an AND operation outputs a 1 only if both compared bits are 1; otherwise, it outputs a 0:

\[\text{Pixel Bit} \land \text{Mask Bit} = \text{Output Bit}\]

When isolating a specific bit plane, the mask is set to a power of two (\(2^n\), where \(n\) represents the zero-indexed bit position to inspect):

Target Bit Plane Exponential Value (\(2^n\)) Bitmask (Decimal) Bitmask (Binary)
Bit 0 (LSB) \(2^0\) 1 ...00000001
Bit 1 \(2^1\) 2 ...00000010
Bit 2 \(2^2\) 4 ...00000100
Bit 7 \(2^7\) 128 ...10000000
Bit 11 (12-bit MSB) \(2^{11}\) 2048 ...100000000000

Applying a mask such as 128 forces all bit positions other than Bit 7 to 0. If a pixel's seventh bit is 1, its value becomes 128. If its seventh bit is 0, its value becomes 0.

Practical Isolation and Visualization

Because masking a lower bit plane leaves pixels with values of either 0 or \(2^n\), the resulting image will appear completely black on standard displays without dynamic range expansion. To inspect the isolated bit plane visually, the masked output must be normalized.

Example Workflow

To extract and visualize the 8th bit (Bit 7, mask value 128) of a 16-bit raw sensor dump:

magick raw_sensor.gray -depth 16 -evaluate And 128 -auto-level bit_7_isolated.png
  1. -depth 16: Declares the raw file depth to preserve native ADC quantization levels.
  2. -evaluate And 128: Sets all bits to zero except for Bit 7.
  3. -auto-level: Stretches the binary output values (\(0\) and \(128\)) across the displayable range (\(0\) to \(65535\)), rendering a high-contrast binary map where active bits appear white and inactive bits appear black.

Sensor Diagnostic Applications

Using -evaluate And to slice sensor data provides critical hardware diagnostics:

  • Stuck Bits and ADC Linearity: A defective ADC column or bit register will display vertical lines or solid blocks of static values across specific bit planes.
  • Pattern Noise Isolation: Fixed-Pattern Noise (FPN) and row/column banding artifacts often concentrate inside the lowest 2 to 3 bit planes, separate from visual scene content.
  • Firmware Padding and Alignment: Many raw formats pack 12-bit or 14-bit data inside 16-bit containers. Evaluating the upper bits reveals whether the camera manufacturer padded the data with zeros, left-aligned the bits, or embedded proprietary metadata in the unused spaces.
