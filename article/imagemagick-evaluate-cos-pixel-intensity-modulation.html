ImageMagick Evaluate Cos Pixel Intensity Modulation

The ImageMagick -evaluate Cos operator transforms image pixel values using a trigonometric cosine function, mapping input channel values to smooth, oscillating intensity waves. By applying this operator to a pre-existing intensity gradient across an image grid, linear changes in brightness are converted into periodic sinusoidal patterns scaled precisely to the system's dynamic range.

The Mathematical Transformation

ImageMagick processes pixel intensities using an internal dynamic scale called QuantumRange (typically 0 to 255 for 8-bit installations, or 0 to 65535 for 16-bit installations). The -evaluate Cos operation normalizes the input intensity, applies the cosine function scaled by a frequency multiplier, and rescales the output back to the full dynamic range.

The formula applied to each channel value (\(I_{\text{in}}\)) is:

\[I_{\text{out}} = \text{QuantumRange} \times \left[ 0.5 \times \cos\left(2\pi \times \text{frequency} \times \frac{I_{\text{in}}}{\text{QuantumRange}}\right) + 0.5 \right]\]

In this function:

  • \(\frac{I_{\text{in}}}{\text{QuantumRange}}\) maps the input pixel intensity to the normalized range \([0.0, 1.0]\).
  • The parameter supplied to Cos acts as the frequency factor, determining how many complete cycles occur over the dynamic range.
  • The factor of \(2\pi\) converts the normalized value into radians.
  • Scaling by \(0.5\) and adding \(0.5\) shifts the cosine range from \([-1.0, 1.0]\) to \([0.0, 1.0]\), preventing negative clipping and ensuring full dynamic utilization.
  • Multiplying by QuantumRange restores standard integer or floating-point pixel representation.

Spatial Modulation Across the Grid

The -evaluate operator acts on pixel values rather than spatial coordinates (\(x, y\)). Therefore, spatial modulation across an image grid relies on the underlying distribution of pixel values already present in the canvas.

Linear Gradients

When applied to a linear horizontal gradient where pixel intensity increases from left to right (\(0 \to \text{QuantumRange}\)):

  • An argument of 1 produces one full cosine cycle: starting at maximum intensity (white), dropping to minimum (black) in the center, and returning to maximum at the far edge.
  • An argument of \(N\) generates \(N\) complete alternating light and dark bands (fringes) across the grid.

Radial and Complex Gradients

When applied to non-linear intensity structures:

  • Radial Gradients: Modulating a center-to-edge radial gradient produces concentric rings (Airy-disk-like patterns).
  • Two-Dimensional Coordinates: Applying the operation to combined \(X\) and \(Y\) gradients creates interference grids or checkerboard-style ripples.
  • Natural Images: Applying the command to a standard photograph maps smooth tonal transitions into topographical-style contours, creating a solarized or psychedelic banding effect wherever luminance varies smoothly.

Frequency Control and Phase

The scalar parameter supplied to -evaluate Cos dictates the frequency of the modulation:

  • Fractional Frequencies (e.g., 0.5): Traverses only half a cosine wave over the input range, converting a linear black-to-white transition into a smooth transition from white to black.
  • Integer Frequencies (e.g., 2, 5, 10): Multiplies the density of the fringe cycles across the spatial gradient, producing tighter oscillations between dynamic limits.
  • Phase Offset: Because standard cosine starts at peak amplitude when the input is \(0\), an input of zero intensity results in maximum brightness. To achieve a sine response (starting at zero intensity), you must pre-offset or post-offset the intensity using -evaluate Add or chain complementary transformations.
