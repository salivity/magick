ImageMagick Evaluate OR with Binary Mask

Applying the ImageMagick -evaluate Or operator against a binary mask performs a bitwise OR operation between each pixel's color channel values and a specified operand. In a binary mask context—where pixels exist purely as fully off (black, value 0) or fully on (white, maximum quantum value)—this operation selectively sets binary bits to 1. As a result, fully white pixels remain permanently saturated, while black pixels adopt the exact bit pattern of the applied value, transforming the mask's contrast and tone.

The Bitwise OR Mechanism

ImageMagick processes pixel intensities using integers scaled to the build's quantum depth (typically Q16 with values from 0 to 65,535, or Q8 with values from 0 to 255). The -evaluate Or <value> command compares the binary representation of each pixel's current channel value to the binary representation of <value>:

  • 0 OR 0 = 0
  • 0 OR 1 = 1
  • 1 OR 0 = 1
  • 1 OR 1 = 1

The result of this operation replaces the original pixel value for every targeted channel.

Transformation of Binary Mask Pixels

When you execute -evaluate Or <value> directly on a binary mask, the transformation depends on whether the pixel starts as black or white:

  • White Pixels (Maximum Quantum Range): In a standard binary mask, white pixels have all bits set to 1 (e.g., 11111111 in 8-bit). Performing a bitwise OR with any integer leaves all bits at 1. Consequently, white pixels undergo zero change and remain pure white.
  • Black Pixels (Zero): Black pixels have all bits set to 0 (00000000). Performing a bitwise OR against zero yields the operand itself (0 | value = value). Black areas are therefore lifted directly to the numerical intensity of the provided operand.

For example, if you run -evaluate Or 50% on a binary mask, the white pixels remain at 100% white, while the black pixels shift immediately to 50% gray.

Evaluating an Image Against a Binary Value

If the operation is instead conceptualized as evaluating an arbitrary image using binary values (0 or the maximum quantum limit):

  • Evaluating with 0 (-evaluate Or 0): Pixels remain entirely unchanged because X | 0 = X.
  • Evaluating with Max (-evaluate Or QuantumRange): Every bit is set to 1 across all channels, instantly converting the entire image into a flat, solid white canvas.

Key Takeaway

Applying -evaluate Or to a binary mask acts as a non-destructive floor raiser: it raises the baseline brightness of black regions to the specified value while guaranteeing that white regions stay strictly clamped to their maximum ceiling.
