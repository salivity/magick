ImageMagick Evaluate Pow for Custom Gamma Correction

This article provides a quick overview and practical guide on using ImageMagick's -evaluate Pow operator to perform custom gamma corrections. By applying a power-law transformation directly to normalized pixel values, the Pow operator gives you exact mathematical control over the luminance curve of an image. You will learn the underlying mathematical relationship between gamma and power functions, the standard command syntax, and how to target specific color channels.

Understanding Power-Law and Gamma Correction

Gamma correction follows the standard power-law equation:

\[V_{\text{out}} = V_{\text{in}}^\gamma\]

In ImageMagick, image pixels are evaluated on a normalized scale where 0.0 represents pure black and 1.0 represents pure white (the maximum quantum depth).

The native -gamma operator in ImageMagick uses the inverse of the value you supply (i.e., it computes \(V_{\text{in}}^{1/\gamma}\)). This means a command like -gamma 2.0 brightens the image by applying an exponent of 0.5.

By contrast, the -evaluate Pow operator applies the exact exponent you specify directly:

  • Exponent < 1.0 (e.g., 0.5): Brightens midtones and lifts shadows.
  • Exponent = 1.0: Leaves pixel values unchanged.
  • Exponent > 1.0 (e.g., 2.2): Darkens midtones and expands contrast in highlights.

Basic Syntax

For ImageMagick v7, use the magick command:

magick input.jpg -evaluate Pow <exponent> output.jpg

For ImageMagick v6, replace magick with convert:

convert input.jpg -evaluate Pow <exponent> output.jpg

Practical Examples

1. Standard Gamma Decoding (Linearization)

To decode an sRGB image with a standard 2.2 gamma curve into linear light for computational processing, apply an exponent of 2.2:

magick input.jpg -evaluate Pow 2.2 linear_output.png

2. Standard Gamma Encoding

To return a linear image back to a display-ready gamma of 2.2, raise the pixels to the reciprocal power (\(1 / 2.2 \approx 0.4545\)):

magick linear_output.png -evaluate Pow 0.4545 display_output.jpg

3. Brightening Underexposed Midtones

To lift shadows and midtones without clipping pure highlights or crushing pure blacks, use a power value between 0.0 and 1.0:

magick dark_photo.jpg -evaluate Pow 0.7 brightened_photo.jpg

Channel-Specific Gamma Adjustments

The -evaluate Pow operator respects channel restrictions. You can adjust the gamma curve of individual color channels independently to correct color casts or create stylized color grades:

magick input.jpg -channel R -evaluate Pow 0.8 +channel warmer_output.jpg

In this command:

  • -channel R limits subsequent operations to the Red channel.
  • -evaluate Pow 0.8 lifts the midtones of the Red channel.
  • +channel resets channel selection back to default so subsequent operations affect all channels normally.
