ImageMagick Evaluate Sequence Multiply Explained

This article provides an overview of the evaluate-sequence Multiply operator in ImageMagick, explaining its core function, mathematical behavior, and practical applications. Readers will learn how this operator processes multiple images simultaneously to perform tasks such as sequence blending, masking, and technical image attenuation.

The evaluate-sequence Multiply operator collapses a list of two or more images into a single output image by multiplying the corresponding color channel values of each pixel across the entire sequence. Instead of processing images in separate pairwise steps, ImageMagick evaluates the entire stack sequentially at each coordinate position.

Mathematical Behavior

ImageMagick treats pixel values on a normalized scale from 0.0 (completely black/no intensity) to 1.0 (maximum intensity/white), scaled according to the installation's Quantum depth. When using Multiply:

  • Any pixel multiplied by 0.0 (black) results in 0.0 (black).
  • Any pixel multiplied by 1.0 (white) remains unchanged.
  • Values between 0.0 and 1.0 result in a smaller product, creating a darker output.

Because normalized fractions multiplied together always yield a smaller or equal fraction, applying evaluate-sequence Multiply will consistently darken overlapping areas unless one of the pixels is at maximum intensity.

Primary Use Cases

  1. Stack-Wide Multiply Blending: In graphic design, the "Multiply" blend mode is commonly used to combine layers while preserving dark tones. The evaluate-sequence Multiply command replicates this blend mode across three or more images in a single command without the need to chain multiple -composite operations.
  2. Sequential Masking: Multiplying an image stack against a grayscale or binary matte allows users to cut out backgrounds or restrict multiple layers to specific geometric areas. Black regions in the mask zero out underlying pixels entirely.
  3. Scientific and Technical Imaging: The operator is widely used in scientific imaging to compute light transmission through multiple sequential filters, model optical attenuation, or apply flat-field correction frames where values must scale proportionally across an image series.

Basic Syntax Example

To run the operator across a series of images, load all source files in the command line and call -evaluate-sequence Multiply before specifying the final output file:

magick frame1.png frame2.png frame3.png -evaluate-sequence Multiply output.png

ImageMagick reads all specified inputs into memory, calculates the product of each pixel's color channels across the stack, and outputs the collapsed result to output.png.
