ImageMagick Evaluate Sequence RootMeanSquare Math

This article breaks down the mathematical calculation executed by the ImageMagick -evaluate-sequence RootMeanSquare command. You will learn how this operator processes multiple images down to a single output image, the precise algebraic formula applied to each pixel channel, and how quantum depth influences the computation.

The ImageMagick -evaluate-sequence RootMeanSquare operator aggregates a series of \(N\) input images into a single composite image by calculating the root mean square (quadratic mean) of pixel values at identical \((x, y)\) coordinates across the entire image sequence.

The Mathematical Formula

For any given pixel coordinate \((x, y)\) and individual color channel (such as Red, Green, Blue, or Alpha), the resulting intensity value \(P_{RMS}\) is computed using the following formula:

\[P_{RMS}(x, y) = \sqrt{\frac{1}{N} \sum_{i=1}^{N} [P_i(x, y)]^2}\]

Where:

  • \(N\): The total number of images in the input sequence.
  • \(P_i(x, y)\): The channel intensity value of the pixel at coordinates \((x, y)\) in the \(i\)-th image.
  • \(\sum_{i=1}^{N}\): The sum of the squared pixel values across all images in the sequence.
  • \(P_{RMS}(x, y)\): The resulting channel intensity value for the pixel in the output image.

Step-by-Step Calculation Process

  1. Per-Channel Processing: The operation executes independently on each active color channel defined by the -channel setting. If an image has RGB channels, the formula runs separately for Red, Green, and Blue.
  2. Squaring Values: For each corresponding pixel across all \(N\) images, the channel's intensity value is squared (\(P_i^2\)).
  3. Calculating the Mean: The squared values are summed together and divided by the image count \(N\), yielding the mean of the squares (Mean Square).
  4. Taking the Square Root: The square root of the resulting mean is calculated to produce the final root mean square value.
  5. Quantum Representation: In ImageMagick, pixel values are internally represented according to the build's Quantum Depth (typically Q8 with values from 0 to 255, or Q16 with values from 0 to 65535, often normalized internally to a floating-point range of \([0.0, 1.0]\)). The computation occurs within this floating-point range and is mapped back to the output image's quantum range, preventing intermediate rounding errors.

Practical Effect on Pixels

Unlike a standard arithmetic average (-evaluate-sequence Mean), which weights all pixel values linearly, the Root Mean Square operator gives greater weight to higher values due to the initial squaring step. Consequently, areas with bright highlights or high-contrast variations across the image sequence will produce a brighter result than a standard arithmetic average.
