ImageMagick Evaluate-Sequence with Mismatched Sizes

This article explains how ImageMagick's -evaluate-sequence operator behaves when supplied with input images of varying dimensions. It details how the output canvas is established, how overlapping and non-overlapping pixel areas are calculated, and how to properly normalize image sets to prevent unexpected visual artifacts.

Canvas Sizing Follows the First Image

When executing -evaluate-sequence across a series of images, ImageMagick uses the first image in the sequence as the reference canvas. The output image inherits its width, height, color space, and metadata directly from this primary image.

If subsequent images have different dimensions, ImageMagick does not automatically scale, stretch, or expand the canvas to fit the largest boundaries. Instead, it maps all subsequent images starting from the default origin coordinate (0,0), unless a virtual canvas offset (+repage or -page) is explicitly defined.

Behavior with Larger Secondary Images

If an image later in the sequence is larger than the first image:

  • Clipping: ImageMagick only processes pixels within the bounding box of the first image.
  • Ignored Data: Any pixel data extending beyond the width or height of the first image is completely ignored and clipped from the calculation.

Behavior with Smaller Secondary Images

If an image later in the sequence is smaller than the first image:

  • Partial Evaluation: Pixels that fall within the bounds of the smaller image are evaluated normally according to the chosen arithmetic or logical function (such as Mean, Add, or Max).
  • Out-of-Bounds Areas: For regions of the canvas where the smaller image does not exist, ImageMagick treats the missing pixels as having no data or zero/transparent values depending on the channel and the specific operation.

This partial coverage often creates distinct artifacts. For example, using Mean across mismatched sizes will cause noticeable exposure borders, as areas covered by fewer images are averaged differently than fully overlapping areas.

Best Practices for Consistent Results

To avoid unexpected clipping or edge seams, ensure that all input images share identical pixel dimensions before applying -evaluate-sequence. Common preparation methods include:

  • Resizing: Use -resize or -scale to bring all images to a uniform resolution.
  • Canvas Extension: Use -extent along with -gravity center (or another anchor) to pad smaller images with transparent or solid color borders to match the target canvas size.
  • Resetting Offsets: Run +repage on input files to eliminate any lingering virtual canvas offsets that might cause misaligned overlays.
