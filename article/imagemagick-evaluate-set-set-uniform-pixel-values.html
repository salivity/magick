ImageMagick Evaluate Set: Set Uniform Pixel Values

This article explains how the -evaluate Set operator in ImageMagick overwrites pixel channel data to establish a uniform numeric constant across an image. You will learn the mechanics behind this command, how it interacts with quantum ranges and color channels, and how ImageMagick processes raw numerical and percentage inputs to alter pixel memory directly.

The Mechanism of -evaluate Set

The -evaluate operator in ImageMagick provides command-line access to arithmetic and logical operations applied directly to image channels. When paired with the Set method, it acts as an absolute assignment operator rather than a modifier. Unlike operations such as Add, Multiply, or Divide, which read the existing pixel value, calculate an offset, and write the result, Set completely ignores the original pixel data. It assigns the specified constant value uniformly across all targeted pixels in the image buffer.

Quantum Depth and Value Interpretation

ImageMagick processes pixel intensities using an internal scale defined by its compile-time quantum depth (typically Q8 or Q16, with integer or floating-point variations). The maximum representable value is referred to as QuantumRange:

  • Q8: Values range from 0 to 255.
  • Q16: Values range from 0 to 65535.

When you supply an argument to -evaluate Set, ImageMagick interprets the input in one of two ways:

  1. Percentages: Appending a % symbol (such as -evaluate Set 50%) forces ImageMagick to calculate the target value as a normalized percentage of QuantumRange. On a Q16 build, 50% sets every targeted channel value directly to 32767.5.
  2. Raw Integers or Floats: Supplying an absolute number without a percentage sets the channel to that exact raw value, clamped between 0 and QuantumRange. For instance, running -evaluate Set 128 on a Q16 image sets the channel to 128 out of 65535, resulting in a nearly black pixel rather than mid-gray.

Channel Targeting and Masking

The assignment behavior of -evaluate Set is strictly bound to the active channel mask controlled by the -channel option:

  • Default Masking: If no channel mask is defined, the command applies to default color channels (such as Red, Green, and Blue), leaving the Alpha (transparency) channel unmodified.
  • Explicit Masking: By preceding the command with -channel, you can isolate specific channels. For example, using -channel A -evaluate Set 100% overrides the alpha channel completely, making an image fully opaque without altering underlying RGB color information. Conversely, -channel R -evaluate Set 0 completely zeroes out the red channel, leaving green, blue, and alpha untouched.

Execution Flow in Memory

When executed, ImageMagick iterates over the pixel cache of the specified image via a nested loop covering image height and width. For each pixel coordinate within the loop, ImageMagick checks the channel mask. For every active channel, it replaces the existing memory byte or floating-point representation with the calculated uniform constant. Because there are no intermediate arithmetic steps or pixel-to-pixel dependencies, the operation executes rapidly and produces a strictly flat, uniform value across the designated channels.
