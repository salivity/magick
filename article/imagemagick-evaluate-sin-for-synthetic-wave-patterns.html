ImageMagick Evaluate Sin for Synthetic Wave Patterns

The ImageMagick -evaluate Sin command applies a mathematical sine function to the intensity values of image pixels, converting linear data into periodic, oscillating curves. When applied to baseline images such as linear gradients, it alters continuous tonal transitions into recurring dark and bright bands. This functionality serves as a core method for algorithmically generating synthetic wave patterns, sinusoidal gratings, and procedural interference textures without relying on external assets.

How -evaluate Sin Works

The -evaluate operator modifies pixel values using mathematical functions. When using the Sin method, ImageMagick interprets the input pixel values as angles and calculates their sine:

pixel_output = sin(pixel_input * frequency)

The numeric argument provided after Sin defines the frequency factor. Because the sine function is naturally periodic, input values that scale linearly across the canvas produce an output that oscillates smoothly between maximum and minimum values.

Generating Waves from Linear Gradients

To create a synthetic wave pattern, -evaluate Sin is typically paired with a base gradient image.

  1. Creating the Input Ramp: A command like gradient: produces a surface where pixel values increase continuously from 0.0 (black) to 1.0 (white) along an axis.
  2. Applying the Function: When -evaluate Sin [value] processes this gradient, it samples the sine wave along the slope. A higher frequency argument increases the number of complete sine cycles over the dimensions of the image, creating denser wave bands.
  3. Value Mapping: Standard sine calculations produce outputs between -1.0 and 1.0. ImageMagick maps and normalizes these values within the dynamic range of the target color depth (such as 8-bit or 16-bit quantum ranges), translating negative results into troughs (black) and positive results into crests (white).

Common Applications

  • Sinusoidal Gratings: Producing clean, mathematically accurate optical test patterns to measure modulation transfer functions (MTF) and optical sharpness.
  • Ripple and Wave Textures: Generating base maps for displacement mapping, water simulations, or surface caustics.
  • Interference Patterns: Combining multiple rotated or scaled sine gradients using blend modes to simulate Moire patterns or physical wave interference.
