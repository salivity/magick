ImageMagick Evaluate Sine Function Guide

This guide explains how to apply sine function modulation to pixel values using ImageMagick's -evaluate operator. You will learn the underlying mathematical formula the software applies, the basic command-line syntax, and how to control modulation frequency across full images or individual color channels.

How the Evaluate Sine Function Works

In ImageMagick, the -evaluate Sine operator processes the intensity of each pixel on a normalized scale from 0.0 (black) to 1.0 (full intensity/white). The operator transforms the original normalized pixel value (\(u\)) using the following formula:

\[\text{Output} = 0.5 + 0.5 \times \sin(2\pi \times \text{frequency} \times u)\]

Because the raw sine wave fluctuates between -1 and 1, ImageMagick scales and shifts the result to ensure pixel data remains within the valid display range of 0.0 to 1.0.

Basic Command Syntax

To apply sine modulation across an entire image, pass the Sine argument along with a frequency value to the -evaluate option.

For ImageMagick version 7:

magick input.jpg -evaluate Sine 1 output.jpg

(Note: If you are using ImageMagick version 6, replace magick with convert.)

Frequency Values

  • Frequency = 1: Completes one full sine wave cycle across the input range from 0 to 1. Low input values start at mid-gray (0.5), rise to peak brightness (1.0) at a quarter intensity, return to mid-gray at half intensity, dip to black (0.0) at three-quarters intensity, and end at mid-gray.
  • Frequency = 0.5: Produces half of a sine cycle, mapping shadows to mid-gray, midtones to bright highlights, and highlights back to mid-gray.
  • Frequency > 1: Compresses multiple sine cycles into the input brightness range, creating posterized bands and solarization-like effects.

Applying Sine Modulation to Specific Channels

Modulating all channels simultaneously alters brightness while preserving general chromaticity. To create color shifts or interference patterns, restrict the evaluation to specific color channels using the -channel flag.

Apply modulation exclusively to the red channel:

magick input.jpg -channel R -evaluate Sine 2 +channel output.jpg

Apply modulation to the green and blue channels:

magick input.jpg -channel GB -evaluate Sine 1.5 +channel output.jpg

Always include +channel after the -evaluate operation to reset channel limits for any subsequent processing steps.

Generating Gradients with Sine Modulation

A common use of sine modulation is generating smooth, oscillating light bars from a basic linear gradient.

magick -size 500x100 gradient: -evaluate Sine 4 output_wave.png

In this example:

  1. -size 500x100 gradient: generates a smooth left-to-right linear transition from white to black.
  2. -evaluate Sine 4 modulates the linear gradient across four complete wave cycles, producing an alternating pattern of dark and light bands.
