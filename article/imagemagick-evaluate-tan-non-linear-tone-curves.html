ImageMagick -evaluate Tan Non-Linear Tone Curves

ImageMagick's -evaluate Tan operator applies a trigonometric tangent function directly to normalized pixel values, allowing you to generate aggressive, non-linear tone curves that dramatically alter image contrast. By manipulating input values through scaling, phase shifts, and normalization, you can use the tangent curve to create smooth shadow compressions, steep highlight expansions, and custom S-curve contrast profiles directly from the command line without relying on external lookup tables.

Understanding the Mathematics of the Tan Operator

In ImageMagick, image data is processed in a normalized range where black is 0.0 and pure white is 1.0 (scaled to the compile-time Quantum depth, such as Q16). When you execute -evaluate Tan <value>, ImageMagick multiplies the normalized pixel intensity by the supplied argument and calculates the tangent of the resulting value in radians:

\[\text{Output} = \tan(\text{Pixel} \times \text{Value})\]

The tangent function behaves almost linearly near zero (\(\tan(x) \approx x\)), but curves exponentially upward as the angle approaches \(\frac{\pi}{2}\) radians (\(\approx 1.5708\)). This mathematical property allows you to leave dark shadows relatively unchanged while sharply stretching midtones and highlights.

Managing Clipping and Dynamic Range

Because \(\tan\left(\frac{\pi}{4}\right) = \tan(0.7854) = 1.0\), passing any multiplier larger than \(\approx 0.7854\) will cause highlights to exceed the maximum display range (\(1.0\)), resulting in clipped white pixels.

To create a valid tone curve without uncontrolled clipping, you must scale the values back into the [0, 1] range by dividing the output by the tangent of the chosen multiplier:

magick input.png -evaluate Tan 1.2 -evaluate Divide 2.572 output.png

In this example, \(1.2\) radians acts as the curve strength. Because \(\tan(1.2) \approx 2.572\), dividing by \(2.572\) normalizes the white point back to \(1.0\). This produces a non-linear curve that compresses shadows and dramatically lifts contrast in the upper-midtones.

Constructing an S-Curve Using Tan

Standard contrast enhancement typically relies on an S-curve, which symmetrically darkens shadows and brightens highlights around a central midtone pivot (\(0.5\)). While a raw tangent curve only bends in one direction, you can center it to form an S-curve by shifting the pixel values before and after applying the operator:

  1. Shift the midpoint to zero: Subtract \(0.5\) so the range becomes [-0.5, 0.5].
  2. Apply the tangent: Multiply by an angle factor to determine the steepness.
  3. Normalize: Divide by the maximum amplitude achieved at \(0.5\).
  4. Restore the range: Add \(0.5\) to return the image to the standard [0, 1] display range.
magick input.png \
    -evaluate Subtract 50% \
    -evaluate Tan 2.0 \
    -evaluate Divide 3.114 \
    -evaluate Add 50% \
    output.png

In this command:

  • Subtracting 50% places the midtones at \(0.0\), shadows into negative values, and highlights into positive values.
  • Applying -evaluate Tan 2.0 scales the input domain to [-1.0, 1.0] radians.
  • Because \(\tan(1.0) \approx 1.5574\), the overall dynamic spread is doubled to approximately \(3.114\). Dividing by \(3.114\) scales the contrast back down.
  • Adding 50% repositions the midpoint at \(0.5\).

Channel-Specific Adjustments

You can restrict the -evaluate Tan operator to specific color channels using the -channel flag. This allows the non-linear tonal curve to function as a color grading tool:

magick input.png -channel R -evaluate Tan 1.1 -evaluate Divide 1.965 +channel output.png

Applying the transformation exclusively to the red channel introduces non-linear warmth into the brighter areas of the image while keeping neutral shadows intact, simulating traditional film-stock split toning.
