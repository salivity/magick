ImageMagick Exclusion Blending on Overlapping Layers

The ImageMagick Exclusion blending operator combines two overlapping images by producing an effect similar to Difference, but with lower contrast and softer transitions. This guide explains how the Exclusion composite operator works and provides direct command-line examples for blending both two-image compositions and multi-layer stacks using ImageMagick version 7 and version 6.

How the Exclusion Blending Mode Works

The Exclusion operator calculates the output color using the mathematical formula:

\[\text{Result} = A + B - (2 \times A \times B)\]

Where \(A\) is the destination (background) pixel and \(B\) is the source (overlay) pixel, normalized between 0 and 1.

  • Blending with white inverts the underlying color.
  • Blending with black leaves the underlying color unchanged.
  • Blending with 50% gray produces a neutral 50% gray result.

Basic Two-Layer Exclusion Blend

To blend a top layer onto a bottom layer using the Exclusion operator, set the -compose method to Exclusion and apply -composite.

ImageMagick v7:

magick background.png overlay.png -compose Exclusion -composite output.png

ImageMagick v6:

convert background.png overlay.png -compose Exclusion -composite output.png

Positioning the Overlapping Layer

If the overlapping layer is smaller than the background or needs specific placement, use the -geometry flag to set offset coordinates:

magick background.png overlay.png -geometry +100+50 -compose Exclusion -composite output.png

This places overlay.png at an X-offset of 100 pixels and a Y-offset of 50 pixels from the top-left corner before applying the Exclusion blend.

Blending Multiple Overlapping Layers

When working with three or more overlapping layers, you can chain the operations sequentially in a single command using parenthesized expressions.

magick base.png \
  \( layer1.png -geometry +50+50 \) -compose Exclusion -composite \
  \( layer2.png -geometry +120+80 \) -compose Exclusion -composite \
  final_composite.png

Each subsequent layer is blended using the Exclusion mode against the accumulated result of the previous layers.

Adjusting Opacity for Softer Blending

To control the strength of the Exclusion effect, reduce the alpha/opacity of the overlay layer before compositing:

magick background.png \
  \( overlay.png -channel A -evaluate multiply 0.5 +channel \) \
  -compose Exclusion -composite output_soft.png

This scales the overlay opacity to 50%, resulting in a milder Exclusion blend over the background image.
