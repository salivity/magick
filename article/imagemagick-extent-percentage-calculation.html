ImageMagick Extent Percentage Calculation

This article explains how ImageMagick evaluates percentage-based values when resizing or extending canvas boundaries using the -extent operator. When percentages are supplied in the geometry argument, ImageMagick dynamically derives new pixel dimensions from the original image boundaries and aligns the content according to the active gravity setting. Below is the precise mathematical formula, geometry parsing behavior, and offset logic applied during this operation.

Base Dimension Calculation

When you specify a percentage geometry (for example, -extent 150%x150% or -extent 120%), ImageMagick calculates the target canvas size relative to the original image dimensions using the following linear formulas:

\[\text{New Width} = \text{round}\left(\text{Original Width} \times \frac{\text{Percentage}_w}{100}\right)\]

\[\text{New Height} = \text{round}\left(\text{Original Height} \times \frac{\text{Percentage}_h}{100}\right)\]

If a single percentage value is passed without a separator (such as -extent 150%), ImageMagick applies that single percentage to both the horizontal and vertical axes simultaneously.

Floating-Point Precision and Rounding

Internally, ImageMagick’s geometry parser (ParseRegionGeometry or GetGeometry) multiplies the existing image column count (image->columns) and row count (image->rows) by the parsed scale factor (percentage / 100.0). The resulting floating-point value is converted to a size integer using rounding to the nearest whole integer pixel. Fractions of \(0.5\) or greater round up to the next integer.

Positioning and Offset Calculation

The -extent operator does not stretch or resample image pixels; it only resizes the canvas area. Once the new canvas dimensions are determined, ImageMagick determines where to place the original pixels within the new canvas based on the defined -gravity setting.

The coordinate offsets (\(X\) and \(Y\)) determine where the top-left corner of the original image sits relative to the top-left corner of the new canvas:

  • NorthWest (Default): \[X_{\text{offset}} = 0, \quad Y_{\text{offset}} = 0\]
  • Center: \[X_{\text{offset}} = \text{round}\left(\frac{\text{New Width} - \text{Original Width}}{2}\right)\] \[Y_{\text{offset}} = \text{round}\left(\frac{\text{New Height} - \text{Original Height}}{2}\right)\]
  • SouthEast: \[X_{\text{offset}} = \text{New Width} - \text{Original Width}\] \[Y_{\text{offset}} = \text{New Height} - \text{Original Height}\]

Any empty area outside the original image bounds is filled with the color currently set by the -background setting (defaulting to white or transparent depending on format and configuration).
