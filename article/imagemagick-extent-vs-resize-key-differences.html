ImageMagick -extent vs -resize: Key Differences

While both -resize and -extent change an image's final dimensions in ImageMagick, they operate on different principles: -resize scales the image content up or down using pixel resampling, while -extent changes the dimensions of the canvas itself, adding padding or cropping content without scaling the original artwork. Understanding the distinction between scaling image data and adjusting canvas boundaries is essential for effective batch image processing.

The -resize Operator

The -resize operator scales the visual content of an image. It increases or decreases the number of pixels, altering the actual size of the subjects in the image via interpolation algorithms.

  • Behavior: By default, -resize preserves the aspect ratio. If you provide dimensions like 800x600, ImageMagick scales the image so it fits within that bounding box without distortion.
  • Canvas Effect: The canvas size matches the newly scaled image dimensions exactly.
  • Common Use Cases: Creating thumbnails, optimizing high-resolution photos for web display, and scaling images to standard display resolutions.
magick input.jpg -resize 800x600 output.jpg

The -extent Operator

The -extent operator adjusts the canvas size (the bounding box) without altering the scale of the existing image pixels.

  • Behavior: It sets the total output dimensions. If the new dimensions are larger than the original image, ImageMagick fills the extra space with the background color (defined by -background). If the new dimensions are smaller, the image is cropped.
  • Canvas Effect: The original image content maintains its 1:1 scale; only the surrounding borders or visibility are altered.
  • Positioning: The alignment of the image within the new canvas is controlled using the -gravity setting (e.g., -gravity center).
  • Common Use Cases: Creating uniform square thumbnails with letterboxing/pillarboxing, adding solid borders, and cropping an image to fixed canvas dimensions.
magick input.jpg -gravity center -background white -extent 800x800 output.jpg

Summary of Differences

  • Pixel Scaling: -resize resamples and scales pixels; -extent does not scale pixels.
  • Content Alteration: -resize changes the size of the subject; -extent crops the subject or pads around it with a background color.
  • Aspect Ratio: -resize fits the image within target dimensions proportionally; -extent strictly forces the canvas to the specified width and height.

Combining Both Operators

A common workflow in ImageMagick is combining -resize and -extent to create uniformly sized, centered images for galleries or product listings:

magick input.jpg -resize 500x500 -gravity center -background black -extent 500x500 output.jpg

In this command, -resize scales the image to fit proportionally within a 500x500 box, and -extent adds black padding to ensure the final output file is precisely 500x500 pixels.
