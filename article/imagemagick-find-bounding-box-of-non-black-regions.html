ImageMagick Find Bounding Box of Non-Black Regions

Finding the coordinates and dimensions of non-black regions in an image is a common requirement in image processing workflows. ImageMagick accomplishes this efficiently by analyzing pixel data against a black background using the trim operator's bounding box calculation or connected-components labeling. This guide demonstrates the primary commands used to output the exact bounding box coordinates for both single aggregated non-black regions and multiple distinct objects.

Find the Overall Bounding Box of All Non-Black Pixels

To calculate the single bounding box that encloses all non-black pixels in an image, use the %@ format escape sequence with ImageMagick 7:

magick input.png -format "%@" info:

(For ImageMagick 6, replace magick with convert or identify.)

How It Works:

  • %@: Calculates the trim bounding box geometry and outputs it in the standard X11 geometry format: WidthxHeight+X_Offset+Y_Offset (e.g., 450x300+25+50).
  • info:: Outputs the metadata to the standard output without writing an image file to disk.

Handling Near-Black or Compressed Artifacts

If the background is not pure #000000 due to compression artifacts, add the -fuzz option to define a tolerance threshold:

magick input.png -fuzz 5% -format "%@" info:

Find Bounding Boxes for Multiple Distinct Non-Black Regions

If the image contains several separate non-black shapes and individual bounding boxes are required for each, use the Connected Components module:

magick input.png \
  -threshold 0 \
  -define connected-components:verbose=true \
  -define connected-components:area-threshold=10 \
  -connected-components 8 \
  null:

Explanation of Arguments:

  • -threshold 0: Converts all non-black pixels to white and leaves pure black pixels as black.
  • -define connected-components:verbose=true: Prints the details of each detected component to standard output.
  • -define connected-components:area-threshold=10: Ignores noise smaller than 10 pixels.
  • -connected-components 8: Groups connected neighboring pixels (8-way connectivity).
  • null:: Discards the image output since only text metadata is needed.

Output Interpretation:

The connected components output provides a table where each line represents a detected region:

Objects (id: bounding-box centroid area, color):
  0: 1000x800+0+0 498.2,399.1 785000 srgb(0,0,0)
  1: 120x80+45+60 104.5,99.8 9600 srgb(255,255,255)
  2: 50x50+300+400 324.5,424.5 2500 srgb(255,255,255)

In this output, object 0 is the black background, while lines with srgb(255,255,255) provide the bounding box geometries (WidthxHeight+X+Y) for each separate non-black object.
