ImageMagick Fisheye Lens Distortion Command

Simulating a fish-eye lens effect in ImageMagick is achieved by applying a radial barrel distortion to an image. This guide provides the exact command-line syntax using the -distort Barrel operator, explains the underlying parameters, and shows how to adjust the intensity of the distortion for both modern ImageMagick v7 and legacy ImageMagick v6.

The Fisheye Command

To apply a standard fish-eye lens distortion, use the following command:

magick input.jpg -virtual-pixel Black -distort Barrel "0.0 0.0 0.5 0.5" output.jpg

(For ImageMagick v6, replace magick with convert.)

Understanding the Parameters

The -distort Barrel method uses four polynomial coefficients to remap pixel coordinates: A B C D. The formula calculates the new radial distance \(R_{src} = r \cdot (A \cdot r^3 + B \cdot r^2 + C \cdot r + D)\), where \(r\) is the normalized distance from the center.

  • A, B, C: Control the degree of non-linear curvature. Increasing the C parameter while lowering D creates a classic convex fisheye bulge.
  • D: Controls the overall image scaling. For proper scaling without automatic resizing, the sum of \(A + B + C + D\) should equal 1.0.
  • -virtual-pixel Black: Fills the empty areas outside the distorted image frame with black, mimicking the circular lens hood of a physical fisheye camera.

Adjusting the Distortion Intensity

You can adjust the coefficients to change the severity of the effect:

  • Moderate Fisheye: 
    magick input.jpg -virtual-pixel Black -distort Barrel "0.0 0.0 0.3 0.7" output.jpg
  • Strong Fisheye: 
    magick input.jpg -virtual-pixel Black -distort Barrel "0.2 0.0 0.4 0.4" output.jpg

Creating a Circular Fisheye Effect

To simulate an ultra-wide, circular fisheye lens where the entire circle fits inside the image frame, crop the input to a square first and increase the curvature:

magick input.jpg -gravity center -crop 1:1 +repage -virtual-pixel Black -distort Barrel "0.0 0.0 0.6 0.4" output.jpg
