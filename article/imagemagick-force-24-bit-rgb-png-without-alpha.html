ImageMagick Force 24-Bit RGB PNG Without Alpha

This article explains how to force ImageMagick to output 24-bit RGB PNG files without transparency or an alpha channel. By default, ImageMagick automatically selects the most compact or appropriate PNG subtype, which can result in unwanted 8-bit indexed palettes or 32-bit RGBA formats. Using the -define png:color-type=2 or -define png:format=png24 options alongside proper alpha management guarantees a strictly truecolor 24-bit RGB file.

The Define Options

ImageMagick provides two primary define options to enforce an 8-bit per channel RGB PNG with no alpha channel:

  1. -define png:color-type=2
    In the PNG specification, Color Type 2 represents Truecolor (RGB), where each pixel is an R, G, B triple without an alpha channel. Setting this define forces the encoder to write color type 2.

  2. -define png:format=png24
    This define directly restricts the PNG encoder sub-format to PNG24, which is 8-bit RGB without transparency.

Disabling the Alpha Channel

Defining the color type alone may result in an error or unexpected output if the source image still carries active transparency data. To guarantee the alpha channel is stripped before encoding, use the -alpha off operator before defining the PNG parameters.

Command Examples

Using ImageMagick version 7 (using magick):

magick input.png -alpha off -define png:color-type=2 output.png

Alternatively, using the sub-format define:

magick input.png -alpha off -define png:format=png24 output.png

If using ImageMagick version 6 (using convert):

convert input.png -alpha off -define png:color-type=2 output.png

Alternative Format Prefix

ImageMagick also supports format prefixes on the output filename, which functionally mirrors the -define png:format=png24 directive:

magick input.png -alpha off PNG24:output.png

Verifying the Output

To verify that the output file is strictly 24-bit RGB with no alpha channel, inspect the file metadata using the identify command:

magick identify -verbose output.png

Check the properties output:

  • Type: TrueColor
  • Depth: 8-bit
  • Alpha: Not listed under Channels (only Red, Green, Blue should appear)
  • png:IHDR.color-type-str: 2 (RGB)
