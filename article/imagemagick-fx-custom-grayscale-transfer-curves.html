ImageMagick -fx Custom Grayscale Transfer Curves

ImageMagick's -fx operator allows you to manipulate pixel values at an individual level using custom mathematical expressions. This guide explains how to construct and apply custom grayscale transfer curves—ranging from simple power-law (gamma) adjustments to complex polynomial and sigmoidal functions—across all or specific image channels. By utilizing mathematical mapping functions on normalized pixel values, you can execute precise tonal shaping and color grading directly from the command line.

Understanding the -fx Coordinate Space

When using the -fx operator, ImageMagick evaluates mathematical expressions where pixel channel values are normalized to a floating-point range between 0.0 (black/minimum intensity) and 1.0 (white/maximum intensity):

  • u: Represents the current pixel value of the first image in the sequence.
  • u.r, u.g, u.b, u.a: Refer to specific Red, Green, Blue, and Alpha channels of the pixel.
  • Output: The evaluated result of your formula must produce a value between 0.0 and 1.0. Values outside this range are clipped.

Basic Transfer Curves

To apply a transfer curve globally to an image, pass your mathematical function directly to -fx.

1. Power-Law (Gamma) Curve

A standard gamma curve maps input \(u\) to \(u^\gamma\). Values of \(\gamma > 1\) darken midtones, while \(\gamma < 1\) brighten them:

magick input.jpg -fx "u^2.2" output_darkened.jpg
magick input.jpg -fx "u^(1/2.2)" output_brightened.jpg

2. Smoothstep (Cubic S-Curve)

A smoothstep curve adds contrast by compressing shadows and highlights while steepening the midtones using the polynomial \(3u^2 - 2u^3\):

magick input.jpg -fx "3*u^2 - 2*u^3" output_contrast.jpg

3. Custom Linear Segments (Threshold Curve)

You can use ternary conditional operators (condition ? true_val : false_val) to build piecewise transfer curves:

magick input.jpg -fx "u < 0.5 ? 2*u*u : 1 - 2*(1-u)*(1-u)" output_piecewise.jpg

Applying Curves to Specific Channels

To apply a curve to a single channel while leaving the other channels untouched, use the -channel setting before -fx and reset it afterward with +channel.

Example: Modifying the Red Channel Only

The following command applies a quadratic curve to the Red channel, increasing red saturation in brighter areas while preserving the Green and Blue channels:

magick input.jpg -channel R -fx "u^1.5" +channel output_red_modified.jpg

Example: Modifying Multiple Specific Channels

To apply the same curve to both Red and Blue channels simultaneously:

magick input.jpg -channel RB -fx "3*u^2 - 2*u^3" +channel output_split_toned.jpg

Multi-Channel Transfer Curves in a Single Expression

You can also construct complex transfer curves where the mapping of one channel depends on the input values of other channels, without using -channel.

Example: Inverting Blue Based on Luminance

This expression selectively darkens the blue channel where the red channel intensity is high:

magick input.jpg -fx "j==0 ? u.r : (j==1 ? u.g : u.b * (1 - u.r))" output_cross_channel.jpg

(Note: j denotes the channel index: 0 for Red, 1 for Green, 2 for Blue).

Performance Tip: Using FX via 1D LUT

Because -fx evaluates expressions on a per-pixel basis, running it on high-resolution images can be slow. To optimize performance:

  1. Generate a 1-pixel high, 256-pixel wide gradient.
  2. Apply the custom transfer curve to the gradient using -fx.
  3. Apply the modified gradient to your target image using -clut.
# 1. Create the transfer curve map
magick -size 256x1 gradient: -fx "3*u^2 - 2*u^3" curve_lut.png

# 2. Apply the transfer curve to high-resolution images instantly
magick large_image.jpg curve_lut.png -clut output_fast.jpg
