ImageMagick FX: Map Grayscale to Color Channels

This guide explains how to use ImageMagick's -fx operator to map custom mathematical transfer functions from a single-channel grayscale image to individual red, green, and blue color channels. By applying specific formulas per channel, you can create custom false-color mappings, thermal imaging effects, and specialized data visualizations directly from the command line.

Understanding the -fx Operator

The -fx operator evaluates mathematical expressions for every pixel in an image. Pixel values are normalized between 0.0 (black) and 1.0 (white). Within an expression, the primary input image is referenced as u.

When mapping a grayscale image to color, each target channel (Red, Green, Blue) receives a unique mathematical function of u:

  • Red Channel: \(R = f_r(u)\)
  • Green Channel: \(f_g(u)\)
  • Blue Channel: \(f_b(u)\)

Method 1: Channel-Specific -fx Processing

The most straightforward method is to select a specific channel using the -channel flag, apply the -fx formula, and repeat for the remaining channels.

magick input_gray.png -colorspace RGB \
  -channel R -fx "u^2" \
  -channel G -fx "sin(u * pi)" \
  -channel B -fx "1 - u" \
  +channel output_color.png

In this command:

  • -colorspace RGB ensures the image has three distinct color channels to write to.
  • -channel R -fx "u^2" applies a quadratic falloff to the red channel.
  • -channel G -fx "sin(u * pi)" maps midtones to green using a half-sine wave.
  • -channel B -fx "1 - u" creates an inverted linear mapping for blue.
  • +channel resets channel selection back to the default state before saving.

Method 2: Multi-Image Clone and Combine

Alternatively, you can generate each channel as a separate grayscale layer and combine them into a single RGB composite:

magick input_gray.png \
  \( -clone 0 -fx "u^0.5" \) \
  \( -clone 0 -fx "0.5 * (1 + sin(2 * pi * u - pi/2))" \) \
  \( -clone 0 -fx "exp(-4 * u)" \) \
  -delete 0 -combine output_color.png

In this workflow:

  1. Three cloned variations of the base image are processed with distinct equations.
  2. -delete 0 removes the original grayscale reference.
  3. -combine takes the three resulting images and merges them as R, G, and B channels respectively.

Common Transfer Functions for Pseudocoloring

You can construct various color scales by adjusting the mathematical functions:

  • Linear Ramps:
    • Standard: u
    • Inverted: 1 - u
  • Exponential & Gamma Adjustments:
    • High-end emphasize: u^3
    • Shadow emphasize: sqrt(u) or u^0.5
  • Localized Bands (Peaks):
    • Midtone bell curve: exp(-((u - 0.5)^2) / 0.05)
    • Periodic cycling: 0.5 * (1 + sin(2 * pi * f * u)) (where f is the frequency)
  • Thresholds & Steps:
    • Hard cutoff: u > 0.5 ? 1.0 : 0.0
    • Smoothstep: u * u * (3 - 2 * u)

Performance Note

The -fx operator is interpreted per pixel and can be slow on very large images. For batch processing large datasets with fixed transfer functions, consider generating a 1D gradient palette image using -fx once, and applying it to your grayscale images using the faster -clut (Color Look-Up Table) operator.
