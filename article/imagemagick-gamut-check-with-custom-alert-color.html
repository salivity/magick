ImageMagick Gamut Check With Custom Alert Color

Highlighting out-of-gamut pixels is a critical step in color proofing and print preparation workflows. This guide demonstrates how to detect colors that cannot be accurately reproduced in a target profile (such as a CMYK print space) and replace those pixels with a high-visibility custom alert color using ImageMagick.

The Gamut-Check Strategy

ImageMagick identifies out-of-gamut pixels by simulating a color transform round-trip:

  1. Convert the original image (e.g., in sRGB) to the target profile (e.g., a specific CMYK profile), where out-of-gamut values are clipped or remapped.
  2. Convert that result back to the original color space.
  3. Compare the original image with the round-tripped image to generate a difference mask.
  4. Overlay a custom alert color (such as bright magenta, cyan, or neon green) on top of the original image wherever the difference exceeds a chosen tolerance threshold.

ImageMagick Syntax

To perform this operation in ImageMagick v7, use the following syntax:

magick input.jpg \
  \( +clone -profile /path/to/sRGB.icc -profile /path/to/target.icc -profile /path/to/sRGB.icc \) \
  \( -clone 0,1 -compose Difference -composite -colorspace Gray -threshold 1% \) \
  -delete 1 \
  \( -clone 0 -fill "#FF00FF" -colorize 100% \) \
  -swap 1,2 \
  -composite \
  output_gamut_alert.jpg

Syntax Breakdown

  • input.jpg: The source image in its initial color space.
  • \( +clone -profile sRGB.icc -profile target.icc -profile sRGB.icc \): Creates an in-memory copy, converts it into the destination profile (clipping out-of-gamut colors), and converts it back to sRGB.
  • \( -clone 0,1 -compose Difference -composite -colorspace Gray -threshold 1% \): Compares the original image against the round-tripped version. Any pixel that shifted during the color conversion becomes white in the binary mask; matching pixels become black.
  • -threshold 1%: The tolerance level. Lower values (e.g., 0.5%) catch subtle shifts, while higher values (e.g., 2% to 5%) only flag severe out-of-gamut clipping.
  • -delete 1: Removes the intermediate round-tripped image from the stack to free memory.
  • \( -clone 0 -fill "#FF00FF" -colorize 100% \): Creates a solid layer of the custom alert color (hex code #FF00FF for magenta). Replace this value with any desired alert color, such as #00FF00 for lime green.
  • -swap 1,2 -composite: Uses the threshold difference mask to composite the solid alert color over the original image.

Exporting the Mask Only

If you only need a standalone black-and-white mask showing out-of-gamut areas (white pixels representing gamut warnings):

magick input.jpg \
  \( +clone -profile /path/to/sRGB.icc -profile /path/to/target.icc -profile /path/to/sRGB.icc \) \
  -compose Difference -composite \
  -colorspace Gray \
  -threshold 1% \
  gamut_mask.png
