ImageMagick Geometry with Height Only Explained

When working with ImageMagick, providing only the height value in a geometry parameter instructs the software to resize the image to that exact target height while automatically calculating the width to preserve the original aspect ratio. This article covers how ImageMagick interprets height-only geometry strings, the correct syntax needed to apply them, and how common geometry flags interact with this setting.

The Height-Only Syntax

In ImageMagick, the standard geometry format follows the pattern widthxheight. When you want to define only the height, you must omit the width value while retaining the x separator directly in front of the height integer.

magick input.jpg -resize x400 output.jpg

If you omit the leading x (for example, entering -resize 400), ImageMagick will interpret the number as the target width, not the height. Placing the x first indicates to the parser that the width field is empty or unconstrained.

Proportional Scaling Behavior

By default, ImageMagick preserves an image's aspect ratio unless an override flag is supplied. When a height-only string like x300 is processed:

  1. ImageMagick sets the target height to 300 pixels.
  2. It calculates the scaling factor: Scale Factor = 300 / Original Height.
  3. It derives the new width using the formula: New Width = Original Width * Scale Factor.

The resulting image matches the requested height exactly, with no distortion, stretching, or cropping applied to the original content.

Interaction with Geometry Modifiers

Special geometry flags can alter how the height-only instruction is executed:

  • Shrink Only (>): Passing -resize "x400>" will only scale down the image if its original height exceeds 400 pixels. If the original height is equal to or smaller than 400 pixels, no resizing occurs.
  • Enlarge Only (<): Passing -resize "x400<" will only upscale the image if its original height is less than 400 pixels.
  • Minimum Dimensions (^): The fill flag -resize "x400^" is redundant when only height is provided, as there is no second dimension to satisfy, behaving identically to standard proportional scaling.
  • Ignore Aspect Ratio (!): Attempting to use the exclamation mark without specifying a width (e.g., x400!) typically results in normal proportional scaling to that height because ImageMagick requires both target dimensions to force distortion.

Use in Offset and Placement Operations

When the geometry parameter is used for positioning (such as in -geometry during compositing operations) rather than resizing, specifying only an offset in the format +0+100 shifts the layer vertically by 100 pixels without changing dimensions. If used as -geometry x400+10+20, ImageMagick scales the image proportionally to 400 pixels in height and offsets it by 10 pixels on the X-axis and 20 pixels on the Y-axis.
