ImageMagick Gradient Fill in Polygons Syntax

Rendering gradient fills inside vector polygons in ImageMagick can be accomplished directly using Magick Vector Graphics (MVG) within the -draw operator or by masking a generated gradient using a polygon alpha mask. This guide provides the exact command-line syntax for applying linear and radial gradients to custom vector polygons in ImageMagick.

Method 1: Using MVG Gradient Definitions in -draw

ImageMagick's Magick Vector Graphics (MVG) allows you to define a gradient object inside a definition block (push defs ... pop defs) and reference it using url(#gradient_id) as a fill pattern.

Linear Gradient Syntax

magick -size 400x400 xc:transparent -draw '
  push defs
    push gradient "polyGradient" linear 50,50 350,350
      stop-color "crimson" 0%
      stop-color "gold" 100%
    pop gradient
  pop defs
  fill "url(#polyGradient)"
  stroke "#333333"
  stroke-width 2
  polygon 50,50 350,80 300,350 100,300
' output.png
  • linear x1,y1 x2,y2: Defines the start and end coordinates of the gradient vector.
  • stop-color <color> <offset>%: Sets the color and percentage stop points along the gradient line.
  • fill "url(#polyGradient)": Applies the defined gradient ID to subsequent shapes.
  • polygon x1,y1 x2,y2 ...: Specifies the vertex coordinates for the polygon.

Radial Gradient Syntax

magick -size 400x400 xc:transparent -draw '
  push defs
    push gradient "radialGrad" radial 200,200 200,200 150
      stop-color "cyan" 0%
      stop-color "darkblue" 100%
    pop gradient
  pop defs
  fill "url(#radialGrad)"
  polygon 200,30 360,150 300,350 100,350 40,150
' output_radial.png
  • radial cx,cy fx,fy r: Defines the center coordinates (cx,cy), focal coordinates (fx,fy), and the radius (r) of the radial gradient.

Method 2: Masking a Gradient Canvas (Composite Method)

An alternative approach generates a standalone gradient canvas and applies a polygon shape as an opacity mask. This approach offers easier control over complex gradients (such as multi-point or angled gradients).

magick -size 400x400 gradient:deepskyblue-indigo \
  \( -size 400x400 xc:black -fill white \
     -draw "polygon 50,50 350,80 300,350 100,300" \) \
  -alpha off -compose CopyOpacity -composite \
  output_masked.png
  1. gradient:color1-color2: Generates a gradient across the entire bounding box.
  2. \( ... -draw "polygon ..." \): Creates a grayscale mask where the polygon area is pure white and the background is black.
  3. -compose CopyOpacity -composite: Converts the grayscale mask into the alpha channel of the gradient image.

Method 3: Inline SVG Parsing

ImageMagick can also render standard inline SVG code, allowing full SVG gradient specifications directly from the command line:

magick -size 400x400 'svg:
<svg width="400" height="400">
  <defs>
    <linearGradient id="grad" x1="0%" y1="0%" x2="100%" y2="100%">
      <stop offset="0%" stop-color="#ff7e5f" />
      <stop offset="100%" stop-color="#feb47b" />
    </linearGradient>
  </defs>
  <polygon points="100,50 350,100 280,350 80,300" fill="url(#grad)" />
</svg>' output_svg.png
