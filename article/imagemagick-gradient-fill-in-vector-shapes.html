ImageMagick Gradient Fill in Vector Shapes

ImageMagick allows you to apply linear and radial gradient fills to drawn vector shapes using either the -tile modifier or inline Magick Vector Graphics (MVG) definitions within the -draw primitive. This guide covers the exact syntax for applying gradients to shapes such as rectangles, circles, and custom vector paths directly from the command line.

Method 1: Using the -tile Gradient Operator

The most straightforward way to fill a drawn vector shape with a gradient is to pass a gradient: or radial-gradient: image as a texture via the -tile parameter before invoking the -draw command.

Syntax:

magick -size <CanvasWidth>x<CanvasHeight> xc:<Background> \
  -tile gradient:<StartColor>-<EndColor> \
  -draw "<ShapeType> <Coordinates>" <OutputImage>

Linear Gradient Example:

To fill a rectangle with a linear gradient from red to blue on a transparent canvas:

magick -size 400x300 xc:none \
  -tile gradient:red-blue \
  -draw "rectangle 50,50 350,250" \
  linear_box.png

Radial Gradient Example:

To fill a circle with a radial gradient transitioning from yellow at the center to dark orange at the perimeter:

magick -size 400x400 xc:none \
  -tile radial-gradient:yellow-darkorange \
  -draw "circle 200,200 200,50" \
  radial_circle.png

Method 2: Defining Gradients Inside MVG (-draw)

If you require precise control over gradient stop positions, coordinates, and angles inside a vector canvas, you can declare vector gradients using SVG-compatible MVG syntax embedded inside the -draw command.

Syntax Structure:

push defs
  push gradient <GradientID> <linear|radial> <x1,y1 x2,y2>
    stop <offset> <color>
    stop <offset> <color>
  pop gradient
pop defs
fill url(#<GradientID>)
<ShapeCommand>

Linear Gradient Example on a Path:

magick -size 500x500 xc:white -draw "
  push defs
    push gradient myLinear linear 50,50 450,450
      stop 0% #ff007f
      stop 50% #7f00ff
      stop 100% #00d4ff
    pop gradient
  pop defs
  fill url(#myLinear)
  stroke black
  stroke-width 2
  roundrectangle 50,50 450,450 30,30
" linear_mvg.png

Radial Gradient Example on a Polygon:

magick -size 400x400 xc:transparent -draw "
  push defs
    push gradient myRadial radial 200,200 200,200
      stop 0% #ffffff
      stop 100% #11998e
    pop gradient
  pop defs
  fill url(#myRadial)
  polygon 200,20 380,380 20,380
" radial_polygon.png

Method 3: Masking Method (Complex Vector Groups)

For complex multi-shape paths where individual gradients need to align across canvas bounds, render the vector shape as an alpha mask and composite it onto a generated gradient canvas:

magick \( -size 500x500 gradient:cyan-magenta \) \
       \( -size 500x500 xc:black -fill white -draw "circle 250,250 250,50" \) \
       -alpha off -compose CopyOpacity -composite output_masked.png
