ImageMagick Gravity Settings for Placement and Cropping

In ImageMagick, the -gravity setting defines the reference anchor point used for cropping, compositing, text placement, and canvas resizing operations. Instead of calculating absolute pixel offsets manually, setting the gravity instructs ImageMagick to align elements relative to standard directional points on a canvas. This guide outlines the available gravity values, how they behave, and how to apply them to control image placement and cropping effectively.

Available Gravity Settings

ImageMagick provides nine primary directional anchor points based on compass directions, along with two special settings:

  • NorthWest: Top-left corner (ImageMagick's default coordinate origin).
  • North: Top edge, centered horizontally.
  • NorthEast: Top-right corner.
  • West: Left edge, centered vertically.
  • Center: Exact center of the image (both horizontally and vertically).
  • East: Right edge, centered vertically.
  • SouthWest: Bottom-left corner.
  • South: Bottom edge, centered horizontally.
  • SouthEast: Bottom-right corner.
  • None / Forget: Disables directional gravity, reverting coordinate offsets to default top-left origin behavior.

How Gravity Affects Cropping

When cropping an image, -gravity determines where the crop window is positioned before applying width, height, and offset values:

  • Center Crop: Setting -gravity Center -crop 500x500+0+0 extracts a 500x500 pixel square directly from the middle of the image, discarding the outer edges equally.
  • Corner or Edge Crop: Setting -gravity SouthEast -crop 300x200+0+0 extracts a region of 300x200 pixels starting from the bottom-right corner.
  • Offset Adjustment: Any additional +X+Y offset values are applied relative to the defined gravity anchor. For example, -gravity North -crop 200x200+0+50 positions the crop box 50 pixels down from the top edge.

How Gravity Affects Image Placement and Compositing

When overlaying one image onto another (such as watermarks, badges, or multi-layer graphics), gravity controls where the overlay aligns:

  • Watermarking: Using -gravity SouthEast places an overlay image or watermark at the bottom-right corner of the base image.
  • Offset Buffers: Adding offsets allows for padding away from canvas edges. For instance: 
    magick composite -gravity SouthEast -geometry +20+20 watermark.png input.jpg output.jpg
    This anchors the overlay to the bottom-right corner while adding a 20-pixel margin from both the bottom and right edges.

How Gravity Affects Canvas Resizing (-extent)

When expanding or shrinking the canvas size using the -extent operator, -gravity dictates where the original image stays within the new canvas dimensions:

  • Adding Borders Evenly: -gravity Center -extent 1200x800 centers the original image inside a new 1200x800 canvas, filling the remaining space with the specified background color.
  • Expanding Downward: -gravity North -extent 1200x1000 keeps the image pinned to the top while extending extra canvas area exclusively below it.

Key Execution Rules

  1. Placement Order: The -gravity flag must precede the operation it is meant to influence (such as -crop, -extent, or -composite) in the command sequence.
  2. Resetting Gravity: Gravity persists across subsequent operations in a command chain. To reset it to default behavior for later operations, declare -gravity None or -gravity NorthWest.
