ImageMagick Grayscale Morphological Erosion Syntax

This guide provides a concise reference for applying morphological erosion to grayscale images using ImageMagick. You will learn the exact command-line syntax, the available kernel structures, and practical examples demonstrating how erosion replaces pixel values with the minimum neighborhood intensity to shrink bright regions and expand dark features.

Basic Syntax

In ImageMagick version 7, morphological erosion is performed using the -morphology operator:

magick input.png -morphology Erode <Kernel> output.png

For ImageMagick version 6, replace magick with convert:

convert input.png -morphology Erode <Kernel> output.png

If the input is not already grayscale, add the -colorspace Gray option before the morphology operator:

magick input.png -colorspace Gray -morphology Erode <Kernel> output.png

Kernel Specifications

The <Kernel> argument defines the shape and size (structuring element) of the neighborhood used to compute the minimum pixel value. Common kernel types include:

  • Disk:radius – Circular neighborhood (e.g., Disk:1, Disk:2.5)
  • Diamond:radius – Diamond/Manhattan-distance neighborhood (e.g., Diamond:1, Diamond:2)
  • Square:radius – Chebyshev-distance square neighborhood (e.g., Square:1)
  • Octagon:radius – Octagonal neighborhood (e.g., Octagon:2)
  • Rectangle:geometry – Rectangular neighborhood defined by width and height (e.g., Rectangle:3x3, Rectangle:5x1)

Examples

1. Basic Erosion with a Disk Kernel

Shrink bright features uniformly in all directions using a radius of 2:

magick input.png -colorspace Gray -morphology Erode Disk:2 output_eroded.png

2. Erosion with a Diamond Kernel

Apply a light erosion effect using a 1-pixel diamond kernel:

magick input.png -morphology Erode Diamond:1 output_diamond.png

3. Directional Erosion using a Rectangle Kernel

Erode only along the horizontal axis using a 5x1 rectangular kernel:

magick input.png -morphology Erode Rectangle:5x1 output_horizontal.png

4. Multiple Iterations

To repeat the erosion operation multiple times without increasing the kernel radius, append an iteration count to the Erode method:

magick input.png -morphology Erode:3 Diamond:1 output_iterated.png

This command applies a Diamond:1 erosion three successive times.
