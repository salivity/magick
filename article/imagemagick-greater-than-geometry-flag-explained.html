ImageMagick Greater-Than Geometry Flag Explained

In ImageMagick, the greater-than symbol (>) serves as a conditional geometry flag that limits the resizing operation strictly to downsizing. This article explains how the > flag alters default scaling behavior, prevents smaller images from being unintentionally enlarged, and outlines the correct syntax required to avoid command-line errors across different operating systems.

Default Resizing vs. The Greater-Than Flag

By default, standard ImageMagick geometry arguments like -resize 800x600 alter an image to fit within the specified bounding box regardless of its original size. If an input image is 1920x1080, it will be scaled down to 800x450. However, if the input image is only 400x300, ImageMagick will scale it up to 800x600, often resulting in pixelation and unwanted artifacts.

Appending the greater-than flag (>) to the geometry argument changes this behavior by instructing ImageMagick to only execute the resize operation if the original image dimensions are physically greater than the target dimensions.

How the Flag Works in Practice

When the > flag is applied:

  • Larger images are scaled down: If an input image exceeds the specified width or height (e.g., a 2000x1500 image evaluated against 1000x1000>), ImageMagick scales it down proportionally so that neither dimension exceeds 1000 pixels.
  • Smaller images remain unchanged: If an input image is smaller than the target geometry (e.g., a 640x480 image evaluated against 1000x1000>), ImageMagick ignores the resize command entirely and retains the original dimensions.

This makes the flag particularly useful in automated batch-processing pipelines, web content optimization, and thumbnail generation where you want to cap the maximum resolution without inflating smaller files.

Shell Escaping and Syntax

Because the greater-than symbol is reserved for file output redirection in most command-line environments (such as Bash, Zsh, and Windows Command Prompt), passing an unquoted > will cause an error or inadvertently overwrite a file. The geometry argument must always be quoted or escaped.

On Linux and macOS (Bash/Zsh):

magick input.jpg -resize "800x600>" output.jpg

Alternatively, escape the symbol using a backslash:

magick input.jpg -resize 800x600\> output.jpg

On Windows (Command Prompt):

magick input.jpg -resize "800x600>" output.jpg

Contrast with the Less-Than Flag

The greater-than flag is the direct counterpart to the less-than flag (<). While > restricts resizing exclusively to downsizing larger images, < does the exact opposite: it only enlarges images that are smaller than the specified dimensions, leaving larger files untouched.
