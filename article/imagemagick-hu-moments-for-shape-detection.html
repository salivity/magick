ImageMagick Hu Moments for Shape Detection

Hu invariant image moments are a set of mathematical descriptors used in computer vision and image processing to characterize the shape of an object independently of its scale, position, and orientation. In ImageMagick, these moments provide a compact, numerical "fingerprint" of an image's pixel distribution across color channels. By extracting and comparing these invariant values, developers can perform robust shape detection, image matching, and object recognition without requiring computationally heavy machine learning models.

Understanding Hu Invariant Moments

Image moments are weighted averages of image pixel intensities that capture geometric properties like area, center of mass, and orientation. While raw moments change when an object moves or resizes, Hu invariant moments solve this problem through a multi-step mathematical normalization:

  1. Spatial Moments: Calculate basic properties, such as total intensity (area) and centroid (center of mass).
  2. Central Moments: Shift coordinates relative to the centroid, making the values invariant to translation (position).
  3. Normalized Central Moments: Divide central moments by the total area, making them invariant to scale (size).
  4. Hu's Seven Invariants: Derived by Ming-Kuei Hu in 1962, these seven non-linear combinations of normalized central moments remain invariant under translation, scaling, and 2D rotation. The seventh moment also differentiates between mirrored (reflected) shapes.

Extracting Hu Moments in ImageMagick

ImageMagick provides built-in tools to calculate Hu moments directly from the command line or via API bindings.

To output the spatial and Hu moments for an image, use the identify command with the -moments flag:

magick identify -moments input_shape.png

The output returns the centroid, ellipse axis, angle, and the seven Hu invariant moments for each color channel (as well as overall luminance):

Image: input_shape.png
  Channel moments:
    I1: 0.165432
    I2: 0.001245
    I3: 0.000034
    I4: 0.000001
    I5: -0.000000
    I6: 0.000000
    I7: 0.000000

Because higher-order moments yield extremely small floating-point values, algorithms typically apply a logarithmic transformation (e.g., \(-\text{sign}(I_n) \cdot \log_{10}(|I_n|)\)) to normalize their scale for practical comparisons.

How Hu Moments Are Used for Shape Detection

Using ImageMagick Hu moments for shape detection follows a systematic pipeline:

1. Preprocessing and Binarization

Before computing moments, the target image is isolated from background noise. This typically involves converting the image to grayscale, applying thresholding, and morphological operations to create a clean binary silhouette of the shape.

magick input.png -colorspace Gray -threshold 50% -morphology Open Disk:1 binary_shape.png

2. Feature Extraction

Extract the seven Hu moments \((I_1, I_2, ..., I_7)\) from the preprocessed image using ImageMagick to create a 7-dimensional feature vector.

3. Template Comparison

To detect or classify a shape, compare the target shape's vector against reference vectors of known shapes (e.g., circles, triangles, specific logos). The similarity between two shapes \(A\) and \(B\) is measured using distance metrics such as:

  • Euclidean Distance: Measuring the straight-line distance across all seven log-transformed values.
  • Relative Difference: Summing the absolute differences relative to reference magnitudes.

A distance score below a predefined threshold indicates a positive match.

Practical Advantages and Limitations

Advantages

  • Geometric Invariance: Detects shapes accurately even if the object is rotated, enlarged, shrunk, or shifted in the frame.
  • Low Computational Overhead: Fast computation makes it suitable for real-time processing and embedded systems.
  • Compact Representation: Entire silhouettes are reduced to just seven numerical values per channel.

Limitations

  • Sensitivity to Occlusion: If part of the shape is blocked or cropped, the calculated center of mass and moments change significantly.
  • Noise Vulnerability: Noisy borders or extraneous artifacts can alter higher-order moments.
  • Rigid Shapes Only: Hu moments are not designed for flexible or non-rigid objects (such as a person walking) whose fundamental geometry deforms.
