ImageMagick Identify Command for JSON Output

This guide provides the exact command syntax for extracting complete image metadata and properties in JSON format using ImageMagick's identify utility. It covers the required flags, syntax variations across ImageMagick versions 6 and 7, and practical examples for exporting or piping JSON data for automation and scripting.

Standard Syntax for JSON Output

To retrieve image properties as a standard JSON string, use the -format parameter with the json: property specifier.

ImageMagick 7

magick identify -format "%[json:]" input.jpg

ImageMagick 6

identify -format "%[json:]" input.jpg

Alternative: Direct JSON Format Conversion

ImageMagick allows you to treat json: as an output format specifier. This is functionally equivalent to the verbose property dump rendered as JSON:

# ImageMagick 7
magick input.jpg json:

# ImageMagick 6
convert input.jpg json:

To save the metadata directly to a .json file:

magick input.jpg output.json

Processing Multiple Images

When querying multiple files, appending a newline character (\n) prevents the generated JSON objects from concatenating into an invalid single-line payload:

magick identify -format "%[json:]\n" *.png

Filtering JSON Properties with jq

Because the command outputs standard JSON to stdout, you can pipe the output directly to command-line JSON processors like jq to extract specific image attributes:

Extract Dimensions (Width and Height)

magick identify -format "%[json:]" input.jpg | jq '.image.geometry'

Extract EXIF Metadata

magick identify -format "%[json:]" input.jpg | jq '.image.properties.exif'

Extract File Format and Colorspace

magick identify -format "%[json:]" input.jpg | jq '{format: .image.format, colorspace: .image.colorspace}'

Structure of the Output JSON

The resulting output contains a root object named image (or an array of image objects for multi-layer/multi-frame files) with the following key sections:

  • name / format: File path, container format, and MIME type.
  • geometry / resolution: Pixel dimensions, print density (DPI), and units.
  • colorspace / depth: Color model (e.g., sRGB, CMYK) and channel bit depth.
  • properties: Embedded metadata blocks, including EXIF, IPTC, and XMP payloads.
  • filesize / compression: File storage size and compression algorithms used.
