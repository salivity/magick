ImageMagick Image Sequence Limit Policy Directive

ImageMagick provides robust security policies to govern how the software consumes system resources and processes complex media files. When dealing with multi-frame formats such as animated GIFs, multi-page PDFs, or layered files, an unchecked file can consume excessive memory by loading hundreds or thousands of frames simultaneously. The policy directive responsible for restricting the maximum number of images in a single sequence is list-length.

The list-length Policy Directive

The list-length resource limit sets a strict ceiling on the number of images or frames allowed within an individual image sequence. When ImageMagick encounters a file that exceeds this designated count, it aborts processing or refuses to append further images to the sequence, safeguarding the host system against denial-of-service (DoS) attacks caused by decompression bombs or maliciously crafted multi-layer files.

Configuring the Directive

To enforce this restriction, define the list-length directive inside ImageMagick's policy.xml configuration file. The file is typically located in /etc/ImageMagick-7/ (or /etc/ImageMagick-6/ depending on the installation version).

Add the following rule inside the <policymap> block:

<policy domain="resource" name="list-length" value="32"/>

In this example, the value attribute specifies that ImageMagick will process no more than 32 images or frames within a single sequence. You can adjust this numerical threshold according to the operational requirements of your application.

Why Enforcing list-length Matters

  • Memory Protection: Every frame in a multi-image sequence allocates system memory. Limiting the list length prevents exhaustion of RAM and swap space.
  • Denial of Service Prevention: Uncontrolled sequence processing allows attackers to submit files with thousands of lightweight frames that expand exponentially when decoded in memory.
  • Predictable Performance: Enforcing hard limits guarantees that batch image processing tasks complete within predictable timeframes and resource profiles.
