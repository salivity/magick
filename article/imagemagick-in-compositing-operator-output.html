ImageMagick In Compositing Operator Output

This article provides an explanation of the visual result produced when using the ImageMagick In compositing operator on two overlapping shapes. It covers how the Porter-Duff Src In Dst rule functions, which shape's color is retained, and why all non-overlapping areas become completely transparent.

When applying the In compositing operator in ImageMagick (often written as -compose In -composite), the software uses the classic Porter-Duff "Source In Destination" rule. In ImageMagick workflows, the first specified image serves as the Destination (the background), while the second image serves as the Source (the overlay).

The Resulting Visual Output

When two shapes overlap using the In operator:

  1. The Overlapping Region: The only visible output is the intersection where both shapes occupy the same pixel coordinates. The visual appearance—such as color, pattern, and texture—of this intersecting area is taken entirely from the Source (the second shape). The Destination shape merely acts as a stencil or clipping mask.

  2. The Non-Overlapping Regions: All non-overlapping areas of both shapes are completely discarded.

    • The portion of the Destination shape that does not touch the Source disappears.
    • The portion of the Source shape that extends outside the Destination disappears.
    • These empty areas are rendered as fully transparent pixels.

Transparency and Alpha Channels

The resulting opacity (alpha channel) is calculated by multiplying the alpha values of the two shapes:

  • Full Opacity: If both overlapping shapes are 100% opaque in the intersecting area, the resulting output will be 100% opaque, showing only the Source shape's color.
  • Partial Opacity: If either shape has partial transparency (anti-aliased edges or semi-transparent fills), the output alpha is reduced proportionally (\(Alpha_{result} = Alpha_{source} \times Alpha_{destination}\)). This ensures smooth, anti-aliased edges along the clipping boundary.

Concrete Example

Consider a composite operation where a solid red circle is the Destination image and a solid blue square is the Source image placed partially over the circle.

Running the In composite operator produces an image containing only a blue curved segment: the exact portion of the blue square that sat inside the boundary of the red circle. All red pixels vanish, and the rest of the blue square outside the circle vanishes, leaving the surrounding canvas entirely transparent.
