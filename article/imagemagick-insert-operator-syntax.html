ImageMagick -insert Operator Syntax

The ImageMagick -insert operator allows users to rearrange the current list of images in memory by moving an image to a specific position. To place an image at the very beginning of an image sequence, the operator requires an index argument of 0. This guide explains the precise syntax required to position an image at the start of a sequence and demonstrates how the command behaves in practice.

The Syntax for Moving an Image to the Start

ImageMagick uses zero-based indexing for images in the current stack. The syntax to move the last loaded image to the beginning of the sequence is:

-insert 0

By default, the -insert operator targets the last image read into memory and shifts it to the index provided as an argument. Providing 0 instructs ImageMagick to move that final image to the first position.

Command Example

Consider an example where you load page2.jpg first and page1.jpg second, but need them ordered correctly for the final output:

magick page2.jpg page1.jpg -insert 0 output.pdf

In this sequence:

  1. page2.jpg is loaded at index 0.
  2. page1.jpg is loaded at index 1.
  3. -insert 0 takes the last image (page1.jpg) and moves it to index 0.
  4. page2.jpg automatically shifts to index 1.
  5. The resulting output.pdf contains page1.jpg followed by page2.jpg.

Moving Specific Images Using Two Arguments

In ImageMagick version 7, you can also specify both the source image index and the destination index if you want to move an image other than the last one:

-insert source_index destination_index

To move an image from index 2 to the start of the sequence (index 0), use:

magick image0.png image1.png image2.png -insert 2 0 output.png

When using only a single numerical parameter (e.g., -insert 0), ImageMagick assumes the source is always the last image in the current sequence.
