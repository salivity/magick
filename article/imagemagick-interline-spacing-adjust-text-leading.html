ImageMagick Interline Spacing: Adjust Text Leading

The -interline-spacing option in ImageMagick directly controls the vertical distance, commonly referred to as leading, between consecutive lines of text. By specifying a positive or negative pixel value, you can either expand the gap between lines for improved readability or tighten it to fit text within restricted dimensions. This article explains how the option functions, how it modifies the default font metrics, and how to apply it using the command-line interface.

Understanding Leading and Default Font Metrics

When ImageMagick renders multi-line text using operators such as caption: or label:, it automatically calculates line height based on the selected font's embedded metrics. The baseline-to-baseline distance typically accounts for font ascenders, descenders, and built-in leading.

The -interline-spacing setting works as an offset applied to this default metric. Rather than replacing the font's native line height with an absolute measurement, it adds or subtracts a specific number of pixels between each line of rendered text.

Increasing Line Spacing (Positive Values)

To increase the leading between lines, assign a positive integer to -interline-spacing. This pushes subsequent lines downward by adding extra vertical pixels between them.

For example, to add 15 pixels of space between lines of wrapped text:

magick -size 400x300 -background white -fill black -font Arial -pointsize 24 -interline-spacing 15 caption:"This is the first line.\nThis is the second line with increased leading." output_expanded.png

In this command, each line after the first is shifted down by an additional 15 pixels relative to where the font metrics would normally place it. This is particularly useful for improving readability in blocks of body copy or matching specific design specifications.

Decreasing Line Spacing (Negative Values)

To decrease leading, assign a negative integer to -interline-spacing. This reduces the default vertical separation, moving consecutive lines closer together.

For example, to tighten line spacing by 8 pixels:

magick -size 400x300 -background white -fill black -font Arial -pointsize 24 -interline-spacing -8 caption:"This is the first line.\nThis is the second line with decreased leading." output_compact.png

Applying a negative value removes vertical padding. If the negative value exceeds the font’s built-in spacing, glyphs from adjacent lines will overlap, causing descenders (such as the tails on "g" or "y") to collide with ascenders (such as "h" or "l") on the line below.

Key Usage Considerations

  • Placement Order: In ImageMagick commands, -interline-spacing is a setting that must appear before the text generation operator (caption:, label:, or @textfile.txt). If placed after, the setting will not apply to the rendered text.
  • Unit of Measure: The value provided to -interline-spacing is interpreted in pixels. It does not accept percentage or point units directly.
  • Multi-line Operators: While both label: and caption: support -interline-spacing, caption: automatically wraps text into multiple lines based on image width, making -interline-spacing essential for formatting multi-line paragraphs dynamically.
