ImageMagick Interword-Spacing in Text Annotations

The -interword-spacing option in ImageMagick controls the amount of horizontal space inserted between individual words when rendering text onto an image. This article explains how this setting alters typography during text annotations, covers its syntax and accepted values, and distinguishes it from other font-spacing parameters such as kerning and line spacing.

What -interword-spacing Controls

When generating text using operations like annotate or caption:, ImageMagick relies on standard font metrics to determine the default width of space characters. The -interword-spacing option overrides or adjusts this default behavior by adding or subtracting a specified number of pixels between words.

It exclusively targets the whitespace separating words (the ASCII space character) and does not affect the spacing between individual letters inside a single word.

Syntax and Values

The -interword-spacing option requires a numeric argument representing pixels:

magick input.jpg -font Arial -pointsize 24 -interword-spacing 10 -annotate +50+50 "Custom Spaced Text" output.jpg
  • Positive Values: Entering a positive integer (e.g., 10) adds extra pixels to the default space, spreading words further apart. This is useful for wide banners, stylistic headlines, or aligning text to a wider layout without altering letter spacing.
  • Negative Values: Entering a negative integer (e.g., -5) contracts the distance between words by removing pixels. This allows you to fit text into tight bounding boxes or correct fonts that feature disproportionately large space glyphs.
  • Zero Value: Setting the value to 0 restores the font's default native spacing.

Differences Between Related Text-Spacing Options

ImageMagick provides three distinct options for fine-tuning text layout:

  • -interword-spacing: Adjusts the gap strictly between words (space characters).
  • -kerning: Adjusts tracking or letter-spacing, which changes the gap between every adjacent character within a word.
  • -interline-spacing: Adjusts leading, which is the vertical distance between lines of multiline text.

Combining -interword-spacing with these complementary settings grants full typographic control over text annotations generated directly through the command line.
