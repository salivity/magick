ImageMagick Kernel Rotation Symbol > Explained

In ImageMagick, appending the greater-than symbol (>) to a morphology kernel instructs the software to generate a sequence of four rotated variations by turning the base kernel 90 degrees clockwise at each step. During multi-pass morphological filtering, ImageMagick applies these four directional kernels sequentially within each iteration pass. This allows directional operations—such as edge detection, thinning, and pruning—to be evaluated evenly across all cardinal orientations.

Kernel Generation and Rotation Behavior

When configuring a morphological kernel, ImageMagick allows rotational modifiers to expand a single base matrix into a compound kernel list.

The > modifier explicitly dictates:

  • Step Angle: 90 degrees per step.
  • Direction: Clockwise.
  • Kernel Count: Four total kernels representing 0°, 90°, 180°, and 270° orientations.

Without this modifier, ImageMagick applies only the single, fixed orientation defined by the kernel formula or matrix. Appending > automatically constructs the remaining three cardinal rotations without requiring the user to define each matrix manually.

How Multi-Pass Filtering Uses the Rotated Kernels

During multi-pass filtering (such as iterative Thinning, Thicken, or sequential HitAndMiss operations), the four generated kernels are evaluated in sequence rather than simultaneously:

  1. Kernel 0 (0°): Evaluated against the image pixels.
  2. Kernel 1 (90° clockwise): Evaluated on the result of the previous step.
  3. Kernel 2 (180° clockwise): Evaluated on the updated image.
  4. Kernel 3 (270° clockwise): Evaluated to complete the full four-pass cycle.

If an operation specifies multiple iterations (for example, -morphology Thinning:5 "Skeleton:>"), the entire four-pass sequence is repeated for each iteration count. When run to convergence (using -1 or *), ImageMagick loops through all four orientations repeatedly until an entire four-kernel pass results in zero pixel modifications.

Related Rotation Modifiers

ImageMagick provides four directional rotation symbols for kernel definition:

  • > (90° Clockwise): 4 variations covering North, East, South, and West.
  • < (90° Counter-Clockwise): 4 variations rotating in reverse order.
  • } (45° Clockwise): 8 variations covering both cardinal directions and diagonals.
  • { (45° Counter-Clockwise): 8 variations rotating through diagonals and cardinals in reverse order.

Using > is the standard practice when working with symmetric 2D grids where diagonal sampling is unnecessary, ensuring consistent cardinal processing while minimizing execution time compared to 8-pass 45-degree rotations.
