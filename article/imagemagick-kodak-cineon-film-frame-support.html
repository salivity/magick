ImageMagick Kodak Cineon Film Frame Support

ImageMagick handles Kodak Cineon film frames using its built-in CIN coder rather than relying on an external third-party delegate library. This article covers how ImageMagick manages Cineon (.cin) files, the difference between native coders and external delegates in this context, how to verify format support, and how to read and write Cineon image frames.

Native Coder vs. External Delegate

In ImageMagick terminology, an external delegate refers to a third-party library or utility (such as libpng, libjpeg, or Ghostscript) invoked to decode or encode specific file types. Kodak Cineon files do not require an external delegate. Instead, ImageMagick provides internal, native support through its compiled CIN coder module (coders/cin.c).

Because the support is native, any standard compilation of ImageMagick can read and write Cineon files out of the box without installing additional external dependencies.

Verifying Cineon Support

To confirm that your ImageMagick installation has the native Cineon coder enabled, run the following command in your terminal:

magick identify -list format | grep -i cin

(Note: Use identify -list format | grep -i cin if using ImageMagick version 6.)

The output will display the format entry:

CIN* CIN          rw-   Kodak Cineon Film Format
  • CIN*: The recognized file extension and format identifier.
  • rw-: Indicates full support for both reading (r) and writing (w).

Working with Cineon Frames

Kodak Cineon is a standard 10-bit logarithmic format traditionally used in digital intermediate film pipelines. ImageMagick can convert Cineon frames to and from other common digital image formats like DPX, TIFF, or PNG while managing color space conversions.

Reading a Cineon Frame and Converting to PNG

magick input_frame.cin -colorspace sRGB output_frame.png

Converting an Image to Kodak Cineon

magick input_frame.dpx output_frame.cin

When writing Cineon files, ImageMagick automatically packs pixel data into the appropriate 10-bit logarithmic layout according to the Cineon file specification.
