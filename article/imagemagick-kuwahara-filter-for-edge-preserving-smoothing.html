ImageMagick Kuwahara Filter for Edge-Preserving Smoothing

The Kuwahara filter in ImageMagick is a non-linear image smoothing tool designed to reduce image noise and flatten textures while preserving sharp, distinct edges. This article explains the underlying mechanism of the Kuwahara filter, how it achieves edge-preserving smoothing compared to traditional blur operations, and how to apply it using ImageMagick.

How the Kuwahara Filter Works

Standard linear filters, such as Gaussian or box blurs, calculate the weighted average of all pixels within a local neighborhood. When a neighborhood spans an edge between two distinct visual regions, these standard filters blend both sides together, resulting in blurred boundaries.

The Kuwahara filter avoids blurring edges by dynamically selecting the most uniform local sub-region before applying an average. For every pixel in an image, the algorithm executes the following steps:

  1. Quadrant Division: It defines a square window centered on the target pixel and divides this window into four overlapping square sub-regions (quadrants), all sharing the central pixel.
  2. Variance Calculation: It calculates the statistical variance (a measure of roughness or detail) and the mean color value for each of the four sub-regions.
  3. Selection: It identifies the sub-region with the lowest variance, which represents the most homogeneous (flat) area around the pixel.
  4. Assignment: It assigns the mean color of this lowest-variance sub-region to the target pixel.

Edge-Preserving Capabilities

When the filter processes a pixel near an edge, the sub-regions that cross the edge exhibit high variance due to the sharp contrast between colors. In contrast, the sub-regions that sit entirely on one side of the edge have significantly lower variance.

Because the algorithm always selects the quadrant with the lowest variance, it calculates the output using only pixels from one side of the boundary. This prevents color information from bleeding across the edge, leaving transitions sharp while fully smoothing the flat areas on either side.

Visual Characteristics

Applying the Kuwahara filter produces distinct visual traits:

  • Noise Reduction: High-frequency noise within uniform areas is eliminated.
  • Cartoon or Painterly Effect: Continuous gradients are simplified into flat, posterized-like blocks with sharp boundaries, resembling an oil painting or cell-shaded artwork.
  • Corner Rounding: While straight edges remain crisp, sharp geometric corners may become slightly rounded due to the geometry of the square sub-windows.

Applying the Filter in ImageMagick

ImageMagick provides built-in support for the Kuwahara filter through the -kuwahara command-line option.

magick input.jpg -kuwahara 3 output.jpg

Parameters

  • Radius: The parameter supplied to -kuwahara defines the size of the sub-windows. A larger radius increases the scale of the smoothing effect and produces broader flat regions, while a smaller radius preserves finer details while targeting fine-grained noise.
