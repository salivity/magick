ImageMagick label vs caption Differences

In ImageMagick, both the label: and caption: input protocols generate images from text strings, but they differ fundamentally in how they handle dimensions, line breaking, and text scaling. The primary distinction is that label: renders text on a single line by default and scales the font size to fit the specified dimensions, while caption: automatically wraps words across multiple lines to fit within a bounded width and height.

Automatic Word Wrapping

  • label: does not perform automatic word wrapping. Any text provided to label: is rendered as a continuous single line unless you manually insert explicit newline characters (\n) into the string.
  • caption: includes built-in word wrapping. It evaluates the available canvas width and automatically breaks lines between words to ensure the text fits within the boundaries.

Handling of Dimensions and Font Sizing

The behavior of both protocols depends heavily on whether you define the -size property, the -pointsize property, or both:

With a Defined Width and Height (-size WidthxHeight)

  • label: calculates the largest possible font size that allows the entire text line (or explicitly broken lines) to fit inside the specified width and height. If the text is very long, the font size will shrink significantly to keep the line intact on a single line.
  • caption: wraps the text to the specified width and automatically reduces the font size until all wrapped lines fit entirely within the specified height.

With a Defined Width Only (-size Widthx)

  • label: sets the image width to the requested size and scales the font size to fill that exact width, adjusting the resulting image height dynamically.
  • caption: uses the specified width to determine where lines should wrap. It maintains the defined -pointsize (or the default size) and expands the image vertically to whatever height is necessary to contain all wrapped lines.

With a Defined -pointsize and No -size

  • label: creates an image canvas sized precisely to fit the text at the requested point size on a single line.
  • caption: cannot automatically wrap text without a defined width boundary, so it behaves similarly to label:, generating an image wide enough to hold the text on a single line at the chosen point size.

Practical Examples

Using label: for Titles and Badges

label: is best suited for titles, watermarks, buttons, and short labels where the text must scale dynamically to fill a fixed area without breaking onto multiple lines:

magick -size 300x100 -background lightblue -fill black label:"Single Line Title" output_label.png

Using caption: for Paragraphs and Dynamic Content

caption: is ideal for descriptions, quotes, subtitles, and user-generated text of unpredictable length where readability requires multi-line paragraph flow:

magick -size 300x100 -background lightgray -fill black caption:"This is a longer text string that will automatically wrap across multiple lines to fit inside the box." output_caption.png

Summary Comparison

Feature label: caption:
