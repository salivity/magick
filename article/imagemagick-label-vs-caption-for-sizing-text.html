ImageMagick Label vs Caption for Sizing Text

ImageMagick provides two primary pseudo-image protocols for rendering text: label: and caption:. While both can dynamically adjust font sizes to fit specific dimensions defined by the -size parameter, they differ fundamentally in how they handle line breaks and text wrapping. The label: protocol is designed for non-wrapping text, scaling a single line (or explicitly broken lines) to fill the available space, whereas caption: automatically word-wraps text across multiple lines to fit within the designated width and height constraints.

The label: Protocol

The label: protocol renders text strictly as provided, without introducing automatic word breaks.

  • Line Wrapping: label: does not perform automatic word wrapping. If text exceeds the boundary width, it will not break into a second line unless newline characters (\n) are manually inserted into the string.
  • Auto-Sizing Behavior: When a fixed box is defined using -size WIDTHxHEIGHT and no point size is specified, label: calculates the largest possible font size that allows the entire text line to fit within both the width and height limits.
  • Single Dimension Sizing: If only the width is defined (e.g., -size 500x), label: will scale the font size until the text spans that width, adjusting the canvas height proportionally.
  • Primary Use Case: Short strings, titles, banners, single-line buttons, and graphics where text must span as large as possible across a predefined area without breaking.

Example command:

magick -size 400x100 -background lightblue -fill black label:"Single Line Text" output_label.png

The caption: Protocol

The caption: protocol is specifically engineered for multi-line text formatting and paragraph rendering.

  • Line Wrapping: caption: automatically inserts line breaks between words to ensure the text wraps to fit the specified canvas width.
  • Auto-Sizing Behavior: When both dimensions are set with -size WIDTHxHEIGHT, caption: iteratively wraps the words and adjusts the font point size down until the entire paragraph fits neatly within the exact bounding box.
  • Single Dimension Sizing: If only width is defined (e.g., -size 400x) alongside a fixed -pointsize, caption: will wrap the text at that width and automatically expand the canvas height downward to accommodate all necessary lines.
  • Primary Use Case: Descriptions, paragraphs, watermarks with variable length, and automated templates where dynamic input text must be contained inside a fixed bounding area.

Example command:

magick -size 400x100 -background lightgray -fill black caption:"This is a longer block of text that will automatically wrap into multiple lines to fit the canvas." output_caption.png

Key Sizing Differences Summary

Automatic Word Wrap No Yes
