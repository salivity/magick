ImageMagick Lagrange Filter Interpolation

The ImageMagick Lagrange filter evaluates multi-point polynomial interpolation by constructing a continuous, piecewise polynomial weighting function based on classical Lagrange basis polynomials. This article explores how ImageMagick applies this mathematical formulation across discrete pixel grids, detailing its windowed support mechanism, separable 1D convolution processing, and the trade-offs between interpolation sharpness and polynomial ringing artifacts.

The Lagrange Polynomial Formulation

Lagrange interpolation constructs a unique polynomial of degree \(n-1\) that passes precisely through \(n\) distinct data points. For a given set of data coordinates \((x_0, y_0), (x_1, y_1), \dots, (x_{n-1}, y_{n-1})\), the interpolated value \(y(x)\) is defined as:

\[P(x) = \sum_{i=0}^{n-1} y_i \ell_i(x)\]

where the basis polynomials \(\ell_i(x)\) are given by:

\[\ell_i(x) = \prod_{\substack{0 \le j < n \\ j \ne i}} \frac{x - x_j}{x_i - x_j}\]

ImageMagick translates this continuous formulation into a filter weighting function. When sampling an intermediate sub-pixel position, the distance between the target location and adjacent discrete pixel centers serves as the variable \(x\). The calculated basis weights are then applied to the corresponding pixel values to determine the reconstructed color value.

Multi-Point Support and Kernel Sizing

In image processing, infinite-degree interpolation across the entire image is computationally infeasible and mathematically unstable. ImageMagick restricts the Lagrange interpolation to a localized neighborhood defined by the filter's support radius.

By default, the Lagrange filter in ImageMagick operates with a support radius of 2.0. This yields a 4-point (cubic) polynomial interpolation centered around the target coordinate, evaluating two pixel samples to the left and two to the right in a 1D context. Users can modify this support radius via the -define filter:support setting:

  • A support of 1.0 yields a 2-point linear interpolation.
  • A support of 2.0 yields a 4-point cubic Lagrange interpolation.
  • A support of 3.0 yields a 6-point quintic Lagrange interpolation.

For any chosen support radius \(R\), the filter considers \(2R\) points uniformly spaced along the sampling axis. The kernel satisfies the Kronecker delta property at integer intervals: \(L(0) = 1\) and \(L(k) = 0\) for all non-zero integers \(k\) within the support. This ensures that sampling directly on a pixel center reproduces the original input value without blurring.

Separable Two-Pass Resampling

For standard affine transformations, scaling, and distortions, ImageMagick optimizes multi-point reconstruction using separable filtering. Rather than calculating a complex two-dimensional surface polynomial simultaneously, the operation decomposes into two orthogonal 1D passes:

  1. Horizontal Pass: For each row, ImageMagick identifies the surrounding horizontal pixels within the support boundary, calculates the 1D Lagrange weights based on sub-pixel offsets, and computes the intermediate row values.
  2. Vertical Pass: The process repeats vertically along the columns of the intermediate image, applying the same 1D Lagrange kernel to determine final pixel color values.

When using cylindrical Elliptical Weighted Average (EWA) resampling—typically invoked during non-orthogonal or perspective distortions—ImageMagick maps the Lagrange function into a radial profile, weighting source pixels based on their radial distance in the mapped coordinate space.

Characteristics and Artifact Handling

Because the Lagrange filter fits an exact polynomial through the discrete points, it functions as an interpolating filter rather than an approximating filter (such as a Gaussian or B-spline filter). This design produces distinct visual characteristics:

  • Sharpness Preservation: Edge definition remains high because high-frequency transitions are not smoothed out by attenuation at the pixel centers.
  • Runge’s Phenomenon and Ringing: When higher-order polynomials (higher support radii) are configured, multi-point polynomial interpolation can oscillate near sharp transitions. This causes visible ringing or halo artifacts around high-contrast edges.
  • Negative Lobes: The Lagrange basis polynomials yield negative values between sample nodes outside the central peak. In ImageMagick, this can produce undershoot (values dropping below zero) or overshoot (values exceeding the maximum quantum depth), which are clamped to the valid color range during output generation.
