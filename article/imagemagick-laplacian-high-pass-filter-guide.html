ImageMagick Laplacian High-Pass Filter Guide

This guide details how to execute a Laplacian high-pass filter on an image using ImageMagick's command-line tools. You will learn the exact syntax for applying built-in Laplacian convolution kernels, how to configure kernel variations for different neighbor sensitivity levels, and how to handle zero-bias offsets to correctly visualize high-pass edge results.

Basic Syntax

In ImageMagick, a Laplacian high-pass filter is applied using the -morphology operator with the Convolve method and the built-in Laplacian kernel.

ImageMagick v7 (Recommended)

magick input.png -morphology Convolve Laplacian:0 output.png

ImageMagick v6

convert input.png -morphology Convolve Laplacian:0 output.png

Laplacian Kernel Variations

The number following the Laplacian: argument specifies the kernel type and neighbor connectivity:

  • Laplacian:0 (Standard 3x3, 4-neighbor): Evaluates strictly orthogonal adjacent pixels. 
    [  0, -1,  0 ]
[ -1,  4, -1 ]
[  0, -1,  0 ]
  • Laplacian:1 (Standard 3x3, 8-neighbor): Evaluates both orthogonal and diagonal pixels, resulting in stronger omnidirectional edge detection. 
    [ -1, -1, -1 ]
[ -1,  8, -1 ]
[ -1, -1, -1 ]
  • Laplacian:2 (3x3 with fractional weights): Offers a smoother edge response.
  • Laplacian:3 (5x5 kernel): Provides a larger radius high-pass extraction.

Handling Negative Values (Adding Bias)

Laplacian filters produce positive and negative values representing edge transitions. Because standard image formats clip values below zero to black, add a 50% gray bias to preserve the full frequency spectrum:

magick input.png -define convolve:bias=50% -morphology Convolve Laplacian:0 output.png

Custom Laplacian Kernel Syntax

To define a custom discrete Laplacian matrix manually, specify the kernel dimensions followed by the matrix weights:

magick input.png -morphology Convolve "3x3: 0,-1,0 -1,4,-1 0,-1,0" output.png
