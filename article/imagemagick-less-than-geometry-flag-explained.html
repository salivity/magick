ImageMagick Less-Than Geometry Flag Explained

In ImageMagick, the less-than symbol (<) is a geometry modifier used primarily with the -resize and -scale operators to enforce conditional upscaling. When appended to target dimensions, this flag instructs ImageMagick to enlarge an image only if its current dimensions are smaller than the specified boundary. If an image is already equal to or larger than the specified dimensions, the command leaves the image at its original size, preventing accidental downscaling.

How the Flag Works

The standard resize command in ImageMagick scales an image to fit within a bounding box, regardless of whether the original image is larger or smaller than the target. Adding the < symbol changes this behavior into an "enlarge-only" condition.

For example:

magick input.jpg -resize "800x600<" output.jpg

Under this command:

  • Smaller Images: An image measuring 400x300 pixels is smaller than the 800x600 target. ImageMagick will scale it up proportionally to 800x600.
  • Larger Images: An image measuring 1920x1080 pixels exceeds the target boundaries. ImageMagick detects that it is already larger than 800x600 and ignores the resize operation, preserving the original resolution.

Maintaining Proportions

By default, ImageMagick preserves an image's aspect ratio. When using 800x600<, the image will scale up until either the width reaches 800 pixels or the height reaches 600 pixels, whichever constraint is met first. If you need to force an upscale to exact dimensions regardless of distortion, the flag can be combined with the exclamation point (!), such as 800x600<!.

Shell Escaping Requirement

In Unix-like shells (such as Bash or Zsh) and Windows Command Prompt, the < character is reserved for standard input redirection. To prevent the shell from misinterpreting the flag as an input redirect operator, the geometry string must always be enclosed in quotes (e.g., "800x600<") or escaped with a backslash (e.g., 800x600\<).

Common Use Cases

The < modifier is typically used in automated asset pipelines where a minimum dimension is required, such as:

  • Meeting Minimum Resolution Requirements: Ensuring profile pictures, banners, or print assets meet baseline dimension thresholds without downscaling high-resolution submissions.
  • Upscaling Low-Resolution Thumbnails: Standardizing small icons or legacy graphics to fit modern display grids without degrading existing high-resolution assets in the same batch.
