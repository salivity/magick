ImageMagick level-colors: Map Shadows and Highlights

This guide explains how to use the ImageMagick level-colors operator to create a custom two-tone color grade by mapping shadows to navy blue and highlights to amber. Using this operator allows you to remap the black and white points of an image to specific target colors, smoothly interpolating all midtone values between them.

The Basic Command

The level-colors operator takes two color arguments separated by a comma: the shadow color (black point) followed by the highlight color (white point).

To map shadows to navy blue and highlights to amber, execute the following command:

magick input.jpg -level-colors navy,amber output.jpg

For older versions of ImageMagick (version 6 and earlier), use convert instead of magick:

convert input.jpg -level-colors navy,amber output.jpg

Understanding the Syntax

The argument format is:

-level-colors <shadow-color>,<highlight-color>
  • Shadow color: This replaces pure black (#000000). ImageMagick recognizes the named color navy (equivalent to #000080).
  • Highlight color: This replaces pure white (#FFFFFF). ImageMagick recognizes amber (equivalent to #FFBF00).

Midtone values are linearly blended across the color spectrum between the two specified targets.

Using Precise Hex Codes

While ImageMagick recognizes standard color names, using hexadecimal color codes provides exact control over your palette. For example, if you prefer a deeper navy and a warm, golden amber:

magick input.jpg -level-colors "#001F3F,#FFBF00" output.jpg

Achieving a Clean Duotone Effect

If applied to a full-color image, level-colors remaps each RGB channel independently, which can produce unexpected color shifts. To create a true duotone effect where the color gradient strictly represents image brightness, convert the source image to grayscale first:

magick input.jpg -colorspace Gray -level-colors navy,amber duotone_output.jpg

This ensures dark areas shift completely toward navy, bright areas shift toward amber, and gray tones become a balanced mix of both colors.
