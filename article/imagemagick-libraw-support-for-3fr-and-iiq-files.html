ImageMagick LibRaw Support for 3FR and IIQ Files

This article provides an overview of how ImageMagick utilizes the LibRaw delegate to decode, process, and render digital medium format RAW files, specifically Hasselblad's 3FR and Phase One's IIQ formats. It examines the internal delegation pipeline, how LibRaw parses proprietary sensor data and color profiles from these high-resolution systems, and the technical considerations required to maintain dynamic range and color accuracy during conversion.

The ImageMagick Delegation Architecture

ImageMagick does not natively parse the proprietary raw sensor structures of high-end medium format systems. Instead, it relies on an external delegate subsystem defined in its delegates.xml configuration. When ImageMagick encounters a RAW image file, it offloads the initial decoding and demosaicing to LibRaw, typically through the dcraw_emu utility or via direct C-API integration in modern builds. LibRaw reads the sensor matrices, unpacks the raw sensor voltages, applies camera-specific calibration and demosaicing algorithms, and passes a decoded linear or gamma-corrected raster buffer back to ImageMagick for further manipulation or format conversion.

Processing Hasselblad 3FR Files

Hasselblad 3FR is a proprietary raw container format based on the TIFF/EP standard, typically generated by Hasselblad digital backs and cameras before being converted into fully tagged 3F files via Phocus.

When handling 3FR files, LibRaw performs the following:

  • Container Parsing: LibRaw parses the TIFF-like directory structure to extract uncompressed or losslessly compressed raw pixel arrays alongside embedded camera metadata.
  • Bayer Interpolation: Hasselblad medium format sensors (both CCD and CMOS variants) use customized Bayer filter arrays. LibRaw automatically selects an appropriate demosaicing method—such as AHD (Adaptive Homogeneity-Directed) or AMaZE—to resolve fine detail while minimizing chromatic aberration.
  • Color Matrices and White Balance: LibRaw reads camera-embedded white balance presets and applies factory-calibrated color correction matrices. Because Hasselblad relies heavily on its Hasselblad Natural Colour Solution (HNCS), standard LibRaw decoding uses reverse-engineered color profiles to approximate the sensor's native rendering.
  • High Bit-Depth Retention: 3FR files often capture up to 16 bits of color data per channel. LibRaw unpacks this full bit depth, which ImageMagick retains if compiled with Q16 or HDRI (High Dynamic Range Imaging) enabled.

Processing Phase One IIQ Files

Phase One medium format cameras produce raw files in the IIQ (Intelligent Image Quality) format. These files generally come in two compression profiles: IIQ L (lossless, full 14-bit or 16-bit raw data) and IIQ S (lossy, non-linear compression optimized to reduce file size).

LibRaw handles Phase One IIQ through distinct pipelines:

  • Decompression Algorithms: LibRaw includes specific routines to decode Phase One’s proprietary compression algorithms. For IIQ S files, LibRaw linearizes the tone curve from the compressed format back into raw sensor luminance values. For IIQ L, it extracts the native linear sensor data intact.
  • Sensor Calibration: Phase One backs often exhibit specific black-level offsets and sensor-edge patterns. LibRaw calculates active image boundaries and crops non-image optical black areas based on internal camera profile definitions.
  • Matrix Calibration: Phase One camera profiles in LibRaw utilize mapped color matrices to translate the wide-gamut sensor output into standard working color spaces (such as Adobe RGB or ProPhoto RGB).

Configuration and Command-Line Controls

ImageMagick allows users to pass operational flags to the underlying LibRaw delegate through -define arguments to modify default processing parameters:

  • Demosaicing Quality: Passing -define dng:read-method or configuring LibRaw flags can switch interpolation algorithms between faster, lower-overhead models and high-detail algorithms suited for high-resolution studio captures.
  • Color Profiles: By default, LibRaw converts raw data to standard sRGB. To preserve medium format fidelity, users should configure ImageMagick to output raw linear data or assign custom ICC profiles (such as the camera's native profile) using ImageMagick’s -profile command immediately following delegate execution.
  • Dynamic Range Management: In ImageMagick builds configured for Q16-HDRI, LibRaw passes the complete dynamic range without clipping highlights, allowing downstream exposure adjustments, tone mapping, and sharpening directly inside ImageMagick.
