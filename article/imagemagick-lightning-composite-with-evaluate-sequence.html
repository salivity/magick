ImageMagick Lightning Composite With evaluate-sequence

Creating a composite lightning photo combines multiple exposures into a single, dramatic image that captures every strike over a period of time. This guide explains the precise ImageMagick syntax needed to blend a series of lightning shots using the -evaluate-sequence operator, describes how the command functions under the hood, and provides practical examples for processing your image stacks efficiently.

The Basic Command Syntax

To blend multiple lightning photographs using ImageMagick 7, navigate to the folder containing your aligned images and run the following command:

magick *.jpg -evaluate-sequence max lightning_composite.jpg

If you are using ImageMagick 6, the legacy syntax uses convert instead:

convert *.jpg -evaluate-sequence max lightning_composite.jpg

How the Command Works

  • magick *.jpg: Loads all JPEG files in the current working directory into memory as an image sequence. You can substitute *.jpg with specific file names (e.g., frame1.tif frame2.tif frame3.tif) or another supported format like TIFF or PNG.
  • -evaluate-sequence max: Iterates through every pixel coordinate across all loaded images and selects the maximum pixel channel value (the brightest pixel) among them. Because lightning consists of extremely bright channels against a comparatively dark sky, the max method overlays every lightning bolt while preserving the base exposure of the landscape.
  • lightning_composite.jpg: Specifies the output filename and format for the final merged image.

Recommended Workflow for High-Resolution Stacks

When processing large sequences of high-resolution images, memory usage can become an issue. You can optimize the process and handle color management using the following best practices:

1. Pre-align the Frames

Ensure all source images were taken on a sturdy tripod. The -evaluate-sequence operator performs pixel-by-pixel evaluation without image alignment, so any camera shake will cause ghosting or blur in static foreground elements.

2. Process High-Bit-Depth TIFFs

For maximum dynamic range and color fidelity, export your raw files as 16-bit TIFFs before combining them:

magick input_*.tif -evaluate-sequence max -depth 16 final_composite.tif

3. Manage Memory Limits

If you are combining dozens of full-resolution camera files, ImageMagick might exhaust system RAM and fall back to disk caching. To ensure stable performance, limit memory or process images in smaller batches:

magick -limit memory 8GiB -limit map 16GiB *.tif -evaluate-sequence max output.tif
