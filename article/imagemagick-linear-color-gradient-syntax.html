ImageMagick Linear Color Gradient Syntax

This article explains how to generate linear color gradients using ImageMagick's built-in gradient pseudo-image formats. You will learn the exact command-line syntax for basic two-color gradients, custom-angle transitions, multi-stop blends, and dimension specifications using both standard and modern ImageMagick commands.

Basic Linear Gradient Syntax

ImageMagick generates linear gradients using the built-in gradient: pseudo-format. The general syntax requires defining an image size with -size followed by the start and end colors.

magick -size 600x400 gradient:blue-red output.png

In this command:

  • -size 600x400 defines the width and height of the canvas in pixels.
  • gradient:blue-red creates a top-to-bottom vertical transition starting with blue and ending with red.
  • output.png specifies the destination file.

Controlling Gradient Direction

By default, ImageMagick renders linear gradients vertically from top to bottom. You can change the orientation using gradient properties or transformation operations.

Angled Gradients (ImageMagick 7)

In ImageMagick 7, you can specify an angle using the -define gradient:angle parameter:

magick -size 600x400 -define gradient:angle=45 gradient:orange-purple diagonal.png
  • angle=0 creates a left-to-right horizontal gradient.
  • angle=90 creates a top-to-bottom vertical gradient.
  • angle=45 creates a diagonal gradient.

Horizontal Gradients Using Rotation (ImageMagick 6 & 7)

For backward compatibility or simpler scripts, generate the gradient at flipped dimensions and rotate it:

magick -size 400x600 gradient:black-white -rotate 90 horizontal.png

Multi-Stop Linear Gradients

ImageMagick 7 supports multi-stop linear gradients directly within the syntax by chaining multiple color values separated by hyphens:

magick -size 800x200 gradient:red-yellow-green-blue multi_gradient.png

Each color acts as a stop distributed evenly across the designated axis.

Supported Color Formats

Colors in gradient definitions support various representations:

  • Color Names: gradient:navy-gold
  • Hex Codes: gradient:"#ff0055-#00ffaa" (quotes are required when using the # character)
  • RGB/RGBA Values: gradient:"rgb(255,0,0)-rgb(0,0,255)"
  • Transparency: gradient:"rgba(255,0,0,1)-transparent"

Using the linear-gradient: Pseudoclass

Modern versions of ImageMagick also support the linear-gradient: pseudo-format, which aligns closely with SVG style gradient definitions by allowing coordinate bounding:

magick -size 600x400 -define gradient:bounding-box=600x400 linear-gradient:cyan-magenta svg_style.png
