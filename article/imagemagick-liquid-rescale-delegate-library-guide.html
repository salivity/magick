ImageMagick Liquid Rescale Delegate Library Guide

To use the liquid-rescale feature in ImageMagick, you must have the liblqr (Liquid Rescale Library) external delegate installed on your system. Liquid rescaling relies on seam carving technology to intelligently resize images without distorting the primary subjects. This article explains what liblqr is, how ImageMagick utilizes it, and how to check, install, and configure this delegate on your machine.

The Required Delegate: liblqr

The liquid-rescale functionality in ImageMagick is powered by liblqr (specifically liblqr-1). It is an open-source, C/C++ implementation of the seam carving algorithm designed by Shai Avidan and Ariel Shamir.

Standard scaling operations alter every pixel uniformly, which often causes distortion or awkward stretching. The liblqr library calculates energy maps across an image to identify paths of least importance (seams) and removes or inserts them, enabling content-aware resizing directly within ImageMagick via the -liquid-rescale operator.

How to Check for liblqr Support

You can determine whether your current ImageMagick build includes liblqr support by running the following command in your terminal:

magick -version

(Or convert -version for ImageMagick version 6)

Look at the Delegates (built-in) line in the output. If lqr is listed among the delegates, liquid-rescale is ready to use.

Alternatively, you can query ImageMagick delegates directly:

magick identify -list configure | grep -i "delegates"

Installing liblqr

If lqr is missing from your configuration, you need to install the library package and recompile ImageMagick or install a precompiled binary that includes it.

Ubuntu / Debian

Install the development package before compiling ImageMagick from source:

sudo apt-get update
sudo apt-get install liblqr-1-0-dev

Fedora / RHEL / CentOS

sudo dnf install liblqr-1-devel

macOS (via Homebrew)

brew install liblqr

Using the Liquid-Rescale Command

Once the delegate is installed and enabled, you can perform content-aware image resizing using the -liquid-rescale parameter:

magick input.jpg -liquid-rescale 75x100% output.jpg

This command reduces the width of the image to 75% using seam carving while retaining the original height and preserving key focal points of the composition.
