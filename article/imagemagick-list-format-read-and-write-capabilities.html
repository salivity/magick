ImageMagick -list format Read and Write Capabilities

Running the magick -list format (or identify -list format) command in ImageMagick outputs a comprehensive catalog of supported file types alongside their respective coder capabilities. This article details the specific information provided by this command, focusing on how it communicates read, write, and multi-frame processing permissions through its structured column output.

Output Structure of the Command

When executed, the -list format command returns a tabbed table containing four primary columns for every registered format:

  1. Format: The internal file format tag or file extension (such as PNG, JPEG, TIFF, or PDF).
  2. Module: The underlying coder or delegate library responsible for handling the format (e.g., PNG, JPEG, PDF).
  3. Mode: A set of character flags representing the read, write, and multi-frame capabilities of the coder.
  4. Description: The human-readable name of the format, often including version or specification details.

The Mode Column: Decoding Read and Write Flags

The coder's read and write capabilities are specifically conveyed within the Mode column. This column contains a three-character string where each position defines a specific operation permission:

  • Read Support (r): If an r is present in the first position, ImageMagick possesses the coder or external delegate necessary to decode and read the file format into memory. If read capability is absent, a hyphen (-) appears.
  • Write Support (w): If a w is present in the second position, ImageMagick can encode and save images in that format. If writing is not supported, a hyphen (-) appears.
  • Multi-Image Support (+): The third position denotes whether the coder supports multiple frames, layers, or pages within a single file (such as animated GIFs, multi-page PDFs, or layered TIFFs). A plus sign (+) indicates multi-image read and write capability, while a hyphen (-) indicates single-image-only support.

Common Mode Output Examples

  • rw+ (Full Support): The format can be read, written, and supports multiple frames or pages (e.g., GIF, TIFF, MNG).
  • rw- (Single-Image Read/Write): The format can be decoded and encoded, but each file holds only a single image frame (e.g., JPEG, PNG, BMP).
  • r-- (Read-Only): ImageMagick can read and extract data from the format, but it cannot generate or save new files using that format coder (common with proprietary camera RAW formats such as CR2 or NEF).
  • -w- (Write-Only): ImageMagick can export data to this format, but cannot read it back.
  • --- (Unsupported / Inactive): The format tag is recognized by ImageMagick's registry, but neither reading nor writing is available, usually because the required third-party delegate library (such as libpng, libjpeg, or Ghostscript) is missing from the system.
