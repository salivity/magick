ImageMagick List Threshold Command Output

Executing the ImageMagick -list threshold command generates a detailed list of all built-in threshold maps available within the software installation. This article breaks down the exact output produced by this command, explains the structure of the data displayed, and clarifies how these threshold maps are utilized in image processing tasks like ordered dithering and halftoning.

When you run magick -list threshold (or convert -list threshold in ImageMagick 6), ImageMagick queries its internal configuration and outputs an index of predefined dither matrices.

Typical Terminal Output

The command outputs plain text organized in columns, resembling the following structure:

Map                  Width Height Divisor Levels Description
--------------------------------------------------------------------------------
threshold                1      1       2      2 Simple 1x1 threshold map
checks                   2      1       2      2 Checkerboard 2x1 map
o2x2                     2      2       4      2 2x2 ordered dither
o3x3                     3      3       9      2 3x3 ordered dither
o4x4                     4      4      16      2 4x4 ordered dither
o8x8                     8      8      64      2 8x8 ordered dither
h4x4a                    4      4      16      5 4x4 halftone angled
h6x6a                    6      6      36      9 6x6 halftone angled
h8x8a                    8      8      64     17 8x8 halftone angled
c5x5b                    5      5      25      2 5x5 circle (black)
c5x5w                    5      5      25      2 5x5 circle (white)
c6x6b                    6      6      36      2 6x6 circle (black)
c6x6w                    6      6      36      2 6x6 circle (white)
c7x7b                    7      7      49      2 7x7 circle (black)
c7x7w                    7      7      49      2 7x7 circle (white)

(Note: Depending on the specific release and build options of ImageMagick, the column headers or exact map names may vary slightly, but the categorized matrices remain standard.)

Understanding the Output Columns

The output provides the mathematical parameters for each matrix pattern:

  • Map: The alias or identifier of the threshold pattern. This is the exact string passed to operators such as -ordered-dither.
  • Width & Height: The pixel dimensions of the threshold matrix. Larger matrices generally provide smoother gradients at the cost of high-frequency detail.
  • Divisor: The normalization factor used to scale integer values within the threshold matrix into floating-point thresholds between 0.0 and 1.0.
  • Levels: The default number of distinct intensity levels or steps represented by the pattern.
  • Description: A short explanation of the visual pattern, such as Bayer ordered dither, halftone screen, or circular dispersed dot.

Common Use Cases for This Output

The names listed in this output are primarily referenced when applying ordered dithering. For example, knowing the identifier o8x8 enables users to apply an 8x8 Bayer dither pattern using:

magick input.jpg -ordered-dither o8x8 output.png

Running -list threshold confirms which standard matrices—such as traditional Bayer grids (o2x2 through o8x8), halftone dot clusters (h4x4a, h8x8a), or circular patterns (c5x5b)—are supported natively by your current ImageMagick binary.
