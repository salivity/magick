ImageMagick MagickWand Unsharp Mask in C

This article explains how to perform an unsharp mask sharpening operation in C using the ImageMagick MagickWand API. It covers the specific function used, its parameters, and a minimal C code implementation to sharpen an image.

The MagickUnsharpMaskImage Function

The MagickWand C API provides the MagickUnsharpMaskImage() function to sharpen an image by applying an unsharp mask.

Function Signature

MagickBooleanType MagickUnsharpMaskImage(
    MagickWand *wand,
    const double radius,
    const double sigma,
    const double amount,
    const double threshold
);

Parameter Breakdown

  • wand: A pointer to the MagickWand structure containing the loaded image.
  • radius: The radius of the Gaussian blur operator in pixels, excluding the center pixel. A value of 0 lets ImageMagick calculate a reasonable default based on sigma.
  • sigma: The standard deviation of the Gaussian operator in pixels. This determines how much detail is targeted.
  • amount: The percentage of the blurred image to subtract from the original (expressed as a decimal, e.g., 1.0 for 100%, 1.5 for 150%). This defines the strength of the sharpening.
  • threshold: The minimum difference required between the original and blurred pixels to apply sharpening. It helps prevent noise enhancement in smooth areas.

C Code Example

Below is a complete example of applying an unsharp mask using MagickWand in C:

#include <stdio.h>
#include <wand/MagickWand.h>

int main(int argc, char **argv) {
    MagickWand *magick_wand;
    MagickBooleanType status;

    // Initialize the MagickWand environment
    MagickWandGenesis();
    magick_wand = NewMagickWand();

    // Read the input image
    status = MagickReadImage(magick_wand, "input.jpg");
    if (status == MagickFalse) {
        fprintf(stderr, "Failed to read image\n");
        return 1;
    }

    // Apply the unsharp mask: radius=0, sigma=1.0, amount=1.5, threshold=0.05
    status = MagickUnsharpMaskImage(magick_wand, 0.0, 1.0, 1.5, 0.05);
    if (status == MagickFalse) {
        fprintf(stderr, "Failed to apply unsharp mask\n");
        return 1;
    }

    // Save the sharpened image
    status = MagickWriteImage(magick_wand, "output.jpg");
    if (status == MagickFalse) {
        fprintf(stderr, "Failed to write image\n");
        return 1;
    }

    // Clean up resources
    magick_wand = DestroyMagickWand(magick_wand);
    MagickWandTerminus();

    return 0;
}
