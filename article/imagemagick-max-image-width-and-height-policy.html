ImageMagick Max Image Width and Height Policy

This article explains how to restrict the maximum image pixel width and height in ImageMagick using security policy configurations. By modifying the policy.xml configuration file, administrators can enforce strict dimension boundaries to prevent resource exhaustion and denial-of-service attacks caused by oversized image processing.

The Policy Parameters: width and height

To restrict the maximum pixel dimensions of an image, ImageMagick uses the width and height resource policies. Additionally, the area parameter can be used to limit the total pixel count (width multiplied by height).

  • name="width": Defines the maximum allowed horizontal dimension in pixels.
  • name="height": Defines the maximum allowed vertical dimension in pixels.
  • name="area": Defines the maximum total pixel area (width × height) an image can occupy before triggering a policy restriction.

Configuring policy.xml

Resource limits are defined in ImageMagick's policy.xml file, typically located at /etc/ImageMagick-7/policy.xml or /etc/ImageMagick-6/policy.xml on Linux systems.

To apply maximum width and height limits, add or modify the following lines inside the <policymap> element:

<policymap>
  <!-- Set maximum width to 8,000 pixels -->
  <policy domain="resource" name="width" value="8KP"/>

  <!-- Set maximum height to 8,000 pixels -->
  <policy domain="resource" name="height" value="8KP"/>

  <!-- Optional: Restrict total pixel area -->
  <policy domain="resource" name="area" value="64MP"/>
</policymap>

Values can be specified in plain integers (e.g., 8000), or using SI unit prefixes such as KP (kilo-pixels) or MP (mega-pixels).

Error Behavior

When an image exceeds the defined width or height thresholds, ImageMagick immediately halts processing and returns a fatal error:

convert: width or height exceeds limit `image.jpg' @ error/validate.c/ValidateColormap/123

This prevents the server from allocating excessive memory or CPU time to process maliciously crafted or excessively large images.
