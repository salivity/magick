ImageMagick Max Pixel Dimension Limits

This article explains how to restrict the maximum pixel dimensions of images processed by ImageMagick to prevent memory exhaustion and Denial-of-Service (DoS) attacks. ImageMagick uses resource limits defined via command-line arguments and configuration policy files to enforce strict boundaries on image width, height, and total pixel area.

The Resource Limit Parameters

In ImageMagick, the primary parameters used to restrict the maximum pixel dimensions are the width, height, and area resource limits.

  • width: Caps the maximum allowable width in pixels for any read or processed image.
  • height: Caps the maximum allowable height in pixels for any read or processed image.
  • area: Sets a limit on the total number of pixels (\(\text{width} \times \text{height}\)) an image can contain before ImageMagick rejects it or offloads pixel caching to disk.

Setting Dimension Limits via the Command Line

You can enforce dimension limits on individual operations using the -limit command-line option:

magick input.jpg -limit width 4000 -limit height 4000 -limit area 16MP output.jpg

In this example:

  • Any image with a width greater than 4,000 pixels will be rejected.
  • Any image with a height greater than 4,000 pixels will be rejected.
  • The area parameter limits the total pixel buffer to 16 megapixels.

Enforcing System-Wide Limits in policy.xml

For permanent, system-wide protection, these constraints are defined inside the policy.xml configuration file (typically located in /etc/ImageMagick-7/ or /etc/ImageMagick-6/).

Add or modify the following XML directives inside the <policymap> section:

<policymap>
  <!-- Restrict maximum width to 8,000 pixels -->
  <policy domain="resource" name="width" value="8KP"/>

  <!-- Restrict maximum height to 8,000 pixels -->
  <policy domain="resource" name="height" value="8KP"/>

  <!-- Restrict total image pixel area to 64 Megapixels -->
  <policy domain="resource" name="area" value="64MP"/>
</policymap>

When an input image exceeds any of these configured limits, ImageMagick immediately halts processing and throws a fatal/cache: width or height exceeds limit exception, safeguarding system memory and CPU resources.
