ImageMagick Mogrify Output Directory Syntax

This article provides the exact syntax for directing processed images to an alternate output directory using ImageMagick's mogrify command. By default, mogrify overwrites the original input files in place, but using the -path parameter ensures your modified images are saved safely to a designated destination folder.

The Basic Syntax

To specify an alternate output directory, use the -path option followed by the target folder path:

magick mogrify -path /path/to/output_directory [options] input_files

(Note: For ImageMagick version 6, omit the leading magick keyword and simply use mogrify.)

Important Requirements

  • The Directory Must Exist: ImageMagick will not create the output directory automatically. You must create the destination folder before running the command (e.g., using mkdir output_dir).
  • Path Placement: Place the -path parameter before specifying the input files.

Practical Examples

1. Resize images and save to a subfolder:

mkdir -p ./resized
magick mogrify -path ./resized -resize 800x600 *.jpg

2. Convert format and write to a separate directory:

mkdir -p /absolute/path/to/png_output
magick mogrify -path /absolute/path/to/png_output -format png *.jpg

3. Compress quality and save to a parent directory:

mkdir -p ../compressed
magick mogrify -path ../compressed -quality 80% *.webp
