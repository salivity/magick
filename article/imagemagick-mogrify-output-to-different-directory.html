ImageMagick Mogrify Output to Different Directory

Batch processing images with ImageMagick's mogrify command typically overwrites the original source files in place. However, you can prevent overwriting and redirect the processed files to a dedicated folder by using the -path flag. This guide explains the exact syntax required to route mogrify outputs to another directory, along with practical examples for resizing and format conversion.

The Basic Syntax

To specify an output destination, use the -path option followed by the target directory path:

magick mogrify -path /path/to/output_directory [options] *.ext

(Note: For ImageMagick version 6, omit the leading magick command and run mogrify directly.)

Important Prerequisite

The target directory must exist before running the command. ImageMagick will not create the destination directory automatically and will produce an error if the folder is missing.

You can create the target directory beforehand using mkdir:

mkdir -p /path/to/output_directory

Practical Examples

1. Batch Resizing Images to a New Directory

To resize all .jpg images in the current directory to a maximum width of 800 pixels and save them in a subfolder named resized:

mkdir -p resized
magick mogrify -path resized -resize 800x *.jpg

2. Converting File Formats While Changing Directory

You can combine the -path flag with the -format flag to convert file types and route them elsewhere simultaneously. For example, converting all .png files to .webp and saving them into an output folder:

mkdir -p output
magick mogrify -path output -format webp *.png

3. Adjusting Compression Quality to an Absolute Path

To compress images to 85% JPEG quality and route them using an absolute file path:

mkdir -p /var/www/images/optimized
magick mogrify -path /var/www/images/optimized -quality 85 *.jpg
