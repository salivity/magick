ImageMagick Mogrify vs Convert Explained

ImageMagick provides two primary command-line utilities for processing images: convert and mogrify. While both tools share similar underlying transformation features and command-line options, they fundamentally differ in how they handle input files, output generation, and batch processing. This guide breaks down the key distinctions between these two commands to help you choose the right tool for your workflow.

File Overwriting vs. New File Creation

The most significant difference between the two commands is how they treat the source image:

  • convert reads a source file, applies operations, and saves the output to a new, explicitly defined destination file. The original image remains unchanged.
  • mogrify is designed to overwrite the original image file by default. It processes the image and saves the results back onto the source file unless configured otherwise.

Syntax and Output Specifications

The structure of each command reflects how it handles file creation:

  • convert Syntax: Requires both an input filename and an output filename. 
    convert input.jpg -resize 800x600 output.jpg
  • mogrify Syntax: Takes operations first, followed by the target file(s). It does not take an explicit output filename parameter. 
    mogrify -resize 800x600 input.jpg

Batch Processing Capabilities

  • convert is tailored for single-image workflows. To process multiple files using convert, you generally need to write a shell loop (such as a Bash for loop) to iterate through the directory.
  • mogrify natively supports wildcard operations for batch processing across entire directories without external scripts: 
    mogrify -resize 50% *.png

Preventing Overwriting in Mogrify

Although mogrify defaults to in-place modification, it includes flags to prevent overwriting originals during batch operations:

  • -path: Directs output files to a specific target folder. 
    mogrify -path /path/to/output/ -resize 800x600 *.jpg
  • -format: Converts images to a different extension while retaining the base filename. 
    mogrify -format png *.jpg

Modern Usage (ImageMagick v7)

In ImageMagick version 7, standard tool execution changed slightly:

  • convert is invoked using the base command: magick
  • mogrify is invoked using: magick mogrify

Despite this update, the functional difference remains: magick creates new files, while magick mogrify handles batch and in-place transformations.
