ImageMagick Montage Drop Shadows on Tiles

ImageMagick makes it easy to generate polished grid layouts by applying shadow effects directly beneath individual image tiles using its built-in montage command. By combining the -shadow operator with proper tile spacing and background configurations, you can automatically render soft drop shadows around each image in an assembled grid without needing complex manual layering.

Basic Command for Drop Shadows

The simplest way to add shadows to individual tiles is by including the -shadow switch in your montage command.

montage *.jpg -shadow -geometry 200x200+15+15 -background white output.jpg

Key Parameters Explained

To ensure shadows render correctly and do not clip, specific options must be tuned:

  • -shadow: Enables the default drop-shadow effect underneath each individual thumbnail tile.
  • -geometry: Controls the thumbnail size and spacing. The format [width]x[height]+[x_offset]+[y_offset] (such as 200x200+15+15) provides the necessary margin around each tile so the shadow has room to display without overlapping neighboring images or getting clipped.
  • -background: Defines the canvas color behind the tiles and shadows. Use white for solid backgrounds or none if you want a transparent PNG output.
  • -tile: (Optional) Specifies the grid layout dimension, such as -tile 3x for a fixed 3-column grid.

Creating Shadows with Transparent Backgrounds

If you are generating a PNG and require the shadow to blend over other elements on the web, set the canvas background to transparent:

montage *.png -background none -shadow -geometry 150x150+20+20 output.png

Advanced Custom Shadows

The built-in -shadow option in montage applies a fixed shadow profile. If you need precise control over shadow opacity, blur radius, or offset coordinates, preprocess the tiles using the modern magick command before assembling them:

magick *.jpg -thumbnail 200x200 \
  \( +clone -background black -shadow 60x4+5+5 \) +swap \
  -background none -layers merge +repage miff:- | \
  montage - -background white -geometry +10+10 custom_shadow_grid.jpg

In this pipeline, each tile is scaled, cloned to generate a custom shadow with specific blur and offset values (60x4+5+5), merged, and piped directly into montage for final grid placement.
