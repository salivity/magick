ImageMagick Montage Frame Option Guide

The -frame option in the ImageMagick montage command is used to place a decorative, three-dimensional border around individual image tiles within a composite grid. This article explains the purpose of the -frame option, breaks down its geometry syntax, demonstrates how to customize its appearance, and provides practical command-line examples.

Core Purpose of the -frame Option

When generating image grids or contact sheets using montage, images are placed side-by-side by default. Applying the -frame option surrounds each thumbnail with an ornamental frame that includes beveled edges, creating a raised, recessed, or picture-frame effect. This visually separates individual tiles, enhances aesthetics, and makes thumbnails stand out against the background.

Syntax and Geometry Breakdown

The -frame option accepts a specific geometry format:

-frame <width>x<height>+<outer-bevel>+<inner-bevel>
  • <width>x<height>: Defines the thickness (in pixels) of the horizontal and vertical sides of the frame.
  • +<outer-bevel>: Specifies the pixel depth of the outer highlight/shadow bevel.
  • +<inner-bevel>: Specifies the pixel depth of the inner bevel touching the image border.

If the bevel values are omitted (e.g., -frame 5x5), ImageMagick automatically calculates proportional bevel depths.

Customizing Frame Color

The frame's base color is controlled using the -mattecolor option, while the lighting effects (highlights and shadows) are automatically computed by ImageMagick based on that color:

montage *.jpg -mattecolor "#dcdcdc" -frame 8x8+3+3 output.png

In this command:

  • Each image receives an 8-pixel horizontal and vertical frame.
  • Both the outer and inner edges feature a 3-pixel 3D bevel.
  • The frame color is light gray (#dcdcdc), producing realistic light and shade transitions along the beveled edges.

-frame vs. -border

While the -border option adds a flat, solid-colored rectangle around each image tile, -frame adds depth using shaded highlights and shadows. Use -frame whenever a physical, raised-mount, or classic framed gallery look is required.
