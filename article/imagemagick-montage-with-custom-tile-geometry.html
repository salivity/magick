ImageMagick Montage with Custom Tile Geometry

Creating an image montage with custom tile geometry in ImageMagick allows you to combine multiple images into a structured grid with precise control over thumbnail dimensions, spacing, offsets, and grid layout. By utilizing the montage tool alongside the -geometry and -tile options, you can define exact pixel constraints, remove or add borders, and control how many rows and columns appear in the final output.

Basic Syntax

In ImageMagick (version 7+), the core syntax for generating a montage with custom geometry is:

magick montage [input_images] -tile [columns]x[rows] -geometry [width]x[height]+[x_offset]+[y_offset] [output_image]

(Note: In ImageMagick version 6, replace magick montage with simply montage.)

Understanding the Key Parameters

1. The -geometry Option

The -geometry parameter controls both the size of individual image tiles and the spacing between them. The syntax follows the format:

-geometry <width>x<height>+<x_offset>+<y_offset>
  • <width>x<height>: Defines the maximum bounding box for each thumbnail while preserving the original aspect ratio by default.
  • +<x_offset>+<y_offset>: Sets the horizontal and vertical margins (gap) surrounding each tile.

Common geometry modifiers:

  • 200x200+5+5 — Scales images to fit within 200x200 pixels with a 5px margin.
  • 200x200!+0+0 — Forces exact dimensions of 200x200 pixels (ignoring aspect ratio) with zero spacing.
  • 200x200^+0+0 — Resizes the image to completely fill the 200x200 area (often used with -gravity center -crop 200x200+0+0 for uniform cropped squares).
  • +0+0 — Retains the original image sizes and removes all default spacing and borders.

2. The -tile Option

The -tile parameter defines the layout of the grid:

-tile <columns>x<rows>
  • 3x2 — Arranges images in 3 columns and 2 rows.
  • 4x — Fixes the layout to 4 columns, dynamically creating as many rows as needed.
  • x3 — Fixes the layout to 3 rows, dynamically creating as many columns as needed.

Practical Examples

Standard Grid with Spacing

To arrange all JPEG files in a directory into a 3-column grid with 150x150 px thumbnails and 10px spacing:

magick montage *.jpg -tile 3x -geometry 150x150+10+10 output_grid.jpg

Seamless Grid (No Borders, Padding, or Spacing)

By default, montage adds a frame and background color. To produce a seamless composite with zero gap:

magick montage image1.png image2.png image3.png image4.png -tile 2x2 -geometry 300x300+0+0 -background none seamless_montage.png

Uniform Cropped Square Thumbnails

To create uniform square tiles from images with varying aspect ratios without distortion, combine geometry sizing with gravity and cropping:

magick montage *.jpg -tile 4x -geometry 200x200^+2+2 -gravity center -crop 200x200+0+0 cropped_montage.jpg

Montage Retaining Original Image Sizes

If images are pre-scaled and you only want to align them in a 2x2 grid without resizing:

magick montage *.png -tile 2x2 -geometry +0+0 output.png
