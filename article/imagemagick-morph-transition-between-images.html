ImageMagick Morph Transition Between Images

Creating an animated fade or morph transition between two photographs in ImageMagick is achieved primarily using the -morph operator. This guide covers the exact syntax required to generate a smooth cross-fading GIF transition, ensure both input images match in dimension, and configure frame delays and looping for optimal playback.

Basic Morph Syntax

To generate a fading transition between two images of the same dimensions, use the following core command:

ImageMagick v7:

magick image1.jpg image2.jpg -morph 20 output.gif

ImageMagick v6:

convert image1.jpg image2.jpg -morph 20 output.gif

The integer passed to -morph (in this case, 20) specifies the number of in-between interpolation frames generated between the two source images.

Controlling Playback Speed and Looping

By default, an animated GIF produced by -morph will animate rapidly without pauses. You can control frame rate and continuous looping with the -delay and -loop flags:

magick image1.jpg image2.jpg -delay 10 -morph 20 -loop 0 output.gif
  • -delay 10: Sets the duration of each frame in ticks (where 100 ticks = 1 second; 10 equals 0.10 seconds per frame).
  • -loop 0: Ensures the resulting GIF loops indefinitely.

Adding a Pause on the Start and End Photos

To pause on the full starting and ending images before and after the morphing sequence, set a custom delay on the first and last frames:

magick image1.jpg image2.jpg -morph 20 -set delay "%[fx:(t==0 || t==n-1) ? 150 : 8]" -loop 0 output.gif
  • t==0: Identifies the first frame.
  • t==n-1: Identifies the final frame.
  • 150: Delays the start and end frames by 1.5 seconds.
  • 8: Keeps transition frames moving smoothly at 0.08 seconds per frame.

Handling Images with Different Dimensions

The -morph operator requires both input images to share identical dimensions. If the source photos have different sizes or aspect ratios, normalize them inline before applying the morph:

magick image1.jpg image2.jpg -resize 800x600^ -gravity center -extent 800x600 -morph 25 -delay 10 -loop 0 transition.gif
  • -resize 800x600^: Scales the image while maintaining aspect ratio to fill the bounding box.
  • -gravity center -extent 800x600: Crops excess areas symmetrically to enforce identical canvas sizes.
