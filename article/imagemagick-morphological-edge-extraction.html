ImageMagick Morphological Edge Extraction

Morphological edge extraction in ImageMagick is a technique used to detect boundaries in an image by analyzing spatial structures through mathematical morphology. By applying the -morphology operator with specific kernels such as diamonds, disks, or squares, ImageMagick can calculate the difference between dilated and eroded regions of an image to isolate high-contrast boundaries. This guide explains the commands, methods, and kernel selections required to extract standard, internal, and external edges using ImageMagick.

Understanding Morphological Edge Detection

Morphological edge extraction relies on standard dilation (expanding bright regions) and erosion (shrinking bright regions). ImageMagick provides three primary edge detection methods:

  • Standard Edge (Gradient): Subtracts the eroded image from the dilated image. This generates a balanced outline along object borders.
  • EdgeIn (Internal Edge): Subtracts the eroded image from the original image, producing an edge strictly inside the boundary of bright objects.
  • EdgeOut (External Edge): Subtracts the original image from the dilated image, producing an edge strictly outside the boundary of bright objects.

Standard Edge Extraction (Morphological Gradient)

To perform standard edge extraction, apply the Edge method along with a kernel definition. A 1-pixel radius diamond or square is commonly used for standard pixel-level boundaries.

magick input.png -morphology Edge Diamond:1 output_edge.png

For ImageMagick v6, replace magick with convert:

convert input.png -morphology Edge Diamond:1 output_edge.png

Internal and External Edge Extraction

If you need the edge lines to sit specifically inside or outside the object boundaries, use EdgeIn or EdgeOut.

Internal Edge (EdgeIn):

magick input.png -morphology EdgeIn Diamond:1 output_edge_in.png

External Edge (EdgeOut):

magick input.png -morphology EdgeOut Diamond:1 output_edge_out.png

Kernel Selection and Radius

The shape and size of the kernel determine which edge angles are emphasized and the thickness of the resulting line.

  • Diamond: Ideal for thin, pixel-aligned 4-connected boundary detection. 
    magick input.png -morphology Edge Diamond:1 output.png
  • Square: Captures 8-connected boundaries including diagonal transitions. 
    magick input.png -morphology Edge Square:1 output.png
  • Disk: Produces smooth, circular edge boundaries, which is useful when working with larger radii. 
    magick input.png -morphology Edge Disk:2.5 output.png
  • Octagon: Provides a balanced, isotropic approximation between squares and disks. 
    magick input.png -morphology Edge Octagon:2 output.png

Preprocessing and Enhancing Results

For cleaner edge lines, it is best practice to convert the image to grayscale and remove unwanted noise before running the morphology command.

  1. Grayscale Conversion: Prevent channel-by-channel artifacts by converting to grayscale first using -colorspace Gray.
  2. Thresholding: Apply -threshold either before morphology (for binary edge detection) or after (to remove faint edge artifacts).
magick input.png -colorspace Gray -morphology Edge Diamond:1 -threshold 10% output_clean.png

For binary silhouettes, thresholding the input first creates sharp, solid boundaries:

magick input.png -colorspace Gray -threshold 50% -morphology Edge Diamond:1 output_binary_edge.png
