ImageMagick Morphology EdgeIn Explained

The EdgeIn operator in ImageMagick is a mathematical morphology method used for edge detection, specifically designed to extract the inner boundary of shapes within an image. By subtracting an eroded version of an image from the original image, EdgeIn isolates pixels that lie directly along the inside perimeter of foreground objects. This guide explains how the operator works, how the chosen kernel affects the result, and how to implement it effectively using the ImageMagick command line.

How the EdgeIn Operator Works

In mathematical morphology, edge detection is typically achieved by calculating the difference between an image and an altered version of itself. The EdgeIn operator generates an "inner edge" using the following formula:

\[\text{EdgeIn} = \text{Original Image} - \text{Erosion}\]

  1. Erosion: The algorithm shrinks the bright (foreground) regions of the image based on a specified shape and size known as a kernel or structuring element.
  2. Subtraction: The eroded image is subtracted pixel-by-pixel from the original image.

Because the erosion operation eats away at the edges of shapes from the outside in, subtracting this smaller version from the original leaves behind only the thin shell of pixels that were removed. Consequently, the detected boundary lines fall entirely inside the original boundaries of the target object.

The Role of the Kernel

The appearance, thickness, and directional sensitivity of the resulting edge depend entirely on the kernel applied with the operator. ImageMagick allows you to specify various kernel shapes—such as Disk, Diamond, Square, or Octagon—along with a radius.

  • Radius/Size: A kernel with a radius of 1 produces a sharp, thin edge (typically 1 pixel wide). Increasing the kernel size broadens the erosion effect, producing a thicker inner border.
  • Shape: Symmetrical shapes like Disk produce smooth, uniform borders around curves, while shapes like Diamond or Square favor specific pixel connectivity (4-connected or 8-connected neighbors).

Command-Line Usage

To use the EdgeIn operator in ImageMagick, combine the -morphology option with the EdgeIn method and your chosen kernel.

Basic syntax:

magick input.png -morphology EdgeIn Disk:1 output.png

In this command:

  • input.png is the source image (typically a binary or high-contrast grayscale image for best results).
  • -morphology EdgeIn specifies the inner edge morphological operation.
  • Disk:1 defines a disk-shaped kernel with a radius of 1 pixel.
  • output.png is the resulting image showing only the inner perimeter of the shapes.

Difference Between EdgeIn, EdgeOut, and Edge

ImageMagick provides three related morphological edge operators:

  • EdgeIn (Inner Edge): Subtracts the eroded image from the original (\(\text{Original} - \text{Erosion}\)). The edge rests entirely inside the shape's original perimeter.
  • EdgeOut (Outer Edge): Subtracts the original image from the dilated image (\(\text{Dilation} - \text{Original}\)). The edge rests completely outside the shape's original perimeter.
  • Edge (Morphological Gradient): Subtracts the eroded image from the dilated image (\(\text{Dilation} - \text{Erosion}\)). The edge straddles the true boundary, overlapping both the inside and outside of the shape.

The EdgeIn operator is ideal when object boundaries must not expand into neighboring elements or when preserving the exact exterior dimensions of an object is critical to the analysis.
