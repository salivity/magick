ImageMagick Morphology Thinning to Find Skeletons

Image skeletonization reduces shapes in a binary image to a 1-pixel-wide central line representation while preserving the essential topological structure and connectivity. In ImageMagick, this process is achieved using the morphological Thinning method paired with specialized structuring kernels, such as the Skeleton kernel. By iteratively applying this operation until the image converges, you can extract clean topological skeletons for shape analysis, optical character recognition (OCR), or feature extraction.

Preparing the Input Image

Morphological operations in ImageMagick operate under the convention that the foreground object is pure white (#FFFFFF) and the background is pure black (#000000). If your source image is not already in this format, you must convert it to grayscale and threshold it before applying morphology.

To ensure the foreground is correctly targeted:

  • Convert color images to grayscale.
  • Apply a threshold to create a binary mask.
  • Use -negate if your original object is black on a white background.

The Basic Thinning Command

The syntax for performing morphological thinning uses the -morphology operator followed by the method, iteration count, and the kernel name:

magick input.png -colorspace Gray -threshold 50% -morphology Thinning:-1 Skeleton output_skeleton.png

Command Breakdown

  • -colorspace Gray -threshold 50%: Converts the image into a strict black-and-white binary image.
  • -morphology Thinning: Specifies the morphological thinning method, which removes pixels from the boundary of an object as long as removing them does not break the object's connectivity.
  • :-1: Defines the iteration count. A value of -1 (or > for until-no-change) tells ImageMagick to repeat the thinning process iteratively until the image reaches a state of convergence where no more pixels can be removed.
  • Skeleton: Specifies the built-in kernel series designed specifically to strip away outer layers while maintaining endpoints and connectivity.

Using Different Skeleton Kernels

ImageMagick provides built-in variations of the skeleton kernel to handle different geometric configurations:

  1. Standard Skeleton (Skeleton or Skeleton:1): Preserves 8-connected lines and prevents the erasure of endpoints.

    magick input.png -morphology Thinning:-1 Skeleton skeleton.png

  2. Medial Axis Skeleton (Skeleton:2): A variation that produces a slightly different skeleton path along corners and diagonal intersections.

    magick input.png -morphology Thinning:-1 Skeleton:2 skeleton_medial.png

Post-Processing: Pruning Skeletons

Raw skeletons often contain unwanted spurs or small branches caused by minor surface noise on the original shape. You can prune these extra branches using the LineEnds kernel to erode small terminal lines:

magick skeleton.png -morphology Thinning:3 LineEnds pruned_skeleton.png

In this command, replacing -1 with a specific integer (such as 3) limits the thinning to three iterations, stripping away the outer three pixels from every open end without collapsing the main connected paths.
