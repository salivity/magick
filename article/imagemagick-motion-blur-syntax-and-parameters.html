ImageMagick Motion Blur Syntax and Parameters

This guide provides a comprehensive breakdown of the motion-blur operator in ImageMagick, detailing its command-line syntax, the role of each required parameter, and practical implementation examples. Readers will learn how to accurately configure radius, sigma, and angle settings to simulate realistic directional motion in digital images.

Command Syntax

The operator used to apply a directional blur in ImageMagick is -motion-blur. The syntax follows this structure:

magick input.jpg -motion-blur {radius}x{sigma}+{angle} output.jpg

(Note: Use convert instead of magick for ImageMagick version 6.)

Parameter Breakdown

The parameter string {radius}x{sigma}+{angle} consists of three core components separated by standard delimiters:

  1. Radius (radius)

    • Unit: Pixels
    • Description: Defines the maximum distance (bounding area) of the blur effect.
    • Recommended Value: Set to 0. When set to 0, ImageMagick automatically calculates the optimal radius based on the sigma value, preventing premature cutoff of the blur trail.

  2. Sigma (sigma)

    • Unit: Floating-point number (pixels)
    • Description: Represents the standard deviation of the Gaussian filter. This is the primary control for blur intensity and length.
    • Effect: Larger values create a longer, more pronounced motion streak; smaller values produce subtle movement.

  3. Angle (angle)

    • Unit: Degrees (0 to 360)
    • Description: Dictates the direction of the motion path.
    • Direction Reference:
      • 0: Horizontal blur (left-to-right)
      • 90: Vertical blur (top-to-bottom)
      • 180: Horizontal blur (right-to-left)
      • 270: Vertical blur (bottom-to-top)
      • 45 / 135: Diagonal movement

Practical Examples

1. Horizontal Motion Blur

To create a standard horizontal blur across the image with an intensity of 15:

magick input.png -motion-blur 0x15+0 output.png

2. Vertical Motion Blur

To simulate rapid vertical movement (such as falling or rising) with an intensity of 20:

magick input.png -motion-blur 0x20+90 output.png

3. Diagonal Motion Blur

To apply a 45-degree diagonal blur with a soft intensity of 8:

magick input.png -motion-blur 0x8+45 output.png
