ImageMagick Negative Sigmoidal Contrast Explained

When a negative contrast value is supplied to ImageMagick's -sigmoidal-contrast operator, the contrast of the image is still increased rather than decreased. Due to the algebraic symmetry of the underlying sigmoidal formula, the negative sign cancels out during normalization, producing the exact same contrast-enhancing result as a positive value of the same magnitude. To actually decrease contrast using a sigmoidal curve, you must use the +sigmoidal-contrast operator instead.

The Mathematics Behind the Behavior

Many ImageMagick operators—such as -brightness-contrast—use negative numbers to decrease an effect and positive numbers to increase it. The -sigmoidal-contrast operator does not follow this convention because of the way its transfer function is calculated.

ImageMagick adjusts tonal values using a scaled logistic S-curve defined by:

\[f(x) = \frac{S(x) - S(0)}{S(1) - S(0)}\]

where \(S(x)\) is the sigmoid function:

\[S(x) = \frac{1}{1 + e^{-\alpha(x - \beta)}}\]

In this formula, \(\alpha\) represents the contrast factor and \(\beta\) represents the midpoint.

Because of the algebraic identity of the logistic function:

\[1 - \frac{1}{1 + e^{-u}} = \frac{1}{1 + e^u}\]

Negating the contrast parameter (\(\alpha \to -\alpha\)) negates both the numerator and the denominator of the normalized curve:

\[\frac{-[S(x) - S(0)]}{-[S(1) - S(0)]} = \frac{S(x) - S(0)}{S(1) - S(0)}\]

Because both negative signs cancel out, the final lookup table generated for a negative contrast parameter (such as -sigmoidal-contrast -5x50%) is identical to the one generated for its positive counterpart (-sigmoidal-contrast 5x50%). The image neither inverts nor flattens; it gains contrast around the midpoint.

How to Properly Decrease Contrast

To reduce contrast using an inverse sigmoidal transformation, use the plus form of the command:

magick input.png +sigmoidal-contrast 5x50% output.png

In ImageMagick, the + prefix signals the inverse operation. The +sigmoidal-contrast command uses the inverse mathematical function, expanding shadows and highlights while compressing midtones to flatten the dynamic range without clipping.
