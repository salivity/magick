ImageMagick Net Protocol and Canvas Patterns

ImageMagick does not have an official built-in net: protocol for generating canvas patterns, and invoking it directly results in an unrecognized format error. This guide clarifies the misconception surrounding the net: prefix, explains the error ImageMagick produces when it is called, and demonstrates how to properly generate net and mesh patterns using ImageMagick's legitimate built-in canvas protocols.

The Behavior of the net: Protocol

In ImageMagick, protocols (or pseudo-image formats) are predefined prefixes followed by a colon that instruct the engine to generate images dynamically or read from special inputs (such as xc:, canvas:, or pattern:).

There is no registered coder or protocol named net: in ImageMagick. If you attempt to invoke net: via the command line:

magick net: output.png

ImageMagick will interpret net as an explicit file format specification or look for a local file named net:. Because neither a file nor a corresponding decoding delegate exists, ImageMagick terminates execution with an error similar to:

magick: no decode delegate for this image format `NET' @ error/constitute.c/ReadImage/...

Generating Net Patterns with the pattern: Protocol

Users seeking a built-in canvas net pattern are typically looking for ImageMagick's built-in bitmap tile patterns, which are accessed via the pattern: protocol rather than a standalone net: prefix.

ImageMagick provides two primary built-in net patterns:

  1. pattern:fishnet: Generates a classic tiled net or mesh pattern composed of diagonal interlocking lines.
  2. pattern:smallfishnet: Generates a higher-density, smaller-scale variation of the fishnet pattern suitable for tighter textures.

Syntax and Examples

To generate a net pattern canvas, specify the desired image dimensions using the -size flag and supply the pattern name:

# Generate a standard fishnet canvas
magick -size 300x300 pattern:fishnet net_canvas.png

# Generate a high-density fishnet canvas
magick -size 300x300 pattern:smallfishnet small_net_canvas.png

Alternative Mesh and Grid Patterns

If the fishnet patterns do not suit your requirements, ImageMagick includes several related geometric cross-line patterns under the pattern: protocol:

  • pattern:crosshatch: Creates a standard perpendicular horizontal and vertical grid.
  • pattern:crosshatch45: Creates a 45-degree angled crosshatch resembling diamond wire netting.
  • pattern:hexagons: Creates a hexagonal chicken-wire style mesh.

Example usage:

magick -size 300x300 pattern:crosshatch45 wire_mesh.png

Standard Built-In Canvas Protocols Summary

To avoid protocol naming errors in ImageMagick, use the established prefixes for procedural image generation:

  • canvas:<color> or xc:<color>: Creates a blank canvas filled with a solid color.
  • pattern:<name>: Tiles a named built-in geometric pattern across the canvas.
  • gradient:<color1>-<color2>: Generates a linear color gradient.
  • plasma:: Produces a randomized fractal plasma texture.
