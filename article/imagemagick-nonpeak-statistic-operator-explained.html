ImageMagick Nonpeak Statistic Operator Explained

ImageMagick’s Nonpeak statistic operator analyzes local pixel neighborhoods to identify pixel values that diverge from the dominant intensity in a local histogram. While traditional operators like Mode select the most frequently occurring value (the histogram peak), Nonpeak deliberately selects an intensity that is not the peak, typically targeting values furthest from the mode within the kernel. This article explains how the Nonpeak operator functions, how it evaluates image histograms, and when to use it for image processing tasks such as edge isolation and contrast detection.

How the Operator Evaluates Neighborhood Histograms

When you run ImageMagick's -statistic command, the software applies a moving window (defined by geometry, such as 3x3 or 5x5) across the image. For every pixel, ImageMagick constructs a local histogram of the intensities present within that window.

The standard -statistic Mode operator finds the bin in this histogram with the highest count and writes that value to the center pixel. In contrast, the Nonpeak operator identifies the peak value (the mode) and selects a valid pixel value from the histogram that deviates from that peak. If all pixels in the window share the identical intensity, that uniform value is retained. When variation exists, Nonpeak ignores the primary peak to return an alternate, non-dominant intensity present within the neighborhood.

Command Syntax

The Nonpeak operator is invoked using the -statistic option:

magick input.png -statistic Nonpeak 3x3 output.png

In this command:

  • Nonpeak specifies the statistical operation.
  • 3x3 defines the width and height of the pixel neighborhood used to generate each local histogram.

Practical Applications

Because the Nonpeak operator suppresses dominant tones within localized areas, it serves specific roles in computer vision and image filtering:

  • Background Suppression: In regions where a uniform background dominates the local window, Nonpeak discards the background tone in favor of subtle foreground details.
  • Edge and Boundary Detection: Along boundaries where two distinct tones meet, Nonpeak prevents the majority tone from overwhelming the transition, highlighting contrasting borders.
  • Texture and Outlier Analysis: It reveals variations that would otherwise be smoothed out by Mean or masked by Mode filters, making it useful for surface inspection and anomaly detection.
