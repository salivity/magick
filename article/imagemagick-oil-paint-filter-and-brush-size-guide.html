ImageMagick Oil Paint Filter and Brush Size Guide

The ImageMagick oil-paint filter is a built-in artistic effect that transforms standard digital photos into visuals resembling classic oil paintings. This guide explains how the filter processes image data and identifies the exact parameter used to control the simulated brush stroke size.

What is the ImageMagick Oil-Paint Filter?

The oil-paint effect in ImageMagick is executed using the -paint operator. Rather than applying a simple blur, this filter analyzes a circular neighborhood of pixels around each individual pixel and replaces that pixel with the most frequently occurring color (the statistical mode) within that neighborhood.

This process groups adjacent pixels into solid color patches with defined edges, mimicking the texture and stroke patterns of oil paint applied with a brush.

Which Parameter Controls Brush Size?

The parameter that controls the brush size is the radius, passed as a numerical argument directly after the -paint option:

magick input.jpg -paint <radius> output.jpg

(Note: In ImageMagick version 6, use convert instead of magick.)

How the Radius Parameter Works

  • The Value: The <radius> value is measured in pixels and defines the size of the circular neighborhood examined around each pixel.
  • Small Radius (e.g., -paint 2 or -paint 3): Simulates fine, delicate brush strokes. Fine details from the original image are preserved, creating a subtle painted effect.
  • Large Radius (e.g., -paint 8 or higher): Simulates broad, heavy brush strokes. Fine details merge into large, flat patches of dominant color, creating a heavily abstracted, dramatic painting effect.
  • Default/Radius of 0: When set to 0, ImageMagick attempts to select a reasonable default radius based on the image properties.

By increasing or decreasing the radius value, you directly control the coarseness or fineness of the simulated brushwork across the entire image.
