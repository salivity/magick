ImageMagick Out of Gamut Warning Syntax

This guide explains how to identify and highlight out-of-gamut pixels using ImageMagick when converting images between color profiles, such as transitioning from an RGB workspace to a target CMYK print profile. By generating a gamut comparison mask and compositing a distinct alarm color over non-reproducible pixels, you can visually verify which areas of your image will clip or shift before sending files to production.

Gamut Warning Command Syntax

ImageMagick utilizes color profile transformations to detect colors that cannot be accurately reproduced in a target color space. The standard method converts an image to the target profile, converts it back to the original color space, calculates the difference, and overlays a warning color (such as bright magenta or red) over the clipped pixels.

ImageMagick 7 (CLI Syntax)

magick input.jpg \
  \( +clone -profile sRGB.icc -profile TargetCMYK.icc -profile sRGB.icc \) \
  \( -clone 0,1 -compose Difference -composite -colorspace Gray -threshold 1% \) \
  -fill "#FF00FF" -compose Over -composite \
  output_gamut_warning.png

Step-by-Step Parameter Breakdown

  1. input.jpg: Loads the original source image.
  2. \( +clone -profile sRGB.icc -profile TargetCMYK.icc -profile sRGB.icc \):
    • Duplicates the image.
    • Assigns the source color profile (sRGB.icc).
    • Converts the duplicate into the target color space (TargetCMYK.icc), which clips all out-of-gamut values to the boundary of that profile.
    • Converts the clipped result back to sRGB.icc so pixel values can be directly compared against the original.
  3. \( -clone 0,1 -compose Difference -composite -colorspace Gray -threshold 1% \):
    • Compares the original image (index 0) with the clipped version (index 1).
    • Generates a grayscale difference map where changed pixels appear bright.
    • Applies -threshold 1% to convert any pixel with perceptible color shifts into a pure white mask while keeping in-gamut pixels pure black.
  4. -fill "#FF00FF": Sets the warning color (in this case, pure magenta).
  5. -compose Over -composite: Applies the warning color exclusively onto the coordinates flagged by the difference mask.
  6. output_gamut_warning.png: Exports the rendered image showing original colors alongside highlighted out-of-gamut regions.

Adjusting Detection Sensitivity

You can fine-tune the gamut detection threshold depending on the tolerance required:

  • Strict Detection (Minor Shifts): Change the threshold to -threshold 0.5% to catch very subtle tonal shifts.
  • Loose Detection (Severe Clipping Only): Increase the threshold to -threshold 3% or -threshold 5% to highlight only heavily clipped areas.

Alternative: Isolating Out-of-Gamut Mask

To output only the black-and-white gamut mask for use in other editing workflows:

magick input.jpg \
  \( +clone -profile sRGB.icc -profile TargetCMYK.icc -profile sRGB.icc \) \
  -compose Difference -composite \
  -colorspace Gray \
  -threshold 1% \
  gamut_mask_only.png

Pixels rendered as white in the resulting mask represent areas outside the gamut of the target profile.
