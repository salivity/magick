ImageMagick Over vs SrcOver Explained

In ImageMagick, the Over and SrcOver composition modes perform the exact same visual and mathematical operation: placing a source image over a destination image using standard Porter-Duff compositing. The difference between them is purely semantic and historical, as Over is ImageMagick's traditional default naming convention, while SrcOver exists to adhere directly to standard Porter-Duff and SVG/CSS terminology.

Mathematical Functionality

Both Over and SrcOver use the standard Porter-Duff "Source Over" formula. When compositing a source pixel (\(S\)) with opacity (\(S_a\)) over a destination pixel (\(D\)) with opacity (\(D_a\)), the output color and alpha are calculated as:

  • Result Color: \(Color = S \cdot S_a + D \cdot D_a \cdot (1 - S_a)\)
  • Result Alpha: \(Alpha = S_a + D_a \cdot (1 - S_a)\)

Because both operators execute this identical algorithm, rendering an image with -compose Over yields pixel-for-pixel identical output to rendering with -compose SrcOver.

Why Both Names Exist

  • Over (Legacy/Default): ImageMagick historically adopted shorthand terms for standard compositing operations. Over is the default compose mode in ImageMagick when no operator is explicitly declared.
  • SrcOver (Standards Compliance): The official 1984 Porter-Duff paper and subsequent W3C SVG/CSS specifications use SrcOver (Source Over) to contrast clearly with operations like DstOver (Destination Over). ImageMagick supports SrcOver as an alias to maintain standard-compliant syntax for scripts, SVG parsers, and cross-platform workflows.

Usage in Commands

In practice, both operators are interchangeable on the command line:

# Using the traditional ImageMagick name
magick composite -compose Over source.png background.png output.png

# Using the standard Porter-Duff alias
magick composite -compose SrcOver source.png background.png output.png

Both commands read the alpha channel of source.png, blend transparent or semi-transparent pixels smoothly into background.png, and write the identical resulting file to disk.
