ImageMagick -page Parameter in Multi-Layer Composition

The ImageMagick -page parameter defines the canvas dimensions and positional offsets of individual image layers during multi-layer composition. This article explains how -page establishes virtual canvas geometries, positions distinct image layers along the X and Y axes, and impacts multi-image operations such as flattening, mosaicing, and animated GIF creation.

Virtual Canvas and Layer Offsets

In ImageMagick, multi-layer operations rely on the concept of a "virtual canvas"—a larger coordinate space in which individual image layers exist. The -page parameter sets both the canvas size and the layer's position on that canvas using standard geometry syntax: [width]x[height]+[x_offset]+[y_offset].

When reading or creating an image, applying -page +X+Y assigns metadata to that layer indicating where its top-left corner should be anchored relative to the top-left origin (0,0) of the virtual canvas.

Behavior During Layer Flattening and Merging

When multiple images are combined using operations like -flatten, -mosaic, or -layers merge, ImageMagick uses the -page offset data to arrange the images in the final output:

  • -flatten: Creates a single image canvas sized to the first image or the canvas size defined by -page, then overlays subsequent images at their respective -page coordinate offsets.
  • -mosaic: Automatically expands the final canvas dimensions to accommodate the maximum extent of all combined layers and their assigned -page offsets.
  • -layers merge: Resolves negative offsets by expanding the canvas boundaries in all directions to fit every layer without clipping.

Setting Overall Canvas Dimensions

Beyond positioning, -page can define the total target canvas dimensions for formats that support explicit pages (such as PDF or PostScript) or for blank canvas generation. Specifying dimensions such as -page 1920x1080 establishes the canvas boundary, ensuring that subsequent layers are rendered inside that defined resolution.

Frame-by-Frame Control in Animations

In multi-frame formats like animated GIFs, the -page parameter dictates the placement of smaller sub-frame updates. Rather than replacing the full frame, optimized animations use -page offsets to place smaller differential frames only over the areas of the canvas that change, reducing total file size.

Difference Between -page and -repage

The -page parameter is an input setting that applies canvas geometry to images as they are being read into memory. If an image has already been loaded, the -repage operator must be used instead to modify, reset, or adjust its existing canvas offsets and dimensions.
