ImageMagick Perspective Distortion Parameters

This guide explains the parameters required to perform perspective distortion using ImageMagick. Perspective distortion maps an input image onto a 3D-like quadrilateral projection by remapping specific pixel coordinates. Below is a breakdown of the distortion operator, the required coordinate pairs, command syntax, and essential supporting settings.

The Distortion Operator

Perspective distortion is invoked using either the -distort or +distort operator followed by the distortion method argument:

  • -distort Perspective: Distorts the image within the original image dimensions, clipping any content falling outside the original canvas.
  • +distort Perspective: Automatically resizes the output canvas to encompass the entire distorted image.

Required Coordinate Parameters

Perspective distortion requires a minimum of four sets of source and destination coordinate pairs (16 numerical values in total). These eight points define a homographic projection mapping four points from the original image to four points in the destination space.

The parameters are passed as a single quoted string containing comma-separated or space-separated floating-point coordinates:

"sx1,sy1 dx1,dy1   sx2,sy2 dx2,dy2   sx3,sy3 dx3,dy3   sx4,sy4 dx4,dy4"
  • sx,sy (Source Coordinates): The pixel coordinates (X, Y) on the original image (typically the four corners).
  • dx,dy (Destination Coordinates): The target pixel coordinates (X, Y) where the source points should be moved.

Coordinate Order Mapping

The standard convention maps the four corners of a rectangular image (width W, height H):

  1. Top-Left: 0,0 \(\rightarrow\) dx1,dy1
  2. Top-Right: W,0 \(\rightarrow\) dx2,dy2
  3. Bottom-Right: W,H \(\rightarrow\) dx3,dy3
  4. Bottom-Left: 0,H \(\rightarrow\) dx4,dy4

Passing fewer than four pairs will reduce the transformation to an Affine (3 pairs) or Bilinear/Translation distortion, while four pairs activate full 8-parameter perspective projection.

Supporting Parameters

To control how empty areas or edges are handled during the transformation, configure the following settings prior to the -distort operator:

  • -virtual-pixel <method>: Determines how areas outside the image boundaries are filled. Common values include transparent, black, white, edge, or background.
  • -background <color>: Sets the color used when -virtual-pixel background is specified.
  • -define distort:viewport=<geometry>: Explicitly defines the output dimensions and offset if you do not want to use the default canvas size.

Complete Command Example

To project a 500x500 image into a tilted perspective against a transparent background:

magick input.png -virtual-pixel transparent +distort Perspective \
    "0,0 50,50   500,0 450,100   500,500 400,420   0,500 80,480" \
    output.png
