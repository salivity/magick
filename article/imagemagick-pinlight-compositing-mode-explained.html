ImageMagick PinLight Compositing Mode Explained

The PinLight compositing mode in ImageMagick is a hybrid blending operator that selectively replaces destination pixels based on the lightness values of the source image. By utilizing 50% neutral gray as a dividing baseline, it evaluates whether the source pixel is dark or light and selectively applies a minimum or maximum threshold to the underlying image. This article explains the exact mathematical rules, threshold conditions, and color-replacement behavior of the PinLight operator.

The 50% Neutral Gray Threshold

ImageMagick’s PinLight operates on normalized channel values ranging from 0.0 (pure black) to 1.0 (pure white), where 0.5 represents 50% neutral gray (value 128 in standard 8-bit channels). When blending an overlay (source) image onto a base (destination) image, PinLight treats 50% gray as a neutral element. If a source pixel has a channel value of exactly 0.5, the underlying destination channel is left completely untouched.

When the source color deviates from 50% gray, PinLight switches between two operations: a darkening clamp or a lightening clamp.

Darkening with Dark Source Pixels

When a source pixel channel value (\(S\)) is darker than 50% gray (\(S \le 0.5\)):

  • Threshold Calculation: The threshold limit is determined by \(2 \times S\).
  • Replacement Rule: If the destination pixel channel (\(D\)) is brighter than \(2 \times S\), it is replaced by \(2 \times S\). If the destination pixel is already darker than this threshold, it remains unchanged.
  • Mathematical Function: Output = min(D, 2 * S)

In this state, PinLight acts like the Darken blend mode. It eliminates highlights in the base image that exceed twice the brightness of the source pixel, effectively forcing brighter areas to become darker.

Lightening with Bright Source Pixels

When a source pixel channel value (\(S\)) is lighter than 50% gray (\(S > 0.5\)):

  • Threshold Calculation: The threshold limit is determined by \(2 \times S - 1.0\) (or \(2 \times (S - 0.5)\)).
  • Replacement Rule: If the destination pixel channel (\(D\)) is darker than \(2 \times S - 1.0\), it is replaced by that value. If the destination pixel is already brighter than this threshold, it remains unchanged.
  • Mathematical Function: Output = max(D, 2 * S - 1.0)

In this state, PinLight acts like the Lighten blend mode. It replaces shadows and dark tones in the base image with lighter values derived from the source, while leaving existing high-value highlights intact.

Per-Channel Execution

ImageMagick processes these conditions independently across the Red, Green, and Blue channels. Because lightness is evaluated on a per-channel basis:

  • A single pixel can simultaneously have its red channel darkened and its blue channel lightened if the source pixel contains a low red value and a high blue value.
  • Mid-tone detail in the destination image is often replaced completely, while extreme highlights and deep shadows are preserved unless overridden by pure white or pure black source inputs.

By restricting modifications strictly to values exceeding the calculated thresholds, the PinLight operator allows fine control over removing intermediate tones without generating smooth gradients across the blend.
