ImageMagick Plasma Fractal Color Boundaries Syntax

This guide explains how to generate procedural plasma fractals in ImageMagick using custom color boundaries. By defining specific starting colors instead of relying on default random values, you can control the overall palette and mood of the resulting fractal texture. Below is the exact command-line syntax, along with practical examples for two-color and four-color corner boundaries.

Basic Syntax

To define starting colors for a plasma fractal, append the color names or hex codes separated by hyphens directly after the plasma: image generator format:

magick -size [width]x[height] plasma:[color1]-[color2] output.png

(Note: For ImageMagick version 6, replace magick with convert.)

Two-Color Boundaries

When specifying two colors, ImageMagick uses them as the initial seed limits for the recursive subdivision algorithm, producing a continuous gradient across the canvas:

magick -size 800x600 plasma:blue-gold plasma_two_color.png

You can also use hexadecimal values. When using hex codes in a shell environment, wrap the argument in quotes to prevent # from being interpreted as a comment:

magick -size 800x600 plasma:"#1a2a6c-#fdbb2d" plasma_hex.png

Four-Color Corner Boundaries

ImageMagick allows you to specify up to four distinct seed colors. These colors anchor the four corners of the canvas before the plasma algorithm subdivides the interior:

  1. Top-Left
  2. Top-Right
  3. Bottom-Left
  4. Bottom-Right

Syntax for four corners:

magick -size 800x600 plasma:red-green-blue-yellow plasma_four_corners.png

Advanced Control: Pure Fractals vs. Attenuated Variations

If you want the algorithm to produce a pure, non-random fractal with consistent boundary interpolation, use fractal in place of one of the parameters or combine it with boundaries:

magick -size 800x600 plasma:red-blue plasma_attenuated.png

To introduce complete randomness while strictly enforcing corner boundaries, ensure each corner color is explicitly stated. You can also mix named colors, rgb() functional notation, and hex codes as long as they remain separated by hyphens.
