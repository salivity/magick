ImageMagick png:compression-level Explained

In ImageMagick, the png:compression-level option configures the zlib compression strength applied when encoding a PNG image. This article explains what the setting does, how its values affect output file sizes and processing speeds, and how it differs from ImageMagick's standard quality parameter.

What png:compression-level Controls

The -define png:compression-level setting directly controls the deflate compression algorithm utilized by the underlying libpng and zlib libraries. PNG is an inherently lossless format, meaning this setting has zero impact on visual image quality. Instead, it manages the trade-off between encoding speed and the resulting file size.

Supported Values

The setting accepts integer values ranging from 0 to 9:

  • 0 (No compression): The image data is stored without compression. Encoding is extremely fast, but the resulting file size is very large.
  • 1 (Fastest compression): Applies basic zlib compression. It yields moderate file size reductions with minimal CPU overhead.
  • 2 to 8 (Intermediate levels): Progressively applies deeper compression algorithms, balancing processing time and size reduction.
  • 9 (Maximum compression): Executes the most thorough search for redundancies. It produces the smallest possible file size using standard zlib, but requires the highest CPU time.

If unspecified, ImageMagick typically defaults to compression level 6, which represents the standard balance between compression speed and space savings recommended by zlib.

png:compression-level vs. -quality

In standard ImageMagick syntax, PNG compression is set via the -quality flag, where the tens digit defines the zlib compression level (0–9) and the units digit defines the PNG row filter type (0–5).

Using -define png:compression-level=<value> isolates the compression setting completely. This allows you to explicitly enforce a zlib compression level without altering filter strategies, or to override the compression component defined by the -quality argument.

Syntax Example

To apply maximum compression explicitly via the command line:

magick input.jpg -define png:compression-level=9 output.png

This configuration ensures the encoder prioritizes the smallest possible storage footprint at the cost of longer execution times during the write process.
