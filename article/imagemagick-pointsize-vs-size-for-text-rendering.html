ImageMagick: Pointsize vs Size for Text Rendering

When rendering text in ImageMagick, configuring typographical dimensions usually comes down to choosing between the -pointsize setting and the -size geometry option. While -pointsize explicitly dictates the exact typographical font size in points, the -size geometry defines the dimensions of the target bounding box or canvas. Understanding how these two properties differ and interact is essential for predictable typography, automated text scaling, and proper text wrapping across commands like label:, caption:, and -annotate.

What -pointsize Does

The -pointsize option directly controls the font size of your text, functioning much like font size controls in standard word processors or design software.

  • Explicit Scale: Setting -pointsize 48 forces the text glyphs to render at 48 points (which equates to pixels depending on your image resolution or DPI settings).
  • Automatic Canvas Sizing: When used alone with the label: operator (e.g., magick -pointsize 48 label:"Hello" output.png), ImageMagick measures the rendered text and automatically generates a canvas that tightly wraps the text at that exact scale.
  • Consistency: If you render multiple strings with different character lengths using the same -pointsize, the letterforms will remain identical in visual scale across all outputs, while the resulting image dimensions will vary based on string length.

What -size Geometry Does

The -size option defines the width and height of the image canvas or bounding container (e.g., -size 800x600). It is a layout dimension constraint rather than a typographic measurement.

  • Canvas Creation: Setting -size 500x200 defines a fixed canvas boundary of 500 pixels wide by 200 pixels high.
  • Dynamic Auto-Fitting: When -size is defined without a -pointsize in a label: or caption: command, ImageMagick dynamically calculates the largest possible font size that fits the provided text entirely within the defined box.
  • Layout-Driven: Short text will scale up to be very large to fill the area, while long text will scale down to ensure it does not overflow.

Key Behavioral Differences

The fundamental difference lies in which dimension dictates the final output: font dimensions or canvas dimensions.

Feature -pointsize -size Geometry
Primary Function Sets exact font size Sets exact canvas dimensions
Font Scaling Fixed and static Dynamic (when used alone with label:/caption:)
Canvas Size Adapts to fit the text Fixed to specified width/height
Text Wrapping Does not wrap automatically Wraps text when used with caption:

Using Both Options Together

When you specify both -size and -pointsize in the same command, the behavior shifts:

  1. Fixed Canvas, Fixed Font: -size dictates the fixed boundaries of the image, while -pointsize sets the fixed scale of the text.
  2. Clipping Risk with label:: If the text rendered at the requested -pointsize exceeds the boundaries set by -size, the text will be cropped or clipped off the edges.
  3. Word Wrapping with caption:: When used with caption:, -size defines the boundary within which words wrap. If -pointsize is specified, ImageMagick will wrap lines at the defined width and render them at that point size. However, if the wrapped text exceeds the vertical height, it may be clipped.

Practical Guidelines

  • Use -pointsize alone when maintaining exact, uniform typographical scale is required across different strings and canvas size does not need to be rigid.
  • Use -size alone when text must strictly fit inside a fixed UI space, banner, or thumbnail, letting ImageMagick automatically maximize the font size to fill the allocated space.
  • Combine -size and -pointsize primarily with caption: when you need a fixed-dimension banner where the text wraps naturally at a specific, consistent font size.
