ImageMagick Polar to Rectangular Transformation

In ImageMagick, converting an image from polar coordinates to Cartesian (rectangular) coordinates is accomplished using the DePolar distortion operator. This article explains how to use the DePolar command, details the syntax and parameter options, and demonstrates how to effectively unwrap circular or 360-degree images into standard rectangular formats.

The DePolar Operator

To convert a circular or polar-mapped image into a rectangular image, use the -distort or +distort setting with the DePolar argument.

  • +distort DePolar 0: The +distort variant automatically calculates the output image dimensions to best fit the unwrapped image without clipping.
  • -distort DePolar 0: The -distort variant keeps the canvas dimensions identical to the source image.

Command Syntax

The basic command structure in ImageMagick 7 is:

magick input.png +distort DePolar 0 output.png

For legacy ImageMagick 6 installations, replace magick with convert:

convert input.png +distort DePolar 0 output.png

Parameter Breakdown

Passing 0 as the parameter allows ImageMagick to automatically calculate all necessary values based on the image's dimensions. However, you can provide up to eight optional arguments for precise control:

+distort DePolar "radius, inner_radius, center_x, center_y, angle_start, angle_end"
  • radius: The maximum outer radius to unwrap. Setting this to 0 automatically finds the furthest edge or corner.
  • inner_radius: Defines an inner boundary to ignore, which is useful for donut-shaped or ring-shaped images.
  • center_x, center_y: The exact coordinates of the circle's center point. If omitted, it defaults to the center of the image canvas.
  • angle_start, angle_end: The angular range in degrees to map into the rectangular output (default is -180 to 180 or 0 to 360).

Practical Example

To unwrap a circular panoramic image with a defined center point at (500, 500) and an outer radius of 400 pixels:

magick circle_pano.jpg +distort DePolar "400, 0, 500, 500" unwrapped_pano.jpg

This transforms the top of the circle to the top edge of the rectangular result and unrolls the circumference along the horizontal axis.
