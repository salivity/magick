ImageMagick Precision Setting Explained

The -precision setting in ImageMagick controls the maximum number of significant digits printed when converting floating-point values into text output. It directly influences how numerical data—such as image statistics, color values, and coordinates—is formatted across informational commands, custom string formats, and text-based image outputs without altering the underlying precision of internal image calculations.

Primary Purpose of the -precision Option

By default, ImageMagick displays floating-point numbers using standard library defaults (typically 6 or 7 significant digits). The -precision option allows users to increase or decrease this limit depending on whether they need human-readable summaries or high-precision scientific data.

It dictates significant digits (similar to the standard %.*g printf specification in C) rather than a fixed count of digits after the decimal point.

Where -precision Applies

The setting affects any output pipeline where numeric values are serialized into strings:

  • Informational Queries: Output generated by magick identify -verbose or specific format directives via -format "%[...]" (such as calculating standard deviations, entropy, or channel means).
  • FX Expressions: Output resulting from the -fx operator or mathematical expressions where computed floating-point values are returned to the console.
  • Text-Based Image Formats: Formats that store pixel data as readable text rather than binary data, such as TXT:, JSON:, MVG:, or SVG:.

Example Usage

To restrict output to two significant digits for a cleaner summary:

magick input.png -precision 2 -format "%[mean]" info:

To preserve maximum fidelity when exporting pixel data to a plain text format (useful when working with High Dynamic Range Images / HDRI):

magick input.exr -precision 16 output.txt

Internal Calculations vs. Output Formatting

The -precision flag strictly affects serialization and rendering of numbers into strings. It does not change the internal mathematical precision used by ImageMagick during image processing. Internal calculations remain bound by ImageMagick's compile-time quantum depth (such as Q16 or Q32) and whether HDRI support is enabled.
