ImageMagick Proportional Height Scaling

Scaling portrait photos to a uniform height while preserving their original aspect ratio is a common image processing requirement. This article explains how to use ImageMagick's command-line tools to apply proportional, height-based scaling to portrait photos individually or in bulk, preventing distortion by allowing the width to adjust automatically.

The Height-Only Geometry Syntax

ImageMagick controls resizing dimensions using geometry arguments passed to the -resize option. To constrain the height while letting the width calculate proportionally, omit the width parameter and precede the height value with an x:

magick input.jpg -resize x1200 output.jpg

In this command, x1200 instructs ImageMagick to set the height to exactly 1200 pixels. Because no value precedes the x, the horizontal dimension scales automatically according to the original aspect ratio. For ImageMagick 6, replace magick with convert.

Correcting EXIF Orientation First

Portrait photos taken on digital cameras and smartphones often contain an EXIF orientation flag rather than physically rotated pixel data. If you scale the image without handling this tag, ImageMagick may interpret the photo as landscape and scale the wrong edge. Use -auto-orient before the resize operation:

magick input.jpg -auto-orient -resize x1200 output.jpg

Conditional Height Scaling

You can add condition flags directly to the geometry string to limit when resizing occurs:

  • Scale down only: To prevent enlarging photos smaller than your target height, append the > flag. In most shells, escape the character with a backslash or wrap the argument in quotes: 
    magick input.jpg -auto-orient -resize "x1200>" output.jpg
  • Scale up only: To enlarge images without shrinking larger ones, use the < flag: 
    magick input.jpg -auto-orient -resize "x1200<" output.jpg

Batch Processing Portrait Photos

Using mogrify (In-Place Overwrite)

To batch process a directory of images and overwrite the originals with the resized versions:

magick mogrify -auto-orient -resize x1200 *.jpg

Using a Shell Loop (Preserving Originals)

To maintain original files and save processed portraits to a separate directory, run a shell loop:

mkdir -p resized
for img in *.jpg; do
  magick "$img" -auto-orient -resize x1200 "resized/$img"
done

This workflow ensures every portrait image adopts a consistent vertical measurement across digital displays, galleries, and print layouts while maintaining proper proportions.
