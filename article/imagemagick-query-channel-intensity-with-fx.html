ImageMagick Query Channel Intensity with FX

This article explains how to query and calculate image intensity in ImageMagick using the -fx operator and the intensity keyword. You will learn the exact command-line syntax required to print numeric intensity values to the terminal, as well as how to apply the expression to transform image channels directly into luminance maps.

Understanding the Intensity Keyword

In ImageMagick, the intensity keyword evaluates the perceived brightness (luminance) of a pixel according to standard colorimetric weighting:

\[\text{Intensity} = 0.299 \times \text{Red} + 0.587 \times \text{Green} + 0.114 \times \text{Blue}\]

The resulting value is normalized to a floating-point range between 0.0 (black) and 1.0 (full intensity/white).

Syntax for Querying Numeric Intensity

To query and print the intensity value as text without modifying the source image, use the %[fx:...] format escape within a -format argument:

ImageMagick v7:

magick input.png -format "%[fx:intensity]\n" info:

ImageMagick v6:

identify -format "%[fx:intensity]\n" input.png

To query the intensity of a specific pixel at coordinates (X, Y), crop a 1x1 region before evaluating the expression:

magick input.png[1x1+100+50] -format "%[fx:intensity]\n" info:

Syntax for Applying Intensity Across Channels

To replace the pixel colors in an image with their calculated intensity, invoke -fx "intensity" directly:

magick input.png -fx "intensity" output.png

To limit the intensity calculation to a specific channel (such as replacing only the Alpha or Green channel with the image's overall intensity), use the -channel flag:

magick input.png -channel G -fx "intensity" +channel output.png

Multi-Image Syntax

When working with multiple images in a single command, specify the image index before the keyword:

# Reads the intensity of the first image (index 0)
magick image1.png image2.png -format "%[fx:u[0].intensity]\n" info:

# Reads the intensity of the second image (index 1)
magick image1.png image2.png -format "%[fx:u[1].intensity]\n" info:
