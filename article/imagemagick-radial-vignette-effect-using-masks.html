ImageMagick Radial Vignette Effect Using Masks

This article provides a concise guide to generating a radial vignette effect in ImageMagick using gradient masks. Applying a radial vignette darkens or tints the edges of an image while preserving the center. By utilizing ImageMagick's built-in gradient generation and composition operators, you can create fully customizable mask-based vignette effects from the command line.

Basic Radial Vignette Syntax

In ImageMagick (version 7+), the most efficient way to apply a radial vignette mask is to generate an inline radial gradient sized to the source image and composite it over the original:

magick input.jpg \( -size %[w]x%[h] radial-gradient:none-black \) -composite output.jpg

Breakdown of the Command

  • input.jpg: The source image you want to modify.
  • \( and \): Encloses an operational block, isolating the mask generation. (On Windows Command Prompt, use ( and ) without backslashes).
  • -size %[w]x%[h]: Dynamically sets the mask dimensions to match the source image's width (%[w]) and height (%[h]).
  • radial-gradient:none-black: Generates a transparent-to-black radial gradient. The center is fully transparent (none), gradually fading outward to solid black.
  • -composite: Overlays the generated radial mask directly onto the source image.
  • output.jpg: The resulting image with the vignette applied.

Advanced Syntax: True Alpha Masking

To control opacity, color, and blending modes more precisely, create a grayscale mask and apply it using the multiply or blend composition operators.

1. Black Vignette via Multiply Composition

Using a white-to-black gradient mask with the -compose multiply operator darkens only the edges without altering the center pixels:

magick input.jpg \( +clone -size %[w]x%[h] radial-gradient:white-black \) -compose multiply -composite output.jpg

2. Vignette with Custom Colors and Falloff

To create a colored vignette (such as dark blue or white) with custom center positioning and falloff:

magick input.jpg \( -size %[w]x%[h] -define gradient:radii=50%,70% radial-gradient:none-navy \) -composite output.jpg
  • -define gradient:radii=50%,70%: Sets the inner radius (where fading starts) and outer radius (where the color reaches full opacity).
  • radial-gradient:none-navy: Fades from transparent to navy blue.

Legacy Syntax for ImageMagick 6

For ImageMagick 6 installations, replace magick with convert and use the following syntax:

convert input.jpg \( -size "%[fx:w]x%[fx:h]" radial-gradient:none-black \) -composite output.jpg
