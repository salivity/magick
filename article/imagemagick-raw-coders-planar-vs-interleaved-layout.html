ImageMagick Raw Coders Planar vs Interleaved Layout

ImageMagick relies on explicit command-line parameters to interpret or write uncompressed, headerless raw pixel streams. The primary parameter defining planar versus interleaved color layouts is -interlace, which works in tandem with parameters like -size, -depth, and explicit coder prefixes (such as RGB:, RGBA:, or YUV:). Configuring these parameters correctly ensures that ImageMagick accurately calculates byte offsets and reconstructs channel data from raw memory blocks.

The Core Parameter: -interlace

The -interlace parameter directly controls the memory layout structure of raw pixel components during decoding and encoding:

  • -interlace None (Interleaved / Pixel-by-Pixel): This is the default arrangement for standard raw pixel streams. The color components are packed contiguously for each individual pixel (e.g., RGBRGBRGB... or RGBARGBARGBA...).
  • -interlace Plane (Planar / Band-Sequential): All samples for a single color channel are grouped together contiguously before the next channel begins. For an RGB image, the file will contain the entire Red channel data block, followed by the entire Green channel block, and finally the Blue channel block (RRR...GGG...BBB...).
  • -interlace Line (Line-Interleaved): Color channels are interleaved on a row-by-row basis. A single scanline of Red is followed by the same scanline for Green and Blue before moving to the next scanline.

Required Supporting Parameters

Because raw formats do not contain header metadata, -interlace requires several complementary parameters to calculate byte boundaries correctly:

  • -size <width>x<height>: Informs ImageMagick of the image dimensions. For planar formats, ImageMagick uses the width and height to calculate the exact offset where one color plane ends and the next begins (width * height * (depth / 8) bytes per plane).
  • -depth <bits>: Specifies the bit depth per channel (e.g., 8, 16, or 32). This dictates whether each channel sample uses one, two, or four bytes in memory.
  • Raw Coder Prefix: Dictates the channel structure and order. Common prefixes include RGB:, RGBA:, BGR:, CMYK:, YUV:, and GRAY:.

Practical Usage Examples

Reading an Interleaved Raw Image

To read an 8-bit, 1920x1080 raw file stored as contiguous RGB pixels (RGBRGB...):

magick -size 1920x1080 -depth 8 -interlace None rgb:input.raw output.png

Reading a Planar Raw Image

To read the same image stored in planar format (all Red bytes, then all Green bytes, then all Blue bytes):

magick -size 1920x1080 -depth 8 -interlace Plane rgb:input.raw output.png

Writing a Planar Raw Image

To convert a standard image file into a raw planar byte stream:

magick input.png -depth 8 -interlace Plane rgb:output.raw
