ImageMagick: Read File Names from a Text File

This article explains how to pass a list of input file names to ImageMagick using an external text file instead of specifying each path manually on the command line. By using ImageMagick's built-in filename expansion operator, you can streamline batch processing workflows, bypass operating system command-length limitations, and automate complex image manipulation tasks.

The @ Syntax

To instruct ImageMagick to read input file names from an external text file, prepend the text file's path with the at symbol (@).

magick @filelist.txt output.pdf

In this command, ImageMagick reads filelist.txt and replaces @filelist.txt with the sequence of filenames listed inside that file.

Formatting the Input Text File

The text file containing your input file names must follow these conventions:

  • One entry per line: Place each file path on its own line.
  • Relative or absolute paths: You can use relative paths (relative to your current working directory) or full absolute paths.
  • Spaces in filenames: If file paths contain spaces, wrap each path in double quotes inside the text file (e.g., "my image 1.png").

Example images.txt File

image1.jpg
image2.png
"folder with spaces/image3.tiff"
/var/data/images/image4.jpg

Common Usage Examples

Converting a List of Images into a Single PDF

To combine multiple files listed in images.txt into a single multi-page PDF document:

magick @images.txt document.pdf

Applying Batch Operations

To apply operations (such as resizing) across all images specified in the text file before creating an output:

magick @images.txt -resize 800x600 -quality 85 output_archive_%d.jpg

Reading from Standard Input (@-)

If you are generating file lists dynamically with another command or script, you can direct ImageMagick to read file names from standard input (stdin) using @-:

find . -name "*.png" | magick @- output.pdf

This pipes the output of the find command directly into ImageMagick without needing to save an intermediate text file to disk.
