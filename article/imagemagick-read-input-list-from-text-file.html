ImageMagick Read Input List From Text File

Processing hundreds or thousands of images at once can exceed operating system command-line length limits. ImageMagick provides a built-in mechanism to read input filenames directly from an external text file using the @ prefix. This guide covers the exact syntax, file formatting rules, and practical examples for batch processing files from a text list.

Basic Syntax

To instruct ImageMagick to read filenames from a text file, place the @ character immediately before the path to the text file where you would normally specify input images:

magick @filelist.txt [options] output_file

Note: For ImageMagick version 6, replace magick with convert.

Formatting the Text File

The external text file should contain the paths to the images. Each entry can be on a new line or separated by spaces:

image1.jpg
image2.png
folder/image3.webp
/absolute/path/to/image4.tiff

If filenames contain spaces, wrap each path in quotation marks inside the text file:

"photo one.jpg"
"photo two.jpg"
"vacation photos/beach 1.png"

Practical Examples

1. Combine Multiple Images into a Single PDF

To merge an ordered list of images into a single multi-page PDF document:

magick @pages.txt document.pdf

2. Batch Resize and Convert Images

To apply a batch operation (such as resizing and quality compression) to all files specified in a list:

magick @images.txt -resize 1920x1080 -quality 85% output_%03d.jpg

3. Create a Montage Contact Sheet

You can use the list syntax with other ImageMagick tools, such as montage:

magick montage @thumbnails.txt -tile 4x -geometry +2+2 collage.jpg

Passing Settings and Command Arguments

The @ syntax can also be used to pass complex command-line arguments and options from a text file, not just image filenames. For example, if arguments.txt contains image names along with settings like -resize 50% -strip, ImageMagick will parse and execute them in order:

magick @arguments.txt final_output.png
