ImageMagick Remap Command and External Palettes

The ImageMagick -remap command replaces all colors in an input image with the closest matching colors found in a designated external palette image. By sampling the unique color values of the external reference file, ImageMagick creates a strict color table and maps every pixel of the target image to this predefined set. This article explains how the -remap option processes color data, how it handles dithering, and how to use it effectively.

How the Remap Process Works

When you supply an image to the -remap operator, ImageMagick extracts all unique pixel colors from that secondary image to construct an exact, constrained color lookup table. It then analyzes the primary image pixel by pixel, calculating the shortest distance in color space (typically sRGB or Lab) to find the nearest match among the extracted palette colors. Every original pixel is then replaced with its nearest palette equivalent.

Dithering Options

By default, ImageMagick applies Floyd-Steinberg dithering during the remapping process. Dithering mixes adjacent pixels of available colors to visually approximate smooth gradients and tones that are missing from the external palette.

You can control this behavior:

  • With Dithering (Default): Produces smoother visual transitions by creating patterned pixel noise.
  • Without Dithering (+dither): Forces each pixel directly to the single nearest color in the palette, resulting in flat, solid regions of color and sharper edges.

Command Syntax

To remap an image using an external palette image with default dithering:

magick input.png -remap palette.png output.png

To remap without dithering:

magick input.png +dither -remap palette.png output.png

Common Applications

Constraining an image to an external palette is commonly used for:

  • Retro Gaming and Pixel Art: Matching modern artwork to legacy hardware limitations (such as Game Boy, CGA, or NES color sets).
  • Brand Compliance: Forcing user-submitted or generated imagery to adhere strictly to a brand's approved color palette.
  • GIF Optimization: Creating a single global color table across multiple animation frames to reduce file size and eliminate flickering artifacts.
