ImageMagick Remap Custom Color Palette Guide

ImageMagick allows you to restrict and transform an image's color space to a specific set of colors using the -remap option. This guide explains how to generate a custom color palette image, apply it to target images using the ImageMagick command line, and control color dithering for precise visual results.

Understanding the -remap Option

The -remap option replaces the colors in an image with the closest matching colors present in a reference palette image. To use -remap, you must first have a palette image containing only your target colors, which can either be extracted from an existing graphic or built manually from specific color values.

Step 1: Generating the Custom Palette

Before remapping an image, create the reference palette. You can generate this reference file using either of the following methods:

Method A: Extracting a Palette from an Image To extract a reduced, unique color palette from an existing source image, use the -colors and -unique-colors operators:

magick input.jpg +dither -colors 16 -unique-colors palette.png

This command reduces input.jpg to 16 dominant colors, strips duplicate pixels, and outputs a 1-pixel-high strip (palette.png) containing only the extracted color swatches.

Method B: Creating a Custom Palette from Specific Colors To build a palette containing exact hex codes or color names, combine single-pixel canvases using +append:

magick xc:"#0f380f" xc:"#306230" xc:"#8bac0f" xc:"#9bbc0f" +append palette.png

This creates a palette containing only the four specified color values.

Step 2: Applying the Palette Using -remap

Once your palette.png file is ready, apply it to your target image using -remap:

magick input.jpg -remap palette.png output.png

ImageMagick evaluates each pixel in input.jpg and replaces it with the nearest mathematical color match found in palette.png.

Step 3: Managing Dithering Settings

By default, ImageMagick applies dithering to simulate missing colors and smooth out transitions. You can modify this behavior depending on your desired output style:

  • Disable Dithering: For flat, posterized, or pixel-art graphics, place +dither before -remap:

    magick input.jpg +dither -remap palette.png output.png

  • Custom Dithering Algorithm: To use a specific dithering method, specify -dither followed by the algorithm name (such as FloydSteinberg or Riemersma):

    magick input.jpg -dither FloydSteinberg -remap palette.png output.png

Step 4: Generating and Remapping in a Single Command

You can combine the palette creation and remapping into a single command without saving an intermediate palette file to disk. The following command extracts 8 colors from the input and immediately applies them back:

magick input.jpg \( +clone +dither -colors 8 -unique-colors \) -remap - output.png
