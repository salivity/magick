ImageMagick -repage Plus vs Minus Syntax

In ImageMagick, the distinction between plus and minus syntax regarding the repage functionality applies to two distinct contexts: the operator flag itself (-repage versus +repage) and the coordinate signs used within the geometry string (+X+Y versus -X-Y). While -repage sets or modifies the virtual canvas and offset coordinates, +repage completely removes existing canvas offsets and resets the canvas boundaries to match the image dimensions. Within geometry arguments, plus and minus signs define the direction and positioning of the layer relative to the canvas origin.

The Operator Prefix: -repage vs. +repage

ImageMagick commands typically use a minus prefix (-) to set an option and a plus prefix (+) to reset or disable that option.

  • -repage [geometry]: This operator sets or updates the virtual canvas (page) metadata of an image. It defines canvas dimensions, offsets, or both. For example, -repage 800x600+50+50 assigns an image to an 800x600 canvas with a 50-pixel offset from the top-left origin. It is used to position layers before compositing or creating animated GIFs.
  • +repage: This operator takes no geometry arguments. It completely resets the virtual canvas, erasing any offsets and setting the canvas size to the exact pixel width and height of the current image. It is equivalent to resetting the page geometry to the image bounds. This is most commonly applied after cropping or trimming operations (such as -crop or -trim) to prevent formats like PNG and GIF from preserving the original canvas coordinates and showing unexpected blank space or viewport offsets.

Geometry Coordinate Signs: +X+Y vs. -X-Y

When passing coordinates to the -repage operator, the signs preceding the X and Y values determine the placement of the image's top-left corner relative to the virtual canvas origin:

  • Positive Offsets (+X+Y): Shifts the image to the right along the X-axis and downward along the Y-axis. For instance, -repage +20+30 moves the top-left corner of the image 20 pixels to the right and 30 pixels down from the (0,0) origin of the canvas.
  • Negative Offsets (-X-Y): Positions the image in negative coordinate space relative to the canvas origin. Specifying -repage -20-30 places the image's top-left corner 20 pixels to the left and 30 pixels above the (0,0) mark, causing parts of the image to sit outside the viewable canvas area unless the canvas dimensions or offsets are adjusted later.

Relative Offset Adjustments

The -repage operator also supports relative adjustments when combined with signs directly following an existing offset. If an image already possesses canvas metadata, specifying a relative delta using signed values (e.g., -repage +>+10 or adjusting existing offsets) increments or decrements the current coordinate position rather than setting an absolute value. In contrast, standard +X and -X declarations overwrite the existing offset coordinates unless explicit relative syntax is invoked.
