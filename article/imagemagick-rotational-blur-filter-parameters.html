ImageMagick Rotational Blur Filter Parameters

ImageMagick provides the -rotational-blur operator to simulate the effect of a camera rotating around a central axis during exposure. This filter radially blurs pixels along concentric circular paths, producing a dynamic spinning effect. Configuring this filter involves setting the rotation angle as its primary argument, alongside complementary settings like channel selection and virtual pixel handling to control how the blur interacts with the image boundaries and color layers.

Primary Parameter: Angle

The -rotational-blur operator accepts a single numerical parameter:

magick input.jpg -rotational-blur <angle> output.jpg
  • angle (Degrees): Specifies the sweep of the blur in degrees. A larger floating-point or integer value produces a stronger, wider blur effect, while smaller values (such as 2 to 10) provide subtle motion. Setting the angle to 0 results in no blur.

Blur Center Point

By default, -rotational-blur applies the rotational effect centered precisely at the geometric middle of the image (width / 2, height / 2).

To change the origin of the blur to a custom coordinate, you must translate the image canvas using operators like -roll or -distort before applying the filter, and then translate it back:

# Blurs around an offset point (e.g., shifted by +100,+50 pixels)
magick input.jpg -roll +100+50 -rotational-blur 15 -roll -100-50 output.jpg

Channel Selection

You can restrict the rotational blur to specific color components or alpha channels using the -channel setting before calling the blur operator:

  • -channel RGB: Blurs only the color information, leaving the alpha channel intact.
  • -channel A: Blurs only the alpha/transparency mask.
  • -channel R / -channel G / -channel B: Blurs an individual color channel to create chromatic aberration effects.
# Blur only the red channel
magick input.jpg -channel R -rotational-blur 20 +channel output.jpg

Edge Handling with Virtual Pixels

When pixels near the perimeter rotate, they may sample data from outside the original image boundaries. The -virtual-pixel setting controls how these edge pixels are sampled:

  • edge (Default behavior in many operations): Extends the outermost pixel colors outward.
  • mirror: Reflects the image data back across the boundary.
  • dither or transparent: Treats areas outside the boundary as transparent.
magick input.jpg -virtual-pixel mirror -rotational-blur 15 output.jpg

Summary of Usage

  • Basic rotation: magick input.png -rotational-blur 10 output.png
  • Intense rotation: magick input.png -rotational-blur 45 output.png
  • Selective channel rotation: magick input.png -channel G,B -rotational-blur 12 +channel output.png
