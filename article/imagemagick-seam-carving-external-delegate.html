ImageMagick Seam Carving External Delegate

To perform content-aware image resizing, known as seam carving, ImageMagick relies on an external delegate library called Liquid Rescaling (liblqr). This article explains the role of liblqr within ImageMagick, how to check for its support on your system, how to enable it, and the basic command-line syntax used to execute seam-carving operations.

The Required Delegate: Liquid Rescaling (liblqr)

Standard resizing scales or crops an image uniformly, but seam carving detects low-energy paths (seams) of pixels to remove or insert, preserving important visual content. ImageMagick does not contain a native implementation of this algorithm. Instead, it interfaces with the open-source Liquid Rescale library (liblqr) developed by Carlo Baldassi.

Without liblqr compiled and configured as a delegate, ImageMagick cannot execute content-aware scaling operations.

How to Check if liblqr Is Installed

You can verify whether your current ImageMagick installation includes support for liblqr by checking the delegates list in your terminal:

magick -version

(Or convert -version on older versions)

Look for lqr in the Delegates (built-in) line. Alternatively, you can query ImageMagick directly:

magick -list configure | grep -i "delegates"

If lqr appears in the output, your installation is ready to perform seam carving.

Installing the Delegate

If lqr is missing, you must install the library and either rebuild ImageMagick from source or install a package build that includes the delegate.

  • Ubuntu / Debian: 
    sudo apt-get install liblqr-1-0-dev
  • macOS (via Homebrew): 
    brew install liblqr imagemagick
  • Building from Source: Ensure liblqr is installed before running the ImageMagick build configuration: 
    ./configure --with-lqr
make
sudo make install

Using Seam Carving in ImageMagick

Once the lqr delegate is enabled, seam carving is invoked using the -liquid-rescale operator.

Basic Syntax

To reduce the width of an image to 75% while keeping the height at 100%:

magick input.jpg -liquid-rescale 75x100% output.jpg

Absolute Dimensions

To resize an image to specific pixel dimensions (e.g., 800x600) using content-aware scaling:

magick input.jpg -liquid-rescale 800x600! output.jpg
