ImageMagick Set Maximum JPEG File Size

Controlling output file size is a common requirement when optimizing web images or adhering to strict upload limits. ImageMagick includes a built-in define directive that automatically calculates and applies the necessary compression to keep an output JPEG below a designated threshold. This guide explains which define flag sets the maximum JPEG target file size in ImageMagick, how to structure the command, and how the mechanism functions.

The Flag: jpeg:extent

The define flag used to set a maximum JPEG target file size in ImageMagick is -define jpeg:extent={size}.

When this option is applied, ImageMagick runs a binary search across JPEG compression quality settings to find the highest quality level that produces a file size less than or equal to the specified target.

Syntax and Supported Units

The target size value can be specified in bytes or using standard standard file size suffixes:

  • KB or B: Kilobytes (e.g., 500KB, 300kb)
  • MB: Megabytes (e.g., 1MB, 2mb)
  • Bytes: Plain integer without a suffix (e.g., 102400 for 100 KB)

Command Example

In ImageMagick 7, use the magick command:

magick input.png -define jpeg:extent=500KB output.jpg

For legacy ImageMagick 6 installations, use the convert command:

convert input.png -define jpeg:extent=500KB output.jpg

Important Considerations

  • Placement: The -define jpeg:extent parameter should be placed before the output file name in your command line sequence so it applies during the write operation.
  • Minimum Bounds: If the target size is unrealistically low for the image dimensions, ImageMagick will reduce the JPEG quality to its lowest allowable setting, which may cause severe visual artifacts.
  • No Upscaling: If the image is already smaller than the target size when saved at high quality, ImageMagick will not artificially inflate the file size to match the target.
