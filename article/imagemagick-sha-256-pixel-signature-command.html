ImageMagick SHA-256 Pixel Signature Command

This guide explains how to calculate the SHA-256 digital signature of raw image pixel data using ImageMagick. By generating a cryptographic hash based purely on the pixel stream rather than the entire file, you can identify visually identical images regardless of differences in metadata, file formats, or compression artifacts.

The Primary Command

To compute the SHA-256 signature of an image's pixel data in ImageMagick 7, use the identify tool with the %# format specifier:

magick identify -format "%#\n" input.png

For ImageMagick 6 installations, the legacy command is:

identify -format "%#\n" input.png

Alternatively, you can load the image first and output the property using the info: operator:

magick input.png -format "%#\n" info:

How the Pixel Signature Works

Standard file hashing tools like sha256sum calculate a checksum of the entire file byte-by-byte. If two images have identical pixel data but different EXIF metadata, creation dates, or file containers (such as PNG vs. BMP), standard hashing will produce entirely different values.

The ImageMagick %# property works differently:

  1. It decodes the image into raw, uncompressed RGBA pixel bytes in memory.
  2. It strips all metadata, color profiles, and header information.
  3. It passes the pure pixel array through the SHA-256 algorithm to generate a 64-character hexadecimal digest.

Viewing the Signature via Verbose Output

You can also view the SHA-256 pixel signature along with other image details by running:

magick identify -verbose input.png

Locate the Signature field in the generated output:

Image: input.png
  ...
  Properties:
    date:create: 2023-10-25T12:00:00+00:00
    date:modify: 2023-10-25T12:00:00+00:00
    signature: 4a6c8b9d0e2f1a3b5c7d9e0f2a4b6c8d0e2f1a3b5c7d9e0f2a4b6c8d0e2f1a3b

To extract just the signature line from the verbose output, combine it with grep:

magick identify -verbose input.png | grep "signature:"
