ImageMagick Shade Filter Azimuth and Elevation

This article provides a concise overview of the parameters used to control the directional light source in the ImageMagick -shade operator. It covers the specific {azimuth}x{elevation} syntax, how each angle is measured on a coordinate plane, and how adjusting these values affects the resulting 3D embossed lighting effect on an image.

The -shade Parameter Syntax

In ImageMagick, the -shade operator creates a 3D effect by simulating a distant light source shining on the image's intensity surface. The operator requires two numerical values separated by an x:

-shade <azimuth>x<elevation>

Azimuth

The azimuth parameter defines the horizontal direction of the incoming light source in degrees.

  • Scale: Measured in degrees from 0 to 360.
  • Direction: The angle is measured clockwise starting from the positive X-axis (the 3 o'clock / East position).
    • 0° represents light coming from the East (right).
    • 90° represents light coming from the South (bottom).
    • 180° represents light coming from the West (left).
    • 270° represents light coming from the North (top).
  • A common standard light direction is 120 or 135 degrees, which positions the light source in the upper-left or top region relative to the subject.

Elevation

The elevation parameter defines the vertical angle of the light source above the horizon or the image plane.

  • Scale: Measured in degrees from 0 to 90.
  • Angle Behavior:
    • 0° places the light source directly on the horizon (parallel to the image surface), producing long, harsh shadows and maximum contrast.
    • 90° positions the light source directly overhead (perpendicular to the image surface), resulting in no directional shadows and minimal shading effect.
    • Angles around 30° to 45° are typically used for natural-looking relief and embossing effects.

Usage Example

To apply a light source coming from the top-left (130° azimuth) at a moderate height above the surface (45° elevation), the command is structured as follows:

magick input.png -shade 130x45 output.png

If grayscale shading is desired without preserving the original colors, the -shade option should be used without color modifications. If colors should be preserved, you typically combine -shade with color blending or apply it specifically to an alpha channel or intensity map.
