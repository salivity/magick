ImageMagick Sigmoidal Contrast Syntax

This guide provides a straightforward reference for applying non-linear sigmoidal contrast adjustments using ImageMagick. You will learn the exact command-line syntax, understand the required parameters, and see practical examples for both increasing and decreasing image contrast without clipping highlights or shadows.

The Basic Syntax

The primary operator for sigmoidal contrast in ImageMagick uses the following structure:

magick input.png -sigmoidal-contrast <contrast>x<mid-point>% output.png

(Note: In ImageMagick v6, replace magick with convert.)

You can separate the parameters using either an x or a comma ,.

Parameters Explained

  • contrast: Controls the steepness of the S-curve. A value of 0 applies no change. Values typically range from 3 (subtle) to 20 (extreme), with 5 to 10 being standard for general contrast enhancement.
  • mid-point: Determines the center of the curve where the contrast pivots. It is usually expressed as a percentage (e.g., 50%). A value of 50% targets mid-tones, values below 50% brighten the image while adjusting contrast, and values above 50% darken the image.

Increasing vs. Decreasing Contrast

ImageMagick uses the hyphen (-) and plus (+) flags to determine whether to increase or decrease contrast:

1. Increasing Contrast (-)

To steepen the curve and increase tonal separation:

magick input.jpg -sigmoidal-contrast 8x50% output_high_contrast.jpg

2. Decreasing Contrast (+)

To flatten the curve and compress the tonal dynamic range:

magick input.jpg +sigmoidal-contrast 8x50% output_low_contrast.jpg

Channel-Specific Adjustments

You can restrict the sigmoidal contrast adjustment to specific color channels by combining it with the -channel setting:

magick input.jpg -channel R -sigmoidal-contrast 5x50% +channel output_red_adjusted.jpg
