ImageMagick SouthWest Gravity Cropping Explained

This article explains how ImageMagick establishes anchor points and calculates crop coordinates when using SouthWest gravity. It covers how the canvas origin shifts to the bottom-left corner, how crop dimensions (WxH) are positioned relative to that corner, and how positive offsets (+X+Y) adjust the final cut area.

In ImageMagick, the -gravity setting alters the reference origin for coordinate operations. By default, ImageMagick uses NorthWest gravity, which places the origin (0, 0) at the top-left corner of the image canvas. When you define -gravity SouthWest, the software relocates the primary anchor point to the bottom-left corner of the source image.

The SouthWest Anchor Position

When evaluating a crop command such as -crop WxH+X+Y, ImageMagick binds the bottom-left corner of the crop window to the bottom-left corner of the target image:

  • Horizontal Anchor: The left edge of the image canvas (X = 0).
  • Vertical Anchor: The bottom edge of the image canvas (Y = Canvas_Height).

Calculating the Crop Region

Once the SouthWest anchor is established, ImageMagick determines the pixel area to extract based on the crop width (\(W\)), height (\(H\)), and the offsets (\(X\) and \(Y\)).

  1. Zero Offsets (-crop WxH+0+0): The crop box sits directly against the bottom-left corner.

    • Left boundary: \(0\)
    • Right boundary: \(W\)
    • Bottom boundary: \(\text{Canvas\_Height}\)
    • Top boundary: \(\text{Canvas\_Height} - H\)

  2. Applying Offsets (-crop WxH+X+Y): Offsets measure displacement away from the anchor point:

    • Horizontal Offset (\(+X\)): Moves the crop box inward to the right. The left boundary becomes \(X\).
    • Vertical Offset (\(+Y\)): Moves the crop box inward toward the top. The bottom boundary becomes \(\text{Canvas\_Height} - Y\).

Using standard top-left Cartesian coordinates (where \(y = 0\) is the top of the image), ImageMagick converts a SouthWest crop into absolute coordinates using the following formulas:

\[\text{Top-Left } X = X\] \[\text{Top-Left } Y = \text{Canvas\_Height} - H - Y\]

The extracted area spans horizontally from \(X\) to \(X + W\), and vertically from \(\text{Canvas\_Height} - H - Y\) to \(\text{Canvas\_Height} - Y\). Any portion of the defined rectangle extending beyond the canvas boundaries will be clipped unless virtual canvas adjustments are explicitly preserved.
