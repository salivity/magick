ImageMagick Sparse-Color Bilinear Syntax

This article provides a concise guide to generating smooth, multi-point color gradients in ImageMagick using the sparse-color operator with Bilinear interpolation. You will learn the exact command-line syntax, how point-color mapping works, and how to define canvas dimensions to produce seamless four-corner color blends.

Basic Command Syntax

In ImageMagick, the sparse-color operator interpolates colors across an image canvas from a defined set of control points. The Bilinear method specifically interpolates between exactly four points, typically placed at the four corners of an image.

The general syntax using ImageMagick v7 (using magick) is:

magick -size WIDTHxHEIGHT xc:none -sparse-color Bilinear \
  "X1,Y1,COLOR1  X2,Y2,COLOR2  X3,Y3,COLOR3  X4,Y4,COLOR4" \
  output.png

For ImageMagick v6, replace magick with convert.

Argument Breakdown

  • -size WIDTHxHEIGHT xc:none: Defines the canvas dimensions and initializes a blank transparent canvas to apply the interpolation onto.
  • -sparse-color Bilinear: Specifies the sparse-color operation using bilinear interpolation. Bilinear interpolation solves for four coordinate points mapped to specific color values.
  • "X,Y,COLOR ...": A quoted string containing coordinate-color pairs separated by whitespace or commas:
    • X,Y: The pixel coordinates (horizontal and vertical offsets starting from 0,0 at the top-left).
    • COLOR: Any valid ImageMagick color definition (such as standard names like red, hex values like #ff0000, or RGB functions like rgb(255,0,0)).

Practical Example: Four-Corner Gradient

To create a 400×400 smooth gradient with different colors at each corner, target the coordinate boundaries of the image:

  • Top-Left (0, 0): Red
  • Top-Right (399, 0): Blue
  • Bottom-Right (399, 399): Green
  • Bottom-Left (0, 399): Yellow

Run the following command:

magick -size 400x400 xc:none -sparse-color Bilinear \
  "0,0 red  399,0 blue  399,399 green  0,399 yellow" \
  bilinear_gradient.png

Important Considerations

  • Point Count Requirement: The Bilinear method requires exactly four control points. If you provide fewer or more than four points, ImageMagick will generate an error or produce unexpected fallbacks. For arbitrary numbers of points, use alternative methods like Shepards or Voronoi.
  • Ordering of Points: The coordinates can be listed in any order within the string, but they must represent a quadrilateral configuration (such as the four corners of a rectangle) to render an even, unskewed field.
  • Coordinate Boundaries: Coordinates are zero-indexed. For an image of width W and height H, the extreme outer corners are at (0, 0), (W-1, 0), (W-1, H-1), and (0, H-1).
