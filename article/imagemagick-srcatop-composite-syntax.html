ImageMagick SrcAtop Composite Syntax

This guide provides the exact command-line syntax for performing a SrcAtop composite operation using ImageMagick. You will learn the command structure for both modern ImageMagick 7 and legacy ImageMagick 6, understand how the Source and Destination layers interact under the SrcAtop composition rule, and see practical command examples.

Understanding the SrcAtop Operator

In Porter-Duff compositing, SrcAtop (Source Atop Destination) composites the source image over the destination image, but only within the boundaries where the destination is opaque. Any portion of the source that extends outside the destination's alpha channel is clipped and discarded. If the destination image has transparent areas, those areas remain completely transparent in the final output.

ImageMagick 7 Syntax

In ImageMagick 7, compositing is performed using the unified magick command. The destination image is specified first, followed by the source image, the composition method, and the -composite operator.

magick destination.png source.png -compose SrcAtop -composite output.png
  • destination.png: The base image containing the shape or alpha mask.
  • source.png: The image or texture you want to overlay atop the destination.
  • -compose SrcAtop: Selects the SrcAtop Porter-Duff operator.
  • -composite: Performs the operation.
  • output.png: The resulting image.

ImageMagick 6 Syntax

For ImageMagick 6, you can use the convert tool with the same parameter order:

convert destination.png source.png -compose SrcAtop -composite output.png

Alternatively, you can use the dedicated composite binary. Note that the file order changes when using the composite command, requiring the source image before the destination image:

composite -compose SrcAtop source.png destination.png output.png

In-Line Image Generation Example

You can also create shapes directly in the command line to test the operation. This example creates a red circle (destination) and places a semi-transparent blue rectangle (source) atop it:

magick -size 200x200 xc:none -fill red -draw "circle 100,100 100,30" \
       \( -size 200x200 xc:none -fill blue -draw "rectangle 50,50 150,150" \) \
       -compose SrcAtop -composite output.png

The resulting output.png will display the blue rectangle strictly confined inside the circular shape of the red base, leaving the background transparent.
