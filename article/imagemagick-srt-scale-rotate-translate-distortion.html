ImageMagick SRT Scale Rotate Translate Distortion

This article provides an overview of the Scale-Rotate-Translate (SRT) distortion operator in ImageMagick. It details how the operator combines multiple affine transformations into a single step, explains its syntax and parameter handling, and covers the practical advantages of using it over sequential transformation commands.

The Scale-Rotate-Translate (SRT) distortion operator in ImageMagick is a specialized mapping method used with the -distort and +distort operators. It allows users to scale, rotate, translate (shift), and optionally shear an image in a single mathematical pass. Instead of applying individual resize, rotation, and crop operations sequentially, SRT recalculates pixel locations simultaneously, resulting in faster processing and significantly reduced image degradation.

How SRT Works

Traditional sequential operations—such as calling -resize, followed by -rotate, followed by a canvas offset—require the image to be resampled multiple times. Each resampling pass introduces blurring and interpolation artifacts.

The SRT operator resolves this by compiling the requested scaling, rotation, and translation parameters into a single 2D affine transformation matrix. ImageMagick then applies a single Elliptical Weighted Average (EWA) resampling filter across the entire transformation, preserving maximum image sharpness and detail.

Parameter Syntax

The SRT operator accepts between one and eight numerical arguments, adjusting its behavior based on how many parameters are provided:

  • 1 Argument (Angle): Rotates the image by the specified angle around the center of the image.
  • 2 Arguments (Scale, Angle): Scales the image uniformly and rotates it around the center.
  • 3 Arguments (X,Y, Angle): Rotates the image around a custom origin point (X, Y).
  • 4 Arguments (X,Y, Scale, Angle): Scales and rotates the image around the custom origin point (X, Y).
  • 5 Arguments (InX,InY, Scale, Angle, OutX,OutY): Maps a specific point in the source image (InX, InY) to a specific location in the output image (OutX, OutY), while simultaneously applying scaling and rotation.
  • 6 Arguments (InX,InY, ScaleX,ScaleY, Angle, OutX,OutY): Performs the same operation as the 5-parameter version, but allows independent horizontal (ScaleX) and vertical (ScaleY) scaling.
  • 7 Arguments (InX,InY, Scale, AngleX,AngleY, OutX,OutY): Adds the ability to specify different rotation angles for each axis, enabling skew and shear transformations.
  • 8 Arguments (InX,InY, ScaleX,ScaleY, AngleX,AngleY, OutX,OutY): Complete 2D affine control, allowing independent scaling and shearing along both axes relative to defined source and destination coordinates.

Canvas Control: -distort vs. +distort

The behavior of the output viewport depends on which operator invocation is used:

  • -distort SRT ...: Locks the output image dimensions to the original canvas size. Any content rotated or scaled outside the original image boundary is clipped, and newly exposed areas are filled with the background color.
  • +distort SRT ...: Automatically recalculates the output canvas size (the bounding box) to ensure that the entire transformed image is preserved without clipping. It also sets the virtual canvas offsets accordingly.
