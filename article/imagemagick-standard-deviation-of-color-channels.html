ImageMagick Standard Deviation of Color Channels

This guide demonstrates how to calculate and output the standard deviation of individual color channels in an image using ImageMagick. Standard deviation measures color variation and contrast within an image, and ImageMagick provides built-in channel statistics through both comprehensive verbose outputs and specific format strings for automation and scripting.

Viewing Full Channel Statistics with Verbose Output

To quickly view the standard deviation alongside other metrics (such as mean, minimum, and maximum) for all color channels, use the identify tool with the -verbose flag.

For ImageMagick 7:

magick identify -verbose input.png

For ImageMagick 6:

identify -verbose input.png

Within the command output, locate the Channel statistics: section to find the standard deviation: values listed separately for Red, Green, Blue, and Alpha channels (if applicable).

Outputting Exact Standard Deviation Values via -format

To extract only the standard deviation without parsing the full verbose output, use the -format option with ImageMagick's built-in format properties.

1. All Channels in Normalized Float Format (0.0 to 1.0)

magick input.png -format "%[channel:standard-deviation]" info:

2. Specific Color Channels Using FX Expressions

To print the standard deviation for individual channels formatted clearly, use FX expressions:

magick input.png -format "Red: %[fx:standard_deviation.r]\nGreen: %[fx:standard_deviation.g]\nBlue: %[fx:standard_deviation.b]\n" info:

3. Standard Deviation in 8-bit Integer Scale (0 to 255)

By default, FX expressions return values normalized between 0.0 and 1.0. To output values scaled to standard 8-bit channel ranges (0–255), multiply the result within the expression:

magick input.png -format "Red (0-255): %[fx:standard_deviation.r*255]\nGreen (0-255): %[fx:standard_deviation.g*255]\nBlue (0-255): %[fx:standard_deviation.b*255]\n" info:
