ImageMagick -stretch Option with OpenType Fonts

The ImageMagick -stretch option controls typographic width characteristics when rendering text, functioning primarily as a font matching filter and variable-axis selector rather than an algorithmic image distortion tool. When applied to modern OpenType fonts (OTF/TTF), it alters the rendered output by either selecting dedicated width variants within a font family or directly manipulating the width variation axis in modern OpenType variable fonts.

Font Matching via OpenType Width Classes

Unlike standard graphic transforms that compress or stretch pixel data horizontally, -stretch targets typographic width designs created by type designers. In static OpenType font families, the option queries the font management subsystem (typically Fontconfig and FreeType) to match the specified width against the font’s internal usWidthClass metric located in its OS/2 table.

ImageMagick accepts several predefined width arguments:

  • Normal (standard width, equivalent to usWidthClass 5)
  • UltraCondensed, ExtraCondensed, Condensed, SemiCondensed (narrow designs, usWidthClass 1–4)
  • SemiExpanded, Expanded, ExtraExpanded, UltraExpanded (wide designs, usWidthClass 6–9)
  • Any (matches any available width)

When you specify an option such as -stretch Condensed, ImageMagick requests the specific condensed sub-family file of the selected OpenType font family. This preserves stroke contrast, vertical stem weights, and optical counters, avoiding the distorted, uneven stroke weights caused by manual horizontal scaling.

Modulation of OpenType Variable Font Axes

In modern OpenType variable fonts, multiple widths are contained inside a single font file using continuous variation axes. When supported by underlying rendering libraries (such as modern versions of FreeType and HarfBuzz), the -stretch argument maps directly to the standardized width variation axis tag (wdth).

Instead of merely switching static files, -stretch prompts the renderer to interpolate the glyph outlines to the designated point along the width axis. This yields an organically designed narrow or wide glyph outline that maintains consistent optical proportions and horizontal spacing without geometric warping.

Fallback Behavior and Distinction from Graphic Distortion

The alterations produced by -stretch are strictly typographic:

  • No Artificial Shearing or Stretching: If an OpenType font family does not contain condensed or expanded variants, and lacks a wdth variable axis, ImageMagick does not horizontally stretch the glyphs artificially. Instead, it falls back to the default Normal width.
  • True Metric Scaling: When an appropriate width variant is found, glyph spacing, kerning pairs, and sidebearings defined specifically for that width in the OpenType GPOS table are applied automatically.

To achieve non-proportional, artificial geometric distortion on fonts lacking native width variants, transforms such as -scale, -resize, or affine transformation matrices must be used instead of -stretch.
