ImageMagick Stroke Dash Patterns and Line Caps

Customizing vector line styles in ImageMagick allows you to create precise borders, diagrams, and graphic overlays directly from the command line. This guide covers how to define dashed stroke patterns and configure line cap styles using ImageMagick’s drawing options and Magick Vector Graphics (MVG) syntax. By adjusting parameters like stroke-dasharray and stroke-linecap, you can control dash lengths, gap intervals, and line endpoint shapes.

Setting Line Caps

Line caps determine the shape applied to the endpoints of open subpaths and lines. ImageMagick supports three standard line cap styles:

  • butt: The default style. The stroke stops abruptly at the exact coordinate of the endpoint with a flat edge.
  • round: Extends the stroke beyond the endpoint with a semicircle whose diameter matches the stroke width.
  • square: Extends the stroke beyond the endpoint with a rectangular shape whose length is equal to half the stroke width.

Command-Line Usage

You can define line caps using the -stroke-linecap setting or directly inside the -draw primitive:

# Using CLI options
magick -size 300x100 xc:white -stroke black -strokewidth 10 \
  -stroke-linecap round -draw "line 20,50 280,50" output_round.png

# Using MVG commands inside -draw
magick -size 300x100 xc:white \
  -draw "stroke black stroke-width 10 stroke-linecap square line 20,50 280,50" output_square.png

Specifying Stroke Dash Patterns

Stroke dash patterns are controlled by specifying a sequence of numbers that alternate between the length of the dash (drawn portion) and the length of the gap (empty space).

Syntax for stroke-dasharray

The stroke-dasharray property accepts a comma-separated or space-separated list of pixel values:

  • Simple Dash/Gap: 5, 5 creates a 5-pixel dash followed by a 5-pixel gap.
  • Asymmetric Dash/Gap: 10, 4 creates a 10-pixel dash followed by a 4-pixel gap.
  • Complex Pattern: 10, 4, 2, 4 creates a dash-dot pattern (10px dash, 4px gap, 2px dot, 4px gap).
  • Reset: Use none to disable dashing and revert to a solid stroke.

Dash Offset

The stroke-dashoffset setting allows you to specify an offset into the dash pattern, changing the exact point along the pattern where the line starts rendering.

Command-Line Usage

# Specifying a dashed pattern using CLI options
magick -size 400x100 xc:white -stroke black -strokewidth 4 \
  -stroke-dasharray 10 5 -draw "line 20,50 380,50" dashed_line.png

# Specifying a dash-dot pattern with an offset inside -draw
magick -size 400x100 xc:white \
  -draw "stroke black stroke-width 4 stroke-dasharray 12,4,2,4 stroke-dashoffset 2 line 20,50 380,50" dash_dot.png

Combined Example

You can combine both properties to create custom lines, such as a rounded dashed line or border:

magick -size 500x200 xc:#f0f0f0 \
  -fill none -stroke #333333 -strokewidth 6 \
  -stroke-linecap round \
  -stroke-dasharray 15 10 \
  -draw "roundrectangle 20,20 480,180 15,15" \
  dashed_box.png

In this example, each dash within the array inherits the rounded cap style, creating smooth pill-shaped segments along the rounded rectangle path.
