ImageMagick stroke-linejoin: Guide to Vector Corners

The stroke-linejoin attribute in ImageMagick defines the visual appearance of the outer corners where two vector path segments intersect. When rendering strokes with a thickness greater than one pixel on shapes such as polygons, polylines, or custom SVG-like paths, sharp angles can create awkward visual artifacts. By setting stroke-linejoin inside the -draw primitive, developers can choose between sharp, rounded, or squared-off corners to maintain clean vector rendering.

The Purpose of stroke-linejoin

When drawing paths with thick strokes, the outer edges of two meeting lines do not naturally overlap in a clean way. ImageMagick uses the stroke-linejoin property to dictate how the empty wedge or overlap at the intersection point is filled.

The attribute accepts three standard values:

  • miter (Default): Extends the outer edges of the stroke lines until they intersect at a sharp point. This creates crisp, angular corners.
  • round: Caps the corner with a circular arc whose diameter matches the stroke width. This produces smooth, rounded vertices.
  • bevel: Cuts off the corner with a straight diagonal edge connecting the endpoints of the outer stroke lines, resulting in a flattened edge.

Interaction with stroke-miterlimit

When using the default miter join, very sharp angles can cause the corner point to extend unnaturally far from the actual vertex. To prevent this, ImageMagick provides the stroke-miterlimit setting.

The miter limit defines the maximum allowable ratio between the miter length (the distance between the inner corner and outer tip) and the stroke width. If a corner is so sharp that this ratio exceeds the stroke-miterlimit value, ImageMagick automatically converts that specific corner into a bevel join to prevent graphical clipping or exaggerated spikes.

Syntax and Implementation

The stroke-linejoin attribute is applied directly inside the string argument of the -draw option alongside other stroke properties like stroke, stroke-width, and shape commands.

Example: Applying a Round Join

magick -size 300x300 xc:white \
  -stroke black -strokewidth 15 -fill none \
  -draw "stroke-linejoin round polyline 50,250 150,50 250,250" \
  output_round.png

In this command, the peak of the polyline is rendered with a smooth curve instead of a sharp spike.

Example: Applying a Bevel Join

magick -size 300x300 xc:white \
  -stroke black -strokewidth 15 -fill none \
  -draw "stroke-linejoin bevel polyline 50,250 150,50 250,250" \
  output_bevel.png

Here, the sharp peak is truncated with a flat line connecting the two stroke boundaries.

Example: Adjusting Miter Limits

magick -size 300x300 xc:white \
  -stroke black -strokewidth 15 -fill none \
  -draw "stroke-linejoin miter stroke-miterlimit 2 polyline 50,250 150,50 250,250" \
  output_miter_limited.png

By lowering the stroke-miterlimit value, acute angles that would normally result in large spikes are automatically flattened into beveled corners.
