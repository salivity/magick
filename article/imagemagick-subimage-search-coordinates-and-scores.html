ImageMagick Subimage Search Coordinates and Scores

This article provides a practical guide on locating a template image within a larger image using ImageMagick's subimage-search feature. You will learn how to run the compare command, interpret the distortion metric output, capture the similarity scores, and extract the exact pixel coordinates where the match occurs.

The Core Command

ImageMagick utilizes the compare tool with the -subimage-search parameter to find a smaller image inside a larger one.

The standard syntax is:

compare -metric RMSE -subimage-search large_image.png template.png null:

Using null: prevents ImageMagick from writing visual comparison images to the disk, which significantly speeds up processing when you only need numerical data.

Understanding the Output Format

ImageMagick prints the match data to the standard error stream (stderr), not standard output (stdout). The raw output typically follows this structure:

0 (0) @ 142,88

The output contains three primary elements:

  1. Raw Metric Value: The first number represents the absolute difference calculated by the chosen metric (e.g., 0).
  2. Normalized Similarity Score: The value inside the parentheses represents the normalized distortion score between 0.0 (identical match) and 1.0 (complete mismatch) when using metrics like RMSE.
  3. Coordinates: The values following the @ symbol are the X,Y coordinates corresponding to the top-left corner of the matched subimage within the primary image.

Extracting Values via the Command Line (Bash)

Because ImageMagick writes to stderr, you must redirect stream 2 to stream 1 using 2>&1 to capture and process the output with tools like awk or sed.

Extracting the Coordinates

output=$(compare -metric RMSE -subimage-search large_image.png template.png null: 2>&1)
coords=$(echo "$output" | awk -F'@ ' '{print $2}')
echo "Match coordinates: $coords"

To separate the X and Y coordinates into distinct variables:

IFS=',' read -r x y <<< "$coords"
echo "X: $x, Y: $y"

Extracting the Similarity Score

To isolate the normalized similarity score inside the parentheses:

score=$(echo "$output" | sed -n 's/.*(\(.*\)).*/\1/p')
echo "Normalized Score: $score"

Extracting Values Using Python

When integrating ImageMagick into automation pipelines, Python's subprocess and re modules provide a clean way to parse both the score and the coordinates.

import subprocess
import re

command = [
    "compare",
    "-metric", "RMSE",
    "-subimage-search",
    "large_image.png",
    "template.png",
    "null:"
]

# Run the command and capture standard error
result = subprocess.run(command, stderr=subprocess.PIPE, stdout=subprocess.PIPE, text=True)

# Parse output using regular expressions
pattern = r"([\d\.\+e\-]+)\s*\(([\d\.\+e\-]+)\)\s*@\s*(\d+),(\d+)"
match = re.search(pattern, result.stderr)

if match:
    raw_score = float(match.group(1))
    normalized_score = float(match.group(2))
    x_coord = int(match.group(3))
    y_coord = int(match.group(4))

    print(f"Similarity (RMSE): {normalized_score}")
    print(f"Location: X={x_coord}, Y={y_coord}")
else:
    print("Match failed or invalid output format.")

Selecting the Right Metric

The choice of metric affects how the score should be interpreted:

  • RMSE (Root Mean Squared Error): Standard choice. A normalized score of 0.0 is an exact match; values below 0.1 generally denote high-confidence visual matches.
  • NCC (Normalized Cross Correlation): Yields a score where 1.0 is a perfect match and 0.0 represents no correlation.
  • PAE (Peak Absolute Error): Measures the single largest color channel difference across all matching pixels.
