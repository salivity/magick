ImageMagick Subimage Search Syntax and Usage

Sub-image template matching in ImageMagick allows you to locate where a smaller reference image appears within a larger target image. This guide explains the exact command-line syntax using the compare tool and the -subimage-search setting, details the required arguments, and demonstrates how to interpret the resulting coordinate and similarity data.

Basic Syntax

To perform a sub-image search, use the compare command (prefixed with magick in ImageMagick version 7):

magick compare -metric RMSE -subimage-search large_image.png template.png difference.png

For ImageMagick version 6:

compare -metric RMSE -subimage-search large_image.png template.png difference.png

Parameter Breakdown

  • -metric <type>: Specifies the error metric used to evaluate similarity across pixels. Common metrics include:
    • RMSE (Root Mean Squared Error): Highly recommended; returns a normalized score where 0.0 represents an exact match.
    • AE (Absolute Error): Counts the exact number of different pixels based on a color tolerance.
    • NCC (Normalized Cross Correlation): Often used for image registration and feature detection.
  • -subimage-search: Tells ImageMagick to slide the second image across the first image at every possible offset to locate the best match. Without this flag, the command expects both images to have identical dimensions.
  • large_image.png: The target base image to be searched. It must be larger than or equal to the template in both width and height.
  • template.png: The smaller sub-image you want to locate.
  • difference.png: The output filename. ImageMagick writes two output files (or a two-layer image depending on format):
    • difference-0.png: A visual highlight of the best match superimposed on the original image (unmatched regions are dimmed or tinted red).
    • difference-1.png: A grayscale correlation map where the brightest (or darkest, depending on the metric) pixel indicates the best offset.

Reading the Coordinate Output

ImageMagick outputs the match score and the pixel offset coordinates to standard error (stderr).

Example terminal output:

0 (0) @ 142,88
  • 0 (0): The distortion score based on the chosen metric. A value of 0 in RMSE indicates a 100% exact match.
  • @ 142,88: The top-left corner coordinates \((X, Y)\) within the large image where the top-left corner of the template matched.

Suppressing Image Output

If you only need the coordinates and distortion score without generating output images, redirect the output file to the null device:

Linux / macOS:

magick compare -metric RMSE -subimage-search large_image.png template.png null:

Windows:

magick compare -metric RMSE -subimage-search large_image.png template.png NUL:

Adjusting Similarity Tolerance

If the template has slight compression artifacts or color variations, apply the -fuzz option to allow for color differences:

magick compare -metric AE -fuzz 5% -subimage-search large_image.png template.png difference.png
