ImageMagick Text Tracking and Character Spacing

In ImageMagick, text tracking and inter-character spacing are controlled using the -kerning parameter. This setting allows users to expand or condense the space between individual characters when rendering text using operations such as -annotate, label:, or caption:. By assigning positive or negative numerical values to this option, you can precisely fine-tune typography across command-line workflows.

The -kerning Setting

The primary option for adjusting inter-character spacing is -kerning <value>.

  • Positive values add space between characters (loose tracking/expanded text).
  • Negative values reduce space between characters, pulling them closer together (tight tracking/condensed text).
  • A value of zero (0) leaves the default font metrics intact.

Values can be specified as whole integers or floating-point numbers representing points (or pixels depending on resolution settings).

Using -kerning with -annotate

When placing text over an existing image using the -annotate operator, apply -kerning prior to the annotation call.

magick input.jpg -font Arial -pointsize 36 -fill white -kerning 4 -annotate +50+100 "Expanded Text" output.jpg

In this command:

  • -kerning 4 increases the default spacing between each letter by 4 points.
  • -annotate +50+100 applies the spaced text onto input.jpg at the specified coordinates.

To tighten character spacing instead:

magick input.jpg -font Arial -pointsize 36 -fill white -kerning -2 -annotate +50+100 "Condensed Text" output.jpg

Using -kerning with label: and caption:

The setting applies equally to generated text canvases created with label: or caption:.

magick -background lightblue -fill black -font Helvetica -pointsize 48 -kerning 8 label:"Wide Spacing" output.png

Behavior Notes

  • Position in Command: In ImageMagick version 7 (magick), -kerning is a setting that affects all subsequent text rendering operators. It should be declared before -annotate, label:, or caption:.
  • Font Support: The -kerning parameter functions by altering the horizontal advance between glyphs, so it functions consistently regardless of whether the underlying font file natively supports TrueType kerning tables.
