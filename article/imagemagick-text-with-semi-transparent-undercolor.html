ImageMagick Text with Semi-Transparent Undercolor

Rendering text with a semi-transparent background box in ImageMagick is achieved by configuring the -undercolor setting with an alpha-enabled color format such as RGBA or 8-digit hexadecimal notation. This technique allows you to overlay legible captions or subtitles directly onto varied backgrounds without obscuring the underlying imagery entirely.

Basic Syntax and Color Formats

The -undercolor operator specifies the color of the bounding box drawn directly beneath rendered text. To make this box semi-transparent, supply an alpha channel value between 0.0 (fully transparent) and 1.0 (fully opaque), or use standard 8-digit hexadecimal notation (#RRGGBBAA).

Common transparent color formats include:

  • RGBA: "rgba(0, 0, 0, 0.5)" (Black at 50% opacity)
  • Hexadecimal: "#00000080" (Black at ~50% opacity)
  • Named color with alpha: "rgba(255, 255, 255, 0.7)" (White at 70% opacity)

Example Using ImageMagick 7

In ImageMagick 7, use the magick command along with -annotate or -draw to apply the styled text:

magick input.jpg \
  -font Arial \
  -pointsize 36 \
  -fill white \
  -undercolor "rgba(0, 0, 0, 0.6)" \
  -gravity south \
  -annotate +0+30 " Sample Caption Text " \
  output.jpg

Example Using ImageMagick 6

For legacy systems running ImageMagick 6, use the convert tool:

convert input.jpg \
  -font Arial \
  -pointsize 36 \
  -fill white \
  -undercolor "rgba(0, 0, 0, 0.6)" \
  -gravity south \
  -annotate +0+30 " Sample Caption Text " \
  output.jpg

Key Parameters Explained

  • -fill white: Defines the foreground color of the text itself.
  • -undercolor "rgba(0, 0, 0, 0.6)": Generates the background rectangle behind the text using black at 60% opacity.
  • -gravity south: Anchors the text positioning to the bottom of the image.
  • -annotate +0+30: Offsets the text by 0 pixels horizontally and 30 pixels vertically from the gravity anchor point.

Adjusting Box Padding

The -undercolor setting creates a tight bounding box around the text string based on font metrics. To add horizontal padding around the text, include leading and trailing spaces inside the text string (e.g., " Your Text Here ").
