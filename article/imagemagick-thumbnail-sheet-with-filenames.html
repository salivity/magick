ImageMagick Thumbnail Sheet with Filenames

This guide explains how to generate an image thumbnail sheet (also known as a contact sheet or montage) with original filenames printed beneath each thumbnail using ImageMagick. By utilizing ImageMagick's built-in montage tool alongside the -label property, you can automate the process of creating organized image grids directly from the command line.

The Basic Command

To create a thumbnail sheet displaying filenames beneath each image, run the following command in your terminal:

montage -label "%f" -geometry 150x150+5+5 *.jpg thumbnail_sheet.png

For ImageMagick version 7 and later, prefix the command with magick:

magick montage -label "%f" -geometry 150x150+5+5 *.jpg thumbnail_sheet.png

How It Works

  • -label "%f": Instructs ImageMagick to read the filename of each input file and print it as a label directly beneath its corresponding thumbnail.
  • -geometry 150x150+5+5: Defines the size of each thumbnail (150x150 pixels) and adds horizontal and vertical spacing (5px margin on each side).
  • *.jpg: The input images to include in the thumbnail sheet.
  • thumbnail_sheet.png: The output image file.

Advanced Customization Options

You can refine the layout, typography, and styling by adding additional flags:

1. Define Grid Layout (Columns and Rows)

Use the -tile option to specify the number of columns and rows:

magick montage -label "%f" -tile 4x -geometry 200x200+10+10 *.jpg contact_sheet.png

(Setting -tile 4x creates a fixed 4-column layout with an automatic number of rows.)

2. Change Font Size and Colors

Customize the appearance of the text and background:

magick montage -label "%f" -font Arial -pointsize 12 -background "#ffffff" -fill "#333333" -geometry 150x150+10+10 *.jpg styled_sheet.png
  • -pointsize 12: Sets the label font size to 12 points.
  • -background "#ffffff": Sets the sheet background color to white.
  • -fill "#333333": Sets the text color to dark gray.

3. Display Filenames Without File Extensions

If you want only the base filename without the extension, replace %f with %t:

magick montage -label "%t" -geometry 150x150+5+5 *.jpg base_names_sheet.png
