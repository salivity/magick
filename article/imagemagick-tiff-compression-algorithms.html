ImageMagick TIFF Compression Algorithms

ImageMagick provides robust support for writing Tagged Image File Format (TIFF) files using a variety of compression algorithms to balance file size, image quality, and compatibility. By using the -compress command-line option, users can apply lossless, lossy, and specialized bi-level compression methods when generating TIFF images.

How to Specify TIFF Compression in ImageMagick

To set the compression algorithm when writing a TIFF file, pass the -compress flag followed by the algorithm name before specifying the output file:

magick input.png -compress <type> output.tiff

General Lossless Compression Algorithms

  • LZW (-compress LZW): Lempel-Ziv-Welch is one of the most widely supported lossless compression algorithms for TIFF. It works well on flat colors, graphics, and indexed palettes, making it universally compatible across older software.
  • Zip / Deflate (-compress Zip): Uses the DEFLATE algorithm (the same standard used in ZIP files and PNGs). It typically achieves higher compression ratios than LZW on continuous-tone images without discarding any image data.
  • PackBits / RLE (-compress RLE): A simple Run-Length Encoding scheme historically used in Macintosh systems. It offers fast encoding and decoding with minimal CPU overhead, though it yields lower compression ratios on photographic images.
  • LZMA (-compress LZMA): Provides high lossless compression ratios at the expense of higher CPU usage and longer processing times. It requires an ImageMagick build linked against a libtiff version configured with LZMA support.
  • ZSTD (-compress ZSTD): Zstandard compression offers modern, high-speed lossless compression with superior ratios and very fast decompression, available in modern libtiff builds.

Bi-Level (Black-and-White) Compression Algorithms

These algorithms are tailored specifically for 1-bit monochrome images, such as scanned text documents, line art, and faxes:

  • Group4 / CCITT Fax 4 (-compress Group4): A two-dimensional encoding standard optimized for bi-level document imaging. It provides exceptionally high compression ratios for clean black-and-white documents and is standard in legal and archival workflows.
  • Group3 / CCITT Fax 3 (-compress Group3): A one-dimensional or two-dimensional standard used in traditional facsimile machines.
  • Fax (-compress Fax): Standard CCITT Group 3 encoding used for legacy fax transmission compatibility.
  • JBIG (-compress JBIG): Joint Bi-level Image Experts Group standard designed specifically for lossless bi-level image compression, outperforming Group 4 in compression efficiency.

Lossy Compression Algorithms

  • JPEG (-compress JPEG): Embeds standard lossy JPEG compression inside the TIFF container. This significantly reduces file size for photographic and continuous-tone imagery. You can control the compression level using the -quality flag (e.g., -quality 85).
  • WebP (-compress WebP): Uses Google's WebP codec within the TIFF container for lossy or lossless compression, provided both ImageMagick and libtiff have been compiled with WebP delegate support.

Uncompressed TIFF

  • None (-compress None): Writes raw, uncompressed pixel data to the TIFF file. This produces the largest file sizes but avoids any CPU overhead and guarantees maximum compatibility across legacy systems.
