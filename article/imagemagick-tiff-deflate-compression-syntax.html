ImageMagick TIFF Deflate Compression Syntax

This guide explains how to configure Deflate (Zip) compression levels and predictors when saving TIFF files in ImageMagick, ensuring you achieve the optimal balance between file size and processing speed.

Basic Syntax

To apply Deflate compression to a TIFF image, specify the compression type using -compress Zip (or -compress Deflate) and control the compression strength using the -quality setting.

For ImageMagick v7:

magick input.png -compress Zip -quality 9 output.tif

For ImageMagick v6:

convert input.png -compress Zip -quality 9 output.tif

Understanding Compression Levels

ImageMagick uses the zlib library to handle Deflate compression. The -quality option directly sets the zlib compression level:

  • Level 1 (-quality 1): Fastest execution time with the lowest compression ratio.
  • Level 6 (-quality 6): The default balance of speed and file size reduction.
  • Level 9 (-quality 9): Maximum compression, resulting in the smallest file size at the cost of higher CPU time and slower processing.

Optimizing Deflate with Predictors

Deflate compression in TIFF files is often significantly more effective when paired with a predictor. Predictors store the difference between adjacent pixels rather than the raw pixel values, creating data streams that zlib can compress much smaller.

To enable the horizontal differencing predictor, use the -define flag:

magick input.png -compress Zip -quality 9 -define tiff:predictor=2 output.tif

Available predictor options include:

  • tiff:predictor=1: None (standard Deflate without pre-filtering).
  • tiff:predictor=2: Horizontal differencing (recommended for continuous-tone or photographic images).
  • tiff:predictor=3: Floating-point horizontal differencing (used specifically for floating-point data).
