ImageMagick Top-Hat Transform for Bright Specks

This guide explains how to isolate small, bright specks from an image using the morphological White Top-Hat transform in ImageMagick. The Top-Hat transform functions by subtracting an image's morphological opening from the original image, effectively filtering out large background elements and retaining only bright anomalies smaller than the chosen structuring element. Below, you will find the fundamental command syntax, how to choose the right kernel size, and methods for enhancing or thresholding the extracted specks.

The Basic Top-Hat Command

In ImageMagick (version 7 uses magick, while version 6 uses convert), you execute a White Top-Hat transform using the -morphology operator:

magick input.png -morphology TopHat Disk:2.5 output.png

This operation performs two steps internally:

  1. It applies a morphological opening using the defined kernel shape and radius (Disk:2.5), which erases features smaller than that radius.
  2. It subtracts the opened image from the original image. The result contains only the bright elements that were smaller than the structuring element.

Selecting Kernels and Sizing

The kernel determines the geometry and maximum scale of the specks you want to capture:

  • Kernel Types:
    • Disk: Best for round specks, dust, or stars.
    • Diamond or Square: Suitable for pixel-aligned artifacts or faster, coarse approximations.
    • Octagon: A balanced, near-circular alternative to Disk.
  • Kernel Radius:
    • The value following the colon represents the radius in pixels (e.g., Disk:1, Disk:3.5).
    • Set the radius slightly larger than the largest speck you wish to isolate. If a bright spot has a radius of 2 pixels, a Disk:3 kernel will cleanly isolate it, whereas a Disk:1 kernel will only extract its edges.

Improving Contrast and Visibility

Because the subtracted background leaves the bright specks surrounded by black, the resulting specks may appear faint. You can stretch the dynamic range using -auto-level:

magick input.png -morphology TopHat Disk:2 -auto-level enhanced_specks.png

Creating a Binary Mask of Specks

If you need to segment the specks into a binary mask (white specks on a pure black background) for analysis or further masking, append a -threshold command:

magick input.png -morphology TopHat Disk:2 -threshold 15% binary_specks.png

Adjust the percentage value to filter out faint noise while keeping the distinct bright specks.
