ImageMagick Transparent Background by Corner Pixel

This article explains how to use ImageMagick to automatically remove an image background by sampling the color of a corner pixel. You will learn the specific command-line parameters required to sample the top-left corner pixel, apply a tolerance threshold for subtle color variations, and convert that background color into full transparency using both floodfill and global replacement techniques.

Method 1: Floodfill Transparency from a Corner Pixel (Recommended)

The floodfill approach samples the pixel at coordinate (0,0) (the top-left corner) and replaces all contiguous matching pixels with transparency. This prevents interior details that share the same color from accidentally becoming transparent.

ImageMagick 7

magick input.png -fuzz 10% -fill none -draw "color 0,0 floodfill" output.png

ImageMagick 6

convert input.png -fuzz 10% -fill none -draw "matte 0,0 floodfill" output.png

Method 2: Global Replacement Using Dynamic Corner Sampling

If the background is split into non-contiguous sections or is blocked by foreground objects, you can sample the corner pixel dynamically and remove that color across the entire image.

ImageMagick 7

magick input.png -fuzz 10% -transparent "%[pixel:p{0,0}]" output.png

Command Parameters Explained

  • -fuzz 10%: Defines the tolerance range. Because compression artifacts (like those in JPEG images) often cause subtle color variations, a fuzz value between 5% and 15% ensures the entire background is captured without leaving halos.
  • 0,0: The pixel coordinate targeted for the color sample (top-left corner). To use a different corner, update the coordinates (e.g., using dynamic image width/height dimensions).
  • -fill none: Sets the replacement color to completely transparent.
  • -draw "color 0,0 floodfill": Starts the transparency fill at coordinate (0,0) and expands outward to all connected pixels matching that color.
  • %[pixel:p{0,0}]: An ImageMagick 7 inline string format that automatically extracts the exact color value of the pixel at coordinate (0,0).
