ImageMagick Transparent Rounded Corners with Masks

This guide explains how to apply transparent rounded corners to an image using ImageMagick's alpha masking and composite operators. By creating a rounded rectangle mask that matches the source image dimensions and combining them using the DstIn composition method, you can produce clean, anti-aliased transparent corners on any image format in a single command.

The Single-Command Method

The most efficient way to round an image's corners with transparency is to create an inline mask and apply it using alpha compositing.

ImageMagick 7 Syntax

magick input.jpg \
  \( +clone -alpha transparent -background none \
     -fill white -draw "roundrectangle 0,0,%[fx:w-1],%[fx:h-1],30,30" \) \
  -compose DstIn -composite output.png

ImageMagick 6 Syntax

convert input.jpg \
  \( +clone -alpha transparent -background none \
     -fill white -draw "roundrectangle 0,0,%[fx:w-1],%[fx:h-1],30,30" \) \
  -compose DstIn -composite output.png

How the Command Works

  1. input.jpg: Loads the original source image.
  2. \( ... \): Creates an isolated sub-process to generate the mask without affecting the original image.
  3. +clone: Duplicates the source image to automatically inherit its exact dimensions (width and height).
  4. -alpha transparent -background none: Clears the cloned image data, leaving a fully transparent canvas of the exact same size.
  5. -fill white -draw "roundrectangle 0,0,%[fx:w-1],%[fx:h-1],30,30": Draws a solid white rectangle with rounded corners over the transparent canvas.
    • 0,0: The top-left starting coordinate.
    • %[fx:w-1],%[fx:h-1]: The dynamic bottom-right coordinates based on image width (w) and height (h).
    • 30,30: The horizontal and vertical corner radius in pixels. Adjust these numbers to change the roundness.
  6. -compose DstIn: Sets the composition operator to "Destination In", which keeps only the parts of the original image that overlap with the opaque parts of the mask.
  7. -composite: Executes the composition of the image and the mask.
  8. output.png: Saves the result. A format supporting an alpha channel (such as PNG, WebP, or TIFF) must be used to preserve corner transparency.

Two-Step Method Using an External Mask

If you prefer to generate a reusable mask file before applying it to multiple images, use the following two-step approach:

Step 1: Create the Mask

magick -size 800x600 xc:none \
  -fill white -draw "roundrectangle 0,0,799,599,30,30" \
  mask.png

Step 2: Composite the Mask onto the Source

magick input.jpg mask.png -alpha set -compose DstIn -composite output.png

This applies the pre-generated mask.png to input.jpg, replacing the rectangular edges with smooth, transparent borders.
