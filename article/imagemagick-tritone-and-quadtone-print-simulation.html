ImageMagick Tritone and Quadtone Print Simulation

Tritone and quadtone print simulations reproduce the depth of multi-ink monochrome printing by mapping a grayscale image's luminance values across three or four distinct ink colors. In ImageMagick, this effect is achieved either by applying Color Lookup Tables (CLUT) across defined tonal gradients or by manipulating individual color channels with custom curve adjustments. This guide outlines the exact ImageMagick commands and syntax required to simulate tritone and quadtone printing processes.

Understanding the CLUT Approach

The most reliable and versatile method for simulating multi-tone prints in ImageMagick 7 is the -clut (Color Look-Up Table) operator. The source image is converted to grayscale, and its tonal range (from 0/black to 255/white) is replaced by a custom multi-stop gradient representing the ink set (shadows, midtones, highlights, and paper tone).

Tritone Print Simulation Syntax

A tritone print uses three ink values: typically a deep shadow tone (e.g., carbon black), a midtone body ink (e.g., warm sepia or cool slate), and a highlight tint (e.g., paper cream or light amber).

Basic Tritone Command

magick input.jpg -colorspace Gray \
  ( -size 1x256 gradient:"#120c06-#6e543c-#f3ede2" ) \
  -clut tritone_output.jpg

Syntax Breakdown:

  • -colorspace Gray: Strips existing color data to ensure mapping is based solely on luminosity.
  • ( -size 1x256 gradient:"#120c06-#6e543c-#f3ede2" ): Creates a 256-level vertical gradient defining:
    • #120c06: Deep shadow ink
    • #6e543c: Midtone ink
    • #f3ede2: Highlight / paper base
  • -clut: Applies the gradient map directly to the grayscale pixels.

Quadtone Print Simulation Syntax

Quadtones introduce a fourth ink to provide smoother gradations between shadow, lower-midtone, upper-midtone, and paper highlights.

Basic Quadtone Command

magick input.jpg -colorspace Gray \
  ( -size 1x256 gradient:"#0d0b09-#362d26-#8a7765-#faf6ee" ) \
  -clut quadtone_output.jpg

Syntax Breakdown:

  • gradient:"#0d0b09-#362d26-#8a7765-#faf6ee": Defines a four-stop continuous color ramp:
    • #0d0b09: Maximum black density (shadows)
    • #362d26: Deep neutral/warm tone (3/4 tones)
    • #8a7765: Primary body tone (1/4 to midtones)
    • #faf6ee: Base highlight / paper tone

Advanced Multi-Stop Gradients with Custom Tonal Distribution

By default, ImageMagick distributes multi-stop gradients evenly. If you need precise control over where specific inks take effect (e.g., pinning a tone strictly to the 75% shadow mark), you can construct multi-segment gradient strips and append them vertically before applying -clut:

magick input.jpg -colorspace Gray \
  ( \
    -size 1x64  gradient:"#0a0806-#2b221a" \
    -size 1x128 gradient:"#2b221a-#8c7a6b" \
    -size 1x64  gradient:"#8c7a6b-#fdfbf7" \
    -append \
  ) \
  -clut advanced_quadtone.jpg

Alternative Method: Using +level-colors

For quick split-toning and tritones where strict multi-stop gradients are not required, +level-colors maps shadows and highlights directly:

magick input.jpg -colorspace Gray +level-colors "#1b140e","#f5ede4" duotone_base.jpg

To create a tritone effect via layering, tint specific tonal ranges using blend modes:

magick input.jpg -colorspace Gray \
  ( +clone -fill "#402f1d" -tint 100% ) \
  ( +clone -fill "#99826a" -tint 50% ) \
  -average tritone_blend.jpg
