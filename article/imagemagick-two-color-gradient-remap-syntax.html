ImageMagick Two-Color Gradient Remap Syntax

This article explains how to remap the pixel intensities of an image to an arbitrary two-color gradient using ImageMagick. It details the dedicated +level-colors operator and the alternative Color Look-Up Table (-clut) technique, providing the exact command-line syntax and parameter explanations needed to create duotone effects and custom gradient mappings.

Using the +level-colors Operator

The most efficient and direct way to map pixel intensities to a two-color gradient in ImageMagick is the +level-colors operator. This command maps black (0% intensity) to the first specified color, white (100% intensity) to the second specified color, and recalculates all intermediate values as a smooth linear transition between them.

magick input.jpg +level-colors "navy,gold" output.jpg

In ImageMagick version 6, replace magick with convert:

convert input.jpg +level-colors "navy,gold" output.jpg

Color Specification Options

You can specify the two colors using standard color names, hex values, or RGB coordinates:

  • Hex format: +level-colors "#1a2a6c,#fdbb2d"
  • RGB format: +level-colors "rgb(20,40,80),rgb(255,200,50)"
  • Named colors: +level-colors "midnightblue,coral"

If you invert the order of the colors, the intensity values will invert accordingly, mapping highlights to the first color and shadows to the second.

Using the Color Look-Up Table (-clut) Method

An alternative approach is using the -clut (Color Look-Up Table) operator. This method generates an explicit gradient image in memory and maps the grayscale intensities of the primary image to the coordinates of that gradient.

magick input.jpg ( -size 1x256 gradient:"navy-gold" ) -clut output.jpg

This method functions as follows:

  1. input.jpg loads the base image.
  2. ( -size 1x256 gradient:"navy-gold" ) generates a 1-pixel wide, 256-pixel tall gradient transitioning from navy at the top to gold at the bottom.
  3. -clut replaces each pixel's color in input.jpg based on where its brightness falls along that 256-level gradient.

Ensuring Proper Luminance Mapping

If the source image contains strong hue variations that you want to neutralize before remapping, convert the image to grayscale using -colorspace Gray immediately before applying either method:

magick input.jpg -colorspace Gray +level-colors "darkgreen,lightgreen" output.jpg

This ensures the remapping is calculated strictly from the perceived brightness of the original image rather than channel-by-channel variations.
