ImageMagick Undercolor vs Fill Text Settings

When annotating images with text in ImageMagick, the -fill and -undercolor settings control two completely different visual components of the rendering process. In short, the -fill setting determines the color of the actual text characters (the glyphs), while the -undercolor setting creates a colored rectangular background box directly behind that text to enhance readability against complex backgrounds.

The Fill Setting

The -fill setting defines the foreground color of the text characters. When you draw or annotate text, ImageMagick uses the color specified by -fill to paint the interior of each letter and number.

  • Purpose: Sets the text font color.
  • Default Behavior: If no fill is specified, ImageMagick defaults to black.
  • Scope: It applies directly to the vector outlines of the text glyphs and does not alter the canvas or background area surrounding the characters.
magick input.jpg -fill white -annotate +50+50 "White Text" output.jpg

The Undercolor Setting

The -undercolor setting defines the color of a solid rectangular bounding box rendered immediately behind the annotated text. It acts as an inline highlight or label background, ensuring that text remains legible when placed over busy, multi-colored, or low-contrast image regions.

  • Purpose: Sets the background bounding box color for the text snippet.
  • Default Behavior: By default, -undercolor is set to none (fully transparent), meaning no box is drawn behind the text.
  • Scope: It only covers the exact dimensional bounding box of the rendered text string, not the entire image canvas.
magick input.jpg -undercolor black -annotate +50+50 "Text with Background Box" output.jpg

Key Differences Summary

Feature -fill -undercolor
Visual Target Text glyphs (the letters themselves) Rectangular area behind the text
Default Value black (or current draw fill) none (transparent)
Primary Use Defining the font color Adding contrast against complex backgrounds
Transparency Can be transparent (leaves hollow text if stroked) Transparent by default

Using Both Settings Together

Combining -fill and -undercolor is standard practice for creating subtitles, captions, or watermarks. This ensures the text color and its background box provide immediate visual contrast against whatever image is underneath.

magick input.jpg -font Arial -pointsize 24 -fill yellow -undercolor "rgba(0,0,0,0.7)" -annotate +20+40 "High Contrast Caption" output.jpg

In this example, -fill yellow turns the text bright yellow, while -undercolor "rgba(0,0,0,0.7)" places a semi-transparent black rectangular backdrop behind the text.
