ImageMagick Unique Colors Command Explained

This guide explains the purpose, operation, and practical applications of the -unique-colors command-line option in ImageMagick. By reading this overview, you will learn how this option extracts distinct color profiles from images, how to inspect or export these palettes, and how to apply the tool to automate color analysis workflows.

Purpose of -unique-colors

The primary purpose of the -unique-colors option in ImageMagick is to scan an input image, discard all duplicate color values, and output a new image containing exactly one pixel for every unique color found in the source file.

The resulting output is typically an image that is one pixel high, with a width equal to the total number of unique colors present in the original graphic. For example, if a source image contains 256 distinct colors, applying -unique-colors generates a 256×1 pixel image strip where each pixel represents one of those individual colors.

Basic Usage and Syntax

In modern ImageMagick (version 7+), the basic syntax applies the option directly to the input image before writing to an output file:

magick input.jpg -unique-colors palette.png

For legacy ImageMagick (version 6), the convert utility is used:

convert input.jpg -unique-colors palette.png

Common Use Cases

  1. Extracting Color Palettes as Text Pairing -unique-colors with ImageMagick's txt: output format generates a readable text file listing every distinct RGB or HEX value in the image:

    magick input.png -unique-colors palette.txt

  2. Counting Unique Colors Because the generated image's width equals the number of distinct colors, you can determine the exact color count by retrieving the width dimension:

    magick input.png -unique-colors -format "%w" info:

  3. Visual Swatch Generation The 1-pixel-high strip can be resized using nearest-neighbor interpolation (-scale) to create a visible color swatch bar:

    magick input.png -unique-colors -scale 500x50! color_bar.png

Important Considerations

  • Photographic Images: Continuous-tone photographs often contain tens or hundreds of thousands of distinct colors. Running -unique-colors on an uncompressed photograph can produce extremely wide images.
  • Palette Reduction: To extract a dominant or limited palette rather than every subtle shade, reduce the colors first using the -colors or -quantize options prior to invoking -unique-colors: 
    magick input.jpg -colors 16 -unique-colors limited_palette.png
