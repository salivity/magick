ImageMagick Unsharp Mask on Luminance Channel

Applying an unsharp mask exclusively to the luminance channel enhances edge details while preventing color fringing and chromatic noise. This guide provides the exact ImageMagick command-line syntax required to isolate the lightness information, apply the unsharp filter, and convert the image back to the standard color space.

ImageMagick Command Syntax

To sharpen only the luminance channel in ImageMagick 7, convert the image to the CIELAB (Lab) color space, target the Lightness channel (L), apply the unsharp mask, and convert back to sRGB.

magick input.jpg -colorspace Lab -channel 0 -unsharp 0x1.5+1.0+0.05 +channel -colorspace sRGB output.jpg

(Note: For legacy ImageMagick v6, replace magick with convert.)

Parameter Breakdown

  • -colorspace Lab: Converts the image from RGB to CIELAB color space, separating the image into Lightness (Channel 0), green-red component (Channel 1), and blue-yellow component (Channel 2).
  • -channel 0: Restricts subsequent image processing operations exclusively to the first channel (the Lightness/Luminance channel).
  • -unsharp {radius}x{sigma}+{amount}+{threshold}: Applies the unsharp mask filter.
    • radius: The size of the Gaussian blur matrix (setting 0 lets ImageMagick calculate an optimal radius automatically).
    • sigma: The standard deviation of the blur (typically between 0.5 and 2.0).
    • amount: The strength of the sharpening effect (e.g., 1.0 equals 100% effect).
    • threshold: The minimum tonal difference required to apply sharpening, which prevents noise amplification in flat areas (e.g., 0.05).
  • +channel: Resets the channel mask so subsequent operations apply to the entire image.
  • -colorspace sRGB: Restores the image to the standard RGB color space suitable for web and digital display.
