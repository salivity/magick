ImageMagick Unsharp Mask Parameters Guide

This guide explains how to control sharpening in ImageMagick using the -unsharp operator, detailing the exact parameters for radius, sigma, gain (amount), and threshold. Understanding these parameters allows you to precisely enhance image details without introducing unwanted noise or harsh artifacts.

The -unsharp Syntax

ImageMagick controls unsharp masking using a single parameter string with the following format:

-unsharp radiusxsigma+gain+threshold

Parameter Breakdown

  • Radius (radius): Defines the size of the Gaussian blur kernel in pixels. It determines how far the blur extends when creating the mask. In most cases, setting this to 0 is recommended, which instructs ImageMagick to automatically calculate the optimal mathematical radius based on the sigma value.
  • Sigma (sigma): Represents the standard deviation of the Gaussian blur, measured in pixels. This is the most critical parameter for setting the scale of the sharpening effect. A smaller value (e.g., 0.5 to 1.0) targets fine details, while larger values (e.g., 1.5 to 3.0) sharpen broader edges and larger features.
  • Gain / Amount (gain): Dictates the strength or intensity of the sharpening effect applied to the image. It represents the fraction or multiplier of the difference between the original and blurred image added back. A value of 1.0 adds 100% of the difference, while higher values like 1.5 or 2.0 increase the contrast along edges significantly.
  • Threshold (threshold): Defines the minimum brightness difference required between pixels before sharpening is applied, expressed as a fraction of the maximum color value (or percentage). This prevents the filter from sharpening flat areas, such as sky or skin, thereby reducing background noise. A typical value ranges from 0.02 to 0.05.

Example Command

To apply a standard, balanced sharpening filter to an image:

magick input.jpg -unsharp 0x1.0+1.2+0.05 output.jpg

In this command:

  • 0 lets ImageMagick calculate the radius automatically.
  • 1.0 sets the Gaussian blur sigma to 1 pixel.
  • 1.2 boosts edge contrast by 120% (gain).
  • 0.05 ensures subtle noise below a 5% contrast difference remains untouched.
