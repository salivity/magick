ImageMagick Verbose Output Switch

This article explains how to enable detailed processing output across ImageMagick command-line tools. Using the -verbose switch, users can monitor real-time operations, inspect detailed image properties, troubleshoot conversion issues, and track the exact execution flow of ImageMagick commands.

The -verbose Option

The command-line switch that enables verbose processing output across ImageMagick tools is -verbose.

When applied to a command, -verbose instructs ImageMagick to print detailed diagnostic messages to the standard output (stdout). This includes read/write progress, image dimensions, color profiles, compression types, rendering operations, and the time taken to complete each step.

How to Use -verbose in ImageMagick Commands

The switch works across various utilities within the ImageMagick suite, including magick (ImageMagick v7), as well as legacy v6 utilities such as convert, identify, mogrify, composite, and montage.

1. Basic Conversion with Verbose Logging

In ImageMagick 7:

magick -verbose input.jpg output.png

In ImageMagick 6:

convert -verbose input.jpg output.png

2. Inspecting Image Metadata with identify

When combined with identify, the -verbose flag provides an extensive breakdown of the image's internal metadata, including EXIF data, channel statistics, color spaces, and resolution:

magick identify -verbose input.jpg

(Or identify -verbose input.jpg in legacy versions)

3. Batch Processing with mogrify

When modifying multiple files in place, using -verbose tracks the progress of each individual file being processed:

mogrify -verbose -resize 800x600 *.jpg

Typical Output Information

When -verbose is active, ImageMagick outputs details such as:

  • Input and output file formats and paths
  • Geometry and canvas dimensions (e.g., 800x600 => 400x300)
  • Color profiles and depth (e.g., sRGB, 8-bit)
  • Compression quality settings
  • Elapsed real and user CPU time per processing step

To disable verbose reporting after enabling it in a complex command chain, you can specify +verbose.
