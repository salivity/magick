ImageMagick Watermark Blend Opacity Settings

When applying a watermark graphic to an image using ImageMagick, controlling transparency is essential for balancing protection and content visibility. This article explains the primary parameters used to adjust watermark blend opacity—specifically the -dissolve and -blend options—and demonstrates how to implement them effectively across common ImageMagick commands.

The Primary Parameter: -dissolve

The most common and direct parameter for adjusting watermark opacity is -dissolve. It sets the transparency percentage of the overlaid watermark graphic relative to the background image.

When using the composite command, specify the percentage value immediately following the -dissolve flag:

composite -dissolve 30% watermark.png input.jpg output.jpg

In this example, 30% dictates that the watermark will appear with 30% opacity, allowing 70% of the underlying image to show through. You can also specify dual percentages (e.g., -dissolve 30x100%) where the first number controls watermark opacity and the second controls background opacity.

Alternative Parameter: -blend

The -blend parameter is another option that controls how two images are merged, typically used with the composite operator.

composite -blend 25% watermark.png input.jpg output.jpg

Like -dissolve, -blend accepts a percentage. A single value alters the overlay opacity. You can also supply two comma-separated percentages (e.g., -blend 30,70) to independently set the weight of the watermark and the source image.

Using Opacity in Modern ImageMagick (v7)

In ImageMagick 7, workflows typically use the unified magick command instead of composite. You can control blend opacity using -define compose:args combined with -compose dissolve:

magick input.jpg watermark.png -define compose:args=30,100 -compose dissolve -composite output.jpg

Alternatively, you can modify the alpha channel of the watermark in-memory before compositing using the -channel A -evaluate multiply sequence:

magick input.jpg \( watermark.png -channel A -evaluate multiply 0.3 +channel \) -gravity center -composite output.jpg

In this syntax, multiplying the alpha channel by 0.3 reduces the watermark's opacity to 30% prior to placing it on the base image.
