ImageMagick Wavelet Denoise Threshold and Softness

ImageMagick features a built-in wavelet noise reduction filter that separates an image into multiple frequency layers to strip away sensor noise and grain while preserving sharp edges. The behavior of this filter is governed by two parameters: threshold, which sets the noise detection cutoff, and softness, which determines how abruptly those noise frequencies are attenuated. Fine-tuning both settings allows you to eliminate high-frequency artifacts without causing unnatural blurring or halo artifacts.

Basic Syntax

The wavelet denoising operator uses the following command structure:

magick input.jpg -wavelet-denoise threshold[%][xsoftness] output.jpg

If you are using ImageMagick v6, replace magick with convert. The parameters are passed as a single argument where threshold is optionally followed by a percentage sign and separated from softness by an x.

Configuring the Threshold

The threshold parameter defines the cutoff level for high-frequency coefficients. Any coefficient with an amplitude lower than this value is treated as noise.

  • Format: Can be expressed as an absolute value or a percentage (recommended, such as 3% or 5%).
  • Low Values (1% – 3%): Ideal for subtle luminance noise or low-ISO digital grain. It leaves fine textures, such as fabric weaves or skin pores, completely intact.
  • High Values (5% – 10%+): Targets aggressive high-ISO noise or heavy scanner artifacts. Setting the threshold too high removes legitimate image detail and results in a flat, plastic, or "watercolor" look.

Configuring the Softness

The softness parameter determines the attenuation curve applied to details near the threshold boundary, acting as a transition between hard and soft thresholding.

  • Format: Expressed as a floating-point number (e.g., 0.0, 0.5, 1.0), appended to the threshold with an x.
  • Value of 0.0 (Hard Thresholding): Any wavelet coefficient below the threshold is set directly to zero, while coefficients above it remain untouched. This maximizes edge sharpness but frequently produces speckling, ringing, or blocky artifacts in smooth gradient areas like skies.
  • Values between 0.2 and 0.8 (Partial Soft Thresholding): Gradually shrinks coefficients near the threshold rather than cutting them off immediately. This is the optimal range for photographic cleanup, offering a balance between edge retention and smooth background transitions.
  • Value of 1.0 (Full Soft Thresholding): Subtracts the threshold value from all retained coefficients. This eliminates all harsh artifacts but introduces a moderate reduction in overall edge contrast.

Practical Examples

Subtle Denoising for High-Detail Photos:

magick input.jpg -wavelet-denoise 2%x0.2 output.jpg

This configuration uses a low threshold to retain micro-textures, with just enough softness to prevent edge halos.

Standard Clean-Up for Low-Light Grain:

magick input.jpg -wavelet-denoise 5%x0.5 output.jpg

This serves as a reliable baseline for images with noticeable grain in shadow regions, smoothing out mid-level noise without destroying primary edges.

Aggressive Noise Suppression:

magick input.jpg -wavelet-denoise 8%x0.75 output.jpg

Use this when dealing with severe digital sensor noise. The higher softness setting compensates for the elevated threshold by preventing banding and posterization in uniform areas.
