ImageMagick Weight Option for TrueType Fonts

When rendering typography using ImageMagick, the -weight option controls the thickness or boldness of the font's strokes. This guide explains how ImageMagick interprets this setting, how it maps to TrueType font files via font rendering engines, and what happens when configuring numeric or named weights.

How the -weight Option Works

The -weight setting instructs ImageMagick's text rendering delegates (primarily FreeType and Fontconfig) to select a specific stroke thickness from a font family. When working with TrueType (.ttf) or OpenType (.otf) fonts, the rendering engine matches your requested weight against the glyph styles available in the font.

ImageMagick accepts either named weights or standard CSS-style numeric values ranging from 100 to 900:

  • 100: Thin / Ultra Light
  • 200: Extra Light
  • 300: Light
  • 400: Normal / Regular
  • 500: Medium
  • 600: Semi Bold / Demi Bold
  • 700: Bold
  • 800: Extra Bold / Ultra Bold
  • 900: Heavy / Black

Font Selection vs. Synthetic Bolding

For standard static TrueType fonts, the -weight option acts as a selector rather than an algorithmic transformation.

  • Fontconfig Resolution: If you specify a general font family (such as -font "Roboto"), Fontconfig inspects installed fonts and picks the distinct .ttf file corresponding to the specified -weight (for example, choosing Roboto-Bold.ttf when -weight 700 is used).
  • Single File Limitation: If you specify a path directly to a specific static font file (such as -font Arial-Regular.ttf), applying -weight bold typically will not alter the stroke width. Traditional TrueType rendering does not synthesize a "faux bold" effect unless specifically supported by the configured delegate.
  • Variable TrueType Fonts: When modern variable TrueType fonts containing a wght axis are utilized, the -weight option directly manipulates the font's interpolation parameters, allowing continuous, precise control over the rendered glyph thickness.

Example Usage

To render text with a heavy stroke using a system font family:

magick -background white -fill black -font "Liberation-Sans" -weight 700 -pointsize 32 label:"Bold Headline" output.png

To render light text using a named weight:

magick -background white -fill black -font "Liberation-Sans" -weight Light -pointsize 32 label:"Light Subtitle" output.png
