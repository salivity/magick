ImageMagick Windowing Radius for Circular Kernels

In ImageMagick, the cylindrical windowing radius for circular (2D/EWA) kernels is primarily controlled using the -define filter:window-support parameter, in conjunction with -define filter:support. This guide explains how these parameters determine the radial extent and falloff of circular filters, highlights the difference between filter support and window support, and provides practical syntax for fine-tuning elliptical weighted average (EWA) resampling.

The Primary Parameters: filter:window-support and filter:support

When working with cylindrical or radially symmetric filters (such as Jinc, EWA Lanczos, or radial Gaussian kernels), ImageMagick applies a windowing function to truncate and scale the kernel smoothly.

  • -define filter:window-support=radius: Explicitly defines the radius of the windowing function itself. This setting isolates the windowing limit from the base filter’s native scale, setting the exact cylindrical boundary where the window reaches zero.
  • -define filter:support=radius: Sets the overall filter support radius. If filter:window-support is not explicitly declared, ImageMagick defaults the windowing radius to match the filter's overall support value.

Understanding Cylindrical Windowing

Linear orthogonal filters process horizontal and vertical passes separately (1D passes). Cylindrical filters, by contrast, operate in two dimensions simultaneously using Elliptical Weighted Average (EWA) resampling.

In a cylindrical filter setup, the kernel is composed of two mathematical components:

  1. The Base Filter Function (e.g., Jinc or Sinc): Provides the primary weighting across lobes.
  2. The Windowing Function (e.g., Blackman, Hann, or Jinc): Constrains the infinite lobes of the base function to a finite disc.

The filter:window-support setting controls the radial cutoff of this circular window. Adjusting this value alters how many lobes of the base function are included before the kernel drops to zero, directly impacting sharpness, ringing artifacts, and aliasing.

Syntax and Command-Line Usage

To modify the cylindrical windowing radius during an image transformation (such as -distort or -resize), use -define before applying the geometry operation.

Example: Setting Custom Window Support on a Jinc Kernel

magick input.png \
  -filter Jinc \
  -define filter:window=Blackman \
  -define filter:window-support=3.0 \
  -distort Resize 200% output.png

In this example:

  • -filter Jinc defines the primary kernel function.
  • -define filter:window=Blackman assigns the windowing function.
  • -define filter:window-support=3.0 sets the cylindrical windowing radius to 3.0 units.

Example: Overriding Filter Support vs. Window Support

If you need a wider filter range but want a steeper windowing drop-off, you can define both settings independently:

magick input.png \
  -filter Jinc \
  -define filter:support=4.0 \
  -define filter:window-support=3.0 \
  -distort Resize 200% output.png

Summary of Complementary Defines

To achieve precise control over circular kernels, use these settings together:

  • filter:window: Selects the shape of the window (e.g., Jinc, Cosine, Hanning, Blackman).
  • filter:window-support: Sets the specific radius limit of the window.
  • filter:support: Sets the default radius of the filter calculation if window-support is omitted.
  • filter:blur: Scales the radius along the radial axis without changing the mathematical definition of the support limit.
