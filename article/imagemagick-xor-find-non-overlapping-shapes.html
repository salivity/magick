ImageMagick XOR: Find Non-Overlapping Shapes

This guide explains how to use the Xor compositing operator in ImageMagick to isolate and extract non-overlapping regions between two shapes. By applying exclusive-OR logic to the alpha channels of two images, ImageMagick removes the intersecting areas while preserving only the unique, non-overlapping parts of each shape. Below, you will find the direct command-line syntax, practical examples using alpha channels, and guidance on working with binary masks.

Understanding the XOR Composite Operation

In digital image compositing, the Xor operator follows standard boolean exclusive-OR rules applied primarily to the alpha (transparency) channels.

  • If an area is transparent in both images, it remains transparent.
  • If an area is opaque in only one image, it remains fully opaque.
  • If an area is opaque in both images (the overlap), it becomes completely transparent.

This makes Xor the ideal operator for isolating differences in shape silhouettes.

Basic Syntax for Images with Transparency

For standard images containing opaque shapes on transparent backgrounds, use the -compose Xor -composite syntax.

magick shape1.png shape2.png -compose Xor -composite non_overlapping_result.png

In this command:

  1. shape1.png serves as the destination image.
  2. shape2.png serves as the source image layered on top.
  3. -compose Xor defines the compositing method.
  4. -composite executes the operation and outputs the non-overlapping segments.

Step-by-Step Example

To demonstrate this behavior directly, you can generate two overlapping circles and extract their non-overlapping parts:

# 1. Create a 300x300 image with a blue circle on the left
magick -size 300x300 xc:none -fill blue -draw "circle 120,150 70,150" circle_left.png

# 2. Create a 300x300 image with a red circle on the right
magick -size 300x300 xc:none -fill red -draw "circle 180,150 230,150" circle_right.png

# 3. Composite using XOR to show only non-overlapping regions
magick circle_left.png circle_right.png -compose Xor -composite xor_result.png

In xor_result.png, the intersection where the two circles meet will be cut out to complete transparency, leaving behind only the outer crescents.

Handling Black-and-White Binary Masks

If your shapes are black-and-white silhouettes without an alpha channel (white shapes on a black background), the standard alpha-based Xor composite will treat the entire image as opaque. To find non-overlapping areas on grayscale masks, use the Difference compose mode instead:

magick mask1.png mask2.png -compose Difference -composite mask_non_overlap.png

The Difference mode subtracts overlapping white pixels (\(1 - 1 = 0\), resulting in black) and preserves regions that appear white in only one image (\(1 - 0 = 1\) or \(0 - 1 = |-1| = 1\), resulting in white).
