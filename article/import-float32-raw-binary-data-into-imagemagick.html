Import Float32 Raw Binary Data into ImageMagick

Importing raw 32-bit floating-point (float32) binary pixel streams into ImageMagick requires explicitly specifying image geometry, color components, and data representation before defining the input source. Because raw binary files lack header metadata, you must supply parameters such as dimensions, byte order, pixel format, and floating-point flags directly in your command to interpret the stream accurately.

Essential Flags and Parameters

To read raw float32 data, ImageMagick relies on several configuration flags placed before the input file or stream identifier:

  • -size WIDTHxHEIGHT: Defines the resolution of the input buffer (e.g., -size 1920x1080).
  • -depth 32: Specifies the bit depth per channel (32 bits = 4 bytes per channel).
  • -define quantum:format=floating-point: Instructs the decoder to parse the binary payload as IEEE 754 floating-point values rather than standard integers.
  • -endian [msb|lsb]: Sets the byte order. Most modern systems use Little-Endian (lsb).
  • Channel Format Specifiers: Prepend the file path or standard input indicator with the layout format, such as gray:, rgb:, or rgba:.

Importing from a Binary File

Grayscale (1 Channel)

To convert a single-channel float32 binary file named input.raw with dimensions of 512x512 into a standard PNG:

magick -size 512x512 -depth 32 -endian lsb -define quantum:format=floating-point gray:input.raw output.png

RGB (3 Channels)

For an interleaved 3-channel (Red, Green, Blue) float32 file:

magick -size 1920x1080 -depth 32 -endian lsb -define quantum:format=floating-point rgb:input.raw output.exr

RGBA (4 Channels)

For a 4-channel image containing an alpha channel:

magick -size 1024x1024 -depth 32 -endian lsb -define quantum:format=floating-point rgba:input.raw output.tiff

Piping from a Binary Stream (Standard Input)

If the pixel stream is generated dynamically from another process, pipe the output into standard input using - prefixed with the channel format:

cat stream.bin | magick -size 800x600 -depth 32 -endian lsb -define quantum:format=floating-point rgb:- output.png

Value Range and Normalization

  • Standard Range: ImageMagick expects normalized floating-point data where values range from 0.0 (black) to 1.0 (white).
  • Arbitrary Ranges (HDR/Scientific Data): If your stream contains values outside the [0.0, 1.0] range, use the -auto-level operator after reading the input to stretch values across the dynamic range, or apply -evaluate multiply / -evaluate add to rescale the values manually.
  • HDRI Build: Ensure your installed version of ImageMagick was compiled with High Dynamic Range Imaging (HDRI) enabled (standard in modern ImageMagick 7 installations), which you can verify by running magick -version and checking for HDRI in the features list.
