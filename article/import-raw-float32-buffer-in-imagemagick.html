Import Raw Float32 Buffer in ImageMagick

This guide demonstrates how to import a raw binary 32-bit floating-point (float32) buffer into ImageMagick using the command-line interface. You will learn the exact flags required to define image dimensions, endianness, pixel format, and channel layout so that ImageMagick correctly interprets the raw memory stream and outputs a standard image format.

The Import Command

To import a raw binary float32 buffer, you must explicitly declare the data type, dimensions, and color format because raw binary files contain no metadata headers.

Grayscale (Single-Channel) Command

magick -size 1920x1080 -depth 32 -define quantum:format=floating-point -endian LSB gray:buffer.raw output.png

Color (RGB / RGBA) Command

For a multi-channel buffer such as RGB or RGBA, change the format prefix:

magick -size 1920x1080 -depth 32 -define quantum:format=floating-point -endian LSB rgb:buffer.raw output.png

For RGBA data, replace rgb: with rgba:.

Reading Directly from Standard Input (stdin)

If you are piping raw binary data directly from another application or script:

cat buffer.raw | magick -size 1920x1080 -depth 32 -define quantum:format=floating-point -endian LSB gray:- output.png

Parameter Breakdown

  • -size <width>x<height>: Specifies the resolution of the image buffer.
  • -depth 32: Sets the bit depth to 32 bits per channel.
  • -define quantum:format=floating-point: Instructs ImageMagick to interpret the 32-bit values as IEEE 754 floating-point numbers rather than standard integers.
  • -endian LSB: Defines byte ordering. Use LSB (Least Significant Byte) for Little-Endian systems (standard on x86/ARM) or MSB for Big-Endian.
  • gray:, rgb:, rgba:: Tells ImageMagick the layout of the color channels in the raw data stream.
  • - (in gray:-): Denotes reading the stream from standard input instead of a physical file.
