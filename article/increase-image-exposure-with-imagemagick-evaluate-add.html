Increase Image Exposure with ImageMagick Evaluate Add

Adjusting image exposure is a common post-processing task, and ImageMagick provides a direct way to brighten images through the -evaluate Add operator. This guide explains how to use the command, how it alters pixel data across color channels, and the exact syntax required to achieve predictable exposure increases without unnecessary complexity.

Understanding the Evaluate Add Operator

The -evaluate operator in ImageMagick applies an arithmetic, relational, or logical expression to every pixel in an image. When paired with the Add method, it performs a linear offset by adding a specified numerical value directly to each color channel's intensity.

Adding a fixed value shifts the entire image histogram to the right. This brightens shadows, midtones, and highlights uniformly. Any pixel value that exceeds the maximum limit (such as pure white) automatically clips at the maximum quantum range.

Basic Syntax

To raise overall exposure across all color channels, use the following syntax with ImageMagick version 7:

magick input.jpg -evaluate Add 10% output.jpg

For ImageMagick version 6, replace magick with convert:

convert input.jpg -evaluate Add 10% output.jpg

Specifying Values: Percentages vs. Raw Quantum Values

You can specify the value to add in two ways:

  1. Percentage (Recommended): Using a percent sign (e.g., 10% or 15%) makes your command independent of the ImageMagick build's quantum depth (Q8, Q16, or Q32). A value of 10% adds 10% of the maximum luminance to every pixel.
  2. Absolute Integer Values: If omitted, ImageMagick assumes raw quantum integers. For example, in a standard Q16 build where pixel values range from 0 to 65535, adding 6553 is roughly equivalent to a 10% brightness increase. Using percentages avoids having to calculate values based on the active quantum depth.

Restricting Exposure to Specific Channels

By default, modern ImageMagick versions apply the evaluation to all color channels while preserving transparency. If you need to explicitly restrict the operation to the red, green, and blue channels without affecting an alpha channel, define the active channel target:

magick input.png -channel RGB -evaluate Add 15% +channel output.png

The +channel switch resets the channel mask to default values for any subsequent operations in the pipeline.

Considerations When Using Add vs. Multiply

While -evaluate Add raises overall brightness, it works as a linear pedestal shift. This means black pixels (0) will become lightened (e.g., to 10% gray), potentially reducing contrast in deep shadows.

If you want an exposure adjustment that mimics a camera's exposure value (EV) stops—where absolute black remains black and midtones/highlights scale proportionally—consider whether -evaluate Multiply or -modulate better fits your needs. Use -evaluate Add primarily when shadows need a direct lift or when lifting an underexposed flat scene.
