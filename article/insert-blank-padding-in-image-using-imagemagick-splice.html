Insert Blank Padding in Image Using ImageMagick Splice

This guide explains how to use the ImageMagick -splice command to insert blank padding directly into the middle of an existing image. You will learn the exact command syntax, how to control the dimensions and background color of the inserted space, and how to use gravity and coordinate offsets to position the padding precisely where you need it.

Understanding the -splice Command

The -splice operator cuts an image at a specified location and inserts a blank area using the current background color. The basic syntax requires setting the background color, the gravity or coordinate offset, and the dimensions of the gap you want to insert.

magick input.png -background white -gravity <Direction> -splice <Width>x<Height> output.png

(Note: In ImageMagick version 6, replace magick with convert.)

Inserting Padding Across the Exact Center

The easiest way to insert padding in the middle of an image is to set -gravity Center.

1. Insert a Horizontal Blank Strip Across the Middle

To add a 50-pixel horizontal blank gap across the vertical center of an image:

magick input.png -background white -gravity Center -splice 0x50 output.png
  • 0x50 specifies a width increase of 0 pixels and a height increase of 50 pixels.
  • -gravity Center ensures the height is added directly in the vertical middle.

2. Insert a Vertical Blank Strip Down the Middle

To add a 40-pixel vertical gap splitting the left and right halves:

magick input.png -background white -gravity Center -splice 40x0 output.png
  • 40x0 creates a 40-pixel wide column without adding any extra height.

3. Insert Both Horizontal and Vertical Padding (Cross Shape)

To add both horizontal and vertical padding simultaneously:

magick input.png -background white -gravity Center -splice 40x50 output.png

Inserting Padding at Specific Pixel Coordinates

If you need the padding at a specific offset rather than the exact geometric center, use coordinate offsets with -gravity NorthWest (the default coordinate system starting from the top-left corner).

The geometry format for offset splicing is WIDTHxHEIGHT+X+Y:

  • Insert a 60px horizontal gap at Y-coordinate 300:

    magick input.png -background "#ECECEC" -gravity NorthWest -splice 0x60+0+300 output.png

  • Insert an 80px vertical gap at X-coordinate 450:

    magick input.png -background transparent -gravity NorthWest -splice 80x0+450+0 output.png

Setting Background Color and Transparency

The inserted padding adopts whatever color is defined by the -background setting immediately preceding the -splice command.

  • Use named colors: -background white, -background black, -background red
  • Use hex codes: -background "#1a1a1a"
  • Use transparency (for PNG/TIFF/WEBP): -background none or -background transparent
