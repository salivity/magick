Insert Frame into Multi-Frame TIFF ImageMagick

This guide explains how to insert a single new frame into an existing multi-frame TIFF file using ImageMagick. By using ImageMagick's built-in image sequence operators, you can place a new image at the beginning, end, or any specific position within an existing multi-page document without degrading image quality or needing complex scripts.

The Basic Command Structure

ImageMagick treats multi-frame TIFF files as a zero-indexed sequence of images (0 is the first frame, 1 is the second frame, and so on). When you load the existing multi-frame TIFF and then load the new single image, the new image is initially placed at the end of the sequence. You can use the -insert operator to move that last image to any index position you choose.

ImageMagick v7 Syntax

magick existing.tif new_frame.tif -insert INDEX output.tif

ImageMagick v6 Syntax

convert existing.tif new_frame.tif -insert INDEX output.tif

Examples by Position

1. Insert at the Beginning (Prepend as the First Page)

To place new_frame.tif as page 1 (index 0):

magick existing.tif new_frame.tif -insert 0 output.tif

2. Insert into a Specific Position in the Middle

To insert new_frame.tif so that it becomes the third page (index 2):

magick existing.tif new_frame.tif -insert 2 output.tif

All existing frames from index 2 onward will automatically shift down by one position.

3. Append to the End (Last Page)

If you simply want to add the single frame to the very end of the file, you do not need the -insert operator:

magick existing.tif new_frame.tif output.tif

Overwriting the Original File

To overwrite your source multi-frame TIFF directly, use the same filename as both input and output:

magick existing.tif new_frame.tif -insert 1 existing.tif

Note: It is recommended to create a backup of your original TIFF before running destructive in-place modifications.
