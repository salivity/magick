Inspect Image Metadata With ImageMagick Identify

ImageMagick provides a dedicated command-line utility called identify designed specifically to inspect and extract image metadata without altering the source files. This guide covers how the identify tool works, its primary command syntax, and practical examples for extracting detailed file properties, EXIF data, and custom metadata fields safely and efficiently.

The identify Command

The identify tool describes the format and characteristics of one or more image files. It operates strictly in read-only mode, guaranteeing that file contents and timestamps remain untouched during inspection.

  • For ImageMagick v6, use: identify
  • For ImageMagick v7, use: magick identify

Basic Metadata Inspection

To retrieve basic information about an image (format, dimensions, color depth, and file size), run the command followed by the filename:

identify photo.jpg

Example Output:

photo.jpg JPEG 4032x3024 4032x3024+0+0 8-bit sRGB 2.85MB 0.000u 0.000s

Viewing Detailed Metadata with -verbose

To view all available metadata—including EXIF data, color profiles, compression details, geometry, and embedded color palettes—add the -verbose flag:

identify -verbose photo.jpg

This generates a comprehensive, structured report covering:

  • Image Geometry: Width, height, aspect ratio, and resolution (DPI).
  • Color Properties: Colorspace, color depth, channel statistics, and gamma.
  • EXIF Profiles: Camera make, model, exposure time, aperture, ISO, and GPS coordinates (if present).
  • File Properties: MIME type, compression type, and creation date.

Extracting Specific Properties with -format

The -format option allows you to query specific attributes using format specifiers, making it ideal for scripting and automation.

Get Image Dimensions (Width x Height)

identify -format "%w x %h\n" photo.jpg

Get Image Format and Colorspace

identify -format "%m: %r\n" photo.jpg

Extract Camera Make and Model

identify -format "%[EXIF:Make] %[EXIF:Model]\n" photo.jpg

Common Format Specifiers

Specifier Description
%w Image width in pixels
%h Image height in pixels
%m Image file format (e.g., JPEG, PNG)
%z Image depth (e.g., 8-bit)
%r Image class and colorspace
%b File size in human-readable units
%[EXIF:*] Access specific EXIF metadata tags

Inspecting Multiple Images

The identify command accepts wildcards to process entire directories at once:

identify *.png

To output the filename and dimensions for all PNG files in a folder:

identify -format "%f: %wx%h\n" *.png
