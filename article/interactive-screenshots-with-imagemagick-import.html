Interactive Screenshots with ImageMagick Import

This guide explains how to capture interactive screenshots on a Unix or Linux desktop using the import command from the ImageMagick suite. You will learn the basic command syntax to select windows or draw custom capture regions, capture window decorations, add execution delays, and save outputs in various image formats directly from the command line.

Prerequisites

Ensure ImageMagick is installed on your Unix/Linux system running the X11 display server. On Debian/Ubuntu-based systems, install it via:

sudo apt-get install imagemagick

On Fedora or RHEL:

sudo dnf install ImageMagick

Basic Interactive Capture

The import tool enters interactive mode by default when you specify an output filename without defining a root window or specific coordinates.

Run the following command:

import screenshot.png

Your cursor will transform into a crosshair. You have two interactive choices:

  1. Capture a Window: Left-click anywhere inside an application window to capture only that window.
  2. Capture a Custom Region: Click and drag a rectangle over the desired area of the screen, then release the mouse button.

Including Window Borders and Title Bars

By default, clicking a window captures only the client area, excluding the window manager's title bar and borders. To include the window frame:

import -frame window_with_border.png

Click the target window, and the output will contain the full window including title bars and borders.

Adding a Delay for Menu and Hover Captures

To capture tooltips, context menus, or drop-down menus, add a time delay using the sleep command. This gives you time to open the menu before the interactive cursor appears:

sleep 3 && import menu_capture.png

Alternatively, use ImageMagick's built-in -pause flag (specified in seconds):

import -pause 3 tooltip.png

Output Formats and Quality Adjustments

The import command automatically determines the output format from the file extension. You can control compression and quality using the -quality flag:

  • PNG (Lossless compression level from 0 to 9):

    import -quality 9 capture.png

  • JPEG (Quality scale from 1 to 100):

    import -quality 85 capture.jpg
