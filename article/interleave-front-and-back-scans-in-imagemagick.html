Interleave Front and Back Scans in ImageMagick

This article provides the exact ImageMagick commands and syntax required to combine alternating front and back scanned pages into a single, correctly ordered document. Whether dealing with separate image files or multi-page PDFs where the back pages were scanned in reverse order, these methods ensure your document is reassembled seamlessly.

Interleaving Individual Image Files

When scanning two-sided documents through a simplex (single-sided) feeder, the front sides are typically saved in sequential order (front-01.jpg, front-02.jpg, etc.), while the back sides are fed in reverse order (back-01.jpg, back-02.jpg, etc., where back-01 corresponds to the last front page).

You can use standard shell expansion alongside ImageMagick to interleave the forward and reversed lists directly into a single PDF:

magick $(paste -d' ' <(ls -v front-*.jpg) <(ls -vr back-*.jpg)) output.pdf

Explanation of Arguments:

  • ls -v front-*.jpg: Lists front page files sorted by natural version number.
  • ls -vr back-*.jpg: Lists back page files in reverse numerical order.
  • paste -d' ': Interleaves the two lists line-by-line, separated by spaces.
  • magick ... output.pdf: Reads the interleaved file list and outputs a multi-page PDF.

Interleaving Multi-Page PDFs (Fronts and Backs)

If your scanner generates two distinct multi-page PDFs—one containing all odd pages (odds.pdf) and one containing all even pages in reverse order (evens_reversed.pdf)—use the following syntax:

magick ( odds.pdf ) ( evens_reversed.pdf -reverse ) -write mpr:pages +delete \
  -script <(
    num=$(magick identify -format "%n\n" odds.pdf | head -n 1)
    for ((i=0; i<num; i++)); do
      echo "-read mpr:pages[$i]"
      echo "-read mpr:pages[$((num + i))]"
    done
    echo "-write output.pdf"
  )

For systems where back scans were scanned in normal order instead of reverse, omit the -reverse flag inside the second set of parentheses.

Direct Command for Known Page Counts

For smaller documents with a known number of pages (for example, 3 sheets / 6 total pages), you can reference and rearrange the image stack explicitly within ImageMagick using index positions:

magick odds.pdf ( evens_reversed.pdf -reverse ) \
  -insert 1 \
  -swap 3,4 \
  output.pdf

To optimize the output quality and ensure uniform document sizing, append density and compression parameters to the command:

magick -density 300 -compress jpeg -quality 85 $(paste -d' ' <(ls -v front-*.jpg) <(ls -vr back-*.jpg)) output.pdf
