Interleave Scanned Pages with ImageMagick Montage

This guide demonstrates how to interleave separate front and back scanned pages into a single, correctly ordered document using ImageMagick's montage command. You will find the exact command-line syntax for merging sequentially named files, managing reverse-order back scans from document feeders, and controlling output layout and geometry.

Basic Syntax for Interleaving

To interleave front and back page images and save them as a single multi-page PDF where each page appears in sequence, use montage with -tile 1x1 and -geometry +0+0:

montage front_01.png back_01.png front_02.png back_02.png -tile 1x1 -geometry +0+0 output.pdf

Key Parameters:

  • -tile 1x1: Places one image per page/frame instead of creating a grid.
  • -geometry +0+0: Preserves the original image size and removes the default montage borders and spacing.

Automating Sequential Interleaving (Bash)

When dealing with a large batch of sequentially numbered front (front_01.png, front_02.png) and back (back_01.png, back_02.png) scans, generate the interleaved list automatically using shell expansion:

montage $(for f in front_*.png; do echo "$f ${f/front_/back_}"; done) -tile 1x1 -geometry +0+0 interleaved_output.pdf

Interleaving with Reversed Back Scans

Automatic Document Feeders (ADFs) that lack duplex scanning typically scan all front sides in ascending order and all back sides in descending order (e.g., front_01.png to front_10.png and back_10.png down to back_01.png).

To interleave ascending fronts with descending backs:

fronts=( $(ls -v front_*.png) )
backs=( $(ls -vr back_*.png) )

interleaved=()
for ((i=0; i<${#fronts[@]}; i++)); do
    interleaved+=("${fronts[i]}" "${backs[i]}")
done

montage "${interleaved[@]}" -tile 1x1 -geometry +0+0 output.pdf

Placing Front and Back Pages Side-by-Side

If you want front and back pages placed side-by-side on a single page spread rather than sequential pages:

montage front_01.png back_01.png front_02.png back_02.png -tile 2x1 -geometry +0+0 spread_output.pdf
  • -tile 2x1: Arranges two images per row (front on the left, back on the right) before starting a new page.
