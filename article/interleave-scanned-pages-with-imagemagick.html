Interleave Scanned Pages with ImageMagick

This article provides the exact ImageMagick syntax required to collate and interleave alternating front and back page scans into a single properly ordered document. When using manual duplex scanning or automatic document feeders (ADFs) without duplex hardware, scans are typically produced as separate sets of front (odd) and back (even) pages. The instructions below cover command syntax for both individual image files and multi-page scan formats.

Syntax for Individual Image Files

When your front pages (front-01.jpg, front-02.jpg, ...) and back pages (back-01.jpg, back-02.jpg, ...) are stored as separate image files, use shell expansion alongside the magick command (or convert in ImageMagick v6).

Scenario A: Back Pages Are in Normal Order (1, 2, 3...)

If both sets of scans are in ascending order (Front 1, Back 1, Front 2, Back 2...):

magick $(for i in $(seq -w 1 10); do echo "front-$i.jpg back-$i.jpg"; done) output.pdf

Scenario B: Back Pages Are in Reverse Order (10, 9, 8...)

Most sheet-fed document scanners output back pages in reverse order when the entire stack is flipped over. You can reverse the order of the back pages before interleaving:

magick $(paste -d ' ' <(ls front-*.jpg | sort -V) <(ls back-*.jpg | sort -Vr)) output.pdf

Syntax for Multi-Page Files (PDF/TIFF)

If you have two separate multi-page files (fronts.pdf and backs.pdf), ImageMagick cannot natively interleave two PDF streams with a single flag, but you can extract and assemble them dynamically using the command line:

1. Forward Fronts and Forward Backs

magick $(for i in $(seq 0 9); do echo "fronts.pdf[$i] backs.pdf[$i]"; done) output.pdf

2. Forward Fronts and Reversed Backs

If backs.pdf contains 10 pages scanned in reverse order (pages indexed from 0 to 9):

magick $(for i in $(seq 0 9); do echo "fronts.pdf[$i] backs.pdf[$((9 - i))]"; done) output.pdf

Key Parameter Breakdown

  • magick: Invokes ImageMagick v7. Replace with convert if using ImageMagick v6.
  • [N]: The frame/page index syntax (zero-indexed) used by ImageMagick to select specific pages from multi-page formats.
  • sort -V and sort -Vr: Performs a natural version sort in ascending and descending (reverse) order respectively, ensuring page-10.jpg follows page-9.jpg rather than page-1.jpg.
  • output.pdf: The target multi-page file where all interleaved frames are compiled.
