Invert 1-Bit TIFF to Mask in ImageMagick

Converting a 1-bit bilevel TIFF into an inverted monochrome mask in ImageMagick is a straightforward operation achieved primarily through the -negate operator. This article details the exact command-line syntax required for both ImageMagick v7 and v6, breaks down the essential parameters to ensure the output retains its 1-bit binary depth, and covers how to verify the resulting mask.

The Command

To invert a 1-bit TIFF so that white becomes black and black becomes white while keeping the output as a strict monochrome mask, use the following command:

ImageMagick v7:

magick input.tif -negate -depth 1 -type bilevel output_mask.tif

ImageMagick v6:

convert input.tif -negate -depth 1 -type bilevel output_mask.tif

Parameter Breakdown

  • input.tif: Specifies the source 1-bit bilevel TIFF file.
  • -negate: Inverts every pixel value in the image. Black pixels (value 0) become white (value 1), and white pixels become black.
  • -depth 1: Forces the output color depth to remain 1-bit per channel, preventing ImageMagick from promoting the image to an 8-bit or 16-bit grayscale file.
  • -type bilevel: Ensures the image format is explicitly categorized as a two-color monochrome image (black and white only) without anti-aliasing or intermediate gray values.
  • output_mask.tif: The destination file name for the generated mask. You can also output to other mask-supported formats such as PNG.

Inverting with an Alpha Channel

If the source TIFF contains transparency or an alpha channel that needs to be preserved or inverted as part of the mask, use -channel controls:

magick input.tif -channel RGB -negate +channel -depth 1 -type bilevel output_mask.tif

Using -channel RGB restricts the inversion exclusively to the color data, leaving any existing alpha channel intact.

Verifying the Output

To confirm that the output file remains a true 1-bit bilevel image rather than a standard grayscale image, run the identify tool:

magick identify -verbose output_mask.tif

Look for the following properties in the output text:

  • Depth: 1-bit
  • Type: Bilevel
  • Colors: 2
