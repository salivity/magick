Invert Specific Bit Planes in ImageMagick

This article provides a direct guide on how to invert specific bit planes within an image using ImageMagick's bitwise evaluation tools. By applying an exclusive OR (XOR) operation with targeted binary masks, you can invert individual bit layers—ranging from the least significant bit (LSB) to the most significant bit (MSB)—across all color channels or within a single channel.

Understanding Bit Plane Values

In an 8-bit grayscale or color channel, each pixel is represented by an integer from 0 to 255 composed of 8 bits. Inverting a bit plane requires flipping a specific bit from 0 to 1, or 1 to 0. This is achieved using the bitwise XOR operator against a specific integer value corresponding to that bit's power of two:

  • Bit 0 (LSB): \(2^0 = 1\)
  • Bit 1: \(2^1 = 2\)
  • Bit 2: \(2^2 = 4\)
  • Bit 3: \(2^3 = 8\)
  • Bit 4: \(2^4 = 16\)
  • Bit 5: \(2^5 = 32\)
  • Bit 6: \(2^6 = 64\)
  • Bit 7 (MSB): \(2^7 = 128\)

The Basic Command Structure

ImageMagick uses the -evaluate xor operator to perform bitwise XOR operations on pixel values.

For standard 8-bit installations (Q8):

magick input.png -evaluate xor <BitValue> output.png

For example, to invert the most significant bit (Bit 7), use 128:

magick input.png -evaluate xor 128 output.png

To invert the least significant bit (Bit 0):

magick input.png -evaluate xor 1 output.png

Handling ImageMagick Q16 Builds

Most modern ImageMagick installations use a 16-bit quantum depth (Q16), meaning pixels are internally processed on a 0 to 65535 scale rather than 0 to 255.

If your build is Q16 (check using magick -version), 8-bit values are shifted left by 8 bits (multiplied by 256). To target an 8-bit plane in a Q16 build, adjust the mask values accordingly:

  • Bit 0 (LSB of an 8-bit file): \(1 \times 256 = 256\)
  • Bit 1: \(2 \times 256 = 512\)
  • Bit 2: \(4 \times 256 = 1024\)
  • Bit 3: \(8 \times 256 = 2048\)
  • Bit 4: \(16 \times 256 = 4096\)
  • Bit 5: \(32 \times 256 = 8192\)
  • Bit 6: \(64 \times 256 = 16384\)
  • Bit 7 (MSB of an 8-bit file): \(128 \times 256 = 32768\)

To invert the MSB of an 8-bit image using ImageMagick Q16:

magick input.png -evaluate xor 32768 output.png

Inverting Multiple Bit Planes

To invert multiple bit planes at once, calculate the sum of their corresponding values.

For example, to invert both Bit 6 (\(64\)) and Bit 7 (\(128\)) on a Q8 build: \(64 + 128 = 192\)

magick input.png -evaluate xor 192 output.png

For a Q16 build, multiply the total by 256 (\(192 \times 256 = 49152\)):

magick input.png -evaluate xor 49152 output.png

Inverting Bit Planes in Specific Channels

By default, -evaluate applies to all active color channels. To isolate the inversion to a specific channel (such as Red, Green, or Blue), use the -channel option, and reset it afterward with +channel.

To invert Bit 7 only in the Red channel (Q8 build):

magick input.png -channel R -evaluate xor 128 +channel output.png

To invert Bit 7 only in the Red channel (Q16 build):

magick input.png -channel R -evaluate xor 32768 +channel output.png
