Invisible High Frequency Watermark in ImageMagick

This guide demonstrates how to embed an imperceptible, high-frequency digital watermark into an image using ImageMagick. By taking advantage of the human visual system's low sensitivity to high-frequency spatial variations, you can embed identifiable text or logos directly into the fine noise or edge spectrum of an image. The resulting watermark remains invisible under standard viewing conditions but can be easily verified using high-pass filtering or contrast normalization.

Understanding High-Frequency Watermarking

Digital images consist of low frequencies (smooth gradients, large shapes) and high frequencies (fine textures, sharp edges, and sensor noise). Embedding data into low frequencies causes noticeable color or brightness shifts. In contrast, embedding data into high frequencies blends the watermark into microscopic surface variations, ensuring complete invisibility while maintaining survivability against minor color adjustments.

Step 1: Generate the Watermark Pattern

First, create a high-contrast binary source image containing the text or logo you want to embed. The dimensions should match your base image.

magick -size 1920x1080 xc:black -fill white -gravity center -pointsize 72 -annotate 0 "CONFIDENTIAL" watermark_raw.png

Step 2: Convert the Watermark to a High-Frequency Layer

To prevent hard edges that the eye could detect, turn the watermark into a subtle, high-frequency pattern. This is achieved by creating an edge-detected or difference-of-gaussians (DoG) layer centered on a neutral 50% gray base.

magick watermark_raw.png -morphology Edge Diamond -evaluate divide 20 -bias 50% watermark_hf.png

This step produces an image where the watermark outlines exist as minuscule deviations around mid-gray, ready for frequency modulation.

Step 3: Embed the Watermark into the Target Image

To apply the high-frequency watermark invisibly, combine it with the source image using the SoftLight or Overlay composition operators at a strongly attenuated intensity.

magick source.png watermark_hf.png -compose SoftLight -composite watermarked_output.png

Alternatively, you can add the high-frequency values directly into the color values using mathematics:

magick source.png \( watermark_raw.png -morphology Edge Diamond -evaluate divide 100 \) -compose Plus -composite watermarked_output.png

Dividing the high-frequency mask by a large factor (such as 100 or 150) shifts the pixel brightness by only 1–2 levels in an 8-bit image channel, rendering it mathematically present but completely imperceptible.

Step 4: Extract and Verify the Invisible Watermark

Because the watermark is embedded as a persistent high-frequency pattern, it can be extracted without requiring the original base image. Applying an edge detection filter followed by extreme contrast stretching reveals the hidden signature:

magick watermarked_output.png -colorspace Gray -morphology Edge Diamond -auto-level revealed_watermark.png

If the original unaltered source image is available, a simple differential subtraction provides an even clearer verification:

magick compare -compose src watermarked_output.png source.png -highlight-color red -lowlight-color black difference.png
