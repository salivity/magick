Invisible Luminance Watermark in ImageMagick fx

This guide explains how to embed an imperceptible luminance watermark into an image using ImageMagick's -fx operator. By shifting the image into a colorspace that isolates brightness from color data, you can subtly modify the luminance channel to hide text or a logo. Below is the precise command syntax, an explanation of each component, and the method for revealing the embedded watermark.

Embedding Syntax

To inject an invisible watermark, run the following ImageMagick command:

magick input.png watermark.png -colorspace YCbCr -channel 0 -fx "u + (v - 0.5) * 0.02" +channel -colorspace sRGB output.png

If you are using ImageMagick version 6, replace magick with convert.

Syntax Breakdown

  • input.png watermark.png: Loads the host image as the first image (u) and the watermark pattern as the second image (v). The watermark image should match the dimensions of the host image or be tiled to fit.
  • -colorspace YCbCr: Converts the color model so that channel 0 represents pure luminance (\(Y\)), while channels 1 and 2 represent chrominance (\(Cb\) and \(Cr\)).
  • -channel 0: Restricts all subsequent operations exclusively to the luminance channel, leaving color channels untouched.
  • -fx "u + (v - 0.5) * 0.02": The mathematical expression applied to every pixel in the targeted channel:
    • u: The current luminance value of the source image (scaled from 0.0 to 1.0).
    • v: The corresponding pixel value of the watermark image.
    • (v - 0.5): Centers the watermark values so neutral gray causes zero change, whites slightly brighten the source, and blacks slightly darken it.
    • * 0.02: The scaling factor (modulation strength). A value between 0.01 and 0.03 is typically invisible to the human eye under normal viewing conditions.
  • +channel: Resets the channel mask so following operations affect all channels.
  • -colorspace sRGB: Converts the altered image data back to standard sRGB for normal display and export.

Extracting and Revealing the Watermark

Because the modification is imperceptible to the naked eye, revealing the hidden watermark requires isolating the luminance channel and amplifying the difference between the watermarked image and the original:

magick output.png input.png -colorspace YCbCr -channel 0 -fx "abs(u - v) * 50" -separate recovered.png

This calculates the absolute difference between the luminance of the watermarked image and the original image, then multiplies the result by 50 to make the hidden watermark clearly visible as a high-contrast grayscale image.
