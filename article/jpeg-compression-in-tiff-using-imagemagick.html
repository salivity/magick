JPEG Compression in TIFF Using ImageMagick

Configuring JPEG compression inside a TIFF container allows you to leverage the smaller file sizes typical of JPEG images while retaining the multi-page, metadata, and container benefits of the TIFF specification. This guide explains how to use ImageMagick from the command line to wrap JPEG-compressed image data into a .tif file, adjust compression quality, and ensure maximum viewer compatibility.

Basic Conversion Command

To convert an image to a TIFF file using JPEG compression, use the standard magick command (ImageMagick v7) or convert (ImageMagick v6) paired with the -compress operator:

magick input.png -compress JPEG output.tif

This command reads input.png, applies standard JPEG compression algorithms to the pixel data, and encapsulates that stream within the TIFF container format.

Adjusting the Compression Quality

By default, ImageMagick will apply an internal default quality level if none is specified. You can manually adjust the compression ratio and visual fidelity using the -quality flag, which accepts an integer value between 1 (lowest quality, smallest file size) and 100 (highest quality, largest file size):

magick input.png -compress JPEG -quality 85 output.tif

A quality setting between 75 and 85 is generally recommended to achieve significant file size reduction without noticeable artifacting.

Managing Color Spaces and Viewer Compatibility

A common issue with JPEG-compressed TIFF files is incompatible color space rendering in legacy software. Standard JPEG compression typically operates in the YCbCr color space, while TIFFs traditionally expect RGB data.

To ensure broad software compatibility, define the photometric interpretation explicitly:

For Standard RGB (safest for older TIFF readers):

magick input.png -compress JPEG -quality 85 -define tiff:photometric=rgb output.tif

For YCbCr (maximum compression efficiency):

magick input.png -compress JPEG -quality 85 -define tiff:photometric=ycbcr output.tif

Converting Multi-Page Documents

If you are working with multi-page documents (such as PDF files or existing multi-frame TIFFs), ImageMagick applies JPEG compression to every frame in the sequence automatically:

magick input.pdf -compress JPEG -quality 80 -define tiff:photometric=ycbcr output.tif

Verifying the Output

To verify that the compression was applied properly and check the underlying parameters of the output file, use the identify utility:

magick identify -format "Compression: %[compression]\nQuality: %[quality]\n" output.tif

The output should confirm Compression: JPEG alongside your defined quality metric.
