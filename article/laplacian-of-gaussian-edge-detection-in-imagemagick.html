Laplacian of Gaussian Edge Detection in ImageMagick

This article explains how to implement a Laplacian of Gaussian (LoG) edge detector using ImageMagick command-line tools. You will learn the exact command syntax, how the kernel parameters function, and how to properly scale output values to visualize detected edges effectively.

The ImageMagick LoG Command

In modern ImageMagick (version 7), the standard command to apply a Laplacian of Gaussian convolution is:

magick input.png -define convolve:scale='!' -morphology Convolve LoG:0,1.5 output.png

For legacy ImageMagick (version 6), replace magick with convert:

convert input.png -define convolve:scale='!' -morphology Convolve LoG:0,1.5 output.png

Parameter Breakdown

  • -morphology Convolve LoG:radius,sigma: Instructs ImageMagick to generate and convolve a Laplacian of Gaussian kernel.
    • radius: The physical pixel radius of the convolution matrix. Setting this to 0 allows ImageMagick to compute the appropriate radius automatically based on the sigma value.
    • sigma: The standard deviation of the Gaussian smoothing filter. Larger sigma values detect broader, coarser edges, while smaller values (e.g., 0.5 to 2.0) detect fine, detailed edges.
  • -define convolve:scale='!': Normalizes the kernel weights so that the convolution results fit properly within the dynamic range of the image format, preventing data clipping.

Visualizing Zero-Crossings and Edges

The LoG operator produces both positive and negative values. By default, negative values may be clipped to pure black. To produce a standard visual edge map where edges appear as high-intensity lines on a black background, take the absolute value of the convolved result:

magick input.png -morphology Convolve LoG:0,1.5 -evaluate Abs output.png

Alternatively, to visualize the LoG zero-crossings around a 50% neutral gray baseline, apply a bias:

magick input.png -define convolve:bias=50% -define convolve:scale='!' -morphology Convolve LoG:0,1.5 output.png
