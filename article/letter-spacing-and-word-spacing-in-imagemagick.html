Letter Spacing and Word Spacing in ImageMagick

This guide explains how to control letter-spacing and word-spacing when rendering text using the -annotate operator in ImageMagick. ImageMagick uses specific command-line settings—specifically -kerning for letter-spacing and -interword-spacing for spacing between words—to alter font geometry before drawing text onto an image.

Controlling Letter-Spacing: -kerning

In ImageMagick, letter-spacing (or tracking) is controlled using the -kerning setting.

  • Positive values (e.g., -kerning 3) increase the gap between adjacent characters by the specified number of pixels.
  • Negative values (e.g., -kerning -1) reduce the space between characters, pulling them closer together.
  • Default value is 0, which uses the font's standard character spacing.

Controlling Word-Spacing: -interword-spacing

Spacing between individual words is managed via the -interword-spacing setting.

  • Positive values (e.g., -interword-spacing 10) add additional pixels to the standard space character width.
  • Negative values (e.g., -interword-spacing -5) decrease the width of the space character.
  • Default value is 0, which relies entirely on the font's default space character width.

Command Example

Both settings must be declared before the -annotate operator in your command sequence so that ImageMagick applies the metrics to the rendered text.

magick input.png \
  -font Arial-Bold \
  -pointsize 32 \
  -fill "#FFFFFF" \
  -kerning 4 \
  -interword-spacing 12 \
  -annotate +50+100 "Custom Spaced Text" \
  output.png

Additional Spacing Controls

When working with multiline text inside -annotate, you can also manage vertical line height using the -interline-spacing parameter. A positive or negative pixel value adjusts the vertical gap between lines of wrapped or newline-separated text.
