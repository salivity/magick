Limit Disk Cache in ImageMagick policy.xml

This guide explains how to restrict the maximum disk cache allocation in ImageMagick by configuring resource boundaries in the policy.xml file. By default, when image operations exceed physical memory and memory-mapped files, ImageMagick offloads pixel cache data to temporary disk storage. Without explicit limits, this behavior can exhaust available drive space and lead to server crashes. The following instructions provide the exact configuration needed to enforce a hard cap on disk cache usage.

Locate the policy.xml File

The policy.xml configuration file controls security policies and system resource allocations for ImageMagick. Its location depends on your operating system and ImageMagick version:

  • Ubuntu / Debian (ImageMagick 7): /etc/ImageMagick-7/policy.xml
  • Ubuntu / Debian (ImageMagick 6): /etc/ImageMagick-6/policy.xml
  • RHEL / CentOS / AlmaLinux: /etc/ImageMagick/policy.xml
  • macOS (Homebrew): /opt/homebrew/etc/ImageMagick-7/policy.xml or /usr/local/etc/ImageMagick-7/policy.xml

Open the file in a text editor with root or administrative privileges:

sudo nano /etc/ImageMagick-6/policy.xml

Configure the Disk Cache Limit

Within the <policymap> tags, look for a policy directive defining the disk resource. If it does not exist, you can add it directly above the closing </policymap> tag.

To set a limit, define the domain, name, and value attributes. For example, to restrict ImageMagick's temporary disk cache to 2 Gigabytes:

<policy domain="resource" name="disk" value="2GiB"/>

Supported units include:

  • B (Bytes)
  • KB / KiB (Kilobytes)
  • MB / MiB (Megabytes)
  • GB / GiB (Gigabytes)

To disable disk caching entirely—forcing ImageMagick to fail immediately rather than using the hard drive when RAM is exhausted—set the value to 0:

<policy domain="resource" name="disk" value="0"/>

Save the file and exit the editor. Changes take effect immediately without requiring a daemon restart.

Verify the Resource Limit

Confirm that ImageMagick recognizes the newly applied limit by querying the active resource policies using the terminal:

For ImageMagick 7:

magick -list resource

For ImageMagick 6:

identify -list resource

Look for the Disk line in the output:

Resource limits:
  Width: 16KP
  Height: 16KP
  List length: 18.446744EP
  Area: 128MP
  Memory: 1GiB
  Map: 2GiB
  Disk: 2GiB
  ...

The output should match the value specified in your policy.xml. Once this threshold is reached during processing, ImageMagick will stop allocating temporary disk space and throw a CacheResourcesExhausted exception, safeguarding the host system against disk exhaustion.
