Linear Color Stretching by Channel in ImageMagick

Linear color stretching enhances image contrast by expanding the intensity range of pixel values across the available dynamic spectrum. In ImageMagick, you can selectively apply this operation to individual color channels—such as Red, Green, or Blue—using the -channel setting alongside stretching operators like -contrast-stretch or -auto-level. This guide demonstrates how to target specific channels and execute linear stretching accurately in ImageMagick.

Understanding the Key Operators

Performing a channel-specific linear stretch requires two main components:

  1. -channel <channel-list>: Restricts subsequent operations to specified channels (e.g., R, G, B, Red, Green, Blue, RGB).
  2. -contrast-stretch <black-point>x<white-point>: Stretches the range of intensity values linearly. The parameters define the percentage (or absolute number) of pixels to clip at the dark and light ends of the histogram.
  3. +channel: Resets the channel selector back to the default state, ensuring further processing affects all channels normally.

Alternatively, the -auto-level operator performs a strict linear stretch mapping the absolute minimum value in the channel to 0 and the absolute maximum value to the maximum dynamic range without clipping.

Basic Syntax

To stretch a specific channel using percentages:

magick input.png -channel Red -contrast-stretch 1%x1% +channel output.png

In this command:

  • -channel Red isolates the red channel.
  • -contrast-stretch 1%x1% clips the lowest 1% of pixel intensities to pure black (0) and the highest 1% to maximum value, linearly interpolating all intermediate values.
  • +channel restores channel operations.

Common Use Cases and Examples

1. Stretching Multiple Specific Channels

You can chain multiple channel operations within a single command to adjust individual color distributions independently:

magick input.png \
  -channel R -contrast-stretch 0.5%x0.5% \
  -channel B -contrast-stretch 2%x2% \
  +channel output.png

This applies a gentle stretch to the Red channel and a stronger stretch to the Blue channel, leaving the Green channel unmodified.

2. Absolute Linear Stretch Without Clipping (-auto-level)

If you want to stretch the values of a channel from its exact minimum to its exact maximum without clipping any data, use -auto-level:

magick input.png -channel Green -auto-level +channel output.png

3. Absolute Pixel Count Stretching

Instead of percentages, you can pass integer values to -contrast-stretch representing exact pixel counts:

magick input.png -channel Blue -contrast-stretch 500x500 +channel output.png

This forces the 500 darkest pixels in the Blue channel to zero and the 500 brightest pixels to full saturation before distributing the intermediate values linearly.

ImageMagick 6 vs. ImageMagick 7 Considerations

  • ImageMagick 7: Use the magick binary. Channel settings apply strictly to image processing operators that follow it until +channel is called.
  • ImageMagick 6: Use the convert binary. Ensure +channel is set before saving the image to prevent writing only the selected channel to the output file.
