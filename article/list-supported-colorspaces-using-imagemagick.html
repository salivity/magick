List Supported Colorspaces Using ImageMagick

This article explains how system administrators can query all supported colorspaces in ImageMagick using the -list colorspace option. ImageMagick relies on specific colorspace models to accurately process, convert, and render digital images. By running the colorspace diagnostic command, administrators can verify system capabilities, ensure required color models are available for automated processing workflows, and troubleshoot color-rendering issues.

Executing the Command

The command used to query available colorspaces depends on the installed version of ImageMagick.

For ImageMagick version 7, use the primary magick CLI tool:

magick -list colorspace

For systems running ImageMagick version 6, the legacy convert command provides the same query functionality:

convert -list colorspace

Understanding the Output

Executing the command outputs a straightforward, line-by-line list of all colorspace profiles compiled into your ImageMagick build. Typical outputs include standard formats such as:

  • RGB / sRGB: Standard Red-Green-Blue models used for web and digital displays.
  • CMYK: Cyan-Magenta-Yellow-Key (Black) model used for print preparation.
  • Gray: Monochromatic grayscale spaces.
  • CIELab / Lab: Perceptually uniform colorspaces used in precise color management.
  • HSL / HSV: Hue-Saturation-Lightness/Value spaces used in graphic manipulation.
  • YUV / YCbCr: Component video and digital compression colorspaces.

Filtering and Searching Colorspace Results

Administrators managing headless servers or deployment scripts can pipe the output into standard Linux utilities to verify specific configurations.

To search for a specific colorspace (e.g., CMYK):

magick -list colorspace | grep -i "cmyk"

To count the total number of colorspaces supported by the current installation:

magick -list colorspace | wc -l

Why Administrators Should Query Colorspaces

  1. Pipeline Validation: Automated image-processing pipelines require verification that target output formats (like sRGB or CMYK) are supported before executing bulk conversion jobs.
  2. Compile-Time Checks: If ImageMagick is compiled from source, listing colorspaces confirms that underlying delegate libraries—such as Little CMS (lcms2)—were detected and linked properly.
  3. Error Prevention: Specifying an unsupported colorspace in a transformation script causes processing failures; checking the list beforehand allows administrators to establish safe defaults in batch scripts.
