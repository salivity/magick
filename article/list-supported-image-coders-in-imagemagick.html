List Supported Image Coders in ImageMagick

This guide explains how to list and verify all supported image coders and file formats in your current ImageMagick installation. By using built-in command-line tools, you can quickly check whether specific formats have read (r), write (w), or multi-frame support on your system.

Listing Supported Formats (ImageMagick v7)

In ImageMagick version 7, use the magick command with the -list format argument to display all available coders and their capabilities:

magick -list format

Alternatively, to see the internal coder definitions directly, run:

magick -list coder

Listing Supported Formats (ImageMagick v6)

If you are using ImageMagick version 6, run the identify or convert utility:

identify -list format

Understanding the Output

The output generates a table with several columns:

  • Format: The file extension or format tag (e.g., JPEG, PNG, WEBP).
  • Module: The internal coder module used to process the format.
  • Mode: The permissions supported by the coder:
    • r: Read support.
    • w: Write support.
    • +: Multi-image/frame support (e.g., animated GIFs or multi-page PDFs).
  • Description: A brief summary of the file format standard.

Filtering for Specific Formats

To check support for a specific image format, pipe the output to a search utility.

On Linux or macOS:

magick -list format | grep -i "webp"

On Windows (Command Prompt):

magick -list format | findstr /i "webp"
