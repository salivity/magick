Lossless JPEG XL Compression in ImageMagick

This guide explains how to configure mathematically lossless JPEG XL (JXL) compression using ImageMagick command-line defines. By setting the appropriate quality flags and encoder defines, you can ensure bit-perfect image preservation while tuning compression effort and decoding speeds for optimal file size and performance.

Basic Lossless Configuration

In ImageMagick, JPEG XL encoding is handled via libjxl. To ensure an image is compressed without any generation loss, you can either explicitly enable the lossless define or set the quality flag to 100.

The primary method to enforce lossless encoding is:

magick input.png -define jxl:lossless=true output.jxl

Alternatively, setting the quality to 100 achieves the same result by setting the internal Butteraugli visual distance to 0:

magick input.png -quality 100 output.jxl

For maximum clarity and to prevent ambiguity across different ImageMagick builds, combining both parameters is common practice:

magick input.png -quality 100 -define jxl:lossless=true output.jxl

Controlling Compression Effort

The compression effort dictates how hard the encoder works to find the smallest file size. It ranges from 1 (fastest encoding, larger file size) to 9 (slowest encoding, smallest file size). The default value is 7.

You configure this using the jxl:effort define:

magick input.png -define jxl:lossless=true -define jxl:effort=9 output.jxl
  • Effort 1–3: Useful for real-time capture or rapid batch processing where CPU usage is a concern.
  • Effort 7: Balanced setting suitable for general storage.
  • Effort 9: Recommended for web delivery or long-term archiving where maximum bandwidth savings are desired.

Optimizing for Decoding Speed

JPEG XL allows you to trade a small amount of compression efficiency for faster decompression. This is controlled via the jxl:decoding-speed define, with values ranging from 0 (slowest decode, smallest file) to 4 (fastest decode, slightly larger file). The default is 0.

magick input.png -define jxl:lossless=true -define jxl:decoding-speed=2 output.jxl

Setting jxl:decoding-speed to higher values (such as 1 or 2) is helpful if the target devices have constrained CPU resources, such as mobile hardware.

Complete Production Example

For an archival-grade, highly compressed lossless file, combine the lossless flag, maximum effort, and standard decoding speed into a single command:

magick input.tiff -quality 100 -define jxl:lossless=true -define jxl:effort=9 -define jxl:decoding-speed=0 output.jxl
