MagickWand C Function for Affine Distortion

In ImageMagick’s MagickWand C API, the primary function used to execute an affine distortion on an active image is MagickDistortImage. By passing the AffineDistortion enumeration to this function, developers can scale, rotate, translate, and shear images using source-to-destination coordinate mapping. This article explains the syntax, parameters, coordinate requirements, and implementation details for performing affine transformations using MagickDistortImage.

The Core Function: MagickDistortImage

The C function signature for performing distortions in MagickWand is:

MagickBooleanType MagickDistortImage(
    MagickWand *wand,
    const DistortImageMethod method,
    const size_t number_arguments,
    const double *arguments,
    const MagickBooleanType bestfit
);

To execute an affine distortion specifically, set the method parameter to AffineDistortion.

Parameter Breakdown

  • wand: A pointer to the active MagickWand containing the image you want to manipulate.
  • method: Set to AffineDistortion (or AffineProjectionDistortion if supplying a raw 6-element matrix coefficient array directly).
  • number_arguments: The total count of floating-point numbers provided in the arguments array.
  • arguments: An array of double values representing mapping coordinates:
    • 1 pair (4 values: sx1, sy1, dx1, dy1): Performs simple translation.
    • 2 pairs (8 values: sx1, sy1, dx1, dy1, sx2, sy2, dx2, dy2): Performs translation, uniform scaling, and rotation.
    • 3 pairs (12 values: sx1, sy1, dx1, dy1, sx2, sy2, dx2, dy2, sx3, sy3, dx3, dy3): Performs a full affine transformation including translation, independent X/Y scaling, rotation, and shearing.
  • bestfit: A boolean flag (MagickTrue or MagickFalse). When set to MagickTrue, the canvas resizes to fit the entire distorted image. When set to MagickFalse, the canvas dimensions and offset remain unchanged.

Code Example

Below is a direct implementation showing how to define coordinate pairs and apply an affine transformation to an active wand:

#include <wand/MagickWand.h>

void ApplyAffineTransform(MagickWand *wand) {
    /* 
       Define 3 source points and their 3 destination points:
       Format: sx1, sy1, dx1, dy1, sx2, sy2, dx2, dy2, sx3, sy3, dx3, dy3
    */
    double affine_args[12] = {
        0.0,   0.0,    10.0,  15.0,  /* Point 1: (0,0) moves to (10,15) */
        100.0, 0.0,    120.0, 5.0,   /* Point 2: (100,0) moves to (120,5) */
        0.0,   100.0,  5.0,   110.0  /* Point 3: (0,100) moves to (5,110) */
    };

    MagickDistortImage(
        wand,
        AffineDistortion,
        12,
        affine_args,
        MagickTrue
    );
}

Alternative Function: MagickAffineTransformImage

For vector-based transformations relying on a transformation matrix rather than point-mapping, MagickWand also provides:

MagickBooleanType MagickAffineTransformImage(
    MagickWand *wand,
    const DrawingWand *drawing_wand
);

This method requires initializing a DrawingWand, configuring an affine matrix via DrawAffine(drawing_wand, &affine_matrix), and passing it to the image wand. For general distortion operations and precise coordinate-based mapping, MagickDistortImage remains the standard and more flexible approach.
