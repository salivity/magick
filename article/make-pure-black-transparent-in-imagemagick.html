Make Pure Black Transparent in ImageMagick

This guide explains how to convert pure black pixels into fully transparent pixels using ImageMagick. You will learn the core command syntax for modern and legacy versions of the tool, how to target hex values, and how to handle near-black compression artifacts using the fuzz option.

The Basic Command

To make pure black pixels completely transparent, use the -transparent operator followed by the color name or hex code.

For ImageMagick version 7:

magick input.png -transparent black output.png

For ImageMagick version 6 (legacy):

convert input.png -transparent black output.png

You can also specify the color using its exact hexadecimal value:

magick input.png -transparent "#000000" output.png

Important Considerations

  1. Output Format: Ensure your output file format supports an alpha channel (transparency). Common supported formats include PNG, WebP, and TIFF. Formats like JPEG do not support transparency; saving as a JPEG will replace transparent areas with a solid background color (often white or black).

  2. Handling Compression Artifacts with -fuzz: If your source image is a JPEG or has undergone lossy compression, the dark areas might not be mathematically pure black (#000000). Instead, they may be slightly off-black (e.g., #010101 or #020202). To capture these near-black pixels along with pure black, add the -fuzz parameter before -transparent:

magick input.png -fuzz 2% -transparent black output.png

A fuzz value between 1% and 5% is typically sufficient to remove compression noise around dark edges without affecting other dark colors in the image.
