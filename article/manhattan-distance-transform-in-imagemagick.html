Manhattan Distance Transform in ImageMagick

This article provides the exact syntax and usage guidelines for executing a Manhattan distance transform in ImageMagick. The Manhattan metric—also known as L1 distance, taxicab distance, or city block distance—calculates the distance between points along grid lines rather than diagonally. In ImageMagick, this operation is performed using morphological operators to create a grayscale distance map representing the proximity of each pixel to the nearest edge or background.

Basic Command Syntax

In ImageMagick, distance transforms are applied using the -morphology operator set to the Distance method with the Manhattan kernel.

The core syntax using ImageMagick version 7 is:

magick input.png -morphology Distance Manhattan output.png

For ImageMagick version 6, replace magick with convert:

convert input.png -morphology Distance Manhattan output.png

Kernel Arguments and Scaling

The Manhattan kernel accepts optional arguments to modify how distances are scaled or clamped:

Manhattan:[radius][xscale]
  • Radius (optional): A maximum distance limit. Distances greater than this value will be clamped to the maximum value.
  • Scale (optional): A multiplication factor applied to each distance unit.

For example, to limit the calculation to a maximum radius of 50 pixels with a scale factor of 1:

magick input.png -morphology Distance Manhattan:50 output.png

Complete Working Example

Distance transforms operate on binary images where the foreground (usually white) is measured relative to the background (black). Because raw distance transforms output values proportional to pixel distance, the results can easily clip in standard 8-bit image formats. To properly view the resulting gradient, use -auto-level to stretch the pixel values across the entire dynamic range.

A full implementation pipeline:

magick input.png \
  -colorspace Gray \
  -threshold 50% \
  -morphology Distance Manhattan \
  -auto-level \
  manhattan_output.png

If you need to calculate the distance from the outside of the shape inward, invert the binary mask using -negate before running the morphology operator:

magick input.png \
  -colorspace Gray \
  -threshold 50% \
  -negate \
  -morphology Distance Manhattan \
  -auto-level \
  inverted_manhattan.png
