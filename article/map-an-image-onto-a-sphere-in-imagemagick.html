Map an Image onto a Sphere in ImageMagick

This guide explains how to project a planar 2D image onto a spherical surface using ImageMagick's built-in -distort operator. By utilizing cartographic and geometric distortions, you can wrap flat rectangular images into 3D-style spherical globes or orthographic projections directly from the command line.

Basic Syntax for Spherical Projection

To map a flat image onto a sphere, ImageMagick provides the Orthographic and Fisheye distortion methods within the -distort option.

1. Orthographic Projection (Globe View)

If your input image is an equirectangular planar map (a 2:1 aspect ratio flat map of a surface), use the Orthographic projection to render a view of the sphere:

magick input.jpg -virtual-pixel Black -distort Orthographic 180 output.png
  • -distort Orthographic [FOV [lon,lat]]: Specifies the orthographic mapping. Setting the Field of View (FOV) to 180 projects a full visible hemisphere.
  • -virtual-pixel Black: Defines what appears outside the spherical boundary (options include Transparent, Black, or Edge).

To rotate the sphere to a specific latitude and longitude:

magick input.jpg -virtual-pixel Transparent -background none -distort Orthographic "180 45,10" output.png

2. Fisheye Distortion (Lens/Sphere Effect)

To create a spherical "bubble" or wrap a non-equirectangular planar image into a circular 3D ball, use the Fisheye distortion:

magick input.jpg -virtual-pixel Black -distort Fisheye 180 output.png
  • 180: The angle/field of view defining the spherical curvature. Adjusting this value alters how strongly the edges warp toward the boundary.

3. Polar Distortion (Circular Wrap)

If you want to wrap a planar strip around a central polar point into a disk or top-down spherical cap:

magick input.jpg -virtual-pixel HorizontalTile -distort Polar 0 output.png
  • -distort Polar 0: Maps the horizontal axis across 360 degrees and the vertical axis radially from the center outward.
  • -virtual-pixel HorizontalTile: Ensures seamless edges if the image wraps completely around the circular surface.

Recommended Best Practices

  • Format and Transparency: Output to .png or .webp when using -virtual-pixel Transparent or -background none to retain transparent corners around the circular sphere edge.
  • Aspect Ratios: For true geographic globes using Orthographic, use an input image with a 2:1 width-to-height ratio for accurate proportions.
