Map Custom Color Names in ImageMagick colors.xml

This article explains how to define custom color names mapped to specific RGBA values in ImageMagick using the colors.xml configuration file. It covers locating the configuration path, formatting the XML definition for RGBA values, verifying the configuration, and applying the custom color names directly within ImageMagick command-line operations.

Locating or Creating colors.xml

ImageMagick searches for configuration files in system-wide and user-specific directories. To define user-level custom colors without modifying system installations, create or edit colors.xml in your user configuration directory:

  • Linux / macOS: ~/.config/ImageMagick/colors.xml
  • Windows: %APPDATA%\ImageMagick\colors.xml

You can verify your active configuration search paths by running:

magick -list configure

Defining Custom RGBA Colors in XML

Open or create the colors.xml file and define your custom colors using the <color-list> root element and <color> child elements. The name attribute sets the custom alias, while the color attribute specifies the standard rgba(r, g, b, a) value or hexadecimal notation #RRGGBBAA.

<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE color-list [
<!ELEMENT color-list (color)+>
<!ELEMENT color EMPTY>
<!ATTLIST color name CDATA #REQUIRED>
<!ATTLIST color compliance CDATA #IMPLIED>
<!ATTLIST color color CDATA #REQUIRED>
]>
<color-list>
  <color name="brandSemiRed" compliance="Custom" color="rgba(255, 0, 0, 0.5)" />
  <color name="brandTransparentBlue" compliance="Custom" color="rgba(0, 102, 204, 0.75)" />
</color-list>

Verifying the Custom Color Mapping

To check if ImageMagick recognizes the newly defined color names, query the internal color list using the command line:

magick -list color | grep brandSemiRed

For legacy ImageMagick (v6), replace magick with convert:

convert -list color | grep brandSemiRed

Using Custom RGBA Colors in Commands

Once mapped, custom color names can be used anywhere ImageMagick accepts a standard color name or value:

magick -size 300x300 canvas:brandSemiRed output.png

To use the custom color for drawing shapes, text, or backgrounds:

magick input.png -background brandTransparentBlue -fill brandSemiRed -font Arial -pointsize 24 -annotate +50+50 "Custom Color Test" output.png
