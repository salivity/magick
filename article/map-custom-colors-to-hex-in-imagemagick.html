Map Custom Colors to Hex in ImageMagick

ImageMagick allows you to define custom color names and map them directly to specific RGBA hexadecimal values using internal XML configuration files. This guide explains how to create, configure, and apply custom color mappings so you can use proprietary, branded, or project-specific color names directly within your ImageMagick command-line operations.

Understanding the colors.xml File

ImageMagick resolves color names using an internal configuration file named colors.xml. You can override or extend the default color list by creating your own colors.xml file in your local ImageMagick configuration directory.

Step 1: Locate the Configuration Directory

ImageMagick looks for user-defined configuration files in specific directories depending on your operating system:

  • Linux / macOS: ~/.config/ImageMagick/ or ~/.magick/
  • Windows: %APPDATA%\ImageMagick\

If the directory does not exist, create it manually.

Step 2: Create the Custom colors.xml File

Create a file named colors.xml inside your configuration directory. Define your custom color names and their 8-character RGBA hex values using the <color> element.

<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE colormap [
<!ELEMENT colormap (color)+>
<!ELEMENT color EMPTY>
<!ATTLIST color name CDATA #REQUIRED>
<!ATTLIST color compliance CDATA #IMPLIED>
<!ATTLIST color color CDATA #REQUIRED>
]>
<colormap>
  <color name="brand_primary" color="#1A73E8FF" compliance="SVG, X11, XPM" />
  <color name="brand_accent" color="#FF5722CC" compliance="SVG, X11, XPM" />
  <color name="translucent_dark" color="#00000080" compliance="SVG, X11, XPM" />
</colormap>

In the RGBA hex format (#RRGGBBAA):

  • RR represents Red (00–FF).
  • GG represents Green (00–FF).
  • BB represents Blue (00–FF).
  • AA represents Alpha / Opacity (00 is fully transparent, FF is fully opaque).

Step 3: Using an Environment Variable (Alternative Method)

If you prefer to keep your custom configuration in a project repository rather than the system-wide user profile, you can set the MAGICK_CONFIGURE_PATH environment variable to point to the directory containing your custom colors.xml.

Linux / macOS:

export MAGICK_CONFIGURE_PATH="/path/to/custom/config"

Windows (Command Prompt):

set MAGICK_CONFIGURE_PATH=C:\path\to\custom\config

Step 4: Verify the Custom Colors

Check if ImageMagick recognizes your newly defined colors by querying the color list:

magick -list color | grep "brand_"

Step 5: Use Custom Colors in Commands

Once mapped, your custom color names can be used anywhere a standard color name or hex code is accepted:

magick -size 400x200 xc:brand_primary -fill brand_accent -draw "circle 200,100 200,50" output.png
