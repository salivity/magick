Map Custom Colors to Hex RGBA in ImageMagick

This guide explains how to define custom color keywords and map them directly to 8-digit hexadecimal RGBA values in ImageMagick. By creating or modifying ImageMagick's colors.xml configuration file, you can establish global or user-specific color aliases that streamline image processing workflows and maintain brand consistency across all CLI commands.

Locating the Configuration File

ImageMagick loads color definitions from an XML configuration file named colors.xml. You can map custom colors either system-wide or for a single user:

  • User Configuration (Recommended): ~/.config/ImageMagick/colors.xml (Linux/macOS) or %APPDATA%\ImageMagick\colors.xml (Windows)
  • System-Wide Configuration: /etc/ImageMagick-7/colors.xml or the installation directory on Windows.

Defining Custom RGBA Colors

To define custom color keywords, edit or create colors.xml and include your mappings inside the <colormap> root element. In ImageMagick, 8-digit hex values follow the #RRGGBBAA format, where the final two hex digits represent the alpha (opacity) channel from 00 (completely transparent) to ff (completely opaque).

<?xml version="1.0" encoding="UTF-8"?>
<colormap>
  <color name="brandBlue" value="#1A5276FF" />
  <color name="translucentRed" value="#FF000080" />
  <color name="accentGreen" value="#2ECC71CC" />
</colormap>

Verifying the Custom Colors

After saving the file, verify that ImageMagick recognizes the newly mapped keywords by querying the internal color list:

magick -list color | grep brandBlue

Or for ImageMagick 6:

convert -list color | grep brandBlue

Using Custom Keywords in Commands

Once mapped, your custom color names can be used anywhere a standard color name or hex code is accepted:

magick -size 200x200 canvas:translucentRed output.png
magick input.jpg -bordercolor brandBlue -border 10x10 output.jpg
