Map Panorama to Arc Projection in ImageMagick

This guide details how to transform a standard rectangular panoramic image into a curved arc or circular projection using ImageMagick. By utilizing the -distort Arc operator, you can wrap linear horizons into semi-circles or complete 360-degree polar projections. The following instructions cover the core command syntax, argument settings, and practical examples to achieve clean, distortion-free results.

The Arc Distortion Syntax

ImageMagick performs arc mappings through the -distort Arc operator. The general syntax for the command is:

magick input.jpg -virtual-pixel HorizontalTile -background none -distort Arc "angle [rotation] [outer_radius] [inner_radius]" output.png

The arguments inside the quotation marks control the shape and curvature of the arc:

  • angle: The sweep of the arc in degrees. Using 360 bends the image into a complete circle, while smaller values like 180 create a semi-circular curve.
  • rotation (optional): The rotation offset in degrees. A value of 0 places the center of the panorama at the top of the arc.
  • outer_radius (optional): The radius of the outer edge of the arc. If left blank or set to auto, ImageMagick calculates this automatically based on image dimensions.
  • inner_radius (optional): The radius of the inner hole. Setting this to 0 closes the hole completely, meeting at a central point.

Key Pre-Processing Options

To ensure clean output edges, set these options before applying the distortion:

  • -virtual-pixel HorizontalTile: Panorama images wrap naturally from left to right. This setting prevents black seams where the left and right edges join.
  • -background none (or a specific color): Defines the canvas color filling the negative space around the generated arc.

Examples

1. Full 360-Degree Circular Projection

To wrap a 360-degree equirectangular panorama into a complete disk (such as a "little planet" or circular tunnel projection):

magick panorama.jpg -virtual-pixel HorizontalTile -background transparent -distort Arc 360 output_circle.png

If you want the ground at the center instead of the sky, invert the image vertically using -flip before applying the arc:

magick panorama.jpg -flip -virtual-pixel HorizontalTile -background transparent -distort Arc 360 output_planet.png

2. Semi-Circular (180-Degree) Arc

To bend a panorama into a gentle upward arc without creating a full circle, specify an angle of 180:

magick panorama.jpg -virtual-pixel HorizontalTile -background transparent -distort Arc 180 output_arc.png

3. Custom Arc with a Defined Center Hole

To create an arc that sweeps 120 degrees, rotated by 90 degrees, with an explicit outer radius of 800 pixels and an inner radius of 200 pixels:

magick panorama.jpg -virtual-pixel HorizontalTile -background transparent -distort Arc "120 90 800 200" output_ring.png
