Measure Shape Compactness with ImageMagick

This guide explains how to calculate shape compactness using ImageMagick's connected-components labeling feature. You will learn how to prepare a binary image, extract geometric metrics such as area and bounding box dimensions directly from the command line, and use these measurements to determine the compactness score of individual shapes.

Understanding Shape Compactness

Compactness measures how closely a shape resembles a circle (the most compact two-dimensional shape) or how efficiently an object occupies its bounding area.

There are two primary methods to evaluate compactness:

  1. Isoperimetric Quotient (Circularity): Measures the ratio of a shape's area to the square of its perimeter: \[\text{Compactness} = \frac{4\pi \times \text{Area}}{\text{Perimeter}^2}\] A perfect circle yields a value of 1.0, while convoluted, elongated, or dispersed shapes approach 0.
  2. Bounding Box Extent: Measures the ratio of a shape's area to the area of its minimum axis-aligned bounding box: \[\text{Extent} = \frac{\text{Area}}{\text{Width} \times \text{Height}}\] A solid rectangle yields a value of 1.0.

ImageMagick’s -connected-components operator automatically generates the area, centroid, and bounding box for every discrete region in an image.

Step 1: Extract Metrics with Connected Components

To get the metrics of white shapes on a black background, ensure the image is thresholded to pure black and white, then run the -connected-components operator with verbose output enabled.

magick input.png -threshold 50% \
  -define connected-components:verbose=true \
  -connected-components 8 \
  null:

The output displays an entry for each detected region:

Objects (id: box area centroid color):
  0: 500x500+0+0 235480 248.6,251.2 srgb(0,0,0)
  1: 140x140+180+180 15394 249.5,249.5 srgb(255,255,255)

In this output:

  • id: 1 is a shape.
  • 140x140+180+180 is the bounding box (Width x Height + X + Y).
  • 15394 is the Area in pixels.

Step 2: Calculate Extent Compactness

If using the Bounding Box Extent method, you can compute the compactness directly from the -connected-components output using awk:

magick input.png -threshold 50% \
  -define connected-components:verbose=true \
  -connected-components 8 null: | \
  awk '/srgb\(255,255,255\)/ {
    split($2, bbox, /[x+]/);
    width = bbox[1];
    height = bbox[2];
    area = $3;
    extent = area / (width * height);
    printf "Object ID %s: Extent Compactness = %.4f\n", $1, extent;
  }'

Step 3: Calculate Isoperimetric Compactness

To calculate the standard isoperimetric compactness (\(4\pi \times \text{Area} / \text{Perimeter}^2\)), you need the shape's perimeter length in addition to its area.

You can determine the perimeter by extracting the edges of the shape using -morphology Edge and measuring the area (pixel count) of that one-pixel-wide edge:

# 1. Get the area of the shape
AREA=$(magick input.png -threshold 50% \
  -define connected-components:verbose=true \
  -connected-components 8 null: | \
  awk '/srgb\(255,255,255\)/ {print $3}')

# 2. Get the perimeter by isolating the boundary pixels
PERIMETER=$(magick input.png -threshold 50% \
  -morphology Edge Diamond \
  -define connected-components:verbose=true \
  -connected-components 8 null: | \
  awk '/srgb\(255,255,255\)/ {sum += $3} END {print sum}')

# 3. Compute Isoperimetric Quotient: (4 * pi * Area) / (Perimeter^2)
awk -v a="$AREA" -v p="$PERIMETER" 'BEGIN {
  pi = 3.14159265359;
  compactness = (4 * pi * a) / (p * p);
  printf "Area: %d, Perimeter: %d, Compactness: %.4f\n", a, p, compactness;
}'

A score closer to 1.0 indicates a highly compact, circular structure, whereas smaller decimal values indicate more irregular, elongated, or complex boundaries.
