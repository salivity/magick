Merge Bracketed Photos into HDR Using ImageMagick

Merging exposure bracketed photographs into a High Dynamic Range (HDR) image preserves details across extreme shadows and bright highlights. ImageMagick provides flexible command-line tools to combine multiple photos captured at varying exposure levels into high-bit-depth formats such as .hdr or .exr. This guide walks through the required commands to merge bracketed exposures and prepare your final composite directly from the terminal.

1. Verify HDRI Support

ImageMagick must be compiled with High Dynamic Range Imaging (HDRI) enabled so it can handle 32-bit floating-point color values without clipping.

Run the following command to check your version:

magick -version

Look for HDRI in the Features line of the output. ImageMagick version 7 includes HDRI enabled by default.

2. Prepare and Align Your Source Images

For the best dynamic range output, use uncompressed 16-bit TIFF or linear formats rather than 8-bit JPEGs.

Ensure your images are perfectly aligned. If the bracketed shots were taken handheld, align them before merging using a dedicated tool such as align_image_stack:

align_image_stack -a aligned_ input1.tif input2.tif input3.tif

3. Merge the Exposures into an HDR File

To merge your aligned exposures, use the -evaluate-sequence operator. This calculates the pixel-by-pixel mathematical average across the exposure bracket and stores the dynamic range within a high-depth file format like Radiance RGBE (.hdr) or OpenEXR (.exr).

magick aligned_*.tif -evaluate-sequence mean output.hdr

Alternatively, if saving to OpenEXR:

magick aligned_*.tif -evaluate-sequence mean output.exr

4. Advanced Exposure Blending

If you want to blend images based on contrast and luminance without saving directly to a floating-point HDR file, you can blend two exposures using layer masking:

magick underexposed.tif overexposed.tif ( underexposed.tif -colorspace Gray ) -composite blended.tif

This creates a grayscale mask from the darker image to selectively merge the bright highlights of the underexposed frame into the overexposed frame.

5. Tone Mapping the HDR Output for Display

HDR formats (.hdr and .exr) cannot be displayed directly on standard 8-bit monitors. To convert the final HDR file into a standard JPEG or PNG, apply gamma adjustments and contrast stretching:

magick output.hdr -gamma 2.2 -contrast-stretch 0.5%x0.5% final_display.jpg

This compresses the high dynamic range into an 8-bit color space suitable for web display and printing.
