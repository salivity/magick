Merge Visible Layers in PSD with ImageMagick

Merging visible layers of a Photoshop (PSD) file using ImageMagick is an efficient way to automate batch image processing and convert layered assets via the command line. This guide provides the exact ImageMagick commands required to merge PSD layers, preserve transparent backgrounds, and export the result to standard image formats like PNG or JPEG.

The Standard Merge Command

To merge all visible layers in a PSD file using ImageMagick 7, use the -flatten operator:

magick input.psd -flatten output.png

For ImageMagick 6 (legacy syntax), use convert:

convert input.psd -flatten output.png

Preserving Transparency

By default, the -flatten command may apply a default background color (usually white) behind transparent areas. To retain transparency in the output image, set the background to none before flattening:

magick input.psd -background none -flatten output.png

Alternatively, use the -layers merge operator, which natively respects layer dimensions and transparent canvas areas:

magick input.psd -layers merge output.png

Extracting the Pre-Rendered PSD Composite

Photoshop files often contain an embedded, pre-merged composite image as the first frame (index 0). If you only need this composite without manually recalculating layer blend modes, extract the first frame directly:

magick input.psd[0] output.png

Command Breakdown

  • input.psd: The source PSD file containing multiple layers.
  • -background none: Ensures that transparent canvas regions remain transparent rather than filling with a default solid color.
  • -flatten: Combines all image layers into a single layer using the dimensions of the bottom layer or canvas.
  • -layers merge: Merges all canvas layers while expanding the canvas boundaries to encompass all layer offsets.
  • output.png: The resulting flattened output file.
