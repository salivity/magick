MIFF Header Tags in ImageMagick

The Magick Image File Format (MIFF) is ImageMagick's native raster format, designed to preserve the complete internal state of an image in memory when written to disk. When exporting raster data to MIFF, ImageMagick writes a human-readable, text-based header consisting of keyword=value pairs followed by a form-feed character (\x0c) and a colon delimiter before the raw binary pixel payload begins. This article details the primary header tags stored during the export process and their roles in defining the raster image's attributes.

Structural and Identification Tags

  • id: Identifies the file format. For standard MIFF files, this is set to id=ImageMagick.
  • class: Defines the pixel storage model. It is typically set to DirectClass (for direct truecolor representations) or PseudoClass (for colormapped/indexed images).
  • columns: Specifies the width of the image in pixels as an integer.
  • rows: Specifies the height of the image in pixels as an integer.
  • depth: Indicates the bit depth per color channel (such as 8, 16, or 32 bits), reflecting the quantum depth of the ImageMagick build and export settings.

Color and Channel Tags

  • colorspace: Specifies the color model used for the pixel data, such as sRGB, RGB, CMYK, Gray, or Lab.
  • alpha (or matte in legacy versions): Set to True or False to indicate whether an alpha transparency channel is present in the binary payload.
  • colors: Used primarily when class=PseudoClass, indicating the number of colors contained in the accompanying color lookup table.
  • gamma: Stores the gamma correction exponent of the image data.
  • rendering-intent: Defines the ICC color rendering intent (e.g., Perceptual, Relative, Saturation, or Absolute).

Encoding and Storage Tags

  • compression: Identifies the compression algorithm applied to the binary raster payload. Common values include None, BZip, Fax, JPEG, LZW, RLE, and Zip.
  • quality: An integer indicating the compression quality or level requested during the save operation.
  • endian: Declares the byte ordering of multi-byte binary values, set to either MSB (Most Significant Byte / big-endian) or LSB (Least Significant Byte / little-endian).

Sizing and Geometry Tags

  • resolution: The horizontal and vertical resolution of the image, written in the format WidthxHeight (e.g., 300x300).
  • units: The metric used for resolution measurements, commonly PixelsPerInch or PixelsPerCentimeter.
  • page: The canvas geometry or offset for layered images, stored in geometry syntax (e.g., 800x600+0+0).
  • scene: The index or frame number of the image within an animation or multi-image sequence.

Profiles and Custom Metadata

  • profile-[name]: Embedded metadata profiles—such as ICC, EXIF, IPTC, or XMP—are saved with their byte length specified as the tag value, immediately followed by the raw profile data within the header section.
  • Arbitrary Key-Value Attributes: Any custom properties or EXIF metadata fields associated with the image artifact (such as date:create, comment, or software identifiers) are appended as literal text key-value pairs directly in the header text block.

Header Termination

The MIFF header is terminated by the sequence \x0c\n: (a form-feed character, newline, and colon). ImageMagick uses this distinct boundary to halt text parsing and immediately begin streaming the binary colormap (if PseudoClass) and raster pixel packets.
