Mirror and Tile Images in ImageMagick

ImageMagick provides powerful command-line tools to transform, mirror, and repeat patterns across any canvas size. This guide demonstrates the exact syntax needed to create a 2x2 mirrored (quad-reflection) base pattern from a single input image and seamlessly tile it across a large canvas.

The Complete Command

To create a quad-mirrored pattern and tile it over a defined canvas size (e.g., 1920x1080), use the following ImageMagick 7 command:

magick input.png \
  \( -clone 0 -flop \) +append \
  \( -clone 0 -flip \) -append \
  -write mpr:mirrortile +delete \
  -size 1920x1080 tile:mpr:mirrortile output.png

If you are using ImageMagick 6, replace magick with convert.

Syntax Breakdown

  1. magick input.png: Loads the original source image into memory at index 0.
  2. \( -clone 0 -flop \) +append: Clones the original image, mirrors it horizontally with -flop, and combines both horizontally side-by-side using +append. This forms the top half of the mirrored unit.
  3. \( -clone 0 -flip \) -append: Clones the newly created top row, flips it vertically using -flip, and stacks it underneath using -append. This completes a four-quadrant, perfectly seamless 2x2 mirrored tile.
  4. -write mpr:mirrortile +delete: Writes the mirrored composite into ImageMagick's temporary Memory Program Register (mpr:) named mirrortile, then removes the working image from the current sequence using +delete.
  5. -size 1920x1080 tile:mpr:mirrortile output.png: Creates a new canvas of the specified dimensions (1920x1080), fills it repeatedly using the cached mirrored pattern (tile:mpr:mirrortile), and writes the final image to output.png.
