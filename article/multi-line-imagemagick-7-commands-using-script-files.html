Multi-Line ImageMagick 7 Commands Using Script Files

ImageMagick 7 introduced a dedicated scripting mode that simplifies running complex, multi-line image processing commands without relying on fragile shell-continuation characters like backslashes. This article demonstrates how to create standalone ImageMagick 7 script files, format multi-line commands cleanly, handle comments, and execute the scripts across different environments.

The magick -script Facility

In ImageMagick 6 and earlier, running multi-line operations required using the underlying shell's line continuation character (such as \ in Bash or ^ in Windows Command Prompt). ImageMagick 7 introduces native scripting via the -script option.

When you pass a file to magick -script, ImageMagick treats the contents of the file as an execution sequence. It processes lines sequentially, ignores standard indentation, and removes the need for terminal-specific escape characters.

Creating a Script File

An ImageMagick 7 script file is a standard plain text file containing options and arguments separated by whitespace or newlines.

Basic Syntax and Formatting

  • Newlines: Each command argument or operation can be placed on its own line without trailing slashes.
  • Comments: Any line starting with a hash symbol (#) is treated as a comment.
  • Indentation: Spaces and tabs are treated as general whitespace, allowing you to indent operations logically.

Example: process_image.mgk

# Load the base image
input.jpg

# Resize and enhance
-resize 1200x800^
-gravity center
-extent 1200x800
-unsharp 0x0.75+0.75+0.008

# Adjust colors
-brightness-contrast 5x10

# Save the result
-quality 85
output.jpg

Executing the Script

There are two primary methods to execute your multi-line script.

Method 1: Using the magick Command

Run the script by passing it as an argument to the magick command:

magick -script process_image.mgk

This method works consistently across Linux, macOS, and Windows.

Method 2: Direct Execution via Shebang (Linux/macOS)

On Unix-like systems, you can make the script directly executable by adding a shebang pointing to the ImageMagick binary.

  1. Create a file named optimize.sh:
#!/usr/bin/magick -script

input.png
-strip
-resize 50%
-colorspace sRGB
output.png
  1. Make the file executable:
chmod +x optimize.sh
  1. Run the script directly:
./optimize.sh

Passing Dynamic Arguments

ImageMagick script files can accept dynamic command-line arguments using placeholder references. The argument markers correspond to the order in which parameters are passed when invoking the script:

  • %[1] corresponds to the first passed argument.
  • %[2] corresponds to the second passed argument.

Script with Placeholders (convert_dynamic.mgk)

# Read input from first argument
%[1]

# Apply processing
-thumbnail 800x600
-auto-orient

# Write output to second argument
%[2]

Execution:

magick -script convert_dynamic.mgk photo.raw photo_preview.jpg
