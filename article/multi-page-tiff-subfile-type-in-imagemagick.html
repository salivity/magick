Multi-Page TIFF Subfile Type in ImageMagick

This guide explains how to generate multi-page TIFF files with distinct sub-file type tags assigned to individual frames using ImageMagick. By setting specific TIFF tag metadata per layer, you can designate whether a page is a full-resolution image, a reduced-resolution preview, or a page of a multi-page document.

Understanding TIFF Subfile Types

The TIFF specification defines the NewSubfileType tag (Tag 254) as a bitmask that indicates the purpose of each subfile (or page) within a multi-directory TIFF file:

  • 0 (Bitmask 0): Default / Full-resolution image data.
  • 1 (Bitmask 1): Reduced-resolution image data (thumbnail or preview).
  • 2 (Bitmask 2): Single page of a multi-page document.
  • 4 (Bitmask 4): Transparency mask for another image within the file.

Setting Subfile Types Per Page

In ImageMagick 7, you can set the tiff:subfiletype property on individual images within the same command using parenthesis \( ... \) and the -set operator.

Example: Main Image with a Reduced-Resolution Thumbnail

If you want the first page to be marked as a primary document page and the second page to be tagged as a reduced-resolution preview:

magick \( full_page.png -set tiff:subfiletype 2 \) \
       \( thumbnail.png -set tiff:subfiletype 1 \) \
       output.tiff

Example: Setting Full-Resolution and Preview Tags

To create a master image followed by an embedded preview:

magick \( high_res.png -set tiff:subfiletype 0 \) \
       \( low_res.png -set tiff:subfiletype 1 \) \
       output.tiff

Legacy ImageMagick 6 Syntax

If you are using ImageMagick 6, replace magick with convert and use the -define operator scoped to specific image operations:

convert \( page1.png -define tiff:subfiletype=0 \) \
        \( page2.png -define tiff:subfiletype=1 \) \
        output.tiff

Verifying the Subfile Type Tags

After writing the file, you can verify that each page contains the intended tag using the identify tool:

magick identify -format "Page %p: SubFileType = %[tiff:subfiletype]\n" output.tiff

Alternatively, you can inspect the raw TIFF directory headers using tiffinfo (from the standard libtiff tools):

tiffinfo output.tiff

In the tiffinfo output, look for the SubFileType field under each directory listing to ensure the correct values (0, (reduced-resolution image), or (page of multi-page image)) were written.
