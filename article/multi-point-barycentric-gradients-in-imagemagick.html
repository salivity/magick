Multi-Point Barycentric Gradients in ImageMagick

This article explains how ImageMagick's sparse-color operator employs the Barycentric method to generate multi-point linear gradients. It details the underlying mathematics of barycentric coordinates, how the algorithm transitions from basic two-point lines to three-point planes, and how it resolves overdetermined systems using least-squares linear regression when four or more color points are supplied.

The Sparse-Color Barycentric Operator

ImageMagick provides the -sparse-color operator to generate continuous color fields from an arbitrary list of coordinates and colors:

magick -size 500x500 xc:none -sparse-color Barycentric "X1,Y1,Color1 X2,Y2,Color2 ... Xn,Yn,Colorn" output.png

Unlike distance-weighted methods such as Shepard's method, which produce localized, curved color contours, the Barycentric method enforces strict linearity across the entire canvas. Every color channel (\(Red, Green, Blue, Alpha\)) is treated as an independent dimension and evaluated as a flat, linear mathematical plane.

Two-Point Gradients: 1D Linear Interpolation

When exactly two points are defined, the Barycentric method computes a standard directional linear gradient:

  1. A vector is drawn between Point A \((x_1, y_1)\) and Point B \((x_2, y_2)\).
  2. For any arbitrary pixel \(P(x, y)\) on the canvas, the point is orthogonally projected onto this vector.
  3. The color value varies linearly along the line connecting the two points and remains completely uniform along any line perpendicular to that vector.
  4. The gradient extends infinitely in both directions across the canvas, linearly extrapolating colors beyond the segment defined by the two endpoints.

Three-Point Gradients: Exact Planar Interpolation

With three non-collinear points, the system forms a triangle in 2D space. In 3D space (where the Z-axis represents a color channel intensity), three points uniquely define a single flat plane.

The algorithm solves for barycentric coordinates \((\lambda_1, \lambda_2, \lambda_3)\) for any pixel \((x, y)\):

\[x = \lambda_1 x_1 + \lambda_2 x_2 + \lambda_3 x_3\] \[y = \lambda_1 y_1 + \lambda_2 y_2 + \lambda_3 y_3\] \[\lambda_1 + \lambda_2 + \lambda_3 = 1\]

The resulting color \(C\) at \((x, y)\) is calculated as:

\[C(x, y) = \lambda_1 C_1 + \lambda_2 C_2 + \lambda_3 C_3\]

Because this produces a flat plane in color space, the resulting visual output is an affine 2D linear gradient. The isolines (lines of constant color) remain perfectly straight, oriented according to the slope determined by the three points.

Multi-Point Gradients (>3 Points): Least-Squares Fitting

When four or more points are provided, three independent points can rarely share a single plane with the remaining points. Instead of partitioning the canvas into a mesh of separate triangles (such as Delaunay triangulation), ImageMagick preserves global linearity by treating the input as an overdetermined linear system.

For each color channel, the algorithm defines a plane equation:

\[Z(x, y) = Ax + By + C\]

Where:

  • \(x\) and \(y\) are spatial pixel coordinates.
  • \(Z\) is the resulting color channel intensity.
  • \(A, B,\) and \(C\) are the coefficients defining the orientation and offset of the plane.

To fit \(N\) points \((x_i, y_i, Z_i)\) where \(N > 3\), ImageMagick uses linear regression via a least-squares fit. It minimizes the sum of squared residuals:

\[S = \sum_{i=1}^{N} \left( Z_i - (A x_i + B y_i + C) \right)^2\]

This system is solved using the normal equations:

$$\begin{bmatrix} \sum x_i^2 & \sum x_i y_i & \sum x_i \ \sum x_i y_i & \sum y_i^2 & \sum y_i \ \sum x_i & \sum y_i & N \end{bmatrix} \begin{bmatrix} A \ B \ C \end{bmatrix}

\begin{bmatrix} \sum x_i Z_i \ \sum y_i Z_i \ \sum Z_i \end{bmatrix}$$

Solving this matrix yields the optimal coefficients \(A, B,\) and \(C\) for each color channel.

Key Characteristics of the Resulting Canvas

  • Strict Planarity: Even with dozens of control points, the resulting gradient is always a single flat plane. It will never curve, warp, or create local extrema.
  • Best-Fit Compromise: If multi-point inputs do not naturally align along a single plane, the colors at the specified coordinates will not match the input colors exactly; they will match the mathematically closest points on the best-fit plane.
  • Collinear Handling: If all points lie along a single straight line, the method degenerates cleanly into a 1D gradient along that line, maintaining constant color perpendicularly.
