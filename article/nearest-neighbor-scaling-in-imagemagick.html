Nearest Neighbor Scaling in ImageMagick

Scaling images like pixel art without causing blurriness requires nearest-neighbor interpolation, which duplicates existing pixels rather than blending them. By default, ImageMagick applies smoothing filters (such as Lanczos or Mitchell) when resizing, resulting in soft, anti-aliased edges. This guide explains how to scale images in ImageMagick using -sample, -scale, and -filter point to keep your pixel edges completely sharp and crisp.

Method 1: Using the -sample Operator

The fastest and most direct way to scale an image with nearest-neighbor interpolation is using the -sample operator. It samples the pixel values directly without performing any color blending.

To scale an image by a percentage:

magick input.png -sample 400% output.png

To scale an image to specific dimensions (e.g., 800x600 pixels):

magick input.png -sample 800x600 output.png

Method 2: Using the -scale Operator

The -scale operator is similar to -sample, but it is optimized for speed using a simple box filter. When magnifying images, it effectively produces identical results to nearest-neighbor interpolation.

magick input.png -scale 500% output.png

Method 3: Using -resize with the Point Filter

If you need the flexibility of the -resize operator (such as specific geometry flags) while forcing nearest-neighbor behavior, you can explicitly set the filter to point and the interpolation method to Nearest.

magick input.png -filter point -interpolate Nearest -resize 400% output.png

Why Use -filter point?

  • -filter point: Disables complex multi-tap filtering and uses only the single nearest pixel.
  • -interpolate Nearest: Ensures that any sub-pixel calculations fall back to the closest whole pixel coordinate.

ImageMagick 6 vs. ImageMagick 7 Syntax

  • ImageMagick 7 (Current): Use magick 
    magick input.png -sample 400% output.png
  • ImageMagick 6 (Legacy): Use convert 
    convert input.png -sample 400% output.png
