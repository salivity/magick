Non-Rectangular SVG Clipping Masks in ImageMagick

Applying non-rectangular clipping masks in ImageMagick allows you to mask images into complex vector shapes such as stars, organic curves, or custom logos using Scalable Vector Graphics (SVG). This guide explains how to use external SVG vector paths and inline vector drawing commands to clip raster images cleanly using ImageMagick's alpha compositing and clipping operators.

Method 1: Masking with an External SVG File

The most versatile method for applying a non-rectangular vector mask is to use an SVG file as an alpha matte via the DstIn composition method. In this approach, ImageMagick renders the SVG path, treats its shape as an opacity mask, and retains only the image pixels that overlap with the opaque parts of the SVG.

Run the following command in your terminal:

magick input.jpg -density 300 mask.svg -alpha set -compose DstIn -composite output.png
  • -density 300: Sets the rasterization resolution for the vector SVG to ensure crisp, anti-aliased edges. Place this before loading the SVG file.
  • -alpha set: Ensures the base image has an alpha channel enabled for transparency.
  • -compose DstIn: Defines the compositing operator, which keeps the destination (the original image) only where the source (the SVG mask) is opaque.
  • -composite: Executes the blending operation.

Method 2: Defining Inline SVG Paths with -draw

If you do not have a standalone .svg file, you can define an SVG vector path directly within the ImageMagick command using the path drawing primitive.

magick input.jpg \
  \( +clone -alpha transparent -background none \
     -fill white -draw "path 'M 100,100 L 300,100 L 200,300 Z'" \) \
  -compose DstIn -composite output.png
  • +clone -alpha transparent: Creates an empty, transparent canvas matching the exact dimensions of input.jpg.
  • -draw "path '...'": Uses standard SVG path syntax (M for moveto, L for lineto, Z for closepath, C for cubic Bézier curves) to render the vector mask onto the temporary canvas.
  • The resulting shape is then used to clip the underlying image.

Method 3: Using Embedded SVG Clipping Paths (-clip-path)

If your image format (such as TIFF or PSD) contains an embedded named vector clipping path, or if you are working with an SVG file that contains a defined <clipPath id="myPath">, you can invoke the path directly:

magick input.jpg -clip-path "myPath" -alpha transparent output.png

To extract and apply the primary embedded clipping path without referencing an ID name:

magick input.jpg -clip -alpha transparent output.png

Best Practices for SVG Vector Masks

  • Output Format: Always save the resulting image to a format that supports transparency, such as PNG, WebP, or TIFF. Saving to JPEG will replace transparent areas with the default background color.
  • Canvas Alignment: Ensure that the viewBox or width/height attributes inside your SVG match the dimensions and aspect ratio of the raster image you are clipping to prevent misalignment or scaling distortion.
