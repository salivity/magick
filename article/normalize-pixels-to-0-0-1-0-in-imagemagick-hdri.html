Normalize Pixels to 0.0-1.0 in ImageMagick HDRI

This article explains how to normalize pixel intensity values to a floating-point range between 0.0 and 1.0 using High Dynamic Range Imaging (HDRI) builds of ImageMagick. You will learn how ImageMagick handles quantum ranges in HDRI mode, how to linearly stretch pixel ranges using -auto-level, how to map pixel data down to a unit interval using mathematical operators, and how to properly export floating-point output files.

Understanding HDRI Quantum Ranges

In ImageMagick HDRI builds (such as Q16HDRI or Q32HDRI), pixel values are stored internally as floating-point numbers capable of exceeding traditional bounds and representing fractional values. However, ImageMagick still calculates intensity relative to its compiled QuantumRange (e.g., 65535.0 for Q16). To bring pixel values strictly into the [0.0, 1.0] range, you must scale the values mathematically.

Method 1: Linear Min-Max Scaling (Recommended)

To stretch the minimum pixel intensity to 0.0 and the maximum pixel intensity to 1.0 across the entire image, use -auto-level combined with an arithmetic division:

magick input.exr -auto-level -evaluate Divide %[fx:quantumrange] output.exr
  • -auto-level: Linearly expands the dynamic range so the lowest pixel value in the image becomes 0 and the highest value becomes QuantumRange.
  • -evaluate Divide %[fx:quantumrange]: Divides every pixel value by the compiled maximum quantum value, scaling the entire data range into [0.0, 1.0].

Method 2: Direct Normalization with -fx

For direct mathematical normalization based on the absolute minimum and maximum values without modifying intermediate quantum mappings, use the -fx operator:

magick input.hdr -fx "(u-minima)/(maxima-minima)" output.exr
  • u: Represents the current pixel value.
  • minima: The smallest pixel value found in the channel/image.
  • maxima: The largest pixel value found in the channel/image.

Note: The -fx operator is interpreted per pixel and will run slower on large files than -evaluate.

Method 3: Absolute Scaling Without Min-Max Stretching

If your input image is already zero-referenced and you only want to scale the standard quantum representation to a unit scale (where reference white equals 1.0, while allowing out-of-range HDR values to remain above 1.0 or below 0.0), simply divide by the quantum range:

magick input.hdr -evaluate Divide %[fx:quantumrange] output.exr

Preserving Normalized Floating-Point Data

Standard formats (such as 8-bit PNG or JPEG) will quantize fractional values between 0.0 and 1.0, rendering them either entirely black or clipped. To maintain the normalized 32-bit or 16-bit floating-point data, output to formats like EXR, PFM, or floating-point TIFF:

magick input.exr -auto-level -evaluate Divide %[fx:quantumrange] -define quantum:format=floating-point output.tif
