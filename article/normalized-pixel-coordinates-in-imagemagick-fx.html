Normalized Pixel Coordinates in ImageMagick FX

This article explains how normalized pixel coordinates are accessed and calculated using ImageMagick’s -fx special effects operator. While graphics pipelines typically designate normalized horizontal and vertical coordinates as \(u\) and \(v\), ImageMagick handles these symbols differently within its mathematical expression parser. Below, you will learn the exact FX variables required to compute normalized coordinates, the distinction between ImageMagick's built-in image references and UV mapping, and practical examples for generating coordinate-based image manipulations.

Variables for Normalized Coordinates in FX

ImageMagick does not have dedicated single-letter FX variables representing normalized \(u\) and \(v\) coordinates directly. Instead, the letters u and v are reserved aliases for input images:

  • u: Refers to the first image in the current image sequence (index 0).
  • v: Refers to the second image in the current image sequence (index 1).

To access normalized pixel coordinates (ranging from 0.0 to 1.0), you must derive them using the standard pixel position and dimension variables provided by the FX engine:

  • i: The current horizontal pixel column index (ranges from 0 to w - 1).
  • j: The current vertical pixel row index (ranges from 0 to h - 1).
  • w: The total width of the image in pixels.
  • h: The total height of the image in pixels.

Computing \(u\) and \(v\) Coordinates

To obtain normalized \(u\) (horizontal) and \(v\) (vertical) coordinates across an image surface, use the following FX expressions:

  • Normalized Horizontal Coordinate (\(u\)): i/w
  • Normalized Vertical Coordinate (\(v\)): j/h

For exact center-pixel alignment, add a half-pixel offset:

  • Centered \(u\): (i+0.5)/w
  • Centered \(v\): (j+0.5)/h

Practical Usage Examples

1. Generating a Horizontal Linear Gradient

By mapping the normalized horizontal coordinate directly to pixel intensity, you create a gradient that scales consistently regardless of image dimensions:

magick -size 256x256 xc:black -fx "i/w" gradient_u.png

2. Generating a Centered Radial Vignette

Normalized coordinates simplify geometric distance formulas by making them independent of the source image's pixel dimensions:

magick -size 300x300 xc:black -fx "hypot(i/w - 0.5, j/h - 0.5) * sqrt(2)" radial_distance.png

In this expression, i/w - 0.5 shifts the horizontal origin to the center, j/h - 0.5 shifts the vertical origin to the center, and hypot() computes the Euclidean distance from that center.
