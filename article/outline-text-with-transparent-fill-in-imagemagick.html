Outline Text with Transparent Fill in ImageMagick

Rendering outlined text with a transparent interior in ImageMagick is a straightforward process achieved by combining stroke styling with a transparent fill color. This guide demonstrates how to configure the command-line options in both ImageMagick v7 and v6 to create hollow, stroked typography on transparent backgrounds or over existing images.

The Core Parameters

To make the inside of the text transparent while keeping the border visible, you must define three primary attributes:

  • -fill none: Disables the text fill, making the interior completely transparent.
  • -stroke <color>: Sets the color of the text outline (e.g., black, red, #FFFFFF).
  • -strokewidth <number>: Defines the thickness of the outline in pixels.

Method 1: Generating Standalone Outlined Text (Using label:)

The fastest way to render text on an automatically sized, transparent canvas is with the label: operator.

ImageMagick 7:

magick -background none \
       -font Arial \
       -pointsize 72 \
       -fill none \
       -stroke black \
       -strokewidth 3 \
       label:"Outlined Text" \
       outlined_output.png

ImageMagick 6:

convert -background none \
        -font Arial \
        -pointsize 72 \
        -fill none \
        -stroke black \
        -strokewidth 3 \
        label:"Outlined Text" \
        outlined_output.png

Method 2: Drawing Outlined Text on a Fixed Canvas (Using -annotate)

If you need a specific canvas dimension and explicit placement:

magick -size 800x300 xc:none \
       -font Helvetica-Bold \
       -pointsize 60 \
       -gravity center \
       -fill none \
       -stroke "#FF5733" \
       -strokewidth 2 \
       -annotate +0+0 "Custom Dimensions" \
       hollow_text.png

Method 3: Overlaying Outlined Text onto an Existing Image

To place hollow text directly onto a background photo or graphic:

magick input.jpg \
       -font Arial-Bold \
       -pointsize 48 \
       -gravity south \
       -fill none \
       -stroke white \
       -strokewidth 3 \
       -annotate +0+50 "Watermark Text" \
       watermarked_output.jpg

Important Tips

  1. Anti-Aliasing: Keep anti-aliasing enabled (default) for smoother edges. Do not pass +antialias unless pixelated text is desired.
  2. Stroke Clipping: Large stroke widths can clip at the image boundaries. If you use label:, increase the stroke gradually to ensure the glyph boundaries fit within the calculated canvas box.
  3. Format: Always save the standalone graphic in a format that supports alpha transparency, such as .png, .webp, or .tiff.
