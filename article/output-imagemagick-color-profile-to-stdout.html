Output ImageMagick Color Profile to Stdout

Extracting embedded color profile information from an image directly to standard output (stdout) is a common task for automated image processing workflows and color management audits. This article explains the exact ImageMagick commands required to dump both raw binary ICC profiles and human-readable profile metadata straight to your terminal or into a pipe without saving intermediary files.

Outputting the Raw ICC Profile to Stdout

To extract the raw, binary ICC/ICM profile data and stream it directly to stdout, specify the output format as icc:- or icm:-. The hyphen (-) tells ImageMagick to direct output to standard output rather than a physical file.

For ImageMagick version 7:

magick input.jpg icc:-

For ImageMagick version 6:

convert input.jpg icc:-

You can pipe this raw stream directly into another utility (such as an ICC profile parser or a checksum generator):

magick input.jpg icc:- | sha256sum

Outputting Human-Readable Profile Metadata to Stdout

If you need to inspect the textual description and metadata of the embedded profile rather than the raw binary payload, use the identify utility or the -format parameter.

Method 1: Formatted Profile Description

To output just the profile's text attributes to stdout:

magick identify -format "%[profile:icc]" input.jpg

Method 2: Comprehensive Profile Details

To extract the complete embedded profile section from the verbose image metadata:

magick identify -verbose input.jpg | sed -n '/Profile-icc/,/Profile-iptc/p'

(Alternatively, replace sed with grep -A 20 "Profile-icc" depending on your system's available tools).

Summary of Syntax Components

  • icc: / icm: — Specifies the International Color Consortium format for the output stream.
  • - — Directs the output to stdout instead of writing to a filesystem path.
  • %[profile:icc] — A format escape sequence that reads and outputs textual properties embedded within the image's ICC profile.
