Pack Non-Uniform Images into Sprites with ImageMagick

This guide explains how to combine multiple images of varying dimensions into a single, compact sprite texture map using ImageMagick. You will learn the specific command-line tools, parameters, and techniques required to handle non-uniform asset sizes, eliminate unnecessary transparent padding, and export a clean texture sheet suitable for web or game development.

Understanding the Challenge with Non-Uniform Images

Standard sprite generation often assumes uniformly sized tiles. When images have different widths and heights, simple grid tools either force uniform cell dimensions (adding wasteful whitespace) or misalign assets. ImageMagick solves this through its montage and magick (or convert) commands by dynamically adjusting tile bounds and handling transparency.

Method 1: Using the montage Command

The montage utility is the most direct way to assemble multiple images into a unified sheet. To prevent montage from resizing your non-uniform images into fixed bounding boxes, you must explicitly clear the default geometry dimensions.

Run the following command in your terminal:

magick montage *.png -background none -tile 4x -geometry +0+0 sprite_sheet.png

Key parameters explained:

  • *.png: Specifies all input images to be packed.
  • -background none: Ensures transparent spacing instead of the default white background.
  • -tile 4x: Constrains the output to 4 columns wide, letting the height expand automatically. You can also specify an exact grid like 4x3 or a fixed width by row such as x4.
  • -geometry +0+0: The most critical flag. Omitting the width/height values keeps the original image dimensions while setting the horizontal and vertical offsets to 0 pixels (no gaps).

To add padding between sprites to prevent texture bleeding in rendering engines, adjust the geometry offsets:

magick montage *.png -background none -tile 4x -geometry +2+2 sprite_sheet.png

Method 2: Dynamic Strip Appending

If you want tighter packing without aligning to a rigid grid, you can assemble images into horizontal or vertical strips using ImageMagick's append operators:

  • +append: Joins images horizontally side-by-side.
  • -append: Stacks images vertically on top of each other.

To create a single row of non-uniform images aligned along the top:

magick *.png -background none +append horizontal_strip.png

To create a single column:

magick *.png -background none -append vertical_strip.png

For a hybrid approach, group images of similar heights into separate horizontal strips first, then combine those strips vertically:

magick row1_*.png -background none +append row1.png
magick row2_*.png -background none +append row2.png
magick row1.png row2.png -background none -append final_packed_sheet.png

Extracting Sprite Coordinates and Offsets

When packing textures for game engines or CSS, you need the coordinates of each sprite. ImageMagick can calculate and output these coordinates during processing using the -format flag with identify properties:

magick *.png -format "%f: %w x %h @ %X, %Y\n" info:

For detailed JSON metadata containing the exact bounding box and position of each sprite when using montage:

magick montage *.png -background none -geometry +0+0 -verbose json: > sprites.json

This output provides the dimensions and placement offsets required to reference individual sub-textures in your rendering framework.
