Pad Image to 16:9 Ratio in ImageMagick

Padding an image to a 16:9 aspect ratio in ImageMagick allows you to fit any picture into widescreen dimensions without cropping or distorting the original content. By using the -extent operator alongside -gravity and -background, you can expand the image canvas to a standard 16:9 frame and fill the extra space with black, white, or transparent borders (letterboxing or pillarboxing).

The Basic Command Structure

To pad an image, you must define the background color, center the original image, and define the new canvas dimensions using -extent.

magick input.jpg -gravity center -background black -extent 1920x1080 output.jpg

Note: For ImageMagick version 6, replace magick with convert.

Method 1: Pad to a Fixed 16:9 Resolution

If you want your output to match a specific widescreen dimension (such as 1920x1080 or 3840x2160), resize the image first so it fits within the bounds, then pad the canvas using -extent:

magick input.jpg -resize 1920x1080 -gravity center -background black -extent 1920x1080 output.jpg
  • -resize 1920x1080: Scales the image down or up so that it fits entirely inside a 1920x1080 boundary without altering its original aspect ratio.
  • -gravity center: Positions the resized image in the exact middle of the canvas.
  • -background black: Sets the padding color to black. You can change this to white, #1a1a1a, or none (for transparent PNGs).
  • -extent 1920x1080: Expands the canvas to the specified 16:9 dimensions.

Method 2: Dynamic 16:9 Padding (Preserve Original Resolution)

If you do not want to scale the image up or down, but instead want to dynamically add padding to match a 16:9 ratio based on the image's original dimensions, use ImageMagick's built-in FX expressions:

magick input.jpg -gravity center -background black -extent "%[fx:w/h>16/9?w:h*16/9]x%[fx:w/h>16/9?w*9/16:h]" output.jpg

How the Dynamic Formula Works:

  • w/h > 16/9: Checks if the image is wider than 16:9.
  • Width calculation (%[fx:w/h>16/9?w:h*16/9]): If the image is wider than 16:9, the width remains unchanged (w). If the image is taller (like a portrait photo), the width expands to h * 16 / 9.
  • Height calculation (%[fx:w/h>16/9?w*9/16:h]): If the image is wider than 16:9, the height expands to w * 9 / 16. If the image is taller, the height remains unchanged (h).

Batch Processing Multiple Images

To pad an entire folder of images to 16:9 at 1920x1080 resolution, use magick mogrify:

magick mogrify -path ./padded_output -resize 1920x1080 -gravity center -background black -extent 1920x1080 *.jpg

This processes all .jpg files in the current directory and saves the 16:9 padded versions inside the padded_output folder.
