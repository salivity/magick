Pad Image to 16:9 with ImageMagick Extent

This guide explains how to pad any image to a 16:9 aspect ratio using ImageMagick's -extent operator. Whether you need to fit an image into a fixed 16:9 resolution like 1920x1080 or dynamically add letterbox or pillarbox black bars while preserving the original image's dimensions, ImageMagick provides efficient command-line options to achieve this without distorting or cropping the content.

Dynamic 16:9 Padding (Preserving Original Resolution)

To automatically determine whether to add horizontal or vertical black bars based on the source image dimensions, use ImageMagick's internal fx expressions with the magick command (ImageMagick v7):

magick input.jpg -gravity center -background black -extent "%[fx:w/h>16/9?w:h*16/9]x%[fx:w/h>16/9?w*9/16:h]" output.jpg

How It Works:

  • -gravity center: Centers the original image within the newly defined canvas area.
  • -background black: Sets the color of the padding bars to black.
  • -extent: Adjusts canvas dimensions without scaling the original pixels.
  • "%[fx:...]" : Evaluates the aspect ratio dynamically. If the image is wider than 16:9, it expands the height (w*9/16). If the image is taller than 16:9, it expands the width (h*16/9).

Fixed Resolution 16:9 Padding (e.g., 1920x1080)

If you want to scale the image to fit inside a standard 16:9 container and fill any remaining space with black bars:

magick input.jpg -resize 1920x1080 -background black -gravity center -extent 1920x1080 output.jpg

How It Works:

  • -resize 1920x1080: Proportionally scales the image so that its longest side fits within the 1920x1080 boundary.
  • -extent 1920x1080: Forces the final canvas to be exactly 1920x1080, filling any empty margins created around the resized image with the specified background color.

Batch Processing Multiple Images

To apply 16:9 black bar padding to an entire directory of images using ImageMagick v7:

magick mogrify -path ./output_dir -gravity center -background black -extent "%[fx:w/h>16/9?w:h*16/9]x%[fx:w/h>16/9?w*9/16:h]" *.jpg

This command processes all .jpg files in the current folder and saves the padded 16:9 images into the output_dir directory.
