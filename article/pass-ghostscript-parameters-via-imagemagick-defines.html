Pass Ghostscript Parameters via ImageMagick Defines

ImageMagick relies on Ghostscript as an external delegate to interpret and render PostScript, EPS, and PDF documents into raster images. While ImageMagick configures standard Ghostscript flags automatically during conversion, you can alter Ghostscript's behavior using ImageMagick's -define command-line option. This guide explains the specific syntax required to pass Ghostscript-related arguments using -define, covers the built-in coder definitions, and demonstrates how to supply arbitrary Ghostscript flags.

Built-In Delegate Defines for Ghostscript

ImageMagick maps several built-in -define keys directly to specific Ghostscript parameters before launching the delegate. The standard syntax requires placing the -define flag prior to loading the input file:

magick -define <coder>:<property>=<value> input.pdf output.png

For ImageMagick v6, replace magick with convert.

The most common built-in defines passed to Ghostscript include:

  • PDF Page Cropping:
    -define pdf:use-cropbox=true
    Instructs Ghostscript to use the CropBox rather than the default MediaBox (-dUseCropBox).
  • Error Handling:
    -define pdf:stop-on-error=true
    Forces Ghostscript to halt immediately when encountering corrupt objects or syntax errors (-dPDFSTOPONERROR).
  • Page Scaling:
    -define pdf:fit-page=geometry
    Forces Ghostscript to scale the rendering area to match the specified page geometry.
  • CMYK Profiles:
    -define ps:cmyk=true or -define ps:alpha=true
    Enforces specific color model handling within Ghostscript PostScript routines.

Passing Arbitrary Ghostscript Parameters

ImageMagick does not offer a universal, open-ended -define gs:args="..." key for arbitrary flags. Instead, to pass custom, arbitrary Ghostscript arguments—such as -dNOOUTERSAVE, -dTextAlphaBits, or rendering optimizations—you must override the entire delegate execution string using the ghostscript:command define:

magick -define ghostscript:command='gs [custom_flags] -sOutputFile="%o" "%i"' input.pdf output.png

In this syntax:

  • ghostscript:command redefines the shell command ImageMagick runs to process the document.
  • %i represents the input file path substituted by ImageMagick.
  • %o represents the output temporary file path generated by Ghostscript for ImageMagick to read.
  • [custom_flags] represents any valid Ghostscript parameters, such as -dPrinted=false, -dTextAlphaBits=4, or -dDownsampleColorImages=false.

Example: Enforcing Custom Antialiasing and Batch Mode

magick -define ghostscript:command='gs -q -dQUIET -dSAFER -dBATCH -dNOPAUSE -dNOPROMPT -dMaxBitmap=500000000 -dTextAlphaBits=4 -dGraphicsAlphaBits=4 -sDEVICE=pngalpha -sOutputFile="%o" "%i"' input.pdf output.png

Modifying the Delegates XML Alternative

When complex command strings become unwieldy in command-line defines, you can permanently alter the delegate invocation template inside delegates.xml. Locate the PDF decoding entry:

<delegate decode="pdf" encode="png" mode="bi" command="&quot;@PSDelegate@&quot; -q -dQUIET -dSAFER -dBATCH -dNOPAUSE -dNOPROMPT -dMaxBitmap=500000000 -dAlignToPixels=0 -dGridFitTT=2 &quot;-sDEVICE=pngalpha&quot; -dTextAlphaBits=%u -dGraphicsAlphaBits=%u &quot;-r%s&quot; %s &quot;-sOutputFile=%u&quot; &quot;-f%s&quot; &quot;-f%u&quot;"/>

Insert your persistent Ghostscript flags directly into the command attribute to apply them across all ImageMagick invocations without requiring runtime -define flags.
