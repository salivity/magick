Password Protect Multi-Page PDF in ImageMagick

Creating a password-encrypted, multi-page PDF using ImageMagick allows you to combine multiple images into a single secure document directly from the command line. This guide provides the exact syntax and options required to specify input files, set user and owner passwords, and define encryption levels to generate a secure PDF.

Basic Syntax

To create an encrypted multi-page PDF from multiple image files, use the magick command (ImageMagick v7) along with the -define operator to set the passwords and encryption settings:

magick page1.png page2.png page3.png -define pdf:user-password=UserPass123 -define pdf:owner-password=AdminPass123 -define pdf:encryption-level=128 output.pdf

If you are using ImageMagick version 6, replace magick with convert:

convert page1.png page2.png page3.png -define pdf:user-password=UserPass123 -define pdf:owner-password=AdminPass123 -define pdf:encryption-level=128 output.pdf

Batch Processing Multiple Files

To combine and encrypt all images in a directory matching a specific extension into a single multi-page PDF, use wildcard matching:

magick *.jpg -define pdf:user-password=UserPass123 -define pdf:owner-password=AdminPass123 output.pdf

Parameter Breakdown

  • Input Files (page1.png page2.png ... or *.jpg): The list of source image files in the order you want them to appear as pages in the final document.
  • -define pdf:user-password=<password>: Sets the document-open password. Anyone opening the file will be prompted to enter this password to view the contents.
  • -define pdf:owner-password=<password>: Sets the master/owner password, granting full permissions to edit, print, or modify security settings.
  • -define pdf:encryption-level=<level>: (Optional) Defines the encryption strength. Supported standard values typically include 40, 128, or 256 (AES), depending on the underlying Ghostscript/PDF delegate library installed on your system.
  • output.pdf: The destination path and filename for the encrypted multi-page PDF.
