Pipe Raw RGB Bytes to ImageMagick Stdin

Piping raw RGB byte arrays directly into ImageMagick's standard input (stdin) allows you to process in-memory pixel buffers efficiently without writing temporary files to disk. Because raw pixel arrays lack file headers containing dimensions and color encoding, you must explicitly instruct ImageMagick how to interpret the incoming stream. This guide explains the required command-line syntax, essential parameters, and practical implementation examples in Python and Node.js.

The Core Command-Line Syntax

To read raw pixel data from stdin, use the format identifier followed by a colon and a hyphen (rgb:- for 24-bit RGB or rgba:- for 32-bit RGBA).

magick -size 640x480 -depth 8 rgb:- output.png

If you are using ImageMagick v6, replace magick with convert:

convert -size 640x480 -depth 8 rgb:- output.png

Required Parameters

Raw byte streams contain no metadata. You must declare three critical parameters before the input indicator (rgb:-):

  1. -size <width>x<height>: Defines the pixel resolution of the incoming raw frame (e.g., -size 1920x1080).
  2. -depth <bits>: Specifies the bit depth per color channel. For standard 8-bit per channel arrays (0–255), use -depth 8. For 16-bit values, use -depth 16.
  3. rgb:-: Specifies both the pixel format (rgb) and the input source (- signifies standard input).

The expected byte payload size must match the calculation: width × height × channels × (depth / 8). For an 8-bit 640x480 RGB image, the stream must receive exactly 921,600 bytes (640 × 480 × 3).

Code Examples

Python (using subprocess)

You can stream raw bytes directly from libraries like NumPy or standard byte arrays using Python's subprocess.Popen:

import subprocess
import numpy as np

width, height = 300, 200

# Create a solid red RGB byte array
image_data = np.zeros((height, width, 3), dtype=np.uint8)
image_data[:, :] = [255, 0, 0]
raw_bytes = image_data.tobytes()

command = [
    "magick",
    "-size", f"{width}x{height}",
    "-depth", "8",
    "rgb:-",
    "output.jpg"
]

process = subprocess.Popen(command, stdin=subprocess.PIPE)
process.communicate(input=raw_bytes)

Node.js (using child_process)

In Node.js, create a buffer containing the raw values and pipe it to the spawned process:

const { spawn } = require('child_process');

const width = 300;
const height = 200;
const rawBytes = Buffer.alloc(width * height * 3);

// Fill buffer with blue pixels (R:0, G:0, B:255)
for (let i = 0; i < rawBytes.length; i += 3) {
  rawBytes[i] = 0;     // Red
  rawBytes[i + 1] = 0; // Green
  rawBytes[i + 2] = 255; // Blue
}

const magick = spawn('magick', [
  '-size', `${width}x${height}`,
  '-depth', '8',
  'rgb:-',
  'output.png'
]);

magick.stdin.write(rawBytes);
magick.stdin.end();

Alternative Channel Formats

ImageMagick supports various raw formats by altering the format prefix before :-:

  • rgba:-: 4 channels (Red, Green, Blue, Alpha).
  • bgr:-: 3 channels in reverse order (standard output for OpenCV arrays).
  • bgra:-: 4 channels in BGR order with Alpha.
  • gray:-: 1 channel grayscale image.
