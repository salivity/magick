Pipe Raw RGB Bytes to ImageMagick via Stdin

Reading raw RGB byte buffers into ImageMagick from standard input (stdin) requires explicitly defining image metadata that would otherwise exist in a standard file header. Because raw pixel streams contain no header information regarding dimensions, bit depth, or color layout, you must specify the image width, height, color depth, and format explicitly on the command line before telling ImageMagick to read from the standard input pipe.

The Basic Command Syntax

When reading from a pipe, specify the dimensions with -size, the bit depth with -depth, and the raw format combined with the standard input descriptor -:

cat raw_pixels.rgb | magick -size 1920x1080 -depth 8 rgb:- output.png

For ImageMagick v6, replace magick with convert.

Required Parameters

  • -size <width>x<height>: Tells ImageMagick the exact resolution of the incoming buffer (for example, -size 640x480).
  • -depth <bits>: Specifies the number of bits per channel. The standard is typically 8, but it can be 16 or 32 depending on your source data.
  • rgb:-: Specifies the pixel arrangement and source. The rgb: prefix forces ImageMagick to decode the stream as interleaved Red, Green, and Blue bytes. The hyphen (-) tells it to read from standard input.

Common Channel Formats

ImageMagick supports various raw pixel arrangements. Match the prefix to your byte stream:

  • RGB (rgb:-): Interleaved 3-channel data (R, G, B, R, G, B...).
  • RGBA (rgba:-): Interleaved 4-channel data including alpha (R, G, B, A...).
  • BGR (bgr:-) or BGRA (bgra:-): Interleaved data with blue ordered first.
  • Grayscale (gray:-): Single-channel luminescence data.

Practical Piping Examples

1. Piping from FFmpeg

To extract a single raw frame from a video and convert it directly into a JPEG:

ffmpeg -i input.mp4 -vframes 1 -f rawvideo -pix_fmt rgb24 - | magick -size 1920x1080 -depth 8 rgb:- frame.jpg

2. Streaming from Python

You can write raw byte buffers directly to an ImageMagick subprocess without touching the disk:

import subprocess
import numpy as np

# Generate a 640x480 RGB image (noise)
width, height = 640, 480
raw_bytes = np.random.randint(0, 256, (height, width, 3), dtype=np.uint8).tobytes()

# Run ImageMagick process
cmd = ['magick', '-size', f'{width}x{height}', '-depth', '8', 'rgb:-', 'output.png']
process = subprocess.Popen(cmd, stdin=subprocess.PIPE)
process.communicate(input=raw_bytes)

3. Streaming from Node.js

const { spawn } = require('child_process');

const width = 800;
const height = 600;
const buffer = Buffer.alloc(width * height * 3, 255); // White image

const magick = spawn('magick', [
  '-size', `${width}x${height}`,
  '-depth', '8',
  'rgb:-',
  'output.png'
]);

magick.stdin.write(buffer);
magick.stdin.end();
