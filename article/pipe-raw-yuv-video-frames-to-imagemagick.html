Pipe Raw YUV Video Frames to ImageMagick

Piping uncompressed YUV video frames directly into ImageMagick allows for fast, memory-efficient image processing without writing intermediate files to disk. Because raw YUV contains no header data, you must extract the raw video stream using a tool like FFmpeg, pipe it through standard input (stdin), and explicitly define the dimensions, sampling factor, and color depth in ImageMagick.

Basic Pipeline Command

To decode a video stream and pipe the raw YUV frames directly into ImageMagick for processing, use the following command structure:

ffmpeg -i input.mp4 -f rawvideo -pix_fmt yuv420p - | magick -size 1920x1080 -depth 8 -sampling-factor 4:2:0 yuv:- -negate output_%03d.png

For legacy ImageMagick v6 installations, replace magick with convert.

Breakdown of Flags

FFmpeg (Producer)

  • -i input.mp4: Specifies the input video file.
  • -f rawvideo: Forces the output container format to be raw, uncompressed video frames.
  • -pix_fmt yuv420p: Sets the pixel format to standard planar YUV 4:2:0. Other options include yuv422p or yuv444p.
  • -: Sends the raw output directly to standard output (stdout) instead of a file.

ImageMagick (Consumer)

  • -size 1920x1080: Defines the frame width and height. This must match the source resolution exactly, as raw video streams do not contain metadata headers.
  • -depth 8: Specifies an 8-bit color depth per channel.
  • -sampling-factor 4:2:0: Matches the chroma subsampling configured in the producer command (4:2:0 for yuv420p, 4:2:2 for yuv422p, or 4:4:4 for yuv444p).
  • yuv:-: Instructs ImageMagick to interpret the stream from standard input (stdin) as raw YUV data.
  • -negate output_%03d.png: Applies any desired ImageMagick operations (such as -negate, -resize, or -blur) and writes the output frames as indexed PNG files.

Processing a Single Frame

To process a single specific frame instead of the entire video stream, limit the output in FFmpeg using -vframes 1 alongside an optional seek timestamp:

ffmpeg -ss 00:00:05 -i input.mp4 -vframes 1 -f rawvideo -pix_fmt yuv420p - | magick -size 1920x1080 -depth 8 -sampling-factor 4:2:0 yuv:- output_frame.jpg

This approach extracts a single frame at the 5-second mark and converts it directly to a processed JPEG image.
