Preserve CMYK Profile in JPEG XL with ImageMagick

This article provides the exact ImageMagick commands needed to convert or save images to the JPEG XL (JXL) format while preserving CMYK color profiles. Readers will learn the correct syntax to ensure print-ready CMYK data and embedded ICC color profiles are retained without automatic conversion to sRGB.

The Command to Preserve Embedded CMYK Profiles

By default, modern versions of ImageMagick (ImageMagick 7) preserve embedded ICC profiles unless the -strip option is explicitly called. However, to guarantee that an existing CMYK colorspace and its associated ICC profile are strictly retained when encoding to JPEG XL, run:

magick input_cmyk.tif -colorspace CMYK output.jxl

Embedding an Explicit CMYK Profile

If the source file lacks an embedded profile, or if you need to enforce a specific CMYK color profile (such as ISO Coated or U.S. Web Coated) during conversion, use the -profile option:

magick input.tif -profile "/path/to/CMYK_Profile.icc" output.jxl

Important Flags Explained

  • magick: Invokes ImageMagick 7. (Use convert if working on legacy ImageMagick 6 installations).
  • -colorspace CMYK: Explicitly instructs ImageMagick to maintain the four-channel CMYK color space and prevents the delegate encoder (libjxl) from attempting a default conversion to RGB.
  • -profile [path]: Embeds the specified ICC profile file directly into the output JXL container metadata.
  • Avoid -strip: Do not include -strip in the command chain, as this removes all metadata, including embedded ICC color profiles.

Verifying the JXL Profile

After conversion, verify that the CMYK profile was successfully retained in the JPEG XL file by running:

magick identify -verbose output.jxl | grep -E "Colorspace|Profile-icc"

The output should confirm Colorspace: CMYK along with the details of the embedded ICC profile.
