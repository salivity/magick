Preserving Photoshop Layers in TIFF via ImageMagick

Exporting layered TIFF files from ImageMagick while maintaining compatibility with Adobe Photoshop requires the -define tiff:preserve-layers=true configuration. This article covers the exact syntax required to retain Photoshop layer data during export, how ImageMagick handles layer metadata, and essential command configurations to ensure your layered workflow remains intact.

The Define for Preserving Photoshop Layers

To ensure ImageMagick retains Adobe Photoshop layer data when exporting or converting to TIFF, use the following define:

-define tiff:preserve-layers=true

By default, ImageMagick processes multi-image sequences into standard multi-page (multi-directory) TIFF files rather than Adobe's proprietary layer structure. Adding -define tiff:preserve-layers=true instructs the TIFF encoder to format the layer data so that Adobe Photoshop recognizes each sub-image as an independent layer in the Layers panel upon opening.

Basic Command Syntax

When converting from a layered source (such as a Photoshop PSD or an existing layered TIFF), place the define before the output file:

magick input.psd -define tiff:preserve-layers=true output.tif

If you are updating or modifying an existing TIFF file that already contains Photoshop layers, ensure that ImageMagick does not discard the layer block upon reading:

magick -define tiff:ignore-layers=false input.tif -define tiff:preserve-layers=true output.tif

How Photoshop Layers Work Inside TIFF Containers

Adobe Photoshop does not store layers as standard TIFF directory pages. Instead, it embeds standard flattened pixel data into the main TIFF image directory and packs the layer stack, blending modes, masks, and metadata into a private TIFF tag: Tag 37724 (ImageSourceData).

When standard TIFF utilities process an image, they only see the primary composite image and typically strip unknown private tags. Setting -define tiff:preserve-layers=true directs ImageMagick's libtiff delegate to structure and write the layer streams into the expected ImageSourceData block.

Key Considerations for Layered TIFF Exports

  • Avoid Flattening: Do not use operators like -flatten, -merge, or -layers merge in your command sequence, as these will collapse your layer stack into a single frame before writing.
  • Color Profiles and Metadata: Preserve embedded Photoshop profiles (such as 8BIM clipping paths and color profiles) by avoiding the -strip command.
  • File Size: Layered TIFFs contain both the composite raster and the raw layer streams, making them significantly larger than standard single-page or flattened TIFFs.
  • Compression: You can pair the layer preservation define with standard TIFF compression methods (such as -compress zip or -compress lzw) to manage file size without corrupting layer data.
