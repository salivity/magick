Process OpenEXR Floating-Point in ImageMagick

OpenEXR is a high dynamic range (HDR) image format supporting 16-bit and 32-bit floating-point channels, widely used in visual effects and computer graphics. Processing these channels in ImageMagick requires an HDRI-enabled build to preserve non-clamped, high-precision color values across transformations. This guide covers how to verify your environment, manipulate floating-point data, extract or combine specific channels, and export accurate EXR files.

1. Verify HDRI Support in ImageMagick

Standard builds of ImageMagick clamp pixel values to an integer range (such as 0 to 255 for 8-bit, or 0 to 65535 for 16-bit). To retain floating-point numbers outside the standard [0.0, 1.0] range without clipping, you must use a version built with High Dynamic Range Imaging (HDRI) enabled.

Check your current installation:

magick -version

Look for HDRI and OpenEXR in the Features and Delegates lines:

  • Features: Should include HDRI (e.g., Q16HDRI or Q32HDRI).
  • Delegates: Should list openexr.

2. Inspecting OpenEXR Channels

To view the embedded channels, bit depth, and metadata of an EXR file:

magick identify -verbose input.exr

This output displays the channel layout (RGBA or arbitrary custom channels), channel depth (Half or Float), and color space information.

3. Preserving Floating-Point Precision on Export

When writing data back to an EXR file, specify the floating-point quantum format and the desired bit depth (16-bit half-float or 32-bit full float):

# Export as 16-bit Half-Float EXR
magick input.exr -define quantum:format=floating-point -depth 16 output_half.exr

# Export as 32-bit Float EXR
magick input.exr -define quantum:format=floating-point -depth 32 output_float.exr

4. Adjusting Floating-Point Values

OpenEXR images store linear data. Common processing tasks include exposure scaling, gamma correction, and math operations across the floating-point range:

  • Adjust Exposure (Linear Multiplication):

    magick input.exr -evaluate multiply 2.5 -define quantum:format=floating-point -depth 16 exposed.exr

  • Apply Bias/Offset:

    magick input.exr -evaluate add 0.1 -define quantum:format=floating-point -depth 16 offset.exr

  • Apply Gamma Correction:

    magick input.exr -gamma 2.2 -define quantum:format=floating-point -depth 16 gamma_corrected.exr

5. Extracting and Combining Individual Channels

To process channels independently (e.g., normal passes, depth maps, or individual color channels):

  • Extract a Single Channel:

    # Extract the Red channel to a grayscale floating-point EXR
magick input.exr -channel R -separate -define quantum:format=floating-point -depth 16 red_channel.exr

  • Extract All Channels into Separate Files:

    magick input.exr -separate -define quantum:format=floating-point -depth 16 channel_%d.exr

  • Combine Separate Channels into a Multichannel EXR:

    magick channel_0.exr channel_1.exr channel_2.exr -combine -define quantum:format=floating-point -depth 16 combined.exr

6. Managing EXR Compression

OpenEXR supports various compression schemes. You can set the compression algorithm via -define exr:compression:

# Options: none, rle, zip, zips, piz, pxr24, b44, b44a, dwaa, dwab
magick input.exr -define exr:compression=zip -define quantum:format=floating-point -depth 16 output_compressed.exr
