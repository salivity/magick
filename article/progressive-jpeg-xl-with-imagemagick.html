Progressive JPEG XL With ImageMagick

Progressive decoding allows JPEG XL (JXL) images to display lower-resolution previews that progressively sharpen as data downloads. ImageMagick supports this feature by exposing specialized encoder settings through command-line defines that interface directly with the underlying libjxl library.

Primary Define Settings

To configure progressive-decoding passes in JPEG XL files using ImageMagick, use the -define flag followed by the appropriate jxl: parameter:

  • jxl:progressive=true
    Enables progressive encoding mode. This is the main switch required to instruct the encoder to output data in progressive order.

  • jxl:progressive-dc=<level>
    Controls the progressive decoding of DC (low-frequency) information, producing the initial blurry preview.

    • 0: Disables progressive DC.
    • 1: Enables standard progressive DC (displays an 8x downsampled preview).
    • 2: Enables 64x downsampled DC preview followed by the 8x DC pass.

  • jxl:progressive-ac=true
    Enables progressive decoding of AC (high-frequency detail) passes, allowing the image to sharpen progressively through multiple passes after the initial DC frame is loaded.

  • jxl:responsive=1
    Enables responsive/saliency-based progression, prioritizing important parts of the image (often used in modular mode or combined with progressive passes).

Usage Example

To convert an image to a progressive JPEG XL file with both progressive DC and AC passes enabled, run:

magick input.png \
  -define jxl:progressive=true \
  -define jxl:progressive-dc=1 \
  -define jxl:progressive-ac=true \
  output.jxl

Alternatively, setting the standard ImageMagick interlace flag also triggers progressive encoding in the JXL delegate:

magick input.png -interlace Plane output.jxl
