Python Wand Crop Image with Coordinate Offsets

This article explains how to crop images using coordinate offsets in Python Wand, the ctypes-based ImageMagick binding. You will learn about the crop() method, understand how its positional arguments define crop boundaries, and review a concise code example demonstrating how to execute coordinate-based cropping in your projects.

The primary method used to crop an image with coordinate offsets in Python Wand is Image.crop(). This method interfaces directly with ImageMagick's cropping routines, allowing you to specify starting offset points along the X and Y axes, as well as the dimensions or end boundaries of the extracted region.

The crop() Method Syntax

The crop() method accepts the following key parameters:

  • left: The starting horizontal offset (X-coordinate) from the left edge of the image.
  • top: The starting vertical offset (Y-coordinate) from the top edge of the image.
  • width: The horizontal width of the cropped area starting from left.
  • height: The vertical height of the cropped area starting from top.
  • right: The ending horizontal coordinate (alternative to setting width).
  • bottom: The ending vertical coordinate (alternative to setting height).
  • reset_coords: A boolean flag (defaults to True) that resets the virtual canvas coordinates to 0,0, preventing offset issues in downstream processing or file formats like PNG and GIF.

Implementation Example

To crop an image using coordinate offsets, open the image using the Image context manager, call the crop() method with your specified left and top offsets, and save the result:

from wand.image import Image

# Define coordinate offsets and dimensions
x_offset = 50
y_offset = 100
target_width = 300
target_height = 200

with Image(filename='input.jpg') as img:
    # Crop using starting offsets and dimensions
    img.crop(left=x_offset, top=y_offset, width=target_width, height=target_height)
    img.save(filename='cropped_output.jpg')

Alternatively, you can crop using absolute boundary coordinates instead of width and height:

with Image(filename='input.jpg') as img:
    # Crop using left, top, right, and bottom boundary coordinates
    img.crop(left=50, top=100, right=350, bottom=300)
    img.save(filename='boundary_output.jpg')

Wand also supports Python slice notation on the image object itself (e.g., img[50:350, 100:300]), but invoking the explicit crop() method provides full control over coordinate resets and parameter definitions.
