Query Image Width in ImageMagick 7 Inline Formula

This guide explains how to reference and calculate image width dynamically using inline mathematical formulas in ImageMagick 7. By utilizing ImageMagick's built-in fx expression engine, you can read the width of an image directly within command-line operations to perform real-time resizing, cropping, and canvas generation without external scripts.

The Basic Syntax

Inside an inline FX formula denoted by %[fx:...], the width of the current image is represented simply by the lowercase letter w.

%[fx:w]

When placed inside command arguments, ImageMagick evaluates the expression inside the brackets and returns the numeric pixel value or calculation result.

Syntax in Multi-Image Contexts

When working with multiple images in a single command, you can query the width of specific images in the sequence by prepending the image index or identifier to .w:

  • w or s.w: Width of the current image in the sequence.
  • u.w or u[0].w: Width of the first image in the current list.
  • v.w or u[1].w: Width of the second image in the current list.
  • u[n].w: Width of the image at index n.

Practical Examples

1. Printing the Calculated Width

To output an image's width or a modified calculation to standard output:

magick input.png -format "%[fx:w]\n" info:

To calculate half the width:

magick input.png -format "%[fx:w/2]\n" info:

2. Resizing Based on Inline Width Calculations

ImageMagick 7 allows you to dynamically resize an image relative to its own dimensions:

magick input.png -resize "%[fx:w*0.75]x" output.png

3. Creating a Responsive Canvas

You can query the width of a loaded image to set the dimensions of an operation or a new canvas:

magick input.png -background black -extent "%[fx:w+100]x%[fx:h+100]" output.png

4. Relative Calculations Between Two Images

To scale the second image (v) to match the width of the first image (u):

magick base.png overlay.png -resize "%[fx:u.w]x" result.png
