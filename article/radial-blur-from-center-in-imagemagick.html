Radial Blur from Center in ImageMagick

This article provides the exact command-line syntax and parameter usage for applying a radial blur centered on an image using ImageMagick. You will learn the commands for both ImageMagick 7 and ImageMagick 6, how the blur angle works, and how to control the effect.

ImageMagick 7 Syntax

In ImageMagick 7, the -radial-blur operator has been renamed to -rotational-blur. By default, the rotation originates from the exact center of the image.

magick input.jpg -rotational-blur <angle> output.jpg
  • <angle>: The degree of rotational blur to apply (e.g., 5, 10, 45). A higher number creates a stronger circular blur around the center.

Example:

magick photo.jpg -rotational-blur 15 blurred_center.jpg

ImageMagick 6 Syntax

For ImageMagick 6, use the legacy convert command with the -radial-blur parameter:

convert input.jpg -radial-blur <angle> output.jpg

Example:

convert photo.jpg -radial-blur 15 blurred_center.jpg

Adjusting the Origin Point

By default, ImageMagick centers the radial blur on the middle coordinates of the image (50%,50%). If you need to blur from a specific offset rather than the default center, you can define the origin using the -distort operator or use -page offsets prior to applying the blur.

For standard center-aligned radial blurs, specifying the angle value with -rotational-blur (v7) or -radial-blur (v6) is all that is required.
