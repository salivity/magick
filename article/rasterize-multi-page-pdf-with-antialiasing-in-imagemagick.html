Rasterize Multi-Page PDF with Antialiasing in ImageMagick

Rasterizing a multi-page PDF into high-quality image files requires balancing resolution, vector rendering, and smooth edge rendering. ImageMagick relies on Ghostscript as its delegate to interpret PDF files, allowing you to control text and graphic antialiasing alongside output resolution. This guide explains how to convert all pages of a PDF into smooth, rasterized image formats such as PNG or JPEG using the proper command-line arguments.

The Basic Command

To rasterize every page of a multi-page PDF with antialiasing and high clarity, use the magick command (ImageMagick v7) or convert (ImageMagick v6):

magick -density 300 -antialias input.pdf -background white -alpha remove -alpha off output_%03d.png

Breakdown of Key Parameters

  • -density 300: Sets the horizontal and vertical resolution to 300 DPI. This must be placed before the input PDF file name so Ghostscript renders the vector data at high resolution before rasterization occurs.
  • -antialias: Enables the antialiasing rendering filter for fonts and vector shapes. While enabled by default in modern builds, explicitly defining it ensures smooth edges on text and line art.
  • input.pdf: The source multi-page document. By not specifying a page index, ImageMagick processes all pages automatically.
  • -background white -alpha remove -alpha off: Replaces any default transparent PDF background with solid white, preventing black or muddy backgrounds during format conversions.
  • output_%03d.png: The output naming pattern. The %03d format specifier generates zero-padded sequential numbers for each page (e.g., output_000.png, output_001.png).

Fine-Tuning Text and Vector Smoothness

If standard antialiasing produces text that appears too thin or slightly blurred, adjust the Ghostscript rendering defines directly within ImageMagick:

magick -density 300 -define pdf:use-cropbox=true -define filter:blur=0.8 -antialias input.pdf page_%d.png
  • -define pdf:use-cropbox=true: Restricts the rasterized area to the PDF's defined CropBox rather than the full MediaBox.
  • -define filter:blur=0.8: Adjusts the antialiasing sharpness during scaling and downsampling operations.

Converting to JPEG

When rasterizing directly to JPEG instead of PNG, include a quality setting:

magick -density 300 -antialias input.pdf -background white -flatten -quality 95 output_%02d.jpg

Using -flatten guarantees each layer and page background merges correctly into the non-transparent JPEG format.
