Rasterize SVG with Embedded CSS in ImageMagick

Rasterizing SVG files that contain embedded CSS styling using ImageMagick often results in broken or missing styles because the utility's default internal renderer lacks full CSS specification support. This guide explains how to configure and run ImageMagick to properly parse embedded <style> blocks and CSS classes by utilizing specialized rendering delegates such as librsvg or Inkscape. Following these steps ensures your SVG assets convert accurately to raster formats like PNG, JPEG, or WebP without losing their visual styling.

Why ImageMagick Fails on Embedded CSS

By default, ImageMagick frequently falls back on its internal parser, MSVG (Micro-SVG). While lightweight and dependency-free, MSVG does not support embedded CSS stylesheets, advanced selectors, or modern SVG styling techniques. To preserve these styles, ImageMagick must delegate the parsing and rasterization process to an external library that fully implements the SVG specification.

Method 1: Use the RSVG Delegate

The most common and efficient solution is librsvg. When built with librsvg support, ImageMagick can parse embedded CSS declarations accurately.

1. Verify RSVG Support

Check if your ImageMagick installation includes librsvg by running:

magick -version

Look at the Delegates line in the output. If rsvg is listed, support is already enabled. If it is missing, install the librsvg development package for your operating system (e.g., librsvg2-bin or librsvg2-dev on Debian/Ubuntu, or librsvg via Homebrew on macOS) and rebuild or reinstall ImageMagick.

2. Explicitly Invoke RSVG

Force ImageMagick to use the RSVG engine by prepending the delegate prefix to your input filename:

magick RSVG:input.svg output.png

To control output resolution and preserve transparency, specify the density and background:

magick -density 300 -background none RSVG:input.svg output.png

Method 2: Use the Inkscape Delegate

For complex SVG files utilizing CSS3 features, CSS variables, or web fonts, librsvg may still produce rendering discrepancies. Inkscape provides the most comprehensive SVG/CSS implementation available for command-line rasterization.

1. Install Inkscape

Ensure Inkscape is installed on your system and accessible in your system PATH:

inkscape --version

2. Configure delegates.xml

ImageMagick manages delegate commands through a configuration file named delegates.xml. Locate this file using:

magick -list delegate

Find the entry that handles SVG rendering and update or add the XML definition to call Inkscape:

<delegate decode="svg" command="&quot;inkscape&quot; &quot;%i&quot; --export-filename=&quot;%o&quot;"/>

3. Run the Conversion

Once configured, ImageMagick automatically delegates the file conversion to Inkscape when reading any standard SVG input:

magick input.svg output.png

Using either librsvg explicitly or configuring Inkscape as your primary delegate resolves rendering issues, ensuring that all embedded stylesheets, classes, and inline styles are honored during rasterization.
