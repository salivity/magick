Read and Write Memory Buffers in ImageMagick C API

This guide explains how to read and write in-memory image buffers directly using ImageMagick’s C API (MagickWand). By bypassing the filesystem, you can process encoded image formats like JPEG and PNG directly from RAM, as well as import and export raw pixel data. Using blob functions and pixel transfer methods ensures maximum performance in streaming, microservice, and embedded applications.

Reading Encoded Buffers with MagickReadImageBlob

To read an encoded image file stored in memory (such as a buffer loaded from a network socket or database), use the MagickReadImageBlob function. This function parses the raw byte array and initializes the image container within the wand.

#include <wand/MagickWand.h>

MagickBooleanType status;
MagickWand *wand = NewMagickWand();

// unsigned char *input_buffer contains the encoded image data (e.g., PNG, JPEG)
// size_t buffer_length contains the size of the buffer in bytes
status = MagickReadImageBlob(wand, input_buffer, buffer_length);

if (status == MagickFalse) {
    // Handle read error
}

Writing Encoded Buffers with MagickGetImageBlob

To export an image to an encoded memory buffer instead of writing it to disk, set the desired output format with MagickSetImageFormat and retrieve the buffer using MagickGetImageBlob. ImageMagick allocates the necessary memory, which must be freed using MagickRelinquishMemory.

size_t output_length = 0;
unsigned char *output_buffer = NULL;

// Set the target format (e.g., "JPEG", "PNG", "WEBP")
MagickSetImageFormat(wand, "JPEG");
MagickSetImageCompressionQuality(wand, 85);

// Generate the memory buffer
output_buffer = MagickGetImageBlob(wand, &output_length);

if (output_buffer != NULL) {
    // output_buffer now contains the compressed image bytes
    // output_length contains the total byte count
    
    // Free the allocated buffer when done
    output_buffer = (unsigned char *)MagickRelinquishMemory(output_buffer);
}

Reading and Writing Raw Pixel Buffers

If your application requires raw, uncompressed pixel arrays (such as RGBA, RGB, or BGR byte buffers), use the direct pixel import and export functions.

Exporting Raw Pixels

To dump raw pixel components from an image into a pre-allocated memory buffer:

size_t width = MagickGetImageWidth(wand);
size_t height = MagickGetImageHeight(wand);
const char *map = "RGBA"; // Desired channel layout
StorageType type = CharPixel; // 1 byte per channel (0-255)

// Allocate memory: width * height * 4 channels
unsigned char *raw_pixels = (unsigned char *)malloc(width * height * 4);

status = MagickExportImagePixels(wand, 0, 0, width, height, map, type, raw_pixels);

Importing Raw Pixels

To create or overwrite an image from an uncompressed array of raw pixel values:

// Create a blank canvas or configure an existing wand
MagickConstituteImage(wand, width, height, "RGBA", CharPixel, raw_pixels);

// Or overwrite a region of an existing image
MagickImportImagePixels(wand, 0, 0, width, height, "RGBA", CharPixel, raw_pixels);

Complete Example: In-Memory Conversion

Below is a complete, minimal lifecycle demonstrating reading a JPEG buffer, converting it, and writing a PNG buffer:

#include <stdio.h>
#include <stdlib.h>
#include <wand/MagickWand.h>

int main() {
    MagickWandGenesis();
    MagickWand *wand = NewMagickWand();

    // Example dummy allocation (replace with real data)
    size_t input_size = 1024;
    unsigned char *input_data = (unsigned char *)malloc(input_size);

    if (MagickReadImageBlob(wand, input_data, input_size) == MagickTrue) {
        // Change format to PNG
        MagickSetImageFormat(wand, "PNG");

        size_t output_size = 0;
        unsigned char *output_data = MagickGetImageBlob(wand, &output_size);

        if (output_data) {
            // Process output_data (size: output_size)
            MagickRelinquishMemory(output_data);
        }
    }

    free(input_data);
    DestroyMagickWand(wand);
    MagickWandTerminus();
    return 0;
}
