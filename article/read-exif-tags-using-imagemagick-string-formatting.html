Read EXIF Tags Using ImageMagick String Formatting

Extracting specific metadata from images is a common task in automation and asset management workflows. This guide demonstrates how to extract individual EXIF tag values directly from the command line using ImageMagick's string formatting features, allowing you to retrieve precise metadata fields without parsing entire metadata dumps.

Basic Syntax

To read a specific EXIF tag, use the -format option combined with the %[exif:TagName] property escape.

For ImageMagick version 7:

magick identify -format "%[exif:TagName]" image.jpg

Alternatively, using the general magick tool with info::

magick image.jpg -format "%[exif:TagName]\n" info:

For ImageMagick version 6:

identify -format "%[exif:TagName]\n" image.jpg

Note: The \n sequence adds a newline to the output, which prevents the terminal prompt from printing directly after the output value.

Common EXIF Tag Examples

Below are common examples for retrieving specific metadata fields:

1. Camera Make and Model

magick identify -format "Camera: %[exif:Make] %[exif:Model]\n" image.jpg

2. Date and Time Original

magick identify -format "Date Taken: %[exif:DateTimeOriginal]\n" image.jpg

3. Exposure and Aperture

magick identify -format "Exposure Time: %[exif:ExposureTime] | F-Number: %[exif:FNumber]\n" image.jpg

4. ISO Speed Rating

magick identify -format "ISO: %[exif:ISOSpeedRatings]\n" image.jpg

5. GPS Coordinates

magick identify -format "Latitude: %[exif:GPSLatitude] %[exif:GPSLatitudeRef]\nLongitude: %[exif:GPSLongitude] %[exif:GPSLongitudeRef]\n" image.jpg

How to Find Available Tag Names

EXIF tag names are case-sensitive and must match the tags stored inside the image file. To view all available EXIF properties for a file, run:

magick identify -format "%[exif:*]" image.jpg

This outputs a key-value list of all EXIF data embedded in the image, allowing you to find the exact property name required for your formatting string.
