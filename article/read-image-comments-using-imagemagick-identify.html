Read Image Comments Using ImageMagick Identify

ImageMagick provides powerful command-line utilities for viewing and manipulating image metadata. This guide explains the exact identify commands required to extract and read embedded comment fields from various image formats, such as JPEG, PNG, and GIF.

The Basic Command

To read only the embedded comment field from an image, use the -format option with the %c or %[comment] format specifier.

Syntax for ImageMagick v6:

identify -format "%c" image.jpg

Alternatively:

identify -format "%[comment]\n" image.jpg

Syntax for ImageMagick v7:

In ImageMagick version 7, utility commands are generally run through the main magick binary:

magick identify -format "%c" image.jpg

How It Works

  • identify: The utility that displays format, characteristics, and metadata of image files.
  • -format: Allows you to customize the output using specific property format codes.
  • "%c" or "%[comment]": The specific format placeholder that targets the embedded text comment field inside the image header.
  • \n: Appends a newline to the output for cleaner display in the terminal.

Viewing All Metadata Including Comments

If you want to view the entire metadata profile of an image (which includes the comment field along with EXIF, IPTC, and dimension data), use the verbose flag:

identify -verbose image.jpg

Look for the Comment: or Properties: section in the generated output to find the embedded text.

Reading Comments from Multiple Images

To extract comments from all images in a directory, pass a wildcard expression:

identify -format "%f: %c\n" *.jpg

In this command, %f prints the filename followed by the embedded comment (%c). If an image does not have an embedded comment, the comment field will simply return empty.
