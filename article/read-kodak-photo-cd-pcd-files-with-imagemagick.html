Read Kodak Photo CD PCD Files with ImageMagick

This article provides a guide on how to configure and use ImageMagick to read, decode, and extract specific resolutions from multi-resolution Kodak Photo CD (PCD) files. It covers the syntax required to select specific image dimensions, details the standard resolution layers available in PCD archives, and explains essential color management options to ensure accurate image rendering.

PCD Resolution Selection Syntax

Kodak Photo CD files store multiple resolutions of a single scan within a single file, arranged in a proprietary hierarchy based on a standard "Base" resolution (768 × 512 pixels).

To select a specific resolution in ImageMagick, append the desired resolution index in square brackets directly after the input filename:

magick "input.pcd[index]" output.jpg

(Note: For ImageMagick 6, replace magick with convert.)

PCD Resolution Index Reference

The bracket index corresponds directly to the internal image component (overview to maximum resolution):

  • [0] — Base/16: 192 × 128 pixels (used for thumbnails and contact sheets)
  • [1] — Base/4: 384 × 256 pixels
  • [2] — Base: 768 × 512 pixels (standard TV/monitor display resolution)
  • [3] — 4Base: 1536 × 1024 pixels (standard quality print resolution)
  • [4] — 16Base: 3072 × 2048 pixels (high-resolution archive/print)
  • [5] — 64Base: 6144 × 4096 pixels (available only on Pro Photo CD formats)

If no index is supplied, ImageMagick defaults to reading all resolutions or selects the Base resolution depending on the installed delegate configuration. Specifying index [3] or [4] is recommended for standard digital conversion.

Example Commands

Extracting a Specific Resolution

To extract the standard high-resolution 16Base image (3072 × 2048):

magick "scan01.pcd[4]" output.tiff

Handling PhotoYCC Color Space

Kodak PCD files store color data in the proprietary PhotoYCC color space rather than standard RGB. While ImageMagick automatically attempts to convert PhotoYCC to RGB, specifying the colorspace explicitly prevents color shifts or dark conversions:

magick "scan01.pcd[3]" -colorspace sRGB output.png

Batch Converting Highest Standard Resolution

To convert an entire folder of PCD files to JPEG at 4Base (1536 × 1024) resolution:

magick mogrify -format jpg -define pcd:size=1536x1024 *.pcd

Alternatively, use the bracket index in a loop to guarantee exact resolution indexing:

for file in *.pcd; do
    magick "$file[3]" -colorspace sRGB "${file%.pcd}.jpg"
done
