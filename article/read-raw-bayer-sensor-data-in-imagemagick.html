Read Raw Bayer Sensor Data in ImageMagick

Reading raw Bayer sensor data into ImageMagick requires explicitly defining the image parameters via the command line because raw sensor files lack metadata headers. This guide details the exact syntax, flags, and format prefixes needed to import, interpret, and convert raw Bayer pixel streams into standard viewable image formats.

Basic Syntax

To read a raw Bayer sensor dump, specify the image dimensions, bit depth, and input format before providing the raw input filename:

magick -size <width>x<height> -depth <bit-depth> GRAY:<input_file> <output_file>

For ImageMagick v6, replace magick with convert:

convert -size <width>x<height> -depth <bit-depth> GRAY:<input_file> <output_file>

Essential Parameters Explained

  • -size <width>x<height>: Specifies the exact pixel dimensions of the sensor output (e.g., -size 1920x1080).
  • -depth <bit-depth>: Specifies the bit depth per pixel, typically 8, 10, 12, 14, or 16.
  • GRAY:<filename>: Tells ImageMagick to interpret the stream as uncompressed, single-channel grayscale data, which corresponds to the unprocessed raw Bayer pixel grid.
  • -endian <type>: Specifies the byte order (msb for Big-Endian or lsb for Little-Endian) when working with bit depths greater than 8-bit.
  • -offset <bytes>: Skips custom proprietary header bytes at the start of the raw file if present.

Command Examples

1. Standard 8-bit Raw Bayer Image

For an 8-bit raw stream with a resolution of 1920x1080:

magick -size 1920x1080 -depth 8 GRAY:sensor_dump.raw output.png

2. 16-bit Raw Bayer Data with Little-Endian Encoding

For high-bit-depth raw sensor data (e.g., 10-bit to 16-bit unpacked into 2 bytes per pixel) stored in little-endian format:

magick -size 4096x3072 -depth 16 -endian lsb GRAY:sensor_dump.raw output.tiff

3. Skipping a File Header

If the capture system prepends a 64-byte metadata header before the raw pixel buffer:

magick -size 1920x1080 -depth 8 -offset 64 GRAY:sensor_dump.raw output.png

Handling Demosaicing (Color Reconstruction)

ImageMagick treats the GRAY: format as a raw grayscale mosaic representing the physical pixel filters (such as RGGB, BGGR, GRBG, or GBRG). To convert the Bayer pattern into full RGB color:

  1. Using LibRaw/dcraw integration: If the raw file is wrapped in a recognized container format (such as .dng or .raw supported by LibRaw), load it directly using DNG: or CR2: prefixes: 
    magick DNG:sensor_capture.dng output.png
  2. Using Custom Filters: For headless raw files, after loading with GRAY:, write custom script routines or convolution matrices to interpolate the specific color filter array (CFA) pattern into distinct RGB channels.
