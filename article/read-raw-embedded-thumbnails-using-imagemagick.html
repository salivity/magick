Read RAW Embedded Thumbnails Using ImageMagick

Extracting embedded thumbnail previews from camera RAW files (such as CR2, NEF, ARW, and DNG) allows you to quickly generate image previews without the high processing overhead of fully demosaicing RAW sensor data. Using ImageMagick, you can access these pre-rendered JPEG previews directly by passing a specific configuration flag to its RAW decoding delegate.

The Command to Read Embedded Thumbnails

To read and extract the embedded thumbnail preview using ImageMagick 7, use the dng:read-thumbnail=true define option:

magick -define dng:read-thumbnail=true input.RAW output.jpg

For ImageMagick 6 installations, use the legacy convert binary with the same syntax:

convert -define dng:read-thumbnail=true input.RAW output.jpg

Replace input.RAW with your actual source file (e.g., sample.CR2, photo.NEF, image.ARW) and output.jpg with your desired destination filename.

How It Works

Digital camera RAW files contain a fully rendered JPEG or TIFF preview generated by the camera's internal image processor at the moment the photo is taken.

By default, ImageMagick invokes delegates like libraw or dcraw to fully decode, interpolate, and demosaic the raw sensor pixels, which is computationally expensive. Setting -define dng:read-thumbnail=true instructs the delegate to bypass sensor data processing entirely and extract the pre-existing embedded preview stream, resulting in near-instant extraction times.

Batch Extracting Thumbnails

To extract embedded previews from multiple RAW files in a single directory, run the mogrify command:

magick mogrify -define dng:read-thumbnail=true -format jpg *.CR2

This command extracts the preview from every .CR2 file in the current directory and saves them as standalone .jpg files while leaving the original RAW files untouched.
