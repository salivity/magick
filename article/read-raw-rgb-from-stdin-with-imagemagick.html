Read Raw RGB from Stdin with ImageMagick

Reading raw RGB byte buffers from standard input (stdin) in ImageMagick allows you to process uncompressed pixel streams generated dynamically by external scripts, hardware capture devices, or video pipelines. Because raw pixel streams contain no header metadata, you must explicitly define the dimensions, color depth, and channel format before reading the input stream. This guide explains the exact command syntax, required parameters, and practical usage examples for piping raw buffers into ImageMagick.

Basic Syntax

To read raw RGB bytes from stdin using ImageMagick 7 (or convert in ImageMagick 6), use the rgb:- format specifier combined with the -size and -depth options:

magick -size <WIDTH>x<HEIGHT> -depth <BIT_DEPTH> rgb:- output.png

The hyphen (-) following the colon in rgb:- explicitly instructs ImageMagick to consume raw pixel data from standard input instead of reading from a file path.

Required Parameters

Raw byte streams contain only pixel values without headers describing image structure. You must provide the following parameters before the input specifier:

  • -size <WIDTH>x<HEIGHT>: Defines the exact pixel dimensions of the raw buffer (e.g., -size 1920x1080). ImageMagick cannot infer resolution from raw byte counts.
  • -depth <BITS>: Specifies the color bit depth per channel, typically 8 for 8-bit (24-bit total RGB) or 16 for 16-bit buffers.
  • rgb:-: Sets the pixel layout. ImageMagick expects interleaved red, green, and blue bytes.

Practical Examples

1. Piping from Python

Generate raw RGB bytes using a standard Python script and pipe the buffer directly into ImageMagick to produce a PNG:

python3 -c "import sys; sys.stdout.buffer.write(b'\xFF\x00\x00' * 100 * 100)" | \
magick -size 100x100 -depth 8 rgb:- red_square.png

2. Handling RGBA (Alpha Channel)

If your buffer includes an alpha channel (4 bytes per pixel for 8-bit depth), change the format specifier to rgba:-:

cat raw_frame.rgba | magick -size 1280x720 -depth 8 rgba:- output.png

3. Handling BGR Format

If the source produces bytes in Blue-Green-Red order (commonly used by OpenCV and Windows bitmaps), use bgr:- or bgra:-:

cat frame.bgr | magick -size 640x480 -depth 8 bgr:- output.jpg

4. Piping from FFmpeg

Extract a raw frame from a video file directly into an ImageMagick pipeline without saving intermediate files to disk:

ffmpeg -i input.mp4 -vframes 1 -f rawvideo -pix_fmt rgb24 - | \
magick -size 1920x1080 -depth 8 rgb:- frame.webp
