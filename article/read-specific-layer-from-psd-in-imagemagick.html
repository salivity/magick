Read Specific Layer from PSD in ImageMagick

Extracting individual sub-image layers from a multi-layer Adobe Photoshop (PSD) file using ImageMagick requires index notation appended to the file path. This guide covers the exact command-line syntax for isolating individual layers, understanding layer indexing, extracting layer ranges, and handling layer offsets properly.

Basic Syntax

To target a specific layer in a PSD file, append the zero-based layer index in square brackets directly after the input filename:

magick input.psd[index] output.png

(Note: In ImageMagick v6, replace magick with convert.)

Understanding Layer Indexing

Photoshop PSD files structure layers with a composite image at the beginning of the stack:

  • Index [0]: The merged composite (flattened preview) generated by Photoshop.
  • Index [1]: The first actual layer in the PSD layer stack.
  • Index [2]: The second layer.
  • Index [n]: Subsequent layers.

Examples

Extract the merged composite preview:

magick design.psd[0] preview.png

Extract the first actual layer:

magick design.psd[1] layer_1.png

Extract a specific layer and reset canvas geometry: PSD layers often retain virtual canvas offsets. Use +repage to remove the virtual canvas metadata and crop the output strictly to the layer's actual pixel dimensions:

magick design.psd[2] +repage layer_2.png

Extracting Multiple Layers or Ranges

ImageMagick allows selecting multiple non-contiguous layers or a sequential range in a single command.

Extract a layer range (e.g., layers 1 through 3):

magick "design.psd[1-3]" +repage layer_%d.png

Extract specific discrete layers (e.g., layers 1 and 4):

magick "design.psd[1,4]" +repage layer_%d.png

Export all individual layers at once:

magick design.psd[1--1] +repage layer_%d.png

(The index [1--1] instructs ImageMagick to read from the first layer to the last layer, skipping the [0] composite preview).

Identifying Available Layers

To inspect a PSD file and view the index numbers, dimensions, and names of all contained layers without extracting them, run the identify command:

magick identify design.psd
