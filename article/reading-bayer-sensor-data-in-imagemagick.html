Reading Bayer Sensor Data in ImageMagick

This article provides a direct guide on reading and demosaicing raw Bayer pattern sensor data using ImageMagick. Because raw sensor dumps lack metadata headers, ImageMagick requires explicit command-line parameters to interpret the image geometry, bit depth, byte order, and Color Filter Array (CFA) alignment. Below is the precise syntax and parameter breakdown required to decode these files into standard image formats.

Command Syntax

The general syntax for reading raw Bayer sensor data in ImageMagick 7 is:

magick -size <Width>x<Height> -depth <BitDepth> [-endian <Endianness>] bayer:<Pattern>:<InputFile> <OutputFile>

For ImageMagick 6, replace magick with convert.

Parameter Breakdown

  • -size <Width>x<Height>: Specifies the exact pixel dimensions of the raw sensor capture (e.g., -size 1920x1080). This is mandatory because raw files contain no header information.
  • -depth <BitDepth>: Defines the bit depth per pixel/channel, typically 8, 10, 12, 14, or 16.
  • -endian <msb|lsb>: Defines the byte order. This is required for bit depths greater than 8-bit to ensure high and low bytes are interpreted correctly (e.g., -endian lsb for little-endian or -endian msb for big-endian).
  • bayer:<Pattern>:: Specifies the Bayer coder and the specific CFA layout of your sensor.
    • Supported patterns include: rggb, bggr, grbg, and gbrg.
    • If the pattern is omitted (i.e., using simply bayer:<InputFile>), ImageMagick defaults to rggb.
  • <InputFile>: The path to the raw binary file.
  • <OutputFile>: The desired output file path and format (e.g., output.png, output.tiff).

Practical Examples

1. Standard 8-bit RGGB Raw Image

To read an 8-bit 1920x1080 raw file using the default RGGB layout:

magick -size 1920x1080 -depth 8 bayer:rggb:sensor_dump.raw output.png

2. 16-bit BGGR Raw Image with Little-Endian Encoding

To convert a 16-bit 4096x2160 raw file captured with a BGGR layout in little-endian format:

magick -size 4096x2160 -depth 16 -endian lsb bayer:bggr:capture.raw output.tiff

3. 12-bit Packed or Padded GRBG Sensor Data

When working with sensors outputting unpacked 12-bit data stored in 16-bit containers:

magick -size 3840x2160 -depth 16 -endian msb bayer:grbg:frame.raw -auto-level output.png

Note: If the converted image shows incorrect color balance (e.g., a strong green or magenta tint), verify and switch the pattern identifier (rggb, bggr, grbg, or gbrg) to match the hardware sensor's starting pixel alignment.
