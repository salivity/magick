Reduce Image Palette to Exact Colors with ImageMagick

This article provides a straightforward guide on how to reduce an image's color palette to a specific, exact number of colors using ImageMagick. You will learn the precise command-line parameters required to quantize colors, disable dithering to prevent unintended color blending, generate and remap exact palettes, and verify the final unique color count.

The Standard -colors Operator

ImageMagick provides the -colors operator to reduce the number of colors in an image. By default, ImageMagick applies dithering to simulate missing colors, which can introduce additional unique pixels into the final output. To constrain the palette strictly, you should disable dithering using the +dither flag.

magick input.png +dither -colors 16 output.png

For ImageMagick v6, replace magick with convert:

convert input.png +dither -colors 16 output.png

Forcing an Exact Palette via Remapping

The -colors option defines the maximum number of colors to target, but the quantization algorithm may occasionally choose fewer colors if the image lacks sufficient tonal variation. To strictly limit and control the palette:

  1. Generate the unique color palette: Extract the exact number of dominant colors from the source image.
  2. Remap the original image: Apply that exact palette back onto the image.

Run the following unified command to generate a reduced palette and remap it in a single step:

magick input.png ( +clone +dither -colors 16 -unique-colors ) -remap - output.png

Note: On Windows Command Prompt, omit the backslashes escaping the parentheses: magick input.png ( +clone +dither -colors 16 -unique-colors ) -remap - output.png.

Choosing the Correct Output Format

File formats directly affect the final color count:

  • Use PNG8 or GIF: Indexed formats (like PNG8:output.png or output.gif) preserve strict palette restrictions.
  • Avoid JPEG: Lossy compression formats like JPEG introduce compression artifacts that generate thousands of new, interpolated colors upon saving.

To enforce an 8-bit indexed PNG output:

magick input.png +dither -colors 16 PNG8:output.png

Verifying the Unique Color Count

To confirm that the output image contains the exact number of colors expected, query the %k format property:

magick output.png -format "%k\n" info:

This command returns the precise count of unique colors currently present in the file.
