Reference Previous Image in ImageMagick FX

ImageMagick's -fx operator provides a built-in scripting mechanism to perform complex mathematical calculations across image sequences. When processing a sequence of multiple frames or layers, you can access pixel data from the immediately preceding image by using the sequence index variable t inside image array references, specifically with the syntax u[t-1].

Understanding FX Sequence Variables

In the -fx expression language, ImageMagick provides several special variables to identify images within a sequence:

  • t: The zero-based index of the current image being processed.
  • n: The total number of images in the current sequence.
  • u: The image sequence array, where u[0] is the first image, u[1] is the second, and u[t] is the current image.

To reference the pixel values of the previous image in the sequence, decrement the current index using u[t-1].

Syntax and Handling the First Frame

Because the first image has an index of t = 0, referencing u[t-1] directly on the first image results in an out-of-bounds error or unexpected behavior. To prevent this, use a ternary conditional operator (condition ? true_expr : false_expr) to check if t > 0.

Basic conditional syntax:

magick frame*.png -fx "t > 0 ? u[t-1] : u[0]" output_%03d.png

Accessing Channels and Offsets

You can query specific color channels or coordinate offsets from the previous image:

  • Current pixel channel: u[t-1] returns the value of the current channel being evaluated from the previous image.
  • Specific color channel: u[t-1].r, u[t-1].g, or u[t-1].b extracts the red, green, or blue channel explicitly.
  • Spatial pixel offset: u[t-1].p{x,y} accesses a specific pixel location (x, y) in the previous image rather than the current coordinates.

Practical Examples

1. Calculating the Difference Between Consecutive Frames

To compute an absolute visual difference between each frame and its predecessor:

magick input_sequence*.png -fx "t > 0 ? abs(u - u[t-1]) : 0" diff_%03d.png

In this command:

  • If t > 0, the output pixel is the absolute difference between the current frame (u) and the previous frame (u[t-1]).
  • If t == 0 (the first frame), the output is set to 0 (black).

2. Temporal Smoothing (Frame Blending)

To blend 50% of the current frame with 50% of the previous frame:

magick input_sequence*.png -fx "t > 0 ? (0.5 * u + 0.5 * u[t-1]) : u" smoothed_%03d.png

This blends each frame with the one prior, leaving the first frame unaltered.
