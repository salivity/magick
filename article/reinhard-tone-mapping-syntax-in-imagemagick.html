Reinhard Tone Mapping Syntax in ImageMagick

This article provides the exact command-line syntax for applying the Reinhard tone mapping operator to high dynamic range (HDR) images using ImageMagick. You will learn the mathematical foundation of the Reinhard operator, the standard global implementation syntax using the -fx operator, how to tune the operator with a custom white point, and how to apply luminance-preserving tone mapping to prevent color distortion.

Standard Global Reinhard Syntax

The standard Reinhard tone mapping operator compresses luminance according to the formula:

\[\text{Output} = \frac{\text{Input}}{1 + \text{Input}}\]

In ImageMagick, this global operator is applied across color channels using the -fx expression:

magick input.exr -fx "u/(1+u)" output.png

To ensure accurate dynamic range compression and gamma correction when converting HDR formats (.exr, .hdr) to 8-bit SDR formats (.jpg, .png), ensure the image is processed in linear RGB before converting to sRGB:

magick input.hdr -colorspace RGB -fx "u/(1+u)" -colorspace sRGB output.jpg

Extended Reinhard Operator (White Point Clipping)

The extended Reinhard operator allows high-luminance values to burn out smoothly to pure white by defining a maximum white point (\(L_{\text{white}}\)):

\[\text{Output} = \frac{\text{Input} \times \left(1 + \frac{\text{Input}}{L_{\text{white}}^2}\right)}{1 + \text{Input}}\]

In ImageMagick, set \(L_{\text{white}}\) (for example, a value of 2.5) directly in the -fx expression:

magick input.exr -fx "u * (1 + (u / (2.5 * 2.5))) / (1 + u)" -colorspace sRGB output.png

Luminance-Based Reinhard Tone Mapping

Applying the Reinhard operator directly to the R, G, and B channels independently can lead to color desaturation or channel clipping. To preserve chromaticity, apply the operator solely to the image luminance channel:

magick input.exr \
  \( +clone -colorspace Rec709Luminance -fx "u/(1+u)" \) \
  \( -clone 0 -colorspace Rec709Luminance \) \
  -compose Divide -composite \
  -compose Multiply -composite \
  -colorspace sRGB output.png

Explanation of the Pipeline:

  1. +clone -colorspace Rec709Luminance -fx "u/(1+u)": Extracts luminance and computes the tone-mapped luminance map.
  2. -clone 0 -colorspace Rec709Luminance: Extracts the original linear luminance map.
  3. -compose Divide -composite: Computes the gain ratio (\(\text{Luminance}_{\text{mapped}} / \text{Luminance}_{\text{original}}\)).
  4. -compose Multiply -composite: Multiplies the original RGB image by the gain ratio to scale all color channels uniformly.
