Remove a Frame from a GIF with ImageMagick

This guide explains how to delete specific frame indices from an animated GIF using ImageMagick command-line tools. By using the -delete operator alongside standard 0-based indexing, you can quickly cut unwanted frames, fix stuttering animations, or trim animation length without needing a graphic editor.

Basic Syntax

To remove a specific frame, load the animated GIF, specify the -delete operator with the target frame index, and save the output.

For ImageMagick v7:

magick input.gif -delete <index> output.gif

For ImageMagick v6:

convert input.gif -delete <index> output.gif

Understanding Frame Indexing

ImageMagick uses zero-based indexing:

  • 0 refers to the first frame.
  • 1 refers to the second frame.
  • -1 refers to the last frame.

Examples

1. Remove a Single Frame

To delete the third frame (index 2) from an animation:

magick animation.gif -delete 2 output.gif

2. Remove the First or Last Frame

To remove the very first frame:

magick animation.gif -delete 0 output.gif

To remove the final frame:

magick animation.gif -delete -1 output.gif

3. Remove Multiple Frames

You can pass multiple comma-separated indices to delete non-consecutive frames, or use a range:

  • Delete frames 1, 3, and 5:
magick animation.gif -delete 1,3,5 output.gif
  • Delete a range of frames (e.g., from index 3 through 7):
magick animation.gif -delete 3-7 output.gif

Handling Optimized or Differential GIFs

If the original GIF uses frame optimization (where each frame only contains the pixel changes from the previous frame), deleting a frame directly may cause visual glitches. To fix this, unpack the frames with -coalesce before deleting:

magick animation.gif -coalesce -delete 2 -layers optimize output.gif
  • -coalesce fully renders each frame to prevent visual artifacts.
  • -layers optimize re-compresses and optimizes the GIF structure when saving.
