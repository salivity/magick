Remove GPS EXIF Data in ImageMagick

Image files frequently contain sensitive geolocation data embedded alongside exposure settings, camera details, and date information. This guide explains how to strip only GPS coordinates and location metadata from your images using ImageMagick while preserving all other valuable EXIF properties.

Removing GPS Tags from a Single Image

In ImageMagick version 7, you can use the +set operator with a wildcard pattern to delete all GPS-related metadata fields in one command:

magick input.jpg +set "exif:GPS*" output.jpg

If you are using ImageMagick version 6, use convert instead:

convert input.jpg +set "exif:GPS*" output.jpg

This command instructs ImageMagick to read the input image, unset any EXIF tags that begin with GPS (such as GPSLatitude, GPSLongitude, GPSAltitude, and GPSTimeStamp), and save the remaining data to the output file.

Targeting Specific GPS Properties

If you want to ensure specific coordinates are blanked out without relying on wildcards, you can clear individual tags explicitly by setting them to empty values:

magick input.jpg \
  -set "exif:GPSLatitude" "" \
  -set "exif:GPSLatitudeRef" "" \
  -set "exif:GPSLongitude" "" \
  -set "exif:GPSLongitudeRef" "" \
  -set "exif:GPSAltitude" "" \
  -set "exif:GPSAltitudeRef" "" \
  output.jpg

Batch Processing Multiple Images

To remove GPS tags from an entire directory of JPEG images in place, use the mogrify command:

magick mogrify +set "exif:GPS*" *.jpg

Note: The mogrify command overwrites original files. Create a backup of your folder before running batch modifications.

Verifying GPS Removal

To verify that the GPS tags were successfully removed while leaving the rest of the metadata intact, inspect the image properties:

magick identify -verbose output.jpg | grep -i "exif:GPS"

If the command returns no output, all GPS tags have been removed. You can verify that standard metadata remains intact by inspecting general camera attributes:

magick identify -verbose output.jpg | grep -i "exif:Make\|exif:Model\|exif:DateTime"
