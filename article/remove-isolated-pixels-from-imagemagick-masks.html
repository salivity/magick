Remove Isolated Pixels from ImageMagick Masks

This guide explains how to effectively eliminate small, isolated noise specks (both white and black pixels) from a binary or grayscale mask using ImageMagick. By utilizing morphological operations such as opening, closing, or applying a median filter, you can rapidly clean up noisy edges and rogue pixels without degrading the overall structure of your mask.

1. Removing White Specks Using Morphological Opening

The most effective way to eliminate stray white pixels (salt noise) on a black background is by using the Open morphology operation. Morphological opening performs an erosion followed by a dilation, which erases features smaller than the defined kernel size while restoring larger structures to their original dimensions.

Run the following command:

magick input_mask.png -morphology Open Disk:1.5 output_mask.png
  • Disk:1.5: Defines a circular kernel with a radius of 1.5 pixels. You can adjust this value (e.g., 1, 2, 2.5) depending on the size of the specks you need to remove.
  • Alternative shapes include Diamond or Square (e.g., -morphology Open Diamond:1).

2. Removing Black Specks (Holes) Using Morphological Closing

If your mask contains isolated black specks or tiny holes within solid white areas (pepper noise), use the Close morphology operation. Closing performs a dilation followed by an erosion, bridging small gaps and filling isolated black pixels.

Run the following command:

magick input_mask.png -morphology Close Disk:1.5 output_mask.png

3. Removing Both White and Black Specks Simultaneously

To clean up both rogue white pixels and internal black holes in a single step, use the Smooth morphology method, or chain Open and Close together.

magick input_mask.png -morphology Smooth Disk:1.5 output_mask.png

Alternatively, chain them explicitly to use different kernel sizes for each step:

magick input_mask.png -morphology Open Disk:1.5 -morphology Close Disk:1.5 output_mask.png

4. Alternative Method: Using the Median Filter

For quick noise cleanup across standard masks, a median filter provides a straightforward alternative. It replaces each pixel's value with the median value of neighboring pixels, effectively erasing single-pixel outliers.

magick input_mask.png -median 3 output_mask.png
  • -median 3: Uses a 3x3 pixel neighborhood radius. Increase to 5 for larger noise clusters, though higher numbers may round the sharp corners of your mask.

5. Thresholding for Clean Binary Output

Applying morphology operations can sometimes introduce anti-aliased gray pixels along the edges. If your workflow requires a strict black-and-white binary mask, finish the operation with a -threshold command:

magick input_mask.png -morphology Open Disk:1.5 -threshold 50% output_mask.png
