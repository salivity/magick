Remove Only GPS Metadata in ImageMagick

This guide explains how to strip GPS location data from images using ImageMagick while preserving essential EXIF metadata such as camera settings, timestamps, and exposure details. You will learn the exact commands for processing individual files, executing batch removals across directories, and verifying that the location tags were successfully deleted.

The ImageMagick Command

To remove all GPS-related EXIF properties without deleting the rest of the EXIF profile, use the -set operator with a wildcard pattern targeting the GPS namespace:

magick input.jpg -set "exif:GPS*" "" output.jpg

(For ImageMagick v6, replace magick with convert.)

How It Works

  • input.jpg: The source image containing full EXIF and GPS data.
  • -set "exif:GPS*" "": Finds all metadata tags beginning with the exif:GPS prefix (including GPSLatitude, GPSLongitude, GPSAltitude, GPSTimeStamp, etc.) and sets their values to empty strings, effectively stripping the location information.
  • output.jpg: The output image containing the original image data and non-GPS EXIF tags (such as Make, Model, DateTimeOriginal, FNumber, and ExposureTime).

Targeted Tag Removal

If you need to delete specific coordinates while retaining other specific GPS tags, you can target them individually:

magick input.jpg \
  -set exif:GPSLatitude "" \
  -set exif:GPSLatitudeRef "" \
  -set exif:GPSLongitude "" \
  -set exif:GPSLongitudeRef "" \
  -set exif:GPSAltitude "" \
  -set exif:GPSAltitudeRef "" \
  output.jpg

Batch Processing Multiple Files

To remove GPS tags from all JPEG files in a directory in-place, use mogrify:

magick mogrify -set "exif:GPS*" "" *.jpg

Verifying GPS Tag Removal

To confirm that the GPS data has been cleared while the rest of the EXIF data remains intact, run the following verification commands:

  1. Check for remaining GPS tags (should return empty):

    magick identify -format "%[EXIF:GPS*]" output.jpg

  2. Verify that standard EXIF data still exists:

    magick identify -format "Camera: %[EXIF:Make] %[EXIF:Model]\nDate: %[EXIF:DateTimeOriginal]\n" output.jpg
