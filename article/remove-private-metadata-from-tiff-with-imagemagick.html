Remove Private Metadata From TIFF With ImageMagick

This article provides the exact ImageMagick commands needed to strip private metadata tags, embedded profiles, and sensitive information from TIFF files. You will learn how to process single images, handle batch conversions, and target specific metadata types to ensure your TIFF files are clean and optimized.

The Standard Command to Strip All Metadata

The most effective and direct way to remove all private metadata tags, EXIF data, XMP blocks, IPTC profiles, and comments from a TIFF image is using the -strip operator.

For ImageMagick v7+:

magick input.tif -strip output.tif

For ImageMagick v6 (legacy):

convert input.tif -strip output.tif

The -strip command deletes all standard and private profiles, EXIF tags, and proprietary camera/software metadata while preserving the essential image data and compression format.

In-Place Batch Removal for Multiple TIFF Files

To remove metadata from multiple TIFF files in a folder without creating new files, use the mogrify tool:

magick mogrify -strip *.tif

(For ImageMagick v6, run mogrify -strip *.tif)

Removing Specific Profiles Selectively

If you need to remove private metadata profiles (such as EXIF, IPTC, or XMP) while preserving specific properties like the embedded ICC color profile, use the +profile option instead of -strip:

To remove all profiles:

magick input.tif +profile "*" output.tif

To remove only private EXIF and XMP tags:

magick input.tif +profile "exif" +profile "xmp" output.tif

Verifying Metadata Removal

To confirm that the private tags have been completely removed from your TIFF file, run the identify command:

magick identify -verbose output.tif

Look for the Properties: and Profiles: sections in the terminal output. A successfully stripped TIFF will only contain baseline geometry, resolution, and color depth information.
