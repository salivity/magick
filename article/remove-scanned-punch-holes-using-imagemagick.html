Remove Scanned Punch Holes Using ImageMagick

Scanned documents often contain dark punch-hole marks along the margins that degrade visual quality and cause issues during optical character recognition (OCR). This guide provides the exact ImageMagick commands to automatically detect and eliminate punch-hole artifacts from scanned page margins, restoring a clean white background without damaging the document text.

The ImageMagick Command

To remove punch-hole marks using ImageMagick v7, use the connected-components analysis feature. This method identifies isolated dark objects matching the size of typical punch holes and fills them with the surrounding background color.

magick input_scan.png \
  -threshold 80% \
  -define connected-components:area-threshold=300-3000 \
  -define connected-components:mean-color=true \
  -connected-components 8 \
  output_clean.png

If you are using ImageMagick v6, replace magick with convert:

convert input_scan.png \
  -threshold 80% \
  -define connected-components:area-threshold=300-3000 \
  -define connected-components:mean-color=true \
  -connected-components 8 \
  output_clean.png

How the Parameters Work

  • -threshold 80%: Binarizes the image to clearly separate dark scan artifacts from the white page background.
  • -define connected-components:area-threshold=300-3000: Restricts the filter to shapes containing between 300 and 3,000 pixels. This ensures small text characters (under 300 pixels) and large page borders (over 3,000 pixels) are preserved while targeting the standard dimensions of scanned hole punches at 300 DPI.
  • -define connected-components:mean-color=true: Replaces the pixels of matched components with the mean color of the neighboring background (white), erasing the hole.
  • -connected-components 8: Applies 8-connectivity pixel grouping to evaluate contiguous shapes accurately.

Restricting Removal to Specific Margins

If your document contains large bold text characters that fall into the same pixel range as the punch holes, restrict the operation to a specific margin (such as a 150-pixel strip along the left edge) by applying a composite mask:

magick input_scan.png \
  \( +clone -crop 150x0+0+0 \
     -threshold 80% \
     -define connected-components:area-threshold=300-3000 \
     -define connected-components:mean-color=true \
     -connected-components 8 \) \
  -geometry +0+0 -composite output_clean.png

Batch Processing Multiple Scanned Documents

To clean punch holes across an entire folder of scanned images (e.g., PNG or TIFF files), run the mogrify batch tool:

magick mogrify \
  -threshold 80% \
  -define connected-components:area-threshold=300-3000 \
  -define connected-components:mean-color=true \
  -connected-components 8 \
  -path ./cleaned_output/ *.png
