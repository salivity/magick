Remove Specks with ImageMagick Connected Components

This guide explains how to remove small specks, dust, and unwanted visual noise from images using ImageMagick's connected-components labeling feature. By defining an area threshold, you can automatically detect isolated pixel clusters below a specific size and replace them with the surrounding background color.

Understanding Connected-Component Labeling

ImageMagick's -connected-components operator analyzes an image to find contiguous groups of pixels that share the same color or intensity values. By pairing this operator with specific settings, you can automatically filter out components based on their pixel area, effectively eliminating specks without blurring sharp edges.

The Basic Command

To discard specks smaller than a given number of pixels, use the -define connected-components:area-threshold option alongside -define connected-components:mean-color=true.

ImageMagick v7 Command:

magick input.png \
  -define connected-components:area-threshold=15 \
  -define connected-components:mean-color=true \
  -connected-components 8 \
  output.png

ImageMagick v6 Command:

convert input.png \
  -define connected-components:area-threshold=15 \
  -define connected-components:mean-color=true \
  -connected-components 8 \
  output.png

Parameter Breakdown

  • -define connected-components:area-threshold=15: Sets the minimum size (in pixels) for a connected group. Any object smaller than this threshold (15 pixels in this example) will be targeted for removal.
  • -define connected-components:mean-color=true: Replaces the pixels of filtered components with the mean color of the larger surrounding region, effectively erasing the speck into the background.
  • -connected-components 8: Executes the connected components algorithm. The value 8 defines 8-connectivity (pixels touching diagonally or orthogonally count as connected). You can also use 4 for 4-connectivity (orthogonal neighbors only).

Handling Scanned Text and Binary Masks

For scanned documents or black-and-white masks containing noise, it is best to threshold the image before applying the filter to ensure clear boundaries between foreground and background.

magick scan.png \
  -threshold 50% \
  -define connected-components:area-threshold=20 \
  -define connected-components:mean-color=true \
  -connected-components 8 \
  cleaned_scan.png

Inspecting Component Data

If you need to determine the exact area size of your specks before removing them, enable verbose output:

magick input.png \
  -define connected-components:verbose=true \
  -connected-components 8 \
  null:

This prints a list of every identified component, including its bounding box, centroid, color, and total area in pixels, allowing you to choose the exact area-threshold value needed for your image.
