Remove Vertical Table Borders Using ImageMagick

This guide demonstrates how to detect, isolate, and eliminate vertical table borders from document images using ImageMagick's directional morphological operations. By applying a vertical structuring element during morphological erosion, you can target tall, narrow vertical rules without degrading text or horizontal borders, streamlining pre-processing for optical character recognition (OCR) and layout analysis.

Understanding Directional Morphological Erosion

Morphological erosion shrinks the foreground regions of an image based on a predefined shape called a structuring element or kernel. When you define an asymmetric kernel—such as a vertical line that is 1 pixel wide and several pixels tall—erosion selectively eliminates any foreground elements that are shorter than the kernel's height.

Because text characters and horizontal lines lack sufficient continuous vertical height, they are completely eroded away, leaving behind only the long vertical table borders. In practice, an erosion step is usually followed immediately by a dilation step using the same kernel (an operation known as morphological "Open") to restore the retained vertical borders to their original thickness.

Step 1: Isolating the Vertical Lines

Assuming a standard document with black lines on a white background, you must first invert or threshold the image so the lines are treated as the foreground (white), apply the directional kernel, and save or pipe the mask.

Run the following command to isolate only the vertical borders:

magick input.png -threshold 50% -negate -morphology Open Rectangle:1x30 vertical_mask.png
  • -threshold 50%: Converts the document into a clean binary image.
  • -negate: Inverts the colors so that the borders become white foreground pixels against a black background.
  • -morphology Open Rectangle:1x30: Executes a directional erosion with a 1-pixel wide by 30-pixel tall kernel, followed by a dilation. Any feature shorter than 30 consecutive vertical pixels is removed. Adjust the height (30) depending on your image resolution to ensure tall characters like "l" or "|" are not mistaken for borders.

Step 2: Removing the Isolated Borders from the Original Image

Once the vertical borders are isolated into a mask, you can subtract them from the original document. For black-on-white documents, compositing the mask over the original image using the Lighten blend mode replaces the black border pixels with white background pixels.

You can perform the entire process in a single command using in-memory cloning:

magick input.png \
  \( +clone -threshold 50% -negate -morphology Open Rectangle:1x30 \) \
  -compose Lighten -composite output.png

Tuning the Kernel Dimensions

  • Kernel Height: If parts of tall characters (such as the letter "l", brackets, or parentheses) are still being removed, increase the kernel height (e.g., Rectangle:1x50).
  • Kernel Width: If your table contains thick vertical borders (2 or 3 pixels wide), you can broaden the kernel (e.g., Rectangle:2x40 or Rectangle:3x40) to ensure proper matching and full removal.
  • Broken Borders: If lines are broken or faint, you can apply a slight directional closing (-morphology Close Rectangle:1x5) prior to the erosion step to bridge micro-gaps in the borders.
