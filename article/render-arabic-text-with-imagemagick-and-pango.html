Render Arabic Text with ImageMagick and Pango

Rendering right-to-left (RTL) scripts like Arabic in ImageMagick requires the Pango text layout engine to properly handle bidirectional text, character shaping, and ligatures. Standard ImageMagick text primitives (such as label: or annotate:) often fail to connect Arabic letters correctly, whereas Pango delegates text rendering to libraries like HarfBuzz and FriBidi. This guide demonstrates the exact command-line syntax required to render shaped, RTL Arabic script into an image using ImageMagick and Pango.

Basic Syntax

To render Arabic text directly from the command line, prefix the text string with pango: and specify an appropriate Arabic-compatible font:

magick -background white -fill black -font "Amiri" pango:"مرحبا بالعالم" output.png

(Note: Use convert instead of magick if you are using ImageMagick v6).

Using Pango Markup for Explicit RTL and Styling

Pango supports an HTML-like markup language that allows you to explicitly enforce text direction, font family, font size, and text alignment.

magick -size 500x200 xc:white -fill black \
pango:"<span font='Noto Sans Arabic 24' dir='rtl'>مرحبا بكم في عالم البرمجة</span>" \
-gravity center -composite output.png

Key attributes used in Pango markup:

  • font: Defines the font family and point size (e.g., font='Amiri 30').
  • dir='rtl': Explicitly forces the text rendering direction from right to left.
  • align: Sets the text alignment (left, center, or right).

Rendering Arabic Text from a UTF-8 File

When working with long strings or complex multi-line Arabic paragraphs, it is best practice to read the text directly from a UTF-8 encoded file using the @ symbol to avoid shell-encoding issues.

  1. Create a UTF-8 text file (arabic.txt):
<span font='Amiri 28' dir='rtl'>
هذا النص مكتوب باللغة العربية ومُشَكَّل بطريقة صحيحة عبر محرك بانغو.
</span>
  1. Run the ImageMagick command:
magick -background transparent -fill "#222222" pango:@arabic.txt output.png

Essential Requirements

For this syntax to work correctly on your system:

  1. ImageMagick Pango Delegate: ImageMagick must be compiled with Pango support. You can verify this by running magick -version or convert -list configure | grep DELEGATES and checking for pango in the output.
  2. Arabic Fonts: An Arabic-compatible font (such as Amiri, Noto Sans Arabic, Scheherazade New, or Arial) must be installed on the host system.
