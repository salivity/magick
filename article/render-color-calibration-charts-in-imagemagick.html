Render Color Calibration Charts in ImageMagick

This guide outlines the precise ImageMagick syntax used to generate custom color calibration test charts, step wedges, and multi-patch targets. You will learn how to define color values precisely across different color spaces, assemble individual patches into grids using append and montage commands, generate dynamic grayscale ladders, and embed standard ICC color profiles for accurate hardware and display profiling.

Basic Patch Generation and Direct Appending

The most direct way to create a calibration strip or chart is by generating solid color canvases (xc:) and joining them horizontally (+append) or vertically (-append).

Horizontal Color Strip

magick -size 100x100 \
  xc:"rgb(255,0,0)" \
  xc:"rgb(0,255,0)" \
  xc:"rgb(0,0,255)" \
  xc:"rgb(255,255,0)" \
  xc:"rgb(0,255,255)" \
  xc:"rgb(255,0,255)" \
  +append calibration_strip.png

Multi-Row Patch Chart

To build a multi-row chart, generate separate horizontal strips in memory and combine them vertically:

magick \
  \( -size 80x80 xc:"#735244" xc:"#c29682" xc:"#627a9d" +append \) \
  \( -size 80x80 xc:"#576c43" xc:"#8580b1" xc:"#67bdaa" +append \) \
  \( -size 80x80 xc:"#d67e2c" xc:"#505ba6" xc:"#c15a63" +append \) \
  -append custom_chart_3x3.png

Grid Layouts with montage

For larger multi-patch charts (such as 24-patch standard targets), the montage utility arranges individual swatches into a defined grid layout automatically, complete with customizable borders and spacing.

magick montage \
  -size 100x100 \
  xc:"#735244" xc:"#c29682" xc:"#627a9d" xc:"#576c43" xc:"#8580b1" xc:"#67bdaa" \
  xc:"#d67e2c" xc:"#505ba6" xc:"#c15a63" xc:"#5e3c6c" xc:"#9dbc40" xc:"#e0a32e" \
  xc:"#383d96" xc:"#469449" xc:"#ae363a" xc:"#e6c622" xc:"#b94c7a" xc:"#1c84a4" \
  xc:"#ffffff" xc:"#d2d2d2" xc:"#9e9e9e" xc:"#666666" xc:"#333333" xc:"#000000" \
  -tile 6x4 \
  -geometry +5+5 \
  -background "#1a1a1a" \
  color_checker_24.png
  • -tile 6x4: Specifies the column-by-row structure (6 columns, 4 rows).
  • -geometry +5+5: Defines the horizontal and vertical gap between patches.
  • -background "#1a1a1a": Sets the chart's border/substrate color.

Grayscale Step Wedges for Gamma Calibration

To calibrate exposure, dynamic range, or tonal response, use gradient: combined with quantization steps to generate stepped grayscale wedges.

11-Step Density Wedge (0% to 100%)

magick -size 1100x100 gradient:black-white \
  -colorspace Gray \
  -posterize 11 \
  step_wedge_11.png

Multi-Density Calibration Ramp

magick -size 600x150 \
  \( gradient:black-white -posterize 16 \) \
  \( gradient:black-white \) \
  -append gamma_test_ramp.png

Defining Absolute Color Spaces (Lab, CMYK, Device RGB)

For colorimeter and spectrophotometer profiling, test patches must often be defined in absolute or device-independent color spaces.

CIE L*a*b* Color Chart

Specify CIELAB color values by creating images in the Lab color space:

magick -size 100x100 \
  \( xc:"cielab(50, 0, 0)" \) \
  \( xc:"cielab(50, 50, 0)" \) \
  \( xc:"cielab(50, -50, 0)" \) \
  \( xc:"cielab(50, 0, 50)" \) \
  \( xc:"cielab(50, 0, -50)" \) \
  +append -colorspace sRGB lab_calibration_strip.png

CMYK Printing Calibration Target

magick -size 100x100 -colorspace CMYK \
  xc:"cmyk(100%, 0%, 0%, 0%)" \
  xc:"cmyk(0%, 100%, 0%, 0%)" \
  xc:"cmyk(0%, 0%, 100%, 0%)" \
  xc:"cmyk(0%, 0%, 0%, 100%)" \
  xc:"cmyk(50%, 50%, 50%, 0%)" \
  +append -profile /path/to/ISOcoated_v2_300_eci.icc cmyk_chart.tif

Adding Labels and Patch Markers

To render chart coordinates or patch labels programmatically, combine -draw or -annotate into the generation loop:

magick -size 120x120 xc:"#9e9e9e" \
  -fill black -pointsize 12 -gravity South \
  -annotate +0+5 "Patch: D3\nL* 65.5" \
  labeled_patch.png
