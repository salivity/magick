Render HTML-Like Markup with Pango and ImageMagick

Rendering text with inline styling such as bold, italics, font sizing, and custom colors is easily accomplished by combining ImageMagick with the Pango markup engine. By leveraging ImageMagick's built-in pango: delegate, you can interpret a lightweight, HTML-like XML syntax directly within your image generation commands. This guide explains how the Pango delegate works, details the supported markup tags, and provides practical command-line examples for rendering rich text into images.

Understanding Pango Markup

Pango does not parse full HTML or CSS, but instead uses a dedicated, XML-based markup language that mimics HTML. All tags must be properly nested and closed.

The primary tags and attributes include:

  • <b>...</b>: Bold text.
  • <i>...</i>: Italicized text.
  • <u>...</u>: Underlined text.
  • <s>...</s>: Strikethrough text.
  • <big>...</big> and <small>...</small>: Relatively increases or decreases font size.
  • <sup>...</sup> and <sub>...</sub>: Superscript and subscript text.
  • <tt>...</tt>: Monospace font.
  • <span attributes...>...</span>: A versatile container tag supporting attributes like foreground (text color), background (highlight color), font_family, size (in points or Pango units), weight (e.g., "bold", "light"), and style (e.g., "italic", "normal").

Basic Command Line Usage

To render markup directly from the command line, prefix your input string with pango:.

magick -background white pango:"<b>Hello</b> <span foreground='red'>World</span>" output.png

If you are using ImageMagick 6, replace magick with convert:

convert -background white pango:"<b>Hello</b> <span foreground='red'>World</span>" output.png

Specifying Canvas Size and Word Wrapping

Pango automatically handles text layout and line wrapping when provided with canvas dimensions. By specifying the -size option with a defined width, Pango wraps the text to fit within the boundary:

magick -size 300x -background lightgray pango:"This is a <i>longer paragraph</i> designed to demonstrate how <b>Pango</b> wraps text automatically when given a fixed canvas width." wrapped_text.png

Leaving the height dimension empty (e.g., 300x) allows the image height to dynamically adjust based on the amount of text.

Rendering Markup from a File

For long passages or complex templates, writing markup directly on the command line can lead to shell-escaping issues. You can store the markup inside a text file and reference it using the @ symbol:

  1. Create a file named markup.txt:
<span font="Georgia 16">
  This text uses <b>Georgia</b> at 16pt.<br/>
  Here is a <span foreground="#007ACC" underline="single">blue underlined link style</span>.
</span>
  1. Run the ImageMagick command:
magick -background transparent -size 400x pango:@markup.txt output.png

Important Formatting Considerations

  • XML Escaping: Special characters such as ampersands (&), less-than (<), and greater-than (>) must be escaped as &amp;, &lt;, and &gt;.
  • Font Matching: If a specified font_family is not installed on the host system, Pango falls back to the system's default sans-serif font.
  • Self-Closing Tags: Tags like <br/> should be written with a self-closing slash to ensure strict XML compliance.
