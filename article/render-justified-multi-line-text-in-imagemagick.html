Render Justified Multi-Line Text in ImageMagick

Rendering justified multi-line text in ImageMagick requires the Pango text layout engine, as standard primitives like label: or caption: only support left, center, and right alignments. This guide explains how to use ImageMagick's pango: delegate to format and render fully justified, multi-line paragraphs cleanly onto an image canvas.

The Justified Text Command

To achieve full text justification where text is aligned evenly along both the left and right margins, format the text string using Pango Markup within ImageMagick.

ImageMagick v7 Command

magick -size 600x400 -background white -fill black \
pango:"<span align='justify'>Your long paragraph text goes here. ImageMagick will automatically wrap the lines according to the specified width and adjust the word spacing so that every line fills the entire horizontal space, creating a clean justified block of text.</span>" \
justified_text.png

ImageMagick v6 Command

For ImageMagick version 6, replace magick with convert:

convert -size 600x400 -background white -fill black \
pango:"<span align='justify'>Your long paragraph text goes here. ImageMagick will automatically wrap the lines according to the specified width and adjust the word spacing so that every line fills the entire horizontal space, creating a clean justified block of text.</span>" \
justified_text.png

How the Parameters Work

  • -size 600x400: Sets the bounding box for the text. The width determines where lines wrap and justify, while the height defines the canvas boundaries.
  • -background white: Sets the canvas background color (use none for a transparent background).
  • -fill black: Defines the base text color.
  • pango:"...": Invokes the Pango rendering engine.
  • <span align='justify'>...</span>: The XML markup tag that instructs Pango to apply full justification to the enclosed text.

Reading Multi-Line Text from a File

If you have a long text file, you can pass it directly to ImageMagick using Pango by prepending the markup inside the file or embedding it in the shell command:

magick -size 800x600 -background "#f4f4f4" -fill "#222222" \
pango:"<span align='justify'>$(cat input.txt)</span>" \
