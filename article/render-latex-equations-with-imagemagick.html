Render LaTeX Equations with ImageMagick

ImageMagick allows you to render mathematical equations from LaTeX strings directly into image formats like PNG, JPEG, or SVG by delegating the compilation to an underlying TeX installation. This guide covers the exact command-line syntax required to convert LaTeX equation strings into crisp images, along with essential formatting flags for resolution and transparency.

The Primary Command

To render a LaTeX equation string into an image using ImageMagick (version 7+), use the magick command with the latex: input prefix:

magick -density 300 latex:"\\[ E = mc^2 \\]" equation.png

If you are using ImageMagick version 6, replace magick with convert:

convert -density 300 latex:"\\[ E = mc^2 \\]" equation.png

Command Breakdown and Options

  • latex:"...": Specifies the LaTeX input string. ImageMagick wraps minimal math strings inside a standard LaTeX document template before compiling.
  • -density <DPI>: Sets the horizontal and vertical resolution (e.g., 300 or 600). Because TeX outputs vector data, setting a high density ensures the resulting raster image is sharp and readable.
  • -background none: Produces an image with a transparent background rather than the default white background.
  • -trim: Automatically crops the whitespace around the rendered equation.

Example: High-Resolution Transparent Equation

To generate a cropped equation with a transparent background suitable for web or document embedding:

magick -density 300 -background none latex:"\\[ \int_{0}^{\infty} e^{-x^2} dx = \frac{\sqrt{\pi}}{2} \\]" -trim output.png

Rendering via Standard Input (Piping)

For complex strings or multi-line equations, you can pipe the LaTeX code directly into ImageMagick using latex:-:

echo "\\[ f(x) = \sum_{n=0}^{\infty} \frac{f^{(n)}(a)}{n!} (x - a)^n \\]" | magick -density 300 -background none latex:- -trim output.png

Rendering from a File

If you have a dedicated .tex file, pass the file path directly to ImageMagick:

magick -density 300 equation.tex -trim output.png

System Prerequisites

For ImageMagick to process LaTeX strings, the following dependencies must be installed on your system and accessible in your system's PATH:

  1. A TeX Distribution: pdflatex, latex, or xelatex (e.g., TeX Live, MacTeX, or MiKTeX).
  2. Ghostscript: Required by ImageMagick to interpret and convert PostScript/PDF output generated by the TeX engine.
