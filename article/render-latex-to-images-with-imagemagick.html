Render LaTeX to Images with ImageMagick

This article provides the exact command-line syntax and necessary parameters to render LaTeX mathematical formulas directly into high-resolution bitmap images (such as PNG or JPEG) using ImageMagick. It covers the required ImageMagick delegates, resolution settings, background handling, and practical command examples.

Prerequisites

To render LaTeX equations via ImageMagick, your system must have ImageMagick, Ghostscript, and a working TeX distribution (such as TeX Live or MiKTeX) installed and available in your system path. ImageMagick delegates the compilation to latex or pdflatex and uses Ghostscript to convert the resulting output into a raster graphic.

The Basic Command

The standard command to render an inline LaTeX math expression to a PNG image using ImageMagick (version 7+) is:

magick -density 300 tex:"$E = mc^2$" output.png

For ImageMagick version 6 (legacy), use convert:

convert -density 300 tex:"$E = mc^2$" output.png

High-Quality Equation Rendering with Transparency

For complex formulas where you need crisp text, no excess margins, and a transparent background, use the following command:

magick -density 600 -background none tex:"\documentclass{standalone}\usepackage{amsmath}\begin{document}\$\displaystyle \int_{-\infty}^{\infty} e^{-x^2} \, dx = \sqrt{\pi}\$\end{document}" -trim +repage formula.png

Breakdown of Key Parameters

  • tex:: Directs ImageMagick to pass the string to the LaTeX delegate compiler.
  • -density [DPI]: Controls the output resolution. Because LaTeX documents are vector-based, setting -density 300 or -density 600 ensures sharp rendering for bitmaps.
  • -background none: Produces a transparent background behind the rendered equation (ideal for PNG output).
  • -trim: Automatically crops out unnecessary white space or margins surrounding the equation.
  • +repage: Resets the canvas dimensions to match the trimmed boundary.
  • \displaystyle: Forces LaTeX to render operators, fractions, and integrals in full display mode instead of inline text mode.
