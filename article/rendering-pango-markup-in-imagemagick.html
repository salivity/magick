Rendering Pango Markup in ImageMagick

ImageMagick utilizes the Pango text layout engine to render complex typography using an HTML-like markup language directly onto images. Unlike standard text primitives that apply uniform styles across an entire string, the pango: input protocol allows users to mix font weights, styles, colors, and sizes inline. This article explains how ImageMagick processes Pango markup, details the tags used for bold, italic, and color styling, and demonstrates how to execute these commands via the command-line interface.

The Pango Delegate Mechanism

ImageMagick does not parse rich text tags natively with its default label: or -annotate operators. Instead, it relies on an external delegate library called Pango, developed under the GNOME project. When ImageMagick encounters an input prefixed with pango:, it passes the text string to the Pango library. Pango parses the XML-style markup, resolves font metrics, applies layout algorithms, and rasterizes the rendered text into an image buffer that ImageMagick can then manipulate or save.

To use this feature, ImageMagick must be compiled with Pango support. You can verify this by running magick -list delegate (or convert -list delegate) and confirming that pango appears in the delegates list.

Basic Markup Tags: Bold, Italic, and Color

Pango markup uses lightweight, XML-compliant tags to designate styling boundaries within a single string:

  • Bold: Created using either the convenience tag <b>...</b> or the explicit <span weight="bold">...</span>. You can also specify numeric weights, such as weight="heavy" or weight="700".
  • Italic: Created using either the convenience tag <i>...</i> or <span style="italic">...</span>. Oblique styling can also be applied using <span style="oblique">...</span>.
  • Color: Applied via the <span> element using the foreground (or fgcolor) attribute. Colors accept standard X11 color names (e.g., red, navy) or hexadecimal RGB/RGBA values (e.g., #FF5733, #00FF0088).

These tags can be nested freely, allowing a word to be simultaneously bold, italicized, and colored.

Syntax and Command-Line Implementation

When running ImageMagick commands, the markup string is passed as the input filename following the pango: prefix. Because Pango relies on XML-like tags and shell environments interpret characters such as quotes and angle brackets, the markup string should be enclosed in quotes.

Example: Combining Bold, Italic, and Color

magick -background white \
       -size 600x \
       pango:"Normal text, <b>bold text</b>, <i>italic text</i>, and <span foreground='#007ACC'><b><i>colored bold italic text</i></b></span>." \
       output.png

In this command:

  • -background white sets the canvas fill behind the rendered text.
  • -size 600x defines a target width of 600 pixels while allowing the height to adjust automatically based on text volume and line wrapping.
  • pango:"..." supplies the tagged string to the Pango engine.

Handling Special Characters

Because Pango treats markup as XML, special characters within the actual text content must be escaped using standard XML entities:

  • & must be written as &amp;
  • < must be written as &lt;
  • > must be written as &gt;

Failing to escape these characters will cause Pango's XML parser to fail, resulting in an error and halting image generation.
