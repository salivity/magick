Reorder Frames with ImageMagick TrimBounds

This article explains how to reorder animation frames in ImageMagick using list manipulation techniques combined with the -layers TrimBounds method. You will learn the exact command syntax required to adjust frame sequences, reset dynamic offsets, and enforce a uniform canvas size across your animation.

The Reordering Command

In ImageMagick, frame sequence is determined by image list operators (such as frame indexing, -reverse, or -swap), while -layers TrimBounds recalculates the canvas to fit the smallest bounding box containing all non-transparent pixels across all frames.

To reorder frames using explicit indices and apply TrimBounds, use the following command:

magick input.gif[3,0,1,2] -coalesce -layers TrimBounds output.gif

If you are using ImageMagick version 6, replace magick with convert:

convert input.gif[3,0,1,2] -coalesce -layers TrimBounds output.gif

Reversing Frame Order with TrimBounds

If the goal is to completely reverse the animation order rather than specifying individual indices, use the -reverse operator:

magick input.gif -coalesce -reverse -layers TrimBounds output.gif

Swapping Specific Frames

To swap specific adjacent or non-adjacent frames before trimming the bounds, use the -swap operator with frame index positions:

magick input.gif -coalesce -swap 0,2 -layers TrimBounds output.gif

How the Parameters Work

  • input.gif[...]: Frame indices specified inside brackets define the exact order in which frames are read into the image sequence. Zero-based indexing is used (the first frame is 0).
  • -coalesce: Reconstructs each frame fully by rendering disposal methods. This step is necessary before reordering or trimming to prevent ghosting or frame corruption caused by differential frame layers.
  • -reverse / -swap: Image sequence operators that alter the current frame list order in memory.
  • -layers TrimBounds: Scans the entire sequence, finds the global bounding box that encompasses all visible pixels across all reordered layers, trims the transparent margins, and sets a uniform canvas size.
