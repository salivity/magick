Replace Alpha Channel with Grayscale TIFF in ImageMagick

Replacing an existing alpha mask or transparency layer with an external grayscale TIFF is a common workflow in automated image processing pipelines. This guide demonstrates how to use ImageMagick to remove any existing transparency from a base image and bind the luminance values of an external grayscale TIFF file directly to the image's alpha channel.

The ImageMagick Command

To replace the existing alpha channel using ImageMagick v7, run the following command in your terminal:

magick input.png -alpha off mask.tiff -compose CopyOpacity -composite output.png

For legacy ImageMagick v6 installations, substitute magick with convert:

convert input.png -alpha off mask.tiff -compose CopyOpacity -composite output.png

How the Command Works

  • input.png: The target base image whose alpha channel you want to replace.
  • -alpha off: Disables the image's current alpha channel. This ensures that any pre-existing transparency or clipping paths are ignored before applying the new mask.
  • mask.tiff: The external grayscale TIFF file. In standard alpha mapping, white areas (#FFFFFF) represent 100% opacity, black areas (#000000) represent 100% transparency, and gray values represent partial transparency.
  • -compose CopyOpacity: Instructs ImageMagick's composition engine to take the grayscale intensity of the source image (mask.tiff) and write it directly into the opacity/alpha channel of the destination image (input.png).
  • -composite: Applies the composition operation between the two loaded images.
  • output.png: The resulting image file containing the original RGB channels paired with the new alpha channel.

Handling Inverted Masks

If your grayscale TIFF uses black for opaque areas and white for transparent areas, invert the mask values inline before composition using -negate:

magick input.png -alpha off \( mask.tiff -negate \) -compose CopyOpacity -composite output.png

(Note: On Windows Command Prompt, omit the backslashes before parentheses: ( mask.tiff -negate ))
