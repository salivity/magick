Reset Animated GIF Page Geometry in ImageMagick

When working with animated GIFs in ImageMagick, frame offsets and virtual canvas metadata can cause visual artifacts, misaligned animations, or incorrect bounding boxes after operations like cropping or resizing. This guide explains how to completely reset the page geometry offsets across all frames of an animated GIF using ImageMagick's +repage operator.

The Command: +repage

In ImageMagick, the operator used to reset canvas offsets and page geometry is +repage.

While -repage allows you to define specific canvas dimensions and offsets (for example, -repage 500x500+10+10), using the plus sign (+repage) instructs ImageMagick to remove all virtual canvas offset information, resetting the page canvas to match the exact dimensions of each individual frame.

Basic Usage

To reset the page offsets of an existing animated GIF, run:

magick input.gif +repage output.gif

(Note: In ImageMagick version 6, replace magick with convert.)

Handling Optimized GIFs with -coalesce

Animated GIFs frequently use optimization techniques where individual frames only contain the changed pixels and rely on offset coordinates to display in the correct location. If you modify or reset the geometry of an optimized GIF directly, the frames can become distorted.

To safely reset geometry while preserving the animation, pair +repage with -coalesce:

magick input.gif -coalesce +repage output.gif
  • -coalesce fully reconstructs every frame to its complete display state, removing partial-frame dependencies.
  • +repage strips the existing offset data across every frame.

Cropping or Resizing Workflow

When modifying the dimensions of an animated GIF, +repage should be placed immediately after the transformation operator to prevent the cropped or resized frames from retaining obsolete canvas coordinates:

magick input.gif -coalesce -crop 300x300+50+50 +repage -layers optimize output.gif

In this sequence:

  1. -coalesce expands the frames.
  2. -crop cuts out the specified region.
  3. +repage resets the page geometry so the frames no longer look for the pre-crop canvas coordinates.
  4. -layers optimize reapplies GIF frame optimization to reduce the final file size.
