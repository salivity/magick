Resize Image with Nearest Neighbor in ImageMagick

Resizing an image using nearest-neighbor interpolation allows you to scale graphics without introducing blurriness or anti-aliasing artifacts, making it the ideal method for pixel art, screenshots, and categorical masks. ImageMagick provides two straightforward methods to achieve this: using the dedicated -sample operator or applying the -filter point setting alongside the standard -resize operator.

Method 1: Using the -sample Operator (Recommended)

The simplest and fastest way to perform nearest-neighbor scaling in ImageMagick is with the -sample command. It bypasses complex filtering algorithms and directly samples pixels to scale the image.

ImageMagick v7 syntax:

magick input.png -sample 400% output.png

ImageMagick v6 syntax:

convert input.png -sample 400% output.png

You can also specify absolute pixel dimensions:

magick input.png -sample 800x600 output.png

Method 2: Using -filter point with -resize

Alternatively, you can achieve the exact same nearest-neighbor effect by explicitly setting the filter algorithm to point before calling the standard -resize flag.

ImageMagick v7 syntax:

magick input.png -filter point -resize 400% output.png

ImageMagick v6 syntax:

convert input.png -filter point -resize 400% output.png

Key Considerations

  • Aspect Ratio: By default, ImageMagick preserves the aspect ratio when specifying dimensions (e.g., 800x600). To force exact dimensions without preserving the aspect ratio, append an exclamation point to the geometry string: 800x600!.
  • Performance: The -sample operator is computationally lighter and faster than -filter point -resize because it directly skips pixels rather than executing general-purpose filtering logic.
