Resize ImageMagick Canvas Without Resizing Image

In ImageMagick, adjusting the canvas boundaries without altering or scaling the original image content is accomplished using the -extent flag along with a geometry specification. This article details how the -extent operator works, how to define canvas dimensions using geometry parameters, and how to combine geometry offsets and gravity to place unscaled image content precisely within the expanded or trimmed boundaries.

The -extent Operator and Geometry Syntax

Standard geometry flags passed to operators like -resize or -scale automatically resample or distort image pixels. To scale only the canvas boundary without modifying the dimensions or aspect ratio of the image content itself, ImageMagick provides the -extent operator.

The basic geometry format for -extent is:

magick input.jpg -extent WIDTHxHEIGHT output.jpg

When new dimensions are larger than the original image, ImageMagick enlarges the canvas and fills the extra space with the current -background color. When the dimensions are smaller, the canvas boundary shrinks, cropping the outer edges of the image without resizing the pixels.

Controlling Positioning with -gravity

By default, ImageMagick places the original image in the top-left corner (NorthWest) of the new canvas geometry. To center the content or anchor it to an edge, set the -gravity flag before specifying -extent.

Example: Adding a border/padding around an image by expanding the canvas symmetrically:

magick input.jpg -background white -gravity center -extent 1200x800 output.jpg

In this command:

  • -gravity center instructs ImageMagick to place the untouched image directly in the middle of the new canvas.
  • -extent 1200x800 sets the new canvas boundaries.
  • -background white defines the fill color for the newly exposed canvas area.

Fine-Tuning Offsets with Geometry Flags

The geometry string passed to -extent can also include explicit offset flags (+X+Y or -X-Y):

magick input.jpg -background transparent -extent 800x600+50+50 output.png
  • 800x600: The target canvas dimensions.
  • +50+50: Shifts the image 50 pixels to the right and 50 pixels down from the gravity anchor point without scaling the content.

Virtual Canvas Adjustments: -repage

For formats supporting layers and page offsets (such as PNG, TIFF, or GIF), you can adjust canvas metadata boundaries without altering pixel data using -repage:

magick input.png -repage 1000x1000+0+0 output.png

Unlike -extent, which physically adds or removes pixel areas, -repage changes the virtual canvas geometry coordinates while leaving the underlying raster data completely untouched.
