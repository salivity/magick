Restrict Pixel Color Values in ImageMagick

Restricting pixel color values in ImageMagick allows you to limit the dynamic range of an image, prevent color clipping, or create specific tonal effects. This guide covers the exact syntax and commands needed to cap, clamp, or remap pixel color values to a specific minimum and maximum threshold using ImageMagick version 7 (magick) and version 6 (convert).

1. Hard Clipping with -evaluate Max and -evaluate Min

If you want to cut off pixel values so that anything below a minimum threshold or above a maximum threshold is clipped to those boundaries, use the -evaluate operator.

  • -evaluate Max <value>: Sets a lower bound. Any pixel value lower than this value is raised to it.
  • -evaluate Min <value>: Sets an upper bound. Any pixel value higher than this value is lowered to it.
magick input.png -evaluate Max 20% -evaluate Min 80% output.png

In this example, all pixels with a brightness below 20% become 20%, and all pixels above 80% are capped at 80%. Values between 20% and 80% remain unchanged.

2. Scaling Values to a Range with +level

If you want to compress the entire tonal range into a specific minimum and maximum bracket rather than clipping the highlights and shadows, use the +level operator (note the plus sign).

magick input.png +level 20%,80% output.png
  • Syntax: +level <black_point>,<white_point>%
  • Pure black (0%) becomes 20%.
  • Pure white (100%) becomes 80%.
  • All intermediate values are scaled linearly to fit inside the 20%–80% range.

3. Restricting Values on Specific Color Channels

To apply range restrictions to a specific channel (such as red, green, blue, or alpha), combine the channel selector with the evaluation or level commands:

magick input.png -channel R -evaluate Max 10% -evaluate Min 90% +channel output.png

This command restricts only the red channel to values between 10% and 90%, leaving the green and blue channels unmodified.

4. Clamping to the Standard Quantum Range with -clamp

If operations (such as color space conversions or mathematical evaluations in HDRI mode) produce out-of-bounds pixel values (below 0 or above the standard Quantum range), you can restrict them back to the valid 0–100% display range using -clamp:

magick input.exr -clamp output.png
