Reverse Animated WebP Using ImageMagick

Reversing the playback of an animated WebP image is a straightforward task using ImageMagick, a versatile command-line image editing suite. This guide covers the exact commands needed to flip the sequence of frames using ImageMagick 7 and ImageMagick 6, along with tips to ensure playback speed and image quality remain consistent.

The Basic Command

To reverse the frame sequence, ImageMagick provides the -reverse operator. This operator inverts the order of all loaded frames in the current image sequence.

For ImageMagick 7 (Recommended)

magick input.webp -reverse output.webp

For ImageMagick 6

convert input.webp -reverse output.webp

Preserving Frame Timing and Geometry

Some animated WebP files use frame optimizations where each frame only updates changed pixels, or each frame has custom display delays. To avoid rendering artifacts or altered animation speeds, use the -coalesce option before reversing the frames:

magick input.webp -coalesce -reverse output.webp
  • -coalesce: Fully reconstructs each frame to its complete canvas view, preventing visual glitches when the frame order is inverted.
  • -reverse: Inverts the list of coalesced frames from last to first.

Setting Loop Count and Quality

By default, ImageMagick will maintain the standard properties, but you can explicitly specify looping and compression settings during the export:

magick input.webp -coalesce -reverse -loop 0 -quality 80 output.webp
  • -loop 0: Ensures the output animation loops indefinitely.
  • -quality [value]: Sets the WebP compression quality from 0 to 100 (where 100 is lossless).
