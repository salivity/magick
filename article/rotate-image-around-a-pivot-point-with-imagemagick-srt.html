Rotate Image Around a Pivot Point with ImageMagick SRT

Rotating an image around an arbitrary pivot point is straightforward using ImageMagick’s Scale-Rotate-Translate (SRT) distortion operator. By default, standard rotation methods spin an image around its center, but the SRT operator allows you to define custom coordinates for the axis of rotation. This guide demonstrates how to construct the SRT arguments, prevent unwanted image clipping, and handle canvas backgrounds for precise rotational transforms.

Understanding the SRT Syntax

The SRT operator is called using -distort SRT or +distort SRT. The parameters passed to SRT follow a specific coordinate-mapping order:

"[pivot_x],[pivot_y] [scale] [angle] [new_x],[new_y]"

To simply rotate around an arbitrary pivot point without altering image scale or moving the pivot location on the canvas, you can omit the trailing parameters and provide only the pivot coordinates and the rotation angle:

"X,Y angle"
  • X,Y: The horizontal and vertical pixel coordinates of the pivot point, where 0,0 is the top-left corner.
  • angle: The rotation in degrees clockwise (negative values rotate counter-clockwise).

Basic Rotation Command

To rotate an image named input.png by 45 degrees clockwise around the pixel coordinate (150, 200):

magick input.png -distort SRT "150,200 45" output.png

In ImageMagick version 6, replace magick with convert.

Preventing Canvas Clipping with +distort

Using -distort retains the original image dimensions, which cuts off parts of the image that rotate outside the original boundaries.

To automatically expand the output canvas to accommodate the entire rotated image, use the +distort form:

magick input.png -virtual-pixel transparent +distort SRT "150,200 45" output.png
  • +distort: Calculates the new bounding box necessary to fit the rotated image.
  • -virtual-pixel transparent: Ensures the newly revealed empty canvas area is transparent (for PNGs) rather than filled with stretched edge pixels.

Setting a Background Color

When rotating non-transparent formats such as JPEG, or when an explicit canvas color is needed, define the background color before applying the distortion:

magick input.jpg -background black -virtual-pixel background +distort SRT "100,100 30" output.jpg

Using Relative or Percentage Coordinates

If you prefer to define coordinates relative to the image dimensions rather than hardcoding absolute pixel values, use ImageMagick's embedded FX expressions:

magick input.png -virtual-pixel transparent +distort SRT "%[fx:w*0.25],%[fx:h*0.75] 90" output.png

In this command:

  • %[fx:w*0.25] sets the horizontal pivot at 25% of the total width.
  • %[fx:h*0.75] sets the vertical pivot at 75% of the total height.
