Rotate Text at Any Angle Using ImageMagick Annotate

Drawing rotated text at an arbitrary angle using ImageMagick is accomplished through the -annotate operator by specifying rotation degrees within its geometry argument. This guide outlines the proper command syntax, explains how angle and coordinate parameters function, and provides ready-to-use examples for rotating text clockwise or counter-clockwise to any degree.

The -annotate Geometry Syntax

The -annotate operator allows you to apply text to an image with full control over scaling, shearing, rotation, and translation. The standard geometry syntax for rotation and placement is:

-annotate [degreesX]x[degreesY]+[X]+[Y] "Your Text"
  • degreesX and degreesY: Control the rotation and shear angle. Setting both values to the same number (e.g., 45x45) rotates the text without skewing it. If you specify only a single signed or unsigned number before the offsets, ImageMagick applies it uniformly as the rotation angle.
  • +X+Y: Represents the pixel offset (horizontal and vertical coordinates) from the origin or anchor point specified by the -gravity setting.

Basic Command Structure

In ImageMagick version 7, use the magick command (for version 6, replace magick with convert).

To draw text rotated at a 30-degree angle on an existing image:

magick input.png -font Arial -pointsize 36 -fill white -annotate 30x30+100+200 "Rotated Text" output.png

To create a new canvas from scratch with rotated text:

magick -size 500x500 xc:lightgray -font DejaVu-Sans -pointsize 32 -fill black -annotate 45x45+150+250 "45 Degree Angle" output.png

Understanding Angle Direction and Gravity

  • Positive Angles: Rotate the text clockwise. For example, 45 tilts the text downward to the right.
  • Negative Angles: Rotate the text counter-clockwise. For example, -45 (or 315) tilts the text upward to the right.

The point around which the text rotates depends on the -gravity setting:

  • Default (NorthWest): Text rotates around the baseline starting point at the specified +X+Y coordinate.
  • Center: When combined with -gravity Center, the rotation anchor shifts relative to the center of the image canvas.

Centered Text at an Arbitrary Angle

To center text on the canvas and rotate it by -30 degrees:

magick input.png -gravity Center -font Arial -pointsize 40 -fill "#FF0000" -annotate -30x-30+0+0 "Centered and Tilted" output.png

Setting +0+0 keeps the text positioned directly in the middle of the canvas, while -30x-30 applies the rotation around that center point.
