Rotational Blur Operator Syntax in ImageMagick

This guide explains the syntax, parameters, and practical usage of the rotational blur operator in ImageMagick. You will learn how to apply rotational motion blur to images, understand how the angle argument works, and see examples using both ImageMagick 7 and ImageMagick 6 commands.

Basic Syntax

In modern versions of ImageMagick (ImageMagick 7), the command-line operator for applying rotational blur is -rotational-blur.

The general syntax is:

magick input.jpg -rotational-blur <angle> output.jpg

For ImageMagick 6, the standard command uses convert:

convert input.jpg -rotational-blur <angle> output.jpg

Parameters

  • <angle>: A numerical value representing the rotational blur angle in degrees.
    • A larger angle increases the intensity of the rotational sweep.
    • A value of 0 applies no blur.
    • Typical values range from 2 (subtle rotation effect) to 45 or higher (extreme spin effect).

Usage Examples

1. Subtle Rotational Blur

To apply a slight circular motion effect around the center of an image:

magick photo.jpg -rotational-blur 5 result_subtle.jpg

2. Strong Spin Effect

To create an intense spinning or vortex-like motion:

magick photo.jpg -rotational-blur 30 result_spin.jpg

3. Combining with Virtual Pixel Settings

You can modify how edge pixels are handled during the rotation using the -virtual-pixel setting:

magick photo.jpg -virtual-pixel mirror -rotational-blur 15 result_mirror.jpg

Legacy Syntax Note

In earlier iterations of ImageMagick 6, this operation was named -radial-blur. It was later renamed to -rotational-blur to more accurately describe the circular sweep motion rather than a zoom-out radial blur. If you are maintaining legacy scripts, -radial-blur functions identically to -rotational-blur:

convert photo.jpg -radial-blur 10 output.jpg
