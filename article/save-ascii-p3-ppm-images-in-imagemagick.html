Save ASCII P3 PPM Images in ImageMagick

This guide explains how to export images to uncompressed, plain-text ASCII Portable Pixmap (PPM) format using ImageMagick. By default, ImageMagick saves PPM files in the binary P6 format to conserve space. To generate an ASCII-encoded file starting with the P3 magic identifier, you must explicitly instruct ImageMagick to disable compression.

The Command Syntax

To save an image as an ASCII P3 PPM file, use the -compress none option.

For ImageMagick 7, use the magick command:

magick input.jpg -compress none output.ppm

For ImageMagick 6, use the legacy convert command:

convert input.jpg -compress none output.ppm

How It Works

  • input.jpg: The source image in any supported format (PNG, JPEG, TIFF, etc.).
  • -compress none: Tells ImageMagick not to use binary encoding for Netpbm formats. For PPM files, this forces the output to plain-text ASCII values, which triggers the use of the P3 magic identifier.
  • output.ppm: The destination file. ImageMagick infers the PPM format from the file extension.

Verifying the P3 Header

Because the output is plain text, you can inspect the first few lines of the generated file using standard shell utilities to verify that it uses the P3 identifier:

head -n 3 output.ppm

The output will display the P3 magic number, followed by the image dimensions (width and height), and the maximum color value (typically 255), followed by space- or newline-separated RGB triplets in decimal format:

P3
# Created by ImageMagick
100 100
255
