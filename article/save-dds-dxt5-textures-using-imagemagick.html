Save DDS DXT5 Textures Using ImageMagick

This guide outlines the precise ImageMagick syntax required to convert and save textures into the DirectDraw Surface (DDS) format using DXT5 (BC3) compression. You will learn the command-line parameters for modern ImageMagick versions, how to handle alpha channels properly, and how to control mipmap generation for game engine and 3D rendering workflows.

Basic Syntax for DDS DXT5 Conversion

To convert an image to a DDS file using DXT5 compression, use the -define dds:compression=dxt5 argument. DXT5 is ideal for textures that include smooth or complex transparency gradients because it uses interpolated alpha.

For ImageMagick 7 (recommended):

magick input.png -define dds:compression=dxt5 output.dds

For ImageMagick 6 (legacy):

convert input.png -define dds:compression=dxt5 output.dds

Controlling Mipmaps

Game engines typically require mipmaps for DDS textures to prevent aliasing and optimize rendering performance at a distance.

Enable automatic mipmap generation:

magick input.png -define dds:compression=dxt5 -define dds:mipmaps=from-filter output.dds

Disable mipmap generation (single surface only):

magick input.png -define dds:compression=dxt5 -define dds:mipmaps=0 output.dds

Preserving Texture Dimensions

DXT compression requires texture dimensions to be multiples of 4 (and traditionally powers of two, such as 512x512, 1024x1024, or 2048x2048). If your source image does not meet these criteria, you can resize it during conversion:

magick input.png -resize 1024x1024! -define dds:compression=dxt5 output.dds

Batch Conversion

To convert all PNG textures within a directory to DDS DXT5 on Linux or macOS:

for file in *.png; do
  magick "$file" -define dds:compression=dxt5 "${file%.png}.dds"
done

On Windows (Command Prompt):

for %f in (*.png) do magick "%f" -define dds:compression=dxt5 "%~nf.dds"
