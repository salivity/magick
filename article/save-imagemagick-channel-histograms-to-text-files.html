Save ImageMagick Channel Histograms to Text Files

ImageMagick provides built-in tools to analyze the tonal and color distribution of an image and export that data directly into plain text files. This guide demonstrates how to isolate individual color channels (Red, Green, Blue, Alpha, or Grayscale), compute their histogram frequency data, and output the numerical values to text files using ImageMagick command-line tools.

Extracting Individual Channel Histograms

To generate a histogram for a specific channel, you isolate the desired channel using the -channel and -separate operators, then pipe the result to the histogram:info: output delegate.

Red Channel

magick input.png -channel R -separate histogram:info:red_histogram.txt

Green Channel

magick input.png -channel G -separate histogram:info:green_histogram.txt

Blue Channel

magick input.png -channel B -separate histogram:info:blue_histogram.txt

Alpha Channel (if applicable)

magick input.png -channel A -separate histogram:info:alpha_histogram.txt

(Note: If you are using ImageMagick version 6, replace magick with convert in all commands).

Extracting All Channels in a Single Command

You can split an image into all of its constituent channels simultaneously and export each channel's histogram to distinct text files using an index format:

magick input.png -separate histogram:info:channel_%d_histogram.txt

This generates channel_0_histogram.txt (Red), channel_1_histogram.txt (Green), and channel_2_histogram.txt (Blue).

Formatting Histogram Output for Data Analysis

By default, histogram:info: outputs comments, color codes, and sRGB metadata. If you require a clean list containing only pixel counts and intensity values, use the -format option:

magick input.png -channel R -separate -format "%c" histogram:info:red_clean.txt

Understanding the Output Format

The exported text file contains entries formatted as follows:

    10452: (  0,  0,  0) #000000 gray(0)
      321: (  1,  1,  1) #010101 gray(1)
     1890: (  2,  2,  2) #020202 gray(2)
      ...
    45120: (255,255,255) #FFFFFF gray(255)
  • First column (10452:): The total pixel count matching that specific intensity level.
  • Second column ((0, 0, 0)): The raw channel intensity value.
  • Third column (#000000): The hex representation.
  • Fourth column (gray(0)): The normalized color name or value.

Parsing Output with Command-Line Tools

If you need a two-column CSV containing only intensity,pixel_count for plotting tools (such as Python, R, or Gnuplot), combine the command with awk or sed:

magick input.png -channel R -separate -format "%c" histogram:info: | \
awk '{gsub(/:/, ""); print $3 "," $1}' | \
tr -d '()' > red_histogram.csv
