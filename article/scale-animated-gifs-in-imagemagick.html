Scale Animated GIFs in ImageMagick

Resizing an animated GIF while preserving its animation requires handling individual frames properly to prevent visual artifacts and distortion. This guide provides the exact ImageMagick syntax to scale all frames of an animated GIF to fit within a specific bounding box while maintaining the aspect ratio, along with an explanation of each parameter used in the command.

The Command Syntax

To scale an animated GIF so that it fits inside a specific bounding box (for example, 500x500 pixels), use the following syntax in ImageMagick:

magick input.gif -coalesce -resize 500x500\> -layers Optimize output.gif

(Note: In ImageMagick version 6, replace magick with convert.)

Command Breakdown

  1. input.gif
    The source animated GIF file.

  2. -coalesce
    Animated GIFs often use frame disposal methods that only store the differences between consecutive frames to save space. The -coalesce option rebuilds each frame completely to its full visual state before resizing. Skipping this step often results in broken or distorted animations after scaling.

  3. -resize 500x500\>
    Specifies the target bounding box dimensions (Width x Height).

    • By default, -resize 500x500 scales the image so that the longest side fits within 500 pixels while strictly preserving the aspect ratio.
    • The \> symbol ensures the image is only downscaled if it is larger than the bounding box. If you are using Windows Command Prompt instead of Bash, omit the backslash and use "500x500>".

  4. -layers Optimize
    After resizing, the frames are re-optimized to reduce file size by discarding redundant pixel data between frames. This replaces the older -deconstruct parameter and ensures the output file size remains as small as possible.

  5. output.gif
    The name of the generated, scaled GIF.

Geometry Variations for Bounding Boxes

Depending on your scaling requirements, you can modify the geometry string:

  • Fit within box (shrink only): 500x500\> (Only resizes if larger than 500x500)
  • Fit within box (shrink or enlarge): 500x500 (Resizes larger images down and smaller images up to fit)
  • Fit to fixed width: 500x (Maintains aspect ratio based on width)
  • Fit to fixed height: x500 (Maintains aspect ratio based on height)
  • Force exact bounding box (ignore aspect ratio): 500x500\!
