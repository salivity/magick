Scale Image to Exact Height in ImageMagick

Resizing an image to a specific height while preserving its aspect ratio is a common task in image processing. In ImageMagick, this is achieved by leaving the width parameter empty in the geometry argument, prompting the tool to automatically calculate the proportional width. This guide details the exact command-line syntax required for both modern and legacy versions of ImageMagick.

The Basic Syntax

To constrain only the height of an image, specify the target height preceded by an x within the -resize option:

magick input.jpg -resize x<height> output.jpg

By omitting the number before the x, ImageMagick understands that the width is unconstrained and should scale automatically to prevent distortion.

Command Examples

ImageMagick 7 (Current Version)

For ImageMagick version 7 and later, use the magick command:

magick photo.jpg -resize x600 resized_photo.jpg

In this example, photo.jpg will be scaled to an exact height of 600 pixels, and its width will automatically adjust to preserve the original aspect ratio.

ImageMagick 6 (Legacy Version)

If you are working on an older system using ImageMagick version 6, use the convert command:

convert photo.jpg -resize x600 resized_photo.jpg

Batch Processing Multiple Files

To apply this transformation across an entire directory of images without altering their names, use the mogrify tool. Be aware that this command overwrites the original files unless a separate output directory is specified:

magick mogrify -resize x600 *.jpg

For ImageMagick 6:

mogrify -resize x600 *.jpg

Important Modifiers

  • Prevent Upscaling (>): If you only want to shrink images that are taller than the target height without enlarging smaller images, append the > character inside quotes: 
    magick input.jpg -resize "x600>" output.jpg
  • Force Upscaling (<): If you only want to enlarge images that are shorter than the target height, use the < modifier: 
    magick input.jpg -resize "x600<" output.jpg
