Select PSD Layers with ImageMagick Indices

This guide explains how to extract and manipulate specific layers from Adobe Photoshop (PSD) files using ImageMagick's bracket index notation. You will learn how ImageMagick numbers PSD layers, how to target the composite image versus individual layers, and the exact syntax required for extracting single layers, ranges, and non-consecutive layers.

Understanding PSD Layer Indexing

ImageMagick treats multi-layer formats like PSD files as a sequence of frames, assigning each layer a zero-based index ([0], [1], [2], etc.).

  • Index [0]: In standard PSD files saved from Photoshop, index 0 represents the flattened, composite preview of the entire image.
  • Index [1] and higher: These indices represent the individual layers of the document, ordered from the bottom of the layer stack to the top.

To target a specific layer, append the desired index inside square brackets directly after the filename, with no space in between.

Selecting a Single Layer

To extract a single layer and save it to a new file, append [index] to the input filename.

Extract the flattened composite image:

magick input.psd[0] output_composite.png

Extract the first actual layer:

magick input.psd[1] layer_1.png

Extract a specific layer (e.g., layer 4):

magick input.psd[4] layer_4.png

Selecting Layer Ranges

You can select a sequential range of layers using a hyphen ([start-end]).

Extract layers 1 through 3:

magick input.psd[1-3] layer_%d.png

Note: Using %d in the output filename will generate sequentially numbered output files (e.g., layer_0.png, layer_1.png, layer_2.png).

Selecting Multiple Non-Consecutive Layers

To select multiple specific layers that are not in a direct sequence, separate the indices with commas inside the brackets.

Extract layers 1, 3, and 5:

magick input.psd[1,3,5] extracted_%d.png

Handling Sub-images and Canvas Offsets

Individual PSD layers often retain their original canvas coordinates and transparency offsets. If an extracted layer appears clipped or misplaced, use the -dispose or +repage operators to reset the canvas geometry:

magick input.psd[2] +repage layer_2_cropped.png

The +repage operator removes the canvas offset metadata, ensuring the output image's boundaries match the actual pixel dimensions of the selected layer.
