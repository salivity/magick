Set CCITT Group 3 TIFF Compression in ImageMagick

This guide explains how to convert images to TIFF format using CCITT Group 3 (Fax) compression in ImageMagick. You will learn the mandatory image preparation steps, the correct command-line parameters for Group 3 encoding, and common configuration options to ensure compatibility with standard fax software and legacy archiving systems.

Prerequisites: 1-Bit Bilevel Formatting

CCITT Group 3 compression is strictly designed for 1-bit monochrome (black-and-white) images. Before applying compression, the input image must be converted to a bilevel color space. If color or grayscale data is passed to the encoder, ImageMagick will either fail or automatically posterize the image, often with suboptimal results.

To prepare the image:

  • Use -monochrome for basic dithering.
  • Alternatively, use -threshold 50% (or another percentage) for a hard cutoff without dithering.
  • Explicitly set -depth 1.

Basic Command Syntax

In ImageMagick version 7, use the magick command (or convert in ImageMagick version 6). The CCITT Group 3 compression algorithm is specified using either -compress Group3 or -compress Fax.

magick input.png -monochrome -depth 1 -compress Group3 output.tif

Using -compress Fax is an alias that produces the identical CCITT T.4 (Group 3) compression stream:

magick input.png -threshold 50% -depth 1 -compress Fax output.tif

Configuring Group 3 Fax Options

Standard TIFF files using Group 3 compression can store data in different fill orders and polarities depending on the target fax hardware or software requirements.

1. Bit Fill Order

Some legacy fax receivers expect the most significant bit (MSB) to appear first, while others expect the least significant bit (LSB) first. You can control this via the TIFF fill-order definition:

magick input.jpg -threshold 50% -depth 1 -define tiff:fill-order=msb2lsb -compress Group3 output.tif

Accepted values are msb2lsb (standard for most TIFF readers) and lsb2msb (common in raw fax transmissions).

2. Photometric Interpretation (Polarity)

CCITT faxes typically define 0 as white and 1 as black (PhotometricInterpretation = WhiteIsZero), which is inverted relative to standard digital displays. ImageMagick handles this automatically when converting to bilevel TIFFs, but you can invert or enforce polarity if required:

# Invert colors before compression if the output appears inverted
magick input.jpg -threshold 50% -negate -depth 1 -compress Group3 output.tif

3. Strips vs. Rows per Strip

Group 3 works best with continuous streams or small strip sizes. You can set the number of rows per strip to maintain compatibility with specific fax parsers:

magick input.jpg -threshold 50% -depth 1 -define tiff:rows-per-strip=16 -compress Group3 output.tif

Verifying the Output

To verify that the CCITT Group 3 compression and 1-bit depth have been applied correctly, run the magick identify command:

magick identify -format "Compression: %[compression]\nDepth: %[depth]\n" output.tif

The output should display:

Compression: Group3
Depth: 1
