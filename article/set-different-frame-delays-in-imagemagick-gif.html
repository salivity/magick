Set Different Frame Delays in ImageMagick GIF

This article explains how to assign custom, distinct display durations to individual frames within an animated GIF using ImageMagick. You will learn the unit measurements used by the software, how to apply specific delays when assembling individual image files, and how to modify frame timings in an already existing animated GIF.

Understanding ImageMagick Delay Values

In ImageMagick, frame duration is controlled by the -delay setting. The duration unit is measured in ticks per second, with the default being 100 ticks per second (centiseconds).

  • -delay 10 = 0.10 seconds (100 ms)
  • -delay 50 = 0.50 seconds (500 ms)
  • -delay 100 = 1.00 second (1000 ms)
  • -delay 200 = 2.00 seconds (2000 ms)

Creating a GIF with Distinct Frame Durations

To set different durations for each frame while building a new GIF, specify the -delay option immediately before each input image file. The delay applies to all subsequent images until a new -delay flag is declared.

magick -delay 50 frame1.png -delay 200 frame2.png -delay 100 frame3.png -loop 0 output.gif

In this command:

  • frame1.png displays for 0.5 seconds.
  • frame2.png displays for 2.0 seconds (e.g., to create a pause on a key frame).
  • frame3.png displays for 1.0 second.
  • -loop 0 sets the GIF to loop infinitely.

Modifying Frame Delays in an Existing GIF

To adjust timings in an existing GIF without recreating it from individual image assets, use the -coalesce operator to extract fully rendered frames, followed by conditional operators or frame indexing.

Method 1: Using Conditional Logic (FX Expressions)

You can set global base timings and modify specific frames using ImageMagick’s %[fx:...] expression syntax. Frame indices start at 0.

magick input.gif -coalesce -set delay "%[fx: t==0 ? 300 : (t==2 ? 150 : 50)]" output.gif

In this example:

  • Frame 0 (the first frame) is set to 3.0 seconds (300).
  • Frame 2 (the third frame) is set to 1.5 seconds (150).
  • All other frames are set to 0.5 seconds (50).

Method 2: Targeting Specific Frame Ranges with Parentheses

You can clone, modify, and overwrite specific frames directly:

magick input.gif -coalesce \
  -set delay 50 \
  ( -clone 0 -set delay 200 ) -swap 0,-1 +delete \
  ( -clone 4 -set delay 300 ) -swap 4,-1 +delete \
  output.gif

In this command:

  • -set delay 50 resets all frames to 0.5 seconds.
  • The subshell ( -clone 0 -set delay 200 ) updates the first frame duration to 2 seconds.
  • -swap 0,-1 +delete replaces the original frame 0 with the updated clone.
  • The same operation is repeated for frame 4 to set it to 3 seconds.
