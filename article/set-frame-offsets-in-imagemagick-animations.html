Set Frame Offsets in ImageMagick Animations

This guide explains how to set custom canvas offsets for individual animation sub-frames using ImageMagick. By defining spatial offsets (+X+Y) for specific frames, you can position smaller image elements across a larger canvas without rendering full-sized frames for every step, reducing file sizes and controlling frame positioning in formats like GIF or APNG.

Setting Offsets When Creating New Animations

To assign specific coordinates to individual frames when generating a new animation, use the -page geometry setting before specifying each input file. Define the overall canvas size on the first frame, followed by relative or absolute pixel offsets for subsequent frames.

magick -dispose previous -delay 20 \
  -page 500x500+0+0   frame0.png \
  -page +50+50        frame1.png \
  -page +120+80       frame2.png \
  -page +200+150      frame3.png \
  -loop 0 output.gif
  • 500x500+0+0: Sets the master canvas size (500x500 pixels) and positions the base frame at the top-left corner.
  • +X+Y: Specifies the horizontal (X) and vertical (Y) offset from the canvas origin for each corresponding sub-frame.
  • -dispose previous: Ensures previous sub-frames are cleared before drawing the next frame at its new offset.

Modifying Offsets on Existing Animations

To adjust the offsets of specific frames in an already existing animation file, use frame indexing combined with the ( ... ) operators and the -repage or -set page options.

Adjusting Specific Frames by Index

magick input.gif -coalesce \
  \( -clone 1 -repage +80+40 \) -swap 1,2 +delete \
  \( -clone 2 -repage +150+90 \) -swap 2,3 +delete \
  -loop 0 output.gif
  1. -coalesce: Reconstructs the full frames from the original animation, ensuring accurate dimensions.
  2. \( -clone [index] -repage +X+Y \): Targets the specific sub-frame (0-indexed) and assigns the new canvas offset.
  3. -swap and +delete: Replaces the original frame with the modified offset version.

Setting Offsets Globally Across All Sub-Frames

If you want to apply a uniform shifting rule or reset offsets to absolute zero for the entire animation:

magick input.gif -coalesce -repage +0+0 output.gif

Important Settings for Canvas Offsets

  • -page WxH+X+Y: Configures the total canvas dimensions (WxH) alongside the top-left offset (+X+Y) for incoming source images.
  • -repage +X+Y: Modifies the virtual canvas offset of images already loaded into memory.
  • -dispose: Defines what happens to the canvas area when advancing to the next frame. Use -dispose background or -dispose previous when sub-frames are smaller than the main canvas to avoid ghosting artifacts.
