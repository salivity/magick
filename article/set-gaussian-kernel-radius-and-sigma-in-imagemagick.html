Set Gaussian Kernel Radius and Sigma in ImageMagick

This guide explains how to define and configure a discrete Gaussian kernel's radius and sigma in ImageMagick. You will learn the exact syntax for specifying these values, the mathematical difference between radius and sigma, and how to apply them using standard blur operations and custom convolution kernels.

The Radius x Sigma Syntax

In ImageMagick, Gaussian kernels are defined using the geometry format {radius}x{sigma}.

  • sigma (\(\sigma\)): The standard deviation of the Gaussian distribution. It determines the actual spread or intensity of the blur. A higher sigma produces a wider curve and a stronger blur.
  • radius (\(r\)): The physical half-width of the discrete matrix window. The generated convolution matrix will have dimensions of \((2r + 1) \times (2r + 1)\) pixels.

Basic Gaussian Blur Command

To apply a Gaussian filter directly to an image, use the -gaussian-blur or -blur operator:

magick input.png -gaussian-blur 5x2 output.png

In this example:

  • The kernel radius is 5, creating an \(11 \times 11\) matrix window (\(2 \times 5 + 1\)).
  • The sigma is 2.0, defining the bell-curve spread inside that \(11 \times 11\) area.

Defining a Gaussian Kernel with Morphology

To construct a specific discrete Gaussian matrix for convolution or morphology operations, use the -morphology operator:

magick input.png -morphology Convolve Gaussian:5x2 output.png

You can also output the generated kernel values directly to the terminal for inspection by passing the kernel definition to the showkernel format:

magick -define morphology:showkernel=1 -morphology Convolve Gaussian:3x1.5 null:

Automatic Radius Calculation

If you set the radius to 0, ImageMagick automatically calculates an optimal matrix size based on the provided sigma:

magick input.png -gaussian-blur 0x3 output.png

When radius is set to 0, ImageMagick typically sets the radius to approximately \(3 \times \sigma\) or \(4 \times \sigma\). This ensures that the discrete array is large enough to capture roughly 99.7% or more of the Gaussian curve, preventing harsh edge cutoffs while avoiding unnecessary matrix computations.

Key Considerations for Discrete Kernels

  1. Clipping: If the radius is set too small relative to the sigma (e.g., radius = 1, sigma = 5), the Gaussian curve will be clipped prematurely, leading to hard edges and clipping artifacts.
  2. Performance: Increasing the radius expands the matrix size quadratically. For large blurs, relying on a fixed sigma with radius = 0 allows ImageMagick to balance performance and visual quality.
