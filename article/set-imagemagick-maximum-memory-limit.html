Set ImageMagick Maximum Memory Limit

This article explains the specific security and resource policy parameter used to configure the maximum memory footprint for ImageMagick processes. It details how the memory parameter works, where to locate the configuration file, how to apply changes, and how related limits like map and disk interact with system RAM.

The Memory Policy Parameter

In ImageMagick, the primary parameter used to restrict the maximum RAM footprint is the memory resource limit.

This setting is defined inside ImageMagick's security policy configuration file, typically named policy.xml. It limits the maximum amount of physical RAM that can be allocated to the pixel cache during image processing operations.

Configuration Syntax

To set the memory limit, open your system's policy.xml file and add or modify the following line within the <policymap> tags:

<policy domain="resource" name="memory" value="512MiB"/>

You can specify values in standard units such as KB, MB, MiB, GB, or GiB.

Related Resource Parameters

When an image exceeds the allocated memory limit, ImageMagick does not necessarily fail immediately. Instead, it relies on a hierarchy of fallback memory-handling limits:

  • map: Sets the maximum memory footprint for memory-mapped files (e.g., <policy domain="resource" name="map" value="1GiB"/>). Once the memory limit is exceeded, ImageMagick attempts to use memory-mapped disk files.
  • area: Limits the maximum width × height of an image that can reside entirely in memory before caching to disk occurs.
  • disk: Sets the maximum disk space allowed for caching when both memory and map limits are exhausted.

Locating policy.xml

Depending on your operating system and ImageMagick version, policy.xml is commonly found in one of the following directories:

  • Linux (Debian/Ubuntu): /etc/ImageMagick-6/policy.xml or /etc/ImageMagick-7/policy.xml
  • Linux (RHEL/CentOS): /etc/ImageMagick/policy.xml
  • macOS (Homebrew): /usr/local/etc/ImageMagick-7/policy.xml or /opt/homebrew/etc/ImageMagick-7/policy.xml
  • Windows: Inside the main ImageMagick installation directory.

Verifying Active Resource Limits

To verify that your memory limits are applied correctly, run the following command in your terminal:

magick identify -list resource

(For ImageMagick v6, use identify -list resource)

The output displays the active maximum limits for Memory, Map, Area, and other system resources.
