Set ImageMagick PostScript Resolution to 1200 DPI

This guide demonstrates how to configure ImageMagick to rasterize PostScript (PS and EPS) files at 1200 dots per inch (DPI). By default, ImageMagick renders PostScript files using Ghostscript at a low default resolution of 72 DPI. To achieve crisp, high-resolution raster output suitable for commercial printing or detailed archiving, you must instruct the Ghostscript delegate to render the vector source at 1200 DPI using the -density setting placed before the input file.

The Core Command

To render a PostScript file at 1200 DPI, place the -density 1200 argument before specifying your input file.

For ImageMagick 7:

magick -density 1200 input.ps output.png

For ImageMagick 6:

convert -density 1200 input.ps output.png

Why Parameter Order Matters

ImageMagick treats options differently based on their position in the command line:

  • Before the input file (-density 1200 input.ps): Acts as an input setting. It instructs Ghostscript to rasterize the native vector PostScript data directly at 1200 DPI.
  • After the input file (input.ps -density 1200): Acts as an image property. The file will render at the default 72 DPI first, and ImageMagick will merely change the metadata flag without improving raster image quality.

Always define -density prior to the input filename to ensure full vector-to-raster quality.

Recommended Command for Print Production

When working with 1200 DPI PostScript files, you often need to explicitly set measurement units, handle transparency, and manage color profiles:

magick -density 1200 -units PixelsPerInch input.eps -background white -flatten -colorspace sRGB output.tiff
  • -density 1200: Rasterizes vector paths at 1200 DPI.
  • -units PixelsPerInch: Ensures the density metadata is properly stored in PPI/DPI rather than PixelsPerCentimeter.
  • -background white -flatten: Replaces transparent areas with a solid white background, preventing rendering artifacts common in PostScript transparency.
  • -colorspace sRGB: Converts CMYK PostScript assets to standard RGB for digital use (omit this if producing CMYK print TIFFs).

Verifying the Output Resolution

After rendering, confirm that the target file has retained the correct DPI and dimensions using the identify utility:

magick identify -format "%w x %h pixels, Resolution: %x x %y %U\n" output.tiff

This returns the exact pixel dimensions alongside the designated resolution in PixelsPerInch.
