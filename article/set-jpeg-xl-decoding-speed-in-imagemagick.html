Set JPEG XL Decoding Speed in ImageMagick

Adjusting the JPEG XL decoding speed tier in ImageMagick allows you to optimize how computationally demanding a file is to decompress by using the -define jxl:decoding-speed parameter. This setting accepts integer values ranging from 0 to 4, balancing decoding performance against compression efficiency and image fidelity. This guide explains how the decoding speed tiers function and demonstrates the exact command-line syntax required to apply them.

Understanding Decoding Speed Tiers

In the JPEG XL specification, the decoding speed tier (values 0 through 4) is an encoder-side setting that instructs the encoder to avoid specific compression tools that require intensive CPU processing to decode:

  • 0 (Default): Highest compression efficiency and fidelity. The decoder uses all necessary processing features, which requires the most CPU resources.
  • 1: Minor optimizations for faster decoding with minimal impact on compression ratio.
  • 2: Moderate decoding speed increase, disabling more resource-heavy reconstruction filters.
  • 3: Fast decoding suitable for lower-powered devices or mobile targets.
  • 4: Maximum decoding speed. Strips out most complex post-processing features to ensure the fastest possible decompression at the expense of file size and some quality.

Command-Line Syntax

To apply this parameter in ImageMagick, use the -define flag followed by the key jxl:decoding-speed= and your desired value (0 to 4) when writing a JPEG XL image.

Basic Conversion Example

To convert a standard PNG or JPEG into a JPEG XL image optimized for maximum decoding speed (Tier 4):

magick input.png -define jxl:decoding-speed=4 output.jxl

Balancing Quality and Decoding Speed

For a balanced approach that provides faster decoding on mobile devices while preserving strong compression, Tier 2 or 3 is generally recommended:

magick input.jpg -quality 85 -define jxl:decoding-speed=2 output.jxl

Verifying libjxl Support

The jxl:decoding-speed parameter requires ImageMagick to be compiled with libjxl support. You can verify that your ImageMagick installation includes the JPEG XL delegate by running:

magick -version

Look for jxl in the Delegates (built-in) list to ensure that JPEG XL encoding and its associated configuration options are available.
