Set JPEG XL Effort in ImageMagick

This article explains how to control the compression effort for JPEG XL (JXL) images using ImageMagick. By using a specific define flag, users can adjust the encoding speed and efficiency trade-off on a scale from 1 to 9 to achieve either faster processing times or superior file size optimization.

The ImageMagick define used to configure the JPEG XL encoding effort is jxl:effort. This parameter directly maps to the underlying libjxl encoder effort setting, accepting an integer value from 1 to 9.

Syntax

To set the effort level, pass the -define option before or during the output specification:

magick input.png -define jxl:effort=7 output.jxl

Effort Scale Breakdown

The value assigned to jxl:effort controls the balance between CPU time and compression density:

  • 1 (Fastest): Minimal CPU usage and fastest encoding speed, resulting in larger file sizes. Suitable for real-time applications or quick previews.
  • 7 (Default): The recommended balance for general use, providing strong compression efficiency with reasonable encoding speed.
  • 9 (Slowest): Maximum compression density ("tortoise" mode). This setting uses exhaustive search algorithms to produce the smallest possible file size at the cost of high CPU utilization and significantly slower processing.

Usage Example

To convert an image with maximum lossless compression effort:

magick input.tif -quality 100 -define jxl:effort=9 output.jxl

To optimize for high-speed batch processing with standard quality:

magick input.jpg -quality 85 -define jxl:effort=3 output.jxl
