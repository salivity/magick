Set Line Spacing in ImageMagick with Interline-Spacing

This article explains how to adjust the vertical gap between lines of multiline text in ImageMagick using the -interline-spacing option. You will learn the command syntax, how positive and negative pixel offsets affect text layout, and practical examples using common text operators like caption: and label:.

The -interline-spacing Setting

ImageMagick controls line spacing using the -interline-spacing option. This setting defines an extra vertical pixel offset added between consecutive lines of text.

  • Positive value (e.g., 10): Adds additional space between lines, expanding the total height of the text block.
  • Negative value (e.g., -5): Decreases the gap between lines, condensing the lines closer together.
  • Default value (0): Uses the font's standard built-in line height metrics.

Basic Syntax

To apply line spacing, specify -interline-spacing <pixels> before defining your text operator (caption:, label:, or -annotate):

magick -size 400x200 xc:white -font Arial -pointsize 24 -fill black \
  -interline-spacing 15 caption:"First line of text\nSecond line of text" \
  output.png

Examples

Increasing Line Spacing with caption:

When generating blocks of wrapped text with caption:, you can enhance readability by increasing line spacing:

magick -size 500x300 xc:#f4f4f4 -fill #333333 \
  -font DejaVu-Sans -pointsize 20 \
  -interline-spacing 12 \
  -gravity center \
  caption:"ImageMagick allows you to format text blocks dynamically and control line heights directly from the terminal." \
  spaced_text.png

Decreasing Line Spacing with Negative Offsets

If a font has naturally wide line spacing or you need to fit multiline text into a constrained area, pass a negative integer:

magick -size 400x150 xc:white -fill black \
  -font Arial -pointsize 28 \
  -interline-spacing -6 \
  -gravity center \
  label:"COMPACT\nHEADLINE" \
  compact_text.png

Applying Spacing with -annotate

When overlaying multiline text directly onto an existing image using -annotate:

magick input.jpg -font Arial -pointsize 22 -fill white \
  -interline-spacing 8 \
  -gravity south -annotate +0+20 "Line One\nLine Two" \
  annotated.jpg

Key Considerations

  • Option Order: In ImageMagick (especially version 7 and later), -interline-spacing is a setting. It must appear on the command line before the text generation operator (caption:, label:) or -annotate command to take effect.
  • Excessive Negative Values: Setting a negative value larger than the font's baseline-to-baseline distance will cause lines to overlap.
