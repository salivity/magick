Set Loop Count for Animated WebP in ImageMagick

This guide explains how to define the loop count for animated WebP images using ImageMagick's command-line tools. By utilizing the -loop setting, you can configure your animated WebP files to repeat infinitely or stop after a designated number of playback cycles, whether you are building a new animation from scratch or modifying an existing file.

The -loop Setting

ImageMagick controls animation repetition through the -loop option. The value assigned to this flag determines the behavior:

  • 0: Plays the animation in an infinite loop.
  • 1: Plays the animation once without repeating.
  • N (any positive integer): Loops the animation N times before stopping on the final frame.

Creating a New Animated WebP with a Loop Count

When generating a WebP animation from a series of static source images, place the -loop flag and the -delay flag before the output file name.

ImageMagick 7 (Recommended)

To create an infinitely looping WebP:

magick -delay 20 -loop 0 frame1.png frame2.png frame3.png output.webp

To create a WebP that loops exactly 3 times:

magick -delay 20 -loop 3 frame1.png frame2.png frame3.png output.webp

ImageMagick 6

In ImageMagick 6, use the convert command:

convert -delay 20 -loop 0 frame*.png output.webp

Changing the Loop Count on an Existing WebP

If you already have an animated WebP file and need to adjust its loop count without regenerating the frames from scratch, load the input file, apply the new loop parameter, and overwrite or save to a new file.

Infinite Loop

magick input.webp -loop 0 output.webp

Fixed Loop Count

magick input.webp -loop 5 output.webp

Verifying the WebP Loop Count

You can confirm that the loop metadata has been successfully embedded by inspecting the file with ImageMagick's identify command:

magick identify -verbose output.webp | grep -i iterations

The output will display the configured iteration count, where 0 confirms continuous looping.
