Set PDF CropBox Instead of MediaBox in ImageMagick

When converting PDF files to image formats, ImageMagick defaults to rendering the entire page canvas using the PDF's MediaBox boundary, often ignoring margins that were trimmed using a CropBox. This article explains how to configure ImageMagick to respect the CropBox dimension instead, ensuring that only the cropped, visible portion of the PDF document is rendered in the final output.

Understanding MediaBox vs. CropBox

PDF files contain multiple bounding box definitions:

  • MediaBox: Defines the physical medium size on which the page is printed (e.g., standard US Letter or A4).
  • CropBox: Defines the region to which page contents are clipped when displayed or printed.

By default, Ghostscript (the delegate library ImageMagick uses to parse PDFs) renders according to the MediaBox. If a PDF has been cropped after creation, using default settings will cause the excluded whitespace or hidden content to reappear in the converted image.

How to Enforce the CropBox Boundary

To force ImageMagick to use the CropBox, use the -define pdf:use-cropbox=true option.

ImageMagick v7 Command:

magick -define pdf:use-cropbox=true input.pdf output.png

ImageMagick v6 Command:

convert -define pdf:use-cropbox=true input.pdf output.png

Ensuring High Resolution Output

When converting PDFs to raster formats like PNG or JPEG, specify the -density setting to maintain visual quality. Place both -density and the -define option before the input filename:

magick -density 300 -define pdf:use-cropbox=true input.pdf output.png

Important Usage Notes

  1. Option Placement: The -define pdf:use-cropbox=true argument must be placed before the input PDF file in your command line. If placed after, the PDF will already have been rendered using the default MediaBox.
  2. Alternative Boundaries: If your PDF uses other bounding boxes such as TrimBox, ArtBox, or BleedBox, you can adapt the command accordingly:
    • -define pdf:use-trimbox=true
    • -define pdf:use-artbox=true
    • -define pdf:use-bleedbox=true
