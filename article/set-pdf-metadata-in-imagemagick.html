Set PDF Metadata in ImageMagick

Setting PDF metadata such as the document title, author, and subject in ImageMagick is a straightforward process achieved by using format-specific defines during the file creation or conversion process. By leveraging the -define operator, you can embed essential document properties directly into output PDF files, ensuring your documents are properly indexed, accessible, and organized.

The Command Syntax

To set metadata fields when writing a PDF, use the -define command with the pdf: prefix followed by the property you wish to configure:

  • pdf:title sets the document title.
  • pdf:author sets the name of the author or creator.
  • pdf:subject sets the topic or subject matter of the document.
  • pdf:keywords sets searchable keywords (optional, but commonly used alongside the others).

Example: Creating a PDF from Images with Metadata

In ImageMagick version 7, use the magick command:

magick input.jpg \
  -define pdf:title="Quarterly Financial Report" \
  -define pdf:author="Jane Doe" \
  -define pdf:subject="Q3 Performance and Revenue Analysis" \
  -define pdf:keywords="finance, quarterly, report, revenue" \
  output.pdf

For ImageMagick version 6, replace magick with convert:

convert input.jpg \
  -define pdf:title="Quarterly Financial Report" \
  -define pdf:author="Jane Doe" \
  -define pdf:subject="Q3 Performance and Revenue Analysis" \
  output.pdf

Updating Metadata on an Existing PDF

You can also read an existing PDF and rewrite it with updated metadata. Note that this process rasterizes the pages using Ghostscript unless specified otherwise:

magick -density 300 existing_document.pdf \
  -define pdf:title="Updated Document Title" \
  -define pdf:author="New Author" \
  -define pdf:subject="Revised Subject" \
  updated_document.pdf

Note: The -density 300 flag ensures the rasterized pages retain high print quality.

Verifying the Metadata

Once the output file is generated, you can verify that the metadata was successfully embedded using the pdfinfo command-line utility:

pdfinfo output.pdf

Alternatively, you can inspect properties using ImageMagick’s identify tool:

magick identify -verbose output.pdf
