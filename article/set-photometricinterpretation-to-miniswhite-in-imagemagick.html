Set PhotometricInterpretation to MinIsWhite in ImageMagick

This guide explains how to configure ImageMagick to output TIFF images with the TIFF PhotometricInterpretation tag set to MinIsWhite (WhiteIsZero). By default, ImageMagick saves grayscale and bilevel TIFF files using MinIsBlack (BlackIsZero). You can override this behavior using built-in ImageMagick defines to ensure compatibility with legacy document viewers, medical imaging systems, or specific TIFF readers.

The Solution: quantum:polarity

To set PhotometricInterpretation to MinIsWhite, use the -define quantum:polarity=min-is-white option. The image must also be in a grayscale or bilevel colorspace for ImageMagick's TIFF coder to apply this tag.

ImageMagick 7 (Standard CLI)

magick input.jpg -colorspace Gray -define quantum:polarity=min-is-white output.tif

If you are working with a pure black-and-white (bilevel) image, such as a 1-bit scan:

magick input.jpg -colorspace Gray -threshold 50% -type bilevel -define quantum:polarity=min-is-white output.tif

ImageMagick 6 (Legacy CLI)

If you are using ImageMagick 6, replace magick with convert:

convert input.jpg -colorspace Gray -define quantum:polarity=min-is-white output.tif

Compressing the Output

When generating bilevel TIFFs with MinIsWhite, common fax and document formats often require Group 4 fax compression. You can combine compression settings directly with the polarity define:

magick input.pdf[0] -colorspace Gray -threshold 50% -compress Group4 -define quantum:polarity=min-is-white output.tif

Verifying the Output Tag

To confirm that the tag was written properly, inspect the generated TIFF using tiffinfo (part of libtiff-tools) or ImageMagick's identify:

Using tiffinfo:

tiffinfo output.tif

Look for the following line in the output:

Photometric Interpretation: min-is-white

Using identify:

magick identify -verbose output.tif | grep -i photometric
