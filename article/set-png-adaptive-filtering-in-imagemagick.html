Set PNG Adaptive Filtering in ImageMagick

This guide explains how to apply adaptive filtering to PNG images using ImageMagick to optimize compression and reduce file size. You will learn the specific command-line options required to enable adaptive filtering, how the PNG quality settings correlate to filter methods, and how to apply these commands across single or multiple images.

Using the png:compression-filter Define

The most direct way to set the PNG compression filter method to adaptive filtering is by using the -define flag with the value 5. In the PNG specification, filter type 5 corresponds to adaptive filtering, where ImageMagick tests different filter algorithms (None, Sub, Up, Average, and Paeth) on each scanline and selects the one that produces the best compression.

Execute the following command in your terminal:

magick input.jpg -define png:compression-filter=5 output.png

If you are using ImageMagick version 6, replace magick with convert:

convert input.jpg -define png:compression-filter=5 output.png

Using the -quality Shorthand

ImageMagick provides a shorthand method for setting both the zlib compression level and the filter type simultaneously via the -quality option.

For PNG output, the tens digit represents the zlib compression level (0–9), and the units digit represents the filter method (0–5, where 5 is adaptive).

To use maximum zlib compression (9) alongside adaptive filtering (5), use a quality value of 95:

magick input.jpg -quality 95 output.png

PNG Quality Value Breakdown

  • Tens digit (Compression level): 0 (none) to 9 (maximum compression).
  • Units digit (Filter type):
    • 0: None
    • 1: Sub
    • 2: Up
    • 3: Average
    • 4: Paeth
    • 5: Adaptive

Batch Processing with Adaptive Filtering

To apply adaptive filtering to an entire directory of PNG images in-place, use the mogrify command:

magick mogrify -define png:compression-filter=5 -quality 95 *.png

For ImageMagick 6:

mogrify -define png:compression-filter=5 -quality 95 *.png

Verifying the Filter Method

You can verify that the image uses adaptive filtering by inspecting the verbose output of ImageMagick's identify tool:

magick identify -verbose output.png

Look under the Properties section for the png:compression-filter entry to confirm it is set to 5 (adaptive).
