Set PNG Huffman Compression in ImageMagick

This guide explains how to configure ImageMagick to apply the Huffman coding compression strategy when encoding PNG images. By utilizing ImageMagick's internal PNG defines, you can bypass the default zlib compression strategy and force the encoder to use Huffman-only encoding, which significantly speeds up compression times at the expense of compression ratio.

To set the PNG compression strategy to Huffman coding in ImageMagick, use the -define png:compression-strategy option with a value of 2.

Command Syntax

For ImageMagick version 7, use the following syntax:

magick input.png -define png:compression-strategy=2 output.png

If you are using ImageMagick version 6, replace magick with convert:

convert input.png -define png:compression-strategy=2 output.png

Understanding Compression Strategy Values

ImageMagick maps its strategy values directly to the underlying zlib compression library settings:

  • 0: Default compression (Z_DEFAULT_STRATEGY)
  • 1: Filtered (Z_FILTERED)
  • 2: Huffman only (Z_HUFFMAN_ONLY)
  • 3: Run-Length Encoding (Z_RLE)
  • 4: Fixed Huffman codes (Z_FIXED)

Setting the value to 2 forces the zlib compressor to skip string matching (LZ77) entirely and perform only Huffman entropy encoding.

Combining with Compression Levels

You can pair the Huffman strategy with the -quality flag to control both the compression level and the PNG row filter. In ImageMagick, the tens digit represents the zlib compression level (0–9), and the units digit represents the filter type (0–5):

magick input.png -quality 90 -define png:compression-strategy=2 output.png

In this command:

  • 9 sets zlib compression level 9 (maximum effort).
  • 0 sets the PNG row filter to "None".
  • -define png:compression-strategy=2 enforces Huffman coding on the resulting stream.

Use Cases for Huffman Only

Using the Huffman-only strategy is ideal when encoding speed is a higher priority than file size, or when compressing pre-processed, high-entropy imagery where traditional LZ77 dictionary searches yield negligible size reductions.
