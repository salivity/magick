Set Print Resolution in ImageMagick TIFF Exports

Configuring the physical print resolution metadata in ImageMagick allows you to specify the target dots per inch (DPI) or pixels per inch (PPI) for a TIFF export without altering the underlying pixel dimensions of the image. This guide covers the exact command-line syntax required to set resolution units and density metadata, ensuring files export correctly for print workflows.

Basic Syntax

To define print resolution metadata when exporting to TIFF, combine the -density option with the -units attribute:

magick input.jpg -units PixelsPerInch -density 300 output.tiff

(Note: In ImageMagick version 6, replace magick with convert.)

Core Parameters Explained

  • -units <type>: Defines the unit of measurement used for the resolution. For standard print setups, use PixelsPerInch. For metric setups, use PixelsPerCentimeter.
  • -density <value>: Sets the physical resolution value. For example, -density 300 defines a print density of 300 DPI.

Modifying Metadata Without Resampling

If you are modifying an existing image and want to strictly alter the metadata headers without triggering any accidental rasterization or resampling processes, use the -set operator:

magick input.tiff -set units PixelsPerInch -set density 300 output.tiff

Setting Asymmetric Print Resolutions

If your target output requires different horizontal and vertical resolutions (common in specific fax and specialized printing devices), provide both values separated by an x:

magick input.png -units PixelsPerInch -density 300x600 output.tiff

Verifying the TIFF Resolution Metadata

To confirm that the resolution metadata was written correctly to the TIFF header, run the identify command:

magick identify -format "%x x %y %U\n" output.tiff

This will output the stored horizontal resolution, vertical resolution, and the active units (e.g., 300 PixelsPerInch x 300 PixelsPerInch PixelsPerInch).
