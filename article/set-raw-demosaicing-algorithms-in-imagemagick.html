Set RAW Demosaicing Algorithms in ImageMagick

This guide explains how to select demosaicing algorithms, such as AHD (Adaptive Homogeneity-Directed) and DCB, when decoding camera RAW images using ImageMagick. ImageMagick relies on external delegates—primarily LibRaw or dcraw—to interpret sensor bayer data, and you can control which interpolation method is applied either dynamically via command-line flags or globally by editing delegate configuration files.

Understanding RAW Decoding in ImageMagick

ImageMagick does not decode camera RAW files (such as .CR2, .NEF, .ARW, or .DNG) natively. Instead, it passes these formats to an external delegate coder. Modern builds typically use LibRaw, while older setups use dcraw. Both libraries assign numeric values to demosaicing algorithms:

  • 0: Linear / Bilinear interpolation (fastest, lowest quality)
  • 1: VNG (Variable Number of Gradients)
  • 2: PPG (Patterned Pixel Grouping)
  • 3: AHD (Adaptive Homogeneity-Directed)
  • 4: DCB

Method 1: Using the Command-Line -define Flag

If your ImageMagick installation is compiled with LibRaw support, the most direct way to change the demosaicing method is to pass the dng:interpolation-quality define prior to reading the input file.

To use AHD demosaicing:

magick -define dng:interpolation-quality=3 input.CR2 output.png

To use DCB demosaicing:

magick -define dng:interpolation-quality=4 input.CR2 output.png

For ImageMagick 6 installations, replace magick with convert:

convert -define dng:interpolation-quality=3 input.CR2 output.png

Note: The -define flag must appear before the input file name so that ImageMagick passes the parameter to the underlying decoder during file ingestion.

Method 2: Modifying delegates.xml for dcraw

If your ImageMagick build uses standalone dcraw instead of the LibRaw library, you must pass the -q parameter directly via the delegates.xml configuration file.

  1. Locate your delegates.xml file:

    magick -list delegate | grep -i raw

    Typical locations include /etc/ImageMagick-7/delegates.xml on Linux or within the installation root on Windows.

  2. Open delegates.xml in a text editor and search for the delegate rule handling raw files (often targeting decode="dng:decode" or pattern rules like *.cr2).

  3. Locate the dcraw invocation string, which typically looks like:

    <delegate decode="dng:decode" command="&quot;dcraw&quot; -6 -W -q 3 -O &quot;%u.ppm&quot; &quot;%i&quot;"/>

  4. Change the -q parameter to your preferred algorithm:

    • Set -q 3 to enforce AHD.
    • Set -q 4 to enforce DCB.

  5. Save the file. Future conversions relying on that delegate rule will automatically execute the selected demosaicing algorithm.
