Set Spacing and Margins in ImageMagick Montage

ImageMagick's montage command creates image grids, contact sheets, and collages directly from the command line. Controlling the gaps between individual images (inter-tile spacing) and the space around the edges (margins) is achieved primarily using the -geometry flag alongside background and border parameters. This guide explains the syntax, default behaviors, and command options required to customize your montage layout precisely.

The Role of the -geometry Option

The -geometry argument is the primary mechanism for setting tile dimensions and spacing in montage. Its basic syntax for grid layout is:

-geometry [width]x[height]+[horizontal_spacing]+[vertical_spacing]
  • width and height: The maximum bounding box size for each thumbnail.
  • horizontal_spacing (X offset): The horizontal space applied to both sides of each tile.
  • vertical_spacing (Y offset): The vertical space applied to the top and bottom of each tile.

Because offsets apply around every individual tile, the space between two adjacent tiles is effectively the sum of their adjacent offsets, while the outer edge receives a single offset width.

Setting Custom Inter-Tile Spacing

To define specific horizontal and vertical gaps while keeping thumbnail sizes uniform:

montage image1.jpg image2.jpg image3.jpg image4.jpg \
  -tile 2x2 \
  -geometry 200x200+10+15 \
  -background white \
  output.jpg
  • 200x200 restricts each thumbnail to a maximum of 200 by 200 pixels.
  • +10 adds 10 pixels of horizontal margin per tile.
  • +15 adds 15 pixels of vertical margin per tile.
  • -background white colors the resulting gaps white.

Removing All Spacing and Margins (Seamless Grid)

By default, montage applies a frame and default padding. To create a seamless grid with zero space between tiles and zero outer margins, set both offsets to +0+0:

montage *.jpg \
  -tile 3x3 \
  -geometry 300x300+0+0 \
  output.jpg

If you want to keep the original image resolutions without resizing, omit the width and height values while keeping the offsets:

montage *.jpg \
  -tile 3x3 \
  -geometry +0+0 \
  output.jpg

Adding Borders and Outer Margins

If you need distinct outer canvas margins separate from inter-tile spacing, combine the -geometry flag with -border or post-processing operations:

Adding Tile Borders

To add individual borders around each image inside the grid:

montage *.jpg \
  -tile 2x2 \
  -geometry 150x150+8+8 \
  -border 2 \
  -bordercolor black \
  -background grey \
  output.jpg

Adding an Outer Canvas Border

To create an outer border around the entire montage after arranging the tiles:

montage *.jpg \
  -tile 4x \
  -geometry 100x100+5+5 \
  -background white \
  -mattecolor white \
  -frame 10 \
  output.jpg

Alternatively, use the magick or convert command to add uniform outer margins around the generated montage:

montage *.jpg -tile 2x2 -geometry 200x200+5+5 temp.png
magick temp.png -bordercolor white -border 20 output.jpg
