Set Throttle Time in ImageMagick policy.xml

This guide explains how to configure ImageMagick's policy.xml file to throttle operations by introducing delays during processing. Setting a throttle limit forces ImageMagick to periodically yield the CPU, reducing overall processor load and preventing resource exhaustion during heavy image processing tasks.

Locating the policy.xml File

The policy.xml file resides in your system's ImageMagick configuration directory. Its exact location depends on your operating system and installation method:

  • Linux (ImageMagick 7): /etc/ImageMagick-7/policy.xml
  • Linux (ImageMagick 6): /etc/ImageMagick-6/policy.xml
  • macOS (Homebrew): /usr/local/etc/ImageMagick-7/policy.xml or /opt/homebrew/etc/ImageMagick-7/policy.xml
  • Windows: Found inside the primary installation directory (e.g., C:\Program Files\ImageMagick-7.x.x-Q16\policy.xml)

You can confirm the active path using the command line:

magick -list policy

(For ImageMagick 6, replace magick with identify or convert.)

Configuring the Throttle Policy

The throttle resource limit defines the period (in milliseconds) that ImageMagick pauses or yields the CPU during intensive pixel operations.

  1. Open policy.xml in a text editor with administrative privileges:

    sudo nano /etc/ImageMagick-7/policy.xml

  2. Locate the <policymap> section.

  3. Add or update the resource policy entry for throttle:

    <policy domain="resource" name="throttle" value="20"/>
    • value: The delay in milliseconds. For instance, a value of 20 pauses processing for 20 milliseconds periodically throughout execution. Adjust this number depending on how aggressively you want to limit CPU usage.

  4. Save and close the file.

Verifying the Configuration

To confirm that the throttle limit is actively recognized by ImageMagick, inspect the configured resource limits:

magick -list resource

Look for the Throttle line in the output:

Resource limits:
  ...
  Throttle: 20
  ...

Once confirmed, any subsequent ImageMagick commands or integrated scripts will automatically respect the throttle interval without requiring code-level modifications.
