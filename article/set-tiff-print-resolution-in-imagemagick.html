Set TIFF Print Resolution in ImageMagick

This article provides a direct guide on how to define the physical print resolution (DPI or PPI) when exporting TIFF images using ImageMagick. You will learn the exact command-line syntax to embed print metadata without altering the pixel dimensions, as well as the method for resampling images to match a specific physical output size.

Basic Syntax for Setting Resolution Metadata

To set the print resolution metadata (DPI) without modifying the actual pixel dimensions of the image, use the -units and -density flags.

ImageMagick v7:

magick input.jpg -units PixelsPerInch -density 300 output.tif

ImageMagick v6:

convert input.jpg -units PixelsPerInch -density 300 output.tif

Parameter Breakdown

  • -units PixelsPerInch: Defines the measurement unit for the resolution. You can also specify PixelsPerCentimeter if you work in metric units.
  • -density 300: Sets the horizontal and vertical resolution to 300 DPI. For asymmetric resolutions, you can specify X_RESxY_RES (e.g., -density 300x600).

Resampling Image Pixels

If you want ImageMagick to scale the pixel dimensions of the image proportionally to match a new print density while keeping the original physical print size, use the -resample flag instead of -density.

magick input.tif -units PixelsPerInch -resample 300 output.tif

Verifying the Output Resolution

To confirm that the TIFF file contains the correct print resolution metadata, inspect the file using the identify tool:

magick identify -format "%x x %y %U\n" output.tif

This command prints the horizontal resolution, vertical resolution, and the active unit type (e.g., 300 Undefined x 300 Undefined PixelsPerInch).
