Set TIFF Resolution Unit to Centimeters in ImageMagick

This guide demonstrates how to set the TIFF resolution unit tag to centimeters using ImageMagick command-line tools. By specifying the metric resolution unit, you ensure that imaging software, print drivers, and layout applications correctly read your image's physical dimensions in pixels per centimeter rather than the default pixels per inch.

The Basic Syntax

To set the TIFF resolution unit to centimeters, use the -units flag with the value PixelsPerCentimeter.

For ImageMagick version 7:

magick input.tif -units PixelsPerCentimeter output.tif

For ImageMagick version 6 (legacy):

convert input.tif -units PixelsPerCentimeter output.tif

Setting Density Alongside the Unit

In most workflows, changing the resolution unit requires defining or updating the density (resolution) value to match the metric scale. You can combine the -density flag with -units:

magick input.tif -units PixelsPerCentimeter -density 118 output.tif

(Note: A density of approximately 118 pixels per centimeter corresponds to roughly 300 pixels per inch).

Modifying an Existing File in Place

If you want to update the metadata of an existing TIFF file without creating a new file, use the mogrify command:

magick mogrify -units PixelsPerCentimeter -density 118 image.tif

Verifying the Changes

To verify that the TIFF tag (Tag 296, ResolutionUnit) has been successfully updated to centimeters, inspect the file metadata using the identify command:

magick identify -format "%[resolution.units] - %x x %y\n" output.tif

This will return PixelsPerCentimeter along with the horizontal and vertical resolution values.
