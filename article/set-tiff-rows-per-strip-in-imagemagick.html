Set TIFF Rows Per Strip in ImageMagick

This article provides a quick overview and guide on configuring the rows-per-strip parameter when writing TIFF files using ImageMagick. Controlling strip size is essential for optimizing memory utilization, improving decoding performance in streaming applications, and adhering to strict software compatibility requirements.

Using the -define Option

ImageMagick controls TIFF-specific parameters through the -define flag. To set the number of scanlines per strip in your output TIFF file, use the tiff:rows-per-strip definition:

magick input.png -define tiff:rows-per-strip=16 output.tif

If you are using ImageMagick version 6, replace magick with convert:

convert input.png -define tiff:rows-per-strip=16 output.tif

How It Works

By default, the TIFF specification recommends that a strip contains approximately 8 kilobytes of uncompressed image data. However, many production pipelines require custom strip heights.

  • Lower values (e.g., 1 to 16): Reduce the memory footprint needed by a decoder to process parts of the image, which is useful for low-memory environments or partial rendering.
  • Higher values: Reduce metadata overhead by creating fewer total strips, which can slightly improve compression efficiency and file-reading speed on modern systems.
  • Full-height strip (equal to image height): Storing the entire image as a single strip removes strip boundaries entirely, though it requires the reader to load the full image into memory at once.

Example: Batch Processing

You can apply the setting across multiple images using mogrify:

magick mogrify -format tif -define tiff:rows-per-strip=32 *.jpg

Verifying the Configuration

To confirm that the rows-per-strip setting was successfully written to the TIFF tags, inspect the file metadata using identify or standard TIFF utilities:

identify -verbose output.tif | grep -i "rows-per-strip"

Alternatively, use the tiffinfo utility provided by libtiff:

tiffinfo output.tif

Look for the Rows/Strip entry in the output to ensure it matches the integer value passed to -define tiff:rows-per-strip.
