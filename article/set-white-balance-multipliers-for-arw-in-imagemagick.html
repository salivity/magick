Set White Balance Multipliers for ARW in ImageMagick

Processing Sony ARW raw files with specific white balance multipliers in ImageMagick requires controlling how the underlying raw decoder demosaics the image. ImageMagick delegates raw file decoding to tools like dcraw or LibRaw. This guide explains how to apply custom red, green, and blue white balance multipliers by piping raw output from dcraw into ImageMagick, editing ImageMagick's delegate configuration, or modifying color channels directly within the command line.

Method 1: Pipe Decoded ARW Data from dcraw to ImageMagick

The most direct and flexible way to process an ARW file with custom white balance multipliers is piping output directly from dcraw into ImageMagick. The dcraw utility uses the -r flag followed by four multipliers (Red, Green 1, Blue, Green 2).

dcraw -c -6 -w -r 2.25 1.0 1.65 1.0 input.ARW | magick - output.png

Parameter Breakdown:

  • -c: Writes the decoded image data to standard output.
  • -6: Outputs 16-bit linear PPM data to preserve dynamic range.
  • -r 2.25 1.0 1.65 1.0: Applies custom white balance multipliers (Red = 2.25, Green = 1.0, Blue = 1.65). Green values are typically normalized to 1.0.
  • magick - output.png: Reads standard input (-) and converts it to the final format.

Method 2: Configure ImageMagick's delegates.xml

If your workflow requires reading ARW files directly via magick input.ARW output.png, you can modify ImageMagick's delegates.xml configuration file to permanently inject custom multipliers into the raw decoding step.

  1. Locate your delegates.xml file:

    magick -list delegate | grep -i arw

    Or find the file path directly:

    find / -name "delegates.xml" 2>/dev/null

  2. Open delegates.xml and locate the line handling dng:decode or arw:

    <delegate decode="dng:decode" command="&quot;dcraw&quot; -6 -W -O &quot;%u.ppm&quot; &quot;%i&quot;"/>

  3. Insert the -r multipliers into the command string:

    <delegate decode="dng:decode" command="&quot;dcraw&quot; -6 -W -r 2.25 1.0 1.65 1.0 -O &quot;%u.ppm&quot; &quot;%i&quot;"/>

  4. Save the file. Any subsequent native execution of magick input.ARW output.jpg will use these raw multipliers during demosaicing.

Method 3: Apply Channel Multipliers in ImageMagick Post-Demosaic

If you are using the built-in LibRaw delegate and cannot pipe from dcraw, you can disable camera white balance and manually apply multipliers across individual color channels in a 16-bit workspace.

magick input.ARW \
  -define dng:use-camera-wb=false \
  -define dng:use-auto-wb=false \
  -channel R -evaluate multiply 2.25 \
  -channel B -evaluate multiply 1.65 \
  +channel \
  -colorspace sRGB \
  output.jpg

Parameter Breakdown:

  • -define dng:use-camera-wb=false: Prevents the embedded camera metadata white balance from applying.
  • -define dng:use-auto-wb=false: Prevents automated scene analysis white balance.
  • -channel R -evaluate multiply 2.25: Scales the red channel by your desired multiplier.
  • -channel B -evaluate multiply 1.65: Scales the blue channel by your desired multiplier.
  • +channel: Resets the channel focus to all channels for remaining operations.
