Set XMP Copyright and Rights in ImageMagick

Managing digital rights is essential for protecting creative assets and ensuring proper attribution across distribution channels. This article demonstrates how to set Extensible Metadata Platform (XMP) copyright status and rights usage terms using the ImageMagick command-line utility. By leveraging ImageMagick's profile-handling capabilities and metadata manipulation options, you can embed standard copyright protection tags into images efficiently.

Understanding the Target XMP Properties

When defining copyright and usage terms, two primary XMP properties are used according to standard Adobe and IPTC schemas:

  1. xmpRights:Marked: A boolean value (True or False) indicating whether the work is copyrighted.
  2. xmpRights:UsageTerms: A text field describing the license, rights restrictions, or terms under which the asset may be used.

Method 1: Injecting an XMP Profile (Recommended)

ImageMagick processes complex XMP structures most reliably by embedding a prepared XMP metadata packet. Direct property editing of deeply nested XMP structures in ImageMagick can be limited depending on the underlying delegate libraries (such as libxml2).

Step 1: Create an XMP Template File

Create an XML file named rights.xmp with the following contents:

<x:xmpmeta xmlns:x="adobe:ns:meta/">
 <rdf:RDF xmlns:rdf="http://www.w3.org/1999/02/22-rdf-syntax-ns#">
  <rdf:Description rdf:about=""
    xmlns:xmpRights="http://ns.adobe.com/xap/1.0/rights/"
    xmlns:dc="http://purl.org/dc/elements/1.1/">
   <xmpRights:Marked>True</xmpRights:Marked>
   <xmpRights:UsageTerms>
    <rdf:Alt>
     <rdf:li xml:lang="x-default">All rights reserved. Unauthorized reproduction prohibited.</rdf:li>
    </rdf:Alt>
   </xmpRights:UsageTerms>
   <dc:rights>
    <rdf:Alt>
     <rdf:li xml:lang="x-default">Copyright (C) 2026 Your Name or Company.</rdf:li>
    </rdf:Alt>
   </dc:rights>
  </rdf:Description>
 </rdf:RDF>
</x:xmpmeta>

Step 2: Apply the Profile Using ImageMagick

Use the magick command (or convert in ImageMagick 6) with the -profile flag to embed this metadata directly into the image:

magick input.jpg -profile rights.xmp output.jpg

To apply this to an image while stripping out existing conflicting color or text profiles, place the profile command after any strip options:

magick input.jpg +profile "xmp" -profile rights.xmp output.jpg

Method 2: Setting Basic Copyright Properties Directly

If you prefer a single-command approach without creating an external XML file, you can define the core copyright string directly using ImageMagick's -set option. While this primarily sets the standard EXIF and IPTC fields, modern image viewers and processors map these into the XMP data block automatically.

Run the following command to set the copyright and rights terms:

magick input.jpg -set copyright "Copyright 2026 Your Company. All Rights Reserved." -set "xmp:UsageTerms" "Single use editorial only." output.jpg

Verifying the Embedded Metadata

To confirm that the XMP copyright data has been correctly applied to your output file, inspect the image properties using the identify utility:

magick identify -verbose output.jpg | grep -i "xmp"

To extract and read the entire embedded XMP block specifically:

magick identify -format "%[xmp:*]" output.jpg

This output displays all assigned XMP namespaces and confirms whether xmpRights:Marked and xmpRights:UsageTerms are present and valid.
