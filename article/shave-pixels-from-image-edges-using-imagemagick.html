Shave Pixels from Image Edges Using ImageMagick

This guide explains how to crop a specific, fixed number of pixels symmetrically from all sides of an image using ImageMagick's built-in -shave operator. You will learn the correct command-line syntax for single images in both ImageMagick v7 and v6, understand how the dimension parameters work, and see how to batch process multiple files at once.

The -shave Operator

ImageMagick provides the -shave option specifically for cutting margins off the outer borders of an image. The operator uses the format WIDTHxHEIGHT, where:

  • WIDTH: The number of pixels removed from both the left and right sides.
  • HEIGHT: The number of pixels removed from both the top and bottom sides.

Basic Command (ImageMagick v7)

To remove 10 pixels from all four edges (left, right, top, and bottom) using ImageMagick 7, use the magick command:

magick input.jpg -shave 10x10 output.jpg

In this example:

  • 10 pixels are shaved from the left.
  • 10 pixels are shaved from the right.
  • 10 pixels are shaved from the top.
  • 10 pixels are shaved from the bottom.
  • The total image width decreases by 20 pixels, and the total height decreases by 20 pixels.

Legacy Syntax (ImageMagick v6)

If you are running ImageMagick 6, use the convert command with the same parameters:

convert input.jpg -shave 10x10 output.jpg

Unequal Edge Shaving

If you need to remove different amounts of pixels from the horizontal and vertical edges, adjust the width and height values accordingly. For example, to remove 15 pixels from the left and right, and 30 pixels from the top and bottom:

magick input.png -shave 15x30 output.png

Batch Processing Multiple Images

To apply the same shave operation to multiple images in place, use the mogrify tool.

To remove 10 pixels from all edges of every PNG file in the current directory:

magick mogrify -shave 10x10 *.png

(For ImageMagick v6, run mogrify -shave 10x10 *.png)

Note: The mogrify command overwrites the original files directly, so ensure you have a backup before executing the command.
