Simulate Depth of Field in ImageMagick

Simulating depth of field (DoF) allows you to create realistic camera focus effects by selectively blurring an image based on distance. This article demonstrates how to combine an RGB source image with a grayscale depth map using ImageMagick's composite blur operators. By adjusting the depth map to isolate a specific focal plane and applying variable blurring, you can quickly produce professional, optical-quality depth effects directly from the command line.

1. Understanding the Depth Map Requirement

ImageMagick’s -compose Blur operation uses a secondary image (the depth map) as an intensity mask to determine blur radius. In standard blur composition:

  • Black (#000000) receives zero blur (sharp focus).
  • White (#FFFFFF) receives the maximum specified blur radius.
  • Grayscale tones receive proportional intermediate blur amounts.

A raw depth map typically assigns black to the nearest point and white to the furthest point (or vice versa). To set a specific focal subject in focus, the depth map must be remapped so that the desired focal depth becomes pure black, while both closer and farther distances scale toward white.

2. Adjusting the Depth Map for a Focal Point

If your subject sits at mid-depth (represented as gray in a raw depth map), you must create a "V-curve" so that values below and above the focal point both transition to white.

You can remap the depth map using ImageMagick’s -solarize or mathematical operators:

magick depth.png -solarize 50% -level 0,50% depth_mask.png

Alternatively, to focus on the foreground (where pure black is already in focus) or the background (invert with -negate), you can use the depth map directly without remapping the midtones.

3. Applying the Blur Composite

Once the depth map has pure black at the focal plane, combine the original image and the depth mask using the Blur composition method.

In ImageMagick 7, use the following syntax:

magick input.jpg depth_mask.png -compose Blur -set option:compose:args 20x0 -composite output.jpg

4. Configuring the Blur Arguments

The -set option:compose:args parameter controls the magnitude and orientation of the blur:

  • Isotropic Blur (Spherical/Standard): Define only the X-radius or equal X and Y values (e.g., 15x0 or 15x15).
  • Anamorphic / Directional Blur: Set unequal values or supply an angle (e.g., 20x5+45 applies an elliptical blur oriented at 45 degrees).

5. Complete Single-Line Execution

To process the image in a single pipeline without writing intermediate mask files, use inline parenthesis operations:

magick input.jpg \
  \( depth.png -solarize 50% -level 0,50% \) \
  -compose Blur -set option:compose:args 25x0 -composite \
  dof_result.jpg

This command loads the source, adjusts the depth map in memory to create the focal plane, and composites the variable blur in a single step.
