Simulate Depth of Field with ImageMagick Depth Maps

Simulating realistic optical depth of field (DoF) requires applying a variable lens blur across an image based on spatial distance. This article explains how to use ImageMagick's composition tools to map a 2D grayscale depth map to an image, define a precise focal plane, and apply depth-dependent blur to achieve a shallow depth-of-field effect.

Understanding the Depth Map Blur Concept

A standard grayscale depth map represents distance: typically, pure black (#000000) represents the closest point to the camera, while pure white (#FFFFFF) represents the furthest background (or vice versa).

ImageMagick's -compose Blur operator interprets pixel luminance as the radius of blur to apply. A value of 0 (black) produces zero blur, while 1 (white) produces the maximum specified blur radius. To place an arbitrary object in focus, the depth map must be adjusted so that the chosen subject's depth value becomes pure black, with blur increasing as distance deviates in either direction.

Step 1: Adjusting the Depth Map for a Specific Focal Plane

If your subject has a middle-gray value (e.g., 50% gray) in the depth map, you must remap the values so that 50% gray becomes black, and both near (darker) and far (lighter) distances become brighter.

To set the focal point to a specific depth level (e.g., 40% distance), use the following ImageMagick command to generate a modified blur mask:

magick depth.png -bias 50% -evaluate subtract 40% -solarize 50% -evaluate multiply 2 -negate focus_mask.png
  • -evaluate subtract 40%: Shifts the chosen focus point toward zero.
  • -solarize 50%: Flips the gradient symmetrically around the focal point.
  • -negate: Ensures that the focal point becomes pure black (zero blur) and all out-of-focus areas scale toward white.

Step 2: Applying the Depth of Field Blur

Once the depth mask accurately represents blur intensity relative to the focal plane, use the -compose Blur operation to combine the original image, the blur mask, and the blur parameters.

Basic Blur Command

magick source.png focus_mask.png -compose Blur -set option:compose:args 15x0 -composite output.png
  • source.png: The original in-focus image.
  • focus_mask.png: The prepared focal map.
  • -set option:compose:args 15x0: Specifies the maximum blur radius in pixels (in this case, 15 pixels). The x0 argument controls the angle of directional blur; 0 produces standard radial/defocus blur.
  • -composite: Applies the mapped blur operation.

Step 3: Combining into a Single-Line Pipeline

To avoid creating intermediate mask files, combine the map adjustment and blur application into a single command using ImageMagick parenthetical processing:

magick source.png \
  ( depth.png -bias 50% -evaluate subtract 45% -solarize 50% -evaluate multiply 2 -negate ) \
  -compose Blur -set option:compose:args 20x0 \
  -composite dof_result.png

Step 4: Fine-Tuning Blur Intensity and Falloff

  • Increase Blur Intensity: Increase the first parameter in -set option:compose:args (e.g., 35x0) to simulate a wider aperture / shallower depth of field.
  • Adjust Falloff Curve: Use -gamma or -sigmoidal-contrast on the depth map to change how quickly objects transition from sharp focus to blurry background.
