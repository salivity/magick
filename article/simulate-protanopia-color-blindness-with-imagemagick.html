Simulate Protanopia Color Blindness with ImageMagick

This guide demonstrates how to simulate protanopia—a form of red-green color blindness caused by the absence of red retinal photoreceptors—using ImageMagick's color matrix transformation feature. By applying a mathematically derived 3x3 matrix to standard RGB channels, you can transform ordinary images to reflect how they appear to someone with protanopia, making it a valuable method for accessibility testing and design validation.

The Protanopia Color Matrix

Simulating color vision deficiency relies on transforming the standard sRGB color space to model how the remaining green (M-cone) and blue (S-cone) photoreceptors interpret wavelengths.

For protanopia, the established 3x3 transformation matrix is:

| 0.56667  0.43333  0.00000 |
| 0.55833  0.44167  0.00000 |
| 0.00000  0.24167  0.75833 |

In this matrix:

  • The red output channel (\(R'\)) is calculated as 0.56667*R + 0.43333*G + 0.0*B.
  • The green output channel (\(G'\)) is calculated as 0.55833*R + 0.44167*G + 0.0*B.
  • The blue output channel (\(B'\)) is calculated as 0.0*R + 0.24167*G + 0.75833*B.

Because protanopic vision relies heavily on the green spectrum in place of red, both the red and green output channels receive heavily weighted contributions from the original red and green values, neutralizing red-green distinction.

ImageMagick Command Syntax

ImageMagick provides the -color-matrix operator to apply linear transformations to image channels.

ImageMagick v7 Command

magick input.png -color-matrix " \
  0.56667 0.43333 0.00000 \
  0.55833 0.44167 0.00000 \
  0.00000 0.24167 0.75833" \
  output_protanopia.png

ImageMagick v6 Command

If using legacy versions of ImageMagick, substitute magick with convert:

convert input.png -color-matrix " \
  0.56667 0.43333 0.00000 \
  0.55833 0.44167 0.00000 \
  0.00000 0.24167 0.75833" \
  output_protanopia.png

Matrix String Formatting

ImageMagick accepts matrix values either as a single space-separated string or with line breaks for readability. The values are mapped row by row:

  • Row 1: Red channel multiplier values.
  • Row 2: Green channel multiplier values.
  • Row 3: Blue channel multiplier values.

If an image contains an alpha channel, standard 3x3 matrices leave transparency untouched, as ImageMagick automatically defaults the alpha channel to an identity transform when given a 9-element list.

Batch Processing Images

To process an entire directory of assets for accessibility audits on a Unix-like system (Linux/macOS), use a simple loop:

for file in *.png; do
  magick "$file" -color-matrix "0.56667 0.43333 0 0.55833 0.44167 0 0 0.24167 0.75833" "protanopia_${file}"
done

On Windows (Command Prompt):

for %f in (*.png) do magick "%f" -color-matrix "0.56667 0.43333 0 0.55833 0.44167 0 0 0.24167 0.75833" "protanopia_%f"
