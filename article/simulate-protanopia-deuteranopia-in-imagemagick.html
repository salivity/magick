Simulate Protanopia & Deuteranopia in ImageMagick

This article explains how to simulate red-green color vision deficiencies—specifically protanopia and deuteranopia—using ImageMagick's color transformation matrices. By applying calibrated linear color transformation matrices via the command-line interface, developers and designers can quickly test visual assets for accessibility directly in their build pipelines or design workflows.

Understanding the Color Matrix Operator

ImageMagick allows you to transform the color channels of an image using the -color-matrix operator. The operator applies a mathematical matrix to each pixel's RGB values, remapping them to simulate how colors are perceived by an individual with missing or defective photoreceptors (L-cones for protanopia, M-cones for deuteranopia).

For standard RGB images, a 3x3 matrix transforms the red (\(R\)), green (\(G\)), and blue (\(B\)) channels into simulated channels (\(R'\), \(G'\), \(B'\)):

| R' |   | m00 m01 m02 |   | R |
| G' | = | m10 m11 m12 | * | G |
| B' |   | m20 m21 m22 |   | B |

Simulating Protanopia (Red-Blindness)

Protanopia is characterized by the complete absence of red retinal photoreceptors. To simulate protanopia, use a matrix that collapses red and green variations primarily into yellow and blue shades.

The standard 3x3 matrix approximation for protanopia is:

  • Red output: 0.56667 * R + 0.43333 * G + 0.00000 * B
  • Green output: 0.55833 * R + 0.44167 * G + 0.00000 * B
  • Blue output: 0.00000 * R + 0.24167 * G + 0.75833 * B

ImageMagick Command:

ImageMagick v7:

magick input.png -color-matrix \
  " 0.56667 0.43333 0.00000 \
    0.55833 0.44167 0.00000 \
    0.00000 0.24167 0.75833 " \
  protanopia_output.png

ImageMagick v6:

convert input.png -color-matrix \
  " 0.56667 0.43333 0.00000 \
    0.55833 0.44167 0.00000 \
    0.00000 0.24167 0.75833 " \
  protanopia_output.png

Simulating Deuteranopia (Green-Blindness)

Deuteranopia is the most common form of color blindness, caused by the absence of green retinal photoreceptors. The matrix shifts green hues toward red and yellow channels to simulate the reduced color discrimination.

The standard 3x3 matrix approximation for deuteranopia is:

  • Red output: 0.62500 * R + 0.37500 * G + 0.00000 * B
  • Green output: 0.70000 * R + 0.30000 * G + 0.00000 * B
  • Blue output: 0.00000 * R + 0.30000 * G + 0.70000 * B

ImageMagick Command:

ImageMagick v7:

magick input.png -color-matrix \
  " 0.62500 0.37500 0.00000 \
    0.70000 0.30000 0.00000 \
    0.00000 0.30000 0.70000 " \
    deuteranopia_output.png

ImageMagick v6:

convert input.png -color-matrix \
  " 0.62500 0.37500 0.00000 \
    0.70000 0.30000 0.00000 \
    0.00000 0.30000 0.70000 " \
    deuteranopia_output.png

Batch Processing for Automated Testing

To evaluate multiple UI assets or screenshots automatically, you can incorporate the command into a shell loop:

for img in *.png; do
  magick "$img" -color-matrix "0.56667 0.43333 0 0.55833 0.44167 0 0 0.24167 0.75833" "protanopia_${img}"
  magick "$img" -color-matrix "0.625 0.375 0 0.7 0.3 0 0 0.3 0.7" "deuteranopia_${img}"
done

This generates simulated variants for every PNG file in the working directory, enabling rapid accessibility audits for visual designs.
