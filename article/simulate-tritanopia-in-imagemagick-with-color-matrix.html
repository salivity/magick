Simulate Tritanopia in ImageMagick with Color Matrix

This article explains how to simulate tritanopia (blue-yellow color blindness) on digital images using ImageMagick. By applying a 3×3 color transformation matrix via the -color-matrix operator, you can accurately recalculate standard sRGB values to represent how colors appear to individuals lacking functional S-cones (blue-sensitive cones).

The Tritanopia Color Transformation Matrix

To simulate tritanopia, the standard linear RGB transformation matrix derived from physiological color vision deficiency models (such as the Brettel, Viénot, and Mollon model) is:

Channel Red (Input) Green (Input) Blue (Input)
Red (Output) 0.950 0.050 0.000
Green (Output) 0.000 0.433 0.567
Blue (Output) 0.000 0.475 0.525

In this transformation:

  • The Red channel is composed of 95% original red and 5% green.
  • The Green channel is composed of 43.3% original green and 56.7% original blue.
  • The Blue channel is composed of 47.5% original green and 52.5% original blue.

ImageMagick Command Syntax

ImageMagick processes the -color-matrix operator using a flattened, row-major order string of coefficients.

ImageMagick v7

magick input.png -color-matrix " \
    0.950  0.050  0.000 \
    0.000  0.433  0.567 \
    0.000  0.475  0.525 \
" output_tritanopia.png

ImageMagick v6

convert input.png -color-matrix " \
    0.950  0.050  0.000 \
    0.000  0.433  0.567 \
    0.000  0.475  0.525 \
" output_tritanopia.png

Single-Line Execution

You can also pass the matrix as a single comma- or space-separated string:

magick input.png -color-matrix "0.95 0.05 0 0 0.433 0.567 0 0.475 0.525" output_tritanopia.png

Considerations for Accuracy

  • Color Space: The matrix is calibrated for standard linear RGB color spaces. For strict scientific accuracy, convert the image to linear RGB before applying the matrix, then convert back to sRGB: 
    magick input.png -colorspace RGB -color-matrix "0.95 0.05 0 0 0.433 0.567 0 0.475 0.525" -colorspace sRGB output_tritanopia.png
  • Alpha Channels: If your input image includes transparency, ImageMagick preserves alpha channels automatically unless a 4×4 or 5×5 matrix is explicitly defined.
