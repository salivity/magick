Simulating Color Blindness with ImageMagick

This article explains how to simulate common color vision deficiencies—such as protanopia (red-blindness), deuteranopia (green-blindness), and tritanopia (blue-blindness)—using ImageMagick's -color-matrix operator. You will learn the mathematical foundation behind color transformation matrices, obtain ready-to-use matrix coefficients for standard deficiencies, and see practical command-line examples to transform any image into an accurate color blindness preview.

Understanding ImageMagick Color Matrices

ImageMagick provides the -color-matrix operator, which applies an affine transformation to an image's color channels. For standard RGB images, you define a 3x3 matrix (9 values) or a 5x5 matrix (for RGBA/offset adjustments).

In a standard 3x3 matrix, the output channels (\(R'\), \(G'\), \(B'\)) are calculated as linear combinations of the input channels (\(R\), \(G\), \(B\)):

\[R' = m_{00}R + m_{01}G + m_{02}B\] \[G' = m_{10}R + m_{11}G + m_{12}B\] \[B' = m_{20}R + m_{21}G + m_{22}B\]

To preserve overall image luminance, the sum of each row in the matrix should ideally equal 1.0.

Standard Color Blindness Matrices

The following matrices are derived from standard physiological color appearance models (such as the Machado, Vienot, and Brettel models) simplified for standard sRGB color spaces.

1. Protanopia (Red-Blind)

Individuals with protanopia lack functional L-cones (long-wavelength/red receptors), making it difficult to distinguish red from green and shifting reds toward darker shades.

Matrix:

 0.56667  0.43333  0.00000
 0.55833  0.44167  0.00000
 0.00000  0.24167  0.75833

ImageMagick Command:

magick input.jpg -color-matrix "0.56667 0.43333 0.00000 \
                                0.55833 0.44167 0.00000 \
                                0.00000 0.24167 0.75833" protanopia_output.jpg

2. Deuteranopia (Green-Blind)

Deuteranopia occurs when M-cones (medium-wavelength/green receptors) are absent. This is the most common form of red-green color blindness.

Matrix:

 0.62500  0.37500  0.00000
 0.70000  0.30000  0.00000
 0.00000  0.30000  0.70000

ImageMagick Command:

magick input.jpg -color-matrix "0.62500 0.37500 0.00000 \
                                0.70000 0.30000 0.00000 \
                                0.00000 0.30000 0.70000" deuteranopia_output.jpg

3. Tritanopia (Blue-Blind)

Tritanopia is a rarer condition characterized by the absence of S-cones (short-wavelength/blue receptors), resulting in difficulty distinguishing blue from green and yellow from violet.

Matrix:

 0.95000  0.05000  0.00000
 0.00000  0.43333  0.56667
 0.00000  0.47500  0.52500

ImageMagick Command:

magick input.jpg -color-matrix "0.95000 0.05000 0.00000 \
                                0.00000 0.43333 0.56667 \
                                0.00000 0.47500 0.52500" tritanopia_output.jpg

4. Achromatopsia (Complete Monochromacy)

Achromatopsia is total color blindness, where the viewer perceives only luminance variations.

Matrix:

 0.29900  0.58700  0.11400
 0.29900  0.58700  0.11400
 0.29900  0.58700  0.11400

ImageMagick Command:

magick input.jpg -color-matrix "0.29900 0.58700 0.11400 \
                                0.29900 0.58700 0.11400 \
                                0.29900 0.58700 0.11400" achromatopsia_output.jpg

Batch Processing and Scripting

To evaluate an entire directory of UI assets or images for accessibility testing, you can automate transformations across multiple deficiency types using a shell script:

#!/bin/bash
INPUT="$1"
BASENAME="${INPUT%.*}"

# Protanopia
magick "$INPUT" -color-matrix "0.56667 0.43333 0 0.55833 0.44167 0 0 0.24167 0.75833" "${BASENAME}_protanopia.png"

# Deuteranopia
magick "$INPUT" -color-matrix "0.625 0.375 0 0.7 0.3 0 0 0.3 0.7" "${BASENAME}_deuteranopia.png"

# Tritanopia
magick "$INPUT" -color-matrix "0.95 0.05 0 0 0.43333 0.56667 0 0.475 0.525" "${BASENAME}_tritanopia.png"

Legacy ImageMagick Versions

If you are using ImageMagick version 6, replace magick with convert and use the same -color-matrix parameters:

convert input.jpg -color-matrix "0.625 0.375 0 0.7 0.3 0 0 0.3 0.7" deuteranopia_v6.jpg
