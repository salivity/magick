Skeletonize Text Using ImageMagick Morphology

This guide explains how to reduce text characters to one-pixel-wide centerlines—known as a skeleton—and clean up unwanted artifacts using morphological pruning in ImageMagick. You will learn how to prepare high-contrast text images, apply skeletonization kernels, and prune extraneous spurs to produce clean, single-pixel vector-ready paths.

1. Prepare the Binary Text Image

ImageMagick’s morphology operators expect the foreground object to be white and the background to be black. If your source text image has dark text on a white background, it must be inverted and thresholded to ensure clean binary edges.

magick input_text.png -colorspace Gray -negate -threshold 50% binary_text.png

2. Apply Skeletonization

To thin the white character glyphs down to their centerlines, use the Thinning morphological method with the Skeleton kernel. The parameter -1 instructs ImageMagick to repeat the thinning process until the image no longer changes (the point of convergence).

magick binary_text.png -morphology Thinning:-1 Skeleton skeleton.png

At this stage, the characters are reduced to continuous one-pixel-thick representations. However, natural anti-aliasing and rough edges on the original font often produce small, unwanted branch artifacts known as "spurs."

3. Prune Spurious Branches

Morphological pruning removes dead ends and short branches without breaking closed loops. In ImageMagick, pruning is performed using the Thinning method paired with the LineEnds kernel.

Instead of running to convergence (which would erase all non-looping lines completely), specify a limited number of iterations. Each iteration strips one pixel from every exposed endpoint:

magick skeleton.png -morphology Thinning:2 LineEnds pruned_skeleton.png

In this command, :2 removes two pixels from every line terminal, trimming off small spurs while keeping the core stroke structure of the characters intact. Adjust this value depending on the resolution of your original text and the size of the artifacts.

4. Combine into a Single Command

You can chain the binarization, skeletonization, and pruning steps into a single, efficient command that processes an input image and outputs the final pruned skeleton:

magick input_text.png \
  -colorspace Gray -negate -threshold 50% \
  -morphology Thinning:-1 Skeleton \
  -morphology Thinning:3 LineEnds \
  output_skeleton.png

If your final workflow requires black strokes on a white background, append -negate right before the output file name to invert the result.
