Smooth Contours Using ImageMagick Morphology Open

This guide provides a straightforward walkthrough on smoothing jagged contours and noisy boundaries in images using ImageMagick. By applying a morphological Open operation paired with a circular structuring element (Disk), you can round sharp external corners, eliminate small protrusions, and achieve cleaner, smoother object shapes without blurring the entire image.

Understanding Morphology Open and Circular Kernels

In digital image processing, morphological opening consists of an erosion followed immediately by a dilation using the same structuring element (kernel).

  • Erosion shrinks bright regions and removes features smaller than the structuring element (such as thin spikes or noise).
  • Dilation restores the eroded shape back to its approximate original size.
  • A circular kernel (Disk) ensures that edges are eroded and restored uniformly in all directions, turning rough, pixelated contours into smooth, rounded curves.

The Basic Command

In ImageMagick version 7, use the magick command (or convert if you are using ImageMagick version 6) to run the -morphology operator with the Open method and the Disk kernel.

magick input.png -morphology Open Disk:3 output.png

In this command:

  • input.png is the source image (typically a high-contrast or binary silhouette).
  • -morphology Open directs ImageMagick to perform erosion followed by dilation.
  • Disk:3 specifies a circular structuring element with a radius of 3 pixels.
  • output.png is the smoothed result.

Adjusting the Kernel Radius

The numeric value passed to the Disk kernel determines the smoothing intensity:

  • Small Radii (Disk:1.5 to Disk:3): Ideal for subtle edge-smoothing, eliminating slight pixelation or anti-aliasing artifacts while maintaining overall geometry.
  • Larger Radii (Disk:5 to Disk:10+): Aggressively removes large jagged bumps and rounds out sharp outer corners, though it will discard finer structural details.

Floating-point numbers can be used for the radius (e.g., Disk:2.5) to allow fine-grained control over the smoothing amount.

Preserving Inner and Outer Contours (Open vs. Close)

While Open smooths outer jagged edges and eliminates small outer protrusions, it does not fill in sharp inward-pointing notches or small holes. If you need to smooth both inner and outer contours simultaneously, chain an Open operation with a Close operation (dilation followed by erosion):

magick input.png -morphology Open Disk:3 -morphology Close Disk:3 output.png

Complete Workflow for High-Quality Contours

When working with scanned art or low-resolution masks, combining thresholding with morphological operations produces the cleanest vector-like contours:

magick input.png \
  -threshold 50% \
  -morphology Open Disk:3 \
  -blur 0x1 \
  -threshold 50% \
  smoothed_output.png
  1. -threshold 50% ensures a clean black-and-white binary mask.
  2. -morphology Open Disk:3 smooths outer contour irregularities.
  3. -blur 0x1 -threshold 50% provides an optional final anti-aliasing and micro-smoothing pass on the resulting boundary.
