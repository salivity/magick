Soft-Proof Images with ImageMagick ICC Profiles

Soft-proofing allows you to preview how a digital image will look when printed by simulating the physical characteristics of a specific printer, ink, and paper combination on an RGB display. This guide explains how to perform soft-proofing using ImageMagick's color management features powered by LittleCMS (lcms). By applying sequential ICC profile conversions, you can accurately evaluate gamut clipping, contrast loss, and color shifts from the command line before sending an image to print.

Prerequisites

To perform soft-proofing in ImageMagick, ensure your installation includes LittleCMS delegate support. Verify this by running:

magick -version

Look for lcms in the Delegates list. You will also need:

  1. The source image (typically in sRGB or Adobe RGB).
  2. The printer ICC profile (e.g., printer_paper.icc or standard CMYK profiles like GRACoL2006_Coated1v2.icc).
  3. The display profile (e.g., sRGB.icc or your custom calibrated monitor profile).

The Soft-Proofing Command

Soft-proofing in ImageMagick is achieved by chaining profile conversions: converting from the source profile to the printer's color space, and then converting back to the monitor's RGB space so the output file accurately represents the printed result on a digital display.

magick input.jpg \
  -profile sRGB.icc \
  -intent Relative \
  -profile printer_paper.icc \
  -profile sRGB.icc \
  softproof_preview.jpg

Command Breakdown

  1. -profile sRGB.icc (First Call):
    Assigns or embeds the source color space. If your image already contains an embedded profile, this confirms the initial color interpretation.

  2. -intent <Intent>:
    Specifies the rendering intent used to map out-of-gamut colors to the destination space. Common options include:

    • Perceptual: Compresses the overall gamut to maintain visual relationships between colors.
    • Relative: Maps out-of-gamut colors to the nearest reproducible shade while preserving in-gamut colors and adjusting the white point.
    • Absolute: Preserves exact color coordinates and simulates paper white/tint without white point adaptation.
    • Saturation: Maximizes vividness, ideal for business graphics rather than photographic work.

  3. -profile printer_paper.icc (Second Call):
    Transforms the image data into the printer's device profile space using the specified rendering intent.

  4. -profile sRGB.icc (Third Call):
    Transforms the simulated print data back into an RGB display profile (or your monitor profile), producing an image file that visually mimics the printed output on your screen.

Simulating Paper White and Black Point

To simulate paper color and dynamic range (Absolute Colorimetric intent), use the -intent Absolute flag:

magick input.jpg \
  -profile sRGB.icc \
  -intent Absolute \
  -profile printer_paper.icc \
  -profile sRGB.icc \
  softproof_paper_sim.jpg

This output will reflect paper tint and compressed shadow detail, giving a realistic preview of the final print medium.
