SoftLight Composite Overlay in ImageMagick

This article provides a concise guide on using the SoftLight composition method in ImageMagick to blend two images together. The SoftLight blend mode simulates a diffused spotlight effect, softly darkening or lightening the base image depending on the color values of the overlay image. Below, you will find the exact command-line syntax for both modern ImageMagick v7 and legacy ImageMagick v6, along with practical examples for resizing and adjusting the overlay's intensity.

Basic SoftLight Command (ImageMagick v7)

In ImageMagick v7, the unified magick command handles composition. The base image is specified first, followed by the overlay image, the composition operator, and the output filename:

magick base.jpg overlay.png -compose SoftLight -composite output.jpg

Basic SoftLight Command (ImageMagick v6)

For ImageMagick v6, you can use either the convert command or the dedicated composite tool:

Using convert:

convert base.jpg overlay.png -compose SoftLight -composite output.jpg

Using composite (note that the overlay is passed before the base image):

composite -compose SoftLight overlay.png base.jpg output.jpg

Resizing the Overlay to Match the Base Image

If your overlay image is a different size than the base image, resize it on the fly before applying the composite:

magick base.jpg \( overlay.png -resize "%[fx:u.w]x%[fx:u.h]!" \) -compose SoftLight -composite output.jpg

Alternatively, you can resize the overlay directly to standard pixel dimensions:

magick base.jpg \( overlay.png -resize 1920x1080! \) -compose SoftLight -composite output.jpg

Adjusting Overlay Opacity

To reduce the strength of the SoftLight effect, adjust the opacity of the overlay image prior to compositing:

magick base.jpg \( overlay.png -alpha set -channel A -evaluate multiply 0.5 +channel \) -compose SoftLight -composite output.jpg

In this command, 0.5 sets the overlay opacity to 50%, resulting in a more subtle lighting blend.
