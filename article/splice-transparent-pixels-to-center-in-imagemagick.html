Splice Transparent Pixels to Center in ImageMagick

This article explains how to insert extra transparent space directly into the center of an image using ImageMagick's -splice operator. You will learn the exact command-line syntax to add vertical, horizontal, or dual-axis transparent padding without distorting the original image elements.

The Core Command

To insert transparent pixels into the center of an image, use the -splice operator combined with -gravity Center and -background none.

magick input.png -alpha set -background none -gravity Center -splice 0x100 output.png

(Note: If using ImageMagick version 6, replace magick with convert.)

Breakdown of the Parameters

  • input.png: Your source image file.
  • -alpha set: Ensures the image contains an alpha channel so the spliced pixels remain fully transparent (especially important when starting from formats without native transparency, like JPEG).
  • -background none: Defines the fill color for the newly created pixels as fully transparent. You can also use -background transparent.
  • -gravity Center: Sets the reference point for the splice operation to the exact center of the image.
  • -splice <Width>x<Height>: Specifies the dimensions of the area to insert.
    • To add vertical space (split top and bottom): use 0xHEIGHT (e.g., -splice 0x100 adds 100 pixels vertically).
    • To add horizontal space (split left and right): use WIDTHx0 (e.g., -splice 150x0 adds 150 pixels horizontally).
    • To add both dimensions simultaneously: use WIDTHxHEIGHT (e.g., -splice 150x100).
  • output.png: The final file. Ensure you save to an image format that supports transparency (such as PNG, WebP, or TIFF).

Examples

1. Splitting Vertically (Adding Height)

To insert 80 transparent pixels horizontally across the middle:

magick original.jpg -alpha set -background none -gravity Center -splice 0x80 expanded_vertical.png

2. Splitting Horizontally (Adding Width)

To insert 120 transparent pixels vertically down the middle:

magick original.png -alpha set -background none -gravity Center -splice 120x0 expanded_horizontal.png

3. Adding a Grid Gap (Both Dimensions)

To insert a 50x50 transparent cross into the center:

magick original.png -alpha set -background none -gravity Center -splice 50x50 expanded_both.png
