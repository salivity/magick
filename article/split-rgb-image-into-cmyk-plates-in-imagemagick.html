Split RGB Image into CMYK Plates in ImageMagick

This guide explains how to convert an RGB image into the CMYK color space and extract individual Cyan, Magenta, Yellow, and Black plates as separate image files using ImageMagick.

The ImageMagick Command

To split an RGB image into four individual CMYK grayscale plates, run the following command in your terminal:

For ImageMagick v7:

magick input_rgb.jpg -colorspace CMYK -separate plate_%d.png

For ImageMagick v6:

convert input_rgb.jpg -colorspace CMYK -separate plate_%d.png

How the Command Works

  • input_rgb.jpg: Specifies your source image in the RGB color space.
  • -colorspace CMYK: Converts the internal image data from RGB to CMYK color space.
  • -separate: Instructs ImageMagick to break the multi-channel CMYK image into individual channel layers.
  • plate_%d.png: Defines the output format and filename pattern. The %d syntax automatically numbers the generated files from 0 to 3.

Understanding the Output Files

The execution produces four grayscale files, where lighter tones represent higher ink density:

  • plate_0.png: The Cyan channel plate.
  • plate_1.png: The Magenta channel plate.
  • plate_2.png: The Yellow channel plate.
  • plate_3.png: The Black (Key) channel plate.
