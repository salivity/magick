Split RGB to CMYK Plates in ImageMagick

Splitting an RGB image into individual CMYK color separation plates is a standard task in prepress workflows for print production. This article provides the exact ImageMagick command needed to convert an RGB image to the CMYK color space and output each channel—Cyan, Magenta, Yellow, and Black—into distinct grayscale separation files.

The Command

To split an RGB image into individual CMYK plates, run the following command in your terminal:

magick input.jpg -colorspace CMYK -separate plate_%d.tiff

If you are using ImageMagick version 6 or earlier, use the convert binary:

convert input.jpg -colorspace CMYK -separate plate_%d.tiff

How It Works

  • input.jpg: The source RGB file you want to process.
  • -colorspace CMYK: Converts the RGB color data into the four-channel CMYK color space.
  • -separate: Instructs ImageMagick to extract each channel into an individual grayscale image representing ink density.
  • plate_%d.tiff: The output naming format. The %d placeholder writes sequential numbers for each channel:
    • plate_0.tiff: Cyan channel
    • plate_1.tiff: Magenta channel
    • plate_2.tiff: Yellow channel
    • plate_3.tiff: Black (Key) channel

Using TIFF format is recommended for print workflows to preserve uncompressed image quality and metadata across separation plates.
