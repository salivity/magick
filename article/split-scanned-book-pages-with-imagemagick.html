Split Scanned Book Pages with ImageMagick

This guide explains how to split a scanned two-page book spread into two individual image files using ImageMagick. By utilizing ImageMagick’s built-in cropping and percentage-based sizing features, you can quickly divide a dual-page spread down the middle into left and right pages without manually calculating pixel dimensions.

The Basic Command

To split an image vertically into two equal halves (left page and right page), use the -crop parameter set to 50%x100%.

ImageMagick v7 (Current)

magick input_spread.jpg -crop 50%x100% +repage page_%d.jpg

ImageMagick v6 (Legacy)

convert input_spread.jpg -crop 50%x100% +repage page_%d.jpg

This generates two output files: page_0.jpg (left page) and page_1.jpg (right page).

How It Works

  • -crop 50%x100%: Instructs ImageMagick to divide the image into tiles that are 50% of the original width and 100% of the original height. This produces two horizontal slices representing the left and right pages.
  • +repage: Removes the virtual canvas metadata and resets the image offsets, ensuring the resulting images open and display correctly in all image viewers.
  • page_%d.jpg: A C-style format string that automatically names the resulting files sequentially (page_0.jpg, page_1.jpg).

Batch Processing Multiple Book Spreads

If you have an entire directory of scanned spreads, you can automate the process using a shell loop.

Linux / macOS (Bash)

for file in *.jpg; do
  magick "$file" -crop 50%x100% +repage "${file%.*}_page_%d.jpg"
done

Windows (Command Prompt)

for %f in (*.jpg) do magick "%f" -crop 50%x100% +repage "%~nf_page_%d.jpg"

Handling Asymmetrical or Off-Center Spreads

If the book spine is not centered in the scan, you can specify exact pixel dimensions and offsets rather than percentages.

To extract each page individually:

  1. Extract the left page:

    magick input_spread.jpg -crop [WIDTH]x[HEIGHT]+0+0 +repage left_page.jpg

  2. Extract the right page:

    magick input_spread.jpg -crop [WIDTH]x[HEIGHT]+[X_OFFSET]+0 +repage right_page.jpg

Replace [WIDTH], [HEIGHT], and [X_OFFSET] with your specific pixel measurements.
