Split Scanned Book Spreads in ImageMagick

Splitting dual-page scanned book spreads into individual, sequential pages is a common task when digitizing books and documents. Using ImageMagick, you can automatically divide two-page spreads into left and right halves while maintaining the correct reading order. This guide explains the exact ImageMagick commands required to split single spreads, process entire directories, and convert multi-page PDF documents.

Splitting a Single Image Spread

To divide a side-by-side scanned spread into two separate image files in standard left-to-right reading order, use the -crop and +repage operators.

For ImageMagick v7:

magick spread.jpg -crop 50%x100% +repage page_%02d.jpg

For ImageMagick v6:

convert spread.jpg -crop 50%x100% +repage page_%02d.jpg

How the command works:

  • -crop 50%x100%: Divides the image horizontally into two equal halves (the left half first, then the right half).
  • +repage: Resets the virtual canvas geometry so the resulting images do not retain offset metadata.
  • page_%02d.jpg: Uses a standard format specifier to output sequentially numbered files (e.g., page_00.jpg for the left page, page_01.jpg for the right page).

Batch Processing Multiple Image Spreads

When you have a folder of scanned spreads (e.g., spread_01.jpg, spread_02.jpg), running a simple batch command ensures that the final output maintains continuous page numbering across all files.

Using a Bash Loop (Linux / macOS):

counter=1
for file in $(ls -v spread_*.jpg); do
  magick "$file" -crop 50%x100% +repage "temp_%d.jpg"
  mv "temp_0.jpg" $(printf "page_%04d.jpg" $counter)
  counter=$((counter + 1))
  mv "temp_1.jpg" $(printf "page_%04d.jpg" $counter)
  counter=$((counter + 1))
done

Single Command Batch Processing: If your operating system sorts filenames correctly in memory, you can process all files simultaneously:

magick spread_*.jpg -crop 50%x100% +repage page_%04d.jpg

Splitting Spreads in a Multi-Page PDF

If your scanned spreads are saved within a single multi-page PDF, ImageMagick can extract, split, and reassemble them into a new single-page sequential PDF.

magick -density 300 input_spreads.pdf -crop 50%x100% +repage output_single_pages.pdf
  • -density 300: Sets the rasterization resolution to 300 DPI to preserve document clarity. Ensure this flag is placed before the input file name.

Handling Right-to-Left (RTL) Formats

For materials read right-to-left (such as manga or Arabic texts), the right side of the spread must be ordered before the left side. You can swap the order of the generated slices using -reverse:

magick spread.jpg -crop 50%x100% +repage -reverse rtl_page_%02d.jpg
