Star Trails in ImageMagick with evaluate-sequence Max

This guide explains how to generate composite star trail photographs from an interval sequence using ImageMagick's -evaluate-sequence Max operator. By comparing every image in a dataset and retaining only the brightest pixels at each coordinate, ImageMagick effortlessly draws continuous stellar paths across the frame while keeping stationary elements properly exposed.

Basic Syntax

In ImageMagick 7, the standard command-line syntax for stacking star trails is:

magick input_*.jpg -evaluate-sequence Max star_trail_output.jpg

If you are using legacy ImageMagick 6, replace magick with convert:

convert input_*.jpg -evaluate-sequence Max star_trail_output.jpg

How the Command Works

  • input_*.jpg: Matches all the sequential source photos in alphabetical or numerical order. Ensure your filenames are consistently zero-padded (e.g., frame_0001.jpg, frame_0002.jpg) so ImageMagick reads them in correct chronological sequence.
  • -evaluate-sequence Max: Iterates through every pixel coordinate across all loaded frames, compares the luminance values, and saves the maximum (brightest) value found at that coordinate into the resulting composite. Because stars are significantly brighter than the surrounding night sky, their new positions in each successive frame are added to the canvas without washing out the darker sky background.
  • star_trail_output.jpg: Specifies the output file path and format.

Recommended Command for High-Resolution Photos

Stacking hundreds of high-resolution images can exhaust system memory. To prevent crashes, handle memory efficiently, and preserve dynamic range, use uncompressed 16-bit output formats like TIFF:

magick -limit memory 4GB -limit map 8GB *.jpg -evaluate-sequence Max star_trail_output.tif
  • -limit memory 4GB -limit map 8GB: Restricts RAM usage and offloads excessive pixel cache to disk, preventing out-of-memory errors during large stacking jobs.
  • .tif: Prevents repeated compression loss, making the stacked file ideal for final post-processing in editing software.
