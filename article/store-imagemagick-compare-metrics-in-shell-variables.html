Store ImageMagick Compare Metrics in Shell Variables

This article provides a direct guide on capturing error metrics from ImageMagick's compare tool directly into shell variables. Because ImageMagick writes its numerical comparison metrics to standard error (stderr) rather than standard output (stdout), standard command substitution requires specific redirection techniques. Below are the precise commands and methods for POSIX-compliant shells and Bash to capture, parse, and store these values cleanly.

The Standard Redirection Method

By default, the compare command outputs the difference image to standard output or a specified file, while numerical metrics specified by -metric are sent to standard error (file descriptor 2).

To assign the metric output to a shell variable without creating an unwanted diff image file, output the diff to null: and redirect stderr to stdout (2>&1):

# ImageMagick v6
metric_value=$(compare -metric RMSE image1.png image2.png null: 2>&1)

# ImageMagick v7
metric_value=$(magick compare -metric RMSE image1.png image2.png null: 2>&1)

echo "$metric_value"

Parsing Specific Metric Outputs

Depending on the metric used (such as RMSE, MAE, or PAE), ImageMagick often outputs two values: the absolute raw value and the normalized value inside parentheses (e.g., 1245.2 (0.0189996)).

Extracting Only the Raw Metric

To capture only the first numeric value:

raw_metric=$(magick compare -metric RMSE image1.png image2.png null: 2>&1 | awk '{print $1}')

Extracting Only the Normalized Metric

To capture only the normalized metric inside the parentheses:

norm_metric=$(magick compare -metric RMSE image1.png image2.png null: 2>&1 | sed -n 's/.*(\(.*\))/\1/p')

Single-Value Metrics (e.g., AE, NCC, SSIM)

Metrics like AE (Absolute Error) or NCC (Normalized Cross Correlation) return a single scalar value and can be assigned directly:

ae_count=$(magick compare -metric AE image1.png image2.png null: 2>&1)

Handling Shell Exit Codes

ImageMagick's compare utility returns specific exit codes:

  • 0: The images are identical.
  • 1: The images are different (even though the metric calculation succeeded).
  • 2: An error occurred (e.g., file not found or dimension mismatch).

If your shell script uses set -e (exit on error), the exit status of 1 on different images will terminate the script. To prevent this, append || true inside the substitution:

metric_value=$(magick compare -metric RMSE image1.png image2.png null: 2>&1 || true)

If you need both the metric value and the exit status:

metric_output=$(magick compare -metric RMSE image1.png image2.png null: 2>&1)
exit_code=$?

if [ $exit_code -eq 2 ]; then
    echo "Comparison failed due to an error: $metric_output"
else
    echo "Metric: $metric_output"
fi
