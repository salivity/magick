Strip Adobe Tags from TIFF Using ImageMagick

TIFF files processed in Adobe Photoshop often contain proprietary private tags—such as 8BIM image resource blocks, layer data, and XMP metadata—that can increase file sizes and cause parsing errors in non-Adobe software. This guide demonstrates how to quickly identify and strip proprietary Adobe tags from TIFF files using ImageMagick, either completely or by targeting specific metadata profiles.

Complete Metadata Removal with -strip

The simplest and most effective way to eliminate all Adobe private tags, standard profiles, and embedded comments is the -strip operator. This command removes the Photoshop Resource Block (Tag 34377), ImageSourceData (Tag 37724), XMP packets, and ICC color profiles.

Run the following command in your terminal:

magick input.tif -strip output.tif

For ImageMagick version 6, use:

convert input.tif -strip output.tif

Removing Only Adobe 8BIM Metadata

If you need to preserve standard EXIF or ICC color profiles while removing only Adobe-specific metadata (such as Photoshop paths, grids, and guides), use the +profile operator targeting the 8bim profile.

magick input.tif +profile "8bim" output.tif

To remove both the Adobe 8BIM profile and Adobe XMP packets while leaving color profiles intact:

magick input.tif +profile "8bim" +profile "xmp" output.tif

Discarding Photoshop Layers and Extra Channels

Adobe Photoshop often stores proprietary multi-layer data inside TIFF Tag 37724 (ImageSourceData). Even when metadata profiles are stripped, this tag can remain if the TIFF was saved with layers enabled.

To discard Photoshop layer data and save only the composite image, use the -flatten operator combined with the TIFF ignore-layers define:

magick input.tif -define tiff:ignore-layers=true -flatten -strip output.tif

Batch Processing Multiple TIFF Files

To process an entire directory of TIFF files in place without manually naming each output file, use mogrify:

magick mogrify -strip *.tif

Note: The mogrify command overwrites the original files. Ensure you have backups before executing it.

Verifying the Tags Are Removed

You can verify that the Adobe private profiles and tags have been completely removed by inspecting the file with ImageMagick's identify tool:

magick identify -verbose output.tif | grep -i -E "8bim|photoshop|xmp|profile"

If the command returns no matches, all proprietary Adobe metadata blocks have been stripped from the TIFF file.
