Strip WebP Metadata While Keeping ICC in ImageMagick

This guide explains how to remove unnecessary metadata such as EXIF, XMP, and IPTC from WebP images while preserving critical ICC color profiles using ImageMagick. Standard stripping commands typically discard all metadata indiscriminately, leading to potential color shifts on color-managed displays. By explicitly removing non-color profiles or skipping them during processing, you can optimize file size without sacrificing color fidelity.

The Command

To strip extraneous metadata while preserving the embedded ICC color profile, use the +profile operator:

magick input.webp -auto-orient +profile exif +profile xmp +profile iptc output.webp

(For ImageMagick 6, replace magick with convert.)

How It Works

  • -auto-orient: Reads the EXIF orientation tag and physically rotates the pixel data if necessary before the metadata is removed. If you strip EXIF data without running -auto-orient, rotated images may display in the wrong orientation.
  • +profile exif: Strips camera details, capture settings, geolocation, and timestamps.
  • +profile xmp: Removes Extensible Metadata Platform data, typically added by editing software like Photoshop or Lightroom.
  • +profile iptc: Removes legacy editorial and copyright metadata.
  • Preserving ICC: Because you are specifying only exif, xmp, and iptc to be removed, the embedded icc profile remains intact inside the WebP container.

Alternative Method: Skipping on Read

In modern versions of ImageMagick 7, you can prevent non-ICC profiles from loading into memory during read time:

magick -define profile:skip=EXIF,XMP,IPTC input.webp -auto-orient output.webp

This method avoids loading non-color metadata chunks entirely, saving memory and ensuring the output file only retains the ICC profile.

Why Not Use -strip?

The default -strip parameter removes all profiles and comments:

magick input.webp -strip output.webp

Running -strip strips the ICC profile alongside EXIF and XMP data. If your image uses wide-gamut profiles (such as Display P3 or Adobe RGB), stripping the ICC profile will cause standard sRGB browsers and viewers to render the colors incorrectly or washed out. Targeting profiles individually preserves color integrity.
