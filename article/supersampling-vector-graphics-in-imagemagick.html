Supersampling Vector Graphics in ImageMagick

This guide explains how to use supersampling in ImageMagick to achieve ultra-smooth, professional-grade edge anti-aliasing when converting vector graphics (such as SVG, PDF, or EPS) to raster formats. By instructing ImageMagick to render the vector file at a significantly higher pixel density before downscaling it to your target dimensions, you can eliminate jagged edges and produce pristine raster images.

The Supersampling Principle

Vector rasterizers typically render graphics at standard display densities (usually 72 or 96 DPI), which can produce visible stair-stepping (aliasing) on fine curves and diagonal lines.

Supersampling anti-aliasing (SSAA) solves this by:

  1. Rendering the vector graphic at a high multiple of the target resolution.
  2. Downscaling the high-resolution raster image to the desired final dimensions using an advanced resampling filter.

Basic Supersampling Command

To supersample, define a high -density value before specifying the input file, then use -resize to scale down to the target dimension.

magick -density 384 input.svg -resize 25% output.png

In this example:

  • -density 384 renders the SVG at \(4\times\) the default 96 DPI resolution.
  • -resize 25% reduces the dimensions back to the original intended size, blending the extra pixel data into smooth edges.

Targeting Exact Dimensions

When you need a specific output width and height, set a high density first, then resize to your exact target pixel dimensions:

magick -density 600 -background none input.svg -filter Lanczos -resize 800x800 output.png

Key Parameter Breakdown

  • -density [DPI] (Input setting): Must appear before the input vector file. Setting this to 300–600 DPI ensures fine curves are captured with high precision.
  • -background none: Ensures transparent vector backgrounds remain transparent without creating dark fringing around edges.
  • -filter Lanczos: Applies a high-quality resampling algorithm during the downscaling step. Mitchell or Catrom are also effective alternatives for softer or sharper edges, respectively.
  • -resize [geometry] (Output setting): Scales the oversized raster down to your final required resolution.

Advanced: Calculating Density for Pixel-Perfect Outputs

If your source vector file has native dimensions and you want an exact \(N\times\) supersampling factor:

  1. Multiply the base density (typically 72 for PDF/EPS, 96 for SVG) by your supersampling factor (e.g., \(4\times\) or \(8\times\)).
    • For SVG at \(4\times\): \(96 \times 4 = 384\text{ DPI}\)
    • For SVG at \(8\times\): \(96 \times 8 = 768\text{ DPI}\)
    • For PDF/EPS at \(4\times\): \(72 \times 4 = 288\text{ DPI}\)
  2. Load the vector with the calculated -density.
  3. Downsample using -resize with the reciprocal percentage (\(25\%\) for \(4\times\), \(12.5\%\) for \(8\times\)).
magick -density 768 -background none graphic.svg -filter Mitchell -resize 12.5% graphic_smooth.png
