Swap Red and Blue Channels in ImageMagick 7

Swapping color channels is a common image processing task frequently used to fix inverted channel formats (like BGR to RGB) or to produce artistic color effects. This guide demonstrates the precise syntax required to swap the red and blue color channels in ImageMagick 7 using the modern -channel-fx operator.

The -channel-fx Swap Syntax

ImageMagick 7 introduced the -channel-fx option, which provides a concise expression syntax for channel extraction, transfer, and exchange. To swap the red and blue channels, use the bidirectional exchange operator <=>:

magick input.png -channel-fx "red<=>blue" output.png

Abbreviated Syntax

You can also use single-letter channel abbreviations (r for red, b for blue) for a more compact command:

magick input.png -channel-fx "r<=>b" output.png

How It Works

  • magick: Invokes ImageMagick 7's unified command-line tool.
  • input.png: Specifies the source file to process.
  • -channel-fx "red<=>blue": Evaluates the channel-fx expression. The <=> symbol exchanges the pixel data of the red and blue channels simultaneously without altering other channels, such as green or alpha.
  • output.png: The destination file where the resulting image is saved.
