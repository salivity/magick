Switch Units Between PPI and PPCM in ImageMagick

Changing an image's resolution unit metadata between pixels-per-inch (PPI) and pixels-per-centimeter (PPCM) is a common requirement when preparing digital assets for specific print layouts or international standards. ImageMagick provides dedicated options—primarily the -units and -density operators—to switch these measurement units directly from the command line without altering the underlying image data or visual quality.

The -units Option

ImageMagick uses the -units setting to define how resolution density values are interpreted and stored in the image file's metadata.

The two primary unit values are:

  • PixelsPerInch (PPI)
  • PixelsPerCentimeter (PPCM)

Switching Units Automatically

When you change the unit type without manually specifying a new -density, ImageMagick automatically recalculates the existing density value to maintain the exact physical print dimensions.

Convert from PPI to PPCM

To switch an image's resolution metadata from pixels-per-inch to pixels-per-centimeter:

magick input.jpg -units PixelsPerCentimeter output.jpg

For example, an image with an initial density of 300 PPI will automatically be recalculated to approximately 118.11 PPCM.

Convert from PPCM to PPI

To switch from pixels-per-centimeter back to pixels-per-inch:

magick input.jpg -units PixelsPerInch output.jpg

An image set to 118.11 PPCM will be recalculated to 300 PPI.

(Note: If you are using ImageMagick v6, replace magick with convert in your commands.)

Setting Custom Density Alongside Unit Changes

If you want to explicitly define a new density value while setting the unit, apply both the -units and -density operators together:

magick input.jpg -units PixelsPerCentimeter -density 120 output.jpg

This sets the resolution metadata directly to 120 pixels per centimeter.

Verifying the Resolution Metadata

You can verify that the unit switch was applied correctly by inspecting the image metadata using ImageMagick's identify tool:

magick identify -format "%x x %y %U\n" output.jpg

This command outputs the horizontal density (%x), vertical density (%y), and the active resolution unit (%U).
