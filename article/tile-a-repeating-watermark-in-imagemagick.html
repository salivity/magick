Tile a Repeating Watermark in ImageMagick

This guide explains how to protect your images by applying a repeating, tiled copyright watermark across an entire image using ImageMagick. You will learn the commands required to generate a semi-transparent, rotated text pattern and seamlessly tile it over any target photo to deter unauthorized use without obscuring the underlying subject completely.

Method 1: The Single-Command Approach

In modern ImageMagick (version 7), you can generate a watermark pattern in memory and tile it over the target image in a single execution.

Run the following command in your terminal:

magick input.jpg \
  \( -size 300x200 xc:none \
     -fill "rgba(255,255,255,0.3)" \
     -gravity center \
     -pointsize 24 \
     -annotate +30 "© Copyright" \) \
  -write mpr:tile +delete \
  -tile mpr:tile \
  -draw "rectangle 0,0 %[w],%[h]" \
  output.jpg

How the Parameters Work:

  • -size 300x200 xc:none: Creates a transparent canvas of 300 by 200 pixels. Increasing these values spaces the watermarks further apart.
  • -fill "rgba(255,255,255,0.3)": Sets the text color to white with 30% opacity. You can change this to rgba(0,0,0,0.3) for black text.
  • -annotate +30 "© Copyright": Rotates the watermark text 30 degrees counter-clockwise and sets the copyright string.
  • -write mpr:tile +delete: Saves the generated tile into an in-memory register named tile and removes it from the immediate image stack.
  • -tile mpr:tile -draw "rectangle 0,0 %[w],%[h]": Fills the entire dimensions of the base image using the stored tile pattern.

Method 2: The Two-Step Approach (File-Based)

If you prefer creating a reusable watermark file or are working with ImageMagick 6, you can split the process into two steps.

Step 1: Create the Watermark Tile

Generate a single transparent PNG containing the angled watermark text:

magick -size 250x150 xc:none \
  -fill "rgba(255,255,255,0.25)" \
  -gravity center \
  -pointsize 20 \
  -annotate 35 "© Your Name" \
  watermark_tile.png

Step 2: Tile the Watermark Across the Image

Composite the generated tile over your target image:

magick composite -tile watermark_tile.png input.jpg output.jpg

If you are using ImageMagick 6, replace magick composite with composite.

Customization Tips

  • Adjust Density: Modify the dimensions in -size WxH when defining the tile. A smaller canvas (e.g., 150x100) creates a dense grid, while a larger canvas (e.g., 500x300) spreads the text farther apart.
  • Adjust Transparency: Change the alpha value in the RGBA string. A value of 0.15 is very subtle, while 0.5 makes the watermark significantly more prominent.
  • Change Font: Add -font Arial (or the path to any .ttf file) before the -pointsize option to customize typography.
