Timestamp RTSP Stream Snapshots with ImageMagick

This article provides a complete guide to capturing a still frame from an RTSP camera stream and burning a dynamic, accurate timestamp directly onto the image using FFmpeg and ImageMagick. Combining these tools allows you to pull real-time video frames from IP cameras and render clear, customizable date and time overlays suitable for security logging, monitoring, and archival purposes.

The Workflow Overview

ImageMagick does not ingest live network video streams like RTSP directly. The industry-standard approach is to fetch a single frame from the RTSP stream using FFmpeg, pipe the raw image data directly into ImageMagick, and apply the dynamic timestamp in memory before saving the final image to disk. This avoids unnecessary disk I/O and keeps the process fast.

Prerequisites

Ensure both FFmpeg and ImageMagick (version 7 is recommended) are installed on your system.

On Debian/Ubuntu:

sudo apt update
sudo apt install ffmpeg imagemagick

The Single-Line Command

You can capture a frame and overlay the current dynamic timestamp using a single piped command in bash:

ffmpeg -rtsp_transport tcp -i "rtsp://username:password@camera_ip:554/stream" \
  -frames:v 1 -f image2pipe -vcodec mjpeg - | \
  magick - \
  -gravity SouthEast \
  -pointsize 24 \
  -fill white \
  -undercolor "#00000080" \
  -annotate +20+20 "$(date '+%Y-%m-%d %H:%M:%S')" \
  snapshot_timestamped.jpg

How It Works

1. The FFmpeg Frame Grab

  • -rtsp_transport tcp: Forces TCP transmission to prevent packet loss, image smearing, or artifacts common with UDP.
  • -i "rtsp://...": Specifies the RTSP stream URL of your camera.
  • -frames:v 1: Tells FFmpeg to extract only one video frame.
  • -f image2pipe -vcodec mjpeg -: Formats the captured frame as an MJPEG image and streams it directly to standard output (-) instead of writing to disk.

2. The ImageMagick Dynamic Text Overlay

  • magick -: Reads the incoming MJPEG image from standard input (-).
  • -gravity SouthEast: Sets the reference origin to the bottom-right corner of the image.
  • -pointsize 24: Controls the font size of the timestamp text.
  • -fill white: Sets the text color to white.
  • -undercolor "#00000080": Adds a semi-transparent black background behind the text (50% opacity) to ensure the timestamp remains legible over light and dark video backgrounds.
  • -annotate +20+20 "...": Offsets the text 20 pixels horizontally and 20 pixels vertically from the bottom-right corner.
  • "$(date '+%Y-%m-%d %H:%M:%S')": Dynamically executes the system's date command to generate the current local timestamp at the moment of execution.
  • snapshot_timestamped.jpg: The final destination file.

Automating Periodic Snapshots

To run this process automatically, place the command into a bash script:

#!/usr/bin/env bash

CAMERA_URL="rtsp://username:password@camera_ip:554/stream"
OUTPUT_DIR="/var/www/html/snapshots"
TIMESTAMP=$(date '+%Y-%m-%d_%H-%M-%S')
PRETTY_DATE=$(date '+%Y-%m-%d %H:%M:%S')

ffmpeg -rtsp_transport tcp -i "$CAMERA_URL" \
  -frames:v 1 -f image2pipe -vcodec mjpeg - | \
  magick - \
  -font DejaVu-Sans-Bold \
  -gravity SouthEast \
  -pointsize 28 \
  -fill yellow \
  -undercolor "rgba(0,0,0,0.6)" \
  -annotate +15+15 "$PRETTY_DATE" \
  "$OUTPUT_DIR/snap_$TIMESTAMP.jpg"

You can then trigger this script via cron at scheduled intervals or integrate it into a background loop for continuous capture.
