Transfer Alpha Channel in ImageMagick

This guide explains how to transfer the alpha transparency channel from one image to another using ImageMagick. Whether you are dealing with PNG, TIFF, or WebP formats, this technique allows you to extract the transparency layer from a source image and apply it cleanly to a target image using command-line syntax compatible with both ImageMagick 6 and 7.

Modern Syntax (ImageMagick v7)

The most efficient way to replace an alpha channel is using a single magick command with subshell operations. This approach extracts the alpha channel of the source image as a grayscale mask and applies it directly to the target image using the CopyOpacity composition operator.

magick target.png ( source.png -alpha extract ) -alpha off -compose CopyOpacity -composite output.png

Note: On Windows Command Prompt (cmd.exe), omit the backslashes around parentheses. In PowerShell or Linux/macOS shells, escape the parentheses with backslashes if not using quotes, like \( source.png -alpha extract \).

Legacy Syntax (ImageMagick v6)

For systems running ImageMagick 6, the convert binary is used instead, and parentheses must be escaped to prevent shell interference:

convert target.png \( source.png -alpha extract \) -alpha off -compose CopyOpacity -composite output.png

Step-by-Step Breakdown of the Parameters

  • target.png: The base image that will receive the new transparency layer. Both images should ideally share the same pixel dimensions to avoid alignment and scaling issues.
  • ( source.png -alpha extract ): Opens the source image in memory and runs -alpha extract, converting its transparency channel into an isolated, grayscale mask image.
  • -alpha off: Disables any existing alpha channel on target.png to ensure the incoming alpha data cleanly overrides previous transparency without blending errors.
  • -compose CopyOpacity: Sets the composition operator. This tells ImageMagick to take the grayscale intensity of the second image (the mask) and map it into the alpha/opacity channel of the target image.
  • -composite: Executes the composition of the two image buffers.
  • output.png: Writes the final composited image to disk.

Two-Step Alternative Using an Intermediate Mask

If you prefer to verify or manipulate the alpha mask separately, you can split the operation into two distinct commands:

  1. Extract the alpha mask:
magick source.png -alpha extract mask.png
  1. Apply the mask to the target:
magick target.png mask.png -alpha off -compose CopyOpacity -composite output.png
