Transfer Luminosity in ImageMagick with Luminize

This guide explains how to use ImageMagick's Luminize composition mode to transfer the brightness and tonal values from one image onto another while preserving the target's original colors. You will learn the correct command-line syntax for both ImageMagick v7 and legacy versions, understand how source and destination layers interact during blending, and see how to prepare images of varying dimensions for a seamless luminosity transfer.

How the Luminize Operator Works

In digital image processing, color can be separated into chromaticity (hue and saturation) and luminance (perceived brightness). The Luminize operator in ImageMagick takes the luminance channel of the source image and merges it with the hue and saturation channels of the destination image.

  • Destination image: Provides the color (Hue and Saturation).
  • Source image: Provides the tonal map, highlights, and shadows (Luminosity).

Applying Luminize in ImageMagick v7

In ImageMagick 7, standard workflows utilize the unified magick command. The first image listed acts as the destination (color), and the second image acts as the source (luminance).

magick color_base.jpg tone_source.jpg -compose Luminize -composite output.jpg

In this command:

  • color_base.jpg retains its original color hues.
  • tone_source.jpg dictates the light and dark areas.
  • -compose Luminize sets the blending algorithm.
  • -composite executes the blend before writing to output.jpg.

Applying Luminize in ImageMagick v6

If you are using ImageMagick 6, the legacy composite command requires inverted ordering compared to the magick tool:

composite -compose Luminize tone_source.jpg color_base.jpg output.jpg

Alternatively, you can use the convert tool in version 6, which maintains the same layer order as version 7:

convert color_base.jpg tone_source.jpg -compose Luminize -composite output.jpg

Handling Differing Dimensions and Aspect Ratios

To transfer luminosity accurately, both images should share identical dimensions. If the luminance source differs in size from the color base, resize the source within the command stream:

magick color_base.jpg \( tone_source.jpg -resize "%[fx:u.w]x%[fx:u.h]!" \) -compose Luminize -composite output.jpg

This inline operation resizes tone_source.jpg to match the exact width (u.w) and height (u.h) of color_base.jpg before executing the composition.

Preserving Linear Color Accuracy

By default, ImageMagick operates in non-linear sRGB space. For technically accurate luminosity blending that mimics physical light interaction, convert the image to a linear color space prior to composition, then convert it back:

magick color_base.jpg tone_source.jpg -colorspace RGB -compose Luminize -composite -colorspace sRGB output.jpg
