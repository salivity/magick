Transparent Rounded Corners with ImageMagick

Applying transparent rounded corners to an image using ImageMagick involves generating a rounded rectangle mask via drawing primitives and compositing it onto the source image. This guide demonstrates how to use the roundrectangle drawing primitive along with alpha compositing operators to cleanly cut out the corners of an image and leave them completely transparent in PNG format.

The Core Concept

To create transparent rounded corners, ImageMagick generates a grayscale or transparent mask that defines which parts of the image should remain visible. The roundrectangle drawing primitive draws a shape with smooth, curved edges. When combined with the DstIn (Destination In) composite operator, the image retains only the pixels overlapping the solid areas of the mask, turning the corners transparent.

The Basic Command

For modern ImageMagick (v7+), use the following syntax to round the corners of an image:

magick input.jpg \
\( +clone -alpha transparent -background none \
   -fill white -draw "roundrectangle 0,0,%[fx:w-1],%[fx:h-1],30,30" \) \
-compose DstIn -composite output.png

If you are using ImageMagick v6, replace magick with convert:

convert input.jpg \
\( +clone -alpha transparent -background none \
   -fill white -draw "roundrectangle 0,0,%[fx:w-1],%[fx:h-1],30,30" \) \
-compose DstIn -composite output.png

Understanding the Parameters

  • +clone: Creates a copy of the input image in memory to serve as the base canvas for the mask, ensuring the dimensions match precisely.
  • -alpha transparent -background none: Clears the canvas so it becomes fully transparent.
  • -fill white: Sets the color used to draw the visible area.
  • -draw "roundrectangle x0,y0,x1,y1,wc,hc": Defines the rounded rectangle geometry:
    • 0,0: The top-left starting coordinate.
    • %[fx:w-1],%[fx:h-1]: Dynamic expressions representing the bottom-right corner coordinates (width minus 1, height minus 1).
    • 30,30: The horizontal and vertical corner radius in pixels. Adjust these values to increase or decrease the roundness.
  • -compose DstIn -composite: Applies the mask to the original image, preserving only the content within the white rounded rectangle.
  • output.png: The resulting file. A format supporting transparency (such as PNG or WebP) must be used.

Handling Specific Dimensions Directly

If you know the exact dimensions of your image beforehand (for example, 400x300 pixels), you can pass fixed coordinates instead of dynamic calculations:

magick input.jpg \
\( +clone -alpha transparent -background none \
   -fill white -draw "roundrectangle 0,0,399,299,20,20" \) \
-compose DstIn -composite output.png

This method provides precise, anti-aliased transparency suitable for web assets, user avatars, and UI components.
