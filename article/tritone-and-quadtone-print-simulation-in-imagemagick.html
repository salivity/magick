Tritone and Quadtone Print Simulation in ImageMagick

Simulating tritone and quadtone prints in ImageMagick involves converting a base image to grayscale and remapping its tonal spectrum across three or four specific ink colors using a Color Look-Up Table (CLUT). This guide provides the exact command-line syntax to simulate multi-ink print techniques, allowing you to achieve authentic darkroom and fine-art press color toning.

Understanding Multi-Tone Color Look-Up Tables

In traditional multi-tone printing, multiple inks are applied across specific tonal values (shadows, mid-tones, and highlights). In ImageMagick, this process is modeled by generating a 1-pixel wide gradient containing your target ink stops, then mapping that gradient onto a grayscale base image using the -clut operator.

Tritone Simulation Syntax

A tritone uses three ink colors: typically a deep tone for shadows, a tinted midtone, and a highlight color.

magick input.jpg -colorspace Gray \
  \( -size 1x256 gradient:"#1a1105-#734f2d-#f5e6d3" \) \
  -clut output_tritone.jpg

Syntax breakdown:

  • input.jpg -colorspace Gray: Strips original color data to create a clean luminosity map.
  • \( -size 1x256 gradient:"#color1-#color2-#color3" \): Creates a 256-level color ramp.
    • #1a1105: Deep shadow ink.
    • #734f2d: Midtone ink.
    • #f5e6d3: Highlight paper/ink tint.
  • -clut: Replaces the grayscale values of the main image with the corresponding colors from the generated gradient.

Quadtone Simulation Syntax

A quadtone introduces four distinct ink ranges: deep shadows, dark midtones, light midtones, and paper base/highlights.

magick input.jpg -colorspace Gray \
  \( -size 1x256 gradient:"#0a0a0f-#36454f-#8b8589-#fdfbf7" \) \
  -clut output_quadtone.jpg

Syntax breakdown:

  • #0a0a0f: Primary shadow tone (e.g., carbon black).
  • #36454f: Dark midtone (e.g., cool slate gray).
  • #8b8589: Light midtone (e.g., warm gray).
  • #fdfbf7: Highlight tone (e.g., warm cotton rag base).

Asymmetrical Tonal Distribution

By default, standard multi-stop gradients space color stops evenly. To bias ink saturation toward shadows or highlights, generate the gradient using non-linear interpolation or specific percentage stops using the sparse-color or gradient weighting parameters:

magick input.jpg -colorspace Gray \
  \( -size 1x256 xc: -sparse-color Barycentric \
     "0,0 #0a0a0f  0,64 #36454f  0,160 #8b8589  0,255 #fdfbf7" \) \
  -clut output_asymmetric_quadtone.jpg

In this command, the coordinates define the vertical position (from 0 to 255) where each ink reaches peak density, providing precise control over ink curves.
