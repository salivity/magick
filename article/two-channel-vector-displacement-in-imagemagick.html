Two-Channel Vector Displacement in ImageMagick

This guide explains how to apply two-channel X and Y vector displacement in ImageMagick to distort an image based on directional coordinate maps. By utilizing the Displace composite operator, you can independently control horizontal and vertical pixel shifts using dedicated color channels—typically Red for horizontal displacement and Green for vertical displacement.

Understanding Vector Displacement Maps

In ImageMagick, a two-channel displacement map encodes directional shifts using color values:

  • Red Channel (X-axis): Controls horizontal movement. Mid-gray (value 128 in 8-bit, or 50%) represents zero displacement. Values closer to white (255) shift pixels in one direction, while values closer to black (0) shift pixels in the opposite direction.
  • Green Channel (Y-axis): Controls vertical movement following the same midpoint rule.
  • Scale Factor: Sets the maximum pixel distance that full black or full white will displace the source pixels.

The Basic Command Syntax

To displace an image using ImageMagick v7, provide the base image, the displacement map, the displacement scale arguments, and the -compose Displace operation:

magick input.png displacement_map.png -define compose:args=Xscale,Yscale -compose Displace -composite output.png
  • input.png: The source image to be distorted.
  • displacement_map.png: The image containing the X (Red) and Y (Green) displacement data.
  • -define compose:args=30,30: Sets the maximum displacement to 30 pixels along the X-axis and 30 pixels along the Y-axis.
  • -compose Displace -composite: Executes the vector displacement.

Creating and Applying a Custom Two-Channel Map

If you need to generate a combined two-channel vector map from separate grayscale masks (one for horizontal shift and one for vertical shift), combine them into the Red and Green channels before displacing:

# Combine two separate grayscale masks into Red and Green channels
magick x_map.png y_map.png -combine -set colorspace sRGB combined_map.png

# Apply the displacement map to the source image
magick input.png combined_map.png -define compose:args=50,50 -compose Displace -composite output.png

Absolute vs. Relative Displacement

  • Percentage Scaling: You can define the displacement as a percentage of the image dimensions by appending % to the scale parameters (e.g., -define compose:args=10%,10%).
  • One-Dimensional Shifts: If you only want to displace along a single axis, set the unused axis scale to 0 (e.g., -define compose:args=40,0 for horizontal-only distortion).
