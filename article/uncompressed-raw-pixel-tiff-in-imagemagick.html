Uncompressed Raw Pixel TIFF in ImageMagick

This article provides an overview of storing uncompressed raw pixel data within TIFF containers using ImageMagick. It details the exact command-line options and define directives required to disable compression, suppress predictors, and write raw raster bytes directly into the TIFF structure.

In ImageMagick, storing raw, uncompressed pixels inside a TIFF container is achieved by setting the compression method to none via -compress None alongside the -define tiff:raw-pixels=true option. Applying this configuration instructs ImageMagick's LibTIFF delegate to bypass standard compression algorithms and write raw, decoded pixel buffers directly to the image strips.

Command Syntax

To convert an image to an uncompressed TIFF with raw pixel storage, use the following command structure:

magick input.png -compress None -define tiff:raw-pixels=true output.tiff

If you are using ImageMagick 6, replace magick with convert:

convert input.png -compress None -define tiff:raw-pixels=true output.tiff

Additional Configuration for Raw Storage

When storing raw raster data inside a TIFF, additional -define options help control the exact memory layout and organization of the pixel strips:

  • Predictor Configuration: Ensure no differencing or floating-point predictors alter the raw pixel stream by including -define tiff:predictor=1 (None).
  • Strip Management: Specify the number of rows per strip using -define tiff:rows-per-strip=<rows> to align pixel blocks with specific hardware or processing buffers. Setting this to the full image height writes the entire image as a single raw block.
  • Endianness: Control byte order for multi-byte pixel depths using -define tiff:endian=lsb (little-endian) or -define tiff:endian=msb (big-endian).

Uncompressed raw TIFF files eliminate decompression overhead and prevent encoding artifacts, making them ideal for medical imaging, machine vision, and real-time scientific data analysis pipelines.
