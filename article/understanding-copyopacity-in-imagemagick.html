Understanding CopyOpacity in ImageMagick

The CopyOpacity composite operator in ImageMagick transfers the tonal values or alpha channel of a mask image directly into the opacity channel of a target photo. This process converts grayscale intensities into varying levels of transparency, allowing you to cut out shapes, apply vignettes, or extract subjects without altering the original RGB color data of the base image.

How CopyOpacity Translates Values

When using CopyOpacity, ImageMagick treats the secondary image as a matte or transparency map and applies it to the primary image:

  • White Pixels (Full Intensity): Render the corresponding areas of the photo completely opaque (100% visible).
  • Black Pixels (Zero Intensity): Render the corresponding areas completely transparent (0% visible).
  • Gray Pixels (Intermediate Tones): Create semi-transparent regions, with lighter grays producing higher opacity and darker grays producing lower opacity.

If the mask image already possesses an alpha channel, CopyOpacity extracts and uses that existing alpha channel instead of converting the grayscale color values.

Image Order and Mechanics

In standard ImageMagick syntax, the order of inputs determines how the operation is applied:

  1. Destination Image (Base Photo): Provides the RGB color channels.
  2. Source Image (Mask): Provides the opacity data that replaces the destination's alpha channel.

Because JPEG files do not support an alpha channel, the resulting image must be saved in a format that supports transparency, such as PNG, TIFF, or WebP.

Standard Command Usage

In modern ImageMagick (version 7), the operation is structured using the magick command:

magick photo.jpg mask.png -alpha off -compose CopyOpacity -composite output.png

In this command:

  • photo.jpg is loaded as the base image.
  • mask.png is loaded as the mask.
  • -alpha off ensures the base photo does not carry pre-existing alpha interference.
  • -compose CopyOpacity sets the compositing algorithm.
  • -composite executes the blend, producing output.png with transparency applied.

Key Considerations

  • Dimensions: The mask and the photo should share the same pixel dimensions. If they do not, ImageMagick will align the mask to the top-left corner by default, leaving non-overlapping areas either fully opaque or transparent depending on gravity settings.
  • Inverted Masks: If your mask uses black for the subject and white for the background, apply the -negate operator to the mask before compositing to avoid making the subject transparent instead of the background.
