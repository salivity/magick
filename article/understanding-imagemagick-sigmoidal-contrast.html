Understanding ImageMagick Sigmoidal Contrast

ImageMagick’s -sigmoidal-contrast operator enhances visual detail by adjusting tonal values along an S-shaped (sigmoid) transfer curve centered around a designated pivot point. By mathematically steepening the curve at this pivot—typically the midtones—the operator expands the local dynamic range and perceptual separation of similar tones, all while smoothly compressing shadows and highlights to prevent harsh clipping.

The Sigmoidal Function and Parameters

The operator takes two primary arguments: contrast and mid-point:

magick input.png -sigmoidal-contrast [contrast]x[mid-point]% output.png
  • contrast: A positive number representing the steepness of the curve. A value of 0 leaves the image unchanged, while higher values create a sharper transition between light and dark.
  • mid-point: A percentage (typically 50%) specifying the exact tonal value where the inflection point of the curve sits.

Mathematically, the operator applies a scaled and normalized logistic function to normalized pixel values \(x \in [0, 1]\):

\[f(x) = \frac{\frac{1}{1 + e^{-\alpha (x - x_0)}} - \frac{1}{1 + e^{\alpha x_0}}}{\frac{1}{1 + e^{-\alpha (1 - x_0)}} - \frac{1}{1 + e^{\alpha x_0}}}\]

Here, \(\alpha\) represents the contrast parameter, and \(x_0\) represents the mid-point fraction.

How Dynamic Range Expands Around the Pivot

Dynamic range expansion in a digital image refers to allocating a larger portion of the available output code values (e.g., \(0\) to \(255\) in 8-bit channels) to a narrow range of input values.

The rate of change of the output values relative to the input values is determined by the derivative of the transfer function, \(f'(x)\). For a sigmoidal curve:

  1. Peak Slope at the Midpoint: The derivative \(f'(x)\) reaches its maximum precisely at \(x = x_0\) (the pivot). At this point, the slope is greater than 1 (\(f'(x_0) > 1\)).
  2. Tonal Stretching: Because the slope is greater than 1, a small interval of input brightness levels centered at \(x_0\) (for example, input values between 45% and 55%) is mapped to a significantly wider interval in the output (such as 35% to 65%). This expansion separates subtle differences in intermediate tones, dramatically boosting perceived contrast and detail around the pivot.

Non-Linear Roll-Off and Highlight/Shadow Preservation

Linear contrast adjustments multiply pixel values by a constant gain factor (\(f(x) = m \cdot x + b\)), which causes values near 0% and 100% to exceed the allowable range and clip abruptly into pure black or blown-out white.

In contrast, the sigmoidal function features asymptotic behavior at the extremes:

  • As \(x\) approaches \(0\) or \(1\), the derivative \(f'(x)\) drops below 1, approaching zero.
  • Instead of clipping, the extreme shadows and highlights are softly compressed into the remaining output range.
  • The normalized formula guarantees that an input of \(0\) remains exactly \(0\), and an input of \(1\) remains exactly \(1\).

Inverting the Operation

Using +sigmoidal-contrast applies the mathematical inverse of the S-curve. This configuration compresses the tonal range around the pivot point while expanding the dynamic range of the deep shadows and extreme highlights, which is often used in high-dynamic-range (HDR) tone-mapping pipelines to recover detail from overexposed or underexposed areas without washing out the midtones.
