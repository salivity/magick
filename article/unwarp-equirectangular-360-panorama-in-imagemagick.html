Unwarp Equirectangular 360 Panorama in ImageMagick

This guide explains how to convert a 360-degree equirectangular panoramic image into a flat, rectilinear (perspective) projection using ImageMagick. You will learn the exact mathematical transformation required to extract a standard field of view (FOV) from a spherical projection, customize viewing angles (yaw and pitch), and run the command directly from your terminal.

Understanding the Projection

An equirectangular image maps a full sphere onto a 2:1 aspect ratio rectangle, where the X-axis represents longitude (yaw) from \(-180^\circ\) to \(+180^\circ\) and the Y-axis represents latitude (pitch) from \(-90^\circ\) to \(+90^\circ\). A rectilinear projection simulates a standard pinhole camera view (gnomonic projection), projecting a portion of that sphere onto a flat plane.

The ImageMagick Command

To perform this transformation in ImageMagick 7, use the -fx operator to map each pixel of the rectilinear output back to the spherical coordinates of the equirectangular source image.

Run the following command in your terminal:

magick input_360.jpg -virtual-pixel HorizontalTile -monitor -fx '
  fov = 90 * pi / 180;
  yaw = 0 * pi / 180;
  pitch = 0 * pi / 180;
  
  nx = (2 * i / w - 1) * tan(fov / 2);
  ny = (1 - 2 * j / h) * tan(fov / 2) * (h / w);
  
  d = hypot(nx, ny);
  c = atan(d);
  
  lat = (d == 0) ? pitch : asin(cos(c) * sin(pitch) + (ny * sin(c) * cos(pitch)) / d);
  lon = yaw + atan2(nx * sin(c), (d * cos(pitch) * cos(c) - ny * sin(pitch) * sin(c)));
  
  u_norm = (lon / (2 * pi) + 0.5) - floor(lon / (2 * pi) + 0.5);
  v_norm = 0.5 - (lat / pi);
  
  u.p{u_norm * u.w, v_norm * u.h}
' -resize 1920x1080 output_rectilinear.jpg

Parameter Explanations

  • fov (Field of View): Defines the horizontal angle of view in degrees (e.g., 90 for a wide-angle standard lens). Adjust between 60 and 110 depending on the desired perspective.
  • yaw: Horizontal rotation angle in degrees. Set 0 for center-front view, 90 for right, -90 for left, or 180 for rear view.
  • pitch: Vertical tilt angle in degrees. Set 0 for straight ahead, positive values (e.g., 30) to look upward, and negative values (e.g., -30) to look downward.
  • -virtual-pixel HorizontalTile: Ensures smooth wrapping around the \(360^\circ\) boundary without black border artifacts.
  • -resize: Sets the final output resolution while maintaining the rectilinear aspect ratio.
