Use ImageMagick Hue Composite to Change Colors

This article provides a concise guide on using the Hue composite operator in ImageMagick to alter the color of an image while preserving its original lightness and texture. You will learn the fundamental command syntax, how the Hue blend mode works in relation to the HSL color model, and how to apply both solid tint colors and reference images onto target visuals directly from the command line.

Understanding the Hue Composite Operator

In color science, particularly within the HSL (Hue, Saturation, Lightness) color space, an image can be decoupled into its color tone (Hue), color intensity (Saturation), and brightness (Lightness).

When you apply the -compose Hue operator in ImageMagick:

  • Source (overlay): Supplies the new Hue value.
  • Destination (base image): Retains its original Saturation and Lightness values.

Because the destination image keeps its original lightness and saturation, shadows, highlights, and structural details are completely maintained while shifting only the base color tone.

Basic Syntax with the magick Command

In ImageMagick version 7, image composition is performed using the magick command with the -composite operator. The general syntax is:

magick destination.png source.png -compose Hue -composite output.png
  • destination.png: The base image whose lightness and saturation you want to preserve.
  • source.png: The image or color block providing the target hue.
  • output.png: The resulting image.

Changing the Color Using a Solid Fill

You do not need an external reference image to change colors; you can generate a solid color source directly within the command using an in-memory clone.

Command Example:

magick input.jpg \( +clone -fill "#0077ff" -colorize 100% \) -compose Hue -composite output.jpg

How it works:

  1. magick input.jpg: Loads the target image.
  2. \( +clone -fill "#0077ff" -colorize 100% \): Creates an in-memory duplicate with identical dimensions, completely covered by the hexadecimal color #0077ff.
  3. -compose Hue -composite: Extracts the hue component from the solid blue color and applies it across the base image, keeping the base image's original lightness intact.

Using the Legacy composite Command (ImageMagick v6)

If you are working on older systems running ImageMagick 6, the dedicated composite tool uses a reversed order of input files (source first, destination second):

composite -compose Hue color_source.png base_image.jpg output.jpg

Hue vs. Colorize Composite Operators

When working with color replacement in ImageMagick, it is essential to distinguish between -compose Hue and -compose Colorize:

  • -compose Hue: Replaces only the hue. If the destination area has low saturation (such as gray, white, or black), the new color will not appear vibrant because the low saturation is preserved.
  • -compose Colorize: Replaces both hue and saturation from the source image while preserving only the lightness of the destination image.

If your base image has neutral or desaturated regions where the new color fails to appear using Hue, switch the operator to Colorize:

magick input.jpg \( +clone -fill "#0077ff" -colorize 100% \) -compose Colorize -composite output.jpg
