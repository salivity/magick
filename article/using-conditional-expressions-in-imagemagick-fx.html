Using Conditional Expressions in ImageMagick -fx

ImageMagick's -fx operator allows for complex, pixel-by-pixel image processing using custom mathematical and logical formulas. This article explains how to construct conditional statements inside a -fx expression string, outlining the required ternary operator syntax, available logical operators, and practical command-line examples for common image manipulation tasks.

The Conditional Syntax

ImageMagick -fx expressions use the standard C-style ternary operator for conditional logic:

condition ? expression_if_true : expression_if_false

If the condition evaluates to a non-zero value (true), the entire expression returns the result of expression_if_true. If the condition evaluates to zero (false), it returns expression_if_false.

Comparison and Logical Operators

Inside the condition part of the expression, you can use standard comparison and boolean operators:

  • Equal to: ==
  • Not equal to: !=
  • Greater than: >
  • Greater than or equal to: >=
  • Less than: <
  • Less than or equal to: <=
  • Logical AND: &&
  • Logical OR: ||
  • Logical NOT: !

Common Variables

When evaluating conditions, -fx provides access to several built-in variables representing image data:

  • u: The current pixel value of the first image (values range from 0.0 to 1.0).
  • u.r, u.g, u.b: The red, green, and blue channel values of the current pixel.
  • i, j: The current column (X) and row (Y) coordinate.
  • w, h: The width and height of the image.

Practical Examples

1. Basic Luminance Threshold

To convert an image to pure black and white based on pixel brightness (thresholding at 50% intensity):

magick input.jpg -fx "u > 0.5 ? 1.0 : 0.0" output.png

2. Modifying a Specific Channel

To isolate pixels where the red channel is stronger than the green channel, setting those pixels to full intensity while leaving others unchanged:

magick input.jpg -fx "u.r > u.g ? 1.0 : u" output.png

3. Coordinate-Based Conditions

To create a split effect where the left half of an image remains unchanged and the right half is inverted:

magick input.jpg -fx "i < (w / 2) ? u : (1.0 - u)" output.png

4. Nested Conditionals

You can nest ternary operators to evaluate multiple criteria. For example, dividing pixel values into three distinct output tiers (dark, medium, bright):

magick input.jpg -fx "u < 0.33 ? 0.0 : (u < 0.66 ? 0.5 : 1.0)" output.png
