Using DstIn to Apply Shape Masks in ImageMagick

The DstIn (Destination In) composition operator in ImageMagick allows you to mask an image using the shape and transparency of another image. By utilizing the Porter-Duff compositing model, DstIn retains the pixel content of the destination image only where it overlaps with the non-transparent areas of the source image. This guide explains how the DstIn operator works and provides direct command-line examples to apply custom shape masks to your graphics.

Understanding the DstIn Operator

In ImageMagick's composition workflow, the first image specified in the command is the Destination (the image you want to keep), and the second image is the Source (the mask).

When you apply the DstIn composition method:

  • The color and detail of the Destination image are preserved.
  • The opacity of the Destination image is modified to match the alpha channel of the Source image.
  • Any part of the Destination image that falls outside the opaque regions of the Source mask becomes completely transparent.

Basic Syntax

To apply a mask using DstIn, use the following structure:

magick destination.png mask.png -compose DstIn -composite output.png

Note: For ImageMagick version 6, replace magick with convert.

Applying an External Shape Mask

If you have a source photo (photo.jpg) and a transparent PNG containing your desired shape (mask.png), ensure both images are the same dimensions, then run:

magick photo.jpg mask.png -alpha set -compose DstIn -composite masked_result.png
  • -alpha set ensures the destination image has an active transparency channel to receive the mask shape.
  • The output format should support transparency (such as PNG, TIFF, or WebP).

Creating and Applying a Mask On the Fly

You can also generate a vector mask dynamically within a single command using ImageMagick's parenthetical expressions.

Circular Shape Mask

To crop a 400x400 image into a perfect circle:

magick input.jpg -alpha set \
  \( -size 400x400 xc:none -fill white -draw "circle 200,200 200,0" \) \
  -compose DstIn -composite circle_output.png

Rounded Rectangle Mask

To apply a rounded rectangle shape to a 600x400 image:

magick input.jpg -alpha set \
  \( -size 600x400 xc:none -fill white -draw "roundrectangle 0,0 600,400 30,30" \) \
  -compose DstIn -composite rounded_output.png

Key Considerations

  • Alpha Channel Requirement: The mask image must use an alpha channel to define the shape. White pixels without transparency will not create a cutout; non-transparent pixels define what remains visible, while transparent pixels (xc:none or transparent alpha) define the removed areas.
  • Grayscale Masks: If your mask is a black-and-white image without transparency (a luminance mask), you must first convert the grayscale values into an alpha channel using -alpha copy before applying the DstIn operation.
