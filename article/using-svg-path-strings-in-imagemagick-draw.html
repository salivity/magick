Using SVG Path Strings in ImageMagick Draw

ImageMagick enables the rendering of complex vector graphics directly onto raster canvases through its -draw "path '...'" syntax, which directly implements the W3C SVG path specification. This article details how ImageMagick interprets standard SVG path data commands, coordinates, and styling options, allowing developers to execute precise vector operations via the command-line interface without converting entire SVG files.

The -draw "path '...'" Primitive

ImageMagick's -draw option provides a path graphic primitive designed to parse SVG path syntax (d="..." in standard SVG). Because the path data contains spaces and coordinate pairs, proper shell quoting is required:

magick -size 500x500 xc:white -fill none -stroke black -strokewidth 2 \
  -draw "path 'M 50,50 L 200,50 L 200,200 Z'" output.png

The string passed inside the nested quotes follows standard SVG whitespace-separated or comma-separated command and coordinate structures.

Supported SVG Path Commands

ImageMagick supports the core SVG path commands, differentiating between absolute coordinates (uppercase letters) and relative coordinates (lowercase letters):

  • MoveTo (M, m): Sets the current point without drawing. M x,y moves to an absolute position, while m dx,dy moves relative to the previous point.
  • LineTo (L, l, H, h, V, v): Draws straight lines. L x,y draws to an absolute point; l dx,dy draws to a relative point. Horizontal (H, h) and vertical (V, v) shortcuts take single-axis values.
  • Cubic Bézier Curve (C, c, S, s): C x1,y1 x2,y2 x,y creates a cubic Bézier curve using two control points and an endpoint. Smooth cubic Bézier (S, s) assumes the first control point is a reflection of the previous curve's control point.
  • Quadratic Bézier Curve (Q, q, T, t): Q x1,y1 x,y draws a curve with a single control point. Smooth quadratic Bézier (T, t) continues the curve using a mirrored control point.
  • Elliptical Arc (A, a): A rx ry x-axis-rotation large-arc-flag sweep-flag x y draws an elliptical arc based on radii, rotation, and boolean flags controlling arc orientation.
  • ClosePath (Z, z): Connects the current position back to the initial point of the current subpath.

Controlling Vector Styles

Path geometry rendered through -draw 'path' inherits properties from preceding ImageMagick settings rather than embedding CSS or inline XML attributes:

  • Fill and Stroke: Controlled using -fill <color> and -stroke <color>. Setting -fill none creates open, stroked paths.
  • Stroke Width and Caps: Configured using -strokewidth <pixels>, -strokelinecap <butt|round|square>, and -strokelinejoin <miter|round|bevel>.
  • Fill Rule: Handled via -fill-rule <evenodd|nonzero>, replicating SVG's winding rules for overlapping or self-intersecting path segments.

Coordinate Systems and Canvas Bounds

Path calculations rely on pixel coordinates based from the top-left origin (0,0) of the input or defined canvas. ImageMagick renders these paths using internal anti-aliasing algorithms to project continuous mathematical curves onto discrete pixel grids, providing visual parity with standard SVG renderers while operating within a pure raster pipeline.
