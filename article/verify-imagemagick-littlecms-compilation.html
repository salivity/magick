Verify ImageMagick LittleCMS Compilation

Verifying that ImageMagick includes LittleCMS (lcms or lcms2) support is essential for accurate color space conversions, ICC profile rendering, and color management workflows. This guide demonstrates how system administrators can quickly check ImageMagick build configurations using the command line, verify delegate integration, and run a practical test to ensure color management functions properly at runtime.

Check the Build Delegates

The quickest way to verify LittleCMS integration is to check the compiled delegates using the main binary:

For ImageMagick 7:

magick -version

For ImageMagick 6:

convert -version

Examine the Delegates (built-in): line in the output. If the compilation was successful, you will see either lcms or lcms2 listed among the libraries. For example:

Version: ImageMagick 7.1.1-28 Q16-HDRI x86_64
Features: Cipher DPC HDRI Modules OpenMP
Delegates (built-in): bzlib cairo fontconfig freetype heic jbig jng jp2 jpeg lcms lqr lzma openexr png raw tiff webp xml zlib

If lcms or lcms2 is absent from this list, ImageMagick cannot perform LittleCMS-based color transformations.

Inspect the Configuration List

To get more detailed build settings, query the configuration parameters directly:

magick -list configure | grep -i delegates

Look for lcms or lcms2 within the DELEGATES key:

DELEGATES      = bzlib fontconfig freetype heic jng jp2 jpeg lcms png tiff webp zlib

You can also check the configuration flags used during compilation to confirm that LittleCMS was not explicitly disabled:

magick -list configure | grep -i lcms

Look for LIBS linking against -llcms2 (or -llcms) and include flags pointing to the LittleCMS headers.

Perform a Functional Test

Even if the delegate appears in the list, performing a color profile assignment verifies that the runtime dynamic linker resolves the LittleCMS shared library correctly:

magick -size 100x100 xc:white -profile sRGB.icc test.jpg

If LittleCMS is properly linked, this command creates test.jpg without any errors or warnings. If LittleCMS is missing or misconfigured, ImageMagick will throw a delegate error or a warning stating that color profiles cannot be transformed without LittleCMS support.
