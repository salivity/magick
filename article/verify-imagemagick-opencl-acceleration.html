Verify ImageMagick OpenCL Acceleration

This guide explains how to verify whether ImageMagick is actively using OpenCL hardware acceleration on your system. By setting specific debugging and configuration environment variables, you can monitor GPU execution logs, confirm device initialization, and ensure your image processing tasks are taking advantage of hardware acceleration rather than falling back to CPU processing.

The Primary Environment Variable: MAGICK_DEBUG

The primary environment variable used to verify that OpenCL acceleration is functional in ImageMagick is MAGICK_DEBUG. Setting this variable to Accelerate or OpenCL forces ImageMagick to output real-time diagnostic information regarding OpenCL initialization, kernel compilation, and device execution.

To test acceleration on Linux or macOS, run:

MAGICK_DEBUG=Accelerate magick input.jpg -blur 0x8 output.jpg

On Windows (Command Prompt):

set MAGICK_DEBUG=Accelerate
magick input.jpg -blur 0x8 output.jpg

On Windows (PowerShell):

$env:MAGICK_DEBUG="Accelerate"
magick input.jpg -blur 0x8 output.jpg

Interpreting the Debug Output

When OpenCL is functioning correctly, the console output will display lines detailing:

  • The detection of OpenCL-capable devices (GPUs or accelerators).
  • The selection of the active OpenCL profile and device name.
  • Kernel compilation and caching events.
  • Execution times for accelerated algorithms (such as resize, blur, or convolve operations).

If OpenCL is unavailable, misconfigured, or disabled, the output will indicate that OpenCL failed to initialize or that ImageMagick has fallen back to standard CPU multi-threading.

Supporting Environment Variable: MAGICK_OCL_DEVICE

You can also use the MAGICK_OCL_DEVICE environment variable to control and verify device selection.

  • Specify a Device: Set MAGICK_OCL_DEVICE to the specific device index (e.g., 0, 1) to force ImageMagick to use a particular GPU.
  • Disable OpenCL: Setting MAGICK_OCL_DEVICE=OFF disables acceleration, allowing you to run performance benchmarks comparing execution times with and without OpenCL.

Checking Build Support

Before testing environment variables, ensure your ImageMagick binary was compiled with OpenCL support by running:

magick -version

Look for OpenCL in the Features list. If OpenCL is present, configuring MAGICK_DEBUG=Accelerate will provide full visibility into hardware-accelerated operations.
