Vintage Photo Effect with Scratches in ImageMagick

This guide demonstrates how to transform standard digital images into aged, vintage photographs using ImageMagick's command-line tools. By combining color grading, sepia toning, film grain, vignetting, and a scratch texture overlay, you can reproduce an authentic antique photo aesthetic directly from your terminal.

The Complete ImageMagick Command

To apply a vintage grade and composite an external scratch texture onto an image, use the following syntax (compatible with ImageMagick 7):

magick input.jpg \
  -modulate 110,70,100 \
  -sepia-tone 80% \
  -attenuate 0.4 +noise Gaussian \
  \( +clone -background black -vignette 0x25 \) -compose multiply -composite \
  \( scratches.png -resize %[w]x%[h]\! -colorspace Gray \) -compose screen -composite \
  vintage_output.jpg

(Note: For ImageMagick 6, replace the initial magick keyword with convert.)

Parameter Breakdown

  • -modulate 110,70,100: Slightly increases brightness (110%) and reduces color saturation (70%) to simulate the faded color profile of aged prints before applying the sepia effect.
  • -sepia-tone 80%: Applies the classic warm brown tint characteristic of early chemical photo processing. The percentage value controls the intensity of the sepia tone.
  • -attenuate 0.4 +noise Gaussian: Adds simulated analog film grain. The -attenuate flag limits the intensity of the noise generated by +noise Gaussian.
  • \( +clone -background black -vignette 0x25 \) -compose multiply -composite:
    • Clones the current image state.
    • Applies a -vignette to create soft, darkened edges typical of vintage camera lenses.
    • Uses the multiply blend mode to merge the darkened edges back onto the base image.
  • \( scratches.png -resize %[w]x%[h]\! -colorspace Gray \) -compose screen -composite:
    • Loads a black-and-white scratch texture overlay file (scratches.png).
    • Automatically resizes the texture to match the exact dimensions (%[w]x%[h]\!) of the input image.
    • Ensures the texture is in grayscale format.
    • Uses the screen blending mode so that the white scratches remain visible while the black background becomes completely transparent.

Procedural Scratch Effect (Without External Textures)

If you do not have an external scratch texture image, you can procedurally generate fine scratches and dust using ImageMagick's built-in noise generators:

magick input.jpg \
  -sepia-tone 75% \
  -attenuate 0.3 +noise Gaussian \
  \( +clone -background black -vignette 0x20 \) -compose multiply -composite \
  \( -size %[w]x%[h] xc:black \
     +noise Random -virtual-pixel tile -blur 0x15 -threshold 99.8% \
     -motion-blur 0x25+45 \) \
  -compose screen -composite \
  vintage_procedural.jpg
  • -motion-blur 0x25+45: Takes isolated noise specks generated by thresholding random noise and streaks them at a 45-degree angle, simulating linear surface scratches.
