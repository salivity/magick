Voronoi Diagrams in ImageMagick Using Sparse-Color

This guide explains how to generate Voronoi diagrams directly from a list of coordinate points using ImageMagick's -sparse-color operator. You will learn the underlying command structure, the format required for inputting points and colors, how to render solid partitions, and how to extract cell boundaries for clean diagram outlines.

The Basic Command Structure

ImageMagick provides the sparse-color operator to interpolate or partition an image space from a sparse set of points. When using the Voronoi method, the engine assigns each pixel in the canvas the color of the nearest defined coordinate point according to Euclidean distance.

The general syntax using ImageMagick 7 is:

magick -size <WIDTH>x<HEIGHT> xc:white -sparse-color Voronoi '<X1>,<Y1> <COLOR1>  <X2>,<Y2> <COLOR2> ...' output.png

Note: If you are using ImageMagick 6, replace magick with convert.

Step-by-Step Implementation

1. Define Canvas Dimensions

The canvas size defines the bounding box for your diagram. If any coordinates fall outside this resolution, they will still influence the partition of the visible area, but won't appear on screen.

2. Format Coordinates and Colors

Points must be passed to the Voronoi argument as space-separated tokens where each point consists of X,Y immediately followed by its color definition (e.g., hex code, RGB, or named color):

"50,50 red  150,80 blue  80,180 green  180,160 yellow"

3. Generate the Image

Execute the following command to render a 200x200 pixel Voronoi diagram with four distinct cells:

magick -size 200x200 xc:none -sparse-color Voronoi \
  "50,50 #e74c3c  150,80 #3498db  80,180 #2ecc71  180,160 #f1c40f" \
  voronoi_colored.png

Extracting Boundary Edges

To turn a solid color partition into a standard line-drawn Voronoi diagram, apply morphological edge detection immediately after the sparse-color step.

magick -size 200x200 xc:none -sparse-color Voronoi \
  "50,50 red  150,80 blue  80,180 green  180,160 yellow" \
  -morphology Edge Diamond \
  -negate \
  voronoi_edges.png
  • -morphology Edge Diamond: Detects color transitions and converts boundaries into lines.
  • -negate: Inverts the result so borders appear as dark lines on a white background instead of white lines on black.

Automating Large Coordinate Lists

For large datasets, passing arguments directly on the command line can become unwieldy. You can store your coordinates in a shell variable or read them from an external file:

# Define points list
POINTS="30,40 #ff0000 120,60 #00ff00 90,140 #0000ff 170,170 #ffff00 40,160 #ff00ff"

# Generate diagram
magick -size 200x200 xc:none -sparse-color Voronoi "$POINTS" voronoi_large.png

Alternatively, pass coordinates directly from a text file using standard shell expansion:

magick -size 500x500 xc:none -sparse-color Voronoi "$(< points.txt)" voronoi_from_file.png

Inside points.txt, ensure coordinates and colors are separated by spaces or newlines:

50,50   #e6194b
120,80  #3cb44b
200,300 #ffe119
350,150 #4363d8
400,420 #f58231
