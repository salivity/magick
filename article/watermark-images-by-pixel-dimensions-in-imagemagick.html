Watermark Images by Pixel Dimensions in ImageMagick

Applying a watermark conditionally based on output pixel dimensions in ImageMagick allows you to protect high-resolution photos while leaving thumbnails or smaller web variants unmarked. This article demonstrates how to evaluate image width and height directly inside ImageMagick 7 commands using conditional FX expressions, as well as how to implement dimension-checking logic in a batch script.

Conditional Watermarking in ImageMagick 7

ImageMagick 7 introduces inline FX expressions that can dynamically inspect the dimensions of the base image. You can conditionally adjust the watermark's transparency to 0% (making it completely invisible) if the base image's width or height does not meet your specified threshold.

Run the following command to apply a watermark only if the base image width exceeds 1200 pixels:

magick input.jpg watermark.png -gravity southeast \
  -channel A -evaluate multiply "%[fx:u.w > 1200 ? 0.7 : 0]" +channel \
  -composite output.jpg

How It Works

  • input.jpg watermark.png: Loads the target image as the first image index (u or u[0]) and the watermark as the second (v or u[1]).
  • -gravity southeast: Positions the watermark in the bottom-right corner of the base image.
  • -channel A: Restricts subsequent operations to the alpha (transparency) channel of the images.
  • -evaluate multiply "%[fx:u.w > 1200 ? 0.7 : 0]": Checks if the base image width (u.w) is greater than 1200 pixels. If true, it scales the watermark's alpha channel by 0.7 (70% opacity). If false, it multiplies by 0, rendering the watermark completely transparent.
  • +channel: Resets channel operations back to all channels.
  • -composite output.jpg: Merges the two layers together and outputs the file.

Watermarking by Height or Total Area

You can adapt the FX expression to evaluate image height, minimum dimensions, or total pixel area:

  • Height-based threshold (greater than 800px): "%[fx:u.h > 800 ? 0.7 : 0]"

  • Both width and height threshold (both must qualify): "%[fx:(u.w >= 1920 && u.h >= 1080) ? 0.7 : 0]"

  • Total pixel count (megapixels): "%[fx:(u.w * u.h) > 2000000 ? 0.7 : 0]"

Bash Scripting Approach for ImageMagick 6 and 7

If you are using ImageMagick 6, or prefer explicit control before running the composite step, query the image dimensions using identify (or magick identify) and conditionally execute the watermark step using a shell script:

#!/usr/bin/env bash

INPUT="input.jpg"
OUTPUT="output.jpg"
WATERMARK="watermark.png"
THRESHOLD_WIDTH=1200

# Extract the width of the input image
WIDTH=$(magick identify -format "%w" "$INPUT")

if [ "$WIDTH" -gt "$THRESHOLD_WIDTH" ]; then
    magick "$INPUT" "$WATERMARK" -gravity southeast -compose dissolve -define compose:args=70 -composite "$OUTPUT"
else
    # Keep the original image without applying the watermark
    cp "$INPUT" "$OUTPUT"
fi

This method avoids loading the watermark entirely when the file does not meet your dimension requirements, which can save CPU cycles during large batch processing jobs.
