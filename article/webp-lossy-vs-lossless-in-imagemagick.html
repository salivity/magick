WebP Lossy vs Lossless in ImageMagick

Converting images to the WebP format using ImageMagick allows you to optimize file sizes while controlling visual fidelity. This guide explains how to set the lossy and lossless compression flags using ImageMagick's command-line interface, along with the appropriate quality settings for each mode.

Setting Lossless WebP Compression

To enable lossless compression, use the -define webp:lossless=true flag. In lossless mode, ImageMagick preserves all original pixel data without any generation loss.

When using lossless WebP, the -quality parameter changes its behavior: instead of controlling visual degradation, it controls the compression effort and processing time from 0 (fastest, larger file) to 100 (slowest, smallest file). The default quality setting for lossless mode is typically 75.

magick input.png -define webp:lossless=true -quality 75 output.webp

(Note: For older versions of ImageMagick 6, replace magick with convert.)

Setting Lossy WebP Compression

ImageMagick applies lossy compression by default when converting to WebP. However, you can explicitly enforce it using the -define webp:lossless=false flag.

In lossy mode, the -quality parameter directly dictates the visual quality versus file size trade-off on a scale from 0 (lowest quality, highest compression) to 100 (highest quality, lowest compression). A setting between 75 and 85 is typically recommended for general web use.

magick input.jpg -define webp:lossless=false -quality 80 output.webp

Summary of Flags

  • Lossless Mode:
    • Flag: -define webp:lossless=true
    • -quality behavior: Sets compression effort (file size vs. processing speed).
    • Best for: Icons, screenshots, diagrams, and sharp graphics with transparency.
  • Lossy Mode:
    • Flag: -define webp:lossless=false (or omitted)
    • -quality behavior: Sets visual fidelity (perceptual quality vs. file size).
    • Best for: Photographs and complex color imagery.
