Write PNG32 with 8-Bit Alpha in ImageMagick

This article explains how to export images to the PNG32 format with explicit 8-bit alpha channels using ImageMagick. By default, ImageMagick often optimizes PNG outputs into smaller depths like PNG8 or PNG24 if it detects limited color ranges or binary transparency. Following the instructions below, you will learn the exact syntax and flags required to force an uncompressed, true-color 32-bit RGBA output containing a dedicated 8-bit transparency layer.

The Explicit PNG32 Format Prefix

ImageMagick provides built-in subformats for PNG outputs. To guarantee an output contains 8 bits each for red, green, blue, and alpha channels (totaling 32 bits per pixel), prepend the output filename with the PNG32: subformat specifier.

Basic Command Syntax

In ImageMagick 7, use the magick command:

magick input.png PNG32:output.png

For legacy ImageMagick 6 installations, use convert:

convert input.png PNG32:output.png

Prefixing the filename overrides ImageMagick's automatic PNG compression heuristics, ensuring that the final file is saved as a 32-bit RGBA image rather than being downgraded to indexed PNG8 or 24-bit RGB without transparency.

Guaranteeing the 8-Bit Alpha Channel

If the source image does not already have an alpha channel, or if it has 1-bit binary transparency, you must explicitly enable the alpha channel and define the bit depth.

Use the -alpha on (or -alpha set) and -depth 8 flags to configure the channel data properly:

magick input.jpg -alpha set -depth 8 PNG32:output.png
  • -alpha set: Activates the alpha channel if not already present.
  • -depth 8: Ensures each individual channel (R, G, B, and A) is explicitly written at 8-bit precision (giving 256 levels of transparency).
  • PNG32:: Prevents the encoder from stripping the alpha channel or reducing color depth during file write.

Practical Example: Creating a Transparent Gradient

To generate a new image with semi-transparent elements and write it directly to PNG32:

magick -size 100x100 gradient:none-black -depth 8 PNG32:gradient_alpha.png

This creates a 100x100 gradient fading from fully transparent to black, stored strictly with an 8-bit alpha channel.

Verifying the Output

To verify that your file was written correctly as a 32-bit RGBA image with an 8-bit alpha channel, run the identify tool:

magick identify -verbose output.png

In the output, check the following properties:

  • Format: Should display PNG (Portable Network Graphics) or indicate PNG32.
  • Depth: Should show 8-bit.
  • Type: Should be listed as TrueColorAlpha.
  • Channel depth -> Alpha: Should confirm 8-bit.
